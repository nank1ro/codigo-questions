# --description--

Una comprehension puede tener **más de un `for`**.
Funcionan como bucles anidados: el primer `for` es el bucle externo, el segundo es el interno.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
