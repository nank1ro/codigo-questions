# --description--

Dentro de una comprehension puedes usar cualquier variable definida antes, por ejemplo como límite de un `range()`.

# --instructions--

Ordena los elementos para imprimir los múltiplos de 7 por debajo de `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
multiples = [n for n in range(1, limit) if n % 7 == 0]
print(multiples)
```
