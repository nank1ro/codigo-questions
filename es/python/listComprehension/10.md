# --description--

Las dos posiciones de `if` se confunden fácilmente, así que mantenlas separadas:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else antes del for: elige un valor, else obligatorio
positives = [n for n in nums if n > 0]      # if después del for: filtra, else no permitido
```
Poner un `else` después del filtro `if` es un error de sintaxis.

# --instructions--

¿Cuál es el __problema__ con este fragmento de código?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- El `if` de filtro después del `for` no puede tener un `else`: un `if-else` debe ir antes del `for`
- Una list comprehension no puede contener una condición
- `nums` contiene un número negativo, lo cual no está permitido
- `else` debe reemplazarse por `elif`
