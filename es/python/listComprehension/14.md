# --description--

La misma idea funciona para diccionarios: una **dict comprehension** usa llaves y una expresión `key: value`:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
