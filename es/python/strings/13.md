# --description--

`find(sub)` devuelve el **índice** de la primera aparición de `sub`, o `-1` si no se encuentra:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` devuelve **cuántas veces** aparece `sub`:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

Guarda en `position` el índice de la primera `o` en `text`, en `missing` el resultado de buscar `z`, y en `total` cuántas `o` contiene el texto
