# --description--

Ya sabes que `+` une dos cadenas (**concatenación**).
El operador `*` **repite** una cadena un número determinado de veces:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
La repetición es una forma rápida de dibujar separadores y patrones simples.
