# --description--

La función incorporada `len()` devuelve la **longitud** de una cadena, es decir, cuántos caracteres contiene.
Los espacios y la puntuación también cuentan como caracteres:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
