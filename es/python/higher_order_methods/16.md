# --instructions--

Escribe un decorador `memoize` para funciones de un argumento: debe guardar cada resultado en un diccionario dentro del closure, de modo que llamar de nuevo a la función decorada con el mismo argumento retorne el resultado guardado sin llamar a la función original

# --asserts--

La función decorada debe retornar los mismos resultados que la original

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

Repetir una llamada no debe ejecutar la función original otra vez

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

Cada función decorada debe tener su propia caché

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
