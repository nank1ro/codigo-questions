# --description--

Un pequeño programa asíncrono sigue una forma fija: importar `asyncio`, definir las funciones corrutina, definir una corrutina `main` que las espere con `await` y, finalmente, llamar a `asyncio.run(main())` una vez al final.

# --instructions--

Ordena los elementos para construir un programa que empiece con el import, defina `download` antes de `main`, ejecute dos descargas de forma concurrente con `asyncio.gather` e imprima los resultados, produciendo la salida `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

['report.pdf', 'data.csv']
