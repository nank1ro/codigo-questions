# --description--

Una tarea sigue ejecutándose haya o no alguien esperándola. Créala temprano, haz otro trabajo y hazle `await` solo en el punto donde se necesita su resultado: la espera es más corta porque parte de la tarea ya se ejecutó en segundo plano. Una tarea también puede consultarse con `task.done()`, que retorna `True` una vez que terminó.

# --instructions--

Completa el código para que `compute()` se programe como tarea, `"waiting"` se imprima mientras se ejecuta y luego se espere la tarea con `await` para obtener su valor, produciendo la salida `waiting`, `42`

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```
