# --description--

Con `gather`, las corrutinas se turnan en cada `await`. Una corrutina se ejecuta hasta que espera algo que aún no está listo, y entonces el bucle cambia a otra. Los efectos secundarios como `print` ocurren por lo tanto en el orden en que las corrutinas **se reanudan**, no en el orden en que se pasaron:
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    print(await asyncio.gather(step("a", 0.03), step("b", 0.01)))

asyncio.run(main())
```
Esto imprime `b`, luego `a` y luego `['a', 'b']`: `b` se despierta primero, pero la lista de resultados mantiene el orden de los argumentos.

```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    names = await asyncio.gather(step("x", 0.03), step("y", 0.01), step("z", 0.02))
    print(names)

asyncio.run(main())
```

- `x`, `y`, `z`, luego `['x', 'y', 'z']`, porque `gather` ejecuta las corrutinas una tras otra
- `y`, `z`, `x`, luego `['y', 'z', 'x']`, porque `gather` retorna los resultados en orden de finalización
- `x`, `y`, `z`, luego `['y', 'z', 'x']`, porque las impresiones ocurren antes de que comience cualquier espera
