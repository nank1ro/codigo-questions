# --description--

Debido a que el cuerpo debe ser una única expresión, una lambda **no puede contener sentencias**.
Ni `return`, ni bloques `if`, ni bucles, ni asignaciones:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Si necesitas algo de eso, escribe en su lugar una función `def` normal.

# --instructions--

¿Cuál es el __problema__ con este fragmento de código?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- El cuerpo de una lambda es una expresión, no puede contener return
- Una lambda no se puede guardar en una variable
- Una lambda no se puede llamar con paréntesis
- Una lambda necesita al menos dos parámetros
