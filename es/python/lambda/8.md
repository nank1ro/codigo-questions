# --description--

La lambda de `key` puede elegir cualquier parte de un elemento.
Para una lista de listas, `lambda p: p[1]` ordena por el segundo elemento de cada lista interna.

# --instructions--

Ordena los elementos para imprimir a las personas de la más joven a la mayor

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
