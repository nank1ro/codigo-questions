# --description--

`map()` aplica una función a **cada elemento** de una lista.
Retorna un objeto especial _map_, así que envuélvelo en `list()` para ver los valores:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
