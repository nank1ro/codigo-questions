# --description--

`and` y `or` no siempre devuelven `True` o `False`: devuelven uno de sus **operandos**. `a and b` devuelve `a` si es falso, y si no `b`; `a or b` devuelve `a` si es verdadero, y si no `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
El resultado es verdadero o falso exactamente cuando lo es toda la expresión, y por eso `if a and b:` sigue funcionando. Un uso habitual es un valor por defecto: `name = user_input or "guest"`.

# --instructions--

¿Qué muestra este código?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, porque `or` devuelve el primer operando verdadero y `and` el primero falso, o el último operando cuando no hay ninguno
- `True False True`, porque los operadores lógicos siempre producen un booleano
- `0 3 x`, porque `and` y `or` siempre devuelven su primer operando
- `5 3 y`, porque ambos operadores devuelven el operando verdadero
