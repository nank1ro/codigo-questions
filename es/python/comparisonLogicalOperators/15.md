# --instructions--

Ordena los elementos para definir el diccionario `users` y la función `can_login`, que usa `name in users` para proteger la búsqueda, y luego muestra el resultado para Ada con la contraseña correcta y para Grace, que no está registrada, produciendo la salida `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
