# --instructions--

¿Qué muestra este código?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, porque `c` es otro nombre para la misma lista que `a`, así que añadir a través de `c` cambia `a` y hace que sea distinta de `b`
- `True True [1, 2]`, porque `c = a` copia la lista, así que `a` no cambia
- `True False [1, 2, 3]`, porque `is` compara valores y `==` compara identidad
- `False False [1, 2, 3]`, porque `append` crea una lista nueva, así que `c` ya no se refiere a `a`
