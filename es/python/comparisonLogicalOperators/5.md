# --description--

Cuando `not`, `and` y `or` aparecen en una misma expresión, Python aplica primero `not`, luego `and` y luego `or`. Así que `a or b and c` significa `a or (b and c)`, y `not a == b` significa `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Cuando se busca una agrupación distinta, añade paréntesis; además hacen la expresión más fácil de leer.

# --instructions--

¿Qué muestra este código?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, porque `and` se aplica antes que `or`, así que la expresión se lee `x == 3 or (x > 10 and x < 0)`
- `False`, porque los operadores se aplican de izquierda a derecha: `(x == 3 or x > 10) and x < 0`
- `False`, porque `x < 0` es falso y todas las condiciones de la expresión deben cumplirse
- Un `SyntaxError`, porque `and` y `or` no se pueden mezclar sin paréntesis
