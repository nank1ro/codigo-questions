# --description--

Como `if value:` ya aplica el valor de verdad, comparar con `== True` o `== False` es innecesario e incluso puede ser incorrecto: `2 == True` es `False`, y sin embargo `2` es verdadero. Comprueba el valor en sí:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Escribe una función `count_truthy(values)` que devuelva cuántos elementos de la lista `values` son verdaderos

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
