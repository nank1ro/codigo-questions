# --description--

A veces un manejador debe reaccionar ante un fallo sin asumir la responsabilidad de él: registrarlo, contarlo, cerrar algo — y luego dejar que quien llama se ocupe. Un `raise` a solas dentro de un bloque `except` **vuelve a lanzar** la excepción que se está manejando, con su tipo, mensaje y traceback originales intactos:
```python
try:
    value = int(text)
except ValueError:
    print("could not read the value")
    raise
```
Escribir `raise ValueError(...)` en su lugar construiría una excepción nueva y descartaría el traceback original, que es exactamente la información que necesitas al depurar.

def load(text):

    except ValueError:
        print(f"could not read {text}")
        raise

try:
    load("abc")
except ValueError:
    print("handled by the caller")
