# --description--

Hay una trampa al crear un **set vacío**.
Las llaves también son la sintaxis de los diccionarios, por lo que `{}` crea un **diccionario** vacío, no un set:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Para obtener un set vacío debes llamar a `set()` sin argumentos:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

¿Qué imprime este código?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, porque `{}` crea un diccionario vacío
- `<class 'set'>`, porque las llaves crean un set
- `<class 'NoneType'>`, porque el set no tiene elementos
- Un `SyntaxError`, porque las llaves deben contener al menos un elemento
