# --description--

Cuando una clave contiene otro objeto o un array, el patrón simplemente puede continuar y describir también esa forma:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Cuidado con lo que esa línea crea: `address: { city }` significa "entra en `address`", no "dame `address`", así que solo `city` se convierte en variable. Para conseguir ambos, menciona la clave dos veces: `const { address, address: { city } } = user;`. Los patrones de array y de objeto se anidan libremente entre sí, como en `{ tags: [first] }`.

# --asserts--

Una ciudad anidada debe devolverse.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Una ciudad anidada diferente debe devolverse.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Una dirección vacía debe dar `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Las demás claves de la dirección deben ignorarse.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Una ciudad explícitamente `undefined` debe dar `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
