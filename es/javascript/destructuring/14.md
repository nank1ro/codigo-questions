# --description--

Un parámetro destructurado con valores por defecto forma un objeto de opciones elegante, pero sigue fallando cuando quien llama no pasa nada: leer una clave de `undefined` lanza un `TypeError`. Dar al patrón entero un valor por defecto `{}` lo arregla:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// prints guest/false
```
Lee la línea de fuera hacia dentro: `= {}` aporta un objeto vacío cuando falta el argumento, y después cada valor por defecto interno rellena su propia clave.

# --asserts--

Llamar a `button()` sin argumento debe usar ambos valores por defecto.

```javascript
tryCatch(button() === "OK/medium");
```

Un objeto vacío también debe usar ambos valores por defecto.

```javascript
tryCatch(button({}) === "OK/medium");
```

Dar solo `label` debe mantener el tamaño por defecto.

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

Dar solo `size` debe mantener la etiqueta por defecto.

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

Si se dan ambas opciones, deben usarse.

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
