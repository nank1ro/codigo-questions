# --description--

Los patrones de objeto y los valores por defecto se combinan exactamente igual que los de array, lo que los convierte en una forma ordenada de leer un objeto de configuración cuyas claves pueden estar o no:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// imprime dark en
```
Como el patrón entero es una sola sentencia, una función puede desempaquetar todo lo que necesita de su argumento en su misma primera línea.

# --asserts--

Ambas claves presentes deben usarse.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Un usuario diferente debe dar una cadena diferente.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

Una `city` ausente debe recurrir a `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Las claves extra deben ignorarse.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

El orden de las claves no debe importar.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
