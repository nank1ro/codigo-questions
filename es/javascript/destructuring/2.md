# --description--

La destructuración es más útil justo donde llega un array: un argumento de función, o el resultado de una llamada. En lugar de conservar el array e indexarlo por todas partes, lo desempaquetas una vez y das a las partes nombres reales:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// imprime 5
```
No se copia ni se cambia nada en el array original, el patrón solo lee de él.

# --asserts--

`label(["Ada", 90])` debe devolver `"Ada: 90"`.

```javascript
tryCatch(label(["Ada", 90]) === "Ada: 90");
```

`label(["Bob", 0])` debe devolver `"Bob: 0"`.

```javascript
tryCatch(label(["Bob", 0]) === "Bob: 0");
```

Una puntuación negativa debe conservarse tal cual.

```javascript
tryCatch(label(["Cy", -3]) === "Cy: -3");
```

`label(["Dee", 100])` debe devolver `"Dee: 100"`.

```javascript
tryCatch(label(["Dee", 100]) === "Dee: 100");
```

Los elementos extra deben ignorarse.

```javascript
tryCatch(label(["Eve", 55, "extra"]) === "Eve: 55");
```
