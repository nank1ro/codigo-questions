# --description--

El método `indexOf()` devuelve el índice donde aparece **por primera vez** un fragmento de texto en la cadena.
Si el texto no se encuentra, devuelve `-1`:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
