# --instructions--

Ordena las líneas para mostrar una línea de recibo: `item` rellenado con puntos hasta 8 caracteres, seguido del precio alineado a la derecha en 6 caracteres

# --answers--

```javascript
let item = "Tea";
```

```javascript
let row = item.padEnd(8, ".");
```

```javascript
row = row + "2.50".padStart(6);
```

```javascript
console.log(row);
```
