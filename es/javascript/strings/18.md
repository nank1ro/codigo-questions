# --description--

Las cadenas son **inmutables**: una vez creada, una cadena nunca puede cambiarse.
Asignar a un índice no hace nada, y todo método de cadena devuelve una **nueva** cadena en lugar de modificar la original:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
Para conservar un resultado, asígnalo de nuevo a la variable:
```javascript
word = word.toUpperCase();
```

# --instructions--

El primer `console.log` muestra `hello` porque `toUpperCase()` no modificó `word`. Completa el código para que el segundo `console.log` muestre `HELLO`
