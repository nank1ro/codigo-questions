# --description--

El texto que viene de formularios, archivos o URLs siempre es una cadena, incluso cuando representa un número o un booleano. Devolverlo al tipo correcto combina lo que ya has visto: compara con `"true"` y `"false"` para los booleanos, y prueba `Number()` para los números, recordando que `Number("")` es `0` y que `Number.isNaN` te dice cuándo la conversión falló:
```javascript
console.log(Number("3.5"), Number(""), Number("12px"));
// prints 3.5 0 NaN
```
Cuando nada coincide, conserva la cadena tal como está.

# --asserts--

`parseValue("42")` debe devolver el número `42`.

```javascript

```

`parseValue("3.5")` debe devolver `3.5`.

```javascript

```

`parseValue("true")` y `parseValue("false")` deben devolver los booleanos `true` y `false`.

```javascript
tryCatch(parseValue("true") === true && parseValue("false") === false);
```

`parseValue("Ana")` debe devolver `"Ana"`.

```javascript
tryCatch(parseValue("Ana") === "Ana");
```

`parseValue("12px")` debe devolver `"12px"`, porque el texto completo no es un número.

```javascript
tryCatch(parseValue("12px") === "12px");
```

`parseValue("")` debe devolver `""`, no `0`.

```javascript
tryCatch(parseValue("") === "");
```

# --solutions--

```javascript
function parseValue(text) {
  if (text === "true") {
    return true;
  }
  if (text === "false") {
    return false;
  }
  if (text !== "" && !Number.isNaN(Number(text))) {
    return Number(text);
  }
  return text;
}
```
