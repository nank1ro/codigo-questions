# --description--

Todo se junta en `groupBy(items, keyFn)`: una función de orden superior que recibe un callback que decide la **clave de grupo** de cada elemento y devuelve un objeto que asocia cada clave con el array de elementos que tienen esa clave. `reduce` con un acumulador objeto hace todo el trabajo:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Para cada elemento, calcula la clave, crea el array de esa clave si todavía no existe (`acc[key] ?? []`), añade el elemento y devuelve el acumulador. Como quien llama elige `keyFn`, la misma función agrupa palabras por inicial, personas por ciudad o números por paridad.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` debe devolver `{ h: ["hi", "hey"], y: ["yo"] }`.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

Agrupar `[1, 2, 3, 4]` por paridad debe devolver `{ odd: [1, 3], even: [2, 4] }`.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Agrupar personas por `city` debe conservar los objetos completos, en el orden original.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

```javascript

```

El array original no debe modificarse.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
