# --description--

Un comentario JSDoc también es un **contrato**: le dice a quien llama a la función qué pasar y qué esperar a cambio, incluso antes de que el cuerpo esté escrito. Leer el comentario suele bastar para implementar la función:
```javascript
/**
 * Returns the larger of two numbers.
 * @param {number} a the first number
 * @param {number} b the second number
 * @returns {number} a if it is greater than b, otherwise b
 */
function larger(a, b) {
  return a > b ? a : b;
}
```
Cada `@param` corresponde a un parámetro, en el mismo orden, y `@returns` describe todos los resultados posibles.

```javascript
/**
 * Returns value limited to the range from min to max.
 * @param {number} value the number to limit
 * @param {number} min the smallest allowed result
 * @param {number} max the largest allowed result
 * @returns {number} min if value is below it, max if value is above it, otherwise value
 */
function clamp(value, min, max) {
  if (value < min) {
    return min;
  }
  if (value > max) {
    return max;
  }
  return value;
}
```
