# --description--

`for...of` y el operador spread `...` no funcionan sobre cualquier objeto: funcionan sobre **iterables**, objetos que proporcionan un método guardado bajo la clave especial `Symbol.iterator`. Dale a tu clase ese método y se une al club:
```javascript
class Playlist {
    constructor(songs) {
        this.songs = songs;
    }
    *[Symbol.iterator]() {
        for (const song of this.songs) {
            yield song;
        }
    }
}
const list = new Playlist(["a", "b"]);
console.log([...list]);
// imprime [ 'a', 'b' ]
```
El `*` delante del nombre lo convierte en un **generador**: una función que entrega valores de uno en uno con `yield` y hace una pausa entre ellos. Esa es la forma más corta de satisfacer el protocolo de iteración, y funciona para valores que se calculan en lugar de almacenarse.

# --asserts--

Hacer spread de `new Range(1, 4)` debe dar `[1, 2, 3, 4]`.

```javascript
tryCatch(JSON.stringify([...new Range(1, 4)]) === "[1,2,3,4]");
```

`for...of` debe visitar cada número de `new Range(3, 5)`.

```javascript
let _sum = 0;
for (const n of new Range(3, 5)) {
  _sum += n;
}
tryCatch(_sum === 12);
```

Un rango de un solo número debe producir únicamente ese número.

```javascript
tryCatch(JSON.stringify([...new Range(7, 7)]) === "[7]");
```

Un rango vacío no debe producir nada.

```javascript
tryCatch(JSON.stringify([...new Range(5, 2)]) === "[]");
```

# --solutions--

```javascript
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}
```
