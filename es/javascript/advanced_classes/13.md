# --description--

Los métodos también pueden ser privados. Prefija el nombre con `#` y el método desaparece de la superficie pública de la clase, aunque sigue pudiéndose llamar desde cualquier otro método con `this.#name(...)`:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// prints $7
```
Así mantienes los pasos auxiliares fuera de la API: quien llama ve `print`, no el detalle de formato que hay detrás. Los campos privados y los métodos privados juntos le dan a una clase un interior y un exterior bien definidos.

# --asserts--

Una puntuación nueva debe empezar en `0`.

```javascript
tryCatch(new Score().total === 0);
```

Los valores positivos deben sumarse.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

Los valores negativos deben ignorarse.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

El cero debe ignorarse.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

Los puntos deben ser privados, así que la instancia no debe tener ninguna propiedad pública.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
