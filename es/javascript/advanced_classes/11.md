# --description--

El verdadero valor de un setter es que puede negarse. Entre la asignación y el valor almacenado tienes la oportunidad de comprobar, limitar o rechazar lo que llega:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// prints 3, the setter rejected 50
```
Un getter y un setter con el mismo nombre forman una sola propiedad, así que no pueden ser además un campo normal: el valor almacenado vive bajo un nombre distinto, por convención el mismo nombre con un guion bajo delante.

# --asserts--

El getter debe devolver el valor dado al constructor.

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

El setter debe aceptar un valor válido.

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

El setter debe ignorar un valor negativo.

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

El setter debe aceptar `0`.

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

El valor debe almacenarse en `_temperature`.

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```

```javascript
class Thermostat {
  constructor(temperature) {
    this._temperature = temperature;
  }
  get temperature() {
    return this._temperature;
  }
  set temperature(value) {
    if (value >= 0) {
      this._temperature = value;
    }
  }
}
```
