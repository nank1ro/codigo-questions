# --instructions--

Ordena las líneas para imprimir un array con los nombres de `all` que no están en `done`.
Declara `all` antes que `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
