# --description--

El **operador OR** `||` combina dos expresiones booleanas. Devuelve `true` cuando **al menos un** lado es `true`. Solo devuelve `false` cuando **ambos** lados son `false`.

```dart
bool a = false;
bool b = true;
bool result = a || b; // true

bool c = false;
bool d = false;
bool result2 = c || d; // false
```
