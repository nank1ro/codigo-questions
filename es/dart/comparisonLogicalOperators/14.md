# --description--

El **operador AND** `&&` combina dos expresiones booleanas. Devuelve `true` solo cuando **ambos** lados son `true`. Si cualquiera de los lados es `false`, el resultado es `false`.

```dart
bool a = true;
bool b = true;
bool result = a && b; // true

bool c = true;
bool d = false;
bool result2 = c && d; // false
```
