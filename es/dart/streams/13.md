# --description--

Los streams vistos hasta ahora son de **suscripción única**: permiten exactamente un oyente. Llamar a `listen`, `await for` o a cualquier método de consumo por segunda vez lanza un `StateError` ("Stream has already been listened to").

Para compartir un stream entre varios oyentes, conviértelo en un stream **broadcast** con `asBroadcastStream()`:

```dart
final shared = Stream.fromIterable([1, 2, 3]).asBroadcastStream();
final total = shared.reduce((a, b) => a + b);
final count = shared.length;
print(await total); // 6
print(await count); // 3
```

Un stream broadcast no usa búfer: un oyente solo recibe los eventos emitidos **después** de suscribirse. En el ejemplo, ambos oyentes se suscriben antes del primer `await`, así que ambos reciben todos los eventos.

# --instructions--

Escribe una función `sumAndCount` que reciba un `Stream<int>` `source` y devuelva un `Future<List<int>>` que se complete con una lista de dos elementos: la suma de los valores y el número de valores. Convierte `source` en un stream broadcast, inicia las dos llamadas de consumo **antes** de esperar cualquiera de ellas, y luego espéralas. El stream siempre tiene al menos un evento.

Ejemplo:
```dart
print(await sumAndCount(Stream.fromIterable([1, 2, 3]))); // [6, 3]
```

```dart
Future<List<int>> sumAndCount(Stream<int> source) async {
  final shared = source.asBroadcastStream();
  final sum = shared.reduce((a, b) => a + b);
  final count = shared.length;
  return [await sum, await count];
}
```
