# --instructions--

Escribe una función `sumUntilError` que reciba un `Stream<int>` `source` y devuelva un `Future<int>` que se complete con la suma de sus valores. Si el stream emite un error, para y complétate con la suma de los valores recibidos **antes** del error, en lugar de lanzar la excepción.

Ejemplo:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
