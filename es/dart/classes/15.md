# --description--

Un **constructor factory** usa la palabra clave `factory` y te permite controlar la creación de objetos, por ejemplo, devolviendo una instancia almacenada en caché o un subtipo:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

Cada llamada a `Logger()` devuelve la misma instancia (patrón singleton).

Crea una clase `Counter` con un campo privado `_count` inicializado en `0`. Añade un método de instancia `increment()` que aumente `_count` en `1`, y un getter `count` que devuelva `_count`. Usa un constructor `factory` `Counter.start()` que siempre devuelva un nuevo `Counter` inicializado con `_count = 0` (usando un constructor privado con nombre `Counter._internal()`).

class Counter {
