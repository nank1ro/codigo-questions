# --description--

Un **método** es una función definida dentro de una clase. Los métodos describen el comportamiento de un objeto:

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() {
    print('$name makes a sound.');
  }
}
```

Llamas a un método en un objeto usando la notación de punto: `dog.speak()`.
