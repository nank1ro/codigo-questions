# --description--

Los métodos de las cadenas devuelven cadenas, así que se pueden **encadenar** uno tras otro. Combinado con `.split('')`, la propiedad de lista `.reversed` y `.join()`, esto te permite invertir una cadena en una sola expresión:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

Un **palíndromo** es un texto que se lee igual hacia adelante y hacia atrás, como `level`.

# --instructions--

Escribe una función `isPalindrome` que reciba un parámetro `String` llamado `text` y devuelva `true` si es un palíndromo, ignorando mayúsculas/minúsculas y espacios, o `false` en caso contrario.

Ejemplo:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
