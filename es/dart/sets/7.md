# --description--

Un Set es un `Iterable`, por lo que puedes recorrer sus elementos directamente con `for-in`, igual que con una lista. No hay índices: los elementos se visitan en el orden de inserción:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
