# --description--

Real data is full of gaps: a form field left empty, a column missing from a file, a string that is not quite a number. The tools of this chapter combine naturally to handle them: `nonNulls` to drop missing elements, `int.tryParse` to convert safely, `??` or an `if` check to deal with what could not be converted.

# --instructions--

Write a function `total` that takes a `List<String?>` parameter `prices` and returns the sum of the values that can be converted to an `int`, ignoring both `null` entries and strings that are not valid integers.

Example:
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
