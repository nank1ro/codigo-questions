# --description--

Recolectar toda una serie de mensajes sigue una sola receta: una lista vacía antes del bucle, un `add` por cada mensaje real, y `close()` con la señal que termina el stream. Una vez que el puerto se cierra, el `await for` termina y la función puede devolver:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

Los mensajes conservan el orden en el que fueron enviados, así que la lista que construyes refleja el trabajo del otro isolate paso a paso.

# --instructions--

Escribe una función de nivel superior `sendWords` que reciba una `List<Object>` `message` donde el elemento `0` es un `SendPort` y el elemento `1` es una `List<String>`: envía cada palabra al puerto y luego envía `null` para señalar el final.

Luego escribe una función `collectWords` que reciba una `List<String>` `words` y devuelva un `Future<List<String>>` que se complete con todas las palabras recibidas de un isolate `sendWords` iniciado.

Ejemplo:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

# --solutions--

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
