# --instructions--

Escribe una extensión llamada `Words` sobre `String` con:
- un getter `wordCount` de tipo `int`, el número de palabras de la cadena, donde las palabras están separadas por un único espacio
- un getter `initials` de tipo `String`, formado por el primer carácter de cada palabra en mayúsculas, unido sin separadores

La cadena siempre contiene al menos una palabra y nunca tiene espacios iniciales, finales ni dobles.

Ejemplo:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
