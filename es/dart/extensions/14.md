# --instructions--

La clase `Temperature` está dada. Escribe una extensión llamada `Conversions` sobre `Temperature` con:
- un getter `fahrenheit` de tipo `double`, igual a `celsius * 9 / 5 + 32`
- un método `isAbove` que reciba un parámetro `limit` de tipo `double` y devuelva `true` cuando `celsius` sea mayor que `limit`

Ejemplo:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
