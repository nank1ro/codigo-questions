# --description--

Una extensión genérica puede recibir **funciones** como parámetros, exactamente igual que hacen `where` y `map`. El tipo de la función se escribe con el tipo de elemento `T`, así que el callback recibe elementos del tipo correcto:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

Completa la extensión para que `countWhere` devuelva cuántos elementos cumplen la función `test` dada, de modo que el programa imprima `2` y luego `1`.

```dart
extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
```
