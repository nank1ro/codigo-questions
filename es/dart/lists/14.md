# --description--

La propiedad `.isEmpty` es `true` cuando una lista no tiene elementos, y `.isNotEmpty` es `true` cuando tiene al menos uno.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
