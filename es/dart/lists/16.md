# --description--

El método `.indexOf(value)` devuelve el índice del primer elemento igual a `value`. Si el valor no está en la lista, devuelve `-1`.

```dart
var colors = ['red', 'green', 'blue'];
print(colors.indexOf('green')); // 1
print(colors.indexOf('pink')); // -1
```
