# --description--

Como `await` convierte los errores de un future en excepciones normales, al código asíncrono se le aplican todos los patrones habituales de `try`/`catch`, incluidos los bucles que reintentan. Dentro de un bloque `catch`, **`rethrow`** vuelve a lanzar el mismo error, que es la forma de rendirse tras el último intento:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Un parámetro de tipo función como `Future<String> Function() task` recibe la **función** en sí, no un future: cada llamada a `task()` inicia un intento nuevo.

# --instructions--

Escribe una función `async` `retry` que reciba un `Future<int> Function()` `task` y un `int` `attempts`, y devuelva un `Future<int>`. Llama a `task()` y complétate con su valor; si lanza, inténtalo de nuevo, llamando a `task` como mucho `attempts` veces en total. Si el último intento también falla, vuelve a lanzar su error con `rethrow`.

Ejemplo:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` de una tarea que siempre tiene éxito debería completarse con su valor tras una única llamada

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` de una tarea que falla dos veces y luego devuelve `7` debería completarse con `7` tras `3` llamadas

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` de una tarea que siempre falla debería llamarla exactamente `attempts` veces y luego fallar con el mismo error

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
