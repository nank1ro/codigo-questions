# --description--

Los mixins apilados son la forma de combinar en una sola clase reglas pequeñas e independientes. Cada mixin sobrescribe el mismo miembro, hace su propia parte y llama a `super` para pasarle el trabajo. Como la llamada entra primero en el **último** mixin, el orden de la lista `with` decide qué regla se ejecuta antes que cuál:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` duplica cada depósito. Añade un segundo mixin después de `Doubled` y será quien reciba el depósito primero, antes de que `Doubled` lo vea.

# --instructions--

La clase `Account` ya está escrita: tiene un campo `int` `balance` que empieza en `0` y un método `deposit` que suma su argumento `int` a `balance`.

Declara un mixin `Audited` sobre `Account` con un campo `List<String>` `log` que empiece vacío, que sobrescriba `deposit` de modo que primero añada a `log` la cadena `'deposit '` seguida del importe, y luego llame a `super.deposit`.

Declara un mixin `Limited` sobre `Account` que sobrescriba `deposit` de modo que un importe mayor que `100` se ignore, y cualquier otro importe se le pase a `super.deposit`.

Declara una clase `SafeAccount` que extienda `Account` y use ambos mixins, de modo que un depósito rechazado nunca llegue al log.

Ejemplo:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
