# --instructions--

Dado `enum Size { small, medium, large }`, ¿qué ocurre con el siguiente código?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- No compila: una expresión `switch` sobre un enum debe cubrir todos los valores
- Compila y devuelve `null` para `Size.large`
- Compila y lanza una excepción en tiempo de ejecución para `Size.large`
- Compila y devuelve `'L'` para `Size.large` automáticamente
