# --description--

Una función anónima puede tomar parámetros y `return` un valor, exactamente igual que una con nombre. El tipo de retorno no se escribe: Dart lo **infiere** de las sentencias `return` del cuerpo.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
