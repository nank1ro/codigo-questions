# --description--

No estás limitado a las clases genéricas que trae Dart: puedes declarar las tuyas. Un **parámetro de tipo** va entre corchetes angulares después del nombre de la clase, y a partir de ahí es un tipo normal dentro del cuerpo:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` es solo un marcador de posición. Se rellena cuando se crea un `Box`, ya sea explícitamente o por inferencia:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, inferido a partir del argumento
print(a.value + 1);      // 8, el compilador sabe que value es int
```

La letra no importa: `T` es una convención para "tipo", nada más.

# --instructions--

Declara una clase genérica `Box` con un parámetro de tipo `T`, un campo `final` `value` de tipo `T` asignado por el constructor y un getter `label` que devuelva el texto `Box of ` seguido del valor.

Ejemplo:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` debería tener `value` `7` y `label` `'Box of 7'`

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` debería funcionar con cualquier tipo, así que `Box<String>('fig')` también debería ser un `Box<String>`

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

El argumento de tipo debería deducirse a partir del argumento del constructor

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
