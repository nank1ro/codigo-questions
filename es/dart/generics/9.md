# --description--

La diferencia importa en cuanto usas el valor. Sobre un `Box<int?>` accedes al campo con normalidad y luego te ocupas del `null` que hay dentro, mientras que sobre un `Box<int>?` primero tienes que superar la caja ausente:

```dart
Box<int?> a = Box(null);
print(a.value ?? 0); // 0, the box is there, its content is null

Box<int>? b = null;
print(b?.value ?? 0); // 0, the box itself is missing
```

Escribir `b.value` sobre un `Box<int>?` no compila en absoluto: Dart se niega a leer un campo de algo que puede no existir.

# --instructions--

Dado `Box<int?> a = Box(null);` y `Box<int>? b = null;`, ¿qué afirmación es cierta?

# --answers--

- `a` es una caja real cuyo `value` es `null`, mientras que `b` no es una caja en absoluto
- Ambas declaraciones significan lo mismo, el `?` puede escribirse en cualquier lado
- `a` no compila, porque un argumento de tipo nunca puede ser nullable
- `b` es una caja que contiene `null`, mientras que `a` no es una caja en absoluto
