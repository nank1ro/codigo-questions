# --description--

El operador **XOR** `^` (or exclusivo) conserva un `1` solo donde los dos bits son *diferentes*:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// imprime "6"
```
De esto se deduce una propiedad útil: aplicar el mismo XOR dos veces devuelve el valor original.
