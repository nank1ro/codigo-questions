# --description--

Las letras mayúsculas y minúsculas están separadas por `32` posiciones en la tabla ASCII: `'A'` es `65` y `'a'` es `97`.
Restar `32` a una letra minúscula da entonces su versión en mayúscula, y el resultado puede almacenarse de nuevo en un `char`:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Ordena las líneas para almacenar la letra `'a'` en `letter`, calcular su versión en mayúscula en `upper`, e imprimir cada una como un carácter seguido de su código (`letter` primero)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
