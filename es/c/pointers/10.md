# --description--

Cuando un array se pasa a una función **decae** a un puntero a su primer elemento. Por esto los parámetros `int values[]` e `int *values` significan exactamente lo mismo, y por esto la función no puede conocer la longitud por sí sola: solo recibe una dirección.
Los punteros al mismo array se pueden comparar y restar. `end - start` es el número de elementos entre ellos, y un bucle puede mover un puntero de una dirección a otra:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
Pasar `numbers` y `numbers + 3` describe los primeros tres elementos sin un parámetro de tamaño aparte.

# --instructions--

Completa `sum_between` para que devuelva la suma de todos los elementos desde la dirección `start` hasta, pero sin incluir, la dirección `end`

# --asserts--

Los primeros tres elementos de `{1, 2, 3, 4}` deben sumar `6`

```c
    int a1[4] = {1, 2, 3, 4};
    try_catch(sum_between(a1, a1 + 3) == 6);
```

Los elementos desde el índice `1` hasta `3` de `{5, 6, 7, 8}` deben sumar `21`

```c
    int a2[4] = {5, 6, 7, 8};
    try_catch(sum_between(a2 + 1, a2 + 4) == 21);
```

Un rango vacío debe sumar `0`

```c
    int a3[2] = {9, 9};
    try_catch(sum_between(a3, a3) == 0);
```

```c
int sum_between(int *start, int *end) {
    int total = 0;
    for (int *p = start; p < end; p++) {
        total += *p;
    }
    return total;
}
```
