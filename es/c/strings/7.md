# --description--

`strcat(destination, source)` añade `source` al final de `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// text ahora es "Hello World"
```
Como con `strcpy`, el array de destino debe tener suficiente espacio para el resultado.
