# --description--

Dado que una cadena es un array, cada carácter tiene un índice que empieza en `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Un único carácter se imprime con `%c`. Los caracteres también se pueden reemplazar:
```c
word[0] = 'K'; // word ahora es "Koding"
```
