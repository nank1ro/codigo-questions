# --instructions--

¿Qué ocurre con este código?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- No compila: una clase anidada no puede ver los miembros exteriores, `Nested` debe ser `inner`
- Compila, y `show()` devuelve el `name` de la instancia exterior
- Compila, y `show()` siempre devuelve una cadena vacía
- No compila: Kotlin no permite una clase dentro de otra clase
