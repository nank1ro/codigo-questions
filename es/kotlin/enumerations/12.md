# --instructions--

Dado `enum class Size { SMALL, MEDIUM, LARGE }`, ¿qué ocurre con el siguiente código?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- No compila: una expresión `when` sobre un enum debe cubrir todas las entradas o añadir una rama `else`
- Compila y devuelve `null` para `LARGE`
- Compila y lanza una excepción en tiempo de ejecución para `LARGE`
- Compila y devuelve `"L"` para `LARGE` automáticamente
