# --instructions--

Dado `enum class Color { RED, GREEN, BLUE }`, ¿qué hace `Color.valueOf("PURPLE")`?

# --answers--

- Lanza una `IllegalArgumentException`, porque ninguna entrada se llama `PURPLE`
- Devuelve `null`
- Devuelve `Color.RED`, la primera entrada
- Añade una nueva entrada `PURPLE` al enum
