# --description--

Puedes recorrer un mapa con `for`, desestructurando cada entrada en su clave y su valor:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Los paréntesis `(name, age)` dividen cada entrada en dos variables. Las entradas se visitan en el orden de inserción.

# --instructions--

Escribe una función `report(stock: Map<String, Int>): List<String>` que devuelva una lista con una cadena por entrada, con el formato `"item: count"`, en el orden en que las entradas aparecen en el mapa.

Ejemplo de llamada a la función:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
