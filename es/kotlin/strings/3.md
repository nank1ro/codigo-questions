# --description--

`uppercase()` devuelve una copia de la cadena con todas las letras en mayúscula, `lowercase()` hace lo contrario.
La cadena original no se modifica:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
