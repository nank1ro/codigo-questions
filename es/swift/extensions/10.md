# --description--

Las extensiones no son solo para tipos ajenos. Una forma común de organizar tu propio código es mantener las propiedades almacenadas en el cuerpo del struct o de la clase, y añadir el comportamiento en una o más extensiones, cada una agrupando miembros relacionados:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
Los miembros añadidos en una extensión pueden usar las propiedades almacenadas directamente, exactamente como si estuvieran escritos dentro del tipo.

# --asserts--

Debes usar una extensión de `Rectangle`

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

El área de un rectángulo de `2` por `3` debe ser `6.0`

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

El área de un rectángulo de `1.5` por `4` debe ser `6.0`

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

Un rectángulo de `2` por `3` escalado por `2` debe ser de `4` por `6`

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

Escalar no debe cambiar el rectángulo original

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
