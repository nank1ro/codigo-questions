# --description--

Las extensiones funcionan con cualquier tipo, incluso con aquellos de los que no tienes el código fuente. `String` proviene de la biblioteca estándar, pero aun así puedes darle métodos nuevos:
```swift
extension String {
    func whisper() -> String {
        return self.lowercased() + "..."
    }
}
print("HELLO".whisper()) // hello...
```
Dentro de una extensión puedes omitir `self.` al llamar a otros miembros del tipo: `lowercased()` a secas significa `self.lowercased()`.

# --instructions--

Escribe una extensión de `String` con un método `shout()` que devuelva la cadena en mayúsculas seguida de un signo de exclamación `!`

Ejemplo de llamada al método:
```swift
print("hi".shout())
// prints HI!
```

```json

  "shouldMatch": true

```

```swift
tryCatch("hi".shout() == "HI!")
```

`"Swift is fun".shout()` debe devolver `"SWIFT IS FUN!"`

```swift
tryCatch("Swift is fun".shout() == "SWIFT IS FUN!")
```

`"".shout()` debe devolver `"!"`

```swift
tryCatch("".shout() == "!")
```
