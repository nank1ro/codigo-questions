# --description--

Las extensiones solo pueden **añadir** miembros, nunca reemplazar o sobrescribir los existentes. `override` pertenece a las subclases, que son un tipo distinto de su clase padre; una extensión es el mismo tipo, así que declarar un método que ya existe es un error de redeclaración:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
Si necesitas un comportamiento distinto, añade un método con un nombre nuevo, o escribe una subclase cuando el tipo sea una clase.

# --instructions--

¿Qué sucede cuando este programa se compila y se ejecuta?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- No compila, porque `speak()` está declarado dos veces para el mismo tipo
- Imprime `Bark`, porque la extensión sobrescribe el método original
- Imprime `Woof`, porque el método original gana sobre la extensión
- Imprime `Woof` y después `Bark`
