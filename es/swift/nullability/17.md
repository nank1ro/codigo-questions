# --description--

Las conversiones que pueden fallar combinan de forma natural con `guard let`: convertir, salir si el resultado es `nil`, y luego trabajar con el valor simple.

# --instructions--

Completa la función para que convierta el texto a un `Int` y devuelva su doble, o `nil` cuando la conversión falle.
Luego imprime los resultados, usando `0` como valor de respaldo

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
