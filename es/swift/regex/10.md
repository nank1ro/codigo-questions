# --description--

Un patrón puede contener varios grupos. Se numeran de izquierda a derecha por su paréntesis de apertura, así que el segundo es `m.2`, el tercero `m.3`, y así sucesivamente:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` sigue siendo siempre la coincidencia completa, sea cual sea el número de grupos.

# --instructions--

Escribe una función `setting` que reciba un texto (`String`) sin etiqueta de argumento, busque un ajuste escrito como letras minúsculas, un signo `=` y dígitos, y devuelva el nombre y el valor unidos por dos puntos, o `"none"` cuando el texto no contenga tal ajuste

Ejemplo de llamada a la función:
```swift
print(setting("size=10"))
// imprime size:10
```

# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
