# --instructions--

¿Cuál es el __problema__ con este fragmento de código?
```swift
print(greet(name: "Mathew"))
/// Esta función saluda a la persona pasada como argumento
func greet(name: String) -> String {
    return "Hello, \(name). Good morning!"
}
print(greet(name: "Alex"))
```

# --answers--

- No podemos usar greet() antes de definirla
- No podemos usar greet() dos veces
- greet() no devuelve nada
- No podemos usar name como parámetro
