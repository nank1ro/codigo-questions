# --instructions--

¿Por qué este código no compila?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` es una constante `let`, así que no se puede llamar a un método mutante sobre ella
- `increase` debe marcarse `static` para cambiar `value`
- `value` debe declararse con `let`
- Una estructura no puede contener métodos
