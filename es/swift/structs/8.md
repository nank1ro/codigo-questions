# --description--

Como una estructura es un valor, a un método no se le permite cambiar sus propiedades a menos que lo indiques con la palabra clave `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Un método mutante solo puede llamarse sobre una instancia almacenada en una `var`. Sobre una instancia `let` el valor está congelado, así que `c.increase(by: 5)` no compilaría.

# --instructions--

Agrega a `Counter` un método mutante `increase` que tome un `Int` con la etiqueta de argumento `by` y lo sume a `value`

Ejemplo de uso:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

El método debe estar marcado con `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Incrementar `0` en `5` debe dar `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Incrementar `10` dos veces debe acumular

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Incrementar en `0` no debe cambiar nada

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Cambiar una copia no debe cambiar el original

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
