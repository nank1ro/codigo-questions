# --description--

Dividir por espacios es la forma más simple de descomponer una frase en palabras, y unir es cómo reconstruyes texto a partir de un array.

# --instructions--

Escribe una función `wordCount` que reciba un `String` (omite la etiqueta de argumento) y devuelva cuántas palabras separadas por espacios contiene, y una función `slug` que reciba un array de `String` (omite la etiqueta de argumento) y devuelva las palabras unidas por `-`

Ejemplo de llamada a la función:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
