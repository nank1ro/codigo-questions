# --description--

Los casts condicionales se encadenan naturalmente con `else if` para manejar varios tipos posibles, convirtiendo cada uno al tipo que necesitas para el resultado:
```swift
let item: Any = 2.5
if let number = item as? Int {
    print(Double(number))
} else if let number = item as? Double {
    print(number)
}
```
Un `Int` almacenado en `Any` sigue siendo un `Int`: `as? Double` sobre él devuelve `nil`, porque `as?` comprueba el tipo, no convierte números.

# --instructions--

Escribe una función `sumNumbers` que reciba un array de `Any` (omite la etiqueta de argumento) y devuelva la suma de sus elementos `Int` y `Double` como un `Double`, ignorando los elementos de cualquier otro tipo

Ejemplo de llamada a la función:
```swift
print(sumNumbers([1, 2.5, "x"]))
// prints 3.5
```

# --solutions--

```swift
func sumNumbers(_ values: [Any]) -> Double {
    var total = 0.0
    for value in values {
        if let number = value as? Int {
            total += Double(number)
        } else if let number = value as? Double {
            total += number
        }
    }
    return total
}
```
