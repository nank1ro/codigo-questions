# --description--

A protocol can build on another one. Writing a protocol name after the colon makes the new protocol **inherit** every requirement of the old one:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
A type conforming to `Aged` must provide `age` *and* `name`, and it counts as a `Named` type everywhere. A protocol can inherit from several protocols at once, separated by commas.

# --asserts--

A track named `Intro` of `90` seconds must be labelled `Intro 90`

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

A track named `Outro` of `5` seconds must be labelled `Outro 5`

```swift
tryCatch(Track(name: "Outro", seconds: 5).label() == "Outro 5")
```

A track named `Gap` of `0` seconds must be labelled `Gap 0`

```swift
tryCatch(Track(name: "Gap", seconds: 0).label() == "Gap 0")
```

A `Timed` value must be usable as a `Named` value

```swift
tryCatch(_name(Track(name: "Intro", seconds: 90)) == "Intro")
```
