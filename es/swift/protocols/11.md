# --description--

Un protocolo puede construirse sobre otro. Escribir el nombre de un protocolo después de los dos puntos hace que el nuevo protocolo **herede** todos los requisitos del anterior:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
Un tipo que conforma a `Aged` debe proporcionar `age` *y* `name`, y cuenta como un tipo `Named` en todas partes. Un protocolo puede heredar de varios protocolos a la vez, separados por comas.

Declara un protocolo `Timed` que herede de `Named` y añada una propiedad `Int` legible `seconds`, y luego haz que `Track` conforme a `Timed`

# --before-asserts--

```swift
extension Timed {
    func label() -> String {
        return "\(name) \(seconds)"
    }

func _name(_ n: Named) -> String {
    return n.name
}
```

# --asserts--

A track named `Intro` of `90` seconds must be labelled `Intro 90`

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

A track named `Outro` of `5` seconds must be labelled `Outro 5`

```swift
tryCatch(Track(name: "Outro", seconds: 5).label() == "Outro 5")
```

A track named `Gap` of `0` seconds must be labelled `Gap 0`

```swift
tryCatch(Track(name: "Gap", seconds: 0).label() == "Gap 0")
```

A `Timed` value must be usable as a `Named` value

```swift
tryCatch(_name(Track(name: "Intro", seconds: 90)) == "Intro")
```
