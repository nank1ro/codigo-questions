# --description--

Un protocolo también puede requerir **métodos**. Escribes la firma —nombre, parámetros y tipo de retorno— y te detienes ahí, sin cuerpo:
```swift
protocol Greeter {
    func greet() -> String
}
```
Un tipo que conforma debe declarar un método con exactamente esa firma, y es él quien aporta el cuerpo:
```swift
struct Robot: Greeter {
    func greet() -> String {
        return "BEEP"
    }
}

print(Robot().greet()) // BEEP
```
Si algo difiere —el nombre, el tipo de un parámetro, el tipo de retorno—, el tipo no conforma, y el compilador te dice qué requisito falta.

# --instructions--

Haz que `Friendly` conforme a `Greeter` añadiendo el método requerido `greet()`, devolviendo el nombre entre `Hello, ` y `!`

Ejemplo de uso:
```swift
print(Friendly(name: "Ada").greet())
// imprime Hello, Ada!
```

func _asGreeter(_ g: Greeter) -> String {
    return g.greet()
}

# --asserts--

`Friendly(name: "Ada")` must greet with `Hello, Ada!`

```swift
tryCatch(_asGreeter(Friendly(name: "Ada")) == "Hello, Ada!")
```

`Friendly(name: "Bo")` must greet with `Hello, Bo!`

```swift
tryCatch(_asGreeter(Friendly(name: "Bo")) == "Hello, Bo!")
```

An empty name must greet with `Hello, !`

```swift
tryCatch(_asGreeter(Friendly(name: "")) == "Hello, !")
```
