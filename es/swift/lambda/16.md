# --description--

Los cierres se pueden almacenar en arrays como cualquier otro valor. El tipo del elemento es el tipo de función:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Recorrer un array así y llamar a cada cierre en orden construye un pequeño **pipeline** de transformaciones.

# --instructions--

Escribe una función `pipeline` que reciba un `Int` y un array de cierres de tipo `(Int) -> Int` (omite ambas etiquetas de argumento) y devuelva el resultado de aplicar cada cierre en orden, cada uno al resultado del anterior

Ejemplo de llamada a la función:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
