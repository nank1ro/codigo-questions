# --description--

当类相互继承时，顺序很重要。`class` 声明**不会**像 `function` 那样被提升：这个名字只从类被书写的那一行开始才存在。所以子类必须出现在它所继承的父类*之后*，否则 `extends` 子句会因 `ReferenceError` 而失败。

# --instructions--

将这些代码块排列成一个能正常运行的程序。记住父类必须定义在子类之前

# --answers--

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
```

```javascript
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
```

```javascript
console.log(new Car().describe());
```
