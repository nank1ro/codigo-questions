# --description--

setter 的真正价值在于它可以拒绝。在赋值和存储的值之间，你有机会检查、限制或拒绝传进来的内容：
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// 打印 3，setter 拒绝了 50
```
同名的 getter 和 setter 共同构成一个属性，所以它们不能同时也是一个普通字段：存储的值存放在另一个名字下，按照惯例就是同名但前面加一个下划线。

# --asserts--

getter 必须返回传给构造函数的值。

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

setter 必须接受有效的值。

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

setter 必须忽略负值。

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

setter 必须接受 `0`。

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

值必须存储在 `_temperature` 中。

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```
