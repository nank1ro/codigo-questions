# --description--

`for...of` 和展开运算符 `...` 并不是对任何对象都有效：它们作用于**可迭代对象（iterable）**，即提供了存储在特殊键 `Symbol.iterator` 下的方法的对象。给你的类加上这个方法，它就加入了这个俱乐部：
```javascript
class Playlist {
    constructor(songs) {
        this.songs = songs;
    }
    *[Symbol.iterator]() {
        for (const song of this.songs) {
            yield song;
        }
    }
}
const list = new Playlist(["a", "b"]);
console.log([...list]);
// prints [ 'a', 'b' ]
```
名字前面的 `*` 使它成为一个**生成器（generator）**：一种用 `yield` 逐个交出值并在其间暂停的函数。这是满足迭代协议的最简短方式，而且它也适用于那些被计算出来而非存储起来的值。

# --asserts--

展开 `new Range(1, 4)` 必须得到 `[1, 2, 3, 4]`。

```javascript
tryCatch(JSON.stringify([...new Range(1, 4)]) === "[1,2,3,4]");
```

`for...of` 必须遍历 `new Range(3, 5)` 的每一个数字。

```javascript
let _sum = 0;
for (const n of new Range(3, 5)) {
  _sum += n;
}
tryCatch(_sum === 12);
```

只有一个数字的范围必须只产出该数字。

```javascript
tryCatch(JSON.stringify([...new Range(7, 7)]) === "[7]");
```

空范围必须不产出任何值。

```javascript
tryCatch(JSON.stringify([...new Range(5, 2)]) === "[]");
```

# --solutions--

```javascript
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}
```
