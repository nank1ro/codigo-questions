# --description--

一切都汇集到 `groupBy(items, keyFn)`：这是一个高阶函数，它接收一个决定每个元素**分组键**的回调，并返回一个把每个键映射到具有该键的元素数组的对象。用对象作累加器的 `reduce` 就能完成全部工作：
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
对每个元素，先计算键，如果该键的数组还不存在就创建它（`acc[key] ?? []`），把元素放进去，然后返回累加器。因为 `keyFn` 由调用方选择，同一个函数既能按首字母给单词分组，也能按城市给人分组，或按奇偶给数字分组。

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` 必须返回 `{ h: ["hi", "hey"], y: ["yo"] }`。

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

按奇偶给 `[1, 2, 3, 4]` 分组必须返回 `{ odd: [1, 3], even: [2, 4] }`。

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

按 `city` 给人分组必须保留完整的对象，并保持原始顺序。

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` 必须返回一个空对象。

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

原数组不能被修改。

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

该函数必须使用 `reduce`。

```javascript
tryCatch(/\.reduce\(/.test(groupBy.toString()));
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
