# --description--

闭包让返回的函数能在多次调用之间保持**私有状态**。用这种方式构建的经典助手是 `once(fn)`：它返回一个函数，只在第一次被调用时运行 `fn`，记住结果，并在之后每次调用时返回同一个结果而不再运行 `fn`：
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
包装器需要两个私有变量：`fn` 是否已经运行过，以及保存下来的结果。两者都存在于闭包中，对外部不可见。要把包装器的所有参数转发给 `fn`，用剩余参数 `(...args)` 声明包装器，并调用 `fn(...args)`。

# --asserts--

被包装的函数必须只运行 `fn` 一次，并持续返回它的结果。

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

第一次调用的参数必须转发给 `fn`：`once((a, b) => a + b)(2, 3)` 必须返回 `5`。

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

之后的调用即使传入不同的参数，也必须返回保存下来的结果。

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

即使 `fn` 的结果是 `undefined`，它也不能再次运行。

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

同一个函数的两个包装器必须彼此独立。

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` 必须返回一个函数。

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
