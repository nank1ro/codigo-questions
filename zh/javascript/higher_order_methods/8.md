# --description--

高阶函数也可以**返回**一个函数。返回的函数会记住它被创建之处的变量，即使外层函数已经结束：这称为**闭包**。
```javascript
function makeMultiplier(factor) {
  return function (n) {
    return n * factor;
  };
}
const triple = makeMultiplier(3);
console.log(triple(5));
// prints 15
console.log(makeMultiplier(10)(5));
// prints 50
```
每次调用 `makeMultiplier` 都会创建一个拥有自己 `factor` 的新函数。这就是从一个模板构建一族相似函数的方法。同样的写法也可以用箭头函数：`const makeMultiplier = (factor) => (n) => n * factor;`。

# --asserts--

`makeGreeter("Hello")("Ana")` 必须返回 `"Hello, Ana!"`。

```javascript
tryCatch(makeGreeter("Hello")("Ana") === "Hello, Ana!");
```

`makeGreeter` 必须返回一个函数。

```javascript
tryCatch(typeof makeGreeter("Yo") === "function");
```

返回的函数必须能用不同的名字重复使用。

```javascript
tryCatch((() => { const hi = makeGreeter("Hi"); return hi("Bo") === "Hi, Bo!" && hi("Cy") === "Hi, Cy!"; })());
```

每个 greeter 必须保留自己的问候语。

```javascript
tryCatch((() => { const hello = makeGreeter("Hello"); const bye = makeGreeter("Bye"); return hello("Ana") === "Hello, Ana!" && bye("Ana") === "Bye, Ana!"; })());
```
