# --description--

把任意值转换为布尔值的一个常见捷径是**双重取反** `!!`：第一个 `!` 把值转换为布尔值并取反，第二个再把它取反回来：
```javascript
console.log(!!"text", !!0);
// prints true false
```
`!!value` 和 `Boolean(value)` 给出的结果完全相同；显式的写法更易读。

# --instructions--

这段代码会输出什么？
