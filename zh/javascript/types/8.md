# --description--

把字符串转换为数字的一种简写方式是**一元加号**：放在单个值前面的 `+` 会完全按照 `Number()` 的方式转换它：
```javascript
console.log(+"5" + 5);
// prints 10
console.log(typeof +"5");
// prints number
```
它很简洁，但容易与加法混淆，所以很多团队更喜欢显式的 `Number("5")`。
