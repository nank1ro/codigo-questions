# --description--

Map 没有像 `sort()` 或 `filter()` 这样的数组方法。要使用它们，需要用 `Array.from()` 或展开运算符 `...` 把 Map（或它的键、值）转换成数组：
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
反向转换 `Object.fromEntries(ages)` 可以把 Map 转换回普通对象。

# --asserts--

包含键 `"pear"`、`"apple"` 和 `"kiwi"` 的 map 的 `sortedKeys` 必须返回 `["apple", "kiwi", "pear"]`。

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

空 map 的 `sortedKeys` 必须返回 `[]`。

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
