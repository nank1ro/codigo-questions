# --description--

Map 和普通对象都在键下存储值，但它们在一些重要方面有所不同：
- 对象的键始终是字符串（或 symbol），而 Map 的键可以是**任意**类型
- Map 会保持其键值对的确切**插入顺序**
- Map 知道自己的 `size`，而对象需要用 `Object.keys(obj).length`
- Map 一开始是真正为空的，而对象会从其原型继承像 `toString` 这样的键
