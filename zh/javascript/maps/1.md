# --description--

**Map** 存储**键值对**：每个值都保存在一个键下，你可以使用该键再次找到该值。
你可以用 `new Map()` 创建一个空的 Map，用 `set(key, value)` 添加一对键值，用 `get(key)` 读取一个值：
```javascript
let ages = new Map();
ages.set("Ann", 30);
ages.set("Bob", 25);
console.log(ages.get("Ann"));
// prints 30
```
使用一个已经存在的键调用 `set()` 会替换它的值。
