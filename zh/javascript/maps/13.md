# --description--

`delete(key)` 在成功删除一对键值对时返回 `true`，在该键不存在时返回 `false`。
要一次性删除**所有**键值对，调用 `clear()`：
```javascript
let cart = new Map([["pen", 2], ["ink", 1]]);
console.log(cart.delete("pen"));
// prints true
console.log(cart.delete("pen"));
// prints false
cart.clear();
console.log(cart.size);
// prints 0
```
