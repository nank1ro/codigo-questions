# --description--

那么，什么时候应该使用 `Map` 而不是普通对象呢？
- 当键是在运行时添加和删除的、键不是字符串，或者你需要 `size` 和可靠的顺序时，使用 **Map**
- 当记录的字段名是固定且已知的，比如 `{ name, email }`，或者需要将数据转换为 JSON 时，使用**对象**，因为 `JSON.stringify()` 会忽略 map 的内容
