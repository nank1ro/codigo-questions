# --instructions--

排序代码行，将 `"pie"` 添加到 Map 中，并打印一个包含全部三个价格的数组

# --answers--

```javascript
const prices = new Map([["tea", 2], ["cake", 4]]);
```

```javascript
prices.set("pie", 3);
```

```javascript
const values = [...prices.values()];
```

```javascript
console.log(values);
```
