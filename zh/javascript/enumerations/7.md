# --description--

枚举天然地与 `switch` 语句搭配使用，`switch` 会将一个值与一系列 `case` 标签进行比较，并执行第一个匹配项的代码。
每个分支以 `return` 或 `break` 结尾，可选的 `default` 分支会在没有任何匹配时执行：
```javascript
const Light = Object.freeze({ RED: "red", GREEN: "green" });

function action(light) {
  switch (light) {
    case Light.RED:
      return "stop";
    case Light.GREEN:
      return "go";
    default:
      return "unknown";
  }
}
console.log(action(Light.GREEN));
// prints go
```
始终与成员（`Light.RED`）进行比较，而不是与原始值（`"red"`）比较：这样即使值发生变化，`switch` 仍能正常工作。

```javascript
const Day = Object.freeze({
  MONDAY: "monday",
  FRIDAY: "friday",
  SATURDAY: "saturday",
  SUNDAY: "sunday",
});

function weekend(day) {
  switch (day) {
    case Day.SATURDAY:
    case Day.SUNDAY:
      return true;
    default:
      return false;
  }
}
```
