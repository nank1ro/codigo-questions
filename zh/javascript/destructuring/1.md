# --description--

一次一个索引地从数组中读取值非常繁琐：
```javascript
const point = [3, 7];
const x = point[0];
const y = point[1];
```
**解构**用一行代码完成同样的工作。在 `=` 的左边，你写出一个看起来就像数组本身的模式，其中的每个名字都会接收到相同位置上的元素：
```javascript
const point = [3, 7];
const [x, y] = point;
console.log(x, y);
// 打印 3 7
```
模式不必覆盖整个数组：多余的元素会被直接忽略，而没有匹配元素的名字则会变成 `undefined`。
