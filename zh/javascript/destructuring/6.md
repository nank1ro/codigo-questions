# --description--

对象也可以被解构，只是使用花括号而不是方括号。在这里位置毫无意义：每个名字都会与拼写相同的**键**进行匹配：
```javascript
const user = { name: "Ada", age: 36 };
const { age, name } = user;
console.log(name, age);
// prints Ada 36
```
在模式中调换 `age` 和 `name` 的顺序不会有任何影响，而模式没有提到的键则会被直接留下。没有匹配键的名字会变成 `undefined`。
