# --description--

默认值有一条让所有人都惊讶的规则：它们**只**对 `undefined` 生效。一个存在并保存着 `null`、`0`、`""` 或 `false` 的键是真实的值，所以模式会取用它，默认值永远不会被使用：
```javascript
const { count = 10 } = { count: 0 };
console.log(count);
// prints 0
```
`null` 在这里的行为和 `0` 一样，尽管在 API 响应中它通常表示“没有值”。当 `null` 也必须被替换时，先解构，之后再用 `??` 回退。

# --instructions--

这个程序会输出什么？
```javascript
const { a = 1 } = { a: null };
const { b = 2 } = { b: undefined };
console.log(a, b);
```
