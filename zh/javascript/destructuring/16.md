# --description--

到目前为止看到的一切都属于同一套语法，所以各个部分可以自由组合：一个对象模式可以嵌套另一个对象模式，后者可以包含一个带默认值的重命名键，旁边还可以放一个以剩余元素结尾的数组模式。于是一行代码就能描述函数期望的整个形状：
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// 打印 Post [js] +2
```
保持可读性：一个不再能放在几行之内的模式，通常说明这个函数想要的东西太多了。

# --asserts--

三个条目必须剩下两个。

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

单个条目必须一个也不剩。

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

没有名字的顾客必须变成 `guest`。

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

显式的 `undefined` 名字也必须变成 `guest`。

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

四个条目必须剩下三个。

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

```javascript
function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
```
