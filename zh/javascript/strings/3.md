# --description--

字符串自带许多内置**方法**。其中两个最简单的方法可以改变每个字母的大小写：
```javascript
let word = "Hello";
console.log(word.toUpperCase());
// prints HELLO
console.log(word.toLowerCase());
// prints hello
```
这两个方法都不需要参数，但别忘了括号。
