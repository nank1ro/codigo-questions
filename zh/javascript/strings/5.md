# --description--

`indexOf()` 方法返回一段文本在字符串中**第一次**出现的索引。
如果没有找到该文本，则返回 `-1`：
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
