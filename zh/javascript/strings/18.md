# --description--

字符串是**不可变的**：一旦创建，字符串就永远不能被更改。
对索引赋值不会产生任何效果，每个字符串方法都会返回一个**新**字符串，而不是修改原字符串：
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
要保留结果，需要把它重新赋值给变量：
```javascript
word = word.toUpperCase();
```

第一个 `console.log` 打印 `hello`，因为 `toUpperCase()` 没有改变 `word`。补全代码，使第二个 `console.log` 打印 `HELLO`
