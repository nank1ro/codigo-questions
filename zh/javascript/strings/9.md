# --description--

`split(separator)` 方法将字符串拆分为一个**数组**片段，在每个 `separator` 处切分：
```javascript
let sentence = "I like JavaScript";
let words = sentence.split(" ");
console.log(words);
// prints [ 'I', 'like', 'JavaScript' ]
```
与之相反的是数组方法 `join(separator)`，它把这些片段重新粘合成一个字符串：
```javascript
console.log(words.join("-"));
// prints I-like-JavaScript
```
