# --description--

`slice(start, end)` 方法从索引 `start` 到索引 `end`（不包含）提取字符串的一部分：
```javascript
let word = "JavaScript";
console.log(word.slice(0, 4));
// prints Java
console.log(word.slice(4));
// prints Script
```
如果省略 `end`，截取会一直到字符串末尾。
负数索引从末尾开始计数：`word.slice(-3)` 为 `"ipt"`。
`substring(start, end)` 方法的用法相同，但不接受负数索引。
