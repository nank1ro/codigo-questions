# --description--

**字符串**是用引号括起来的字符序列，例如 `"hello"` 或 `'hello'`。
每个字符串都有一个 `length` 属性，用来说明它包含多少个字符：
```javascript
let greeting = "hello";
console.log(greeting.length);
// prints 5
```
空格和标点符号也算作字符。
