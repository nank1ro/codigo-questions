# --description--

`null` 和 `undefined` 相互比较时结果如何？这取决于运算符。
**宽松**相等 `==` 把它们视为同一种东西，并认为它们与任何其他值都不同，包括 `0`、`""` 和 `false`：
```javascript
console.log(null == undefined);
// prints true
console.log(null == 0, undefined == "");
// prints false false
```
**严格**相等 `===` 还会比较类型，而 `null` 和 `undefined` 的类型不同：
```javascript
console.log(null === undefined);
// prints false
console.log(null === null);
// prints true
```
