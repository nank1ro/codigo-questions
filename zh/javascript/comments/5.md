# --description--

无论你用哪种注释，规则都一样：注释里的文字**不是代码**。注释中的 `console.log` 永远不会输出任何内容，同一行里写在 `//` 之后的代码也永远不会运行，即便这一行以真正的代码开头：
```javascript
console.log("a"); // console.log("b");
/* console.log("c"); */
// prints only a
```
当你不确定一个程序会输出什么时，先在心里删掉所有注释，再读剩下的内容。

# --instructions--

这段代码输出什么？
```javascript
// console.log("one");
console.log("two"); // console.log("three");
/* console.log("four"); */
console.log("five");
```

# --answers--

- `two` 和 `five`
- `one`、`two`、`three`、`four` 和 `five`
- `two`、`three` 和 `five`
- `two`、`four` 和 `five`
