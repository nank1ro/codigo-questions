# --description--

好的注释说明代码**为什么**这样做，而不是它**做了什么**。代码本身已经展示了发生的事情；用文字重复一遍只会增加噪音，而且代码一改动它就过时了：
```javascript
// 将 timeout 设为 30
const timeout = 30;
```
这个数字背后的原因才是读者猜不到的：
```javascript
// 服务器会在 35 秒后断开空闲连接，所以要提前停止
const timeout = 30;
```
如果一条注释只是复述它下面那一行，就删掉它，或者换成写明原因。
