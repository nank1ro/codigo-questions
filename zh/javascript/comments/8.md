# --description--

要一次注释掉多行，就用一条块注释把它们包起来，而不是给每一行都加 `//`：
```javascript
let total = 100;
/*
total = total - 30;
total = total - 20;
*/
console.log(total); // prints 100
```
由于块内的这些行被忽略，`total` 始终不变。记住，只有当这些行中都不含 `*/` 时这样做才有效。
