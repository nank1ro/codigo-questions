# --description--

你不必存储箭头函数也可以调用它。把它用圆括号包裹起来，并在后面直接加上实参列表：这就是**立即调用**的箭头函数：
```javascript
const doubled = ((n) => n * 2)(5);
console.log(doubled);
// prints 10
```
箭头两侧的圆括号是必需的：没有它们，`(n) => n * 2(5)` 会尝试调用数字 `2`。立即调用的函数非常适合用几个临时变量来计算一个值，而这些变量不会泄漏到程序的其他部分。
