# --description--

模式某一部分周围的圆括号会创建一个**捕获组**：该部分匹配到的文本会被单独保存起来，供你读取。

这些组出现在 `match[0]` 之后，按其左括号从左到右编号：
```javascript
const match = "2026-09-12".match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(match[0]);
// prints 2026-09-12
console.log(match[1]);
// prints 2026
console.log(match[3]);
// prints 12
```
所以 `match[0]` 始终是整个匹配，而 `match[1]`、`match[2]`、……是各个组。如果模式中的某个组完全没有匹配，那么整个 `match` 会返回 `null`。
