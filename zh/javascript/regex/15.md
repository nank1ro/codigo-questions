# --description--

**`split`** 把字符串切分成数组。给它普通字符串时，它按这段确切的文本切分；给它正则表达式时，它按模式的每一次匹配切分，这让一次调用就能处理各不相同的分隔符：
```javascript
console.log("a, b;c".split(", "));
// prints [ 'a', 'b;c' ]
console.log("a, b;c".split(/[,;]\s*/));
// prints [ 'a', 'b', 'c' ]
```
分隔符本身不会出现在结果中。要小心位于字符串开头或结尾的分隔符：它会在数组中产生一个空字符串，因为那一侧存在一个空字段。
