# --description--

`Promise.all` 会在一个 promise 被拒绝时立刻放弃。当你无论如何都想要每一个结果时，使用 **`Promise.allSettled(promises)`**：它永远不会被拒绝，并且以每个 promise 一个小对象兑现，顺序相同：

- 成功的那些是 `{ status: "fulfilled", value: ... }`；
- 失败的那些是 `{ status: "rejected", reason: ... }`。

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
只有当 `status` 是 `"fulfilled"` 时才读取 `value`，只有当它是 `"rejected"` 时才读取 `reason`：另一个属性根本不存在。

# --asserts--

`await countFulfilled([])` 必须是 `0`。

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` 必须是 `2`。

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

三个 promise 中有一个被拒绝时，答案必须是 `2`。

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

当每个 promise 都被拒绝时，答案必须是 `0`，并且 `countFulfilled` 不能被拒绝。

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
