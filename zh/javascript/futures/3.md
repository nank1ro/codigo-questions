# --description--

当值真的稍后才到达时，你要用 **`new Promise`** 自己构建 promise。它接收一个函数，该函数会得到一个 **`resolve`** 回调：在值就绪时调用 `resolve(value)`，promise 就会以这个值兑现。
```javascript
const soon = new Promise((resolve) => {
  setTimeout(() => resolve("done"), 1000);
});
```
`setTimeout(callback, ms)` 安排 `callback` 在 `ms` 毫秒后运行并立即返回，所以在此期间什么都不会被阻塞。

传给 `new Promise` 的函数会立刻运行，但在 `resolve` 被调用之前，promise 会一直保持**待定**状态。await 它就能得到值：
```javascript
async function main() {
  console.log(await soon);
  // prints done, about one second later
}

main();
```

# --asserts--

`delay(10, "ok")` 必须返回一个 promise。

```javascript
(async () => {
  tryCatch(delay(10, "ok") instanceof Promise);
})().catch(() => tryCatch(false));
```

`await delay(0, 7)` 必须是 `7`。

```javascript
(async () => {
  tryCatch((await delay(0, 7)) === 7);
})().catch(() => tryCatch(false));
```

`await delay(10, "ok")` 必须是 `"ok"`。

```javascript
(async () => {
  tryCatch((await delay(10, "ok")) === "ok");
})().catch(() => tryCatch(false));
```

`await delay(60, "x")` 必须至少花费 `50` 毫秒。

```javascript
(async () => {
  const start = Date.now();
  await delay(60, "x");
  tryCatch(Date.now() - start >= 50);
})().catch(() => tryCatch(false));
```
