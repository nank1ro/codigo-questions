# --description--

promise 总是处于三种状态之一：

- **待定**（pending）：工作仍在进行；
- **已兑现**（fulfilled）：工作成功，promise 中持有一个值；
- **已拒绝**（rejected）：工作失败，promise 中持有一个错误。

promise 从待定开始，并且最多改变一次状态。一旦兑现或拒绝，它就是**已定型**（settled）的，再也不会改变。

调用 `async` 函数从不等待：它会启动工作并立即交给你一个待定的 promise，所以调用之后的下一行会在工作完成之前运行。那个 promise 是一个普通的对象，而不是它内部的值，这就是为什么忘记 `await` 是一个如此常见的错误。

# --instructions--

在这段代码中，关于 `n` 哪一项是正确的？
```javascript
async function fetchNumber() {
  return 42;
}

const n = fetchNumber();
console.log(n);
```

# --answers--

- `n` 是一个 promise，所以 `console.log(n)` 不会打印 `42`
- `n` 是数字 `42`，因为函数返回了 `42`
- `n` 是 `undefined`，直到 promise 定型后才变成 `42`
- 只有当 `fetchNumber` 的函数体包含 `await` 时，`n` 才是 promise
