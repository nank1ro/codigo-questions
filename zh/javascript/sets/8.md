# --description--

当值被移除时，`delete(value)` 返回 `true`；当该值不在 set 中时，返回 `false`。
要一次性移除**所有**值，调用 `clear()`：
```javascript
let cart = new Set(["pen", "ink"]);
console.log(cart.delete("pen"));
// prints true
console.log(cart.delete("pen"));
// prints false
cart.clear();
console.log(cart.size);
// prints 0
```
