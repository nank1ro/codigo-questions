# --description--

把展开运算符和 `filter()` 结合起来，就能得到集合论中的经典操作。每一种都会构建一个**新的**集合，不会改变原来的集合：
- **并集**，出现在 `a`、`b` 或两者中的每一个值：`new Set([...a, ...b])`
- **交集**，只有同时出现在**两者**中的值：`[...a].filter((x) => b.has(x))`
- **差集**，`a` 中**不**在 `b` 里的值：`[...a].filter((x) => !b.has(x))`

```javascript
let a = new Set([1, 2, 3]);
let b = new Set([3, 4]);
console.log([...new Set([...a, ...b])]);
// prints [ 1, 2, 3, 4 ]
console.log([...a].filter((x) => b.has(x)));
// prints [ 3 ]
console.log([...a].filter((x) => !b.has(x)));
// prints [ 1, 2 ]
```
较新的 JavaScript 引擎也直接在 set 上提供了 `a.union(b)`、`a.intersection(b)` 和 `a.difference(b)`，但展开加 filter 的写法在任何地方都能用。

# --asserts--

`union(new Set([1, 2]), new Set([2, 3]))` 必须恰好包含 `1`、`2` 和 `3`。

```javascript
tryCatch(JSON.stringify([...union(new Set([1, 2]), new Set([2, 3]))]) === '[1,2,3]');
```

结果必须是一个 `Set`。

```javascript
tryCatch(union(new Set([1]), new Set([2])) instanceof Set);
```

两个空 set 的并集的 `size` 必须为 `0`。

```javascript
tryCatch(union(new Set(), new Set()).size === 0);
```

第一个 set 不能被修改。

```javascript
let _a = new Set([1]);
union(_a, new Set([2]));
tryCatch(_a.size === 1);
```
