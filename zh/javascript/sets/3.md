# --description--

`add()` 返回 set 本身，因此可以链式调用多次：
```javascript
let letters = new Set();
letters.add("a").add("b");
```
无论是否链式调用，已经存在的值都不会被再次添加，因此 `size` 只统计每个不同的值一次。

# --instructions--

let letters = new Set();
