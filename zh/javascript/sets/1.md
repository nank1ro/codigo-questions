# --description--

**Set** 是**唯一**值的集合：每个值最多只能出现一次，并且没有可以按位置访问值的索引。
当你只关心*哪些*值存在，而不关心出现次数或顺序时，Set 非常合适。
你可以用 `new Set()` 创建一个空的 set，用 `add(value)` 添加一个值，用 `has(value)` 检查某个值是否存在：
```javascript
let colors = new Set();
colors.add("red");
colors.add("blue");
console.log(colors.has("red"));
// prints true
console.log(colors.has("green"));
// prints false
```
