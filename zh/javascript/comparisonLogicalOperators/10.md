# --description--

`==` 会先把两边的值转换为同一类型，再进行比较，所以 `"5" == 5` 的结果是 `true`。严格运算符 `===` 会跳过这一转换，还要求两边的类型也必须一致。
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```
