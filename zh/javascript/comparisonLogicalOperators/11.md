# --description--

`!=` 和 `==` 一样，会先转换再比较，所以 `"5" != 5` 的结果是 `false`。它的严格版本 `!==` 无论内容是什么，都会把字符串和数字视为不同的值。
```javascript
console.log("5" !== 5); // true
```
