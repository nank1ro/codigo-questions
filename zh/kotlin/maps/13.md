# --instructions--

`mapOf` 和 `mutableMapOf` 之间有什么区别？

# --answers--

- `mutableMapOf` 创建的 map 在创建后可以添加、更新或删除条目，`mapOf` 创建的是只读 map
- `mapOf` 只能存储 `String` 类型的键，`mutableMapOf` 可以接受任意类型的键
- `mutableMapOf` 允许重复的键，`mapOf` 不允许
- 没有区别，它们是同一个函数的两个名字
