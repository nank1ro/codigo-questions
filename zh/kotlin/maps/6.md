# --description--

要检查某个键是否存在，可以使用 `containsKey` 或 `in` 运算符；要检查某个值是否存在，可以使用 `containsValue`：
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
println(ages.containsKey("Alice")) // true
println("Zoe" in ages)             // false
println(ages.containsValue(25))    // true
```

fun isRegistered(users: Map<String, String>, username: String): Boolean {
    return users.containsKey(username)
}

fun isEmailTaken(users: Map<String, String>, email: String): Boolean {
    return users.containsValue(email)
}
