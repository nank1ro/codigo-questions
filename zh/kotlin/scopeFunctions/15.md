# --instructions--

这个程序会打印什么？

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`，因为 `apply` 返回列表，而 `run` 返回代码块的结果
- `true 2`，因为 `apply` 返回 `add` 的结果
- `[a, b] [a, b]`，因为两者都返回列表
- `2 [a, b]`，因为 `apply` 返回大小，而 `run` 返回列表
