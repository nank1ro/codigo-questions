# --description--

`also` 是 `apply` 的镜像：对象以 `it` 的形式被引用，而调用返回**对象本身**。由于代码块的结果会被丢弃，`also` 适用于日志记录或检查这类**副作用**，并且它可以插入到链的中间，而不会改变链最终产生的结果：
```kotlin
val total = listOf(1, 2, 3)
    .also { println("size: ${it.size}") } // size: 3
    .sum()
println(total) // 6
```
可以把它读作*“顺便用它再做这件事”*：值会原封不动地继续流向下一步。
