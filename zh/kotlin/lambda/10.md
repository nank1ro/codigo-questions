# --description--

由于 lambda 是一个值，函数可以**返回**一个 lambda。返回类型是一个函数类型：
```kotlin
fun multiplier(factor: Int): (Int) -> Int {
    return { it * factor }
}
val triple = multiplier(3)
println(triple(5)) // 15
```
返回的 lambda 捕获了 `factor`，因此每次调用 `multiplier` 都会构建一个不同的函数。
接受或返回其他函数的函数称为**高阶函数**。
