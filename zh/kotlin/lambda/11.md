# --description--

返回的 lambda 可以捕获函数内部声明的 `var`。这个变量在函数返回之后仍然存活，并且只有 lambda 能访问它：它是私有状态。
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
每次调用 `makeGreeter()` 都会声明一个全新的 `calls`，因此两个 greeter 各自独立计数。

# --instructions--

编写一个函数 `makeCounter(): () -> Int`，返回一个没有参数的 lambda。lambda 的每次调用都会增加一个从 `0` 开始的计数器，并返回新值。不同调用 `makeCounter` 得到的计数器必须相互独立。

示例：先 `val next = makeCounter()`，然后 `next()` 返回 `1`，`next()` 返回 `2`。

# --asserts--

计数器的第一次调用必须返回 `1`

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

同一计数器的第二次调用必须返回 `2`

```kotlin
    tryCatch(first() == 2)
```

三次调用之后计数器必须返回 `3`

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

两个计数器必须相互独立

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
