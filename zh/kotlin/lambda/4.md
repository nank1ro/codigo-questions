# --description--

当 lambda 恰好有**一个**参数时，你可以省略它的声明：Kotlin 会自动把它命名为 `it`。
```kotlin
// val double: (Int) -> Int = { n -> n * 2 }
val double: (Int) -> Int = { it * 2 } // same thing
```
`it` 只在参数没有被显式声明时才存在，并且只适用于单参数的 lambda。
它让简短的 lambda 保持紧凑，但对于较长的函数体，一个真正的名字会更清晰。
