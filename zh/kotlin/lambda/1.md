# --description--

**lambda** 是一个没有名字的小函数，直接写成花括号之间的表达式。
参数在前，然后是一个箭头 `->`，接着是函数体：
```kotlin
val add = { a: Int, b: Int -> a + b }
```
lambda 和其他值一样：你可以把它存储在变量中，之后用括号调用它，和调用函数完全一样：
```kotlin
println(add(2, 3)) // 5
```
没有参数的 lambda 完全没有箭头：`val hello = { println("Hello!") }`。
