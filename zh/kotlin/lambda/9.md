# --description--

lambda 可以使用在它周围声明的变量，即使周围代码已经执行完毕。这称为**闭包**：lambda 会*捕获*它需要的变量。
与许多其他语言不同，Kotlin 允许 lambda **修改**捕获到的 `var`：
```kotlin
var clicks = 0
val onClick = { clicks++ }
onClick()
onClick()
println(clicks) // 2
```
每次调用 `onClick` 都会更新同一个 `clicks` 变量，外部代码看到的就是它。
