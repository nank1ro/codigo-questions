# --description--

生成的 `equals()` 使 `==` 成为**结构**比较：当主构造函数中的每个属性都相等时，两个实例就相等。`===` 运算符则不同，它询问的是两个名字是否指向内存中**同一个对象**。

```kotlin
data class User(val id: Int, val name: String)

val a = User(1, "Ann")
val b = User(1, "Ann")
println(a == b)  // true, same data
println(a === b) // false, two different objects
println(a === a) // true
```

由于 `hashCode()` 与 `equals()` 一起生成，data class 实例在 `Set` 中或作为 `Map` 键时也能正确工作：重复项会被合并。

```kotlin
println(setOf(a, b).size) // 1
```

普通类不会生成这些，所以对它来说 `==` 回退为同一性比较。

# --asserts--

用相同数据构建的两个用户必须具有相同的数据

```kotlin
    tryCatch(sameData(User(1, "Ann"), User(1, "Ann")))
```

用不同数据构建的两个用户必须不具有相同的数据

```kotlin
    tryCatch(!sameData(User(1, "Ann"), User(2, "Ann")))
```

分别构建的两个用户必须不是同一个实例

```kotlin
    tryCatch(!sameInstance(User(1, "Ann"), User(1, "Ann")))
```

同一个用户与自身比较必须是同一个实例

```kotlin
    val user = User(3, "Bo")
    tryCatch(sameInstance(user, user))
```

`User` 必须生成 `hashCode()`，因此包含两个相等用户的集合只持有一个元素

```kotlin
    tryCatch(setOf(User(4, "Cy"), User(4, "Cy")).size == 1)
```

data class User(val id: Int, val name: String)

fun sameData(a: User, b: User): Boolean {
    return a == b
}

fun sameInstance(a: User, b: User): Boolean {
    return a === b
}
