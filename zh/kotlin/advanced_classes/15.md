# --instructions--

这段代码会发生什么？

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- 无法编译：嵌套类无法看到外部类的成员，`Nested` 必须是 `inner`
- 可以编译，并且 `show()` 返回外部实例的 `name`
- 可以编译，并且 `show()` 总是返回空字符串
- 无法编译：Kotlin 不允许在一个类内部声明另一个类
