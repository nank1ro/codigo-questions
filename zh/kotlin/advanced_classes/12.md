# --instructions--

这个程序会发生什么？

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- 它打印 `moving`，因为 `Robot` 继承了默认实现
- 无法编译：`Robot` 必须覆盖 `move()`
- 无法编译：接口不能包含函数体
- 它打印 `null`
