# --description--

每个 `Char` 都以数字形式存储，即它的**码**。`code` 属性给出字符背后的 `Int`，而 `toChar()` 做相反的事，把一个 `Int` 变成具有该码的 `Char`：
```kotlin
println('A'.code)        // 65
println(66.toChar())     // B
println(('A'.code + 2).toChar()) // C
```
字母的码是连续的，因此对码做加法就能沿着字母表移动。
注意 `'7'` 的码是 `55`，而不是 `7`：要读取 `Char` 所表示的数字，请使用 `digitToInt()`，它会返回 `7`。
