# --description--

`replace(old, new)` 返回一个字符串副本，其中 `old` 的**每一次**出现都被替换为 `new`：
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
