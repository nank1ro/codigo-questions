# --description--

`indexOf` 返回一段文本**第一次**出现的索引，如果完全没有出现则返回 `-1`。
`lastIndexOf` 则从末尾开始查找：
```kotlin
val text = "hello"
println(text.indexOf("l"))     // 2
println(text.lastIndexOf("l")) // 3
println(text.indexOf("z"))     // -1
```
