# --description--

`uppercase()` 返回一个所有字母都变为大写的字符串副本，`lowercase()` 则相反。
原字符串不会被修改：
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
