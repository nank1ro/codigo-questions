# --description--

扩展函数可以声明在**可空接收者**上，因此它甚至可以在 `null` 值上被调用。在函数内部，`this` 是可空的，必须进行检查：
```kotlin
fun String?.orDash(): String {
    return this ?: "-"
}
val none: String? = null
println(none.orDash()) // -
```
注意，调用处不需要任何 `?.`：由函数本身处理 `null` 的情况。
标准库在 `isNullOrEmpty()` 和 `orEmpty()` 中就使用了这个技巧，它们可以安全地调用在任何 `String?` 上。
