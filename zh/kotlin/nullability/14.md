# --description--

当 `null` 意味着调用方犯了错误时，应该用 `requireNotNull` 尽早失败。
当值存在时，它以非空形式返回该值；当值为 `null` 时，它抛出一个 `IllegalArgumentException`，并可以附带一条消息：
```kotlin
fun greet(name: String?): String {
    val safeName = requireNotNull(name) { "name is required" }
    return "Hello, $safeName"
}
greet(null) // IllegalArgumentException: name is required
```
调用之后，编译器还会把 `name` 本身智能转换为 `String`，因此从那一行起可以使用 `name.length`。
与 `!!` 不同，这种失败带有清晰的消息，并指明是*参数*错了。

# --asserts--

`safeUpper("abc")` 必须返回 `"ABC"`

```kotlin
    tryCatch(safeUpper("abc") == "ABC")
```

`safeUpper("Kotlin")` 必须返回 `"KOTLIN"`

```kotlin
    tryCatch(safeUpper("Kotlin") == "KOTLIN")
```

`safeUpper(null)` 必须抛出 `IllegalArgumentException`

```kotlin
    var threw = false
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        threw = true
    }
    tryCatch(threw)
```

异常消息必须是 `text is required`

```kotlin
    var message = ""
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        message = e.message ?: ""
    }
    tryCatch(message == "text is required")
```

fun safeUpper(text: String?): String {
    val value = requireNotNull(text) { "text is required" }
    return value.uppercase()
}
