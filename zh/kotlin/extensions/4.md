# --description--

扩展**不会**修改它所扩展的类，也不会往类里插入新成员。编译器只是改写了调用：`"kotlin".first3()` 变成对该函数的调用，并把 `"kotlin"` 作为 `this` 传进去。
```kotlin
fun String.first3(): String = take(3)
val word = "kotlin"
println(word.first3()) // kot
```
这就是你能扩展 `String` 和 `Int` 这类 final 类的原因：它们内部什么都没变，扩展只存在于你的代码里。
