# --description--

在 Java 中，块注释不能包含另一个块注释，但在 Kotlin 中它们**可以嵌套**：每个 `/*` 都必须有与之匹配的 `*/`，只有最外层的注释闭合后，注释才会结束。
```kotlin
/* outer /* inner */ still a comment */
println("done")
```
这里 `still a comment */` 是外层注释的一部分，因此只会打印 `done`。正因如此，即使某段代码已经包含 `/* */` 注释，你也可以把整段代码注释掉。
