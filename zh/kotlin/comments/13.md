# --description--

编译器只在代码中识别注释，绝不会在**字符串字面量**中识别。在双引号之间，`//` 和 `/* */` 只是普通字符：
```kotlin
println("50 // 2") // prints 50 // 2
```
第一个 `//` 是文本的一部分，第二个才开始真正的注释。这一点最常让人吃惊的地方是网址，因为协议后面紧跟 `//`。

# --instructions--

以下代码会打印什么？
```kotlin
val site = "https://codigo.dev" // the project home page
println(site)
```

# --answers--

- `https://codigo.dev`
- `https:`
- `https://codigo.dev // the project home page`
- 什么都不打印：整行都是注释
