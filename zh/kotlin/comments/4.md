# --description--

当注释需要占用多行时，Kotlin 提供了**多行注释**（也称为块注释）：它以 `/*` 开头，以 `*/` 结尾，中间的所有内容都会被忽略，包括换行符。
```kotlin
/*
  Prints the welcome banner.
  Called once when the app starts.
*/
println("Welcome!")
```
块注释也可以很短，只占一行：`/* like this */`。
