# --description--

**注释**是写在源代码中的说明性文字，供阅读代码的人参考。编译器会完全忽略注释，因此注释绝不会改变程序的行为。

最简单的注释是**单行注释**：它以 `//` 开头，一直延伸到行尾。
```kotlin
// 问候用户
println("Hello")
```
使用注释来解释一段代码的用途，或者解释代码为什么这样编写。
