# --description--

枚举类可以声明一个**抽象方法**，让每个枚举项在用花括号括起来的代码体中提供自己的实现：
```kotlin
enum class Operation {
    ADD {
        override fun apply(a: Int, b: Int): Int = a + b
    },
    SUBTRACT {
        override fun apply(a: Int, b: Int): Int = a - b
    };

    abstract fun apply(a: Int, b: Int): Int
}
println(Operation.ADD.apply(2, 3)) // 5
```
每个枚举项的行为各不相同，但仍然共享相同的类型和方法签名。
