# --instructions--

给定 `enum class Color { RED, GREEN, BLUE }`，`Color.valueOf("PURPLE")` 会做什么？

# --answers--

- 抛出 `IllegalArgumentException`，因为没有枚举项叫 `PURPLE`
- 返回 `null`
- 返回第一个枚举项 `Color.RED`
- 向枚举中添加一个新的 `PURPLE` 枚举项
