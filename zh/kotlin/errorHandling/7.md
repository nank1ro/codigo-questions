# --description--

由于 `try` 是一个表达式，它可以用在任何需要值的地方——包括作为用 `=` 编写的整个函数体：
```kotlin
fun length(text: String): Int = try {
    text.toInt()
} catch (e: NumberFormatException) {
    -1
}
```
两个块必须产生相同类型的值，这里是 `Int`。把回退值写成 `catch` 块的最后一个表达式；两个块中都没有 `return`。
