# --description--

捕获 `Exception` 会捕获所有异常，这很少是你想要的结果：块中其他地方的拼写错误也会被一起吞掉。相反，应写明你知道如何恢复的**确切类型**。

每种失败都有自己的类型。`"abc".toInt()` 抛出的是 `NumberFormatException`，所以要捕获的就是它：
```kotlin
try {
    println("abc".toInt())
} catch (e: NumberFormatException) {
    println("that is not a number")
}
```
如果块中抛出的是另一种异常，这个 `catch` 就不会匹配，异常会继续向函数外传播。

# --instructions--

编写一个函数 `parseOrZero(text: String): Int`，返回 `text` 中包含的数字，当 `text` 不是数字时返回 `0`。要捕获 `NumberFormatException`。

函数调用示例：
```kotlin
println(parseOrZero("abc"))
// prints 0
```
