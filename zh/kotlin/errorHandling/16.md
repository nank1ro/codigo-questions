# --description--

`try` 放在哪里决定了单个坏值会毁掉多少工作。包住**整个循环**，第一次失败就会放弃批次中剩余的部分；包住**循环体**，则只损失那一个元素：

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // 跳过这一个
    }
}
println(total) // 8
```
这与会抛出异常的校验函数天然搭配：函数声明一条规则并拒绝一切违反它的输入，而循环则决定一次拒绝只损失一个元素。

# --instructions--

编写两个函数。

`validate(text: String): Int` 必须返回 `text` 中包含的数字，或者抛出一个 `IllegalArgumentException`，消息为 `not a number: ` 后接该文本。

`sumValid(values: List<String>): Int` 必须把 `validate` 接受的值加起来，跳过那些使它抛出异常的值。

函数调用示例：
```kotlin
println(sumValid(listOf("1", "x", "3")))
// prints 4
```

```kotlin

```

`validate("x")` 必须抛出一个 `IllegalArgumentException`，消息为 `not a number: x`

```kotlin
    var message = ""
    try { validate("x") } catch (e: IllegalArgumentException) { message = e.message ?: "" }
    tryCatch(message == "not a number: x")
```

```kotlin
    tryCatch(sumValid(listOf("1", "2", "3")) == 6)
```

```kotlin

```


```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // 跳过这一个
        }
    }
    return total
}
```
