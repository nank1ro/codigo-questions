# --description--

因为 `findAll` 给出的是一个序列，你已经知道的聚合方法也可以用在匹配上：`sumOf`、`maxOfOrNull`、`filter`、`sortedBy`。从自由文本中提取数字是一个两步工作：先匹配它们，再把文本转换成数字。
```kotlin
val total = Regex("""\d+""").findAll("2 apples, 3 pears").sumOf { it.value.toInt() }
println(total) // 5
```
