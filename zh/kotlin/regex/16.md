# --description--

一个实际的模式通常同时混合所有内容：用组保留你需要的部分，用转义的 `\.` 表示字面上的点，再用 lambda 替换来围绕它们重建文本。
```kotlin
val email = Regex("""(\w+)@(\w+\.\w+)""")
println(email.replace("ping ann@mail.com now") { m -> "<" + m.groupValues[2] + ">" })
// ping <mail.com> now
```
让模式保持任务允许范围内的简单：一个试图描述每一个合法电子邮件地址的模式是难以阅读的，而 `\w+@\w+\.\w+` 足以在句子中找到地址。

# --instructions--

编写一个函数 `redactEmails(text: String): String`，把每个地址中 `@` 前面的名字替换成 `***`，保留域名。一个地址是一段连续的单词字符、一个 `@`、一段连续的单词字符、一个点和一段连续的单词字符。

示例：`redactEmails("write to ann@mail.com")` 返回 `write to ***@mail.com`。

fun redactEmails(text: String): String {
