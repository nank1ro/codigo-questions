# --description--

`#/ ... /#` 字面量在编译时就固定了。当模式要到运行时才确定时——例如因为它是用户输入的——用 `Regex(_:)` 来构建它：
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
这个初始化器会**抛出错误**：像 `"["` 这样的无效模式只有在程序运行时才会被发现，所以调用需要 `try`，并且错误必须要么用 `do`/`catch`（或 `try?`）处理，要么像本练习所做的那样，把外围函数标记为 `throws` 来传播。以这种方式构建的正则表达式没有编译期已知的编号属性，但 `contains`、`matches(of:)` 和 `replacing` 的工作方式与之前完全相同。

# --instructions--

编写一个函数 `countMatches`，接收一个文本（`String`）和一个模式（`String`），两者都省略参数标签，标记为 `throws`，返回模式在文本中出现的次数。无效的模式必须让错误传播出去

函数调用示例：
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// prints 2
```

# --asserts--

函数必须用 `try Regex(` 构建正则表达式

```json
{
  "regex": "try\\s+Regex\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`countMatches("a1 b22", "[0-9]+")` 必须返回 `2`

```swift
tryCatch((try? countMatches("a1 b22", "[0-9]+")) == 2)
```

`countMatches("abc", "[0-9]+")` 必须返回 `0`

```swift
tryCatch((try? countMatches("abc", "[0-9]+")) == 0)
```

`countMatches("hello world", "o")` 必须返回 `2`

```swift
tryCatch((try? countMatches("hello world", "o")) == 2)
```

`countMatches("abc", "[")` 必须抛出错误

```swift
tryCatch((try? countMatches("abc", "[")) == nil)
```

# --solutions--

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
