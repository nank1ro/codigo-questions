# --description--

默认情况下，模式可以匹配文本中的任何位置。**锚点**则把它固定到一个位置上：
- `^` 表示"文本的开头"
- `$` 表示"文本的结尾"

```swift
print("swift".contains(#/^sw/#))  // true，文本以 sw 开头
print("myswift".contains(#/^sw/#)) // false，sw 不在开头
print("swift".contains(#/ft$/#))  // true，文本以 ft 结尾
```
锚点匹配的是一个位置，而不是字符，所以它们不会给匹配的内容添加任何东西。
