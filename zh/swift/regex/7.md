# --description--

`matches(of:)` 返回**每一个**匹配而不是第一个，形式为数组。这个数组永远不会是 `nil`：没有匹配时它只是空数组，因此可以直接对它进行循环或转换：
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
每个元素都是一个匹配，所以 `map` 中的 `$0.0` 就是匹配到的文本：
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```
