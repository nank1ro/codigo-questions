# --description--

扩展不仅适用于别人的类型。组织自己代码的一种常见方式是把存储属性保留在结构体或类的主体中，而把行为添加到一个或多个扩展中，每个扩展归组相关的成员：
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
在扩展中添加的成员可以直接使用存储属性，完全就像它们写在类型内部一样。

# --asserts--

你必须使用一个 `Rectangle` 扩展

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`2` 乘 `3` 的矩形的面积必须为 `6.0`

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

`1.5` 乘 `4` 的矩形的面积必须为 `6.0`

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

`2` 乘 `3` 的矩形按 `2` 缩放后必须是 `4` 乘 `6`

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

缩放不得改变原始矩形

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
