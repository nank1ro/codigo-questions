# --description--

除了方法之外，扩展还可以添加**计算属性**：这种属性不存储值，而是在每次被读取时计算它。
计算属性用 `var`、类型注解以及返回值的花括号主体来声明：
```swift
extension Int {
    var isNegative: Bool {
        return self < 0
    }
}
print((-3).isNegative) // true
print(7.isNegative)    // false
```
它的读取方式和其他属性一样，不带括号：是 `7.isNegative`，而不是 `7.isNegative()`。
