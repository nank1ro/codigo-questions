# --description--

扩展只能**添加**成员，永远不能替换或重写已有成员。`override` 属于子类，子类与其父类是不同的类型；而扩展是同一个类型，因此声明一个已经存在的方法是重复声明错误：
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
如果你需要不同的行为，可以添加一个使用新名称的方法，或者在类型是类时编写一个子类。

# --instructions--

这段程序在编译和运行时会发生什么？
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- 无法编译，因为 `speak()` 在同一个类型中被声明了两次
- 打印 `Bark`，因为扩展重写了原始方法
- 打印 `Woof`，因为原始方法优先于扩展
- 先打印 `Woof`，然后打印 `Bark`
