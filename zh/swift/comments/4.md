# --description--

当注释需要不止一行时，Swift 提供了**多行注释**（也叫块注释）：它以 `/*` 开始，以 `*/` 结束，中间的一切都会被忽略，包括换行。
```swift
/*
  Prints the welcome banner.
  Called once when the app starts.
*/
print("Welcome!")
```
块注释也可以很短，写在一行里：`/* like this */`。
