# --description--

在摘要之后，文档注释可以用 Xcode 能识别的特殊 Markdown 列表项来描述参数和返回值：
```swift
/// 返回给定分钟数对应的秒数。
/// - Parameter minutes: 一个整数分钟数，不能为负数
/// - Returns: `minutes` 乘以六十
func toSeconds(_ minutes: Int) -> Int {
    return minutes * 60
}
```
顺序始终一致：先是摘要，然后为每个参数写 `- Parameter 名称:`，最后是 `- Returns:`。
