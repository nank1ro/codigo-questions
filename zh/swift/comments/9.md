# --description--

Swift 还有第三种注释，即**文档注释**：以 `///`（三个斜杠）开头的单行注释，放在函数、类型或属性的正上方。
```swift
/// 返回 `name` 对应的问候语。
func greet(_ name: String) -> String {
    return "Hi, \(name)!"
}
```
对编译器来说它只是注释，但 Xcode 这样的工具会读取它，并把它显示为 `greet` 的帮助文本。文档注释支持 **Markdown**，所以你可以用反引号表示代码，也可以用 `**粗体**` 和列表。
