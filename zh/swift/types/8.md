# --description--

数字和字符串使用相同的初始化器语法进行转换。`String(42)` 把数字变成文本 `"42"`，就像用 `"\(42)"` 对它进行插值一样。
反方向可能会失败，因为并非所有文本都是数字，所以 `Int("42")` 返回一个**可选**的 `Int?`：这里它持有 `42`，而 `Int("hello")` 是 `nil`。
正如你在可选值课程中学到的，你可以用 `??` 提供一个回退值，或者用 `if let` 解包它：
```swift
let typed = "42"
let number = Int(typed) ?? 0
print(number + 1) // 43
```
