# --description--

Swift 中的每个值都有一个**类型**，它告诉编译器这是哪种数据，以及你能用它做什么。
基本类型有：
- `Int`：整数，比如 `42` 或 `-7`
- `Double`：带小数部分的数，比如 `3.14`
- `String`：一段文本，比如 `"Hello"`
- `Character`：单个字符，比如 `"a"`
- `Bool`：`true` 或 `false`

你可以使用**类型注解**来标明常量或变量的类型：在名称后面加上冒号和类型名：
```swift
let age: Int = 36
let name: String = "Ada"
```
一种类型的值不能存储到另一种类型的常量中：`let age: Int = "36"` 是一个编译错误。
