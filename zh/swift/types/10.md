# --description--

**类型别名**使用 `typealias` 关键字为一个已有的类型赋予新名称：
```swift
typealias Score = Int
let best: Score = 100
print(best + 1) // 101
```
`Score` 和 `Int` 是同一个类型，所以它们可以随意混用。别名不会增加任何安全性：当普通类型在你的程序中有特定含义时，它只是让代码更易读。
