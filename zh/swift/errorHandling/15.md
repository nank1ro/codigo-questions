# --description--

`do` 代码块所在的位置决定了一次失败要付出多大代价。把它放在循环**内部**，每个元素就会拥有自己的尝试，这样一个坏值会被跳过，其余的仍会继续运行：
```swift
for age in [4, -1, 7] {
    do {
        print(try label(age))
    } catch {
        print("skipped")
    }
}
```
如果改成把整个循环包在一个 `do` 里，则会在第一个错误处停下，永远到达不了 `7`。两种方式都没有错——区别只在于是*一个坏元素*，还是*直接放弃*。
