# --description--

宽度标志只在 `String(format:)` 内部起作用。要自己填充普通字符串，可以用 `String(repeating:count:)` 构建空格并把它们拼接到文本上：
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
如果文本已经比宽度长，`4 - text.count` 会变成负数，`String(repeating:count:)` 会崩溃。用 `max(0, ...)` 来防护，这样数量永远不会低于零，较长的文本保持原样。

# --instructions--

编写一个函数 `leftPad`，接收一个文本（`String`）和一个宽度（`Int`），两者都省略参数标签，通过在左边添加空格使文本在该宽度内右对齐。比宽度长的文本必须原样返回

函数调用示例：
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
