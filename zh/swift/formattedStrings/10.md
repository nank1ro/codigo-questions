# --instructions--

哪一行会精确打印 `3.14`？
```swift
import Foundation

let pi = 3.14159
```

# --answers--

- `print(String(format: "%.2f", pi))`
- `print("\(pi)")`
- `print(String(format: "%2f", pi))`
- `print(String(format: "%d", pi))`
