# --description--

整数也可以用其他进制书写。`%x` 以小写字母打印**十六进制**值，`%X` 使用大写字母，`%o` 则是八进制：
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
宽度和 `0` 标志在这里同样适用：`%02x` 是书写颜色中一个字节的经典方式，例如 `#ff8000`。
