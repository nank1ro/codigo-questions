# --instructions--

补全这个函数，使它把文本转换为 `Int` 并返回它的两倍，当转换失败时返回 `nil`。
然后打印结果，使用 `0` 作为兜底值

func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
