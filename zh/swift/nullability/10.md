# --description--

在连续使用 `??` 时，Swift 会从左到右依次求值，遇到第一个不是 `nil` 的值就停止；只有当它之前所有的可选值都是 `nil` 时，才会使用最后的默认值。

# --instructions--

这段代码会打印什么？
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0)
```

# --answers--

- 7
- 0
- nil
- Optional(7)
