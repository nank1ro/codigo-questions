# --description--

有些值属于类型本身，而不是属于任何单个实例：货币代码、共享的默认值、构建常见情形的工厂。把它们标记为 `static`，然后通过类型名来读取：
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
这里 `currency` 用 `let` 声明，因为它从不改变，所以它是一个由整个程序共享的常量。`Money.currency` 无需创建任何 `Money` 就能使用，而 `amount` 则需要实例。

# --instructions--

为 `Money` 添加一个等于 `"EUR"` 的静态常量 `currency`，以及一个不接收参数的静态方法 `zero`，它返回一个 `amount` 等于 `0` 的 `Money`

使用示例：
```swift
print(Money.currency)
// prints EUR
```

# --asserts--

`currency` 必须是静态常量

```json
{
  "regex": "static\\s+let\\s+currency",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`Money.currency` 必须是 `"EUR"`

```swift
tryCatch(Money.currency == "EUR")
```

`Money.zero()` 的 `amount` 必须为 `0`

```swift
tryCatch(Money.zero().amount == 0)
```

逐一成员初始化器必须仍然可用

```swift
tryCatch(Money(amount: 7).amount == 7)
```
