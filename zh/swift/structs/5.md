# --description--

**计算属性**看起来像属性，但行为像方法：它不存储任何东西，而是在每次读取时计算它的值。你先写出类型，然后写一个返回该值的代码块：
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, no parentheses
```
计算属性不属于逐一成员初始化器的一部分，因为没有东西需要存储。当值由其他值推导而来时使用计算属性，当工作需要参数时使用方法。

# --instructions--

为 `Temperature` 添加一个 `Double` 类型的计算属性 `fahrenheit`，返回摄氏值乘以 `9`、除以 `5` 再加 `32` 的结果

使用示例：
```swift
print(Temperature(celsius: 100).fahrenheit)
// prints 212.0
```
