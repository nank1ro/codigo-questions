# --description--

结构体是一种**值类型**：把它赋值给另一个变量，或把它传递给函数时，交出去的是一份*副本*。修改副本不会影响原始值。
```swift
struct Point {
    var x: Int
}

var a = Point(x: 1)
var b = a
b.x = 99
print(a.x) // 1
```
类是一种**引用类型**：`b = a` 会让两个名字指向同一个实例，因此 `b.x = 99` 也会把 `a.x` 改成 `99`。

这就是两者真正的区别，也是 Swift 用结构体对大多数数据进行建模的原因：你持有的值不会被接收它的代码在背后修改。
