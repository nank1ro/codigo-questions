# --description--

存储属性可以在声明之处直接赋予**默认值**。Swift 会根据该值推断它的类型，因此你可以省略类型注解：
```swift
struct Counter {
    var label: String
    var value = 0
}
```
逐一成员初始化器会把每个有默认值的属性变成可选参数：传入它即可覆盖默认值，省略它则保留默认值。
```swift
let a = Counter(label: "clicks")
print(a.value) // 0

let b = Counter(label: "clicks", value: 7)
print(b.value) // 7
```
