# --description--

因为结构体是一个值，所以方法不允许修改它的属性，除非你用 `mutating` 关键字声明：
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
mutating 方法只能在存储于 `var` 中的实例上调用。对于 `let` 实例，它的值是冻结的，因此 `c.increase(by: 5)` 将无法编译。

# --instructions--

为 `Counter` 添加一个 mutating 方法 `increase`，它接收一个带参数标签 `by` 的 `Int`，并将其加到 `value` 上

使用示例：
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

该方法必须标记为 `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

将 `0` 增加 `5` 必须得到 `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

将 `10` 增加两次必须能够累加

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

增加 `0` 必须不改变任何值

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

修改副本必须不改变原始值

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
