# --instructions--

为什么这段代码无法编译？
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` 是一个 `let` 常量，因此不能对它调用 mutating 方法
- 要修改 `value`，`increase` 必须标记为 `static`
- `value` 必须用 `let` 声明
- 结构体不能包含方法
