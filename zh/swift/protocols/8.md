# --description--

遵循关系不必在类型旁边声明。**扩展**可以在之后添加它，这让类型自身的声明专注于它的数据：
```swift
protocol Resettable {
    mutating func reset()
}

struct Timer {
    var seconds = 0
}

extension Timer: Resettable {
    mutating func reset() {
        seconds = 0
    }
}
```
这也适用于不是你编写的类型：你可以让标准库类型遵循你的某个协议，而无需改动它的源代码。
