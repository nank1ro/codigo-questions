# --description--

结构体是值类型，因此修改其存储属性的方法必须标记为 `mutating`。当这个方法是一项协议要求时，协议也必须这样声明：
```swift
protocol Togglable {
    mutating func toggle()
}

struct Light: Togglable {
    var isOn = false

    mutating func toggle() {
        isOn = !isOn
    }
}

var lamp = Light()
lamp.toggle()
print(lamp.isOn) // true
```
如果协议中没有 `mutating`，结构体就永远无法满足该要求。类是引用类型，从不需要这个关键字：类用一个普通方法就能满足 `mutating` 要求。调用 mutating 方法需要一个 `var`——在 `let` 上调用是编译错误。

    mutating func reset()
}

struct Score {
    var points: Int
}

# --before-asserts--

```swift
func _reset<T: Resettable>(_ v: inout T) {
    v.reset()
}
```

# --asserts--

分数为 `10` 时，重置后必须是 `0`

```swift
var _s1 = Score(points: 10)
_reset(&_s1)
tryCatch(_s1.points == 0)
```

分数为 `-4` 时，重置后必须是 `0`

```swift
var _s2 = Score(points: -4)
_reset(&_s2)
tryCatch(_s2.points == 0)
```

分数为 `0` 时，重置后必须保持为 `0`

```swift
var _s3 = Score(points: 0)
_reset(&_s3)
tryCatch(_s3.points == 0)
```

protocol Resettable {
    mutating func reset()
}

struct Score: Resettable {
    var points: Int

    mutating func reset() {
        points = 0
    }
}
