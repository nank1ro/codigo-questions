# --description--

默认实现是一个后备方案，而不是一条规则。如果遵循协议的类型提供了自己对某项要求的实现，运行的就是它自己的版本：
```swift
protocol Priced {
    var price: Int { get }
}

extension Priced {
    var price: Int { return 0 }
}

struct Ticket: Priced {
    var price = 12
}

print(Ticket().price) // 12, not 0
```
默认实现只填补类型留出的空缺。
