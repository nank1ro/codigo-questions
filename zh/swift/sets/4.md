# --description--

要检查某个值是否在集合中，可以使用 `contains(_:)` 方法，它返回一个 `Bool`：
```swift
let primes: Set<Int> = [2, 3, 5, 7]
print(primes.contains(5)) // true
print(primes.contains(6)) // false
```
这种检查在集合上非常快，即使有成千上万个元素也是如此，这也是在做成员检查时更倾向于使用集合而不是数组的主要原因之一。
