# --description--

集合支持经典的集合论运算。每个运算都会返回一个**新的**集合，原始集合保持不变：
- `a.union(b)` 包含所有在 `a` 中、在 `b` 中，或者两者都在的元素
- `a.intersection(b)` 只包含**同时**在 `a` 和 `b` 中的元素
```swift
let a: Set<Int> = [1, 2, 3]
let b: Set<Int> = [3, 4]
print(a.union(b).sorted())        // [1, 2, 3, 4]
print(a.intersection(b).sorted()) // [3]
```
