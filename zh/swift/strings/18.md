# --description--

`Character` 不是 `String`，所以不能直接用 `+` 把它拼接到字符串上。先用 `String(...)` 转换它：
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
把它和 `for`-`in` 循环结合起来，你可以一次一个字符地重建字符串，例如把每个新字符放在目前为止收集到的字符前面。
