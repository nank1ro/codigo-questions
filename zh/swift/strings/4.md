# --description--

`count` 属性返回字符串中的字符数量，当字符串没有任何字符时，`isEmpty` 为 `true`：
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
每一个字符都会被计数，包括空格和标点符号。
