# --description--

两个字符串可以用 `+` 运算符连接，生成一个新字符串：
```swift
let full = "Hello" + " " + "world" // Hello world
```
要在现有字符串变量的末尾添加文本，可以使用 `+=`。该变量必须用 `var` 声明，因为它的值会发生变化：
```swift
var log = "Start"
log += "..."
print(log) // Start...
```
