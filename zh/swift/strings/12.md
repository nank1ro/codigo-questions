# --description--

`uppercased()` 和 `lowercased()` 会返回一个**新**字符串，其中每个字母都被转换为大写或小写。原字符串不会被修改：
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
两者都是方法，所以别忘了括号。
