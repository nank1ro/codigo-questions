# --description--

字符串可以使用和数字相同的运算符进行比较。`==` 检查两个字符串是否完全由相同的字符组成，而 `<` 和 `>` 会按字典顺序逐个字符进行比较：
```swift
print("apple" == "apple")  // true
print("apple" < "banana")  // true
print("car" < "cat")       // true
```
比较是区分大小写的，并且每个大写字母都排在每个小写字母**之前**，所以 `"B" < "a"` 为 `true`。
