# --description--

Swift 更进一步：在闭包内部，你可以使用**简写参数名称** `$0`、`$1`、`$2` 等来引用参数，而无需声明任何参数或使用 `in` 关键字。
`$0` 是第一个参数，`$1` 是第二个：
```swift
let add: (Int, Int) -> Int = { $0 + $1 }
print(add(2, 3)) // 5
```
类型仍然来自注解 `(Int, Int) -> Int`。
