# --description--

`reduce` 把所有元素合并成一个值。它接收一个初始值和一个带两个参数的闭包：目前累积的值和当前元素。闭包返回新的累积值：
```swift
let nums = [1, 2, 3, 4]
let product = nums.reduce(1) { $0 * $1 }
print(product) // 24
```
这里 `$0` 最初是 `1`，然后依次变为 `1 * 1`、`1 * 2`、`2 * 3`，最后是 `6 * 4`。
因为 `map`、`filter` 和 `reduce` 都会返回值，所以它们可以链式调用：`nums.filter { $0 > 1 }.map { $0 * 10 }`。
