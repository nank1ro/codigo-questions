# --description--

由于闭包是值，函数可以接受闭包作为参数。参数类型就是这个函数类型：
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
函数 `apply` 并不知道 `operation` 做了什么，它只知道 `operation` 接收一个 `Int` 并返回一个 `Int`，然后像调用其他函数一样调用它。
