# --description--

`zip` 按位置逐个配对两个序列的元素，产生一个元组序列。它在较短的那个序列末尾停止：
```swift
let names = ["Ann", "Bob"]
let ages = [31, 27, 99]
let pairs = zip(names, ages).map { "\($0) is \($1)" }
print(pairs) // ["Ann is 31", "Bob is 27"]
```
在闭包内部，`$0` 是来自第一个序列的元素，`$1` 是来自第二个序列的元素。`zip` 是一个自由函数，而不是方法：你写的是 `zip(a, b)`，而不是 `a.zip(b)`。
