# --description--

依次写下的多个 `await` 调用会**顺序执行**：第二个调用要等第一个返回后才会开始。代码自上而下阅读，与普通代码完全一样：
```swift
func step(_ name: String) async -> String {
    print("start \(name)")
    return "done \(name)"
}

let a = await step("A")
print(a)
let b = await step("B")
print(b)
// start A
// done A
// start B
// done B
```
当第二个调用需要第一个调用的结果时，这正是你想要的行为。当各调用相互独立时，先等一个再开始另一个是浪费时间，接下来的练习会展示如何避免这一点。
