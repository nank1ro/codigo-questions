# --description--

异步函数通常建立在其他异步函数之上。在 `async` 函数内部，你可以 `await` 任何其他 `async` 函数，其结果可以像普通值一样使用：
```swift
func base() async -> Int {
    return 10
}

func withBonus() async -> Int {
    let value = await base()
    return value + 5
}

print(await withBonus())
// 输出 15
```
`await` 只能在异步上下文中使用：`async` 函数内部，或脚本的顶层。普通的、非 `async` 的函数不能 `await` 任何东西。

```swift
}

print(await second())
```
