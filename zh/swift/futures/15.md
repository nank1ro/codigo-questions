# --instructions--

这段代码在输出中显示什么？
```swift
func value(_ n: Int) async -> Int {
    return n + 1
}

let job = Task {
    return await value(9)
}
print(await job.value)
```

# --answers--

- `10`
- `9`
- `Task<Int, Never>`
- 什么都不显示，因为任务从未启动
