# --description--

随着时间进行的工作经常会失败：服务器宕机、文件丢失、输入有误。这样的函数会标记为 **`async throws`**，并使用 **`try await`** 来调用：
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
要处理错误，需要把调用包在 `do` 块中并捕获它：
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// prints could not load
```
关键字的顺序是固定的：先写 `try`，再写 `await`。

# --instructions--

编写一个函数 `parse`，接收一个字符串（省略参数标签），是异步的，可以抛出错误，返回该字符串转换为 `Int` 的结果。如果字符串不是数字，则抛出 `InputError.notANumber`

函数调用示例：
```swift
print(try await parse("7"))
// prints 7
```


`parse("7")` 必须返回 `7`

```swift
do {
    let value = try await parse("7")
    tryCatch(value == 7)
} catch {
    tryCatch(false)
}
```

`parse("-3")` 必须返回 `-3`

```swift
do {
    let value = try await parse("-3")
    tryCatch(value == -3)
} catch {
    tryCatch(false)
}
```

`parse("abc")` 必须抛出错误

```swift
do {
    _ = try await parse("abc")
    tryCatch(false)
} catch {
    tryCatch(true)
}
```

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
