# --description--

`in` 运算符检查一个字符串是否**包含**另一个字符串。
它返回 `True` 或 `False`，所以很自然地可以放进 `if` 里：
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` 执行相反的检查。
