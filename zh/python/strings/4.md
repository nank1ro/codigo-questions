# --description--

索引也可以是**负数**：它们从字符串末尾开始计数。
`-1` 是最后一个字符，`-2` 是它前面的一个，依此类推：
```python
word = "python"
print(word[-1])  # n
print(word[-2])  # o
```
这很方便，因为你不需要知道字符串的长度就能到达它的末尾。
