# --description--

跨越**多行**的字符串可以用**三引号** `"""..."""`（或 `'''...'''`）书写。
引号内的每个换行都会成为字符串的一部分，所以你不需要用 `\n`：
```python
poem = """Roses are red,
Violets are blue"""
print(poem)
```
打印：
```
Roses are red,
Violets are blue
```
三引号字符串还可以自由包含单引号和双引号。
