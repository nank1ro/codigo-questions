# --description--

字符串自带许多内置**方法**：在字符串后面加一个点来调用的函数。
`upper()` 返回大写形式的文本，`lower()` 返回小写形式：
```python
word = "Python"
print(word.upper())  # PYTHON
print(word.lower())  # python
print(word)          # Python
```
注意，这些方法会**返回一个新的字符串**：原来的 `word` 不会被改变。
`lower()` 常用于忽略大小写比较文本：`"Yes".lower() == "yes"`。
