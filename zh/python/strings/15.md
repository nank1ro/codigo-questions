# --description--

有些字符不能直接输入到字符串中。
**转义序列**是一个反斜杠 `\`，后面跟着一个代表特殊字符的字母或符号：

- `\n` 换行
- `\t` 制表符
- `\"` 双引号字符串中的一个双引号
- `\'` 单引号字符串中的一个单引号
- `\\` 一个字面意义上的反斜杠

```python
print("Line 1\nLine 2")
print("She said \"hi\"")
```
打印：
```
Line 1
Line 2
She said "hi"
```
每个转义序列都算作**一个**字符，即使你输入了两个。
