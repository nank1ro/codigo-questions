# --description--

`split()` 将字符串拆分成一个**列表**片段。
不带参数时按空白字符拆分；带参数时按该分隔符拆分：
```python
print("a b  c".split())      # ['a', 'b', 'c']
print("2024-01-31".split("-"))  # ['2024', '01', '31']
```
`join()` 做相反的事：将列表中的元素粘合成一个字符串。
它在**分隔符**上调用，列表作为参数：
```python
words = ["one", "two", "three"]
print(", ".join(words))  # one, two, three
print("".join(words))    # onetwothree
```
