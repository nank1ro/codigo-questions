# --description--

`replace(old, new)` 返回一个字符串副本，其中**每一处** `old` 都被替换为 `new`：
```python
text = "a-b-c"
print(text.replace("-", "+"))  # a+b+c
```
由于字符串是不可变的，如果想保留结果，记得把它存储起来。
