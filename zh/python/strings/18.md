# --description--

**slug** 是标题的 URL 友好版本：小写、两端没有空格，单词之间用短横线分隔，例如 `hello-world`。
构建它只需要串联你已经学过的方法：`strip()`、`lower()` 和 `replace()`。

# --instructions--

编写一个函数 `slugify(title)`，返回去除两端空格、转换为小写，并将每个空格替换为 `-` 的 `title`

```python
def slugify(title):
    return title.strip().lower().replace(" ", "-")
```
