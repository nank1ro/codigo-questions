# --description--

**字符串**是一段文本：用引号括起来的字符序列。
Python 既接受单引号 `'...'`，也接受双引号 `"..."`，它们的工作方式完全相同：
```python
name = 'Ada'
language = "Python"
```
当文本本身包含引号时，选择哪种引号就很重要。
单引号内的撇号会过早地结束字符串，所以这时应改用双引号：
```python
print("It's sunny")  # It's sunny
```
