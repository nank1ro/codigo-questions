# --description--

字符串的每个字符都有一个位置，称为**索引**。
索引从 `0` 开始，而不是从 `1` 开始：第一个字符的索引是 `0`，第二个字符的索引是 `1`，依此类推。
在字符串后面的方括号中写上索引即可读取单个字符：
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
访问一个不存在的索引，比如 `word[6]`，会引发 `IndexError`。
