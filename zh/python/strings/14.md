# --description--

`startswith(prefix)` 和 `endswith(suffix)` 会根据字符串的开头或结尾返回 `True` 或 `False`：
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
这是检查文件扩展名、协议或前缀的常用方法。
