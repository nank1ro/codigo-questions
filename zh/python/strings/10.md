# --description--

用户输入的文本周围经常带有多余的空格。
`strip()` 方法返回一个**去除首尾空白字符**（空格、制表符和换行符）的字符串副本：
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
文本中间的空格会被保留。
`lstrip()` 只去除左侧，`rstrip()` 只去除右侧。
