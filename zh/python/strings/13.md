# --description--

`find(sub)` 返回 `sub` 第一次出现的**索引**，如果没有找到则返回 `-1`：
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` 返回 `sub` 出现的**次数**：
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

将 `text` 中第一个 `o` 的索引存储在 `position` 中，将搜索 `z` 的结果存储在 `missing` 中，将 `text` 中 `o` 出现的次数存储在 `total` 中
