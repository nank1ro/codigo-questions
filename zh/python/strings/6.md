# --description--

你已经知道 `+` 可以将两个字符串连接在一起（**拼接**）。
`*` 运算符可以将字符串**重复**指定的次数：
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
重复是绘制分隔符和简单图案的快捷方式。
