# --description--

**切片**（slice）可以提取字符串的一部分。
在方括号中写 `[开始:结束]`：位置为 `开始` 的字符会被包含，位置为 `结束` 的字符会被**排除**：
```python
word = "python"
print(word[0:3])  # pyt
print(word[2:4])  # th
```
你可以省略 `开始` 来从字符串开头切片，或省略 `结束` 来切片到末尾：
```python
print(word[:2])  # py
print(word[2:])  # thon
```
切片永远不会引发错误：如果 `结束` 大于字符串长度，切片只会在最后一个字符处停止。
