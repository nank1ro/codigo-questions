# --description--

字符串是**不可变的**：一旦创建，它的字符就不能被修改。
对索引赋值会引发 `TypeError`：
```python
word = "dog"
word[1] = "i"  # TypeError: 'str' object does not support item assignment
```
要"修改"一个字符串，你需要构建一个新的字符串，例如使用切片和拼接，然后存储到变量中：
```python
word = word[0] + "i" + word[2:]
print(word)  # dig
```

# --instructions--

运行这段代码会发生什么？
```python
word = "cat"
word[0] = "b"
print(word)
```

# --answers--

- 一个 `TypeError`：字符串是不可变的，不能就地替换某个字符
- 打印 `bat`
- 打印 `b`
- 打印 `cat`，赋值被静默忽略
