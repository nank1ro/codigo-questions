# --description--

**装饰器**是一种高阶函数，它接收一个函数并返回一个包装它的新函数，通常用于在原始调用之前或之后添加行为：
```python
def announce(func):
    def wrapper(name):
        print("calling " + func.__name__)
        return func(name)
    return wrapper
```
`func.__name__` 是函数定义时所用的名称。应用装饰器就是一次调用：`greet = announce(greet)`。放在 `def` **上方**一行的 `@` 语法所做的正是这件事：
```python
@announce
def greet(name):
    return "Hello, " + name
```
装饰器必须在使用 `@` 之前定义，因为替换会在 `def` 执行时立即发生。
