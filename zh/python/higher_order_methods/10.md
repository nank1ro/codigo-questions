# --description--

`functools` 中的 `partial(func, *fixed)` 构建一个新函数，其中一些参数**已被填入**。调用结果时提供其余的参数：
```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(5))  # 25
```
提供给 `partial` 的位置参数填充最前面的参数；关键字参数按名称固定一个参数，而在调用时仍然可以覆盖它。partial 是普通的可调用对象，因此可以传递给 `map`、`sorted` 或任何其他高阶函数。

# --instructions--

这段代码会打印出什么？
```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(5), square(base=3))
```

# --answers--

- `25 9`，因为 `exponent` 被固定为 `2`，调用时提供底数
- `32 8`，因为 `partial` 的第一个参数是底数
- `25 8`，因为 `square(base=3)` 覆盖了固定的指数
- 一个 `TypeError`，因为 `base` 对 `partial` 来说也是必需的
