# --description--

闭包可以读取外层函数的变量，但对其中某个变量赋值却会创建一个**新的局部**变量。要更新外层变量，请在内部函数中用 `nonlocal` 声明它：
```python
def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment
```
`global` 会在模块级别查找 `count`，而那里并不存在这个变量。使用 `nonlocal` 后，每次调用返回的函数都会更新同一个 `count`，因此闭包在调用之间携带着状态，就像一个小型对象。
