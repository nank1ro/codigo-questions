# --description--

一个小的异步程序遵循固定的形状：导入 `asyncio`，定义协程函数，定义一个 await 它们的 `main` 协程，最后在结尾调用一次 `asyncio.run(main())`。

# --instructions--

排列各项以构建一个程序：以导入开始，在 `main` 之前定义 `download`，用 `asyncio.gather` 并发运行两个下载并打印结果，产生输出 `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

['report.pdf', 'data.csv']
