# --description--

`await` 会暂停当前协程，直到被等待的操作完成，然后交回它的结果。在协程暂停期间，事件循环可以自由地运行其他协程。`await` 只能用在 `async def` 内部。

`asyncio.sleep(seconds)` 是最简单的可等待对象：它等待给定的时间而不阻塞事件循环。与 `time.sleep` 不同，它必须用 `await` 等待：
```python
import asyncio

async def countdown():
    print("ready")
    await asyncio.sleep(0.05)
    print("go")

asyncio.run(countdown())
```
程序打印 `ready`，等待 50 毫秒，然后打印 `go`。写 `asyncio.sleep(0.05)` 而不加 `await` 会创建协程对象但从不运行它，因此不会发生任何等待。

```python
    def test_1(self):
        self.assertEqual(asyncio.run(wait_and_return("ok", 0.01)), "ok", "--err-t1--")
```

`wait_and_return(7, 0.02)` 必须返回 `7`，并且耗时至少 `0.02` 秒

```python
    def test_2(self):
        start = time.perf_counter()
        result = asyncio.run(wait_and_return(7, 0.02))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, 7, "--err-t2--")
        self.assertGreaterEqual(elapsed, 0.018, "--err-t2--")
```
