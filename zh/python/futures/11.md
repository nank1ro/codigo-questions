# --description--

无论有没有人在等待它，任务都会持续运行。尽早创建它，做其他工作，只在需要其结果的地方才 `await` 它：等待会更短，因为任务的一部分已经在后台运行过了。任务还可以用 `task.done()` 来检查，它一旦完成就返回 `True`。

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```
