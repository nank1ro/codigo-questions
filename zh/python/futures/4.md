# --description--

调用协程函数并不足以运行它。调用只是构建一个协程对象；函数体在该对象被 await 或传给 `asyncio.run` 时才会运行：
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python 甚至会对此发出警告：`RuntimeWarning: coroutine 'hello' was never awaited`。忘记 `await` 是最常见的异步错误：代码看起来被调用了，却从未执行，而本应保存其结果的变量保存的却是一个协程对象。

# --instructions--

这段代码会打印什么？
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- 只有 `main`，因为 `hello()` 创建了一个从未被 await 的协程对象，所以它的函数体不会运行
- 先 `hi` 再 `main`，因为调用协程函数会立即运行它
- 先 `main` 再 `hi`，因为协程在 `main` 返回时才运行
- `TypeError`，因为协程不能赋值给变量
