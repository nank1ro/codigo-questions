# --description--

这些部件可以自然地组合起来。要并发运行许多操作，且每个操作都有自己的时限，可以把每一个包装在一个应用 `wait_for` 并捕获 `TimeoutError` 的小协程中，然后 `gather` 这些包装协程：
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])` 然后会为每个按时完成的任务返回一个值，为每个未按时完成的任务返回 `None`，顺序保持原样，而整批任务最多耗时约 `limit` 秒。

# --instructions--

编写一个协程函数 `job(delay)`，它等待 `delay` 秒并返回 `delay`；再编写一个协程函数 `run_jobs(delays, limit)`，它为每个 delay **并发**运行一个 `job`，每个都用 `asyncio.wait_for` 限制在 `limit` 秒内，并返回一个列表，其中包含每个按时完成的任务的 delay，以及每个超时任务的 `None`，顺序保持原样


`run_jobs([0.01, 0.06, 0.02], 0.04)` 必须返回 `[0.01, None, 0.02]`，`run_jobs([], 0.01)` 必须返回 `[]`

```python
    def test_2(self):
        self.assertEqual(asyncio.run(run_jobs([0.01, 0.06, 0.02], 0.04)), [0.01, None, 0.02], "--err-t2--")
        self.assertEqual(asyncio.run(run_jobs([], 0.01)), [], "--err-t2--")
```

五个 `0.02` 秒的任务在 `0.05` 的限制下必须全部完成并并发运行，耗时远低于 `0.1` 秒

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(run_jobs([0.02] * 5, 0.05))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [0.02] * 5, "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
