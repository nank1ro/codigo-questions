# --description--

当模式包含捕获组时，`findall` 的行为会改变。恰好只有一个组时，它返回该组的内容而不是整个匹配；有两个或更多组时，它为每个匹配返回一个由各组组成的元组：
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
这一点值得记住：仅仅为了分组而给模式加上括号，就会悄悄改变 `findall` 的返回结果。`re.finditer` 从不这样表现，因为匹配对象总是同时保留完整匹配和各个分组。

# --instructions--

这段代码会打印出什么？
```python
import re

print(re.findall(r"(\w+)@(\w+)", "ada@example bob@test"))
```

# --answers--

- `[('ada', 'example'), ('bob', 'test')]`，因为组多于一个时 `findall` 会为每个匹配返回一个由各组组成的元组
- `['ada@example', 'bob@test']`，因为 `findall` 总是返回整个匹配的文本
- `['ada', 'example', 'bob', 'test']`，因为 `findall` 把每个匹配的每个组放进一个扁平列表
- `[]`，因为带捕获组的模式只能配合 `re.finditer` 使用
