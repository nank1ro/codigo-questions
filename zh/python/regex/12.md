# --description--

传给 `re.sub` 的替换内容也可以是一个**函数**。每个匹配会调用它一次，它接收匹配对象，并必须返回用来放在该处的字符串。这样替换结果就可以取决于匹配到了什么：
```python
import re

def shout(match):
    return match.group().upper()

print(re.sub(r"[a-z]+", shout, "one two"))  # ONE TWO
```
函数按名称传递，不带括号：写成 `shout(match)` 会立刻调用它，而不是把它交给 `re.sub`。
