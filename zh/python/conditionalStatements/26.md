# --description--

当 `online` 被设为 `False` 时，条件永远不成立，代码块会被跳过，什么都不会被打印。

# --instructions--

这段代码在输出中显示什么？
```python
online = False
if (online):
    print("Hello user!")
```

# --answers--

- Hello user!
- "Hello user!"
- 什么都不显示，代码被跳过了
