当我们只想在满足某个条件时才执行代码时，就需要进行决策判断。
假设我们只想在天气好的时候出去玩。
在编程中，我们可以保存一个布尔变量 `nice_weather`，并在该变量为 `True` 时执行出去玩的操作，如下所示：
```python
nice_weather = True
if (nice_weather):
    # 出去玩
```

---

让我们继续之前的例子。
```python
nice_weather = True
if (nice_weather):
    # 出去玩
```
我们已经看到 `if` 语句只有在条件为 `True` 时才会执行代码块。
另一个需要注意的重要事项是**冒号** `:` 和**缩进**，它们表示代码块的开始。
缩进是指代码行开头的空格。
在其他编程语言中，代码缩进仅用于提高可读性，而在 Python 中，缩进是必不可少的。
你可以使用你喜欢的空格数（2、4、6、8），但推荐使用 4 个空格。
在本应用中，我们建议使用 **TAB** 键来缩进你的代码行

---

我们刚刚学习了如何在条件成立时执行一段代码块，现在让我们来看看如何在第一个条件不成立时执行另一段代码块。
如果天气好，我们就出去玩；否则，我们就待在家里。
在 Python 中，我们可以使用 `else` 语句，如下所示：
```python
nice_weather = True
if (nice_weather):
    # 出去玩
else:
    # 待在家里
```

---

假设我们有另一个条件需要检查，如下例所示：
```python
num = 3
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
else:
    print("do something else")
```
这段代码的输出是 `the number is 3`。
首先，让我们检查数字是否等于 2，这是 false。
然后我们继续检查第二个语句，检查 `num` 是否等于 3，由于这是 true，我们执行接下来的代码块，打印 `the number is 3`

---

我们可以添加任意多个 `elif` 语句，没有限制
```python
num = 4
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
elif (num == 4):
    print("the number is 4")
elif (num == 5):
    print("the number is 5")
elif (num == 6):
    print("the number is 6")
```
这段代码的输出是 `the number is 4`。

---

我们还可以在一个条件语句（`if`、`elif` 或 `else`）内部嵌套另一个条件语句，以创建更复杂的结构。
```python
num = 4
if (num < 3):
    print("the number is lower than 3")
else:
    if (num == 3):
        print("the number is 3")
    elif (num == 4):
        print("the number is 4")
    else:
        print("the number is greather than 4")
```
这段代码的输出是 `the number is 4`。

---

每个条件语句都需要用 `if` 关键字引出。正是它告诉 Python：只有当条件成立时，下面的代码块才会执行。

---

条件不一定要是一次比较——像 `True` 这样单独的布尔值也可以，只要这个值为 `True`，代码块就会执行。

---

只需改变条件，就能让同一条语句跳过它的代码块：只要条件的结果是 `False`，Python 就会直接跳过缩进的代码。

---

Python 中的 `if` 语句由三部分组成：`if` 关键字、条件，以及结束该行的冒号。冒号之后所有缩进的内容都属于这个代码块。

---

由于这里的条件是 `True`，Python 会执行下面缩进的那一行，打印出 `Hello!`。

---

条件为 `False` 意味着 Python 永远不会进入缩进的代码块，所以什么都不会被打印。

---

决定代码块是否执行的值叫做条件，它的结果必须是一个布尔值，`True` 或 `False`。

---

`if` 下面的代码块不能为空：如果冒号后面没有缩进的代码行，Python 会抛出 `IndentationError`。当暂时没有内容可执行时，`pass` 是常用的占位语句。

---

冒号属于 `if` 这一行，而不属于代码块：它标志着条件的结束，并表明下面缩进的行都属于这条语句。

---

当条件为 `False` 时，Python 会跳过整个缩进的代码块，继续执行下一行不属于该 `if` 缩进范围的代码。

---

Python 并不要求条件外面加括号——`if True:` 本身就是一条完整的语句。这里的括号只是普通的分组符号，和算术运算中用的一样，不会改变值本身。

---

代码块可以包含不止一行，各行会按书写的顺序执行——添加在已有语句之上的语句会先打印。

---

布尔变量可以单独作为条件使用——不需要先把它和 `True` 或 `False` 做比较。

---

当条件是一个变量时，`if` 读取的是该变量此刻保存的值。只需修改上面的赋值语句，就能关闭这个代码块，完全不用改动 `if` 这一行。

---

属于条件语句的那些缩进行叫做代码块——正是缩进标志着它们属于这条语句。

---

位于 `if` 缩进范围之外的行，无论条件结果如何都会执行，因为它本来就不属于那个代码块。

---

代码块不限于一行——只要每一行都保持一致的缩进，它可以按逻辑需要写得或短或长。

---

当 `online` 被设为 `False` 时，条件永远不成立，代码块会被跳过，什么都不会被打印。

---

只有紧跟在 `if` 后面并缩进的 `print` 才属于它的代码块；与 `if` 本身处于同一缩进级别的行则不属于。

---

写在 `if` 代码块之后、但没有额外缩进的行不再属于它——无论条件结果如何，它每次都会执行。

---

代码块可以包含任意数量的语句。它们会从上到下依次执行，并且每一条都必须缩进到相同的级别。

---

把 `True` 赋值给这个变量，会让它所对应的条件成立，于是下面的代码块就会执行。

---

如果改为赋值 `False`，条件就不成立，下面的代码块会被完全跳过。

---

`if` 关键字是条件语句的起始标志——它和条件一起，决定下面的代码块是否执行。

---

加了引号的 `"False"` 是一个字符串，而不是布尔值，非空字符串总是被判定为真。只有不加引号的 `False` 才能阻止代码块执行。
```python
print(bool("False"))  # True
```

---

在这里选择 `True` 会让代码块中的两行都执行，而不仅仅是第一行——缩进在 `if` 下面的内容都属于同一个代码块。

---

冒号是 `if` 这一行唯一不可或缺的部分：它结束条件，并开启代码块。在 Python 中，条件外的括号是可选的，所以 `if True:` 和 `if (True):` 的行为完全相同。

---

像 `if`、`elif` 和 `else` 这样，根据布尔值来决定执行还是跳过代码的语句，统称为条件语句。

---

`not` 运算符会翻转布尔值：`not True` 是 `False`，`not False` 是 `True`。
```python
is_online = False
print(not is_online)  # True
```

---

`not` 会构建一个新的布尔值，而不是修改它所读取的那个，所以在执行 `is_afternoon = not is_morning` 之后，变量 `is_morning` 仍然保留着原来的值。

---

条件永远位于 `if` 关键字和其后的冒号之间，这一行里其他地方都不会出现条件。

---

`if` 代码块能包含多少行并没有硬性限制——重要的是每一行都保持相同的缩进级别。

---

布尔字面量完全可以作为条件：`if True:` 每次都会执行它的代码块。写成 `if (True):` 是完全相同的语句，因为在 Python 中条件外的括号是可选的。

---

`if` 语句的代码块，是它下面那组缩进的代码行，正是缩进把它们和程序的其余部分区分开来。

---

条件的结果永远只会是两个值之一，`True` 或 `False`——这正是它成为布尔值的原因。
