# --description--

只有紧跟在 `if` 后面并缩进的 `print` 才属于它的代码块；与 `if` 本身处于同一缩进级别的行则不属于。

# --instructions--

哪个 print 语句属于该语句的代码块？
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)

# --solutions--

- print("Hello User!")
