# --description--

位于 `if` 缩进范围之外的行，无论条件结果如何都会执行，因为它本来就不属于那个代码块。

# --instructions--

我们怎么知道 `Hello World` 总是会被打印？
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- 因为它的缩进
- 因为 if 语句不能有多于一行
- 因为没有 else 语句
- 因为没有 elif 语句
