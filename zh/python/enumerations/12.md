# --description--

枚举与 `match` 语句（自 Python 3.10 起可用）天然搭配，后者将一个值与一系列 `case` 模式进行比较，并执行第一个匹配的模式：
```python
def action(light):
    match light:
        case Light.RED:
            return "Stop"
        case Light.GREEN:
            return "Go"
        case _:
            return "Slow down"
```
始终连同类一起书写成员，例如 `Light.RED`：像 `case RED:` 这样的裸名称不会进行任何比较，它只会把值捕获到新变量 `RED` 中并匹配一切。
通配符 `case _:` 是默认分支，必须放在最后，因为它之后的任何模式永远无法到达。

```python
from enum import Enum
class Light(Enum):
    RED = 1
    YELLOW = 2
    GREEN = 3
def action(light):
    match light:
        case Light.RED:
            return "Stop"
        case Light.GREEN:
            return "Go"
        case _:
            return "Slow down"
print(action(Light.YELLOW))
```
