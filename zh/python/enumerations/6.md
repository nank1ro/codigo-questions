# --description--

通常具体值并不重要：你只需要成员彼此不同。
在这种情况下，你可以让 Python 通过 `auto()` 选取值，它同样从 `enum` 模块导入。
它将 `1` 赋给第一个成员，然后依次递增：
```python
from enum import Enum, auto

class Direction(Enum):
    NORTH = auto()
    SOUTH = auto()
    EAST = auto()

print(Direction.EAST.value)  # 3
```
