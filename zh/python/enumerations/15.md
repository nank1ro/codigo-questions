# --description--

当你处理来自外部的数据（例如日志行或文件）时，迭代类和按名称查找成员可以很好地配合使用。
对类进行字典推导式会为每个成员准备一个条目，然后 `Level[name]` 把每个传入的字符串转换为对应的成员：
```python
counts = {level: 0 for level in Level}
counts[Level["INFO"]] += 1
```
由于枚举保持声明顺序，之后迭代 `counts` 会以相同的顺序给出成员。

# --solutions--

```python
from enum import Enum, auto
class Level(Enum):
    DEBUG = auto()
    INFO = auto()
    ERROR = auto()
counts = {level: 0 for level in Level}
for name in ["INFO", "ERROR", "INFO"]:
    counts[Level[name]] += 1
for level, count in counts.items():
    print(f"{level.name}: {count}")
```

# --output--

DEBUG: 0
INFO: 2
ERROR: 1
