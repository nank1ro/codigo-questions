# --description--

枚举类是**可迭代的**：对类进行 `for` 循环会按声明顺序访问每个成员：
```python
for color in Color:
    print(color.name, color.value)
```
`len()` 返回枚举有多少个成员，`list(Color)` 则构建一个由它们组成的列表：
```python
print(len(Color))    # 3
print(list(Color))   # [<Color.RED: 1>, <Color.GREEN: 2>, <Color.BLUE: 3>]
```
在列表中，成员以它们的 `repr()` 形式显示，其中值包含在尖括号之间。
