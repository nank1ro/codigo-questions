# --description--

没有被任何 `except` 块匹配的异常会继续向外传播：跳出当前行、跳出执行它的函数、跳出它的调用者，依此类推。如果在到达程序顶层之前没有任何东西捕获它，Python 会打印回溯信息，进程以非零退出状态结束。失败语句之后的行永远不会执行。

# --instructions--

这段代码运行时会发生什么？
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- 它打印 `start`，然后是以 `TypeError` 结尾的回溯信息，`end` 和 `after` 都不会被打印，因为未被捕获的异常会停止程序
- 它打印 `start`、`end` 和 `after`，因为 Python 只跳过失败的那一行
- 它打印 `start` 和 `after`，因为异常停止了 `sizes` 但程序继续运行
- 它打印 `start` 和 `0`，因为 `len(None)` 是 `0`
