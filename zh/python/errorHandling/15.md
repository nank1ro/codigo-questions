# --description--

有时，处理程序应该对一次失败作出反应，但不必为此承担责任：记录它、计数、关闭某个东西——然后把问题交给调用者处理。在 `except` 块中单独使用一个 `raise` 会**重新引发**正在处理的异常，其原始的类型、消息和回溯信息都保持原样：
```python
try:
    value = int(text)
except ValueError:
    print("could not read the value")
    raise
```
改为编写 `raise ValueError(...)` 会构建一个新的异常并丢弃原始的回溯信息，而这恰恰是调试时最需要的信息。

```python
def load(text):
    try:
        return int(text)
    except ValueError:
        print(f"could not read {text}")
        raise
print(load("5"))
try:
    load("abc")
except ValueError:
    print("handled by the caller")
```
