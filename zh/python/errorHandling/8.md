# --description--

后面不跟类型的 `except:` 是**裸 except**。它会匹配一切，包括与你所保护的操作毫无关系的异常，因此规则很简单：总是指名你真正能从中恢复的类型。

# --instructions--

这段代码为什么应该指名一个具体的异常类型，而不是使用裸 `except:`？
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- 因为裸 `except:` 也会捕获无关的失败，比如由拼写错误的 `amout` 导致的 `NameError`，于是真正的 bug 悄悄变成了 `total = 0`
- 因为裸 `except:` 更慢，Python 必须把异常与每个内置类进行比较
- 因为裸 `except:` 只能在模块层级使用，在函数内部会引发 `SyntaxError`
- 因为裸 `except:` 什么也捕获不到，所以块一结束异常就会被再次引发
