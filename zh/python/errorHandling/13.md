# --description--

一些内置异常覆盖了大多数日常会遇到的失败：

| 异常 | 何时引发 | 示例 |
|---|---|---|
| `ValueError` | 类型正确但值不可能 | `int("abc")` |
| `TypeError` | 类型本身就是错误的 | `"x" + 1` |
| `ZeroDivisionError` | 除法或取模的除数为零 | `1 / 0` |
| `KeyError` | 字典中没有这样的键 | `{"a": 1}["b"]` |
| `IndexError` | 序列索引超出范围 | `[1, 2][5]` |

使用这些异常而不是发明新类型，能让任何懂 Python 的人都轻松读懂你的错误。

# --instructions--

编写一个函数 `get_item(values, index)`，它返回 `values[index]`；当 `index` 为负时，引发一个消息为 `"index must be positive"` 的 `ValueError`；当索引超出范围时，返回 `None`

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`get_item([1, 2, 3], 1)` 必须返回 `2`

```python
    def test_1(self):
        self.assertEqual(get_item([1, 2, 3], 1), 2, "--err-t1--")
```

`get_item([1, 2, 3], 9)` 必须返回 `None`

```python
    def test_2(self):
        self.assertIsNone(get_item([1, 2, 3], 9), "--err-t2--")
```

`get_item([1, 2, 3], -1)` 必须引发一个携带该消息的 `ValueError`

```python
    def test_3(self):
        with self.assertRaises(ValueError, msg="--err-t3--") as ctx:
            get_item([1, 2, 3], -1)
        self.assertEqual(str(ctx.exception), "index must be positive", "--err-t3--")
```

# --solutions--

```python
def get_item(values, index):
    if index < 0:
        raise ValueError("index must be positive")
    try:
        return values[index]
    except IndexError:
        return None
```
