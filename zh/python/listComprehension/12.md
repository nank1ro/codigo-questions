# --description--

内层 `for` 可以使用外层的变量。
这是把嵌套列表**展平**成单一列表的经典方法：
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
然后 `sum()` 函数会把列表中所有数字加起来。
