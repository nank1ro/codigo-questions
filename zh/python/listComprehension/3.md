# --description--

comprehension 也可以对元素进行**过滤**。
在 `for` 部分之后加上 `if` 条件：只有条件为 `True` 的元素才会进入新列表：
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
这和在循环内部加 `if` 效果相同，并且以更易读的方式取代了配合 lambda 使用的 `filter()`。
