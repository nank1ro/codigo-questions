# --description--

`if` 的两个位置很容易混淆，要把它们区分开:
```python
values = [n if n > 0 else 0 for n in nums]  # for 之前的 if-else: 选择一个值，必须有 else
positives = [n for n in nums if n > 0]      # for 之后的 if: 过滤，不允许 else
```
在过滤的 `if` 后面写 `else` 是语法错误。

# --instructions--

这段代码片段有什么__问题__？
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- `for` 之后的过滤 `if` 不能带有 `else`：`if-else` 必须放在 `for` 之前
- list comprehension 不能包含条件
- `nums` 包含一个负数，这是不允许的
- `else` 必须替换为 `elif`
