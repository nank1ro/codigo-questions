# --description--

同样的思路也适用于字典：**dict comprehension** 使用花括号和 `key: value` 表达式：
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
