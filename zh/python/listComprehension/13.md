# --description--

你也可以对**字典**进行循环。
通过 `.items()`，`for` 部分会把每一对键值解包到两个变量中，一个键和一个值：
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
