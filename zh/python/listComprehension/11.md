# --description--

一个 comprehension 可以有**不止一个 `for`**。
它们的工作方式就像嵌套循环：第一个 `for` 是外层循环，第二个是内层循环。
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
