# --description--

这两种条件可以在同一个 comprehension 中组合使用：用 `if-else` 选择值，再用末尾的 `if` 过滤跳过部分元素。
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```
