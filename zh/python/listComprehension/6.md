# --description--

comprehension 非常适合用来**转换字符串**。
对每个元素调用一个字符串方法，或者用 f-string 构建一个新字符串：
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
