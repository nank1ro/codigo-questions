# --description--

可迭代对象不一定要是列表：任何可以循环遍历的东西都可以，而 `range()` 是最受欢迎的一种。
它是构建数字列表最快的方式：
```python
squares = [n * n for n in range(4)]
print(squares)  # [0, 1, 4, 9]
```
记住 `range(start, stop)` 不包含 `stop`。
