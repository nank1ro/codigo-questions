# --description--

花括号**不带** `key: value` 部分，得到的就是 **set comprehension**。
set 是一种无序集合，只保留唯一值，因此重复项会自动消失：
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```
