# --description--

因为 `if value:` 已经应用了真值，所以用 `== True` 或 `== False` 比较是多余的，甚至可能出错：`2 == True` 是 `False`，但 `2` 却为真。直接检查值本身：
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

编写一个函数 `count_truthy(values)`，返回列表 `values` 中有多少个元素为真

# --solutions--

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
