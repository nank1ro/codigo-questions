# --description--

`and` 和 `or` 并不总是返回 `True` 或 `False`：它们返回其中一个**操作数**。`a and b` 在 `a` 为假时返回 `a`，否则返回 `b`；`a or b` 在 `a` 为真时返回 `a`，否则返回 `b`：
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
结果的真假与整个表达式的真假完全一致，这就是 `if a and b:` 仍然有效的原因。一个常见用法是提供默认值：`name = user_input or "guest"`。

# --instructions--

这段代码输出什么？
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`，因为 `or` 返回第一个为真的操作数，`and` 返回第一个为假的操作数，若都没有则返回最后一个操作数
- `True False True`，因为逻辑运算符总是产生布尔值
- `0 3 x`，因为 `and` 和 `or` 总是返回它们的第一个操作数
- `5 3 y`，因为两个运算符都返回为真的操作数
