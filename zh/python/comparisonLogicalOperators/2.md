# --description--

比较运算符不只用于数字。字符串按码位逐字符比较，所以 `"apple" < "banana"` 是 `True`；由于每个大写字母都排在小写字母之前，`"Zoo" < "apple"` 也是 `True`。列表和元组同样按元素逐个比较：
```python
print("cat" < "dog")       # True
print([1, 2, 3] < [1, 3])  # True
print((1, 2) == (1, 2))    # True
```
比较是一个表达式，所以函数可以直接写 `return a < b`，而不必把它包在 `if` 里。

# --asserts--

`comes_first("apple", "banana")` 必须返回 `True`

```python
    def test_1(self):
        self.assertIs(comes_first("apple", "banana"), True, "--err-t1--")
```

`comes_first("pear", "apple")` 和 `comes_first("kiwi", "kiwi")` 必须返回 `False`

```python
    def test_2(self):
        self.assertIs(comes_first("pear", "apple"), False, "--err-t2--")
        self.assertIs(comes_first("kiwi", "kiwi"), False, "--err-t2--")
```

大写字母排在小写字母之前，所以 `comes_first("Zoo", "apple")` 必须返回 `True`

```python
    def test_3(self):
        self.assertIs(comes_first("Zoo", "apple"), True, "--err-t3--")
```
