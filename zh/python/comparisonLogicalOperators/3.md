# --description--

比较可以**串联**：`1 < x < 10` 检查 `x` 大于 `1` **并且**小于 `10`，与 `1 < x and x < 10` 完全一样，但 `x` 只求值一次：
```python
x = 5
print(1 < x < 10)   # True
print(1 < x <= 5)   # True
print(10 < x < 20)  # False
```
任何比较运算符都可以串联，每个运算符作用于它两侧的相邻值：`a < b == c` 表示 `a < b and b == c`。把串联读作区间 `low < x < high` 是最常见的用法。
