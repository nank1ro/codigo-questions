# --description--

比较运算符比较两个值并返回一个**布尔值** `True` 或 `False`：`==` 等于，`!=` 不等于，`<` 小于，`>` 大于，`<=` 小于或等于，`>=` 大于或等于：
```python
age = 18
print(age == 18)  # True
print(age != 18)  # False
print(age < 18)   # False
print(age >= 18)  # True
```
结果可以存入变量，也可以直接输出。单个 `=` 是赋值，不是比较。
