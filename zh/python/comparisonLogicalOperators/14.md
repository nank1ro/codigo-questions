# --instructions--

这段代码输出什么？
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`，因为 `c` 是与 `a` 相同列表的另一个名字，所以通过 `c` 追加元素会改变 `a`，使它与 `b` 不同
- `True True [1, 2]`，因为 `c = a` 会复制列表，所以 `a` 保持不变
- `True False [1, 2, 3]`，因为 `is` 比较值而 `==` 比较身份
- `False False [1, 2, 3]`，因为 `append` 会创建一个新列表，所以 `c` 不再指向 `a`
