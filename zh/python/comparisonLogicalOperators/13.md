# --instructions--

编写一个函数 `is_vowel(ch)`，当 `ch` 恰好是一个字符且该字符是小写或大写的元音（`a`、`e`、`i`、`o`、`u`）时返回 `True`，对其他任何字符串返回 `False`，包括空字符串

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` 和 `is_vowel("E")` 必须返回 `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` 和 `is_vowel("y")` 必须返回 `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

不是单个字符的字符串必须返回 `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

# --solutions--

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
