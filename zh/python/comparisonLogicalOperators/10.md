# --description--

`==` 比较**值**；`is` 比较**身份**，也就是两个名字是否指向同一个对象。分别创建的两个相等列表满足 `==` 但不满足 `is`：
```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)  # True False True
```
`is` 适用于 `None`、`True` 和 `False` 这类单例：写 `value is None` 或 `value is not None`，绝不要写 `value == None`，因为类可以把 `==` 定义成返回任何东西。对数字或字符串使用 `is` 并不可靠，Python 会对此发出警告。

# --instructions--

编写一个函数 `is_missing(value)`，仅当 `value` 是 `None` 时返回 `True`，对其他任何值返回 `False`，包括 `0`、`""` 和 `[]` 这类为假的值

# --asserts--

`is_missing(None)` 必须返回 `True`

```python
    def test_1(self):
        self.assertIs(is_missing(None), True, "--err-t1--")
```

为假的值不是 `None`

```python
    def test_2(self):
        self.assertIs(is_missing(0), False, "--err-t2--")
        self.assertIs(is_missing(""), False, "--err-t2--")
        self.assertIs(is_missing([]), False, "--err-t2--")
        self.assertIs(is_missing(False), False, "--err-t2--")
```

一个 `==` 声称与任何东西都相等的对象仍然不是 `None`，所以检查必须使用身份比较

```python
    def test_3(self):
        class Anything:
            def __eq__(self, other):
                return True
        self.assertIs(is_missing(Anything()), False, "--err-t3--")
```
