# --description--

**集合推导式**（set comprehension）用一个表达式构建集合，语法和列表推导式相同，只是使用花括号：
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
一个可选的 `if` 用于过滤元素，表达式产生的重复项会被自动丢弃：
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```
