# --description--

两个集合的**交集**只包含**两者都有**的元素。
使用 `&` 运算符或 `intersection()` 方法：
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
如果两个集合没有共同元素，结果就是一个空集合。
