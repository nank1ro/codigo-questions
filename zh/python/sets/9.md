# --description--

**差集** `a - b` 包含 `a` 中**不**在 `b` 中的元素。
顺序很重要：`a - b` 和 `b - a` 通常是不同的：
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**对称差集** `a ^ b` 包含只属于两个集合中**恰好一个**的元素：
```python
print(a ^ b)  # {1, 4}
```
对应的方法形式是 `difference()` 和 `symmetric_difference()`。
