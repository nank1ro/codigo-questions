# --description--

创建**空集合**时有一个陷阱。
花括号也是字典的语法，所以 `{}` 创建的是一个空**字典**，而不是集合：
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
要得到一个空集合，必须不带任何参数地调用 `set()`：
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

这段代码会打印出什么？
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`，因为 `{}` 创建的是一个空字典
- `<class 'set'>`，因为花括号创建的是集合
- `<class 'NoneType'>`，因为集合没有元素
- 一个 `SyntaxError`，因为花括号必须至少包含一个元素
