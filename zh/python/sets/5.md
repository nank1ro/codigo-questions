# --description--

`pop()` 从集合中删除**一个任意元素**并返回它。
由于集合没有顺序，你无法选择删除哪个元素；对空集合调用 `pop()` 会抛出 `KeyError`：
```python
tickets = {101, 102, 103}
picked = tickets.pop()
print(len(tickets))  # 2
```
`clear()` 删除**所有**元素，留下一个空集合：
```python
tickets.clear()
print(len(tickets))  # 0
```
