# --description--

你可以像遍历列表一样，使用 `for` 遍历一个集合：
```python
for color in {"red", "blue"}:
    print(color)
```
由于集合是无序的，元素可能以**任意顺序**出现，而且这个顺序甚至可能在不同的运行之间发生变化。
当你需要一个可预测的顺序时，把集合传给 `sorted()`，它会返回其元素的一个有序**列表**：
```python
for color in sorted({"red", "blue"}):
    print(color)  # blue, then red
```
