# --description--

内置函数 `set()` 可以从任何集合（例如列表或字符串）构建一个集合。
由于集合只保留每个值一次，这是**去除重复项**的经典方法：
```python
nums = [1, 2, 2, 3]
unique = set(nums)
print(len(unique))  # 3
```
要检查某个值是否存在，可以使用 `in` 运算符，它会返回 `True` 或 `False`：
```python
print(2 in unique)  # True
print(9 in unique)  # False
```
即使有成千上万个元素，对集合进行成员检查也非常快。
