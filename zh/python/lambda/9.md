# --description--

`map()` 将一个函数应用到列表的**每一个元素**上。
它返回一个特殊的 _map 对象_，所以要用 `list()` 把它包起来才能看到值：
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
