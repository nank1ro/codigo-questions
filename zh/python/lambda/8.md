# --description--

用作 `key` 的 lambda 可以选取元素的任意部分。
对于列表的列表，`lambda p: p[1]` 会按每个内层列表的第二个元素排序。

# --instructions--

对元素排序，从最年轻到最年长打印出这些人

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
