# --description--

注意 lambda 的函数体没有 `return` 关键字。
函数体是一个**单一表达式**，它的值会被自动返回：
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

将一个接受参数 `n` 并返回 `n` 自身相乘结果的 lambda 存储到变量 `square` 中
