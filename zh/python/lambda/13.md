# --description--

`max()` 和 `min()` 也和 `sorted()` 一样接受 `key` 函数：
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

# --answers--

```python
names = ["bob", "Alice", "Charlie"]
```

```python
ordered = sorted(names, key=lambda s: s.lower())
```

```python

```

```python
print(ordered)
```
