# --description--

直接打印 `map` 对象并不会显示它的值，你会得到类似 `<map object at 0x7f2b1c>` 的结果。
只有用 `list()`（或循环）才能得到你期望的值。

# --instructions--

这段代码会打印出什么？
```python
nums = [1, 2, 3]
print(list(map(lambda x: x + 1, nums)))
```

# --answers--

- [2, 3, 4]
- [1, 2, 3]
- 2 3 4
- <map object>

# --solutions--
