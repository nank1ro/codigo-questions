# --description--

**什么时候应该优先使用 `def`？**
lambda 非常适合作为参数传递的简短一次性函数。
如果逻辑需要名字、需要多行、需要文档字符串，或者会在多处复用，那么 `def` 函数更清晰。
最后一个技巧：`sorted()` 也接受 `reverse=True`，可以先得到最大的值：
```python
print(sorted([3, 1, 2], reverse=True))  # [3, 2, 1]
```

```python
students = [
    {"name": "Ana", "grade": 88},
    {"name": "Bo", "grade": 72},
    {"name": "Cy", "grade": 95},
]
ranking = sorted(students, key=lambda s: s["grade"], reverse=True)
names = list(map(lambda s: s["name"], ranking))
```
