# --description--

有时你只需要一个只用一次的小函数，例如把一个数翻倍。
为此写一整个 `def` 代码块显得有些笨重。
Python 提供了一种更简短的形式：**lambda** 表达式，一个写在单行上的_匿名_函数：
```python
lambda x: x * 2
```
语法是 `lambda 参数: 表达式`。
lambda 没有名字，但你可以把它存储在变量中，像调用其他函数一样调用它：
```python
double = lambda x: x * 2
print(double(4))  # 8
```
