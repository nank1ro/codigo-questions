# --description--

由于函数体必须是单一表达式，lambda **不能包含语句**。
不能有 `return`、`if` 代码块、循环或赋值：
```python
# SyntaxError
increment = lambda x: return x + 1
```
如果你需要这些功能，请改用普通的 `def` 函数。

# --instructions--

这段代码片段有什么__问题__？
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- lambda 的函数体是一个表达式，不能包含 return
- lambda 不能存储在变量中
- lambda 不能用括号调用
- lambda 至少需要两个参数
