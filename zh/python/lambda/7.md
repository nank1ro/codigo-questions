# --description--

lambda 真正大放异彩的地方，是作为**传给其他函数的参数**。
`sorted()` 接受一个 `key` 参数：一个对每个元素调用的函数，其结果决定排序方式。
lambda 正是绝佳选择：
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```
