# --description--

当 `0` 或 `""` 必须保留、只有 `None` 需要替换时，回退就需要显式的 `is None` 检查。紧凑的形式是**条件表达式** `a if condition else b`：条件为真时其结果为 `a`，否则为 `b`：
```python
timeout = 0
seconds = timeout if timeout is not None else 30
print(seconds)  # 0, not 30
```
