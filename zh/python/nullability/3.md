# --description--

要检查一个变量是否为 `None`，请使用 `is` 和 `is not`，而不要用 `==`：
```python
if user is None:
    print("nobody logged in")
if user is not None:
    print("welcome")
```
`==` 问的是"这些值是否*相等*？"，任何类都可以通过定义 `__eq__` 方法以自己的方式回答这个问题。`is` 问的是"它们是否是*同一个对象*？"，这一点没有任何东西能改变。
由于 `None` 只有一个，`is None` 总是正确且稍快一些，而 `== None` 对带有自定义 `__eq__` 的对象可能给出令人意外的答案。

# --instructions--

这段代码会打印出什么？
```python
class Anything:
    def __eq__(self, other):
        return True

a = Anything()
print(a == None, a is None)
```

# --answers--

- `True False`，因为 `==` 调用自定义的 `__eq__`，而 `is` 检查的是同一性
- `False False`，因为无论哪种情况 `a` 都不是 `None`
- `True True`，因为 `__eq__` 同样控制着 `is` 的结果
- 一个 `TypeError`，因为对象不能与 `None` 进行比较
