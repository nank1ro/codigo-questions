# --description--

列表中可以在真实值旁边包含 `None`，例如读取失败的测量值或被跳过的回答。大多数操作不接受它：`sum([8, None])` 会引发 `TypeError`。
用条件为 `is not None` 的列表推导式把 `None` 值过滤掉：
```python
readings = [3, None, 5]
valid = [r for r in readings if r is not None]
print(valid)  # [3, 5]
```
如果改用 `if r`，也会把每个 `0` 丢弃，因此当零是有效读数时要写得明确。
