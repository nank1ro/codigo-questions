# --description--

查找之后再做 `None` 检查通常需要两行：一行保存结果，一行测试它。**赋值表达式**运算符 `:=`，昵称*海象运算符*，可以在表达式**内部**赋值，于是两个步骤都能放进 `if` 里：
```python
ages = {"Ada": 36}
if (age := ages.get("Ada")) is not None:
    print(age + 1)  # 37
```
圆括号是必需的：没有它们，`:=` 会试图对整个比较进行赋值。`if` 之后，`age` 仍然像其他变量一样可用。

# --instructions--

编写一个函数 `describe_user`，它接受一个把名字映射到年龄的字典 `users` 和一个 `name`；使用海象运算符保存 `get` 的结果，当名字存在时返回 `"<name> is <age>"`，否则返回 `"unknown user"`

# --solutions--

```python
def describe_user(users, name):
    if (age := users.get(name)) is not None:
        return f"{name} is {age}"
    return "unknown user"
```
