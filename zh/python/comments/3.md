# --description--

由于 Python 会完全丢弃注释，添加或删除注释永远不会改变程序的行为。只有**没有**被注释掉的代码才会运行。

这使得 `#` 成为在不删除代码的情况下快速禁用某行代码的方法。这称为**注释掉（commenting out）**：
```python
total = 10
# total = total + 5
print(total)  # 打印 10
```
现在第二行是注释，因此 `total` 保持为 `10`。删掉 `#` 就能让这一行重新生效。

在试验代码时注释掉很方便，但记得要清理：长期被注释掉的代码只会让下一个阅读它的人感到困惑。
