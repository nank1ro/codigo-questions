# --description--

Python 只在代码中寻找 `#`，绝不会在**字符串**内部寻找。在引号之间，`#` 只是一个普通字符：
```python
print("black is #000000")  # a hex colour
```
第一个 `#` 是文本的一部分，第二个 `#` 才开启一条真正的注释。`#` 注释内部的 `"""` 也是同样道理：它只是三个引号字符，不会开启任何东西。

# --instructions--

编写一个函数 `label(name)`，返回在 `name` 前面加上 `#` 的结果，因此 `label("python")` 返回 `"#python"`。

```python
    def test_1(self):
        self.assertEqual(label("python"), "#python", "--err-t1--")
```

`label("ai")` 必须返回 `"#ai"`。

```python
    def test_2(self):
        self.assertEqual(label("ai"), "#ai", "--err-t2--")
```

`label("")` 必须返回 `"#"`。

```python
    def test_3(self):
        self.assertEqual(label(""), "#", "--err-t3--")
```
