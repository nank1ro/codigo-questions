# --description--

把说明函数用途的注释放在函数上方是错误的位置。docstring 才是合适的地方：它依附于函数，`help()` 能找到它，编辑器也能显示它，而 `def` 上方的 `#` 注释对它们全都不可见。

```python
# 将 a 和 b 相加
def add(a, b):
    return a + b
```
把同一句话向下移动一行，放到三重引号之间，它就变成了真正的文档：
```python
def add(a, b):
    """Returns the sum of a and b."""
    return a + b
```
