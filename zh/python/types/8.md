# --description--

`bool` 是 `int` 的**子类**：在需要数字的地方，`True` 表现得像 `1`，`False` 像 `0`：
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` 把列表中的项相加，所以对布尔值列表求和就是**统计**其中有多少个 `True`：
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
由于这层子类关系，`isinstance(True, int)` 返回 `True`，而 `type(True)` 仍然是 `bool`。
