# --description--

每个值都可以被解释为布尔值。`bool()` 把一个值转换成 `True` 或 `False`，当值直接用在 `if` 中时也适用同样的规则。
被当作**假**的值是那些"空"的值：
- 数字 `0`（以及 `0.0`）
- 空字符串 `""`
- 空集合，例如 `[]`、`{}`、`()` 和 `set()`
- `None`

任何非空的值都是**真**的，包括负数以及只是看起来像空的字符串，例如 `"0"` 或 `" "`：
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
这就是为什么 `if name:` 是检查字符串非空的常见写法。

# --instructions--

这段代码会打印什么？
```python
print(bool(0), bool("0"), bool([]), bool(None))
```

# --answers--

- `False True False False`，因为 `"0"` 是非空字符串
- `False False False False`，因为它们都表示零或什么都没有
- `True True False False`，因为数字总是真的
- `TypeError`，因为 `None` 不能转换成布尔值
