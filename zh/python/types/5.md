# --description--

值不会自己改变类型：要把一个值变成另一种类型，你要像调用函数那样调用类型名。这称为**转换**（或*强制类型转换*）：
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` 和 `float()` 读取以文本形式书写的数字，用户输入或文件里得到的正是这种形式。`str()` 把任何东西变成文本，因此可以用 `+` 与其他字符串拼接。
注意 `int(3.9)` 不会四舍五入：它直接丢弃小数部分。
