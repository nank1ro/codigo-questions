# --description--

来自外部的文本总是 `str`，弄清楚它实际承载的是哪种类型是你的程序的任务。
一种常见做法是先尝试**最严格的**转换，当它抛出 `ValueError` 时再退回到下一种：
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
在 `except` 块中再嵌套一个 `try`，可以让你再退回一次，例如保持文本原样。

def parse_value(text):
