# --description--

打印一个 `float` 会显示精确表示它所需的全部位数，这往往太多了：
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
在 f-string 中，你可以在冒号后添加**格式说明**。`.2f` 表示"保留 2 位小数的定点数"：
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
数值会被四舍五入到所要求的小数位数，必要时补零：`f"{2.5:.2f}"` 得到 `2.50`。
