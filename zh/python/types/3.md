# --description--

Python 是**动态类型**的：类型属于**值**，而不属于变量。
变量只是附加在值上的一个名字，你随时可以把它附加到另一种类型的值上：
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
不需要声明，也不需要转换：旧的值直接被遗忘。
这很方便，但也意味着变量的类型只有在程序运行时才知道，所以不小心混用类型会在运行时才表现为错误，而不是更早。

# --instructions--

这段代码会打印什么？
```python
x = 10
x = "ten"
print(type(x))
```

# --answers--

- `<class 'str'>`，因为 `x` 现在指向一个字符串
- `<class 'int'>`，因为 `x` 的类型由第一次赋值固定了
- `TypeError`，因为字符串不能赋给整数变量
- `<class 'int'> <class 'str'>`，因为 `x` 保留了两个值
