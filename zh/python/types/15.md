# --description--

转换可以组合使用。`int("3.7")` 会失败，但 `float("3.7")` 可以，而对一个 `float` 使用 `int()` 会丢弃小数部分：
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` 遵循真值规则：`bool("")` 是 `False`，注意 `bool("False")` 是 `True`，因为它是一个非空字符串。
