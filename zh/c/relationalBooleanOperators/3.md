# --description--

C 中最常见的错误是把 `==` 写成了 `=`。单个 `=` 是**赋值**，而在 C 中赋值是一个表达式，其值就是被赋的值：
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
使用 `=` 的代码仍然能编译，所以写成 `if (x = 0)` 的条件会悄悄把 `x` 设为 `0`，而不是判断它。大多数编译器会为此输出警告：请阅读它。
