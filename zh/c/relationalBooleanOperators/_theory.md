**关系运算符**比较两个值。结果不是特殊类型：它是一个 `int`，比较成立时为 `1`，不成立时为 `0`。C 有六个关系运算符：
```c
printf("%d\n", 5 == 5); // equal: prints "1"
printf("%d\n", 5 != 5); // not equal: prints "0"
printf("%d\n", 3 < 5);  // less than: prints "1"
printf("%d\n", 3 > 5);  // greater than: prints "0"
printf("%d\n", 5 <= 5); // less than or equal: prints "1"
printf("%d\n", 4 >= 5); // greater than or equal: prints "0"
```
因为结果是 `int`，所以用 `%d` 输出，并且可以像其他数字一样存入 `int` 变量。

---

函数可以直接返回一个比较结果：调用者会得到 `1` 或 `0`。
```c
int is_big(int n) {
    return n > 100;
}

printf("%d\n", is_big(250)); // prints "1"
```
在 `>` 和 `>=`（或 `<` 和 `<=`）之间的选择决定了边界值是否算在内：对于 `100`，`n >= 100` 为 `1`，而 `n > 100` 为 `0`。

---

C 中最常见的错误是把 `==` 写成了 `=`。单个 `=` 是**赋值**，而在 C 中赋值是一个表达式，其值就是被赋的值：
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
使用 `=` 的代码仍然能编译，所以写成 `if (x = 0)` 的条件会悄悄把 `x` 设为 `0`，而不是判断它。大多数编译器会为此输出警告：请阅读它。

---

**逻辑运算符**用于组合条件。**与**运算符 `&&` 只有在两边都为真时才得到 `1`，**或**运算符 `||` 在至少一边为真时得到 `1`：
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
在 C 中**任何非零值都算作真**，只有 `0` 算作假，所以 `5 && 1` 为 `1`，`0 || -3` 也为 `1`。`&&` 和 `||` 的结果总是恰好为 `1` 或 `0`。

---

保存 `0` 或非零值的变量可以单独用作条件：单独写 `holiday` 就表示“holiday 非零”，不需要写 `holiday != 0`。
```c
int is_open(int weekday, int holiday) {
    return weekday && !holiday;
}
```
**非**运算符 `!` 会翻转条件：`!0` 为 `1`，任何非零值的 `!` 为 `0`。

---

因为 `!` 把任何非零值变成 `0`，把 `0` 变成 `1`，所以连用两次会把一个值规范化为恰好 `0` 或 `1`：`!!42` 为 `1`，`!!0` 为 `0`。
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
当函数返回任意非零数字而你想要一个干净的 `1` 时，这很有用。

---

从 C99 开始，头文件 `stdbool.h` 提供了类型 `bool` 以及常量 `true`（值为 `1`）和 `false`（值为 `0`）：
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
`bool` 底层仍然是整数：它用 `%d` 输出，并且和比较结果一样可以配合 `&&`、`||` 和 `!` 使用。它只是比普通的 `int` 更清楚地表达意图。

---

回答“是/否”问题的函数应该返回 `bool`。`bool` 参数本身就是一个条件，因此直接把它用作 `&&` 或 `||` 的操作数：写 `age >= 18 && citizen`，而不是 `citizen == true`。
```c
bool can_enter(int age, bool member) {
    return age >= 16 && member;
}
```
在这些练习中，`stdbool.h` 已经在你的代码上方包含好了。

---

`&&` 和 `||` 使用**短路求值**：一旦结果确定就停止求值。
- 对于 `&&`，如果左边为 `0`，右边永远不会被求值
- 对于 `||`，如果左边非零，右边永远不会被求值

这样左边的检查就能保护右边的危险操作：
```c
int ok = count != 0 && total / count > 2;
```
当 `count` 为 `0` 时，除法永远不会执行，所以程序不会崩溃。

---

短路求值同样会跳过函数调用。在 `1 || check()` 中函数 `check` 永远不会被调用，所以它的任何副作用（比如更新计数器）都不会发生。
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
当 `&&` 或 `||` 右边的函数做了你依赖的事情时，请记住这一点。

---

运算符有**优先级**，它决定先计算什么：
1. 先应用 `!`
2. 然后是关系比较 `<`、`>`、`<=`、`>=`
3. 然后是相等比较 `==`、`!=`
4. 然后是 `&&`
5. 然后是 `||`

所以 `a > 0 && a < 10` 不需要括号，而 `a && b || c` 表示 `(a && b) || c`，因为 `&&` 比 `||` 结合得更紧。使用括号可以强制不同的分组，或者只是为了让意图更易读。

---

`char` 是一个小整数，所以字符也用同样的运算符比较。要和单引号中的字符字面量比较：双引号的 `"a"` 是字符串，不能这样比较。
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // prints "1"
```
像 `'0'`、`'1'`、... `'9'` 或 `'a'`、`'b'`、... `'z'` 这样的连续字符具有连续的编码，所以对字符做范围检查和对数字做范围检查完全一样：
```c
bool is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

不要像数学里那样连写比较。`1 <= x <= 10` 能编译，但它被解释为 `(1 <= x) <= 10`：第一个比较得到 `0` 或 `1`，然后再和 `10` 比较，所以整个表达式永远为 `1`。
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
始终把两个比较都明确写出来，并用 `&&` 连接。

---

当一个条件同时混用 `&&` 和 `||` 时，即使优先级已经能得到正确结果，也要用括号把每一部分分组：这样规则一眼就能读懂。
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
求余运算符 `%` 天然和 `==` 搭配：当 `n` 能被 `4` 整除时，`n % 4 == 0` 为 `1`。
