# --description--

运算符有**优先级**，它决定先计算什么：
1. 先应用 `!`
2. 然后是关系比较 `<`、`>`、`<=`、`>=`
3. 然后是相等比较 `==`、`!=`
4. 然后是 `&&`
5. 然后是 `||`

所以 `a > 0 && a < 10` 不需要括号，而 `a && b || c` 表示 `(a && b) || c`，因为 `&&` 比 `||` 结合得更紧。使用括号可以强制不同的分组，或者只是为了让意图更易读。

# --instructions--
