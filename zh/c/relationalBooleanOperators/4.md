# --description--

**逻辑运算符**用于组合条件。**与**运算符 `&&` 只有在两边都为真时才得到 `1`，**或**运算符 `||` 在至少一边为真时得到 `1`：
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
在 C 中**任何非零值都算作真**，只有 `0` 算作假，所以 `5 && 1` 为 `1`，`0 || -3` 也为 `1`。`&&` 和 `||` 的结果总是恰好为 `1` 或 `0`。
