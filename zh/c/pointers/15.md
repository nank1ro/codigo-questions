# --description--

指针本身也是变量，因此它也有自己的地址，这个地址可以存储在**指向指针的指针**（pointer to pointer）中，声明时要用两颗星号：
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp` 是 `p`，即 `x` 的地址；`**pp` 连走两步到达 `7`。指向指针的指针让函数能够改变指针所持有的地址：函数接收 `&p` 并对 `*pp` 赋值。
