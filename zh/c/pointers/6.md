# --description--

指向 `char` 的指针和其他任何指针一样：它持有一个字符的地址，`*p` 可以读写该字符：
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
通过指针读和写可以随意混用：`*p = *p + 1` 会把 `'A'` 变成 `'B'`。
