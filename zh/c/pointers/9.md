# --description--

由于 `p + 1` 是下一个元素，`p++` 会把指针就地移动到下一个元素。循环可以让指针不断前进，从而代替索引来遍历数组：
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
每一轮先打印 `p` 所指向的元素，然后把 `p` 向前移动一个元素。

# --instructions--

对代码行排序，把 `1`、`2` 和 `3` 存入 `values`，让 `p` 指向它的第一个元素，并通过推进指针打印每个元素
