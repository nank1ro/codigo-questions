# --description--

**NOT**（按位取反）运算符 `~` 只接受一个操作数，并把它的每一个位都翻转：每个 `0` 变成 `1`，每个 `1` 变成 `0`。
一个 `unsigned int` 持有 32 个位，所以 `~0x0Fu` 会翻转全部 32 个位，得到一个非常大的数。要只保留你关心的那个字节，可以把 `~` 和 `& 0xFF` 结合使用：
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// prints "240"
```
`~` 的优先级比 `&` 高，所以它先被应用。
不要把 `~` 和逻辑 `!` 混淆：`!` 看的是整个值并给出 `0` 或 `1`，而 `~` 改写每一个位。
