# --description--

要**翻转**单个位，也就是不管它当前状态如何都把它翻转，用掩码对值做 XOR（异或）运算：
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// 打印 "7"
```
由于 XOR 会自我抵消，第二次翻转同一个位会得到原来的值。
