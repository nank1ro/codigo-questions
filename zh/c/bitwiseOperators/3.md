# --description--

**XOR**（按位异或，exclusive or）运算符 `^` 只在两个位*不同*的地方保留 `1`：
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
由此可得一个有用的性质：对同一个值应用两次 XOR 会得到原来的值。
