# --description--

位从最右边那位开始从 `0` 编号，所以 `1u << n` 是一个只打开第 `n` 位的掩码。
要**置位**单个位，也就是在不碰其他位的情况下把它打开，用该掩码对值做 OR（或）运算：
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// 打印 "6"
```
如果该位本来就开着，值不会改变，这使得置位操作可以安全地重复。
