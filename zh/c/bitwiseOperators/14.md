# --description--

在 C23 之前，没有能把数字打印成二进制的格式说明符，`0b1010` 这样的字面量也不是标准 C 的写法。要显示这些位，你需要自己写循环：从最高位一直遍历到第 `0` 位，每次打印 `(value >> i) & 1u`。
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// 打印 "0101"
```
把值右移 `i` 位，会把第 `i` 位移到最右端，这时 `& 1u` 就能把它单独取出来。
