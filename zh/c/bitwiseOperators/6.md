# --description--

**右移**运算符 `>>` 把每一个位向右移动；从右端移出的位会被丢弃。对无符号值来说，左侧腾出的位置用零填充：
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// 打印 "3"
```
右移 `n` 位相当于把无符号值除以 2 的 `n` 次方，并丢弃余数。
对*负*值做右移是不可移植的，这是把位运算保持在 `unsigned` 类型上的又一个理由。
