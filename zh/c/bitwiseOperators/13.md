# --description--

**标志**是带名字的掩码，每个标志各占不同的一位，可以全部保存在同一个变量里。它们用 `|` 组合，用 `&` 读取回来：
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// 打印 "1"
```
因此，一个 `unsigned int` 就能携带 32 个独立的是/否答案。
