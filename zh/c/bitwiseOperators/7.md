# --description--

每个二元位运算符都有一个**复合赋值**形式，可以原地更新变量：`&=`、`|=`、`^=`、`<<=` 和 `>>=`。
```c
unsigned int x = 12;
x &= 10;  // same as x = x & 10;
x |= 1;   // same as x = x | 1;
x ^= 3;   // same as x = x ^ 3;
x <<= 1;  // same as x = x << 1;
x >>= 2;  // same as x = x >> 2;
```
它们比重复写变量名更易读，也是修改标志变量各位的常用方式。
