# --description--

结构体可以像任何其他类型一样存入数组。每个元素用它自己的一对大括号初始化，循环逐个访问它们，先做索引，再使用点：
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

int sum = 0;
