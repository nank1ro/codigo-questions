# --description--

每次都写 `struct Point` 很啰嗦。使用 `typedef` 可以给结构体起一个简短的类型名，结构体本身则可以保持匿名：
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
新名字 `Temperature` 可以单独使用，前面不需要 `struct` 关键字。这是实际程序中声明结构体最常见的方式。
