# --description--

按顺序初始化成员很脆弱：一旦结构体增加了一个成员，所有的初始化值都会错位。从 C99 开始，**指定初始化器**（designated initialiser）用点为每个成员命名，顺序可以任意：
```c
struct Point p = {.y = 4, .x = 3};
```
没有列出的成员会被设为 `0`，因此 `{.y = 5}` 使 `x` 等于 `0`。这与声明时不带任何初始化器的变量 `struct Point q;` 不同，后者的成员在被赋值之前保存的是**垃圾值**：
```c
struct Point q;
q.x = 1;
q.y = 2;
```
