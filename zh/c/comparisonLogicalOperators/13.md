# --description--

C 语言中一个经典的错误是把本该写成 `==` 的地方写成了 `=`。代码依然能编译通过，因为赋值是一个表达式，其值就是被赋的值：
```c
int x = 5;
if (x = 0) { ... } // 将 0 赋给 x，条件为 0（假）
if (x = 3) { ... } // 将 3 赋给 x，条件为 3（真）
```
大多数编译器会对此发出警告，所以当条件表现异常时，请留意这些警告。
