# --description--

短路求值同样会跳过函数调用：在 `0 && check()` 中，函数 `check` 永远不会被调用，因此它的任何副作用（比如更新计数器）都不会发生。

# --solutions--

```c
#include <stdio.h>
int calls = 0;
int check() {
    calls++;
    return 1;
}
int main() {
    int result = 0 && check();
    printf("%d %d\n", result, calls);
    return 0;
}
```
