**比较运算符**比较两个值并给出结果：比较成立时为 `1`，不成立时为 `0`。
**等于**运算符 `==` 检查两个值是否相同，**不等于**运算符 `!=` 检查它们是否不同：
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// 输出 "0"
printf("%d\n", a != b);
// 输出 "1"
```
注意：`==`（两个等号）用于比较，而单个 `=` 用于赋值。

---

其他比较运算符用于检查两个值的大小关系：
- `<` 小于，`>` 大于
- `<=` 小于等于，`>=` 大于等于
```c
printf("%d\n", 3 < 5);  // 输出 "1"
printf("%d\n", 5 >= 6); // 输出 "0"
```
函数可以直接返回比较结果，因为其结果就是普通的 `int`：
```c
int is_big(int n) {
    return n > 100;
}
```

---

在 C 中，比较的结果不是一种特殊类型：它是一个 `int`，其值恰好是 `1`（真）或 `0`（假）。
这意味着你可以像存储其他数字一样把它存入一个 `int` 变量：
```c
int n = 42;
int big = n > 100; // big 为 0
```
输出中不会出现 `true`/`false` 这样的词：`printf("%d", 2 == 2)` 打印的是 `1`。

---

**逻辑运算符**用于组合比较。**与**运算符 `&&` 只有在两边都为真时才给出 `1`：
```c
int age = 25;
printf("%d\n", age >= 18 && age < 65); // 输出 "1"
```
不要像数学那样连写比较：`1 <= x <= 10` 会被求值为 `(1 <= x) <= 10`，也就是把 `0` 或 `1` 与 `10` 比较，结果永远为真。
请始终把两个比较分别写出，再用 `&&` 连接。

---

**或**运算符 `||` 只要有一边为真就给出 `1`，只有当两边都为假时才给出 `0`：
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // 输出 "1"
```
每一边都必须是完整的比较：`day == 6 || 7` 并不表示“6 或 7”（后面你会明白原因）。

---

**非**运算符 `!` 会反转结果：`!1` 是 `0`，`!0` 是 `1`。
它写在表达式前面，所以要对整个比较取反，需要使用括号：
```c
int n = 5;
printf("%d\n", !(n > 3)); // 输出 "0"
```
如果不加括号，`!n > 3` 会先计算 `!n`，再把结果与 `3` 比较。

---

逻辑运算符不仅适用于 `0` 和 `1`：在 C 中，**任何非零值都视为真**，只有 `0` 视为假。
所以 `5 && 1` 是 `1`，`0 || -3` 是 `1`，`!` 会把任何非零值变成 `0`：
```c
printf("%d\n", !7); // 输出 "0"
printf("%d\n", !0); // 输出 "1"
```
这就是为什么 `day == 6 || 7` 永远为真：单独的 `7` 本身就是一个真值。

---

`&&` 和 `||` 使用**短路求值**：一旦结果已经确定，它们就会立即停止求值。
- 对于 `&&`，如果左边是 `0`，右边永远不会被求值
- 对于 `||`，如果左边为真，右边永远不会被求值

这让你可以把检查放在危险操作的左边来保护它：
```c
int safe = divisor != 0 && value / divisor > 2;
```
当 `divisor` 为 `0` 时，除法永远不会执行。

---

短路求值同样会跳过函数调用：在 `0 && check()` 中，函数 `check` 永远不会被调用，因此它的任何副作用（比如更新计数器）都不会发生。

---

运算符具有**优先级**，决定先计算哪一部分：
1. `!` 最先应用
2. 然后是关系比较 `<`、`>`、`<=`、`>=`
3. 然后是相等性比较 `==`、`!=`
4. 然后是 `&&`
5. 然后是 `||`

所以 `a > 0 && a < 10` 不需要括号：两个比较都会在 `&&` 之前计算。
而 `x == 1 || y == 2 && z == 3` 的意思是 `x == 1 || (y == 2 && z == 3)`，因为 `&&` 的优先级比 `||` 高。

---

`char` 本质上是一个小整数，所以字符可以用同样的运算符进行比较。
使用单引号中的字符字面量进行比较：
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // 输出 "1"
```
双引号会创建一个字符串，不能用这种方式比较。

---

由于字符本质上是数字，`<` 和 `>` 比较的是它们的编码，而像 `'a'`、`'b'`、`'c'` 或 `'0'`、`'1'`、`'2'` 这样的连续字符具有连续的编码。
因此对字符的范围检查和对数字的范围检查完全一样：
```c
int is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

C 语言中一个经典的错误是把本该写成 `==` 的地方写成了 `=`。代码依然能编译通过，因为赋值是一个表达式，其值就是被赋的值：
```c
int x = 5;
if (x = 0) { ... } // 将 0 赋给 x，条件为 0（假）
if (x = 3) { ... } // 将 3 赋给 x，条件为 3（真）
```
大多数编译器会对此发出警告，所以当条件表现异常时，请留意这些警告。

---

`if` 的条件其实就是一个表达式，只要它非零就被视为真，所以比较和逻辑运算符可以很自然地用在这里：
```c
if (n < 0) {
    printf("negative\n");
} else if (n == 0) {
    printf("zero\n");
}
```
你也可以先把结果存起来，再对变量进行判断：`int ok = n > 0; if (ok) { ... }`。

---

`while` 循环会持续运行，只要它的条件非零，因此由比较来决定循环何时停止：
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 输出 0, 1, 2
```
在 `<` 和 `<=` 之间的选择决定了是否包含最后一个值。

---

从 C99 开始，头文件 `stdbool.h` 提供了 `bool` 类型以及常量 `true`（`1`）和 `false`（`0`）：
```c
#include <stdbool.h>

bool ready = true;
bool done = count == 10;
```
`bool` 底层仍然是一个整数：用 `%d` 打印它会显示 `1` 或 `0`，并且它可以像任何比较结果一样用于 `&&`、`||` 和 `!`。
使用 `bool` 能让函数的意图比返回普通的 `int` 更清晰。

---

`bool` 类型的参数可以直接作为 `&&` 或 `||` 的操作数使用，无需将其与 `true` 比较：应写作 `age >= 18 && citizen`，而不是 `citizen == true`。

---

当一个条件同时混用 `&&` 和 `||` 时，即使运算符优先级本身已经能得到正确结果，也要给每一组加上括号：这能让规则一眼就看得明白。
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
