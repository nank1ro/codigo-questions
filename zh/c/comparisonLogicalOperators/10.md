# --description--

运算符具有**优先级**，决定先计算哪一部分：
1. `!` 最先应用
2. 然后是关系比较 `<`、`>`、`<=`、`>=`
3. 然后是相等性比较 `==`、`!=`
4. 然后是 `&&`
5. 然后是 `||`

所以 `a > 0 && a < 10` 不需要括号：两个比较都会在 `&&` 之前计算。
而 `x == 1 || y == 2 && z == 3` 的意思是 `x == 1 || (y == 2 && z == 3)`，因为 `&&` 的优先级比 `||` 高。
