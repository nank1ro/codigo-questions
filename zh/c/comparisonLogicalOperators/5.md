# --description--

**或**运算符 `||` 只要有一边为真就给出 `1`，只有当两边都为假时才给出 `0`：
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // 输出 "1"
```
每一边都必须是完整的比较：`day == 6 || 7` 并不表示“6 或 7”（后面你会明白原因）。
