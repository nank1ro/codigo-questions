# --description--

把布尔变量当作条件来读取，效果和字面量一样：既然 `online` 保存的是 `true`，代码块就会执行，其中的 `printf` 也会运行。

# --instructions--

这段代码在输出中显示什么？
```c
bool online = true;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- 什么都不显示，代码被跳过了
