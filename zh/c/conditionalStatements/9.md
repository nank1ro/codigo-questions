# --description--

C 语言没有独立的布尔判断：只要一个值不是零，条件就为真。`<stdbool.h>` 中的 `false` 其实就是 `0`，所以由它守护的代码块永远不会执行。

# --instructions--

填写空白处以使代码块**不**被执行
