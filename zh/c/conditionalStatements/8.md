# --description--

C 语言的布尔字面量是 `true` 和 `false`：小写、不加引号，并且是由 `<stdbool.h>` 定义的，而不是语言内置的。把 `True` 写成条件是无法编译的——只有小写形式才有效，当它为 `true` 时代码块才会执行。
