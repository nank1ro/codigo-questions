# --description--

如果 `online` 保存的是 `false`，条件就为假，代码块会被完全跳过，花括号内的内容都不会被打印。

# --instructions--

这段代码在输出中显示什么？
```c
bool online = false;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- 什么都不显示，代码被跳过了
