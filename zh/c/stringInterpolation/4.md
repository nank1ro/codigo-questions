# --description--

`%x` 用小写字母以十六进制打印整数，`%X` 则用大写字母做同样的事。`%c` 接收一个整数字符码并打印它所代表的字符，因此 `%c` 配上 `65` 会打印 `A`：
```c
printf("%x %X %c\n", 31, 31, 66); // prints "1f 1F B"
```

# --instructions--

以下代码的输出是什么？
```c
printf("%x %X %c\n", 255, 255, 65);
```

# --answers--

- ff FF A
- 255 255 65
- ff ff A
- FF FF 65
