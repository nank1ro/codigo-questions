# --description--

字符串也可以分几步构建，把每一部分紧接着上一部分写入。返回值告诉你文本在哪里结束，因此 `buffer + n` 就是终止符的地址，下一个 `sprintf` 可以从那里继续：
```c
char buffer[32];
int n = sprintf(buffer, "%s", "Hello");
n += sprintf(buffer + n, ", %s", "world"); // buffer is "Hello, world", n is 12
```
把每个返回值累加到 `n` 上，`n` 就始终等于目前已构建文本的总长度。
