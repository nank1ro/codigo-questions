# --description--

当没有什么需要格式化时，`puts` 会打印一个字符串并跟上换行。与 `printf` 不同，它不解释 `%`，因此文本会完全按写法原样打印：
```c
puts("Done");      // 打印 "Done" 和一个换行符
puts("50% off");   // 打印 "50% off" 和一个换行符
printf("50% off"); // 未定义：% off 不是有效的说明符
```
固定文本用 `puts` 最合适，而需要插入值时则用 `printf`。
