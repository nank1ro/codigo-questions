# --description--

字符串也可以不用格式字符串来拼接。`string.h` 中的 `strcat` 会把第二个参数的副本追加到第一个参数的末尾，第一个参数必须有足够的空闲空间；而 `strncat` 最多追加指定数量的字符：
```c
char text[32] = "Hi";
strcat(text, "!!!");        // text is "Hi!!!"
strncat(text, "abcdef", 2); // text is "Hi!!!ab"
```
两者都总会在追加的字符之后加上终止符 `'\0'`。
