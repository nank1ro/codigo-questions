# --description--

一个点后跟一个数字设置**精度**。对 `%f` 来说它是小数位数，会四舍五入；对 `%s` 来说它是最多打印的字符数：
```c
printf("%.2f\n", 3.14159);    // prints "3.14"
printf("%.3s\n", "formatting"); // prints "for"
```
宽度和精度可以组合：`%8.2f` 会在 8 列中右对齐打印两位小数。
