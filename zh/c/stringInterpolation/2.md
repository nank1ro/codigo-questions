# --description--

`sprintf` 的用法和 `printf` 完全一样，但它不是写到屏幕上，而是把格式化后的文本写入一个 `char` 数组，称为**缓冲区**，并在末尾加上终止符 `'\0'`：
```c
char buffer[32];
sprintf(buffer, "%d-%d", 3, 7);
printf("%s\n", buffer); // prints "3-7"
```
缓冲区必须在调用之前声明，并且要足够大以容纳整段文本加上终止符，否则 `sprintf` 会越过它的末尾继续写。
