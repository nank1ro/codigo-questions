C 是一门**静态类型**语言：每个变量在声明时都要指定一个类型，这个类型决定了它能存储什么以及占用多少内存。
你最常用到的三种类型是：
- `int` 用于整数，例如 `30` 或 `-4`
- `double` 用于带小数部分的数字，例如 `1.75`
- `char` 用于单个字符，用单引号书写，例如 `'A'`

每种类型都有自己的 `printf` **格式说明符**：`%d` 打印 `int`，`%f` 打印 `double`（默认显示六位小数），`%c` 打印 `char`：
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// prints "30 1.750000 A"
```
对某个类型使用错误的说明符会打印出乱码，所以要始终匹配正确。

---

C 有两种浮点类型：`float`（单精度，约 7 位有效数字）和 `double`（双精度，约 15 位有效数字）。
像 `1.75` 这样的小数字面量默认是 `double`；要写一个 `float` 字面量，需要加上后缀 `f`，例如 `1.75f`。
除非内存紧张，否则优先使用 `double`：它是默认类型，并且精度更高。
```c
double pi = 3.14159;
float ratio = 0.5f;
```
返回小数结果的函数应将 `double` 声明为返回类型，并且 `double` 类型的参数既能接受整数也能接受小数实参：
```c
double half(double x) {
    return x / 2;
}
```

---

`%f` 会打印六位小数，但这很少是你想要的。在 `%` 和 `f` 之间加上精度，就可以选择显示多少位小数：`%.2f` 打印两位小数，`%.1f` 打印一位，并且数值会被**四舍五入**，而不是被截断：
```c
double price = 9.987;
printf("%.2f\n", price); // prints "9.99"
printf("%.1f\n", price); // prints "10.0"
```
`float` 使用和 `double` 相同的说明符打印：传给 `printf` 时它会自动转换为 `double`。

---

`/` 的结果取决于其操作数的类型。
当**两个**操作数都是整数时，结果也是整数，小数部分会被舍弃：`7 / 2` 是 `3`，而不是 `3.5`。
当**至少一个**操作数是浮点值时，除法会保留小数部分：`7 / 2.0` 是 `3.5`。
```c
printf("%d\n", 7 / 2);     // prints "3"
printf("%f\n", 7 / 2.0);   // prints "3.500000"
```
把字面量写成 `2.0` 而不是 `2`，是强制进行浮点除法最简单的方法。

---

当一个值被赋给不同类型的变量时，C 会**隐式**在数值类型之间进行转换。
- 存入 `double` 的 `int` 会被无损地扩展：`double d = 3;` 会让 `d` 等于 `3.0`
- 存入 `int` 的 `double` 会被**截断**：`int n = 3.99;` 会让 `n` 等于 `3`（编译器通常会对此发出警告）

转换只发生在赋值的那一刻。右边的表达式会先按照自己的类型计算：
```c
double d = 7 / 2;
```
这里 `7 / 2` 是整数除法，结果为 `3`，之后 `3` 才会被转换为 `3.0`。

---

当隐式转换不是你想要的效果，或者你想让转换变得明显时，可以使用**显式类型转换**：在值前面用括号写出目标类型。
```c
double x = 3.99;
int n = (int) x;   // n is 3
```
将浮点值转换为 `int` 会**向零截断**：`(int) 3.99` 是 `3`，`(int) -2.5` 是 `-2`，不会发生四舍五入。
类型转换只作用于紧跟其后的值，所以 `(int) x * 2` 会先转换 `x`，然后再做乘法。

---

要从两个 `int` 变量得到浮点除法结果，标准做法是在做除法之前把**其中一个操作数**转换为 `double`。
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
把整个结果转换为 `double`，例如 `(double) (total / count)`，是一个常见错误：整数除法已经发生，小数部分已经丢失。

---

`char` 本质上是一个小整数：它存储字符的 **ASCII 码**。
`'A'` 是 `65`，`'a'` 是 `97`，`'0'` 是 `48`，并且连续的字符具有连续的编码。
这就是为什么可以对字符进行算术运算：
- `'a' + 1` 是 `98`，也就是 `'b'` 的编码
- `'7' - '0'` 是 `55 - 48`，也就是数字 `7`

同一个值既可以用 `%c` 作为字符打印，也可以用 `%d` 作为数字打印：
```c
char c = 'A';
printf("%c %d\n", c, c); // prints "A 65"
```

---

在 ASCII 表中，大写字母和小写字母相差 `32` 个位置：`'A'` 是 `65`，`'a'` 是 `97`。
因此，从小写字母中减去 `32` 就得到它的大写版本，结果可以重新存入一个 `char`：
```c
char upper = 'g' - 32; // 'G'
```

---

`int` 并不是唯一的整数类型。修饰符会改变它的大小和范围：
- `short` 占用更少内存，范围更小（通常是 -32768 到 32767）
- `long` 范围更大（在 64 位系统上约为 ±9×10¹⁸）
- `unsigned` 去掉了符号：`unsigned int` 的范围是 `0` 到约 40 亿，但永远不能为负数

必须是 `long` 的字面量要加上后缀 `L`，`unsigned` 的要加上后缀 `U`，并且每种类型都有自己的说明符：
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // prints "8000000000 40"
```
`%ld` 打印 `long`，`%u` 打印 `unsigned int`，`%lu` 打印 `unsigned long`。在大多数系统上，普通的 `int` 最多能容纳约 20 亿，所以 `5000000000` 放不下。

---

`sizeof` 运算符能告诉你一个类型或变量占用多少**字节**。它的结果类型是 `size_t`，用 `%zu` 打印：
```c
printf("%zu\n", sizeof(int));  // prints "4" on most systems
```
标准只保证 `sizeof(char)` 为 `1`，并且 `short <= int <= long`，但在典型的 64 位系统上，各类型的大小分别是：`char` 1，`short` 2，`int` 4，`long` 8，`float` 4，`double` 8。
`sizeof` 常用于在不硬编码数字的情况下检查一个变量占用了多少内存。

---

每种整数类型都有一个有限的范围，头文件 `limits.h` 为这些界限赋予了名字：`int` 对应 `INT_MAX` 和 `INT_MIN`，`long` 对应 `LONG_MAX`，`unsigned int` 对应 `UINT_MAX`，等等。
```c
#include <limits.h>

printf("%d\n", INT_MAX); // prints "2147483647" on most systems
```
对有符号类型超过 `INT_MAX` 是**未定义行为**：程序可能会环绕、崩溃，或者做任何其他事情。在计算之前先检查：
```c
if (a <= INT_MAX - b) { /* a + b is safe */ }
```
注意这里的检查用的是减法而不是加法，因为 `a + b` 本身可能已经溢出。

---

与有符号类型不同，**unsigned** 运算在超出范围时是良好定义的：值会像里程表一样**环绕归零**。
给 `UINT_MAX` 加 `1` 得到 `0`，从 `0` 减去 `1` 得到 `UINT_MAX`（当 `unsigned int` 为 32 位时是 `4294967295`）：
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // prints "0"
```
这就是为什么一个把 `unsigned` 变量递减"直到变为负数"的循环永远不会停止：unsigned 的值永远不会小于 `0`。

---

自 C99 起，头文件 `stdbool.h` 提供了 `bool` 类型，以及常量 `true`（`1`）和 `false`（`0`）。
`bool` 是一种只有两个值的整数类型，所以把任何数字转换为 `bool` 时，非零值都得到 `true`，`0` 得到 `false`。这与转换为 `int` 不同：
```c
#include <stdbool.h>

bool b = 0.5;  // true, because 0.5 is not zero
int n = 0.5;   // 0, because the decimals are truncated
```
像 `x != 0` 这样的比较已经产生了与 `bool` 兼容的结果，而返回 `bool` 的函数则表明它回答的是一个是/否问题。

---

算术运算是在其操作数的类型下进行的，**而不是**在接收结果的变量的类型下进行的。
所以对于 `int` 类型的 `n`，`long big = n * n;` 会先相乘两个 `int` 值，如果乘积过大就会溢出，然后才把（已经错误的）结果存入 `long`。
在运算**之前**把一个操作数转换为更大的类型：
```c
int n = 100000;
long big = (long) n * n; // 10000000000, computed as long
```
同样的规则也解释了为什么 `(double) total / count` 能正常工作：类型转换改变了操作数的类型，除法随之进行。

---

综合运用：根据值的种类选择类型，让每个 `printf` 说明符与其参数类型匹配，并在计算需要用与操作数不同的类型进行时使用类型转换。
