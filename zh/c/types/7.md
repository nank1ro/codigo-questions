# --description--

要从两个 `int` 变量得到浮点除法结果，标准做法是在做除法之前把**其中一个操作数**转换为 `double`。
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
把整个结果转换为 `double`，例如 `(double) (total / count)`，是一个常见错误：整数除法已经发生，小数部分已经丢失。

# --instructions--

补全代码，使 `avg` 保存 `total` 除以 `count` 并保留小数部分的结果，然后以一位小数打印它
