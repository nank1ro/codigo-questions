# --description--

C 是一门**静态类型**语言：每个变量在声明时都要指定一个类型，这个类型决定了它能存储什么以及占用多少内存。
你最常用到的三种类型是：
- `int` 用于整数，例如 `30` 或 `-4`
- `double` 用于带小数部分的数字，例如 `1.75`
- `char` 用于单个字符，用单引号书写，例如 `'A'`

每种类型都有自己的 `printf` **格式说明符**：`%d` 打印 `int`，`%f` 打印 `double`（默认显示六位小数），`%c` 打印 `char`：
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// prints "30 1.750000 A"
```
对某个类型使用错误的说明符会打印出乱码，所以要始终匹配正确。
