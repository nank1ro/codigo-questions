# --description--

当一个值被赋给不同类型的变量时，C 会**隐式**在数值类型之间进行转换。
- 存入 `double` 的 `int` 会被无损地扩展：`double d = 3;` 会让 `d` 等于 `3.0`
- 存入 `int` 的 `double` 会被**截断**：`int n = 3.99;` 会让 `n` 等于 `3`（编译器通常会对此发出警告）

转换只发生在赋值的那一刻。右边的表达式会先按照自己的类型计算：
```c
double d = 7 / 2;
```
这里 `7 / 2` 是整数除法，结果为 `3`，之后 `3` 才会被转换为 `3.0`。
