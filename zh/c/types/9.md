# --description--

在 ASCII 表中，大写字母和小写字母相差 `32` 个位置：`'A'` 是 `65`，`'a'` 是 `97`。
因此，从小写字母中减去 `32` 就得到它的大写版本，结果可以重新存入一个 `char`：
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

对代码行排序，将字母 `'a'` 存入 `letter`，计算其大写版本存入 `upper`，并依次打印每个字符及其编码（先打印 `letter`）

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
