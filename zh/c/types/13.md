# --description--

与有符号类型不同，**unsigned** 运算在超出范围时是良好定义的：值会像里程表一样**环绕归零**。
给 `UINT_MAX` 加 `1` 得到 `0`，从 `0` 减去 `1` 得到 `UINT_MAX`（当 `unsigned int` 为 32 位时是 `4294967295`）：
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // prints "0"
```
这就是为什么一个把 `unsigned` 变量递减"直到变为负数"的循环永远不会停止：unsigned 的值永远不会小于 `0`。
