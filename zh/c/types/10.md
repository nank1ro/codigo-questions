# --description--

`int` 并不是唯一的整数类型。修饰符会改变它的大小和范围：
- `short` 占用更少内存，范围更小（通常是 -32768 到 32767）
- `long` 范围更大（在 64 位系统上约为 ±9×10¹⁸）
- `unsigned` 去掉了符号：`unsigned int` 的范围是 `0` 到约 40 亿，但永远不能为负数

必须是 `long` 的字面量要加上后缀 `L`，`unsigned` 的要加上后缀 `U`，并且每种类型都有自己的说明符：
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // prints "8000000000 40"
```
`%ld` 打印 `long`，`%u` 打印 `unsigned int`，`%lu` 打印 `unsigned long`。在大多数系统上，普通的 `int` 最多能容纳约 20 亿，所以 `5000000000` 放不下。

# --instructions--

在典型的 64 位系统上，哪个声明能正确存储五十亿这个值？

# --answers--

- `long n = 5000000000L;`
- `int n = 5000000000;`
- `short n = 5000000000;`
- `unsigned int n = 5000000000U;`
