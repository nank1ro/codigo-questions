# --description--

`%f` 会打印六位小数，但这很少是你想要的。在 `%` 和 `f` 之间加上精度，就可以选择显示多少位小数：`%.2f` 打印两位小数，`%.1f` 打印一位，并且数值会被**四舍五入**，而不是被截断：
```c
double price = 9.987;
printf("%.2f\n", price); // prints "9.99"
printf("%.1f\n", price); // prints "10.0"
```
`float` 使用和 `double` 相同的说明符打印：传给 `printf` 时它会自动转换为 `double`。
