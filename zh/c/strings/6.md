# --description--

数组在声明之后不能用 `=` 赋值：
```c
char copy[20];
copy = "Codigo"; // error
```
要复制字符串，使用 `string.h` 中的 `strcpy(destination, source)`。
目标数组必须足够大，能容纳所有字符加上 `'\0'`。

# --instructions--

排序代码行，将 `source` 复制到 `copy` 并打印它。在 `copy` 之前声明 `source`
