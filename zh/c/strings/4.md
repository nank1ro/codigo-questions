# --description--

由于字符串是一个数组，每个字符都有一个从 `0` 开始的索引：
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
单个字符使用 `%c` 打印。字符也可以被替换：
```c
word[0] = 'K'; // word is now "Koding"
```
