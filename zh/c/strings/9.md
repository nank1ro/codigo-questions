# --description--

`strcmp` 使用字符编码逐个字符地比较字符串。
当第一个字符串排在第二个之前时，结果为负数；排在之后时为正数；相等时为 `0`：
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

# --instructions--

`strcmp("apple", "banana")` 返回什么？

# --answers--

- 一个负数
- 0
- 一个正数
- 字符串 "apple"
