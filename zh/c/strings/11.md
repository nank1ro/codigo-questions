# --description--

头文件 `ctype.h` 提供了处理单个字符的函数。
`toupper(c)` 返回字母的大写形式，`tolower(c)` 返回小写形式；其他任何字符都会原样返回：
```c
char letter = toupper('a'); // 'A'
```

# --instructions--

将 `first` 转换为大写、`second` 转换为小写，打印出 `Ab`

# --seed--

```c
#include <stdio.h>
#include <ctype.h>

int main() {

    char second = 'B';

    return 0;
}
```
