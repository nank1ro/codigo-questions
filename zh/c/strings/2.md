# --description--

空字符会占用内存空间：字面量 `"hi"` 占用 3 个字节，即 `'h'`、`'i'` 和 `'\0'`。
当你自己声明大小时，一定要为它留出空间：
```c
char word[6] = "hello"; // 5 letters + '\0'
```
没有终止符，C 语言就无法知道字符串在哪里结束。
