# --description--

**注释**是源代码中给人看的文本，而不是给编译器看的。编译器在构建程序之前会把注释丢弃，因此你可以用注释来解释代码的用途、留下提醒或记录某个决定。

最常见的是**单行注释**：从 `//` 到该行末尾的所有内容都会被忽略。
```c
// Greet the user
printf("Hello\n");
```
程序运行时第一行什么也不做；只有 `printf` 会产生输出。
