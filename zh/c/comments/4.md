# --description--

块注释**不能嵌套**。编译器会在它找到的第一个 `*/` 处结束 `/*` 注释，无论前面有多少个 `/*`：
```c
/* outer /* inner */ still code */
```
这里注释在 `inner` 之后立即结束，所以 `still code */` 会被当作代码编译并产生错误。

当你想注释掉一个已经包含 `/* */` 注释的代码块时，这一点很重要：里面的 `*/` 会让你的外层注释过早结束。在这种情况下，应改为在每一行前面加上 `//`。

# --instructions--

编译这段代码时会发生什么？
```c
/* start
   /* nested */
   printf("hidden\n");
*/
printf("done\n");
```

# --answers--

- 编译错误：注释在第一个 `*/` 处结束，在 `printf` 之后留下一个多余的 `*/`
- 它打印 `done`
- 它打印 `hidden` 和 `done`
- 它什么都不打印，因为所有内容都在外层注释内
