# --description--

好的注释解释代码**为什么**这么做，而不是它**做了什么**。代码本身已经展示了发生了什么；用文字重复它只会增加噪音，而且一旦代码改动就会过时：
```c
// 把 price 乘以 90 再除以 100
return price * 90 / 100;
```
数字背后的原因才是读者无法猜到的：
```c
// 首发优惠：会员在 6 月底前享受 10% 的折扣
return price * 90 / 100;
```
如果一条注释只是复述了它下面的那一行，就删掉它，或者换成原因。
