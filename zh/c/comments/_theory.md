**注释**是源代码中给人看的文本，而不是给编译器看的。编译器在构建程序之前会把注释丢弃，因此你可以用注释来解释代码的用途、留下提醒或记录某个决定。

最常见的是**单行注释**：从 `//` 到该行末尾的所有内容都会被忽略。
```c
// Greet the user
printf("Hello\n");
```
程序运行时第一行什么也不做；只有 `printf` 会产生输出。

---

由于编译器会完全移除注释，添加或删除注释永远不会改变程序的行为。只有**没有**被注释掉的代码才会运行。

这使得 `//` 成为在不删除代码行的情况下将其快速关闭的方法。这称为**注释掉**：
```c
int total = 10;
// total = total + 5;
printf("%d\n", total); // prints "10"
```
第二行现在是注释，所以 `total` 保持为 `10`。删掉 `//` 就能让这一行重新生效。

在实验时注释掉代码很方便，但记得要清理：长时间被注释掉的代码只会让下一个读它的人感到困惑。

---

当注释需要占用多行时，C 提供了**多行注释**（也称为块注释）：它以 `/*` 开头，以 `*/` 结尾，中间的所有内容都会被忽略，包括换行符。
```c
/*
  Prints the welcome banner.
  Called once when the program starts.
*/
printf("Welcome!\n");
```
块注释也可以很短，留在一行之内：`/* like this */`。

与在行尾停止的 `//` 不同，`/*` 注释只在 `*/` 处停止。如果忘记闭合它，编译器会把后面的所有代码都当作注释的一部分。

---

块注释**不能嵌套**。编译器会在它找到的第一个 `*/` 处结束 `/*` 注释，无论前面有多少个 `/*`：
```c
/* outer /* inner */ still code */
```
这里注释在 `inner` 之后立即结束，所以 `still code */` 会被当作代码编译并产生错误。

当你想注释掉一个已经包含 `/* */` 注释的代码块时，这一点很重要：里面的 `*/` 会让你的外层注释过早结束。在这种情况下，应改为在每一行前面加上 `//`。

---

注释不必独占一行：它可以跟在同一行的代码后面。这称为**尾随注释**，它适合用来写关于那条特定语句的简短说明：
```c
int retries = 3; // give up after three attempts
```
`//` 和 `/* */` 都可以用作尾随注释，但要小心 `/*`：由于它只在 `*/` 处停止，行尾一个未闭合的 `/*` 会吞掉后面的所有行，程序将无法编译。

---

块注释的一个常见用途是**头注释**：放在函数正上方的简短代码块，说明函数做什么、参数的含义以及返回什么。
```c
/*
 * Returns the number of seconds in the given minutes.
 * minutes: a whole number of minutes, never negative
 */
int to_seconds(int minutes) {
    return minutes * 60;
}
```
调用 `to_seconds` 的人现在可以阅读头注释而不是函数体。请把头注释放在函数旁边，以便它们一起更新。

---

编译器会把每个注释替换成一个空格。这意味着 `/* */` 注释可以出现在任何空格能出现的地方，甚至在语句或表达式的中间：
```c
int area = width /* cm */ * height /* cm */;
```
这偶尔可用于标注操作数或调用实参的含义。`//` 注释做不到这一点，因为它会注释掉该行剩余的部分，包括后面的代码。

---

程序员会在注释开头使用一些约定俗成的关键字来标记尚未完成的工作：

- `TODO` 标记还有待编写的内容
- `FIXME` 标记已知有误、必须修正的代码

```c
// TODO: validate the input before using it
// FIXME: crashes when the list is empty
```
编辑器和工具可以列出这些标记，因此待办的工作很容易找到。工作完成后，删除标记：过期的 `TODO` 会产生误导。

---

好的注释解释代码**为什么**这么做，而不是它**做了什么**。代码本身已经展示了发生了什么；用文字重复它只会增加噪音，而且一旦代码改动就会过时：
```c
// multiply price by 90 and divide by 100
return price * 90 / 100;
```
数字背后的原因才是读者无法猜到的：
```c
// launch discount: members get 10% off until the end of June
return price * 90 / 100;
```
如果一条注释只是复述了它下面的那一行，就删掉它，或者换成原因。

---

综合运用：用 `//` 写简短说明和尾随注释，用 `/* */` 写较长的块注释和头注释，用 `TODO` 或 `FIXME` 标记未完成的工作，并在被注释掉的代码和过期标记不再需要时将它们删除。
