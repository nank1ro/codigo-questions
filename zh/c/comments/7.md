# --description--

编译器会把每个注释替换成一个空格。这意味着 `/* */` 注释可以出现在任何空格能出现的地方，甚至在语句或表达式的中间：
```c
int area = width /* cm */ * height /* cm */;
```
这偶尔可用于标注操作数或调用实参的含义。`//` 注释做不到这一点，因为它会注释掉该行剩余的部分，包括后面的代码。

# --instructions--
