**链表**（linked list）把值存储在散布于内存中的一个个**节点**（node）里：每个节点持有一个值和一个指向下一个节点的指针，最后一个节点指向 `NULL`。结构体内部的指针引用的正是正在声明的类型本身，因此该结构体需要一个**标签**（tag）来为自身命名；在大括号内部，`typedef` 的名字还不存在：
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
节点之间通过把一个节点的地址存入另一个节点的 `next` 来链接，被指向节点的成员用箭头来访问：
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```

---

声明为局部变量的节点在其函数返回后就消失了，因此链表建立在**堆**（heap）上，使用 `stdlib.h` 中的 `malloc`。它保留所请求的字节数并返回它们的地址，内存耗尽时返回 `NULL`；`sizeof(Node)` 正是一个节点所需的大小：
```c
Node *node = malloc(sizeof(Node));
node->value = 5;
node->next = NULL;
```
堆内存绝不会自行释放：从 `malloc` 获得的每个节点一旦不再需要，就必须用 `free(node)` 归还。在这些练习中，`stdlib.h` 已被包含，`Node` 已在你的代码上方声明。

---

链表由一个指向其第一个节点的指针持有，这个节点就是**头节点**（head）。其余每个节点都从头部出发沿着 `next` 依次到达，而且箭头可以串联：`head->next` 是第二个节点，`head->next->next` 是第三个。空链表就是等于 `NULL` 的头节点，最后一个节点的 `next` 也是 `NULL`，因此多跟一步箭头就会对 `NULL` 解引用，使程序崩溃。

---

走一遍链表，称为**遍历**（traversal），是一个从头部开始、沿着 `next` 前进直到到达 `NULL` 的循环。`for` 循环可以用一行来表达，循环变量是一个指针：
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
这里没有索引：到达某个节点的唯一途径，就是存储在它前一个节点中的指针。

---

在**前端**添加节点时，先创建节点，让它指向当前的头节点，再把它作为新的头节点返回。调用方把结果存回自己的头变量：
```c
Node *head = NULL;
head = push_front(head, 7);
head = push_front(head, 8); // the list is now 8, 7
```
向空链表推入节点也是同样的道理：新节点指向 `NULL`，并成为整个链表。

---

释放链表意味着释放每一个节点，每次前进一个遍历步骤。`next` 指针必须在节点被释放**之前**保存起来，因为已释放的节点不能再读取，连它的 `next` 也不行：
```c
while (head != NULL) {
    Node *next = head->next;
    free(head);
    head = next;
}
```
先写 `free(head)` 再写 `head = head->next` 会读取刚刚释放的内存，这是未定义行为。`free(NULL)` 是允许的且什么也不做，因此空链表无需特殊处理。

---

链表不存储自己的长度：必须通过遍历来计数。`while` 形式的循环把指针放在循环外面，当循环体还要更新其他变量时会很方便：
```c
int count = 0;
Node *n = head;
while (n != NULL) {
    count++;
    n = n->next;
}
```
对于空链表，循环体从不运行，计数保持为 `0`。

---

在**尾部**添加节点需要先找到最后一个节点，即 `next` 为 `NULL` 的那个节点。函数一路走到它，把新节点接在那里，并返回未改变的头部：
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
链表为空时没有可以走到的最后一个节点：新节点直接作为头节点返回。

---

在链表中查找是一个遍历过程，逐个比较值并在第一个匹配处停下。函数返回指向所找到节点的指针，如果走到链表末尾都没有匹配，则返回 `NULL`：
```c
Node *found = find(head, 5);
if (found != NULL) {
    printf("%d\n", found->value);
}
```
返回节点而不是值，让调用方可以修改它，或把它作为另一个操作的起点。

---

`free(p)` 之后，变量 `p` 仍然持有旧地址，但它指向的内存已不再属于你：`p` 现在是一个**悬空指针**（dangling pointer）。通过它读取或写入，或者把它再释放一次，都是未定义行为：程序可能打印旧值、打印垃圾值或崩溃，而编译器不会报错。当指针必须在 `free` 之后继续存在时，应紧接着把它设为 `NULL`，这样之后的任何使用都会被 `NULL` 检查拦下。

---

在给定节点**之后**插入不需要遍历：新节点接管 `node` 的后继，然后让 `node` 指向新节点：
```c
new_node->next = node->next;
node->next = new_node;
```
这两次赋值的顺序很重要：先设置 `node->next` 会覆盖指向链表其余部分的唯一指针，那些节点就会丢失。在最后一个节点之后插入也可以，因为它的 `next` 是 `NULL`。

---

移除第一个节点正好是 `push_front` 的镜像：保存第二个节点的地址，释放第一个节点，并返回所保存的地址作为新的头节点。调用方把结果存回自己的头变量：
```c
Node *next = head->next;
free(head);
return next;
```
不断弹出直到头节点为 `NULL`，就释放了整个链表，每次调用释放一个节点。

---

移除位于链表中间的节点需要它**前面**的那个节点，因此遍历要维护两个指针：`prev` 是已经访问过的节点，`cur` 是正在检查的节点。当 `cur` 匹配时，让 `prev->next` 跳过它，然后释放 `cur`。如果匹配的正是头节点本身，`prev` 仍是 `NULL`，新的头节点就是 `cur->next`：
```c
if (prev == NULL) {
    head = cur->next;
} else {
    prev->next = cur->next;
}
free(cur);
```
没有节点匹配时，链表原样返回。

---

反转链表就是用三个指针把每个 `next` 指针原地调转方向：`prev` 是已经反转的部分，`head` 是正在处理的节点，`next` 是链表其余部分的副本，在改变链接之前保存。每一步中，当前节点回指 `prev`，然后 `prev` 和 `head` 都向前移动：
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
当 `head` 到达 `NULL` 时，每个链接都已翻转，`prev` 就是新的头节点。

---

链表在数组开销大的地方很便宜，反之亦然。无论长度如何，在**前端**添加或移除都只是几次指针赋值，而数组则必须移动每个元素。另一方面，节点在内存中并不连续，因此没有 `list[i]`：要到达第 n 个节点、最后一个节点或求出总长度，只能从头部出发走过中间的每一个节点。经常追加元素的程序通常会保留第二个指针指向最后一个节点，即**尾节点**（tail），以避免这种遍历。

---

综合运用：链表常常由数组构建。从前端推入会颠倒顺序，因此要**反向**遍历数组，从最后一个元素到第一个，这样第一个元素最终位于头节点。程序随后用一次遍历打印链表，并逐个节点释放它，让每个 `malloc` 都有对应的 `free`。
