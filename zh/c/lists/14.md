# --description--

反转链表就是用三个指针把每个 `next` 指针原地调转方向：`prev` 是已经反转的部分，`head` 是正在处理的节点，`next` 是链表其余部分的副本，在改变链接之前保存。每一步中，当前节点回指 `prev`，然后 `prev` 和 `head` 都向前移动：
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
当 `head` 到达 `NULL` 时，每个链接都已翻转，`prev` 就是新的头节点。

# --solutions--

```c
#include <stdio.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head != NULL) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
int main() {
    Node c = {3, NULL};
    Node b = {2, &c};
    Node a = {1, &b};
    for (Node *n = reverse(&a); n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    return 0;
}
```
