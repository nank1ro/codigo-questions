# --description--

当 `switch` 的每个 case 都处理一个常量时，记得在每个 case 后加上 `break`，否则执行会继续落入下一个 case。
如果覆盖了枚举的所有常量，就不需要 `default` 分支。

# --instructions--

排序代码行，声明 `enum Size`，把 `MEDIUM` 存入 `size`，并用 `switch` 打印 `Medium`。保持 case 顺序与声明中常量的顺序一致

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

```c
    case SMALL: printf("Small\n"); break;
```

```c
    case MEDIUM: printf("Medium\n"); break;
```

```c
    case LARGE: printf("Large\n"); break;
```

```c
}
```

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
