# --description--

枚举也是一种类型：你可以通过写 `enum` 加上枚举名来声明该类型的变量，并给它赋值某个常量：
```c
enum Color favorite = GREEN;
```
由于常量是整数，你可以用通常的运算符比较 enum 变量：
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```
