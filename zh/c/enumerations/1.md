# --description--

**枚举**（`enum`）为一组相关的整数常量命名，这样你就可以写 `RED` 而不是一个孤零零的数字。
你使用 `enum` 关键字、一个名称以及花括号之间的常量列表来声明它：
```c
enum Color { RED, GREEN, BLUE };
```
每个常量都是一个整数：除非另有说明，第一个常量是 `0`，后面每一个都是前一个加一，因此 `RED` 是 `0`，`GREEN` 是 `1`，`BLUE` 是 `2`。
因为它们是整数，所以你用 `%d` 打印它们：
```c
printf("%d\n", GREEN);
// prints "1"
```
