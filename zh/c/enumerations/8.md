# --description--

每次都写 `enum Color` 很啰嗦。用 `typedef` 可以给枚举起一个简短的类型名，而枚举本身可以保持匿名：
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
新名称 `Color` 可以单独使用，前面不需要加 `enum` 关键字。
