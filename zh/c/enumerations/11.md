# --description--

一个常见的技巧是在枚举末尾多加一个常量，通常命名为 `COUNT`：由于编号从 `0` 开始，它的值正好等于它之前真正常量的数量。
```c
enum Day { MON, TUE, WED, DAY_COUNT }; // DAY_COUNT is 3
```
这个哨兵值让你可以遍历所有常量而不用把数字写死，并且在你在它前面添加常量时依然保持正确：
```c
for (int d = MON; d < DAY_COUNT; d++) {
    printf("%d\n", d);
}
```
