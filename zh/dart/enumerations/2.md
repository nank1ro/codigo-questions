# --description--

每个枚举值都有两个内置属性：

- `name` 是该值的名称，类型为 `String`
- `index` 是它在声明中的位置，从 `0` 开始

```dart
enum Direction { north, south, east, west }

print(Direction.east.name);  // east
print(Direction.east.index); // 2
```
