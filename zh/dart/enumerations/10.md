# --description--

从 Dart 2.17 开始，枚举可以像类一样声明**字段**和**构造函数**。这被称为*增强枚举*。每个值会向构造函数传入自己的参数：

```dart
enum Planet {
  mercury(0),
  earth(1),
  mars(2);

  final int moons;

  const Planet(this.moons);
}

print(Planet.mars.moons); // 2
```

注意这三条规则：值列表以**分号** `;` 结尾，字段必须是 `final`，构造函数必须是 `const`。
