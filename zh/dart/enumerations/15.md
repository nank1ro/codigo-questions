# --description--

枚举值是极好的 **map 键**：它们是唯一的、易于比较，并且编译器会检查你只使用真实存在的值。将枚举声明为键类型来创建 map，并使用 `[]` 查找值：

```dart
enum Direction { north, south, east, west }

Map<Direction, String> arrows = {
  Direction.north: '^',
  Direction.south: 'v',
  Direction.east: '>',
  Direction.west: '<',
};

print(arrows[Direction.east]); // >
```

和任何 map 一样，当键不存在时查找会返回 `null`，因此使用 `??` 提供一个回退值。

# --solutions--

```dart
enum Size { small, medium, large }

Map<Size, int> prices = {
  Size.small: 2,
  Size.medium: 3,
  Size.large: 4,
};

int totalPrice(List<Size> order) {
  int total = 0;
  for (var size in order) {
    total += prices[size] ?? 0;
  }
  return total;
}
```
