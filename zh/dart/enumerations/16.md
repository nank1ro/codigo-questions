# --description--

枚举可以使用 `implements` 关键字**实现一个接口**。这样枚举就承诺提供接口声明的每一个成员，并且它的值可以用在任何期望该接口类型的地方：

```dart
abstract class Describable {
  String describe();
}

enum Animal implements Describable {
  dog,
  cat;

  @override
  String describe() => 'I am a $name';
}

Describable pet = Animal.cat;
print(pet.describe()); // I am a cat
```

接口中声明的 getter 既可以用 getter 实现，也可以用同名的 `final` 字段实现。

# --solutions--

```dart
abstract class Priced {
  int get price;
}

enum Ticket implements Priced {
  child(5),
  adult(12),
  senior(8);

  @override
  final int price;

  const Ticket(this.price);
}

int total(List<Priced> items) {
  int sum = 0;
  for (var item in items) {
    sum += item.price;
  }
  return sum;
}
```
