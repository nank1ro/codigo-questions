# --instructions--

给定 `enum Size { small, medium, large }`，下面的代码会发生什么？

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- 无法编译：作用于枚举的 `switch` 表达式必须覆盖所有值
- 可以编译，并对 `Size.large` 返回 `null`
- 可以编译，并在运行时对 `Size.large` 抛出异常
- 可以编译，并自动对 `Size.large` 返回 `'L'`
