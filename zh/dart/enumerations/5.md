# --description--

遍历 `values` 是处理枚举全部值的常用方式。在循环中，当前值和其他对象一样，因此你可以读取它的 `index` 和 `name`，并直接用在字符串插值中:

```dart
enum Direction { north, south, east, west }

for (var direction in Direction.values) {
  print('${direction.index}: ${direction.name}');
}
```
