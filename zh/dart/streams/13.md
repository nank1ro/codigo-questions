# --description--

到目前为止见到的流都是**单订阅**流：它们只允许恰好一个监听者。第二次调用 `listen`、`await for` 或任何消费方法都会抛出 `StateError`（"Stream has already been listened to"）。

要在多个监听者之间共享一个流，用 `asBroadcastStream()` 把它转换成**广播**流：

```dart
final shared = Stream.fromIterable([1, 2, 3]).asBroadcastStream();
final total = shared.reduce((a, b) => a + b);
final count = shared.length;
print(await total); // 6
print(await count); // 3
```

广播流不做缓冲：监听者只会收到它订阅**之后**发出的事件。在这个例子里，两个监听者都在第一个 `await` 之前订阅，所以两者都收到了每个事件。

# --instructions--

编写一个函数 `sumAndCount`，它接收一个 `Stream<int>` `source`，返回一个以两个元素的列表完成的 `Future<List<int>>`：这些值的和以及值的个数。把 `source` 转换成广播流，在等待其中任何一个**之前**先启动两个消费调用，然后再等待它们。流中总是至少有一个事件。

示例：
```dart
print(await sumAndCount(Stream.fromIterable([1, 2, 3]))); // [6, 3]
```

```dart
Future<List<int>> sumAndCount(Stream<int> source) async {
  final shared = source.asBroadcastStream();
  final sum = shared.reduce((a, b) => a + b);
  final count = shared.length;
  return [await sum, await count];
}
```
