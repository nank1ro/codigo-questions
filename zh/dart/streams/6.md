# --description--

`async*` 生成器可以用 `yield*`（yield-star）转发**另一个流的每个事件**。它就像一个把每个值都 yield 出来的 `await for` 循环，只用一行：

```dart
Stream<int> ones() async* {
  yield 1;
  yield 1;
}

Stream<int> sequence() async* {
  yield 0;
  yield* ones();
  yield 2;
}
// sequence() emits 0, 1, 1, 2
```

内层流结束后，外层流继续执行它自己的 `yield`。
