# --description--

因为 `where`、`map` 和 `take` 各自都返回一个流，你可以把它们链起来，最后用 `toList()` 把结果拿成一个列表。只有最后的 `toList()` 需要 `await`，因为它是唯一返回 `Future` 的调用：

```dart
final numbers = Stream.fromIterable([5, 12, 8, 20, 3]);
final big = await numbers.where((n) => n > 6).take(2).toList();
print(big); // [12, 8]
```
