# --description--

组合起来，一个 `Isolate.run` 程序读起来就像普通的顺序代码：调用之前的那一行在主 isolate 上运行，计算在别处运行，而 `await` 之后的那一行带着结果回到主 isolate 上运行。

```dart
import 'dart:isolate';

int twice(int n) => n * 2;

Future<void> main() async {
  print('start');
  final result = await Isolate.run(() => twice(4));
  print(result);
}
// start
// 8
```
