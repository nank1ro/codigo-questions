# --description--

收集一整串消息遵循同一个配方：循环前准备一个空列表，每条真正的消息做一次 `add`，在结束流的信号到来时调用 `close()`。端口一旦关闭，`await for` 就会结束，函数也就可以返回了：

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

消息保持它们被发送时的顺序，所以你构建的列表一步一步地映出另一个 isolate 的工作。

# --instructions--

编写一个顶层函数 `sendWords`，它接收一个 `List<Object>` 类型的 `message`，其中元素 `0` 是一个 `SendPort`，元素 `1` 是一个 `List<String>`：把每个单词发送到端口，然后发送 `null` 表示结束。

然后编写一个函数 `collectWords`，它接收一个 `List<String>` 类型的 `words`，返回一个 `Future<List<String>>`，以从被 spawn 的 `sendWords` isolate 收到的所有单词完成。

示例：
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

# --solutions--

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
