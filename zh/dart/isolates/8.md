# --description--

`Isolate.spawn` 只向入口点传递**一条**消息，而工作单元通常既需要一个用来应答的 `SendPort`，又需要一些要处理的数据。常见的技巧是把所有东西打包进一个 `List`，在另一侧再把它解开：

```dart
void multiply(List<Object> message) {
  final port = message[0] as SendPort;
  final value = message[1] as int;
  port.send(value * 2);
}

Future<void> main() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(multiply, <Object>[receivePort.sendPort, 21]);
  print(await receivePort.first); // 42
}
```

列表在进入时被复制，所以工作单元读取的是它自己的那些值。`SendPort` 是少数不被复制而是被共享的东西之一：它始终指向创建它的那个 isolate 的邮箱，这正是它能被用作回信地址的原因。

# --instructions--

编写一个顶层函数 `sendSum`，它接收一个 `List<Object>` 类型的 `message`，其中元素 `0` 是一个 `SendPort`，元素 `1` 和 `2` 是 `int`，并把它们的和发送到该端口。

然后编写一个函数 `addInIsolate`，它接收两个 `int` 类型的 `a` 和 `b`，返回一个 `Future<int>`，以由被 spawn 的 `sendSum` isolate 计算出的和完成。

示例：
```dart
print(await addInIsolate(2, 3)); // 5
```

# --solutions--

```dart
void sendSum(List<Object> message) {
  final port = message[0] as SendPort;
  final a = message[1] as int;
  final b = message[2] as int;
  port.send(a + b);
}

Future<int> addInIsolate(int a, int b) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendSum, <Object>[receivePort.sendPort, a, b]);
  return await receivePort.first as int;
}
```
