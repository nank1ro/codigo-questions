# --description--

在 isolate 之间只有**数据**会被复制；**代码**不会。程序的每个 isolate 本来就能看到该程序所有的顶层函数和类，因此交给 `Isolate.run` 的计算可以随意调用它们：

```dart
int slowLength(String text) => text.length;

Future<int> lengthInIsolate(String text) {
  return Isolate.run(() => slowLength(text));
}
```

传递的是进去时被捕获的 `text` 和出来时的结果 `int`，两者都是副本。这个模式始终一样：把繁重的函数留在原地，把**调用**包进 `Isolate.run`。

# --instructions--

函数 `wordCount(text)` 会统计字符串的单词数。编写一个函数 `countWords`，它接收一个 `String` 类型的 `text`，返回一个 `Future<int>`，以 `wordCount(text)` 的结果完成，且计算用 `Isolate.run` 在另一个 isolate 上进行。

示例：
```dart
print(await countWords('hello isolate world')); // 3
```

import 'dart:isolate';

int wordCount(String text) {
  return text.split(' ').where((w) => w.isNotEmpty).length;
}
