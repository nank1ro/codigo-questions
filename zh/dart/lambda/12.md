# --description--

闭包不只是读取它捕获的变量：它还可以**修改**它们，并且这些修改会在多次调用之间保留。这使得不使用类也能保存私有的状态：

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

每次调用 `makeTimer()` 都会创建一个全新的 `seconds` 变量，所以两个计时器永远不会共享它们的计数。

# --instructions--

编写一个没有参数的函数 `makeCounter`，它返回一个类型为 `int Function()` 的函数。每次调用返回的函数时，它必须把捕获的计数器加一并返回，从 `1` 开始。

示例：
```dart
var counter = makeCounter();
print(counter()); // 1
print(counter()); // 2
```
