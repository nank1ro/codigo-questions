# --description--

另外两个接收匿名函数的非常常见的方法是 `map` 和 `where`：

- `map` 用该函数转换每个元素并返回新的值
- `where` 只保留函数对其返回 `true` 的元素

两者都返回一个惰性的 `Iterable`；调用 `toList()` 可以把结果转换成 `List`：

```dart
var numbers = [1, 2, 3];

var squares = numbers.map((n) => n * n).toList();
print(squares); // [1, 4, 9]

var big = numbers.where((n) => n > 1).toList();
print(big); // [2, 3]
```
