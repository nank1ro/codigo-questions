# --description--

函数还可以**返回一个函数**。此时返回类型是一个函数类型，函数体返回一个匿名函数：

```dart
int Function(int) makeAdder(int amount) {
  return (int n) => n + amount;
}

var addTen = makeAdder(10);
print(addTen(5)); // 15
```

注意，返回的函数即使在 `makeAdder` 结束之后，仍然使用着 `makeAdder` 的参数 `amount`。像这样记住周围变量的函数被称为**闭包**。
