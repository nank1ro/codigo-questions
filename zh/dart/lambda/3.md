# --description--

当函数体是单个表达式时，匿名函数可以使用**箭头语法** `=>`，与命名函数一样。箭头取代了花括号和 `return` 关键字：

```dart
var add = (int a, int b) => a + b;

print(add(2, 3)); // 5
```

这种简写形式是 Dart 中编写匿名函数最常见的方式。
