# --description--

由于函数类型是一种普通类型，函数可以把**另一个函数作为参数**。在函数体中，该参数可以像任何函数一样被调用：

```dart
int apply(int n, int Function(int) operation) {
  return operation(n);
}

print(apply(5, (n) => n * 2)); // 10
print(apply(5, (n) => n - 1)); // 4
```

这里调用者通过传递一个匿名函数作为第二个参数，来决定 `apply` 做什么。

# --instructions--

编写一个函数 `applyTwice`，它接收一个 `int` 参数 `n` 和一个类型为 `int Function(int)` 的函数参数 `operation`，并返回把 `operation` 应用到 `n` 两次的结果。

示例：
```dart
print(applyTwice(3, (n) => n * 2)); // 12
```
