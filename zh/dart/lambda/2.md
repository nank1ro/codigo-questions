# --description--

匿名函数可以接收参数并 `return` 一个值，与命名函数完全一样。返回类型不需要写出：Dart 会根据函数体中的 `return` 语句**推断**它。

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
