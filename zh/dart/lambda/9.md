# --description--

`sort` 会对列表就地重新排序。默认情况下它使用元素的自然顺序，但你也可以传递一个**比较两个元素**的匿名函数，它返回一个负数、零或正数。`compareTo` 正好给出这样的数字，因此它是常用的构建块：

```dart
var words = ['pear', 'fig', 'banana'];

words.sort((a, b) => a.length.compareTo(b.length));
print(words); // [fig, pear, banana]
```

在比较中交换 `a` 和 `b` 会反转顺序。
