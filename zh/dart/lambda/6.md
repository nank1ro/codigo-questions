# --description--

Dart 集合的许多方法都把函数作为参数，而匿名函数是传递函数的自然方式。最简单的是 `forEach`，它会为列表中的每个元素调用一次给定的函数：

```dart
var fruits = ['apple', 'kiwi'];

fruits.forEach((fruit) {
  print('I like $fruit');
});
// I like apple
// I like kiwi
```

参数类型是从列表中推断出来的，所以无需写出，`fruit` 就是一个 `String`。
