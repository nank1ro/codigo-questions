# --description--

`.first` 和 `.last` 属性可以让你在不使用索引的情况下获取列表的第一个和最后一个元素。

```dart
var colors = ['red', 'green', 'blue'];
print(colors.first); // red
print(colors.last); // blue
```

如果列表为空，两者都会抛出错误。
