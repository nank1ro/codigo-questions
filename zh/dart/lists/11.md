# --description--

`.remove(value)` 方法会从列表中删除**第一个**等于 `value` 的元素。如果删除了元素则返回 `true`，如果未找到该值则返回 `false`。

```dart
var colors = ['red', 'green', 'blue'];
bool removed = colors.remove('green');
print(removed); // true
print(colors); // [red, blue]
```
