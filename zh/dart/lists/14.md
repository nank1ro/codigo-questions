# --description--

当列表没有元素时，`.isEmpty` 属性为 `true`；当列表至少有一个元素时，`.isNotEmpty` 属性为 `true`。

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
