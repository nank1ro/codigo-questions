# --description--

空安全最大的好处是：大多数 `null` 错误由**编译器**发现，而不是由你的用户发现。目前学到的规则：

- 非空类型（`String`、`int`、`List<int>`...）永远不能是 `null`
- 可空类型（`String?`、`int?`、`List<int>?`...）可以，并且在声明时不赋值就以 `null` 开始
- 在可空值上使用 `.` 无法编译：请使用 `?.`，或用 `??` 提供默认值

# --instructions--

以下哪个声明**无法**编译？

# --answers--

- `String b = null;`
- `String? a = null;`
- `int? c;`
- `int d = 0;`
