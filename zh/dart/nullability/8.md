# --description--

记住你已经见过的三个用于可空值的运算符之间的区别：

- `?.` 在值为 `null` 时返回 `null`，绝不抛出错误
- `??` 用默认值替换 `null`
- `!` 假定值一定存在，当它不存在时**在运行期抛出错误**

它们都不是编译错误：编译器信任你的 `!`，只有运行中的程序才能发现这个承诺被打破了。

# --instructions--

运行下面的代码会发生什么？

```dart
void main() {
  String? city;
  print(city!.length);
}
```

# --answers--

- 它会在运行期抛出错误
- 它会打印 `null`
- 它会打印 `0`
- 它无法编译
