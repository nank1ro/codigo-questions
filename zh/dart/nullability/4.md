# --description--

缺失的值常常应该用一个**默认值**来代替。**if-null** 运算符 `??` 在左操作数不是 `null` 时返回左操作数，否则返回右操作数：

```dart
String? nickname;
print(nickname ?? 'anonymous'); // anonymous

nickname = 'Ada';
print(nickname ?? 'anonymous'); // Ada
```

`??` 只对 `null` 起作用：空字符串 `''` 或数字 `0` 都是真实的值，因此会被保留。

`??` 与 `?.` 配合得很好，因为 `?.` 产生的是可空结果：

```dart
String? text;
print(text?.length ?? 0); // 0
```

```dart

```
