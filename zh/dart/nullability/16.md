# --description--

真实数据中到处是缺口：留空的表单字段、文件中缺失的一列、算不上数字的字符串。本章的工具可以自然地组合起来处理它们：用 `nonNulls` 丢弃缺失的元素，用 `int.tryParse` 安全地转换，用 `??` 或 `if` 检查来处理无法转换的内容。

# --instructions--

编写一个函数 `total`，它接受一个 `List<String?>` 参数 `prices`，返回其中可以转换成 `int` 的值之和，同时忽略 `null` 条目和不是有效整数的字符串。

示例：
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
