# --description--

声明时**没有赋值**的可空变量初始为 `null`，所以 `= null` 可以省略：

```dart
int? age;
print(age); // null
```

非空变量没有这样的默认值：在赋值之前读取它的代码，Dart 会拒绝编译。

```dart
int count;
print(count); // error: 'count' must be assigned before it can be used
```
