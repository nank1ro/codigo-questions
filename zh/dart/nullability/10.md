# --description--

类型提升**不**适用于可以从外部修改的类**字段**，因为在检查和使用之间，另一段代码（子类中被重写的 getter、另一个方法）可能又把它设回 `null`：

```dart
class Box {
  int? value;

  int doubled() {
    if (value != null) {
      return value * 2; // error: 'value' can't be unconditionally accessed
    }
    return 0;
  }
}
```

标准做法是把字段复制到一个**局部变量**中，局部变量是可以被提升的：

```dart
int doubled() {
  final v = value;
  if (v != null) {
    return v * 2;
  }
  return 0;
}
```

# --instructions--

为什么描述中 `doubled` 的第一个版本无法编译？

# --answers--

- `value` 是字段，所以判空不会提升它：请先把它复制到局部变量
- `int?` 的值不能做乘法，即使它们不是 `null`
- `if` 语句缺少 `else` 分支
- 类的字段不能使用可空类型
