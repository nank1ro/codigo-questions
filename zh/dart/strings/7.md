# --description--

`.substring(start, end)` 方法返回字符串从索引 `start` 开始到索引 `end`（**不包含**）为止的部分。如果省略 `end`，则返回从 `start` 到字符串末尾的全部内容：

```dart
var text = 'Hello Dart';
print(text.substring(0, 5));  // Hello
print(text.substring(6));     // Dart
```
