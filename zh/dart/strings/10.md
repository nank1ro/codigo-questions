# --description--

`.split(separator)` 方法在每次出现分隔符的地方把字符串切分成 `List<String>`。与之相反的是 `.join(separator)`，这是列表的一个方法，把元素粘合成一个字符串：

```dart
var csv = 'a,b,c';
List<String> parts = csv.split(',');
print(parts);            // [a, b, c]
print(parts.join(' - ')); // a - b - c
```

用空字符串调用 `.split('')` 会得到一个包含每个单独字符的列表。
