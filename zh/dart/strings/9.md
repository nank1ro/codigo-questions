# --description--

`.replaceAll(from, to)` 方法返回一个新字符串，其中**每一处** `from` 都被替换为 `to`。`.replaceFirst(from, to)` 只替换第一处：

```dart
var text = 'a-b-c';
print(text.replaceAll('-', '+'));    // a+b+c
print(text.replaceFirst('-', '+'));  // a+b-c
```
