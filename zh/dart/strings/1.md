# --description--

**字符串（String）**是一段文本：一串用引号包裹的字符。在 Dart 中，你可以使用单引号 `'...'` 或双引号 `"..."`，它们的作用完全相同：

```dart
String name = 'Dart';
String other = "Dart";
print(name == other); // true
```

选择一种引号后，可以在文本内部不加转义地使用另一种引号：

```dart
print("It's sunny");   // It's sunny
print('Say "hi"');     // Say "hi"
```

如果需要在文本内部使用相同的引号，用反斜杠对其进行转义：`'It\'s sunny'`。
