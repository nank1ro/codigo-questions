# --description--

用户输入的文本周围经常带有多余的空格。`.trim()` 方法返回一个去掉首尾空白字符（空格、制表符和换行符）的字符串副本。`.trimLeft()` 和 `.trimRight()` 只去除某一侧的空白：

```dart
var input = '   hello  ';
print('[${input.trim()}]');      // [hello]
print('[${input.trimLeft()}]');  // [hello  ]
```
