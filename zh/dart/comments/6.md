# --description--

除了这两种编写注释的方式外，Dart 还包含_文档注释_。

_文档注释_是以 `///` 或 `/**` 开头的多行或单行注释。在连续行上使用 `///` 与多行文档注释具有相同的效果。

_文档注释_非常有用，因为它们可以生成文档。
你会希望在代码中添加_文档注释_，以便清楚地说明特定代码块的作用。

在_文档注释_中，分析器会忽略所有文本，除非文本被方括号括起来。
使用方括号可以引用_类_、_方法_、_字段_、_变量_、_函数_和_参数_。

以下是一个示例：
```dart
/// 一种驯化的南美骆驼科动物（Lama glama）。
///
/// 和其他动物一样，llama 也需要进食，
/// 所以别忘了用 [feed] 给它们喂一些 [Food]。
class Llama {
  String? name;

  /// 给你的 llama 喂食 [food]。
  ///
  /// 典型的 llama 每周吃一捆干草。
  void feed(Food food) {
    // ...
  }

  /// 让你的 llama 用 [activity] 进行锻炼，持续
  /// [timeLimit] 分钟。
  void exercise(Activity activity, int timeLimit) {
    // ...
  }
}
```

在生成的文档中，`[feed]` 会变成指向 `feed` 方法文档的链接，`[Food]` 会变成指向 `Food` 类文档的链接。
而 `[activity]` 和 `[timeLimit]` 分别会变成指向 `activity` 和 `timeLimit` 文档的链接。
