# --description--

`firstWhere` 返回第一个通过测试的元素。当没有元素通过时，它没有元素可返回，于是抛出一个 `StateError`：

```dart
final words = ['a', 'fg'];
print(words.firstWhere((w) => w.length > 3)); // Bad state: No element
```

就像 `int.tryParse` 一样，库也提供了一条出路。命名参数 `orElse` 接受一个函数，在没有匹配时由它产生要使用的值：

```dart
print(words.firstWhere((w) => w.length > 3, orElse: () => 'none')); // none
```

选择和之前是同一个：当"没有匹配"是寻常结果时用 `orElse`，当它意味着数据已损坏、必须让某个人听到时用不带 `orElse` 的调用。

# --instructions--

编写两个接受 `List<String>` 类型 `words` 的函数。

`firstLong` 使用 `firstWhere` 返回第一个长度超过三个字符的单词，没有时通过 `orElse` 返回 `'none'`。

`firstLongStrict` 同样使用 `firstWhere`，但不带 `orElse`，所以没有时它会抛出一个 `StateError`。

示例：
```dart
print(firstLong(['a', 'bcde', 'fg'])); // bcde
print(firstLong(['a', 'fg'])); // none
```

```dart
String firstLong(List<String> words) {
  return words.firstWhere((w) => w.length > 3, orElse: () => 'none');
}

String firstLongStrict(List<String> words) {
  return words.firstWhere((w) => w.length > 3);
}
```
