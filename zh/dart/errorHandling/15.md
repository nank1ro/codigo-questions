# --description--

`try` 块放在哪里，决定了一次失败会毁掉多少工作。放在循环外面，第一个坏元素会结束整批处理；放在循环**里面**，只有那个元素被丢弃，其余的仍然会被处理：

```dart
for (final text in texts) {
  try {
    total += int.parse(text);
  } on FormatException {
    continue;
  }
}
```

这是导入文件、读取一组设置或处理一批消息时最常见的形状：一行坏数据不应该把好数据也一起扔掉。规则和之前一样——把 `try` 块保持在可能失败的语句周围，不要再大。

# --instructions--

编写一个函数 `sumOf`，接受一个 `List<String>` 类型的 `texts`，返回其中能表示整数的元素之和，忽略其他的。

在循环内部使用带 `try`/`catch` 的 `int.parse`，使一个无法解析的条目不会让其余的停下来。

示例：
```dart
print(sumOf(['1', 'x', '3'])); // 4
```

```dart
int sumOf(List<String> texts) {
  var total = 0;
  for (final text in texts) {
    try {
      total += int.parse(text);
    } on FormatException {
      continue;
    }
  }
  return total;
}
```
