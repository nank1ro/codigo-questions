# --description--

通常恢复动作根本不需要被抛出的对象：类型本身已经说明了一切。这时可以去掉 `catch` 部分，只保留 `on` 子句：

```dart
try {
  return int.parse(text);
} on FormatException {
  return 0;
}
```

两种形式的区别只在于是否得到一个变量：

- `on FormatException catch (e)` — 匹配该类型，并把对象作为 `e` 交给你
- `on FormatException` — 匹配该类型，没有变量
- `catch (e)` — 匹配一切，并把对象交给你

省略用不到的变量，能让处理程序诚实地反映它实际使用的东西。
