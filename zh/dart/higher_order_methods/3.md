# --description--

传给 `map` 的函数不必返回与它接收的元素相同的类型。把一个字符串列表映射成它们的长度，会把 `List<String>` 变成 `Iterable<int>`，再用 `toList()` 变成 `List<int>`：

```dart
final words = ['fig', 'kiwi'];
print(words.map((w) => w.length).toList()); // [3, 4]
```

结果的元素个数**总是和原来完全一样**，顺序也一样：`map` 只转换元素，从不增加或删除元素。
