# --description--

有些高阶方法回答的是关于集合的问题，而不是构建一个新集合。它们接收一个谓词并返回 `bool`：

- 当**至少有一个**元素满足谓词时 `any` 为 `true`
- 当**所有**元素都满足谓词时 `every` 为 `true`

```dart
final numbers = [1, 2, 3];
print(numbers.any((n) => n > 2));   // true
print(numbers.every((n) => n > 2)); // false
```

两者都会在答案确定时立刻停止：`any` 停在第一个匹配的元素，`every` 停在第一个不匹配的元素。

对空集合来说 `any` 是 `false`，`every` 是 `true`：没有元素能证明前者，也没有元素能推翻后者。

# --instructions--

编写两个函数，都接收一个 `List<int>` `numbers`：

- 如果至少有一个元素小于 `0`，`hasNegative` 返回 `true`
- 如果每个元素都是偶数，`allEven` 返回 `true`

示例：
```dart
print(hasNegative([1, -2, 3])); // true
print(allEven([2, 4]));         // true
```

# --solutions--

```dart
bool hasNegative(List<int> numbers) {
  return numbers.any((n) => n < 0);
}

bool allEven(List<int> numbers) {
  return numbers.every((n) => n % 2 == 0);
}
```
