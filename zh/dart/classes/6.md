# --description--

`this` 指向类的**当前实例**，即调用方法的那个对象。在方法内部可以用它访问对象自己的字段：

```dart
class Circle {
  double radius;

  Circle(this.radius);

  double diameter() {
    return this.radius * 2;
  }
}
```

此处 `this.radius` 读取调用 `diameter()` 的那个圆的 `radius` 字段。当没有其他同名变量时，`this.` 可以省略：`radius * 2` 效果相同。
