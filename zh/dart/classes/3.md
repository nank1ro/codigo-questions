# --description--

**构造函数**是在从类创建（实例化）对象时运行的特殊方法。构造函数与类同名：

```dart
class Animal {
  String name;

  Animal(this.name);
}
```

写作 `this.name` 的参数会把传给构造函数的值直接存入新对象的字段 `name`。以这种方式设置的字段不需要初始值。

使用 `new` 关键字（在 Dart 中可省略）或直接用类名创建对象：

```dart
var dog = Animal('Rex');
```
