# --description--

上一题中看到的 `this.x` 参数是一种简写。完整写法在构造函数体内把每个参数赋值给对应字段（`this.x` 是字段，`x` 是参数）：

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

同一个类可以写成：

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

这种更简短的形式称为**初始化形式参数**。

# --instructions--

下列哪项正确使用了初始化形式参数简写语法？

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`
