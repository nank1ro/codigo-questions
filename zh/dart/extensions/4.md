# --description--

`on` 后面的类型可以是**参数化**类型，例如 `List<int>`。这时扩展只适用于该元素类型的列表：`[1, 2].total()` 可以运行，`['a', 'b'].total()` 则无法编译。

```dart
extension Totals on List<int> {
  int total() {
    var sum = 0;
    for (final n in this) {
      sum += n;
    }
    return sum;
  }
}
```

在扩展内部，`this` 就是这个列表，因此你可以像往常一样遍历它、按索引访问它，或调用 `length`。
