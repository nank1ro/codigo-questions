# --description--

扩展不仅适用于 SDK 类型：你也可以扩展**自己的类**。当类来自一个你无法控制的包，或者你想让类保持精简、把可选的辅助功能放在需要它们的代码旁边时，这会很有用。

```dart
class Circle {
  final double radius;
  Circle(this.radius);
}

extension CircleMath on Circle {
  double get diameter => radius * 2;
}

void main() {
  print(Circle(3).diameter); // 6.0
}
```

扩展可以看到类的公共字段和方法，与写在类外面的代码完全一样。
