# --instructions--

编写一个名为 `Words` 的 `String` 扩展，包含：
- 一个 `int` 类型的 getter `wordCount`，即字符串中单词的数量，单词之间以单个空格分隔
- 一个 `String` 类型的 getter `initials`，由每个单词首字符的大写形式组成，拼接时不加分隔符

字符串总是至少包含一个单词，并且绝不会有前导空格、尾随空格或连续空格。

示例：
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
