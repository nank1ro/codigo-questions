# --description--

扩展适用于任何类型，包括数字。下面这个扩展为每个 `int` 提供了一个让它翻倍的方法：

```dart
extension Doubling on int {
  int doubled() => this * 2;
}
```

由于扩展作用于**类型**，你既可以在变量上调用该方法，也可以直接在**字面量**上调用。负数字面量需要加括号，否则点号会先于负号被解析：

```dart
var n = 21;
print(n.doubled());    // 42
print(4.doubled());    // 8
print((-3).doubled()); // -6
```
