# --description--

mixin 不局限于方法：它也可以声明**字段**，使用该 mixin 的每个类的每个对象都拥有自己的一份副本。

```dart
mixin Counter {
  int count = 0;

  void increment() {
    count++;
  }
}

class Clicker with Counter {}

void main() {
  final a = Clicker();
  final b = Clicker();
  a.increment();
  a.increment();
  print(a.count); // 2
  print(b.count); // 0, b has its own count
}
```

这正是 mixin 胜过接口的地方：它既带来数据，也带来操作这些数据的代码。

# --instructions--

声明一个 mixin `Scored`，包含：
- 一个 `int` 字段 `score`，初始值为 `0`
- 一个方法 `addPoints`，接受一个 `int` 参数 `points` 并把它加到 `score` 上

声明一个类 `Player`，使用 `Scored` 且不添加任何自己的成员。

示例：
```dart
final p = Player();
p.addPoints(3);
print(p.score); // 3
```

    score += points;

class Player with Scored {}
