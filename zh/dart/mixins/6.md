# --description--

把各个部分组合起来，一个使用 mixin 的程序有三部分：`mixin` 声明、一个或多个用 `with` 混入它的类，以及调用共享成员的代码。

```dart
mixin Barker {
  String bark() => 'Woof!';
}

class Dog with Barker {}

void main() {
  print(Dog().bark()); // Woof!
}
```

在 Dart 中，顶层声明可以按任意顺序编写，但当 mixin 出现在使用它的类之前时，从上到下阅读文件会更容易。
