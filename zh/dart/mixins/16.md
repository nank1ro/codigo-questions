# --description--

叠放的 mixin 是把小的、独立的规则组合进一个类的方式。每个 mixin 覆盖同一个成员，完成自己那一部分，然后调用 `super` 把工作继续传递下去。由于调用先进入**最后**一个 mixin，`with` 列表的顺序决定了哪条规则先于哪条运行：

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` 会把每一笔存款翻倍。在 `Doubled` 之后再加一个 mixin，那个 mixin 会先拿到这笔存款，`Doubled` 之后才看到它。

# --instructions--

类 `Account` 已经写好：它有一个初始值为 `0` 的 `int` 字段 `balance`，以及一个方法 `deposit`，把它的 `int` 参数加到 `balance` 上。

声明一个作用于 `Account` 的 mixin `Audited`，包含一个初始为空的 `List<String>` 字段 `log`，覆盖 `deposit`，使它先把字符串 `'deposit '` 加上金额添加到 `log`，然后调用 `super.deposit`。

声明一个作用于 `Account` 的 mixin `Limited`，覆盖 `deposit`，使大于 `100` 的金额被忽略，其他任何金额都传递给 `super.deposit`。

声明一个类 `SafeAccount`，继承 `Account` 并使用这两个 mixin，使被拒绝的存款永远不会进入日志。

示例：
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
