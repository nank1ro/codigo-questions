# --description--

一旦使用这个值，区别就会显现。在 `Box<int?>` 上你可以正常访问字段，然后再处理其中的 `null`；而在 `Box<int>?` 上，你必须先越过“盒子缺失”这一关：

```dart
Box<int?> a = Box(null);
print(a.value ?? 0); // 0，盒子是存在的，其内容是 null

Box<int>? b = null;
print(b?.value ?? 0); // 0，盒子本身就不存在
```

在 `Box<int>?` 上写 `b.value` 根本无法编译：Dart 拒绝读取可能不存在的东西的字段。

# --instructions--

给定 `Box<int?> a = Box(null);` 和 `Box<int>? b = null;`，哪个说法是正确的？

# --answers--

- `a` 是一个真实的盒子，其 `value` 是 `null`，而 `b` 根本不是盒子
- 两个声明的含义相同，`?` 写在哪一边都可以
- `a` 无法编译，因为类型实参绝不能是可空的
- `b` 是一个装着 `null` 的盒子，而 `a` 根本不是盒子
