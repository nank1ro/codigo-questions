# --description--

泛型类可以像其他类一样拥有命名构造函数和**工厂构造函数**，而且类型参数在它们内部同样可用。工厂构造函数并不亲自创建对象：它运行一个函数体并返回一个实例，因此可以随意选择、复用或以任何方式构建实例。

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

类型实参写在类上，而不是构造函数名上：`Box<int>.first(...)`。在工厂内部，`<T>[]` 是一个真正的空 `List<T>`，所以工厂是为尚未知道的类型构建默认值的理想场所。

# --instructions--

声明一个泛型类 `Stack`，它有一个类型参数 `T`、一个由普通构造函数设置的 `List<T>` 类型的 `final` 字段 `items`、一个用空列表构建 `Stack` 的**工厂构造函数** `Stack.empty()`，以及一个 `T?` 类型的 getter `top`，返回最后一个元素，栈为空时返回 `null`。

示例：
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
