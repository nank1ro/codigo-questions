# --description--

`typedef` 为一个类型起一个名字，而且它可以拥有自己的类型参数。通常的理由是给一族函数类型只命名一次，而不必在每次使用时都把它完整写出来：

```dart
typedef Transform<I, O> = O Function(I input);

final Transform<String, int> length = (word) => word.length;
print(length('kiwi')); // 4
```

`Transform<String, int>` 只是 `int Function(String)` 的另一种写法，两者可以互换。收益在于可读性：声明为 `Transform<I, O> transform` 的参数说明了这个函数是做什么用的，而 `O Function(I)` 只说明了它长什么样。

泛型 typedef 和泛型函数可以自然地组合，由函数自己的类型参数填入 typedef 的类型参数。

# --instructions--

声明一个泛型 typedef `Transform`，它有两个类型参数 `I` 和 `O`，为一个接受 `I` 并返回 `O` 的函数命名。

然后编写一个泛型函数 `convertAll`，它有类型参数 `I` 和 `O`，接受一个 `List<I>` 参数 `items` 和一个 `Transform<I, O>` 参数 `transform`，返回一个 `List<O>`，按顺序包含每个转换后的条目。

示例：
```dart
print(convertAll<String, int>(['fig', 'kiwi'], (w) => w.length)); // [3, 4]
```

```dart
typedef Transform<I, O> = O Function(I input);

List<O> convertAll<I, O>(List<I> items, Transform<I, O> transform) {
  return items.map(transform).toList();
}
```
