# --description--

在泛型类内部，类型参数处处可见：在字段中、在构造函数参数中、在方法签名中以及在方法体中。它只声明一次，就在类名旁边，之后每个成员都可以使用它。

```dart
class Holder<T> {
  final T item;

  Holder(this.item);

  String describe() => 'holding $item';
}
```

创建对象时才决定类型：`Holder<String>('fig')` 使 `item` 成为 `String`，`Holder<int>(3)` 使它成为 `int`。
