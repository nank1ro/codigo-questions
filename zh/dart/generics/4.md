# --description--

你并不局限于 Dart 自带的泛型类：你也可以声明自己的泛型类。**类型参数**放在类名后面的尖括号中，从此它在类体内就是一个普通的类型：

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` 只是一个占位符。它在创建 `Box` 时被填充，可以是显式指定，也可以通过推断得出：

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>，从参数推断得出
print(a.value + 1);      // 8，编译器知道 value 是 int
```

字母本身并不重要：`T` 只是“类型”的一种约定，仅此而已。

# --instructions--

声明一个泛型类 `Box`，它有一个类型参数 `T`、一个由构造函数设置的 `T` 类型的 `final` 字段 `value`，以及一个 getter `label`，返回文本 `Box of ` 再加上该值。

示例：
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` 的 `value` 应该是 `7`，`label` 应该是 `'Box of 7'`

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` 应该能用于任何类型，所以 `Box<String>('fig')` 也应该是一个 `Box<String>`

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

类型实参应该从构造函数的参数推断得出

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
