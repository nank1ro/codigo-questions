# --description--

让两个 future 同时运行并不一定需要 `Future.wait`。`async` 函数在被**调用**时就开始运行，直到它的第一个 `await`；你拿回的 future 就是已经在进行中的工作。所以诀窍是：**先调用，后 await**：

```dart
Future<int> pages() => Future.delayed(const Duration(milliseconds: 20), () => 300);
Future<int> words() => Future.delayed(const Duration(milliseconds: 20), () => 90000);

Future<double> average() async {
  final p = pages();          // both timers start now
  final w = words();
  return await w / await p;   // waits once, about 20 ms in total
}
```

对比 `return await words() / await pages();`，其中 `pages()` 只有在 `words()` 完成后才被调用：结果相同，时间翻倍。只要第二次调用不需要第一次的结果，就优先使用并发写法。

# --instructions--

函数 `slow(value)` 返回一个 `Future<int>`，在短暂延迟后以 `value` 完成，并在被调用时把 `start <value>`、完成时把 `end <value>` 记录到列表 `calls` 中。编写一个 `async` 函数 `addConcurrently`，它接收两个 `int` `a` 和 `b`，调用 `slow(a)` 和 `slow(b)` 使两者**同时**运行，并返回一个 `Future<int>`，以两个结果之和完成。

示例：
```dart
print(await addConcurrently(2, 3)); // 5
print(calls); // [start 2, start 3, end 2, end 3]
```

# --before-seed--

```dart
final calls = <String>[];

Future<int> slow(int value) async {
  calls.add('start $value');
  await Future.delayed(const Duration(milliseconds: 5));
  calls.add('end $value');
  return value;
}
```

```dart
Future<int> addConcurrently(int a, int b) async {
  final first = slow(a);
  final second = slow(b);
  return await first + await second;
}
```
