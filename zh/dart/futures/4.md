# --description--

把 future 的两个方向记清楚：

- `async` 函数**声明** `Future<T>` 而**返回**普通的 `T`：包装是自动的
- 对 `Future<T>` 使用 `await` 的调用方**收到**普通的 `T`：拆包是自动的

```dart
Future<int> count() async {
  return 3;                 // int，被包装进 Future<int>
}

Future<void> main() async {
  int n = await count();    // Future<int>，解包为 int
  Future<int> f = count();  // 没有 await：仍然是 Future<int>
}
```

写成 `int count() async` 是错误的：`async` 函数必须声明 `Future`（或 `void`）返回类型。
