# --description--

因为 `await` 把 future 的错误变成了普通异常，所有常见的 `try`/`catch` 写法都适用于异步代码，包括重试循环。在 `catch` 块里，**`rethrow`** 会再次抛出同一个错误，这就是在最后一次尝试之后放弃的方式：

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

像 `Future<String> Function() task` 这样的函数类型参数接收的是**函数**本身，而不是一个 future：每次调用 `task()` 都会开始一次新的尝试。

# --instructions--

编写一个 `async` 函数 `retry`，它接收一个 `Future<int> Function()` `task` 和一个 `int` `attempts`，返回一个 `Future<int>`。调用 `task()` 并以它的值完成；如果它抛出异常，就再试一次，总共最多调用 `task` `attempts` 次。如果最后一次尝试也失败，就用 `rethrow` 重新抛出它的错误。

示例：
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

对于总是成功的任务，`retry` 应该在一次调用后以它的值完成

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

对于失败两次然后返回 `7` 的任务，`retry` 应该在 `3` 次调用后以 `7` 完成

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

对于总是失败的任务，`retry` 应该恰好调用它 `attempts` 次，然后以同样的错误失败

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
