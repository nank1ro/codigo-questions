# --description--

`.update(key, update)` 方法会替换已有键的值。第二个参数是一个函数，它接收当前值并返回新值。如果键不存在，`.update()` 会抛出错误，除非你传入一个生成初始值的 `ifAbsent` 函数：

```dart
var stock = {'apple': 3};
stock.update('apple', (n) => n + 1); // apple becomes 4
stock.update('kiwi', (n) => n + 1, ifAbsent: () => 1); // kiwi is added with 1
print(stock); // {apple: 4, kiwi: 1}
```

# --instructions--

给定 map `stock`，使用 `.update()` 将 `'apple'` 的值翻倍，然后对键 `'kiwi'` 使用带 `ifAbsent` 的 `.update()`，使其以值 `5` 被添加进去。
