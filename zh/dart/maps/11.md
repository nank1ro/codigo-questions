# --description--

`.forEach()` 方法会对每一对键值对执行一次函数。该函数接收两个参数：键和值：

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
