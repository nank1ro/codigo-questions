# --description--

map 不是 `Iterable`，所以不能直接用 `for-in` 遍历它。你需要遍历 `.entries`：每个元素都是一个 `MapEntry`，拥有 `.key` 和 `.value`：

```dart
var ages = {'Ann': 30, 'Bob': 25};
for (var entry in ages.entries) {
  print('${entry.key}: ${entry.value}');
}
// Ann: 30
// Bob: 25
```
