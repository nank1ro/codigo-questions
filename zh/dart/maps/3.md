# --description--

使用 `map[key] = value` 赋值：如果键还不在 map 中，就**添加**一个新的键值对；如果键已存在，就**更新**该键对应的值：

```dart
var ages = {'Ann': 30};
ages['Bob'] = 25; // adds Bob
ages['Ann'] = 31; // updates Ann
print(ages); // {Ann: 31, Bob: 25}
```

新的键会添加在已有键之后，所以 map 会记住插入顺序。
