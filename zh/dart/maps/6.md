# --description--

读取不存在的键永远不会抛出异常，所以要始终考虑查找可能得到 `null`。一种安全的做法是用 `??` 运算符提供一个回退值：

```dart
var ages = {'Ann': 30};
int age = ages['Zed'] ?? 0;
print(age); // 0
```

# --instructions--

以下代码会打印什么？

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Zed']);
```

# --answers--

- `null`
- `0`
- 抛出错误
- 空字符串
