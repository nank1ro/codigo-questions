# --description--

空的 map 字面量 `{}` 没有可供推断类型的键值对，所以要用 `<K, V>{}` 或类型注解显式指定类型：

```dart
var cart = <String, int>{};
Map<String, int> other = {};
```

当 map 没有任何键值对时，`.isEmpty` 属性为 `true`；当它至少有一对时，`.isNotEmpty` 为 `true`：

```dart
print(cart.isEmpty); // true
cart['pen'] = 2;
print(cart.isNotEmpty); // true
```
