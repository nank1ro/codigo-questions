# --description--

读取值时，你在方括号中使用键，就像列表中的索引一样：

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Ann']); // 30
```

如果键不在 map 中，查找**不会**抛出错误：它会返回 `null`。因此 `ages['Ann']` 的类型是 `int?`（可为空的 `int`），而不是 `int`：

```dart
print(ages['Zed']); // null
```
