# --description--

`.remove(key)` 方法从 map 中删除一个键及其值。它返回被删除的值，如果键不存在则返回 `null`：

```dart
var ages = {'Ann': 30, 'Bob': 25};
int? removed = ages.remove('Ann');
print(removed); // 30
print(ages); // {Bob: 25}
```

`.length` 属性返回键值对的数量：

```dart
print(ages.length); // 1
```
