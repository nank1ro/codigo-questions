# --description--

`.putIfAbsent(key, ifAbsent)` 方法**仅当**键还不在 map 中时才添加一对键值对。第二个参数是一个生成值的函数。如果键已经存在，map 保持不变。两种情况下都会返回该键当前存储的值：

```dart
var ages = {'Ann': 30};
ages.putIfAbsent('Ann', () => 99); // Ann is already there, nothing changes
ages.putIfAbsent('Bob', () => 25); // Bob is added
print(ages); // {Ann: 30, Bob: 25}
```

# --instructions--

给定 map `ages`，调用两次 `.putIfAbsent()`：先对键 `'Ann'` 使用值 `99`，再对键 `'Bob'` 使用值 `25`。
