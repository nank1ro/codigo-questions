# --description--

**集合**（`Set`）是由**唯一**值组成的集合：同一个值最多只能出现一次。和 map 一样，集合使用 `{}` 字面量语法创建，但它包含的是普通值而不是 `key: value` 对：

```dart
Set<int> numbers = {1, 2, 3};
print(numbers); // {1, 2, 3}
```

类型注解 `Set<int>` 告诉 Dart 每个元素都是 `int` 类型。和列表、map 一样，`var` 会根据字面量推断类型：

```dart
var colors = {'red', 'green'}; // Set<String>
```
