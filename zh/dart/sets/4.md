# --description--

`.remove(value)` 方法从集合中删除一个值。如果该值存在则返回 `true`，否则返回 `false`：

```dart
var numbers = {1, 2, 3};
print(numbers.remove(2)); // true
print(numbers.remove(9)); // false
print(numbers); // {1, 3}
```

要一次删除所有元素，使用 `.clear()`。
