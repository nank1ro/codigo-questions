# --description--

Dart 中默认的集合会记住**插入顺序**：当你打印或遍历它时，元素会按照它们首次被添加的顺序出现。添加一个已经存在的值不会改变它的位置：

```dart
var numbers = {3, 1, 3, 2};
print(numbers); // {3, 1, 2}
```

# --instructions--

以下代码会打印什么？

```dart
var numbers = {1, 2, 2, 3, 1};
print(numbers.length);
```

- `2`
