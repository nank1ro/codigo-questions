# --description--

集合永远不会存储同一个值两次。如果字面量中有重复项，只会保留第一次出现的值，其余的会在运行时被丢弃，且不会报错（分析器会对重复值的字面量发出警告）：

```dart
var letters = {'a', 'b', 'a', 'b', 'c'};
print(letters); // {a, b, c}
```

`.length` 属性返回集合中**唯一**元素的数量：

```dart
print(letters.length); // 3
```
