# --description--

集合支持经典的集合运算。每个运算都会返回一个**新**集合，并保持原集合不变：

- `a.union(b)` 包含在 `a` **或** `b` 中的元素
- `a.intersection(b)` 包含**同时**在 `a` 和 `b` 中的元素
- `a.difference(b)` 包含 `a` 中**不在** `b` 中的元素

```dart
var a = {1, 2, 3};
var b = {2, 3, 4};
print(a.union(b));        // {1, 2, 3, 4}
print(a.intersection(b)); // {2, 3}
print(a.difference(b));   // {1}
```

# --instructions--

给定集合 `a` 和 `b`，创建一个名为 `both` 的集合表示它们的并集，一个名为 `common` 的集合表示它们的交集，以及一个名为 `onlyA` 的集合表示 `a` 中不在 `b` 中的元素。
