# --description--

Object patterns have a rest too, and there it collects every key the pattern did not mention into a new object:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// prints { name: 'Ada', city: 'London' }
```
This is the shortest way to build a copy of an object without one of its keys: the original is never touched, and the rest object is a fresh one holding the remaining values.

# --instructions--

Write a function `withoutPassword` that returns a copy of the given object without its `password` key, leaving the original object unchanged

# --asserts--

The `password` key must be gone.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

The other keys must survive.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

Every other key must survive.

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

The original object must not be changed.

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

An object with only a password must give an empty object.

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
