# --description--

Where a key holds another object or an array, the pattern can simply keep going and describe that shape too:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Careful with what that line creates: `address: { city }` means "go into `address`", not "give me `address`", so only `city` becomes a variable. To get both, mention the key twice: `const { address, address: { city } } = user;`. Array and object patterns nest into each other freely, as in `{ tags: [first] }`.

# --instructions--

# --asserts--

A nested city must be returned.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

A different nested city must be returned.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

An empty address must give `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Other keys of the address must be ignored.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

An explicit `undefined` city must give `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
