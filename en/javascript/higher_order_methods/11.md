# --description--

A function that returns a function is also the natural way to **adapt** a callback. Suppose you have a predicate and you need its opposite for `filter`: instead of rewriting it, wrap it:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
A general `not(predicate)` would do this for any predicate: it returns a new function that calls `predicate` with the same argument and flips the result with `!`. Predicates for `filter`, `find`, `some` and `every` receive the element as their first argument, so the wrapper only needs to forward that one value.

# --asserts--

`not((n) => n % 2 === 0)(3)` must return `true`.

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)` must return `false`.

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))` must return `[1, 3]`.

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))` must return `["a", "b"]`.

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

Negating twice must give back the original answer: `not(not(isEven))(4)` must return `true`.

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not` must return a function.

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
