# --description--

Closures let a returned function keep **private state** between calls. A classic helper built this way is `once(fn)`: it returns a function that runs `fn` only the first time it is called, remembers the result, and returns that same result on every later call without running `fn` again:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
The wrapper needs two private variables: whether `fn` has already run, and the stored result. Both live in the closure, invisible to the outside world. To forward every argument of the wrapper to `fn`, declare the wrapper with a rest parameter `(...args)` and call `fn(...args)`.

# --asserts--

The wrapped function must run `fn` only once and keep returning its result.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

The arguments of the first call must be forwarded to `fn`: `once((a, b) => a + b)(2, 3)` must return `5`.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

Later calls must return the stored result even with different arguments.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` must not run again even when its result is `undefined`.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

Two wrappers of the same function must be independent.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` must return a function.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
