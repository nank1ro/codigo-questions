# --description--

`delete(key)` returns `true` when a pair was removed and `false` when the key was not there.
To remove **every** pair at once, call `clear()`:
```javascript
let cart = new Map([["pen", 2], ["ink", 1]]);
console.log(cart.delete("pen"));
// prints true
console.log(cart.delete("pen"));
// prints false
cart.clear();
console.log(cart.size);
// prints 0
```
