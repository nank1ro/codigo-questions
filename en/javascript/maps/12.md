# --description--

Like arrays, maps have a `forEach()` method that calls a function for every pair.
Be careful with the order of the parameters: the callback receives the **value first**, then the key:
```javascript
let stock = new Map([["apple", 3], ["pear", 5]]);
stock.forEach((qty, name) => {
  console.log(`${name} x${qty}`);
});
// prints apple x3
// prints pear x5
```

# --instructions--

Write a function `lowStock(stock)` that uses `forEach()` to return an array with the names of the items whose quantity is lower than `5`

# --solutions--

```javascript
function lowStock(stock) {
  let low = [];
  stock.forEach((qty, name) => {
    if (qty < 5) {
      low.push(name);
    }
  });
  return low;
}
```
