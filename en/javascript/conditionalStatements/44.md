# --description--

The code block of an `if` statement is the set of instructions inside the curly braces `{ }`, the part that actually runs when the condition is `true`.

# --instructions--

What is an if statement's code block?

# --answers--

- Code that runs if the condition is false
- Code that determines if a piece of code should run
- A comparison keyword
