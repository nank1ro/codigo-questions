# --description--

Putting the last pieces together gives a small tool used in almost every real application: a deadline. Build a promise that is rejected after `ms` milliseconds, race it against the real work, and whichever settles first decides the outcome:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
Returning a promise from an `async` function is fine: the promise the function gives back follows it, so the caller awaits the final value and not a promise of a promise.

# --instructions--

Write an `async` function `withTimeout` that takes a promise and a number of milliseconds `ms`, and returns the outcome of the promise if it settles within `ms`, or is rejected with `new Error("timeout")` otherwise. Use `Promise.race`

# --asserts--

A promise that is already fulfilled must give its value.

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

A promise that is rejected before the deadline must keep its own error.

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

A promise that is fast enough must give its value, not a promise.

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

A promise that is too slow must be rejected with the message `"timeout"`.

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```

async function withTimeout(promise, ms) {

    setTimeout(() => reject(new Error("timeout")), ms);
  });
  return Promise.race([promise, timer]);
}
