# --description--

The real value of a setter is that it can refuse. Between the assignment and the stored value you get a chance to check, clamp or reject what arrives:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// prints 3, the setter rejected 50
```
A getter and a setter with the same name form one property, so they cannot also be a normal field: the stored value lives under a different name, by convention the same name with a leading underscore.

# --asserts--

The getter must return the value given to the constructor.

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

The setter must accept a valid value.

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

The setter must ignore a negative value.

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

The setter must accept `0`.

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

The value must be stored in `_temperature`.

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```

```javascript
class Thermostat {
  constructor(temperature) {
    this._temperature = temperature;
  }
  get temperature() {
    return this._temperature;
  }
  set temperature(value) {
    if (value >= 0) {
      this._temperature = value;
    }
  }
}
```
