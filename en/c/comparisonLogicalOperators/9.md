# --description--

Short-circuit evaluation also skips function calls: in `0 && check()` the function `check` is never called, so any side effect it has (like updating a counter) does not happen.

# --instructions--

# --solutions--

```c
#include <stdio.h>
int calls = 0;
int check() {
    calls++;
    return 1;
}
int main() {
    int result = 0 && check();
    printf("%d %d\n", result, calls);
    return 0;
}
```
