# --description--

A `while` loop keeps running as long as its condition is non-zero, so a comparison decides when it stops:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// prints 0, 1, 2
```
Choosing between `<` and `<=` changes whether the last value is included.
