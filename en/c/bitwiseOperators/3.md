# --description--

The **XOR** operator `^` (exclusive or) keeps a `1` only where the two bits are *different*:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
A useful property follows from this: applying the same XOR twice gives back the original value.
