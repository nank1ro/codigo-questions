# --description--

Uppercase and lowercase letters are `32` positions apart in the ASCII table: `'A'` is `65` and `'a'` is `97`.
Subtracting `32` from a lowercase letter therefore gives its uppercase version, and the result can be stored back in a `char`:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Sort the lines to store the letter `'a'` in `letter`, compute its uppercase version in `upper`, and print each of them as a character followed by its code (`letter` first)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
