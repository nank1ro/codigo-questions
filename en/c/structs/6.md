# --description--

Structs can be stored in an array like any other type. Each element is initialised with its own braces, and a loop visits them one by one, indexing first and then using the dot:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

# --instructions--

Sort the lines to define the `Point` type, store three points in `path`, add up their `x` members in `sum` and print it. Declare `path` before `sum`

typedef struct { int x; int y; } Point;

int sum = 0;
