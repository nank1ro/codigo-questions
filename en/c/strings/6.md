# --description--

An array cannot be assigned with `=` after its declaration:
```c
char copy[20];
copy = "Codigo"; // error
```
To copy a string use `strcpy(destination, source)` from `string.h`.
The destination must be large enough to hold all the characters plus the `'\0'`.

# --instructions--

Sort the lines to copy `source` into `copy` and print it. Declare `source` before `copy`

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
