# --description--

When every case of a `switch` handles one constant, remember the `break` after each one, otherwise execution falls through to the next case.
A `default` case is not required if you cover every constant of the enumeration.

# --instructions--

Sort the lines to declare `enum Size`, store `MEDIUM` in `size` and print `Medium` with a `switch`. Keep the cases in the same order as the constants in the declaration

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
