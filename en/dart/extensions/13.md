# --description--

A generic extension can take **functions** as parameters, exactly like `where` and `map` do. The function type is written with the element type `T`, so the callback receives elements of the right type:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

Complete the extension so that `countWhere` returns how many elements satisfy the given `test` function, so that the program prints `2` and then `1`.

extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
