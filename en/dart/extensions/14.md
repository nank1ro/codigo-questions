# --instructions--

The class `Temperature` is given. Write an extension named `Conversions` on `Temperature` with:
- a getter `fahrenheit` of type `double`, equal to `celsius * 9 / 5 + 32`
- a method `isAbove` that takes a `double` parameter `limit` and returns `true` when `celsius` is greater than `limit`

Example:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

```dart
extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
```
