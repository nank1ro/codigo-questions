# --instructions--

Write an extension named `Words` on `String` with:
- a getter `wordCount` of type `int`, the number of words in the string, where words are separated by a single space
- a getter `initials` of type `String`, made of the first character of each word in uppercase, joined without separators

The string always contains at least one word and never has leading, trailing or double spaces.

Example:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
