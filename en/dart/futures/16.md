# --description--

Because `await` turns future errors into ordinary exceptions, all the usual `try`/`catch` patterns apply to asynchronous code, including loops that retry. Inside a `catch` block, **`rethrow`** throws the same error again, which is how you give up after the last attempt:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

A function-typed parameter such as `Future<String> Function() task` receives the **function** itself, not a future: each `task()` call starts a fresh attempt.

# --instructions--

Write an `async` function `retry` that takes a `Future<int> Function()` `task` and an `int` `attempts`, and returns a `Future<int>`. Call `task()` and complete with its value; if it throws, try again, calling `task` at most `attempts` times in total. If the last attempt also fails, `rethrow` its error.

Example:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` of a task that always succeeds should complete with its value after a single call

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` of a task that fails twice and then returns `7` should complete with `7` after `3` calls

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` of a task that always fails should call it exactly `attempts` times and then fail with the same error

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
