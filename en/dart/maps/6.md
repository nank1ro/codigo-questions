# --description--

Reading a missing key never throws, so always consider that a lookup can give you `null`. A safe pattern is to provide a fallback with the `??` operator:

```dart
var ages = {'Ann': 30};
int age = ages['Zed'] ?? 0;
print(age); // 0
```

# --instructions--

What does the following code print?

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Zed']);
```
