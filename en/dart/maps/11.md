# --description--

The `.forEach()` method runs a function once for every pair. The function receives two parameters: the key and the value:

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
