# --description--

A mixin is not limited to methods: it can declare **fields** too, and every object of every class using the mixin gets its own copy of them.

```dart
mixin Counter {
  int count = 0;

  void increment() {
    count++;
  }
}

class Clicker with Counter {}

void main() {
  final a = Clicker();
  final b = Clicker();
  a.increment();
  a.increment();
  print(a.count); // 2
  print(b.count); // 0, b has its own count
}
```

This is what makes a mixin more than an interface: it brings both the data and the code that works on it.

# --instructions--

Declare a mixin `Scored` with:
- an `int` field `score` that starts at `0`
- a method `addPoints` that takes an `int` `points` and adds it to `score`

Declare a class `Player` that uses `Scored` and adds nothing of its own.

Example:
```dart
final p = Player();
p.addPoints(3);
print(p.score); // 3
```
