# --description--

Every stream eventually ends. For an `async*` generator, the stream is **done** as soon as the function body finishes, whether it reached the end or hit a `return`. An `await for` loop over a done stream exits, and any `toList()` future completes.

A stream does not restart or repeat its values: once it is done, it stays done.

# --instructions--

What happens to the stream returned by an `async*` function when the function body finishes?

# --answers--

- The stream is done, and an `await for` loop over it ends
- The stream starts again from the first `yield`
- The stream stays open until `close()` is called on it
- The last yielded value is emitted one more time
