# --instructions--

Write a function `sumUntilError` that takes a `Stream<int>` `source` and returns a `Future<int>` completing with the sum of its values. If the stream emits an error, stop and complete with the sum of the values received **before** the error, instead of throwing.

Example:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
