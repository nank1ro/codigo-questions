# --description--

A generic class can have named and **factory** constructors like any other class, and the type parameter is available inside them. A factory constructor does not create the object itself: it runs a body and returns one, which lets it choose, reuse or build the instance in any way it likes.

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

The type argument goes on the class, not on the constructor name: `Box<int>.first(...)`. Inside the factory, `<T>[]` is a real empty `List<T>`, so a factory is the natural place to build a default value for a type you do not know yet.

# --instructions--

Declare a generic class `Stack` with one type parameter `T`, a `final` field `items` of type `List<T>` set by the normal constructor, a **factory** constructor `Stack.empty()` that builds a `Stack` with an empty list, and a getter `top` of type `T?` returning the last element, or `null` when the stack is empty.

Example:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

`Stack.empty()` should build an empty stack of the right type, whose `top` is `null`

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
```

# --solutions--

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
