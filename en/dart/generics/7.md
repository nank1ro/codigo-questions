# --description--

A class can declare more than one type parameter, separated by commas. `Map<K, V>` is the built-in example: one type for the keys, one for the values.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

The **order** is part of the type: `Entry<String, int>` and `Entry<int, String>` are unrelated types, and a value of one cannot be assigned to the other. Type parameters can also be reordered in a return type, which is how a method can hand back a flipped version of the object:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

Declare a generic class `Pair` with two type parameters `A` and `B`, a `final` field `first` of type `A` and a `final` field `second` of type `B`, both set by the constructor, and a getter `swapped` that returns a `Pair<B, A>` holding the same two values in the opposite order.

Example:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

`Pair<String, int>('age', 30)` should have `first` `'age'` and `second` `30`

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` should return a `Pair<int, String>` with the values exchanged

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` should work with any two types, and swapping twice should give the original values back

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
    expect(pair.swapped.second, true, reason: '--err-t3--');
    expect(pair.swapped.swapped, isA<Pair<bool, String>>(), reason: '--err-t3--');
    expect(pair.swapped.swapped.first, true, reason: '--err-t3--');
  });
```

class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
