# --description--

Collecting a whole series of messages follows one recipe: an empty list before the loop, one `add` per real message, and `close()` on the signal that ends the stream. Once the port is closed the `await for` finishes and the function can return:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

Messages keep the order in which they were sent, so the list you build mirrors the work of the other isolate step by step.

# --instructions--

Write a top-level function `sendWords` that takes a `List<Object>` `message` where element `0` is a `SendPort` and element `1` is a `List<String>`: send every word to the port, then send `null` to signal the end.

Then write a function `collectWords` that takes a `List<String>` `words` and returns a `Future<List<String>>` completing with all the words received from a spawned `sendWords` isolate.

Example:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
