# --instructions--

Given `enum Size { small, medium, large }`, what happens with the following code?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- It does not compile: a `switch` expression over an enum must cover every value
- It compiles and returns `null` for `Size.large`
- It compiles and throws an exception at runtime for `Size.large`
- It compiles and returns `'L'` for `Size.large` automatically
