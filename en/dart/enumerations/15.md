# --description--

Enum values make excellent **map keys**: they are unique, easy to compare and the compiler checks that you only use real values. Declare the map with the enum as the key type and look values up with `[]`:

```dart
enum Direction { north, south, east, west }

Map<Direction, String> arrows = {
  Direction.north: '^',
  Direction.south: 'v',
  Direction.east: '>',
  Direction.west: '<',
};

print(arrows[Direction.east]); // >
```

As with any map, a lookup returns `null` when the key is missing, so use `??` to provide a fallback.

# --instructions--

Given `enum Size { small, medium, large }`, declare a top-level `Map<Size, int>` called `prices` where `small` costs `2`, `medium` costs `3` and `large` costs `4`. Then write a function `totalPrice(List<Size> order)` that returns the sum of the prices of every size in `order`.

# --solutions--

```dart
enum Size { small, medium, large }

Map<Size, int> prices = {
  Size.small: 2,
  Size.medium: 3,
  Size.large: 4,
};

int totalPrice(List<Size> order) {
  int total = 0;
  for (var size in order) {
    total += prices[size] ?? 0;
  }
  return total;
}
```
