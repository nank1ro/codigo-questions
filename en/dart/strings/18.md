# --description--

String methods return strings, so they can be **chained** one after the other. Combined with `.split('')`, the list property `.reversed` and `.join()`, this lets you reverse a string in a single expression:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

A **palindrome** is a text that reads the same forwards and backwards, like `level`.

# --instructions--

Write a function `isPalindrome` that takes a `String` parameter `text` and returns `true` if it is a palindrome, ignoring letter case and spaces, or `false` otherwise.

Example:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
