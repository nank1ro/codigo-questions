# --description--

Functions that take and return other functions can be combined freely. A classic example is **composition**: building a new function that runs one function and then feeds its result into another:

```dart
int Function(int) then(int Function(int) first, int Function(int) second) {
  return (n) => second(first(n));
}
```

# --instructions--

Write a function `compose` that takes two parameters `f` and `g`, both of type `int Function(int)`, and returns a function of type `int Function(int)` that applies `f` to its argument and then `g` to the result.

Example:
```dart
var addThenDouble = compose((n) => n + 1, (n) => n * 2);
print(addThenDouble(3)); // 8
```
