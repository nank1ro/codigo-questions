# --solutions--

```dart
var words = ['sun', 'moon', 'sun', 'star', 'moon', 'sun'];
var seen = <String>{};
var duplicates = <String>{};
for (var word in words) {
  if (!seen.add(word)) {
    duplicates.add(word);
  }
}
```
