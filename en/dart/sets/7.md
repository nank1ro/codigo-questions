# --description--

A set is an `Iterable`, so you can loop over its elements directly with `for-in`, just like a list. There are no indexes: the elements are visited in insertion order:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
