# --description--

The `.isEmpty` property is `true` when a list has no elements, and `.isNotEmpty` is `true` when it has at least one.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
