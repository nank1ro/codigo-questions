# --description--

Building a long string piece by piece with `+` creates a new string at every step. A `StringBuilder` is a mutable text buffer made for this job: `append` adds text to the end (and returns the builder, so calls can be chained) and `toString()` gives the final `String`:
```kotlin
val sb = StringBuilder()
sb.append("Hello")
sb.append(", ").append("world")
println(sb.toString()) // Hello, world
```
`append` accepts strings, characters and numbers.

# --instructions--

Write a function `initials(fullName: String): String` that splits `fullName` on spaces and returns the first character of every word, joined together.

Example: `initials("Ada Lovelace")` returns `"AL"`.

```kotlin
fun initials(fullName: String): String {
    val sb = StringBuilder()
    for (word in fullName.split(" ")) {
        sb.append(word[0])
    }
    return sb.toString()
}
```
