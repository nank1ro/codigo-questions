# --description--

`uppercase()` returns a copy of the string with every letter in upper case, `lowercase()` does the opposite.
The original string is not modified:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
