# --description--

To check whether a key exists use `containsKey` or the `in` operator; to check whether a value exists use `containsValue`:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
println(ages.containsKey("Alice")) // true
println("Zoe" in ages)             // false
println(ages.containsValue(25))    // true
```

# --instructions--

Given a map of usernames to email addresses, write two functions:
- `isRegistered(users: Map<String, String>, username: String): Boolean` that returns `true` if `username` is a key of the map
- `isEmailTaken(users: Map<String, String>, email: String): Boolean` that returns `true` if `email` is one of the values

# --solutions--

```kotlin
fun isRegistered(users: Map<String, String>, username: String): Boolean {
    return users.containsKey(username)
}

fun isEmailTaken(users: Map<String, String>, email: String): Boolean {
    return users.containsValue(email)
}
```
