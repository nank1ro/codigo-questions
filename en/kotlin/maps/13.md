# --instructions--

What is the difference between `mapOf` and `mutableMapOf`?

# --answers--

- `mutableMapOf` creates a map whose entries can be added, updated or removed after creation, `mapOf` creates a read-only map
- `mapOf` can only store `String` keys, `mutableMapOf` accepts any key type
- `mutableMapOf` allows duplicate keys, `mapOf` does not
- There is no difference, they are two names for the same function
