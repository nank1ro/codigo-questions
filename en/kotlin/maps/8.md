# --description--

You can loop over a map with `for`, destructuring each entry into its key and value:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
The parentheses `(name, age)` split every entry into two variables. Entries are visited in insertion order.

# --instructions--

Write a function `report(stock: Map<String, Int>): List<String>` that returns a list with one string per entry, formatted as `"item: count"`, in the order the entries appear in the map.

Example of function call:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
