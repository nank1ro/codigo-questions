# --instructions--

What happens with this program?

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- It prints `moving`, because `Robot` inherits the default implementation
- It does not compile: `Robot` must override `move()`
- It does not compile: an interface cannot contain a function body
- It prints `null`
