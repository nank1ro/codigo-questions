# --instructions--

What happens with this code?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- It does not compile: a nested class cannot see the outer members, `Nested` must be `inner`
- It compiles, and `show()` returns the `name` of the outer instance
- It compiles, and `show()` always returns an empty string
- It does not compile: Kotlin does not allow a class inside another class
