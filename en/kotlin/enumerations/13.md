# --instructions--

Given `enum class Color { RED, GREEN, BLUE }`, what does `Color.valueOf("PURPLE")` do?

# --answers--

- It throws an `IllegalArgumentException`, because no entry is named `PURPLE`
- It returns `null`
- It returns `Color.RED`, the first entry
- It adds a new `PURPLE` entry to the enum
