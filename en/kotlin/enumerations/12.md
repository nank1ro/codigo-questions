# --instructions--

Given `enum class Size { SMALL, MEDIUM, LARGE }`, what happens with the following code?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- It does not compile: a `when` expression over an enum must cover every entry or add an `else` branch
- It compiles and returns `null` for `LARGE`
- It compiles and throws an exception at runtime for `LARGE`
- It compiles and returns `"L"` for `LARGE` automatically
