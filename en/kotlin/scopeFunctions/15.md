# --instructions--

What does this program print?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, because `apply` returns the list and `run` returns the block's result
- `true 2`, because `apply` returns the result of `add`
- `[a, b] [a, b]`, because both return the list
- `2 [a, b]`, because `apply` returns the size and `run` returns the list
