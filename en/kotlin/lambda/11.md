# --description--

A returned lambda can capture a `var` declared inside the function. That variable lives on after the function has returned, and only the lambda can reach it: it is private state.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Every call of `makeGreeter()` declares a fresh `calls`, so two greeters count independently.

# --instructions--

Write a function `makeCounter(): () -> Int` that returns a lambda with no parameters. Each call of the lambda increases a counter that starts at `0` and returns the new value. Counters returned by different calls of `makeCounter` must be independent.

Example: `val next = makeCounter()`, then `next()` returns `1`, `next()` returns `2`.

# --asserts--

The first call of a counter must return `1`

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

The second call of the same counter must return `2`

```kotlin
    tryCatch(first() == 2)
```

After three calls a counter must return `3`

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

Two counters must be independent

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
