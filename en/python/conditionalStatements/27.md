# --description--

Only the indented `print` right after the `if` belongs to its block; a line written at the same indentation as the `if` itself does not.

# --instructions--

Which print statement is part of the statement's code block?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)

# --solutions--

- print("Hello User!")
