# --description--

You already know that `+` joins two strings together (**concatenation**).
The `*` operator **repeats** a string a given number of times:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
Repetition is a quick way to draw separators and simple patterns.
