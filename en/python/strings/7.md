# --description--

The `in` operator checks whether a string **contains** another one.
It returns `True` or `False`, so it fits naturally inside an `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` does the opposite check.
