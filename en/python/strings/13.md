# --description--

`find(sub)` returns the **index** of the first occurrence of `sub`, or `-1` if it is not found:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` returns **how many times** `sub` appears:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

Store in `position` the index of the first `o` in `text`, in `missing` the result of searching `z`, and in `total` how many `o` the text contains
