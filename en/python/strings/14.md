# --description--

`startswith(prefix)` and `endswith(suffix)` return `True` or `False` depending on how the string begins or ends:
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
They are the usual way to check file extensions, protocols or prefixes.

# --instructions--

Write a function `is_python_file(name)` that returns `True` if `name` ends with `.py`, and a function `is_comment(line)` that returns `True` if `line` starts with `#`

# --solutions--

```python
def is_python_file(name):
    return name.endswith(".py")

def is_comment(line):
    return line.startswith("#")
```
