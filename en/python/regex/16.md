# --instructions--

Define a compiled pattern `PAIR_RE` that matches a setting written as one or more letters, an `=` sign and one or more digits, with the two parts in named groups `key` and `value`; then write a function `parse_settings(text)` that returns a dictionary mapping every key found in the text to its value as an `int`

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
