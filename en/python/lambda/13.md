# --description--

`max()` and `min()` accept a `key` function too, just like `sorted()`:
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

# --instructions--

Sort the items to print the names in alphabetical order ignoring the case, and then the longest name

# --answers--

```python
names = ["bob", "Alice", "Charlie"]
```

```python
ordered = sorted(names, key=lambda s: s.lower())
```

```python
longest = max(ordered, key=lambda s: len(s))
```

