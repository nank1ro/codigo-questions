# --description--

`map()` applies a function to **every item** of a list.
It returns a special _map object_, so wrap it in `list()` to see the values:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
