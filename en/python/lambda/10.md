# --description--

`filter()` keeps only the items for which the function returns `True`:
```python
nums = [5, 12, 8, 20]
big = list(filter(lambda n: n > 10, nums))
print(big)  # [12, 20]
```

# --solutions--

```python
nums = [1, 2, 3, 4]
evens = list(filter(lambda n: n % 2 == 0, nums))
print(evens)
```
