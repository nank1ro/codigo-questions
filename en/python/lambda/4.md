# --description--

Because the body must be a single expression, a lambda **cannot contain statements**.
No `return`, no `if` blocks, no loops, no assignments:
```python
# SyntaxError
increment = lambda x: return x + 1
```
If you need any of those, write a normal `def` function instead.

# --instructions--

What's the __issue__ with this code snippet?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- A lambda body is an expression, it cannot contain return
- A lambda cannot be stored in a variable
- A lambda cannot be called with parentheses
- A lambda needs at least two parameters
