# --instructions--

Sort the items to keep only the words longer than three letters, convert them to upper case and print them sorted by length

# --answers--

```python
words = ["pear", "fig", "banana", "kiwi"]
```

```python
long_words = filter(lambda w: len(w) > 3, words)
```

```python
shouted = map(str.upper, long_words)
```

```python
print(sorted(shouted, key=len))
```

# --solutions--

```python
words = ["pear", "fig", "banana", "kiwi"]
long_words = filter(lambda w: len(w) > 3, words)
shouted = map(str.upper, long_words)
print(sorted(shouted, key=len))
```

# --output--

['PEAR', 'KIWI', 'BANANA']
