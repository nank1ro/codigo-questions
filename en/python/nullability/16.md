# --instructions--

Write a function `get_path` that takes a dictionary `data`, a list of `keys` and an optional `default` (`None` if not provided); it must follow the keys one level at a time and return the value found, or `default` when any key is missing, holds `None` or when a step is not a dictionary; values such as `0` and `""` must be returned as they are

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` must return `"Rome"`

    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")

    def test_2(self):

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
