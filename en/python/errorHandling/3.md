# --description--

An exception that no `except` block matches keeps travelling outwards: out of the line, out of the function that ran it, out of its caller, and so on. If nothing catches it before the top of the program, Python prints the traceback and the process ends with a non-zero exit status. The lines after the failing statement never run.

# --instructions--

What happens when this code runs?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- It prints `start`, then a traceback ending with `TypeError`, and neither `end` nor `after` is printed, because the uncaught exception stops the program
- It prints `start`, `end` and `after`, because Python skips only the failing line
- It prints `start` and `after`, because the exception stops `sizes` but the program continues
- It prints `start` and `0`, because `len(None)` is `0`
