# --instructions--

Write a function `is_vowel(ch)` that returns `True` when `ch` is exactly one character and that character is a vowel (`a`, `e`, `i`, `o`, `u`) in lower or upper case, and `False` for any other string, including the empty string

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` and `is_vowel("E")` must return `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` and `is_vowel("y")` must return `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Strings that are not a single character must return `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

# --after-asserts--

```python
if __name__ == "__main__":
    unittest.main()
```

# --solutions--

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
