# --instructions--

What does this code print?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, because `c` is another name for the same list as `a`, so appending through `c` changes `a` and makes it different from `b`
- `True True [1, 2]`, because `c = a` copies the list, so `a` is unchanged
- `True False [1, 2, 3]`, because `is` compares values and `==` compares identity
- `False False [1, 2, 3]`, because `append` creates a new list, so `c` no longer refers to `a`
