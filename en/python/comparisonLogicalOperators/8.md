# --description--

`and` and `or` do not always return `True` or `False`: they return one of their **operands**. `a and b` returns `a` if it is falsy, otherwise `b`; `a or b` returns `a` if it is truthy, otherwise `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
The result is truthy or falsy exactly when the whole expression is, which is why `if a and b:` still works. A common use is a default value: `name = user_input or "guest"`.

# --instructions--

What does this code print?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, because `or` returns the first truthy operand and `and` the first falsy one, or the last operand when there is none
- `True False True`, because logical operators always produce a boolean
- `0 3 x`, because `and` and `or` always return their first operand
- `5 3 y`, because both operators return the truthy operand
