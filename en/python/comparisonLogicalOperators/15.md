# --instructions--

Sort the items to define the `users` dictionary and the `can_login` function, which uses `name in users` to guard the lookup, then print the result for Ada with the right password and for Grace, who is not registered, producing the output `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
