# --description--

Because `if value:` already applies the truth value, comparing with `== True` or `== False` is unnecessary and can even be wrong: `2 == True` is `False`, yet `2` is truthy. Test the value itself:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Write a function `count_truthy(values)` that returns how many elements of the list `values` are truthy

# --solutions--

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
