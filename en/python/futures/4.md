# --description--

Calling a coroutine function is not enough to run it. The call only builds a coroutine object; the body runs when that object is awaited or passed to `asyncio.run`:
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python even warns about it: `RuntimeWarning: coroutine 'hello' was never awaited`. A forgotten `await` is the most common asynchronous bug: the code looks called but never executes, and any variable that should hold its result holds a coroutine object instead.

# --instructions--

What does this code print?
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- Only `main`, because `hello()` creates a coroutine object that is never awaited, so its body does not run
- `hi` then `main`, because calling a coroutine function runs it immediately
- `main` then `hi`, because the coroutine runs when `main` returns
- A `TypeError`, because a coroutine cannot be assigned to a variable
