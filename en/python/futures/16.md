# --description--

The pieces combine naturally. To run many operations concurrently, each with its own time limit, wrap every one in a small coroutine that applies `wait_for` and catches the `TimeoutError`, then `gather` the wrappers:
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])` then returns a value for each job that finished in time and `None` for each one that did not, in the original order, and the whole batch takes about `limit` seconds at most.

# --instructions--

Write a coroutine function `job(delay)` that waits `delay` seconds and returns `delay`, and a coroutine function `run_jobs(delays, limit)` that runs a `job` for every delay **concurrently**, each one limited to `limit` seconds with `asyncio.wait_for`, and returns a list with the delay of every job that finished in time and `None` for every job that timed out, in the original order

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
