# --description--

A small asynchronous program follows a fixed shape: import `asyncio`, define the coroutine functions, define a `main` coroutine that awaits them, and finally call `asyncio.run(main())` once at the end.

# --instructions--

Sort the items to build a program that starts with the import, defines `download` before `main`, runs two downloads concurrently with `asyncio.gather` and prints the results, producing the output `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

# --output--

['report.pdf', 'data.csv']
