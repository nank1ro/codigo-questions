# --description--

An exception raised inside a coroutine does not appear where the coroutine object was created: it is raised at the `await` that runs it, or by `asyncio.run` for the outermost one. `try`/`except` therefore has to wrap the **`await`**:
```python
import asyncio

async def load(path):
    await asyncio.sleep(0.01)
    if path == "":
        raise FileNotFoundError("empty path")
    return "contents"

async def safe_load(path):
    try:
        return await load(path)
    except FileNotFoundError:
        return ""

print(asyncio.run(safe_load("")))  # prints an empty line
```
An exception that nobody catches propagates through every `await` up to `asyncio.run`, which re-raises it in the synchronous code, exactly like a normal call stack.

# --instructions--

Write a coroutine function `divide(a, b)` that waits `0.01` seconds and returns `a / b`, and a coroutine function `safe_divide(a, b)` that awaits `divide(a, b)` and returns its result, or `None` if a `ZeroDivisionError` is raised

# --before-asserts--

```python
import asyncio
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`divide(10, 4)` must return `2.5`

```python
    def test_1(self):
        self.assertEqual(asyncio.run(divide(10, 4)), 2.5, "--err-t1--")
```

`divide(1, 0)` must raise a `ZeroDivisionError` when run

```python
    def test_2(self):
        with self.assertRaises(ZeroDivisionError, msg="--err-t2--"):
            asyncio.run(divide(1, 0))
```

`safe_divide(10, 2)` must return `5.0` and `safe_divide(1, 0)` must return `None`

```python
    def test_3(self):
        self.assertEqual(asyncio.run(safe_divide(10, 2)), 5.0, "--err-t3--")
        self.assertIsNone(asyncio.run(safe_divide(1, 0)), "--err-t3--")
```
