# --description--

A task keeps running whether or not someone is waiting for it. Create it early, do other work, and `await` it only at the point where its result is needed: the wait is shorter because part of the task has already run in the background. A task can also be inspected with `task.done()`, which returns `True` once it has finished.

# --instructions--

Complete the code so that `compute()` is scheduled as a task, `"waiting"` is printed while it runs, and the task is then awaited to get its value, producing the output `waiting`, `42`

# --solutions--

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```

42
