# --description--

You can loop over a **dictionary** too.
With `.items()` the `for` part unpacks each pair into two variables, a key and a value:
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
