# --description--

Curly braces **without** the `key: value` part give a **set comprehension**.
A set is an unordered collection that keeps only unique values, so duplicates disappear automatically:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```
