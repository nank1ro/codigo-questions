# --description--

The two positions of `if` are easy to mix up, so keep them apart:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else before the for: picks a value, else required
positives = [n for n in nums if n > 0]      # if after the for: filters, no else allowed
```
Putting an `else` after the filter `if` is a syntax error.

# --instructions--

What's the __issue__ with this code snippet?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- The filter `if` after the `for` cannot have an `else`: an `if-else` must go before the `for`
- A list comprehension cannot contain a condition
- `nums` contains a negative number, which is not allowed
- `else` must be replaced by `elif`
