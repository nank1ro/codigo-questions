# --description--

A comprehension can have **more than one `for`**.
They work like nested loops: the first `for` is the outer loop, the second is the inner one.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
