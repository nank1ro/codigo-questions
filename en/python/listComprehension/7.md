# --description--

Inside a comprehension you can use any variable defined before it, for example as the limit of a `range()`.

# --instructions--

Sort the items to print the multiples of 7 below `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
```
