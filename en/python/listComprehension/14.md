# --description--

The same idea works for dictionaries: a **dict comprehension** uses curly braces and a `key: value` expression:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
