# --description--

Comprehensions are great for **transforming strings**.
Call a string method on each item, or build a new string with an f-string:
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
