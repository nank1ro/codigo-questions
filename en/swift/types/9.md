# --description--

`Int(text)` succeeds only when the whole text is a valid whole number, with an optional sign:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
For decimal text use `Double(text)`, which returns a `Double?` in the same way: `Double("3.5")` is `Optional(3.5)`.

# --instructions--

Write a function `sumOfNumbers` that takes an array of `String` (omit the argument label) and returns the sum of the ones that are valid whole numbers, ignoring the others

Example of function call:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
