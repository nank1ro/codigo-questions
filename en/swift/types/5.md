# --description--

`Int(x)` doesn't round: it **truncates**, simply dropping the decimal part, so `Int(3.99)` is `3` and `Int(-3.99)` is `-3`.
To round to the nearest whole number, call `rounded()` on the `Double` first and then convert:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
Halfway values like `2.5` are rounded away from zero: `2.5` becomes `3.0` and `-2.5` becomes `-3.0`.

# --instructions--

Write a function `roundedAverage` that takes two `Int` (omit the argument labels) and returns their average rounded to the nearest whole number, as an `Int`

Example of function call:
```swift
print(roundedAverage(3, 4))
// prints 4
```

func roundedAverage(_ a: Int, _ b: Int) -> Int {
    let average = Double(a + b) / 2
    return Int(average.rounded())
}
