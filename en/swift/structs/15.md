# --description--

A struct is a type like any other, so it can be stored in an array, a dictionary or a set, and every tool you already know keeps working on it:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
Remember that the array holds *copies*: reading `items[0]` into a variable and changing it does not touch the array.

# --instructions--

Write a function `totalPrice` that takes an array of `Item` without argument label and returns the sum of the `price` of every item, or `0` when the array is empty

Example of function call:
```swift
print(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]))
// prints 10
```
