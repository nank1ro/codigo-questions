# --instructions--

Why does this code fail to compile?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` is a `let` constant, so a mutating method cannot be called on it
- `increase` must be marked `static` to change `value`
- `value` must be declared with `let`
- A struct cannot contain methods
