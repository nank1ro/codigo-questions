# --description--

A **protocol** describes what a type must have, without saying how. It is a list of requirements — properties and methods — that any type adopting it promises to provide.

You declare one with the `protocol` keyword. A property requirement is written with its type followed by a block saying how it can be accessed: `{ get }` means the type must at least let you read it.
```swift
protocol Named {
    var name: String { get }
}
```
A type **conforms** to the protocol by writing its name after a colon and providing everything the protocol asks for:
```swift
struct Cat: Named {
    var name: String
}

let cat = Cat(name: "Luna")
print(cat.name) // Luna
```
A protocol holds no data of its own: it is a contract. Every type that satisfies it can be treated the same way by the rest of your code.
