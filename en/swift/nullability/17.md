# --description--

Failable conversions pair naturally with `guard let`: convert, bail out when the result is `nil`, then work with the plain value.

# --instructions--

Complete the function so that it converts the text to an `Int` and returns its double, or `nil` when the conversion fails.
Then print the results, using `0` as the fallback value

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

# --solutions--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```

0
