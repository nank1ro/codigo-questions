# --description--

When chaining `??`, Swift evaluates from left to right and stops at the first value that is not `nil`; the last default is used only when every optional before it is `nil`.

# --instructions--

What does this code print?
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0)
```

# --answers--

- 7
- 0
- nil
- Optional(7)

# --solutions--

- 7
