# --description--

Because a string is a collection of characters, you can iterate over it with a `for`-`in` loop. Each iteration gives you one `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
A `Character` can be compared with `==` to a character literal, so counting how many times a character appears is just a loop and a counter.

# --instructions--

Write a function `occurrences` that takes a `Character` with argument label `of` and a `String` with argument label `in`, and returns how many times the character appears in the string.

Example of function call:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
