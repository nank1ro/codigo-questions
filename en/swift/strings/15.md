# --description--

Splitting on a space is the simplest way to break a sentence into words, and joining is how you rebuild text from an array.

# --instructions--

Write a function `wordCount` that takes a `String` (omit the argument label) and returns how many space-separated words it contains, and a function `slug` that takes an array of `String` (omit the argument label) and returns the words joined by `-`

Example of function call:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
