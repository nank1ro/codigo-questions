# --description--

A `String` is a collection of `Character` values. A `Character` is a single letter, digit, symbol or space, and it is written with the same double quotes as a string, so you need a type annotation to get one:
```swift
let letter: Character = "a"
let text = "abc"
print(text.count) // 3
```
Checking `isEmpty` is preferred over comparing `count` with `0`: it reads better and doesn't need to count every character.

# --instructions--

Write a function `length` that takes a `String` (omit the argument label) and returns its number of characters, and a function `hasText` that takes a `String` (omit the argument label) and returns `true` only when the string is not empty

# --solutions--

```swift
func length(_ text: String) -> Int {
    return text.count
}

func hasText(_ text: String) -> Bool {
    return !text.isEmpty
}
```
