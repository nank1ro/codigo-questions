# --description--

When a function throws, everything after the `throw` is skipped — including the line that was supposed to close the file or release the lock. `defer` solves that: it registers a block now and runs it when the current scope ends, whichever way it ends.
```swift
func load() throws {
    print("open")
    defer { print("close") }
    throw FileError.missing
}
```
The call prints `open`, then `close`, and only then does the error travel on to the caller. Had the function returned normally, `close` would still have printed — that is the point. Put the cleanup right next to the setup and stop worrying about which exit the code takes.

# --instructions--

Add a `defer` block inside `run` that appends `"cleanup"` to `log`, so it happens both when `run` returns normally and when it throws

# --seed--

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```

# --asserts--

on the successful path the log must be `start`, `done`, `cleanup`

```swift
let _ok: [String] = steps(false)
tryCatch(_ok == ["start", "done", "cleanup"])
```

on the throwing path the log must be `start`, `cleanup`, `caught`

```swift
let _bad: [String] = steps(true)
tryCatch(_bad == ["start", "cleanup", "caught"])
```

the cleanup must run on both paths

```swift
tryCatch(steps(false).contains("cleanup") && steps(true).contains("cleanup"))
```

the cleanup must run exactly once on the throwing path

```swift
let _once: [String] = steps(true)
tryCatch(_once.filter { $0 == "cleanup" }.count == 1)
```

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        defer { log.append("cleanup") }
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```
