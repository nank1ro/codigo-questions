# --description--

Closures can be stored in arrays like any other value. The element type is the function type:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Looping over such an array and calling each closure in turn builds a small **pipeline** of transformations.

# --instructions--

Write a function `pipeline` that takes an `Int` and an array of closures of type `(Int) -> Int` (omit both argument labels) and returns the result of applying every closure in order, each one to the result of the previous

Example of function call:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
