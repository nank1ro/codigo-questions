# --description--

Since `%` starts a specifier, a literal percent sign must be written as `%%`. This is how you format a percentage:
```swift
let ratio = 0.4567
print(String(format: "%.1f%%", ratio * 100)) // 45.7%
```
Multiply the ratio by `100` first, then pick the precision: `%.0f%%` for `46%`, `%.1f%%` for `45.7%`.

# --instructions--

Write a function `percent` that takes a part and a total (both `Double`, without argument labels) and returns the part as a percentage of the total with one decimal, followed by `%`

Example of function call:
```swift
print(percent(9, 20))
// prints 45.0%
```
