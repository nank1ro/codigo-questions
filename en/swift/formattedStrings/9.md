# --description--

To insert a `String` into a format string, use the specifier `%@`:
```swift
let name = "Ada"
let age = 36
print(String(format: "%@ is %d years old", name, age)) // Ada is 36 years old
```
`%@` accepts a Swift `String` directly. Do not use `%s` with a Swift string: that specifier expects a C string and prints garbage or crashes.

# --instructions--

Write a function `greeting` that takes a name (`String`) and an age (`Int`), both without argument labels, and returns `<name> is <age> years old` using `String(format:)` with `%@` and `%d`

Example of function call:
```swift
print(greeting("Ada", 36))
// prints Ada is 36 years old
```
