# --description--

Width flags only work inside `String(format:)`. To pad a plain string yourself, build the spaces with `String(repeating:count:)` and join them to the text:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
If the text is already longer than the width, `4 - text.count` becomes negative and `String(repeating:count:)` crashes. Guard it with `max(0, ...)`, so the count never goes below zero and long text is left as it is.

# --instructions--

Write a function `leftPad` that takes a text (`String`) and a width (`Int`), both without argument labels, and returns the text right-aligned in that width by adding spaces on the left. Text longer than the width must be returned unchanged

Example of function call:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
