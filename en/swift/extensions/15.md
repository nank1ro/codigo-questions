# --description--

Extensions can only **add** members, never replace or override existing ones. `override` belongs to subclasses, which are a different type from their parent; an extension is the same type, so declaring a method that already exists is a redeclaration error:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
If you need different behaviour, add a method with a new name, or write a subclass when the type is a class.

# --instructions--

What happens when this program is compiled and run?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- It doesn't compile, because `speak()` is declared twice for the same type
- It prints `Bark`, because the extension overrides the original method
- It prints `Woof`, because the original method wins over the extension
- It prints `Woof` and then `Bark`
