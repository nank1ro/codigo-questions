# --description--

A mutating method can take parameters like any other method, and can replace `self` entirely instead of updating it in place:
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

# --instructions--

Write an extension of `Int` with a mutating method `clamp(to max: Int)` that replaces the number with `max` when the number is greater than `max`, and leaves it unchanged otherwise

Example of method call:
```swift
var speed = 15
speed.clamp(to: 10)
print(speed)
// prints 10
```
