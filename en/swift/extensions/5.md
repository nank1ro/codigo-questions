# --description--

Computed properties in extensions are a natural fit for `String` too. The `reversed()` method returns the characters in reverse order, and `String(...)` turns them back into a string:
```swift
extension String {
    var backwards: String {
        return String(reversed())
    }
}
print("swift".backwards) // tfiws
```
As with methods, `reversed()` inside the extension means `self.reversed()`.

# --instructions--

Write an extension of `String` with a computed property `isPalindrome` of type `Bool`, that is `true` when the string reads the same forwards and backwards. The comparison is case-sensitive

Example of use:
```swift
print("level".isPalindrome)
// prints true
```
