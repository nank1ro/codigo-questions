# --description--

A pattern can hold several groups. They are numbered from left to right by their opening bracket, so the second one is `m.2`, the third `m.3`, and so on:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` always stays the whole match, whatever the number of groups.

# --instructions--

Write a function `setting` that takes a text (`String`) without argument label, finds a setting written as lowercase letters, an `=` sign and digits, and returns the name and the value joined by a colon, or `"none"` when the text holds no such setting

Example of function call:
```swift
print(setting("size=10"))
// prints size:10
```

# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
