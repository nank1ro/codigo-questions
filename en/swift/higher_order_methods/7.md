# --description--

Higher-order functions work on any array, including arrays of your own structs. Chaining `filter` and then `map` is the usual way to select some elements and extract a value from each:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
Doing it in the opposite order, `map` then `filter`, would lose the `pages` property before the check could use it.

# --instructions--

The struct `Product` is given. Write a function `cheapNames` that takes an array of `Product` (omit the argument label) and returns the names of the products whose `price` is below `10`, in the original order, chaining `filter` and `map`

Example of function call:
```swift
print(cheapNames([Product(name: "Pen", price: 2.5), Product(name: "Bag", price: 30)]))
// prints ["Pen"]
```

```swift
struct Product {
    var name: String
    var price: Double
}
func cheapNames(_ products: [Product]) -> [String] {
    return products.filter { $0.price < 10 }.map { $0.name }
}
```
