# --instructions--

Triez les lignes pour afficher un tableau avec les noms de `all` qui ne sont pas dans `done`.
Déclarez `all` avant `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
