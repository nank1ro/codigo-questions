# --description--

`new Set()` accepte n'importe quel **itérable**, pas seulement des tableaux. Une chaîne est itérable caractère par caractère, ce qui vous donne les caractères distincts d'un texte :
```javascript
let letters = new Set("hello");
console.log([...letters]);
// prints [ 'h', 'e', 'l', 'o' ]
```

Écrivez une fonction `commonLetters(a, b)` qui renvoie un tableau avec les caractères qui apparaissent dans les deux chaînes, sans doublons et dans l'ordre de leur première apparition dans `a`

```javascript
function commonLetters(a, b) {
  let lettersB = new Set(b);
  return [...new Set(a)].filter((ch) => lettersB.has(ch));
}
```
