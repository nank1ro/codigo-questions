# --description--

`for...of` et l'opérateur de spread `...` ne fonctionnent pas sur n'importe quel objet : ils fonctionnent sur les **itérables**, les objets qui fournissent une méthode stockée sous la clé spéciale `Symbol.iterator`. Donnez cette méthode à votre classe et elle rejoint le club :
```javascript
class Playlist {
    constructor(songs) {
        this.songs = songs;
    }
    *[Symbol.iterator]() {
        for (const song of this.songs) {
            yield song;
        }
    }
}
const list = new Playlist(["a", "b"]);
console.log([...list]);
// affiche [ 'a', 'b' ]
```
Le `*` devant le nom en fait un **générateur** : une fonction qui distribue les valeurs une à une avec `yield` et fait une pause entre elles. C'est la façon la plus courte de satisfaire le protocole d'itération, et cela fonctionne pour des valeurs calculées plutôt que stockées.

# --asserts--

Étendre `new Range(1, 4)` avec le spread doit donner `[1, 2, 3, 4]`.

```javascript
tryCatch(JSON.stringify([...new Range(1, 4)]) === "[1,2,3,4]");
```

`for...of` doit visiter chaque nombre de `new Range(3, 5)`.

```javascript
let _sum = 0;
for (const n of new Range(3, 5)) {
  _sum += n;
}
tryCatch(_sum === 12);
```

Une plage d'un seul nombre ne doit produire que ce nombre.

```javascript
tryCatch(JSON.stringify([...new Range(7, 7)]) === "[7]");
```

Une plage vide ne doit rien produire.

```javascript
tryCatch(JSON.stringify([...new Range(5, 2)]) === "[]");
```

# --solutions--

```javascript
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}
```
