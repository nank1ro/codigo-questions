# --description--

L'ordre compte quand des classes héritent les unes des autres. Une déclaration `class` n'est **pas** hissée comme l'est une `function` : le nom n'existe qu'à partir de la ligne où la classe est écrite. Une classe enfant doit donc apparaître *après* le parent qu'elle étend, sinon la clause `extends` échoue avec une `ReferenceError`.

# --instructions--

Triez les éléments pour obtenir un programme fonctionnel. N'oubliez pas que la classe parente doit être définie avant l'enfant

# --answers--

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
```

```javascript
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
```

```javascript
console.log(new Car().describe());
```

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
console.log(new Car().describe());
```
