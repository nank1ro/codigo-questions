# --description--

Les motifs d'objets et les valeurs par défaut se combinent exactement comme ceux des tableaux, ce qui en fait une façon élégante de lire un objet de configuration dont les clés sont présentes ou non :
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// affiche dark en
```
Puisque le motif entier ne fait qu'une instruction, une fonction peut déballer tout ce dont elle a besoin depuis son argument dès sa toute première ligne.

# --asserts--

Les deux clés présentes doivent être utilisées.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Un utilisateur différent doit donner une chaîne différente.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

Une `city` manquante doit retomber sur `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Les clés en trop doivent être ignorées.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

L'ordre des clés ne doit pas avoir d'importance.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
