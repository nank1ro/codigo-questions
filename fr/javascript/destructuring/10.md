# --description--

Là où une clé contient un autre objet ou un tableau, le motif peut simplement continuer et décrire cette forme aussi :
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Attention à ce que cette ligne crée : `address: { city }` signifie « va dans `address` », pas « donne-moi `address` », donc seul `city` devient une variable. Pour obtenir les deux, mentionnez la clé deux fois : `const { address, address: { city } } = user;`. Les motifs de tableaux et d'objets s'imbriquent librement l'un dans l'autre, comme dans `{ tags: [first] }`.

# --asserts--

Une ville imbriquée doit être renvoyée.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Une autre ville imbriquée doit être renvoyée.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Une adresse vide doit donner `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Les autres clés de l'adresse doivent être ignorées.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Une ville explicitement `undefined` doit donner `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
