# --description--

Les motifs d'objets ont aussi un rest, et là il rassemble toutes les clés que le motif n'a pas mentionnées dans un nouvel objet :
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// prints { name: 'Ada', city: 'London' }
```
C'est la façon la plus courte de construire une copie d'un objet sans une de ses clés : l'original n'est jamais touché, et l'objet rest est neuf et contient les valeurs restantes.

# --asserts--

La clé `password` doit avoir disparu.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

Les autres clés doivent survivre.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

Toutes les autres clés doivent survivre.

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

L'objet d'origine ne doit pas être modifié.

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

Un objet avec seulement un mot de passe doit donner un objet vide.

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
