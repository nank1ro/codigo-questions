# --description--

`Promise.all` abandonne dès qu'une promesse est rejetée. Quand vous voulez quand même chaque résultat, utilisez **`Promise.allSettled(promises)`** : il n'est jamais rejeté, et il est tenu avec un petit objet par promesse, dans le même ordre :

- `{ status: "fulfilled", value: ... }` pour celles qui ont réussi ;
- `{ status: "rejected", reason: ... }` pour celles qui ont échoué.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
Lisez `value` seulement quand `status` vaut `"fulfilled"`, et `reason` seulement quand il vaut `"rejected"` : l'autre propriété est simplement absente.

# --asserts--

`await countFulfilled([])` doit être `0`.

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` doit être `2`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Avec une promesse rejetée sur trois, la réponse doit être `2`.

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Quand toutes les promesses sont rejetées, la réponse doit être `0`, et `countFulfilled` ne doit pas être rejetée.

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
