# --description--

En assemblant les dernières pièces, on obtient un petit outil utilisé dans presque toutes les applications réelles : une échéance. Construisez une promesse qui est rejetée après `ms` millisecondes, faites-la courir contre le vrai travail, et celle qui se règle en premier décide de l'issue :
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
Renvoyer une promesse depuis une fonction `async` est très bien : la promesse que la fonction renvoie suit celle-ci, donc l'appelant attend la valeur finale et non une promesse de promesse.

# --asserts--

Une promesse déjà tenue doit donner sa valeur.

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

Une promesse rejetée avant l'échéance doit garder sa propre erreur.

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

Une promesse assez rapide doit donner sa valeur, pas une promesse.

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

Une promesse trop lente doit être rejetée avec le message `"timeout"`.

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```
