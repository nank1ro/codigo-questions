# --description--

Les chaînes sont **immuables** : une fois créée, une chaîne ne peut jamais être modifiée.
Assigner à un index ne fait rien, et chaque méthode de chaîne renvoie une **nouvelle** chaîne au lieu de modifier l'originale :
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
Pour conserver un résultat, réassigne-le à la variable :
```javascript
word = word.toUpperCase();
```

# --instructions--

Le premier `console.log` affiche `hello` car `toUpperCase()` n'a pas modifié `word`. Complète le code pour que le second `console.log` affiche `HELLO`
