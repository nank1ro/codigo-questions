# --description--

Chaque caractère d'une chaîne a un **index**, en commençant à `0`.
Tu peux lire un caractère unique avec des crochets ou avec la méthode `charAt()` :
```javascript
let word = "hello";
console.log(word[0]);
// prints h
console.log(word.charAt(1));
// prints e
```
Le dernier caractère se trouve à l'index `length - 1` :
```javascript
console.log(word[word.length - 1]);
// prints o
```

# --instructions--

Stocke le premier caractère de `word` dans une variable `first` et le dernier caractère dans une variable `last`
