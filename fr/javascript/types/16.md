# --description--

Le texte provenant de formulaires, de fichiers ou d'URL est toujours une chaîne, même quand il représente un nombre ou un booléen. Le reconvertir vers le bon type combine ce que vous avez vu : comparez avec `"true"` et `"false"` pour les booléens, et essayez `Number()` pour les nombres, en vous rappelant que `Number("")` vaut `0` et que `Number.isNaN` vous dit quand la conversion a échoué :
```javascript
console.log(Number("3.5"), Number(""), Number("12px"));
// prints 3.5 0 NaN
```
Quand rien ne correspond, gardez la chaîne telle quelle.

# --instructions--

Écrivez une fonction `parseValue(text)` qui renvoie `true` ou `false` quand `text` est `"true"` ou `"false"`, un nombre quand tout `text` est un nombre, et `text` inchangé dans tous les autres cas, y compris la chaîne vide

# --asserts--

`parseValue("42")` doit renvoyer le nombre `42`.

```javascript
tryCatch(parseValue("42") === 42);
```

`parseValue("3.5")` doit renvoyer `3.5`.

```javascript
tryCatch(parseValue("3.5") === 3.5);
```

`parseValue("true")` et `parseValue("false")` doivent renvoyer les booléens `true` et `false`.

```javascript
tryCatch(parseValue("true") === true && parseValue("false") === false);
```

`parseValue("Ana")` doit renvoyer `"Ana"`.

```javascript
tryCatch(parseValue("Ana") === "Ana");
```

`parseValue("12px")` doit renvoyer `"12px"`, car tout le texte n'est pas un nombre.

```javascript
tryCatch(parseValue("12px") === "12px");
```

`parseValue("")` doit renvoyer `""`, pas `0`.

```javascript
tryCatch(parseValue("") === "");
```

# --solutions--

```javascript
function parseValue(text) {
  if (text === "true") {
    return true;
  }
  if (text === "false") {
    return false;
  }
  if (text !== "" && !Number.isNaN(Number(text))) {
    return Number(text);
  }
  return text;
}
```
