# --description--

La condition d'une déclaration `if` se place toujours entre parenthèses `()`, juste après le mot-clé `if` et avant l'accolade ouvrante.

# --instructions--

Où écrivons-nous la condition de l'instruction if ?

# --answers--

- Entre les parenthèses ()
- Entre les crochets []
- Entre le mot-clé if et l'accolade ouvrante {
- Avant le mot-clé if
