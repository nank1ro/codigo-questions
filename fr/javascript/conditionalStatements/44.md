# --description--

Le bloc de code d'une déclaration `if` est l'ensemble des instructions à l'intérieur des accolades `{ }`, la partie qui s'exécute réellement quand la condition est `true`.

# --instructions--

Qu'est-ce qu'un bloc de code d'une instruction if ?

# --answers--

- Code qui s'exécute si la condition est false
- Code qui détermine si un morceau de code doit s'exécuter
- Un mot-clé de comparaison
