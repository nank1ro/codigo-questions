# --description--

Tout se rejoint dans `groupBy(items, keyFn)` : une fonction d'ordre supérieur qui reçoit un callback décidant la **clé de groupe** de chaque élément et renvoie un objet associant chaque clé au tableau des éléments ayant cette clé. `reduce` avec un accumulateur objet fait tout le travail :
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Pour chaque élément, calcule la clé, crée le tableau de cette clé s'il n'existe pas encore (`acc[key] ?? []`), ajoute l'élément et renvoie l'accumulateur. Comme l'appelant choisit `keyFn`, la même fonction regroupe des mots par initiale, des personnes par ville ou des nombres par parité.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` doit renvoyer `{ h: ["hi", "hey"], y: ["yo"] }`.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

Regrouper `[1, 2, 3, 4]` par parité doit renvoyer `{ odd: [1, 3], even: [2, 4] }`.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Regrouper des personnes par `city` doit conserver les objets entiers, dans l'ordre d'origine.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` doit renvoyer un objet vide.

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

Le tableau d'origine ne doit pas être modifié.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

La fonction doit utiliser `reduce`.


# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
