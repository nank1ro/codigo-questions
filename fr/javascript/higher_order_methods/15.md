# --description--

Les closures permettent à une fonction renvoyée de garder un **état privé** entre les appels. Un utilitaire classique construit ainsi est `once(fn)` : il renvoie une fonction qui exécute `fn` seulement la première fois qu'elle est appelée, mémorise le résultat, et renvoie ce même résultat à chaque appel suivant sans réexécuter `fn` :
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
L'enveloppe a besoin de deux variables privées : si `fn` a déjà été exécutée, et le résultat mémorisé. Toutes deux vivent dans la closure, invisibles depuis l'extérieur. Pour transmettre à `fn` tous les arguments de l'enveloppe, déclare l'enveloppe avec un paramètre du reste `(...args)` et appelle `fn(...args)`.

# --asserts--

La fonction enveloppée doit exécuter `fn` une seule fois et continuer à renvoyer son résultat.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

Les arguments du premier appel doivent être transmis à `fn` : `once((a, b) => a + b)(2, 3)` doit renvoyer `5`.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

Les appels suivants doivent renvoyer le résultat mémorisé même avec des arguments différents.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` ne doit pas être réexécutée, même quand son résultat est `undefined`.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

Deux enveloppes de la même fonction doivent être indépendantes.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` doit renvoyer une fonction.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
