# --description--

`!=` convertit avant de comparer, tout comme `==`, donc `"5" != 5` vaut `false`. Son équivalent strict `!==` considère une chaîne et un nombre comme différents quel que soit leur contenu.
```javascript
console.log("5" !== 5); // true
```
