# --description--

Toute comparaison impliquant `NaN` renvoie `false`, même les comparaisons opposées : `NaN < 3` et `NaN >= 3` valent toutes les deux `false`, donc un `<` qui échoue ne signifie pas toujours que le côté gauche est plus grand.
