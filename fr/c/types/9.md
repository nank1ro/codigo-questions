# --description--

Les lettres majuscules et minuscules sont séparées de `32` positions dans la table ASCII : `'A'` vaut `65` et `'a'` vaut `97`.
Soustraire `32` à une lettre minuscule donne donc sa version majuscule, et le résultat peut être stocké dans un `char` :
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Triez les lignes pour stocker la lettre `'a'` dans `letter`, calculer sa version majuscule dans `upper`, et afficher chacune d'elles comme un caractère suivi de son code (`letter` en premier)

# --answers--

```c
char letter = 'a';
```

```c

printf("%c %d\n", letter, letter);
```
