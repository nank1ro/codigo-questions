# --description--

Une condition littérale `false` n'est jamais vraie, donc le bloc est entièrement ignoré et rien de ce qu'il contient ne s'exécute.

# --instructions--

Qu'affiche ce code en sortie?
```c
if (false) {
    printf("Hello!\n");
}
```

# --answers--

- Hello!
- Rien car le bloc de code est ignoré
