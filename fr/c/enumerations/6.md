# --description--

Quand chaque cas d'un `switch` traite une constante, pensez au `break` après chacun, sinon l'exécution se poursuit dans le cas suivant.
Un cas `default` n'est pas nécessaire si vous couvrez toutes les constantes de l'énumération.

# --instructions--

Triez les lignes pour déclarer `enum Size`, stocker `MEDIUM` dans `size` et afficher `Medium` avec un `switch`. Gardez les cas dans le même ordre que les constantes de la déclaration

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

```c
    case SMALL: printf("Small\n"); break;
```

```c
    case MEDIUM: printf("Medium\n"); break;
```

```c
    case LARGE: printf("Large\n"); break;
```

```c
}
```

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
