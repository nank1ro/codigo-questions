# --description--

`strcat(destination, source)` ajoute `source` à la fin de `destination` :
```c
char text[20] = "Hello";
strcat(text, " World");
// text vaut maintenant "Hello World"
```
Comme avec `strcpy`, le tableau de destination doit avoir assez de place pour le résultat.
