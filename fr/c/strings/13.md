# --description--

`sprintf` fonctionne comme `printf`, mais écrit le texte formaté dans un tableau de caractères au lieu de l'écran :
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer vaut "3 items"
```
Le tampon doit être assez grand pour tout le texte et son `'\0'`.

# --instructions--

Triez les lignes pour construire le texte `Age: 25` dans `buffer` et l'afficher. Déclarez `buffer` avant `age`

# --answers--

```c
char buffer[30];
```

```c
int age = 25;
```

```c
sprintf(buffer, "Age: %d", age);
```

```c
printf("%s\n", buffer);
```
