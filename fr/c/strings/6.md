# --description--

Un tableau ne peut pas être assigné avec `=` après sa déclaration :
```c
char copy[20];
copy = "Codigo"; // erreur
```
Pour copier une chaîne, utilisez `strcpy(destination, source)` de `string.h`.
La destination doit être assez grande pour contenir tous les caractères plus le `'\0'`.

# --instructions--

Triez les lignes pour copier `source` dans `copy` et l'afficher. Déclarez `source` avant `copy`

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
