# --instructions--

La classe `Temperature` est fournie. Écrivez une extension nommée `Conversions` sur `Temperature` avec :
- un getter `fahrenheit` de type `double`, égal à `celsius * 9 / 5 + 32`
- une méthode `isAbove` qui prend un paramètre `double` `limit` et retourne `true` quand `celsius` est supérieur à `limit`

Exemple :
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
