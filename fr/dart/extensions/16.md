# --instructions--

Écrivez une extension nommée `Words` sur `String` avec :
- un getter `wordCount` de type `int`, le nombre de mots dans la chaîne, les mots étant séparés par un espace unique
- un getter `initials` de type `String`, composé du premier caractère de chaque mot en majuscule, joint sans séparateurs

La chaîne contient toujours au moins un mot et n'a jamais d'espaces de début, de fin ni doubles.

Exemple :
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
