# --description--

Un Set est un `Iterable`, vous pouvez donc parcourir directement ses éléments avec `for-in`, tout comme une liste. Il n'y a pas d'index : les éléments sont visités dans l'ordre d'insertion :

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
