# --description--

La méthode `.forEach()` exécute une fonction une fois pour chaque paire. La fonction reçoit deux paramètres : la clé et la valeur :

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
