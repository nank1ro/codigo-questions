# --description--

Vous n'êtes pas limité aux classes génériques livrées avec Dart : vous pouvez déclarer les vôtres. Un **paramètre de type** s'écrit entre chevrons après le nom de la classe, et à partir de là c'est un type normal à l'intérieur du corps :

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` n'est qu'un espace réservé. Il est rempli quand une `Box` est créée, explicitement ou par inférence :

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, inferred from the argument
print(a.value + 1);      // 8, the compiler knows value is an int
```

La lettre n'a pas d'importance : `T` est une convention pour « type », rien de plus.

# --instructions--

Déclarez une classe générique `Box` avec un paramètre de type `T`, un champ `final` `value` de type `T` défini par le constructeur, et un getter `label` qui retourne le texte `Box of ` suivi de la valeur.

Exemple :
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` devrait avoir `value` égal à `7` et `label` égal à `'Box of 7'`

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` devrait fonctionner avec n'importe quel type, donc `Box<String>('fig')` devrait aussi être une `Box<String>`

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

L'argument de type devrait être déduit de l'argument du constructeur

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
