# --description--

L'**opérateur OU** `||` combine deux expressions booléennes. Il renvoie `true` lorsqu'**au moins un** côté est `true`. Il ne renvoie `false` que lorsque **les deux** côtés sont `false`.

```dart
bool a = false;
bool b = true;
bool result = a || b; // true

bool c = false;
bool d = false;
bool result2 = c || d; // false
```
