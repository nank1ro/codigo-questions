# --instructions--

Écris une fonction `sumUntilError` qui prend un `Stream<int>` `source` et renvoie un `Future<int>` se complétant avec la somme de ses valeurs. Si le stream émet une erreur, arrête-toi et complète avec la somme des valeurs reçues **avant** l'erreur, au lieu de lever l'exception.

Exemple :
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
