# --instructions--

Avec `enum Size { small, medium, large }`, que se passe-t-il avec le code suivant ?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Il ne compile pas : une expression `switch` sur un enum doit couvrir toutes les valeurs
- Il compile et retourne `null` pour `Size.large`
- Il compile et lève une exception à l'exécution pour `Size.large`
- Il compile et retourne automatiquement `'L'` pour `Size.large`
