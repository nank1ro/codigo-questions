# --description--

Comme `await` transforme les erreurs d'un future en exceptions ordinaires, tous les motifs `try`/`catch` habituels s'appliquent au code asynchrone, y compris les boucles qui réessaient. Dans un bloc `catch`, **`rethrow`** relance la même erreur, c'est ainsi que l'on abandonne après la dernière tentative :

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Un paramètre de type fonction comme `Future<String> Function() task` reçoit la **fonction** elle-même, pas un future : chaque appel à `task()` démarre une nouvelle tentative.

# --instructions--

Écris une fonction `async` `retry` qui prend un `Future<int> Function()` `task` et un `int` `attempts`, et renvoie un `Future<int>`. Appelle `task()` et termine avec sa valeur ; si elle lève une exception, réessaie, en appelant `task` au plus `attempts` fois au total. Si la dernière tentative échoue aussi, relance son erreur avec `rethrow`.

Exemple :
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` d'une tâche qui réussit toujours devrait se terminer par sa valeur après un seul appel

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` d'une tâche qui échoue deux fois puis renvoie `7` devrait se terminer par `7` après `3` appels

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` d'une tâche qui échoue toujours devrait l'appeler exactement `attempts` fois puis échouer avec la même erreur

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
