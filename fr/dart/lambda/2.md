# --description--

Une fonction anonyme peut prendre des paramètres et `return` une valeur, exactement comme une fonction nommée. Le type de retour n'est pas écrit : Dart l'**infère** à partir des instructions `return` du corps.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
