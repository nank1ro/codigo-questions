# --description--

Une fermeture ne fait pas que lire les variables qu'elle capture : elle peut aussi les **modifier**, et les modifications sont conservées entre les appels. Cela permet de garder un état privé sans classe :

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

Chaque appel à `makeTimer()` crée une toute nouvelle variable `seconds`, donc deux minuteurs ne partagent jamais leur compteur.

# --instructions--

Écrivez une fonction `makeCounter` sans paramètres qui retourne une fonction de type `int Function()`. Chaque fois que la fonction retournée est appelée, elle doit incrémenter un compteur capturé et le retourner, en commençant à `1`.

Exemple :
```dart
var counter = makeCounter();
print(counter()); // 1
print(counter()); // 2
```
