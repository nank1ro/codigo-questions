# --description--

Les mixins empilés permettent de combiner des règles petites et indépendantes en une seule classe. Chaque mixin redéfinit le même membre, fait sa propre part et appelle `super` pour transmettre le travail. Comme l'appel entre d'abord dans le **dernier** mixin, l'ordre de la liste `with` décide quelle règle s'exécute avant laquelle :

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` double chaque dépôt. Ajoutez un second mixin après `Doubled` et il reçoit le dépôt en premier, avant même que `Doubled` le voie.

# --instructions--

La classe `Account` est déjà écrite : elle possède un champ `int` `balance` commençant à `0` et une méthode `deposit` qui ajoute son argument `int` à `balance`.

Déclarez un mixin `Audited` sur `Account` avec un champ `List<String>` `log` commençant vide, redéfinissant `deposit` pour qu'il ajoute d'abord à `log` la chaîne `'deposit '` suivie du montant, puis appelle `super.deposit`.

Déclarez un mixin `Limited` sur `Account` redéfinissant `deposit` pour qu'un montant supérieur à `100` soit ignoré, et que tout autre montant soit transmis à `super.deposit`.

Déclarez une classe `SafeAccount` qui étend `Account` et utilise les deux mixins, pour qu'un dépôt refusé n'atteigne jamais le journal.

Exemple :
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
