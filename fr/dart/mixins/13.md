# --description--

Une fois qu'un mixin a une clause `on`, il peut **redéfinir** un membre de ce type et appeler **`super`** pour atteindre la version située en dessous de lui dans la chaîne :

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log` n'est pas le `log` propre au mixin, c'est celui situé en dessous de lui, donc il n'y a pas de récursion infinie. Empilez plusieurs mixins de ce genre avec `with A, B` et chacun enveloppe le précédent : l'appel entre d'abord dans le **dernier** mixin puis descend jusqu'à la superclasse.

# --instructions--

Déclarez une classe `Pipeline` avec une méthode `run` qui prend une `String` `input` et la retourne inchangée.

Déclarez un mixin `Trimmed` sur `Pipeline` qui redéfinit `run` en passant l'entrée débarrassée de ses espaces à `super.run`, et un mixin `Upper` sur `Pipeline` qui redéfinit `run` en retournant le résultat de `super.run` en majuscules.

Déclarez une classe `TextPipeline` qui étend `Pipeline` et utilise `Trimmed` puis `Upper`, et une classe `TrimOnly` qui étend `Pipeline` et utilise uniquement `Trimmed`.

Exemple :
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

# --solutions--

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
