# --description--

Même lorsqu'un tableau est déclaré avec `val`, ses **éléments** peuvent être remplacés en assignant à un index :
```kotlin
val nums = intArrayOf(1, 2, 3)
nums[0] = 10 // nums is now [10, 2, 3]
```
Pour visiter chaque élément, vous pouvez utiliser une boucle `for` ou `forEach` :
```kotlin
for (n in nums) {
    println(n)
}
nums.forEach { println(it) }
```
Notez que `n` et `it` sont des copies en lecture seule des valeurs et ne peuvent pas être réassignées, donc pour modifier des éléments vous avez besoin de leur index.

# --asserts--

Après `doubleAll` le tableau `[1, 2, 3]` doit devenir `[2, 4, 6]`

```kotlin
    val a1 = intArrayOf(1, 2, 3)
    doubleAll(a1)
    tryCatch(a1.contentEquals(intArrayOf(2, 4, 6)))
```

Après `doubleAll` le tableau `[0, -5]` doit devenir `[0, -10]`

```kotlin
    val a2 = intArrayOf(0, -5)
    doubleAll(a2)
    tryCatch(a2.contentEquals(intArrayOf(0, -10)))
```

`doubleAll` ne doit pas échouer sur un tableau vide

```kotlin
    val a3 = intArrayOf()
    doubleAll(a3)
    tryCatch(a3.size == 0)
```

fun doubleAll(numbers: IntArray) {
    for (i in numbers.indices) {
        numbers[i] = numbers[i] * 2
    }
}
