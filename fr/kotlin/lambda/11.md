# --description--

Une lambda retournée peut capturer une variable `var` déclarée à l'intérieur de la fonction. Cette variable continue d'exister après que la fonction a retourné, et seule la lambda peut y accéder : c'est un état privé.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Chaque appel de `makeGreeter()` déclare un nouveau `calls`, ainsi deux greeters comptent indépendamment.

# --instructions--

Écrivez une fonction `makeCounter(): () -> Int` qui retourne une lambda sans paramètres. Chaque appel de la lambda augmente un compteur qui commence à `0` et retourne la nouvelle valeur. Les compteurs retournés par différents appels de `makeCounter` doivent être indépendants.

Exemple : `val next = makeCounter()`, puis `next()` retourne `1`, `next()` retourne `2`.

# --asserts--

Le premier appel d'un compteur doit retourner `1`

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

Le deuxième appel du même compteur doit retourner `2`

```kotlin
    tryCatch(first() == 2)
```

Après trois appels, un compteur doit retourner `3`

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

Deux compteurs doivent être indépendants

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
