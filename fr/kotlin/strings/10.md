# --description--

`replace(old, new)` retourne une copie de la chaîne où **chaque** occurrence de `old` est remplacée par `new` :
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
