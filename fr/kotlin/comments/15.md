# --description--

Un `FIXME` est différent d'un `TODO` : le code existe déjà, mais on sait qu'il est faux. Un bon `FIXME` dit quel est le bug et, si possible, donne un exemple qui le montre, pour que la personne suivante puisse le corriger vite. Comme pour `TODO`, supprimez le marqueur une fois le bug corrigé, mais gardez le commentaire de documentation, qui reste vrai.

# --asserts--

Le commentaire `FIXME` doit être supprimé

```json
{
  "regex": "FIXME",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

Le commentaire de documentation doit être conservé

```json
{
  "regex": "Returns the average of",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`average(4, 6)` doit renvoyer `5`

```kotlin
    tryCatch(average(4, 6) == 5)
```

`average(10, 20)` doit renvoyer `15`

```kotlin
    tryCatch(average(10, 20) == 15)
```

`average(3, 4)` doit renvoyer `3`

```kotlin
    tryCatch(average(3, 4) == 3)
```
