# --description--

L'endroit où se trouve le `try` décide de la quantité de travail qu'une seule valeur incorrecte détruit. Englobez la **boucle entière** et le premier échec abandonne le reste du lot ; englobez le **corps** et seul cet élément est perdu :

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // on ignore celle-ci
    }
}
println(total) // 8
```
Cela se marie naturellement avec une fonction de validation qui lève une exception : la fonction énonce une règle et refuse tout ce qui la viole, et la boucle décide qu'un refus ne coûte qu'un seul élément.

# --instructions--

Écrivez deux fonctions.

`validate(text: String): Int` doit retourner le nombre contenu dans `text`, ou lever une `IllegalArgumentException` avec le message `not a number: ` suivi du texte.

`sumValid(values: List<String>): Int` doit additionner les valeurs que `validate` accepte, en ignorant celles qui la font lever une exception.

Exemple d'appel de fonction :
```kotlin
println(sumValid(listOf("1", "x", "3")))
// affiche 4
```

# --solutions--

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // on ignore celle-ci
        }
    }
    return total
}
```
