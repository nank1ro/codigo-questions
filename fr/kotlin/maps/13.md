# --instructions--

Quelle est la différence entre `mapOf` et `mutableMapOf` ?

# --answers--

- `mutableMapOf` crée une map dont les entrées peuvent être ajoutées, mises à jour ou supprimées après création, `mapOf` crée une map en lecture seule
- `mapOf` ne peut stocker que des clés `String`, `mutableMapOf` accepte tout type de clé
- `mutableMapOf` autorise les clés en double, `mapOf` non
- Il n'y a pas de différence, ce sont deux noms pour la même fonction
