# --description--

Vous pouvez parcourir une map avec `for`, en déstructurant chaque entrée en sa clé et sa valeur :
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Les parenthèses `(name, age)` divisent chaque entrée en deux variables. Les entrées sont parcourues dans l'ordre d'insertion.

# --instructions--

Écrivez une fonction `report(stock: Map<String, Int>): List<String>` qui retourne une liste avec une chaîne par entrée, au format `"item: count"`, dans l'ordre où les entrées apparaissent dans la map.

Exemple d'appel de fonction :
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
