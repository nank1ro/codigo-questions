# --instructions--

Avec `enum class Size { SMALL, MEDIUM, LARGE }`, que se passe-t-il avec le code suivant ?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Il ne compile pas : une expression `when` sur un enum doit couvrir toutes les entrées ou ajouter une branche `else`
- Il compile et retourne `null` pour `LARGE`
- Il compile et lève une exception à l'exécution pour `LARGE`
- Il compile et retourne automatiquement `"L"` pour `LARGE`
