# --instructions--

Avec `enum class Color { RED, GREEN, BLUE }`, que fait `Color.valueOf("PURPLE")` ?

# --answers--

- Il lève une `IllegalArgumentException`, car aucune entrée ne s'appelle `PURPLE`
- Il retourne `null`
- Il retourne `Color.RED`, la première entrée
- Il ajoute une nouvelle entrée `PURPLE` à l'enum
