# --instructions--

Qu'affiche ce programme ?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, car `apply` retourne la liste et `run` retourne le résultat du bloc
- `true 2`, car `apply` retourne le résultat de `add`
- `[a, b] [a, b]`, car les deux retournent la liste
- `2 [a, b]`, car `apply` retourne la taille et `run` retourne la liste
