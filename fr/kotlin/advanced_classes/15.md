# --instructions--

Que se passe-t-il avec ce code ?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Il ne compile pas : une classe imbriquée ne peut pas voir les membres de la classe externe, `Nested` doit être `inner`
- Il compile, et `show()` retourne le `name` de l'instance externe
- Il compile, et `show()` retourne toujours une chaîne vide
- Il ne compile pas : Kotlin n'autorise pas une classe à l'intérieur d'une autre classe
