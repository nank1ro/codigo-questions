# --instructions--

Que se passe-t-il avec ce programme ?

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- Il affiche `moving`, car `Robot` hérite de l'implémentation par défaut
- Il ne compile pas : `Robot` doit redéfinir `move()`
- Il ne compile pas : une interface ne peut pas contenir de corps de fonction
- Il affiche `null`
