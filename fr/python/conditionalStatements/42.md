# --description--

Le bloc de code d'une déclaration `if` est le groupe de lignes indentées en dessous, distingué du reste du programme par cette indentation.

# --instructions--

Qu'est-ce qu'un bloc de code d'une déclaration if ?

# --answers--

- Du code qui s'exécute si la condition est False
- Du code qui détermine si un morceau de code doit s'exécuter
