# --description--

Le mot-clé `if` est ce qui démarre une déclaration conditionnelle — avec sa condition, il décide si le bloc ci-dessous s'exécute.

# --instructions--

Quel est le mot-clé qui décide si un bloc de code doit s'exécuter ou non ?

# --answers--

- if
- for
- when
- else
