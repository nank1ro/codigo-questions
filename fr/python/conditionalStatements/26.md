# --description--

Avec `online` défini sur `False`, la condition n'est jamais remplie, donc le bloc est ignoré et rien n'est affiché.

# --instructions--

Qu'affiche ce code en sortie ?
```python
online = False
if (online):
    print("Hello user!")
```
