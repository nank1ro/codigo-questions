# --description--

Une ligne qui se trouve en dehors de l'indentation du `if` s'exécute quelle qu'ait été la condition, puisqu'elle n'a jamais fait partie de ce bloc.

# --instructions--

Comment savons-nous que `Hello World` sera toujours imprimé ?
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- Because of its indentation
- Because the if statement can't have more than one line
- Because there isn't an else statement
- Because there isn't an elif statement
