# --description--

Une ligne qui se trouve en dehors de l'indentation du `if` s'exécute quelle qu'ait été la condition, puisqu'elle n'a jamais fait partie de ce bloc.

# --instructions--

Comment savons-nous que `Hello World` sera toujours imprimé ?
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- À cause de son indentation
- Parce que l'instruction if ne peut pas avoir plus d'une ligne
- Parce qu'il n'y a pas d'instruction else
- Parce qu'il n'y a pas d'instruction elif
