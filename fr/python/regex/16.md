# --instructions--

Définissez un motif compilé `PAIR_RE` qui correspond à un réglage écrit sous la forme d'une ou plusieurs lettres, d'un signe `=` et d'un ou plusieurs chiffres, avec les deux parties dans les groupes nommés `key` et `value` ; puis écrivez une fonction `parse_settings(text)` qui renvoie un dictionnaire associant chaque clé trouvée dans le texte à sa valeur sous forme d'`int`

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
