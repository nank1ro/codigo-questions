# --description--

Choisir le type le plus étroit qui couvre la défaillance attendue est ce qui rend la gestion des erreurs digne de confiance. Une fonction qui lit du texte doit se remettre d'un texte invalide (`ValueError`) mais ne doit pas masquer le fait d'être appelée avec le mauvais type d'argument (`TypeError`) — cette erreur appartient à l'appelant, laissez-la passer.

# --instructions--

Écrivez une fonction `parse_age(text)` qui renvoie `int(text)`, et renvoie `-1` quand `text` n'est pas un nombre entier valide. Capturez uniquement `ValueError`, pour que `parse_age(None)` lève toujours une `TypeError`

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`parse_age("30")` doit renvoyer `30`

```python
    def test_1(self):
        self.assertEqual(parse_age("30"), 30, "--err-t1--")
```

`parse_age("old")` doit renvoyer `-1`

```python
    def test_2(self):
        self.assertEqual(parse_age("old"), -1, "--err-t2--")
```

`parse_age(None)` doit toujours lever une `TypeError`

```python
    def test_3(self):
        with self.assertRaises(TypeError, msg="--err-t3--"):
            parse_age(None)
```

# --after-asserts--

```python
if __name__ == "__main__":
    unittest.main()
```

# --solutions--

```python
def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
```
