# --instructions--

Écrivez un décorateur `memoize` pour les fonctions à un seul argument : il doit stocker chaque résultat dans un dictionnaire à l'intérieur de la fermeture, de sorte qu'appeler à nouveau la fonction décorée avec le même argument renvoie le résultat enregistré sans appeler la fonction d'origine

# --asserts--

La fonction décorée doit renvoyer les mêmes résultats que l'originale

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

Répéter un appel ne doit pas exécuter à nouveau la fonction d'origine

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

Chaque fonction décorée doit avoir son propre cache

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
