# --instructions--

Ordonnez les éléments pour ne garder que les mots de plus de trois lettres, les convertir en majuscules et les afficher triés par longueur

# --answers--

```python
words = ["pear", "fig", "banana", "kiwi"]
```

```python
long_words = filter(lambda w: len(w) > 3, words)
```

# --solutions--

```python
words = ["pear", "fig", "banana", "kiwi"]
long_words = filter(lambda w: len(w) > 3, words)
shouted = map(str.upper, long_words)
print(sorted(shouted, key=len))
```

# --output--

['PEAR', 'KIWI', 'BANANA']
