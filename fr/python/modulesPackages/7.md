# --instructions--

Les packages ne sont rien de plus que des dossiers contenant un fichier `__init__.py`.
Que se passe-t-il si nous oublions d'ajouter un tel fichier ?

# --answers--

- Python ne reconnaîtra pas le dossier comme un package
- Nous pouvons toujours importer des packages mais pas des sous-packages
- Nous pouvons toujours importer des fonctions
