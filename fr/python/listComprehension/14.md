# --description--

La même idée fonctionne pour les dictionnaires : une **dict comprehension** utilise des accolades et une expression `key: value` :
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
