# --description--

Les deux positions de `if` se confondent facilement, gardez-les donc distinctes :
```python
values = [n if n > 0 else 0 for n in nums]  # if-else avant le for : choisit une valeur, else obligatoire
positives = [n for n in nums if n > 0]      # if après le for : filtre, else interdit
```
Mettre un `else` après le filtre `if` est une erreur de syntaxe.

# --instructions--

Quel est le __problème__ avec cet extrait de code ?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- Le filtre `if` après le `for` ne peut pas avoir de `else` : un `if-else` doit se placer avant le `for`
- Une list comprehension ne peut pas contenir de condition
- `nums` contient un nombre négatif, ce qui n'est pas autorisé
- `else` doit être remplacé par `elif`
