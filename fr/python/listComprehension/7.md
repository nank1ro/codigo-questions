# --description--

À l'intérieur d'une comprehension, vous pouvez utiliser toute variable définie avant elle, par exemple comme limite d'un `range()`.

# --instructions--

Triez les éléments pour afficher les multiples de 7 en dessous de `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
multiples = [n for n in range(1, limit) if n % 7 == 0]
print(multiples)
```

# --output--

[7, 14]
