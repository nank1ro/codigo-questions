# --description--

La condition de filtre peut être n'importe quelle expression qui donne un booléen, y compris des appels de fonction comme `len()` :
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
