# --description--

Parce que le corps doit être une expression unique, une lambda **ne peut pas contenir d'instructions**.
Ni `return`, ni blocs `if`, ni boucles, ni affectations :
```python
# SyntaxError
increment = lambda x: return x + 1
```
Si vous avez besoin de l'un de ces éléments, écrivez plutôt une fonction `def` normale.

# --instructions--

Quel est le __problème__ avec cet extrait de code ?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- Le corps d'une lambda est une expression, il ne peut pas contenir return
- Une lambda ne peut pas être stockée dans une variable
- Une lambda ne peut pas être appelée avec des parenthèses
- Une lambda a besoin d'au moins deux paramètres
