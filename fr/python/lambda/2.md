# --description--

Remarquez que le corps de la lambda n'a pas de mot-clé `return`.
Le corps est une **expression unique**, et sa valeur est retournée automatiquement :
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

Stockez dans la variable `square` une lambda qui prend un paramètre `n` et retourne `n` multiplié par lui-même
