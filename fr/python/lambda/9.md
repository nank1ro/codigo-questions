# --description--

`map()` applique une fonction à **chaque élément** d'une liste.
Elle retourne un _objet map_ spécial, il faut donc l'entourer de `list()` pour voir les valeurs :
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
