# --description--

Les lambdas ne se limitent pas aux fonctions intégrées : **vos propres fonctions** peuvent prendre une fonction en paramètre et l'appeler.
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```
