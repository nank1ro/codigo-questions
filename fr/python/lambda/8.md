# --description--

La lambda `key` peut choisir n'importe quelle partie d'un élément.
Pour une liste de listes, `lambda p: p[1]` trie selon le deuxième élément de chaque liste interne.

# --instructions--

Triez les éléments pour afficher les personnes de la plus jeune à la plus âgée

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
