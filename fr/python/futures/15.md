# --description--

Gérer une coroutine qui échoue suit le schéma synchrone : la coroutine lève l'exception, l'appelant englobe le `await` dans un `try`/`except` et décide quoi faire de l'objet erreur, par exemple afficher son message avec `print(e)`.

# --instructions--

Triez les éléments pour construire un programme qui commence par l'import, définit `load` avant `main`, affiche le résultat du chargement de `"config"`, puis intercepte l'erreur levée par le chargement d'un nom vide et affiche son message, produisant la sortie `loaded config`, `empty name`

```python
import asyncio
```

```python
async def load(name):

    if name == "":
        raise ValueError("empty name")
    return f"loaded {name}"
```

# --solutions--

```python
import asyncio
async def load(name):
    await asyncio.sleep(0.01)
    if name == "":
        raise ValueError("empty name")
    return f"loaded {name}"
async def main():
    print(await load("config"))
    try:
        await load("")
    except ValueError as e:
        print(e)
asyncio.run(main())
```

# --output--

loaded config
empty name
