# --description--

Un petit programme asynchrone suit une forme fixe : importer `asyncio`, définir les fonctions coroutine, définir une coroutine `main` qui les attend avec `await`, et enfin appeler `asyncio.run(main())` une seule fois à la fin.

# --instructions--

Triez les éléments pour construire un programme qui commence par l'import, définit `download` avant `main`, exécute deux téléchargements de manière concurrente avec `asyncio.gather` et affiche les résultats, produisant la sortie `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

# --output--

['report.pdf', 'data.csv']
