# --description--

`find(sub)` renvoie l'**index** de la première occurrence de `sub`, ou `-1` si elle n'est pas trouvée :
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` renvoie **combien de fois** `sub` apparaît :
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

Stockez dans `position` l'index du premier `o` dans `text`, dans `missing` le résultat de la recherche de `z`, et dans `total` le nombre de `o` que contient le texte
