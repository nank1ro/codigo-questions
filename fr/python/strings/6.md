# --description--

Vous savez déjà que `+` assemble deux chaînes (**concaténation**).
L'opérateur `*` **répète** une chaîne un certain nombre de fois :
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
La répétition est un moyen rapide de dessiner des séparateurs et des motifs simples.
