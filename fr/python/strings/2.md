# --description--

La fonction intégrée `len()` renvoie la **longueur** d'une chaîne, c'est-à-dire le nombre de caractères qu'elle contient.
Les espaces et la ponctuation comptent aussi comme des caractères :
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
