# --description--

Il y a un piège lors de la création d'un **set vide**.
Les accolades sont aussi la syntaxe des dictionnaires, donc `{}` crée un **dictionnaire** vide, pas un set :
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Pour obtenir un set vide, vous devez appeler `set()` sans argument :
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

Qu'affiche ce code ?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, car `{}` crée un dictionnaire vide
- `<class 'set'>`, car les accolades créent un set
- `<class 'NoneType'>`, car le set n'a aucun élément
- Une `SyntaxError`, car les accolades doivent contenir au moins un élément
