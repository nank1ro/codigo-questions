# --description--

Lorsque `not`, `and` et `or` apparaissent dans une même expression, Python applique d'abord `not`, puis `and`, puis `or`. Ainsi `a or b and c` signifie `a or (b and c)`, et `not a == b` signifie `not (a == b)` :
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Lorsqu'un autre regroupement est voulu, ajoutez des parenthèses ; elles rendent aussi l'expression plus lisible.

# --instructions--

Qu'affiche ce code ?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, car `and` est appliqué avant `or`, donc l'expression se lit `x == 3 or (x > 10 and x < 0)`
- `False`, car les opérateurs sont appliqués de gauche à droite : `(x == 3 or x > 10) and x < 0`
- `False`, car `x < 0` est faux et toutes les conditions de l'expression doivent être vérifiées
- Une `SyntaxError`, car `and` et `or` ne peuvent pas être mélangés sans parenthèses
