# --instructions--

Triez les éléments pour définir le dictionnaire `users` et la fonction `can_login`, qui utilise `name in users` pour protéger la recherche, puis affichez le résultat pour Ada avec le bon mot de passe et pour Grace, qui n'est pas enregistrée, produisant la sortie `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
