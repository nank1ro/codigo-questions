# --instructions--

Qu'affiche ce code ?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, car `c` est un autre nom pour la même liste que `a`, donc ajouter via `c` modifie `a` et le rend différent de `b`
- `True True [1, 2]`, car `c = a` copie la liste, donc `a` est inchangé
- `True False [1, 2, 3]`, car `is` compare les valeurs et `==` compare l'identité
- `False False [1, 2, 3]`, car `append` crée une nouvelle liste, donc `c` ne désigne plus `a`
