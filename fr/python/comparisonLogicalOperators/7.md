# --description--

Comme `if value:` applique déjà la valeur de vérité, comparer avec `== True` ou `== False` est inutile et peut même être faux : `2 == True` vaut `False`, et pourtant `2` est vrai. Testez la valeur elle-même :
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Écrivez une fonction `count_truthy(values)` qui renvoie combien d'éléments de la liste `values` sont vrais

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
