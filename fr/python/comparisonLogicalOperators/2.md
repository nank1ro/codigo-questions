# --description--

Les opérateurs de comparaison ne se limitent pas aux nombres. Les chaînes sont comparées caractère par caractère à l'aide de leurs points de code, donc `"apple" < "banana"` vaut `True` et, comme toute majuscule vient avant les minuscules, `"Zoo" < "apple"` vaut aussi `True`. Les listes et les tuples sont comparés élément par élément de la même façon :
```python
print("cat" < "dog")       # True
print([1, 2, 3] < [1, 3])  # True
print((1, 2) == (1, 2))    # True
```
Une comparaison est une expression, donc une fonction peut faire `return a < b` directement au lieu de l'envelopper dans un `if`.

# --instructions--

Écrivez une fonction `comes_first(a, b)` qui renvoie `True` lorsque la chaîne `a` est ordonnée avant la chaîne `b`, et `False` lorsqu'elles sont égales ou que `a` vient après `b`

`comes_first("apple", "banana")` doit renvoyer `True`

```python
    def test_1(self):
        self.assertIs(comes_first("apple", "banana"), True, "--err-t1--")
```

`comes_first("pear", "apple")` et `comes_first("kiwi", "kiwi")` doivent renvoyer `False`

```python
    def test_2(self):
        self.assertIs(comes_first("pear", "apple"), False, "--err-t2--")
        self.assertIs(comes_first("kiwi", "kiwi"), False, "--err-t2--")
```

Les majuscules viennent avant les minuscules, donc `comes_first("Zoo", "apple")` doit renvoyer `True`

```python
    def test_3(self):
        self.assertIs(comes_first("Zoo", "apple"), True, "--err-t3--")
```
