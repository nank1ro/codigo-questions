# --instructions--

Écrivez une fonction `is_vowel(ch)` qui renvoie `True` lorsque `ch` est exactement un caractère et que ce caractère est une voyelle (`a`, `e`, `i`, `o`, `u`) en minuscule ou en majuscule, et `False` pour toute autre chaîne, y compris la chaîne vide

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` et `is_vowel("y")` doivent renvoyer `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Les chaînes qui ne sont pas un caractère unique doivent renvoyer `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
