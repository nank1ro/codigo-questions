# --description--

Les fermetures peuvent être stockées dans des tableaux comme n'importe quelle autre valeur. Le type d'élément est le type de fonction :
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Boucler sur un tel tableau et appeler chaque fermeture à tour de rôle construit un petit **pipeline** de transformations.

# --instructions--

Écris une fonction `pipeline` qui prend un `Int` et un tableau de fermetures de type `(Int) -> Int` (omets les deux libellés d'argument) et renvoie le résultat de l'application de chaque fermeture dans l'ordre, chacune au résultat de la précédente

Exemple d'appel de fonction :
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
