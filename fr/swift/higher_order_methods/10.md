# --description--

`enumerated()` transforme un tableau en une séquence de paires `(offset, element)`, si bien qu'une fermeture peut utiliser la position de chaque élément en même temps que sa valeur :
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
Comme chaque paire est un tuple, la fermeture peut aussi le déstructurer : `.map { (i, step) in "\(i + 1). \(step)" }`.

# --instructions--

Écris une fonction `evenPositions` qui prend un tableau de `String` (omets le libellé de l'argument) et renvoie les éléments situés aux indices pairs (0, 2, 4, ...), en utilisant `enumerated()`, `filter` et `map`

Exemple d'appel de fonction :
```swift
print(evenPositions(["a", "b", "c", "d", "e"]))
// prints ["a", "c", "e"]
```

```swift
func evenPositions(_ items: [String]) -> [String] {
    return items.enumerated().filter { $0.offset % 2 == 0 }.map { $0.element }
}
```
