# --description--

Les fonctions d'ordre supérieur fonctionnent sur n'importe quel tableau, y compris les tableaux de tes propres structs. Enchaîner `filter` puis `map` est la façon habituelle de sélectionner certains éléments et d'extraire une valeur de chacun :
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
Faire l'inverse, `map` puis `filter`, perdrait la propriété `pages` avant que la vérification puisse l'utiliser.

# --instructions--

La struct `Product` est donnée. Écris une fonction `cheapNames` qui prend un tableau de `Product` (omets le libellé de l'argument) et renvoie les noms des produits dont le `price` est inférieur à `10`, dans l'ordre d'origine, en enchaînant `filter` et `map`

Exemple d'appel de fonction :
```swift
print(cheapNames([Product(name: "Pen", price: 2.5), Product(name: "Bag", price: 30)]))
// prints ["Pen"]
```

struct Product {
    var name: String
    var price: Double
}
func cheapNames(_ products: [Product]) -> [String] {
    return products.filter { $0.price < 10 }.map { $0.name }
}
