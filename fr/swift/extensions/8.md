# --description--

Une méthode `mutating` peut prendre des paramètres comme n'importe quelle autre méthode, et peut remplacer `self` entièrement au lieu de le mettre à jour sur place :
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

# --instructions--

Écris une extension de `Int` avec une méthode `mutating` `clamp(to max: Int)` qui remplace le nombre par `max` lorsque le nombre est supérieur à `max`, et le laisse inchangé sinon

Exemple d'appel de méthode :
```swift
var speed = 15
speed.clamp(to: 10)
print(speed)
// prints 10
```
