# --description--

Les extensions ne servent pas qu'aux types des autres. Une façon courante d'organiser ton propre code est de garder les propriétés stockées dans le corps de la struct ou de la classe et d'ajouter le comportement dans une ou plusieurs extensions, chacune regroupant des membres liés :
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
Les membres ajoutés dans une extension peuvent utiliser les propriétés stockées directement, exactement comme s'ils étaient écrits à l'intérieur du type.

# --asserts--

Tu dois utiliser une extension de `Rectangle`

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

L'aire d'un rectangle de `2` par `3` doit être `6.0`

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

L'aire d'un rectangle de `1.5` par `4` doit être `6.0`

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

Un rectangle de `2` par `3` mis à l'échelle par `2` doit être `4` par `6`

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

La mise à l'échelle ne doit pas changer le rectangle d'origine

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
