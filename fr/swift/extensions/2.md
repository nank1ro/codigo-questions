# --description--

Les extensions fonctionnent sur n'importe quel type, même ceux dont tu n'as pas le code source. `String` vient de la bibliothèque standard, mais tu peux quand même lui ajouter de nouvelles méthodes :
```swift
extension String {
    func whisper() -> String {
        return self.lowercased() + "..."
    }
}
print("HELLO".whisper()) // hello...
```
À l'intérieur d'une extension, tu peux omettre `self.` lorsque tu appelles d'autres membres du type : `lowercased()` seul signifie `self.lowercased()`.

# --instructions--

Écris une extension de `String` avec une méthode `shout()` qui renvoie la chaîne en majuscules suivie d'un point d'exclamation `!`

Exemple d'appel de méthode :
```swift
print("hi".shout())
// prints HI!
```

Tu dois utiliser une extension de `String`

```json
{
  "regex": "extension\\s+String",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`"hi".shout()` doit renvoyer `"HI!"`

```swift
tryCatch("hi".shout() == "HI!")
```

`"Swift is fun".shout()` doit renvoyer `"SWIFT IS FUN!"`

```swift
tryCatch("Swift is fun".shout() == "SWIFT IS FUN!")
```

`"".shout()` doit renvoyer `"!"`

```swift
tryCatch("".shout() == "!")
```
