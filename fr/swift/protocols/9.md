# --description--

Une extension d'un **protocole** est un autre outil : elle ajoute des membres à tous les types qui se conforment, présents et futurs. C'est ainsi que tu donnes à une exigence une **implémentation par défaut** :
```swift
protocol Greeter {
    var name: String { get }
    func greet() -> String
}

extension Greeter {
    func greet() -> String {
        return "Hi, \(name)"
    }
}

struct Person: Greeter {
    var name: String
}

print(Person(name: "Ada").greet()) // Hi, Ada
```
`Person` n'écrit jamais `greet()` et se conforme quand même. À l'intérieur de l'extension du protocole, tu peux utiliser chaque exigence du protocole — ici `name` — car tout type conforme est garanti de l'avoir.

Exemple d'utilisation :
```swift
print(Fruits(items: ["fig", "plum"]).summary())
```

# --asserts--

Un panier avec `fig` et `plum` doit se résumer en `2 items`

```swift
tryCatch(Fruits(items: ["fig", "plum"]).summary() == "2 items")
```

Un panier vide doit se résumer en `0 items`

```swift
tryCatch(Fruits(items: []).summary() == "0 items")
```

Un panier avec trois fruits doit se résumer en `3 items`

```swift
tryCatch(Fruits(items: ["fig", "plum", "pear"]).summary() == "3 items")
```

Un autre type `Basket` qui n'écrit aucune méthode doit se résumer en `1 items`

```swift
tryCatch(_Veg(items: ["pea"]).summary() == "1 items")
```

```swift
protocol Basket {
    var items: [String] { get }
    func summary() -> String
}

extension Basket {
    func summary() -> String {
        return "\(items.count) items"
    }
}

struct Fruits: Basket {
    var items: [String]
}
```
