# --description--

Une struct est un type valeur, donc une méthode qui modifie l'une de ses propriétés stockées doit être marquée `mutating`. Quand cette méthode est une exigence de protocole, le protocole doit aussi le dire :
```swift
protocol Togglable {
    mutating func toggle()
}

struct Light: Togglable {
    var isOn = false

    mutating func toggle() {
        isOn = !isOn
    }
}

var lamp = Light()
lamp.toggle()
print(lamp.isOn) // true
```
Sans `mutating` dans le protocole, une struct ne pourrait jamais satisfaire l'exigence. Les classes sont des types référence et n'ont jamais besoin du mot-clé : une classe satisfait une exigence `mutating` avec une méthode ordinaire. Appeler une méthode mutante nécessite un `var` — sur un `let` c'est une erreur de compilation.

# --instructions--

Fais en sorte que `Score` soit conforme à `Resettable` avec une méthode `reset()` qui met `points` à `0`

Exemple d'utilisation :
```swift
var score = Score(points: 10)
score.reset()
print(score.points)
// affiche 0
```

struct Score {

}

# --before-asserts--

```swift
func _reset<T: Resettable>(_ v: inout T) {
    v.reset()
}
```

# --asserts--

Un score de `10` doit être `0` après la réinitialisation

```swift
var _s1 = Score(points: 10)
_reset(&_s1)
tryCatch(_s1.points == 0)
```

Un score de `-4` doit être `0` après la réinitialisation

```swift
var _s2 = Score(points: -4)
_reset(&_s2)
tryCatch(_s2.points == 0)
```

Un score de `0` doit rester `0` après la réinitialisation

```swift
var _s3 = Score(points: 0)
_reset(&_s3)
tryCatch(_s3.points == 0)
```

protocol Resettable {
    mutating func reset()

struct Score: Resettable {
    var points: Int

    mutating func reset() {
        points = 0
    }
