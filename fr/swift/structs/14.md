# --instructions--

Pourquoi ce code ne compile-t-il pas ?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` est une constante `let`, donc une méthode `mutating` ne peut pas être appelée sur elle
- `increase` doit être marquée `static` pour changer `value`
- `value` doit être déclarée avec `let`
- Une struct ne peut pas contenir de méthodes
