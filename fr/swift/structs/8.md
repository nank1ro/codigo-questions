# --description--

Comme une struct est une valeur, une méthode n'a pas le droit de changer ses propriétés sauf si tu le déclares avec le mot-clé `mutating` :
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Une méthode `mutating` ne peut être appelée que sur une instance stockée dans une `var`. Sur une instance `let` la valeur est figée, donc `c.increase(by: 5)` ne compilerait pas.

# --instructions--

Ajoute une méthode `mutating` `increase` à `Counter` qui prend un `Int` avec le libellé d'argument `by` et l'ajoute à `value`

Exemple d'utilisation :
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

La méthode doit être marquée `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Augmenter `0` de `5` doit donner `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Augmenter `10` deux fois doit cumuler les augmentations

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Augmenter de `0` ne doit rien changer

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Modifier une copie ne doit pas changer l'original

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
