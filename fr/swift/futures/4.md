# --description--

Le travail qui s'étire dans le temps échoue souvent : un serveur est en panne, un fichier est manquant, l'entrée est incorrecte. Une telle fonction est marquée **`async throws`**, et on l'appelle avec **`try await`** :
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
Pour gérer l'erreur, tu places l'appel dans un bloc `do` et tu l'interceptes :
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// affiche could not load
```
L'ordre des mots-clés est fixe : `try` vient en premier, puis `await`.

# --instructions--

Écris une fonction `parse` qui prend une chaîne de caractères sans libellé d'argument, est asynchrone, peut lever une erreur et renvoie la chaîne convertie en `Int`. Si la chaîne n'est pas un nombre, lève `InputError.notANumber`

Exemple d'appel de fonction :
```swift
print(try await parse("7"))
// affiche 7
```

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
