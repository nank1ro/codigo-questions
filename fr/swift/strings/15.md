# --description--

Diviser sur un espace est la façon la plus simple de décomposer une phrase en mots, et joindre est la façon de reconstruire du texte à partir d'un tableau.

# --instructions--

Écris une fonction `wordCount` qui prend un `String` (omets l'étiquette d'argument) et renvoie combien de mots séparés par des espaces elle contient, et une fonction `slug` qui prend un tableau de `String` (omets l'étiquette d'argument) et renvoie les mots joints par `-`

Exemple d'appel de fonction :
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
