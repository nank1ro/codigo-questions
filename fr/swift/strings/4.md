# --description--

La propriété `count` renvoie le nombre de caractères d'une chaîne, et `isEmpty` vaut `true` quand la chaîne ne contient aucun caractère :
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
Chaque caractère est compté, y compris les espaces et la ponctuation.

# --instructions--

Qu'affiche ce code ?
```swift
let text = "Hi there!"
print(text.count)
```
