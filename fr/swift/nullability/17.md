# --description--

Les conversions faillibles s'associent naturellement à `guard let` : convertir, abandonner si le résultat est `nil`, puis travailler avec la valeur simple.

# --instructions--

Complète la fonction pour qu'elle convertisse le texte en `Int` et renvoie son double, ou `nil` lorsque la conversion échoue.
Affiche ensuite les résultats, en utilisant `0` comme valeur de repli

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
