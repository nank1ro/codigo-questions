# --description--

Vérifier `nil` puis extraire de force est verbeux. Swift propose la **liaison optionnelle** avec `if let`, qui extrait l'optionnel et stocke la valeur dans une nouvelle constante en une seule étape :
```swift
let score: Int? = 10
if let value = score {
    print("Score: \(value)") // value est un Int, pas un Int?
} else {
    print("No score")
}
```
Le corps du `if` ne s'exécute que lorsque l'optionnel contient une valeur ; à l'intérieur, `value` est un simple `Int` et n'a pas besoin de `!`.

# --instructions--

Écris une fonction `describe` qui prend un `Int?` (omets le libellé de l'argument) et renvoie `"Value: "` suivi du nombre (par exemple `"Value: 5"` pour `5`) lorsque l'optionnel contient une valeur, ou `"No value"` lorsqu'il est `nil`

func describe(_ number: Int?) -> String {
    if let value = number {
        return "Value: \(value)"
    } else {
        return "No value"
