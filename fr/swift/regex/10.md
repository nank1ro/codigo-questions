# --description--

Un motif peut contenir plusieurs groupes. Ils sont numérotés de gauche à droite selon leur parenthèse ouvrante, donc le deuxième est `m.2`, le troisième `m.3`, et ainsi de suite :
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` reste toujours la correspondance entière, quel que soit le nombre de groupes.

# --instructions--

Écris une fonction `setting` qui prend un texte (`String`) sans étiquette d'argument, trouve un réglage écrit comme des lettres minuscules, un signe `=` et des chiffres, et renvoie le nom et la valeur joints par deux-points, ou `"none"` quand le texte ne contient pas un tel réglage

Exemple d'appel de fonction :
```swift
print(setting("size=10"))
// prints size:10
```

# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
