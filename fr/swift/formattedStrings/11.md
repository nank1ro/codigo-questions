# --description--

Puisque `%` commence un spécificateur, un signe pourcentage littéral doit s'écrire `%%`. C'est ainsi que tu formates un pourcentage :
```swift
let ratio = 0.4567
print(String(format: "%.1f%%", ratio * 100)) // 45.7%
```
Multiplie d'abord le rapport par `100`, puis choisis la précision : `%.0f%%` pour `46%`, `%.1f%%` pour `45.7%`.

# --instructions--

Écris une fonction `percent` qui prend une partie et un total (tous deux `Double`, sans étiquette d'argument) et renvoie la partie en pourcentage du total avec une décimale, suivi de `%`

Exemple d'appel de fonction :
```swift
print(percent(9, 20))
// prints 45.0%
```
