# --description--

Une fonction qui prend une fermeture a un problème : elle ne peut pas savoir si la fermeture qu'on lui remet va lever une erreur. Marquer la fonction `throws` obligerait chaque appelant à écrire `try`, même ceux qui passent une fermeture inoffensive. `rethrows` dit *je lève une erreur seulement si la fermeture que tu m'as donnée en lève une* :
```swift
func applyTwice(_ value: Int, _ transform: (Int) throws -> Int) rethrows -> Int {
    return try transform(transform(value))
}
```
Dans le corps, tu écris quand même `try`, car l'appel peut vraiment échouer. Sur le site d'appel, le compilateur regarde la fermeture que tu as passée :
```swift
let doubled = applyTwice(3, { (n: Int) -> Int in n * 2 }) // pas de try nécessaire
```
La bibliothèque standard utilise cela partout — `map`, `filter` et `sorted(by:)` sont tous `rethrows` — c'est pourquoi tu n'écris jamais `try` devant un `map` ordinaire.

# --instructions--

Complète `applyAll` pour qu'il accepte une fermeture qui peut lever une erreur, qu'il lève une erreur seulement quand cette fermeture en lève une, et qu'il renvoie le tableau des valeurs transformées

Exemple d'appel de fonction :
```swift
print(applyAll([1, 2], { (n: Int) -> Int in n + 1 }))
// affiche [2, 3]
```

# --asserts--

doubler `1, 2, 3` doit donner `2, 4, 6` sans aucun `try`

```swift
let _doubled: [Int] = applyAll([1, 2, 3], { (n: Int) -> Int in n * 2 })
tryCatch(_doubled == [2, 4, 6])
```

un tableau vide doit donner un tableau vide

```swift
let _empty: [Int] = applyAll([], { (n: Int) -> Int in n * 2 })
tryCatch(_empty.isEmpty)
```

ajouter un à `5` doit donner `6`

```swift
let _plus: [Int] = applyAll([5], { (n: Int) -> Int in n + 1 })
tryCatch(_plus == [6])
```

une fermeture qui lève une erreur doit faire lever une erreur à `applyAll`

```swift
tryCatch(_propagates())
```

# --solutions--

```swift
func applyAll(_ numbers: [Int], _ transform: (Int) throws -> Int) rethrows -> [Int] {
    var result: [Int] = []
    for number in numbers {
        result.append(try transform(number))
    }
    return result
}
```
