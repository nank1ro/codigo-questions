# --description--

`re.search` はテキスト全体を走査しますが、`re.match` はテキストの**先頭**でだけパターンを試します：
```python
import re

print(re.search(r"\d+", "order 42"))  # <re.Match object; span=(6, 8), match='42'>
print(re.match(r"\d+", "order 42"))   # None
print(re.match(r"\d+", "42 orders"))  # <re.Match object; span=(0, 2), match='42'>
```

どちらもマッチしなければ `None` を返し、マッチオブジェクトは常にtruthyなので、「マッチしたか？」を確かめる一般的な方法はシンプルな `if` です：
```python
if re.search(r"\d", text):
    print("there is a digit")
```
本物の `True` や `False` が必要なときは、`is not None` と比較するか、呼び出しを `bool(...)` で囲みます。

# --asserts--

`has_digit` はテキスト内のどこかにある数字を見つけられなければなりません

```python
    def test_1(self):
        self.assertEqual(has_digit("order 42"), True, "--err-t1--")
        self.assertEqual(has_digit("7up"), True, "--err-t1--")
```

数字がないとき `has_digit` は `False` を返す必要があります

```python
    def test_2(self):
        self.assertEqual(has_digit("no numbers here"), False, "--err-t2--")
        self.assertEqual(has_digit(""), False, "--err-t2--")
```

`starts_with_digit` はテキストの先頭だけを見る必要があります

```python
    def test_3(self):
        self.assertEqual(starts_with_digit("42 orders"), True, "--err-t3--")
        self.assertEqual(starts_with_digit("order 42"), False, "--err-t3--")
        self.assertEqual(starts_with_digit(""), False, "--err-t3--")
```

# --solutions--

```python
import re

def has_digit(text):
    return re.search(r"\d", text) is not None

def starts_with_digit(text):
    return re.match(r"\d", text) is not None
```
