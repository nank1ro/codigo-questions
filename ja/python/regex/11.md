# --description--

`re.sub(pattern, replacement, text)` は、すべてのマッチを置き換えた新しい文字列を返します。文字列はイミュータブルなので、元のテキストはそのまま残ります：
```python
import re

print(re.sub(r"\d", "#", "call 555 now"))     # call ### now
print(re.sub(r"\s+", " ", "too    many gaps"))  # too many gaps
```

置換文字列は `\1`、`\2`、... でキャプチャグループを後方参照できます（名前付きグループは `\g<name>`）。これによりテキストの並べ替えが1行で書けます。同じバックスラッシュの理由から、置換文字列もraw文字列にします：
```python
import re

print(re.sub(r"(\w+), (\w+)", r"\2 \1", "Lovelace, Ada"))  # Ada Lovelace
```
`count` 引数は置き換えるマッチの数を制限します。`re.sub(r"\d", "#", "1 2 3", count=1)` は `# 2 3` になります。

`mask_digits` はすべての数字を置き換えなければなりません

```python
    def test_1(self):
        self.assertEqual(mask_digits("call 555 now"), "call ### now", "--err-t1--")
        self.assertEqual(mask_digits("no digits"), "no digits", "--err-t1--")
```

`swap_names` は名を姓の前に置く必要があります

```python
    def test_2(self):
        self.assertEqual(swap_names("Lovelace, Ada"), "Ada Lovelace", "--err-t2--")
        self.assertEqual(swap_names("Turing, Alan"), "Alan Turing", "--err-t2--")
```

カンマを含まないテキストは `swap_names` によって変更されずに残る必要があります

```python
    def test_3(self):
        self.assertEqual(swap_names("Ada Lovelace"), "Ada Lovelace", "--err-t3--")
```

# --solutions--

```python
import re

def mask_digits(text):
    return re.sub(r"\d", "#", text)

def swap_names(text):
    return re.sub(r"(\w+), (\w+)", r"\2 \1", text)
```
