# --instructions--

1つ以上の英字、`=` 記号、1つ以上の数字として書かれた設定にマッチし、2つの部分を名前付きグループ `key` と `value` に格納するコンパイル済みパターン `PAIR_RE` を定義してください。その上で、テキスト内で見つかったすべてのキーをその値（`int` として）に対応付ける辞書を返す関数 `parse_settings(text)` を書いてください

# --asserts--

`PAIR_RE` は名前付きグループ `key` と `value` を持つコンパイル済みパターンである必要があります

```python
    def test_1(self):
        self.assertIsInstance(PAIR_RE, re.Pattern, "--err-t1--")
        self.assertEqual(PAIR_RE.search("width=10").groupdict(), {"key": "width", "value": "10"}, "--err-t1--")
```

`parse_settings` はすべての設定を整数の値とともに返す必要があります

```python
    def test_2(self):
        self.assertEqual(parse_settings("width=10 height=20"), {"width": 10, "height": 20}, "--err-t2--")
        self.assertEqual(parse_settings("size=3; depth=7"), {"size": 3, "depth": 7}, "--err-t2--")
```

設定を含まないテキストは空の辞書を返す必要があります

```python
    def test_3(self):
        self.assertEqual(parse_settings("nothing to read"), {}, "--err-t3--")
        self.assertEqual(parse_settings(""), {}, "--err-t3--")
```

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
