# --description--

3つ目のエントリーポイントとして `re.fullmatch` があります。これは最初の文字から最後の文字までパターンがテキスト**全体**をカバーするときにだけ成功します。バリデーションに適したツールです：
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

つまり3つの関数が違うのは、パターンがどこに置かれることを許すかだけです。`re.match` はテキストの先頭、`re.search` はテキスト内のどこでも、`re.fullmatch` はテキスト全体です。

# --instructions--

このコードは出力に何を表示しますか？
```python
import re

print(bool(re.match(r"\d+", "12abc")), bool(re.search(r"\d+", "12abc")), bool(re.fullmatch(r"\d+", "12abc")))
```

# --answers--

- `True True False`、数字は先頭にありテキスト内にも含まれますが、テキスト全体をカバーしていないためです
- `True True True`、パターンがどこかに見つかれば3つの関数すべてが成功するためです
- `False True False`、`re.match` はパターンがテキスト全体をカバーする必要があるためです
- `True False False`、`re.search` は最初の文字の後だけを調べるためです
