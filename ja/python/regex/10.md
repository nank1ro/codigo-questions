# --description--

パターンにキャプチャグループが含まれると、`findall` は動作を変えます。グループがちょうど1つの場合はマッチ全体ではなくそのグループの内容を返し、2つ以上の場合はマッチごとにグループのタプルを返します：
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
これは覚えておく価値があります。グルーピングのためだけにパターンへ括弧を加えると、`findall` の戻り値が静かに変わってしまいます。`re.finditer` はマッチオブジェクトが常にマッチ全体とグループの両方を保持するため、このような動作にはなりません。

# --instructions--

このコードは出力に何を表示しますか？
```python
import re

print(re.findall(r"(\w+)@(\w+)", "ada@example bob@test"))
```

# --answers--

- `[('ada', 'example'), ('bob', 'test')]`、グループが複数あるとき `findall` はマッチごとにグループのタプルを返すためです
- `['ada@example', 'bob@test']`、`findall` は常にマッチ全体のテキストを返すためです
- `['ada', 'example', 'bob', 'test']`、`findall` はすべてのマッチのすべてのグループをフラットなリストに入れるためです
- `[]`、キャプチャグループを含むパターンは `re.finditer` でしか使えないためです
