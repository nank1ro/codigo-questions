# --description--

タスクは、誰かが待っているかどうかに関係なく実行を続けます。早めに作成し、他の作業を行い、その結果が必要になる時点でのみ `await` します。タスクの一部はすでにバックグラウンドで実行されているため、待ち時間は短くなります。タスクは `task.done()` で状態を確認することもでき、完了すれば `True` を返します。

# --instructions--

コードを完成させて、`compute()` がタスクとしてスケジュールされ、実行中に `"waiting"` が出力され、その後タスクが await されて値を取得するようにし、`waiting`、`42` を出力してください

# --seed--

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.[/](compute())
    print("waiting")
    value = [/] task
    print(value)

asyncio.run(main())
```

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```
