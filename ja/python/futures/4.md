# --description--

コルーチン関数を呼び出すだけでは実行されません。呼び出しはコルーチンオブジェクトを作るだけです。本体は、そのオブジェクトが await されるか、`asyncio.run` に渡されたときに実行されます：
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python は `RuntimeWarning: coroutine 'hello' was never awaited` という警告まで出します。忘れられた `await` は最もよくある非同期のバグです：コードは呼び出されたように見えるのに決して実行されず、結果を受け取るはずの変数には代わりにコルーチンオブジェクトが入ります。

# --instructions--

このコードは何を出力しますか？
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- `main` だけです。`hello()` は await されないコルーチンオブジェクトを作るため、その本体は実行されません
- `hi` の次に `main` です。コルーチン関数を呼び出すとすぐに実行されるためです
- `main` の次に `hi` です。コルーチンは `main` が返るときに実行されるためです
- `TypeError` です。コルーチンは変数に代入できないためです
