# --description--

これらの部品は自然に組み合わさります。多くの操作を並行して実行し、それぞれに個別の時間制限を付けるには、各操作を `wait_for` を適用して `TimeoutError` を捕捉する小さなコルーチンで包み、そのラッパーを `gather` します：
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
そうすると、`gather(*[guarded(job(x), limit) for x in items])` は、時間内に終わったジョブにはその値を、終わらなかったジョブには `None` を、元の順序で返します。バッチ全体にかかる時間は最大でも約 `limit` 秒です。

# --instructions--

`delay` 秒待って `delay` を返すコルーチン関数 `job(delay)` と、すべての delay に対して `job` を `asyncio.wait_for` で `limit` 秒に制限しながら**並行して**実行し、時間内に終わったジョブの delay と、タイムアウトしたジョブに対する `None` を元の順序で並べたリストを返すコルーチン関数 `run_jobs(delays, limit)` を書いてください

`job(0.01)` は `0.01` を返す必要があります

```python
    def test_1(self):
        self.assertEqual(asyncio.run(job(0.01)), 0.01, "--err-t1--")
```

`run_jobs([0.01, 0.06, 0.02], 0.04)` は `[0.01, None, 0.02]` を返し、`run_jobs([], 0.01)` は `[]` を返す必要があります

```python
    def test_2(self):
        self.assertEqual(asyncio.run(run_jobs([0.01, 0.06, 0.02], 0.04)), [0.01, None, 0.02], "--err-t2--")
        self.assertEqual(asyncio.run(run_jobs([], 0.01)), [], "--err-t2--")
```

`0.02` 秒の5つのジョブは制限 `0.05` ですべて終わり、並行して実行される必要があります。所要時間は `0.1` 秒を大きく下回ります

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(run_jobs([0.02] * 5, 0.05))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [0.02] * 5, "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
