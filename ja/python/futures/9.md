# --description--

小さな非同期プログラムは決まった形に従います：`asyncio` をインポートし、コルーチン関数を定義し、それらを await する `main` コルーチンを定義し、最後に `asyncio.run(main())` を一度だけ呼び出します。

# --instructions--

アイテムを並べ替えて、インポートから始まり、`main` の前に `download` を定義し、2つのダウンロードを `asyncio.gather` で並行して実行して結果を出力するプログラムを作り、`['report.pdf', 'data.csv']` を出力してください

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```
