# --description--

クラスも同じやり方で動作します。クラス本体の最初の文として置かれた文字列は、そのクラスのdocstringであり、`__doc__` に格納されます：
```python
class Point:
    """A point on a grid."""

    def __init__(self, x, y):
        self.x = x
        self.y = y

print(Point.__doc__)  # A point on a grid.
```
クラスの中の各メソッドも、`Point.__init__.__doc__` のようにして読める独自のdocstringを持てます。つまり、docstringを受け入れる3つの場所とは、モジュールの先頭、クラスの先頭、関数の先頭です。
