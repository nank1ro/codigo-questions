# --description--

1行では足りないとき、docstringは**PEP 257**で説明されている決まったレイアウトへと成長します。1行の要約、空行、その後に詳細、そして閉じる `"""` はそれだけで1行に置きます。
```python
def to_seconds(minutes):
    """Returns the number of seconds in the given minutes.

    minutes is a whole number and is never negative.
    """
    return minutes * 60
```
空行には意味があります。ツールは1行目を短い説明として単独で表示し、残りはもっと読みたい人のために取っておくからです。

`area` はdocstringを持っていなければなりません

```python
    def test_1(self):

```

docstringは、要約の行の後に空行とさらなるテキストが続く形で始まっていなければなりません

```python
    def test_2(self):
        lines = area.__doc__.split("\n")
        self.assertTrue(len(lines) >= 3, "--err-t2--")
        self.assertNotEqual(lines[0].strip(), "", "--err-t2--")
        self.assertEqual(lines[1].strip(), "", "--err-t2--")
        self.assertNotEqual(lines[2].strip(), "", "--err-t2--")
        self.assertEqual(lines[-1].strip(), "", "--err-t2--")
```

`area(3, 4)` は `12` を返し、`area(0, 5)` は `0` を返さなければなりません

