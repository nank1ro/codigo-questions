# --description--

文字列が関数の中の**最初の文**であるとき、Pythonはそれをその関数のドキュメントとして扱います。これは**docstring**と呼ばれます：
```python
def greet(name):
    """Returns the greeting for name."""
    return "Hi, " + name + "!"
```
慣例として、docstringは1行に収まる場合でも、トリプルダブルクォート `"""` の間に書きます。後で内容が増えても引用符を変更せずに済むようにするためです。

要約は、関数を説明するかのように三人称で書きます。「Returns...」「Adds...」「Checks...」のようにです。docstringは本体の中で他のどの文よりも前に来なければなりません。そうでなければ、それは単なる普通の文字列です。

# --asserts--

`double` は最初の文としてdocstringを持っていなければなりません

```python
    def test_1(self):
        self.assertIsNotNone(double.__doc__, "--err-t1--")
```

`double(21)` は `42` を返さなければなりません

```python
    def test_2(self):
        self.assertEqual(double(21), 42, "--err-t2--")
```

`double(-3)` は `-6` を返し、`double(0)` は `0` を返さなければなりません

```python
    def test_3(self):
        self.assertEqual(double(-3), -6, "--err-t3--")
        self.assertEqual(double(0), 0, "--err-t3--")
```
