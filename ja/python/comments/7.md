# --description--

docstringは捨てられてしまうわけではありません。Pythonはそれを関数の `__doc__` 属性に格納するので、プログラムは実行中に自分自身のドキュメントを読むことができます：
```python
def greet(name):
    """Returns the greeting for name."""
    return "Hi, " + name + "!"

print(greet.__doc__)  # name への挨拶を返す。
```
関数にdocstringがないとき、`__doc__` は `None` です。`help(greet)` が表示するもの、そして名前の上にカーソルを合わせたときにエディタが表示するものは、これです。
