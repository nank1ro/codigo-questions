# --description--

Pythonは `#` をコードの中でだけ探し、**文字列**の中では決して探しません。引用符の間では、`#` は普通の文字です：
```python
print("black is #000000")  # a hex colour
```
最初の `#` はテキストの一部であり、2つ目の `#` が本物のコメントを始めます。`#` コメントの中の `"""` についても同じです。そこでは単なる3つの引用符文字であり、何も始めません。

# --instructions--

`name` の前に `#` を付けたものを返す関数 `label(name)` を書いてください。つまり、`label("python")` は `"#python"` を返します

# --asserts--

`label("python")` は `"#python"` を返さなければなりません

```python
    def test_1(self):
        self.assertEqual(label("python"), "#python", "--err-t1--")
```

`label("ai")` は `"#ai"` を返さなければなりません

```python
    def test_2(self):
        self.assertEqual(label("ai"), "#ai", "--err-t2--")
```

`label("")` は `"#"` を返さなければなりません

```python
    def test_3(self):
        self.assertEqual(label(""), "#", "--err-t3--")
```
