# --description--

1つの引数しか受け取れないデコレータはほとんど役に立ちません。**どんな**関数でも包めるように、ラッパーはすべての位置引数を `*args` に、すべてのキーワード引数を `**kwargs` に集め、そのまま転送します：
```python
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@uppercase
def greet(name, punctuation="!"):
    return "hello " + name + punctuation

print(greet("ada"))                    # HELLO ADA!
print(greet("ada", punctuation="?"))   # HELLO ADA?
```
ラッパーの中では、`args` はタプル、`kwargs` は辞書です。呼び出しのときの `*` と `**` が、それらを個別の引数に展開し直します。

# --instructions--

任意の引数を受け取り、それらで包まれた関数を呼び出し、その結果に `"!"` を付けて返すラッパーを返すデコレータ `exclaim` を書いてください。その後、それを使って、`name` を受け取り `"hello <name>"` を返す関数 `greet` をデコレートしてください

# --asserts--

デコレータを `@exclaim` で適用する必要があります

```json
{
  "regex": "^@exclaim\\s*$",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`greet("ada")` は `"hello ada!"` を返さなければなりません

```python
    def test_1(self):
        self.assertEqual(greet("ada"), "hello ada!", "--err-t1--")
```

`exclaim` は2つの引数を持つ関数でも動作しなければなりません

```python
    def test_2(self):
        joined = exclaim(lambda a, b: a + " " + b)
        self.assertEqual(joined("good", "day"), "good day!", "--err-t2--")
```

`exclaim` はキーワード引数を転送しなければなりません

```python
    def test_3(self):
        tag = exclaim(lambda word, times=1: word * times)
        self.assertEqual(tag("hi", times=2), "hihi!", "--err-t3--")
```
