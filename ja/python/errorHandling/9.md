# --description--

例外はオブジェクトであり、`as` はそれを名前に束縛するので、ハンドラからその内容を調べられます：
```python
try:
    int("abc")
except ValueError as e:
    print(e)                   # invalid literal for int() with base 10: 'abc'
    print(type(e).__name__)    # ValueError
```
`str(e)`（`print(e)` やf文字列のスロットが使うもの）は例外が構築されたときのメッセージを返し、`type(e).__name__` はクラス名をテキストとして返します。`as` で束縛された名前は `except` ブロックの中でのみ存在し、ブロックが終わるとPythonはその名前を削除します。

# --instructions--

`int(text)` を返し、それが `ValueError` を発生させたときは例外のクラス名、`": "`、例外のメッセージをつなげた文字列（例えば `"ValueError: ..."`）を返す関数 `error_label(text)` を書いてください

# --asserts--

`error_label("8")` は `8` を返さなければなりません

```python
    def test_1(self):
        self.assertEqual(error_label("8"), 8, "--err-t1--")
```

`error_label("abc")` はクラス名で始まらなければなりません

```python
    def test_2(self):
        self.assertTrue(error_label("abc").startswith("ValueError: "), "--err-t2--")
```

`error_label("abc")` は `abc` に触れているメッセージも含まなければなりません

```python
    def test_3(self):
        self.assertIn("abc", error_label("abc")[12:], "--err-t3--")
```

# --solutions--

```python
def error_label(text):
    try:
        return int(text)
    except ValueError as e:
        return f"{type(e).__name__}: {e}"
```
