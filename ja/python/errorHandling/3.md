# --description--

どの`except`ブロックにも一致しない例外は、外側へ伝わり続けます：その行の外、その行を実行した関数の外、さらにその呼び出し元の外、という具合です。プログラムの最上部に達するまでに何も捕捉しないと、Pythonはトレースバックを出力し、プロセスはゼロ以外の終了ステータスで終了します。失敗した文の後の行が実行されることはありません。

# --instructions--

このコードを実行すると何が起こりますか？
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- `start` を出力し、その後 `TypeError` で終わるトレースバックが表示されます。捕捉されない例外がプログラムを停止させるため、`end` も `after` も出力されません
- `start`、`end`、`after` を出力します。Pythonは失敗した行だけをスキップするためです
- `start` と `after` を出力します。例外は `sizes` を停止させますが、プログラムは続行するためです
- `start` と `0` を出力します。`len(None)` は `0` であるためです
