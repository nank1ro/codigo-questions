# --description--

予期する失敗をカバーする最も狭い型を選ぶことが、信頼できるエラー処理の鍵です。テキストを読み取る関数は不正なテキストから回復すべきですが（`ValueError`）、間違った種類の引数で呼び出されることを隠してはいけません（`TypeError`）。そのエラーは呼び出し元に属するものなので、そのまま通しましょう。

# --instructions--

`int(text)` を返し、`text` が有効な整数でないときは `-1` を返す関数 `parse_age(text)` を書いてください。`ValueError` だけを捕捉し、`parse_age(None)` が依然として `TypeError` を発生させるようにします

# --before-asserts--

import unittest

class CodigoTests(unittest.TestCase):

# --asserts--

`parse_age("30")` は `30` を返さなければなりません

```python
    def test_1(self):
        self.assertEqual(parse_age("30"), 30, "--err-t1--")
```

`parse_age("old")` は `-1` を返さなければなりません

```python
    def test_2(self):
        self.assertEqual(parse_age("old"), -1, "--err-t2--")
```

`parse_age(None)` は依然として `TypeError` を発生させなければなりません

```python
    def test_3(self):
        with self.assertRaises(TypeError, msg="--err-t3--"):
            parse_age(None)
```

# --solutions--

```python
def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
```
