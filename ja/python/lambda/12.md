# --description--

lambdaは組み込み関数だけに限られません。**あなた自身の関数**も関数をパラメータとして受け取り、それを呼び出すことができます。
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

# --instructions--

`func` を `value` に2回適用してその結果を返す関数 `apply_twice(func, value)` を定義してください。
次に、`3` を足すlambdaと値 `10` で呼び出した `apply_twice` の値を `result` に格納してください
