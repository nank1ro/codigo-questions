# --description--

lambdaのパラメータも**デフォルト値**をサポートします。
```python
greet = lambda name="World": f"Hello, {name}!"
print(greet())       # Hello, World!
print(greet("Ana"))  # Hello, Ana!
```

# --instructions--

変数 `multiply` に、`n` とデフォルト値 `2` を持つ2番目のパラメータ `factor` を取り、`n` に `factor` を掛けた値を返すlambdaを格納してください
