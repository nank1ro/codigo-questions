# --description--

`map` オブジェクトをそのまま出力しても値は表示されず、`<map object at 0x7f2b1c>` のような結果になります。
`list()`（またはループ）を使って初めて期待した値が得られます。

# --instructions--

このコードは何を出力しますか？
```python
nums = [1, 2, 3]
print(list(map(lambda x: x + 1, nums)))
```

# --answers--

- [2, 3, 4]
- [1, 2, 3]
- 2 3 4
- <map object>
