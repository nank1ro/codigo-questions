# --description--

lambdaが本当に輝くのは**他の関数への引数**として使われるときです。
`sorted()` は `key` パラメータを受け取ります。これは各アイテムに対して呼び出される関数で、その結果が順序を決定します。
lambdaはまさにぴったりです。
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```
