# --description--

本体は単一の式でなければならないため、lambdaは**文を含むことができません**。
`return` も `if` ブロックも、ループも代入もありません。
```python
# SyntaxError
increment = lambda x: return x + 1
```
これらが必要な場合は、代わりに通常の `def` 関数を書いてください。

# --instructions--

このコードスニペットの__問題点__は何ですか？
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- lambdaの本体は式であり、returnを含むことはできない
- lambdaは変数に格納できない
- lambdaは括弧で呼び出すことができない
- lambdaは少なくとも2つのパラメータが必要
