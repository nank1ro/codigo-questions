# --description--

`max()` と `min()` も、`sorted()` と同じように `key` 関数を受け取ることができます。
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

# --instructions--

アイテムを並べ替えて、大文字小文字を無視したアルファベット順に名前を出力し、その後に最も長い名前を出力してください
