# --description--

lambdaの本体には `return` キーワードがないことに注目してください。
本体は**単一の式**であり、その値は自動的に返されます。
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

変数 `square` に、パラメータ `n` を1つ取り `n` をそれ自身と掛けた値を返すlambdaを格納してください
