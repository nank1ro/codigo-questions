# --description--

フォーマットは数値の表示方法を変えるだけです。丸められた**値**を得るには、組み込みの `round()` を使います：
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
引数が1つの場合、`round()` は最も近い整数に丸めて `int` を返します。桁数を指定すると `float` を返します：
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
2つの数のちょうど中間にある値は**偶数**のほうに丸められることに注意してください：`round(2.5)` は `2`、`round(3.5)` は `4` です。
