# --description--

`float` を出力すると、正確に表すのに必要なだけの桁数が表示されます。これは多すぎることがよくあります：
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
f文字列の中では、コロンの後に**フォーマット指定**を追加できます。`.2f` は「小数2桁の固定小数点数」を意味します：
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
値は指定した桁数に丸められ、必要なときにはゼロが追加されます：`f"{2.5:.2f}"` は `2.50` になります。
