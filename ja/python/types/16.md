# --description--

外部から来るテキストは常に `str` であり、それが実際にどの型を保持しているのかを見極めるのはプログラムの役目です。
一般的なアプローチは、まず**最も厳しい**変換を試し、`ValueError` が発生したら次の変換にフォールバックすることです：
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` ブロックの中に2つ目の `try` を入れ子にすると、もう一度フォールバックできます。たとえば、テキストをそのまま保持するような場合です。

# --instructions--

文字列を受け取り、整数であれば `int` として、小数であれば `float` として返し、それ以外はそのまま返す関数 `parse_value` を書いてください

def parse_value(text):

    except ValueError:
        try:
            return float(text)
        except ValueError:
