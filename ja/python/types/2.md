# --description--

`type()` は値のクラスを返すので、`is` を使ってクラス名と比較できます：
```python
age = 30
print(type(age) is int)  # True
```
しかし、ほとんどの場合は、値がある型**かどうか**を知りたいだけです。それが `isinstance(value, cls)` の役割で、`True` か `False` を返します：
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
2番目の引数にはクラスの**タプル**も指定できます：値がそのいずれかに属していれば結果は `True` になります：
```python
print(isinstance(2.5, (int, float)))  # True
```
