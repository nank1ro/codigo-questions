# --description--

値は自分で型を変えることはありません：値を別の型に変えるには、型名を関数のように呼び出します。これは**変換**（*キャスト*）と呼ばれます：
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` と `float()` はテキストとして書かれた数値を読み取ります。これはユーザー入力やファイルから得られるものです。`str()` は何でもテキストに変えるので、`+` で他の文字列と連結できます。
`int(3.9)` は四捨五入しないことに注意してください：小数部分を切り捨てます。
