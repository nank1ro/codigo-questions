# --description--

変数、パラメータ、戻り値の期待される型は**型ヒント**として書けます：変数とパラメータには名前の後にコロンを、戻り値にはコロンの前に矢印 `->` を書きます：
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
型ヒントは人やエディタのようなツールのための**ドキュメント**です：Python はそれらを確認**しません**。このコードは何も言わずに実行され、`hello` を出力します：
```python
count: int = "hello"
print(count)
```
型ヒントは意図した型を明確にしますが、実際の型はやはり値が決めます。
