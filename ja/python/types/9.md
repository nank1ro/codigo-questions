# --description--

`None` は「ここには何もない」ことを意味する、それ自身の値です。関数に `return` 文がないときに返される値であり、まだ分かっていない値の一般的なプレースホルダーでもあります。
`None` は1つしか存在しないので、`==` ではなく `is` で確認します：
```python
result = None
if result is None:
    print("no result yet")
```
すべての型には、その名前を文字列として持つ `__name__` 属性があり、メッセージに便利です：
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

値を受け取り、その値が `None` のときは文字列 `"nothing"` を、そうでなければその型の名前を返す関数 `describe` を書いてください

```json

```

`__name__` を使用する必要があります

```json
{
  "regex": "__name__",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`describe(None)` は `"nothing"` を返す必要があります

```python
    def test_1(self):
        self.assertEqual(describe(None), "nothing", "--err-t1--")
```

`describe(5)` は `"int"` を返し、`describe(2.0)` は `"float"` を返す必要があります

```python
    def test_2(self):
        self.assertEqual(describe(5), "int", "--err-t2--")
        self.assertEqual(describe(2.0), "float", "--err-t2--")
```

`describe("a")` は `"str"` を返し、`describe(True)` は `"bool"` を返す必要があります

```python
    def test_3(self):
        self.assertEqual(describe("a"), "str", "--err-t3--")
        self.assertEqual(describe(True), "bool", "--err-t3--")
```
