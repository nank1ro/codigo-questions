# --description--

すべての値はブーリアンとして解釈できます。`bool()` は値を `True` か `False` に変換します。値が `if` で直接使われるときにも同じルールが適用されます。
**偽**とみなされる値は、「空」のものです：
- 数値の `0`（および `0.0`）
- 空の文字列 `""`
- `[]`、`{}`、`()`、`set()` のような空のコレクション
- `None`

空でない値はすべて**真**です。負の数や、`"0"` や `" "` のように空に見えるだけの文字列も含まれます：
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
このため、`if name:` は文字列が空でないことを確認する一般的な方法です。

# --instructions--

このコードは何を出力しますか？
```python
print(bool(0), bool("0"), bool([]), bool(None))
```

# --answers--

- `False True False False`：`"0"` は空でない文字列であるため
- `False False False False`：すべてゼロまたは無を表しているため
- `True True False False`：数値は常に真であるため
- `TypeError`：`None` はブーリアンに変換できないため
