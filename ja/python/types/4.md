# --description--

算術演算子はすでに知っていますね。ここで重要なのは**結果の型**です。
`int` と `float` を組み合わせると `float` になります。小数部分がゼロでも同じです：
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**除算** `/` は、数値がきれいに割り切れるときでも、常に `float` を返します：
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**切り捨て除算** `//` は結果を最も近い整数に切り下げ（したがって `-7 // 2` は `-4`）、両方のオペランドが整数のときは `int` を返します。剰余 `%` と組み合わせると、量を整数の部分に分割できます：
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```
