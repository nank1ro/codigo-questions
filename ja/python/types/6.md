# --description--

変換は失敗することがあります。`int("abc")` は数値を作れないので、`ValueError` を発生させ、プログラムは停止します：
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
プログラムを動かし続けるには、`try` / `except` でエラーを捕捉できます：`try` ブロックのコードが実行され、指定した名前のエラーが発生すると、代わりに `except` ブロックが実行されます：
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
変換が成功すると、`except` ブロックはスキップされます。

def to_int(text):
    try:
        return int(text)
    except ValueError:
        return None
