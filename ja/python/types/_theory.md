Python のすべての値には**型**があり、それがどんな種類のデータで、何ができるのかを教えてくれます。
基本的な組み込み型は次のとおりです：
- `int`：`42` や `-3` のような整数
- `float`：`3.5` のような小数部分を持つ数値
- `str`：`"hello"` のようなテキスト
- `bool`：`True` と `False` の2つの値のいずれか
- `NoneType`：「値がない」ことを意味する特別な値 `None` の型

組み込み関数 `type()` は値の型を返します。printするとクラス名が表示されます：
```python
print(type(42))     # <class 'int'>
print(type("hi"))   # <class 'str'>
```
`NoneType` を自分で書くことはありません：`type(None)` はそれを返しますが、この名前は他の4つのような組み込みではありません。

---

`type()` は値のクラスを返すので、`is` を使ってクラス名と比較できます：
```python
age = 30
print(type(age) is int)  # True
```
しかし、ほとんどの場合は、値がある型**かどうか**を知りたいだけです。それが `isinstance(value, cls)` の役割で、`True` か `False` を返します：
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
2番目の引数にはクラスの**タプル**も指定できます：値がそのいずれかに属していれば結果は `True` になります：
```python
print(isinstance(2.5, (int, float)))  # True
```

---

Python は**動的型付け**です：型は変数ではなく**値**に属します。
変数は値に付けられた名前にすぎず、いつでも別の型の値に付け替えることができます：
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
宣言も変換も必要ありません：古い値は単に忘れられます。
これは便利ですが、プログラムが実行されるまで変数の型が分からないことも意味します。そのため、うっかり型を混ぜると、実行前にではなく実行時にエラーとして現れます。

---

算術演算子はすでに知っていますね。ここで重要なのは**結果の型**です。
`int` と `float` を組み合わせると `float` になります。小数部分がゼロでも同じです：
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**除算** `/` は、数値がきれいに割り切れるときでも、常に `float` を返します：
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**切り捨て除算** `//` は結果を最も近い整数に切り下げ（したがって `-7 // 2` は `-4`）、両方のオペランドが整数のときは `int` を返します。剰余 `%` と組み合わせると、量を整数の部分に分割できます：
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```

---

値は自分で型を変えることはありません：値を別の型に変えるには、型名を関数のように呼び出します。これは**変換**（*キャスト*）と呼ばれます：
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` と `float()` はテキストとして書かれた数値を読み取ります。これはユーザー入力やファイルから得られるものです。`str()` は何でもテキストに変えるので、`+` で他の文字列と連結できます。
`int(3.9)` は四捨五入しないことに注意してください：小数部分を切り捨てます。

---

変換は失敗することがあります。`int("abc")` は数値を作れないので、`ValueError` を発生させ、プログラムは停止します：
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
プログラムを動かし続けるには、`try` / `except` でエラーを捕捉できます：`try` ブロックのコードが実行され、指定した名前のエラーが発生すると、代わりに `except` ブロックが実行されます：
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
変換が成功すると、`except` ブロックはスキップされます。

---

すべての値はブーリアンとして解釈できます。`bool()` は値を `True` か `False` に変換します。値が `if` で直接使われるときにも同じルールが適用されます。
**偽**とみなされる値は、「空」のものです：
- 数値の `0`（および `0.0`）
- 空の文字列 `""`
- `[]`、`{}`、`()`、`set()` のような空のコレクション
- `None`

空でない値はすべて**真**です。負の数や、`"0"` や `" "` のように空に見えるだけの文字列も含まれます：
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
このため、`if name:` は文字列が空でないことを確認する一般的な方法です。

---

`bool` は `int` の**サブクラス**です：数値が期待される場所では、`True` は `1` のように、`False` は `0` のように振る舞います：
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` はリストの項目を合計するので、ブーリアンのリストを合計すると `True` の個数を**数える**ことになります：
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
このサブクラス関係のため、`isinstance(True, int)` は `True` を返しますが、`type(True)` はやはり `bool` です。

---

`None` は「ここには何もない」ことを意味する、それ自身の値です。関数に `return` 文がないときに返される値であり、まだ分かっていない値の一般的なプレースホルダーでもあります。
`None` は1つしか存在しないので、`==` ではなく `is` で確認します：
```python
result = None
if result is None:
    print("no result yet")
```
すべての型には、その名前を文字列として持つ `__name__` 属性があり、メッセージに便利です：
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

---

`float` を出力すると、正確に表すのに必要なだけの桁数が表示されます。これは多すぎることがよくあります：
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
f文字列の中では、コロンの後に**フォーマット指定**を追加できます。`.2f` は「小数2桁の固定小数点数」を意味します：
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
値は指定した桁数に丸められ、必要なときにはゼロが追加されます：`f"{2.5:.2f}"` は `2.50` になります。

---

フォーマットは数値の表示方法を変えるだけです。丸められた**値**を得るには、組み込みの `round()` を使います：
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
引数が1つの場合、`round()` は最も近い整数に丸めて `int` を返します。桁数を指定すると `float` を返します：
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
2つの数のちょうど中間にある値は**偶数**のほうに丸められることに注意してください：`round(2.5)` は `2`、`round(3.5)` は `4` です。

---

`float` は固定されたビット数で2進数として格納されるため、ほとんどの10進数は**近似**しかできません。誤差はごくわずかですが、算術では現れます：
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
このため、float を完全な等価で比較すべきではありません。両側を丸めるか、微小な許容差の範囲で2つの数が等しいかを確認する `math.isclose()` を使います：
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
整数にはこの問題がありません：`1 + 2 == 3` は常に `True` です。

---

多くの言語と違って、Python の整数には**最大サイズがありません**：`int` は必要なだけ桁を保持できるように大きくなるので、大きな計算も正確なままです：
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
一方、`float` は約15桁の有効数字しか保持しないので、同じ累乗も float としては精度を失います：
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
`str()` は任意の `int` に使えるので、数の桁数を数える手っ取り早い方法は、そのテキストの長さを測ることです。

---

変数、パラメータ、戻り値の期待される型は**型ヒント**として書けます：変数とパラメータには名前の後にコロンを、戻り値にはコロンの前に矢印 `->` を書きます：
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
型ヒントは人やエディタのようなツールのための**ドキュメント**です：Python はそれらを確認**しません**。このコードは何も言わずに実行され、`hello` を出力します：
```python
count: int = "hello"
print(count)
```
型ヒントは意図した型を明確にしますが、実際の型はやはり値が決めます。

---

変換は組み合わせられます。`int("3.7")` は失敗しますが、`float("3.7")` はうまくいき、`float` に対する `int()` は小数部分を切り捨てます：
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` は真偽のルールに従います：`bool("")` は `False` で、`bool("False")` は空でない文字列であるため `True` になることに注意してください。

---

外部から来るテキストは常に `str` であり、それが実際にどの型を保持しているのかを見極めるのはプログラムの役目です。
一般的なアプローチは、まず**最も厳しい**変換を試し、`ValueError` が発生したら次の変換にフォールバックすることです：
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` ブロックの中に2つ目の `try` を入れ子にすると、もう一度フォールバックできます。たとえば、テキストをそのまま保持するような場合です。
