# --description--

2つのセットの**和集合（union）**は、**両方**の要素を重複なく含む新しいセットです。
`|` 演算子または `union()` メソッドを使います：
```python
a = {1, 2}
b = {2, 3}
print(a | b)        # {1, 2, 3}
print(a.union(b))   # {1, 2, 3}
```
`a` も `b` も変更されません：セット演算は常に新しいセットを返します。
