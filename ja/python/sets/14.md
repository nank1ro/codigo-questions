# --description--

**集合内包表記（set comprehension）**は、リスト内包表記と同じ構文で波括弧を使い、1つの式でセットを構築します：
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
オプションの `if` で要素をフィルタリングでき、式によって生成された重複は自動的に取り除かれます：
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```
