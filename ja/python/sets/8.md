# --description--

2つのセットの**積集合（intersection）**は、**両方**に存在する要素だけを含みます。
`&` 演算子または `intersection()` メソッドを使います：
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
セットに共通の要素がない場合、結果は空のセットになります。
