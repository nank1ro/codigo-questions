# --description--

**空のセット**を作成する際には落とし穴があります。
波括弧は辞書の構文でもあるため、`{}` は空の**辞書**を作成し、セットにはなりません：
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
空のセットを得るには、引数なしで `set()` を呼び出す必要があります：
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

このコードは何を出力しますか？
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`：`{}` は空の辞書を作成するため
- `<class 'set'>`：波括弧はセットを作成するため
- `<class 'NoneType'>`：セットに要素がないため
- `SyntaxError`：波括弧は少なくとも1つの要素を含まなければならないため
