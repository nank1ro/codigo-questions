# --description--

**差集合（difference）** `a - b` は、`a` の要素のうち `b` に**含まれない**ものです。
順序が重要です：`a - b` と `b - a` は通常異なります：
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**対称差（symmetric difference）** `a ^ b` は、2つのセットの**どちらか一方だけ**に含まれる要素です：
```python
print(a ^ b)  # {1, 4}
```
メソッド形式は `difference()` と `symmetric_difference()` です。
