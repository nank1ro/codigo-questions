# --description--

`if`の直後にインデントされた`print`だけがそのブロックに属します。`if`自体と同じインデントで書かれた行はブロックに属しません。

# --instructions--

どのprint文が文のコードブロックの一部ですか？
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)

# --solutions--

- print("Hello User!")
