特定の条件が満たされた場合にのみコードを実行したいとき、意思決定が必要になります。
天気が良いときだけ外で遊びたいとしましょう。
プログラミングでは、ブール変数 `nice_weather` を保存し、この変数が `True` の場合に外で遊ぶというアクションを `if` で実行できます。例えば：
```python
nice_weather = True
if (nice_weather):
    # 外で遊ぶ
```

---

前の例の続きを見てみましょう。
```python
nice_weather = True
if (nice_weather):
    # 外で遊ぶ
```
`if` 文は条件が `True` の場合にのみコードブロックを実行することがわかりました。
もう一つ重要なことは、**コロン** `:` と**インデント**です。これらはコードブロックの開始を示します。
インデントとは、コード行の先頭にあるスペースのことです。
他のプログラミング言語ではインデントは読みやすさのためだけですが、Pythonではインデントは不可欠です。
お好みのスペース数（2、4、6、8）を使用できますが、4が推奨されています。
このアプリでは、コード行をインデントするために**TAB**キーを使用することをお勧めします

---

条件が成立した場合にコードブロックを実行する方法を見ました。次に、最初の条件が偽の場合に別のコードブロックを実行する方法を見てみましょう。
天気が良ければ外で遊びます。そうでなければ、家にいます。
Pythonでは、`else` 文を使用できます。例えば：
```python
nice_weather = True
if (nice_weather):
    # 外で遊ぶ
else:
    # 家にいる
```

---

もう一つの条件をチェックしたい場合を考えてみましょう。次の例のように：
```python
num = 3
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
else:
    print("do something else")
```
このコードの出力は `the number is 3` です。
まず、数値が2に等しいかチェックします。これは偽です。
次に、2番目の文に進み、`num` が3に等しいかチェックします。これは真なので、`the number is 3` を出力するコードブロックを実行します

---

`elif` 文はいくつでも追加できます。制限はありません
```python
num = 4
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
elif (num == 4):
    print("the number is 4")
elif (num == 5):
    print("the number is 5")
elif (num == 6):
    print("the number is 6")
```
このコードの出力は `the number is 4` です。

---

条件文（`if`、`elif`、`else`）を別の条件文の中にネストして、より複雑な構造を作ることもできます。
```python
num = 4
if (num < 3):
    print("the number is lower than 3")
else:
    if (num == 3):
        print("the number is 3")
    elif (num == 4):
        print("the number is 4")
    else:
        print("the number is greather than 4")
```
このコードの出力は `the number is 4` です。

---

すべての条件文は、それを導入する`if`キーワードを必要とします。これは、下のブロックが条件が成立したときにのみ実行されることをPythonに伝えるものです。

---

条件は比較である必要はありません — `True`のようなブール値単体でも機能し、その値が`True`である限りブロックが実行されます。

---

同じ文でも、条件を変えるだけでブロックをスキップさせることができます。条件が`False`と評価されるたびに、Pythonはインデントされたコードをそのまま飛ばします。

---

Pythonの`if`行は3つの部分から構成されます。`if`キーワード、条件、そして行を閉じるコロンです。そのコロンの後にインデントされたものすべてがブロックです。

---

ここでは条件が`True`なので、Pythonはその下のインデントされた行を実行し、`Hello!`を出力します。

---

条件が`False`のとき、Pythonはインデントされたブロックに決して入らないので、何も出力されません。

---

ブロックが実行されるかどうかを決める値は条件と呼ばれ、常に`True`か`False`というブール値に評価されなければなりません。

---

`if`の下のブロックを空にすることはできません。コロンの後にインデントされた行が続かないと、Pythonは`IndentationError`を発生させます。まだ実行することがない場合、通常のプレースホルダーとして`pass`が使われます。

---

コロンはブロックではなく`if`行に属します。条件の終わりを示し、下にあるインデントされた行がその文の一部であることを表します。

---

条件が`False`のとき、Pythonはインデントされたブロック全体をスキップし、`if`の下にインデントされていない次の行から処理を続けます。

---

Pythonでは条件を括弧で囲む必要はありません — `if True:`だけで完全な文です。ここでの括弧は算術で使われるのと同じ普通のグループ化であり、値を変えることはありません。

---

コードブロックは複数行を含むことができ、行は書かれた順に実行されます — 既存の文の上に追加された文が先に出力されます。

---

ブール変数はそれ単体で条件として使うことができます — 先に`True`や`False`と比較する必要はありません。

---

条件が変数の場合、`if`はその時点で変数が保持している値を読み取ります。上の代入を変えるだけでブロックを無効にでき、`if`行自体には触れる必要がありません。

---

条件文に属するインデントされた行はコードブロックと呼ばれます — インデントこそが、それらがブロックの一部であることを示すものです。

---

`if`のインデントの外にある行は、条件が何であっても実行されます。それはそもそもそのブロックの一部ではなかったからです。

---

コードブロックは1行に限定されません — すべての行が一貫してインデントされている限り、ロジックに必要なだけ短くも長くもできます。

---

`online`が`False`に設定されている場合、条件は決して成立しないので、ブロックはスキップされ、何も出力されません。

---

`if`の直後にインデントされた`print`だけがそのブロックに属します。`if`自体と同じインデントで書かれた行はブロックに属しません。

---

`if`ブロックの後に置かれていても、追加のインデントがない行はもはやそのブロックの一部ではありません — 条件が何であっても毎回実行されます。

---

ブロックにはいくつでも文を入れることができます。それらは上から下へ実行され、それぞれが他と同じレベルにインデントされている必要があります。

---

変数に`True`を代入すると、それを使う条件が成立するので、その下のブロックが実行されます。

---

代わりに`False`を代入すると条件が成立しなくなるので、その下のブロックは完全にスキップされます。

---

`if`キーワードは条件文を開始するものです — その条件とともに、下のブロックが実行されるかどうかを決定します。

---

クォートで囲まれた`"False"`はブール値ではなく文字列であり、空でない文字列は常に真として扱われます。ブロックの実行を防げるのは、クォートなしの`False`だけです。
```python
print(bool("False"))  # True
```

---

ここで`True`を選ぶと、最初の行だけでなくブロック内の両方の行が実行されます — `if`の下にインデントされたものはすべて同じブロックに属します。

---

コロンは`if`行に欠かせない要素です。条件を閉じ、ブロックを開きます。Pythonでは条件を囲む括弧は任意なので、`if True:`と`if (True):`はまったく同じように動作します。

---

`if`、`elif`、`else`のように、ブール値に基づいてコードを実行またはスキップする文は、まとめて条件文と呼ばれます。

---

`not`演算子はブール値を反転させます。`not True`は`False`、`not False`は`True`になります。
```python
is_online = False
print(not is_online)  # True
```

---

`not`は読み取った値を変更するのではなく、新しいブール値を作り出します。そのため、`is_afternoon = not is_morning`の後でも、変数`is_morning`は元の値を保持したままです。

---

条件は常に`if`キーワードとその後に続くコロンの間に置かれ、行の他の場所には置かれません。

---

`if`ブロックに含められる行数に厳密な上限はありません — 重要なのは、すべての行が同じレベルにインデントされ続けることです。

---

ブールリテラルは条件として申し分なく機能します。`if True:`は毎回そのブロックを実行します。`if (True):`と書いても、Pythonでは条件を囲む括弧が任意なので、まったく同じ文になります。

---

`if`文のコードブロックとは、その下にあるインデントされた行の集まりであり、そのインデントによってプログラムの他の部分と区別されます。

---

条件は常に`True`か`False`のどちらか一方に帰着します — それが条件をブール値たらしめるものです。
