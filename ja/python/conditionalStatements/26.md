# --description--

`online`が`False`に設定されている場合、条件は決して成立しないので、ブロックはスキップされ、何も出力されません。

# --instructions--

このコードは出力に何を表示しますか？
```python
online = False
if (online):
    print("Hello user!")
```

# --answers--

- Hello user!
- "Hello user!"
- 何も表示されない、コードはスキップされる
