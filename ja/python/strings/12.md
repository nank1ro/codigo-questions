# --description--

`replace(old, new)` は、`old` の**すべて**の出現箇所を `new` に置き換えた文字列のコピーを返します：
```python
text = "a-b-c"
print(text.replace("-", "+"))  # a+b+c
```
文字列はイミュータブルなので、結果を残しておきたい場合は忘れずに保存してください。
