# --description--

`+` が2つの文字列を連結する（**concatenation**）ことはすでに知っています。
`*` 演算子は文字列を指定した回数だけ**繰り返し**ます：
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
繰り返しは、区切り線や簡単なパターンをすばやく描く方法です。
