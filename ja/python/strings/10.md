# --description--

ユーザーが入力したテキストには、前後に余分なスペースが含まれていることがよくあります。
`strip()` メソッドは、**先頭と末尾の空白**（スペース、タブ、改行）を取り除いた文字列のコピーを返します：
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
テキストの途中にあるスペースはそのまま残ります。
`lstrip()` は左側のみ、`rstrip()` は右側のみを取り除きます。
