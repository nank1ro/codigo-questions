# --description--

文字列の各文字には**インデックス**と呼ばれる位置があります。
インデックスは `1` からではなく `0` から始まります：最初の文字はインデックス `0`、2番目はインデックス `1`、というように続きます。
文字列の後に角括弧でインデックスを書くと、1文字だけを読み取れます：
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
`word[6]` のように存在しないインデックスを指定すると、`IndexError` が発生します。
