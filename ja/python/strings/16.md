# --description--

**複数行**にまたがる文字列は、**トリプルクォート** `"""..."""`（または `'''...'''`）で書くことができます。
引用符の中の改行はすべて文字列の一部になるので、`\n` を使う必要はありません：
```python
poem = """Roses are red,
Violets are blue"""
print(poem)
```
これは次のように表示されます：
```
Roses are red,
Violets are blue
```
トリプルクォート文字列には、シングルクォートやダブルクォートを自由に含めることもできます。
