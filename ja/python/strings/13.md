# --description--

`find(sub)` は `sub` が最初に出現する位置の**インデックス**を返し、見つからない場合は `-1` を返します：
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` は `sub` が**何回**現れるかを返します：
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

`text` の中で最初に現れる `o` のインデックスを `position` に、`z` を検索した結果を `missing` に、`text` に含まれる `o` の数を `total` に格納してください
