# --description--

`startswith(prefix)` と `endswith(suffix)` は、文字列の始まり方や終わり方に応じて `True` か `False` を返します：
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
これらは、ファイル拡張子やプロトコル、接頭辞をチェックする一般的な方法です。

# --instructions--

`name` が `.py` で終わっていれば `True` を返す関数 `is_python_file(name)` と、`line` が `#` で始まっていれば `True` を返す関数 `is_comment(line)` を書いてください

# --solutions--

```python
def is_python_file(name):
    return name.endswith(".py")

def is_comment(line):
    return line.startswith("#")
```
