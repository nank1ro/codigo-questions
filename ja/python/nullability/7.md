# --description--

数値**または** `None` を返す関数は、シグネチャでそれを明示すべきです。**型ヒント**は、期待される型を文書化する注釈です。パラメータには `name: str`、戻り値には `-> int` のように書きます。Python はヒントを強制しませんが、エディタや読み手はそれを頼りにします：
```python
def parse_age(text: str) -> int | None:
    if text.isdigit():
        return int(text)
    return None
```
`int | None` は「`int` または `None`」と読みます。古い書き方である `typing` モジュールの `Optional[int]` はまったく同じ意味で、既存のコードではまだ出会うことになります。
シグネチャに `| None` を見つけたら、その結果を使う前に必ずチェックすることを忘れないでください。

戻り値の型は `int | None` とヒントされていなければなりません

```json
{
  "regex": "->\\s*(int\\s*\\|\\s*None|None\\s*\\|\\s*int|Optional\\[int\\])",
  "modifiers": ["m"],
  "shouldMatch": true

```

`parse_age("42")` は `42` を返す必要があります

```python
    def test_1(self):
        self.assertEqual(parse_age("42"), 42, "--err-t1--")
        self.assertIsInstance(parse_age("42"), int, "--err-t1--")
```

`parse_age("abc")` は `None` を返す必要があります

```python
    def test_2(self):
        self.assertIsNone(parse_age("abc"), "--err-t2--")
        self.assertIsNone(parse_age("4a"), "--err-t2--")
```

`parse_age("")` は `None` を返す必要があります

```python
    def test_3(self):
        self.assertIsNone(parse_age(""), "--err-t3--")
```
