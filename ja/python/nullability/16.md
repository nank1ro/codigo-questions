# --instructions--

辞書 `data` と `keys` のリストと省略可能な `default`（提供されなければ `None`）を受け取る関数 `get_path` を書いてください。キーを1レベルずつたどり、見つかった値を返す必要があります。いずれかのキーが存在しない、`None` を保持する、または途中のステップが辞書でないときは `default` を返します。`0` や `""` のような値はそのまま返す必要があります

# --asserts--

`default` のデフォルト値は `None` でなければなりません

```json
{
  "regex": "default\\s*=\\s*None",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` は `"Rome"` を返す必要があります

```python
    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")
        self.assertEqual(get_path(data, ["address"]), {"city": "Rome"}, "--err-t1--")
```

存在しない、`None`、辞書でないステップはデフォルトを返す必要があります

```python
    def test_2(self):
        data = {"address": None, "name": "Ada"}
        self.assertIsNone(get_path(data, ["address", "city"]), "--err-t2--")
        self.assertEqual(get_path(data, ["phone", "home"], "n/a"), "n/a", "--err-t2--")
        self.assertEqual(get_path(data, ["name", "first"], "n/a"), "n/a", "--err-t2--")
```

`0` と `""` はそのまま返す必要があります

```python
    def test_3(self):
        data = {"stats": {"count": 0, "note": ""}}
        self.assertEqual(get_path(data, ["stats", "count"], -1), 0, "--err-t3--")
        self.assertEqual(get_path(data, ["stats", "note"], "none"), "", "--err-t3--")
```

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
