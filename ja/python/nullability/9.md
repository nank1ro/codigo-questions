# --description--

`or` 演算子は `True` や `False` を返すのではありません。左のオペランドが真であればそれを返し、そうでなければ右のオペランドを返します。これにより、フォールバックを提供する1行の方法が得られます：
```python
name = None
print(name or "anonymous")  # anonymous
name = "Ada"
print(name or "anonymous")  # Ada
```
落とし穴は、`or` が `None` ではなく真偽値を見ることです：`0`、`""`、`[]` もフォールバックに置き換えられます。`x or fallback` を使うのは、すべての空の値もフォールバックになってよいときだけにしてください。

# --instructions--

このコードは何を出力しますか？
```python
def label(count):
    return count or "unknown"

print(label(0), label(None), label(5))
```

# --answers--

- `unknown unknown 5`：`0` は偽なので、フォールバックに置き換えられるため
- `0 unknown 5`：`None` だけがフォールバックに置き換えられるため
- `False unknown 5`：`or` が `0` をブーリアンに変換するため
- `True True True`：`or` は常にブーリアンを返すため
