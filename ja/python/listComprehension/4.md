# --description--

フィルタ条件は、`len()` のような関数呼び出しを含む、ブール値を返す任意の式にできます。
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```

リスト内包表記を使って、`words` の中で4文字より長い単語のリストを変数 `long_words` に格納してください
