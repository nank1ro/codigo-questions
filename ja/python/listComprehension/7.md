# --description--

内包表記の中では、それより前に定義された変数を、例えば `range()` の上限として使うことができます。

# --instructions--

`limit` 未満の7の倍数を出力するように項目を並べ替えてください

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--
