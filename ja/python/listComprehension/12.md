# --description--

内側の `for` は外側のものの変数を使うことができます。
これはリストのリストを1つのリストに**平坦化**する定番の方法です。
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
そして `sum()` 関数がリストの数値をすべて合計します。

# --instructions--

`matrix` を平坦化して、平坦化されたリストとその数値の合計を一緒に出力するように項目を並べ替えてください
