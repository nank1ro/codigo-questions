# --description--

**辞書**に対してもループすることができます。
`.items()` を使うと、`for` の部分が各ペアをキーと値の2つの変数に展開します。
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
