# --description--

`key: value` の部分が**ない**波括弧は、**集合内包表記**になります。
集合（set）は順序を持たず、一意な値だけを保持するコレクションなので、重複は自動的になくなります。
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```

words = ["hi", "yo", "hey"]
