# --description--

内包表記は**文字列の変換**にも最適です。
各要素に対して文字列メソッドを呼び出したり、f文字列で新しい文字列を組み立てたりできます。
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
