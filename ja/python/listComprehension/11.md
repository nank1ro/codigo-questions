# --description--

内包表記は**複数の `for`** を持つことができます。
これらはネストしたループのように動作し、最初の `for` が外側のループ、2番目が内側のループになります。
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
