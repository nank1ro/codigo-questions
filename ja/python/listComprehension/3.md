# --description--

内包表記は要素を**フィルタリング**することもできます。
`for` の後に `if` 条件を追加すると、条件が `True` になった要素だけが新しいリストに入ります。
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
これは中に `if` を持つループと同じであり、lambdaを使った `filter()` をより読みやすい形で置き換えます。
