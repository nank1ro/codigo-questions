# --description--

イテラブルはリストである必要はありません。ループできるものなら何でも使え、`range()` はその代表例です。
数値のリストを作る最も手早い方法です。
```python
squares = [n * n for n in range(4)]
print(squares)  # [0, 1, 4, 9]
```
`range(start, stop)` は `stop` を含まないことを覚えておいてください。

# --instructions--
