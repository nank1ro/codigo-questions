# --instructions--

項目を並べ替えて `users` 辞書と、`name in users` で参照をガードする `can_login` 関数を定義し、正しいパスワードの Ada と、登録されていない Grace について結果を出力して、出力 `True`、`False` になるようにしてください

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
