# --description--

`if value:` はすでに真理値を適用しているので、`== True` や `== False` との比較は不要であり、誤りにもなり得ます。`2 == True` は `False` ですが、`2` は真です。値そのものを判定してください:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
