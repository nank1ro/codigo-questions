# --instructions--

このコードは何を出力しますか?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`。`c` は `a` と同じリストの別名なので、`c` を通して追加すると `a` も変わり、`b` と異なるものになるから
- `True True [1, 2]`。`c = a` はリストをコピーするので、`a` は変わらないから
- `True False [1, 2, 3]`。`is` は値を比較し、`==` は同一性を比較するから
- `False False [1, 2, 3]`。`append` は新しいリストを作るので、`c` はもう `a` を指さないから
