# --description--

`not`、`and`、`or` が1つの式に現れると、Python はまず `not`、次に `and`、最後に `or` を適用します。つまり `a or b and c` は `a or (b and c)` を意味し、`not a == b` は `not (a == b)` を意味します:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
別のまとめ方を意図する場合は括弧を追加します。括弧は式を読みやすくもします。

# --instructions--

このコードは何を出力しますか?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`。`and` が `or` より先に適用されるため、式は `x == 3 or (x > 10 and x < 0)` と読めるから
- `False`。演算子は左から右へ適用されるため: `(x == 3 or x > 10) and x < 0`
- `False`。`x < 0` が偽であり、式のすべての条件が成り立つ必要があるから
- `SyntaxError`。`and` と `or` は括弧なしでは混在できないから
