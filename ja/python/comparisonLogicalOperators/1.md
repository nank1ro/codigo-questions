# --description--

比較演算子は2つの値を比較し、**ブール値** `True` または `False` を返します。`==` は等しい、`!=` は等しくない、`<` は未満、`>` は超える、`<=` は以下、`>=` は以上を表します:
```python
age = 18
print(age == 18)  # True
print(age != 18)  # False
print(age < 18)   # False
print(age >= 18)  # True
```
結果は変数に格納することも、そのまま出力することもできます。単独の `=` は代入であり、比較ではありません。
