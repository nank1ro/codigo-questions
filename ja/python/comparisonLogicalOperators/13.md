# --instructions--

`ch` がちょうど1文字で、その文字が小文字または大文字の母音 (`a`、`e`、`i`、`o`、`u`) のとき `True` を返し、空文字列を含むそれ以外の文字列では `False` を返す関数 `is_vowel(ch)` を書いてください

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` と `is_vowel("E")` は `True` を返さなければなりません

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` と `is_vowel("y")` は `False` を返さなければなりません

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

1文字ではない文字列は `False` を返さなければなりません

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

# --solutions--

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
