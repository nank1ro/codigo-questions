# --description--

ミックスインが `on` 句を持つと、その型のメンバーを**上書き**し、**`super`** を呼び出してチェーンの下にあるバージョンに届けられるようになります：

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log` はミックスイン自身の `log` ではなくその下にあるものなので、無限再帰にはなりません。このようなミックスインを `with A, B` で何段か重ねると、それぞれが前のものを包み込みます。呼び出しは**最後の**ミックスインに最初に入り、スーパークラスへと下っていきます。

# --instructions--

`String` 型の `input` を受け取り、そのまま返すメソッド `run` を持つクラス `Pipeline` を宣言してください。

`Pipeline` に対するミックスイン `Trimmed` は、トリムした入力を `super.run` に渡すことで `run` を上書きし、`Pipeline` に対するミックスイン `Upper` は、`super.run` の結果を大文字で返すことで `run` を上書きするように宣言してください。

`Pipeline` を継承し `Trimmed`、`Upper` の順で使うクラス `TextPipeline` と、`Pipeline` を継承し `Trimmed` だけを使うクラス `TrimOnly` を宣言してください。

例：
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

# --solutions--

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
