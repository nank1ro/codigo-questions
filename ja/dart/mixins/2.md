# --description--

ミックスインの本体はクラスの本体とよく似ています。メソッド、ゲッター、フィールドをまったく同じように書けます。違うのは、宣言そのものに対してできることです。

```dart
mixin Timestamped {
  String get stamp => '[log]';

  String format(String text) => '$stamp $text';
}

class Server with Timestamped {}
class Printer with Timestamped {}
```

ミックスインの名前は**型**としても機能するので、`Server() is Timestamped` は `true` になり、変数を `Timestamped t = Server();` と宣言できます。これで2つの無関係なクラスが、互いに継承することなく1つの実装を共有します。

# --instructions--

`String` 型の `text` を受け取り、大文字にして感嘆符を付けたものを返すメソッド `shout` を持つミックスイン `Shouter` を宣言してください。

`Shouter` を使い、自分では何も追加しないクラス `Speaker` を宣言してください。

例：
```dart
print(Speaker().shout('hi')); // HI!
```

# --asserts--

`Speaker().shout('hi')` は `'HI!'` であるべきです

```dart
  test('test1', () {
    expect(Speaker().shout('hi'), 'HI!', reason: '--err-t1--');
  });
```

`Speaker().shout('Dart rocks')` は `'DART ROCKS!'` であり、`Speaker().shout('')` は `'!'` であるべきです

```dart
  test('test2', () {
    expect(Speaker().shout('Dart rocks'), 'DART ROCKS!', reason: '--err-t2--');
    expect(Speaker().shout(''), '!', reason: '--err-t2--');
  });
```

`Speaker` はミックスインから `shout` を手に入れるはずなので、`Speaker` は `Shouter` でもあるべきです

```dart
  test('test3', () {
    expect(Speaker(), isA<Shouter>(), reason: '--err-t3--');
  });
```
