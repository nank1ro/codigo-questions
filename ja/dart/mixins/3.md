# --description--

ミックスインはメソッドに限定されません。**フィールド**も宣言でき、ミックスインを使うすべてのクラスのすべてのオブジェクトが、それぞれ自分専用のコピーを持ちます。

```dart
mixin Counter {
  int count = 0;

  void increment() {
    count++;
  }
}

class Clicker with Counter {}

void main() {
  final a = Clicker();
  final b = Clicker();
  a.increment();
  a.increment();
  print(a.count); // 2
  print(b.count); // 0, b has its own count
}
```

これがミックスインをインターフェース以上のものにしています。データと、それを扱うコードの両方をもたらすのです。

# --instructions--

次の内容を持つミックスイン `Scored` を宣言してください：
- `0` で始まる `int` 型のフィールド `score`
- `int` 型の `points` を受け取り `score` に加算するメソッド `addPoints`

`Scored` を使い、自分では何も追加しないクラス `Player` を宣言してください。

例：
```dart
final p = Player();
p.addPoints(3);
print(p.score); // 3
```

# --asserts--

新しい `Player` の `score` は `0` であり、`addPoints(3)` を呼ぶと `3` になるべきです

```dart
  test('test1', () {
    final p = Player();
    expect(p.score, 0, reason: '--err-t1--');
    p.addPoints(3);
    expect(p.score, 3, reason: '--err-t1--');
  });
```

`addPoints` の呼び出しは加算されるべきです

```dart
  test('test2', () {
    final p = Player();
    p.addPoints(3);
    p.addPoints(4);
    p.addPoints(10);
    expect(p.score, 17, reason: '--err-t2--');
  });
```

各 `Player` は自分専用の `score` を持つべきで、`Player` は `Scored` でもあるべきです

```dart
  test('test3', () {
    final a = Player();
    final b = Player();
    a.addPoints(5);
    expect(a.score, 5, reason: '--err-t3--');
    expect(b.score, 0, reason: '--err-t3--');
    expect(a, isA<Scored>(), reason: '--err-t3--');
  });
```
