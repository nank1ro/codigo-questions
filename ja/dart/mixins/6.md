# --description--

部品を組み合わせると、ミックスインを使うプログラムは3つの部分から成ります。`mixin` 宣言、`with` でそれを取り込む1つ以上のクラス、そして共有メンバーを呼び出すコードです。

```dart
mixin Barker {
  String bark() => 'Woof!';
}

class Dog with Barker {}

void main() {
  print(Dog().bark()); // Woof!
}
```

トップレベルの宣言は Dart では任意の順序で書けますが、ミックスインを使うクラスの前にミックスインがあると、ファイルを上から下に読みやすくなります。
