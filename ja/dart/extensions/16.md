# --instructions--

`String` に対する `Words` という名前の拡張を記述してください：
- `int` 型のゲッター `wordCount`。文字列の中の単語の個数であり、単語は1つのスペースで区切られる
- `String` 型のゲッター `initials`。各単語の最初の文字を大文字にしたものを、区切りなしで連結したもの

文字列には常に少なくとも1つの単語が含まれ、先頭・末尾のスペースや連続したスペースは決してありません。

例：
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
