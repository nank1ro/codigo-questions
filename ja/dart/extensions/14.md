# --instructions--

クラス `Temperature` が与えられています。`Temperature` に対する `Conversions` という名前の拡張を記述してください：
- `double` 型のゲッター `fahrenheit`。`celsius * 9 / 5 + 32` に等しい
- `double` 型のパラメータ `limit` を取り、`celsius` が `limit` より大きいときに `true` を返すメソッド `isAbove`

例：
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
