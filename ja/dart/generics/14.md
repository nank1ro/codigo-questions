# --description--

ジェネリッククラスには、他のクラスと同じように名前付きコンストラクタや**ファクトリ**コンストラクタを持てますし、型パラメータはその中でも使えます。ファクトリコンストラクタはオブジェクトそのものを生成しません。本体を実行して1つ返します。これにより、インスタンスを選んだり、再利用したり、好きな方法で構築したりできます。

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

型引数はコンストラクタ名ではなくクラスに付きます。`Box<int>.first(...)` のようになります。ファクトリの中では `<T>[]` は本物の空の `List<T>` なので、まだわからない型の既定値を作る場所としてファクトリは自然な選択です。

# --instructions--

型パラメータ `T` を1つ持ち、通常のコンストラクタで設定される型 `List<T>` の `final` フィールド `items`、空のリストで `Stack` を構築する**ファクトリ**コンストラクタ `Stack.empty()`、そして最後の要素を返し、スタックが空のときは `null` を返す型 `T?` のゲッター `top` を持つジェネリッククラス `Stack` を宣言してください。

例：
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

# --asserts--

`Stack<int>([1, 2, 3]).top` は `3` になるはずです

```dart
  test('test1', () {
    final stack = Stack<int>([1, 2, 3]);
    expect(stack.top, 3, reason: '--err-t1--');
    expect(stack.items, [1, 2, 3], reason: '--err-t1--');
  });
```

`Stack.empty()` は正しい型の空のスタックを構築し、その `top` は `null` になるはずです

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
    expect(stack, isA<Stack<String>>(), reason: '--err-t2--');
    expect(stack.items, <String>[], reason: '--err-t2--');
    expect(stack.top, null, reason: '--err-t2--');
  });
```

`Stack.empty()` で構築されたリストはそのまま使えるはずです

```dart
  test('test3', () {
    final stack = Stack<int>.empty();
    stack.items.add(4);
    stack.items.add(9);
    expect(stack.top, 9, reason: '--err-t3--');
    expect(Stack<bool>([true]).top, true, reason: '--err-t3--');
  });
```

# --solutions--

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
