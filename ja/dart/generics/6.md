# --description--

ジェネリッククラスの中では、型パラメータはどこからでも見えます。フィールド、コンストラクタのパラメータ、メソッドのシグネチャ、メソッドの本体です。クラス名の横で一度宣言すれば、すべてのメンバーがそれを使えます。

```dart
class Holder<T> {
  final T item;

  Holder(this.item);

  String describe() => 'holding $item';
}
```

型を決めるのはオブジェクトの生成です。`Holder<String>('fig')` は `item` を `String` にし、`Holder<int>(3)` はそれを `int` にします。

# --instructions--

項目を並べ替えて、型 `T` のフィールド `item`、コンストラクタ、メソッド `describe` を持つジェネリッククラス `Holder` を定義し、続いて `'fig'` で作った `Holder<String>` の説明を出力する `main` を定義してください。クラスは `main` の前に定義します。プログラムは次のように出力しなければなりません：

```
holding fig
```
