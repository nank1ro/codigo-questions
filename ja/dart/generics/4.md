# --description--

Dartに用意されているジェネリッククラスに限定されるわけではありません。自分で宣言することもできます。**型パラメータ**はクラス名の後に山括弧で囲んで書き、以降はクラス本体の中で通常の型として扱えます：

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` は単なるプレースホルダです。`Box` が作られるときに、明示的に、あるいは推論によって埋められます：

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, inferred from the argument
print(a.value + 1);      // 8, the compiler knows value is an int
```

文字そのものには意味がありません。`T` は「型」を表す慣習にすぎません。

# --instructions--

型パラメータ `T` を1つ持ち、コンストラクタで設定される型 `T` の `final` フィールド `value`、そして `Box of ` の後に値が続くテキストを返すゲッター `label` を持つジェネリッククラス `Box` を宣言してください。

例：
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` は `value` が `7`、`label` が `'Box of 7'` になるはずです

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` はどんな型でも動くはずです。`Box<String>('fig')` も `Box<String>` になるはずです

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

型引数はコンストラクタの引数から推論されるはずです

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
