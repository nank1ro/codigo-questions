# --description--

Dartには `dynamic` という型もあります。これは「何でもあり」を意味します。`List<dynamic>` はすべての値を受け入れるので、`List<String>` より便利に見えます：

```dart
List<dynamic> things = ['Ada', 'Grace'];
things.add(42);                    // 受け入れられる
print(things.first.toUpperCase()); // 受け入れられる
```

落とし穴は、コードを書いている間は何もチェックされないことです。`dynamic` の値に対するすべての呼び出しはプログラムの実行中に解決されるため、`things.first.toUpperCse()` のようなタイプミスでも問題なくコンパイルされ、ユーザーの目の前でクラッシュします。

ジェネリクスはその代替です。**どんな**型でも動く1つのコードを書きながら、使うたびには**1つの**型でチェックされます。これこそがこのトピックの要点です。

# --instructions--

`List<dynamic>` と `List<String>` はどちらも文字列 `'Ada'` と `'Grace'` を保持できます。`List<String>` には `List<dynamic>` にはない何が与えられますか？

# --answers--

- コンパイラがプログラムの実行前に `names.add(42)` を拒否し、`names.first` はすでに `String` である
- 文字列がよりコンパクトに格納されるため、メモリをあまり使わない
- リストが作成時の要素数を超えて成長するのを防ぐ
- リストが空のときに例外を投げる代わりに `names.first` が `null` を返すようにする
