# --description--

`await` は future のエラーを普通の例外に変えるので、再試行のループも含め、いつもの `try`/`catch` のパターンがそのまま非同期コードにも当てはまります。`catch` ブロックの中で **`rethrow`** は同じエラーをもう一度投げます。最後の試行のあとであきらめるにはこうします：

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

`Future<String> Function() task` のような関数型のパラメータは、future ではなく**関数**そのものを受け取ります。`task()` を呼ぶたびに新しい試行が始まります。

# --instructions--

`Future<int> Function()` の `task` と `int` の `attempts` を受け取り、`Future<int>` を返す `async` 関数 `retry` を書いてください。`task()` を呼び、その値で完了します。例外が投げられたらもう一度試し、`task` を合計で最大 `attempts` 回まで呼びます。最後の試行も失敗したら、そのエラーを `rethrow` してください。

例：
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

常に成功するタスクに対して、`retry` は1回の呼び出しでその値で完了するべきです

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

2回失敗してから `7` を返すタスクに対して、`retry` は `3` 回の呼び出しのあと `7` で完了するべきです

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

常に失敗するタスクに対して、`retry` はちょうど `attempts` 回それを呼び、そのあと同じエラーで失敗するべきです

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
