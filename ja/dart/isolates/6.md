# --description--

`Isolate.spawn` に渡される関数は**エントリーポイント**と呼ばれます。ちょうど1つのパラメーター、すなわち `Isolate.spawn` が渡すメッセージを受け取るトップレベル（または静的）関数でなければなりません。

```dart
void reportAnswer(SendPort port) {
  port.send(42);
}
```

`ReceivePort` に届くメッセージの静的な型は `dynamic` です。どんな値でも送られていた可能性があるからです。他の isolate が何を送るか分かっているなら、キャストします：

```dart
final receivePort = ReceivePort();
await Isolate.spawn(reportAnswer, receivePort.sendPort);
final answer = await receivePort.first as int;
```

# --instructions--

トップレベル関数 `sendGreeting` を書いてください。`SendPort` の `port` を受け取り、文字列 `hello from the isolate` をそれに送ります。

次に、`Future<String>` を返す関数 `greetFromIsolate` を書いてください。`ReceivePort` を作り、その `sendPort` で `sendGreeting` を起動し、受け取った最初のメッセージで完了します。

例：
```dart
print(await greetFromIsolate()); // hello from the isolate
```

# --solutions--

```dart
void sendGreeting(SendPort port) {
  port.send('hello from the isolate');
}

Future<String> greetFromIsolate() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendGreeting, receivePort.sendPort);
  return await receivePort.first as String;
}
```
