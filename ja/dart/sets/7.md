# --description--

セットは `Iterable` なので、リストと同様に `for-in` で直接その要素を反復処理できます。インデックスは存在せず、要素は挿入順に訪問されます：

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
