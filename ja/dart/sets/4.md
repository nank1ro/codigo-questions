# --description--

`.remove(value)` メソッドはセットから値を削除します。値が存在した場合は `true` を、存在しなかった場合は `false` を返します：

```dart
var numbers = {1, 2, 3};
print(numbers.remove(2)); // true
print(numbers.remove(9)); // false
print(numbers); // {1, 3}
```

すべての要素を一度に削除するには `.clear()` を使います。
