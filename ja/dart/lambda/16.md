# --description--

関数を受け取り関数を返す関数は、自由に組み合わせられます。古典的な例が**合成**です。1つの関数を実行し、その結果を別の関数に渡す新しい関数を作ることです：

```dart
int Function(int) then(int Function(int) first, int Function(int) second) {
  return (n) => second(first(n));
}
```

# --instructions--

2つのパラメータ `f` と `g`（どちらも `int Function(int)` 型）を受け取り、引数に `f` を適用し、その結果に `g` を適用する `int Function(int)` 型の関数を返す関数 `compose` を記述してください。

例：
```dart
var addThenDouble = compose((n) => n + 1, (n) => n * 2);
print(addThenDouble(3)); // 8
```
