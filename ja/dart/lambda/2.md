# --description--

無名関数は、名前付き関数とまったく同じように、パラメータを取り `return` で値を返すことができます。戻り値の型は書きません。Dartが本体の `return` 文から**推論**します：

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
