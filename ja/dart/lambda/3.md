# --description--

本体が単一の式である場合、無名関数も名前付き関数と同じように**アロー構文** `=>` を使えます。アローは波括弧と `return` キーワードの両方を置き換えます：

```dart
var add = (int a, int b) => a + b;

print(add(2, 3)); // 5
```

この短い形式は、Dartで無名関数を書く最も一般的な方法です。

# --instructions--

引数に `3` を掛けた値を返すアロー関数を `triple` に格納し、プログラムが `12` を出力するようにコードを完成させてください。
