# --description--

無名関数はどこにも格納する必要がありません。閉じ波括弧の直後に引数を書くことで**即座に呼び出す**ことができます。これは、周囲のコードに漏れてはならないいくつかの一時変数を使って値を計算するのに便利です：

```dart
var area = (double radius) {
  var pi = 3.14;
  return pi * radius * radius;
}(2.0);

print(area); // 12.56
```

ここで `pi` は無名関数の中にのみ存在し、`area` は返された値を受け取ります。
