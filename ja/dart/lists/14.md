# --description--

`.isEmpty` プロパティはリストに要素がない場合に `true` になり、`.isNotEmpty` は少なくとも1つの要素がある場合に `true` になります。

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
