# --description--

`.remove(value)` メソッドは、リストから `value` と等しい**最初の**要素を削除します。要素が削除された場合は `true`、値が見つからなかった場合は `false` を返します。

```dart
var colors = ['red', 'green', 'blue'];
bool removed = colors.remove('green');
print(removed); // true
print(colors); // [red, blue]
```
