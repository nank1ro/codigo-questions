# --description--

現実のデータは欠落だらけです。空のまま送られたフォーム項目、ファイルに存在しない列、数値になりきらない文字列。この章の道具は、それらを扱うために自然に組み合わせられます。欠けている要素を落とすには `nonNulls`、安全に変換するには `int.tryParse`、変換できなかったものを処理するには `??` か `if` チェックです。

# --instructions--

`List<String?>` 引数 `prices` を受け取り、`int` に変換できる値の合計を返す関数 `total` を書いてください。`null` の要素も、有効な整数でない文字列も無視します。

例：
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
