# --description--

**値を指定せずに**宣言されたnull許容の変数は `null` から始まるので、`= null` は省略できます：

```dart
int? age;
print(age); // null
```

非null許容の変数にはそのような既定値はありません。値が代入される前にそれを読み取るコードを、Dartはコンパイルしません。

```dart
int count;
print(count); // error: 'count' must be assigned before it can be used
```
