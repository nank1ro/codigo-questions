> 始める前に、Dartを教えることができてとても嬉しいということをお伝えしたいと思います。
このメッセージを通じて、あなたが使っているこのアプリはまさにDartで、Flutterフレームワークを使って書かれたものであることをお知らせします。ですので、この言語の専門知識を共有できることを光栄に思います。

Dartは他の多くのプログラミング言語と同様に、コードにドキュメントを記述することができます。
これにより、コードの横に任意のテキストを書くことができます。
コメントはコンパイラによって無視されます。

Dartは_単一行_コメント、_複数行_コメント、_ドキュメント_コメントをサポートしています。

_単一行_コメントの書き方は以下の通りです：
```dart
// これはコメントです。実行されません。
```

---

_単一行_コメントを重ねることで、_複数行_コメントを書くことができます。
```dart
// これは
// 複数行のコメント
```

---

コメントブロック、つまり_複数行_コメントを作成することもできます。
_複数行_コメントは`/*`で始まり、`*/`で終わります。
```dart
/*
This is a multi-line
comment
*/
```

---

これら2つのコメントの書き方に加えて、Dartには_ドキュメント_コメントがあります。

_ドキュメント_コメントは、`///`または`/**`で始まる複数行または単一行のコメントです。連続する行に`///`を使用すると、複数行のドキュメントコメントと同じ効果があります。

_ドキュメント_コメントは、ドキュメントを生成できるため非常に便利です。
特定のコードブロックが何をするかを明確にするために、コードに_ドキュメント_コメントを追加することをお勧めします。

_ドキュメント_コメント内では、アナライザは角括弧で囲まれた名前を他のAPI要素への参照として解決します。
角括弧を使用して、_クラス_、_メソッド_、_フィールド_、_変数_、_関数_、_パラメータ_を参照できます。

以下は例です：
```dart
/// 家畜化された南米のラクダ科動物（Lama glama）。
///
/// 他の動物と同じように、ラマも食べる必要があります、
/// [feed]を使って[Food]を与えるのを忘れずに。
class Llama {
  String? name;

  /// [food]をラマに与える。
  ///
  /// 典型的なラマは1週間に干し草を1束食べる。
  void feed(Food food) {
    // ...
  }

  /// [activity]でラマを運動させる、
  /// [timeLimit]分間。
  void exercise(Activity activity, int timeLimit) {
    // ...
  }
}
```

生成されたドキュメントでは、`[feed]`は`feed`メソッドのドキュメントへのリンクになり、`[Food]`は`Food`クラスのドキュメントへのリンクになります。
一方、`[activity]`と`[timeLimit]`はそれぞれ`activity`と`timeLimit`のドキュメントへのリンクになります。
