# --description--

最後の要素は、わざと `Error` を投げることです。何を受け付けるかを文書化している関数は、それ以外を大きな声で拒むべきで、`ArgumentError` がそのためのオブジェクトです：

```dart
int setVolume(int level) {
  if (level < 0 || level > 100) {
    throw ArgumentError('level must be between 0 and 100');
  }
  return level;
}
```

メッセージは `e.message` で取り出せ、`toString()` は `Invalid argument(s): ` に続けてそれを出力します。

これは前の規則と矛盾しません。`ArgumentError` を投げるのは正しく、捕まえるのは正しくありません：それは*呼び出し元*の書き手に、その呼び出し自体が間違っていると伝えるものであり、直し方は呼び出しの周りのハンドラーではなく、呼び出す前の確認だからです。

# --instructions--

`int` の `age` を受け取ってそれを返す関数 `checkAge` を書いてください。ただし、年齢が `0` より小さいか `120` より大きいときは `ArgumentError('age must be between 0 and 120')` を投げます。

例：
```dart
print(checkAge(30)); // 30
```

# --asserts--

`checkAge(30)` は `30` を返すべきで、範囲の両端も受け付けられるべきです

```dart
  test('test1', () {
    expect(checkAge(30), 30, reason: '--err-t1--');
    expect(checkAge(0), 0, reason: '--err-t1--');
    expect(checkAge(120), 120, reason: '--err-t1--');
  });
```

`checkAge(-1)` と `checkAge(121)` は `ArgumentError` を投げるべきです

```dart
  test('test2', () {
    expect(() => checkAge(-1), throwsArgumentError, reason: '--err-t2--');
    expect(() => checkAge(121), throwsArgumentError, reason: '--err-t2--');
  });
```

投げられたエラーは `'age must be between 0 and 120'` というメッセージを持つべきです

```dart
  test('test3', () {
    try {
      checkAge(200);
      fail('--err-t3--');
    } on ArgumentError catch (e) {
      expect(e.message, 'age must be between 0 and 120', reason: '--err-t3--');
    }
  });
```
