# --description--

`Exception` はインターフェースなので、あなた自身のクラスもその一つになれます。独自の例外は、失敗に `on` 節で選べる名前を与え、ハンドラーが読めるフィールドを与えます：

```dart
class EmptyCartException implements Exception {
  final String message;

  EmptyCartException(this.message);

  @override
  String toString() => 'EmptyCartException: $message';
}

throw EmptyCartException('nothing to pay for');
```

押さえておきたい部分は3つです：クラスを他の失敗と同じ仲間にするための `implements Exception`、詳細を運ぶ `final` フィールド、そして未処理の例外のレポートを読みやすくするためにオーバーライドした `toString()` です。このオーバーライドがないと、Dart はむき出しのクラス名を出力し、詳細は失われます。

# --instructions--

`Exception` を実装するクラス `InvalidEmailException` を定義してください。コンストラクタで設定される `final String` のフィールド `message` と、`'InvalidEmailException: '` にメッセージを続けて返す `toString()` を持たせます。

それから、`String` の `email` を受け取ってそれを返す関数 `checkEmail` を書いてください。ただし、メールアドレスが `'@'` を含まないときは `InvalidEmailException('missing @')` を投げます。

例：
```dart
print(checkEmail('ada@dart.dev')); // ada@dart.dev
```

# --asserts--

`checkEmail('ada@dart.dev')` はメールアドレスをそのまま返すべきです

```dart
  test('test1', () {
    expect(checkEmail('ada@dart.dev'), 'ada@dart.dev', reason: '--err-t1--');
  });
```

`checkEmail('nope')` は `InvalidEmailException` を投げるべきで、それは `Exception` でもあります

```dart
  test('test2', () {
    expect(() => checkEmail('nope'), throwsA(isA<InvalidEmailException>()), reason: '--err-t2--');
    expect(() => checkEmail('nope'), throwsA(isA<Exception>()), reason: '--err-t2--');
  });
```

投げられたオブジェクトは `'missing @'` というメッセージを持ち、`InvalidEmailException: missing @` と出力されるべきです

```dart
  test('test3', () {
    try {
      checkEmail('nope');
      fail('--err-t3--');
    } on InvalidEmailException catch (e) {
      expect(e.message, 'missing @', reason: '--err-t3--');
      expect(e.toString(), 'InvalidEmailException: missing @', reason: '--err-t3--');
    }
  });
```

# --solutions--

```dart
class InvalidEmailException implements Exception {
  final String message;

  InvalidEmailException(this.message);

  @override
  String toString() => 'InvalidEmailException: $message';
}

String checkEmail(String email) {
  if (!email.contains('@')) {
    throw InvalidEmailException('missing @');
  }
  return email;
}
```
