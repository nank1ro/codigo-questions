# --description--

1つの `try` ブロックの後ろには**複数の**節を続けられ、それぞれが別々の失敗から回復します。Dart は投げられたオブジェクトを上から下へ各節と比較し、一致した**最初の**ものを実行します：

```dart
try {
  return names[int.parse(text)];
} on FormatException {
  return 'not a number';
} on RangeError {
  return 'out of range';
} catch (e) {
  return 'unknown problem';
}
```

存在しないインデックスでリストを読むと **`RangeError`** が投げられるので、その1行のもつ2つの失敗は別々の答えを受け取ります。

最初に一致したものが勝つため、順番が重要です：より具体的な節の上に一般的な型のための節を置くと、それが常に勝ち、具体的な節は決して実行されなくなります。具体的な節を先に書き、安全網がほしければむき出しの `catch` を最後に書きます。

上の `on RangeError` 節は、複数の節をどう並べるかを見せるためだけにあるものです。`RangeError` は、プログラムが制御できない状況ではなく、コードの間違いを知らせるものです。そのような失敗は捕まえる代わりに防ぐべきである理由は、後の練習で説明します。

# --instructions--

`List<int>` の `scores` と `String` の `text` を受け取り、`text` が表す位置にある `scores` の要素を `'score '` に続けて返す関数 `lookup` を書いてください。

`text` が整数でないときは `'not a number'` を、位置が存在しないときは `'out of range'` を、それ以外の場合は `'unknown problem'` を返してください。

例：
```dart
print(lookup([10, 20, 30], '1')); // score 20
print(lookup([10, 20, 30], 'two')); // not a number
```

```dart
String lookup(List<int> scores, String text) {
  try {
    return 'score ${scores[int.parse(text)]}';
  } on FormatException {
    return 'not a number';
  } on RangeError {
    return 'out of range';
  } catch (e) {
    return 'unknown problem';
  }
}
```
