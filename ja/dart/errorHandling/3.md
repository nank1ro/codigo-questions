# --description--

むき出しの `catch` はすべてを受け入れるため、計画していなかった失敗まで隠してしまいます。ちょうど1種類だけを処理するには、`on` 節にその型を名前で指定します：

```dart
try {
  return int.parse(text);
} on FormatException catch (e) {
  return -1;
}
```

テキストが整数でないとき、`int.parse` は **`FormatException`** を投げるので、入力を読むときに指定すべき型はこれです。`on` 節はその型とそのサブタイプにだけ一致し、それ以外には何も一致しません：ほかの失敗はそのまま外へ伝播し、そのためのものではなかった回復に飲み込まれる代わりに、やはり表面に現れます。
