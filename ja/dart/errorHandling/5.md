# --description--

多くの場合、回復に投げられたオブジェクトはまったく必要ありません：型がすでにすべてを語っています。その場合は `catch` の部分を落とし、`on` 節だけを残します：

```dart
try {
  return int.parse(text);
} on FormatException {
  return 0;
}
```

2つの形式の違いは、変数を受け取るかどうかだけです：

- `on FormatException catch (e)` — その型に一致し、オブジェクトを `e` として渡してくれる
- `on FormatException` — その型に一致するが、変数はない
- `catch (e)` — すべてに一致し、オブジェクトを渡してくれる

使わない変数を省くことで、ハンドラーが実際に使うものがはっきりします。

# --instructions--

変数のない `on` 節を使って、整数でないテキストが `'not a number'` を返すように `half` を補完してください。
