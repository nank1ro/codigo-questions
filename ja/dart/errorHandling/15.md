# --description--

`try` ブロックをどこに置くかが、1つの失敗がどれだけの仕事を壊すかを決めます。ループの周りに置くと、最初の不正な要素がバッチ全体を終わらせます。ループの**中**に置くと、失われるのはその要素だけで、残りは処理され続けます：

```dart
for (final text in texts) {
  try {
    total += int.parse(text);
  } on FormatException {
    continue;
  }
}
```

これはファイルの取り込み、設定の一覧の読み取り、メッセージの待ち行列の処理といった日常的な形です：壊れた行が1つあっても、正しい行まで捨てるべきではありません。規則は前と同じです — `try` ブロックは失敗しうる文の周りに置き、それより大きくしないことです。

# --instructions--

`List<String>` の `texts` を受け取り、整数を表すものの合計を返し、それ以外を無視する関数 `sumOf` を書いてください。

読み取れない項目が1つあっても残りが止まらないように、ループの中で `int.parse` を `try`/`catch` と一緒に使ってください。

例：
```dart
print(sumOf(['1', 'x', '3'])); // 4
```

```dart
int sumOf(List<String> texts) {
  var total = 0;
  for (final text in texts) {
    try {
      total += int.parse(text);
    } on FormatException {
      continue;
    }
  }
  return total;
}
```
