# --description--

`firstWhere` は、テストに一致する最初の要素を返します。何も一致しないときは返す要素がないので、`StateError` を投げます：

```dart
final words = ['a', 'fg'];
print(words.firstWhere((w) => w.length > 3)); // Bad state: No element
```

`int.tryParse` と同じく、ライブラリは逃げ道も用意しています。名前付き引数 `orElse` は、何も一致しなかったときに使う値を作る関数を受け取ります：

```dart
print(words.firstWhere((w) => w.length > 3, orElse: () => 'none')); // none
```

選び方は前と同じです：「何も一致しない」がありふれた結果なら `orElse` を、データが壊れていて誰かが知らなければならないことを意味するなら引数なしの呼び出しを使います。

# --instructions--

`List<String>` の `words` を受け取る2つの関数を書いてください。

`firstLong` は `firstWhere` を使って3文字より長い最初の単語を返し、そのような単語がないときは `orElse` で `'none'` を返します。

`firstLongStrict` は同じことを `firstWhere` で行いますが、`orElse` は使わないので、そのような単語がないときは `StateError` を投げます。

例：
```dart
print(firstLong(['a', 'bcde', 'fg'])); // bcde
print(firstLong(['a', 'fg'])); // none
```

```dart
String firstLong(List<String> words) {
  return words.firstWhere((w) => w.length > 3, orElse: () => 'none');
}

String firstLongStrict(List<String> words) {
  return words.firstWhere((w) => w.length > 3);
}
```
