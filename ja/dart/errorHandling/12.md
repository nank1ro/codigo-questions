# --description--

ライブラリの中には、まったく投げない版を用意しているものもあります。`int.parse` の隣に、Dart には **`int.tryParse`** があります：変換は同じですが、テキストが数値でないときは投げる代わりに `null` を返します。

```dart
print(int.parse('42'));     // 42
print(int.tryParse('42'));  // 42
print(int.tryParse('42x')); // null
```

結果は `int?` なので、`??` 演算子がそのままデフォルト値に変えてくれます：

```dart
final port = int.tryParse(text) ?? 8080;
```

失敗がありふれたもので、代わりの値がほしいだけなら、これは `try` ブロックより短くて分かりやすいです。不正なテキストが本当に、上の誰かが知らなければならない失敗であるときのために `int.parse` を取っておきましょう。
