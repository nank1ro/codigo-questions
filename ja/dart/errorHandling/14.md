# --description--

`throw` と `try` は同じ関数の中にある必要はありません。仕事ができない関数が投げ、それについてどうすべきか知っている呼び出し元が捕まえます：

```dart
int ageFromText(String text) {
  final age = int.tryParse(text);
  if (age == null) throw FormatException('not a number');
  return age;
}
```

`ageFromText` は、不正な年齢がプログラムを終わらせるべきか、メッセージを表示すべきか、読み飛ばすべきかについて意見を持ちません — それは呼び出し元の決定であり、呼び出し元こそ `try` ブロックのあるべき場所です。この分担こそ、`-1` を返すより投げることに価値がある理由です：失敗は、それに答えられる唯一の場所に届きます。

`try` ブロックは最初の失敗で止まるので、失敗した呼び出しの後ろの文も飛ばされることを覚えておいてください。

  return age;
}

void main() {
  try {
    print(ageFromText('31'));
