# --instructions--

`enum Size { small, medium, large }`が与えられたとき、次のコードはどうなりますか？

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- コンパイルエラーになる: enumに対するswitch式はすべての値を網羅しなければならない
- コンパイルが通り、`Size.large`に対して`null`を返す
- コンパイルが通り、`Size.large`に対して実行時に例外をスローする
- コンパイルが通り、`Size.large`に対して自動的に`'L'`を返す
