# --instructions--

拡張enum `Planet`を完成させて、各値が自分の衛星数を保持するようにし、`Planet.mars`の衛星数を出力してください。

enum Planet {
  mercury(0),
  earth(1),
  mars(2)[/]

  final int moons;

  [/] Planet(this.moons);
}

void main() {
  print(Planet.mars.moons);
}
