# --description--

`.replaceAll(from, to)` メソッドは、`from` の**すべての**出現を `to` に置き換えた新しい文字列を返します。`.replaceFirst(from, to)` は最初の1つだけを置き換えます:

```dart
var text = 'a-b-c';
print(text.replaceAll('-', '+'));    // a+b+c
print(text.replaceFirst('-', '+'));  // a+b-c
```
