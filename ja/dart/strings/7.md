# --description--

`.substring(start, end)` メソッドは、インデックス `start` からインデックス `end` の直前まで（`end` は**含みません**）の部分文字列を返します。`end` を省略すると、文字列の末尾までのすべてを取得します:

```dart
var text = 'Hello Dart';
print(text.substring(0, 5));  // Hello
print(text.substring(6));     // Dart
```
