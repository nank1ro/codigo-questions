# --description--

**クラス**はオブジェクトを作成するための設計図です。Dartでは、`class`キーワードの後にクラス名と波括弧のペアを書いてクラスを定義します:

```dart
class Animal {
  // fields and methods go here
}
```

慣例として、クラス名には**PascalCase**（各単語の先頭を大文字にする）を使います。
