# --description--

**メソッドのオーバーライド**により、サブクラスはスーパークラスにすでに存在するメソッドの独自実装を提供できます。`@override`アノテーションを使います:

```dart
class Shape {
  double area() => 0;
}

class Circle extends Shape {
  double radius;
  Circle(this.radius);

  @override
  double area() => 3.14159 * radius * radius;
}
```

`@override`アノテーションは、意図的にスーパークラスのメソッドを置き換えていることをDart（や他の開発者）に伝えます。

# --instructions--

`String`の`'...'`を返すメソッド`sound()`を持つクラス`Animal`を作成してください。次に、`sound()`をオーバーライドして`'Woof'`を返すサブクラス`Dog`を作成してください。さらに、`sound()`をオーバーライドして`'Meow'`を返すサブクラス`Cat`を追加してください。
