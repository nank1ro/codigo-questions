# --description--

サブクラスのコンストラクタがスーパークラスのコンストラクタを呼び出す必要がある場合、**初期化リスト**の中で`super`キーワードを使います:

```dart
class Vehicle {
  String brand;
  Vehicle(this.brand);
}

class Car extends Vehicle {
  int doors;
  Car(String brand, this.doors) : super(brand);
}
```

`super(brand)`は`brand`引数を`Vehicle`のコンストラクタに転送します。
