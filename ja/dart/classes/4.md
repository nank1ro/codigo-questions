# --description--

前の演習で見た`this.x`パラメータは省略記法です。長い形式では、コンストラクタ本体の中で各パラメータをそのフィールドに代入します（`this.x`がフィールド、`x`がパラメータです）:

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

同じクラスは次のように書くこともできます:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

この短い形式は**initializing formals**と呼ばれます。

# --instructions--

initializing formalsの省略記法を正しく使っているのは次のうちどれですか？

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`

# --solutions--

- `Point(this.x, this.y);`
