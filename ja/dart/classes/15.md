# --description--

**ファクトリコンストラクタ**は`factory`キーワードを使い、オブジェクトの生成を制御できるようにします。たとえば、キャッシュされたインスタンスやサブタイプを返すことができます:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

`Logger()`を呼び出すたびに、同じインスタンスが返されます（シングルトンパターン）。

# --instructions--

`0`で初期化されたプライベートフィールド`_count`を持つクラス`Counter`を作成してください。`_count`を`1`増やすインスタンスメソッド`increment()`と、`_count`を返すゲッター`count`を追加してください。常に`_count = 0`で初期化された新しい`Counter`を返す`factory`コンストラクタ`Counter.start()`を使ってください（名前付きプライベートコンストラクタ`Counter._internal()`を使用）。

class Counter {
  int _count = 0;

  factory Counter.start() => Counter._internal();

  void increment() {
    _count++;
  }

  int get count => _count;
}
