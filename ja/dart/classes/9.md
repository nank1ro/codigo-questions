# --description--

**セッター**は、検証ロジックを実行しながら値を代入できる特別なメソッドです。`set`キーワードで定義します:

```dart
class Temperature {
  double _celsius = 0;

  double get celsius => _celsius;

  set celsius(double value) {
    if (value < -273.15) throw ArgumentError('Too cold!');
    _celsius = value;
  }
}
```

プライベートであることを示すため、フィールド名の先頭には`_`を付けることがよくあります。
