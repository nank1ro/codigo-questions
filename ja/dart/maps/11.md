# --description--

`.forEach()` メソッドは、すべてのペアに対して1回ずつ関数を実行します。この関数はキーと値の2つの引数を受け取ります：

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
