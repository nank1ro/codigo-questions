# --description--

`.keys` プロパティはマップのすべてのキーを、`.values` はすべての値を、挿入順に返します。これらは遅延評価の `Iterable` なので、実際の `List` が必要な場合は `.toList()` を呼び出してください：

```dart
var ages = {'Ann': 30, 'Bob': 25};
List<String> names = ages.keys.toList();
List<int> years = ages.values.toList();
print(names); // [Ann, Bob]
print(years); // [30, 25]
```
