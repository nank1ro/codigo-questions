# --description--

`.remove(key)` メソッドは、マップからキーとその値を削除します。削除された値を返しますが、キーが存在しなかった場合は `null` を返します：

```dart
var ages = {'Ann': 30, 'Bob': 25};
int? removed = ages.remove('Ann');
print(removed); // 30
print(ages); // {Bob: 25}
```

`.length` プロパティは、キーと値のペアの数を返します：

```dart
print(ages.length); // 1
```

# --instructions--
