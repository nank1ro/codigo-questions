# --description--

`toList()` のほかにも、ストリームにはすべてのイベントを**消費**して単一の `Future` を返すメソッドがあります：

- `first` と `last` は最初または最後のイベントで完了します
- `length` はイベントの個数で完了します
- `join(separator)` はすべてのイベントを1つの `String` に連結した結果で完了します
- `reduce(combine)` はイベントを2つずつまとめて1つの値にします

```dart
final numbers = Stream.fromIterable([3, 9, 2]);
print(await numbers.reduce((a, b) => a + b)); // 14
```

`reduce` はそれまでの結果と次のイベントを `combine` に渡します。ストリームが空だと例外を投げるので、イベントが少なくとも1つあると保証されるときだけ使ってください。

# --instructions--

2つの関数を書いてください：
- `largest`：`Stream<int>` の `source` を受け取り、`reduce` を使って最大の値で完了する `Future<int>` を返します。ストリームには必ず少なくとも1つのイベントがあります。
- `sentence`：`Stream<String>` の `words` を受け取り、すべての単語を半角スペース1つでつないだ結果で完了する `Future<String>` を返します。

例：
```dart
print(await largest(Stream.fromIterable([3, 9, 2])));        // 9
print(await sentence(Stream.fromIterable(['I', 'am', 'Dart']))); // I am Dart
```

# --solutions--

```dart
Future<int> largest(Stream<int> source) {
  return source.reduce((a, b) => a > b ? a : b);
}

Future<String> sentence(Stream<String> words) {
  return words.join(' ');
}
```
