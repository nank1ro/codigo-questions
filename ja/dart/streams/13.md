# --description--

ここまで見てきたストリームは**シングルサブスクリプション**です。リスナーはちょうど1つしか許されません。`listen`、`await for`、あるいは消費メソッドを2度目に呼ぶと `StateError`（"Stream has already been listened to"）が投げられます。

1つのストリームを複数のリスナーで共有するには、`asBroadcastStream()` で**ブロードキャスト**ストリームに変換します：

```dart
final shared = Stream.fromIterable([1, 2, 3]).asBroadcastStream();
final total = shared.reduce((a, b) => a + b);
final count = shared.length;
print(await total); // 6
print(await count); // 3
```

ブロードキャストストリームはバッファーを持ちません。リスナーは購読した**あと**に送り出されたイベントしか受け取りません。例では両方のリスナーが最初の `await` より前に購読しているので、どちらもすべてのイベントを受け取ります。

# --instructions--

`Stream<int>` の `source` を受け取り、値の合計と値の個数という2要素のリストで完了する `Future<List<int>>` を返す関数 `sumAndCount` を書いてください。`source` をブロードキャストストリームに変換し、どちらかを待つ**前に**両方の消費呼び出しを開始してから、それらを待ちます。ストリームには必ず少なくとも1つのイベントがあります。

例：
```dart
print(await sumAndCount(Stream.fromIterable([1, 2, 3]))); // [6, 3]
```

```dart
Future<List<int>> sumAndCount(Stream<int> source) async {
  final shared = source.asBroadcastStream();
  final sum = shared.reduce((a, b) => a + b);
  final count = shared.length;
  return [await sum, await count];
}
```
