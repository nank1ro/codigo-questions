# --description--

ジェネレーターは1つの関数の中でイベントを生み出します。イベントが**別の場所**（ボタン、ネットワークのコールバック、他のオブジェクト）から来る場合は、**`StreamController`** が必要です。これは `dart:async` ライブラリにあるので、ファイルの先頭に `import 'dart:async';` が必要です。

コントローラーはストリームを持ち、そこにイベントを送り込ませてくれます：

```dart
import 'dart:async';

Stream<int> dice() {
  final controller = StreamController<int>();
  controller.add(4);
  controller.add(2);
  controller.close();
  return controller.stream;
}
```

- `add(value)` は1つのイベントを送ります
- `close()` はストリームを終わらせます。忘れるとリスナーは永遠に待ち続けます
- `stream` はリスナーが消費する `Stream` です

誰かが購読する前に追加されたイベントはバッファーに保持されるので、上のコードは安全です。あとから来たリスナーもちゃんと `4` と `2` を受け取ります。

# --instructions--

`List<String>` の `names` を受け取り、`StreamController` で作った `Stream<String>` を返す関数 `announce` を書いてください。各名前を大文字にして追加し、コントローラーを閉じて、そのストリームを返します。`dart:async` のインポートを忘れないでください。

例：
```dart
print(await announce(['ada', 'linus']).toList()); // [ADA, LINUS]
```

# --solutions--

```dart
import 'dart:async';

Stream<String> announce(List<String> names) {
  final controller = StreamController<String>();
  for (final name in names) {
    controller.add(name.toUpperCase());
  }
  controller.close();
  return controller.stream;
}
```
