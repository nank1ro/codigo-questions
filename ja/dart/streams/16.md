# --instructions--

`Stream<int>` の `source` を受け取り、その値の合計で完了する `Future<int>` を返す関数 `sumUntilError` を書いてください。ストリームがエラーを送り出したら、例外を投げるのではなく、そこで止めてエラーの**前に**受け取った値の合計で完了してください。

例：
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

`5`、`3` に続いてエラーを送り出すストリームに対する `sumUntilError` は `8` で完了するべきです

  test('test2', () async {
    Stream<int> broken() async* {

  });

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
