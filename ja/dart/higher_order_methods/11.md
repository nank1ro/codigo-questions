# --description--

Dart には `sorted` メソッドはありません。`sort` は `List` のメソッドで、リストを**その場で（in place）**並べ替え、何も返しません：

```dart
final numbers = [3, 1, 2];
numbers.sort();
print(numbers); // [1, 2, 3]
```

`void` を返すため、結果を利用することはまったくできません：`final sorted = numbers.sort();` は、コンパイラが読み取りを許さない値になります。順序付きの**コピー**を作る定番の書き方は、`toList()` の後にカスケード `..sort()` を続けるものです：`toList()` がコピーを作り、`..` はコピー自身を返しながらそのコピーに `sort` を実行します。

```dart
final numbers = [3, 1, 2];
final sorted = numbers.toList()..sort();
print(sorted);  // [1, 2, 3]
print(numbers); // [3, 1, 2], untouched
```

`sort` は**コンパレータ**も受け取れます：2つの要素を取り、最初の要素が2番目より先に来るなら負の数、等しければ `0`、そうでなければ正の数を返す関数です。`compareTo` はまさにそれを返すため、任意のキーでの並べ替えは1行で書けます：

```dart
final words = ['kiwi', 'fig', 'banana'];
print(words.toList()..sort((a, b) => a.length.compareTo(b.length)));
// [fig, kiwi, banana]
```

# --instructions--

`List<String>` 型の `words` を受け取り、同じ単語を短い順から長い順に並べた**新しい**リストを返し、`words` は元のまま残す関数 `byLength` を記述してください。

例：
```dart
print(byLength(['kiwi', 'fig', 'banana'])); // [fig, kiwi, banana]
```

# --asserts--

`byLength(['kiwi', 'fig', 'banana'])` は `['fig', 'kiwi', 'banana']` であるべきです

```dart
  test('test1', () {
    expect(byLength(['kiwi', 'fig', 'banana']), ['fig', 'kiwi', 'banana'],
        reason: '--err-t1--');
  });
```

`byLength` は `List<String>` を返すべきで、空のリストでも動作するべきです

```dart
  test('test2', () {
    expect(byLength(['bb', 'a']), isA<List<String>>(), reason: '--err-t2--');
    expect(byLength(['bb', 'a']), ['a', 'bb'], reason: '--err-t2--');
    expect(byLength(<String>[]), <String>[], reason: '--err-t2--');
  });
```

`byLength` は受け取ったリストを変更してはなりません

```dart
  test('test3', () {
    final original = ['kiwi', 'fig', 'banana'];
    final result = byLength(original);
    expect(original, ['kiwi', 'fig', 'banana'], reason: '--err-t3--');
    expect(result, ['fig', 'kiwi', 'banana'], reason: '--err-t3--');
  });
```
