# --instructions--

`all`にあって`done`にない名前を含む配列を出力するように行を並べ替えてください。
`done`より前に`all`を宣言してください

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
