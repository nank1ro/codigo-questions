# --description--

`add()`はセット自体を返すため、複数の呼び出しをチェーンできます：
```javascript
let letters = new Set();
letters.add("a").add("b");
```
チェーンするかどうかにかかわらず、すでに存在する値が2回目に追加されることはないため、`size`は各値を1回だけカウントします。

# --instructions--

このコードは何を出力しますか？
```javascript
let letters = new Set();
letters.add("a").add("b").add("a");
console.log(letters.size);
```
