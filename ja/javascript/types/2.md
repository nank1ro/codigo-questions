# --description--

JavaScriptは**動的型付け**言語です。変数自体には型がなく、現在保持している値だけが型を持ちます。同じ変数は今は数値を保持し、後で文字列を保持することもでき、`typeof`は値に従います:
```javascript
let data = 10;
console.log(typeof data);
// prints number
data = "ten";
console.log(typeof data);
// prints string
```
これは便利ですが、関数が予期しない型の値を受け取る可能性もあるという意味です。そのため、`typeof`でチェックすることはよくある最初のステップです。`typeof`は文字列を返すので、その結果を文字列と比較します:
```javascript
if (typeof data === "string") {
  console.log("text");
}
```

# --asserts--

`sameType(1, 2.5)` は `true` を返すべきです。すべての数値は `number` 型だからです

```javascript
tryCatch(sameType(1, 2.5) === true);
```

`sameType(1, "1")` は `false` を返すべきです

```javascript
tryCatch(sameType(1, "1") === false);
```

`sameType("", "a")` は `true` を返すべきです

```javascript
tryCatch(sameType("", "a") === true);
```

`sameType(true, 1)` は `false` を返すべきです

```javascript
tryCatch(sameType(true, 1) === false);
```

`sameType(null, {})` は `true` を返すべきです。`typeof null` が `"object"` だからです

```javascript
tryCatch(sameType(null, {}) === true);
```

`sameType(undefined, null)` は `false` を返すべきです

```javascript
tryCatch(sameType(undefined, null) === false);
```
