# --description--

インスタンスではなくクラスそのものに属する振る舞いがあります。例えば、2つの単位の間の変換は、操作対象のオブジェクトを必要としません。メソッドに **`static`** を付けると、そのメソッドはクラス上に置かれます：
```javascript
class MathUtils {
    static double(n) {
        return n * 2;
    }
}
console.log(MathUtils.double(4));
// prints 8
```
静的メソッドはインスタンスではなくクラス名に対して呼び出します。`new MathUtils().double(4)` は `TypeError` を投げます。インスタンスは静的メンバーを受け取らないからです。静的メソッドの中では `this` はクラスを指すので、`this.otherStatic(...)` で別の静的メソッドを呼び出せます。

`Temperature.toFahrenheit(0)` は `32` を返すべきです

```javascript

```

`Temperature.toFahrenheit(100)` は `212` を返すべきです

```javascript
tryCatch(Temperature.toFahrenheit(100) === 212);
```

`Temperature.toCelsius(32)` は `0` を返すべきです

```javascript
tryCatch(Temperature.toCelsius(32) === 0);
```

`Temperature.toCelsius(212)` は `100` を返すべきです

```javascript
tryCatch(Temperature.toCelsius(212) === 100);
```

両方のメソッドは静的であるべきなので、インスタンスはそれらを持ってはいけません


# --solutions--

```javascript
class Temperature {
  static toFahrenheit(celsius) {
    return celsius * 9 / 5 + 32;
  }
  static toCelsius(fahrenheit) {
    return (fahrenheit - 32) * 5 / 9;
  }
}
```
