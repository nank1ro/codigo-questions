# --description--

セッターの真の価値は、拒否できることにあります。代入と格納される値の間で、届いた値を確認したり、範囲内に収めたり、拒否したりする機会が得られます：
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// prints 3, the setter rejected 50
```
同じ名前のゲッターとセッターは1つのプロパティを形作るので、同時に通常のフィールドにはなれません。格納される値は別の名前の下に置きます。慣習としては、先頭にアンダースコアを付けた同じ名前です。

# --asserts--

ゲッターはコンストラクタに渡された値を返すべきです

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

セッターは有効な値を受け入れるべきです

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

セッターは負の値を無視すべきです

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

セッターは `0` を受け入れるべきです

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

値は `_temperature` に格納されるべきです

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```
