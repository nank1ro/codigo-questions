# --description--

`super()` についてのルールは「どこかで呼べばよい」よりも厳密です。子のコンストラクタ内では、`super()` が実行されるまで `this` という言葉は存在しません。オブジェクトを作るのは親のコンストラクタだからです。その行より前に `this` に触れると例外が投げられます：
```javascript
class Child extends Base {
    constructor() {
        this.x = 1; // ReferenceError
        super();
    }
}
```
したがって、`this` を使う子のコンストラクタでは、`super(...)` を**最初の文**にすべきです。

# --instructions--

このプログラムを実行すると何が起こりますか？
```javascript
class Base {
  constructor() {
    this.a = 1;
  }
}
class Child extends Base {
  constructor() {
    this.b = 2;
    super();
  }
}
console.log(new Child().a);
```

# --answers--

- `super()` の前に `this` が使われているため、`ReferenceError` が投げられる
- `1` を出力する
- `2` を出力する
- `undefined` を出力する
