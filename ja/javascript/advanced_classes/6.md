# --description--

クラスが互いを継承するときは順序が重要です。`class` 宣言は `function` のように巻き上げられ**ません**。名前はクラスが書かれた行以降でのみ存在します。そのため、子クラスは継承する親より*後*に現れなければなりません。そうしないと `extends` 節が `ReferenceError` で失敗します。

# --instructions--

項目を並べ替えて動作するプログラムにしてください。親クラスは子より先に定義しなければならないことを忘れないでください

# --answers--

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
```

```javascript
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
```

```javascript
console.log(new Car().describe());
```
