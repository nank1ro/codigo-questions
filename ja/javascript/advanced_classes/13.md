# --description--

メソッドもプライベートにできます。名前の前に `#` を付けると、そのメソッドはクラスの公開部分から消えますが、他のどのメソッドからでも `this.#name(...)` で呼び出せます：
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// prints $7
```
これが、ヘルパーの処理を API の外に追いやる方法です。呼び出し側に見えるのは `print` で、その背後にある整形の詳細は見えません。プライベートフィールドとプライベートメソッドを合わせれば、クラスには明確な内側と外側ができます。

# --instructions--

`0` で始まるプライベートフィールド `#points`、`0` より大きい数だけを加算するプライベートメソッド `#add`、引数を `#add` に転送する公開メソッド `record`、ポイントを返すゲッター `total` を持つクラス `Score` を作成してください

# --asserts--

新しいスコアは `0` で始まるべきです

```javascript
tryCatch(new Score().total === 0);
```

正の値は加算されるべきです

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

負の値は無視されるべきです

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

ゼロは無視されるべきです

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

ポイントはプライベートであるべきなので、インスタンスは公開プロパティを持ってはいけません

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

ヘルパーはプライベートメソッドであるべきです

```json
{
  "regex": "this\\.#add\\s*\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
