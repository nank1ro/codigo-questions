# --description--

**`instanceof`** 演算子は、オブジェクトがあるクラス、あるいはそれを継承する任意のクラスから作られたかどうかを調べます：
```javascript
class Animal {}
class Dog extends Animal {}
const max = new Dog();
console.log(max instanceof Dog);    // true
console.log(max instanceof Animal); // true, Dog extends Animal
```
JavaScript には `abstract` キーワードがありませんが、同じ考え方を手で書けます。基底クラスが形を定義し、子が*必ず*提供しなければならないメソッドは単に例外を投げるのです：
```javascript
class Shape {
    area() {
        throw new Error("area() must be implemented");
    }
}
```
`area` のオーバーライドを忘れた子は、黙って `undefined` を返す代わりに、最初に使われた時点で大きな音を立てて失敗します。

# --instructions--

メソッド `area` が `Error` を投げるクラス `Shape` と、それを継承して `side` を受け取り、`area` をオーバーライドして正方形の面積を返すクラス `Square` を作成してください


```javascript

```

正方形は `Shape` であるべきです

```javascript
tryCatch(new Square(3) instanceof Shape === true);
```

基底クラスの `area` の呼び出しは例外を投げるべきです

```javascript

}
tryCatch(_threw === true);
```

# --solutions--

```javascript
class Shape {
  area() {
    throw new Error("area() must be implemented");
  }
}

class Square extends Shape {
  constructor(side) {
    super();
    this.side = side;
  }
  area() {
    return this.side * this.side;
  }
}
```
