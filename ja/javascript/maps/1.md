# --description--

**マップ**は**キーと値のペア**を格納します：それぞれの値はキーの下に保存され、そのキーを使って値を再び見つけることができます。
`new Map()`で空のマップを作成し、`set(key, value)`でペアを追加し、`get(key)`で値を読み取ります：
```javascript
let ages = new Map();
ages.set("Ann", 30);
ages.set("Bob", 25);
console.log(ages.get("Ann"));
// prints 30
```
すでに存在するキーで`set()`を呼び出すと、その値が置き換えられます。
