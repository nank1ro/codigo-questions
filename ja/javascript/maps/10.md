# --description--

マップには`sort()`や`filter()`のような配列のメソッドがありません。それらを使うには、`Array.from()`かスプレッド演算子`...`でマップ（またはそのキーや値）を配列に変換します：
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
逆の変換、`Object.fromEntries(ages)`は、マップをプレーンなオブジェクトに戻します。

# --asserts--

キー`"pear"`、`"apple"`、`"kiwi"`を持つマップに対する`sortedKeys`は`["apple", "kiwi", "pear"]`を返すべきです

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

空のマップに対する`sortedKeys`は`[]`を返すべきです

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
