# --description--

良いコメントは、コードが**何を**するかではなく、**なぜ**そうするのかを説明します。何が起きるかはコード自体が示しています。それを言葉で繰り返すとノイズが増え、コードが変わった途端に古くなります。
```javascript
// timeout を30に設定する
const timeout = 30;
```
その数字の背後にある理由こそ、読む人には推測できないものです。
```javascript
// サーバーは35秒後にアイドル接続を切断するため、早めに停止する
const timeout = 30;
```
コメントが下の行を言い換えているだけなら、削除するか、理由に置き換えましょう。
