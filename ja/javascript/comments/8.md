# --description--

複数行を一度にコメントアウトするには、各行に `//` を付ける代わりに、それらを 1 つのブロックコメントで囲みます。
```javascript
let total = 100;
/*
total = total - 30;
total = total - 20;
*/
console.log(total); // prints 100
```
ブロックの中の行は無視されるので、`total` は変化しません。これはそれらの行に `*/` が含まれていない場合にのみ有効であることを覚えておいてください。

# --instructions--
