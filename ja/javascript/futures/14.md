# --description--

`Promise.all`は、1つでもプロミスが拒否されると諦めます。それでもすべての結果が欲しいときは、**`Promise.allSettled(promises)`**を使ってください。`Promise.allSettled`は決して拒否されず、プロミスごとに1つの小さなオブジェクトを同じ順序で入れて履行されます：

- 成功したものは `{ status: "fulfilled", value: ... }`
- 失敗したものは `{ status: "rejected", reason: ... }`

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
`status`が`"fulfilled"`のときだけ`value`を、`"rejected"`のときだけ`reason`を読んでください。もう片方のプロパティは単に存在しません。

# --asserts--

`await countFulfilled([])` は `0` であるべきです

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` は `2` であるべきです

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

3つのうち1つが拒否された場合、答えは `2` である必要があります

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

すべてのプロミスが拒否された場合、答えは `0` であり、`countFulfilled` が拒否されてはいけません

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
