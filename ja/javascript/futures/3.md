# --description--

値が本当に後で届くときは、**`new Promise`**で自分でプロミスを作ります。`new Promise`は関数を1つ受け取り、その関数は**`resolve`**コールバックを受け取ります。値の準備ができたら`resolve(value)`を呼び出すと、プロミスはその値で履行されます。
```javascript
const soon = new Promise((resolve) => {
  setTimeout(() => resolve("done"), 1000);
});
```
`setTimeout(callback, ms)`は`ms`ミリ秒後に`callback`が実行されるようスケジュールし、すぐに返ります。その間、何もブロックされません。

`new Promise`に渡された関数はすぐに実行されますが、`resolve`が呼ばれるまでプロミスは**pending**のままです。awaitすると値が得られます：
```javascript
async function main() {
  console.log(await soon);
  // prints done, about one second later
}

main();
```

# --asserts--

`delay(10, "ok")` はプロミスを返す必要があります

```javascript
(async () => {
  tryCatch(delay(10, "ok") instanceof Promise);
})().catch(() => tryCatch(false));
```

`await delay(0, 7)` は `7` であるべきです

```javascript
(async () => {
  tryCatch((await delay(0, 7)) === 7);
})().catch(() => tryCatch(false));
```

`await delay(10, "ok")` は `"ok"` であるべきです

```javascript
(async () => {
  tryCatch((await delay(10, "ok")) === "ok");
})().catch(() => tryCatch(false));
```

`await delay(60, "x")` は少なくとも `50` ミリ秒かかる必要があります

```javascript
(async () => {
  const start = Date.now();
  await delay(60, "x");
  tryCatch(Date.now() - start >= 50);
})().catch(() => tryCatch(false));
```
