# --description--

`await`の周りの`try` / `catch`のよくある使い方は、失敗を適切なデフォルト値に置き換えることです。そうすれば、呼び出し元はエラーを扱う必要がありません：
```javascript
async function sizeOf(path) {
  try {
    return await measure(path);
  } catch (error) {
    return 0;
  }
}
```
値をすぐに返す場合でも、`measure(path)`の前の`await`は残してください。`await`がないと、プロミスは`try`ブロックを通らずに関数の外へ出てしまい、拒否が`catch`から逃げてしまいます。

# --instructions--

関数`parseLater`は、`text`に書かれた数値で履行されるか、`text`が数値でないときに拒否されるプロミスを返します。その数値を返し、`parseLater`が失敗したときは`-1`を返す`async`関数`safeParse`を書いてください。`try`と`catch`を使ってください

# --asserts--

`await safeParse("12")` は `12` であるべきです

```javascript
(async () => {
  tryCatch((await safeParse("12")) === 12);
})().catch(() => tryCatch(false));
```

`await safeParse("-7.5")` は `-7.5` であるべきです

```javascript
(async () => {
  tryCatch((await safeParse("-7.5")) === -7.5);
})().catch(() => tryCatch(false));
```

`await safeParse("abc")` は `-1` であるべきです

```javascript
(async () => {
  tryCatch((await safeParse("abc")) === -1);
})().catch(() => tryCatch(false));
```

`safeParse("oops")` は履行される必要があり、決して拒否されてはいけません

```javascript
(async () => {
  let ok = false;
  await safeParse("oops").then(() => { ok = true; }, () => { ok = false; });
  tryCatch(ok);
})().catch(() => tryCatch(false));
```

```javascript
function parseLater(text) {
  return new Promise((resolve, reject) => {
    const value = Number(text);
    if (Number.isNaN(value)) {
      reject(new Error(`not a number: ${text}`));
    } else {
      resolve(value);
    }
  });
}

async function safeParse(text) {
  try {
    return await parseLater(text);
  } catch (error) {
    return -1;
  }
}
```
