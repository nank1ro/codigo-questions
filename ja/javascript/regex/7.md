# --description--

パターンの一部を括弧で囲むと**キャプチャグループ**が作られます: その部分がマッチしたテキストは脇に保存され、後で読み取れます。

グループは `match[0]` の後に現れ、開き括弧の位置に応じて左から右へ番号が付きます:
```javascript
const match = "2026-09-12".match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(match[0]);
// prints 2026-09-12
console.log(match[1]);
// prints 2026
console.log(match[3]);
// prints 12
```
つまり `match[0]` は常にマッチ全体で、`match[1]`、`match[2]`、... がグループです。パターンがまったくマッチしなければ、グループがあっても `match` 全体が `null` を返します。
