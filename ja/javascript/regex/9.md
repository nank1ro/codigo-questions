# --description--

括弧の数を数え続けるのは大変ですし、パターンの途中にグループを追加すると、それ以降の番号がすべてずれてしまいます。**名前付きグループ**はどちらの問題も回避できます: 開き括弧の直後に `?<name>` と書き、`match.groups` から部分を読み戻します:
```javascript
const match = "2026-09-12".match(/(?<year>\d{4})-(?<month>\d{2})-\d{2}/);
console.log(match.groups.year);
// 2026 を出力
console.log(match.groups.month);
// 09 を出力
```
名前付きグループにも番号は付くので `match[1]` は引き続き動作しますが、`match.groups.year` はその値が何を意味するのかを教えてくれます。パターンに名前付きグループがまったくないとき、`match.groups` は `undefined` です。

# --instructions--

このプログラムは何を出力しますか？
```javascript
const match = "mail bob@shop now".match(/(?<user>\w+)@(?<host>\w+)/);
console.log(`${match.groups.user} at ${match.groups.host}`);
```

# --answers--

- `bob at shop`
- `undefined at undefined`
- `bob@shop at bob@shop`
- `user at host`
