# --description--

`g` フラグを使えばマッチしたすべての文字列が得られますが、グループは捨てられてしまいます。*すべての*マッチのグループが必要なときは **`matchAll`** を使います。これは完全なマッチオブジェクトのイテレータを返し、各オブジェクトは普通の `match` の結果とまったく同じものです:
```javascript
const text = "a=1;b=2";
for (const match of text.matchAll(/(?<key>\w+)=(?<value>\w+)/g)) {
  console.log(`${match.groups.key} -> ${match.groups.value}`);
}
// prints a -> 1
// prints b -> 2
```
`matchAll` には `g` フラグが必要で、なければ `TypeError` が発生します。イテレータを返すので、本物の配列が欲しいときは `[...text.matchAll(pattern)]` とスプレッドしてください。また、パターンが一度もマッチしないときは何も生成しないことにも注意してください。

# --instructions--

# --solutions--

```javascript
function parsePairs(text) {
  const pairs = {};
  for (const match of text.matchAll(/(?<key>\w+)=(?<value>\w+)/g)) {
    pairs[match.groups.key] = match.groups.value;
  }
  return pairs;
}
```
