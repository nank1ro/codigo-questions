# --description--

ここまでの話は、すべて最初のマッチで止まっていました。リテラルの閉じスラッシュの後に書く**フラグ**は、これをはじめ検索の細かい挙動を変更します:
- `g` グローバル: 最初の1つだけでなく、すべてのマッチを見つける
- `i` 大文字小文字を無視する。`/cat/i` は `Cat` や `CAT` にもマッチする

`g` フラグがあると `match` の振る舞いは変わります: `index` もグループも持たない、マッチした**文字列**の普通の配列を返し、マッチがなければ `null` を返します:
```javascript
const numbers = "a1 b22 c333".match(/\d+/g);
console.log(numbers);
// prints [ '1', '22', '333' ]
console.log(numbers.length);
// prints 3
```
フラグは `/cat/gi` のように任意の順序で組み合わせられます。`RegExp` コンストラクタでは第2引数に指定します: `new RegExp("\\d+", "g")`。
