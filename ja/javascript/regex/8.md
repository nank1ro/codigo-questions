# --description--

必要なものだけをキャプチャしましょう。グループは部分を読み戻す方法であるだけでなく、パターンのどの部分が重要かを読み手に伝えるものでもあります。分だけが欲しい時刻のパターンでは、分だけをグループにして、残りはグループ化しません:
```javascript
const minutes = "at 14:35:02".match(/\d{2}:(\d{2}):\d{2}/)?.[1];
console.log(minutes);
// 35 を出力
```
パターン全体はマッチする必要があるので、時と秒も依然として要求されます。単にキャプチャされないだけです。グループが少ないほど、`match[1]`、`match[2]` などを読むときに追いかける番号が少なくて済みます。

# --instructions--

`YYYY-MM-DD` として書かれた日付（他のテキストに囲まれている場合もあります）を含むかもしれない文字列 `date` を受け取り、その月を文字列として返し、`date` にそのような日付が含まれていなければ空文字列を返す関数 `monthOf` を書いてください。例えば `monthOf("2026-09-12")` は `09` を返します

