# --description--

パターンが見つからないとき `match` は `null` を返すので、そのまま `match[0]` を読むと `TypeError: Cannot read properties of null` が発生します。ガードを付けましょう:
```javascript
function firstWord(text) {
  const match = text.match(/[a-z]+/);
  if (match === null) {
    return "";
  }
  return match[0];
}
```
Null 合体演算子を使うと、同じガードを1行で書けます。`match` が `null` のとき `match?.[0]` は `undefined` になるからです:
```javascript
return text.match(/[a-z]+/)?.[0] ?? "";
```
