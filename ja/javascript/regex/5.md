# --description--

`test` が教えてくれるのはイエスかノーだけです。マッチしたテキストそのものを得るには、文字列に対して **`match`** を呼び出します:
```javascript
const match = "order 42 shipped".match(/\d+/);
```
何もマッチしないとき、`match` は `null` を返します。マッチしたときは、配列に似た結果を返します:
- `match[0]` はマッチしたテキスト
- `match.index` はマッチが始まる位置
- `match.input` は検索された文字列全体

```javascript
console.log(match[0]);
// prints 42
console.log(match.index);
// prints 6
```
結果は `null` になりうるので、`match[0]` を読む前に必ず確認してください。
