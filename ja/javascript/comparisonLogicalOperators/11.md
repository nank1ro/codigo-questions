# --description--

`!=`も`==`と同様に、比較する前に変換を行うので、`"5" != 5`は`false`になります。厳密な対の演算子`!==`は、内容にかかわらず文字列と数値を異なるものとして扱います。
```javascript
console.log("5" !== 5); // true
```
