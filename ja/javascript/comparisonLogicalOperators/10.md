# --description--

`==`は両辺を共通の型に変換してから比較するので、`"5" == 5`は`true`になります。厳密な演算子`===`はその変換を行わず、型も一致することを要求します。
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```
