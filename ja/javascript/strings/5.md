# --description--

`indexOf()`メソッドは、指定したテキストが文字列内で**最初**に現れるインデックスを返します。
テキストが見つからない場合は`-1`を返します:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
