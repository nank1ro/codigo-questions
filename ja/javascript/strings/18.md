# --description--

文字列は**イミュータブル**です。つまり、一度作成された文字列は決して変更できません。
インデックスへの代入は何も起こさず、すべての文字列メソッドは元の文字列を変更するのではなく、**新しい**文字列を返します:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
結果を保持するには、変数に代入し直してください:
```javascript
word = word.toUpperCase();
```

# --instructions--

最初の`console.log`が`hello`を出力するのは、`toUpperCase()`が`word`を変更しなかったからです。2番目の`console.log`が`HELLO`を出力するように、コードを完成させてください
