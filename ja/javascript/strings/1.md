# --description--

**文字列**は`"hello"`や`'hello'`のように引用符で囲まれた文字の並びです。
すべての文字列には、含まれる文字数を示す`length`プロパティがあります:
```javascript
let greeting = "hello";
console.log(greeting.length);
// prints 5
```
スペースや句読点も文字としてカウントされます。

# --instructions--

`word`に含まれる文字数を出力してください
