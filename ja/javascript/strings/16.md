# --description--

2つの文字列が`===`で等しいのは、まったく同じ文字が同じ大文字・小文字で並んでいる場合だけです:
```javascript
console.log("hello" === "hello");
// prints true
console.log("hello" === "Hello");
// prints false
```
`<`と`>`演算子は、文字列を1文字ずつアルファベット順に比較します。
大文字は小文字より前に来るため、`"Zoo" < "apple"`は`true`になります。
