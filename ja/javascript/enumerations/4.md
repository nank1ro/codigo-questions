# --description--

メンバーは**数値**を保持することもできます。数値は、メンバー同士に自然な順序がある場合に、通常の演算子で比較できるため便利です。
```javascript
const Priority = Object.freeze({
  LOW: 1,
  MEDIUM: 2,
  HIGH: 3,
});
console.log(Priority.HIGH > Priority.LOW);
// prints true
```
トレードオフは可読性です。`Priority.HIGH`を出力すると`3`と表示され、文字列`"high"`ほど多くの情報を伝えません。
