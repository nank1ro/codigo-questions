# --description--

オブジェクトリテラルを括弧で囲むことは、1行のアロー関数でオブジェクトを作る標準的な方法です。例えば、いくつかの値を1つのレコードにまとめるときに使います：
```javascript
const user = (name, age) => ({ name: name, age: age });
console.log(user("Ana", 30).age);
// prints 30
```
パラメータを持たないアロー関数は、空の括弧`()`で始まります：
```javascript
const empty = () => ({});
console.log(empty());
// prints {}
```
