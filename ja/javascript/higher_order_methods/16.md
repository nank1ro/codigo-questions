# --description--

すべてが `groupBy(items, keyFn)` に集約されます。これは、各要素の**グループキー**を決めるコールバックを受け取り、各キーにそのキーを持つ要素の配列を対応させたオブジェクトを返す高階関数です。オブジェクトをアキュムレータにした `reduce` がすべてを行います。
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
各要素についてキーを求め、そのキーの配列がまだなければ作り（`acc[key] ?? []`）、要素を追加してアキュムレータを返します。`keyFn` は呼び出す側が選ぶので、同じ関数で単語を頭文字ごとに、人を都市ごとに、数値を偶奇ごとにグループ分けできます。

# --instructions--

キーが `keyFn(item)` の結果で、値がそのキーを持つ要素を元の順序で並べた配列であるオブジェクトを返す関数 `groupBy(items, keyFn)` を、`reduce` を使って書いてください

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` は `{ h: ["hi", "hey"], y: ["yo"] }` を返さなければなりません。

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

`[1, 2, 3, 4]` を偶奇でグループ分けすると `{ odd: [1, 3], even: [2, 4] }` を返さなければなりません。

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

`city` で人をグループ分けすると、オブジェクト全体が元の順序のまま保たれなければなりません。

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` は空のオブジェクトを返さなければなりません。

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

元の配列を変更してはいけません。

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

関数は `reduce` を使わなければなりません。

```javascript
tryCatch(/\.reduce\(/.test(groupBy.toString()));
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
