# --description--

すべての関数は `bind` メソッドを持ち、いくつかのものをあらかじめ固定した**新しい**関数を返します。最初の引数は新しい関数の `this` になり、残りの引数は、新しい関数を呼び出すときに渡す引数の前に置かれます（**部分適用**）。
```javascript
function multiply(a, b) {
  return a * b;
}
const double = multiply.bind(null, 2);
console.log(double(21));
// prints 42
```
`this` を固定することはメソッドで重要です。メソッドをオブジェクトから取り出して単独で呼び出すと、`this` はもうそのオブジェクトを指さないので、`this.name` は `undefined` になります。`bind` はそれをオブジェクトに固定します。
```javascript
const user = {
  name: "Ana",
  hello() { return `Hi ${this.name}`; },
};
const loose = user.hello;
console.log(loose());
// prints Hi undefined
const bound = user.hello.bind(user);
console.log(bound());
// prints Hi Ana
```
元の関数は決して変更されません。`bind` は常に新しい関数を作り、その `name` は元の名前の前に `bound ` が付いたものになります。

# --asserts--

`square(3)` は `9` を返さなければなりません。

```javascript
tryCatch(square(3) === 9);
```

`square(12)` は `144` を返さなければなりません。

```javascript
tryCatch(square(12) === 144);
```

`square` は `bind` で作られていなければならず、その名前は `"bound power"` になります。

```javascript
tryCatch(square.name === "bound power");
```

`tick` は `bind` で作られた新しい関数でなければならず、`counter.increment` そのものであってはいけません。

```javascript
tryCatch(tick !== counter.increment && tick.name === "bound increment");
```

`tick()` を単独で 2 回呼び出すと `1`、次に `2` を返し、`counter.count` は `2` にならなければなりません。

```javascript
tryCatch(tick() === 1 && tick() === 2 && counter.count === 2);
```

`tick` は別の変数に入れてそこから呼び出しても動かなければなりません。

```javascript
tryCatch((() => { const alone = tick; return alone() === 3; })());
```
