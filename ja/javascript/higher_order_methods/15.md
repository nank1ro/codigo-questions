# --description--

クロージャを使うと、返された関数が呼び出しをまたいで**プライベートな状態**を保てます。こうして作られる定番のヘルパーが `once(fn)` です。返された関数は最初に呼ばれたときだけ `fn` を実行し、その結果を覚えておき、以降の呼び出しでは `fn` を再実行せずに同じ結果を返します。
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
ラッパーには 2 つのプライベート変数が必要です。`fn` をすでに実行したかどうかと、保存した結果です。どちらもクロージャの中にあり、外からは見えません。ラッパーのすべての引数を `fn` に渡すには、残余引数 `(...args)` を使ってラッパーを宣言し、`fn(...args)` を呼び出します。

# --instructions--

最初の呼び出しのときだけ同じ引数で `fn` を呼び出してその結果を返し、以降の呼び出しでは `fn` を再び呼び出さずに保存した結果を返す関数を返す関数 `once(fn)` を書いてください

# --asserts--

包まれた関数は `fn` を一度だけ実行し、その結果を返し続けなければなりません。

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

最初の呼び出しの引数は `fn` に渡されなければなりません。`once((a, b) => a + b)(2, 3)` は `5` を返さなければなりません。

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

以降の呼び出しは、引数が違っていても保存した結果を返さなければなりません。

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

結果が `undefined` の場合でも、`fn` を再び実行してはいけません。

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

同じ関数の 2 つのラッパーは互いに独立でなければなりません。

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` は関数を返さなければなりません。

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
