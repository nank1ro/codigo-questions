# --description--

これまでに見たすべては 1 つの構文に属するので、部品は自由に組み合わさります。オブジェクトのパターンは別のオブジェクトのパターンを入れ子にでき、その中ではデフォルト値付きでキーの名前を変更でき、さらに rest 要素で終わる配列のパターンを並べられます。こうして 1 行で関数が期待する形全体を記述できます:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// Post [js] +2 を出力
```
読みやすさを保ってください。2、3 行に収まらなくなったパターンは、通常、関数が要求しすぎているサインです。

# --instructions--

`id`、`name`（デフォルトは `"guest"`）を持つ `customer` オブジェクト、空でない `items` 配列を持つオブジェクトを受け取り、文字列 `"#id name: firstItem +n"` を返す関数 `report` を書いてください。`n` は最初の 1 つを除いた残りの項目数です

# --asserts--

3 つの項目があると 2 つ残らなければなりません。

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

1 つの項目は何も残してはなりません。

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

名前のない顧客は `guest` にならなければなりません。

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

明示的な `undefined` の名前も `guest` にならなければなりません。

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

4 つの項目があると 3 つ残らなければなりません。

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

# --solutions--

```javascript
function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
```
