# --description--

デフォルト値付きの分割代入パラメータはきれいな options オブジェクトを作りますが、呼び出し側が何も渡さないときにはやはり壊れます。`undefined` からキーを読むと `TypeError` がスローされるからです。パターン全体に `{}` というデフォルト値を与えると修正できます:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// prints guest/false
```
この行は外側から読みます。`= {}` は引数がないときに空のオブジェクトを供給し、その後、内側の各デフォルト値がそれぞれのキーを埋めます。

# --instructions--

`label` がデフォルト `"OK"`、`size` がデフォルト `"medium"` である options オブジェクトを受け取り、文字列 `"label/size"` を返し、引数なしで呼び出されても動く関数 `button` を書いてください

# --asserts--

引数なしで `button()` を呼び出したときは両方のデフォルト値を使わなければなりません。

```javascript
tryCatch(button() === "OK/medium");
```

空のオブジェクトでも両方のデフォルト値を使わなければなりません。

```javascript
tryCatch(button({}) === "OK/medium");
```

`label` だけが与えられたときはデフォルトの size を使わなければなりません。

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

`size` だけが与えられたときはデフォルトの label を使わなければなりません。

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

両方の options が与えられたときは両方とも使わなければなりません。

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
