# --description--

キーが別のオブジェクトや配列を保持している場合も、パターンはそのまま続けてその形を記述できます:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// London を出力
```
その行が何を作るかに注意してください。`address: { city }` は「`address` の中に入る」ことを意味し、「`address` を渡して」ではないので、変数になるのは `city` だけです。両方を得るにはキーを 2 回書きます: `const { address, address: { city } } = user;`。配列とオブジェクトのパターンは、`{ tags: [first] }` のように互いに自由に入れ子にできます。

`address` オブジェクトを保持するオブジェクトを受け取り、その `city` を返す関数 `cityOf` を書いてください。都市がないときは `"unknown"` を返してください

# --asserts--

ネストされた都市を返さなければなりません。

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

別のネストされた都市を返さなければなりません。

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

空の `address` は `"unknown"` を返さなければなりません。

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

`address` の他のキーは無視しなければなりません。

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

明示的な `undefined` の都市は `"unknown"` を返さなければなりません。

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
