# --description--

`Dictionary(grouping:by:)`はコレクションを配列の辞書に分割します。クロージャが各要素の**キー**を計算し、同じキーを持つすべての要素が同じ配列に入ります:
```swift
let words = ["apple", "bee", "avocado"]
let byInitial = Dictionary(grouping: words, by: { $0.first! })
print(byInitial["a"]!) // ["apple", "avocado"]
```
`mapValues`はキーを保ったまま辞書のすべての値を変換するので、グループ化の次のステップとして自然な選択です:
```swift
let sizes = byInitial.mapValues { $0.count }
print(sizes["a"]!) // 2
```

# --instructions--

関数`countByLength`を書いてください。`String`の配列を受け取り(引数ラベルは省略)、`Dictionary(grouping:by:)`と`mapValues`を使って、各単語の長さをその長さの単語が何個あるかに対応付ける`[Int: Int]`型の辞書を返します

関数呼び出しの例:
```swift
print(countByLength(["hi", "yo", "hey"])[2]!)
// prints 2
```

func countByLength(_ words: [String]) -> [Int: Int] {
    return Dictionary(grouping: words, by: { $0.count }).mapValues { $0.count }
}
