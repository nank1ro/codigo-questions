# --description--

高階関数は、自分で作った構造体の配列を含む任意の配列に対して動作します。`filter`の後に`map`を連結するのが、いくつかの要素を選び、それぞれから値を取り出すいつもの方法です:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
逆の順序、つまり`map`の後に`filter`で行うと、チェックで使う前に`pages`プロパティが失われてしまいます。

# --instructions--

構造体`Product`が用意されています。関数`cheapNames`を書いてください。`Product`の配列を受け取り(引数ラベルは省略)、`filter`と`map`を連結して、`price`が`10`未満の商品の名前を元の順序で返します

関数呼び出しの例:
```swift
print(cheapNames([Product(name: "Pen", price: 2.5), Product(name: "Bag", price: 30)]))
// prints ["Pen"]
```

```swift

```

`cheapNames`は元の順序を保たなければなりません

```swift
tryCatch(cheapNames([Product(name: "Tea", price: 4), Product(name: "Cup", price: 9.99), Product(name: "Pot", price: 25)]) == ["Tea", "Cup"])
```

価格がちょうど`10`の商品は除外しなければなりません

```swift
tryCatch(cheapNames([Product(name: "Cap", price: 10)]) == [])
```

`cheapNames([])`は`[]`を返さなければなりません

```swift
tryCatch(cheapNames([]) == [])
```

```swift
struct Product {
    var name: String
    var price: Double
}
func cheapNames(_ products: [Product]) -> [String] {
    return products.filter { $0.price < 10 }.map { $0.name }
}
```
