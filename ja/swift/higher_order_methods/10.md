# --description--

`enumerated()`は配列を`(offset, element)`のペアのシーケンスに変換するので、クロージャは各要素の値と一緒にその位置を使うことができます:
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
各ペアはタプルなので、クロージャでそれを分割代入することもできます。`.map { (i, step) in "\(i + 1). \(step)" }`のようになります。

# --instructions--

関数`evenPositions`を書いてください。`String`の配列を受け取り(引数ラベルは省略)、`enumerated()`と`filter`と`map`を使って、偶数のインデックス(0、2、4、...)にある要素を返します

関数呼び出しの例:
```swift
print(evenPositions(["a", "b", "c", "d", "e"]))
// prints ["a", "c", "e"]
```

```swift
func evenPositions(_ items: [String]) -> [String] {
    return items.enumerated().filter { $0.offset % 2 == 0 }.map { $0.element }
}
```
