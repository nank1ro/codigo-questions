# --description--

拡張は他人の型のためだけにあるのではありません。自分のコードを整理する一般的な方法は、格納プロパティを構造体やクラスの本体に置き、振る舞いを1つ以上の拡張に追加することです。各拡張が関連するメンバーをまとめます:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
拡張に追加されたメンバーは、型の中に書かれているかのように、格納プロパティを直接使えます。

# --instructions--

構造体`Rectangle`が与えられています。`Rectangle`の拡張を書き、次を定義してください:
- `Double`型の計算プロパティ`area`。`width`と`height`の積です
- 両辺に`factor`を掛けた新しい`Rectangle`を返すメソッド`scaled(by factor: Double)`

# --asserts--

`Rectangle`の拡張を使う必要があります

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

幅`2`、高さ`3`の長方形の面積は`6.0`でなければなりません

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

幅`1.5`、高さ`4`の長方形の面積は`6.0`でなければなりません

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

幅`2`、高さ`3`の長方形を`2`で拡大すると、幅`4`、高さ`6`にならなければなりません

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

拡大によって元の長方形が変更されていてはなりません

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
