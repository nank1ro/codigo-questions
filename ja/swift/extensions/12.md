# --description--

`Array`はジェネリック型です。`[Int]`と`[String]`はどちらも配列ですが、**`Element`**型が異なります。`Array`の拡張はそのすべてに適用されるため、新しいメンバーが一部の要素にしか意味を持たない場合は問題になります。文字列のままの数値は足し算ができません。
`where`節を使うと、拡張を`Element`が特定の型である配列に限定できます:
```swift
extension Array where Element == Int {
    var largest: Int {
        var result = Int.min
        for number in self {
            if number > result {
                result = number
            }
        }
        return result
    }
}
print([3, 9, 2].largest) // 9
```
`[3, 9, 2].largest`は動作しますが、`["a", "b"].largest`はコンパイルエラーです。`[String]`にはこのプロパティが存在しないためです。

# --instructions--

`Element == Int`に限定した`Array`の拡張を書き、要素の合計を返すメソッド`sum()`を定義してください。`reduce`は使わないでください

メソッド呼び出しの例:
```swift
print([1, 2, 3].sum())
// prints 6
```

# --asserts--

`where Element == Int`節を付けた`Array`の拡張を使う必要があります

```json
{
  "regex": "extension\\s+Array\\s+where\\s+Element\\s*==\\s*Int",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`reduce`を使ってはいけません

```json
{
  "regex": "reduce",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

`[1, 2, 3].sum()`は`6`を返さなければなりません

```swift
tryCatch([1, 2, 3].sum() == 6)
```

`[10, -4].sum()`は`6`を返さなければなりません

```swift
tryCatch([10, -4].sum() == 6)
```

`[7].sum()`は`7`を返さなければなりません

```swift
tryCatch([7].sum() == 7)
```

空の配列の合計は`0`でなければなりません

```swift
let _empty: [Int] = []
tryCatch(_empty.sum() == 0)
```

extension Array where Element == Int {
    func sum() -> Int {
        var total = 0
        for number in self {
            total += number
        }
        return total
    }
