# --description--

`m.0`は`String`ではなく`Substring`です。これはコピーではなく、元のテキストへのビューです。文字列とまったく同じように表示されますが、`String`が必要な場所では変換する必要があります:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
数値のイニシャライザは`Substring`を直接受け取るので、`Int(m.0)`は回り道なしにそのまま動きます。

# --instructions--

関数`firstNumber`を書いてください。テキスト（`String`）を受け取り(引数ラベルは省略)、最初の数字の並びを`String`として返し、テキストに数字がないときは`"none"`を返します

関数呼び出しの例:
```swift
print(firstNumber("order 42 today 7"))
// prints 42
```

```swift

```

```swift

```


# --solutions--

```swift
func firstNumber(_ text: String) -> String {
    if let m = text.firstMatch(of: #/\d+/#) {
        return String(m.0)
    }
    return "none"
}
```
