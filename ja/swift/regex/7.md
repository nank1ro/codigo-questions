# --description--

`matches(of:)`は最初の1つではなく、**すべての**マッチを配列として返します。この配列が`nil`になることはなく、何もマッチしなければ単に空になるので、そのままループ処理や変換ができます:
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
各要素はマッチなので、`map`の中の`$0.0`がマッチしたテキストになります:
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```

# --instructions--

アイテムを並べ替えて、`text`のすべての数字の並びを`found`に集めて出力するプログラムを作ってください
