# --description--

`#/ ... /#`リテラルはコンパイル時に固定されます。パターンが実行時になって初めて分かる場合、たとえばユーザーが入力したものは、`Regex(_:)`で組み立てます:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
このイニシャライザは**スロー**します。`"["`のような無効なパターンはプログラムの実行中にしか発見されないので、呼び出しには`try`が必要で、エラーは`do`/`catch`（または`try?`）で処理するか、この演習のように外側の関数を`throws`とマークして伝播させなければなりません。この方法で作った正規表現にはコンパイル時に分かる番号付きプロパティはありませんが、`contains`、`matches(of:)`、`replacing`はこれまでどおり動きます。

# --instructions--

関数`countMatches`を書いてください。テキスト（`String`）とパターン（`String`）を両方とも引数ラベルなしで受け取り、`throws`とマークされ、パターンがテキストに何回見つかるかを返します。無効なパターンはエラーを外へスローしなければなりません

関数呼び出しの例:
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// prints 2
```

# --asserts--

関数は`try Regex(`で正規表現を組み立てる必要があります

```json
{
  "regex": "try\\s+Regex\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`countMatches("a1 b22", "[0-9]+")`は`2`を返さなければなりません

```swift
tryCatch((try? countMatches("a1 b22", "[0-9]+")) == 2)
```

`countMatches("abc", "[0-9]+")`は`0`を返さなければなりません

```swift
tryCatch((try? countMatches("abc", "[0-9]+")) == 0)
```

`countMatches("hello world", "o")`は`2`を返さなければなりません

```swift
tryCatch((try? countMatches("hello world", "o")) == 2)
```

`countMatches("abc", "[")`はエラーをスローしなければなりません

```swift
tryCatch((try? countMatches("abc", "[")) == nil)
```

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
