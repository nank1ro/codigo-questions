# --description--

`contains(_:)`が返すのは「はい」か「いいえ」だけです。マッチしたテキストを取得するには、`firstMatch(of:)`を使います。これは**オプショナルのマッチ**を返し、何もマッチしなければ`nil`になるので、`if let`と自然に組み合わせられます。

マッチしたテキストは、マッチのプロパティ`0`に格納され、`m.0`と書きます:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)`は、テキストにさらにマッチがある場合でも、最初のマッチで止まります。
