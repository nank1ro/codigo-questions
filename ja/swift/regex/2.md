# --description--

いくつかの略記がほとんどのパターンをカバーします。それぞれはちょうど**1**文字にマッチします:
- `\d`は1桁の数字
- `\w`は1文字の英字、数字、アンダースコア
- `\s`は1文字の空白、タブ、改行
- `.`は任意の1文字

複数の文字にマッチするには、パターンの直後に**量指定子**を追加します:
- `+`は1回以上
- `*`は0回以上
- `?`は0回または1回

つまり、`\w+`は単語、`\s*`は任意の空白、`\d?`はあってもなくてもよい1桁の数字です:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
特別な意味を持たない文字はその文字自体にマッチするので、`#/cat/#`は`cat`という3文字にマッチします。

関数呼び出しの例:
```swift

// prints true
```

# --asserts--

関数は`#/`で書かれた正規表現リテラルを使う必要があります

```json
{
  "regex": "#/",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`hasDigit("abc1")`は`true`を返さなければなりません

```swift
tryCatch(hasDigit("abc1") == true)
```

`hasDigit("7")`は`true`を返さなければなりません

```swift
tryCatch(hasDigit("7") == true)
```

`hasDigit("abc")`は`false`を返さなければなりません

```swift
tryCatch(hasDigit("abc") == false)
```

`hasDigit("")`は`false`を返さなければなりません

```swift
tryCatch(hasDigit("") == false)
```
