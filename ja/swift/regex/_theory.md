**正規表現**（regex）とは、テキストの形を表す小さなパターンです。例：「数字の並び」「単語の後に等号が続く形」「3つの大文字」。文字を1つずつループで調べる代わりに、形を一度記述すれば、あとはSwiftが見つけてくれます。

Swiftでは、正規表現を`#/`と`/#`の間に書きます:
```swift
let digits = #/\d+/#
```
パターンの中では、`\d`は「任意の1桁の数字」、`+`は「直前のものが1回以上」を意味するので、`\d+`は「1桁以上の数字の並び」を意味します。

一番簡単な使い方は、テキストがマッチを含むかどうかを調べることです。`contains(_:)`は正規表現を受け取り、`Bool`を返します:
```swift
print("order42".contains(#/\d+/#)) // true
print("order".contains(#/\d+/#))   // false
```
必ずここで示す`#/ ... /#`の形を使ってください。短い`/ ... /`の書き方は、パターンをメソッド呼び出しの中に直接書くとコンパイラが混乱します。

---

いくつかの略記がほとんどのパターンをカバーします。それぞれはちょうど**1**文字にマッチします:
- `\d`は1桁の数字
- `\w`は1文字の英字、数字、アンダースコア
- `\s`は1文字の空白、タブ、改行
- `.`は任意の1文字

複数の文字にマッチするには、パターンの直後に**量指定子**を追加します:
- `+`は1回以上
- `*`は0回以上
- `?`は0回または1回

つまり、`\w+`は単語、`\s*`は任意の空白、`\d?`はあってもなくてもよい1桁の数字です:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
特別な意味を持たない文字はその文字自体にマッチするので、`#/cat/#`は`cat`という3文字にマッチします。

---

デフォルトでは、パターンはテキスト内のどこにでもマッチできます。**アンカー**を使うと、代わりに位置に固定できます:
- `^`は「テキストの先頭」を意味します
- `$`は「テキストの末尾」を意味します

```swift
print("swift".contains(#/^sw/#))  // true, the text starts with sw
print("myswift".contains(#/^sw/#)) // false, sw is not at the start
print("swift".contains(#/ft$/#))  // true, the text ends with ft
```
アンカーは文字ではなく位置にマッチするので、マッチの内容には何も追加しません。

---

どの略記も当てはまらないときは、受け入れる文字を角括弧の中に列挙します。`[abc]`は`a`、`b`、`c`のいずれか1文字にマッチし、ダッシュで範囲を表せます:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
波括弧の中の数値は、直前のパターンが正確に何回繰り返すかを指定します。`{3}`は3回、`{2,4}`は2回から4回の間を意味します:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
`^`と`$`でパターンを囲み、回数を指定するのが、テキスト全体が決まった形を持つかを調べる定番の方法です。

---

`contains(_:)`が返すのは「はい」か「いいえ」だけです。マッチしたテキストを取得するには、`firstMatch(of:)`を使います。これは**オプショナルのマッチ**を返し、何もマッチしなければ`nil`になるので、`if let`と自然に組み合わせられます。

マッチしたテキストは、マッチのプロパティ`0`に格納され、`m.0`と書きます:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)`は、テキストにさらにマッチがある場合でも、最初のマッチで止まります。

---

`m.0`は`String`ではなく`Substring`です。これはコピーではなく、元のテキストへのビューです。文字列とまったく同じように表示されますが、`String`が必要な場所では変換する必要があります:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
数値のイニシャライザは`Substring`を直接受け取るので、`Int(m.0)`は回り道なしにそのまま動きます。

---

`matches(of:)`は最初の1つではなく、**すべての**マッチを配列として返します。この配列が`nil`になることはなく、何もマッチしなければ単に空になるので、そのままループ処理や変換ができます:
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
各要素はマッチなので、`map`の中の`$0.0`がマッチしたテキストになります:
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```

---

`Int(_:)`は`Substring`を受け取るので、見つけたテキストを数値にするのは1ステップで済みます。ここで便利なのが`compactMap`です。`nil`になった値を取り除きます:
```swift
let text = "a1 b22"
let numbers = text.matches(of: #/\d+/#).compactMap { Int($0.0) }
print(numbers) // [1, 22]
```
すべての要素が変換できるときは`map`を、失敗する可能性があるときは`compactMap`を使います。

---

パターンの一部を丸括弧で囲むと**キャプチャグループ**が作られます。マッチ全体はこれまでどおり`m.0`で、括弧の中の部分が`m.1`になります:
```swift
let text = "id-42"
if let m = text.firstMatch(of: #/id-(\d+)/#) {
    print(m.0) // id-42
    print(m.1) // 42
}
```
こうして必要な部分を取り出し、周りのテキストを捨てます。括弧がないと`m.1`はまったく存在せず、コードはコンパイルできません。

---

1つのパターンには複数のグループを含められます。グループは開き括弧の位置を基準に左から右へ番号が付き、2番目は`m.2`、3番目は`m.3`、というようになります:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
グループの数に関係なく、`m.0`は常にマッチ全体のままです。

---

パターンが大きくなると、括弧の数を数えるのは壊れやすくなります。代わりに、開き括弧の直後に`?<name>`と書いてグループに**名前**を付け、マッチのプロパティとして読み取ります:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
名前付きグループにも番号は付くので`m.1`は引き続き使えますが、`m.key`は中身が何かを示し、パターンが変わっても影響を受けません。

---

`replacing(_:with:)`はすべてのマッチを固定のテキストに置き換え、元のテキストをそのまま残して新しい`String`を返します:
```swift
let text = "a1 b22"
print(text.replacing(#/\d+/#, with: "#")) // a# b#
print(text)                               // a1 b22
```
`\d+`は数字の並び全体を1つの`#`に置き換えますが、`\d`なら1桁ずつ置き換えることに注意してください。どれだけの部分が消えるかは、パターンが決めます。

---

`split(separator:)`は正規表現も受け取るので、1回の呼び出しで同じようには書かれない区切り文字をまとめて扱えます:
```swift
let line = "a, b;c"
let parts = line.split(separator: #/[,;]\s*/#)
print(parts.joined(separator: "|")) // a|b|c
```
パターン`[,;]\s*`は「カンマまたはセミコロンと、それに続く任意の量の空白」を意味するので、すべての区切りが丸ごと消費され、空のフィールドは作られません。結果は`Substring`の配列です。

---

`^`と`$`でテキスト全体を検証しても動きますが、`wholeMatch(of:)`はそれを直接表します。パターンがテキストの最初の文字から最後の文字までを覆うときにだけマッチを返し、それ以外は`nil`を返します:
```swift
print("1a2b".wholeMatch(of: #/[0-9a-f]+/#) != nil) // true
print("1z".wholeMatch(of: #/[0-9a-f]+/#) != nil)   // false
```
テキストの中から何かを見つけるときは`firstMatch(of:)`を、テキストが決まった1つの形を持つかを調べるときは`wholeMatch(of:)`を使います。

---

`#/ ... /#`リテラルはコンパイル時に固定されます。パターンが実行時になって初めて分かる場合、たとえばユーザーが入力したものは、`Regex(_:)`で組み立てます:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
このイニシャライザは**スロー**します。`"["`のような無効なパターンはプログラムの実行中にしか発見されないので、呼び出しには`try`が必要で、エラーは`do`/`catch`（または`try?`）で処理するか、この演習のように外側の関数を`throws`とマークして伝播させなければなりません。この方法で作った正規表現にはコンパイル時に分かる番号付きプロパティはありませんが、`contains`、`matches(of:)`、`replacing`はこれまでどおり動きます。
