# --description--

どの略記も当てはまらないときは、受け入れる文字を角括弧の中に列挙します。`[abc]`は`a`、`b`、`c`のいずれか1文字にマッチし、ダッシュで範囲を表せます:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
波括弧の中の数値は、直前のパターンが正確に何回繰り返すかを指定します。`{3}`は3回、`{2,4}`は2回から4回の間を意味します:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
`^`と`$`でパターンを囲み、回数を指定するのが、テキスト全体が決まった形を持つかを調べる定番の方法です。

# --instructions--

関数`isCode`を書いてください。テキスト（`String`）を受け取り(引数ラベルは省略)、正規表現を使って、テキスト全体がちょうど3つの大文字であるときにだけ`true`を返します

関数呼び出しの例:
```swift
print(isCode("ABC"))
// prints true
```

関数は`#/`で書かれた正規表現リテラルを使う必要があります

```json
{
  "regex": "#/",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`isCode("ABC")`は`true`を返さなければなりません

```swift
tryCatch(isCode("ABC") == true)
```

`isCode("XYZ")`は`true`を返さなければなりません

```swift
tryCatch(isCode("XYZ") == true)
```

`isCode("AB")`は`false`を返さなければなりません

```swift
tryCatch(isCode("AB") == false)
```

`isCode("ABCD")`は`false`を返さなければなりません

```swift
tryCatch(isCode("ABCD") == false)
```

`isCode("abc")`は`false`を返さなければなりません

```swift

```

`isCode("A1C")`は`false`を返さなければなりません

