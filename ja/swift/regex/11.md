# --description--

パターンが大きくなると、括弧の数を数えるのは壊れやすくなります。代わりに、開き括弧の直後に`?<name>`と書いてグループに**名前**を付け、マッチのプロパティとして読み取ります:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
名前付きグループにも番号は付くので`m.1`は引き続き使えますが、`m.key`は中身が何かを示し、パターンが変わっても影響を受けません。

# --instructions--

値のグループが数字にマッチし、keyがその前に出力されて`size 10`という出力になるように、コードを完成させてください
