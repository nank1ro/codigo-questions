# --description--

これで順次と並行の違いが測定できるようになりました。`work`が返る前に1秒スリープするとします:
```swift
func work(_ n: Int) async -> Int {
    try? await Task.sleep(for: .seconds(1))
    return n
}
```
呼び出しを1つずつawaitすると約**2**秒かかります。2番目のスリープは1番目が終わってから始まるためです:
```swift
let a = await work(1)
let b = await work(2)
```
`async let`で開始すると約**1**秒かかります。両方のスリープが重なるためです:
```swift
async let a = work(1)
async let b = work(2)
let sum = await a + b
```
`await work(1) + await work(2)`を1行に書いても何も変わりません。2つの呼び出しは依然として順番に評価されます。並行性は`async let`やタスクから生まれるものであり、行の書き方から生まれることはありません。

# --instructions--

`work`は返る前に1秒スリープします。約1秒で終わるのはどのバージョンですか?

# --answers--

- `async let a = work(1)`、`async let b = work(2)`、その後`let sum = await a + b`
- `let a = await work(1)`、その後`let b = await work(2)`、その後`let sum = a + b`
- `let sum = await work(1) + await work(2)`
- どれも違います。2つの呼び出しは合計で常に2秒かかります
