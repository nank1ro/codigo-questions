# --instructions--

このコードは何を出力しますか?
```swift
func value(_ n: Int) async -> Int {
    return n + 1
}

let job = Task {
    return await value(9)
}
print(await job.value)
```

# --answers--

- `10`
- `9`
- `Task<Int, Never>`
- タスクが一度も開始されないため、何も表示されない
