# --description--

時間をかけて行う処理はよく失敗します。サーバーがダウンしている、ファイルが見つからない、入力が間違っているなどです。そのような関数には**`async throws`**を付け、**`try await`**で呼び出します:
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
エラーを処理するには、呼び出しを`do`ブロックで囲んでキャッチします:
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// could not load を出力
```
キーワードの順序は決まっています。まず`try`、次に`await`です。

# --instructions--

文字列を引数ラベルなしで受け取り、非同期で、スローでき、その文字列を`Int`に変換して返す関数`parse`を書いてください。文字列が数値でない場合は`InputError.notANumber`をスローしてください

関数呼び出しの例:
```swift
print(try await parse("7"))
// 7 を出力
```

# --asserts--

関数は`async throws`が付けられていなければなりません

```json
{
  "regex": "func\\s+parse\\s*\\([^)]*\\)\\s*async\\s+throws",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`parse("7")`は`7`を返さなければなりません

```swift
do {
    let value = try await parse("7")
    tryCatch(value == 7)
} catch {
    tryCatch(false)
}
```

`parse("-3")`は`-3`を返さなければなりません

```swift
do {
    let value = try await parse("-3")
    tryCatch(value == -3)
} catch {
    tryCatch(false)
}
```

`parse("abc")`はスローしなければなりません

```swift
do {
    _ = try await parse("abc")
    tryCatch(false)
} catch {
    tryCatch(true)
}
```

# --solutions--

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
