# --description--

多くの言語ではブロックコメントの中に別のブロックコメントを含めることはできませんが、Swiftでは**ネストできます**。すべての`/*`には対応する`*/`が必要であり、コメントは最も外側のものが閉じられたときにのみ終わります。
```swift
/* outer /* inner */ still a comment */
print("done")
```
ここで`still a comment */`は外側のコメントの一部なので、出力されるのは`done`だけです。これにより、すでに`/* */`コメントを含むコードのブロック全体でもコメントアウトできます。
