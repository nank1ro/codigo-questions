# --description--

ブロックコメントの一般的な使い方は**ヘッダーコメント**です。関数のすぐ上に置かれる短いブロックで、関数が何をするか、パラメータが何を意味するかを説明します。
```swift
/*
Returns the number of seconds in the given minutes.
minutes is a whole number, never negative.
*/
func toSeconds(_ minutes: Int) -> Int {
    return minutes * 60
}
```
`toSeconds`を呼び出す人は、本体を読む代わりにヘッダーを読むことができます。ヘッダーは関数の隣に置き、一緒に更新されるようにしてください。
