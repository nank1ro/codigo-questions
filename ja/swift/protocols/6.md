# --description--

1つのプロトコルには通常、複数の要件が集められます。そして準拠する型は、そのすべてを満たさなければなりません:
```swift
protocol Vehicle {
    var wheels: Int { get }
    func move() -> String
}

struct Bike: Vehicle {
    var wheels = 2

    func move() -> String {
        return "pedalling"
    }
}
```
波括弧の中での要件の順序は問われません。準拠する型が要件を提供する順序も同じです。コンパイラが確認するのは、欠けているものがないことだけです。
