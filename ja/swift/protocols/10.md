# --description--

プロトコルの拡張は、プロトコルが要件として列挙したことのないメンバーも追加できます。それらは追加のおまけで、準拠するすべての型で使えます:
```swift
protocol Sized {
    var count: Int { get }
}

extension Sized {
    var isEmpty: Bool {
        return count == 0
    }
}
```
`isEmpty`は要件ではないので、準拠する型が提供する必要はありません。型はそれをそのまま手に入れます。
