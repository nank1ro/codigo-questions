# --description--

プロトコルは**メソッド**を要求することもできます。書くのはシグネチャ（名前、パラメータ、戻り値の型）までで、本体は書きません:
```swift
protocol Greeter {
    func greet() -> String
}
```
準拠する型は、そのシグネチャとまったく同じメソッドを宣言し、本体を提供しなければなりません:
```swift
struct Robot: Greeter {
    func greet() -> String {
        return "BEEP"
    }
}

print(Robot().greet()) // BEEP
```
名前、パラメータの型、戻り値の型のどれか1つでも違えば、その型は準拠しておらず、コンパイラがどの要件が満たされていないかを教えてくれます。

# --instructions--

必要な`greet()`メソッドを追加して`Friendly`を`Greeter`に準拠させてください。メソッドは`Hello, `と`!`の間に名前を挟んで返します

使用例:
```swift
print(Friendly(name: "Ada").greet())
// Hello, Ada! を出力
```

# --asserts--

`Friendly(name: "Ada")`は`Hello, Ada!`と挨拶しなければなりません

```swift
tryCatch(_asGreeter(Friendly(name: "Ada")) == "Hello, Ada!")
```

`Friendly(name: "Bo")`は`Hello, Bo!`と挨拶しなければなりません

```swift
tryCatch(_asGreeter(Friendly(name: "Bo")) == "Hello, Bo!")
```

空の名前は`Hello, !`と挨拶しなければなりません

```swift
tryCatch(_asGreeter(Friendly(name: "")) == "Hello, !")
```
