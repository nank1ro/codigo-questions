# --description--

スローする関数でも値を返せます。`throws`キーワードはパラメータリストと返却の矢印の間に書きます:
```swift
func square(_ n: Int) throws -> Int {
    if n < 0 {
        throw SquareError.negative
    }
    return n * n
}
```
声に出して読むとこうなります。*squareは`Int`を受け取り、スローするかもしれず、`Int`を返す*。

呼び出し側では、何もスローされなかったときだけ値が存在します。そのため代入は`do`ブロックの中に置きます:
```swift
do {
    let result = try square(4)
    print(result) // 16
} catch {
    print("failed")
}
```
`try`は飾りではありません。なければコンパイラが呼び出しを拒否するので、読む人はどの行が失敗しうるかを常に見て取れます。

# --instructions--

`half`をスローするようにマークし、`n`が奇数のときは`MathError.notEven`をスローし、そうでなければ`n / 2`を返すようにしてください

関数呼び出しの例:
```swift
do {
    print(try half(10))
} catch {
    print("odd")
}
// 5 を出力
```

# --solutions--

```swift
enum MathError: Error {
    case notEven
}

func half(_ n: Int) throws -> Int {
    if n % 2 != 0 {
        throw MathError.notEven
    }
    return n / 2
}
```
