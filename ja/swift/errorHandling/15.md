# --description--

`do` ブロックをどこに置くかで、1つの失敗にかかるコストが決まります。ループの**内側**に置けば、各要素がそれぞれ独自の試行を持つので、悪い値は1つだけスキップされ、残りはそのまま実行されます:
```swift
for age in [4, -1, 7] {
    do {
        print(try label(age))
    } catch {
        print("skipped")
    }
}
```
代わりにループ全体を1つの`do`で囲むと、最初のエラーで止まってしまい、`7`には決して到達しません。どちらも間違いではありません——それは*1つの悪い要素*と*あきらめる*ことの違いです。
