# --description--

デフォルトでは、関数に渡されたクロージャはその関数が実行されている間だけ使用できます。関数がクロージャを保存したり、それを使う別のクロージャを返したりする場合、そのクロージャは関数を**エスケープ**すると言い、そのパラメータには`@escaping`を付ける必要があります:
```swift
func twice(_ task: @escaping () -> Int) -> () -> Int {
    return { task() * 2 }
}
let answer = twice { 21 }
print(answer()) // 42
```
`@escaping`がないと、コンパイラはエラーを報告します。なぜなら、返されたクロージャは`twice`が終了した後に`task`を使うことになるからです。

# --instructions--

関数`compose`を書いてください。`(Int) -> Int`型の2つのクロージャを受け取り(両方とも引数ラベルは省略)、最初のクロージャを適用してからその結果に2番目のクロージャを適用するクロージャを返します

関数呼び出しの例:
```swift
let addThenDouble = compose({ $0 + 1 }, { $0 * 2 })
print(addThenDouble(3))
// prints 8
```
