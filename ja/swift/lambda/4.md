# --description--

クロージャは値であるため、関数はそれをパラメータとして受け取ることができます。パラメータの型は単なる関数型です:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
関数`apply`は`operation`が何をするかを知りません。ただ`Int`を受け取り`Int`を返すことだけを知っていて、他の関数と同じように呼び出します。

# --instructions--

関数`apply`を完成させて、2番目のパラメータが`Int`を受け取り`Int`を返すクロージャになるようにし、関数がそのクロージャを`n`に対して呼び出した結果を返すようにして、プログラムが`12`を出力するようにしてください
