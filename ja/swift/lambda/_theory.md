**クロージャ**は、後で受け渡して呼び出すことができる一連のコードで、名前のない関数のようなものです。
完全なクロージャ式の構文では、パラメータと戻り値の型を波括弧の中に書き、その後に`in`キーワードと本体を続けます:
```swift
{ (parameters) -> ReturnType in
    body
}
```
他の値と同様に、クロージャは定数に格納し、その定数名を使って呼び出すことができます:
```swift
let greet = { (name: String) -> String in
    return "Hello, \(name)!"
}
print(greet("Ada")) // Hello, Ada!
```

---

クロージャの中にすべての型を書くことは、多くの場合不要です。定数が明示的な**関数型**を持つ場合、Swiftはパラメータと戻り値の型を推論するため、`in`の前にパラメータ名だけを書けばよくなります:
```swift
let triple: (Int) -> Int = { n in
    return n * 3
}
```
`(Int) -> Int`という型は「`Int`を受け取り`Int`を返す関数」と読みます。
本体が単一の式の場合、`return`キーワードも省略できます。これは**暗黙的な戻り値**と呼ばれます:
```swift
let triple: (Int) -> Int = { n in n * 3 }
print(triple(4)) // 12
```

---

Swiftはさらに一歩進んで、クロージャの中では**省略引数名**である`$0`、`$1`、`$2`などを使って、パラメータの宣言も`in`キーワードもなしに引数を参照できます。
`$0`は最初の引数、`$1`は2番目の引数です:
```swift
let add: (Int, Int) -> Int = { $0 + $1 }
print(add(2, 3)) // 5
```
型は依然として`(Int, Int) -> Int`という注釈から来ています。

---

クロージャは値であるため、関数はそれをパラメータとして受け取ることができます。パラメータの型は単なる関数型です:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
関数`apply`は`operation`が何をするかを知りません。ただ`Int`を受け取り`Int`を返すことだけを知っていて、他の関数と同じように呼び出します。

---

クロージャが関数の**最後**の引数である場合、呼び出しの閉じ括弧の後にそれを書くことができます。これが**トレイリングクロージャ**構文です:
```swift
print(apply(5) { $0 + 1 }) // 6
```
クロージャが唯一の引数である場合、括弧を完全に省略することもできます:
```swift
func run(_ task: () -> Int) -> Int {
    return task()
}
print(run { 42 }) // 42
```
どちらの形式もまったく同じ関数を呼び出しますが、クロージャが長いときはトレイリング構文の方が読みやすくなります。

---

クロージャは、それを引数として受け取る配列のメソッドで真価を発揮します。`map`はすべての要素に対してクロージャを呼び出し、その結果からなる新しい配列を返します:
```swift
let nums = [1, 2, 3]
let doubled = nums.map { $0 * 2 }
print(doubled) // [2, 4, 6]
```
元の配列は変更されません。`map`は単一のクロージャ引数を取るため、トレイリングクロージャ構文で呼び出すのが一般的です。

---

`filter`は、クロージャが`true`を返した要素だけを残します。クロージャは1つの要素を受け取り、`Bool`を返す必要があります:
```swift
let nums = [5, 12, 8, 20]
let big = nums.filter { $0 > 10 }
print(big) // [12, 20]
```
要素は元の順序を保ち、結果は同じ要素型の新しい配列になります。

---

`reduce`はすべての要素を1つの値にまとめます。初期値と、2つの引数(これまでに蓄積された値と現在の要素)を取るクロージャを受け取ります。クロージャは新しい蓄積値を返します:
```swift
let nums = [1, 2, 3, 4]
let product = nums.reduce(1) { $0 * $1 }
print(product) // 24
```
ここでは`$0`は`1`から始まり、`1 * 1`、`1 * 2`、`2 * 3`、そして最後に`6 * 4`となります。
`map`、`filter`、`reduce`はすべて値を返すため、`nums.filter { $0 > 1 }.map { $0 * 10 }`のように連結できます。

---

`sorted(by:)`は新しくソートされた配列を返します。クロージャは2つの要素を受け取り、最初の要素が2番目の要素より**前**に来るべきときに`true`を返します:
```swift
let nums = [3, 1, 2]
print(nums.sorted { $0 < $1 }) // [1, 2, 3]
print(nums.sorted { $0 > $1 }) // [3, 2, 1]
```
クロージャは何でも比較できます。例えば`words.sorted { $0.count < $1.count }`は文字列を短いものから長いものへと並べます。
