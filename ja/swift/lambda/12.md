# --description--

クロージャを返すことは、カスタマイズされた関数を作る便利な方法です。外側の関数のパラメータは、それが返すクロージャによってキャプチャされます:
```swift
func makeAdder(_ amount: Int) -> (Int) -> Int {
    return { $0 + amount }
}
let addFive = makeAdder(5)
print(addFive(10)) // 15
```
戻り値の型`(Int) -> Int`はクロージャを表しており、省略記法の`$0`は`makeAdder`の引数ではなく、そのクロージャの引数を参照します。

# --instructions--

関数`makeMultiplier`を書いてください。`factor`という名前の`Int`を受け取り(引数ラベルは省略)、引数に`factor`を掛けた値を返す`(Int) -> Int`型のクロージャを返します

関数呼び出しの例:
```swift
let double = makeMultiplier(2)
print(double(10))
// prints 20
```

```swift
tryCatch(makeMultiplier(2)(10) == 20)
```

```swift
tryCatch(makeMultiplier(3)(4) == 12)
```

`makeMultiplier(0)(99)`は`0`を返さなければなりません

```swift

```

`makeMultiplier(5)`が返すクロージャは、呼び出しをまたいで機能し続けなければなりません

