# --description--

`reduce`はすべての要素を1つの値にまとめます。初期値と、2つの引数(これまでに蓄積された値と現在の要素)を取るクロージャを受け取ります。クロージャは新しい蓄積値を返します:
```swift
let nums = [1, 2, 3, 4]
let product = nums.reduce(1) { $0 * $1 }
print(product) // 24
```
ここでは`$0`は`1`から始まり、`1 * 1`、`1 * 2`、`2 * 3`、そして最後に`6 * 4`となります。
`map`、`filter`、`reduce`はすべて値を返すため、`nums.filter { $0 > 1 }.map { $0 * 10 }`のように連結できます。
