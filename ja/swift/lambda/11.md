# --description--

クロージャは、その本体の外側で宣言された変数を使うことができます。クロージャはその変数を**キャプチャ**します。つまり、その変数を宣言した関数がすでに終了していても、クロージャが存在する限りその変数は生き続けます。
これにより、関数は自分専用のプライベートな状態を持つクロージャを作ることができます:
```swift
func makeCounter() -> () -> Int {
    var count = 0
    return {
        count += 1
        return count
    }
}
```
`() -> Int`は、パラメータを取らず`Int`を返すクロージャの型です。返されたクロージャを呼び出すたびに、キャプチャされた同じ`count`が増加します:
```swift
let counter = makeCounter()
print(counter()) // 1
print(counter()) // 2
```
