# --description--

クロージャを返す関数を呼び出すたびに、**新しい**キャプチャ変数が作られます。別々の呼び出しで作られた2つのクロージャは、その状態を共有しません:
```swift
let first = makeCounter()
let second = makeCounter()
print(first())  // 1
print(first())  // 2
print(second()) // 1
```
状態が共有されるのは、同じクロージャを呼び出したときだけです。

```swift
let a = makeCounter()
let b = makeCounter()

_ = b()
```
