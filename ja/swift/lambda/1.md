# --description--

**クロージャ**は、後で受け渡して呼び出すことができる一連のコードで、名前のない関数のようなものです。
完全なクロージャ式の構文では、パラメータと戻り値の型を波括弧の中に書き、その後に`in`キーワードと本体を続けます:
```swift
{ (parameters) -> ReturnType in
    body
}
```
他の値と同様に、クロージャは定数に格納し、その定数名を使って呼び出すことができます:
```swift
let greet = { (name: String) -> String in
    return "Hello, \(name)!"
}
print(greet("Ada")) // Hello, Ada!
```
