# --description--

クロージャは、それを引数として受け取る配列のメソッドで真価を発揮します。`map`はすべての要素に対してクロージャを呼び出し、その結果からなる新しい配列を返します:
```swift
let nums = [1, 2, 3]
let doubled = nums.map { $0 * 2 }
print(doubled) // [2, 4, 6]
```
元の配列は変更されません。`map`は単一のクロージャ引数を取るため、トレイリングクロージャ構文で呼び出すのが一般的です。
