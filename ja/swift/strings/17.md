# --description--

文字列は数値と同じ演算子で比較できます。`==`は2つの文字列がまったく同じ文字を持つかどうかを調べ、`<`と`>`は1文字ずつ辞書順で比較します:
```swift
print("apple" == "apple")  // true
print("apple" < "banana")  // true
print("car" < "cat")       // true
```
この比較は大文字と小文字を区別し、すべての大文字はすべての小文字より**前**に来ます。そのため`"B" < "a"`は`true`になります。
