# --description--

2つの文字列は`+`演算子で結合でき、新しい文字列が作られます:
```swift
let full = "Hello" + " " + "world" // Hello world
```
既存の文字列変数の末尾にテキストを追加するには`+=`を使います。値が変化するため、その変数は`var`で宣言する必要があります:
```swift
var log = "Start"
log += "..."
print(log) // Start...
```
