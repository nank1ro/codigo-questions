# --description--

`Character`は`String`ではないため、`+`で直接文字列に結合することはできません。まず`String(...)`で変換してください:
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
これを`for`-`in`ループと組み合わせると、たとえば新しい文字をこれまでに集めたものの前に置くなど、1文字ずつ文字列を組み立て直すことができます。
