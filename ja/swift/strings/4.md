# --description--

`count`プロパティは文字列に含まれる文字数を返し、`isEmpty`は文字列にまったく文字が含まれていないとき`true`になります:
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
スペースや句読点を含め、すべての文字が数えられます。

let text = "Hi there!"
