# --description--

通貨コード、共有されるデフォルト、よく使うケースを作るファクトリのように、単一のインスタンスではなく型そのものに属する値があります。それらには`static`を付け、型名を通して読み取ります:
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
ここで`currency`は決して変わらないため`let`で宣言されており、プログラム全体で共有される定数です。`Money.currency`は1つも`Money`を作らなくても使えますが、`amount`にはインスタンスが必要です。

# --instructions--

`Money`に、`"EUR"`と等しいstatic定数`currency`と、パラメータを取らず`amount`が`0`の`Money`を返すstaticメソッド`zero`を追加してください

使用例:
```swift
print(Money.currency)
// prints EUR
```

# --asserts--

`currency`はstatic定数でなければなりません

```json
{
  "regex": "static\\s+let\\s+currency",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`Money.currency`は`"EUR"`でなければなりません

```swift
tryCatch(Money.currency == "EUR")
```

`Money.zero()`の`amount`は`0`でなければなりません

```swift
tryCatch(Money.zero().amount == 0)
```

メンバーワイズイニシャライザは引き続き動作しなければなりません

```swift
tryCatch(Money(amount: 7).amount == 7)
```
