# --instructions--

アイテムを並べ替えて`EUR 12`を出力してください。構造体を先に宣言し、`print`の前にインスタンスを作成します

# --answers--

```swift
struct Money {
    static let currency = "EUR"
    var amount: Int
}
```

```swift
let price = Money(amount: 12)
```

```swift
print("\(Money.currency) \(price.amount)")
```
