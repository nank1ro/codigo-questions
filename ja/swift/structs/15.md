# --description--

構造体も他の型と同じように、配列や辞書やセットに格納でき、すでに知っているすべてのツールがそのまま使えます:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
配列が保持しているのは*コピー*です。`items[0]`を変数に読み出して変更しても、配列には影響しません。

# --instructions--

`Item`の配列を引数ラベルなしで受け取り、すべてのアイテムの`price`の合計を返す(配列が空のときは`0`)関数`totalPrice`を書いてください

関数呼び出しの例:
```swift
print(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]))
// prints 10
```

# --asserts--

`3`と`7`の2つのアイテムの合計は`10`でなければなりません

```swift
tryCatch(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]) == 10)
```

1つのアイテムの合計は、そのアイテム自身の価格でなければなりません

```swift
tryCatch(totalPrice([Item(name: "Pen", price: 2)]) == 2)
```

空の配列の合計は`0`でなければなりません

```swift
tryCatch(totalPrice([]) == 0)
```
