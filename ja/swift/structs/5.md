# --description--

**計算プロパティ**はプロパティのように見えますが、メソッドのように振る舞います。何も格納せず、読み取るたびに値を計算します。型を書き、続けて値を返すコードブロックを書きます:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, no parentheses
```
計算プロパティは何も格納しないため、メンバーワイズイニシャライザには含まれません。値が他の値から導かれるときは計算プロパティを、処理にパラメータが必要なときはメソッドを使います。

# --instructions--

`Temperature`に`Double`型の計算プロパティ`fahrenheit`を追加してください。摂氏の値に`9`を掛け、`5`で割り、`32`を足した値を返します

使用例:
```swift
print(Temperature(celsius: 100).fahrenheit)
// prints 212.0
```

# --asserts--

摂氏`100`度は華氏`212`度でなければなりません

```swift
tryCatch(Temperature(celsius: 100).fahrenheit == 212)
```

摂氏`0`度は華氏`32`度でなければなりません

```swift
tryCatch(Temperature(celsius: 0).fahrenheit == 32)
```

摂氏`-40`度は華氏`-40`度でなければなりません

```swift
tryCatch(Temperature(celsius: -40).fahrenheit == -40)
```
