# --instructions--

なぜこのコードはコンパイルに失敗しますか？
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c`は`let`定数なので、mutatingメソッドを呼び出すことはできません
- `value`を変更するには、`increase`に`static`を付けなければなりません
- `value`は`let`で宣言しなければなりません
- 構造体はメソッドを含められません
