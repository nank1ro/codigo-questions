# --description--

`Int(text)`と`Double(text)`は失敗すると`nil`を返すため、結果を`nil`と比較すると、そのテキストがその種類の数値かどうかが分かります:
```swift
print(Int("42") != nil)     // true
print(Double("4.2") != nil) // true
print(Double("42") != nil)  // true, a whole number is also a valid Double
```
最後の行に注目してください。`Int`が受け付けるテキストはすべて`Double`でも受け付けられるため、両者を区別したい場合は先に`Int`をチェックします。

# --instructions--

`String`を引数に受け取り（引数ラベルは省略）、テキストが有効な整数なら`"Int"`を、有効な小数なら`"Double"`を、それ以外なら`"String"`を返す関数`classify`を書いてください

関数呼び出しの例:
```swift
print(classify("3.5"))
// prints Double
```

# --solutions--

```swift
func classify(_ text: String) -> String {
    if Int(text) != nil {
        return "Int"
    }
    if Double(text) != nil {
        return "Double"
    }
    return "String"
}
```
