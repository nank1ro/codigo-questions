# --description--

**型エイリアス**は、既存の型に新しい名前を与えます。`typealias`キーワードを使います:
```swift
typealias Score = Int
let best: Score = 100
print(best + 1) // 101
```
`Score`と`Int`は同じ型なので、自由に混在できます。エイリアスは安全性を高めるものではありません。単純な型にプログラム内で特定の意味がある場合に、コードを読みやすくするだけのものです。
