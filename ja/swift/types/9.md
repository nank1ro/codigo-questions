# --description--

`Int(text)`は、テキスト全体がオプションの符号付きの有効な整数である場合にのみ成功します:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
小数のテキストには`Double(text)`を使います。これも同じように`Double?`を返します。`Double("3.5")`は`Optional(3.5)`です。

# --instructions--

`String`の配列を引数に受け取り（引数ラベルは省略）、有効な整数であるものの合計を返し、それ以外は無視する関数`sumOfNumbers`を書いてください

関数呼び出しの例:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
