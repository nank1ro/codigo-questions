# --description--

オプショナルから欲しいものは、多くの場合その値かデフォルト値のどちらかです。
**nil結合演算子**`??`はまさにそれを行います。オプショナルが値を持っていればアンラップし、そうでなければ右側の値を返します:
```swift
let score: Int? = nil
let points = score ?? 0 // pointsは0に等しいInt
```
デフォルト値はラップされた値と同じ型でなければなりません。
`??`は複数連結でき、最初の`nil`でない値が採用されます。
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0) // 7
```
