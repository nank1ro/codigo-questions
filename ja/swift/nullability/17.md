# --description--

失敗する可能性のある変換は`guard let`と自然に組み合わさります。変換し、結果が`nil`の場合は処理を中断し、その後は通常の値として扱います。

# --instructions--

テキストを`Int`に変換してその2倍を返し、変換が失敗した場合は`nil`を返すように関数を完成させてください。
その後、フォールバック値として`0`を使って結果を出力してください

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

func doubled(_ text: String) -> Int? {

    return number * 2
}
