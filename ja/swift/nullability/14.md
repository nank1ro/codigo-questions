# --description--

複数のオプショナルを1つの`if let`でバインドすると、コードがフラットに保たれます。1つの`else`分岐が、値が欠けているすべての場合をカバーします。

# --instructions--

`width`と`height`の両方が値を持つ場合は`Area: 20`を、そうでない場合は`Missing size`を出力するようにアイテムを並べ替えてください。
`width`を`height`より先に宣言してください

# --answers--

```swift
let width: Int? = 4
```

```swift
let height: Int? = 5
```

```swift
if let w = width, let h = height {
```

```swift
    print("Area: \(w * h)")
```

```swift
} else {
    print("Missing size")
}
```

# --solutions--

```swift
let width: Int? = 4
let height: Int? = 5
if let w = width, let h = height {
    print("Area: \(w * h)")
} else {
    print("Missing size")
}
```

# --output--

Area: 20
