# --description--

`??`を連結すると、Swiftは左から右へ評価し、`nil`でない最初の値で止まります。最後のデフォルト値は、それより前のすべてのオプショナルが`nil`の場合にのみ使用されます。

# --instructions--

このコードは何を出力しますか?
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0)
```

# --answers--

- 7
- 0
- nil
- Optional(7)
