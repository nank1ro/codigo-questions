# --description--

`if`で値が`null`かどうかをチェックすると、コンパイラはそれを記憶します：値が非nullであると分かっているブランチ内では、**スマートキャスト**によって非null型にキャストされるため、`?.`や`!!`を使わずに直接使用できます：
```kotlin
fun greet(name: String?): String {
    if (name != null) {
        return "Hello, " + name.uppercase() // name is a String here
    }
    return "Hello, stranger"
}
```
早期リターンの後でも同じことが起こります：
```kotlin
fun greet(name: String?): String {
    if (name == null) return "Hello, stranger"
    return "Hello, " + name.uppercase() // name is a String from here on
}
```
スマートキャストは、チェックと使用の間で値が変わらない`val`変数と関数のパラメータに対して機能します。

# --instructions--

`text`が`null`でない場合は`text`を大文字にして`!`を付けたものを返し、`null`の場合は`"..."`を返す関数`shout(text: String?): String`を書いてください。`?.`や`!!`の代わりに`if`によるnullチェックを使用してください。

例：`shout("hi")`は`"HI!"`を返し、`shout(null)`は`"..."`を返します。

```kotlin

```

`shout(null)`は`"..."`を返さなければなりません

```kotlin
    tryCatch(shout(null) == "...")
```

`shout("Kotlin")`は`"KOTLIN!"`を返さなければなりません

```kotlin
    tryCatch(shout("Kotlin") == "KOTLIN!")
```

`shout("")`は`"!"`を返さなければなりません

```kotlin
    tryCatch(shout("") == "!")
```
