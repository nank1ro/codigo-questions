# --description--

`null`が呼び出し側のミスを意味する場合は、`requireNotNull`で早期に失敗させます。
値が存在する場合は非nullとして返し、`null`の場合はオプションのメッセージとともに`IllegalArgumentException`をスローします：
```kotlin
fun greet(name: String?): String {
    val safeName = requireNotNull(name) { "name is required" }
    return "Hello, $safeName"
}
greet(null) // IllegalArgumentException: name is required
```
呼び出し後、コンパイラは`name`自体を`String`にスマートキャストするため、その行以降は`name.length`が許可されます。
`!!`とは異なり、失敗時には明確なメッセージが含まれ、*引数*が間違っていたことを示します。

# --instructions--

`text`を大文字にして返す関数`safeUpper(text: String?): String`を書いてください。`text`が`null`の場合は、`requireNotNull`を使用して、メッセージ`text is required`とともに`IllegalArgumentException`をスローしなければなりません。

# --asserts--

`safeUpper("abc")`は`"ABC"`を返さなければなりません

```kotlin
    tryCatch(safeUpper("abc") == "ABC")
```

`safeUpper("Kotlin")`は`"KOTLIN"`を返さなければなりません

```kotlin
    tryCatch(safeUpper("Kotlin") == "KOTLIN")
```

`safeUpper(null)`は`IllegalArgumentException`をスローしなければなりません

```kotlin
    var threw = false
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        threw = true
    }
    tryCatch(threw)
```

例外のメッセージは`text is required`でなければなりません

```kotlin
    var message = ""
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        message = e.message ?: ""
    }
    tryCatch(message == "text is required")
```

fun safeUpper(text: String?): String {
    val value = requireNotNull(text) { "text is required" }
    return value.uppercase()
}
