# --description--

セーフコールは**連結**できます：チェーンのどこかのリンクが`null`になると、残りのチェーンはスキップされ、式全体が`null`になります。
```kotlin
val text: String? = "  hi  "
println(text?.trim()?.uppercase())   // HI
val none: String? = null
println(none?.trim()?.uppercase())   // null, trim() and uppercase() never run
```
`?:`で終わるチェーンは、1行で非nullの結果を得ることができます：
```kotlin
val cleaned = text?.trim()?.uppercase() ?: ""
```

# --instructions--

`text`の両端の空白を取り除いた長さを返し、`text`が`null`の場合は`-1`を返す関数`trimmedLength(text: String?): Int`を書いてください。

例：`trimmedLength("  abc ")`は`3`を返し、`trimmedLength(null)`は`-1`を返します。

# --asserts--

`trimmedLength("  abc ")`は`3`を返さなければなりません

```kotlin
    tryCatch(trimmedLength("  abc ") == 3)
```

`trimmedLength(null)`は`-1`を返さなければなりません

```kotlin
    tryCatch(trimmedLength(null) == -1)
```

`trimmedLength("   ")`は`0`を返さなければなりません

```kotlin
    tryCatch(trimmedLength("   ") == 0)
```

`trimmedLength("kotlin")`は`6`を返さなければなりません

```kotlin
    tryCatch(trimmedLength("kotlin") == 6)
```
