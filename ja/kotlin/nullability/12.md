# --description--

多くの標準関数は、失敗する代わりに`null`を返します。`toIntOrNull()`は文字列を`Int`に変換し、テキストが整数でない場合は`null`を返します：
```kotlin
println("42".toIntOrNull())  // 42
println("4x2".toIntOrNull()) // null
```
`mapNotNull`は`map`のように各要素を変換しますが、`null`になる結果を取り除きます：
```kotlin
val words = listOf("1", "two", "3")
println(words.mapNotNull { it.toIntOrNull() }) // [1, 3]
```

# --instructions--

`tokens`の中にある数値を同じ順序で返し、整数ではない文字列は無視する関数`parseAll(tokens: List<String>): List<Int>`を書いてください。

例：`parseAll(listOf("1", "x", "3"))`は`[1, 3]`を返します。

# --asserts--

`parseAll(listOf("1", "x", "3"))`は`[1, 3]`を返さなければなりません

```kotlin
    tryCatch(parseAll(listOf("1", "x", "3")) == listOf(1, 3))
```

`parseAll(listOf("a", "b"))`は空のリストを返さなければなりません

```kotlin
    tryCatch(parseAll(listOf("a", "b")) == listOf<Int>())
```

```kotlin

```

