# --description--

`?:`の右側には`return`を含む任意の式を書けます。これにより、値が欠けているときに関数から即座に抜け出すコンパクトな方法が得られます：
```kotlin
fun firstUpper(text: String?): Char? {
    val first = text?.firstOrNull() ?: return null
    return first.uppercaseChar() // first is a Char here
}
```
これまでに見たすべてのツールは上手く組み合わさります：null許容のパラメータと戻り値の型は値が*どこで*欠ける可能性があるかを表し、`?.`、`?:`、`let`、スマートキャスト、`toIntOrNull`は決してクラッシュすることなくそれを処理します。

# --instructions--

両方の文字列を整数に変換して`a / b`を返す関数`divide(a: String?, b: String?): Int?`を書いてください。いずれかの文字列が`null`の場合、いずれかが整数でない場合、または`b`が`0`の場合は`null`を返さなければなりません。

例：`divide("10", "2")`は`5`を返し、`divide("10", "x")`は`null`を返します。

```kotlin
fun divide(a: String?, b: String?): Int? {
    val x = a?.toIntOrNull() ?: return null
    val y = b?.toIntOrNull() ?: return null
    if (y == 0) return null
    return x / y
}
```
