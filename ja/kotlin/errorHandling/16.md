# --description--

`try` をどこに置くかで、1つの不正な値がどれだけの作業をだめにするかが決まります。**ループ全体**を包めば最初の失敗で残りのバッチが諦められ、**本体**を包めばその1要素だけが失われます：

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // この値はスキップする
    }
}
println(total) // 8
```
これはスローする検証関数と自然に組み合わさります。関数は1つのルールを述べてそれに反するものを拒否し、ループは拒否されても1要素分しか損しないと判断します。

# --instructions--

2つの関数を書いてください。

`validate(text: String): Int` は、`text` に含まれる数値を返すか、`not a number: ` というメッセージのあとにテキストが続く `IllegalArgumentException` をスローしなければなりません。

`sumValid(values: List<String>): Int` は、`validate` が受け入れる値を合計し、スローさせる値はスキップしなければなりません。

関数呼び出しの例：
```kotlin
println(sumValid(listOf("1", "x", "3")))
// 4 を出力
```

# --asserts--

`validate("7")` は `7` を返さなければなりません

```kotlin
    tryCatch(validate("7") == 7)
```

`validate("x")` は `not a number: x` という `IllegalArgumentException` をスローしなければなりません

```kotlin
    var message = ""
    try { validate("x") } catch (e: IllegalArgumentException) { message = e.message ?: "" }
    tryCatch(message == "not a number: x")
```

`sumValid(listOf("1", "2", "3"))` は `6` を返さなければなりません

```kotlin
    tryCatch(sumValid(listOf("1", "2", "3")) == 6)
```

1つの不正な値が他の値の処理を止めてはなりません

```kotlin
    tryCatch(sumValid(listOf("1", "x", "3")) == 4)
```

`sumValid(listOf("a", "b"))` は `0` を返さなければなりません

```kotlin
    tryCatch(sumValid(listOf("a", "b")) == 0)
```

# --solutions--

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // この値はスキップする
        }
    }
    return total
}
```
