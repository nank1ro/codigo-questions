# --description--

コンパイラがコメントを探すのはコードの中だけで、**文字列リテラル**の中では決してありません。ダブルクォートの間では、`//` と `/* */` は普通の文字にすぎません:
```kotlin
println("50 // 2") // prints 50 // 2
```
最初の `//` はテキストの一部であり、2つ目が本当のコメントを始めます。これに最も驚かされるのはウェブアドレスです。プロトコルの直後に `//` が含まれています。

# --instructions--

このコードは何を出力しますか？
```kotlin
val site = "https://codigo.dev" // the project home page
println(site)
```

# --answers--

- `https://codigo.dev`
- `https:`
- `https://codigo.dev // the project home page`
- 何も出力されない:行全体がコメントになる
