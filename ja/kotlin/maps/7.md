# --description--

`keys`プロパティはマップのすべてのキーを`Set`として返し、`values`はすべての値をコレクションとして返します：
```kotlin
val capitals = mapOf("Italy" to "Rome", "France" to "Paris")
println(capitals.keys)   // [Italy, France]
println(capitals.values) // [Rome, Paris]
```
どちらもエントリが挿入された順序を保持します。
