# --description--

`mapOf`で作成したマップは読み取り専用です。エントリを追加または変更するには`mutableMapOf`を使います。これは`MutableMap`を返します：
```kotlin
val ages = mutableMapOf("Alice" to 30)
ages["Bob"] = 25   // adds a new entry
ages["Alice"] = 31 // updates the existing one
println(ages)
// prints {Alice=31, Bob=25}
```
`map[key] = value`で代入すると、キーが新しい場合はペアが追加され、キーが既に存在する場合は値が置き換えられます。同じことをする`ages.put("Bob", 25)`を呼び出すこともできます。

# --instructions--

`name`のもとに`grade`を保存し、エントリが存在しない場合は追加し、存在する場合は置き換える関数`setGrade(grades: MutableMap<String, Int>, name: String, grade: Int)`を書いてください。

# --asserts--

`setGrade(grades, "Ben", 90)`の後、マップは成績`90`の`Ben`を含んでいなければならない

```kotlin
    val grades = mutableMapOf("Ann" to 80)
    setGrade(grades, "Ben", 90)
    tryCatch(grades["Ben"] == 90)
```

`setGrade(grades, "Ann", 95)`の後、`Ann`の成績は`95`に置き換えられていなければならない

```kotlin
    setGrade(grades, "Ann", 95)
    tryCatch(grades["Ann"] == 95)
```

マップは`{Ann=95, Ben=90}`と等しくなければならない

```kotlin
    tryCatch(grades == mapOf("Ann" to 95, "Ben" to 90))
```
