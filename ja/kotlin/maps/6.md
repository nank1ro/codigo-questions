# --description--

キーが存在するかを確認するには`containsKey`または`in`演算子を、値が存在するかを確認するには`containsValue`を使います：
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
println(ages.containsKey("Alice")) // true
println("Zoe" in ages)             // false
println(ages.containsValue(25))    // true
```

# --instructions--

ユーザー名とメールアドレスのマップが与えられたとき、次の2つの関数を書いてください：
- `isRegistered(users: Map<String, String>, username: String): Boolean` は、`username`がマップのキーであれば`true`を返す
- `isEmailTaken(users: Map<String, String>, email: String): Boolean` は、`email`が値のいずれかであれば`true`を返す

# --asserts--

`isRegistered`は既存のユーザー名に対して`true`を返さなければならない

```kotlin
    val users = mapOf("ann" to "ann@mail.com", "ben" to "ben@mail.com")
    tryCatch(isRegistered(users, "ann") == true)
```

`isRegistered`は存在しないユーザー名に対して`false`を返さなければならない

```kotlin
    tryCatch(isRegistered(users, "zoe") == false)
```

`isEmailTaken`はすでにマップにあるメールアドレスに対して`true`を返さなければならない

```kotlin
    tryCatch(isEmailTaken(users, "ben@mail.com") == true)
```

`isEmailTaken`は使われていないメールアドレスに対して`false`を返さなければならない

```kotlin
    tryCatch(isEmailTaken(users, "zoe@mail.com") == false)
```

```kotlin
fun isRegistered(users: Map<String, String>, username: String): Boolean {
    return users.containsKey(username)
}

fun isEmailTaken(users: Map<String, String>, email: String): Boolean {
    return users.containsValue(email)
}
```
