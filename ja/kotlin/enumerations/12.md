# --instructions--

`enum class Size { SMALL, MEDIUM, LARGE }`があるとき、次のコードはどうなりますか？

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- コンパイルできない: enumに対する`when`式はすべてのエントリを網羅するか、`else`分岐を追加する必要がある
- コンパイルでき、`LARGE`に対しては`null`を返す
- コンパイルでき、`LARGE`に対しては実行時に例外をスローする
- コンパイルでき、`LARGE`に対して自動的に`"L"`を返す
