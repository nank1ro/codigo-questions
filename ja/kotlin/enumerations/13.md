# --instructions--

`enum class Color { RED, GREEN, BLUE }`があるとき、`Color.valueOf("PURPLE")`はどうなりますか？

# --answers--

- `PURPLE`という名前のエントリが存在しないため、`IllegalArgumentException`をスローする
- `null`を返す
- 最初のエントリである`Color.RED`を返す
- enumに新しい`PURPLE`エントリを追加する
