# --description--

enumクラスは、通常のクラスと同じように**コンストラクタ**を持つことができます。各エントリはそれぞれの引数を渡し、値はプロパティに保存されます:
```kotlin
enum class Planet(val moons: Int) {
    MERCURY(0),
    EARTH(1),
    MARS(2)
}
println(Planet.MARS.moons) // 2
```
エントリのデータは変更されないことが前提なので、コンストラクタのプロパティは通常`val`で宣言します。
