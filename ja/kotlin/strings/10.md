# --description--

`replace(old, new)`は、`old`の**すべて**の出現箇所を`new`に置き換えたコピーを返します:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
