# --description--

`String`は二重引用符で囲んで書かれた文字の並びです。
`length`プロパティは、スペースを含めて文字列に何文字含まれているかを示します:
```kotlin
val greeting = "Hello world"
println(greeting.length) // 11
println("".length)       // 0
```
