# --description--

`split`は区切り文字を基準に文字列を`List`の断片に分割し、`joinToString`はその逆で、コレクションの要素を選んだ区切り文字で1つの文字列につなぎ合わせます:
```kotlin
val csv = "a,b,c"
val parts = csv.split(",")
println(parts)                  // [a, b, c]
println(parts.joinToString("/")) // a/b/c
```
