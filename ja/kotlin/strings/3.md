# --description--

`uppercase()`は文字列のすべての文字を大文字にしたコピーを返し、`lowercase()`はその逆を行います。
元の文字列は変更されません:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
