# --instructions--

このプログラムはどうなりますか？

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- `moving`と出力される。`Robot`がデフォルト実装を継承するため
- コンパイルされない：`Robot`は`move()`をオーバーライドしなければならない
- コンパイルされない：インターフェースは関数の本体を持てない
- `null`と出力される
