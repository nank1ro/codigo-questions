# --description--

生成されるメンバーは**プライマリコンストラクタ**で宣言されたプロパティのみを見ます。クラス**本体**で宣言されたプロパティは通常のプロパティです：`toString()`、`equals()`、`hashCode()`、`copy()`の一部にはなりません。

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

val a = Item("nail")
a.quantity = 5
println(a) // Item(name=nail)
```

これは忘れやすいので、オブジェクトを識別するものはすべてプライマリコンストラクタに置き、派生的な状態や一時的な状態は本体に置くようにしましょう。

# --instructions--

このプログラムは何を出力しますか？

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

fun main() {
    val a = Item("nail")
    a.quantity = 5
    val b = Item("nail")
    b.quantity = 9
    println(a == b)
}
```

# --answers--

- `true`、生成された`equals()`は`name`だけを比較するため
- `false`、`quantity`が異なるため
- `Item(name=nail, quantity=5)`
- コンパイルできない：データクラスは本体にプロパティを宣言できない
