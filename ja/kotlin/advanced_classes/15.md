# --instructions--

このコードはどうなりますか？

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- コンパイルされない：ネストクラスは外側のメンバーを見られないので、`Nested`は`inner`でなければならない
- コンパイルされ、`show()`は外側のインスタンスの`name`を返す
- コンパイルされ、`show()`は常に空文字列を返す
- コンパイルされない：Kotlinはクラスの中にクラスを置くことを許さない
