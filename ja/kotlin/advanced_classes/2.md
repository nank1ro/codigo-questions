# --description--

プライマリコンストラクタの各プロパティに対して、データクラスは`componentN()`関数も生成します：最初のプロパティには`component1()`、2番目には`component2()`、という具合です。

これらの関数は**分割宣言**を支えています。分割宣言では、1行でオブジェクトを複数の変数に展開します：

```kotlin
data class Point(val x: Int, val y: Int)

val point = Point(3, 7)
val (x, y) = point
println(x)               // 3
println(point.component2()) // 7
```

変数の順序は名前ではなくプロパティの順序に従います。不要なものは`_`でスキップできます：

```kotlin
val (_, onlyY) = point
```

# --instructions--

`Int`型の`val`プロパティ`x`と`y`を持つデータクラス`Point`を宣言してください。

その後、分割宣言を使って両方のプロパティを読み取り、`"x=3, y=7"`の形式で返す関数`describe(point: Point): String`を書いてください。

```kotlin
    tryCatch(describe(Point(3, 7)) == "x=3, y=7")
```

`describe(Point(-4, 0))`は`"x=-4, y=0"`を返さなければならない

```kotlin
    tryCatch(describe(Point(-4, 0)) == "x=-4, y=0")
```

`Point`は`component1()`と`component2()`を生成しなければならない

```kotlin
    val point = Point(1, 2)
    tryCatch(point.component1() == 1 && point.component2() == 2)
```
