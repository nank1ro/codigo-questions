# --instructions--

このプログラムはどうなりますか？

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2` と出力される。`apply` はリストを返し、`run` はブロックの結果を返すため
- `true 2` と出力される。`apply` は `add` の結果を返すため
- `[a, b] [a, b]` と出力される。両方ともリストを返すため
- `2 [a, b]` と出力される。`apply` はサイズを返し、`run` はリストを返すため
