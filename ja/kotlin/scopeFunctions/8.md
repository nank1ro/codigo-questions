# --description--

ブロックがオブジェクトを何かの**引数**として必要とするときは、`apply` より `also` の方が読みやすくなります。`it` はそのまま渡せますが、`this` は明示的に書かなければなりません。
```kotlin
val names = mutableListOf<String>()
val user = "ada".also { names.add(it) }
println(user)  // ada
println(names) // [ada]
```
式の値はやはり `"ada"` です。`also` は値が通り過ぎるのを見ているだけです。

# --instructions--

トップレベルで `val log = mutableListOf<String>()` を宣言してください。

そのあとで、`word` を大文字にして返し、`also` を使って返す前にその同じ大文字の値を `log` に追加する関数 `record(word: String): String` を書いてください。

例：`record("hi")` のあと、関数は `HI` を返し、`log` には `HI` が含まれます。

# --asserts--

`log` は空で始まらなければなりません

```kotlin
    tryCatch(log.isEmpty())
```

`record("hi")` は `HI` を返さなければなりません

```kotlin
    tryCatch(record("hi") == "HI")
```

最初の呼び出しのあと、`log` は `HI` だけを含まなければなりません

```kotlin
    tryCatch(log == listOf("HI"))
```

2回目の呼び出しは、最初の値を失わずに `log` に追加しなければなりません

```kotlin
    record("bye")
    tryCatch(log == listOf("HI", "BYE"))
```
