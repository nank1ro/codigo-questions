# --description--

`apply` は作ったばかりのオブジェクトに限定されません。任意のオブジェクトに対して動作し、オブジェクトを返すので、オブジェクトが期待される場所ならどこでも式全体を使えます。
```kotlin
val box = Box()
box.apply { label = "tools" }        // box を変更して返す
println(listOf(Box().apply { label = "nails" }).size) // 1
```
ブロックは普通のコードブロックなので、必要な数の文を含められます。

# --instructions--

プロパティ `var name: String` が `""` で始まり、`var age: Int` が `0` で始まる、2つのプロパティを持つクラス `Profile` を作成してください。

そのあとで、`Profile()` を作成し、`apply` を使って `name` を `n` に、`age` を `a` に設定し、設定済みのオブジェクトを返す関数 `makeProfile(n: String, a: Int): Profile` を書いてください。

```kotlin
class Profile {
    var name: String = ""
    var age: Int = 0
}

fun makeProfile(n: String, a: Int): Profile {
    return Profile().apply {
        name = n
        age = a
    }
}
```
