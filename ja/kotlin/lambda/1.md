# --description--

**ラムダ**は名前のない小さな関数で、波括弧の中に式として直接記述します。
最初にパラメータを書き、次に矢印 `->`、その後に関数本体を続けます:
```kotlin
val add = { a: Int, b: Int -> a + b }
```
ラムダは他の値と同じように扱える値です。変数に格納し、後で関数とまったく同じように括弧を付けて呼び出せます:
```kotlin
println(add(2, 3)) // 5
```
パラメータを持たないラムダには矢印がまったくありません: `val hello = { println("Hello!") }`。
