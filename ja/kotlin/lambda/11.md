# --description--

返されたラムダは、関数の中で宣言された `var` をキャプチャできます。その変数は関数が返った後も生き続け、ラムダからだけアクセスできます。つまりプライベートな状態です。
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
`makeGreeter()` を呼び出すたびに新しい `calls` が宣言されるので、2つのグリーターは独立して数えます。

# --instructions--

パラメータを持たないラムダを返す関数 `makeCounter(): () -> Int` を書いてください。ラムダを呼び出すたびに、`0` から始まるカウンターが増やされ、新しい値が返されます。異なる `makeCounter` の呼び出しで返されるカウンターは独立していなければなりません。

例：`val next = makeCounter()` のあと、`next()` は `1` を返し、さらに `next()` は `2` を返します。

# --asserts--

カウンターの最初の呼び出しは `1` を返さなければなりません

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

同じカウンターの2回目の呼び出しは `2` を返さなければなりません

```kotlin
    tryCatch(first() == 2)
```

3回呼び出した後、カウンターは `3` を返さなければなりません

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

2つのカウンターは独立していなければなりません

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
