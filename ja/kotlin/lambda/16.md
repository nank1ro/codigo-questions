# --description--

**レシーバ付きラムダ**を受け取る関数もあります。ラムダの中では `this` が特定のオブジェクトを指すため、その名前を書かずにメンバーを直接呼び出せます。
`buildString` はよくある例です。そのラムダの中では `this` が `StringBuilder` なので、`append` をローカル関数のように呼び出せます:
```kotlin
val text = buildString {
    append("Hello")
    append(", ")
    append("world")
}
println(text) // Hello, world
```
`buildString` は最終的な文字列を返します。ループの中で `+` で連結する代わりとして便利です。

# --instructions--

`buildString` を使って、すべての項目を角括弧で包んで順に並べた文字列を返す関数 `bracketed(items: List<String>): String` を書いてください。

例：`bracketed(listOf("a", "b"))` は `"[a][b]"` を返します。

# --asserts--

`bracketed(listOf("a", "b"))` は `"[a][b]"` を返さなければなりません

```kotlin
    tryCatch(bracketed(listOf("a", "b")) == "[a][b]")
```

`bracketed(listOf("kotlin"))` は `"[kotlin]"` を返さなければなりません

```kotlin
    tryCatch(bracketed(listOf("kotlin")) == "[kotlin]")
```

`bracketed(listOf())` は空の文字列を返さなければなりません

```kotlin
    tryCatch(bracketed(listOf()) == "")
```

`bracketed(listOf("x", "y", "z"))` は `"[x][y][z]"` を返さなければなりません

```kotlin
    tryCatch(bracketed(listOf("x", "y", "z")) == "[x][y][z]")
```

# --solutions--

```kotlin
fun bracketed(items: List<String>): String {
    return buildString {
        items.forEach { append("[").append(it).append("]") }
    }
}
```
