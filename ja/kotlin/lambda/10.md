# --description--

ラムダは値なので、関数はラムダを**返す**ことができます。戻り値の型は関数型になります:
```kotlin
fun multiplier(factor: Int): (Int) -> Int {
    return { it * factor }
}
val triple = multiplier(3)
println(triple(5)) // 15
```
返されたラムダは `factor` をキャプチャするので、`multiplier` を呼び出すたびに異なる関数が作られます。
関数を受け取ったり返したりする関数は**高階関数**と呼ばれます。
