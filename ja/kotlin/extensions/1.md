# --description--

**拡張関数**は、既存の型のソースコードに手を加えずに新しい関数を追加します。
`fun`、拡張したい型（**レシーバー型**）、ドット、関数名の順に書きます。
```kotlin
fun Int.squared(): Int {
    return this * this
}
println(4.squared()) // 16
```
関数の中の `this` は、その関数が呼び出された値であり、**レシーバー**と呼ばれます。`4.squared()` では `4` です。
拡張を定義したら、最初から `Int` の一部だった関数とまったく同じようにドットで呼び出せます。
