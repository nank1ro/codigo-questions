# --description--

`Regex("cat")`は`catalog`の中の`cat`にも一致します。単語全体を要求するには、**単語境界**の`\b`を使います。これは単語文字とそれ以外の間にある空の位置に一致し、テキストの先頭と末尾も含まれます:
```kotlin
println(Regex("""cat""").findAll("cat catalog").count())     // 2
println(Regex("""\bcat\b""").findAll("cat catalog").count()) // 1
```
パターンは普通の文字列なので、実行時に部品から組み立てられます:
```kotlin
val word = "cat"
val pattern = Regex("""\b""" + word + """\b""")
```

# --instructions--

`\b`と`findAll`を使って、`word`が`text`の中に単語全体として何回現れるかを数える関数`countWord(text: String, word: String): Int`を書いてください

例: `countWord("cat catalog cat", "cat")`は`2`を返します。

```kotlin
fun countWord(text: String, word: String): Int {
    return Regex("""\b""" + word + """\b""").findAll(text).count()
}
```
