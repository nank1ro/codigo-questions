# --description--

**配列**は、同じ型の値を固定数だけ1つの変数名の下に格納します。
`arrayOf`で作成し、角括弧と`0`から始まる**インデックス**で要素を読み取り、`size`で要素数を取得します：
```kotlin
val colors = arrayOf("red", "green", "blue")
println(colors[0])   // red
println(colors.size) // 3
```
最後の要素はインデックス`size - 1`にあります。
