# --description--

`while`ループはその条件が0以外である限り実行され続けるので、比較式がいつ止まるかを決めます:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 0, 1, 2 と出力される
```
`<`と`<=`のどちらを選ぶかによって、最後の値を含めるかどうかが変わります。
