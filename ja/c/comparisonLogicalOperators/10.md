# --description--

演算子には、何が最初に計算されるかを決める**優先順位**があります:
1. まず`!`が適用される
2. 次に関係比較`<`、`>`、`<=`、`>=`
3. 次に等価比較`==`、`!=`
4. 次に`&&`
5. 最後に`||`

そのため`a > 0 && a < 10`には括弧が不要です。両方の比較が`&&`より先に計算されるからです。
また`x == 1 || y == 2 && z == 3`は`x == 1 || (y == 2 && z == 3)`を意味します。`&&`は`||`より結合が強いためです。
