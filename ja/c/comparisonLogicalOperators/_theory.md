**比較演算子**は2つの値を比較し、比較が成り立つときは`1`、成り立たないときは`0`という結果を返します。
**等しい**演算子`==`は2つの値が同じかどうかを調べ、**等しくない**演算子`!=`は2つの値が異なるかどうかを調べます:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" と出力される
printf("%d\n", a != b);
// "1" と出力される
```
注意: `==`（記号2つ）は比較を行い、`=`（記号1つ）は値を代入します。

---

他の比較演算子は2つの値の大小関係を調べます。
- `<` より小さい、`>` より大きい
- `<=` 以下、`>=` 以上
```c
printf("%d\n", 3 < 5);  // "1" と出力される
printf("%d\n", 5 >= 6); // "0" と出力される
```
比較の結果は単なる`int`なので、関数はそれをそのまま返すことができます:
```c
int is_big(int n) {
    return n > 100;
}
```

---

Cでは比較の結果は特別な型ではなく、値がちょうど`1`（真）か`0`（偽）になる`int`です。
つまり、他の数値と同じように`int`型の変数に格納できます:
```c
int n = 42;
int big = n > 100; // big は 0
```
出力に`true`/`false`という単語が現れることはありません。`printf("%d", 2 == 2)`は`1`を出力します。

---

**論理演算子**は複数の比較を組み合わせます。**かつ**演算子`&&`は両辺が真のときだけ`1`になります:
```c
int age = 25;
printf("%d\n", age >= 18 && age < 65); // "1" と出力される
```
数学のように比較を連結してはいけません。`1 <= x <= 10`は`(1 <= x) <= 10`として評価され、これは`0`または`1`と`10`を比較することになり、常に真になります。
2つの比較は必ず別々に書き、`&&`でつなげてください。

---

**または**演算子`||`は少なくとも一方が真のときに`1`になり、両辺がともに偽のときだけ`0`になります:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // "1" と出力される
```
両辺はそれぞれ完全な比較式でなければなりません。`day == 6 || 7`は「6または7」という意味にはなりません（理由は後で分かります）。

---

**否定**演算子`!`は結果を反転させます。`!1`は`0`に、`!0`は`1`になります。
これは式の前に置くので、比較全体を否定するには括弧を使います:
```c
int n = 5;
printf("%d\n", !(n > 3)); // "0" と出力される
```
括弧がないと、`!n > 3`はまず`!n`を計算してから、それを`3`と比較してしまいます。

---

論理演算子は`0`と`1`だけに作用するわけではありません。Cでは**0以外の値はすべて真**とみなされ、`0`だけが偽とみなされます。
そのため`5 && 1`は`1`、`0 || -3`は`1`となり、`!`は0以外の値をすべて`0`に変えます:
```c
printf("%d\n", !7); // "0" と出力される
printf("%d\n", !0); // "1" と出力される
```
これが`day == 6 || 7`が常に真になる理由です。`7`はそれ単体で真の値だからです。

---

`&&`と`||`は**短絡評価**を行います。結果が確定した時点で評価を止めます。
- `&&`では、左辺が`0`のとき右辺は評価されません
- `||`では、左辺が真のとき右辺は評価されません

これを利用すると、危険な処理の左側にチェックを置くことで保護できます:
```c
int safe = divisor != 0 && value / divisor > 2;
```
`divisor`が`0`のとき、除算は実行されません。

---

短絡評価は関数呼び出しもスキップします。`0 && check()`では関数`check`は決して呼び出されないため、（カウンタの更新のような）その副作用も発生しません。

---

演算子には、何が最初に計算されるかを決める**優先順位**があります:
1. まず`!`が適用される
2. 次に関係比較`<`、`>`、`<=`、`>=`
3. 次に等価比較`==`、`!=`
4. 次に`&&`
5. 最後に`||`

そのため`a > 0 && a < 10`には括弧が不要です。両方の比較が`&&`より先に計算されるからです。
また`x == 1 || y == 2 && z == 3`は`x == 1 || (y == 2 && z == 3)`を意味します。`&&`は`||`より結合が強いためです。

---

`char`は小さな整数なので、同じ演算子で文字を比較できます。
シングルクォートで囲んだ文字リテラルと比較します:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // "1" と出力される
```
ダブルクォートを使うと文字列になり、この方法では比較できません。

---

文字は数値なので、`<`や`>`はその文字コードを比較します。`'a'`、`'b'`、`'c'`や`'0'`、`'1'`、`'2'`のような連続した文字は連続したコードを持ちます。
そのため、文字に対する範囲チェックは数値に対するものとまったく同じように動作します:
```c
int is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

Cでよくある間違いは、`==`を書くべきところに`=`を書いてしまうことです。代入は代入した値そのものを値とする式なので、このコードはそれでもコンパイルできてしまいます:
```c
int x = 5;
if (x = 0) { ... } // x に 0 を代入し、条件は 0（偽）になる
if (x = 3) { ... } // x に 3 を代入し、条件は 3（真）になる
```
ほとんどのコンパイラはこれについて警告を出すので、条件式の挙動がおかしいときは警告を確認してください。

---

`if`の条件は0以外のときに真として扱われる単なる式なので、比較演算子や論理演算子を自然に使えます:
```c
if (n < 0) {
    printf("negative\n");
} else if (n == 0) {
    printf("zero\n");
}
```
結果を先に変数に格納しておいて、その変数を調べることもできます。`int ok = n > 0; if (ok) { ... }`のようにします。

---

`while`ループはその条件が0以外である限り実行され続けるので、比較式がいつ止まるかを決めます:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 0, 1, 2 と出力される
```
`<`と`<=`のどちらを選ぶかによって、最後の値を含めるかどうかが変わります。

---

C99以降、ヘッダ`stdbool.h`が型`bool`と定数`true`（`1`）、`false`（`0`）を提供します:
```c
#include <stdbool.h>

bool ready = true;
bool done = count == 10;
```
`bool`は内部的には依然として整数です。`%d`で出力すると`1`か`0`が表示され、比較結果と同じように`&&`、`||`、`!`と組み合わせて使えます。
`bool`を使うと、単なる`int`を返すよりも関数の意図が明確になります。

---

`bool`型の引数は、`true`と比較しなくてもそのまま`&&`や`||`のオペランドとして使えます。`citizen == true`ではなく`age >= 18 && citizen`のように書きます。

---

条件式で`&&`と`||`が混在するときは、優先順位だけで正しく動作する場合でも、各グループを括弧で囲んでください。そうすることでルールが一目で分かるようになります。
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
