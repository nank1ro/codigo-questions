# --description--

Cでは比較の結果は特別な型ではなく、値がちょうど`1`（真）か`0`（偽）になる`int`です。
つまり、他の数値と同じように`int`型の変数に格納できます:
```c
int n = 42;
int big = n > 100; // big は 0
```
出力に`true`/`false`という単語が現れることはありません。`printf("%d", 2 == 2)`は`1`を出力します。

# --instructions--

次のコードの出力は何ですか？
```c
int result = 3 <= 3;
printf("%d\n", result);
```
