# --description--

論理演算子は`0`と`1`だけに作用するわけではありません。Cでは**0以外の値はすべて真**とみなされ、`0`だけが偽とみなされます。
そのため`5 && 1`は`1`、`0 || -3`は`1`となり、`!`は0以外の値をすべて`0`に変えます:
```c
printf("%d\n", !7); // "0" と出力される
printf("%d\n", !0); // "1" と出力される
```
これが`day == 6 || 7`が常に真になる理由です。`7`はそれ単体で真の値だからです。
