# --description--

短絡評価は関数呼び出しもスキップします。`0 && check()`では関数`check`は決して呼び出されないため、（カウンタの更新のような）その副作用も発生しません。

# --instructions--

```c
#include <stdio.h>
int calls = 0;
int check() {
    calls++;
    return 1;
}
int main() {
    int result = 0 && check();
    printf("%d %d\n", result, calls);
    return 0;
}
```
