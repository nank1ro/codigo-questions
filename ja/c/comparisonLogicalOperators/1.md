# --description--

**比較演算子**は2つの値を比較し、比較が成り立つときは`1`、成り立たないときは`0`という結果を返します。
**等しい**演算子`==`は2つの値が同じかどうかを調べ、**等しくない**演算子`!=`は2つの値が異なるかどうかを調べます:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" と出力される
printf("%d\n", a != b);
// "1" と出力される
```
注意: `==`（記号2つ）は比較を行い、`=`（記号1つ）は値を代入します。
