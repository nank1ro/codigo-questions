# --description--

`&&`と`||`は**短絡評価**を使います:結果が確定した時点で評価を止めます。
- `&&`では、左側が`0`のとき右側は決して評価されません
- `||`では、左側が0以外のとき右側は決して評価されません

これにより、左側のチェックで右側の危険な操作を防ぐことができます:
```c
int ok = count != 0 && total / count > 2;
```
`count`が`0`のとき、除算は決して実行されないため、プログラムはクラッシュしません。
