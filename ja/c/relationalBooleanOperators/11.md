# --description--

演算子には、何が先に計算されるかを決める**優先順位**があります:
1. 最初に`!`が適用される
2. 次に関係比較の`<`、`>`、`<=`、`>=`
3. 次に等値比較の`==`、`!=`
4. 次に`&&`
5. 次に`||`

つまり`a > 0 && a < 10`には括弧が不要で、`&&`は`||`よりも強く結合するため、`a && b || c`は`(a && b) || c`を意味します。括弧を使うと、別のまとめ方を強制したり、単に意図を読みやすくしたりできます。

# --instructions--

`without`がデフォルトの優先順位で`a && b || c`を計算し、`with`が`b || c`を先に評価するよう強制するようコードを完成させ、両方を出力してください

# --seed--

int without = a && b [/] c;
int with = a && [/]b || c[/];
printf("%d %d\n", without, with);
