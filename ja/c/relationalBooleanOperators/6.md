# --description--

`!`は0以外の値を`0`に、`0`を`1`に変えるため、2回適用すると値は正確に`0`か`1`に正規化されます:`!!42`は`1`、`!!0`は`0`です。
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
関数が任意の0以外の数を返し、きれいな`1`が欲しいときに便利です。

int n = -5;
