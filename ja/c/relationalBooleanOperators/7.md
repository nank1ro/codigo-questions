# --description--

C99以降、ヘッダ`stdbool.h`は型`bool`と定数`true`（`1`です）および`false`（`0`です）を提供します:
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
`bool`は内部ではやはり整数です:`%d`で出力でき、比較結果とまったく同じように`&&`、`||`、`!`と組み合わせて使えます。単なる`int`よりも意図が明確になるというだけです。

# --instructions--

`open`が真を表すブール定数になり、`closed`がその否定になるようコードを完成させ、両方を出力してください
