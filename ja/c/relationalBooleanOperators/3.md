# --description--

Cで最もよくある間違いは、`==`のつもりで`=`と書いてしまうことです。`=`1つは**代入**であり、Cでは代入は式であり、その値は代入された値になります:
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
`=`を使ったコードはそのままコンパイルできるため、`if (x = 0)`と書かれた条件はテストする代わりに黙って`x`に`0`を設定してしまいます。多くのコンパイラはこれに対して警告を出します:その警告に目を通しましょう。
