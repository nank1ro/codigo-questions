# --description--

**論理演算子**は条件を組み合わせます。**かつ**を表す`&&`演算子は両側が真のときにだけ`1`になり、**または**を表す`||`演算子は少なくとも片側が真のときに`1`になります:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
Cでは**0以外の値はすべて真**として扱われ、`0`だけが偽となるので、`5 && 1`は`1`になり、`0 || -3`は`1`になります。`&&`と`||`の結果は常に正確に`1`か`0`です。
