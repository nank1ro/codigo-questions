**関係演算子**は2つの値を比較します。結果は特殊な型ではなく、比較が成り立てば`1`、成り立たなければ`0`となる`int`です。Cには6つの関係演算子があります:
```c
printf("%d\n", 5 == 5); // equal: prints "1"
printf("%d\n", 5 != 5); // not equal: prints "0"
printf("%d\n", 3 < 5);  // less than: prints "1"
printf("%d\n", 3 > 5);  // greater than: prints "0"
printf("%d\n", 5 <= 5); // less than or equal: prints "1"
printf("%d\n", 4 >= 5); // greater than or equal: prints "0"
```
結果が`int`であるため、`%d`で出力でき、他の数値と同じように`int`変数に格納することもできます。

---

関数は比較の結果を直接返すことができます。呼び出し元は`1`か`0`を受け取ります。
```c
int is_big(int n) {
    return n > 100;
}

printf("%d\n", is_big(250)); // prints "1"
```
`>`と`>=`（または`<`と`<=`）のどちらを選ぶかで、境界値が含まれるかどうかが決まります:`n >= 100`は`100`のとき`1`、`n > 100`は`0`です。

---

Cで最もよくある間違いは、`==`のつもりで`=`と書いてしまうことです。`=`1つは**代入**であり、Cでは代入は式であり、その値は代入された値になります:
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
`=`を使ったコードはそのままコンパイルできるため、`if (x = 0)`と書かれた条件はテストする代わりに黙って`x`に`0`を設定してしまいます。多くのコンパイラはこれに対して警告を出します:その警告に目を通しましょう。

---

**論理演算子**は条件を組み合わせます。**かつ**を表す`&&`演算子は両側が真のときにだけ`1`になり、**または**を表す`||`演算子は少なくとも片側が真のときに`1`になります:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
Cでは**0以外の値はすべて真**として扱われ、`0`だけが偽となるので、`5 && 1`は`1`になり、`0 || -3`は`1`になります。`&&`と`||`の結果は常に正確に`1`か`0`です。

---

`0`または0以外の値を保持する変数は、それ自体を条件としてそのまま使えます:`holiday`だけで「`holiday`が0以外である」ことを意味し、`holiday != 0`と書く必要はありません。
```c
int is_open(int weekday, int holiday) {
    return weekday && !holiday;
}
```
**否定**の`!`演算子は条件を反転させます:`!0`は`1`になり、0以外の値に対する`!`は`0`になります。

---

`!`は0以外の値を`0`に、`0`を`1`に変えるため、2回適用すると値は正確に`0`か`1`に正規化されます:`!!42`は`1`、`!!0`は`0`です。
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
関数が任意の0以外の数を返し、きれいな`1`が欲しいときに便利です。

---

C99以降、ヘッダ`stdbool.h`は型`bool`と定数`true`（`1`です）および`false`（`0`です）を提供します:
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
`bool`は内部ではやはり整数です:`%d`で出力でき、比較結果とまったく同じように`&&`、`||`、`!`と組み合わせて使えます。単なる`int`よりも意図が明確になるというだけです。

---

yes/noの質問に答える関数は`bool`を返すべきです。`bool`の引数はそれ自体がすでに条件なので、`&&`や`||`のオペランドとして直接使いましょう:`citizen == true`ではなく`age >= 18 && citizen`と書きます。
```c
bool can_enter(int age, bool member) {
    return age >= 16 && member;
}
```
これらの演習では、`stdbool.h`はすでにコードの上でインクルードされています。

---

`&&`と`||`は**短絡評価**を使います:結果が確定した時点で評価を止めます。
- `&&`では、左側が`0`のとき右側は決して評価されません
- `||`では、左側が0以外のとき右側は決して評価されません

これにより、左側のチェックで右側の危険な操作を防ぐことができます:
```c
int ok = count != 0 && total / count > 2;
```
`count`が`0`のとき、除算は決して実行されないため、プログラムはクラッシュしません。

---

短絡評価は関数呼び出しもスキップします。`1 || check()`では関数`check`は決して呼び出されないため、カウンタの更新のような副作用も発生しません。
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
`&&`や`||`の右側にある関数が、自分が頼りにしている何かを行う場合は、この点に注意してください。

---

演算子には、何が先に計算されるかを決める**優先順位**があります:
1. 最初に`!`が適用される
2. 次に関係比較の`<`、`>`、`<=`、`>=`
3. 次に等値比較の`==`、`!=`
4. 次に`&&`
5. 次に`||`

つまり`a > 0 && a < 10`には括弧が不要で、`&&`は`||`よりも強く結合するため、`a && b || c`は`(a && b) || c`を意味します。括弧を使うと、別のまとめ方を強制したり、単に意図を読みやすくしたりできます。

---

`char`は小さな整数なので、文字は同じ演算子で比較できます。シングルクォートで囲んだ文字リテラルと比較します:ダブルクォートの`"a"`は文字列であり、この方法では比較できません。
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // prints "1"
```
`'0'`、`'1'`、...`'9'`や`'a'`、`'b'`、...`'z'`のような連続する文字は連続したコードを持つため、文字に対する範囲チェックは数値の場合とまったく同じように機能します:
```c
bool is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

数学のように比較を連結してはいけません。`1 <= x <= 10`はコンパイルできますが、`(1 <= x) <= 10`として評価されます:最初の比較は`0`か`1`になり、その値が`10`と比較されるため、式全体は常に`1`です。
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
必ず両方の比較を明示的に書き、`&&`でつなぎましょう。

---

条件に`&&`と`||`が混ざるときは、優先順位で正しくなる場合でも各部分を括弧でまとめましょう:ルールが一目で読めるようになります。
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
剰余演算子`%`は`==`と自然に組み合わせられます:`n % 4 == 0`は`n`が`4`で割り切れるとき`1`です。
