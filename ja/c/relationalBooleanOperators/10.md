# --description--

短絡評価は関数呼び出しもスキップします。`1 || check()`では関数`check`は決して呼び出されないため、カウンタの更新のような副作用も発生しません。
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
`&&`や`||`の右側にある関数が、自分が頼りにしている何かを行う場合は、この点に注意してください。
