# --description--

数学のように比較を連結してはいけません。`1 <= x <= 10`はコンパイルできますが、`(1 <= x) <= 10`として評価されます:最初の比較は`0`か`1`になり、その値が`10`と比較されるため、式全体は常に`1`です。
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
必ず両方の比較を明示的に書き、`&&`でつなぎましょう。

# --instructions--

連結した比較を`chained`に、正しい範囲チェックを`correct`に格納し、両方を出力するプログラムとなるよう行を並べ替えてください。`chained`は`correct`より前に定義してください
