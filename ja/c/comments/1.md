# --description--

**コメント**とは、コンパイラではなく人間のためにソースコード内に書かれるテキストです。コンパイラはプログラムをビルドする前にコメントを捨ててしまうので、コメントを使ってコードの目的を説明したり、メモを残したり、決定を記録したりできます。

最も一般的な種類は**1行コメント**です: `//`からその行の終わりまですべて無視されます。
```c
// Greet the user
printf("Hello\n");
```
プログラムを実行しても最初の行は何もしません。出力を生成するのは`printf`だけです。

# --instructions--

最初の行が1行コメントになり、プログラムが`Hello, world!`を出力するようにコードを完成させてください
