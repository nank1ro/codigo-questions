# --description--

コメントが複数行にわたるときは、Cの**複数行コメント**（ブロックコメントとも呼ばれます）が使えます: `/*`で始まり`*/`で終わり、改行を含む間のすべてが無視されます。
```c
/*
  Prints the welcome banner.
  Called once when the program starts.
*/
printf("Welcome!\n");
```
ブロックコメントは短くして1行に収めることもできます: `/* like this */`。

`//`が行の終わりで止まるのに対し、`/*`コメントは`*/`に到達するまで止まりません。閉じるのを忘れると、その後のすべてのコードがコメントの一部として扱われます。
