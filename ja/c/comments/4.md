# --description--

ブロックコメントは**ネストしません**。コンパイラは、前にいくつ`/*`があっても、最初に見つけた`*/`で`/*`コメントを終了します:
```c
/* outer /* inner */ still code */
```
この例ではコメントは`inner`の直後に終わるので、`still code */`がコードとしてコンパイルされ、エラーになります。

これは、すでに`/* */`コメントを含むブロックをコメントアウトしたいときに問題になります: 内側の`*/`が外側のコメントを早く閉じてしまうからです。その場合は、代わりに各行の先頭に`//`を付けてください。

# --instructions--

このコードをコンパイルするとどうなりますか？
```c
/* start
   /* nested */
   printf("hidden\n");
*/
printf("done\n");
```

# --answers--

- コンパイルエラー: コメントは最初の`*/`で終わり、`printf`の後に余計な`*/`が残る
- `done`と出力される
- `hidden`と`done`が出力される
- すべて外側のコメントの中にあるため、何も出力されない
