# --description--

**列挙型**（`enum`）は関連する整数定数の集まりに名前を付けるもので、単なる数値の代わりに`RED`のように書くことができます。
`enum`キーワード、名前、そして波括弧で囲まれた定数のリストで宣言します。
```c
enum Color { RED, GREEN, BLUE };
```
すべての定数は整数です。特に指定しない限り、最初の定数は`0`で、以降は1つ前の値に1を足した値になります。つまり`RED`は`0`、`GREEN`は`1`、`BLUE`は`2`です。
整数なので、`%d`で出力します。
```c
printf("%d\n", GREEN);
// prints "1"
```
