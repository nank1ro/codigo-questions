# --description--

Cにはenum定数の名前を取得する組み込みの方法がありません。`printf("%d\n", SUMMER)`は`Summer`ではなく`2`を出力します。一般的な解決策は、`switch`で各定数に対応する文字列を返す小さな関数を書くことです。

# --instructions--

`Season`型、季節の名前を返す関数`season_name`、そして`SUMMER`の名前を出力する`main`を定義するように行を並べ替えてください。関数は`main`より前に定義し、caseは宣言内の定数と同じ順序にして、`default`は最後に置いてください

# --solutions--

```c
#include <stdio.h>
typedef enum { WINTER, SPRING, SUMMER, AUTUMN } Season;
char *season_name(Season season) {
    switch (season) {
        case WINTER: return "Winter";
        case SPRING: return "Spring";
        case SUMMER: return "Summer";
        default: return "Autumn";
    }
}
int main() {
    printf("%s\n", season_name(SUMMER));
    return 0;
}
```
