# --description--

番号付けは、列挙した定数の数だけ自動的に続きます。4番目の定数は`3`、5番目は`4`というようになります。
名前は他の定数と同様に通常大文字で書かれ、プログラム全体で一意でなければなりません。2つの列挙型が同じ定数名を共有することはできません。

# --instructions--

`enum Day { MON, TUE, WED, THU, FRI };`が与えられたとき、`THU`の値は何ですか？

# --answers--

- 3
- 4
- 2
- THUに数値はない
