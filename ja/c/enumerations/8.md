# --description--

毎回`enum Color`と書くのは冗長です。`typedef`を使うと列挙型に短い型名を付けられ、列挙型自体は無名のままにしておけます。
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
新しい名前`Color`は、前に`enum`キーワードを付けずに単独で使われます。
