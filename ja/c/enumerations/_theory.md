**列挙型**（`enum`）は関連する整数定数の集まりに名前を付けるもので、単なる数値の代わりに`RED`のように書くことができます。
`enum`キーワード、名前、そして波括弧で囲まれた定数のリストで宣言します。
```c
enum Color { RED, GREEN, BLUE };
```
すべての定数は整数です。特に指定しない限り、最初の定数は`0`で、以降は1つ前の値に1を足した値になります。つまり`RED`は`0`、`GREEN`は`1`、`BLUE`は`2`です。
整数なので、`%d`で出力します。
```c
printf("%d\n", GREEN);
// prints "1"
```

---

番号付けは、列挙した定数の数だけ自動的に続きます。4番目の定数は`3`、5番目は`4`というようになります。
名前は他の定数と同様に通常大文字で書かれ、プログラム全体で一意でなければなりません。2つの列挙型が同じ定数名を共有することはできません。

---

`=`を使って定数に明示的な値を与えることもできます。それ以降の定数は、その値から数え続けます。
```c
enum Month { JAN = 1, FEB, MAR }; // FEB is 2, MAR is 3
```
明示的な値は連続している必要も増加している必要もありません。`enum Status { OK = 200, NOT_FOUND = 404 };`も全く問題なく有効です。

---

列挙型は型でもあります。`enum`の後に列挙型の名前を書くことでその型の変数を宣言し、定数の1つを代入できます。
```c
enum Color favorite = GREEN;
```
定数は整数なので、列挙型の変数も通常の演算子で比較できます。
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```

---

列挙型は、`int`とまったく同じように関数の引数の型にすることができます。
```c
int is_weekend(enum Day day) {
    return day == SAT || day == SUN;
}
```
関数の中では、`switch`が各定数を扱う自然な方法です。列挙型の定数は`case`ラベルとしてそのまま使えるからです。
```c
switch (day) {
    case SAT: return 1;
    case SUN: return 1;
    default: return 0;
}
```

---

`switch`のすべてのcaseが1つの定数を扱う場合、各caseの後に`break`を書くことを忘れないでください。忘れると、実行は次のcaseへ続けて流れ落ちてしまいます。
列挙型のすべての定数を網羅していれば、`default`ケースは必須ではありません。

---

関数も列挙型を返すことができます。戻り値の型として列挙型を使い、その定数の1つを返すだけです。
```c
enum Grade grade_for(int score) {
    if (score >= 60) {
        return PASS;
    }
    return FAIL;
}
```
名前の付いた定数を返す方が、素の`0`や`1`を返すよりも呼び出し側にとってずっとわかりやすくなります。

---

毎回`enum Color`と書くのは冗長です。`typedef`を使うと列挙型に短い型名を付けられ、列挙型自体は無名のままにしておけます。
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
新しい名前`Color`は、前に`enum`キーワードを付けずに単独で使われます。

---

enumの定数は自動的に`int`に変換されるので、`int n = BLUE;`は有効で`2`が格納されます。
逆方向は**キャスト**で行います。整数の前に括弧で列挙型を書きます。
```c
enum Color c = (enum Color)1; // c is GREEN
```
Cはその数値が定数に一致するかどうかをチェックしません。`(enum Color)7`はどの定数も`7`でなくてもコンパイルが通るので、変換する前に整数を検証してください。

---

enum値に対する算術演算はただの`int`を生成します。`GREEN + 1`は`BLUE`ではなく`2`になります。
その結果をenum変数に戻したり関数から返したりするには、enum型にキャストします。
```c
enum Color after_green = (enum Color)(GREEN + 1); // BLUE
```
剰余演算子`%`と組み合わせることで、定数を巡回させて最初の定数に折り返すことができます。

---

よく使われる手法として、列挙型の最後に`COUNT`という名前の余分な定数を1つ追加します。番号付けは`0`から始まるので、その値はちょうどそれより前にある実際の定数の個数になります。
```c
enum Day { MON, TUE, WED, DAY_COUNT }; // DAY_COUNT is 3
```
この番兵（sentinel）を使えば、数を直接書かなくてもすべての定数をループでき、番兵の前に定数を追加しても正しく動作し続けます。
```c
for (int d = MON; d < DAY_COUNT; d++) {
    printf("%d\n", d);
}
```

---

`COUNT`という番兵は、定数1つにつき1つのスロットを持つ配列のサイズとしても最適で、定数はその配列への読みやすいインデックスになります。
```c
enum Fruit { APPLE, BANANA, CHERRY, FRUIT_COUNT };

int stock[FRUIT_COUNT] = {10, 4, 7};
printf("%d\n", stock[BANANA]); // prints "4"
```
`0`から`FRUIT_COUNT`までのループですべてのスロットを巡回でき、返す必要があるときはループのインデックスを`enum Fruit`にキャストし直せます。

---

Cにはenum定数の名前を取得する組み込みの方法がありません。`printf("%d\n", SUMMER)`は`Summer`ではなく`2`を出力します。一般的な解決策は、`switch`で各定数に対応する文字列を返す小さな関数を書くことです。

---

enumの値は他の整数と同じように配列に格納できます。`enum Fruit basket[] = {APPLE, APPLE, CHERRY};`は3つの果物を保持し、各要素を定数と比較できます。
