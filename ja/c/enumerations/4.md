# --description--

列挙型は型でもあります。`enum`の後に列挙型の名前を書くことでその型の変数を宣言し、定数の1つを代入できます。
```c
enum Color favorite = GREEN;
```
定数は整数なので、列挙型の変数も通常の演算子で比較できます。
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```
