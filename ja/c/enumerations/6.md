# --description--

`switch`のすべてのcaseが1つの定数を扱う場合、各caseの後に`break`を書くことを忘れないでください。忘れると、実行は次のcaseへ続けて流れ落ちてしまいます。
列挙型のすべての定数を網羅していれば、`default`ケースは必須ではありません。

# --instructions--

`enum Size`を宣言し、`size`に`MEDIUM`を格納し、`switch`で`Medium`を出力するように行を並べ替えてください。caseの順序は宣言内の定数の順序と同じにしてください

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
