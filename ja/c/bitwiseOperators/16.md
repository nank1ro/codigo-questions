# --description--

複数の小さな数値が、1つの大きな値に詰め込まれることがよくあります。その1つを読み戻すには、まずビット`0`から始まる位置まで下にシフトし、それからその上のすべてをマスクして落とします:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// "18" を出力する。0x12 のバイト
```
まずシフトし、それからマスクする、この順序を覚えておきましょう。マスクは常に、フィールドが最下部に到達した後のものを表します。

# --instructions--

`packed`を16ビット右にシフトし、シフト後の値の下位8ビットだけを`third_byte`に残して出力するように行を並べ替えてください
