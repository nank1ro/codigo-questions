すべての整数は、メモリに**ビット**の並びとして格納され、各ビットは`0`か`1`のどちらかです。数値`12`は`00001100`として、数値`10`は`00001010`として格納されます。
**ビット演算子**は、数値全体ではなく個々のビットに対して動作します。**AND** 演算子 `&` は2つの値をビットごとに比較し、*両方の*ビットが`1`の場所だけに`1`を残します:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// prints "8"
```
ビットパターンは通常、`0x0C`のような16進リテラルとして書かれます。各16進桁が正確に4ビットを表すためです。ビット操作では必ず`unsigned`型を使い、`%u`で出力してください。

---

**OR** 演算子 `|` は2つの値をビットごとに比較し、*少なくとも1つ*のビットが`1`の場所に`1`を残します:
```c
//  00001100   (12)
// |00001010   (10)
//  --------
//  00001110   (14)
printf("%u\n", 12u | 10u);
// prints "14"
```
`|` は、2つのビットパターンを1つにまとめる一般的な方法です。

---

**XOR** 演算子 `^`（排他的論理和）は、2つのビットが*異なる*場所にだけ`1`を残します:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
ここから便利な性質が導かれます。同じXORを2回適用すると、元の値に戻ります。

---

**NOT** 演算子 `~` は1つのオペランドを受け取り、そのすべてのビットを反転させます。各`0`が`1`になり、各`1`が`0`になります。
`unsigned int`は32ビットを保持するため、`~0x0Fu`はその32ビットすべてを反転させ、非常に大きな数を生成します。必要なバイトだけを残すには、`~`を`& 0xFF`と組み合わせます:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// prints "240"
```
`~` は `&` よりも強く結合するため、先に適用されます。
`~` を論理演算の `!` と混同しないでください。`!` は値全体を見て`0`か`1`を返しますが、`~` はすべてのビットを書き換えます。

---

**左シフト** 演算子 `<<` は、すべてのビットを指定した桁数だけ左に移動させ、右側に空いた場所をゼロで埋めます:
```c
//  00000011   (3)
//  << 2
//  00001100   (12)
printf("%u\n", 3u << 2);
// prints "12"
```
`n`ビット左にシフトすると、値は2の`n`乗倍になります。
Cプログラムを未定義動作にする間違いが2つあります。負の値を左シフトすることと、型の幅（`unsigned int`では32）以上のビット数でシフトすることです。**符号なし**の値を扱えば、前者の間違いは避けられます。

---

**右シフト** 演算子 `>>` は、すべてのビットを右に移動させます。右端からあふれたビットは捨てられます。符号なしの値では、左側に空いた場所はゼロで埋められます:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// prints "3"
```
`n`ビット右にシフトすると、符号なしの値は2の`n`乗で割られ、余りは捨てられます。
*負の*値の右シフトは移植性がないため、これもビット操作を`unsigned`型で行うべきもう1つの理由です。

---

それぞれの2項ビット演算子には、変数をその場で更新する**複合代入**の形があります。`&=`、`|=`、`^=`、`<<=`、`>>=`です。
```c
unsigned int x = 12;
x &= 10;  // same as x = x & 10;
x |= 1;   // same as x = x | 1;
x ^= 3;   // same as x = x ^ 3;
x <<= 1;  // same as x = x << 1;
x >>= 2;  // same as x = x >> 2;
```
これらは変数名を繰り返すよりも読みやすく、フラグ変数のビットを変更する一般的な方法です。

---

**マスク**は、別の値のうち必要な部分を選び出すビットを持つ値です。`&`と組み合わせると、マスクはマスクが`1`になっているビットを残し、それ以外のビットをすべてゼロにします:
```c
//  10101011   (0xAB)
// &00001111   (0x0F)
//  --------
//  00001011   (0x0B)
printf("%u\n", 0xABu & 0x0Fu);
// prints "11"
```
`0x0F`は下位4ビット（下位**ニブル**と呼ばれます）を残し、`0xFF`は下位8ビット、つまり1バイト全体を残します。

---

ビットには最右端から`0`で始まる番号が付くため、`1u << n`はビット`n`だけがオンになっているマスクになります。
1つのビットを**セット**する、つまり他のビットに触れずにそのビットをオンにするには、値とそのマスクのORを取ります:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// prints "6"
```
ビットがすでにオンだった場合、値は変わらないため、ビットのセットは繰り返しても安全です。

---

1つのビットを**クリア**する、つまりそのビットをオフにするには、値とマスクの*逆*のANDを取ります:
```c
unsigned int value = 7;       // 00000111
value = value & ~(1u << 1);   // 00000101
printf("%u\n", value);
// prints "5"
```
`~(1u << 1)`はビット`1`以外のすべてのビットがオンになっている値なので、ANDは他の部分をそのまま残します。

---

1つのビットを**トグル**する、つまり現在の状態にかかわらずそのビットを反転するには、値とマスクのXORを取ります:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// prints "7"
```
XORは自分自身を打ち消すため、同じビットをもう1度トグルすると元の値に戻ります。

---

1つのビットを**テスト**するには、値とマスクのANDを取り、結果が`0`と異なるかどうかを確認します:
```c
unsigned int value = 10;                  // 00001010
printf("%d\n", (value & (1u << 3)) != 0); // prints "1"
printf("%d\n", (value & (1u << 2)) != 0); // prints "0"
```
ANDは`1`を生成するのではなく、`0`またはマスク自身（ビット`3`の場合は`8`）を生成します。そのため、結果はそのまま答えとして使わずに`!= 0`と比較します。

---

**フラグ**は名前付きのマスクで、それぞれが異なるビットを使い、1つの変数にすべて格納できます。フラグは`|`で組み合わせ、`&`で読み戻します:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// prints "1"
```
したがって、1つの`unsigned int`で32個の独立したyes/noの答えを保持できます。

---

C23より前は、数値を2進数で出力するフォーマット指定子がなく、`0b1010`のようなリテラルも標準Cでは使えませんでした。ビットを表示するには、ループを自分で書きます。最上位ビットからビット`0`まで降りながら、毎回`(value >> i) & 1u`を出力します。
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
値を`i`ビット右にシフトするとビット`i`が最右端に移動し、そこで`& 1u`がそのビットを取り出します。

---

値のうち何個のビットが`1`かを数えるのは、典型的なビットループです。`& 1u`で最下位ビットを調べ、それをカウンターに加え、`>>=`で値を1ビット右にシフトし、何もなくなるまで繰り返します。
```c
unsigned int value = 6, count = 0;
while (value != 0) {
    count += value & 1u;
    value >>= 1;
}
// count is 2
```
符号なしの値は十分な回数右にシフトすると`0`になるため、ループは必ず終わります。

---

複数の小さな数値が、1つの大きな値に詰め込まれることがよくあります。その1つを読み戻すには、まずビット`0`から始まる位置まで下にシフトし、それからその上のすべてをマスクして落とします:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// prints "18", the 0x12 byte
```
まずシフトし、それからマスクする、この順序を覚えておきましょう。マスクは常に、フィールドが最下部に到達した後のものを表します。
