# --description--

**NOT** 演算子 `~` は1つのオペランドを受け取り、そのすべてのビットを反転させます。各`0`が`1`になり、各`1`が`0`になります。
`unsigned int`は32ビットを保持するため、`~0x0Fu`はその32ビットすべてを反転させ、非常に大きな数を生成します。必要なバイトだけを残すには、`~`を`& 0xFF`と組み合わせます:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// prints "240"
```
`~` は `&` よりも強く結合するため、先に適用されます。
`~` を論理演算の `!` と混同しないでください。`!` は値全体を見て`0`か`1`を返しますが、`~` はすべてのビットを書き換えます。
