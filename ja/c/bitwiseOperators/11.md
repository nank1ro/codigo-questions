# --description--

1つのビットを**トグル**する、つまり現在の状態にかかわらずそのビットを反転するには、値とマスクのXORを取ります:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// prints "7"
```
XORは自分自身を打ち消すため、同じビットをもう1度トグルすると元の値に戻ります。
