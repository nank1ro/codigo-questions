# --description--

C23より前は、数値を2進数で出力するフォーマット指定子がなく、`0b1010`のようなリテラルも標準Cでは使えませんでした。ビットを表示するには、ループを自分で書きます。最上位ビットからビット`0`まで降りながら、毎回`(value >> i) & 1u`を出力します。
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
値を`i`ビット右にシフトするとビット`i`が最右端に移動し、そこで`& 1u`がそのビットを取り出します。
