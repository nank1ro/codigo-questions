# --description--

それぞれの2項ビット演算子には、変数をその場で更新する**複合代入**の形があります。`&=`、`|=`、`^=`、`<<=`、`>>=`です。
```c
unsigned int x = 12;
x &= 10;  // x = x & 10; と同じ
x |= 1;   // x = x | 1; と同じ
x ^= 3;   // x = x ^ 3; と同じ
x <<= 1;  // x = x << 1; と同じ
x >>= 2;  // x = x >> 2; と同じ
```
これらは変数名を繰り返すよりも読みやすく、フラグ変数のビットを変更する一般的な方法です。

# --instructions--

`flags`が`0x01`で始まり、次に`|=`で値`4`に相当するビットをオンにし、それから`<<=`で2ビット左にシフトし、最後に出力するように行を並べ替えてください
