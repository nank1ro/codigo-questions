# --description--

**フラグ**は名前付きのマスクで、それぞれが異なるビットを使い、1つの変数にすべて格納できます。フラグは`|`で組み合わせ、`&`で読み戻します:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// "1" を出力する
```
したがって、1つの`unsigned int`で32個の独立したyes/noの答えを保持できます。

# --instructions--

3つのフラグを宣言し、`READ`と`WRITE`を`perms`に組み合わせ、そこに`EXEC`を追加して結果を出力するように行を並べ替えてください
