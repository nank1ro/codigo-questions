# --description--

**リンクリスト**は、メモリ上に散らばった個別の**ノード**に値を格納します。各ノードは値と次のノードへのポインタを保持し、最後のノードは`NULL`を指します。内部のポインタは宣言中の型自身を参照するため、構造体には自分自身に名前を付けるための**タグ**が必要です。波括弧の中ではまだ`typedef`の名前は存在しません:
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
ノード同士は、あるノードのアドレスを別のノードの`next`に格納することでつながり、指されたノードのメンバにはアロー演算子でアクセスします:
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```
