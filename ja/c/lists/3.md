# --description--

リストは、その最初のノードである**先頭**（head）への1本のポインタによって保持されます。他のノードはすべて、先頭から`next`をたどって到達します。アローは連ねて書けます: `head->next`は2番目のノード、`head->next->next`は3番目のノードです。空のリストとは`NULL`と等しい先頭のことであり、最後のノードの`next`も`NULL`です。そのため、アローを1つ余分にたどると`NULL`の参照外しが起き、プログラムがクラッシュします。

# --instructions--

```c
Node *head = make_node(1);
head->next = make_node(2);
head->next->next = make_node(3);
printf("%d\n", head->next->next->value);
```
