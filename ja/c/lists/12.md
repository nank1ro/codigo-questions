# --description--

最初のノードの削除は`push_front`の鏡像です。2番目のノードのアドレスを保存し、最初のノードを解放し、保存したアドレスを新しい先頭として返します。呼び出し側はその結果を先頭を保持する変数に格納し直します:
```c
Node *next = head->next;
free(head);
return next;
```
先頭が`NULL`になるまで取り除くと、1回の呼び出しで1ノードずつ、リスト全体が解放されます。

# --instructions--

最初のノードを解放し、2番目のノードを新しい先頭として返すように`pop_front`を完成させてください
