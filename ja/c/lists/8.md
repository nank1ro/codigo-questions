# --description--

ノードを**末尾**に追加するには、`next`が`NULL`である最後のノードが必要です。関数はそれを見つけるまでたどり、そこに新しいノードを付け加え、変更されていない先頭を返します:
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
リストが空のときは、たどるべき最後のノードが存在しません。新しいノードがそのまま先頭として返されます。

# --solutions--

```c
#include <stdio.h>
#include <stdlib.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *push_back(Node *head, int value) {
    Node *node = malloc(sizeof(Node));
    node->value = value;
    node->next = NULL;
    if (head == NULL) {
        return node;
    }
    Node *last = head;
    while (last->next != NULL) {
        last = last->next;
    }
    last->next = node;
    return head;
}
int main() {
    Node *head = NULL;
    head = push_back(head, 1);
    head = push_back(head, 2);
    head = push_back(head, 3);
    for (Node *n = head; n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}
```
