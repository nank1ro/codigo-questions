# --description--

`free(p)`の後も変数`p`は古いアドレスを保持し続けますが、それが指すメモリはもうあなたのものではありません。`p`は今や**ダングリングポインタ**です。それを通じた読み書きや、2回目の解放は未定義動作です。プログラムは古い値を出力したり、ゴミを出力したり、クラッシュしたりするかもしれませんが、コンパイラは警告しません。ポインタが`free`より後まで生き残る必要がある場合は、直後に`NULL`を設定してください。そうすれば、その後の使用は`NULL`チェックに引っかかります。

# --instructions--

次のコードの何が問題ですか？
```c
Node *n = head;
free(n);
printf("%d\n", n->value);
```

# --answers--

- すでに解放されたノードを読んでおり、これは未定義動作です
- 問題なし: `n`はまだそのノードを指しているので、値が出力されます
- `n`が`free`の後で使われているため、コンパイルできません
- `free`はポインタのアドレスを必要とするので、`free(&n)`とすべきです
