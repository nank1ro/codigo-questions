# --description--

リストの反転は、3つのポインタですべての`next`ポインタをその場で逆向きにします。`prev`はすでに反転済みの部分、`head`は処理中のノード、`next`はリンクを変更する前に保存しておいたリストの残りのコピーです。各ステップで現在のノードを`prev`へ逆向きに指し、次に`prev`と`head`の両方を前へ進めます:
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
`head`が`NULL`に達したとき、すべてのリンクは逆向きになっており、`prev`が新しい先頭です。

# --solutions--

```c
#include <stdio.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head != NULL) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
int main() {
    Node c = {3, NULL};
    Node b = {2, &c};
    Node a = {1, &b};
    for (Node *n = reverse(&a); n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    return 0;
}
```
