# --description--

リストをたどること、いわゆる**走査**は、先頭から始めて`NULL`に達するまで`next`をたどるループです。`for`ループを使えば、ループ変数としてポインタを置いて1行で書けます:
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
インデックスは存在しません。ノードに到達する唯一の方法は、その前のノードに格納されたポインタを通ることです。

# --instructions--

`a`から始めてリスト内のすべてのノードの値を出力するようにループを完成させてください
