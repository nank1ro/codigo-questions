# --description--

`char`へのポインタは他のポインタと同じように動作します。1文字のアドレスを保持し、`*p`でその文字を読み書きします:
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
ポインタを通じた読み書きは自由に組み合わせられます: `*p = *p + 1`は`'A'`を`'B'`に変えます。

# --instructions--

行を並べ替えて、`letter`を`'a'`として宣言し、`p`をそれに向け、ポインタを通して文字を`'b'`に置き換え、`letter`を出力するようにしてください
