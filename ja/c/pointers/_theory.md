すべての変数はメモリのどこかに存在し、その場所には**アドレス**と呼ばれる番号が付いています。`&`演算子は「〜のアドレス」と読み、変数のアドレスを返します:
```c
int x = 42;
printf("%p\n", &x); // prints something like 0x7ffd5c3e9a4c
```
`%p`指定子はアドレスを出力します。正確な値は実行のたびに変わるため、プログラムがその値に依存することはありません。
アドレスは**ポインタ**変数に格納されます。ポインタは、指す先の型の後に`*`を付けて宣言します:
```c
int *p = &x; // p is a pointer to int, and it holds the address of x
```
`p`は`x`を**指している**と言います。同じアドレスを保持する2つのポインタは等しいので、`p == &x`は真になります。

---

ポインタ自体は単なるアドレスです。そのアドレスに格納された値を読むには、`*`演算子でポインタを**デリファレンス**します:
```c
int x = 42;
int *p = &x;
printf("%d\n", *p); // prints "42"
```
`*p`は「`p`が指している値」を意味し、`x`自身と同じく`int`です。同じ記号`*`には2つの役割があります。宣言`int *p`では「これはポインタである」ことを表し、式`*p`ではポインタをたどって値に到達します。

---

デリファレンスしたポインタには**代入**もできます。`*p`に書き込むと、`p`が保持するアドレスに新しい値が格納され、ポインタが指す変数が変わります:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x`と`*p`は同じメモリに対する2つの名前です。`*`を付けずに`p`に代入すると、そこに格納された値ではなく、ポインタが保持する**どのアドレスか**が変わります。

---

まだ何も指していないポインタは`NULL`を保持すべきです。`NULL`は`stdio.h`と`stddef.h`で定義されている特別な定数で、「アドレスなし」を意味します:
```c
int *p = NULL;
```
`NULL`ポインタをデリファレンスするとプログラムがクラッシュする実行時エラーになるため、`NULL`の可能性があるポインタは使用前にチェックします:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
`NULL`はゼロなので、`if (p)`は`if (p != NULL)`の一般的な省略形です。初期化子なしで宣言されたポインタは`NULL`ではなくゴミ値を保持するため、ポインタは必ず初期化してください。

---

ポインタは任意の型を指せます: `double *`、`char *`、`bool *`など。宣言の型は、ポインタをデリファレンスしたときに何バイト読み、それを何として解釈するかをコンパイラに伝えます:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
ポインタは指す変数の型と一致しなければならず、`int *p = &price;`はコンパイラに拒否されます。`NULL`は任意の型のポインタに代入できる唯一の値です。

---

`char`へのポインタは他のポインタと同じように動作します。1文字のアドレスを保持し、`*p`でその文字を読み書きします:
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
ポインタを通じた読み書きは自由に組み合わせられます: `*p = *p + 1`は`'A'`を`'B'`に変えます。

---

ポインタはアドレスを格納するものであり、同じマシン上ではそこにどんな型が格納されていても、すべてのアドレスは同じサイズを持ちます。したがってポインタの`sizeof`は`char *`、`int *`、`double *`のいずれでも同じで、64ビットシステムでは`8`バイト、32ビットでは`4`バイトです:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
ポインタのサイズと、ポインタが指すもののサイズを混同しないでください: `sizeof(p)`はアドレスのサイズ、`sizeof(*p)`は値のサイズです。

---

式の中で使われた配列名は**先頭要素**のアドレスを表すので、ポインタに直接代入できます:
```c
int numbers[3] = {10, 20, 30};
int *p = numbers; // same as &numbers[0]
```
ポインタに整数を加えると、バイトではなくその数だけ**要素**分前進します: `p + 1`は`numbers[1]`のアドレス、`*(p + 1)`は`20`です。コンパイラはステップを型のサイズに応じて拡大します。
インデックスによるアクセスはポインタにも機能します: `p[i]`は`*(p + i)`と定義されるので、`p[2]`は`30`です。これは**ポインタ演算**と呼ばれます。

---

`p + 1`が次の要素であるように、`p++`はポインタをその場で次の要素へ進めます。ループはインデックスの代わりにポインタを進めて配列をたどれます:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
各周回で`p`が指す要素を出力し、その後`p`を1要素前進させます。

---

配列が関数に渡されると、先頭要素へのポインタへ**減衰**します。このため、パラメータ`int values[]`と`int *values`はまったく同じ意味であり、関数がそれ自身では長さを知ることができません。受け取るのはアドレスだけだからです。
同じ配列を指すポインタ同士は比較や減算ができます。`end - start`はそれらの間にある要素数であり、ループはポインタをあるアドレスから別のアドレスまで動かせます:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
`numbers`と`numbers + 3`を渡せば、別のサイズパラメータなしに最初の3つの要素を表せます。

---

関数の引数は**値渡し**されます: 関数はコピーを受け取り、パラメータへの代入は呼び出し元の変数を決して変えません。関数に変数を変えさせるには、変数のアドレスを渡して、関数の中でポインタをデリファレンスします:
```c
void reset(int *p) {
    *p = 0;
}

int counter = 7;
reset(&counter); // counter is now 0
```
古典的な例は2つの変数の入れ替えです。片方を上書きする間、もう片方の値の一時コピーが必要になります。

---

関数が`return`できる値は1つだけです。それ以上を返すには、呼び出し元が所有する変数へのポインタを受け取り、そのポインタを通して結果を書き込みます。このようなパラメータは**出力パラメータ**と呼ばれます:
```c
void min_max(int a, int b, int *min, int *max) {
    *min = a;
    *max = b;
    if (a > b) {
        *min = b;
        *max = a;
    }
}

int lo, hi;
min_max(4, 9, &lo, &hi); // lo is 4, hi is 9
```
呼び出し元は変数を宣言してそのアドレスを渡すと、呼び出しの後には値が入っています。多くの標準関数がこのパターンを使っており、`scanf("%d", &n)`に`&`が必要なのはこのためです。

---

構造体へのポインタは矢印`->`でメンバにアクセスし、配列に格納された構造体のアドレスは`&items[i]`で取得します。関数はポインタを**返す**こともできます。例えば、見つけた要素へのポインタを返します:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
呼び出し元は、返されたポインタが`NULL`でないことを確認した後で、そのポインタを`->`でたどってメンバを読みます。ポインタを返すと構造体のコピーが避けられ、呼び出し元は元の要素を変更できます。

---

`const`は書く位置によって、値を保護するか、ポインタを保護するかが決まります:
```c
const int *p = &a; // pointer to const: *p cannot be changed, p can point elsewhere
int *const q = &a; // const pointer: q always points to a, but *q can be changed
```
宣言は右から左に読みます: `p`は定数の`int`へのポインタ、`q`は`int`への定数ポインタです。constへのポインタは、`int sum(const int *values, int size)`のように、関数が受け取ったものを**読むだけ**であると約束する一般的な方法です。通常の変数も渡せます。この約束が制限するのは関数ができることだけです。

---

ポインタも変数なので、それ自身のアドレスを持ちます。このアドレスは、2つの星印で宣言される**ポインタへのポインタ**に格納できます:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp`は`p`、つまり`x`のアドレスであり、`**pp`は両方のステップをたどって`7`に到達します。ポインタへのポインタを使うと、関数はポインタが保持するアドレスを変更できます: 関数は`&p`を受け取り、`*pp`に代入します。

---

まとめです: ポインタで配列をたどり、これまでに見つけた最良の要素へのポインタを保持して返す関数です。返すものがなければ`NULL`を返します:
```c
int *first_negative(int *values, int size) {
    for (int *p = values; p < values + size; p++) {
        if (*p < 0) {
            return p;
        }
    }
    return NULL;
}
```
呼び出し元はデリファレンスする前に結果を`NULL`と比較し、`result - values`で要素のインデックスを復元できます。
