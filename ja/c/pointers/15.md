# --description--

ポインタも変数なので、それ自身のアドレスを持ちます。このアドレスは、2つの星印で宣言される**ポインタへのポインタ**に格納できます:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp`は`p`、つまり`x`のアドレスであり、`**pp`は両方のステップをたどって`7`に到達します。ポインタへのポインタを使うと、関数はポインタが保持するアドレスを変更できます: 関数は`&p`を受け取り、`*pp`に代入します。

# --instructions--

`pp`をポインタ`p`へのポインタとして宣言し、`pp`を通して`x`の値を出力するようにコードを完成させてください
