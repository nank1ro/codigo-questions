# --description--

`p + 1`が次の要素であるように、`p++`はポインタをその場で次の要素へ進めます。ループはインデックスの代わりにポインタを進めて配列をたどれます:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
各周回で`p`が指す要素を出力し、その後`p`を1要素前進させます。

# --instructions--

行を並べ替えて、`1`、`2`、`3`を`values`に格納し、`p`をその先頭要素に向けて、ポインタを進めながらすべての要素を出力するようにしてください
