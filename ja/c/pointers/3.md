# --description--

デリファレンスしたポインタには**代入**もできます。`*p`に書き込むと、`p`が保持するアドレスに新しい値が格納され、ポインタが指す変数が変わります:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x`と`*p`は同じメモリに対する2つの名前です。`*`を付けずに`p`に代入すると、そこに格納された値ではなく、ポインタが保持する**どのアドレスか**が変わります。

# --instructions--

`p`が指す変数に`10`を格納し、`x`を出力するようにコードを完成させてください
