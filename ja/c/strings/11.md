# --description--

ヘッダー`ctype.h`は1つの文字を扱う関数を提供します。
`toupper(c)`は文字の大文字版を、`tolower(c)`は小文字版を返します。それ以外の文字はそのまま返されます:
```c
char letter = toupper('a'); // 'A'
```

# --instructions--

`first`を大文字に、`second`を小文字に変換して`Ab`を出力してください

# --seed--

```c
#include <stdio.h>
#include <ctype.h>

int main() {
    char first = 'a';
    char second = 'B';
    printf("%c%c\n", [/](first), [/](second));
    return 0;
}
```
