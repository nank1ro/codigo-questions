# --description--

`strcmp`は文字コードを使って文字列を1文字ずつ比較します。
最初の文字列が2番目より前に来る場合は負の値、後に来る場合は正の値、等しい場合は`0`が結果になります:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

# --instructions--

`strcmp("apple", "banana")`は何を返しますか？

# --answers--

- 負の数
- 0
- 正の数
