# --description--

ヌル終端文字もメモリ上の領域を使います。リテラル`"hi"`は`'h'`、`'i'`、`'\0'`の3バイトを占有します。
自分でサイズを宣言する場合は、必ずそのための余裕を残してください:
```c
char word[6] = "hello"; // 5 letters + '\0'
```
終端文字がないと、Cは文字列がどこで終わるかを知る手段がありません。
