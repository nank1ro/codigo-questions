# --description--

配列は宣言後に`=`で代入することはできません:
```c
char copy[20];
copy = "Codigo"; // error
```
文字列をコピーするには、`string.h`の`strcpy(destination, source)`を使います。
コピー先はすべての文字と`'\0'`を格納できるだけの十分な大きさが必要です。

# --instructions--

`source`を`copy`にコピーして出力するように行を並べ替えてください。`source`は`copy`より前に宣言してください

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
