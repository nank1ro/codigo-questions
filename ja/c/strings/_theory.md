Cには専用の文字列型がありません。**文字列**とは、特殊な文字である**ヌル終端文字**`'\0'`で終わる`char`の配列です。
文字列を作る最も簡単な方法は、ダブルクォートで囲んだ文字列リテラルを使うことです:
```c
char name[] = "Codigo";
```
コンパイラが文字数を数え、末尾に自動的に`'\0'`を追加してくれます。
文字列を出力するには`%s`プレースホルダーを使います:
```c
printf("%s\n", name);
// prints "Codigo"
```

---

ヌル終端文字もメモリ上の領域を使います。リテラル`"hi"`は`'h'`、`'i'`、`'\0'`の3バイトを占有します。
自分でサイズを宣言する場合は、必ずそのための余裕を残してください:
```c
char word[6] = "hello"; // 5 letters + '\0'
```
終端文字がないと、Cは文字列がどこで終わるかを知る手段がありません。

---

ヘッダー`string.h`は文字列を扱う関数を提供します。
`strlen`はヌル終端文字より前の文字数を返します（終端文字自体はカウントされません）:
```c
strlen("hello"); // 5
```
文字列を受け取る関数は、パラメータを`char *text`、つまり先頭の文字へのポインタとして宣言します。
これらの演習では、`string.h`と`ctype.h`はすでにコードの上部でインクルードされています。

---

文字列は配列なので、すべての文字は`0`から始まるインデックスを持ちます:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
1文字を出力するには`%c`を使います。文字を書き換えることもできます:
```c
word[0] = 'K'; // word is now "Koding"
```

---

すべての文字列は`'\0'`で終わるため、あらかじめ長さを知らなくても走査できます。現在の文字が終端文字でない間だけ処理を続ければよいのです。
```c
for (int i = 0; text[i] != '\0'; i++) {
    printf("%c\n", text[i]);
}
```

---

配列は宣言後に`=`で代入することはできません:
```c
char copy[20];
copy = "Codigo"; // error
```
文字列をコピーするには、`string.h`の`strcpy(destination, source)`を使います。
コピー先はすべての文字と`'\0'`を格納できるだけの十分な大きさが必要です。

---

`strcat(destination, source)`は`source`を`destination`の末尾に追加します:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
`strcpy`と同様に、コピー先の配列は結果を格納できるだけの十分な大きさが必要です。

---

2つの文字列を`==`で比較することはできません。それはメモリ上のアドレスを比較することになり、文字の中身を比較することにはなりません。
代わりに`strcmp(first, second)`を使ってください。これは2つの文字列がまったく同じ文字を含む場合に`0`を返します:
```c
strcmp("cat", "cat"); // 0
strcmp("cat", "dog"); // not 0
```

---

`strcmp`は文字コードを使って文字列を1文字ずつ比較します。
最初の文字列が2番目より前に来る場合は負の値、後に来る場合は正の値、等しい場合は`0`が結果になります:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

---

`strncpy(destination, source, n)`は最大`n`文字までコピーします。
`source`が`n`より長い場合、`'\0'`は書き込まれないため、自分で終端させる必要があります。
```c
char prefix[10];
strncpy(prefix, "Codigo", 3);
prefix[3] = '\0'; // prefix is "Cod"
```

---

ヘッダー`ctype.h`は1つの文字を扱う関数を提供します。
`toupper(c)`は文字の大文字版を、`tolower(c)`は小文字版を返します。それ以外の文字はそのまま返されます:
```c
char letter = toupper('a'); // 'A'
```

---

文字列は関数にポインタとして渡されるため、`char *text`を受け取る関数は呼び出し元の文字をその場で変更できます。
`'\0'`までのループと`toupper`を組み合わせることで、文字列全体を変換できます:
```c
text[i] = toupper(text[i]);
```

---

`sprintf`は`printf`と同じように動作しますが、フォーマットされたテキストを画面ではなく`char`配列に書き込みます:
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer is "3 items"
```
バッファはテキスト全体とその`'\0'`を格納できるだけの十分な大きさが必要です。

---

`sprintf`は数値をテキストに変換する便利な方法です。一度バッファに入れてしまえば、あらゆる文字列関数を使えるようになります。
