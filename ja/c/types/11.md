# --description--

`sizeof`演算子は型や変数が何**バイト**を占めるかを教えてくれます。その結果は`size_t`型を持ち、`%zu`で出力されます:
```c
printf("%zu\n", sizeof(int));  // ほとんどのシステムで"4"と出力される
```
規格が保証しているのは`sizeof(char)`が`1`であることと`short <= int <= long`であることだけですが、典型的な64ビットシステムでのサイズは次のとおりです: `char`が1、`short`が2、`int`が4、`long`が8、`float`が4、`double`が8です。
`sizeof`は数値をハードコードせずに変数が使うメモリ量を調べるためによく使われます。
