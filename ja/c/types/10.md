# --description--

`int`だけが整数型ではありません。修飾子はサイズと範囲を変えます:
- `short`はメモリ使用量が少なく、範囲も狭いです（通常-32768から32767）
- `long`はより広い範囲を持ちます（64ビットシステムでは約±900京）
- `unsigned`は符号を取り除きます: `unsigned int`は`0`から約40億までですが、負の値には決してなりません

`long`でなければならないリテラルには`L`サフィックスを、`unsigned`には`U`サフィックスを付け、各型には専用の指定子があります:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" と出力される
```
`%ld`は`long`を、`%u`は`unsigned int`を、`%lu`は`unsigned long`を出力します。ほとんどのシステムでは通常の`int`は約20億までの値しか保持できないので、`5000000000`はそこに収まりません。

# --instructions--

典型的な64ビットシステムで50億という値を正しく格納する宣言はどれですか？

# --answers--

- `long n = 5000000000L;`
- `int n = 5000000000;`
- `short n = 5000000000;`
- `unsigned int n = 5000000000U;`
