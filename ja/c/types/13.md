# --description--

符号付き型と違い、**符号なし**の算術は範囲を超えても動作が明確に定義されています: 値はオドメーターのように**折り返し**ます。
`UINT_MAX`に`1`を足すと`0`になり、`0`から`1`を引くと`UINT_MAX`（`unsigned int`が32ビットの場合`4294967295`）になります:
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // "0" と出力される
```
これが、`unsigned`変数を「負になるまで」カウントダウンするループが決して止まらない理由です: 符号なしの値は決して`0`より小さくならないからです。
