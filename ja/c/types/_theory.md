Cは**静的型付け**言語です: すべての変数は型を宣言して定義され、その型が格納できる値の種類と使用するメモリ量を決めます。
最もよく使う3つの型は次のとおりです:
- `int` : `30`や`-4`のような整数
- `double` : `1.75`のような小数部を持つ数
- `char` : `'A'`のようにシングルクォートで囲んだ1文字

それぞれの型には専用の`printf`**書式指定子**があります: `%d`は`int`を、`%f`は`double`を（デフォルトで小数点以下6桁）、`%c`は`char`を出力します:
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// "30 1.750000 A" と出力される
```
型に合わない指定子を使うと出力が壊れるので、必ず一致させてください。

---

Cには2つの浮動小数点型があります: `float`（単精度、有効桁数は約7桁）と`double`（倍精度、有効桁数は約15桁）です。
`1.75`のような小数リテラルは`double`型になります。`float`リテラルを書くには`1.75f`のように`f`サフィックスを付けます。
メモリが厳しい場合を除いて`double`を使うのが望ましいです: これがデフォルトであり、より精度が高いからです。
```c
double pi = 3.14159;
float ratio = 0.5f;
```
小数の結果を返す関数は戻り値の型として`double`を宣言すべきで、`double`型のパラメータは整数と小数の両方の引数を受け付けます:
```c
double half(double x) {
    return x / 2;
}
```

---

`%f`は小数点以下6桁を出力しますが、それが欲しい場合はほとんどありません。`%`と`f`の間に精度を指定すると、表示する小数桁数を選べます: `%.2f`は小数点以下2桁、`%.1f`は1桁を出力し、値は切り捨てではなく**四捨五入**されます:
```c
double price = 9.987;
printf("%.2f\n", price); // "9.99" と出力される
printf("%.1f\n", price); // "10.0" と出力される
```
`float`は`double`と同じ指定子で出力されます: `printf`に渡されるときに自動的に`double`へ変換されるためです。

---

`/`の結果は両オペランドの型に依存します。
**両方**のオペランドが整数の場合、結果は整数になり小数部は切り捨てられます: `7 / 2`は`3.5`ではなく`3`です。
**少なくとも一方**が浮動小数点値の場合、除算は小数部を保持します: `7 / 2.0`は`3.5`です。
```c
printf("%d\n", 7 / 2);     // "3" と出力される
printf("%f\n", 7 / 2.0);   // "3.500000" と出力される
```
リテラルを`2`ではなく`2.0`と書くのが、浮動小数点除算を強制する最も簡単な方法です。

---

Cは値を異なる型の変数に代入するとき、**暗黙的に**数値型を変換します。
- `int`が`double`に格納されると、失われることなく拡大されます: `double d = 3;`は`d`を`3.0`にします
- `double`が`int`に格納されると**切り捨て**られます: `int n = 3.99;`は`n`を`3`にします（コンパイラは通常これを警告します）

変換は代入の瞬間にのみ起こります。右辺の式はまず自身の型で計算されます:
```c
double d = 7 / 2;
```
ここでの`7 / 2`は整数除算で`3`になり、その後で`3`が`3.0`に変換されます。

---

暗黙の変換が望みどおりでない場合や、変換を明示したい場合は**明示的キャスト**を使います: 値の前に括弧で対象の型を書きます。
```c
double x = 3.99;
int n = (int) x;   // nは3
```
浮動小数点値を`int`にキャストすると**ゼロ方向に切り捨て**られます: `(int) 3.99`は`3`、`(int) -2.5`は`-2`になり、四捨五入は行われません。
キャストはその直後の値にのみ適用されるので、`(int) x * 2`はまず`x`をキャストしてから掛け算します。

---

2つの`int`変数から浮動小数点除算を得る標準的な方法はキャストです: 割り算の前に**片方のオペランド**を`double`にキャストします。
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
`(double) (total / count)`のように結果全体をキャストするのはよくある間違いです: その時点ですでに整数除算が行われており、小数部は失われています。

---

`char`は実際には小さな整数です: 文字の**ASCIIコード**を格納します。
`'A'`は`65`、`'a'`は`97`、`'0'`は`48`で、連続した文字は連続したコードを持ちます。
そのため文字に対して算術演算ができます:
- `'a' + 1`は`98`、つまり`'b'`のコードです
- `'7' - '0'`は`55 - 48`、つまり数値`7`です

同じ値を`%c`で文字として、`%d`で数値として出力できます:
```c
char c = 'A';
printf("%c %d\n", c, c); // "A 65" と出力される
```

---

大文字と小文字はASCII表で`32`離れています: `'A'`は`65`、`'a'`は`97`です。
したがって小文字から`32`を引くとその大文字版になり、結果は`char`に戻して格納できます:
```c
char upper = 'g' - 32; // 'G'
```

---

`int`だけが整数型ではありません。修飾子はサイズと範囲を変えます:
- `short`はメモリ使用量が少なく、範囲も狭いです（通常-32768から32767）
- `long`はより広い範囲を持ちます（64ビットシステムでは約±900京）
- `unsigned`は符号を取り除きます: `unsigned int`は`0`から約40億までですが、負の値には決してなりません

`long`でなければならないリテラルには`L`サフィックスを、`unsigned`には`U`サフィックスを付け、各型には専用の指定子があります:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" と出力される
```
`%ld`は`long`を、`%u`は`unsigned int`を、`%lu`は`unsigned long`を出力します。ほとんどのシステムでは通常の`int`は約20億までの値しか保持できないので、`5000000000`はそこに収まりません。

---

`sizeof`演算子は型や変数が何**バイト**を占めるかを教えてくれます。その結果は`size_t`型を持ち、`%zu`で出力されます:
```c
printf("%zu\n", sizeof(int));  // ほとんどのシステムで"4"と出力される
```
規格が保証しているのは`sizeof(char)`が`1`であることと`short <= int <= long`であることだけですが、典型的な64ビットシステムでのサイズは次のとおりです: `char`が1、`short`が2、`int`が4、`long`が8、`float`が4、`double`が8です。
`sizeof`は数値をハードコードせずに変数が使うメモリ量を調べるためによく使われます。

---

すべての整数型には限られた範囲があり、ヘッダ`limits.h`はそれらの限界に名前を付けています: `int`用の`INT_MAX`と`INT_MIN`、`long`用の`LONG_MAX`、`unsigned int`用の`UINT_MAX`などです。
```c
#include <limits.h>

printf("%d\n", INT_MAX); // ほとんどのシステムで"2147483647"と出力される
```
符号付き型で`INT_MAX`を超えるのは**未定義動作**です: プログラムが折り返したり、クラッシュしたり、その他何が起きてもおかしくありません。計算する前にチェックしてください:
```c
if (a <= INT_MAX - b) { /* a + b は安全 */ }
```
このチェックが足し算ではなく引き算を使っていることに注意してください。`a + b`自体がすでにオーバーフローする可能性があるからです。

---

符号付き型と違い、**符号なし**の算術は範囲を超えても動作が明確に定義されています: 値はオドメーターのように**折り返し**ます。
`UINT_MAX`に`1`を足すと`0`になり、`0`から`1`を引くと`UINT_MAX`（`unsigned int`が32ビットの場合`4294967295`）になります:
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // "0" と出力される
```
これが、`unsigned`変数を「負になるまで」カウントダウンするループが決して止まらない理由です: 符号なしの値は決して`0`より小さくならないからです。

---

C99以降、ヘッダ`stdbool.h`は定数`true`（`1`）と`false`（`0`）を持つ型`bool`を提供します。
`bool`は値が2つしかない整数型なので、どんな数値を`bool`に変換しても、非ゼロの値はすべて`true`に、`0`は`false`になります。これは`int`への変換とは異なります:
```c
#include <stdbool.h>

bool b = 0.5;  // true、0.5はゼロではないため
int n = 0.5;   // 0、小数部が切り捨てられるため
```
`x != 0`のような比較はすでに`bool`と互換性のある結果を生成し、`bool`を返す関数はそれが「はい/いいえ」の質問に答えるものであることを表します。

---

算術演算は結果を受け取る変数の型ではなく、**そのオペランドの型**で実行されます。
そのため`int`型の`n`に対して`long big = n * n;`と書くと、2つの`int`値を掛け算し、積が大きすぎればオーバーフローし、その後で（すでに誤った）結果を`long`に格納します。
より広い型で計算するには、演算の**前に**片方のオペランドをキャストしてください:
```c
int n = 100000;
long big = (long) n * n; // longとして計算され10000000000になる
```
同じ規則が`(double) total / count`が機能する理由を説明します: キャストがオペランドの型を変え、それに続いて除算が行われるからです。

---

総まとめ: 値の種類に応じて型を選び、すべての`printf`指定子をその引数の型に合わせ、計算がオペランドとは異なる型で行われる必要があるときはキャストしてください。
