# --description--

2つの`int`変数から浮動小数点除算を得る標準的な方法はキャストです: 割り算の前に**片方のオペランド**を`double`にキャストします。
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
`(double) (total / count)`のように結果全体をキャストするのはよくある間違いです: その時点ですでに整数除算が行われており、小数部は失われています。

# --instructions--

`avg`が`total`を`count`で割った結果を小数部を保ったまま保持するようコードを完成させ、それを小数点以下1桁で出力してください
