# --description--

大文字と小文字はASCII表で`32`離れています: `'A'`は`65`、`'a'`は`97`です。
したがって小文字から`32`を引くとその大文字版になり、結果は`char`に戻して格納できます:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

文字`'a'`を`letter`に格納し、その大文字版を`upper`に計算し、それぞれを文字とそのコードとして出力する（`letter`を先に）ように行を並べ替えてください

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
