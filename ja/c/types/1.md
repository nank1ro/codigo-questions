# --description--

Cは**静的型付け**言語です: すべての変数は型を宣言して定義され、その型が格納できる値の種類と使用するメモリ量を決めます。
最もよく使う3つの型は次のとおりです:
- `int` : `30`や`-4`のような整数
- `double` : `1.75`のような小数部を持つ数
- `char` : `'A'`のようにシングルクォートで囲んだ1文字

それぞれの型には専用の`printf`**書式指定子**があります: `%d`は`int`を、`%f`は`double`を（デフォルトで小数点以下6桁）、`%c`は`char`を出力します:
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// "30 1.750000 A" と出力される
```
型に合わない指定子を使うと出力が壊れるので、必ず一致させてください。
