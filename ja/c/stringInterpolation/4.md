# --description--

`%x`は整数を小文字の16進数で出力し、`%X`は同じことを大文字で行います。`%c`は整数の文字コードを受け取り、それが表す文字を出力するので、`65`に対する`%c`は`A`を出力します:
```c
printf("%x %X %c\n", 31, 31, 66); // "1f 1F B" を出力する
```

# --instructions--

次のコードの出力は何ですか？
```c
printf("%x %X %c\n", 255, 255, 65);
```

# --answers--

- ff FF A
- 255 255 65
- ff ff A
- FF FF 65
