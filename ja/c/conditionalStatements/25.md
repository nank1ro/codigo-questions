# --description--

`online`が代わりに`false`を保持している場合、条件は偽になるので、ブロックは完全にスキップされ、その波括弧の中では何も出力されません。

# --instructions--

このコードは出力に何を表示しますか？
```c
bool online = false;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- 何も表示されない、コードはスキップされる
