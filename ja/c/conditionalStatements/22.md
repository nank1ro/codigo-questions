# --description--

`if`文の波括弧の間にあるコードだけが条件付きです。閉じ波括弧の後に書かれたものは、条件が何であっても無条件に実行されます。

# --instructions--

`Hello World`が常に出力されることがなぜ分かりますか？
```c
bool online = false;
if (online) {
    printf("User is online\n");
}
printf("Hello World\n");
```

# --answers--

- 条件文の中にないから
- if文は1行以上持てないから
- else文がないから
- else if文がないから
