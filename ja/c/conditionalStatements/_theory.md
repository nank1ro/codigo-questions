特定の条件が満たされた場合にのみコードを実行したいとき、意思決定が必要になります。
天気が良いときだけ外で遊びたいとしましょう。
プログラミングでは、ブール変数`nice_weather`を保存し、この変数が`true`の場合に外で遊ぶというアクションを`if`で実行できます：
```c
bool nice_weather = true;
if (nice_weather) {
    // 外で遊ぶ
}
```

---

前の例の続きを見てみましょう。
```c
bool nice_weather = true;
if (nice_weather) {
    // 外で遊ぶ
}
```
`if`文は条件が`true`の場合にのみコードブロックを実行することを見てきました。
もう一つ重要なことは、コードブロックを示す**波括弧**`{}`です。

---

条件が成立した場合にコードブロックを実行する方法を見てきました。次に、最初の条件が成立しなかった場合に別のコードブロックを実行する方法を見てみましょう。
天気が良ければ外で遊び、そうでなければ家にいます。
C言語では`else`文を使うことができます：
```c
bool nice_weather = false;
if (nice_weather) {
    // 外で遊ぶ
} else {
    // 家にいる
}
```

---

もう一つチェックする条件があるとしましょう。この例のように：
```c
int num = 3;
if (num == 2) {
    printf("the number is 2\n");
} else if (num == 3) {
    printf("the number is 3\n");
} else {
    printf("do something else\n");
}
```
このコードの出力は`the number is 3`です。
まず、数値が2に等しいかチェックします。これはfalseです。
次の文に進み、`num`が3に等しいかチェックします。trueなので、次のコードブロックを実行し、`the number is 3`と出力します。

---

`else if`文はいくつでも追加でき、制限はありません
```c
int num = 4;
if (num == 2) {
    printf("the number is 2");
} else if (num == 3) {
    printf("the number is 3");
} else if (num == 4) {
    printf("the number is 4");
} else if (num == 5) {
    printf("the number is 5");
} else if (num == 6) {
    printf("the number is 6");
}
```
このコードの出力は`the number is 4`です。

---

条件文（`if`、`else if`、`else`）を別の条件文の中にネストして、より複雑な構造を作ることもできます。
```c
int num = 4;
if (num < 3) {
    printf("the number is lower than 3\n");
} else {
    if (num == 3) {
        printf("the number is 3\n");
  } else if (num == 4) {
        printf("the number is 4\n");
  } else {
        printf("the number is greather than 4\n");
  }
}
```
このコードの出力は`the number is 4`です。

---

`if` 文の構文を実際に使ってみましょう。キーワード、括弧内の条件、そして波括弧で囲まれたコードブロックです。
```c
if (condition) {
    // 条件が true のときに実行される
}
```

---

Cのブールリテラルは`true`と`false`です。小文字で、クォートなしで書き、言語に組み込まれているのではなく`<stdbool.h>`で定義されています。`True`と書いても条件としてコンパイルできません — 小文字の形式だけが有効で、`true`のときにブロックが実行されます。

---

Cには別個の真偽値判定はありません。条件はその値が0以外であれば真になります。`<stdbool.h>`の`false`は単に`0`なので、それによって守られたブロックは決して実行されません。

---

Cの`if`文は3つの部分から成ります。`if`キーワード、括弧内の条件、そして波括弧内のブロックです。括弧は必須です — コンパイラが条件の終わりを認識する手段だからです。

---

すべての条件文は、次に何を実行するかを決める前に条件をチェックする必要があることをコンパイラに伝えるキーワードから始まります。

---

リテラルの`true`条件は常に真なので、ブロックは実行され、その中の`printf`は書かれた通りに実行されます。

---

リテラルの`false`条件は決して真にならないので、ブロックは完全にスキップされ、その中の何も実行されません。

---

条件とは`if`文がチェックする値のことです。条件が`true`のときブロックが実行され、`false`のときはスキップされます。

---

開き波括弧は条件と同じ行に置いても、次の行に置いても構いません。Cは改行を無視するので、どちらのスタイルでもまったく同じプログラムにコンパイルされます。

---

条件を囲む括弧はCの`if`構文の一部であり、任意のグループ化ではありません。`if true { ... }`はコンパイルできません。

---

クォートされた`"false"`はブール値ではなく文字列です — そして条件内の文字列はnullでないアドレスなので、真として扱われます。ブロックの実行を防げるのは、クォートなしの`false`だけです。

---

Cでは`if`行の各要素の間のスペースは自由です。`if(true){`と`if (true) {`はコンパイラにとって同じ文であり、重要なのは要素の順序だけです。

---

コードブロックは1つの文に限定されません。波括弧の間にあるすべての文は、書かれた順に次々と実行されます。

---

ブール変数はそのまま条件として使うことができ、比較は必要ありません。`online`はすでに`true`を保持しているので、`if (online)`と書くだけでブロックを実行するのに十分です。

---

`bool`変数が条件として機能するのは、`if`がその時点で変数に格納されている値だけを見るからです。`online`に`false`が入っている場合、`if (online)`は`if (false)`とまったく同じように振る舞います。

---

`if`文の波括弧の間にあるコードだけが条件付きです。閉じ波括弧の後に書かれたものは、条件が何であっても無条件に実行されます。

---

コードブロックに入れられる文の数に決まった上限はありません — 1行でも100行でも、条件が`true`のときはすべて一緒に実行されます。

---

ブール変数を条件として読み取ることは、リテラルの場合とまったく同じように機能します。`online`が`true`を保持しているので、ブロックが実行され、その中の`printf`が実行されます。

---

`online`が代わりに`false`を保持している場合、条件は偽になるので、ブロックは完全にスキップされ、その波括弧の中では何も出力されません。
