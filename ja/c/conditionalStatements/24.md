# --description--

ブール変数を条件として読み取ることは、リテラルの場合とまったく同じように機能します。`online`が`true`を保持しているので、ブロックが実行され、その中の`printf`が実行されます。

# --instructions--

このコードは出力に何を表示しますか？
```c
bool online = true;
if (online) {
    printf("Hello user!\n");
}
```
