# --description--

毎回`struct Point`と書くのは冗長です。`typedef`を使うと構造体に短い型名を付けられ、構造体自体は匿名のままでいられます:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
新しい名前`Temperature`は、前に`struct`キーワードを付けずに単独で使います。実際のプログラムで構造体を宣言する最も一般的な方法です。

# --instructions--

メンバ`celsius`を持つ匿名の構造体を型名`Temperature`で定義し、その型で`t`を宣言するようにコードを完成させてください
