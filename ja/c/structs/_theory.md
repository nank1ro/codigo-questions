**構造体**（struct）は、異なる型の関連する値を1つの新しい型にまとめたものです。その中の各値は**メンバ**と呼ばれます。
宣言では波括弧の中にメンバを列挙し、セミコロンで終わります。これにより`struct Point`という型が作られますが、変数はまだ作られません:
```c
struct Point {
    int x;
    int y;
};
```
その型の変数は`struct Point`で宣言し、そのメンバは配列のように波括弧で**順番に**初期化できます:
```c
struct Point p = {3, 4}; // x is 3, y is 4
```
メンバの読み書きには**ドット**演算子`.`を使います:
```c
printf("%d\n", p.x); // prints "3"
p.y = 10;
```

---

メンバを順番に初期化する方法は壊れやすいものです: 構造体にメンバが1つ増えると、すべての初期化子がずれてしまいます。C99からは**指定初期化子**でドットを使って各メンバに名前を付け、任意の順序で初期化できます:
```c
struct Point p = {.y = 4, .x = 3};
```
リストにないメンバは`0`に設定されるため、`{.y = 5}`では`x`は`0`になります。これは初期化子なしで宣言された変数`struct Point q;`とは異なります。その場合、代入するまでメンバには**不定値**が入ります:
```c
struct Point q;
q.x = 1;
q.y = 2;
```

---

構造体は、他の値と同じように関数に渡せます。パラメータは完全な型名で宣言し、関数内では`.`でメンバを読みます:
```c
struct Point { int x; int y; };

int sum(struct Point p) {
    return p.x + p.y;
}
```
構造体は、それを使う関数より**前に**宣言しなければなりません。そうすることで、コンパイラはすでにそのメンバを知っています。

---

毎回`struct Point`と書くのは冗長です。`typedef`を使うと構造体に短い型名を付けられ、構造体自体は匿名のままでいられます:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
新しい名前`Temperature`は、前に`struct`キーワードを付けずに単独で使います。実際のプログラムで構造体を宣言する最も一般的な方法です。

---

メンバ自体が構造体である場合もあります。例えば、線分は2つの点からできています:
```c
typedef struct { int x; int y; } Point;

typedef struct {
    Point start;
    Point end;
} Segment;
```
内側の構造体はそれ自身の波括弧のペアで初期化し、そのメンバにはドット演算子を連ねてアクセスします:
```c
Segment s = {{1, 2}, {5, 2}};
printf("%d\n", s.end.x); // prints "5"
```

---

構造体は、他の型と同じように配列に格納できます。各要素はそれぞれの波括弧で初期化し、ループで1つずつ訪れます。まずインデックスでアクセスし、その後にドットを使います:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

---

構造体の配列は、数値の配列とまったく同じように関数に渡せます。パラメータは`Item items[]`と書き、配列は自分の長さを持たないため、サイズは別に渡します:
```c
int count_free(Item items[], int size) {
    int count = 0;
    for (int i = 0; i < size; i++) {
        if (items[i].price == 0) {
            count++;
        }
    }
    return count;
}
```

---

構造体が**値渡し**で関数に渡されると、関数はその**コピー**を受け取ります。パラメータのメンバを変更してもコピーだけが変わり、呼び出し元の変数は元のままです:
```c
void reset(Point p) {
    p.x = 0; // changes the copy
}
```
関数に呼び出し元の構造体を変更させるには、`&`でその**アドレス**を渡し、パラメータを**ポインタ**`Point *p`として宣言します。ポインタはコピーではなく元の変数を参照します:
```c
void reset(Point *p) { ... }

reset(&origin);
```
大きな構造体ではコピーに時間もかかるため、何も変更しない場合でもポインタが通常の選択です。

---

ポインタ経由では、ドットの代わりに**アロー**演算子`->`でメンバにアクセスします:
```c
void grow(Box *b) {
    b->size = b->size * 2;
}
```
`b->size`は`(*b).size`の短縮形です: まずポインタをたどり、それからメンバを取り出します。ドットは構造体にのみ、アローは構造体へのポインタにのみ使えます。
呼び出し元は`&`で自分の変数のアドレスを渡します。ポインタ経由で行われた変更は、呼び出しの後から見えます。

---

構造体へのポインタを受け取る関数は、元の値をその場で更新できます。これがCで値を変更する関数を書く標準的な方法で、最初のパラメータが変更する構造体、残りのパラメータが適用するデータになります:
```c
void set_number(Player *p, int new_number) {
    p->number = new_number;
}
```
読み書きはどちらも同じアローを使います: `p->score += 10`は、ポインタが参照する構造体のメンバに加算します。

---

関数は構造体を**返す**こともできます。ローカル変数で作って返すと、呼び出し元は値全体のコピーを受け取ります:
```c
Point make_point(int x, int y) {
    Point p = {x, y};
    return p;
}

Point origin = make_point(0, 0);
```
これがCで関数から複数の値を返す方法です: 構造体にまとめます。

---

`sizeof`は構造体にも使えます。構造体が占めるメモリ量を知る正しい方法です:
```c
printf("%zu\n", sizeof(Point));
```
サイズはメンバのサイズの合計**以上**です。それより大きくなることもあります。コンパイラは各メンバがその型に適したアドレスに配置されるよう、未使用の**パディング**バイトを挿入することがあり、`struct { char c; int n; }`は通常`5`バイトではなく`8`バイトになります。構造体のサイズをハードコードせず、必ず`sizeof`に聞いてください。

---

構造体は`==`で比較できません: 2つの構造体に`a == b`と書くと**コンパイルエラー**になります。代わりに**メンバごと**に比較し、その結果を`&&`で組み合わせます:
```c
bool same_size(Rectangle a, Rectangle b) {
    return a.width == b.width && a.height == b.height;
}
```
`<`と`>`についても同様です: どのメンバが順序を決めるかは自分で決めます。

---

構造体はテキストを保持することがよくあります。テキストは固定サイズの`char`配列メンバとして格納します:
```c
typedef struct {
    char name[20];
    int age;
} Person;
```
配列メンバは、宣言後に`=`で代入できません: `p.name = "Ann"`はコンパイルできません。`string.h`の`strcpy`を使い、コピー先としてメンバを渡してテキストをコピーします:
```c
Person p;
strcpy(p.name, "Ann");
p.age = 30;
```
宣言時の波括弧初期化子だけが文字列を直接受け付けます: `Person p = {"Ann", 30};`

---

`printf`には構造体全体のための指定子はありません。一般的な解決策は、メンバを固定のフォーマットで出力する小さな関数を書くことです。そうすればプログラムのどの部分でも同じ方法で値を表示できます:
```c
void print_person(Person p) {
    printf("%s (%d)\n", p.name, p.age);
}
```

---

まとめると: 構造体へのポインタを受け取る関数は、アロー経由で`strcpy`を使ってテキストメンバを更新できます。`item->name`は元の構造体の中にある`char`配列だからです:
```c
void set_title(Book *book, char *title) {
    strcpy(book->title, title);
}
```
`strcpy`を使うには、コードの上部に`#include <string.h>`を追加することを忘れないでください。
