# --description--

ポインタ経由では、ドットの代わりに**アロー**演算子`->`でメンバにアクセスします:
```c
void grow(Box *b) {
    b->size = b->size * 2;
}
```
`b->size`は`(*b).size`の短縮形です: まずポインタをたどり、それからメンバを取り出します。ドットは構造体にのみ、アローは構造体へのポインタにのみ使えます。
呼び出し元は`&`で自分の変数のアドレスを渡します。ポインタ経由で行われた変更は、呼び出しの後から見えます。

# --instructions--

ポインタ経由で`size`を2倍にするように`grow`を完成させ、`box`のアドレスを渡すように呼び出しを完成させてください

# --seed--

```c
#include <stdio.h>

typedef struct { int size; } Box;

void grow(Box *b) {
    b[/]size = b->size * 2;
}

int main() {
    Box box = {5};
    grow([/]box);
    printf("%d\n", box.size);
    return 0;
}
```
