# --instructions--

Definisci un pattern compilato `PAIR_RE` che corrisponde a un'impostazione scritta come una o più lettere, un segno `=` e una o più cifre, con le due parti nei gruppi con nome `key` e `value`; poi scrivi una funzione `parse_settings(text)` che restituisce un dizionario che mappa ogni chiave trovata nel testo al suo valore come `int`

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
