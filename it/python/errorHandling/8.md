# --description--

`except:` senza alcun tipo dopo è un **except nudo**. Corrisponde a tutto, comprese eccezioni che non hanno nulla a che fare con l'operazione che stavi proteggendo, quindi la regola è semplice: nomina sempre i tipi dai quali puoi davvero riprenderti.

# --instructions--

Perché questo codice dovrebbe nominare un tipo di eccezione specifico invece di usare un `except:` nudo?
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- Perché l'`except:` nudo cattura anche fallimenti non correlati, come il `NameError` causato da `amout` scritto male, così un vero bug diventa silenziosamente `total = 0`
- Perché un `except:` nudo è più lento, dato che Python deve confrontare l'eccezione con ogni classe integrata
- Perché un `except:` nudo funziona solo a livello di modulo e solleva un `SyntaxError` dentro una funzione
- Perché un `except:` nudo non cattura nulla, quindi l'eccezione viene risollevata non appena il blocco termina
