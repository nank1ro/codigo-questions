# --description--

`find(sub)` restituisce l'**indice** della prima occorrenza di `sub`, o `-1` se non viene trovata:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` restituisce **quante volte** `sub` compare:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

Salva in `position` l'indice della prima `o` in `text`, in `missing` il risultato della ricerca di `z`, e in `total` quante `o` contiene il testo
