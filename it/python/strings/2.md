# --description--

La funzione integrata `len()` restituisce la **lunghezza** di una stringa, cioè quanti caratteri contiene.
Anche spazi e punteggiatura contano come caratteri:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
