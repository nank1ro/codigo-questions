# --description--

Solo il `print` indentato subito dopo l'`if` appartiene al suo blocco; una riga scritta con la stessa indentazione dell'`if` stesso non ne fa parte.

# --instructions--

Quale dichiarazione di stampa fa parte del blocco di codice dell'istruzione?
```python
online = False
if (online):
    print("Ciao Utente!")
print("Ciao Mondo")
```

# --answers--

- print("Ciao Utente!")
- print(Ciao Utente!)
- print("Ciao Mondo")
