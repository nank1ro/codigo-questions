# --description--

Poiché il corpo deve essere una singola espressione, una lambda **non può contenere istruzioni**.
Né `return`, né blocchi `if`, né cicli, né assegnazioni:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Se ti serve qualcosa di tutto ciò, scrivi invece una normale funzione `def`.

# --instructions--

Qual è il __problema__ con questo frammento di codice?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- Il corpo di una lambda è un'espressione, non può contenere return
- Una lambda non può essere salvata in una variabile
- Una lambda non può essere chiamata con le parentesi
- Una lambda necessita di almeno due parametri
