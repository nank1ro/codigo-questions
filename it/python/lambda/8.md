# --description--

La lambda `key` può scegliere qualsiasi parte di un elemento.
Per una lista di liste, `lambda p: p[1]` ordina in base al secondo elemento di ogni lista interna.

# --instructions--

Ordina gli elementi per stampare le persone dalla più giovane alla più anziana

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
