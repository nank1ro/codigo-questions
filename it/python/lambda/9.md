# --description--

`map()` applica una funzione a **ogni elemento** di una lista.
Restituisce un particolare _oggetto map_, quindi racchiudilo in `list()` per vedere i valori:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
