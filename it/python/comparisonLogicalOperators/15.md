# --instructions--

Ordina gli elementi per definire il dizionario `users` e la funzione `can_login`, che usa `name in users` per proteggere la ricerca, poi stampa il risultato per Ada con la password corretta e per Grace, che non è registrata, producendo l'output `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
