# --instructions--

Scrivi una funzione `is_vowel(ch)` che restituisce `True` quando `ch` è esattamente un carattere e quel carattere è una vocale (`a`, `e`, `i`, `o`, `u`) minuscola o maiuscola, e `False` per qualsiasi altra stringa, inclusa la stringa vuota

`is_vowel("a")` e `is_vowel("E")` devono restituire `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")

```

`is_vowel("b")` e `is_vowel("y")` devono restituire `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Le stringhe che non sono un singolo carattere devono restituire `False`

```python
    def test_3(self):

        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
