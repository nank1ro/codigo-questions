# --instructions--

Cosa stampa questo codice?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, perché `c` è un altro nome per la stessa lista di `a`, quindi aggiungere tramite `c` modifica `a` e lo rende diverso da `b`
- `True True [1, 2]`, perché `c = a` copia la lista, quindi `a` resta invariato
- `True False [1, 2, 3]`, perché `is` confronta i valori e `==` confronta l'identità
- `False False [1, 2, 3]`, perché `append` crea una nuova lista, quindi `c` non si riferisce più ad `a`
