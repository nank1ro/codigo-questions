# --description--

Quando `not`, `and` e `or` compaiono in una stessa espressione, Python applica prima `not`, poi `and`, poi `or`. Quindi `a or b and c` significa `a or (b and c)`, e `not a == b` significa `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Quando si intende un raggruppamento diverso, aggiungi le parentesi; rendono anche l'espressione più leggibile.

# --instructions--

Cosa stampa questo codice?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, perché `and` viene applicato prima di `or`, quindi l'espressione si legge `x == 3 or (x > 10 and x < 0)`
- `False`, perché gli operatori vengono applicati da sinistra a destra: `(x == 3 or x > 10) and x < 0`
- `False`, perché `x < 0` è falso e ogni condizione dell'espressione deve essere soddisfatta
- Un `SyntaxError`, perché `and` e `or` non possono essere mescolati senza parentesi
