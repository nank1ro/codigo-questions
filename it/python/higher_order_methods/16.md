# --instructions--

Scrivi un decoratore `memoize` per funzioni di un solo argomento: deve memorizzare ogni risultato in un dizionario all'interno della closure, in modo che chiamare di nuovo la funzione decorata con lo stesso argomento restituisca il risultato salvato senza chiamare la funzione originale

# --asserts--

La funzione decorata deve restituire gli stessi risultati dell'originale

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

Ripetere una chiamata non deve eseguire di nuovo la funzione originale

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

Ogni funzione decorata deve avere la propria cache

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
