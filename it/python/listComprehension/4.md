# --description--

La condizione di filtro può essere qualsiasi espressione che restituisca un booleano, incluse chiamate a funzione come `len()`:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
