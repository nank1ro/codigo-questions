# --description--

All'interno di una comprehension puoi usare qualsiasi variabile definita prima, per esempio come limite di un `range()`.

# --instructions--

Ordina gli elementi per stampare i multipli di 7 al di sotto di `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
```
