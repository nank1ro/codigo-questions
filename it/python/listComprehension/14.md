# --description--

La stessa idea funziona per i dizionari: una **dict comprehension** usa le parentesi graffe e un'espressione `key: value`:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
