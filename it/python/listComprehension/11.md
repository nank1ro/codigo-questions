# --description--

Una comprehension può avere **più di un `for`**.
Funzionano come cicli annidati: il primo `for` è il ciclo esterno, il secondo è quello interno.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
