# --instructions--

Scrivi una funzione `get_path` che prenda un dizionario `data`, una lista di `keys` e un `default` opzionale (`None` se non fornito); deve seguire le chiavi un livello alla volta e restituire il valore trovato, oppure `default` quando una chiave manca, vale `None` o quando un passo non è un dizionario; valori come `0` e `""` devono essere restituiti così come sono

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` deve restituire `"Rome"`

```python
    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")
```

```python
    def test_2(self):
```

```python
        self.assertEqual(get_path(data, ["stats", "note"], "none"), "", "--err-t3--")
```

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
