# --description--

Le conversioni che possono fallire si abbinano naturalmente a `guard let`: converti, esci se il risultato è `nil`, poi lavora con il valore semplice.

# --instructions--

Completa la funzione in modo che converta il testo in un `Int` e restituisca il suo doppio, oppure `nil` quando la conversione fallisce.
Poi stampa i risultati, usando `0` come valore di riserva

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
