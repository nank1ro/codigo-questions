# --instructions--

Perché questo codice non compila?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` è una costante `let`, quindi un metodo mutating non può essere richiamato su di essa
- `increase` deve essere contrassegnato `static` per modificare `value`
- `value` deve essere dichiarato con `let`
- Una struct non può contenere metodi
