# --description--

Poiché una struct è un valore, a un metodo non è consentito modificare le sue proprietà a meno che tu non lo dichiari con la parola chiave `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Un metodo mutating può essere richiamato solo su un'istanza memorizzata in una `var`. Su un'istanza `let` il valore è congelato, quindi `c.increase(by: 5)` non compirebbe.

# --instructions--

Aggiungi a `Counter` un metodo mutating `increase` che prende un `Int` con l'etichetta di argomento `by` e lo somma a `value`

Esempio di utilizzo:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

Il metodo deve essere contrassegnato `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Incrementare `0` di `5` deve dare `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Incrementando `10` due volte i valori devono sommarsi

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Incrementare di `0` non deve cambiare nulla

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Modificare una copia non deve cambiare l'originale

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
