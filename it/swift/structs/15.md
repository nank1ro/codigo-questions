# --description--

Una struct è un tipo come gli altri, quindi può essere memorizzata in un array, un dizionario o un set, e ogni strumento che già conosci continua a funzionare su di essa:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
Ricorda che l'array contiene *copie*: leggere `items[0]` in una variabile e modificarla non tocca l'array.

# --asserts--

Due elementi da `3` e `7` devono totalizzare `10`

```swift
tryCatch(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]) == 10)
```

Un singolo elemento deve totalizzare il suo stesso prezzo

```swift
tryCatch(totalPrice([Item(name: "Pen", price: 2)]) == 2)
```

Un array vuoto deve totalizzare `0`

```swift
tryCatch(totalPrice([]) == 0)
```
