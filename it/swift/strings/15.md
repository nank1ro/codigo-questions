# --description--

Dividere su uno spazio è il modo più semplice per scomporre una frase in parole, e unire è il modo per ricostruire il testo a partire da un array.

# --instructions--

Scrivi una funzione `wordCount` che accetta una `String` (ometti la label dell'argomento) e restituisce quante parole separate da spazi contiene, e una funzione `slug` che accetta un array di `String` (ometti la label dell'argomento) e restituisce le parole unite da `-`

Esempio di chiamata alla funzione:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
