# --description--

Poiché una stringa è una collezione di caratteri, puoi iterarla con un ciclo `for`-`in`. Ogni iterazione ti dà un `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
Un `Character` può essere confrontato con `==` a un literal di carattere, quindi contare quante volte un carattere appare è solo un ciclo con un contatore.

# --instructions--

Scrivi una funzione `occurrences` che accetta un `Character` con label dell'argomento `of` e una `String` con label dell'argomento `in`, e restituisce quante volte il carattere appare nella stringa.

Esempio di chiamata alla funzione:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
