# --description--

Le closure possono essere memorizzate in array come qualsiasi altro valore. Il tipo di elemento è il tipo di funzione:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Scorrere un array del genere e richiamare ogni closure in sequenza costruisce una piccola **pipeline** di trasformazioni.

# --instructions--

Scrivi una funzione `pipeline` che accetta un `Int` e un array di closure di tipo `(Int) -> Int` (ometti entrambe le label degli argomenti) e restituisce il risultato dell'applicazione di ogni closure in ordine, ciascuna al risultato della precedente

Esempio di chiamata alla funzione:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
