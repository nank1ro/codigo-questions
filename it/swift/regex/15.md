# --description--

Un literal `#/ ... /#` è fisso quando compili. Quando il pattern diventa noto solo a run time, per esempio perché lo ha digitato un utente, costruiscilo con `Regex(_:)`:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
Questo inizializzatore **lancia errori**: un pattern non valido come `"["` viene scoperto solo mentre il programma gira, quindi la chiamata richiede `try`, e l'errore deve essere gestito con `do`/`catch` (o `try?`) o propagato marcando `throws` la funzione circostante, come fa questo esercizio. Una regex costruita in questo modo non ha proprietà numerate note a compile time, ma `contains`, `matches(of:)` e `replacing` funzionano esattamente come prima.

# --instructions--

Scrivi una funzione `countMatches` che accetta un testo (`String`) e un pattern (`String`), entrambi senza label degli argomenti, è marcata `throws` e restituisce quante volte il pattern si trova nel testo. Un pattern non valido deve lasciare uscire l'errore

Esempio di chiamata alla funzione:
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// stampa 2
```

La funzione deve costruire la regex con `try Regex(`

```json

  "modifiers": ["m"],
  "shouldMatch": true
```

`countMatches("a1 b22", "[0-9]+")` deve restituire `2`

```swift
tryCatch((try? countMatches("a1 b22", "[0-9]+")) == 2)
```

`countMatches("abc", "[0-9]+")` deve restituire `0`

```swift
tryCatch((try? countMatches("abc", "[0-9]+")) == 0)
```

`countMatches("hello world", "o")` deve restituire `2`

```swift
tryCatch((try? countMatches("hello world", "o")) == 2)
```

`countMatches("abc", "[")` deve lanciare un errore

```swift
tryCatch((try? countMatches("abc", "[")) == nil)
```

# --solutions--

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
