# --description--

I flag di larghezza funzionano solo dentro `String(format:)`. Per riempire da solo una stringa normale, costruisci gli spazi con `String(repeating:count:)` e uniscili al testo:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
Se il testo è già più lungo della larghezza, `4 - text.count` diventa negativo e `String(repeating:count:)` va in crash. Proteggilo con `max(0, ...)`, così il conteggio non scende mai sotto zero e un testo lungo viene lasciato com'è.

# --instructions--

Scrivi una funzione `leftPad` che prende un testo (`String`) e una larghezza (`Int`), entrambi senza etichette degli argomenti, e restituisce il testo allineato a destra in quella larghezza aggiungendo spazi a sinistra. Un testo più lungo della larghezza deve essere restituito invariato

Esempio di chiamata di funzione:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

# --solutions--

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
