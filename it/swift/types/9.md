# --description--

`Int(text)` riesce solo quando tutto il testo è un numero intero valido, con un segno opzionale:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Per il testo decimale usa `Double(text)`, che restituisce un `Double?` nello stesso modo: `Double("3.5")` è `Optional(3.5)`.

# --instructions--

Scrivi una funzione `sumOfNumbers` che accetta un array di `String` (ometti la label dell'argomento) e restituisce la somma di quelle che sono numeri interi validi, ignorando le altre

Esempio di chiamata della funzione:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
