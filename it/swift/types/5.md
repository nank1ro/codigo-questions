# --description--

`Int(x)` non arrotonda: **tronca**, semplicemente scartando la parte decimale, quindi `Int(3.99)` è `3` e `Int(-3.99)` è `-3`.
Per arrotondare al numero intero più vicino, chiama prima `rounded()` sul `Double` e poi converti:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
I valori intermedi come `2.5` vengono arrotondati lontano da zero: `2.5` diventa `3.0` e `-2.5` diventa `-3.0`.

# --instructions--

Scrivi una funzione `roundedAverage` che accetta due `Int` (ometti le label degli argomenti) e restituisce la loro media arrotondata al numero intero più vicino, come `Int`

Esempio di chiamata della funzione:
```swift
print(roundedAverage(3, 4))
// prints 4
```

func roundedAverage(_ a: Int, _ b: Int) -> Int {
    let average = Double(a + b) / 2
    return Int(average.rounded())
}
