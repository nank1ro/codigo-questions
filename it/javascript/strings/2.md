# --description--

Ogni carattere di una stringa ha un **indice**, a partire da `0`.
Puoi leggere un singolo carattere con le parentesi quadre o con il metodo `charAt()`:
```javascript
let word = "hello";
console.log(word[0]);
// prints h
console.log(word.charAt(1));
// prints e
```
L'ultimo carattere si trova all'indice `length - 1`:
```javascript
console.log(word[word.length - 1]);
// prints o
```

# --instructions--

Salva il primo carattere di `word` in una variabile `first` e l'ultimo carattere in una variabile `last`
