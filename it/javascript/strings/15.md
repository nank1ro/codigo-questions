# --instructions--

Ordina le righe per stampare una riga di scontrino: `item` riempito con puntini fino a 8 caratteri, seguito dal prezzo allineato a destra su 6 caratteri

# --answers--

```javascript
let item = "Tea";
```

```javascript
let row = item.padEnd(8, ".");
```

```javascript
row = row + "2.50".padStart(6);
```

```javascript
console.log(row);
```
