# --description--

Le funzioni di ordine superiore ti permettono di separare *cosa fare con ogni elemento* da *come scorrere gli elementi*. La parte che scorre viene scritta una volta sola, e la callback decide il resto:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
La callback riceve un elemento alla volta. Può essere una arrow function scritta in linea, come sopra, o qualsiasi funzione salvata in una variabile. È esattamente così che funzionano internamente i metodi degli array che incontrerai a breve.

# --asserts--

`transform([1, 2, 3], (n) => n * 2)` deve restituire `[2, 4, 6]`.

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())` deve restituire `["A", "B"]`.

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)` deve restituire un array vuoto.

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

Il risultato deve essere un nuovo array e l'originale non deve essere modificato.

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

La funzione non deve usare `map`.

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
