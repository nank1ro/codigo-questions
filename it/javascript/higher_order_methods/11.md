# --description--

Una funzione che restituisce una funzione è anche il modo naturale per **adattare** una callback. Supponi di avere un predicato e di averne bisogno dell'opposto per `filter`: invece di riscriverlo, avvolgilo:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
Un `not(predicate)` generico farebbe questo per qualsiasi predicato: restituisce una nuova funzione che chiama `predicate` con lo stesso argomento e inverte il risultato con `!`. I predicati per `filter`, `find`, `some` ed `every` ricevono l'elemento come primo argomento, quindi il wrapper deve inoltrare solo quel valore.

# --asserts--

`not((n) => n % 2 === 0)(3)` deve restituire `true`.

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)` deve restituire `false`.

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))` deve restituire `[1, 3]`.

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))` deve restituire `["a", "b"]`.

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

Negare due volte deve restituire la risposta originale: `not(not(isEven))(4)` deve restituire `true`.

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not` deve restituire una funzione.

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
