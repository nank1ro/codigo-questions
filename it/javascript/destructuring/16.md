# --description--

Tutto quello visto finora appartiene a un'unica sintassi, quindi i pezzi si combinano liberamente: un pattern di oggetto può annidare un altro pattern di oggetto, che può contenere una chiave rinominata con un valore predefinito, accanto a un pattern di array che termina con un elemento rest. Una sola riga descrive allora l'intera forma che una funzione si aspetta:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// stampa Post [js] +2
```
Mantieni la leggibilità: un pattern che non sta più in un paio di righe di solito è il segno che la funzione sta chiedendo troppo.

# --asserts--

Tre elementi devono lasciarne due.

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

Un solo elemento non deve lasciarne nessuno.

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

Un cliente senza nome deve diventare `guest`.

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

Anche un nome esplicitamente `undefined` deve diventare `guest`.

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

Quattro elementi devono lasciarne tre.

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

function report(order) {

  return `#${id} ${name}: ${first} +${rest.length}`;
}
