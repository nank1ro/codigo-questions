# --description--

Quando una chiave contiene un altro oggetto o un array, il pattern può semplicemente proseguire e descrivere anche quella forma:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Attenzione a ciò che quella riga crea: `address: { city }` significa "entra in `address`", non "dammi `address`", quindi solo `city` diventa una variabile. Per ottenere entrambi, cita la chiave due volte: `const { address, address: { city } } = user;`. I pattern di array e di oggetto si annidano liberamente uno dentro l'altro, come in `{ tags: [first] }`.

# --asserts--

Una città annidata deve essere restituita.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Una città annidata diversa deve essere restituita.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Un indirizzo vuoto deve dare `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Le altre chiavi dell'indirizzo devono essere ignorate.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Una città esplicitamente `undefined` deve dare `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
