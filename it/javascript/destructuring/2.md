# --description--

Il destructuring è più utile proprio dove arriva un array: un argomento di una funzione, o il risultato di una chiamata. Invece di tenersi l'array e indicizzarlo dappertutto, lo scomponi una volta sola e dai alle parti dei nomi veri:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// stampa 5
```
Nell'array originale non viene copiato né modificato nulla, il pattern si limita a leggerlo.

# --asserts--

`label(["Ada", 90])` deve restituire `"Ada: 90"`.

```javascript
tryCatch(label(["Ada", 90]) === "Ada: 90");
```

`label(["Bob", 0])` deve restituire `"Bob: 0"`.

```javascript
tryCatch(label(["Bob", 0]) === "Bob: 0");
```

Un punteggio negativo deve restare com'è.

```javascript
tryCatch(label(["Cy", -3]) === "Cy: -3");
```

`label(["Dee", 100])` deve restituire `"Dee: 100"`.

```javascript
tryCatch(label(["Dee", 100]) === "Dee: 100");
```

Gli elementi in più devono essere ignorati.

```javascript
tryCatch(label(["Eve", 55, "extra"]) === "Eve: 55");
```
