# --description--

I pattern degli oggetti si combinano con i valori predefiniti esattamente come quelli degli array, il che li rende un modo ordinato per leggere un oggetto di configurazione le cui chiavi possono esserci o meno:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// prints dark en
```
Siccome l'intero pattern è una sola istruzione, una funzione può estrarre tutto ciò che le serve dal suo argomento nella primissima riga.

# --asserts--

Entrambe le chiavi presenti devono essere usate.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Un utente diverso deve dare una stringa diversa.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

Una `city` mancante deve ripiegare su `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Le chiavi in più devono essere ignorate.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

L'ordine delle chiavi non deve contare.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
