# --description--

La condizione di un'istruzione `if` va sempre dentro le parentesi `()`, poste subito dopo la parola chiave `if` e prima della parentesi graffa di apertura.

# --instructions--

Dove scriviamo l'istruzione `if`?

# --answers--

- Tra le parentesi tonde ()
- Tra le parantesi quadre []
- Tra la parola chiave if e la parentesi graffa aperta {
- Prima della parola chiave if
