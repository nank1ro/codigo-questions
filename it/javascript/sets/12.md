# --instructions--

Ordina le righe per stampare un array con i nomi in `all` che non sono in `done`.
Dichiara `all` prima di `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
