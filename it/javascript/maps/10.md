# --description--

Le map non hanno metodi da array come `sort()` o `filter()`. Per usarli, converti la map (o le sue chiavi o i suoi valori) in un array con `Array.from()` o l'operatore spread `...`:
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
La conversione opposta, `Object.fromEntries(ages)`, trasforma di nuovo una map in un oggetto semplice.

# --asserts--

`sortedKeys` di una map con le chiavi `"pear"`, `"apple"` e `"kiwi"` deve restituire `["apple", "kiwi", "pear"]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

`sortedKeys` di una map vuota deve restituire `[]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
