# --description--

`for...of` e l'operatore spread `...` non funzionano su qualsiasi oggetto: funzionano sugli **iterabili**, oggetti che forniscono un metodo memorizzato sotto la chiave speciale `Symbol.iterator`. Dai alla tua classe quel metodo ed entra nel club:
```javascript
class Playlist {
    constructor(songs) {
        this.songs = songs;
    }
    *[Symbol.iterator]() {
        for (const song of this.songs) {
            yield song;
        }
    }
}
const list = new Playlist(["a", "b"]);
console.log([...list]);
// stampa [ 'a', 'b' ]
```
Il `*` davanti al nome lo rende un **generatore**: una funzione che consegna i valori uno alla volta con `yield` e si mette in pausa tra uno e l'altro. È il modo più breve per soddisfare il protocollo di iterazione, e funziona anche per valori che vengono calcolati anziché memorizzati.

# --asserts--

Lo spread di `new Range(1, 4)` deve dare `[1, 2, 3, 4]`.

```javascript
tryCatch(JSON.stringify([...new Range(1, 4)]) === "[1,2,3,4]");
```

`for...of` deve visitare ogni numero di `new Range(3, 5)`.

```javascript
let _sum = 0;
for (const n of new Range(3, 5)) {
  _sum += n;
}
tryCatch(_sum === 12);
```

Un intervallo di un solo numero deve produrre soltanto quel numero.

```javascript
tryCatch(JSON.stringify([...new Range(7, 7)]) === "[7]");
```

Un intervallo vuoto non deve produrre nulla.

```javascript
tryCatch(JSON.stringify([...new Range(5, 2)]) === "[]");
```

# --solutions--

```javascript
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}
```
