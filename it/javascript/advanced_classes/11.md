# --description--

Il vero valore di un setter è che può rifiutare. Tra l'assegnazione e il valore memorizzato hai la possibilità di controllare, limitare o respingere ciò che arriva:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// stampa 3, il setter ha rifiutato 50
```
Un getter e un setter con lo stesso nome formano un'unica proprietà, quindi non possono essere anche un campo normale: il valore memorizzato vive sotto un nome diverso, per convenzione lo stesso nome con un underscore iniziale.

# --asserts--

Il getter deve restituire il valore dato al costruttore.

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

Il setter deve accettare un valore valido.

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

Il setter deve ignorare un valore negativo.

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

Il setter deve accettare `0`.

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

Il valore deve essere memorizzato in `_temperature`.

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```

class Thermostat {
  constructor(temperature) {
    this._temperature = temperature;
  }
  get temperature() {

  }

    }
  }
