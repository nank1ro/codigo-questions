# --description--

Anche i metodi possono essere privati. Prefissa il nome con `#` e il metodo sparisce dalla superficie pubblica della classe, pur restando chiamabile da qualsiasi altro metodo con `this.#name(...)`:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// stampa $7
```
È così che tieni fuori dall'API i passaggi di supporto: chi chiama vede `print`, non il dettaglio di formattazione dietro di essa. Campi privati e metodi privati insieme danno a una classe un dentro e un fuori ben chiari.

# --asserts--

Un nuovo punteggio deve partire da `0`.

```javascript
tryCatch(new Score().total === 0);
```

I valori positivi devono essere aggiunti.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

I valori negativi devono essere ignorati.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

Lo zero deve essere ignorato.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

I punti devono essere privati, quindi l'istanza non deve avere alcuna proprietà pubblica.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

Il metodo di supporto deve essere un metodo privato.

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
