# --description--

La posizione del `try` decide quanto lavoro distrugge un singolo valore sbagliato. Avvolgi l'**intero ciclo** e il primo errore abbandona il resto del lotto; avvolgi il **corpo** e si perde solo quell'elemento:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // salta questo
    }
}
println(total) // 8
```
Questo si abbina naturalmente a una funzione di validazione che lancia: la funzione enuncia una regola e rifiuta tutto ciò che la viola, e il ciclo decide che un rifiuto costa solo un elemento.

Scrivi due funzioni.

`validate(text: String): Int` deve restituire il numero contenuto in `text`, oppure lanciare una `IllegalArgumentException` con il messaggio `not a number: ` seguito dal testo.

`sumValid(values: List<String>): Int` deve sommare i valori che `validate` accetta, saltando quelli che la fanno lanciare.

Esempio di chiamata di funzione:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// stampa 4
```

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // salta questo
        }
    }
    return total
}
```
