# --instructions--

Cosa succede con questo codice?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Non compila: una classe nested non può vedere i membri della classe esterna, `Nested` deve essere `inner`
- Compila, e `show()` restituisce il `name` dell'istanza esterna
- Compila, e `show()` restituisce sempre una stringa vuota
- Non compila: Kotlin non permette una classe dentro un'altra classe
