Cosa stampa questo programma?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

- `[a, b] [a, b]`, perché entrambi restituiscono la lista
- `2 [a, b]`, perché `apply` restituisce la dimensione e `run` restituisce la lista
