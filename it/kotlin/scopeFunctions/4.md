# --description--

Dentro un blocco `let` non sei costretto a chiamare l'oggetto `it`: puoi dare un nome al parametro della lambda, cosa che mantiene il codice leggibile quando i blocchi sono annidati o quando `it` non direbbe nulla di utile.
```kotlin
val price: Int? = 12
println(price?.let { amount -> "$amount EUR" }) // 12 EUR
```
La stessa nomenclatura funziona per ogni scope function che usa `it`, quindi per `let` e `also`.

# --instructions--

Scrivi una funzione `shout(word: String?): String` che restituisce `word` in maiuscolo seguito da `!` quando non è `null`, e `silence` quando è `null`. Usa `?.let` e `?:`.

Esempio: `shout("hi")` restituisce `HI!`, `shout(null)` restituisce `silence`.


`shout("Bye")` deve restituire `BYE!`

```kotlin

```

`shout(null)` deve restituire `silence`

```kotlin
    tryCatch(shout(null) == "silence")
```

Una stringa vuota non è `null`, quindi `shout("")` deve restituire `!`

```kotlin
    tryCatch(shout("") == "!")
```
