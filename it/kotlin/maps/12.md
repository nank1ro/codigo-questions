# --solutions--

```kotlin
val fruits = listOf("apple", "pear", "apple")
val counts = mutableMapOf<String, Int>()
for (fruit in fruits) {
    counts[fruit] = counts.getOrDefault(fruit, 0) + 1
}
println(counts)
```

# --output--

{apple=2, pear=1}
