# --description--

Puoi ciclare su una mappa con `for`, destrutturando ogni elemento nella sua chiave e nel suo valore:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Le parentesi `(name, age)` dividono ogni elemento in due variabili. Gli elementi vengono visitati nell'ordine di inserimento.

Esempio di chiamata alla funzione:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
