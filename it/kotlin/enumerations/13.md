# --instructions--

Dato `enum class Color { RED, GREEN, BLUE }`, cosa fa `Color.valueOf("PURPLE")`?

# --answers--

- Lancia una `IllegalArgumentException`, perché nessuna voce si chiama `PURPLE`
- Restituisce `null`
- Restituisce `Color.RED`, la prima voce
- Aggiunge una nuova voce `PURPLE` all'enum
