# --instructions--

Dato `enum class Size { SMALL, MEDIUM, LARGE }`, cosa succede con il codice seguente?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Non compila: un'espressione `when` su un enum deve coprire ogni voce oppure aggiungere un ramo `else`
- Compila e restituisce `null` per `LARGE`
- Compila e lancia un'eccezione a runtime per `LARGE`
- Compila e restituisce automaticamente `"L"` per `LARGE`
