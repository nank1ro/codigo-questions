# --description--

Le lettere maiuscole e minuscole distano `32` posizioni nella tabella ASCII: `'A'` è `65` e `'a'` è `97`.
Sottraendo `32` da una lettera minuscola si ottiene quindi la sua versione maiuscola, e il risultato può essere memorizzato di nuovo in un `char`:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Ordina le righe per memorizzare la lettera `'a'` in `letter`, calcolare la sua versione maiuscola in `upper`, e stampare ciascuna come carattere seguito dal suo codice (prima `letter`)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
