# --description--

Non concatenare i confronti come in matematica. `1 <= x <= 10` compila, ma viene valutato come `(1 <= x) <= 10`: il primo confronto dà `0` o `1`, e quello viene poi confrontato con `10`, quindi l'intera espressione vale sempre `1`.
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
Scrivi sempre entrambi i confronti esplicitamente e uniscili con `&&`.

# --instructions--

Ordina le righe per costruire un programma che memorizza il confronto concatenato in `chained`, il controllo di intervallo corretto in `correct` e stampa entrambi. Definisci `chained` prima di `correct`

```c
#include <stdio.h>

int main() {
```
```c
    int x = 20;
```
```c
    int chained = 1 <= x <= 10;
```
```c
    int correct = 1 <= x && x <= 10;
```
```c
    printf("%d %d\n", chained, correct);
```
```c
    return 0;
}
```
