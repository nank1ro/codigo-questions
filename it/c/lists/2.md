# --description--

I nodi dichiarati come variabili locali scompaiono quando la loro funzione restituisce, quindi le liste si costruiscono nello **heap** con `malloc` di `stdlib.h`. Essa riserva il numero di byte richiesto e ne restituisce l'indirizzo, oppure `NULL` quando la memoria è esaurita; `sizeof(Node)` è la quantità giusta per un nodo:
```c
Node *node = malloc(sizeof(Node));
node->value = 5;
node->next = NULL;
```
La memoria dello heap non viene mai rilasciata da sola: ogni nodo ottenuto da `malloc` deve essere restituito con `free(node)` una volta che non serve più. In questi esercizi `stdlib.h` è incluso e `Node` è dichiarato sopra il tuo codice.

# --instructions--

Completa `make_node` in modo che allochi un nodo nello heap, vi memorizzi `value`, imposti `next` a `NULL` e ne restituisca l'indirizzo

# --asserts--

`make_node(5)` deve restituire un nodo il cui `value` è `5`

```c
    Node *n1 = make_node(5);
    try_catch(n1 != NULL && n1->value == 5);
    free(n1);
```

Il `next` di un nuovo nodo deve essere `NULL`

```c
    Node *n2 = make_node(0);
    try_catch(n2 != NULL && n2->next == NULL);
    free(n2);
```

Due chiamate devono restituire due nodi diversi

```c
    Node *n3 = make_node(1);
    Node *n4 = make_node(2);
    try_catch(n3 != NULL && n4 != NULL && n3 != n4 && n3->value == 1 && n4->value == 2);
    free(n3);
    free(n4);
```
