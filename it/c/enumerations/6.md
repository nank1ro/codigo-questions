# --description--

Quando ogni caso di uno `switch` gestisce una costante, ricordati il `break` dopo ciascuno, altrimenti l'esecuzione prosegue nel caso successivo.
Un caso `default` non è necessario se copri tutte le costanti dell'enumerazione.

# --instructions--

Ordina le righe per dichiarare `enum Size`, salvare `MEDIUM` in `size` e stampare `Medium` con uno `switch`. Mantieni i casi nello stesso ordine delle costanti nella dichiarazione

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

```c

```


# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
