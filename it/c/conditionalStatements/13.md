# --description--

Una condizione letterale `false` non è mai vera, quindi il blocco viene saltato completamente e nulla al suo interno viene eseguito.

# --instructions--

Cosa mostra questo codice nell'output?
```c
if (false) {
    printf("Ciao!\n");
}
```
