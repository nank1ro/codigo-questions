# --description--

Una condizione letterale `true` è sempre vera, quindi il blocco viene eseguito e il suo `printf` viene eseguito esattamente come scritto.

# --instructions--

Cosa mostra questo codice nell'output?
```c
if (true) {
    printf("Ciao!\n");
}
```
