# --description--

Solo il codice tra le parentesi graffe di un'istruzione `if` è condizionale. Tutto ciò che è scritto dopo la parentesi graffa di chiusura viene eseguito incondizionatamente, indipendentemente dalla condizione.

# --instructions--

Come facciamo a sapere che `Ciao Mondo` verrà sempre stampato?
```c
bool online = false;
if (online) {
    printf("L'utente è online\n");
}
printf("Ciao Mondo\n");
```

# --answers--

- Perchè non è all'interno dell'istruzione condizionale
- Perchè l'istruzione if non può avere piu' di una riga
- Perchè non c'è un'istruzione else
- Perchè non c'è un'istruzione else if
