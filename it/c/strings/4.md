# --description--

Poiché una stringa è un array, ogni carattere ha un indice a partire da `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Un singolo carattere si stampa con `%c`. I caratteri possono anche essere sostituiti:
```c
word[0] = 'K'; // ora word è "Koding"
```
