# --description--

`strcat(destination, source)` aggiunge `source` alla fine di `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// ora text è "Hello World"
```
Come con `strcpy`, l'array di destinazione deve avere abbastanza spazio per il risultato.
