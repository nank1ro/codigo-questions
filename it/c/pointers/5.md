# --description--

Un puntatore può puntare a qualsiasi tipo: `double *`, `char *`, `bool *` e così via. Il tipo nella dichiarazione dice al compilatore quanti byte leggere quando il puntatore viene dereferenziato e cosa significano:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
Un puntatore deve corrispondere al tipo della variabile a cui punta; `int *p = &price;` viene rifiutato dal compilatore. `NULL` è l'unico valore compatibile con un puntatore di qualsiasi tipo.

# --instructions--

Completa `value_or` in modo che restituisca il valore a cui `p` punta, oppure `fallback` quando `p` è `NULL`

# --asserts--

Puntando a `2.5` il risultato deve essere `2.5`

```c
    double v1 = 2.5;
    try_catch(value_or(&v1, 0.0) == 2.5);
```

Con un puntatore `NULL` il risultato deve essere il fallback `-1.0`

```c
    try_catch(value_or(NULL, -1.0) == -1.0);
```

Puntando a `0.0` il risultato deve essere `0.0`, non il fallback

```c
    double v3 = 0.0;
    try_catch(value_or(&v3, 7.0) == 0.0);
```

double value_or(double *p, double fallback) {
    if (p == NULL) {
        return fallback;
    }
    return *p;
