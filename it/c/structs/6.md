# --description--

Le struct possono essere memorizzate in un array come qualsiasi altro tipo. Ogni elemento si inizializza con le proprie graffe e un ciclo le visita una a una, prima indicizzando e poi usando il punto:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

# --instructions--

Ordina le righe per definire il tipo `Point`, memorizzare tre punti in `path`, sommare i loro membri `x` in `sum` e stamparlo. Dichiara `path` prima di `sum`

```c
typedef struct { int x; int y; } Point;
```
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};
```
```c
int sum = 0;
```
```c
for (int i = 0; i < 3; i++) {
```
```c
    sum += path[i].x;
```
```c
}
```
```c
printf("%d\n", sum);
```
