# --description--

Una funzione anonima può prendere parametri e restituire un valore con `return`, esattamente come una con nome. Il tipo di ritorno non viene scritto: Dart lo **deduce** dalle istruzioni `return` nel corpo.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
