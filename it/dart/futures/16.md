# --description--

Poiché `await` trasforma gli errori di un future in normali eccezioni, al codice asincrono si applicano tutti i soliti schemi `try`/`catch`, inclusi i cicli che ritentano. Dentro un blocco `catch`, **`rethrow`** rilancia lo stesso errore, ed è così che ti arrendi dopo l'ultimo tentativo:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Un parametro di tipo funzione come `Future<String> Function() task` riceve la **funzione** stessa, non un future: ogni chiamata a `task()` avvia un nuovo tentativo.

# --instructions--

Scrivi una funzione `async` `retry` che prende un `Future<int> Function()` `task` e un `int` `attempts`, e restituisce un `Future<int>`. Chiama `task()` e completa con il suo valore; se lancia, riprova, chiamando `task` al massimo `attempts` volte in totale. Se anche l'ultimo tentativo fallisce, rilancia il suo errore con `rethrow`.

Esempio:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` di un task che ha sempre successo dovrebbe completarsi con il suo valore dopo una sola chiamata

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` di un task che fallisce due volte e poi restituisce `7` dovrebbe completarsi con `7` dopo `3` chiamate

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` di un task che fallisce sempre dovrebbe chiamarlo esattamente `attempts` volte e poi fallire con lo stesso errore

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
