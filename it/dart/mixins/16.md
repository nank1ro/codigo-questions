# --description--

I mixin impilati sono il modo in cui piccole regole indipendenti vengono combinate in una sola classe. Ogni mixin fa override dello stesso membro, fa la sua parte e chiama `super` per passare il lavoro avanti. Poiché la chiamata entra prima nell'**ultimo** mixin, l'ordine della lista `with` decide quale regola viene eseguita prima di quale:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` raddoppia ogni deposito. Aggiungi un secondo mixin dopo `Doubled` ed esso riceve il deposito per primo, prima che `Doubled` lo veda.

# --instructions--

La classe `Account` è già scritta: ha un campo `int` `balance` che parte da `0` e un metodo `deposit` che aggiunge il suo argomento `int` a `balance`.

Dichiara un mixin `Audited` su `Account` con un campo `List<String>` `log` che parte vuoto, che fa override di `deposit` così che prima aggiunga a `log` la stringa `'deposit '` seguita dall'importo, poi chiami `super.deposit`.

Dichiara un mixin `Limited` su `Account` che fa override di `deposit` così che un importo maggiore di `100` venga ignorato, e qualsiasi altro importo venga passato a `super.deposit`.

Dichiara una classe `SafeAccount` che estende `Account` e utilizza entrambi i mixin, così che un deposito rifiutato non arrivi mai al log.

Esempio:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
