# --instructions--

Dato `enum Size { small, medium, large }`, cosa succede con il codice seguente?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Non compila: un'espressione `switch` su un enum deve coprire ogni valore
- Compila e restituisce `null` per `Size.large`
- Compila e lancia un'eccezione a runtime per `Size.large`
- Compila e restituisce automaticamente `'L'` per `Size.large`
