# --instructions--

Scrivi una funzione `sumUntilError` che prende uno `Stream<int>` `source` e restituisce un `Future<int>` che si completa con la somma dei suoi valori. Se lo stream emette un errore, fermati e completa con la somma dei valori ricevuti **prima** dell'errore, invece di lanciare l'eccezione.

Esempio:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
