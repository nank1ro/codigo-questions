# --description--

Oltre a `toList()`, uno stream offre altri metodi che **consumano** tutti i suoi eventi e restituiscono un singolo `Future`:

- `first` e `last` si completano con il primo o l'ultimo evento
- `length` si completa con il numero di eventi
- `join(separator)` si completa con tutti gli eventi uniti in una sola `String`
- `reduce(combine)` combina gli eventi due alla volta in un unico valore

```dart
final numbers = Stream.fromIterable([3, 9, 2]);
print(await numbers.reduce((a, b) => a + b)); // 14
```

`reduce` chiama `combine` con il risultato ottenuto finora e l'evento successivo. Lancia un'eccezione se lo stream è vuoto, quindi usalo solo quando è garantito almeno un evento.

# --instructions--

Scrivi due funzioni:
- `largest`, che prende uno `Stream<int>` `source` e restituisce un `Future<int>` che si completa con il valore più grande, usando `reduce`. Lo stream ha sempre almeno un evento.
- `sentence`, che prende uno `Stream<String>` `words` e restituisce un `Future<String>` che si completa con tutte le parole unite da un singolo spazio.

Esempio:
```dart
print(await largest(Stream.fromIterable([3, 9, 2])));        // 9
print(await sentence(Stream.fromIterable(['I', 'am', 'Dart']))); // I am Dart
```

# --solutions--

```dart
Future<int> largest(Stream<int> source) {
  return source.reduce((a, b) => a > b ? a : b);
}

Future<String> sentence(Stream<String> words) {
  return words.join(' ');
}
```
