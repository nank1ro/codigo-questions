# --description--

L'**operatore AND** `&&` combina due espressioni booleane. Restituisce `true` solo quando **entrambi** i lati sono `true`. Se uno dei lati è `false`, il risultato è `false`.

```dart
bool a = true;
bool b = true;
bool result = a && b; // true

bool c = true;
bool d = false;
bool result2 = c && d; // false
```
