# --description--

L'**operatore di disuguaglianza** `!=` restituisce `true` quando due valori sono **diversi**, e `false` quando sono uguali.

```dart
int x = 3;
int y = 7;
bool result = x != y; // true
```

È il contrario di `==`.

# --instructions--

Completa il codice per verificare se `4` non è uguale a `9` e memorizza il risultato in `isDifferent`.
