# --description--

Raccogliere un'intera serie di messaggi segue una sola ricetta: una lista vuota prima del ciclo, una `add` per ogni messaggio vero, e `close()` sul segnale che termina lo stream. Una volta chiusa la porta, l'`await for` finisce e la funzione può restituire:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

I messaggi mantengono l'ordine in cui sono stati inviati, quindi la lista che costruisci rispecchia passo dopo passo il lavoro dell'altro isolate.

# --instructions--

Scrivi una funzione top-level `sendWords` che prende una `List<Object>` `message` in cui l'elemento `0` è una `SendPort` e l'elemento `1` è una `List<String>`: invia ogni parola alla porta, poi invia `null` per segnalare la fine.

Poi scrivi una funzione `collectWords` che prende una `List<String>` `words` e restituisce un `Future<List<String>>` che si completa con tutte le parole ricevute da un isolate `sendWords` avviato.

Esempio:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
