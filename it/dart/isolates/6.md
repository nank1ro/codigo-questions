# --description--

La funzione passata a `Isolate.spawn` si chiama **punto di ingresso**. Deve essere una funzione top-level (o statica) che prende esattamente un parametro: il messaggio che `Isolate.spawn` le passa.

```dart
void reportAnswer(SendPort port) {
  port.send(42);
}
```

I messaggi che arrivano in una `ReceivePort` hanno tipo statico `dynamic`, perché poteva essere inviato qualsiasi valore. Quando sai cosa invia l'altro isolate, fai un cast:

```dart
final receivePort = ReceivePort();
await Isolate.spawn(reportAnswer, receivePort.sendPort);
final answer = await receivePort.first as int;
```

# --instructions--

Scrivi una funzione top-level `sendGreeting` che prende una `SendPort` `port` e le invia la stringa `hello from the isolate`.

Poi scrivi una funzione `greetFromIsolate` che restituisce un `Future<String>`: crea una `ReceivePort`, avvia `sendGreeting` con il suo `sendPort` e si completa con il primo messaggio ricevuto.

Esempio:
```dart
print(await greetFromIsolate()); // hello from the isolate
```

```dart
void sendGreeting(SendPort port) {
  port.send('hello from the isolate');
}

Future<String> greetFromIsolate() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendGreeting, receivePort.sendPort);
  return await receivePort.first as String;
}
```
