# --instructions--

Scrivi un'estensione denominata `Words` su `String` con:
- un getter `wordCount` di tipo `int`, il numero di parole nella stringa, dove le parole sono separate da un singolo spazio
- un getter `initials` di tipo `String`, formato dal primo carattere di ogni parola in maiuscolo, unito senza separatori

La stringa contiene sempre almeno una parola e non ha mai spazi iniziali, finali o doppi.

Esempio:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
