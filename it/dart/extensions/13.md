# --description--

Un'estensione generica può accettare **funzioni** come parametri, esattamente come fanno `where` e `map`. Il tipo della funzione è scritto con il tipo dell'elemento `T`, così la callback riceve elementi del tipo giusto:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

Completa l'estensione in modo che `countWhere` restituisca quanti elementi soddisfano la funzione `test` data, così che il programma stampi `2` e poi `1`.

```dart
extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
```
