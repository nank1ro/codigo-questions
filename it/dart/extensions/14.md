# --instructions--

La classe `Temperature` è fornita. Scrivi un'estensione denominata `Conversions` su `Temperature` con:
- un getter `fahrenheit` di tipo `double`, uguale a `celsius * 9 / 5 + 32`
- un metodo `isAbove` che accetta un parametro `double` `limit` e restituisce `true` quando `celsius` è maggiore di `limit`

Esempio:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

  bool isAbove(double limit) => celsius > limit;
