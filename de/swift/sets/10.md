# --instructions--

Gib in aufsteigender Reihenfolge die Tage aus, an denen kein Meeting stattfindet

# --seed--

```swift
let weekdays: Set<String> = ["mon", "tue", "wed"]
let meetings: Set<String> = ["tue", "sat"]
let free = weekdays.[/](meetings)
print(free.sorted())
```

# --solutions--

```swift
let weekdays: Set<String> = ["mon", "tue", "wed"]
let meetings: Set<String> = ["tue", "sat"]
let free = weekdays.subtracting(meetings)
print(free.sorted())
```

# --output--

["mon", "wed"]
