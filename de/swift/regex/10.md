# --description--

Ein Muster kann mehrere Gruppen enthalten. Sie werden von links nach rechts nach ihrer öffnenden Klammer nummeriert, daher ist die zweite `m.2`, die dritte `m.3` und so weiter:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` bleibt immer die gesamte Übereinstimmung, ganz gleich wie viele Gruppen es gibt.

# --instructions--

Schreibe eine Funktion `setting`, die einen Text (`String`) ohne Argumentlabel entgegennimmt, eine Einstellung findet, die aus Kleinbuchstaben, einem `=`-Zeichen und Ziffern besteht, und den Namen und den Wert, verbunden durch einen Doppelpunkt, zurückgibt, oder `"none"`, wenn der Text keine solche Einstellung enthält

Beispiel für einen Funktionsaufruf:
```swift
print(setting("size=10"))
// gibt size:10 aus
```

# --asserts--

Die Funktion muss ein Regex-Literal verwenden, das mit `#/` geschrieben ist

```json
{
  "regex": "#/",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`setting("size=10")` muss `"size:10"` zurückgeben

```swift
tryCatch(setting("size=10") == "size:10")
```

`setting("use width=800 here")` muss `"width:800"` zurückgeben

```swift
tryCatch(setting("use width=800 here") == "width:800")
```

`setting("a=1 b=2")` muss `"a:1"` zurückgeben

```swift
tryCatch(setting("a=1 b=2") == "a:1")
```

`setting("nothing here")` muss `"none"` zurückgeben

```swift
tryCatch(setting("nothing here") == "none")
```

# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
