# --description--

Ein `#/ ... /#`-Literal steht beim Kompilieren fest. Wenn das Muster erst zur Laufzeit bekannt wird, zum Beispiel weil ein Nutzer es eingegeben hat, baust du es mit `Regex(_:)`:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
Dieser Initialiser **wirft**: Ein ungültiges Muster wie `"["` wird erst entdeckt, während das Programm läuft, daher benötigt der Aufruf `try`, und der Fehler muss entweder mit `do`/`catch` (oder `try?`) behandelt oder durch das Markieren der umgebenden Funktion mit `throws` weitergereicht werden, wie es diese Übung tut. Ein so gebauter Regex hat keine zur Compilezeit bekannten nummerierten Eigenschaften, aber `contains`, `matches(of:)` und `replacing` funktionieren genau wie vorher.

# --instructions--

Schreibe eine Funktion `countMatches`, die einen Text (`String`) und ein Muster (`String`) ohne Argumentlabels entgegennimmt, mit `throws` markiert ist und zurückgibt, wie oft das Muster im Text gefunden wird. Ein ungültiges Muster muss den Fehler nach außen lassen

Beispiel für einen Funktionsaufruf:
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// gibt 2 aus
```

# --asserts--

Die Funktion muss den Regex mit `try Regex(` bauen

```json
{
  "regex": "try\\s+Regex\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`countMatches("a1 b22", "[0-9]+")` muss `2` zurückgeben

```swift
tryCatch((try? countMatches("a1 b22", "[0-9]+")) == 2)
```

`countMatches("abc", "[0-9]+")` muss `0` zurückgeben

```swift
tryCatch((try? countMatches("abc", "[0-9]+")) == 0)
```

`countMatches("hello world", "o")` muss `2` zurückgeben

```swift
tryCatch((try? countMatches("hello world", "o")) == 2)
```

`countMatches("abc", "[")` muss einen Fehler werfen

```swift
tryCatch((try? countMatches("abc", "[")) == nil)
```

# --solutions--

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
