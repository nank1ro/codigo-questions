# --description--

Du kannst eigene Funktionen höherer Ordnung schreiben. Eine Funktion, die eine Closure entgegennimmt und eine aus ihr aufgebaute **neue Closure zurückgibt**, ist ein verbreitetes Muster: Die zurückgegebene Closure erfasst die ursprüngliche, daher muss der Parameter `@escaping` sein.
Zum Beispiel verwandelt `negate` ein Prädikat in sein Gegenteil, bereit, um an `filter` übergeben zu werden:
```swift
func negate(_ predicate: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { !predicate($0) }
}
let isEven: (Int) -> Bool = { $0 % 2 == 0 }
print([1, 2, 3, 4].filter(negate(isEven))) // [1, 3]
```
Beachte, dass `filter(negate(isEven))` die Closure als normales Argument übergibt, ohne Trailing-Closure-Syntax.

# --instructions--

Schreibe eine Funktion `both`, die zwei Closures vom Typ `(Int) -> Bool` entgegennimmt (lasse beide Argumentlabel weg) und eine Closure desselben Typs zurückgibt, die nur dann `true` ist, wenn beide für dasselbe Argument `true` sind

Beispiel eines Funktionsaufrufs:
```swift
let smallEven = both({ $0 < 10 }, { $0 % 2 == 0 })
print([4, 12, 7, 8].filter(smallEven))
// prints [4, 8]
```

# --asserts--

```swift
tryCatch(both({ $0 < 10 }, { $0 % 2 == 0 })(4) == true)
```

`both({ $0 < 10 }, { $0 % 2 == 0 })` muss für `12` `false` sein

```swift
tryCatch(both({ $0 < 10 }, { $0 % 2 == 0 })(12) == false)
```

`both({ $0 < 10 }, { $0 % 2 == 0 })` muss für `7` `false` sein

```swift
tryCatch(both({ $0 < 10 }, { $0 % 2 == 0 })(7) == false)
```

Die zurückgegebene Closure muss mit `filter` funktionieren

```swift
let _smallEven = both({ $0 < 10 }, { $0 % 2 == 0 })
tryCatch([4, 12, 7, 8].filter(_smallEven) == [4, 8])
```

```swift
func both(_ first: @escaping (Int) -> Bool, _ second: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { first($0) && second($0) }
}
```
