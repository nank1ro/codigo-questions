# --description--

Mehrere Optionals in einem `if let` zu binden hält den Code flach: ein einziger `else`-Zweig deckt jeden fehlenden Wert ab.

# --instructions--

Sortiere die Elemente, um `Area: 20` auszugeben, wenn sowohl `width` als auch `height` einen Wert haben, und `Missing size` andernfalls.
Deklariere `width` vor `height`

# --solutions--

```swift
let width: Int? = 4
let height: Int? = 5
if let w = width, let h = height {
    print("Area: \(w * h)")
} else {
    print("Missing size")
}
```

# --output--

Area: 20
