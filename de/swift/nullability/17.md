# --description--

Fehlschlagbare Umwandlungen passen natürlich zu `guard let`: umwandeln, abbrechen, wenn das Ergebnis `nil` ist, dann mit dem einfachen Wert weiterarbeiten.

# --instructions--

Vervollständige die Funktion so, dass sie den Text in einen `Int` umwandelt und dessen Verdopplung zurückgibt, oder `nil`, wenn die Umwandlung fehlschlägt.
Gib danach die Ergebnisse aus, mit `0` als Ersatzwert

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
