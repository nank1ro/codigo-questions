# --description--

Ein Struct ist ein Werttyp, daher muss eine Methode, die eine seiner gespeicherten Eigenschaften ändert, mit `mutating` markiert sein. Ist diese Methode eine Protokollanforderung, muss das auch das Protokoll sagen:
```swift
protocol Togglable {
    mutating func toggle()
}

struct Light: Togglable {
    var isOn = false

    mutating func toggle() {
        isOn = !isOn
    }
}

var lamp = Light()
lamp.toggle()
print(lamp.isOn) // true
```
Ohne `mutating` im Protokoll könnte ein Struct die Anforderung nie erfüllen. Klassen sind Referenztypen und brauchen das Schlüsselwort nie: Eine Klasse erfüllt eine `mutating`-Anforderung mit einer gewöhnlichen Methode. Der Aufruf einer mutating-Methode braucht ein `var` — bei einem `let` ist es ein Kompilierfehler.

# --instructions--

Sorge dafür, dass `Score` `Resettable` konform implementiert, mit einer Methode `reset()`, die `points` auf `0` setzt

Beispiel einer Verwendung:
```swift
var score = Score(points: 10)
score.reset()
print(score.points)
// gibt 0 aus
```

# --seed--

```swift
protocol Resettable {
    mutating func reset()
}

struct Score {
    var points: Int
}
```

# --before-asserts--

```swift
func _reset<T: Resettable>(_ v: inout T) {
    v.reset()
}
```

# --asserts--

Ein Punktestand von `10` muss nach dem Zurücksetzen `0` sein

```swift
var _s1 = Score(points: 10)
_reset(&_s1)
tryCatch(_s1.points == 0)
```

Ein Punktestand von `-4` muss nach dem Zurücksetzen `0` sein

```swift
var _s2 = Score(points: -4)
_reset(&_s2)
tryCatch(_s2.points == 0)
```

Ein Punktestand von `0` muss nach dem Zurücksetzen `0` bleiben

```swift
var _s3 = Score(points: 0)
_reset(&_s3)
tryCatch(_s3.points == 0)
```

protocol Resettable {

    }
