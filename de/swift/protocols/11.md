# --description--

Ein Protokoll kann auf einem anderen aufbauen. Schreibt man einen Protokollnamen nach den Doppelpunkt, **erbt** das neue Protokoll jede Anforderung des alten:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
Ein Typ, der `Aged` konform implementiert, muss `age` *und* `name` bereitstellen, und er gilt überall als `Named`-Typ. Ein Protokoll kann gleichzeitig von mehreren Protokollen erben, getrennt durch Kommas.

Deklariere ein Protokoll `Timed`, das von `Named` erbt und eine lesbare `Int`-Eigenschaft `seconds` hinzufügt, und sorge dafür, dass `Track` `Timed` konform implementiert

# --before-asserts--

```swift
extension Timed {
    func label() -> String {
        return "\(name) \(seconds)"
    }
}

func _name(_ n: Named) -> String {
    return n.name
}
```

# --asserts--

Ein Track namens `Intro` mit `90` Sekunden muss als `Intro 90` beschriftet werden

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

Ein Track namens `Outro` mit `5` Sekunden muss als `Outro 5` beschriftet werden

```swift
tryCatch(Track(name: "Outro", seconds: 5).label() == "Outro 5")
```

Ein Track namens `Gap` mit `0` Sekunden muss als `Gap 0` beschriftet werden

```swift
tryCatch(Track(name: "Gap", seconds: 0).label() == "Gap 0")
```

Ein `Timed`-Wert muss als `Named`-Wert verwendbar sein

```swift
tryCatch(_name(Track(name: "Intro", seconds: 90)) == "Intro")
```
