# --description--

Da `%` einen Spezifizierer einleitet, muss ein Prozentzeichen als Literal als `%%` geschrieben werden. So formatierst du einen Prozentsatz:
```swift
let ratio = 0.4567
print(String(format: "%.1f%%", ratio * 100)) // 45.7%
```
Multipliziere das Verhältnis zuerst mit `100` und wähle dann die Präzision: `%.0f%%` für `46%`, `%.1f%%` für `45.7%`.

# --instructions--

Schreibe eine Funktion `percent`, die einen Teil und ein Ganzes (beide `Double`, ohne Argumentlabel) entgegennimmt und den Teil als Prozentsatz des Ganzen mit einer Dezimalstelle zurückgibt, gefolgt von `%`

Beispiel eines Funktionsaufrufs:
```swift
print(percent(9, 20))
// prints 45.0%
```
