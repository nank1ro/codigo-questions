# --description--

Da ein String eine Sammlung von Zeichen ist, kannst du mit einer `for`-`in`-Schleife über ihn iterieren. Jede Iteration liefert dir ein `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
Ein `Character` kann mit `==` mit einem Zeichenliteral verglichen werden, daher ist das Zählen, wie oft ein Zeichen vorkommt, nur eine Schleife mit einem Zähler.

# --instructions--

Schreibe eine Funktion `occurrences`, die ein `Character` mit dem Argumentlabel `of` und einen `String` mit dem Argumentlabel `in` entgegennimmt und zurückgibt, wie oft das Zeichen im String vorkommt.

Beispiel für einen Funktionsaufruf:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
