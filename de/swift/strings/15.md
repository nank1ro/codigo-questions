# --description--

Das Aufteilen an Leerzeichen ist der einfachste Weg, einen Satz in Wörter zu zerlegen, und das Zusammenfügen ist der Weg, um Text aus einem Array wiederherzustellen.

# --instructions--

Schreibe eine Funktion `wordCount`, die einen `String` entgegennimmt (lass das Argumentlabel weg) und zurückgibt, wie viele durch Leerzeichen getrennte Wörter er enthält, sowie eine Funktion `slug`, die ein Array von `String` entgegennimmt (lass das Argumentlabel weg) und die Wörter durch `-` verbunden zurückgibt

Beispiel für einen Funktionsaufruf:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
