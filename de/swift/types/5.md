# --description--

`Int(x)` rundet nicht: es **schneidet ab**, verwirft einfach den Dezimalteil, daher ist `Int(3.99)` gleich `3` und `Int(-3.99)` gleich `-3`.
Um auf die nächste Ganzzahl zu runden, rufe zuerst `rounded()` auf dem `Double` auf und wandle dann um:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
Halbe Werte wie `2.5` werden von Null weg gerundet: `2.5` wird zu `3.0` und `-2.5` wird zu `-3.0`.

# --instructions--

Schreibe eine Funktion `roundedAverage`, die zwei `Int` entgegennimmt (lasse die Argumentlabel weg) und ihren auf die nächste Ganzzahl gerundeten Durchschnitt als `Int` zurückgibt

Beispiel eines Funktionsaufrufs:
```swift
print(roundedAverage(3, 4))
// prints 4
```

func roundedAverage(_ a: Int, _ b: Int) -> Int {
    let average = Double(a + b) / 2
    return Int(average.rounded())
}
