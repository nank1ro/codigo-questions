# --description--

`Int(text)` gelingt nur, wenn der gesamte Text eine gültige Ganzzahl ist, mit optionalem Vorzeichen:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Für Dezimaltext verwende `Double(text)`, das auf dieselbe Weise ein `Double?` zurückgibt: `Double("3.5")` ist `Optional(3.5)`.

# --instructions--

Schreibe eine Funktion `sumOfNumbers`, die ein Array aus `String` entgegennimmt (lasse das Argumentlabel weg) und die Summe derjenigen zurückgibt, die gültige Ganzzahlen sind, und die anderen ignoriert

Beispiel eines Funktionsaufrufs:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
