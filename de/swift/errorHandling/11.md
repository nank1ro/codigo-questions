# --description--

Wenn eine Funktion wirft, wird alles nach dem `throw` übersprungen — auch die Zeile, die die Datei schließen oder die Sperre freigeben sollte. `defer` löst das: Es registriert jetzt einen Block und führt ihn aus, wenn der aktuelle Gültigkeitsbereich endet, ganz gleich, wie er endet.
```swift
func load() throws {
    print("open")
    defer { print("close") }
    throw FileError.missing
}
```
Der Aufruf gibt `open` aus, dann `close`, und erst danach reist der Fehler zum Aufrufer weiter. Hätte die Funktion normal zurückgegeben, wäre `close` trotzdem ausgegeben worden — das ist der Punkt. Setze das Aufräumen direkt neben das Einrichten und sorge dich nicht mehr darum, welchen Ausgang der Code nimmt.

# --instructions--

Füge in `run` einen `defer`-Block hinzu, der `"cleanup"` an `log` anhängt, sodass er sowohl passiert, wenn `run` normal zurückkehrt, als auch, wenn es wirft

# --seed--

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```

# --asserts--

auf dem erfolgreichen Pfad muss das Log `start`, `done`, `cleanup` sein

```swift
let _ok: [String] = steps(false)
tryCatch(_ok == ["start", "done", "cleanup"])
```

auf dem werfenden Pfad muss das Log `start`, `cleanup`, `caught` sein

```swift
let _bad: [String] = steps(true)
tryCatch(_bad == ["start", "cleanup", "caught"])
```

das Aufräumen muss auf beiden Pfaden laufen

```swift
tryCatch(steps(false).contains("cleanup") && steps(true).contains("cleanup"))
```

das Aufräumen muss auf dem werfenden Pfad genau einmal laufen

```swift
let _once: [String] = steps(true)
tryCatch(_once.filter { $0 == "cleanup" }.count == 1)
```

enum TaskError: Error {

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        defer { log.append("cleanup") }
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
