# --description--

Berechnete Eigenschaften in Extensions passen auch natürlich zu `String`. Die Methode `reversed()` gibt die Zeichen in umgekehrter Reihenfolge zurück, und `String(...)` macht daraus wieder einen String:
```swift
extension String {
    var backwards: String {
        return String(reversed())
    }
}
print("swift".backwards) // tfiws
```
Wie bei Methoden bedeutet `reversed()` innerhalb der Extension `self.reversed()`.

# --instructions--

Schreibe eine Extension von `String` mit einer berechneten Eigenschaft `isPalindrome` vom Typ `Bool`, die `true` ist, wenn der String vorwärts und rückwärts gelesen gleich lautet. Der Vergleich unterscheidet Groß- und Kleinschreibung

Beispiel einer Verwendung:
```swift
print("level".isPalindrome)
// prints true
```

Du musst eine Extension von `String` verwenden

```json
{
  "regex": "extension\\s+String",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`"level".isPalindrome` muss `true` sein

```swift
tryCatch("level".isPalindrome == true)
```

`"swift".isPalindrome` muss `false` sein

```swift
tryCatch("swift".isPalindrome == false)
```

`"Anna".isPalindrome` muss `false` sein (der Vergleich unterscheidet Groß- und Kleinschreibung)

```swift
tryCatch("Anna".isPalindrome == false)
```

`"".isPalindrome` muss `true` sein

```swift
tryCatch("".isPalindrome == true)
```
