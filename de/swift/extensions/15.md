# --description--

Extensions können Member nur **hinzufügen**, niemals bestehende ersetzen oder überschreiben. `override` gehört zu Subklassen, die einen anderen Typ als ihre Elternklasse sind; eine Extension ist derselbe Typ, daher ist das Deklarieren einer Methode, die bereits existiert, ein Redeklarationsfehler:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
Wenn du ein anderes Verhalten brauchst, füge eine Methode mit einem neuen Namen hinzu oder schreibe eine Subklasse, wenn der Typ eine Klasse ist.

# --instructions--

Was passiert, wenn dieses Programm kompiliert und ausgeführt wird?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- Es kompiliert nicht, weil `speak()` zweimal für denselben Typ deklariert wird
- Es gibt `Bark` aus, weil die Extension die ursprüngliche Methode überschreibt
- Es gibt `Woof` aus, weil die ursprüngliche Methode gegenüber der Extension gewinnt
- Es gibt `Woof` und dann `Bark` aus
