# --description--

Eine `mutating`-Methode kann Parameter wie jede andere Methode entgegennehmen und kann `self` vollständig ersetzen, statt es an Ort und Stelle zu aktualisieren:
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

# --instructions--

Schreibe eine Extension von `Int` mit einer `mutating`-Methode `clamp(to max: Int)`, die die Zahl durch `max` ersetzt, wenn die Zahl größer als `max` ist, und sie andernfalls unverändert lässt

Beispiel eines Methodenaufrufs:
```swift
var speed = 15
speed.clamp(to: 10)
print(speed)
// prints 10
```
