# --description--

Statische Methoden in Extensions sind ein guter Ort für kleine Factory-Funktionen, die einen Wert des Typs erstellen. `String(repeating:count:)` ist der Standardinitialisierer, der ein Stück Text eine bestimmte Anzahl von Malen wiederholt:
```swift
extension String {
    static func dashes(_ count: Int) -> String {
        return String(repeating: "-", count: count)
    }
}
print(String.dashes(4)) // ----
```

# --instructions--

Schreibe eine Extension von `String` mit einer statischen Methode `stars(_ count: Int)`, die einen String zurückgibt, der aus `count` Sternchen `*` besteht

Beispiel eines Methodenaufrufs:
```swift
print(String.stars(3))
// prints ***
```

# --asserts--

Du musst eine Extension von `String` verwenden

```json
{
  "regex": "extension\\s+String",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Die Methode muss `static` sein

```json
{
  "regex": "static\\s+func\\s+stars",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`String.stars(3)` muss `"***"` zurückgeben

```swift
tryCatch(String.stars(3) == "***")
```

`String.stars(1)` muss `"*"` zurückgeben

```swift
tryCatch(String.stars(1) == "*")
```

`String.stars(0)` muss einen leeren String zurückgeben

```swift
tryCatch(String.stars(0) == "")
```
