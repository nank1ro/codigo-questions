# --description--

Closures können wie jeder andere Wert in Arrays gespeichert werden. Der Elementtyp ist der Funktionstyp:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Über ein solches Array zu iterieren und jede Closure der Reihe nach aufzurufen, baut eine kleine **Pipeline** von Transformationen.

# --instructions--

Schreibe eine Funktion `pipeline`, die einen `Int` und ein Array von Closures vom Typ `(Int) -> Int` entgegennimmt (lasse beide Argumentlabel weg) und das Ergebnis der Anwendung jeder Closure der Reihe nach zurückgibt, jeweils auf das Ergebnis der vorherigen

Beispiel eines Funktionsaufrufs:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
