# --instructions--

Ordne die Elemente so, dass `EUR 12` ausgegeben wird, mit dem Struct zuerst deklariert und der Instanz vor dem `print`

# --answers--

```swift
struct Money {
    static let currency = "EUR"
    var amount: Int
}
```

```swift
let price = Money(amount: 12)
```

```swift
print("\(Money.currency) \(price.amount)")
```
