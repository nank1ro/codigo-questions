# --instructions--

Warum kompiliert dieser Code nicht?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` ist eine `let`-Konstante, daher kann keine mutating-Methode darauf aufgerufen werden
- `increase` muss als `static` markiert sein, um `value` zu ändern
- `value` muss mit `let` deklariert werden
- Ein Struct kann keine Methoden enthalten
