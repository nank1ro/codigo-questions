# --description--

Da ein Struct ein Wert ist, darf eine Methode seine Eigenschaften nicht ändern, außer du sagst es mit dem Schlüsselwort `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Eine mutating-Methode kann nur auf einer Instanz aufgerufen werden, die in einem `var` gespeichert ist. Bei einer `let`-Instanz ist der Wert eingefroren, deshalb würde `c.increase(by: 5)` nicht kompilieren.

# --instructions--

Füge `Counter` eine mutating-Methode `increase` hinzu, die einen `Int` mit dem Argument-Label `by` entgegennimmt und ihn zu `value` addiert

Beispiel einer Verwendung:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

Die Methode muss als `mutating` markiert sein

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Erhöhen von `0` um `5` muss `5` ergeben

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Erhöhen von `10` zweimal muss sich aufsummieren

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Erhöhen um `0` darf nichts ändern

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Das Ändern einer Kopie darf das Original nicht ändern

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
