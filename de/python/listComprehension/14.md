# --description--

Dieselbe Idee funktioniert auch für Dictionaries: eine **Dict Comprehension** verwendet geschweifte Klammern und einen `key: value`-Ausdruck:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
