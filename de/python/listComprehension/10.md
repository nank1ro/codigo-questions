# --description--

Die beiden Positionen von `if` werden leicht verwechselt, halte sie also auseinander:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else vor dem for: wählt einen Wert, else erforderlich
positives = [n for n in nums if n > 0]      # if nach dem for: filtert, kein else erlaubt
```
Ein `else` nach dem Filter-`if` ist ein Syntaxfehler.

# --instructions--

Was ist das __Problem__ mit diesem Code-Snippet?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- Das Filter-`if` nach dem `for` darf kein `else` haben: ein `if-else` muss vor dem `for` stehen
- Eine List Comprehension darf keine Bedingung enthalten
- `nums` enthält eine negative Zahl, was nicht erlaubt ist
- `else` muss durch `elif` ersetzt werden
