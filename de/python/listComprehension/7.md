# --description--

Innerhalb einer Comprehension kannst du jede zuvor definierte Variable verwenden, zum Beispiel als Grenzwert eines `range()`.

# --instructions--

Ordne die Elemente, um die Vielfachen von 7 unterhalb von `limit` auszugeben

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
multiples = [n for n in range(1, limit) if n % 7 == 0]
print(multiples)
```

# --output--
