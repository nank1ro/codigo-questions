# --description--

Die Filterbedingung kann jeder Ausdruck sein, der einen Wahrheitswert liefert, einschließlich Funktionsaufrufen wie `len()`:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
