# --description--

Da der Rumpf ein einzelner Ausdruck sein muss, **kann eine lambda keine Anweisungen enthalten**.
Kein `return`, keine `if`-Blöcke, keine Schleifen, keine Zuweisungen:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Wenn du etwas davon brauchst, schreibe stattdessen eine normale `def`-Funktion.

# --instructions--

Was ist das __Problem__ mit diesem Codeausschnitt?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- Der Rumpf einer lambda ist ein Ausdruck, er kann kein return enthalten
- Eine lambda kann nicht in einer Variable gespeichert werden
- Eine lambda kann nicht mit Klammern aufgerufen werden
- Eine lambda braucht mindestens zwei Parameter
