# --description--

`map()` wendet eine Funktion auf **jedes Element** einer Liste an.
Sie gibt ein spezielles _map-Objekt_ zurück, also setze es in `list()`, um die Werte zu sehen:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
