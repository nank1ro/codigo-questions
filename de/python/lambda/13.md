# --description--

Auch `max()` und `min()` akzeptieren eine `key`-Funktion, genau wie `sorted()`:
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

# --instructions--

Ordne die Elemente, um die Namen in alphabetischer Reihenfolge ohne Berücksichtigung der Groß-/Kleinschreibung auszugeben, und dann den längsten Namen

# --answers--

```python
names = ["bob", "Alice", "Charlie"]
```

```python
ordered = sorted(names, key=lambda s: s.lower())
```

```python
longest = max(ordered, key=lambda s: len(s))
```

```python
print(ordered)
```
