# --description--

lambdas sind nicht auf eingebaute Funktionen beschränkt: **deine eigenen Funktionen** können eine Funktion als Parameter nehmen und aufrufen.
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

# --instructions--
