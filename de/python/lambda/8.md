# --description--

Die `key`-lambda kann einen beliebigen Teil eines Elements auswählen.
Bei einer Liste von Listen sortiert `lambda p: p[1]` nach dem zweiten Element jeder inneren Liste.

# --instructions--

Ordne die Elemente, um die Personen vom jüngsten zum ältesten auszugeben

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
