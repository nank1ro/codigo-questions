# --description--

Beachte, dass der Rumpf der lambda kein `return`-Schlüsselwort hat.
Der Rumpf ist ein **einzelner Ausdruck**, und sein Wert wird automatisch zurückgegeben:
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

Speichere in der Variable `square` eine lambda, die einen Parameter `n` nimmt und `n` multipliziert mit sich selbst zurückgibt
