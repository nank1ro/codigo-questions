# --description--

Beim Erstellen eines **leeren Sets** lauert eine Falle.
Geschweifte Klammern sind auch die Syntax von Dictionaries, daher erstellt `{}` ein leeres **Dictionary**, kein Set:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Um ein leeres Set zu erhalten, musst du `set()` ohne Argumente aufrufen:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

Was gibt dieser Code aus?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, weil `{}` ein leeres Dictionary erstellt
- `<class 'set'>`, weil geschweifte Klammern ein Set erstellen
- `<class 'NoneType'>`, weil das Set keine Elemente hat
- Ein `SyntaxError`, weil Klammern mindestens ein Element enthalten müssen
