# --description--

Eine Ausnahme, auf die kein `except`-Block passt, reist weiter nach außen: aus der Zeile heraus, aus der Funktion, die sie ausgeführt hat, aus deren Aufrufer und so weiter. Wenn nichts sie abfängt, bevor sie die oberste Ebene des Programms erreicht, gibt Python den Traceback aus und der Prozess endet mit einem Exit-Status ungleich null. Die Zeilen nach der fehlgeschlagenen Anweisung laufen nie.

# --instructions--

Was passiert, wenn dieser Code ausgeführt wird?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- Er gibt `start` aus, dann einen Traceback, der mit `TypeError` endet, und weder `end` noch `after` wird ausgegeben, weil die nicht abgefangene Ausnahme das Programm stoppt
- Er gibt `start`, `end` und `after` aus, weil Python nur die fehlschlagende Zeile überspringt
- Er gibt `start` und `after` aus, weil die Ausnahme `sizes` stoppt, das Programm aber weiterläuft
- Er gibt `start` und `0` aus, weil `len(None)` gleich `0` ist
