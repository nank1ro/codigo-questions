# --description--

Nebenläufigkeit zahlt sich aus, wenn die Anzahl der Operationen nicht feststeht. Baue die Coroutine-Objekte in einer List Comprehension, entpacke sie in `gather` und awaite die gesamte Gruppe auf einmal:
```python
import asyncio

async def fetch(url):
    await asyncio.sleep(0.02)
    return len(url)

async def fetch_all(urls):
    return await asyncio.gather(*[fetch(u) for u in urls])

print(asyncio.run(fetch_all(["a.com", "bb.com"])))  # [5, 6]
```
Zehn urls dauern insgesamt weiterhin nur etwa 20 Millisekunden statt 200, und die Ergebnisse behalten die Reihenfolge der urls bei.

# --instructions--

Schreibe eine Coroutine-Funktion `fetch(item_id)`, die `0.02` Sekunden wartet und `item_id * 10` zurückgibt, und eine Coroutine-Funktion `fetch_all(ids)`, die `fetch` für jede id **gleichzeitig** mit `asyncio.gather` ausführt und die Liste der Ergebnisse zurückgibt

```python
    def test_2(self):
```

`fetch_all` muss fünf ids gleichzeitig ausführen und dabei deutlich unter `0.1` Sekunden dauern

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(fetch_all([1, 2, 3, 4, 5]))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [10, 20, 30, 40, 50], "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```
