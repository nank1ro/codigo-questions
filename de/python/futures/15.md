# --description--

Der Umgang mit einer fehlschlagenden Coroutine folgt dem synchronen Muster: Die Coroutine löst eine Ausnahme aus, der Aufrufer umschließt das `await` mit `try`/`except` und entscheidet, was mit dem Fehlerobjekt geschehen soll, zum Beispiel seine Meldung mit `print(e)` auszugeben.

# --instructions--

Sortiere die Elemente, um ein Programm zu bauen, das mit dem Import beginnt, `load` vor `main` definiert, das Ergebnis des Ladens von `"config"` ausgibt, dann den Fehler beim Laden eines leeren Namens abfängt und seine Meldung ausgibt, sodass `loaded config`, `empty name` ausgegeben wird

# --solutions--

```python
import asyncio
async def load(name):
    await asyncio.sleep(0.01)
    if name == "":
        raise ValueError("empty name")
    return f"loaded {name}"
async def main():
    print(await load("config"))
    try:
        await load("")
    except ValueError as e:
        print(e)
asyncio.run(main())
```

# --output--

loaded config
empty name
