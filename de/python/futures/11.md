# --description--

Eine Task läuft weiter, egal ob jemand auf sie wartet. Erstelle sie früh, erledige andere Arbeit und `await` sie erst an der Stelle, an der ihr Ergebnis gebraucht wird: Das Warten ist kürzer, weil ein Teil der Task bereits im Hintergrund gelaufen ist. Eine Task kann auch mit `task.done()` geprüft werden, was `True` zurückgibt, sobald sie beendet ist.

# --instructions--

Vervollständige den Code, sodass `compute()` als Task eingeplant wird, `"waiting"` ausgegeben wird, während sie läuft, und die Task danach awaited wird, um ihren Wert zu erhalten, sodass `waiting`, `42` ausgegeben wird

import asyncio

async def compute():

    return 42

    print(value)

asyncio.run(main())

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```
