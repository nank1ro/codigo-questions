# --description--

Ein kleines asynchrones Programm folgt einer festen Form: importiere `asyncio`, definiere die Coroutine-Funktionen, definiere eine `main`-Coroutine, die sie awaitet, und rufe zum Schluss einmal `asyncio.run(main())` auf.

# --instructions--

Sortiere die Elemente, um ein Programm zu bauen, das mit dem Import beginnt, `download` vor `main` definiert, zwei Downloads gleichzeitig mit `asyncio.gather` ausführt und die Ergebnisse ausgibt, sodass `['report.pdf', 'data.csv']` ausgegeben wird

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

# --output--

['report.pdf', 'data.csv']
