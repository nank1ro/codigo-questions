# --description--

Wenn eine der an `gather` übergebenen Coroutinen eine Ausnahme auslöst, propagiert die Ausnahme zur Zeile `await asyncio.gather(...)` und die Ergebnisse der anderen gehen verloren, obwohl sie weiterlaufen. `return_exceptions=True` zu übergeben ändert dies: `gather` löst nie eine Ausnahme aus, und das Ausnahmeobjekt nimmt in der Liste den Platz des fehlenden Ergebnisses ein:
```python
import asyncio

async def ok():
    return 1

async def fail():
    raise ValueError("bad")

async def main():
    results = await asyncio.gather(ok(), fail(), return_exceptions=True)
    print(results)  # [1, ValueError('bad')]

asyncio.run(main())
```
Jedes Element kann dann mit `isinstance(result, Exception)` geprüft werden, um Fehlschläge von Werten zu trennen.

# --instructions--

Welche Ausgabe hat der folgende Code?
```python
import asyncio

async def ok():
    return 1

async def fail():
    raise ValueError("bad")

async def main():
    results = await asyncio.gather(ok(), fail(), return_exceptions=True)
    print(len(results), isinstance(results[1], ValueError))

asyncio.run(main())
```

# --answers--

- `2 True`, weil mit `return_exceptions=True` die Ausnahme in der Liste zurückgegeben wird, statt ausgelöst zu werden
- Ein `ValueError`, weil eine Ausnahme in einer Coroutine immer aus `gather` hinaus propagiert
- `1 False`, weil die fehlgeschlagene Coroutine aus den Ergebnissen entfernt wird
- `2 False`, weil `gather` fehlgeschlagene Ergebnisse durch `None` ersetzt
