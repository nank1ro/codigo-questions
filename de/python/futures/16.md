# --description--

Die Bausteine lassen sich natürlich kombinieren. Um viele Operationen gleichzeitig auszuführen, jede mit eigenem Zeitlimit, verpacke jede einzelne in eine kleine Coroutine, die `wait_for` anwendet und den `TimeoutError` abfängt, und `gather` die Wrapper:
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])` gibt dann für jeden Job, der sich rechtzeitig beendet hat, einen Wert zurück und `None` für jeden anderen, in der ursprünglichen Reihenfolge, und die gesamte Gruppe dauert höchstens etwa `limit` Sekunden.

# --instructions--

Schreibe eine Coroutine-Funktion `job(delay)`, die `delay` Sekunden wartet und `delay` zurückgibt, und eine Coroutine-Funktion `run_jobs(delays, limit)`, die für jedes Delay einen `job` **gleichzeitig** ausführt, jeden mit `asyncio.wait_for` auf `limit` Sekunden begrenzt, und eine Liste zurückgibt, die das Delay jedes Jobs enthält, der sich rechtzeitig beendet hat, und `None` für jeden Job, der das Timeout überschritten hat, in der ursprünglichen Reihenfolge

```python
    def test_2(self):
        self.assertEqual(asyncio.run(run_jobs([0.01, 0.06, 0.02], 0.04)), [0.01, None, 0.02], "--err-t2--")
```

Fünf Jobs von je `0.02` Sekunden mit einer Grenze von `0.05` müssen sich alle beenden und gleichzeitig ausgeführt werden und dabei deutlich unter `0.1` Sekunden dauern

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(run_jobs([0.02] * 5, 0.05))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [0.02] * 5, "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
