# --instructions--

Schreibe einen Decorator `memoize` für Funktionen mit einem Argument: Er muss jedes Ergebnis in einem Wörterbuch innerhalb der Closure speichern, sodass ein erneuter Aufruf der dekorierten Funktion mit demselben Argument das gespeicherte Ergebnis zurückgibt, ohne die ursprüngliche Funktion aufzurufen

# --asserts--

Die dekorierte Funktion muss dieselben Ergebnisse wie das Original zurückgeben

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

Ein wiederholter Aufruf darf die ursprüngliche Funktion nicht erneut ausführen

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

Jede dekorierte Funktion muss ihren eigenen Cache haben

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
