# --instructions--

Ordne die Elemente, um nur die Wörter mit mehr als drei Buchstaben zu behalten, sie in Großbuchstaben umzuwandeln und nach Länge sortiert auszugeben

# --solutions--

```python
words = ["pear", "fig", "banana", "kiwi"]
long_words = filter(lambda w: len(w) > 3, words)
shouted = map(str.upper, long_words)
print(sorted(shouted, key=len))
```

# --output--

['PEAR', 'KIWI', 'BANANA']
