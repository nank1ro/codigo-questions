# --instructions--

Schreibe eine Funktion `is_vowel(ch)`, die `True` zurückgibt, wenn `ch` genau ein Zeichen ist und dieses Zeichen ein Vokal (`a`, `e`, `i`, `o`, `u`) in Klein- oder Großschreibung ist, und `False` für jede andere Zeichenkette, einschließlich der leeren Zeichenkette

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` und `is_vowel("E")` müssen `True` zurückgeben

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` und `is_vowel("y")` müssen `False` zurückgeben

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Zeichenketten, die nicht aus einem einzelnen Zeichen bestehen, müssen `False` zurückgeben

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

# --solutions--

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
