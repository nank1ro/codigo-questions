# --instructions--

Was gibt dieser Code aus?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, weil `c` ein anderer Name für dieselbe Liste wie `a` ist, daher verändert das Anhängen über `c` `a` und macht es verschieden von `b`
- `True True [1, 2]`, weil `c = a` die Liste kopiert, daher bleibt `a` unverändert
- `True False [1, 2, 3]`, weil `is` Werte vergleicht und `==` Identität vergleicht
- `False False [1, 2, 3]`, weil `append` eine neue Liste erzeugt, daher verweist `c` nicht mehr auf `a`
