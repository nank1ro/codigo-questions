# --description--

Weil `if value:` den Wahrheitswert bereits anwendet, ist ein Vergleich mit `== True` oder `== False` unnötig und kann sogar falsch sein: `2 == True` ist `False`, obwohl `2` truthy ist. Prüfe den Wert selbst:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Schreibe eine Funktion `count_truthy(values)`, die zurückgibt, wie viele Elemente der Liste `values` truthy sind

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
