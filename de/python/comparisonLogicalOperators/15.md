# --instructions--

Ordne die Elemente, um das `users`-Wörterbuch und die `can_login`-Funktion zu definieren, die `name in users` verwendet, um die Suche abzusichern, und gib dann das Ergebnis für Ada mit dem richtigen Passwort und für Grace aus, die nicht registriert ist, mit der Ausgabe `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
