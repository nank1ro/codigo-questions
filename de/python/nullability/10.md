# --description--

Wenn `0` oder `""` erhalten bleiben und nur `None` ersetzt werden soll, braucht der Fallback eine explizite `is None`-Prüfung. Die kompakte Form ist der **bedingte Ausdruck**, `a if condition else b`, der zu `a` auswertet, wenn die Bedingung wahr ist, und sonst zu `b`:
```python
timeout = 0
seconds = timeout if timeout is not None else 30
print(seconds)  # 0, not 30
```

Schreibe eine Funktion `port_or_default`, die `port` nimmt und ihn zurückgibt, wenn er nicht `None` ist, und sonst `8080`; der Wert `0` muss unverändert zurückgegeben werden

Du musst mit `is not None` oder `is None` prüfen

```json
{

  "shouldMatch": true

```

`port_or_default(3000)` muss `3000` zurückgeben

```python
    def test_1(self):
        self.assertEqual(port_or_default(3000), 3000, "--err-t1--")
```

`port_or_default(None)` muss `8080` zurückgeben

```python
    def test_2(self):
        self.assertEqual(port_or_default(None), 8080, "--err-t2--")
```

`port_or_default(0)` muss `0` zurückgeben

```python
    def test_3(self):
        self.assertEqual(port_or_default(0), 0, "--err-t3--")
```
