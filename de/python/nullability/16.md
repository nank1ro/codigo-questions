# --instructions--

Schreibe eine Funktion `get_path`, die ein Wörterbuch `data`, eine Liste von `keys` und ein optionales `default` (`None`, wenn nicht angegeben) nimmt; sie muss den Schlüsseln Ebene für Ebene folgen und den gefundenen Wert zurückgeben, oder `default`, wenn ein Schlüssel fehlt, `None` enthält oder wenn ein Schritt kein Wörterbuch ist; Werte wie `0` und `""` müssen unverändert zurückgegeben werden

# --asserts--

Der Standardwert von `default` muss `None` sein

```json

  "shouldMatch": true

```

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` muss `"Rome"` zurückgeben

```python
    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")
        self.assertEqual(get_path(data, ["address"]), {"city": "Rome"}, "--err-t1--")
```

Ein fehlender, `None`- oder Nicht-Wörterbuch-Schritt muss den Standardwert liefern

```python
    def test_2(self):
        data = {"address": None, "name": "Ada"}
        self.assertIsNone(get_path(data, ["address", "city"]), "--err-t2--")
        self.assertEqual(get_path(data, ["phone", "home"], "n/a"), "n/a", "--err-t2--")
        self.assertEqual(get_path(data, ["name", "first"], "n/a"), "n/a", "--err-t2--")
```

`0` und `""` müssen unverändert zurückgegeben werden

```python
    def test_3(self):
        data = {"stats": {"count": 0, "note": ""}}
        self.assertEqual(get_path(data, ["stats", "count"], -1), 0, "--err-t3--")
        self.assertEqual(get_path(data, ["stats", "note"], "none"), "", "--err-t3--")
```

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
