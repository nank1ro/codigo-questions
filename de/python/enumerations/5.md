# --description--

Du erhältst einen Member ausgehend von seinem **Wert**, indem du die Klasse wie eine Funktion aufrufst, oder ausgehend von seinem **Namen** mit eckigen Klammern:
```python
print(Color(2))        # Color.GREEN
print(Color["BLUE"])   # Color.BLUE
```
Beides ist praktisch, wenn der Wert oder der Name von außerhalb des Programms kommt, etwa aus einer Datei oder einer Benutzereingabe.
Wenn nichts übereinstimmt, löst `Color(9)` einen `ValueError` aus und `Color["PINK"]` einen `KeyError`.

# --instructions--

Speichere in `by_value` den Member von `Status`, dessen Wert `code` ist, indem du `Status(...)` aufrufst, und in `by_name` den Member, dessen Name `label` ist, mit `Status[...]`

```json
{
  "regex": "Status\\[\\s*label\\s*\\]",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`by_value` muss `Status.DONE` sein

```python
    def test_1(self):
        self.assertIs(by_value, Status.DONE, "--err-t1--")
```

`by_name` muss `Status.FAILED` sein

```python
    def test_2(self):
        self.assertIs(by_name, Status.FAILED, "--err-t2--")
```
