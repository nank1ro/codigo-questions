# --description--

Es gibt einen dritten Einstiegspunkt, `re.fullmatch`, der nur dann Erfolg hat, wenn das Muster den **ganzen** Text vom ersten bis zum letzten Zeichen abdeckt. Es ist das richtige Werkzeug zur Validierung:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

Die drei Funktionen unterscheiden sich also nur darin, wo das Muster sitzen darf: `re.match` am Anfang des Texts, `re.search` irgendwo im Text und `re.fullmatch` über den gesamten Text.

# --instructions--

Was gibt dieser Code aus?
```python
import re

print(bool(re.match(r"\d+", "12abc")), bool(re.search(r"\d+", "12abc")), bool(re.fullmatch(r"\d+", "12abc")))
```

# --answers--

- `True True False`, weil die Ziffern am Anfang und im Text drin sind, aber nicht den ganzen Text abdecken
- `True True True`, weil alle drei Funktionen Erfolg haben, sobald das Muster irgendwo gefunden wird
- `False True False`, weil `re.match` braucht, dass das Muster den ganzen Text abdeckt
- `True False False`, weil `re.search` erst nach dem ersten Zeichen sucht
