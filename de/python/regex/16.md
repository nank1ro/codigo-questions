# --instructions--

Definiere ein kompiliertes Muster `PAIR_RE`, das auf eine Einstellung passt, die als ein oder mehr Buchstaben, ein `=`-Zeichen und ein oder mehr Ziffern geschrieben ist, mit den beiden Teilen in den benannten Gruppen `key` und `value`; dann schreibe eine Funktion `parse_settings(text)`, die ein Wörterbuch zurückgibt, das jeden im Text gefundenen Schlüssel auf seinen Wert als `int` abbildet

# --asserts--

`PAIR_RE` muss ein kompiliertes Muster mit den benannten Gruppen `key` und `value` sein

```python
    def test_1(self):
        self.assertIsInstance(PAIR_RE, re.Pattern, "--err-t1--")
        self.assertEqual(PAIR_RE.search("width=10").groupdict(), {"key": "width", "value": "10"}, "--err-t1--")
```

`parse_settings` muss jede Einstellung mit einem Ganzzahlwert zurückgeben

```python
    def test_2(self):
        self.assertEqual(parse_settings("width=10 height=20"), {"width": 10, "height": 20}, "--err-t2--")
        self.assertEqual(parse_settings("size=3; depth=7"), {"size": 3, "depth": 7}, "--err-t2--")
```

Text ohne Einstellungen muss ein leeres Wörterbuch zurückgeben

```python
    def test_3(self):
        self.assertEqual(parse_settings("nothing to read"), {}, "--err-t3--")
        self.assertEqual(parse_settings(""), {}, "--err-t3--")
```

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
