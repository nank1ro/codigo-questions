# --description--

Der Code-Block einer `if`-Anweisung ist die Gruppe der darunter eingerückten Zeilen, die durch diese Einrückung vom Rest des Programms abgegrenzt wird.

# --instructions--

Was ist ein Code-Block einer if-Anweisung?

# --answers--

- Code, der ausgeführt wird, wenn die Bedingung False ist
- Code, der bestimmt, ob ein Code ausgeführt werden soll
- Ein Vergleichs-Schlüsselwort
