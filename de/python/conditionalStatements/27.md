# --description--

Nur das eingerückte `print` direkt nach dem `if` gehört zu seinem Block; eine Zeile, die auf derselben Einrückungsebene wie das `if` selbst steht, gehört nicht dazu.

# --instructions--

Welche print-Anweisung ist Teil des Code-Blocks der Anweisung?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)
