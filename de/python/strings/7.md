# --description--

Der `in`-Operator prüft, ob eine Zeichenkette eine andere **enthält**.
Er gibt `True` oder `False` zurück und passt daher gut in ein `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` prüft das Gegenteil.
