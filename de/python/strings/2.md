# --description--

Die eingebaute Funktion `len()` gibt die **Länge** einer Zeichenkette zurück, also wie viele Zeichen sie enthält.
Leerzeichen und Satzzeichen zählen ebenfalls als Zeichen:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
