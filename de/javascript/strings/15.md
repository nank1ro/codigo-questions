# --instructions--

Sortiere die Zeilen, um eine Kassenbon-Zeile auszugeben: `item`, aufgefüllt mit Punkten auf 8 Zeichen, gefolgt vom Preis rechtsbündig in 6 Zeichen

# --answers--

```javascript
let item = "Tea";
```

```javascript
let row = item.padEnd(8, ".");
```

```javascript
row = row + "2.50".padStart(6);
```

```javascript
console.log(row);
```
