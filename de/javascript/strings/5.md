# --description--

Die Methode `indexOf()` gibt den Index zurück, an dem ein Textstück **zum ersten Mal** im String vorkommt.
Wird der Text nicht gefunden, gibt sie `-1` zurück:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
