# --description--

Da eine Funktion ein Wert ist, kann eine Pfeilfunktion **eine andere Pfeilfunktion zurückgeben**. Zwei Pfeilfunktionen zu verketten ist eine kompakte Art, eine Funktion zu schreiben, die Funktionen erzeugt:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
Lies sie von links nach rechts: `makeAdder` nimmt `amount` entgegen und gibt `(n) => n + amount` zurück, eine Pfeilfunktion, die `amount` über eine Closure einfängt. `makeAdder(1)(5)` ruft die zurückgegebene Funktion sofort auf.

`makeMultiplier(3)` muss eine Funktion zurückgeben.

```javascript
tryCatch(typeof makeMultiplier(3) === "function");
```

`makeMultiplier(3)(4)` muss `12` zurückgeben.

```javascript
tryCatch(makeMultiplier(3)(4) === 12);
```

Die Funktion, die `makeMultiplier(2)` zurückgibt, muss beim Aufruf mit `10` den Wert `20` zurückgeben.

```javascript
tryCatch((() => { const twice = makeMultiplier(2); return twice(10) === 20; })());
```

Zwei Multiplikatoren müssen unabhängig sein: `makeMultiplier(5)(2)` muss `10` sein und `makeMultiplier(0)(2)` muss `0` sein.

```javascript
tryCatch(makeMultiplier(5)(2) === 10 && makeMultiplier(0)(2) === 0);
```

Sowohl `makeMultiplier` als auch die zurückgegebene Funktion müssen Pfeilfunktionen sein.

