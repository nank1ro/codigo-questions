# --description--

Auch Objektmuster haben ein Rest-Element, und dort sammelt es jeden Schlüssel, den das Muster nicht erwähnt hat, in einem neuen Objekt:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// gibt { name: 'Ada', city: 'London' } aus
```
Das ist der kürzeste Weg, eine Kopie eines Objekts ohne einen seiner Schlüssel zu bauen: Das Original wird nie angetastet, und das Rest-Objekt ist ein frisches, das die übrigen Werte enthält.

# --instructions--

Schreibe eine Funktion `withoutPassword`, die eine Kopie des gegebenen Objekts ohne seinen `password`-Schlüssel zurückgibt und das ursprüngliche Objekt unverändert lässt

# --asserts--

Der `password`-Schlüssel muss verschwunden sein.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

Die anderen Schlüssel müssen erhalten bleiben.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

Jeder andere Schlüssel muss erhalten bleiben.

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

Das ursprüngliche Objekt darf nicht geändert werden.

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

Ein Objekt mit nur einem `password`-Schlüssel muss ein leeres Objekt liefern.

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
