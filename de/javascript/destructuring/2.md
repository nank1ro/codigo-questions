# --description--

Destrukturierung ist am nützlichsten genau dort, wo ein Array ankommt: als Funktionsargument oder als Ergebnis eines Aufrufs. Statt das Array aufzuheben und überall in ihm zu indizieren, packst du es einmal aus und gibst den Teilen richtige Namen:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// gibt 5 aus
```
Im ursprünglichen Array wird nichts kopiert oder geändert, das Muster liest nur daraus.

# --asserts--

`label(["Ada", 90])` muss `"Ada: 90"` zurückgeben.

```javascript

```

`label(["Bob", 0])` muss `"Bob: 0"` zurückgeben.

```javascript
tryCatch(label(["Bob", 0]) === "Bob: 0");
```

Eine negative Punktzahl muss unverändert bleiben.

```javascript
tryCatch(label(["Cy", -3]) === "Cy: -3");
```

`label(["Dee", 100])` muss `"Dee: 100"` zurückgeben.

```javascript
tryCatch(label(["Dee", 100]) === "Dee: 100");
```

Überzählige Elemente müssen ignoriert werden.

```javascript
tryCatch(label(["Eve", 55, "extra"]) === "Eve: 55");
```
