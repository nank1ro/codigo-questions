# --description--

Alles bisher Gesehene gehört zu einer einzigen Syntax, daher lassen sich die Teile frei kombinieren: Ein Objektmuster kann ein weiteres Objektmuster verschachteln, das einen umbenannten Schlüssel mit Standardwert enthalten kann, neben einem Arraymuster, das mit einem Rest-Element endet. Eine Zeile beschreibt dann die ganze Form, die eine Funktion erwartet:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// prints Post [js] +2
```
Halte es lesbar: Ein Muster, das nicht mehr auf ein paar Zeilen passt, ist meist ein Zeichen dafür, dass die Funktion zu viel verlangt.

# --instructions--

Schreibe eine Funktion `report`, die ein Objekt mit einer `id`, einem `customer`-Objekt mit einem `name` (standardmäßig `"guest"`) und einem nicht leeren `items`-Array entgegennimmt und die Zeichenkette `"#id name: firstItem +n"` zurückgibt, wobei `n` angibt, wie viele Elemente nach dem ersten übrig bleiben

# --asserts--

Drei Elemente müssen zwei übrig lassen.

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

Ein einzelnes Element muss keines übrig lassen.

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

Ein Kunde ohne Name muss zu `guest` werden.

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

Ein explizit `undefined` Name muss ebenfalls zu `guest` werden.

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

Vier Elemente müssen drei übrig lassen.

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
