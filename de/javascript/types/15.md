# --description--

Da `typeof` für Arrays, Objekte und `null` `"object"` antwortet, braucht man zwei zusätzliche Prüfungen, um sie auseinanderzuhalten.
`Array.isArray(value)` ist `true` nur für Arrays:
```javascript
console.log(Array.isArray([1, 2]), Array.isArray({}));
// prints true false
```
Für `null` vergleiche direkt, `value === null`. Kombiniert ergibt das ein vollständiges Bild jedes Werts:
```javascript
function kind(value) {
  if (value === null) return "null";
  if (Array.isArray(value)) return "array";
  return typeof value;
}
```
Prüfe zuerst auf `null` und Arrays, weil das einfache `typeof` sie nicht unterscheiden kann.

# --asserts--

`typeName(null)` muss `"null"` zurückgeben.

```javascript
tryCatch(typeName(null) === "null");
```

`typeName([1, 2])` und `typeName([])` müssen `"array"` zurückgeben.

```javascript
tryCatch(typeName([1, 2]) === "array" && typeName([]) === "array");
```

`typeName({})` muss `"object"` zurückgeben.

```javascript
tryCatch(typeName({}) === "object");
```

`typeName(42)`, `typeName("a")` und `typeName(true)` müssen `"number"`, `"string"` und `"boolean"` zurückgeben.

```javascript
tryCatch(typeName(42) === "number" && typeName("a") === "string" && typeName(true) === "boolean");
```

`typeName(undefined)`, `typeName(10n)` und `typeName(Symbol())` müssen `"undefined"`, `"bigint"` und `"symbol"` zurückgeben.

```javascript
tryCatch(typeName(undefined) === "undefined" && typeName(10n) === "bigint" && typeName(Symbol()) === "symbol");
```

`typeName(function () {})` muss `"function"` zurückgeben.

```javascript
tryCatch(typeName(function () {}) === "function");
```

Die Funktion muss `Array.isArray` verwenden.

```javascript
tryCatch(/Array\.isArray\(/.test(typeName.toString()));
```
