# --description--

Wenn JavaScript einen Boolean benötigt, zum Beispiel in einer `if`-Bedingung oder in `Boolean(value)`, wandelt es den Wert um. Nur acht Werte werden zu `false`; sie werden **falsy** genannt:
`false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` und `NaN`.
**Alles andere ist truthy**, einschließlich einiger Werte, die leer aussehen:
```javascript
console.log(Boolean(0), Boolean(""), Boolean(NaN));
// prints false false false
console.log(Boolean("0"), Boolean("false"), Boolean([]), Boolean({}));
// prints true true true true
```
`"0"` ist ein nicht-leerer String, also ist er truthy; ein leeres Array ist ein Objekt, also ist es auch truthy.

# --asserts--

`countTruthy([1, "a", true])` muss `3` zurückgeben.

```javascript
tryCatch(countTruthy([1, "a", true]) === 3);
```

`countTruthy([0, "", null, undefined, NaN, false])` muss `0` zurückgeben.

```javascript
tryCatch(countTruthy([0, "", null, undefined, NaN, false]) === 0);
```

`countTruthy(["0", "false", [], {}])` muss `4` zurückgeben.

```javascript
tryCatch(countTruthy(["0", "false", [], {}]) === 4);
```

`countTruthy([0n, -0, " "])` muss `1` zurückgeben, weil nur der Leerzeichen-String truthy ist.

```javascript
tryCatch(countTruthy([0n, -0, " "]) === 1);
```

`countTruthy([])` muss `0` zurückgeben.

```javascript
tryCatch(countTruthy([]) === 0);
```

# --solutions--

```javascript
function countTruthy(values) {
  let count = 0;
  for (const value of values) {
    if (value) {
      count++;
    }
  }
  return count;
}
```
