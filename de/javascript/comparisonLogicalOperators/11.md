# --description--

`!=` wandelt vor dem Vergleich um, genau wie `==`, weshalb `"5" != 5` `false` ergibt. Sein striktes Gegenstück `!==` behandelt eine Zeichenkette und eine Zahl als unterschiedlich, egal was sie enthalten.
```javascript
console.log("5" !== 5); // true
```
