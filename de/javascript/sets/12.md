# --instructions--

Ordne die Zeilen, um ein Array mit den Namen aus `all` auszugeben, die nicht in `done` sind.
Deklariere `all` vor `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
