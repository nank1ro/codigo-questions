# --description--

Auch Methoden können privat sein. Stelle dem Namen ein `#` voran und die Methode verschwindet von der öffentlichen Oberfläche der Klasse, während sie aus jeder anderen Methode heraus weiterhin mit `this.#name(...)` aufrufbar bleibt:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// prints $7
```
So hältst du Hilfsschritte aus der API heraus: Der Aufrufer sieht `print`, nicht das Formatierungsdetail dahinter. Private Felder und private Methoden geben einer Klasse zusammen ein klares Innen und Außen.

# --asserts--

Ein neuer Punktestand muss bei `0` starten.

```javascript
tryCatch(new Score().total === 0);
```

Positive Werte müssen hinzugefügt werden.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

Negative Werte müssen ignoriert werden.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

Null muss ignoriert werden.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

Die Punkte müssen privat sein, daher darf die Instanz keine öffentliche Eigenschaft haben.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
