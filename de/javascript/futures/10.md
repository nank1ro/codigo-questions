# --description--

Eine häufige Verwendung von `try` / `catch` um `await` ist es, einen Fehler durch einen sinnvollen Standardwert zu ersetzen, sodass der Aufrufer sich nie mit dem Fehler befassen muss:
```javascript
async function sizeOf(path) {
  try {
    return await measure(path);
  } catch (error) {
    return 0;
  }
}
```
Behalte das `await` vor `measure(path)` bei, auch wenn der Wert sofort zurückgegeben wird. Ohne es verlässt das Promise die Funktion, ohne je durch den `try`-Block zu gehen, und eine Ablehnung würde das `catch` umgehen.

# --instructions--

Die Funktion `parseLater` gibt ein Promise zurück, das mit der in `text` geschriebenen Zahl erfüllt ist, oder abgelehnt wird, wenn `text` keine Zahl ist. Schreibe eine `async`-Funktion `safeParse`, die diese Zahl zurückgibt, oder `-1`, wenn `parseLater` fehlschlägt. Verwende `try` und `catch`

`await safeParse("12")` muss `12` sein.

```javascript
(async () => {
  tryCatch((await safeParse("12")) === 12);
})().catch(() => tryCatch(false));
```

`await safeParse("-7.5")` muss `-7.5` sein.

```javascript
(async () => {
  tryCatch((await safeParse("-7.5")) === -7.5);
})().catch(() => tryCatch(false));
```

`await safeParse("abc")` muss `-1` sein.

```javascript
(async () => {
  tryCatch((await safeParse("abc")) === -1);
})().catch(() => tryCatch(false));
```

`safeParse("oops")` muss erfüllt sein, niemals abgelehnt.

```javascript
(async () => {
  let ok = false;
  await safeParse("oops").then(() => { ok = true; }, () => { ok = false; });
  tryCatch(ok);
})().catch(() => tryCatch(false));
```

function parseLater(text) {
  return new Promise((resolve, reject) => {
    const value = Number(text);
    if (Number.isNaN(value)) {
      reject(new Error(`not a number: ${text}`));
    } else {
      resolve(value);
    }
  });
}

async function safeParse(text) {
  try {
    return await parseLater(text);
  } catch (error) {
    return -1;
  }
}
