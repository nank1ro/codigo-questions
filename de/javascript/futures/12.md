# --description--

`Promise.all` funktioniert mit einem Array beliebiger Länge, auch mit einem leeren: Das Abwarten von `Promise.all([])` liefert sofort ein leeres Array zurück. So kann man gefahrlos eine zur Laufzeit erstellte Liste übergeben, ohne einen Sonderfall für „nichts zu warten“ zu brauchen.
```javascript
const values = await Promise.all(items);
console.log(values.length === items.length);
// prints true
```
Das zurückgegebene Array hat immer genau so viele Einträge wie das übergebene Array, an denselben Positionen, sodass man darüber iterieren kann wie über jedes andere Array.

# --asserts--

`await sumAll([])` muss `0` sein.

```javascript
(async () => {
  tryCatch((await sumAll([])) === 0);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)])` muss `6` sein.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)];
  tryCatch((await sumAll(promises)) === 6);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(-4), Promise.resolve(4)])` muss `0` sein.

```javascript
(async () => {
  const promises = [Promise.resolve(-4), Promise.resolve(4)];
  tryCatch((await sumAll(promises)) === 0);
})().catch(() => tryCatch(false));
```

`sumAll` muss auch mit Promises funktionieren, die unterschiedlich lange dauern.

```javascript
(async () => {
  const later = (n, ms) => new Promise((resolve) => setTimeout(() => resolve(n), ms));
  tryCatch((await sumAll([later(10, 30), later(5, 5)])) === 15);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function sumAll(promises) {
  const values = await Promise.all(promises);
  let total = 0;
  for (const value of values) {
    total += value;
  }
  return total;
}
```
