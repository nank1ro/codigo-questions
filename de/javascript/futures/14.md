# --description--

`Promise.all` gibt auf, sobald ein Promise abgelehnt wird. Wenn du trotzdem jedes Ergebnis willst, verwende **`Promise.allSettled(promises)`**: Es wird nie abgelehnt, sondern mit einem kleinen Objekt je Promise erfüllt, in derselben Reihenfolge:

- `{ status: "fulfilled", value: ... }` für die erfolgreichen;
- `{ status: "rejected", reason: ... }` für die fehlgeschlagenen.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
Lies `value` nur, wenn `status` `"fulfilled"` ist, und `reason` nur, wenn es `"rejected"` ist: Die andere Eigenschaft fehlt schlicht.

# --asserts--

`await countFulfilled([])` muss `0` sein.

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` muss `2` sein.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Mit einem abgelehnten Promise von dreien muss das Ergebnis `2` sein.

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Wenn jedes Promise abgelehnt wird, muss das Ergebnis `0` sein, und `countFulfilled` darf nicht abgelehnt werden.

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
