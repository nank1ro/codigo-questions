# --description--

Setzt man die letzten Bausteine zusammen, entsteht ein kleines Werkzeug, das in fast jeder echten Anwendung verwendet wird: eine Frist. Baue ein Promise, das nach `ms` Millisekunden abgelehnt wird, lies es gegen die eigentliche Arbeit, und welches auch immer zuerst settled, bestimmt das Ergebnis:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
Ein Promise aus einer `async`-Funktion zurückzugeben ist in Ordnung: Das Promise, das die Funktion zurückgibt, folgt ihm, sodass der Aufrufer den endgültigen Wert abwartet und kein Promise in einem Promise.

# --instructions--

Schreibe eine `async`-Funktion `withTimeout`, die ein Promise und eine Anzahl von Millisekunden `ms` entgegennimmt und das Ergebnis des Promises zurückgibt, wenn es innerhalb von `ms` settled, oder andernfalls mit `new Error("timeout")` abgelehnt wird. Verwende `Promise.race`

# --asserts--

Ein bereits erfülltes Promise muss seinen Wert liefern.

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

Ein vor der Frist abgelehntes Promise muss seinen eigenen Fehler behalten.

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

Ein schnell genug vorhandenes Promise muss seinen Wert liefern, kein Promise.

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

Ein zu langsam vorhandenes Promise muss mit der Meldung `"timeout"` abgelehnt werden.

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```

```javascript
async function withTimeout(promise, ms) {
  const timer = new Promise((resolve, reject) => {
    setTimeout(() => reject(new Error("timeout")), ms);
  });
  return Promise.race([promise, timer]);
}
```
