# --description--

Closures erlauben es einer zurückgegebenen Funktion, zwischen den Aufrufen **privaten Zustand** zu behalten. Ein klassischer so gebauter Helfer ist `once(fn)`: Er gibt eine Funktion zurück, die `fn` nur beim ersten Aufruf ausführt, sich das Ergebnis merkt und bei jedem weiteren Aufruf dasselbe Ergebnis zurückgibt, ohne `fn` erneut auszuführen:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
Der Wrapper braucht zwei private Variablen: ob `fn` schon gelaufen ist, und das gespeicherte Ergebnis. Beide leben in der Closure, für die Außenwelt unsichtbar. Um alle Argumente des Wrappers an `fn` weiterzureichen, deklariere den Wrapper mit einem Rest-Parameter `(...args)` und rufe `fn(...args)` auf.

# --asserts--

Die umhüllte Funktion muss `fn` nur einmal ausführen und weiterhin dessen Ergebnis zurückgeben.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

Die Argumente des ersten Aufrufs müssen an `fn` weitergereicht werden: `once((a, b) => a + b)(2, 3)` muss `5` zurückgeben.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

Spätere Aufrufe müssen das gespeicherte Ergebnis zurückgeben, auch mit anderen Argumenten.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` darf auch dann nicht erneut laufen, wenn sein Ergebnis `undefined` ist.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

Zwei Wrapper derselben Funktion müssen unabhängig sein.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` muss eine Funktion zurückgeben.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
