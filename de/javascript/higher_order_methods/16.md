# --description--

Alles kommt in `groupBy(items, keyFn)` zusammen: eine Funktion höherer Ordnung, die einen Callback erhält, der den **Gruppenschlüssel** jedes Elements bestimmt, und ein Objekt zurückgibt, das jedem Schlüssel das Array der Elemente mit diesem Schlüssel zuordnet. `reduce` mit einem Objekt-Akkumulator erledigt die ganze Arbeit:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Berechne für jedes Element den Schlüssel, erzeuge das Array für diesen Schlüssel, falls es noch nicht existiert (`acc[key] ?? []`), füge das Element hinzu und gib den Akkumulator zurück. Da der Aufrufer `keyFn` wählt, gruppiert dieselbe Funktion Wörter nach Anfangsbuchstabe, Personen nach Stadt oder Zahlen nach Parität.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` muss `{ h: ["hi", "hey"], y: ["yo"] }` zurückgeben.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

`[1, 2, 3, 4]` nach Parität zu gruppieren muss `{ odd: [1, 3], even: [2, 4] }` zurückgeben.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Personen nach `city` zu gruppieren muss die ganzen Objekte in der ursprünglichen Reihenfolge behalten.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` muss ein leeres Objekt zurückgeben.

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

Das ursprüngliche Array darf nicht verändert werden.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

Die Funktion muss `reduce` benutzen.

```javascript
tryCatch(/\.reduce\(/.test(groupBy.toString()));
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
