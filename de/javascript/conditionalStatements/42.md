# --description--

Ein Block kann eine beliebige Anzahl von Anweisungen enthalten, aber auch keine: `if (true) {}` ist gültiges JavaScript, das einfach nichts tut.

# --instructions--

Wie viele Codezeilen können wir in einem if-Anweisungsblock schreiben?

# --answers--

- So viele wie wir wollen
- Eins
- Drei
- Nicht mehr als zwei
