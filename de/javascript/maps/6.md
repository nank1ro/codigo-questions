# --description--

Wenn du nur eine Seite der Paare brauchst, verwende in der Schleife `keys()` oder `values()` statt `entries()`:
```javascript
let prices = new Map();
prices.set("tea", 2);
prices.set("cake", 4);
for (const name of prices.keys()) {
  console.log(name);
}
// prints tea
// prints cake
for (const price of prices.values()) {
  console.log(price);
}
// prints 2
// prints 4
```


```javascript

function total(prices) {
```

```javascript
    sum += price;
  }

}
```
