# --description--

Maps haben keine Array-Methoden wie `sort()` oder `filter()`. Um sie zu nutzen, wandle die Map (oder ihre Schlüssel oder Werte) mit `Array.from()` oder dem Spread-Operator `...` in ein Array um:
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
Die umgekehrte Umwandlung, `Object.fromEntries(ages)`, verwandelt eine Map wieder in ein einfaches Objekt.

# --asserts--

`sortedKeys` einer Map mit den Schlüsseln `"pear"`, `"apple"` und `"kiwi"` muss `["apple", "kiwi", "pear"]` zurückgeben.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

`sortedKeys` einer leeren Map muss `[]` zurückgeben.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
