# --description--

Ein zurückgegebenes Lambda kann eine `var` erfassen, die innerhalb der Funktion deklariert wurde. Diese Variable lebt weiter, nachdem die Funktion zurückgekehrt ist, und nur das Lambda kann auf sie zugreifen: Sie ist privater Zustand.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Jeder Aufruf von `makeGreeter()` deklariert ein neues `calls`, daher zählen zwei Greeter unabhängig voneinander.

# --instructions--

Schreiben Sie eine Funktion `makeCounter(): () -> Int`, die ein Lambda ohne Parameter zurückgibt. Jeder Aufruf des Lambdas erhöht einen Zähler, der bei `0` beginnt, und gibt den neuen Wert zurück. Zähler, die von unterschiedlichen Aufrufen von `makeCounter` zurückgegeben werden, müssen unabhängig voneinander sein.

Beispiel: `val next = makeCounter()`, dann gibt `next()` `1` zurück und `next()` gibt `2` zurück.

Der erste Aufruf eines Zählers muss `1` zurückgeben

```kotlin

    tryCatch(first() == 1)
```

Der zweite Aufruf desselben Zählers muss `2` zurückgeben

```kotlin
    tryCatch(first() == 2)
```

Nach drei Aufrufen muss ein Zähler `3` zurückgeben

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

Zwei Zähler müssen unabhängig voneinander sein

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
