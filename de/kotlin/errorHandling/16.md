# --description--

Wo das `try` steht, entscheidet, wie viel Arbeit ein einziger schlechter Wert vernichtet. Umschließen Sie die **gesamte Schleife**, bricht der erste Fehler den Rest des Stapels ab; umschließen Sie den **Schleifenkörper**, geht nur dieses eine Element verloren:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // diesen Wert überspringen
    }
}
println(total) // 8
```
Das lässt sich natürlich mit einer validierenden Funktion kombinieren, die auslöst: Die Funktion formuliert eine Regel und weist alles zurück, das sie verletzt, und die Schleife entscheidet, dass eine Zurückweisung nur ein Element kostet.

# --instructions--

Schreiben Sie zwei Funktionen.

`validate(text: String): Int` muss die in `text` enthaltene Zahl zurückgeben oder eine `IllegalArgumentException` mit der Meldung `not a number: ` gefolgt vom Text auslösen.

`sumValid(values: List<String>): Int` muss die Werte addieren, die `validate` akzeptiert, und die überspringen, bei denen es auslöst.

Beispiel für einen Funktionsaufruf:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// gibt 4 aus
```

`validate("7")` muss `7` zurückgeben

```kotlin

```

`validate("x")` muss eine `IllegalArgumentException` mit der Meldung `not a number: x` auslösen

```kotlin
    var message = ""
    try { validate("x") } catch (e: IllegalArgumentException) { message = e.message ?: "" }
    tryCatch(message == "not a number: x")
```

`sumValid(listOf("1", "2", "3"))` muss `6` zurückgeben

```kotlin
    tryCatch(sumValid(listOf("1", "2", "3")) == 6)
```

Ein schlechter Wert darf die anderen nicht aufhalten

```kotlin
    tryCatch(sumValid(listOf("1", "x", "3")) == 4)
```

`sumValid(listOf("a", "b"))` muss `0` zurückgeben

```kotlin
    tryCatch(sumValid(listOf("a", "b")) == 0)
```

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // diesen Wert überspringen
        }
    }
    return total
}
```
