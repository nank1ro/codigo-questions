# --description--

Ein `FIXME` ist etwas anderes als ein `TODO`: der Code existiert bereits, aber es ist bekannt, dass er falsch ist. Ein gutes `FIXME` sagt, was der Fehler ist, und gibt — wenn möglich — ein Beispiel, das ihn zeigt, damit die nächste Person ihn schnell beheben kann. Wie beim `TODO` gilt: Lösche den Marker, sobald der Fehler behoben ist, aber behalte den Dokumentationskommentar, der weiterhin stimmt.

# --instructions--

Behebe den Fehler, den der `FIXME`-Kommentar in `average` beschreibt (setze die Klammern, damit die Summe vor der Division berechnet wird), und entferne danach den `FIXME`-Kommentar. Behalte den Dokumentationskommentar

# --asserts--

Der `FIXME`-Kommentar muss entfernt sein

```json
{
  "regex": "FIXME",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

Der Dokumentationskommentar muss erhalten bleiben

```json
{
  "regex": "Returns the average of",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`average(4, 6)` muss `5` zurückgeben

```kotlin
    tryCatch(average(4, 6) == 5)
```

`average(10, 20)` muss `15` zurückgeben

```kotlin
    tryCatch(average(10, 20) == 15)
```

`average(3, 4)` muss `3` zurückgeben

```kotlin
    tryCatch(average(3, 4) == 3)
```
