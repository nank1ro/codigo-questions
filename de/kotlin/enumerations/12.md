# --instructions--

Was passiert bei `enum class Size { SMALL, MEDIUM, LARGE }` mit dem folgenden Code?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Er kompiliert nicht: Ein `when`-Ausdruck über ein Enum muss jeden Eintrag abdecken oder einen `else`-Zweig hinzufügen
- Er kompiliert und gibt für `LARGE` `null` zurück
- Er kompiliert und wirft zur Laufzeit für `LARGE` eine Exception
- Er kompiliert und gibt für `LARGE` automatisch `"L"` zurück
