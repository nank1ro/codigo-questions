# --instructions--

Was macht `Color.valueOf("PURPLE")` bei `enum class Color { RED, GREEN, BLUE }`?

# --answers--

- Es wirft eine `IllegalArgumentException`, weil kein Eintrag `PURPLE` heißt
- Es gibt `null` zurück
- Es gibt `Color.RED`, den ersten Eintrag, zurück
- Es fügt dem Enum einen neuen Eintrag `PURPLE` hinzu
