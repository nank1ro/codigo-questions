# --description--

`replace(old, new)` gibt eine Kopie der Zeichenkette zurück, in der **jedes** Vorkommen von `old` durch `new` ersetzt wird:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
