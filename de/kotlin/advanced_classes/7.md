# --description--

Manchmal brauchst du genau **eine** Instanz von etwas: einen Logger, eine Registrierung, eine Anwendungskonfiguration. Ersetzt du `class` durch `object`, deklariert das dieses Singleton für dich:

```kotlin
object Registry {
    var size = 0
    fun add() {
        size++
    }
}

Registry.add()
println(Registry.size) // 1
```

Die Instanz wird erstellt, sobald du sie zum ersten Mal berührst, und du verwendest den Namen selbst: Es gibt keinen `Registry()`-Aufruf und keinen Konstruktor. Ein `object` kann Eigenschaften, Methoden und `init`-Blöcke enthalten, und es kann Interfaces implementieren oder eine Klasse erweitern.

# --instructions--

Deklariere ein `object` mit dem Namen `Logger` mit einer `var`-Eigenschaft `count` vom Typ `Int`, initialisiert mit `0`, und einer Methode `log(message: String): String`, die `1` zu `count` addiert und die Nachricht mit dem neuen Zählerstand als Präfix zurückgibt, in der Form `"[1] hello"`.

# --asserts--

`Logger.count` muss mit `0` beginnen

```kotlin
    tryCatch(Logger.count == 0)
```

Der erste Aufruf muss `"[1] hello"` zurückgeben

```kotlin
    tryCatch(Logger.log("hello") == "[1] hello")
```

Der zweite Aufruf muss `"[2] bye"` zurückgeben, weil der Zustand geteilt ist

```kotlin
    tryCatch(Logger.log("bye") == "[2] bye")
```

`Logger.count` muss nach den beiden Aufrufen `2` sein

```kotlin
    tryCatch(Logger.count == 2)
```
