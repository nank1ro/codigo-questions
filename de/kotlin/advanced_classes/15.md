# --instructions--

Was passiert mit diesem Code?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Es kompiliert nicht: Eine verschachtelte Klasse kann die äußeren Member nicht sehen, `Nested` muss `inner` sein
- Es kompiliert, und `show()` gibt den `name` der äußeren Instanz zurück
- Es kompiliert, und `show()` gibt immer einen leeren String zurück
- Es kompiliert nicht: Kotlin erlaubt keine Klasse innerhalb einer anderen Klasse
