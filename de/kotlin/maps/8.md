# --description--

Sie können mit `for` über eine Map iterieren und dabei jeden Eintrag in seinen Schlüssel und Wert destrukturieren:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Die Klammern `(name, age)` teilen jeden Eintrag in zwei Variablen auf. Die Einträge werden in der Reihenfolge besucht, in der sie eingefügt wurden.

# --instructions--

Schreiben Sie eine Funktion `report(stock: Map<String, Int>): List<String>`, die eine Liste mit einem String pro Eintrag zurückgibt, formatiert als `"item: count"`, in der Reihenfolge, in der die Einträge in der Map erscheinen.

Beispiel für einen Funktionsaufruf:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
