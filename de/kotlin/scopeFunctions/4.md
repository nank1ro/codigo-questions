# --description--

Innerhalb eines `let`-Blocks müssen Sie das Objekt nicht `it` nennen: Sie können dem Lambda-Parameter einen Namen geben, was den Code lesbar hält, wenn Blöcke verschachtelt sind oder wenn `it` nichts Aussagekräftiges sagen würde.
```kotlin
val price: Int? = 12
println(price?.let { amount -> "$amount EUR" }) // 12 EUR
```
Dieselbe Benennung funktioniert bei jeder Scope-Funktion, die `it` verwendet, also bei `let` und `also`.

# --instructions--

Schreiben Sie eine Funktion `shout(word: String?): String`, die `word` in Großbuchstaben gefolgt von `!` zurückgibt, wenn es nicht `null` ist, und `silence`, wenn es `null` ist. Verwenden Sie `?.let` und `?:`.

Beispiel: `shout("hi")` gibt `HI!` zurück, `shout(null)` gibt `silence` zurück.

# --asserts--

`shout("hi")` muss `HI!` zurückgeben

```kotlin
    tryCatch(shout("hi") == "HI!")
```

`shout("Bye")` muss `BYE!` zurückgeben

```kotlin
    tryCatch(shout("Bye") == "BYE!")
```

`shout(null)` muss `silence` zurückgeben

```kotlin
    tryCatch(shout(null) == "silence")
```

Ein leerer String ist nicht `null`, daher muss `shout("")` `!` zurückgeben

```kotlin
    tryCatch(shout("") == "!")
```
