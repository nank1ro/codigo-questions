# --instructions--

Was gibt dieses Programm aus?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, weil `apply` die Liste zurückgibt und `run` das Ergebnis des Blocks zurückgibt
- `true 2`, weil `apply` das Ergebnis von `add` zurückgibt
- `[a, b] [a, b]`, weil beide die Liste zurückgeben
- `2 [a, b]`, weil `apply` die Größe zurückgibt und `run` die Liste zurückgibt
