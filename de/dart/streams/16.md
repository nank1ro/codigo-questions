# --instructions--

Schreibe eine Funktion `sumUntilError`, die einen `Stream<int>` `source` entgegennimmt und ein `Future<int>` liefert, das mit der Summe seiner Werte abgeschlossen wird. Sendet der Stream einen Fehler, hör auf und schließe mit der Summe der **vor** dem Fehler empfangenen Werte ab, statt eine Exception zu werfen.

Beispiel:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
