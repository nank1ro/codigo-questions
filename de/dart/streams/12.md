# --description--

Ein `StreamController` wird oft an derselben Stelle erzeugt und konsumiert: Du abonnierst `controller.stream` mit `listen`, fügst dann mit `add` Events hinzu und schließt den Controller mit `close`. Da `listen` nicht wartet, werden die Events geliefert, nachdem der aktuelle Code fertig ist, aber immer in der Reihenfolge, in der sie hinzugefügt wurden:

```dart
import 'dart:async';

void main() {
  final controller = StreamController<int>();
  controller.stream.listen((n) => print('got $n'));
  controller.add(1);
  controller.add(2);
  controller.close();
}
// got 1
// got 2
```

# --instructions--

Sortiere die Elemente, um `dart:async` zu importieren, einen `StreamController<String>` zu erzeugen, seinen Stream zu abonnieren und dabei jeden Wert auszugeben, `hello` und dann `world` hinzuzufügen und schließlich den Controller zu schließen. Abonniere mit `listen`, bevor du irgendeinen Wert hinzufügst. Das Programm muss Folgendes ausgeben:

```
hello
world
```
