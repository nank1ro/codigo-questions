# --description--

String-Methoden geben Strings zurück, daher können sie nacheinander **verkettet** werden. Kombiniert mit `.split('')`, der Listen-Eigenschaft `.reversed` und `.join()` kannst du damit einen String in einem einzigen Ausdruck umkehren:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

Ein **Palindrom** ist ein Text, der vorwärts und rückwärts gelesen gleich ist, wie `level`.

# --instructions--

Schreibe eine Funktion `isPalindrome`, die einen `String`-Parameter `text` annimmt und `true` zurückgibt, wenn er ein Palindrom ist (Groß-/Kleinschreibung und Leerzeichen werden ignoriert), sonst `false`.

Beispiel:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
