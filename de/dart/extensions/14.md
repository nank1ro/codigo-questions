# --instructions--

Die Klasse `Temperature` ist gegeben. Schreibe eine Extension namens `Conversions` auf `Temperature` mit:
- einem Getter `fahrenheit` vom Typ `double`, gleich `celsius * 9 / 5 + 32`
- einer Methode `isAbove`, die einen `double`-Parameter `limit` nimmt und `true` zurückgibt, wenn `celsius` größer als `limit` ist

Beispiel:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
