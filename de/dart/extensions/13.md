# --description--

Eine generische Extension kann **Funktionen** als Parameter nehmen, genau wie `where` und `map`. Der Funktionstyp wird mit dem Elementtyp `T` geschrieben, sodass der Callback Elemente des richtigen Typs erhält:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

Vervollständige die Extension so, dass `countWhere` zurückgibt, wie viele Elemente die gegebene Funktion `test` erfüllen, sodass das Programm `2` und danach `1` ausgibt.

# --seed--

```dart
extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
```
