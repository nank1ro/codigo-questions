# --instructions--

Schreibe eine Extension namens `Words` auf `String` mit:
- einem Getter `wordCount` vom Typ `int`, der Anzahl der Wörter im String, wobei Wörter durch ein einzelnes Leerzeichen getrennt sind
- einem Getter `initials` vom Typ `String`, bestehend aus dem ersten Zeichen jedes Wortes in Großbuchstaben, ohne Trennzeichen zusammengefügt

Der String enthält immer mindestens ein Wort und hat nie führende, nachgestellte oder doppelte Leerzeichen.

Beispiel:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
