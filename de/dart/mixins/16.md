# --description--

Gestapelte Mixins sind die Art, wie kleine, unabhängige Regeln zu einer Klasse kombiniert werden. Jedes Mixin überschreibt dasselbe Member, erledigt seinen eigenen Teil und ruft `super` auf, um die Arbeit weiterzureichen. Da der Aufruf zuerst das **letzte** Mixin betritt, entscheidet die Reihenfolge der `with`-Liste, welche Regel vor welcher läuft:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` verdoppelt jede Einzahlung. Füge ein zweites Mixin nach `Doubled` hinzu und es bekommt die Einzahlung zuerst, bevor `Doubled` sie überhaupt sieht.

# --instructions--

Die Klasse `Account` ist bereits geschrieben: Sie hat ein `int`-Feld `balance`, das bei `0` startet, und eine Methode `deposit`, die ihr `int`-Argument zu `balance` addiert.

Deklariere ein Mixin `Audited` auf `Account` mit einem `List<String>`-Feld `log`, das leer startet, das `deposit` so überschreibt, dass es zuerst den String `'deposit '` gefolgt vom Betrag zu `log` hinzufügt und dann `super.deposit` aufruft.

Deklariere ein Mixin `Limited` auf `Account`, das `deposit` so überschreibt, dass ein Betrag größer als `100` ignoriert wird und jeder andere Betrag an `super.deposit` weitergegeben wird.

Deklariere eine Klasse `SafeAccount`, die `Account` erweitert und beide Mixins verwendet, sodass eine abgelehnte Einzahlung nie das Log erreicht.

Beispiel:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
