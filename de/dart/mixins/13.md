# --description--

Sobald ein Mixin eine `on`-Klausel hat, darf es ein Member dieses Typs **überschreiben** und **`super`** aufrufen, um die Version darunter in der Kette zu erreichen:

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log` ist nicht das eigene `log` des Mixins, sondern das darunter, daher gibt es keine endlose Rekursion. Stapelt man mehrere solcher Mixins mit `with A, B`, umhüllt jedes das vorherige: Der Aufruf betritt zuerst das **letzte** Mixin und wandert hinunter zur Oberklasse.

# --instructions--

Deklariere eine Klasse `Pipeline` mit einer Methode `run`, die einen `String` `input` nimmt und unverändert zurückgibt.

Deklariere ein Mixin `Trimmed` auf `Pipeline`, das `run` überschreibt, indem es die getrimmte Eingabe an `super.run` weitergibt, und ein Mixin `Upper` auf `Pipeline`, das `run` überschreibt, indem es das Ergebnis von `super.run` in Großbuchstaben zurückgibt.

Deklariere eine Klasse `TextPipeline`, die `Pipeline` erweitert und zuerst `Trimmed` und dann `Upper` verwendet, und eine Klasse `TrimOnly`, die `Pipeline` erweitert und nur `Trimmed` verwendet.

Beispiel:
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

# --solutions--

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
