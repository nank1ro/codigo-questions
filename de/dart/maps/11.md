# --description--

Die Methode `.forEach()` führt eine Funktion einmal für jedes Paar aus. Die Funktion erhält zwei Parameter: den Schlüssel und den Wert:

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
