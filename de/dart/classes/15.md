# --description--

Ein **Factory-Konstruktor** verwendet das Schlüsselwort `factory` und ermöglicht es dir, die Objekterstellung zu steuern — zum Beispiel um eine zwischengespeicherte Instanz oder einen Subtyp zurückzugeben:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

Jeder Aufruf von `Logger()` gibt dieselbe Instanz zurück (Singleton-Muster).

# --instructions--

Erstelle eine Klasse `Counter` mit einem privaten Feld `_count`, das mit `0` initialisiert wird. Füge eine Instanzmethode `increment()` hinzu, die `_count` um `1` erhöht, und einen Getter `count`, der `_count` zurückgibt. Verwende einen `factory`-Konstruktor `Counter.start()`, der immer einen neuen `Counter` mit `_count = 0` zurückgibt (mithilfe eines benannten privaten Konstruktors `Counter._internal()`).

class Counter {
  int _count = 0;

  Counter._internal();

  factory Counter.start() => Counter._internal();

  void increment() {
    _count++;
  }

  int get count => _count;
}
