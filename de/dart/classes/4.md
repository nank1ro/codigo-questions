# --description--

Der Parameter `this.x`, den du in der vorherigen Übung gesehen hast, ist eine Kurzschreibweise. Die lange Form weist jeden Parameter im Konstruktorkörper seinem Feld zu (`this.x` ist das Feld, `x` ist der Parameter):

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

Dieselbe Klasse kann so geschrieben werden:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

Diese kürzere Form wird **initialisierende Formalparameter** genannt.

# --instructions--

Welche der folgenden Optionen verwendet die Kurzschreibweise der initialisierenden Formalparameter korrekt?

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`

# --solutions--

- `Point(this.x, this.y);`
