# --description--

Der **UND-Operator** `&&` verknüpft zwei boolesche Ausdrücke. Er gibt `true` nur zurück, wenn **beide** Seiten `true` sind. Wenn eine der Seiten `false` ist, ist das Ergebnis `false`.

```dart
bool a = true;
bool b = true;
bool result = a && b; // true

bool c = true;
bool d = false;
bool result2 = c && d; // false
```
