# --description--

Type Promotion funktioniert **nicht** bei einem Klassen**feld**, das von außen geändert werden kann, denn zwischen Prüfung und Verwendung könnte ein anderer Codeabschnitt (ein in einer Unterklasse überschriebener Getter, eine andere Methode) es wieder auf `null` setzen:

```dart
class Box {
  int? value;

  int doubled() {
    if (value != null) {
      return value * 2; // error: 'value' can't be unconditionally accessed
    }
    return 0;
  }
}
```

Die übliche Lösung ist, das Feld in eine **lokale Variable** zu kopieren, für die die Promotion tatsächlich greift:

```dart
int doubled() {
  final v = value;
  if (v != null) {
    return v * 2;
  }
  return 0;
}
```

# --instructions--

Warum kompiliert die erste Version von `doubled` in der Beschreibung nicht?

# --answers--

- `value` ist ein Feld, daher findet dafür keine Promotion statt: kopiere es zuerst in eine lokale Variable
- `int?`-Werte können nicht multipliziert werden, auch wenn sie nicht `null` sind
- Der `if`-Anweisung fehlt ein `else`-Zweig
- Felder einer Klasse dürfen keinen nullable Typ haben
