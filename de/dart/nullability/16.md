# --description--

Echte Daten sind voller Lücken: ein leer gelassenes Formularfeld, eine in einer Datei fehlende Spalte, ein String, der nicht ganz eine Zahl ist. Die Werkzeuge dieses Kapitels lassen sich natürlich kombinieren, um damit umzugehen: `nonNulls`, um fehlende Elemente zu verwerfen, `int.tryParse`, um sicher umzuwandeln, und `??` oder eine `if`-Prüfung, um das zu behandeln, was nicht umgewandelt werden konnte.

# --instructions--

Schreibe eine Funktion `total`, die einen `List<String?>`-Parameter `prices` entgegennimmt und die Summe der Werte zurückgibt, die in ein `int` umgewandelt werden können, wobei sowohl `null`-Einträge als auch Strings ignoriert werden, die keine gültigen Ganzzahlen sind.

Example:
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
