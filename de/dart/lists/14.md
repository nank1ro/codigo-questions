# --description--

Die Eigenschaft `.isEmpty` ist `true`, wenn eine Liste keine Elemente enthält, und `.isNotEmpty` ist `true`, wenn sie mindestens eines enthält.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
