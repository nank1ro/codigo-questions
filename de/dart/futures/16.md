# --description--

Weil `await` Future-Fehler in gewöhnliche Ausnahmen verwandelt, gelten für asynchronen Code alle üblichen `try`/`catch`-Muster, einschließlich Schleifen, die es erneut versuchen. Innerhalb eines `catch`-Blocks wirft **`rethrow`** denselben Fehler erneut, so gibst du nach dem letzten Versuch auf:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Ein Parameter mit Funktionstyp wie `Future<String> Function() task` erhält die **Funktion** selbst, nicht ein Future: Jeder Aufruf von `task()` startet einen frischen Versuch.

# --instructions--

Schreibe eine `async`-Funktion `retry`, die ein `Future<int> Function()` `task` und ein `int` `attempts` entgegennimmt und ein `Future<int>` liefert. Rufe `task()` auf und schließe mit seinem Wert ab; wirft es, versuche es erneut und rufe `task` insgesamt höchstens `attempts` Mal auf. Schlägt auch der letzte Versuch fehl, wirf seinen Fehler mit `rethrow` erneut.

Beispiel:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` einer Aufgabe, die immer gelingt, sollte nach einem einzigen Aufruf mit ihrem Wert abschließen

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` einer Aufgabe, die zweimal fehlschlägt und dann `7` zurückgibt, sollte nach `3` Aufrufen mit `7` abschließen

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` einer Aufgabe, die immer fehlschlägt, sollte sie genau `attempts` Mal aufrufen und dann mit demselben Fehler fehlschlagen

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
