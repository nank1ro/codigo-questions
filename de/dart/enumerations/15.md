# --description--

Enum-Werte eignen sich hervorragend als **Map-Schlüssel**: Sie sind eindeutig, leicht zu vergleichen, und der Compiler stellt sicher, dass du nur echte Werte verwendest. Deklariere die Map mit dem Enum als Schlüsseltyp und greife mit `[]` auf die Werte zu:

```dart
enum Direction { north, south, east, west }

Map<Direction, String> arrows = {
  Direction.north: '^',
  Direction.south: 'v',
  Direction.east: '>',
  Direction.west: '<',
};

print(arrows[Direction.east]); // >
```

Wie bei jeder Map liefert eine Suche `null`, wenn der Schlüssel fehlt, also verwende `??`, um einen Ersatzwert bereitzustellen.

# --instructions--

Deklariere bei `enum Size { small, medium, large }` eine `Map<Size, int>` namens `prices` auf oberster Ebene, bei der `small` `2` kostet, `medium` `3` kostet und `large` `4` kostet. Schreibe dann eine Funktion `totalPrice(List<Size> order)`, die die Summe der Preise jeder Größe in `order` zurückgibt.

# --solutions--

```dart
enum Size { small, medium, large }

Map<Size, int> prices = {
  Size.small: 2,
  Size.medium: 3,
  Size.large: 4,
};

int totalPrice(List<Size> order) {
  int total = 0;
  for (var size in order) {
    total += prices[size] ?? 0;
  }
  return total;
}
```
