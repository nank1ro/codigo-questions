# --instructions--

Was passiert bei `enum Size { small, medium, large }` mit dem folgenden Code?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Er kompiliert nicht: Ein `switch`-Ausdruck über ein Enum muss jeden Wert abdecken
- Er kompiliert und gibt für `Size.large` `null` zurück
- Er kompiliert und wirft zur Laufzeit für `Size.large` eine Exception
- Er kompiliert und gibt für `Size.large` automatisch `'L'` zurück
