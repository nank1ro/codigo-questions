# --description--

Eine Klasse kann mehr als einen Typparameter deklarieren, durch Kommas getrennt. `Map<K, V>` ist das eingebaute Beispiel: ein Typ für die Schlüssel, einer für die Werte.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

Die **Reihenfolge** ist Teil des Typs: `Entry<String, int>` und `Entry<int, String>` sind nicht verwandte Typen, und ein Wert des einen kann dem anderen nicht zugewiesen werden. Typparameter lassen sich in einem Rückgabetyp auch umordnen, sodass eine Methode eine gedrehte Version des Objekts zurückgeben kann:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

Deklariere eine generische Klasse `Pair` mit zwei Typparametern `A` und `B`, einem `final`-Feld `first` vom Typ `A` und einem `final`-Feld `second` vom Typ `B`, die beide vom Konstruktor gesetzt werden, und einem Getter `swapped`, der ein `Pair<B, A>` mit denselben beiden Werten in umgekehrter Reihenfolge zurückgibt.

Beispiel:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

# --asserts--

`Pair<String, int>('age', 30)` sollte `first` `'age'` und `second` `30` haben

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` sollte ein `Pair<int, String>` mit vertauschten Werten zurückgeben

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` sollte mit zwei beliebigen Typen funktionieren, und zweimaliges Vertauschen sollte die ursprünglichen Werte zurückgeben

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');

  });

class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
