# --description--

Du bist nicht auf die generischen Klassen beschränkt, die Dart mitbringt: Du kannst eigene deklarieren. Ein **Typparameter** steht in spitzen Klammern nach dem Klassennamen, und von da an ist er innerhalb des Körpers ein normaler Typ:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` ist nur ein Platzhalter. Er wird ausgefüllt, wenn eine `Box` erstellt wird, entweder explizit oder durch Inferenz:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, aus dem Argument abgeleitet
print(a.value + 1);      // 8, der Compiler weiß, dass value ein int ist
```

Der Buchstabe spielt keine Rolle: `T` ist eine Konvention für „Typ“, nichts weiter.

# --instructions--

Deklariere eine generische Klasse `Box` mit einem Typparameter `T`, einem `final`-Feld `value` vom Typ `T`, das vom Konstruktor gesetzt wird, und einem Getter `label`, der den Text `Box of ` gefolgt vom Wert zurückgibt.

Beispiel:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` sollte `value` `7` und `label` `'Box of 7'` haben

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` sollte mit jedem Typ funktionieren, also sollte `Box<String>('fig')` auch eine `Box<String>` sein

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

Das Typargument sollte aus dem Konstruktorargument abgeleitet werden

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
