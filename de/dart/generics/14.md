# --description--

Eine generische Klasse kann benannte und **Factory**-Konstruktoren haben wie jede andere Klasse auch, und der Typparameter ist darin verfügbar. Ein Factory-Konstruktor erstellt das Objekt nicht selbst: Er führt einen Körper aus und gibt eines zurück, sodass er die Instanz beliebig auswählen, wiederverwenden oder bauen kann.

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

Das Typargument gehört zur Klasse, nicht zum Namen des Konstruktors: `Box<int>.first(...)`. Innerhalb der Factory ist `<T>[]` eine echte leere `List<T>`, daher ist eine Factory der natürliche Ort, um einen Standardwert für einen Typ zu bauen, den du noch nicht kennst.

# --instructions--

Deklariere eine generische Klasse `Stack` mit einem Typparameter `T`, einem `final`-Feld `items` vom Typ `List<T>`, das vom normalen Konstruktor gesetzt wird, einem **Factory**-Konstruktor `Stack.empty()`, der einen `Stack` mit einer leeren Liste baut, und einem Getter `top` vom Typ `T?`, der das letzte Element zurückgibt, oder `null`, wenn der Stack leer ist.

Beispiel:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

# --asserts--

`Stack<int>([1, 2, 3]).top` sollte `3` sein

```dart
  test('test1', () {
    final stack = Stack<int>([1, 2, 3]);
    expect(stack.top, 3, reason: '--err-t1--');
    expect(stack.items, [1, 2, 3], reason: '--err-t1--');
  });
```

`Stack.empty()` sollte einen leeren Stack des richtigen Typs bauen, dessen `top` `null` ist

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
    expect(stack, isA<Stack<String>>(), reason: '--err-t2--');
    expect(stack.items, <String>[], reason: '--err-t2--');
    expect(stack.top, null, reason: '--err-t2--');
  });
```

Die von `Stack.empty()` gebaute Liste sollte weiterhin verwendbar sein

```dart
  test('test3', () {
    final stack = Stack<int>.empty();
    stack.items.add(4);
    stack.items.add(9);
    expect(stack.top, 9, reason: '--err-t3--');
    expect(Stack<bool>([true]).top, true, reason: '--err-t3--');
  });
```

# --solutions--

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
