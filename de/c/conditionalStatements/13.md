# --description--

Eine `false`-Bedingung ist nie wahr, also wird der Block vollständig übersprungen und nichts darin wird ausgeführt.

# --instructions--

Was zeigt dieser Code in der Ausgabe an?
```c
if (false) {
    printf("Hello!\n");
}
```

# --answers--

- Hello!
- Nichts, weil der Codeblock übersprungen wird
