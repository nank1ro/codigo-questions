# --description--

Bedingungen sind die Werte, die eine `if`-Anweisung prüft: Ist eine Bedingung `true`, wird der Block ausgeführt, ist sie `false`, wird er übersprungen.

# --instructions--

Was sind die Werte, die entscheiden, ob ein Codeblock ausgeführt wird oder nicht?

# --answers--

- Bedingungen
- Zeichenketten
- Ganzzahlen
