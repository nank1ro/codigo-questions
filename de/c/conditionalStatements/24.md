# --description--

Eine boolesche Variable als Bedingung zu lesen, funktioniert genau wie ein Literal: Da `online` `true` enthält, wird der Block ausgeführt und sein `printf` läuft.

# --instructions--

Was zeigt dieser Code in der Ausgabe an?
```c
bool online = true;
if (online) {
    printf("Hello user!\n");
}
```
