# --description--

Jeder binäre bitweise Operator hat eine Form als **zusammengesetzte Zuweisung**, die eine Variable an Ort und Stelle aktualisiert: `&=`, `|=`, `^=`, `<<=` und `>>=`.
```c
unsigned int x = 12;
x &= 10;  // same as x = x & 10;
x |= 1;   // same as x = x | 1;
x ^= 3;   // same as x = x ^ 3;
x <<= 1;  // same as x = x << 1;
x >>= 2;  // same as x = x >> 2;
```
Sie sind besser lesbar, als den Variablennamen zu wiederholen, und sind die übliche Art, die Bits einer Flag-Variablen zu ändern.

# --instructions--

Ordne die Zeilen so, dass `flags` bei `0x01` startet, dann das Bit mit dem Wert `4` mittels `|=` eingeschaltet bekommt, dann mit `<<=` um 2 Stellen nach links verschoben und schließlich ausgegeben wird
