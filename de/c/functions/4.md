# --description--

Funktionen können mehrere Eingabeparameter haben, die in den Klammern der Funktion geschrieben werden, getrennt durch Kommas.
```c
void say_hello(char *name, bool new_user) {
  char greet[40] = "Hello ";
  strcat(greet, name);
  if (new_user) {
    strcat(greet, "! Welcome on board :)");
  }
  printf("%s\n", greet);
}

int main() {
    // gibt "Hello Tom" aus
    say_hello("Tom", true);
    return 0;
};
```
