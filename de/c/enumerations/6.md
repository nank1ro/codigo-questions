# --description--

Wenn jeder Zweig eines `switch` eine Konstante behandelt, denk an das `break` danach, sonst läuft die Ausführung in den nächsten Zweig durch.
Ein `default`-Zweig ist nicht erforderlich, wenn du jede Konstante der Aufzählung abdeckst.

# --instructions--

Sortiere die Zeilen, um `enum Size` zu deklarieren, `MEDIUM` in `size` zu speichern und `Medium` mit einem `switch` auszugeben. Halte die Zweige in derselben Reihenfolge wie die Konstanten in der Deklaration

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

```c
    case SMALL: printf("Small\n"); break;
```

```c
    case MEDIUM: printf("Medium\n"); break;
```

```c
    case LARGE: printf("Large\n"); break;
```

```c
}
```

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
