# --description--

Ein Array kann nach seiner Deklaration nicht mit `=` zugewiesen werden:
```c
char copy[20];
copy = "Codigo"; // Fehler
```
Um einen String zu kopieren, verwende `strcpy(destination, source)` aus `string.h`.
Das Ziel muss groß genug sein, um alle Zeichen plus das `'\0'` aufzunehmen.

# --instructions--

Sortiere die Zeilen, um `source` in `copy` zu kopieren und auszugeben. Deklariere `source` vor `copy`

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
