# --description--

Da ein String ein Array ist, hat jedes Zeichen einen Index, beginnend bei `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Ein einzelnes Zeichen wird mit `%c` ausgegeben. Zeichen können auch ersetzt werden:
```c
word[0] = 'K'; // word ist jetzt "Koding"
```
