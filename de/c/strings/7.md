# --description--

`strcat(destination, source)` hängt `source` an das Ende von `destination` an:
```c
char text[20] = "Hello";
strcat(text, " World");
// text ist jetzt "Hello World"
```
Wie bei `strcpy` muss das Ziel-Array genug Platz für das Ergebnis haben.
