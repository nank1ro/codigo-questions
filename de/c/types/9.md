# --description--

Groß- und Kleinbuchstaben liegen in der ASCII-Tabelle `32` Positionen auseinander: `'A'` ist `65` und `'a'` ist `97`.
Das Abziehen von `32` von einem Kleinbuchstaben ergibt daher dessen Großbuchstaben-Version, und das Ergebnis kann wieder in einem `char` gespeichert werden:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Ordne die Zeilen so, dass der Buchstabe `'a'` in `letter` gespeichert wird, seine Großbuchstaben-Version in `upper` berechnet wird und beide jeweils als Zeichen gefolgt von ihrem Code ausgegeben werden (`letter` zuerst)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
