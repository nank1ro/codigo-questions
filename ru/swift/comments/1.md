# --description--

**Комментарий** — это заметка, написанная внутри исходного кода для тех, кто его читает. Компилятор полностью игнорирует комментарии, поэтому они никогда не меняют то, что делает программа.

Самый простой комментарий — **однострочный**: он начинается с `//` и продолжается до конца строки.
```swift
// Greets the user
print("Hello")
```
Используйте комментарии, чтобы объяснить, для чего нужен фрагмент кода или почему он написан именно так.
