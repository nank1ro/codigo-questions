# --description--

После краткого описания документирующий комментарий может описать параметры и возвращаемое значение с помощью особых элементов списка Markdown, которые распознаёт Xcode:
```swift
/// Возвращает количество секунд в заданных минутах.
/// - Parameter minutes: целое число минут, всегда неотрицательное
/// - Returns: `minutes`, умноженное на шестьдесят
func toSeconds(_ minutes: Int) -> Int {
    return minutes * 60
}
```
Порядок всегда одинаков: сначала краткое описание, затем `- Parameter имя:` для каждого параметра, затем `- Returns:`.
