# --description--

Мутирующий метод может принимать параметры, как любой другой метод, и может полностью заменить `self` вместо обновления на месте:
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

# --instructions--

Напишите расширение `Int` с мутирующим методом `clamp(to max: Int)`, который заменяет число на `max`, когда число больше `max`, и оставляет его без изменений в противном случае

Пример вызова метода:
```swift
var speed = 15
speed.clamp(to: 10)
print(speed)
// prints 10
```
