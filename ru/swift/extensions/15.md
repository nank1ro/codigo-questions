# --description--

Расширения могут только **добавлять** члены, но никогда не заменяют и не переопределяют существующие. `override` принадлежит подклассам, которые являются другим типом по сравнению с родителем; расширение — тот же тип, поэтому объявление уже существующего метода является ошибкой повторного объявления:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
Если вам нужно другое поведение, добавьте метод с новым именем или напишите подкласс, если тип — класс.

# --instructions--

Что произойдёт при компиляции и запуске этой программы?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- Она не компилируется, потому что `speak()` объявлен дважды для одного типа
- Она выводит `Bark`, потому что расширение переопределяет исходный метод
- Она выводит `Woof`, потому что исходный метод имеет приоритет над расширением
- Она выводит `Woof`, а затем `Bark`
