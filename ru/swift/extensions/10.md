# --description--

Расширения нужны не только для чужих типов. Обычный способ организовать собственный код — хранить хранимые свойства в теле структуры или класса, а поведение добавлять в одном или нескольких расширениях, каждое из которых группирует связанные члены:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
Члены, добавленные в расширении, могут использовать хранимые свойства напрямую, в точности как если бы они были написаны внутри типа.

# --asserts--

Вы должны использовать расширение `Rectangle`

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Площадь прямоугольника `2` на `3` должна быть равна `6.0`

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

Площадь прямоугольника `1.5` на `4` должна быть равна `6.0`

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

Прямоугольник `2` на `3`, масштабированный на `2`, должен стать `4` на `6`

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

Масштабирование не должно изменять исходный прямоугольник

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
