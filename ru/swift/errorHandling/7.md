# --description--

Валидатор читается лучше всего, когда отказы идут первыми, а настоящая работа остаётся внизу без отступов. `guard` создан именно для этого: он формулирует условие, которое должно выполняться, а его блок `else` срабатывает, когда оно не выполняется.
```swift
func priceFor(_ quantity: Int) throws -> Int {
    guard quantity > 0 else {
        throw OrderError.notPositive
    }
    return quantity * 3
}
```
Блок `else` у `guard` обязан покинуть текущую область видимости, и `throw` — один из способов это сделать, наряду с `return`, `break` и `continue`. Несколько `guard` подряд в начале функции читаются как список правил, которым входные данные должны удовлетворять.
