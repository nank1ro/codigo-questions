# --description--

От того, где стоит блок `do`, зависит, во что обходится один сбой. Поставьте его **внутри** цикла, и тогда каждый элемент получает собственную попытку, поэтому одно плохое значение пропускается, а остальные всё равно выполняются:
```swift
for age in [4, -1, 7] {
    do {
        print(try label(age))
    } catch {
        print("skipped")
    }
}
```
Обернуть же весь цикл в один `do` означало бы остановиться на первой ошибке и никогда не дойти до `7`. Ни один из вариантов не ошибочен — это разница между *одним плохим элементом* и *отказом от попыток*.

