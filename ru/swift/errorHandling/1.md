# --description--

В Swift ошибка — это **значение**, а не аварийное падение. Любой тип может выступать в этой роли, приняв протокол `Error`, а перечисление — обычный выбор, ведь его варианты точно называют то, что может пойти не так:
```swift
enum LoginError: Error {
    case wrongPassword
}
```
Функция, которая может завершиться неудачей, помечается `throws` и сообщает о сбое с помощью `throw`:
```swift
func login(_ password: String) throws {
    if password != "swift" {
        throw LoginError.wrongPassword
    }
    print("welcome")
}
```
Вызов такой функции требует `try`, и он должен находиться внутри блока `do`, за которым следует блок `catch`, описывающий, что делать при сбое:
```swift
do {
    try login("hunter2")
} catch {
    print("login failed")
}
// login failed
```
Когда выполняется `throw`, остаток блока `do` пропускается и управление перехватывает `catch`. Ничего не падает: программа продолжает работу после `catch`.
