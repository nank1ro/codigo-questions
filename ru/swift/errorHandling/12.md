# --description--

Одна область видимости может зарегистрировать несколько `defer`. Выполняются они в **обратном** порядке: последний зарегистрированный выполняется первым.

Это не произвольное правило. Очистка обычно отменяет подготовку, шедшую по порядку, — открыть файл, затем заблокировать его, — а отмена должна идти в обратную сторону: разблокировать, затем закрыть. Обратный порядок делает каждый `defer` зеркальным отражением строки над ним.

# --instructions--

Что выведет этот код?
```swift
func run() {
    defer { print("one") }
    defer { print("two") }
    print("body")
}

run()
```

# --answers--

- `body`, затем `two`, затем `one`
- `body`, затем `one`, затем `two`
- `one`, затем `two`, затем `body`
- `two`, затем `one`, затем `body`
