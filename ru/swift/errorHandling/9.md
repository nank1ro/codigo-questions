# --description--

Поскольку `try?` даёт опциональное значение, оператор объединения nil `??` доводит дело до конца, подставляя запасное значение:
```swift
let port = (try? readPort(text)) ?? 8080
```
Круглые скобки важны. Без них `try?` попытался бы покрыть всё выражение целиком, включая `??`, а компилятор требует явно указать, где заканчивается вызов, который может завершиться неудачей.

Прочитайте строку как одно предложение: *взять порт, который удалось прочитать, иначе 8080*. Две строки `do`/`catch` сжимаются в одну, когда восстановление — это действительно просто значение по умолчанию.

# --instructions--

Дополните `portOrDefault` так, чтобы она возвращала порт, прочитанный из `text`, или `8080`, когда `readPort` выбрасывает ошибку

Пример использования:
```swift
print(portOrDefault("abc"))
// выводит 8080
```

```swift
enum ConfigError: Error {
    case notANumber
}

func readPort(_ text: String) throws -> Int {
    guard let value = Int(text) else {
        throw ConfigError.notANumber
    }
    return value
}

func portOrDefault(_ text: String) -> Int {
    return (try? readPort(text)) ?? 8080
}
```
