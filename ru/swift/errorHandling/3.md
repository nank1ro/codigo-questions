# --description--

Голый `catch` обрабатывает любую ошибку одинаково. Чаще всего нужно отреагировать на один конкретный сбой, поэтому `catch` может нести **шаблон**: вариант, который он готов обработать.
```swift
do {
    try check("")
} catch ValidationError.empty {
    print("the text is empty")
} catch {
    print("something else")
}
```
Swift перебирает ветви `catch` сверху вниз и выполняет первую, чей шаблон совпал.

Последний `catch` намеренно оставлен без шаблона. `catch` с шаблоном покрывает только названный в нём вариант, а Swift требует, чтобы каждая ошибка была где-то обработана, поэтому блоку `do` с перечислением шаблонов нужен завершающий `catch` без шаблона, который подберёт всё остальное.
