# --description--

У функции, принимающей замыкание, есть проблема: она не может знать, станет ли переданное ей замыкание выбрасывать ошибку. Пометка функции `throws` заставила бы каждого вызывающего писать `try` — даже тех, кто передаёт безобидное замыкание. `rethrows` говорит *я выбрасываю ошибку, только если её выбрасывает переданное вами замыкание*:
```swift
func applyTwice(_ value: Int, _ transform: (Int) throws -> Int) rethrows -> Int {
    return try transform(transform(value))
}
```
Внутри тела вы по-прежнему пишете `try`, потому что вызов действительно может завершиться неудачей. В месте вызова компилятор смотрит на переданное вами замыкание:
```swift
let doubled = applyTwice(3, { (n: Int) -> Int in n * 2 }) // try не нужен
```
Стандартная библиотека использует это повсюду — `map`, `filter` и `sorted(by:)` все являются `rethrows`, — поэтому перед обычным `map` вы никогда не пишете `try`.

# --asserts--

удвоение `1, 2, 3` должно давать `2, 4, 6` без всякого `try`

```swift
let _doubled: [Int] = applyAll([1, 2, 3], { (n: Int) -> Int in n * 2 })
tryCatch(_doubled == [2, 4, 6])
```

пустой массив должен давать пустой массив

```swift
let _empty: [Int] = applyAll([], { (n: Int) -> Int in n * 2 })
tryCatch(_empty.isEmpty)
```

прибавление единицы к `5` должно давать `6`

```swift
let _plus: [Int] = applyAll([5], { (n: Int) -> Int in n + 1 })
tryCatch(_plus == [6])
```

замыкание, выбрасывающее ошибку, должно заставлять `applyAll` выбрасывать ошибку

```swift
tryCatch(_propagates())
```

# --solutions--

```swift
func applyAll(_ numbers: [Int], _ transform: (Int) throws -> Int) rethrows -> [Int] {
    var result: [Int] = []
    for number in numbers {
        result.append(try transform(number))
    }
    return result
}
```
