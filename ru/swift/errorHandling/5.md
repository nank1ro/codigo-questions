# --description--

Вариант ошибки может нести данные. Задайте варианту **связанные значения**, и `throw` заполнит их, так что обработчик узнает не только *что* завершилось неудачей, но и *насколько*:
```swift
enum ValidationError: Error {
    case tooShort(minimum: Int)
}

throw ValidationError.tooShort(minimum: 8)
```
Соответствующий `catch` привязывает эти значения с помощью `let`:
```swift
} catch ValidationError.tooShort(let minimum) {
    print("needs at least \(minimum) characters")
}
```
Имя после `let` выбираете вы; это новая константа, доступная только внутри этого блока `catch`. Так ошибка несёт полезное сообщение, и вам не приходится вставлять числа в строки там, где произошёл сбой.

# --instructions--

Дайте варианту `tooShort` связанное значение `minimum` типа `Int` и сделайте так, чтобы `check` выбрасывал `PasswordError.tooShort(minimum: 8)`, когда пароль короче 8 символов

Пример использования:
```swift
do {
    try check("abc")
} catch PasswordError.tooShort(let minimum) {
    print(minimum)
}
// выводит 8
```

# --asserts--

`check("abc")` должна выбрасывать `tooShort`, несущий `8`

```swift
tryCatch(_minimum("abc") == 8)
```

`check("")` должна выбрасывать `tooShort`, несущий `8`

```swift
tryCatch(_minimum("") == 8)
```

`check("1234567")` должна выбрасывать ошибку, потому что 7 символов недостаточно

```swift

```

```swift

```

