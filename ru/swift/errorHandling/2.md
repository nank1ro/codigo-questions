# --description--

Функция с `throws` всё равно может возвращать значение. Ключевое слово `throws` ставится между списком параметров и стрелкой возвращаемого значения:
```swift
func square(_ n: Int) throws -> Int {
    if n < 0 {
        throw SquareError.negative
    }
    return n * n
}
```
Прочитаем это вслух: *square принимает `Int`, может выбросить ошибку и возвращает `Int`*.

В месте вызова значение существует, только если ничего не было выброшено, поэтому присваивание находится внутри блока `do`:
```swift
do {
    let result = try square(4)
    print(result) // 16
} catch {
    print("failed")
}
```
`try` — не необязательное украшение: без него компилятор отклоняет вызов, поэтому читающий всегда видит, какие строки могут завершиться неудачей.

# --solutions--

```swift
enum MathError: Error {
    case notEven
}

func half(_ n: Int) throws -> Int {
    if n % 2 != 0 {
        throw MathError.notEven
    }
    return n / 2
}
```
