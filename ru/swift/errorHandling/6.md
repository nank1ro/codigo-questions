# --description--

Одно перечисление обычно собирает все способы, которыми может завершиться неудачей одна задача, — по варианту на каждую причину:
```swift
enum FormError: Error {
    case empty
    case tooLong
}
```
Писать по одному `catch` на каждый вариант утомительно. Вместо этого перехватите весь тип сразу и пройдитесь по значению с помощью `switch`:
```swift
} catch let error as FormError {
    switch error {
    case .empty: print("empty")
    case .tooLong: print("too long")
    }
} catch {
    print("unknown")
}
```
`catch let error as FormError` означает *перехвати всё, что является `FormError`, и назови это `error`*. Внутри блока `error` имеет тип перечисления, поэтому `switch` видит варианты и проверяет, что покрыты все они. Завершающий `catch` без шаблона по-прежнему обязателен, ведь в этот блок `do` может попасть ошибка и другого типа.
