# --description--

Порядок имеет значение. Swift сравнивает выброшенное значение с каждым шаблоном `catch` в том порядке, в каком они записаны, и останавливается на первом совпадении, поэтому `catch` без шаблона, стоящий первым, поглотил бы всё, что ниже него. Держите конкретные варианты сверху, а общий `catch` — снизу.

Ошибка, не совпавшая ни с одним из шаблонов, не игнорируется: она попадает в завершающий `catch` без шаблона.

# --instructions--

Что выведет этот код?
```swift
enum ValidationError: Error {
    case empty
    case tooShort
}

func check() throws {
    throw ValidationError.tooShort
}

do {
    try check()
} catch ValidationError.empty {
    print("empty")
} catch {
    print("other")
}
```

# --answers--

- `other`
- `empty`
- `empty`, затем `other`
- Ничего, программа остановится с необработанной ошибкой
