# --description--

Структура — это такой же тип, как любой другой, поэтому её можно хранить в массиве, словаре или множестве, и каждый инструмент, который вы уже знаете, продолжает с ней работать:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
Помните, что массив хранит *копии*: чтение `items[0]` в переменную и её изменение не затрагивают сам массив.

# --asserts--

Два элемента со значениями `3` и `7` должны в сумме давать `10`

```swift
tryCatch(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]) == 10)
```

Один элемент должен в сумме давать свою собственную цену

```swift
tryCatch(totalPrice([Item(name: "Pen", price: 2)]) == 2)
```

Пустой массив должен в сумме давать `0`

```swift
tryCatch(totalPrice([]) == 0)
```
