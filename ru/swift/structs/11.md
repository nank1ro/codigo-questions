# --description--

Некоторые значения принадлежат самому типу, а не какому-либо отдельному экземпляру: код валюты, общее значение по умолчанию, фабрика, создающая типичное значение. Пометьте их как `static` и обращайтесь к ним через имя типа:
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
Здесь `currency` объявлена с помощью `let`, потому что она никогда не меняется — это константа, общая для всей программы. `Money.currency` работает без создания хоть одного `Money`, тогда как `amount` требует экземпляра.

# --instructions--

Добавьте в `Money` статическую константу `currency`, равную `"EUR"`, и статический метод `zero`, который не принимает параметров и возвращает `Money` с `amount`, равным `0`

Пример использования:
```swift
print(Money.currency)
// prints EUR
```

`currency` должна быть статической константой

```json
{
  "regex": "static\\s+let\\s+currency",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`Money.currency` должна быть равна `"EUR"`

```swift
tryCatch(Money.currency == "EUR")
```

`Money.zero()` должен иметь `amount`, равный `0`

```swift
tryCatch(Money.zero().amount == 0)
```

Memberwise-инициализатор должен по-прежнему работать

```swift
tryCatch(Money(amount: 7).amount == 7)
```
