# --instructions--

Почему этот код не компилируется?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` — константа `let`, поэтому мутирующий метод нельзя вызвать на ней
- `increase` должен быть помечен как `static`, чтобы изменять `value`
- `value` должно быть объявлено с помощью `let`
- Структура не может содержать методы
