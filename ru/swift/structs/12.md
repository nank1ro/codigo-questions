# --instructions--

Отсортируйте элементы так, чтобы выводилось `EUR 12`: сначала объявите структуру, а экземпляр — перед `print`

# --answers--

```swift
struct Money {
    static let currency = "EUR"
    var amount: Int
}
```

```swift
let price = Money(amount: 12)
```

```swift
print("\(Money.currency) \(price.amount)")
```
