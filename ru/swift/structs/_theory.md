**Структура** (struct, от английского *structure*) — это тип, который вы создаёте сами, чтобы хранить связанные значения вместе. Вместо того чтобы жонглировать отдельным `title` и отдельным `pages`, вы один раз описываете `Book` и используете его везде.

Структура объявляется с помощью ключевого слова `struct`, а переменные, записанные внутри неё, являются её **хранимыми свойствами**:
```swift
struct Book {
    var title: String
    var pages: Int
}
```
`Book` теперь является типом, точно так же, как `Int` или `String`. К свойству экземпляра обращаются через точку:
```swift
let book = Book(title: "Swift", pages: 120)
print(book.title) // Swift
```

---

Вы не писали код, который создаёт `Book`, но `Book(title: "Swift", pages: 120)` сработал. Swift пишет его за вас: каждая структура получает бесплатный **memberwise-инициализатор** — инициализатор, параметры которого являются его хранимыми свойствами, в порядке их объявления, причём каждый из них использует имя свойства в качестве метки аргумента:
```swift
struct Point {
    var x: Int
    var y: Int
}

let p = Point(x: 3, y: 4)
print(p.x) // 3
```
Классы не получают этого бесплатно, и это одна из причин, почему структуры — самый быстрый способ смоделировать значение.

---

Хранимому свойству можно задать **значение по умолчанию** прямо в месте его объявления. Swift выводит его тип из этого значения, поэтому аннотацию типа можно опустить:
```swift
struct Counter {
    var label: String
    var value = 0
}
```
Memberwise-инициализатор превращает каждое свойство со значением по умолчанию в необязательный аргумент: передайте его, чтобы переопределить значение по умолчанию, или опустите, чтобы сохранить его.
```swift
let a = Counter(label: "clicks")
print(a.value) // 0

let b = Counter(label: "clicks", value: 7)
print(b.value) // 7
```

---

Структура также может содержать **методы**: функции, написанные внутри фигурных скобок, которые работают с экземпляром, у которого они вызваны. Внутри метода вы используете имена свойств напрямую, без какого-либо префикса:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    func area() -> Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area()) // 12
```
Если параметр метода затеняет имя свойства, напишите `self.width`, чтобы обратиться к свойству экземпляра.

---

**Вычисляемое свойство** выглядит как свойство, но ведёт себя как метод: оно ничего не хранит, а вычисляет своё значение при каждом чтении. Вы пишете тип, а затем блок кода, который возвращает значение:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, без скобок
```
Вычисляемые свойства не входят в memberwise-инициализатор, поскольку хранить нечего. Используйте вычисляемое свойство, когда значение выводится из других свойств, и метод, когда работе нужны параметры.

---

Структура — это **тип значения**: при присваивании её другой переменной или передаче в функцию передаётся *копия*. Изменение копии оставляет оригинал нетронутым.
```swift
struct Point {
    var x: Int
}

var a = Point(x: 1)
var b = a
b.x = 99
print(a.x) // 1
```
Класс — это **ссылочный тип**: `b = a` заставило бы оба имени указывать на один и тот же экземпляр, поэтому `b.x = 99` изменило бы и `a.x` на `99`.

В этом и заключается настоящее различие между ними, и именно поэтому Swift моделирует большинство данных как структуры: значение, которым вы владеете, не может быть изменено у вас за спиной кодом, который его получил.

---

Поскольку структура — это значение, методу не разрешается изменять её свойства, если вы явно не укажете это с помощью ключевого слова `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Мутирующий метод можно вызывать только на экземпляре, хранящемся в `var`. У экземпляра `let` значение заморожено, поэтому `c.increase(by: 5)` не скомпилировался бы.

---

Когда memberwise-инициализатор — не тот способ, которым вы хотите создавать свой тип, напишите собственный **инициализатор**. Он объявляется с помощью `init`, принимает выбранные вами параметры и должен присвоить значение каждому хранимому свойству до своего завершения. Внутри него `self` — это создаваемый экземпляр:
```swift
struct Square {
    var side: Int

    init(_ side: Int) {
        self.side = side
    }
}

let s = Square(5)
print(s.side) // 5
```
Написание `init` внутри фигурных скобок структуры заменяет memberwise-инициализатор, поэтому с этого момента `Square(side: 5)` больше не существует.

---

Некоторые значения принадлежат самому типу, а не какому-либо отдельному экземпляру: код валюты, общее значение по умолчанию, фабрика, создающая типичное значение. Пометьте их как `static` и обращайтесь к ним через имя типа:
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
Здесь `currency` объявлена с помощью `let`, потому что она никогда не меняется — это константа, общая для всей программы. `Money.currency` работает без создания хоть одного `Money`, тогда как `amount` требует экземпляра.

---

Две структуры нельзя сравнивать с помощью `==`, пока тип не заявит о поддержке этого. Вы делаете это, реализуя **протокол** `Equatable`, который записывается после двоеточия в объявлении:
```swift
struct Point: Equatable {
    var x: Int
    var y: Int
}

let a = Point(x: 1, y: 2)
let b = Point(x: 1, y: 2)
print(a == b) // true
```
Вам не нужно писать `==` самостоятельно: когда каждое хранимое свойство уже является `Equatable`, Swift синтезирует его за вас, сравнивая свойства одно за другим. Два экземпляра равны, когда равны все их свойства — именно этого и ожидаешь от значения.

---

Структура — это такой же тип, как любой другой, поэтому её можно хранить в массиве, словаре или множестве, и каждый инструмент, который вы уже знаете, продолжает с ней работать:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
Помните, что массив хранит *копии*: чтение `items[0]` в переменную и её изменение не затрагивают сам массив.
