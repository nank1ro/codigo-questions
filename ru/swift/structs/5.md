# --description--

**Вычисляемое свойство** выглядит как свойство, но ведёт себя как метод: оно ничего не хранит, а вычисляет своё значение при каждом чтении. Вы пишете тип, а затем блок кода, который возвращает значение:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, no parentheses
```
Вычисляемые свойства не входят в memberwise-инициализатор, поскольку хранить нечего. Используйте вычисляемое свойство, когда значение выводится из других свойств, и метод, когда работе нужны параметры.

# --instructions--

Добавьте в `Temperature` вычисляемое свойство `fahrenheit` типа `Double`, возвращающее значение в градусах Цельсия, умноженное на `9`, делённое на `5` и увеличенное на `32`

Пример использования:
```swift
print(Temperature(celsius: 100).fahrenheit)
// prints 212.0
```

# --asserts--

`100` градусов Цельсия должны быть равны `212` градусам Фаренгейта

```swift
tryCatch(Temperature(celsius: 100).fahrenheit == 212)
```

`0` градусов Цельсия должны быть равны `32` градусам Фаренгейта

```swift
tryCatch(Temperature(celsius: 0).fahrenheit == 32)
```

`-40` градусов Цельсия должны быть равны `-40` градусам Фаренгейта

```swift
tryCatch(Temperature(celsius: -40).fahrenheit == -40)
```
