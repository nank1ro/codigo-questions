# --description--

Поскольку структура — это значение, методу не разрешается изменять её свойства, если вы явно не укажете это с помощью ключевого слова `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Мутирующий метод можно вызывать только на экземпляре, хранящемся в `var`. У экземпляра `let` значение заморожено, поэтому `c.increase(by: 5)` не скомпилировался бы.

# --instructions--

Добавьте в `Counter` мутирующий метод `increase`, который принимает `Int` с меткой аргумента `by` и прибавляет его к `value`

Пример использования:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

Метод должен быть помечен как `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Увеличение `0` на `5` должно дать `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Увеличение `10` дважды должно суммироваться

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Увеличение на `0` не должно ничего менять

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Изменение копии не должно менять оригинал

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
