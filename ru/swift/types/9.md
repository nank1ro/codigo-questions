# --description--

`Int(text)` выполняется успешно, только когда весь текст является корректным целым числом, возможно со знаком:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Для десятичного текста используйте `Double(text)`, который аналогичным образом возвращает `Double?`: `Double("3.5")` — это `Optional(3.5)`.

# --instructions--

Напишите функцию `sumOfNumbers`, которая принимает массив `String` (без метки аргумента) и возвращает сумму тех элементов, которые являются корректными целыми числами, игнорируя остальные

Пример вызова функции:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
