# --description--

Поскольку `Int(text)` и `Double(text)` возвращают `nil` при неудаче, сравнение результата с `nil` говорит вам, является ли текст числом соответствующего вида:
```swift
print(Int("42") != nil)     // true
print(Double("4.2") != nil) // true
print(Double("42") != nil)  // true, a whole number is also a valid Double
```
Обратите внимание на последнюю строку: любой текст, принятый `Int`, принимается и `Double`, поэтому, когда нужно их различить, сначала проверяйте на `Int`.

# --instructions--

Напишите функцию `classify`, которая принимает `String` (без метки аргумента) и возвращает `"Int"`, если текст является корректным целым числом, `"Double"`, если это корректное десятичное число, и `"String"` в остальных случаях

Пример вызова функции:
```swift
print(classify("3.5"))
// prints Double
```

# --solutions--

```swift
func classify(_ text: String) -> String {
    if Int(text) != nil {
        return "Int"
    }
    if Double(text) != nil {
        return "Double"
    }
    return "String"
}
```
