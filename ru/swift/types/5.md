# --description--

`Int(x)` не округляет: он **отбрасывает** дробную часть, поэтому `Int(3.99)` — это `3`, а `Int(-3.99)` — это `-3`.
Чтобы округлить до ближайшего целого числа, сначала вызовите `rounded()` у `Double`, а затем выполните преобразование:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
Половинные значения вроде `2.5` округляются от нуля: `2.5` становится `3.0`, а `-2.5` становится `-3.0`.

# --instructions--

Напишите функцию `roundedAverage`, которая принимает два `Int` (без меток аргументов) и возвращает их среднее, округлённое до ближайшего целого числа, как `Int`

Пример вызова функции:
```swift
print(roundedAverage(3, 4))
// prints 4
```

func roundedAverage(_ a: Int, _ b: Int) -> Int {
    let average = Double(a + b) / 2
    return Int(average.rounded())
}
