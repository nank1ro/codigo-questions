# --description--

Когда функция должна вернуть десятичный результат, вычисленный из целых чисел, преобразуйте операнды в `Double` перед делением и объявите возвращаемый тип как `Double`:
```swift
func ratio(_ part: Int, _ total: Int) -> Double {
    return Double(part) / Double(total)
}
print(ratio(1, 4)) // 0.25
```
Помните, что `count` массива — тоже `Int`, поэтому он требует такого же преобразования.

# --instructions--

Напишите функцию `average`, которая принимает массив `Int` (без метки аргумента) и возвращает среднее значение его элементов как `Double`. Массив никогда не бывает пустым

Пример вызова функции:
```swift
print(average([1, 2]))
// prints 1.5
```

# --solutions--

```swift
func average(_ numbers: [Int]) -> Double {
    var sum = 0
    for number in numbers {
        sum += number
    }
    return Double(sum) / Double(numbers.count)
}
```
