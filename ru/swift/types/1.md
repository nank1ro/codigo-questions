# --description--

Каждое значение в Swift имеет **тип**, который сообщает компилятору, что это за данные и что вы можете с ними делать.
Основные типы:
- `Int`: целое число, например `42` или `-7`
- `Double`: число с дробной частью, например `3.14`
- `String`: фрагмент текста, например `"Hello"`
- `Character`: один символ, например `"a"`
- `Bool`: либо `true`, либо `false`

Вы можете указать тип константы или переменной с помощью **аннотации типа**: двоеточия и имени типа после имени:
```swift
let age: Int = 36
let name: String = "Ada"
```
Значение одного типа нельзя сохранить в константе другого типа: `let age: Int = "36"` — ошибка компиляции.
