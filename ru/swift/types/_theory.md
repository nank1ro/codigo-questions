Каждое значение в Swift имеет **тип**, который сообщает компилятору, что это за данные и что вы можете с ними делать.
Основные типы:
- `Int`: целое число, например `42` или `-7`
- `Double`: число с дробной частью, например `3.14`
- `String`: фрагмент текста, например `"Hello"`
- `Character`: один символ, например `"a"`
- `Bool`: либо `true`, либо `false`

Вы можете указать тип константы или переменной с помощью **аннотации типа**: двоеточия и имени типа после имени:
```swift
let age: Int = 36
let name: String = "Ada"
```
Значение одного типа нельзя сохранить в константе другого типа: `let age: Int = "36"` — ошибка компиляции.

---

Чаще всего вы не пишете аннотацию типа: Swift **выводит** тип из присваиваемого значения, следуя нескольким правилам для литералов:
- число без десятичной точки, например `42`, — это `Int`
- число с десятичной точкой, например `3.14`, — это `Double`
- текст в двойных кавычках — это `String`
- `true` и `false` — это `Bool`
```swift
let count = 42     // Int
let price = 9.99   // Double
let name = "Ada"   // String
let isOpen = true  // Bool
```
В Swift есть также `Float` — десятичное число, которое использует вдвое меньше памяти, чем `Double`, но менее точное, поэтому десятичный литерал никогда не выводится как `Float`: его нужно запросить аннотацией.
Точно так же `"a"` выводится как `String`, поэтому для `Character` всегда нужна аннотация.

---

Функция `type(of:)` возвращает тип значения, что удобно для проверки того, что вывел Swift:
```swift
print(type(of: 42))    // Int
print(type(of: 2.5))   // Double
print(type(of: "hi"))  // String
```
Когда вам нужен тип, отличный от выведенного, добавьте аннотацию. Целочисленный литерал можно сохранить в константе `Double` или `Float`, а литерал из одного символа — в константе `Character`:
```swift
let ratio: Double = 3       // 3.0, not an Int
let half: Float = 0.5
let initial: Character = "S"
print(type(of: ratio))      // Double
```

---

Swift никогда не преобразует числовые типы самостоятельно: сложение `Int` с `Double` — ошибка компиляции, хотя оба являются числами.
```swift
let apples = 3
let price = 1.5
let total = apples * price // error: Int and Double can't be mixed
```
Чтобы объединить их, вы создаёте новое значение нужного типа, передавая значение в инициализатор этого типа:
```swift
let total = Double(apples) * price // 4.5
```
То же самое работает и в обратную сторону: `Int(4.5)` создаёт `Int`, сохраняя только целую часть числа.

---

`Int(x)` не округляет: он **отбрасывает** дробную часть, поэтому `Int(3.99)` — это `3`, а `Int(-3.99)` — это `-3`.
Чтобы округлить до ближайшего целого числа, сначала вызовите `rounded()` у `Double`, а затем выполните преобразование:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
Половинные значения вроде `2.5` округляются от нуля: `2.5` становится `3.0`, а `-2.5` становится `-3.0`.

---

Тип операндов определяет, как работает деление. Когда оба операнда — `Int`, оператор `/` выполняет **целочисленное деление**: результатом будет `Int`, а остаток отбрасывается.
Когда хотя бы один операнд — `Double`, `/` выполняет деление с плавающей точкой и сохраняет дробную часть:
```swift
print(7 / 2)              // 3
print(7.0 / 2)            // 3.5
let slices = 7
print(Double(slices) / 2) // 3.5
```
Поэтому, чтобы получить десятичный результат из двух значений `Int`, нужно преобразовать хотя бы одно из них в `Double` **до** деления: `Double(7 / 2)` — это `3.0`, потому что целочисленное деление уже произошло.

---

Когда функция должна вернуть десятичный результат, вычисленный из целых чисел, преобразуйте операнды в `Double` перед делением и объявите возвращаемый тип как `Double`:
```swift
func ratio(_ part: Int, _ total: Int) -> Double {
    return Double(part) / Double(total)
}
print(ratio(1, 4)) // 0.25
```
Помните, что `count` массива — тоже `Int`, поэтому он требует такого же преобразования.

---

Числа и строки преобразуются с помощью того же синтаксиса инициализаторов. `String(42)` превращает число в текст `"42"`, точно так же, как его интерполяция через `"\(42)"`.
Обратное направление может завершиться ошибкой, поскольку не всякий текст является числом, поэтому `Int("42")` возвращает **опциональное** значение `Int?`: здесь оно содержит `42`, но `Int("hello")` — это `nil`.
Как вы узнали из уроков о опциональных значениях, вы можете предоставить запасное значение с помощью `??` или развернуть его с помощью `if let`:
```swift
let typed = "42"
let number = Int(typed) ?? 0
print(number + 1) // 43
```

---

`Int(text)` выполняется успешно, только когда весь текст является корректным целым числом, возможно со знаком:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Для десятичного текста используйте `Double(text)`, который аналогичным образом возвращает `Double?`: `Double("3.5")` — это `Optional(3.5)`.

---

**Псевдоним типа** даёт существующему типу новое имя с помощью ключевого слова `typealias`:
```swift
typealias Score = Int
let best: Score = 100
print(best + 1) // 101
```
`Score` и `Int` — это один и тот же тип, поэтому они свободно смешиваются. Псевдоним не добавляет безопасности: он лишь делает код более читаемым, когда обычный тип имеет особое значение в вашей программе.

---

Значение `Int` использует 64 бита, поэтому оно может представлять числа только в фиксированном диапазоне. Наибольшее и наименьшее значения доступны как `Int.max` и `Int.min`:
```swift
print(Int.max) // 9223372036854775807
print(Int.min) // -9223372036854775808
```
Выход за эти пределы называется **переполнением**. В отличие от многих других языков, Swift не выполняет тихий перенос на другой конец диапазона: операция с переполнением — это **ошибка времени выполнения**, которая останавливает программу.

---

`Int.max` и `Int.min` полезны в качестве начальных значений при поиске экстремума: любое реальное число меньше `Int.max`, поэтому оно является безопасным начальным значением для «наименьшего из увиденных»:
```swift
var smallest = Int.max
for number in [8, 3, 5] {
    if number < smallest {
        smallest = number
    }
}
print(smallest) // 3
```

---

Как вы видели в уроках о строках, итерация по `String` даёт вам по одному `Character` за раз. `Character` — это не `String`, поэтому, чтобы использовать его как текст, преобразуйте его с помощью `String(c)`.
Когда символ является цифрой, свойство `wholeNumberValue` даёт его числовое значение как `Int?`: оно равно `nil` для символов, которые не являются цифрами.
```swift
for c in "a1" {
    print(c.wholeNumberValue)
}
// nil
// Optional(1)
```

---

Поскольку `Int(text)` и `Double(text)` возвращают `nil` при неудаче, сравнение результата с `nil` говорит вам, является ли текст числом соответствующего вида:
```swift
print(Int("42") != nil)     // true
print(Double("4.2") != nil) // true
print(Double("42") != nil)  // true, a whole number is also a valid Double
```
Обратите внимание на последнюю строку: любой текст, принятый `Int`, принимается и `Double`, поэтому, когда нужно их различить, сначала проверяйте на `Int`.

---

Иногда нужно хранить значения разных типов вместе. Специальный тип `Any` может содержать значение **любого** типа, поэтому массив, объявленный как `[Any]`, может смешивать числа, строки и логические значения:
```swift
let items: [Any] = [1, "two", true]
```
Каждый элемент по-прежнему помнит свой настоящий тип, который раскрывает `type(of:)`. Чтобы работать со значением как с его настоящим типом, вы используете **условное приведение** с `as?`, которое возвращает опциональное значение: оно содержит значение, когда тип совпадает, и `nil` в противном случае:
```swift
for item in items {
    if let number = item as? Int {
        print(number + 1) // runs only for 1
    }
}
```
`Any` — это крайнее средство: массив одного конкретного типа безопаснее и проще в использовании, поэтому отдавайте ему предпочтение всегда, когда это возможно.

---

Условные приведения естественно объединяются в цепочку с помощью `else if`, чтобы обрабатывать несколько возможных типов, преобразуя каждый из них к типу, который вам нужен для результата:
```swift
let item: Any = 2.5
if let number = item as? Int {
    print(Double(number))
} else if let number = item as? Double {
    print(number)
}
```
Значение `Int`, хранящееся в `Any`, всё равно остаётся `Int`: `as? Double` для него возвращает `nil`, потому что `as?` проверяет тип, а не преобразует числа.
