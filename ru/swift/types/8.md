# --description--

Числа и строки преобразуются с помощью того же синтаксиса инициализаторов. `String(42)` превращает число в текст `"42"`, точно так же, как его интерполяция через `"\(42)"`.
Обратное направление может завершиться ошибкой, поскольку не всякий текст является числом, поэтому `Int("42")` возвращает **опциональное** значение `Int?`: здесь оно содержит `42`, но `Int("hello")` — это `nil`.
Как вы узнали из уроков о опциональных значениях, вы можете предоставить запасное значение с помощью `??` или развернуть его с помощью `if let`:
```swift
let typed = "42"
let number = Int(typed) ?? 0
print(number + 1) // 43
```
