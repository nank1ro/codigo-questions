# --description--

Условные приведения естественно объединяются в цепочку с помощью `else if`, чтобы обрабатывать несколько возможных типов, преобразуя каждый из них к типу, который вам нужен для результата:
```swift
let item: Any = 2.5
if let number = item as? Int {
    print(Double(number))
} else if let number = item as? Double {
    print(number)
}
```
Значение `Int`, хранящееся в `Any`, всё равно остаётся `Int`: `as? Double` для него возвращает `nil`, потому что `as?` проверяет тип, а не преобразует числа.

# --instructions--

Напишите функцию `sumNumbers`, которая принимает массив `Any` (без метки аргумента) и возвращает сумму его элементов `Int` и `Double` как `Double`, игнорируя элементы любого другого типа

Пример вызова функции:
```swift
print(sumNumbers([1, 2.5, "x"]))
// prints 3.5
```

# --solutions--

```swift
func sumNumbers(_ values: [Any]) -> Double {
    var total = 0.0
    for value in values {
        if let number = value as? Int {
            total += Double(number)
        } else if let number = value as? Double {
            total += number
        }
    }
    return total
}
```
