**Set** — это коллекция, которая хранит значения одного типа без определённого порядка и, самое главное, **без дубликатов**: каждое значение встречается не более одного раза.
Множества идеальны, когда важно только то, *какие* значения присутствуют, а не сколько раз или в какой позиции.
Вы объявляете множество с типом `Set<Element>` и литералом в стиле массива:
```swift
let numbers: Set<Int> = [1, 2, 3]
```
Аннотация типа обязательна: без неё Swift создал бы массив.
Если литерал содержит значение более одного раза, множество сохраняет только одну копию:
```swift
let rolls: Set<Int> = [6, 6, 6]
print(rolls.count) // 1
```
Свойство `count` показывает, сколько различных значений содержит множество.

---

Как и массивы, множества могут быть константами (`let`) или переменными (`var`). Изменить после создания можно только множество `var`.
Чтобы создать пустое множество, вы вызываете инициализатор типа, потому что один лишь пустой литерал `[]` не сообщил бы Swift, какой тип элементов использовать:
```swift
var visited = Set<String>()
print(visited.isEmpty) // true
```
Свойство `isEmpty` равно `true`, когда множество не содержит элементов, точно так же, как и у массивов.

---

Поскольку множество никогда не хранит одно и то же значение дважды, его `count` — это количество *различных* значений, независимо от того, сколько раз каждое из них было записано в литерале.

---

Чтобы проверить, есть ли значение в множестве, используйте метод `contains(_:)`, который возвращает `Bool`:
```swift
let primes: Set<Int> = [2, 3, 5, 7]
print(primes.contains(5)) // true
print(primes.contains(6)) // false
```
Эта проверка выполняется очень быстро для множества, даже с тысячами элементов, что является одной из главных причин предпочитать множество массиву при проверке принадлежности.

---

Множество `var` можно изменять с помощью `insert(_:)` и `remove(_:)`:
```swift
var numbers: Set<Int> = [1, 2]
numbers.insert(3) // {1, 2, 3}
numbers.insert(2) // 2 уже там: ничего не меняется
numbers.remove(1) // {2, 3}
numbers.remove(9) // 9 там нет: ничего не меняется
```
Вставка значения, которое уже присутствует, не имеет эффекта, а удаление отсутствующего значения не вызывает ошибки.
`remove(_:)` возвращает удалённое значение как опциональное (`nil`, если ничего не было удалено), чтобы вы могли проверить, действительно ли удаление произошло.
Чтобы полностью очистить множество, вызовите `removeAll()`.

---

Вы можете перебирать множество с помощью `for`-`in`, но помните, что множество **не имеет определённого порядка**: элементы могут появляться в любом порядке, и этот порядок может меняться между запусками.
Когда порядок важен, сначала вызовите `sorted()`: он возвращает новый **массив** с элементами в порядке возрастания, оставляя множество без изменений.
```swift
let numbers: Set<Int> = [3, 1, 2]
for number in numbers.sorted() {
    print(number) // 1, 2, 3 на отдельных строках
}
```

---

Множества поддерживают классические операции теории множеств. Каждая из них возвращает **новое** множество и оставляет исходные без изменений:
- `a.union(b)` содержит каждый элемент, который есть в `a`, в `b`, или в обоих
- `a.intersection(b)` содержит только элементы, которые есть **в обоих** `a` и `b`
```swift
let a: Set<Int> = [1, 2, 3]
let b: Set<Int> = [3, 4]
print(a.union(b).sorted())        // [1, 2, 3, 4]
print(a.intersection(b).sorted()) // [3]
```

---

Ещё две операции дополняют это семейство:
- `a.subtracting(b)` содержит элементы `a`, которых **нет** в `b`
- `a.symmetricDifference(b)` содержит элементы, которые есть в `a` или в `b`, но **не в обоих**
```swift
let a: Set<Int> = [1, 2, 3]
let b: Set<Int> = [3, 4]
print(a.subtracting(b).sorted())          // [1, 2]
print(a.symmetricDifference(b).sorted())  // [1, 2, 4]
```
В отличие от `union` и `intersection`, `subtracting` не симметрична: `a.subtracting(b)` и `b.subtracting(a)` обычно различаются.

---

Множества также можно сравнивать друг с другом. Эти методы возвращают `Bool`:
- `a.isSubset(of: b)` равно `true`, когда каждый элемент `a` также есть в `b`
- `a.isSuperset(of: b)` равно `true`, когда `a` содержит каждый элемент `b`
- `a.isDisjoint(with: b)` равно `true`, когда у `a` и `b` нет общих элементов
```swift
let small: Set<Int> = [1, 2]
let big: Set<Int> = [1, 2, 3]
print(small.isSubset(of: big))   // true
print(big.isSuperset(of: small)) // true
print(small.isDisjoint(with: big)) // false
```

---

Множества и массивы легко преобразуются друг в друга.
Передача массива в `Set(...)` строит множество из его элементов, что является самым быстрым способом **удалить дубликаты**:
```swift
let votes = [3, 1, 3, 2, 1]
let unique = Set(votes) // {1, 2, 3} в каком-то порядке
```
Передача множества в `Array(...)` возвращает массив, но поскольку у множества нет порядка, элементы появляются в непредсказуемой последовательности.
Поэтому, когда вам нужен упорядоченный результат, вы обычно вызываете `sorted()` на множестве, который уже возвращает массив:
```swift
let ordered = unique.sorted() // [1, 2, 3]
```
