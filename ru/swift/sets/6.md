# --description--

Вы можете перебирать множество с помощью `for`-`in`, но помните, что множество **не имеет определённого порядка**: элементы могут появляться в любом порядке, и этот порядок может меняться между запусками.
Когда порядок важен, сначала вызовите `sorted()`: он возвращает новый **массив** с элементами в порядке возрастания, оставляя множество без изменений.
```swift
let numbers: Set<Int> = [3, 1, 2]
for number in numbers.sorted() {
    print(number) // 1, 2, 3 on separate lines
}
```
