# --description--

Множества поддерживают классические операции теории множеств. Каждая из них возвращает **новое** множество и оставляет исходные без изменений:
- `a.union(b)` содержит каждый элемент, который есть в `a`, в `b`, или в обоих
- `a.intersection(b)` содержит только элементы, которые есть **в обоих** `a` и `b`
```swift
let a: Set<Int> = [1, 2, 3]
let b: Set<Int> = [3, 4]
print(a.union(b).sorted())        // [1, 2, 3, 4]
print(a.intersection(b).sorted()) // [3]
```
