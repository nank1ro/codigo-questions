# --description--

Иногда значения просто нет: у пользователя может не быть отчества, поиск может ничего не найти, текст может не преобразовываться в число.
Swift представляет отсутствующее значение с помощью `nil`, но обычная переменная никогда не может его содержать:
```swift
var age: Int = nil // error: 'nil' cannot initialize type 'Int'
```
Чтобы допустить отсутствующее значение, вы объявляете **опциональный** тип, добавляя знак вопроса `?` после типа.
`Int?` содержит либо `Int`, либо `nil`:
```swift
var age: Int? = 30
age = nil // разрешено
```
Опциональная переменная, объявленная без значения, изначально равна `nil`.
