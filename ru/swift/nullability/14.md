# --description--

Привязка нескольких опциональных значений в одном `if let` делает код плоским: один блок `else` покрывает все случаи отсутствующих значений.

# --instructions--

Расположите элементы так, чтобы напечатать `Area: 20`, когда и `width`, и `height` имеют значение, и `Missing size` в противном случае.
Объявите `width` перед `height`

# --answers--

```swift
let width: Int? = 4
```

```swift
let height: Int? = 5
```

```swift
if let w = width, let h = height {
```

```swift

```

```swift

    print("Missing size")
}
```

# --solutions--

```swift
let width: Int? = 4
let height: Int? = 5
if let w = width, let h = height {
    print("Area: \(w * h)")
} else {
    print("Missing size")
}
```

# --output--

Area: 20
