Иногда значения просто нет: у пользователя может не быть отчества, поиск может ничего не найти, текст может не преобразовываться в число.
Swift представляет отсутствующее значение с помощью `nil`, но обычная переменная никогда не может его содержать:
```swift
var age: Int = nil // error: 'nil' cannot initialize type 'Int'
```
Чтобы допустить отсутствующее значение, вы объявляете **опциональный** тип, добавляя знак вопроса `?` после типа.
`Int?` содержит либо `Int`, либо `nil`:
```swift
var age: Int? = 30
age = nil // разрешено
```
Опциональная переменная, объявленная без значения, изначально равна `nil`.

---

Вы можете сравнить опциональное значение с `nil` с помощью `==` и `!=`, а также сравнить его напрямую с обычным значением того же типа:
```swift
var score: Int? = 10
print(score == nil) // false
print(score == 10)  // true
```
Помните, что `Int?` и `Int` — это два разных типа: `Int?` может быть пустым, `Int` — никогда.

---

Опциональное значение похоже на коробку: прежде чем использовать значение внутри, вы должны её открыть, и Swift называет это **разворачиванием**.
Самый быстрый способ — **принудительное разворачивание** с помощью восклицательного знака `!`:
```swift
let score: Int? = 10
print(score! + 5) // 15
```
`!` сообщает Swift: "я уверен, что здесь есть значение". Если вы ошиблись и опциональное значение равно `nil`, программа немедленно останавливается с аварийным завершением во время выполнения:
```swift
let missing: Int? = nil
print(missing! + 5) // Fatal error: Unexpectedly found nil
```
Именно поэтому принудительное разворачивание считается опасным: используйте его, только когда уверены, что значение существует.

---

Принудительное разворачивание безопасно только тогда, когда вы уже проверили, что опциональное значение не равно `nil`:
```swift
if score != nil {
    print(score! * 2)
}
```

---

Проверять на `nil`, а затем принудительно разворачивать — многословно. Swift предлагает **опциональное связывание** с помощью `if let`, которое разворачивает опциональное значение и сохраняет его в новой константе за один шаг:
```swift
let score: Int? = 10
if let value = score {
    print("Score: \(value)") // value — это Int, а не Int?
} else {
    print("No score")
}
```
Тело `if` выполняется только тогда, когда опциональное значение не пусто; внутри него `value` — это обычный `Int`, не требующий `!`.

---

Когда отсутствие значения означает "остановись здесь", `guard let` понятнее, чем `if let`.
Он разворачивает опциональное значение и, если это не удаётся, выполняет блок `else`, который должен покинуть текущую область видимости (с помощью `return`, `break`, `continue` или `throw`):
```swift
func greet(_ name: String?) {
    guard let name = name else {
        print("Nobody here")
        return
    }
    print("Hello, \(name)!") // начиная отсюда name — это String
}
```
В отличие от `if let`, развёрнутая константа остаётся доступной до конца функции, поэтому основной путь выполнения не вложен внутрь `if`.

---

Типичное применение `guard let` — проверка входных данных функции в самом начале и возврат значения по умолчанию, если данные отсутствуют:
```swift
func length(of text: String?) -> Int {
    guard let text = text else { return 0 }
    return text.count
}
```

---

Очень часто от опционального значения нужно лишь его значение либо значение по умолчанию.
**Оператор объединения с nil** `??` делает именно это: он разворачивает опциональное значение, если оно есть, иначе возвращает значение справа от себя:
```swift
let score: Int? = nil
let points = score ?? 0 // points — это Int, равный 0
```
Значение по умолчанию должно иметь тот же тип, что и обёрнутое значение.
Вы можете объединять несколько `??` в цепочку: побеждает первое значение, не равное `nil`.
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0) // 7
```

---

`??` — самый короткий способ превратить опциональное значение в обычное, когда есть подходящее значение по умолчанию:
```swift
func volume(from setting: Int?) -> Int {
    return setting ?? 50
}
```

---

При объединении `??` Swift вычисляет выражение слева направо и останавливается на первом значении, не равном `nil`; последнее значение по умолчанию используется только тогда, когда все предыдущие опциональные значения равны `nil`.

---

Доступ к свойству или вызов метода у опционального значения потребовал бы сначала его развернуть.
**Опциональная цепочка** с `?.` делает это за вас: если опциональное значение равно `nil`, всё выражение становится `nil`, иначе доступ выполняется как обычно:
```swift
let name: String? = "swift"
let upper = name?.uppercased() // String?, содержащий "SWIFT"
```
Результат всегда опциональный, даже если само свойство таковым не является.
Цепочки могут быть настолько длинными, насколько нужно, и хорошо сочетаются с `??`:
```swift
class User {
    var nickname: String? = "ace"
}
let user: User? = User()
print(user?.nickname?.count ?? 0) // 3
```

---

Опциональная цепочка особенно полезна, когда данные могут отсутствовать на нескольких уровнях: объект может быть `nil`, и одно из его свойств тоже может быть `nil`.
Одна цепочка `?.` обрабатывает оба случая без единого `if`.

---

Один `if let` или `guard let` может развернуть сразу несколько опциональных значений: разделите привязки запятыми.
Тело выполняется только тогда, когда каждое опциональное значение содержит значение:
```swift
let first: String? = "Ada"
let last: String? = "Lovelace"
if let first = first, let last = last {
    print("\(first) \(last)")
}
```
Вы также можете добавить логическое условие после привязок, например `if let n = number, n > 0`.

---

Привязка нескольких опциональных значений в одном `if let` делает код плоским: один блок `else` покрывает все случаи отсутствующих значений.

---

Многие операции могут завершиться неудачей, и Swift сообщает об этом, возвращая опциональное значение.
Преобразование текста в число — классический пример: `Int("42")` возвращает `Int?` со значением `42`, а `Int("abc")` возвращает `nil`.
`Int("3.5")` тоже равно `nil`, потому что текст не является целым числом; используйте `Double("3.5")` для дробных чисел.
```swift
let typed = "42"
if let number = Int(typed) {
    print(number + 1) // 43
}
```
Другие примеры — `array.first` (`nil` для пустого массива) и `dictionary[key]` (`nil`, если ключ отсутствует).

---

Поскольку преобразование может завершиться неудачей, его результат всегда опциональный и должен быть развёрнут перед использованием, даже когда вы уверены, что текст представляет собой корректное число.

---

Ненадёжные преобразования естественно сочетаются с `guard let`: преобразуйте, прервите выполнение, если результат равен `nil`, а затем работайте с обычным значением.

---

Иногда нужно преобразовать значение внутри опционального значения и сохранить результат опциональным, не разворачивая и не оборачивая его вручную.
У опциональных значений есть метод `map`: он применяет замыкание к значению, если оно есть, и возвращает `nil` в противном случае.
```swift
let score: Int? = 10
let doubled = score.map { $0 * 2 } // Int?, содержащий 20
let missing: Int? = nil
let stillMissing = missing.map { $0 * 2 } // nil
```
В сочетании с ненадёжным преобразованием получается компактный конвейер: `Int(text).map { $0 + 1 }`.
