# --description--

Проверять на `nil`, а затем принудительно разворачивать — многословно. Swift предлагает **опциональное связывание** с помощью `if let`, которое разворачивает опциональное значение и сохраняет его в новой константе за один шаг:
```swift
let score: Int? = 10
if let value = score {
    print("Score: \(value)") // value — это Int, а не Int?
} else {
    print("No score")
}
```
Тело `if` выполняется только тогда, когда опциональное значение не пусто; внутри него `value` — это обычный `Int`, не требующий `!`.

# --instructions--

Напишите функцию `describe`, которая принимает `Int?` (без метки аргумента) и возвращает `"Value: "` с добавленным числом (например, `"Value: 5"` для `5`), когда опциональное значение содержит значение, или `"No value"`, когда оно равно `nil`
