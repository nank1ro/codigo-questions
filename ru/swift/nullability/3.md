# --description--

Опциональное значение похоже на коробку: прежде чем использовать значение внутри, вы должны её открыть, и Swift называет это **разворачиванием**.
Самый быстрый способ — **принудительное разворачивание** с помощью восклицательного знака `!`:
```swift
let score: Int? = 10
print(score! + 5) // 15
```
`!` сообщает Swift: "я уверен, что здесь есть значение". Если вы ошиблись и опциональное значение равно `nil`, программа немедленно останавливается с аварийным завершением во время выполнения:
```swift
let missing: Int? = nil
print(missing! + 5) // Fatal error: Unexpectedly found nil
```
Именно поэтому принудительное разворачивание считается опасным: используйте его, только когда уверены, что значение существует.

# --instructions--

Что произойдёт, если принудительно развернуть опциональное значение, содержащее `nil`?

# --answers--

- Программа аварийно завершится во время выполнения
- Выражение примет значение 0
- Компилятор сообщит об ошибке
- Значение будет незаметно преобразовано в пустую строку
