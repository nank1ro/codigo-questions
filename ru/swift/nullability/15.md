# --description--

Многие операции могут завершиться неудачей, и Swift сообщает об этом, возвращая опциональное значение.
Преобразование текста в число — классический пример: `Int("42")` возвращает `Int?` со значением `42`, а `Int("abc")` возвращает `nil`.
`Int("3.5")` тоже равно `nil`, потому что текст не является целым числом; используйте `Double("3.5")` для дробных чисел.
```swift
let typed = "42"
if let number = Int(typed) {
    print(number + 1) // 43
}
```
Другие примеры — `array.first` (`nil` для пустого массива) и `dictionary[key]` (`nil`, если ключ отсутствует).
