# --description--

Когда отсутствие значения означает "остановись здесь", `guard let` понятнее, чем `if let`.
Он разворачивает опциональное значение и, если это не удаётся, выполняет блок `else`, который должен покинуть текущую область видимости (с помощью `return`, `break`, `continue` или `throw`):
```swift
func greet(_ name: String?) {
    guard let name = name else {
        print("Nobody here")
        return
    }
    print("Hello, \(name)!") // начиная отсюда name — это String
}
```
В отличие от `if let`, развёрнутая константа остаётся доступной до конца функции, поэтому основной путь выполнения не вложен внутрь `if`.
