# --description--

При объединении `??` Swift вычисляет выражение слева направо и останавливается на первом значении, не равном `nil`; последнее значение по умолчанию используется только тогда, когда все предыдущие опциональные значения равны `nil`.

# --instructions--

Что напечатает этот код?
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0)
```

# --answers--

- 7
- 0
- nil
- Optional(7)
