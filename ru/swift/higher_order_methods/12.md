# --description--

`forEach` — это аналог цикла `for-in` из мира функций высшего порядка: он вызывает замыкание один раз для каждого элемента, по порядку. Разница в том, как вы покидаете цикл. В `for-in` можно выйти через `break` или продолжить через `continue`; внутри замыкания `forEach` `break` и `continue` не допускаются, а `return` завершает только **текущий вызов** замыкания, после чего следующий элемент обрабатывается как обычно:
```swift
[1, 2, 3].forEach { n in
    if n == 2 { return }
    print(n)
}
// prints 1 and 3
```
Используйте `forEach` для короткого побочного эффекта на каждом элементе, а `for-in` — когда нужно остановиться раньше.

var total = 0
