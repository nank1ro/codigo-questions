# --description--

`flatMap` предназначен для замыканий, возвращающих **массив**: вместо построения массива массивов он объединяет все возвращённые массивы в один плоский результат:
```swift
let teams = [["Ann", "Bob"], ["Cid"]]
print(teams.map { $0 })     // [["Ann", "Bob"], ["Cid"]]
print(teams.flatMap { $0 }) // ["Ann", "Bob", "Cid"]
```
Замыкание также может преобразовать каждый внутренний массив перед сведением, например `teams.flatMap { $0.reversed() }` даёт `["Bob", "Ann", "Cid"]`.
