# --description--

`reduce` создаёт новое накопленное значение на каждом шаге, что расточительно, когда результатом является массив или словарь. `reduce(into:)` передаёт замыканию аккумулятор как параметр `inout`, поэтому его можно изменять на месте без `return`:
```swift
let words = ["a", "b", "a"]
let counts = words.reduce(into: [String: Int]()) { result, word in
    result[word, default: 0] += 1
}
print(counts["a"]!) // 2
```
`[String: Int]()` создаёт пустой словарь, а `result[word, default: 0]` читает текущее количество или `0`, когда ключ отсутствует.
