# --description--

`Dictionary(grouping:by:)` разбивает коллекцию на словарь массивов. Замыкание вычисляет **ключ** каждого элемента, и все элементы с одинаковым ключом попадают в один массив:
```swift
let words = ["apple", "bee", "avocado"]
let byInitial = Dictionary(grouping: words, by: { $0.first! })
print(byInitial["a"]!) // ["apple", "avocado"]
```
`mapValues` преобразует каждое значение словаря, сохраняя ключи, поэтому это естественный следующий шаг после группировки:
```swift
let sizes = byInitial.mapValues { $0.count }
print(sizes["a"]!) // 2
```

func countByLength(_ words: [String]) -> [Int: Int] {
    return Dictionary(grouping: words, by: { $0.count }).mapValues { $0.count }
}
