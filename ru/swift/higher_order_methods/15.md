# --description--

Вы можете писать собственные функции высшего порядка. Функция, которая принимает замыкание и **возвращает новое замыкание**, построенное на его основе, — распространённый шаблон: возвращаемое замыкание захватывает исходное, поэтому параметр должен быть `@escaping`.
Например, `negate` превращает предикат в его противоположность, готовый к передаче в `filter`:
```swift
func negate(_ predicate: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { !predicate($0) }
}
let isEven: (Int) -> Bool = { $0 % 2 == 0 }
print([1, 2, 3, 4].filter(negate(isEven))) // [1, 3]
```
Обратите внимание, что `filter(negate(isEven))` передаёт замыкание как обычный аргумент, без синтаксиса завершающего замыкания.

# --instructions--

Напишите функцию `both`, которая принимает два замыкания типа `(Int) -> Bool` (опустите обе метки аргументов) и возвращает замыкание того же типа, которое равно `true`, только когда оба из них равны `true` для одного и того же аргумента

Пример вызова функции:
```swift
let smallEven = both({ $0 < 10 }, { $0 % 2 == 0 })
print([4, 12, 7, 8].filter(smallEven))
// prints [4, 8]
```

```swift

```

`both({ $0 < 10 }, { $0 % 2 == 0 })` должно быть `false` для `12`

```swift

```

`both({ $0 < 10 }, { $0 % 2 == 0 })` должно быть `false` для `7`

```swift
tryCatch(both({ $0 < 10 }, { $0 % 2 == 0 })(7) == false)
```

Возвращённое замыкание должно работать с `filter`

```swift

func both(_ first: @escaping (Int) -> Bool, _ second: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { first($0) && second($0) }
}
```
