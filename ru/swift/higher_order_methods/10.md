# --description--

`enumerated()` превращает массив в последовательность пар `(offset, element)`, поэтому замыкание может использовать позицию каждого элемента вместе с его значением:
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
Поскольку каждая пара является кортежем, замыкание также может разложить её: `.map { (i, step) in "\(i + 1). \(step)" }`.

func evenPositions(_ items: [String]) -> [String] {
    return items.enumerated().filter { $0.offset % 2 == 0 }.map { $0.element }
}
