**Функция высшего порядка** — это функция, которая принимает другую функцию как аргумент, возвращает её или делает и то и другое. Вы уже встречали `map`, `filter`, `reduce` и `sorted(by:)`: они принимают замыкание и применяют его к элементам коллекции. В Swift таких функций гораздо больше, и их знание позволяет заменять длинные циклы одной читаемой строкой.
`compactMap` работает как `map`, но замыкание возвращает опциональное значение, а результаты `nil` отбрасываются:
```swift
let words = ["3", "seven", "12"]
let numbers = words.compactMap { Int($0) }
print(numbers) // [3, 12]
```
`Int("seven")` — это `nil`, поэтому этот элемент исчезает, а результатом является `[Int]`, а не `[Int?]`.

---

`flatMap` предназначен для замыканий, возвращающих **массив**: вместо построения массива массивов он объединяет все возвращённые массивы в один плоский результат:
```swift
let teams = [["Ann", "Bob"], ["Cid"]]
print(teams.map { $0 })     // [["Ann", "Bob"], ["Cid"]]
print(teams.flatMap { $0 }) // ["Ann", "Bob", "Cid"]
```
Замыкание также может преобразовать каждый внутренний массив перед сведением, например `teams.flatMap { $0.reversed() }` даёт `["Bob", "Ann", "Cid"]`.

---

Три варианта `map` отличаются только тем, что возвращает замыкание:
- `map`: любое значение, один результат на элемент
- `compactMap`: опциональное значение, результаты `nil` отбрасываются
- `flatMap`: массив, все результаты объединяются в один массив

Замыкание, переданное в `flatMap`, может само вызывать `map` для внутреннего массива, вкладывая одно преобразование в другое:
```swift
let matrix = [[1, 2], [3]]
print(matrix.flatMap { row in row.map { $0 + 1 } }) // [2, 3, 4]
```

---

`reduce` создаёт новое накопленное значение на каждом шаге, что расточительно, когда результатом является массив или словарь. `reduce(into:)` передаёт замыканию аккумулятор как параметр `inout`, поэтому его можно изменять на месте без `return`:
```swift
let words = ["a", "b", "a"]
let counts = words.reduce(into: [String: Int]()) { result, word in
    result[word, default: 0] += 1
}
print(counts["a"]!) // 2
```
`[String: Int]()` создаёт пустой словарь, а `result[word, default: 0]` читает текущее количество или `0`, когда ключ отсутствует.

---

Некоторые функции высшего порядка отвечают на вопрос о коллекции вместо её преобразования. Все они принимают замыкание, возвращающее `Bool`:
- `first(where:)` возвращает первый элемент, удовлетворяющий замыканию, или `nil`, если такого нет
- `contains(where:)` возвращает `true`, если хотя бы один элемент удовлетворяет ему
- `allSatisfy` возвращает `true`, если каждый элемент удовлетворяет ему

```swift
let nums = [4, 9, 16]
print(nums.first(where: { $0 > 5 }))  // Optional(9)
print(nums.contains(where: { $0 > 5 })) // true
print(nums.allSatisfy { $0 > 5 })       // false
```
В отличие от `filter`, `first(where:)` останавливается на первом совпадении и не строит новый массив.

---

`contains(where:)` и `allSatisfy` заменяют распространённый шаблон цикла с переменной-флагом. Оба останавливаются, как только ответ становится известен: `contains(where:)` — на первом совпадении, `allSatisfy` — на первом элементе, который не проходит проверку.
```swift
let ages = [15, 22, 40]
let anyMinor = ages.contains { $0 < 18 }  // true
let allAdults = ages.allSatisfy { $0 >= 18 } // false
```
`contains { ... }` — это форма завершающего замыкания для `contains(where:)`, её не следует путать с `contains(_:)`, которая ищет конкретное значение.

---

Функции высшего порядка работают с любым массивом, включая массивы ваших собственных структур. Цепочка из `filter`, а затем `map` — обычный способ выбрать некоторые элементы и извлечь значение из каждого:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
Сделав это в обратном порядке — сначала `map`, затем `filter`, — вы потеряли бы свойство `pages` до того, как проверка смогла бы его использовать.

---

Когда замыкание только читает одно свойство, вместо него можно передать **ключевой путь**: `\.name` означает «свойство `name` элемента», а `map(\.name)` — это то же самое, что `map { $0.name }`.
Сортировка по свойству использует обычное замыкание с двумя аргументами, сравнивающее это свойство у обоих элементов:
```swift
struct City {
    var name: String
    var population: Int
}
let cities = [City(name: "Oslo", population: 700), City(name: "Rome", population: 2800)]
let byPopulation = cities.sorted { $0.population > $1.population }
print(byPopulation.map(\.name)) // ["Rome", "Oslo"]
```

---

Чтобы сортировать по **нескольким критериям**, сравните первое свойство и переходите ко второму только тогда, когда первые значения равны:
```swift
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age < $1.age
    }
    return $0.name < $1.name
}
```
Здесь люди упорядочены по возрасту, а люди с одинаковым возрастом упорядочены по имени. Замыкание должно возвращать `true` только тогда, когда первый элемент должен идти перед вторым, поэтому случай равенства переходит к следующему сравнению.

---

`enumerated()` превращает массив в последовательность пар `(offset, element)`, поэтому замыкание может использовать позицию каждого элемента вместе с его значением:
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
Поскольку каждая пара является кортежем, замыкание также может разложить её: `.map { (i, step) in "\(i + 1). \(step)" }`.

---

`zip` соединяет элементы двух последовательностей позиция за позицией, создавая последовательность кортежей. Он останавливается в конце более короткой:
```swift
let names = ["Ann", "Bob"]
let ages = [31, 27, 99]
let pairs = zip(names, ages).map { "\($0) is \($1)" }
print(pairs) // ["Ann is 31", "Bob is 27"]
```
Внутри замыкания `$0` — это элемент из первой последовательности, а `$1` — из второй. `zip` — это свободная функция, а не метод: вы пишете `zip(a, b)`, а не `a.zip(b)`.

---

`forEach` — это аналог цикла `for-in` из мира функций высшего порядка: он вызывает замыкание один раз для каждого элемента, по порядку. Разница в том, как вы покидаете цикл. В `for-in` можно выйти через `break` или продолжить через `continue`; внутри замыкания `forEach` `break` и `continue` не допускаются, а `return` завершает только **текущий вызов** замыкания, после чего следующий элемент обрабатывается как обычно:
```swift
[1, 2, 3].forEach { n in
    if n == 2 { return }
    print(n)
}
// prints 1 and 3
```
Используйте `forEach` для короткого побочного эффекта на каждом элементе, а `for-in` — когда нужно остановиться раньше.

---

`Dictionary(grouping:by:)` разбивает коллекцию на словарь массивов. Замыкание вычисляет **ключ** каждого элемента, и все элементы с одинаковым ключом попадают в один массив:
```swift
let words = ["apple", "bee", "avocado"]
let byInitial = Dictionary(grouping: words, by: { $0.first! })
print(byInitial["a"]!) // ["apple", "avocado"]
```
`mapValues` преобразует каждое значение словаря, сохраняя ключи, поэтому это естественный следующий шаг после группировки:
```swift
let sizes = byInitial.mapValues { $0.count }
print(sizes["a"]!) // 2
```

---

`prefix(while:)` берёт элементы с начала **пока** замыкание возвращает `true`, и останавливается на первом элементе, который не проходит, даже если последующие элементы снова могли бы пройти. `drop(while:)` — его дополнение: он пропускает ту же начальную серию и возвращает всё остальное:
```swift
let temps = [12, 15, 21, 14]
print(temps.prefix { $0 < 20 }) // [12, 15]
print(temps.drop { $0 < 20 })   // [21, 14]
```
Оба возвращают `ArraySlice` — представление исходного массива, которое печатается как массив и может быть превращено в него с помощью `Array(...)`.

---

Вы можете писать собственные функции высшего порядка. Функция, которая принимает замыкание и **возвращает новое замыкание**, построенное на его основе, — распространённый шаблон: возвращаемое замыкание захватывает исходное, поэтому параметр должен быть `@escaping`.
Например, `negate` превращает предикат в его противоположность, готовый к передаче в `filter`:
```swift
func negate(_ predicate: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { !predicate($0) }
}
let isEven: (Int) -> Bool = { $0 % 2 == 0 }
print([1, 2, 3, 4].filter(negate(isEven))) // [1, 3]
```
Обратите внимание, что `filter(negate(isEven))` передаёт замыкание как обычный аргумент, без синтаксиса завершающего замыкания.

---

`map` и `filter` на массиве **энергичны**: каждый обрабатывает весь массив и строит новый, прежде чем выполнится следующий шаг. На большой коллекции, или когда нужен только первый результат, это напрасная работа.
Свойство `lazy` возвращает представление, операции которого выполняются только тогда, когда элемент реально запрошен, по одному элементу за раз через всю цепочку:
```swift
let firstBig = (1...1000).lazy.map { $0 * $0 }.first { $0 > 50 }
print(firstBig!) // 64
```
Здесь возводятся в квадрат только `1, 2, ..., 8`: `first(where:)` запрашивает элементы, пока один не удовлетворит условию, и цепочка останавливается там. Без `lazy`, `map` сначала возвела бы в квадрат все 1000 чисел.
