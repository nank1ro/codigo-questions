# --description--

`prefix(while:)` берёт элементы с начала **пока** замыкание возвращает `true`, и останавливается на первом элементе, который не проходит, даже если последующие элементы снова могли бы пройти. `drop(while:)` — его дополнение: он пропускает ту же начальную серию и возвращает всё остальное:
```swift
let temps = [12, 15, 21, 14]
print(temps.prefix { $0 < 20 }) // [12, 15]
print(temps.drop { $0 < 20 })   // [21, 14]
```
Оба возвращают `ArraySlice` — представление исходного массива, которое печатается как массив и может быть превращено в него с помощью `Array(...)`.
