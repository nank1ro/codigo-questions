# --description--

Чтобы сортировать по **нескольким критериям**, сравните первое свойство и переходите ко второму только тогда, когда первые значения равны:
```swift
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age < $1.age
    }
    return $0.name < $1.name
}
```
Здесь люди упорядочены по возрасту, а люди с одинаковым возрастом упорядочены по имени. Замыкание должно возвращать `true` только тогда, когда первый элемент должен идти перед вторым, поэтому случай равенства переходит к следующему сравнению.

# --instructions--

Что выводит этот код?
```swift
struct Person {
    var name: String
    var age: Int
}
let people = [Person(name: "Zed", age: 30), Person(name: "Amy", age: 25), Person(name: "Bea", age: 30)]
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age > $1.age
    }
    return $0.name < $1.name
}
print(sorted.map(\.name))
```
