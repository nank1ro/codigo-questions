# --description--

Некоторые функции высшего порядка отвечают на вопрос о коллекции вместо её преобразования. Все они принимают замыкание, возвращающее `Bool`:
- `first(where:)` возвращает первый элемент, удовлетворяющий замыканию, или `nil`, если такого нет
- `contains(where:)` возвращает `true`, если хотя бы один элемент удовлетворяет ему
- `allSatisfy` возвращает `true`, если каждый элемент удовлетворяет ему

```swift
let nums = [4, 9, 16]
print(nums.first(where: { $0 > 5 }))  // Optional(9)
print(nums.contains(where: { $0 > 5 })) // true
print(nums.allSatisfy { $0 > 5 })       // false
```
В отличие от `filter`, `first(where:)` останавливается на первом совпадении и не строит новый массив.

func firstLong(_ words: [String], _ minLength: Int) -> String? {
    return words.first(where: { $0.count >= minLength })
}
