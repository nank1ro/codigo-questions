# --description--

Три варианта `map` отличаются только тем, что возвращает замыкание:
- `map`: любое значение, один результат на элемент
- `compactMap`: опциональное значение, результаты `nil` отбрасываются
- `flatMap`: массив, все результаты объединяются в один массив

Замыкание, переданное в `flatMap`, может само вызывать `map` для внутреннего массива, вкладывая одно преобразование в другое:
```swift
let matrix = [[1, 2], [3]]
print(matrix.flatMap { row in row.map { $0 + 1 } }) // [2, 3, 4]
```
