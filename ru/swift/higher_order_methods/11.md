# --description--

`zip` соединяет элементы двух последовательностей позиция за позицией, создавая последовательность кортежей. Он останавливается в конце более короткой:
```swift
let names = ["Ann", "Bob"]
let ages = [31, 27, 99]
let pairs = zip(names, ages).map { "\($0) is \($1)" }
print(pairs) // ["Ann is 31", "Bob is 27"]
```
Внутри замыкания `$0` — это элемент из первой последовательности, а `$1` — из второй. `zip` — это свободная функция, а не метод: вы пишете `zip(a, b)`, а не `a.zip(b)`.
