# --description--

`contains(where:)` и `allSatisfy` заменяют распространённый шаблон цикла с переменной-флагом. Оба останавливаются, как только ответ становится известен: `contains(where:)` — на первом совпадении, `allSatisfy` — на первом элементе, который не проходит проверку.
```swift
let ages = [15, 22, 40]
let anyMinor = ages.contains { $0 < 18 }  // true
let allAdults = ages.allSatisfy { $0 >= 18 } // false
```
`contains { ... }` — это форма завершающего замыкания для `contains(where:)`, её не следует путать с `contains(_:)`, которая ищет конкретное значение.
