# --description--

Возврат замыкания — удобный способ создавать настраиваемые функции. Параметры внешней функции захватываются замыканием, которое она возвращает:
```swift
func makeAdder(_ amount: Int) -> (Int) -> Int {
    return { $0 + amount }
}
let addFive = makeAdder(5)
print(addFive(10)) // 15
```
Тип возвращаемого значения `(Int) -> Int` описывает замыкание, а сокращение `$0` относится к аргументу этого замыкания, а не `makeAdder`.

# --instructions--

Напишите функцию `makeMultiplier`, которая принимает `Int` по имени `factor` (опустите метку аргумента) и возвращает замыкание типа `(Int) -> Int`, умножающее свой аргумент на `factor`

Пример вызова функции:
```swift
let double = makeMultiplier(2)
print(double(10))
// prints 20
```
