# --description--

Замыкания можно хранить в массивах, как и любое другое значение. Типом элемента является тип функции:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Перебор такого массива с последовательным вызовом каждого замыкания строит небольшой **конвейер** (pipeline) преобразований.

# --instructions--

Напишите функцию `pipeline`, которая принимает `Int` и массив замыканий типа `(Int) -> Int` (опустите обе метки аргументов) и возвращает результат последовательного применения каждого замыкания к результату предыдущего

Пример вызова функции:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
