# --description--

Замыкание, сохранённое в константе, можно передавать везде, где ожидается аргумент-замыкание, используя метку аргумента параметра:
```swift
let ascending = { (a: Int, b: Int) -> Bool in a < b }
print([3, 1, 2].sorted(by: ascending)) // [1, 2, 3]
```

```swift
let words = ["kiwi", "fig", "banana"]
let byLength = { (a: String, b: String) -> Bool in
    a.count < b.count
}
print(words.sorted(by: byLength))
```

# --output--

["fig", "kiwi", "banana"]
