**Замыкание** — это блок кода, который можно передавать и вызывать позже, как функцию без имени.
Полный синтаксис выражения замыкания помещает параметры и тип возвращаемого значения внутри фигурных скобок, за которыми следует ключевое слово `in` и тело:
```swift
{ (parameters) -> ReturnType in
    body
}
```
Как и любое другое значение, замыкание можно сохранить в константе, а затем вызвать по имени этой константы:
```swift
let greet = { (name: String) -> String in
    return "Hello, \(name)!"
}
print(greet("Ada")) // Hello, Ada!
```

---

Указывать все типы внутри замыкания часто не нужно. Когда константа имеет явный **тип функции**, Swift выводит типы параметров и возвращаемого значения, поэтому перед `in` достаточно перечислить только имена параметров:
```swift
let triple: (Int) -> Int = { n in
    return n * 3
}
```
Тип `(Int) -> Int` читается как "функция, которая принимает `Int` и возвращает `Int`".
Когда тело состоит из одного выражения, ключевое слово `return` тоже можно опустить, это называется **неявным возвратом**:
```swift
let triple: (Int) -> Int = { n in n * 3 }
print(triple(4)) // 12
```

---

Swift идёт ещё дальше: внутри замыкания можно ссылаться на аргументы с помощью **сокращённых имён аргументов** `$0`, `$1`, `$2` и так далее, не объявляя ни одного параметра и не используя ключевое слово `in`.
`$0` — это первый аргумент, `$1` — второй:
```swift
let add: (Int, Int) -> Int = { $0 + $1 }
print(add(2, 3)) // 5
```
Типы по-прежнему берутся из аннотации `(Int, Int) -> Int`.

---

Поскольку замыкания являются значениями, функция может принимать одно из них в качестве параметра. Тип параметра — это просто тип функции:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
Функция `apply` не знает, что делает `operation`, ей известно только, что та принимает `Int` и возвращает `Int`, и она вызывает её как любую другую функцию.

---

Когда замыкание является **последним** аргументом функции, его можно записать после закрывающей скобки вызова. Это синтаксис **завершающего замыкания** (trailing closure):
```swift
print(apply(5) { $0 + 1 }) // 6
```
Если замыкание — единственный аргумент, скобки можно опустить полностью:
```swift
func run(_ task: () -> Int) -> Int {
    return task()
}
print(run { 42 }) // 42
```
Обе формы вызывают ровно одну и ту же функцию, завершающий синтаксис просто легче читать, когда замыкание длинное.

---

Замыкания особенно хороши в методах массивов, принимающих их в качестве аргумента. `map` вызывает замыкание для каждого элемента и возвращает новый массив с результатами:
```swift
let nums = [1, 2, 3]
let doubled = nums.map { $0 * 2 }
print(doubled) // [2, 4, 6]
```
Исходный массив не изменяется. Поскольку `map` принимает единственный аргумент-замыкание, синтаксис завершающего замыкания — обычный способ его вызова.

---

`filter` оставляет только те элементы, для которых замыкание возвращает `true`. Замыкание получает один элемент и должно возвращать `Bool`:
```swift
let nums = [5, 12, 8, 20]
let big = nums.filter { $0 > 10 }
print(big) // [12, 20]
```
Элементы сохраняют свой исходный порядок, а результатом является новый массив того же типа элементов.

---

`reduce` объединяет все элементы в одно значение. Он принимает начальное значение и замыкание с двумя аргументами: накопленное на данный момент значение и текущий элемент. Замыкание возвращает новое накопленное значение:
```swift
let nums = [1, 2, 3, 4]
let product = nums.reduce(1) { $0 * $1 }
print(product) // 24
```
Здесь `$0` начинается как `1`, затем становится `1 * 1`, `1 * 2`, `2 * 3` и наконец `6 * 4`.
Поскольку `map`, `filter` и `reduce` возвращают значения, их можно объединять в цепочку: `nums.filter { $0 > 1 }.map { $0 * 10 }`.

---

`sorted(by:)` возвращает новый отсортированный массив. Замыкание получает два элемента и возвращает `true`, когда первый должен идти **перед** вторым:
```swift
let nums = [3, 1, 2]
print(nums.sorted { $0 < $1 }) // [1, 2, 3]
print(nums.sorted { $0 > $1 }) // [3, 2, 1]
```
Замыкание может сравнивать что угодно, например `words.sorted { $0.count < $1.count }` упорядочивает строки от самой короткой до самой длинной.
