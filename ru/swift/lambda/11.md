# --description--

Замыкание может использовать переменные, объявленные за пределами его тела. Оно **захватывает** их: переменная продолжает существовать, пока существует замыкание, даже после того как объявившая её функция завершила выполнение.
Это позволяет функции создавать замыкание с собственным приватным состоянием:
```swift
func makeCounter() -> () -> Int {
    var count = 0
    return {
        count += 1
        return count
    }
}
```
`() -> Int` — это тип замыкания без параметров, возвращающего `Int`. Каждый вызов возвращённого замыкания увеличивает одну и ту же захваченную переменную `count`:
```swift
let counter = makeCounter()
print(counter()) // 1
print(counter()) // 2
```
