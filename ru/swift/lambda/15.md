# --description--

По умолчанию замыкание, переданное функции, может использоваться только пока эта функция выполняется. Если функция сохраняет замыкание или возвращает другое замыкание, использующее его, замыкание **ускользает** (escapes) из функции, и его параметр нужно пометить `@escaping`:
```swift
func twice(_ task: @escaping () -> Int) -> () -> Int {
    return { task() * 2 }
}
let answer = twice { 21 }
print(answer()) // 42
```
Без `@escaping` компилятор сообщит об ошибке, потому что возвращённое замыкание использовало бы `task` уже после завершения `twice`.

# --instructions--

Напишите функцию `compose`, которая принимает два замыкания типа `(Int) -> Int` (опустите обе метки аргументов) и возвращает замыкание, применяющее к своему аргументу сначала первое, а затем второе

Пример вызова функции:
```swift
let addThenDouble = compose({ $0 + 1 }, { $0 * 2 })
print(addThenDouble(3))
// prints 8
```
