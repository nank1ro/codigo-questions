# --description--

Проверять весь текст с помощью `^` и `$` можно, но `wholeMatch(of:)` говорит об этом напрямую: он возвращает совпадение, только когда шаблон покрывает текст от первого символа до последнего, и `nil` в противном случае:
```swift
print("1a2b".wholeMatch(of: #/[0-9a-f]+/#) != nil) // true
print("1z".wholeMatch(of: #/[0-9a-f]+/#) != nil)   // false
```
Используйте `firstMatch(of:)`, чтобы найти что-то внутри текста, и `wholeMatch(of:)`, чтобы проверить, что текст имеет одну точную форму.

func isHex(_ text: String) -> Bool {
    return text.wholeMatch(of: #/[0-9a-f]+/#) != nil
}
