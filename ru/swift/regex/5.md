# --description--

`contains(_:)` лишь говорит да или нет. Чтобы получить совпавший текст, используйте `firstMatch(of:)`. Этот метод возвращает **опциональное совпадение**: `nil`, когда ничего не совпало, поэтому он естественно сочетается с `if let`.

Совпавший текст хранится в свойстве `0` совпадения, записываемом как `m.0`:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)` останавливается на первом совпадении, даже если в тексте их больше.
