# --description--

`m.0` — это не `String`, а `Substring`: представление исходного текста, а не копия. Оно выводится точно так же, как строка, но там, где требуется `String`, его нужно преобразовать:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
Инициализаторы чисел принимают `Substring` напрямую, поэтому `Int(m.0)` работает без обходного пути.

# --instructions--

Напишите функцию `firstNumber`, которая принимает текст (`String`) без метки аргумента и возвращает первую последовательность цифр как `String` или `"none"`, когда в тексте нет ни одной цифры

Пример вызова функции:
```swift
print(firstNumber("order 42 today 7"))
// выводит 42
```

```swift
func firstNumber(_ text: String) -> String {
    if let m = text.firstMatch(of: #/\d+/#) {
        return String(m.0)
    }
    return "none"
}
```
