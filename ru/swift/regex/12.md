# --description--

`replacing(_:with:)` заменяет каждое совпадение на фиксированный текст и возвращает новую `String`, оставляя исходный текст нетронутым:
```swift
let text = "a1 b22"
print(text.replacing(#/\d+/#, with: "#")) // a# b#
print(text)                               // a1 b22
```
Обратите внимание: `\d+` заменяет всю последовательность цифр одним `#`, тогда как `\d` заменял бы по одной цифре за раз. Шаблон решает, сколько текста исчезнет.
