# --description--

Литерал `#/ ... /#` фиксируется во время компиляции. Когда шаблон становится известен только во время выполнения, например потому что его ввёл пользователь, создайте его с помощью `Regex(_:)`:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
Этот инициализатор **бросает ошибку**: недопустимый шаблон, такой как `"["`, обнаруживается только во время работы программы, поэтому вызову нужен `try`, а ошибку необходимо либо обработать с помощью `do`/`catch` (или `try?`), либо пробросить дальше, пометив окружающую функцию как `throws`, как делает это упражнение. У регулярного выражения, созданного таким образом, нет пронумерованных свойств, известных во время компиляции, но `contains`, `matches(of:)` и `replacing` работают точно так же, как и раньше.

Пример вызова функции:
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// prints 2
```

# --solutions--

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
