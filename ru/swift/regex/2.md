# --description--

Несколько сокращений покрывают большинство шаблонов. Каждое из них соответствует ровно **одному** символу:
- `\d` — одна цифра
- `\w` — одна буква, цифра или знак подчёркивания
- `\s` — один пробел, табуляция или перевод строки
- `.` — любой отдельный символ

Чтобы соответствовать более чем одному символу, добавьте **квантификатор** сразу после шаблона:
- `+` означает один или несколько
- `*` означает ноль или несколько
- `?` означает ноль или один

Итак, `\w+` — это слово, `\s*` — необязательные пробельные символы, а `\d?` — необязательная цифра:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
Символ без специального значения просто соответствует самому себе, поэтому `#/cat/#` соответствует трём буквам `cat`.
