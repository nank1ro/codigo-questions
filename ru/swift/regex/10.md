# --description--

Шаблон может содержать несколько групп. Они нумеруются слева направо по открывающей скобке, поэтому вторая группа — `m.2`, третья — `m.3` и так далее:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` всегда остаётся всем совпадением, каково бы ни было количество групп.

# --instructions--

Напишите функцию `setting`, которая принимает текст (`String`) без метки аргумента, находит настройку, записанную как строчные буквы, знак `=` и цифры, и возвращает имя и значение, соединённые двоеточием, или `"none"`, когда в тексте нет такой настройки

Пример вызова функции:
```swift
print(setting("size=10"))
// prints size:10
```

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
