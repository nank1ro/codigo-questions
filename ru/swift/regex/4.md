# --description--

Когда ни одно из сокращений не подходит, перечислите допустимые символы в квадратных скобках. `[abc]` соответствует одной `a`, одной `b` или одной `c`, а дефис записывает диапазон:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
Число в фигурных скобках указывает, сколько раз повторяется предыдущий шаблон: `{3}` означает три раза, `{2,4}` — от двух до четырёх раз:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
Оборачивание шаблона в `^` и `$` вместе с количеством — обычный способ проверить, что весь текст имеет заданную форму.

Пример вызова функции:
```swift
print(isCode("ABC"))
```
