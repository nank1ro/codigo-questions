# --description--

`matches(of:)` возвращает **все** совпадения вместо первого, в виде массива. Массив никогда не бывает `nil`: когда ничего не совпало, он просто пуст, поэтому его можно сразу перебирать в цикле или преобразовывать:
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
Каждый элемент — это совпадение, поэтому `$0.0` внутри `map` — это совпавший текст:
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```
