# --description--

Поскольку `Int(_:)` принимает `Substring`, превращение найденного текста в числа занимает один шаг. Здесь удобен `compactMap`: он отбрасывает значения, которые оказываются `nil`:
```swift
let text = "a1 b22"
let numbers = text.matches(of: #/\d+/#).compactMap { Int($0.0) }
print(numbers) // [1, 22]
```
Используйте `map`, когда преобразуется каждый элемент, и `compactMap`, когда некоторые могут не преобразоваться.
