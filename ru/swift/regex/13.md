# --description--

`split(separator:)` также принимает регулярное выражение, что позволяет одному вызову обрабатывать разделители, которые записаны не всегда одинаково:
```swift
let line = "a, b;c"
let parts = line.split(separator: #/[,;]\s*/#)
print(parts.joined(separator: "|")) // a|b|c
```
Шаблон `[,;]\s*` означает «запятую или точку с запятой, за которыми следует любое количество пробельных символов», поэтому каждый разделитель поглощается целиком и пустое поле не появляется. Результат — массив из `Substring`.

# --instructions--

Что выводит этот код?
```swift
let line = "one,two;  three"
print(line.split(separator: #/[,;]\s*/#).joined(separator: "|"))
```

# --answers--

- `one|two|three`
- `one|two|  three`
- `one|two;  three`
- `one,two;  three`
