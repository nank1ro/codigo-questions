# --description--

**Регулярное выражение** (regex) — это небольшой шаблон, который описывает форму текста: «последовательность цифр», «слово, за которым следует знак равенства», «три заглавные буквы». Вместо того чтобы писать циклы по символам, вы один раз описываете форму и позволяете Swift найти совпадение.

Swift записывает регулярное выражение между `#/` и `/#`:
```swift
let digits = #/\d+/#
```
Внутри шаблона `\d` означает «любую цифру», а `+` — «один или несколько предыдущих элементов», поэтому `\d+` означает «последовательность из одной или нескольких цифр».

Самый простой вопрос, который можно задать, — содержит ли текст совпадение. `contains(_:)` принимает регулярное выражение и возвращает `Bool`:
```swift
print("order42".contains(#/\d+/#)) // true
print("order".contains(#/\d+/#))   // false
```
Всегда используйте форму `#/ ... /#`, показанную здесь: более короткая запись `/ ... /` сбивает компилятор с толку, когда шаблон написан прямо внутри вызова метода.
