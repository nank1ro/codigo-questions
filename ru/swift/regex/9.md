# --description--

Круглые скобки вокруг части шаблона создают **группу захвата**: всё совпадение по-прежнему `m.0`, а часть внутри скобок становится `m.1`:
```swift
let text = "id-42"
if let m = text.firstMatch(of: #/id-(\d+)/#) {
    print(m.0) // id-42
    print(m.1) // 42
}
```
Так вы сохраняете интересующий фрагмент и отбрасываете окружающий текст. Без скобок `m.1` вообще не существует, и код не компилируется.
