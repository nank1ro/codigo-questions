# --description--

Подсчёт скобок становится хрупким, как только шаблон разрастается. Дайте группе **имя**, записав `?<name>` сразу после её открывающей скобки, и читайте её как свойство совпадения:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
Именованные группы по-прежнему нумеруются, поэтому `m.1` продолжает работать, но `m.key` говорит, что он содержит, и не ломается при изменении шаблона.
