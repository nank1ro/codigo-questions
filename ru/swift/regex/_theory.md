**Регулярное выражение** (regex) — это небольшой шаблон, который описывает форму текста: «последовательность цифр», «слово, за которым следует знак равенства», «три заглавные буквы». Вместо того чтобы писать циклы по символам, вы один раз описываете форму и позволяете Swift найти совпадение.

Swift записывает регулярное выражение между `#/` и `/#`:
```swift
let digits = #/\d+/#
```
Внутри шаблона `\d` означает «любую цифру», а `+` — «один или несколько предыдущих элементов», поэтому `\d+` означает «последовательность из одной или нескольких цифр».

Самый простой вопрос, который можно задать, — содержит ли текст совпадение. `contains(_:)` принимает регулярное выражение и возвращает `Bool`:
```swift
print("order42".contains(#/\d+/#)) // true
print("order".contains(#/\d+/#))   // false
```
Всегда используйте форму `#/ ... /#`, показанную здесь: более короткая запись `/ ... /` сбивает компилятор с толку, когда шаблон написан прямо внутри вызова метода.

---

Несколько сокращений покрывают большинство шаблонов. Каждое из них соответствует ровно **одному** символу:
- `\d` — одна цифра
- `\w` — одна буква, цифра или знак подчёркивания
- `\s` — один пробел, табуляция или перевод строки
- `.` — любой отдельный символ

Чтобы соответствовать более чем одному символу, добавьте **квантификатор** сразу после шаблона:
- `+` означает один или несколько
- `*` означает ноль или несколько
- `?` означает ноль или один

Итак, `\w+` — это слово, `\s*` — необязательные пробельные символы, а `\d?` — необязательная цифра:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
Символ без специального значения просто соответствует самому себе, поэтому `#/cat/#` соответствует трём буквам `cat`.

---

По умолчанию шаблон может совпасть в любом месте текста. **Якоря** привязывают его к позиции:
- `^` означает «начало текста»
- `$` означает «конец текста»

```swift
print("swift".contains(#/^sw/#))  // true, the text starts with sw
print("myswift".contains(#/^sw/#)) // false, sw is not at the start
print("swift".contains(#/ft$/#))  // true, the text ends with ft
```
Якоря соответствуют позиции, а не символу, поэтому они ничего не добавляют к содержимому совпадения.

---

Когда ни одно из сокращений не подходит, перечислите допустимые символы в квадратных скобках. `[abc]` соответствует одной `a`, одной `b` или одной `c`, а дефис записывает диапазон:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
Число в фигурных скобках указывает, сколько раз повторяется предыдущий шаблон: `{3}` означает три раза, `{2,4}` — от двух до четырёх раз:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
Оборачивание шаблона в `^` и `$` вместе с количеством — обычный способ проверить, что весь текст имеет заданную форму.

---

`contains(_:)` лишь говорит да или нет. Чтобы получить совпавший текст, используйте `firstMatch(of:)`. Этот метод возвращает **опциональное совпадение**: `nil`, когда ничего не совпало, поэтому он естественно сочетается с `if let`.

Совпавший текст хранится в свойстве `0` совпадения, записываемом как `m.0`:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)` останавливается на первом совпадении, даже если в тексте их больше.

---

`m.0` — это не `String`, а `Substring`: представление исходного текста, а не копия. Оно выводится точно так же, как строка, но там, где требуется `String`, его нужно преобразовать:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
Инициализаторы чисел принимают `Substring` напрямую, поэтому `Int(m.0)` работает без обходного пути.

---

`matches(of:)` возвращает **все** совпадения вместо первого, в виде массива. Массив никогда не бывает `nil`: когда ничего не совпало, он просто пуст, поэтому его можно сразу перебирать в цикле или преобразовывать:
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
Каждый элемент — это совпадение, поэтому `$0.0` внутри `map` — это совпавший текст:
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```

---

Поскольку `Int(_:)` принимает `Substring`, превращение найденного текста в числа занимает один шаг. Здесь удобен `compactMap`: он отбрасывает значения, которые оказываются `nil`:
```swift
let text = "a1 b22"
let numbers = text.matches(of: #/\d+/#).compactMap { Int($0.0) }
print(numbers) // [1, 22]
```
Используйте `map`, когда преобразуется каждый элемент, и `compactMap`, когда некоторые могут не преобразоваться.

---

Круглые скобки вокруг части шаблона создают **группу захвата**: всё совпадение по-прежнему `m.0`, а часть внутри скобок становится `m.1`:
```swift
let text = "id-42"
if let m = text.firstMatch(of: #/id-(\d+)/#) {
    print(m.0) // id-42
    print(m.1) // 42
}
```
Так вы сохраняете интересующий фрагмент и отбрасываете окружающий текст. Без скобок `m.1` вообще не существует, и код не компилируется.

---

Шаблон может содержать несколько групп. Они нумеруются слева направо по открывающей скобке, поэтому вторая группа — `m.2`, третья — `m.3` и так далее:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` всегда остаётся всем совпадением, каково бы ни было количество групп.

---

Подсчёт скобок становится хрупким, как только шаблон разрастается. Дайте группе **имя**, записав `?<name>` сразу после её открывающей скобки, и читайте её как свойство совпадения:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
Именованные группы по-прежнему нумеруются, поэтому `m.1` продолжает работать, но `m.key` говорит, что он содержит, и не ломается при изменении шаблона.

---

`replacing(_:with:)` заменяет каждое совпадение на фиксированный текст и возвращает новую `String`, оставляя исходный текст нетронутым:
```swift
let text = "a1 b22"
print(text.replacing(#/\d+/#, with: "#")) // a# b#
print(text)                               // a1 b22
```
Обратите внимание: `\d+` заменяет всю последовательность цифр одним `#`, тогда как `\d` заменял бы по одной цифре за раз. Шаблон решает, сколько текста исчезнет.

---

`split(separator:)` также принимает регулярное выражение, что позволяет одному вызову обрабатывать разделители, которые записаны не всегда одинаково:
```swift
let line = "a, b;c"
let parts = line.split(separator: #/[,;]\s*/#)
print(parts.joined(separator: "|")) // a|b|c
```
Шаблон `[,;]\s*` означает «запятую или точку с запятой, за которыми следует любое количество пробельных символов», поэтому каждый разделитель поглощается целиком и пустое поле не появляется. Результат — массив из `Substring`.

---

Проверять весь текст с помощью `^` и `$` можно, но `wholeMatch(of:)` говорит об этом напрямую: он возвращает совпадение, только когда шаблон покрывает текст от первого символа до последнего, и `nil` в противном случае:
```swift
print("1a2b".wholeMatch(of: #/[0-9a-f]+/#) != nil) // true
print("1z".wholeMatch(of: #/[0-9a-f]+/#) != nil)   // false
```
Используйте `firstMatch(of:)`, чтобы найти что-то внутри текста, и `wholeMatch(of:)`, чтобы проверить, что текст имеет одну точную форму.

---

Литерал `#/ ... /#` фиксируется во время компиляции. Когда шаблон становится известен только во время выполнения, например потому что его ввёл пользователь, создайте его с помощью `Regex(_:)`:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
Этот инициализатор **бросает ошибку**: недопустимый шаблон, такой как `"["`, обнаруживается только во время работы программы, поэтому вызову нужен `try`, а ошибку необходимо либо обработать с помощью `do`/`catch` (или `try?`), либо пробросить дальше, пометив окружающую функцию как `throws`, как делает это упражнение. У регулярного выражения, созданного таким образом, нет пронумерованных свойств, известных во время компиляции, но `contains`, `matches(of:)` и `replacing` работают точно так же, как и раньше.
