# --description--

Для десятичных чисел (`Double`) спецификатор — `%f`. Сам по себе он всегда выводит шесть цифр после точки:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
Чтобы выбрать, сколько знаков после точки вам нужно, напишите точку и число между `%` и `f`. Это **точность**, и значение округляется, чтобы ей соответствовать:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
`%.2f` — обычный выбор для цен, потому что он всегда показывает ровно два знака после точки.
