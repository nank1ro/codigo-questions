# --description--

В Foundation также есть готовый помощник для дополнения справа: `padding(toLength:withPad:startingAt:)`. Он удлиняет строку до заданной длины, повторяя текст заполнителя, и обрезает её, если она длиннее:
```swift
import Foundation

let name = "Ada"
print(name.padding(toLength: 8, withPad: " ", startingAt: 0) + "|") // Ada     |
print("Tea".padding(toLength: 6, withPad: ".", startingAt: 0))     // Tea...
```
`startingAt` — это индекс внутри текста заполнителя, с которого начинается повторение; при заполнителе из одного символа это всегда `0`.
