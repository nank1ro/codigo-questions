# --description--

Число между `%` и буквой задаёт **минимальную ширину** поля. Если значение короче, слева добавляются пробелы, и оно становится **выровненным по правому краю**; если длиннее — ничего не обрезается:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
Ширина и точность сочетаются: `%8.2f` означает «шириной не менее 8 символов, с 2 знаками после точки»:
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
Именно фиксированная ширина выравнивает столбцы таблицы.
