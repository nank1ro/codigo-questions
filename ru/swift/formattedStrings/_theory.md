**Форматированная строка** — это текст, некоторые части которого заполняются значениями во время выполнения: цена, имя, результат. Swift даёт для этого два инструмента.

Первый — это **интерполяция строк**, которую вы уже знаете: всё, что написано внутри `\( )`, вычисляется и вставляется в текст. Это не обязательно переменная, подойдёт любое выражение:
```swift
let price = 4
print("Total: \(price * 3)") // Total: 12
print("Name: \("ada".uppercased())") // Name: ADA
```
Интерполяция — самый быстрый способ собрать строку, но она выводит числа в точности так, как Swift их хранит: `3.5` остаётся `3.5`, а не `3.50`. Для полного контроля над цифрами, шириной и дополнением мы будем использовать `String(format:)`, который вводится в следующем упражнении.

---

Второй инструмент — `String(format:)`, который входит в фреймворк **Foundation**, поэтому файл должен начинаться с `import Foundation`.

Он принимает **строку формата**, за которой следуют значения для вставки. Внутри строки формата **спецификатор**, начинающийся с `%`, отмечает, куда подставляется каждое значение и как оно записывается. Спецификатор для целого числа — `%d`:
```swift
import Foundation

let count = 7
let text = String(format: "Item %d", count)
print(text) // Item 7
```
`String(format:)` возвращает обычную `String`, поэтому её можно вывести, сохранить или вернуть из функции.

---

Для десятичных чисел (`Double`) спецификатор — `%f`. Сам по себе он всегда выводит шесть цифр после точки:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
Чтобы выбрать, сколько знаков после точки вам нужно, напишите точку и число между `%` и `f`. Это **точность**, и значение округляется, чтобы ей соответствовать:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
`%.2f` — обычный выбор для цен, потому что он всегда показывает ровно два знака после точки.

---

Число между `%` и буквой задаёт **минимальную ширину** поля. Если значение короче, слева добавляются пробелы, и оно становится **выровненным по правому краю**; если длиннее — ничего не обрезается:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
Ширина и точность сочетаются: `%8.2f` означает «шириной не менее 8 символов, с 2 знаками после точки»:
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
Именно фиксированная ширина выравнивает столбцы таблицы.

---

По умолчанию дополнение идёт слева. Знак минуса сразу после `%` размещает дополнение справа, поэтому значение **выровнено по левому краю**:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
Знак минуса — это **флаг**: он меняет способ заполнения поля, не меняя ширину.

---

Ещё один флаг — `0`: вместо пробелов поле заполняется нулями слева. Так получаются числа вроде `007` или `00042`:
```swift
print(String(format: "%05d", 42))  // 00042
print(String(format: "%03d", 7))   // 007
print(String(format: "%03d", 1234)) // 1234
```
Как и с пробелами, значение длиннее ширины никогда не обрезается.

---

Строка формата может содержать столько спецификаторов, сколько вам нужно. Значения следуют в том же порядке, через запятую, и каждое должно соответствовать типу своего спецификатора: `%d` для `Int`, `%f` для `Double`:
```swift
let count = 3
let weight = 4.5
print(String(format: "%d items, %.1f kg", count, weight)) // 3 items, 4.5 kg
```
Передача `Double` в `%d` (или `Int` в `%f`) компилируется, но выводит бессмысленное число, поэтому всегда проверяйте, что спецификаторы и значения соответствуют друг другу.

---

Целые числа можно записывать и в других системах счисления. `%x` выводит значение в **шестнадцатеричной системе** строчными буквами, `%X` — прописными буквами, а `%o` — в восьмеричной системе:
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
Ширина и флаг `0` работают и здесь: `%02x` — классический способ записать один байт цвета, как в `#ff8000`.

---

Чтобы вставить `String` в строку формата, используйте спецификатор `%@`:
```swift
let name = "Ada"
let age = 36
print(String(format: "%@ is %d years old", name, age)) // Ada is 36 years old
```
`%@` принимает Swift-строку `String` напрямую. Не используйте `%s` со строкой Swift: этот спецификатор ожидает C-строку и выводит мусор или вызывает сбой.
