# --description--

Поскольку `%` начинает спецификатор, сам знак процента нужно записывать как `%%`. Так форматируется процентное значение:
```swift
let ratio = 0.4567
print(String(format: "%.1f%%", ratio * 100)) // 45.7%
```
Сначала умножьте долю на `100`, затем выберите точность: `%.0f%%` для `46%`, `%.1f%%` для `45.7%`.

# --instructions--

Напишите функцию `percent`, которая принимает часть и целое (оба `Double`, без меток аргументов) и возвращает часть в процентах от целого с одним знаком после точки, за которым следует `%`

Пример вызова функции:
```swift
print(percent(9, 20))
// prints 45.0%
```
