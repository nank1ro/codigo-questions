# --description--

Флаги ширины работают только внутри `String(format:)`. Чтобы дополнить обычную строку самостоятельно, создайте пробелы с помощью `String(repeating:count:)` и присоедините их к тексту:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
Если текст уже длиннее ширины, `4 - text.count` становится отрицательным, и `String(repeating:count:)` вызывает сбой. Защититесь с помощью `max(0, ...)`, чтобы количество никогда не опускалось ниже нуля, а длинный текст оставался как есть.

# --instructions--

Напишите функцию `leftPad`, которая принимает текст (`String`) и ширину (`Int`), оба без меток аргументов, и возвращает текст, выровненный по правому краю в этой ширине, добавляя пробелы слева. Текст длиннее ширины должен возвращаться без изменений

Пример вызова функции:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
