# --description--

По умолчанию дополнение идёт слева. Знак минуса сразу после `%` размещает дополнение справа, поэтому значение **выровнено по левому краю**:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
Знак минуса — это **флаг**: он меняет способ заполнения поля, не меняя ширину.

# --instructions--

Что выведет этот код?
```swift
import Foundation

print(String(format: "[%-5d]", 42))
```

- `[   42]`
- `[-42  ]`
