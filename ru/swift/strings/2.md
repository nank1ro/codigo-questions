# --description--

**Строковая интерполяция** вставляет значение выражения внутрь строкового литерала. Оберните выражение в `\()`:
```swift
let name = "Ada"
let age = 36
print("\(name) is \(age) years old") // Ada is 36 years old
```
Интерполировать можно значение любого типа: числа, логические значения и другие строки автоматически преобразуются в текст.

# --instructions--

Напишите функцию `greet`, которая принимает `String` (без метки аргумента) и возвращает текст `Hello, <name>!`, где `<name>` — это аргумент.

Пример вызова функции:
```swift
print(greet("Ada"))
// prints Hello, Ada!
```
