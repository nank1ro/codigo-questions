# --description--

**Строка** — это фрагмент текста. В Swift строковый литерал записывается в двойных кавычках, и его тип — `String`:
```swift
let greeting: String = "Hello"
var city = "Rome"
```
Как и с любым другим значением, `let` создаёт константу, которую нельзя изменить, а `var` создаёт переменную, которую можно.
Swift определяет тип `String` по литералу, поэтому аннотация типа необязательна.
