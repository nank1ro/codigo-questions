# --description--

Фреймворк Foundation добавляет множество дополнительных методов для строк. Один из самых полезных — `replacingOccurrences(of:with:)`, который возвращает новую строку, в которой каждое вхождение первого текста заменено вторым:
```swift
import Foundation

let path = "a/b/c"
print(path.replacingOccurrences(of: "/", with: "-")) // a-b-c
```
Не забудьте добавить `import Foundation` в начале файла, иначе метод будет недоступен. Вызовы методов можно объединять в цепочку, поэтому `text.lowercased().replacingOccurrences(of: " ", with: "_")` — допустимая запись.
