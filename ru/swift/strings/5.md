# --description--

`String` — это коллекция значений `Character`. `Character` — это одна буква, цифра, символ или пробел, и записывается он в тех же двойных кавычках, что и строка, поэтому, чтобы получить его, нужна аннотация типа:
```swift
let letter: Character = "a"
let text = "abc"
print(text.count) // 3
```
Проверка `isEmpty` предпочтительнее сравнения `count` с `0`: так код читается лучше и не нужно считать каждый символ.

# --solutions--

```swift
func length(_ text: String) -> Int {
    return text.count
}

func hasText(_ text: String) -> Bool {
    return !text.isEmpty
}
```
