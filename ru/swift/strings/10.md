# --description--

Три метода отвечают на самые распространённые вопросы о содержимом строки, и каждый из них возвращает `Bool`:
- `contains(_:)` равно `true`, когда строка содержит указанный текст (или символ) в любом месте
- `hasPrefix(_:)` равно `true`, когда строка начинается с указанного текста
- `hasSuffix(_:)` равно `true`, когда строка заканчивается указанным текстом
```swift
let email = "ada@example.com"
print(email.contains("@"))          // true
print(email.hasPrefix("ada"))       // true
print(email.hasSuffix(".org"))      // false
```
Все три чувствительны к регистру: `"Swift".hasPrefix("s")` равно `false`.
