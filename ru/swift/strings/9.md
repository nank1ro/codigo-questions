# --description--

Работа с индексами многословна, поэтому Swift предлагает сокращения для самых распространённых случаев:
- `first` и `last` возвращают первый и последний символ в виде опционального `Character?` (`nil` для пустой строки)
- `prefix(n)` возвращает первые `n` символов, а `suffix(n)` — последние `n`
```swift
let word = "Swift"
print(word.first!)     // S
print(word.prefix(2))  // Sw
print(word.suffix(3))  // ift
```
`prefix` и `suffix` возвращают `Substring` — представление исходного текста. Чтобы сохранить его как настоящую `String`, оберните его в `String(...)`. Если `n` больше, чем `count`, вы просто получаете всю строку целиком.

func firstTwo(_ text: String) -> String {

}

func lastTwo(_ text: String) -> String {
    return String(text.suffix(2))
