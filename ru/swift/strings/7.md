# --description--

Поскольку строка — это коллекция символов, по ней можно перебирать значения с помощью цикла `for`-`in`. Каждая итерация даёт вам один `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
`Character` можно сравнить оператором `==` с символьным литералом, поэтому подсчёт количества вхождений символа — это просто цикл со счётчиком.

# --instructions--

Напишите функцию `occurrences`, которая принимает `Character` с меткой аргумента `of` и `String` с меткой аргумента `in`, и возвращает, сколько раз символ встречается в строке.

Example of function call:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
