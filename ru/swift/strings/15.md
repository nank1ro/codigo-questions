# --description--

Разбиение по пробелу — самый простой способ разбить предложение на слова, а объединение — это способ собрать текст обратно из массива.

# --instructions--

Напишите функцию `wordCount`, которая принимает `String` (без метки аргумента) и возвращает количество разделённых пробелами слов в ней, и функцию `slug`, которая принимает массив `String` (без метки аргумента) и возвращает слова, соединённые через `-`

Пример вызова функции:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
