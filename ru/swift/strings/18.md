# --description--

`Character` — это не `String`, поэтому его нельзя напрямую соединить со строкой оператором `+`. Сначала преобразуйте его с помощью `String(...)`:
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
Сочетая это с циклом `for`-`in`, можно собрать строку по одному символу за раз, например, помещая каждый новый символ перед уже собранными.
