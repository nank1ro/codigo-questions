# --description--

Две строки можно объединить оператором `+`, который создаёт новую строку:
```swift
let full = "Hello" + " " + "world" // Hello world
```
Чтобы добавить текст в конец существующей строковой переменной, используйте `+=`. Переменная должна быть объявлена с помощью `var`, потому что её значение изменяется:
```swift
var log = "Start"
log += "..."
print(log) // Start...
```
