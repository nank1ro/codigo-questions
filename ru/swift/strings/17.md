# --description--

Строки можно сравнивать теми же операторами, что и числа. `==` проверяет, что у двух строк точно совпадают символы, а `<` и `>` сравнивают их в алфавитном порядке, символ за символом:
```swift
print("apple" == "apple")  // true
print("apple" < "banana")  // true
print("car" < "cat")       // true
```
Сравнение чувствительно к регистру, и любая заглавная буква идёт **раньше** любой строчной, поэтому `"B" < "a"` равно `true`.
