**Строка** — это фрагмент текста. В Swift строковый литерал записывается в двойных кавычках, и его тип — `String`:
```swift
let greeting: String = "Hello"
var city = "Rome"
```
Как и с любым другим значением, `let` создаёт константу, которую нельзя изменить, а `var` создаёт переменную, которую можно.
Swift определяет тип `String` по литералу, поэтому аннотация типа необязательна.

---

**Строковая интерполяция** вставляет значение выражения внутрь строкового литерала. Оберните выражение в `\()`:
```swift
let name = "Ada"
let age = 36
print("\(name) is \(age) years old") // Ada is 36 years old
```
Интерполировать можно значение любого типа: числа, логические значения и другие строки автоматически преобразуются в текст.

---

Две строки можно объединить оператором `+`, который создаёт новую строку:
```swift
let full = "Hello" + " " + "world" // Hello world
```
Чтобы добавить текст в конец существующей строковой переменной, используйте `+=`. Переменная должна быть объявлена с помощью `var`, потому что её значение изменяется:
```swift
var log = "Start"
log += "..."
print(log) // Start...
```

---

Свойство `count` возвращает количество символов в строке, а `isEmpty` равно `true`, когда в строке вообще нет символов:
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
Учитывается каждый символ, включая пробелы и знаки препинания.

---

`String` — это коллекция значений `Character`. `Character` — это одна буква, цифра, символ или пробел, и записывается он в тех же двойных кавычках, что и строка, поэтому, чтобы получить его, нужна аннотация типа:
```swift
let letter: Character = "a"
let text = "abc"
print(text.count) // 3
```
Проверка `isEmpty` предпочтительнее сравнения `count` с `0`: так код читается лучше и не нужно считать каждый символ.

---

**Многострочный строковый литерал** начинается и заканчивается тремя двойными кавычками `"""`, каждая на своей строке. Каждая строка между ними становится частью строки, а переносы строк сохраняются:
```swift
let poem = """
Roses are red
Violets are blue
"""
print(poem)
```
Это выводит обе строки в точности так, как они написаны. Закрывающие `"""` также задают отступ: любые пробельные символы перед ними удаляются из начала каждой строки.

---

Поскольку строка — это коллекция символов, по ней можно перебирать значения с помощью цикла `for`-`in`. Каждая итерация даёт вам один `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
`Character` можно сравнить оператором `==` с символьным литералом, поэтому подсчёт количества вхождений символа — это просто цикл со счётчиком.

---

В отличие от массивов, строки нельзя индексировать целым числом, как `text[2]`: одни символы занимают больше памяти, чем другие, поэтому Swift использует специальный тип `String.Index` для указания позиции.
`startIndex` — это позиция первого символа, а `endIndex` — позиция *после* последнего. Чтобы сдвинуться от индекса, используйте `index(_:offsetBy:)`, а затем проиндексируйте строку результатом:
```swift
let word = "Swift"
let second = word.index(word.startIndex, offsetBy: 1)
print(word[second]) // w
```
Выход за конец строки приводит к сбою во время выполнения, поэтому смещение должно оставаться в пределах `count`.

---

Работа с индексами многословна, поэтому Swift предлагает сокращения для самых распространённых случаев:
- `first` и `last` возвращают первый и последний символ в виде опционального `Character?` (`nil` для пустой строки)
- `prefix(n)` возвращает первые `n` символов, а `suffix(n)` — последние `n`
```swift
let word = "Swift"
print(word.first!)     // S
print(word.prefix(2))  // Sw
print(word.suffix(3))  // ift
```
`prefix` и `suffix` возвращают `Substring` — представление исходного текста. Чтобы сохранить его как настоящую `String`, оберните его в `String(...)`. Если `n` больше, чем `count`, вы просто получаете всю строку целиком.

---

Три метода отвечают на самые распространённые вопросы о содержимом строки, и каждый из них возвращает `Bool`:
- `contains(_:)` равно `true`, когда строка содержит указанный текст (или символ) в любом месте
- `hasPrefix(_:)` равно `true`, когда строка начинается с указанного текста
- `hasSuffix(_:)` равно `true`, когда строка заканчивается указанным текстом
```swift
let email = "ada@example.com"
print(email.contains("@"))          // true
print(email.hasPrefix("ada"))       // true
print(email.hasSuffix(".org"))      // false
```
Все три чувствительны к регистру: `"Swift".hasPrefix("s")` равно `false`.

---

Поскольку `contains`, `hasPrefix` и `hasSuffix` возвращают логические значения, их можно естественным образом сочетать с `||` и `&&` для построения более сложных проверок.

---

`uppercased()` и `lowercased()` возвращают **новую** строку, в которой каждая буква преобразована в верхний или нижний регистр. Исходная строка не изменяется:
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
Оба являются методами, поэтому не забывайте про скобки.

---

Приведение к нижнему регистру — обычный способ сравнивать текст без учёта регистра: две строки, отличающиеся только регистром, становятся равными, если обе привести к нижнему регистру.

---

`split(separator:)` разбивает строку на массив частей везде, где встречается символ-разделитель. `joined(separator:)` делает обратное: склеивает элементы массива в одну строку, вставляя разделитель между ними:
```swift
let parts = "a-b-c".split(separator: "-") // ["a", "b", "c"]
print(parts.count)                         // 3
print(parts.joined(separator: ", "))       // a, b, c
```
Как и `prefix`, `split` возвращает значения `Substring`; оберните значение в `String(...)`, если нужно сохранить его как `String`.

---

Разбиение по пробелу — самый простой способ разбить предложение на слова, а объединение — это способ собрать текст обратно из массива.

---

Фреймворк Foundation добавляет множество дополнительных методов для строк. Один из самых полезных — `replacingOccurrences(of:with:)`, который возвращает новую строку, в которой каждое вхождение первого текста заменено вторым:
```swift
import Foundation

let path = "a/b/c"
print(path.replacingOccurrences(of: "/", with: "-")) // a-b-c
```
Не забудьте добавить `import Foundation` в начале файла, иначе метод будет недоступен. Вызовы методов можно объединять в цепочку, поэтому `text.lowercased().replacingOccurrences(of: " ", with: "_")` — допустимая запись.

---

Строки можно сравнивать теми же операторами, что и числа. `==` проверяет, что у двух строк точно совпадают символы, а `<` и `>` сравнивают их в алфавитном порядке, символ за символом:
```swift
print("apple" == "apple")  // true
print("apple" < "banana")  // true
print("car" < "cat")       // true
```
Сравнение чувствительно к регистру, и любая заглавная буква идёт **раньше** любой строчной, поэтому `"B" < "a"` равно `true`.

---

`Character` — это не `String`, поэтому его нельзя напрямую соединить со строкой оператором `+`. Сначала преобразуйте его с помощью `String(...)`:
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
Сочетая это с циклом `for`-`in`, можно собрать строку по одному символу за раз, например, помещая каждый новый символ перед уже собранными.
