# --description--

`split(separator:)` разбивает строку на массив частей везде, где встречается символ-разделитель. `joined(separator:)` делает обратное: склеивает элементы массива в одну строку, вставляя разделитель между ними:
```swift
let parts = "a-b-c".split(separator: "-") // ["a", "b", "c"]
print(parts.count)                         // 3
print(parts.joined(separator: ", "))       // a, b, c
```
Как и `prefix`, `split` возвращает значения `Substring`; оберните значение в `String(...)`, если нужно сохранить его как `String`.
