# --description--

`uppercased()` и `lowercased()` возвращают **новую** строку, в которой каждая буква преобразована в верхний или нижний регистр. Исходная строка не изменяется:
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
Оба являются методами, поэтому не забывайте про скобки.
