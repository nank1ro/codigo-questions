# --description--

Требование к свойству всегда указывает, как это свойство можно использовать. `{ get }` требует лишь, чтобы значение можно было читать; `{ get set }` требует, чтобы его можно было читать **и** присваивать:
```swift
protocol Account {
    var owner: String { get }
    var balance: Int { get set }
}
```
Соответствующий тип всегда может дать больше, чем требует контракт: хранимое свойство `var` прекрасно удовлетворяет `{ get }`. Но он никогда не может дать меньше — константа `let` или вычисляемое свойство только для чтения не могут удовлетворить `{ get set }`.

# --instructions--
