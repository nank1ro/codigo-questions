# --description--

Протокол может также требовать **методы**. Вы записываете сигнатуру — имя, параметры и тип возвращаемого значения — и на этом останавливаетесь, без тела:
```swift
protocol Greeter {
    func greet() -> String
}
```
Соответствующий тип должен объявить метод с точно такой сигнатурой и предоставить тело:
```swift
struct Robot: Greeter {
    func greet() -> String {
        return "BEEP"
    }
}

print(Robot().greet()) // BEEP
```
Если что-то отличается — имя, тип параметра, тип возвращаемого значения, — тип не соответствует протоколу, и компилятор сообщит, какого требования не хватает.

# --instructions--

Сделайте `Friendly` соответствующим `Greeter`, добавив требуемый метод `greet()`, возвращающий имя между `Hello, ` и `!`

Пример использования:
```swift
print(Friendly(name: "Ada").greet())
// prints Hello, Ada!
```

# --asserts--

`Friendly(name: "Ada")` должен возвращать приветствие `Hello, Ada!`

```swift
tryCatch(_asGreeter(Friendly(name: "Ada")) == "Hello, Ada!")
```

`Friendly(name: "Bo")` должен возвращать приветствие `Hello, Bo!`

```swift
tryCatch(_asGreeter(Friendly(name: "Bo")) == "Hello, Bo!")
```

Пустое имя должно возвращать приветствие `Hello, !`

```swift
tryCatch(_asGreeter(Friendly(name: "")) == "Hello, !")
```
