# --description--

Протокол может строиться на другом. Запись имени протокола после двоеточия заставляет новый протокол **наследовать** каждое требование старого:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
Тип, соответствующий `Aged`, должен предоставить `age` *и* `name`, и он считается типом `Named` везде. Протокол может наследовать от нескольких протоколов одновременно, разделяя их запятыми.

# --before-asserts--

```swift
extension Timed {
    func label() -> String {
        return "\(name) \(seconds)"
    }
}

func _name(_ n: Named) -> String {
    return n.name
}
```

# --asserts--

Трек с именем `Intro` длиной `90` секунд должен получить метку `Intro 90`

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

Трек с именем `Outro` длиной `5` секунд должен получить метку `Outro 5`

```swift
tryCatch(Track(name: "Outro", seconds: 5).label() == "Outro 5")
```

Трек с именем `Gap` длиной `0` секунд должен получить метку `Gap 0`

```swift
tryCatch(Track(name: "Gap", seconds: 0).label() == "Gap 0")
```

Значение `Timed` должно быть применимо как значение `Named`

```swift
tryCatch(_name(Track(name: "Intro", seconds: 90)) == "Intro")
```
