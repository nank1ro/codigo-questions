# --description--

Реализация по умолчанию — это запасной вариант, а не правило. Если соответствующий тип предоставляет собственную версию требования, выполняется именно его версия:
```swift
protocol Priced {
    var price: Int { get }
}

extension Priced {
    var price: Int { return 0 }
}

struct Ticket: Priced {
    var price = 12
}

print(Ticket().price) // 12, not 0
```
Реализация по умолчанию лишь заполняет пробелы, которые тип оставляет открытыми.
