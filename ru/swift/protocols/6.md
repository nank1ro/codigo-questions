# --description--

Протокол обычно собирает более одного требования, и соответствующий тип должен выполнить каждое из них:
```swift
protocol Vehicle {
    var wheels: Int { get }
    func move() -> String
}

struct Bike: Vehicle {
    var wheels = 2

    func move() -> String {
        return "pedalling"
    }
}
```
Порядок требований внутри фигурных скобок не важен, как и порядок, в котором соответствующий тип их предоставляет: компилятор проверяет лишь, что ничего не пропущено.
