# --description--

Соответствие не обязательно объявлять рядом с типом. **Расширение** может добавить его позже, оставляя собственное объявление типа сосредоточенным на его данных:
```swift
protocol Resettable {
    mutating func reset()
}

struct Timer {
    var seconds = 0
}

extension Timer: Resettable {
    mutating func reset() {
        seconds = 0
    }
}
```
Это работает и для типов, которые вы не писали: можно сделать тип стандартной библиотеки соответствующим одному из ваших протоколов, не трогая его исходный код.

struct Clicks {
