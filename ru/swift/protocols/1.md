# --description--

**Протокол** описывает, что должен иметь тип, не уточняя, как. Это список требований — свойств и методов, — который любой принимающий его тип обещает реализовать.

Протокол объявляется ключевым словом `protocol`. Требование к свойству записывается с указанием его типа, за которым следует блок, определяющий, как к нему можно обращаться: `{ get }` означает, что тип как минимум должен позволять его читать.
```swift
protocol Named {
    var name: String { get }
}
```
Тип **соответствует** протоколу, записывая его имя после двоеточия и предоставляя всё, что требует протокол:
```swift
struct Cat: Named {
    var name: String
}

let cat = Cat(name: "Luna")
print(cat.name) // Luna
```
Протокол сам не хранит данных: это контракт. Каждый тип, удовлетворяющий ему, может одинаково обрабатываться остальным вашим кодом.
