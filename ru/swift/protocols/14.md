# --description--

`CustomStringConvertible` решает, что `print` показывает для вашего типа. Его единственное требование — свойство `description`:
```swift
struct Coin: CustomStringConvertible {
    var value: Int

    var description: String {
        return "\(value)c"
    }
}

print(Coin(value: 25)) // 25c
```
Без соответствия печать структуры возвращается к стандартному дампу вроде `Coin(value: 25)`, и одно лишь свойство `description` ничего не меняет — `print` ищет протокол. Строковая интерполяция тоже использует `description`.
