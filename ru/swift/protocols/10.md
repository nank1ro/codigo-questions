# --description--

Расширение протокола может также добавлять члены, которые протокол никогда не перечислял как требования. Это дополнительные удобства, доступные каждому соответствующему типу:
```swift
protocol Sized {
    var count: Int { get }
}

extension Sized {
    var isEmpty: Bool {
        return count == 0
    }
}
```
`isEmpty` — не требование, поэтому соответствующий тип не обязан его предоставлять — он просто получает его.
