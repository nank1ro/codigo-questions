# --description--

`async let` подходит, когда при написании кода известно количество вызовов. Для списка, размер которого известен только во время выполнения, используйте **группу задач**.

`withTaskGroup(of:)` открывает группу, `addTask` запускает по одной дочерней задаче на каждый элемент, а затем группа читается с помощью `for await`, который выдаёт результаты по мере их готовности:
```swift
let total = await withTaskGroup(of: Int.self) { group in
    for n in numbers {
        group.addTask {
            return await square(n)
        }
    }
    var sum = 0
    for await value in group {
        sum += value
    }
    return sum
}
```
`of: Int.self` объявляет, что возвращает каждая дочерняя задача. Весь вызов `withTaskGroup` — одно выражение, поэтому перед ним нужен единственный `await`, и он не вернёт результат, пока не завершится каждая дочерняя задача.

```swift
func square(_ n: Int) async -> Int {
    return n * n
}

func sumOfSquares(_ numbers: [Int]) async -> Int {
    return await withTaskGroup(of: Int.self) { group in
        for n in numbers {
            group.addTask {
                return await square(n)
            }
        }
        var total = 0
        for await value in group {
            total += value
        }
        return total
    }
}
```
