# --description--

Группа задач выдаёт результаты в **порядке завершения**, а не в порядке добавления задач. Самая быстрая дочерняя задача приходит первой, поэтому сбор значений в массив даёт непредсказуемый порядок.

Когда порядок важен, есть два решения. Если значения можно просто переупорядочить, отсортируйте их в конце:
```swift
return values.sorted()
```
Если каждый результат принадлежит определённой позиции, пусть каждая задача возвращает пару `(index, value)`, и записывайте её в подготовленный массив:
```swift
for (index, word) in words.enumerated() {
    group.addTask {
        return (index, await lengthOf(word))
    }
}
var result = Array(repeating: 0, count: words.count)
for await (index, value) in group {
    result[index] = value
}
```
Для суммы, максимума или количества не нужно ни то ни другое, потому что порядок значений не меняет ответ.
