# --description--

Работа, которая происходит во времени, часто завершается ошибкой: сервер недоступен, файл отсутствует, входные данные неверны. Такая функция помечается **`async throws`** и вызывается с **`try await`**:
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
Чтобы обработать ошибку, вы заворачиваете вызов в блок `do` и перехватываете её:
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// prints could not load
```
Порядок ключевых слов фиксирован: сначала `try`, затем `await`.

# --instructions--

Напишите функцию `parse`, которая принимает строку (без метки аргумента), является асинхронной, может бросать ошибки и возвращает строку, преобразованную в `Int`. Если строка не является числом, бросьте `InputError.notANumber`

Пример вызова функции:
```swift
print(try await parse("7"))
// prints 7
```

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
