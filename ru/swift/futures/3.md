# --description--

Асинхронные функции обычно строятся друг на друге. Внутри `async`-функции можно вызывать с `await` любую другую `async`-функцию, а результат используется как любое обычное значение:
```swift
func base() async -> Int {
    return 10
}

func withBonus() async -> Int {
    let value = await base()
    return value + 5
}

print(await withBonus())
// выводит 15
```
`await` разрешён только внутри асинхронного контекста: `async`-функции или верхнего уровня скрипта. Обычная не-`async` функция не может использовать `await`.

```swift
func first() async -> Int {

}

    return base + 5
}

print(await second())
```

- `10`
- `5`
- ничего, потому что `second` никогда не вызывается с `await`
