# --description--

`Task.sleep` приостанавливает текущую задачу на некоторое время, ничего не блокируя. Его можно прервать, поэтому это бросающий асинхронный вызов, требующий `try await`. Длительность задаётся вспомогательными свойствами вроде `.seconds`, `.milliseconds` или `.nanoseconds`:
```swift
func slowGreeting() async throws -> String {
    try await Task.sleep(for: .milliseconds(50))
    return "hello"
}
```
Это стандартный способ сымитировать медленную работу в примере вместо реального сетевого вызова. Заметьте, что программа не замирает: пока одна задача спит, остальные продолжают выполняться.

# --instructions--

Напишите функцию `delayed`, которая принимает целое число (без метки аргумента), является асинхронной, может бросать ошибки, ждёт `50` миллисекунд с помощью `Task.sleep`, а затем возвращает число, умноженное на `3`

Пример вызова функции:
```swift
print(try await delayed(2))
// prints 6
```
