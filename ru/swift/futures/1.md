# --description--

Некоторая работа не завершается мгновенно: загрузка файла, чтение из базы данных, ожидание таймера. Если бы программа просто останавливалась и ждала, в это время не могло бы происходить ничего другого. Swift решает эту проблему с помощью **асинхронных функций**.

Функция, помеченная **`async`**, может приостановиться посреди работы и продолжить позже. Ключевое слово ставится после списка параметров, перед стрелкой:
```swift
func fetchNumber() async -> Int {
    return 42
}
```
Вызов тоже отличается: перед вызовом нужно написать **`await`**. `await` отмечает точное место, где программа может приостановиться, и даёт готовое значение, как только функция завершится:
```swift
let n = await fetchNumber()
print(n)
// prints 42
```
На верхнем уровне Swift-скрипта `await` уже поддерживается, поэтому асинхронные функции можно вызывать напрямую, без какой-либо дополнительной настройки. Забытые `async` или `await` — это ошибка компиляции, а не тихая ошибка.
