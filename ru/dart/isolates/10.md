# --description--

Сбор целой серии сообщений следует одному рецепту: пустой список перед циклом, один `add` на каждое настоящее сообщение и `close()` на сигнале, завершающем поток. Когда порт закрыт, `await for` заканчивается, и функция может вернуть значение:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

Сообщения сохраняют порядок, в котором были отправлены, поэтому собранный список шаг за шагом повторяет работу другого изолята.

# --instructions--

Напиши функцию верхнего уровня `sendWords`, которая принимает `List<Object>` `message`, где элемент `0` — это `SendPort`, а элемент `1` — `List<String>`: отправь каждое слово в порт, затем отправь `null` как сигнал конца.

Затем напиши функцию `collectWords`, которая принимает `List<String>` `words` и возвращает `Future<List<String>>`, завершающийся всеми словами, полученными от запущенного изолята `sendWords`.

Пример:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
