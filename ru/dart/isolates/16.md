# --description--

Каждый `Isolate.run` запускает свой собственный изолят, поэтому несколько из них действительно выполняются в один и тот же момент, на стольких ядрах, сколько есть у машины. Схема та, которую ты уже знаешь по future: сначала запусти каждое вычисление, затем дождись их всех с помощью `Future.wait`, который сохраняет результаты в порядке входных данных.

```dart
Future<List<int>> doubleAll(List<int> numbers) {
  return Future.wait(numbers.map((n) => Isolate.run(() => n * 2)));
}
```

Запуск изолята не бесплатен: он стоит памяти и нескольких миллисекунд. Разделение одного долгого вычисления между горсткой изолятов окупается, а отправка тысячи тривиальных сложений тысяче изолятов — нет.
