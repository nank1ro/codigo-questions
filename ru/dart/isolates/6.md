# --description--

Функция, передаваемая в `Isolate.spawn`, называется **точкой входа**. Это должна быть функция верхнего уровня (или статическая), принимающая ровно один параметр: сообщение, которое ей передаёт `Isolate.spawn`.

```dart
void reportAnswer(SendPort port) {
  port.send(42);
}
```

Сообщения, приходящие в `ReceivePort`, имеют статический тип `dynamic`, потому что отправить могли любое значение. Когда ты знаешь, что отправляет другой изолят, приведи тип:

```dart
final receivePort = ReceivePort();
await Isolate.spawn(reportAnswer, receivePort.sendPort);
final answer = await receivePort.first as int;
```

# --instructions--

Напиши функцию верхнего уровня `sendGreeting`, которая принимает `SendPort` `port` и отправляет в него строку `hello from the isolate`.

Затем напиши функцию `greetFromIsolate`, которая возвращает `Future<String>`: она создаёт `ReceivePort`, запускает `sendGreeting` с его `sendPort` и завершается первым полученным сообщением.

Пример:
```dart
print(await greetFromIsolate()); // hello from the isolate
```

```dart
void sendGreeting(SendPort port) {
  port.send('hello from the isolate');
}

Future<String> greetFromIsolate() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendGreeting, receivePort.sendPort);
  return await receivePort.first as String;
}
```
