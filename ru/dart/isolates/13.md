# --description--

Ошибка, приходящая обратно от `Isolate.run`, — это **копия** той, что брошена на той стороне, поэтому обычные проверки по-прежнему работают: `catch (e)` даёт объект, а `e is FormatException` говорит, какого рода это был сбой.

```dart
try {
  await Isolate.run(() => int.parse('abc'));
} on FormatException {
  print('not a number');
}
```

Полагаться нельзя на трассировку стека, указывающую в твой собственный изолят: ошибка путешествовала, стек — нет.
