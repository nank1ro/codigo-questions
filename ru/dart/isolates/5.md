# --description--

`Isolate.run` — это короткий путь для получения одного результата. Когда тебе нужен изолят, который продолжает работать и сообщает о себе больше одного раза, запусти его сам с помощью **`Isolate.spawn`** и дай ему способ ответить.

Этот способ — пара портов. **`ReceivePort`** — это почтовый ящик: ты создаёшь его на своей стороне и читаешь приходящие сообщения. Его **`sendPort`** — адрес этого ящика, и это единственное, что нужно другому изоляту, чтобы ответить.

```dart
import 'dart:isolate';

void sayHello(SendPort port) {
  port.send('hi');
}

Future<void> main() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sayHello, receivePort.sendPort);
  final message = await receivePort.first;
  print(message); // hi
}
```

`Isolate.spawn` принимает функцию для запуска и единственное сообщение, которое ей передаётся, — здесь это `SendPort`. На той стороне `send` кладёт значение в почтовый ящик, а `await receivePort.first` ждёт первое сообщение и закрывает порт.
