# --description--

Расширение может также объявлять **геттеры**, которые читаются как свойства, без скобок. Внутри расширения можно вызывать собственные члены типа напрямую: `this.` необязателен, точно как внутри класса.

```dart
extension Sizes on String {
  bool get isLong => length > 10;      // same as this.length
  String get firstChar => this[0];
}

void main() {
  print('Dart'.isLong);           // false
  print('extension'.firstChar);   // e
}
```

Выбирайте геттер, когда член только **читает** значение и не принимает параметров; выбирайте метод, когда он выполняет работу или требует аргументов.

Пример:
```dart
print('   '.isBlank);  // true
print(' hi '.isBlank); // false
```
