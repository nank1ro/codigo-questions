# --description--

Расширение на `String` нельзя вызвать у `String?`: значение может быть `null`, и компилятор отклонит вызов. Если же объявить расширение на **nullable**-типе, метод можно вызвать у `String?` напрямую, а внутри него `this` имеет тип `String?`, поэтому случай `null` нужно обработать самостоятельно, например с помощью `??`:

```dart
extension Defaults on int? {
  int orZero() => this ?? 0;
}

void main() {
  int? count = null;
  print(count.orZero()); // 0
  print(5.orZero());     // 5
}
```

Non-nullable `int` можно передать туда, где ожидается `int?`, поэтому расширение работает с обоими.
