# --description--

Вы уже умеете добавлять методы в класс, который написали сами. Но что насчёт `String`, `int` или `List`, чей код находится в Dart SDK? Изменить их нельзя, однако нередко хочется, чтобы у них был ещё один метод.

**Расширение** решает эту задачу: оно добавляет новые члены в **существующий** тип, не затрагивая его исходный код и не создавая подкласс. Синтаксис такой:

```dart
extension ExtensionName on Type {
  // new methods and getters
}
```

Внутри расширения `this` ссылается на значение, у которого вызван член. Как только расширение объявлено, его члены вызываются точно так же, как собственные члены типа:

```dart
extension Greeting on String {
  String greet() => 'Hello, $this!';
}

void main() {
  var name = 'Ada';
  print(name.greet()); // Hello, Ada!
}
```

Расширения объявляются на **верхнем уровне** файла, рядом с классами и функциями, но никогда внутри `main`.
