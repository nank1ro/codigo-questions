# --description--

Члены расширения разрешаются **во время компиляции** на основе **статического типа** выражения, то есть типа, который известен компилятору, а не фактического объекта во время выполнения. `String`, сохранённый в переменной типа `Object`, остаётся `String`, когда программа выполняется, но компилятор видит только `Object`, поэтому не находит для него расширения:

```dart
extension Shout on String {
  String shout() => toUpperCase() + '!';
}

void main() {
  Object text = 'hi';
  print(text.shout()); // error: the method 'shout' isn't defined for the type 'Object'
}
```

То же самое относится к `dynamic`: члены расширения никогда не находятся через `dynamic`-получатель. Сначала приведите значение к нужному типу или объявите его с точным типом.

# --instructions--

С учётом расширения `Shout` из описания, какая строка выводит `HI!` без ошибок?

# --answers--

- `String text = 'hi'; print(text.shout());`
- `Object text = 'hi'; print(text.shout());`
- `dynamic text = 'hi'; print(text.shout());`
- `Object text = 'hi'; print(Shout.shout(text));`
