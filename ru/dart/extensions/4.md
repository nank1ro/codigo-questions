# --description--

Тип после `on` может быть **параметризованным** типом, например `List<int>`. Такое расширение применяется только к спискам этого типа элементов: `[1, 2].total()` работает, а `['a', 'b'].total()` не компилируется.

```dart
extension Totals on List<int> {
  int total() {
    var sum = 0;
    for (final n in this) {
      sum += n;
    }
    return sum;
  }
}
```

Внутри расширения `this` — это список, поэтому можно перебирать его элементы, обращаться по индексу или вызывать `length` как обычно.
