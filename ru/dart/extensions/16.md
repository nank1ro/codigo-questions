# --instructions--

Напишите расширение с именем `Words` на `String` с:
- геттером `wordCount` типа `int` — количеством слов в строке, где слова разделены одиночным пробелом
- геттером `initials` типа `String`, составленным из первых символов каждого слова в верхнем регистре, соединённых без разделителей

Строка всегда содержит хотя бы одно слово и никогда не имеет начальных, конечных или двойных пробелов.

Пример:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
