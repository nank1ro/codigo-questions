# --description--

Миксин не ограничен методами: он может объявлять и **поля**, причём каждый объект каждого класса, использующего миксин, получает собственную копию этих полей.

```dart
mixin Counter {
  int count = 0;

  void increment() {
    count++;
  }
}

class Clicker with Counter {}

void main() {
  final a = Clicker();
  final b = Clicker();
  a.increment();
  a.increment();
  print(a.count); // 2
  print(b.count); // 0, b has its own count
}
```

Именно это делает миксин большим, чем интерфейс: он приносит и данные, и код, который с ними работает.

# --instructions--

Объяви миксин `Scored` с:
- полем `score` типа `int`, которое начинается с `0`
- методом `addPoints`, который принимает `int` `points` и прибавляет его к `score`

Объяви класс `Player`, который использует `Scored` и не добавляет ничего своего.

Пример:
```dart
final p = Player();
p.addPoints(3);
print(p.score); // 3
```
