# --description--

Когда у миксина есть условие `on`, он может **переопределять** член этого типа и вызывать **`super`**, чтобы добраться до версии, расположенной ниже него в цепочке:

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log` — это не собственный `log` миксина, а тот, что находится ниже, поэтому бесконечной рекурсии не возникает. Сложи несколько таких миксинов через `with A, B`, и каждый обернёт предыдущий: вызов сначала входит в **последний** миксин и спускается вниз до суперкласса.

# --instructions--

Объяви класс `Pipeline` с методом `run`, который принимает `String` `input` и возвращает его без изменений.

Объяви миксин `Trimmed` с условием `on Pipeline`, который переопределяет `run`, передавая обрезанный ввод в `super.run`, и миксин `Upper` с условием `on Pipeline`, который переопределяет `run`, возвращая результат `super.run` в верхнем регистре.

Объяви класс `TextPipeline`, который наследует `Pipeline` и использует сначала `Trimmed`, затем `Upper`, и класс `TrimOnly`, который наследует `Pipeline` и использует только `Trimmed`.

Пример:
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
