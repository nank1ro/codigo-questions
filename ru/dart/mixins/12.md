# --description--

Миксин с условием `on` читает члены своего суперкласса как свои собственные — именно поэтому это удачное место для поведения, украшающего существующий тип:

```dart
class Shape {
  String get kind => 'shape';
}

mixin Printable on Shape {
  void show() {
    print('a $kind');
  }
}

class Square extends Shape with Printable {
  @override
  String get kind => 'square';
}
```

`Square` переопределяет `kind`, и `show` автоматически подхватывает переопределение: миксин всегда вызывает член на реальном объекте.

# --instructions--

Расставь элементы так, чтобы определить класс `Shape` с геттером `kind`, возвращающим `'shape'`, миксин `Printable`, ограниченный `Shape`, с методом `show`, который выводит `a ` и затем `kind`, класс `Square`, который наследует `Shape`, использует `Printable` и переопределяет `kind` значением `'square'`, и `main`, который вызывает `show` у `Square`. Сначала определи `Shape`, затем `Printable`, затем `Square`, затем `main`. Программа должна вывести:

```
a square
```
