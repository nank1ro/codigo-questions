# --description--

Множества поддерживают классические операции над множествами. Каждая из них возвращает **новое** множество и не изменяет исходные:

- `a.union(b)` содержит элементы, которые есть в `a` **или** в `b`
- `a.intersection(b)` содержит элементы, которые есть **и** в `a`, и в `b`
- `a.difference(b)` содержит элементы `a`, которых **нет** в `b`

```dart
var a = {1, 2, 3};
var b = {2, 3, 4};
print(a.union(b));        // {1, 2, 3, 4}
print(a.intersection(b)); // {2, 3}
print(a.difference(b));   // {1}
```
