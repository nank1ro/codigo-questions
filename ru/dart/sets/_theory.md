**Множество** (`Set`) — это коллекция **уникальных** значений: одно и то же значение может встречаться не более одного раза. Как и карта, множество создаётся с помощью синтаксиса литерала `{}`, но оно содержит обычные значения вместо пар `ключ: значение`:

```dart
Set<int> numbers = {1, 2, 3};
print(numbers); // {1, 2, 3}
```

Аннотация типа `Set<int>` сообщает Dart, что каждый элемент имеет тип `int`. Как и для списков и карт, `var` выводит тип из литерала:

```dart
var colors = {'red', 'green'}; // Set<String>
```

---

Множество никогда не хранит одно и то же значение дважды. Если литерал содержит дубликаты, сохраняется только первое вхождение, а остальные отбрасываются во время выполнения без каких-либо ошибок (анализатор предупредит о литерале, который повторяет значение):

```dart
var letters = {'a', 'b', 'a', 'b', 'c'};
print(letters); // {a, b, c}
```

Свойство `.length` возвращает, сколько **уникальных** элементов содержит множество:

```dart
print(letters.length); // 3
```

---

Метод `.add(value)` вставляет одно значение. Он возвращает `true`, если значение было добавлено, и `false`, если оно уже было во множестве — в этом случае ничего не меняется. Метод `.addAll(iterable)` вставляет все элементы списка или другого множества, также пропуская те, что уже присутствуют:

```dart
var tags = {'dart'};
tags.add('web');    // true
tags.add('dart');   // false, already there
tags.addAll(['web', 'mobile']);
print(tags); // {dart, web, mobile}
```

Пустой литерал `{}` — это **карта**, а не множество. Чтобы создать пустое множество, укажите ему тип:

```dart
var empty = <String>{};
Set<int> other = {};
```

---

Метод `.remove(value)` удаляет значение из множества. Он возвращает `true`, если значение там было, и `false` в противном случае:

```dart
var numbers = {1, 2, 3};
print(numbers.remove(2)); // true
print(numbers.remove(9)); // false
print(numbers); // {1, 3}
```

Чтобы удалить все элементы сразу, используйте `.clear()`.

---

Чтобы проверить, есть ли значение во множестве, используйте `.contains(value)`, которая возвращает `bool`. Свойство `.isEmpty` равно `true`, когда во множестве нет элементов, а `.isNotEmpty` — когда есть хотя бы один:

```dart
var seen = {'x', 'y'};
print(seen.contains('x')); // true
print(seen.contains('z')); // false
print(seen.isEmpty);       // false
print(seen.isNotEmpty);    // true
```

---

Стандартное множество в Dart запоминает **порядок вставки**: когда вы его выводите или перебираете, элементы идут в том порядке, в котором были добавлены впервые. Добавление значения, которое уже присутствует, не перемещает его:

```dart
var numbers = {3, 1, 3, 2};
print(numbers); // {3, 1, 2}
```

---

Множество является `Iterable`, поэтому вы можете перебирать его элементы напрямую с помощью `for-in`, как и список. Индексов нет: элементы посещаются в порядке вставки:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
