# --description--

Метод `.add(value)` вставляет одно значение. Он возвращает `true`, если значение было добавлено, и `false`, если оно уже было во множестве — в этом случае ничего не меняется. Метод `.addAll(iterable)` вставляет все элементы списка или другого множества, также пропуская те, что уже присутствуют:

```dart
var tags = {'dart'};
tags.add('web');    // true
tags.add('dart');   // false, already there
tags.addAll(['web', 'mobile']);
print(tags); // {dart, web, mobile}
```

Пустой литерал `{}` — это **карта**, а не множество. Чтобы создать пустое множество, укажите ему тип:

```dart
var empty = <String>{};
Set<int> other = {};
```
