# --description--

**Множество** (`Set`) — это коллекция **уникальных** значений: одно и то же значение может встречаться не более одного раза. Как и карта, множество создаётся с помощью синтаксиса литерала `{}`, но оно содержит обычные значения вместо пар `ключ: значение`:

```dart
Set<int> numbers = {1, 2, 3};
print(numbers); // {1, 2, 3}
```

Аннотация типа `Set<int>` сообщает Dart, что каждый элемент имеет тип `int`. Как и для списков и карт, `var` выводит тип из литерала:

```dart
var colors = {'red', 'green'}; // Set<String>
```
