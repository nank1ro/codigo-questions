# --description--

Чтобы проверить, есть ли значение во множестве, используйте `.contains(value)`, которая возвращает `bool`. Свойство `.isEmpty` равно `true`, когда во множестве нет элементов, а `.isNotEmpty` — когда есть хотя бы один:

```dart
var seen = {'x', 'y'};
print(seen.contains('x')); // true
print(seen.contains('z')); // false
print(seen.isEmpty);       // false
print(seen.isNotEmpty);    // true
```

Дано множество `seen`. Сохраните в `bool` с именем `hasX`, содержит ли оно `'x'`, в `bool` с именем `hasZ`, содержит ли оно `'z'`, и в `bool` с именем `empty`, пусто ли оно.
