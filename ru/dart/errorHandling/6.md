# --description--

За обработчиками может следовать третий блок. `finally` выполняется **в любом случае**: после нормального завершения блока `try`, после восстановившего обработчика, а также когда ничего не совпало и сбой всё ещё распространяется наружу.

```dart
try {
  return 'parsed ${int.parse(text)}';
} on FormatException {
  return 'failed';
} finally {
  print('done');
}
```

Он выполняется даже раньше, чем `return` вернёт значение, именно поэтому сообщение выше печатается до того, как вызывающий увидит результат. Это делает `finally` местом для работы, которая должна произойти в любом случае, например закрытия того, что вы открыли.
