# --description--

Последний элемент — выброс `Error` намеренно. Функция, документирующая, что она принимает, должна громко отказывать всему остальному, и `ArgumentError` — объект для этого:

```dart
int setVolume(int level) {
  if (level < 0 || level > 100) {
    throw ArgumentError('level must be between 0 and 100');
  }
  return level;
}
```

Сообщение доступно как `e.message`, а `toString()` печатает `Invalid argument(s): ` с ним.

Это не противоречит правилу из прошлого упражнения. Выбросить `ArgumentError` — правильно, перехватить — нет: он сообщает автору *вызывающего кода*, что сам вызов неверен, и исправление — это проверка до вызова, а не обработчик вокруг него.

# --instructions--

Напишите функцию `checkAge`, которая принимает `int` `age` и возвращает его, но выбрасывает `ArgumentError('age must be between 0 and 120')`, когда возраст ниже `0` или выше `120`.

Пример:
```dart
print(checkAge(30)); // 30
```

`checkAge(30)` должна вернуть `30`, а оба конца диапазона должны приниматься

```dart
  test('test1', () {
    expect(checkAge(30), 30, reason: '--err-t1--');
    expect(checkAge(0), 0, reason: '--err-t1--');
    expect(checkAge(120), 120, reason: '--err-t1--');
  });
```

`checkAge(-1)` и `checkAge(121)` должны выбросить `ArgumentError`

```dart
  test('test2', () {
    expect(() => checkAge(-1), throwsArgumentError, reason: '--err-t2--');
    expect(() => checkAge(121), throwsArgumentError, reason: '--err-t2--');
  });
```

Выброшенная ошибка должна нести сообщение `'age must be between 0 and 120'`

```dart
  test('test3', () {
    try {
      checkAge(200);
      fail('--err-t3--');
    } on ArgumentError catch (e) {
      expect(e.message, 'age must be between 0 and 120', reason: '--err-t3--');
    }
  });
```
