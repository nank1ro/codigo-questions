# --description--

Некоторые библиотеки предлагают версию, которая вообще не выбрасывает. Рядом с `int.parse` в Dart есть **`int.tryParse`**: то же преобразование, но оно возвращает `null` вместо выброса исключения, когда текст не является числом.

```dart
print(int.parse('42'));     // 42
print(int.tryParse('42'));  // 42
print(int.tryParse('42x')); // null
```

Результат имеет тип `int?`, поэтому оператор `??` превращает его прямо в значение по умолчанию:

```dart
final port = int.tryParse(text) ?? 8080;
```

Когда сбой обычен и вам нужно только запасное значение, это короче и понятнее, чем блок `try`. Оставьте `int.parse` для случаев, когда плохой текст — действительно сбой, о котором кто-то выше должен узнать.
