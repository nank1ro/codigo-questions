# --description--

`firstWhere` возвращает первый элемент, соответствующий проверке. Когда ничего не соответствует, возвращать нечего, и он выбрасывает `StateError`:

```dart
final words = ['a', 'fg'];
print(words.firstWhere((w) => w.length > 3)); // Bad state: No element
```

Как и `int.tryParse`, библиотека предлагает выход. Именованный параметр `orElse` принимает функцию, которая создаёт значение для случая, когда ничего не совпало:

```dart
print(words.firstWhere((w) => w.length > 3, orElse: () => 'none')); // none
```

Выбор тот же, что и раньше: `orElse`, когда «ничего не совпало» — обычный исход, и вызов без него, когда это означало бы, что данные сломаны и кто-то должен об этом узнать.

# --instructions--

Напишите две функции, принимающие `List<String>` `words`.

`firstLong` возвращает первое слово длиннее трёх символов с помощью `firstWhere` или `'none'`, когда такого нет, с `orElse`.

`firstLongStrict` делает то же самое с `firstWhere`, но без `orElse`, поэтому выбрасывает `StateError`, когда такого нет.

Пример:
```dart
print(firstLong(['a', 'bcde', 'fg'])); // bcde
print(firstLong(['a', 'fg'])); // none
```

```dart
String firstLong(List<String> words) {
  return words.firstWhere((w) => w.length > 3, orElse: () => 'none');
}

String firstLongStrict(List<String> words) {
  return words.firstWhere((w) => w.length > 3);
}
```
