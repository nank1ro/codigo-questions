# --description--

Свойство `.isEmpty` равно `true`, когда список не содержит элементов, а `.isNotEmpty` равно `true`, когда в нём есть хотя бы один элемент.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
