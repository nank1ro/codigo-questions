# --description--

Иногда **вы** знаете, что nullable-значение в определённой точке не равно `null`, даже если компилятор этого понять не может. Оператор **null assertion** `!` превращает `String?` в `String`, обещая, что значение присутствует:

```dart
String? text = 'Dart';
String sure = text!;
print(sure.length); // 4
```

Будьте осторожны: `!` переносит проверку с времени компиляции на время выполнения. Если значение **всё же** равно `null`, программа выбрасывает ошибку и останавливается:

```dart
String? text;
print(text!.length); // Null check operator used on a null value
```

Используйте `!` умеренно и только тогда, когда `null` в этом месте в любом случае был бы ошибкой.

Пример:
```dart

```
