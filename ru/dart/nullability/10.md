# --description--

Продвижение типа **не** работает для **поля** класса, которое может быть изменено извне, потому что между проверкой и использованием другой участок кода (геттер, переопределённый в подклассе, другой метод) может снова установить его в `null`:

```dart
class Box {
  int? value;

  int doubled() {
    if (value != null) {
      return value * 2; // error: 'value' can't be unconditionally accessed
    }
    return 0;
  }
}
```

Стандартное решение — скопировать поле в **локальную переменную**, которая продвигается:

```dart
int doubled() {
  final v = value;
  if (v != null) {
    return v * 2;
  }
  return 0;
}
```

# --instructions--

Почему первая версия `doubled` из описания не компилируется?

# --answers--

- `value` — это поле, поэтому проверка на null его не продвигает: сначала скопируйте его в локальную переменную
- Значения `int?` нельзя умножать, даже когда они не `null`
- В инструкции `if` не хватает ветки `else`
- Поля класса не могут иметь nullable-тип
