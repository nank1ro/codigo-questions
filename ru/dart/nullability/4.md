# --description--

Часто отсутствующее значение нужно заменить **значением по умолчанию**. Оператор **if-null** `??` возвращает левый операнд, когда он не `null`, и правый в противном случае:

```dart
String? nickname;
print(nickname ?? 'anonymous'); // anonymous

nickname = 'Ada';
print(nickname ?? 'anonymous'); // Ada
```

`??` реагирует только на `null`: пустая строка `''` или число `0` — настоящие значения, поэтому они сохраняются.

`??` хорошо сочетается с `?.`, потому что `?.` даёт nullable-результат:

```dart
String? text;
print(text?.length ?? 0); // 0
```

Напишите функцию `greet`, которая принимает nullable-параметр типа `String` с именем `name` и возвращает `'Hello, '` с добавленным `name` или с `'stranger'`, когда `name` равно `null`. Используйте `??`.

Пример:
```dart

print(greet(null));  // Hello, stranger
```
