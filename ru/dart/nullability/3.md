# --description--

Вызов метода или чтение свойства у `null` привело бы к аварийному завершению, поэтому Dart не позволяет делать это у nullable-значения через обычную точку:

```dart
String? text;
print(text.length); // error: the property 'length' can't be unconditionally accessed
```

Оператор **null-безопасного доступа** `?.` решает эту проблему: если значение равно `null`, всё выражение равно `null` и больше ничего не вычисляется, иначе он работает как обычная `.`:

```dart
String? text = 'Dart';
print(text?.length); // 4

text = null;
print(text?.length); // null
```

Поскольку результат может быть `null`, его тип nullable: `text?.length` — это `int?`, а не `int`.
