# --description--

Многие библиотечные функции используют `null`, чтобы сообщить, что что-то **не удалось сделать**. Преобразование строки в число — классический пример: `int.parse` выбрасывает `FormatException`, когда текст не является числом, а `int.tryParse` вместо этого возвращает `null` и позволяет вам решить, что делать:

```dart
print(int.tryParse('42'));  // 42
print(int.tryParse('4x2')); // null
print(int.tryParse(''));    // null
```

Возвращаемый тип `int.tryParse` — `int?`, поэтому всё изученное применимо: `??` для значения по умолчанию, `?.` для цепочки вызовов и проверка `if` для продвижения. `double.tryParse` работает так же.

# --instructions--

Напишите функцию `parseOrZero`, которая принимает параметр типа `String` с именем `text` и возвращает содержащееся в нём целое число или `0`, когда текст не является корректным целым числом. Используйте `int.tryParse`.

Пример:
```dart
print(parseOrZero('42'));  // 42
print(parseOrZero('abc')); // 0
```
