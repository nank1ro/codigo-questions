# --description--

Реальные данные полны пробелов: незаполненное поле формы, отсутствующий столбец в файле, строка, которая не совсем число. Инструменты этой главы естественно сочетаются для работы с ними: `nonNulls`, чтобы отбросить отсутствующие элементы, `int.tryParse`, чтобы безопасно преобразовать, и `??` или проверка `if`, чтобы разобраться с тем, что преобразовать не удалось.

# --instructions--

Напишите функцию `total`, которая принимает параметр `List<String?>` с именем `prices` и возвращает сумму значений, которые можно преобразовать в `int`, игнорируя как записи `null`, так и строки, не являющиеся корректными целыми числами.

Пример:
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
