# --description--

Nullability относится и к **элементам** коллекции. `List<int>` никогда не содержит `null`, а `List<int?>` может:

```dart
List<int?> scores = [7, null, 9];
```

Обратите внимание на отличие от `List<int>?` — это список, который сам может отсутствовать, но, когда он есть, содержит только настоящие числа.

Чтобы избавиться от элементов `null`, `nonNulls` возвращает `Iterable` только с присутствующими значениями, типизированный без `?`:

```dart
var present = scores.nonNulls.toList(); // List<int>
print(present); // [7, 9]
```

`whereType<int>()` делает то же самое и работает также, когда список смешивает несколько типов.
