# --description--

Проверять nullable-значение через `if` безопаснее, чем через `!`, и Dart вас за это вознаграждает. После проверки вида `if (x != null)` компилятор знает, что внутри блока `x` не может быть `null`, поэтому считает `x` там non-nullable. Это называется **продвижением типа**:

```dart
int twice(int? n) {
  if (n != null) {
    return n * 2; // here n is an int, no ! needed
  }
  return 0;
}
```

Продвижение работает и после раннего возврата:

```dart
int twice(int? n) {
  if (n == null) return 0;
  return n * 2; // n is an int from here on
}
```

Продвижение применяется к **локальным переменным и параметрам**, значение которых не может измениться за вашей спиной между проверкой и использованием.

# --instructions--

Напишите функцию `half`, которая принимает nullable-параметр типа `int` с именем `n` и возвращает `n`, делённое на `2` целочисленным делением `~/`, или `0`, когда `n` равно `null`. Используйте проверку на null через `if`, а не `!`.

Пример:
```dart
print(half(10));   // 5
print(half(null)); // 0
```
