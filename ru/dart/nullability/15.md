# --description--

Ещё у двух операторов есть null-безопасный вариант.

**Null-безопасный каскад** `?..` выполняет цепочку каскадных операций только тогда, когда объект не равен `null`, и пропускает их все в противном случае:

```dart
List<int>? numbers;
numbers?..add(1)..add(2); // nothing happens, numbers is still null
```

**Null-безопасный спред** `...?` вставляет элементы nullable-коллекции в литерал, не добавляя ничего, когда коллекция равна `null`:

```dart
List<int>? extra;
print([0, ...?extra]); // [0]

extra = [1, 2];
print([0, ...?extra]); // [0, 1, 2]
```

Без `?` запись `...extra` для `List<int>?` была бы ошибкой компиляции.
