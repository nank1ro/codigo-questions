# --description--

Nullable-переменная, объявленная **без значения**, начинается с `null`, поэтому `= null` можно опустить:

```dart
int? age;
print(age); // null
```

У non-nullable переменной такого значения по умолчанию нет: Dart отказывается компилировать любой код, который читает её до присваивания значения.

```dart
int count;
print(count); // error: 'count' must be assigned before it can be used
```
