# --description--

Главное преимущество null-безопасности в том, что большинство ошибок с `null` находит **компилятор**, а не ваши пользователи. Правила, изученные до сих пор:

- non-nullable тип (`String`, `int`, `List<int>`...) никогда не может быть `null`
- nullable тип (`String?`, `int?`, `List<int>?`...) может и начинается с `null`, если объявлен без значения
- `.` у nullable-значения не компилируется: используйте `?.` или задайте значение по умолчанию через `??`

# --instructions--

Какое из этих объявлений **не** компилируется?

# --answers--

- `String b = null;`
- `String? a = null;`
- `int? c;`
- `int d = 0;`
