# --description--

Non-nullable поле обычно должно получить значение в конструкторе. Когда значение становится известно только **позже** (после чтения файла, открытия соединения...), можно пометить поле как `late`: компилятор примет отсутствие инициализатора и поверит, что вы присвоите полю значение до его чтения.

```dart
class Connection {
  late String host;

  void open() {
    host = 'example.com';
  }
}
```

Чтение поля `late`, которому ещё не присвоено значение, выбрасывает `LateInitializationError` во время выполнения. Как и `!`, `late` меняет гарантию времени компиляции на проверку во время выполнения, так что это обещание, которое нужно сдержать.

`late` можно также сочетать с инициализатором, который тогда выполняется **лениво**, при первом чтении переменной:

```dart
late String report = buildReport(); // buildReport() runs only when report is used
```
