# --description--

Запомните разницу между тремя операторами, которые вы видели для nullable-значения:

- `?.` возвращает `null`, когда значение равно `null`, и никогда не выбрасывает ошибку
- `??` заменяет `null` значением по умолчанию
- `!` предполагает, что значение присутствует, и **выбрасывает ошибку во время выполнения**, когда его нет

Ни один из них не является ошибкой компиляции: компилятор доверяет вашему `!`, и только работающая программа может обнаружить, что обещание нарушено.

# --instructions--

Что произойдёт при запуске следующего кода?

```dart
void main() {
  String? city;
  print(city!.length);
}
```

# --answers--

- Он выбросит ошибку во время выполнения
- Он выведет `null`
- Он выведет `0`
- Он не скомпилируется
