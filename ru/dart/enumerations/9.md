# --instructions--

Имея `enum Size { small, medium, large }`, что произойдёт со следующим кодом?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Не компилируется: switch-выражение над enum должно охватывать все значения
- Компилируется и возвращает `null` для `Size.large`
- Компилируется и выбрасывает исключение во время выполнения для `Size.large`
- Компилируется и автоматически возвращает `'L'` для `Size.large`
