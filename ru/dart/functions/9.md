# --description--

Dart также поддерживает **необязательные позиционные параметры** — параметры, заключённые в квадратные скобки `[]`. Они передаются по позиции, могут быть опущены вызывающей стороной и могут иметь значение по умолчанию:

```dart
String greet([String name = "World"]) {
  return "Hello, $name!";
}

void main() {
  print(greet());         // Hello, World!
  print(greet("Alice"));  // Hello, Alice!
}
```

# --instructions--

Напишите функцию `greetUser`, которая принимает **необязательный позиционный** параметр `String` с именем `name` со **значением по умолчанию** `"World"` и возвращает строку `"Hello, <name>!"`.

Пример:
```dart
print(greetUser());          // Hello, World!
print(greetUser("Alice"));   // Hello, Alice!
```
