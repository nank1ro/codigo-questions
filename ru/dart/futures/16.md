# --description--

Поскольку `await` превращает ошибки future в обычные исключения, к асинхронному коду применимы все привычные схемы `try`/`catch`, включая циклы с повторными попытками. Внутри блока `catch` **`rethrow`** бросает ту же ошибку снова — так ты сдаёшься после последней попытки:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Параметр функционального типа, такой как `Future<String> Function() task`, получает саму **функцию**, а не future: каждый вызов `task()` начинает новую попытку.

# --instructions--

Напиши `async`-функцию `retry`, которая принимает `Future<int> Function()` `task` и `int` `attempts` и возвращает `Future<int>`. Вызови `task()` и завершись его значением; если он бросит исключение, попробуй снова, вызвав `task` в общей сложности не более `attempts` раз. Если последняя попытка тоже не удалась, брось её ошибку заново через `rethrow`.

Пример:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` для задачи, которая всегда успешна, должна завершиться её значением после единственного вызова

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` для задачи, которая дважды падает, а затем возвращает `7`, должна завершиться значением `7` после `3` вызовов

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` для задачи, которая всегда падает, должна вызвать её ровно `attempts` раз и затем завершиться с той же ошибкой

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
