# --instructions--

Напиши функцию `sumUntilError`, которая принимает `Stream<int>` `source` и возвращает `Future<int>`, завершающийся суммой его значений. Если поток выдаёт ошибку, остановись и завершись суммой значений, полученных **до** ошибки, вместо того чтобы бросать исключение.

Пример:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

`sumUntilError` для потока, который выдаёт `5`, `3`, а затем ошибку, должен завершиться значением `8`

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
