# --description--

Как и у `Iterable`, у `Stream` есть методы, которые строят **новый поток** из существующего:

- `map` преобразует каждое событие
- `where` оставляет только события, удовлетворяющие условию
- `take` останавливается после заданного числа событий

```dart
final numbers = Stream.fromIterable([1, 2, 3, 4, 5, 6]);
final firstOdds = numbers.where((n) => n.isOdd).take(2);
print(await firstOdds.toList()); // [1, 3]
```

Эти методы **ленивые**: ничего не выполняется, пока кто-нибудь не начнёт слушать получившийся поток. Их можно объединять в цепочку, а исходный поток никогда не изменяется.

```dart
Stream<int> evenSquares(Stream<int> source) {
  return source.where((n) => n.isEven).map((n) => n * n);
}
```
