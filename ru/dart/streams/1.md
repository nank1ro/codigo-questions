# --description--

`Future` представляет **одно** значение, которое приходит позже. **Stream** представляет **последовательность** значений, приходящих со временем: нажатия клавиш, части файла, сообщения от сервера. Каждое значение называется **событием**, и после последнего события поток **завершён**.

Самый простой способ создать поток — `Stream.fromIterable`, который выдаёт каждый элемент списка, один за другим:

```dart
final numbers = Stream.fromIterable([1, 2, 3]);
```

Чтобы потреблять события по одному, используется цикл **`await for`**. Как и `await`, он разрешён только внутри функции, помеченной `async`, поэтому `main` становится `Future<void> main() async`. Тело цикла выполняется один раз на событие, и цикл заканчивается, когда поток завершён:

```dart
Future<void> main() async {
  final names = Stream.fromIterable(['Ada', 'Linus']);
  await for (final name in names) {
    print(name);
  }
  // Ada
  // Linus
}
```

Обычный цикл `for` здесь не работает: `Stream` — не `Iterable`, его значения недоступны все сразу.
