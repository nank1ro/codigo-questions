# --description--

Цикл `await for` может не только выводить: он может обновлять переменную, объявленную до цикла. Функция, которая потребляет поток и вычисляет результат, должна быть помечена `async` и возвращает `Future` этого результата:

```dart
Future<int> count(Stream<String> words) async {
  var total = 0;
  await for (final word in words) {
    total += word.length;
  }
  return total;
}
```

Функция доходит до `return` только после того, как поток завершён, поэтому вызывающий получает итоговое значение, когда дожидается future:

```dart
print(await count(Stream.fromIterable(['hi', 'dart']))); // 6
```
