# --description--

`await for` приостанавливает текущую функцию, пока поток не завершён. Когда ты хочешь реагировать на события **не дожидаясь**, вызови `listen` и передай колбэк: он вызывается один раз на событие, а код после `listen` выполняется сразу же.

```dart
final ticks = Stream.fromIterable([1, 2]);
ticks.listen((tick) => print('tick $tick'));
print('not waiting');
// not waiting
// tick 1
// tick 2
```

`listen` также принимает именованный параметр `onDone` — функцию без аргументов, вызываемую, когда поток заканчивается:

```dart
final ticks2 = Stream.fromIterable([1, 2]);
ticks2.listen((tick) => print(tick), onDone: () => print('no more ticks'));
```
