# --description--

Контроллер может создать широковещательный поток напрямую, с помощью именованного конструктора `StreamController<T>.broadcast()`. Его `stream` принимает любое число слушателей, и каждое событие доставляется им всем, в порядке их подписки:

```dart
import 'dart:async';

void main() {
  final controller = StreamController<String>.broadcast();
  controller.stream.listen((msg) => print('first: $msg'));
  controller.stream.listen((msg) => print('second: $msg'));
  controller.add('hi');
  controller.close();
}
// first: hi
// second: hi
```

Как и любой широковещательный поток, он не буферизует: события, добавленные до того, как слушатель подписался, для него потеряны.
