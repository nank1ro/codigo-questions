# --description--

`StreamController` часто создаётся и потребляется в одном и том же месте: подписываешься на `controller.stream` через `listen`, затем добавляешь события через `add` и закрываешь контроллер через `close`. Так как `listen` не ждёт, события доставляются после того, как текущий код закончится, но всегда в том порядке, в котором были добавлены:

```dart
import 'dart:async';

void main() {
  final controller = StreamController<int>();
  controller.stream.listen((n) => print('got $n'));
  controller.add(1);
  controller.add(2);
  controller.close();
}
// got 1
// got 2
```
