# --description--

Генераторы производят события внутри одной функции. Когда события приходят **откуда-то ещё** (от кнопки, из сетевого колбэка, от другого объекта), тебе нужен **`StreamController`**. Он живёт в библиотеке `dart:async`, поэтому файл должен начинаться с `import 'dart:async';`.

Контроллер владеет потоком и позволяет проталкивать в него события:

```dart
import 'dart:async';

Stream<int> dice() {
  final controller = StreamController<int>();
  controller.add(4);
  controller.add(2);
  controller.close();
  return controller.stream;
}
```

- `add(value)` отправляет одно событие
- `close()` завершает поток; забыть о нём — значит оставить слушателей ждать вечно
- `stream` — это `Stream`, который потребляют слушатели

События, добавленные до того, как кто-либо начал слушать, хранятся в буфере, поэтому код выше безопасен: слушатель, который придёт позже, всё равно получит `4` и `2`.

# --solutions--

```dart
import 'dart:async';

Stream<String> announce(List<String> names) {
  final controller = StreamController<String>();
  for (final name in names) {
    controller.add(name.toUpperCase());
  }
  controller.close();
  return controller.stream;
}
```
