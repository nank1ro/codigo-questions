# --description--

Все потоки, которые мы видели до сих пор, **односубскрипционные**: они допускают ровно одного слушателя. Второй вызов `listen`, `await for` или любого потребляющего метода бросает `StateError` ("Stream has already been listened to").

Чтобы разделить поток между несколькими слушателями, преобразуй его в **широковещательный** (broadcast) поток с помощью `asBroadcastStream()`:

```dart
final shared = Stream.fromIterable([1, 2, 3]).asBroadcastStream();
final total = shared.reduce((a, b) => a + b);
final count = shared.length;
print(await total); // 6
print(await count); // 3
```

Широковещательный поток не буферизует: слушатель получает только события, выданные **после** его подписки. В примере оба слушателя подписываются до первого `await`, поэтому оба получают каждое событие.

# --instructions--

Напиши функцию `sumAndCount`, которая принимает `Stream<int>` `source` и возвращает `Future<List<int>>`, завершающийся списком из двух элементов: суммой значений и количеством значений. Преобразуй `source` в широковещательный поток, запусти оба потребляющих вызова **до** того, как дожидаться любого из них, а потом дождись их. В потоке всегда есть хотя бы одно событие.

Пример:
```dart
print(await sumAndCount(Stream.fromIterable([1, 2, 3]))); // [6, 3]
```

```dart
Future<List<int>> sumAndCount(Stream<int> source) async {
  final shared = source.asBroadcastStream();
  final sum = shared.reduce((a, b) => a + b);
  final count = shared.length;
  return [await sum, await count];
}
```
