# --description--

`Stream.fromIterable` требует все значения заранее. Чтобы **производить** значения по одному, напиши **асинхронный генератор**: функцию, тело которой помечено `async*`, а возвращаемый тип — `Stream<T>`. Внутри неё `yield` отправляет одно событие в поток:

```dart
Stream<int> countTo(int n) async* {
  for (var i = 1; i <= n; i++) {
    yield i;
  }
}
```

Тело не выполняется, когда ты вызываешь `countTo(3)`: оно выполняется лениво, по мере того как слушатель запрашивает значения, и поток завершается, когда тело заканчивается.

Чтобы собрать все события в `List`, вызови `toList()`. Он возвращает `Future<List<T>>`, поэтому его нужно ждать через `await`:

```dart
final values = await countTo(3).toList();
print(values); // [1, 2, 3]
```

# --instructions--

Напиши `async*`-функцию `countdown`, которая принимает `int` `from` и возвращает `Stream<int>`, выдающий значения от `from` вниз до `1`. Если `from` равно `0` или меньше, поток не выдаёт ничего.

Пример:
```dart
print(await countdown(3).toList()); // [3, 2, 1]
```
