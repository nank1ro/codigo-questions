# --description--

Так как `where`, `map` и `take` каждый возвращают поток, их можно объединить в цепочку и закончить `toList()`, чтобы получить результат списком. Только финальный `toList()` требует `await`, потому что это единственный вызов, возвращающий `Future`:

```dart
final numbers = Stream.fromIterable([5, 12, 8, 20, 3]);
final big = await numbers.where((n) => n > 6).take(2).toList();
print(big); // [12, 8]
```
