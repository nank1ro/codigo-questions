# --description--

Поток может нести не только значения, но и **ошибки**. Внутри генератора `async*` `throw` отправляет событие ошибки и завершает поток; `StreamController` может отправить такое событие через `addError`.

На стороне потребителя цикл `await for` перебрасывает ошибку там, где находится цикл, поэтому её обрабатывают обычным `try`/`catch` вокруг цикла:

```dart
Stream<int> risky() async* {
  yield 1;
  throw StateError('sensor offline');
}

Future<void> main() async {
  try {
    await for (final n in risky()) {
      print(n);
    }
  } catch (e) {
    print('caught: $e');
  }
}
// 1
// caught: Bad state: sensor offline
```

С `listen` вместо этого передай колбэк `onError`: `stream.listen(print, onError: (e) => print('caught: $e'));`
