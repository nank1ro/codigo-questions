# --description--

Кроме `toList()`, у потока есть и другие методы, которые **потребляют** все его события и возвращают один `Future`:

- `first` и `last` завершаются первым или последним событием
- `length` завершается количеством событий
- `join(separator)` завершается всеми событиями, соединёнными в одну `String`
- `reduce(combine)` объединяет события по два в одно значение

```dart
final numbers = Stream.fromIterable([3, 9, 2]);
print(await numbers.reduce((a, b) => a + b)); // 14
```

`reduce` вызывает `combine` с накопленным результатом и следующим событием. Он бросает исключение, если поток пуст, поэтому используй его только тогда, когда хотя бы одно событие гарантировано.

# --instructions--

Напиши две функции:
- `largest`, которая принимает `Stream<int>` `source` и возвращает `Future<int>`, завершающийся наибольшим значением, используя `reduce`. В потоке всегда есть хотя бы одно событие.
- `sentence`, которая принимает `Stream<String>` `words` и возвращает `Future<String>`, завершающийся всеми словами, соединёнными одним пробелом.

Пример:
```dart
print(await largest(Stream.fromIterable([3, 9, 2])));        // 9
print(await sentence(Stream.fromIterable(['I', 'am', 'Dart']))); // I am Dart
```

# --solutions--

```dart
Future<int> largest(Stream<int> source) {
  return source.reduce((a, b) => a > b ? a : b);
}

Future<String> sentence(Stream<String> words) {
  return words.join(' ');
}
```
