# --description--

Методы строк возвращают строки, поэтому их можно **выстраивать в цепочку** один за другим. В сочетании с `.split('')`, свойством списков `.reversed` и `.join()` это позволяет перевернуть строку в одном выражении:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

**Палиндром** — это текст, который читается одинаково слева направо и справа налево, например `level`.

# --instructions--

Напишите функцию `isPalindrome`, которая принимает параметр `String` по имени `text` и возвращает `true`, если это палиндром, без учёта регистра и пробелов, или `false` в противном случае.

Пример:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
