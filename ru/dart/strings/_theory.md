**Строка (String)** — это фрагмент текста: последовательность символов, заключённая в кавычки. В Dart можно использовать одинарные кавычки `'...'` или двойные кавычки `"..."`, они работают абсолютно одинаково:

```dart
String name = 'Dart';
String other = "Dart";
print(name == other); // true
```

Выбор одного вида кавычек позволяет использовать другой вид внутри текста без какого-либо экранирования:

```dart
print("It's sunny");   // It's sunny
print('Say "hi"');     // Say "hi"
```

Если внутри текста нужна та же самая кавычка, экранируйте её обратным слэшем: `'It\'s sunny'`.

---

Две строки можно объединить в новую с помощью оператора `+`, который называется **конкатенацией**:

```dart
var greeting = 'Hello' + ', ' + 'Dart';
print(greeting); // Hello, Dart
```

Dart также объединяет два строковых **литерала**, записанных рядом друг с другом, без какого-либо оператора. Это удобно для разбиения длинного текста на несколько строк:

```dart
var text = 'Hello, '
    'Dart';
print(text); // Hello, Dart
```

С помощью `+` можно объединять только строки: `'Age: ' + 30` — это ошибка компиляции, потому что `30` имеет тип `int`.

---

Вместо конкатенации можно вставлять значения прямо в строку с помощью **интерполяции**. Напишите `$name`, чтобы вставить значение переменной, и `${expression}`, чтобы вставить результат любого выражения:

```dart
var name = 'Ana';
var age = 20;
print('$name is $age');             // Ana is 20
print('Next year: ${age + 1}');     // Next year: 21
```

Интерполяция работает с любым типом: числа, булевы значения и списки автоматически преобразуются в текст, поэтому `'Age: $age'` допустимо, даже если `age` имеет тип `int`.

---

Каждая строка знает, сколько символов она содержит, через своё свойство `.length`. Пробелы и знаки препинания тоже считаются символами:

```dart
var word = 'hello';
print(word.length);      // 5
print('a b'.length);     // 3
```

Можно прочитать один символ с помощью квадратных скобок и его **индекса**, начиная с `0`. Результатом будет `String` из одного символа:

```dart
print(word[0]);                // h
print(word[word.length - 1]);  // o
```

Чтение индекса за пределами строки (например, `word[5]`) вызывает ошибку.

---

Строки в Dart **неизменяемы**: однажды созданная строка никогда не меняется. Методы вроде `.toUpperCase()` и `.toLowerCase()` не изменяют исходную строку, они **возвращают новую**:

```dart
var word = 'Dart';
var loud = word.toUpperCase();
print(loud);  // DART
print(word);  // Dart
```

Если вы хотите, чтобы переменная содержала новое значение, присвойте результат обратно ей: `word = word.toUpperCase();`.

---

Текст, введённый пользователем, часто содержит лишние пробелы вокруг. Метод `.trim()` возвращает копию строки без начальных и конечных пробельных символов (пробелов, табуляций и переносов строк). `.trimLeft()` и `.trimRight()` убирают их только с одной стороны:

```dart
var input = '   hello  ';
print('[${input.trim()}]');      // [hello]
print('[${input.trimLeft()}]');  // [hello  ]
```

---

Метод `.substring(start, end)` возвращает часть строки от индекса `start` до индекса `end`, **не включая его**. Если опустить `end`, будет возвращено всё до конца строки:

```dart
var text = 'Hello Dart';
print(text.substring(0, 5));  // Hello
print(text.substring(6));     // Dart
```

---

Несколько методов позволяют искать внутри строки:

- `.contains(other)` возвращает `true`, если `other` встречается где-либо в строке
- `.startsWith(other)` и `.endsWith(other)` проверяют начало и конец
- `.indexOf(other)` возвращает индекс первого вхождения или `-1`, если оно не найдено

```dart
var file = 'report.pdf';
print(file.contains('port'));    // true
print(file.startsWith('rep'));   // true
print(file.endsWith('.txt'));    // false
print(file.indexOf('.'));        // 6
print(file.indexOf('x'));        // -1
```

Все они чувствительны к регистру: `'Dart'.contains('dart')` — это `false`.

---

Метод `.replaceAll(from, to)` возвращает новую строку, в которой **каждое** вхождение `from` заменено на `to`. `.replaceFirst(from, to)` заменяет только первое вхождение:

```dart
var text = 'a-b-c';
print(text.replaceAll('-', '+'));    // a+b+c
print(text.replaceFirst('-', '+'));  // a+b-c
```

---

Метод `.split(separator)` разбивает строку на `List<String>` при каждом вхождении разделителя. Противоположность — `.join(separator)`, метод списков, который склеивает элементы в одну строку:

```dart
var csv = 'a,b,c';
List<String> parts = csv.split(',');
print(parts);            // [a, b, c]
print(parts.join(' - ')); // a - b - c
```

Вызов `.split('')` с пустым разделителем даёт список из каждого отдельного символа.

---

Некоторые символы нельзя ввести прямо внутри кавычек. **Escape-последовательности** начинаются с обратного слэша: `\n` — это новая строка, `\t` — табуляция, `\\` — обратный слэш, а `\$` — символ доллара как есть (иначе `$` начинает интерполяцию):

```dart
print('one\ntwo');   // выводит one и two на разных строках
print('Cost: \$5');  // Cost: $5
```

**Сырая строка (raw string)** имеет префикс `r`: внутри неё обратные слэши и `$` — обычные символы, ничего не экранируется и не интерполируется:

```dart
print(r'C:\new\folder'); // C:\new\folder
print(r'Cost: $5');      // Cost: $5
```

Для текста, занимающего несколько строк, используйте **многострочную строку**, ограниченную тройными кавычками `'''` или `"""`: переносы строк внутри неё сохраняются.

```dart
var poem = '''
roses are red
violets are blue''';
```

---

Под капотом каждый символ строки хранится как число, его **code unit** (код UTF-16). `.codeUnitAt(index)` даёт код одного символа, а `.codeUnits` — весь список. `String.fromCharCode(code)` делает обратное, строя строку из кода:

```dart
var word = 'AB';
print(word.codeUnitAt(0));         // 65
print(word.codeUnits);             // [65, 66]
print(String.fromCharCode(67));    // C
```

Последовательные буквы имеют последовательные коды: `'A'` — это 65, `'B'` — 66, и так далее.

---

Две строки равны при сравнении через `==`, когда они содержат ровно одинаковые символы в одинаковом порядке. Сравнение **чувствительно к регистру** и учитывает каждый пробел:

```dart
print('dart' == 'dart');    // true
print('Dart' == 'dart');    // false
print('dart ' == 'dart');   // false
```

Чтобы сравнить без учёта регистра, сначала преобразуйте обе стороны: `a.toLowerCase() == b.toLowerCase()`. Для упорядочивания `.compareTo(other)` возвращает отрицательное число, `0` или положительное число в зависимости от того, идёт ли строка перед другой, равна ей или идёт после неё.

---

Поскольку строки неизменяемы, построение длинного текста с помощью `+=` в цикле создаёт новую строку на каждом шаге. **StringBuffer** эффективно собирает фрагменты текста и создаёт итоговую строку только тогда, когда вы её запрашиваете:

- `.write(value)` добавляет значение (любой тип преобразуется в текст)
- `.writeln(value)` добавляет значение, за которым следует перенос строки
- `.toString()` возвращает строку, собранную к этому моменту

```dart
var buffer = StringBuffer();
buffer.write('Hello');
buffer.write(', ');
buffer.writeln('Dart!');
buffer.write(42);
print(buffer.toString()); // Hello, Dart!\n42
```

---

Методы строк возвращают строки, поэтому их можно **выстраивать в цепочку** один за другим. В сочетании с `.split('')`, свойством списков `.reversed` и `.join()` это позволяет перевернуть строку в одном выражении:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

**Палиндром** — это текст, который читается одинаково слева направо и справа налево, например `level`.
