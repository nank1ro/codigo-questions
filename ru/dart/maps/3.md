# --description--

Присваивание вида `map[key] = value` либо **добавляет** новую пару, если ключа ещё нет в карте, либо **обновляет** значение, хранящееся под существующим ключом:

```dart
var ages = {'Ann': 30};
ages['Bob'] = 25; // adds Bob
ages['Ann'] = 31; // updates Ann
print(ages); // {Ann: 31, Bob: 25}
```

Новые ключи добавляются после существующих, поэтому карта запоминает порядок вставки.

Дополните код, чтобы обновить количество `apple` до `5`, а затем добавить `pear` с количеством `2`.
