# --description--

**Map** (карта) — это коллекция **пар ключ-значение**: каждое значение хранится под уникальным ключом, и вы используете ключ, чтобы снова найти значение. Карта создаётся с помощью синтаксиса литерала `{}`, где каждая пара записывается как `ключ: значение`:

```dart
Map<String, int> ages = {'Ann': 30, 'Bob': 25};
print(ages); // {Ann: 30, Bob: 25}
```

Аннотация типа `Map<String, int>` сообщает Dart, что каждый ключ имеет тип `String`, а каждое значение — тип `int`. Как и для списков, `var` выводит тип из литерала:

```dart
var capitals = {'Italy': 'Rome', 'France': 'Paris'};
```
