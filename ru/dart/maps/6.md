# --description--

Обращение к отсутствующему ключу никогда не выбрасывает ошибку, поэтому всегда учитывайте, что поиск может вернуть `null`. Безопасный подход — задать значение по умолчанию с помощью оператора `??`:

```dart
var ages = {'Ann': 30};
int age = ages['Zed'] ?? 0;
print(age); // 0
```

# --instructions--

Что выводит следующий код?

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Zed']);
```

# --answers--

- `null`
- `0`
- Выбрасывает ошибку
- Пустую строку
