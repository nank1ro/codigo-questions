**Map** (карта) — это коллекция **пар ключ-значение**: каждое значение хранится под уникальным ключом, и вы используете ключ, чтобы снова найти значение. Карта создаётся с помощью синтаксиса литерала `{}`, где каждая пара записывается как `ключ: значение`:

```dart
Map<String, int> ages = {'Ann': 30, 'Bob': 25};
print(ages); // {Ann: 30, Bob: 25}
```

Аннотация типа `Map<String, int>` сообщает Dart, что каждый ключ имеет тип `String`, а каждое значение — тип `int`. Как и для списков, `var` выводит тип из литерала:

```dart
var capitals = {'Italy': 'Rome', 'France': 'Paris'};
```

---

Чтобы прочитать значение, вы используете ключ в квадратных скобках, точно так же, как индекс в списке:

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Ann']); // 30
```

Если ключа нет в карте, поиск **не** выбрасывает ошибку: он возвращает `null`. Поэтому тип `ages['Ann']` — `int?` (nullable `int`), а не `int`:

```dart
print(ages['Zed']); // null
```

---

Присваивание вида `map[key] = value` либо **добавляет** новую пару, если ключа ещё нет в карте, либо **обновляет** значение, хранящееся под существующим ключом:

```dart
var ages = {'Ann': 30};
ages['Bob'] = 25; // adds Bob
ages['Ann'] = 31; // updates Ann
print(ages); // {Ann: 31, Bob: 25}
```

Новые ключи добавляются после существующих, поэтому карта запоминает порядок вставки.

---

Метод `.remove(key)` удаляет ключ и его значение из карты. Он возвращает удалённое значение или `null`, если такого ключа не было:

```dart
var ages = {'Ann': 30, 'Bob': 25};
int? removed = ages.remove('Ann');
print(removed); // 30
print(ages); // {Bob: 25}
```

Свойство `.length` возвращает количество пар ключ-значение:

```dart
print(ages.length); // 1
```

---

Чтобы проверить, содержит ли карта заданный ключ, используйте `.containsKey(key)`. Чтобы проверить, хранит ли какая-либо пара заданное значение, используйте `.containsValue(value)`. Оба метода возвращают `bool`:

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages.containsKey('Ann')); // true
print(ages.containsKey('Zed')); // false
print(ages.containsValue(25)); // true
```

---

Обращение к отсутствующему ключу никогда не выбрасывает ошибку, поэтому всегда учитывайте, что поиск может вернуть `null`. Безопасный подход — задать значение по умолчанию с помощью оператора `??`:

```dart
var ages = {'Ann': 30};
int age = ages['Zed'] ?? 0;
print(age); // 0
```

---

Свойство `.keys` возвращает все ключи карты, а `.values` — все значения, в порядке вставки. Это ленивые (`lazy`) `Iterable`, поэтому вызывайте `.toList()`, когда нужен настоящий `List`:

```dart
var ages = {'Ann': 30, 'Bob': 25};
List<String> names = ages.keys.toList();
List<int> years = ages.values.toList();
print(names); // [Ann, Bob]
print(years); // [30, 25]
```
