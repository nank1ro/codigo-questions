# --description--

Метод `.update(key, update)` заменяет значение существующего ключа. Второй аргумент — функция, которая получает текущее значение и возвращает новое. Если ключа нет, `.update()` выбрасывает ошибку, если только вы не передадите функцию `ifAbsent`, создающую начальное значение:

```dart
var stock = {'apple': 3};
stock.update('apple', (n) => n + 1); // apple becomes 4
stock.update('kiwi', (n) => n + 1, ifAbsent: () => 1); // kiwi is added with 1
print(stock); // {apple: 4, kiwi: 1}
```

# --instructions--

Дана карта `stock`. Используйте `.update()`, чтобы удвоить значение `'apple'`, а затем используйте `.update()` с `ifAbsent` для ключа `'kiwi'`, чтобы он был добавлен со значением `5`.
