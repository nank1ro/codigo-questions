# --description--

Функции, которые принимают и возвращают другие функции, можно свободно комбинировать. Классический пример — **композиция**: создание новой функции, которая выполняет одну функцию, а затем передаёт её результат в другую:

```dart
int Function(int) then(int Function(int) first, int Function(int) second) {
  return (n) => second(first(n));
}
```

# --instructions--

Напишите функцию `compose`, которая принимает два параметра `f` и `g`, оба типа `int Function(int)`, и возвращает функцию типа `int Function(int)`, которая применяет `f` к своему аргументу, а затем `g` к результату.

Пример:
```dart
var addThenDouble = compose((n) => n + 1, (n) => n * 2);
print(addThenDouble(3)); // 8
```
