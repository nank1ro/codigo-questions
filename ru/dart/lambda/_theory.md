Вы уже знаете, как объявить функцию с именем, например `void sayHello() { ... }`. Dart также позволяет писать функции **без имени**: **анонимные функции**. Она имеет те же части, что и именованная функция (параметры в круглых скобках и тело в фигурных скобках), но без типа возвращаемого значения и без имени:

```dart
(String name) {
  print('Hello, $name!');
}
```

Поскольку у неё нет имени, обычный способ её использования — сохранить её в переменную, а затем вызывать переменную как функцию:

```dart
var sayHello = (String name) {
  print('Hello, $name!');
};

sayHello('Dart'); // Hello, Dart!
```

Обратите внимание на `;` после закрывающей фигурной скобки: присваивание является обычным оператором.

---

Анонимная функция может принимать параметры и `return` значение, точно так же, как именованная. Тип возвращаемого значения не указывается: Dart **выводит** его из операторов `return` в теле.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```

---

Когда тело состоит из одного выражения, анонимная функция может использовать **стрелочный синтаксис** `=>`, как и именованная функция. Стрелка заменяет фигурные скобки и ключевое слово `return`:

```dart
var add = (int a, int b) => a + b;

print(add(2, 3)); // 5
```

Эта краткая форма — безусловно самый распространённый способ записи анонимных функций в Dart.

---

Функции — это значения, поэтому у них есть тип. Тип функции записывается как **тип возвращаемого значения**, затем ключевое слово `Function`, затем **типы параметров** в круглых скобках:

```dart
int Function(int, int) add = (int a, int b) => a + b;
bool Function(String) isEmpty = (String s) => s.isEmpty;
void Function() hello = () => print('Hello');
```

Когда переменная типизирована таким образом, типы параметров можно опустить в анонимной функции, поскольку Dart выводит их из объявленного типа:

```dart
int Function(int, int) add = (a, b) => a + b;
```

Простой тип `Function` принимает любую функцию, каковы бы ни были её параметры и тип возвращаемого значения, но он ничего не говорит Dart о том, как её вызывать.

---

Поскольку тип функции — это обычный тип, функция может принимать **другую функцию в качестве параметра**. Внутри тела параметр вызывается как любая функция:

```dart
int apply(int n, int Function(int) operation) {
  return operation(n);
}

print(apply(5, (n) => n * 2)); // 10
print(apply(5, (n) => n - 1)); // 4
```

Здесь вызывающий решает, что делает `apply`, передавая анонимную функцию в качестве второго аргумента.

---

Многие методы коллекций Dart принимают функцию в качестве аргумента, и анонимные функции — естественный способ её передать. Простейший из них — `forEach`, который вызывает данную функцию один раз для каждого элемента списка:

```dart
var fruits = ['apple', 'kiwi'];

fruits.forEach((fruit) {
  print('I like $fruit');
});
// I like apple
// I like kiwi
```

Тип параметра выводится из списка, поэтому `fruit` — это `String`, без необходимости указывать это явно.

---

Два других очень распространённых метода, принимающих анонимную функцию, — это `map` и `where`:

- `map` преобразует каждый элемент с помощью функции и возвращает новые значения
- `where` оставляет только те элементы, для которых функция возвращает `true`

Оба возвращают ленивый `Iterable`; вызовите `toList()`, чтобы превратить результат в `List`:

```dart
var numbers = [1, 2, 3];

var squares = numbers.map((n) => n * n).toList();
print(squares); // [1, 4, 9]

var big = numbers.where((n) => n > 1).toList();
print(big); // [2, 3]
```

---

Поскольку и `map`, и `where` возвращают `Iterable`, их вызовы можно **объединять в цепочку** друг за другом. Каждый шаг получает результат предыдущего, а `toList()` вызывается один раз в конце:

```dart
var numbers = [1, 2, 3, 4, 5, 6];

var result = numbers.where((n) => n > 3).map((n) => n * 10).toList();
print(result); // [40, 50, 60]
```

---

`sort` переупорядочивает список на месте. По умолчанию он использует естественный порядок элементов, но вы можете передать анонимную функцию, которая **сравнивает два элемента** и возвращает отрицательное число, ноль или положительное число. `compareTo` возвращает именно такое число, поэтому это обычный строительный блок:

```dart
var words = ['pear', 'fig', 'banana'];

words.sort((a, b) => a.length.compareTo(b.length));
print(words); // [fig, pear, banana]
```

Перестановка `a` и `b` местами в сравнении меняет порядок на обратный.

---

`reduce` объединяет все элементы списка в одно значение. Его анонимная функция принимает два параметра: значение, **накопленное к данному моменту**, и **следующий элемент**, и возвращает новое накопленное значение. Первый элемент используется в качестве отправной точки:

```dart
var numbers = [2, 3, 4];

var product = numbers.reduce((total, n) => total * n);
print(product); // 24
```

`reduce` выбрасывает ошибку на пустом списке, поскольку нет первого элемента, с которого можно начать.

---

Функция также может **возвращать функцию**. Тогда типом возвращаемого значения является функциональный тип, а тело возвращает анонимную функцию:

```dart
int Function(int) makeAdder(int amount) {
  return (int n) => n + amount;
}

var addTen = makeAdder(10);
print(addTen(5)); // 15
```

Обратите внимание, что возвращённая функция всё ещё использует `amount`, параметр `makeAdder`, даже после того, как `makeAdder` завершилась. Функция, которая запоминает окружающие её переменные подобным образом, называется **замыканием**.

---

Замыкание не просто читает захваченные переменные: оно также может их **изменять**, и изменения сохраняются между вызовами. Это позволяет хранить приватное состояние без класса:

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

Каждый вызов `makeTimer()` создаёт совершенно новую переменную `seconds`, поэтому два таймера никогда не разделяют свой счётчик.
