# --description--

Функции — это значения, поэтому у них есть тип. Тип функции записывается как **тип возвращаемого значения**, затем ключевое слово `Function`, затем **типы параметров** в круглых скобках:

```dart
int Function(int, int) add = (int a, int b) => a + b;
bool Function(String) isEmpty = (String s) => s.isEmpty;
void Function() hello = () => print('Hello');
```

Когда переменная типизирована таким образом, типы параметров можно опустить в анонимной функции, поскольку Dart выводит их из объявленного типа:

```dart
int Function(int, int) add = (a, b) => a + b;
```

Простой тип `Function` принимает любую функцию, каковы бы ни были её параметры и тип возвращаемого значения, но он ничего не говорит Dart о том, как её вызывать.
