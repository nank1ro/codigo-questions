# --description--

Поскольку тип функции — это обычный тип, функция может принимать **другую функцию в качестве параметра**. Внутри тела параметр вызывается как любая функция:

```dart
int apply(int n, int Function(int) operation) {
  return operation(n);
}

print(apply(5, (n) => n * 2)); // 10
print(apply(5, (n) => n - 1)); // 4
```

Здесь вызывающий решает, что делает `apply`, передавая анонимную функцию в качестве второго аргумента.

# --instructions--

Напишите функцию `applyTwice`, которая принимает параметр `int` с именем `n` и функциональный параметр `operation` типа `int Function(int)`, и возвращает результат применения `operation` к `n` два раза.

Пример:
```dart
print(applyTwice(3, (n) => n * 2)); // 12
```
