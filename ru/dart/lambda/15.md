# --description--

Анонимную функцию не обязательно где-то сохранять: её можно **вызвать немедленно**, написав аргументы сразу после её закрывающей фигурной скобки. Это удобно для вычисления значения с несколькими временными переменными, которые не должны просачиваться в окружающий код:

```dart
var area = (double radius) {
  var pi = 3.14;
  return pi * radius * radius;
}(2.0);

print(area); // 12.56
```

Здесь `pi` существует только внутри анонимной функции, а `area` получает возвращённое значение.
