# --description--

Замыкание не просто читает захваченные переменные: оно также может их **изменять**, и изменения сохраняются между вызовами. Это позволяет хранить приватное состояние без класса:

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

Каждый вызов `makeTimer()` создаёт совершенно новую переменную `seconds`, поэтому два таймера никогда не разделяют свой счётчик.

# --instructions--

Напишите функцию `makeCounter` без параметров, которая возвращает функцию типа `int Function()`. Каждый раз при вызове возвращённой функции она должна увеличивать захваченный счётчик и возвращать его, начиная с `1`.

Пример:
```dart
var counter = makeCounter();
print(counter()); // 1
print(counter()); // 2
```
