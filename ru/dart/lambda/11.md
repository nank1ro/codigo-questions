# --description--

Функция также может **возвращать функцию**. Тогда типом возвращаемого значения является функциональный тип, а тело возвращает анонимную функцию:

```dart
int Function(int) makeAdder(int amount) {
  return (int n) => n + amount;
}

var addTen = makeAdder(10);
print(addTen(5)); // 15
```

Обратите внимание, что возвращённая функция всё ещё использует `amount`, параметр `makeAdder`, даже после того, как `makeAdder` завершилась. Функция, которая запоминает окружающие её переменные подобным образом, называется **замыканием**.
