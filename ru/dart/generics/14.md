# --description--

Обобщённый класс может иметь именованные и **фабричные** конструкторы, как любой другой класс, и параметр типа доступен внутри них. Фабричный конструктор сам не создаёт объект: он выполняет тело и возвращает объект, что позволяет выбирать, переиспользовать или собирать экземпляр любым способом.

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

Аргумент типа указывается у класса, а не у имени конструктора: `Box<int>.first(...)`. Внутри фабрики `<T>[]` — это настоящий пустой `List<T>`, поэтому фабрика — естественное место для создания значения по умолчанию для ещё неизвестного вам типа.

# --instructions--

Объявите обобщённый класс `Stack` с одним параметром типа `T`, `final` полем `items` типа `List<T>`, задаваемым обычным конструктором, **фабричным** конструктором `Stack.empty()`, который создаёт `Stack` с пустым списком, и геттером `top` типа `T?`, возвращающим последний элемент или `null`, когда стек пуст.

Пример:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

# --asserts--

`Stack<int>([1, 2, 3]).top` должен быть `3`

```dart
  test('test1', () {
    final stack = Stack<int>([1, 2, 3]);
    expect(stack.top, 3, reason: '--err-t1--');
    expect(stack.items, [1, 2, 3], reason: '--err-t1--');
  });
```

`Stack.empty()` должна создавать пустой стек нужного типа, у которого `top` равен `null`

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
    expect(stack, isA<Stack<String>>(), reason: '--err-t2--');
    expect(stack.items, <String>[], reason: '--err-t2--');
    expect(stack.top, null, reason: '--err-t2--');
  });
```

Список, созданный `Stack.empty()`, должен оставаться пригодным для использования

```dart
  test('test3', () {
    final stack = Stack<int>.empty();
    stack.items.add(4);
    stack.items.add(9);
    expect(stack.top, 9, reason: '--err-t3--');
    expect(Stack<bool>([true]).top, true, reason: '--err-t3--');
  });
```

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
