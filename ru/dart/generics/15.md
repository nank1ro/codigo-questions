# --description--

Параметр типа, записанный без ограничения, вовсе не является неограниченным: `class Box<T>` — это сокращение для `class Box<T extends Object?>`. Именно поэтому принимается `Box<int?>`, и именно поэтому внутри класса нельзя никогда полагаться на то, что `value` не null.

Чтобы запретить допускающие null аргументы типа, ограничьте параметр через `Object`:

```dart
class Strict<T extends Object> {
  final T value;
  Strict(this.value);
}

final ok = Strict<int>(7);
final bad = Strict<int?>(null);
// error: Type argument 'int?' doesn't conform to the bound 'Object'
```

`Object` — тип всего, кроме `null`, поэтому `T extends Object` читается как «что угодно, лишь бы это действительно было там».

Дано `class Strict<T extends Object> { ... }`. Что произойдёт с `Strict<int?>(null)`?

# --answers--

- Это ошибка компиляции, потому что `int?` не соответствует ограничению `Object`
- Это работает, и `value` хранит `null`
- Это работает, но `value` молча заменяется значением по умолчанию
- Код компилируется, а ошибка выбрасывается при первом чтении `value`
