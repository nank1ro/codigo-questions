# --description--

`List` — не единственная обобщённая коллекция. `Set` принимает один аргумент типа, а `Map` — **два**: один для ключей и один для значений, именно в таком порядке.

```dart
Set<String> tags = {'new', 'sale'};
Map<String, int> ages = {'Ada': 36, 'Grace': 45};
```

Тип пустого литерала коллекции нельзя вывести из его содержимого, поэтому аргументы типа указывают на самом литерале:

```dart
final counts = <String, int>{};
final seen = <String>{};
counts['fig'] = 3;
```

Когда типы известны, всё, что вы извлекаете из коллекции, уже имеет нужный тип: `ages['Ada']` — это `int?`, а не загадочное значение.

```dart
Map<String, int> lengths(List<String> words) {
  final result = <String, int>{};
  for (final word in words) {
    result[word] = word.length;
  }
  return result;
}
```
