# --description--

В Dart есть ещё тип `dynamic`, который означает «можно всё что угодно». `List<dynamic>` принимает любые значения, поэтому выглядит удобнее, чем `List<String>`:

```dart
List<dynamic> things = ['Ada', 'Grace'];
things.add(42);                    // принято
print(things.first.toUpperCase()); // принято
```

Загвоздка в том, что ничего не проверяется, пока вы пишете код. Каждый вызов на значении `dynamic` разрешается во время работы программы, поэтому опечатка вроде `things.first.toUpperCse()` спокойно компилируется и приводит к падению перед глазами пользователя.

Дженерики — альтернатива этому: один фрагмент кода работает с **любым** типом, при этом каждое его использование всё равно проверяется на соответствие **одному** типу. В этом и есть суть всей темы.

# --instructions--

И `List<dynamic>`, и `List<String>` могут хранить строки `'Ada'` и `'Grace'`. Что даёт вам `List<String>` такого, чего не даёт `List<dynamic>`?

# --answers--

- Компилятор отклоняет `names.add(42)` ещё до запуска программы, а `names.first` уже является `String`
- Он использует меньше памяти, потому что строки хранятся более компактно
- Он не даёт списку вырасти больше количества элементов, с которым он был создан
- Он заставляет `names.first` вернуть `null` вместо выбрасывания ошибки, когда список пуст
