# --description--

Класс может объявлять более одного параметра типа, разделяя их запятыми. `Map<K, V>` — встроенный пример: один тип для ключей, один для значений.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

**Порядок** является частью типа: `Entry<String, int>` и `Entry<int, String>` — никак не связанные типы, и значение одного нельзя присвоить другому. Параметры типа можно также переставлять в возвращаемом типе, благодаря чему метод может вернуть перевёрнутую версию объекта:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

Объявите обобщённый класс `Pair` с двумя параметрами типа `A` и `B`, `final` полем `first` типа `A` и `final` полем `second` типа `B`, задаваемыми конструктором, и геттером `swapped`, который возвращает `Pair<B, A>` с теми же двумя значениями в обратном порядке.

Пример:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

`Pair<String, int>('age', 30)` должна иметь `first` `'age'` и `second` `30`

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` должна вернуть `Pair<int, String>` с обменянными значениями

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` должна работать с любыми двумя типами, а двойной обмен должен возвращать исходные значения

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
    expect(pair.swapped.second, true, reason: '--err-t3--');
    expect(pair.swapped.swapped, isA<Pair<bool, String>>(), reason: '--err-t3--');
    expect(pair.swapped.swapped.first, true, reason: '--err-t3--');
  });
```

```dart
class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
