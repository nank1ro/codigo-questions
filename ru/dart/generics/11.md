# --description--

Ключевым словом для ограничения всегда служит `extends`, даже когда ограничение — интерфейс, а не суперкласс. В списке параметров типа нет `implements`.

```dart
num biggerOf<T extends num>(T a, T b) => a > b ? a : b;
```

Без ограничения `a > b` не скомпилировалось бы: оператор сравнения принадлежит `num`, а не каждому объекту.
