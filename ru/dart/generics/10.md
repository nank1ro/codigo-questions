# --description--

Неограниченный `T` может быть чем угодно, поэтому внутри тела разрешено использовать только то, что есть у каждого объекта. Такой код не компилируется:

```dart
T twice<T>(T value) => value + value; // error: + is not defined for T
```

Это исправляет **ограничение** (bound). Запись `T extends num` говорит: «`T` может быть только числом», а взамен тело может использовать всё, что предлагает `num`:

```dart
T twice<T extends num>(T value) => (value + value) as T;

num half<T extends num>(T value) => value / 2;
```

Ограничение проверяется в месте вызова: `half(4)` и `half(2.5)` допустимы, а `half('fig')` — ошибка компиляции. Ограничение — это обещание в обе стороны: более узкие аргументы в обмен на больше возможностей внутри.

# --solutions--

```dart
num total<T extends num>(List<T> values) {
  num sum = 0;
  for (final value in values) {
    sum += value;
  }
  return sum;
}
```
