# --description--

Вы не ограничены обобщёнными классами, которые поставляются вместе с Dart: можно объявлять свои. **Параметр типа** записывается в угловых скобках после имени класса, а дальше внутри тела это обычный тип:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` — это лишь заполнитель. Он подставляется при создании `Box` — явно или с помощью выведения типов:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, inferred from the argument
print(a.value + 1);      // 8, the compiler knows value is an int
```

Конкретная буква не важна: `T` — лишь соглашение для «type», и не более того.

# --instructions--

Объявите обобщённый класс `Box` с одним параметром типа `T`, `final` полем `value` типа `T`, задаваемым конструктором, и геттером `label`, который возвращает текст `Box of `, за которым следует значение.

Пример:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` должна иметь `value` `7` и `label` `'Box of 7'`

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` должна работать с любым типом, поэтому `Box<String>('fig')` тоже должна быть `Box<String>`

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

Аргумент типа должен выводиться из аргумента конструктора

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
