# --description--

Внутри обобщённого класса параметр типа виден везде: в полях, параметрах конструктора, сигнатурах методов и телах методов. Он объявляется один раз рядом с именем класса, и каждый член может его использовать.

```dart
class Holder<T> {
  final T item;

  Holder(this.item);

  String describe() => 'holding $item';
}
```

Тип определяет момент создания объекта: `Holder<String>('fig')` делает `item` строкой `String`, а `Holder<int>(3)` — числом `int`.
