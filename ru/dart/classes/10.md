# --description--

**Наследование** позволяет классу (**подклассу**) расширить другой класс (**суперкласс**) и повторно использовать его поля и методы. Для этого используется ключевое слово `extends`:

```dart
class Animal {
  String name = 'animal';

  void speak() {
    print('$name makes a sound.');
  }
}

class Dog extends Animal {
  void fetch() {
    print('$name fetches the ball.');
  }
}
```

`Dog` наследует `name` и `speak()` от `Animal` и добавляет собственный метод `fetch()`. Класс, который не объявляет конструктор, получает конструктор по умолчанию без параметров, поэтому можно написать `var dog = Dog();`, а затем вызвать и `dog.speak()`, и `dog.fetch()`.
