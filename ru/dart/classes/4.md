# --description--

Параметр `this.x`, который вы видели в предыдущем упражнении, — это сокращение. Длинная форма присваивает каждый параметр его полю в теле конструктора (`this.x` — поле, `x` — параметр):

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

Тот же класс можно записать так:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

Эта более короткая форма называется **инициализирующими формальными параметрами**.

# --instructions--

Какой из вариантов правильно использует сокращённый синтаксис инициализирующих формальных параметров?

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`
