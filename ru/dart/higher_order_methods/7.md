# --description--

`reduce` — это укороченный родственник `fold`. Он не принимает начального значения: **первый элемент** становится стартовым аккумулятором, а функция выполняется для каждого оставшегося элемента:

```dart
final numbers = [1, 2, 3, 4];
print(numbers.reduce((a, b) => a + b)); // 10
```

Поскольку начального значения нет, результат всегда имеет **тот же тип, что и элементы**, а вызов `reduce` на пустой коллекции выбрасывает `StateError`: нет первого элемента, с которого можно начать. У `fold` такой проблемы нет, поэтому он является более безопасным выбором по умолчанию.

`reduce` лучше всего подходит, когда вы ищете один элемент среди многих, например наибольший:

```dart
print(numbers.reduce((a, b) => a > b ? a : b)); // 4
```
