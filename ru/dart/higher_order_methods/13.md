# --description--

Каждый из этих методов возвращает `Iterable`, и у каждого `Iterable` снова есть те же методы. Именно это позволяет выстраивать их в **цепочки**: всё вычисление читается как конвейер слева направо, где каждый шаг работает с тем, что создал предыдущий.

```dart
final words = ['kiwi', 'fig', 'banana', 'date'];
print(words.where((w) => w.length == 4).map((w) => w.toUpperCase()).toList());
// [KIWI, DATE]
```

`toList()` нужен только на последнем шаге: вызов в середине построил бы список, который никто не сохранит.

Тип меняется вдоль цепочки, а вместе с ним и то, что получает следующая функция: после `where` на `List<String>` у вас всё ещё строки, но после `map((w) => w.length)` следующий шаг видит числа.

Поскольку каждый шаг ленив, порядок важен для объёма выполненной работы, а не только для результата: сначала отфильтровать с помощью `where` означает, что `map` будет вызван для меньшего числа элементов.
