# --description--

`fold` сворачивает целую коллекцию в **одно значение**. Он принимает два аргумента: начальное значение **аккумулятора** и функцию, которая получает текущий аккумулятор и следующий элемент, а возвращает новый аккумулятор:

```dart
final numbers = [1, 2, 3, 4];
final total = numbers.fold(0, (acc, n) => acc + n);
print(total); // 10
```

Здесь `acc` начинается с `0`, затем становится `1`, `3`, `6` и наконец `10`.

Аккумулятор не обязан быть числом или иметь тот же тип, что и элементы: начав с `''` и добавляя текст, можно построить `String` из списка чего угодно.

Одна деталь, о которой стоит помнить: Dart выводит тип аккумулятора из начального значения **и** из того, где используется результат. Внутри `print(...)` ожидаемый тип неизвестен, поэтому сначала сохраните результат в переменную (или напишите `fold<int>(...)`), иначе компилятор пожалуется, что не может применить `+` к аккумулятору.
