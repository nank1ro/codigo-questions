# --description--

В этих методах нет ничего особенного: они просто принимают **функцию в качестве параметра**, и ваши собственные функции могут делать то же самое. Тип параметра-функции записывается как тип возвращаемого значения, затем `Function`, затем типы параметров в скобках:

```dart
List<int> applyAll(List<int> numbers, int Function(int) operation) {
  return numbers.map(operation).toList();
}
```

Вызывающий код решает **что** происходит, а функция решает **над чем**. Обратите внимание, как `operation` передаётся прямо в `map`: значение-функцию можно передавать дальше, как любое другое значение.

Аргументом может быть анонимная функция или **имя** существующей, записанное без скобок. Добавление скобок вызвало бы её вместо передачи:

```dart
int square(int n) => n * n;

print(applyAll([1, 2, 3], square));       // [1, 4, 9]
print(applyAll([1, 2, 3], (n) => n + 1)); // [2, 3, 4]
```
