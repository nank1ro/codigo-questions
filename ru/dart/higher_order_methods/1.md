# --description--

**Метод высшего порядка** — это метод, принимающий функцию в качестве аргумента. Коллекции Dart предлагают множество таких методов, а передаваемая функция обычно является анонимной функцией, записанной со стрелочным синтаксисом `(x) => ...`.

`map` — самый распространённый из них: он вызывает функцию для каждого элемента и выдаёт результаты, по одному на каждый элемент, не изменяя исходную коллекцию:

```dart
final numbers = [1, 2, 3];
print(numbers.map((n) => n * 2)); // (2, 4, 6)
print(numbers);                   // [1, 2, 3]
```

Обратите внимание на **круглые скобки** в выводе. `map` не возвращает `List`: он возвращает `Iterable` — последовательность, которую можно пройти. Чтобы получить настоящий список, вызовите на нём **`toList()`**:

```dart
final doubled = numbers.map((n) => n * 2).toList();
print(doubled); // [2, 4, 6]
```

Квадратные скобки в выводе — признак того, что перед вами `List`, круглые — что перед вами обычный `Iterable`.
