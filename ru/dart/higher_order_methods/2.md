# --description--

`where` принимает функцию, возвращающую `bool` — она называется **предикатом**, — и оставляет только те элементы, для которых она отвечает `true`. Порядок оставшихся элементов никогда не меняется:

```dart
final numbers = [4, -2, 7, 0];
print(numbers.where((n) => n > 0).toList()); // [4, 7]
```

Как и `map`, `where` возвращает `Iterable` и никогда не изменяет исходную коллекцию, поэтому `toList()` снова превращает результат в `List`.

В других языках этот метод называется `filter`; в Dart это `where`.
