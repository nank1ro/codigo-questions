# --description--

`firstWhere` возвращает **первый** элемент, удовлетворяющий предикату, а не все такие элементы:

```dart
final words = ['fig', 'kiwi', 'banana'];
print(words.firstWhere((w) => w.length > 3)); // kiwi
```

Когда ничего не подходит, возвращать нечего, поэтому `firstWhere` выбрасывает `StateError`. Чтобы получить ответ вместо ошибки, передайте именованный аргумент **`orElse`**: функцию без параметров, которая выдаёт запасное значение.

```dart
print(words.firstWhere((w) => w.length > 10, orElse: () => 'none')); // none
```

`orElse` — это функция, а не обычное значение, поэтому она вызывается только тогда, когда поиск не удался. Запись `orElse: 'none'` не компилируется.
