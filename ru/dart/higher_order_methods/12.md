# --description--

`fold` и `reduce` похожи, и выбор между ними сводится к двум вопросам: может ли коллекция быть пустой и имеет ли результат тот же тип, что и элементы?

```dart
final words = ['fig', 'kiwi'];
final joined = words.reduce((a, b) => '$a, $b'); // String from Strings
final letters = words.fold(0, (acc, w) => acc + w.length); // int from Strings
print(joined);  // fig, kiwi
print(letters); // 7
```

`reduce` может вернуть только тип элемента, потому что начинает с элемента. `fold` начинает со значения, которое вы выбрали, поэтому аккумулятором может быть `int`-счётчик, растущий `String` или даже собираемый `List`. А поскольку начальное значение уже существует, пустая коллекция — это просто ответ, который `fold` возвращает без изменений, тогда как `reduce` возвращать нечего, и он выбрасывает ошибку.

# --instructions--

В чём разница между `fold` и `reduce`?

# --answers--

- `fold` принимает начальное значение, поэтому работает на пустой коллекции, и его результат может иметь тип, отличный от типа элементов; `reduce` начинает с первого элемента и выбрасывает ошибку на пустой коллекции
- Это два названия одного и того же метода
- `reduce` принимает начальное значение, а `fold` начинает с первого элемента
- `fold` возвращает новый список, а `reduce` возвращает одно значение
