# --description--

Когда функция, передаваемая в `map`, возвращает коллекцию для каждого элемента, на выходе получается последовательность коллекций. **`expand`** делает то же самое, но затем объединяет их все в одну плоскую последовательность:

```dart
final numbers = [1, 2];
print(numbers.map((n) => [n, -n]).toList());    // [[1, -1], [2, -2]]
print(numbers.expand((n) => [n, -n]).toList()); // [1, -1, 2, -2]
```

Порядок сохраняется: сначала идёт всё, что создано первым элементом, затем всё, что создано вторым, и так далее.

Поскольку возвращаемая коллекция может иметь любой размер, `expand` — это также способ получить **больше или меньше** элементов, чем было изначально: пустой список для элемента просто отбрасывает его.

```dart
print(['a b', 'c'].expand((s) => s.split(' ')).toList()); // [a, b, c]
```
