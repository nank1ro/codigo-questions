# --description--

Некоторые методы высшего порядка отвечают на вопрос о коллекции, а не строят новую. Они принимают предикат и возвращают `bool`:

- `any` равен `true`, когда **хотя бы один** элемент удовлетворяет предикату
- `every` равен `true`, когда **все** элементы удовлетворяют ему

```dart
final numbers = [1, 2, 3];
print(numbers.any((n) => n > 2));   // true
print(numbers.every((n) => n > 2)); // false
```

Оба останавливаются, как только ответ становится известен: `any` — на первом подходящем элементе, `every` — на первом неподходящем.

На пустой коллекции `any` равен `false`, а `every` равен `true`: нет элемента, который доказал бы первое, и нет элемента, который нарушил бы второе.

Напишите две функции, каждая из которых принимает `List<int>` `numbers`:

- `hasNegative` возвращает `true`, если хотя бы один элемент меньше `0`
- `allEven` возвращает `true`, если каждый элемент чётный

Пример:
```dart
print(hasNegative([1, -2, 3])); // true
print(allEven([2, 4]));         // true
```

# --solutions--

```dart
bool hasNegative(List<int> numbers) {
  return numbers.any((n) => n < 0);
}

bool allEven(List<int> numbers) {
  return numbers.every((n) => n % 2 == 0);
}
```
