# --description--

Функция также может **возвращать** функцию. Тип возвращаемого значения записывается точно так же, как тип параметра-функции, а возвращаемое значение обычно является анонимной функцией:

```dart
int Function(int) multiplier(int factor) {
  return (n) => n * factor;
}
```

`multiplier(3)` ничего не умножает: она создаёт и возвращает новую функцию, которая умножает на `3`. Затем эта функция сохраняется, вызывается или передаётся в `map`, как любая другая:

```dart
final triple = multiplier(3);
print(triple(5));                       // 15
print([1, 2, 3].map(triple).toList());  // [3, 6, 9]
```

Возвращённая функция по-прежнему помнит `factor` после того, как `multiplier` завершилась. Функция, сохраняющая переменные области видимости, в которой она была создана, называется **замыканием**, и именно она делает возможными такие фабрики функций.
