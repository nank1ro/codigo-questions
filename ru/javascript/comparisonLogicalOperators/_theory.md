Начнём с оператора сравнения **равно** `==`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, равны ли два выражения, например:
```javascript
console.log(2 == 2);
// выводит true
console.log(2 == 3);
// выводит false
```

---

Продолжим с оператором сравнения **не равно** `!=`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, **НЕ** равны ли два выражения, например:
```javascript
console.log(2 != 2);
// выводит false
console.log(2 != 3);
// выводит true
```
Это полная противоположность оператора *равно*

---

Продолжим с оператором сравнения **больше** `>`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, больше ли одно выражение другого, например:
```javascript
console.log(2 > 2);
// выводит false
console.log(3 > 2);
// выводит true
```

---

Продолжим с оператором сравнения **меньше** `<`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, меньше ли одно выражение другого, например:
```javascript
console.log(2 < 2);
// выводит false
console.log(2 < 3);
// выводит true
```

---

Продолжим с оператором сравнения **больше или равно** `>=`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, больше ли или равно одно выражение другому, например:
```javascript
console.log(2 >= 2);
// выводит true
console.log(3 >= 2);
// выводит true
console.log(3 >= 4);
// выводит false
```

---

Продолжим с оператором сравнения **меньше или равно** `<=`.
Он возвращает **логическое значение** (`true` или `false`), указывающее, меньше ли или равно одно выражение другому, например:
```javascript
console.log(2 <= 2);
// выводит true
console.log(3 <= 2);
// выводит false
console.log(3 <= 4);
// выводит true
```

---

Теперь рассмотрим **логические** операторы, начнём с первого — __И__ `&&`.
Он возвращает первый операнд, который вычисляется как *false*, или последний, если все равны *true*.
```javascript
console.log(2 == 2 && 2 == 3);
// выводит false
console.log(1 == 1 && 1 == 1.0);
// выводит true
```

---

Продолжим с логическим оператором **или** `||`.
Он возвращает первый операнд, который вычисляется как *true*, или последний, если все равны *false*.
```javascript
console.log(2 == 2 || 2 == 3);
// выводит true
console.log(1 == 2 || 1 == 3);
// выводит false
```

---

Завершим логическим оператором **НЕ** `!`.
Он возвращает логическое значение, противоположное логическому состоянию выражения.
```javascript
console.log(!true);
// выводит false
console.log(!false);
// выводит true
console.log(!(2 == 2));
// выводит false
```

---

`==` сравнивает свои две стороны после приведения их к общему типу, поэтому `"5" == 5` равно `true`. Строгий оператор `===` пропускает это приведение и требует, чтобы типы тоже совпадали.
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```

---

`!=` перед сравнением приводит типы, точно так же как `==`, поэтому `"5" != 5` равно `false`. Его строгий аналог `!==` считает строку и число разными, независимо от того, что они содержат.
```javascript
console.log("5" !== 5); // true
```

---

Когда обе стороны — строки, `>` сравнивает их посимвольно по коду символов, а не по длине, поэтому `"b" > "a"` равно `true`, и `"apple" > "ant"` тоже равно `true`.

---

`>=` удовлетворяется любой из двух своих половин: `8 >= 8` равно `true`, потому что значения равны, тогда как более строгое `8 > 8` равно `false`.

---

Любое сравнение с участием `NaN` возвращает `false`, даже противоположные: `NaN < 3` и `NaN >= 3` оба равны `false`, поэтому провал `<` не всегда означает, что левая сторона больше.

---

Когда одна сторона — строка, а другая — число, `<=` сначала приводит строку к числу, поэтому `"7" <= 8` равно `true`.
