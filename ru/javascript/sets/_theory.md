**Set** — это коллекция **уникальных** значений: каждое значение может встречаться не более одного раза, и не существует индекса, по которому можно было бы получить значение по позиции.
Sets идеальны, когда вас интересует только то, *какие* значения присутствуют, а не сколько раз или в каком порядке.
Вы создаёте пустой set с помощью `new Set()`, добавляете значение с помощью `add(value)` и проверяете, присутствует ли значение, с помощью `has(value)`:
```javascript
let colors = new Set();
colors.add("red");
colors.add("blue");
console.log(colors.has("red"));
// выводит true
console.log(colors.has("green"));
// выводит false
```

---

Добавление значения, которое уже есть в set, **ничего** не делает: дубликаты просто игнорируются.
Ещё два важных момента:
- `delete(value)` удаляет значение из set
- `size` — это количество хранимых значений (свойство, поэтому без скобок)

```javascript
let tags = new Set();
tags.add("js");
tags.add("css");
tags.add("js");
console.log(tags.size);
// выводит 2
tags.delete("css");
console.log(tags.size);
// выводит 1
```

---

`add()` возвращает сам set, поэтому несколько вызовов можно объединять в цепочку:
```javascript
let letters = new Set();
letters.add("a").add("b");
```
Независимо от того, используете вы цепочку вызовов или нет, значение, которое уже присутствует, никогда не добавляется во второй раз, поэтому `size` считает каждое отдельное значение только один раз.

---

Вы можете построить set сразу, передав массив в `new Set()`. Дубликаты в массиве отбрасываются, поэтому это самый быстрый способ найти отличающиеся значения массива:
```javascript
let nums = [1, 2, 2, 3, 3, 3];
let distinct = new Set(nums);
console.log(distinct.size);
// выводит 3
```
Оператор **расширения** `...` работает в обратную сторону и превращает set обратно в массив:
```javascript
let unique = [...distinct];
console.log(unique);
// выводит [ 1, 2, 3 ]
```
`Array.from(distinct)` делает то же самое.

---

Set запоминает порядок, в котором были добавлены значения, и вы можете перебрать его с помощью `for...of`:
```javascript
let nums = new Set([3, 1, 2]);
for (const n of nums) {
  console.log(n);
}
// выводит 3
// выводит 1
// выводит 2
```
У sets также есть метод `forEach()`, который вызывает функцию для каждого значения:
```javascript
nums.forEach((n) => console.log(n * 10));
// выводит 30
// выводит 10
// выводит 20
```

---

`delete(value)` возвращает `true`, если значение было удалено, и `false`, если его не было в set.
Чтобы удалить **все** значения сразу, вызовите `clear()`:
```javascript
let cart = new Set(["pen", "ink"]);
console.log(cart.delete("pen"));
// выводит true
console.log(cart.delete("pen"));
// выводит false
cart.clear();
console.log(cart.size);
// выводит 0
```

---

Set решает, "одинаковы" ли два значения, почти по тому же правилу, что и `===` (за исключением того, что `NaN` считается равным самому себе). Для строк и чисел это сравнивает содержимое, но **объекты сравниваются по ссылке**: два объектных литерала с одинаковыми полями — это два разных значения.
```javascript
let alice = { name: "Alice" };
let people = new Set();
people.add(alice);
people.add(alice);
console.log(people.size);
// выводит 1
people.add({ name: "Alice" });
console.log(people.size);
// выводит 2
```
Игнорируется только повторное добавление того же самого объекта.

---

Сочетание расширения и `filter()` даёт вам классические операции теории множеств. Каждая из них строит **новую** коллекцию и не изменяет исходные:
- **объединение**, каждое значение, которое есть в `a`, в `b` или в обоих: `new Set([...a, ...b])`
- **пересечение**, только значения, которые есть в **обоих**: `[...a].filter((x) => b.has(x))`
- **разность**, значения из `a`, которых **нет** в `b`: `[...a].filter((x) => !b.has(x))`

```javascript
let a = new Set([1, 2, 3]);
let b = new Set([3, 4]);
console.log([...new Set([...a, ...b])]);
// выводит [ 1, 2, 3, 4 ]
console.log([...a].filter((x) => b.has(x)));
// выводит [ 3 ]
console.log([...a].filter((x) => !b.has(x)));
// выводит [ 1, 2 ]
```
Современные движки JavaScript также предоставляют `a.union(b)`, `a.intersection(b)` и `a.difference(b)` прямо на sets, но версии с расширением и `filter()` работают везде.

---

Чтобы сохранить тот же интерфейс, что и у `Map`, set предлагает методы-итераторы `values()`, `keys()` и `entries()`.
Поскольку у set нет ключей, `keys()` — это просто ещё одно название для `values()`, а `entries()` выдаёт каждое значение **дважды**, в виде пары `[value, value]`:
```javascript
let letters = new Set(["a", "b"]);
console.log([...letters.values()]);
// выводит [ 'a', 'b' ]
console.log([...letters.entries()]);
// выводит [ [ 'a', 'a' ], [ 'b', 'b' ] ]
```
На практике они редко нужны: `for...of` и расширение уже перебирают значения напрямую.

---

`new Set()` принимает любой **итерируемый** объект, а не только массивы. Строка итерируема посимвольно, поэтому она даёт вам отличающиеся символы текста:
```javascript
let letters = new Set("hello");
console.log([...letters]);
// выводит [ 'h', 'e', 'l', 'o' ]
```
