# --instructions--

Расставьте строки в правильном порядке, чтобы вывести массив с именами из `all`, которых нет в `done`.
Объявите `all` перед `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
