# --description--

Если ключ хранит другой объект или массив, шаблон может просто продолжиться и описать и эту форму:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Будьте внимательны к тому, что создаёт эта строка: `address: { city }` означает «зайди в `address`», а не «дай мне `address`», поэтому переменной становится только `city`. Чтобы получить и то и другое, упомяните ключ дважды: `const { address, address: { city } } = user;`. Шаблоны массивов и объектов свободно вкладываются друг в друга, как в `{ tags: [first] }`.

# --asserts--

Вложенный город должен быть возвращён.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Другой вложенный город должен быть возвращён.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Пустой адрес должен давать `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Остальные ключи адреса должны быть проигнорированы.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Явно заданный город `undefined` должен давать `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
