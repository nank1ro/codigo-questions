# --description--

Всё, что мы видели до сих пор, принадлежит одному синтаксису, поэтому части свободно сочетаются: шаблон объекта может вкладывать в себя другой шаблон объекта, который может содержать переименованный ключ со значением по умолчанию, рядом с шаблоном массива, заканчивающимся rest-элементом. Одна строка тогда описывает всю форму, которую ожидает функция:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// prints Post [js] +2
```
Сохраняйте читаемость: шаблон, который больше не помещается в пару строк, — обычно признак того, что функция запрашивает слишком много.

# --asserts--

Три элемента должны оставить два позади.

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

Один элемент не должен оставить ни одного позади.

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

Покупатель без имени должен стать `guest`.

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

Явно заданное имя `undefined` тоже должно стать `guest`.

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

Четыре элемента должны оставить три позади.

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

```javascript
function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
```
