# --description--

Шаблоны объектов и значения по умолчанию сочетаются в точности как шаблоны массивов, что делает их аккуратным способом читать объект конфигурации, чьи ключи могут присутствовать или отсутствовать:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// выводит dark en
```
Поскольку весь шаблон — одна инструкция, функция может распаковать всё, что ей нужно, из своего аргумента уже в самой первой строке.

# --asserts--

Оба присутствующих ключа должны быть использованы.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Другой пользователь должен дать другую строку.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

При отсутствующем `city` должно использоваться `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Лишние ключи должны быть проигнорированы.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

Порядок ключей не должен иметь значения.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
