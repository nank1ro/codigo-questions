# --description--

Деструктурированный параметр со значениями по умолчанию образует аккуратный объект опций, но он всё ещё ломается, когда вызывающий не передаёт ничего: чтение ключа из `undefined` бросает `TypeError`. Задание всему шаблону значения по умолчанию `{}` исправляет это:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// выводит guest/false
```
Читайте строку снаружи внутрь: `= {}` поставляет пустой объект, когда аргумент отсутствует, а каждое внутреннее значение по умолчанию затем заполняет свой ключ.

# --asserts--

Вызов `button()` без аргументов должен использовать оба значения по умолчанию.

```javascript
tryCatch(button() === "OK/medium");
```

Пустой объект тоже должен использовать оба значения по умолчанию.

```javascript
tryCatch(button({}) === "OK/medium");
```

Если передан только `label`, размер должен остаться значением по умолчанию.

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

Если передан только `size`, надпись должна остаться значением по умолчанию.

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

Обе переданные опции должны быть использованы.

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
