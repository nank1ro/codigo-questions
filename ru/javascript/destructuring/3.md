# --description--

Иногда важен только один элемент глубоко внутри массива. Вы можете оставить позицию в шаблоне пустой, сохранив запятую, которая её отделяет: такая пустая позиция называется **дырой**, и она пропускает элемент, не давая ему имени:
```javascript
const rgb = [255, 128, 64];
const [, , blue] = rgb;
console.log(blue);
// prints 64
```
Считайте запятые, а не имена: каждая запятая сдвигает шаблон на одну позицию вперёд, независимо от того, стоит ли перед ней имя.

# --instructions--

Что выведет эта программа?
```javascript
const race = ["Ann", "Ben", "Cia", "Dan"];
const [, second, , fourth] = race;
console.log(second, fourth);
```
