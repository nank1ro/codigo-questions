Извлекать значения из массива по одному индексу за раз — громоздко:
```javascript
const point = [3, 7];
const x = point[0];
const y = point[1];
```
**Деструктуризация** делает ту же работу одной строкой. Слева от `=` вы пишете шаблон, который выглядит как сам массив, и каждое имя внутри него получает элемент на той же позиции:
```javascript
const point = [3, 7];
const [x, y] = point;
console.log(x, y);
// prints 3 7
```
Шаблон не обязан охватывать весь массив: лишние элементы просто игнорируются, а имя без соответствующего элемента становится `undefined`.

---

Деструктуризация полезнее всего там, куда массив приходит: в аргументе функции или в результате вызова. Вместо того чтобы хранить массив и обращаться к нему по индексу повсюду, вы распаковываете его один раз и даёте частям настоящие имена:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// prints 5
```
Ничего не копируется и не меняется в исходном массиве — шаблон только читает его.

---

Иногда важен только один элемент глубоко внутри массива. Вы можете оставить позицию в шаблоне пустой, сохранив запятую, которая её отделяет: такая пустая позиция называется **дырой**, и она пропускает элемент, не давая ему имени:
```javascript
const rgb = [255, 128, 64];
const [, , blue] = rgb;
console.log(blue);
// prints 64
```
Считайте запятые, а не имена: каждая запятая сдвигает шаблон на одну позицию вперёд, независимо от того, стоит ли перед ней имя.

---

Массив не всегда имеет ту длину, которой ожидает шаблон. Запись `= значение` после имени даёт ему **значение по умолчанию**, которое используется всякий раз, когда на этой позиции массив не содержит ничего:
```javascript
const size = [1920];
const [width, height = 1080] = size;
console.log(width, height);
// prints 1920 1080
```
Значение по умолчанию вычисляется только тогда, когда оно нужно, поэтому им может быть даже вызов функции, и его можно задать для любой позиции, а не только для последней.

---

Шаблон может также стоять слева в обычном присваивании, без `const` или `let` перед ним, и тогда он записывает значения в уже существующие переменные. Это превращает обмен значениями двух переменных в одну строку, без временной переменной:
```javascript
let a = 1;
let b = 2;
[a, b] = [b, a];
console.log(a, b);
// prints 2 1
```
Правая часть строится первой, поэтому оба старых значения уже в безопасности внутри временного массива, когда происходит присваивание. Следите за точкой с запятой на предыдущей строке: иначе строка, начинающаяся с `[`, будет прочитана как обращение по индексу к тому, что шло перед ней.

---

Объекты тоже можно деструктурировать, с фигурными скобками вместо квадратных. Здесь позиция не значит ничего: каждое имя сопоставляется с **ключом**, который пишется так же:
```javascript
const user = { name: "Ada", age: 36 };
const { age, name } = user;
console.log(name, age);
// prints Ada 36
```
Перестановка `age` и `name` в шаблоне ничего не меняет, а ключи, которые шаблон не упоминает, просто остаются в стороне. Имя без соответствующего ключа становится `undefined`.

---

Шаблоны объектов и значения по умолчанию сочетаются в точности как шаблоны массивов, что делает их аккуратным способом читать объект конфигурации, чьи ключи могут присутствовать или отсутствовать:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// prints dark en
```
Поскольку весь шаблон — одна инструкция, функция может распаковать всё, что ей нужно, из своего аргумента уже в самой первой строке.

---

Шаблон объекта называет свои переменные по ключам, что неудобно, когда ключи непонятны или уже заняты. Запись `key: newName` **переименовывает** переменную:
```javascript
const row = { n: "Ada", y: 1815 };
const { n: name, y: born } = row;
console.log(name, born);
// prints Ada 1815
```
Читайте это как «возьми `n`, назови `name`». Двоеточие не объявляет тип, и сама `n` никогда не создаётся как переменная — переменной становится только `name`. Переименованное имя всё ещё может получить значение по умолчанию, записанное после него: `{ n: name = "unknown" }`.

---

У значений по умолчанию есть одно правило, которое удивляет всех: они применяются **только** к `undefined`. Ключ, который существует и хранит `null`, `0`, `""` или `false`, — это настоящее значение, поэтому шаблон берёт его, и значение по умолчанию никогда не используется:
```javascript
const { count = 10 } = { count: 0 };
console.log(count);
// prints 0
```
`null` ведёт себя здесь так же, как `0`, хотя в ответах API он часто означает «нет значения». Когда `null` тоже нужно заменить, сначала деструктурируйте, а затем подстрахуйтесь с помощью `??`.

---

Если ключ хранит другой объект или массив, шаблон может просто продолжиться и описать и эту форму:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
Будьте внимательны к тому, что создаёт эта строка: `address: { city }` означает «зайди в `address`», а не «дай мне `address`», поэтому переменной становится только `city`. Чтобы получить и то и другое, упомяните ключ дважды: `const { address, address: { city } } = user;`. Шаблоны массивов и объектов свободно вкладываются друг в друга, как в `{ tags: [first] }`.

---

Взять голову массива и сохранить хвост — настолько распространённая потребность, что у шаблонов есть для неё собственный синтаксис. Три точки перед последним именем делают его **rest-элементом**, и он собирает все оставшиеся элементы в совершенно новый массив:
```javascript
const queue = ["a", "b", "c"];
const [next, ...waiting] = queue;
console.log(next, waiting);
// prints a [ 'b', 'c' ]
```
Rest-элемент должен стоять в шаблоне последним и не может иметь значения по умолчанию: когда ничего не осталось, он — просто пустой массив.

---

У шаблонов объектов тоже есть rest, и там он собирает каждый ключ, который шаблон не упомянул, в новый объект:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// prints { name: 'Ada', city: 'London' }
```
Это кратчайший способ создать копию объекта без одного из его ключей: исходный объект никогда не затрагивается, а rest-объект — новый, хранящий оставшиеся значения.

---

Шаблон может заменить имя параметра в объявлении функции, и тогда распаковка происходит в момент вызова:
```javascript
function area({ width, height }) {
    return width * height;
}
console.log(area({ width: 4, height: 3 }));
// prints 12
```
Внутри тела вообще нет объектной переменной — только `width` и `height`. Вызывающий передаёт один объект, но сигнатура документирует, какие именно ключи читает функция, и ключи могут прийти в любом порядке.

---

Деструктурированный параметр со значениями по умолчанию образует аккуратный объект опций, но он всё ещё ломается, когда вызывающий не передаёт ничего: чтение ключа из `undefined` бросает `TypeError`. Задание всему шаблону значения по умолчанию `{}` исправляет это:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// prints guest/false
```
Читайте строку снаружи внутрь: `= {}` поставляет пустой объект, когда аргумент отсутствует, а каждое внутреннее значение по умолчанию затем заполняет свой ключ.

---

`Object.entries(obj)` превращает объект в массив пар `[key, value]`. Поместите шаблон массива в заголовок цикла `for...of`, и каждая пара будет распакована по мере выполнения цикла:
```javascript
const ages = { ada: 36, bob: 41 };
for (const [name, age] of Object.entries(ages)) {
    console.log(`${name} is ${age}`);
}
// prints ada is 36
// prints bob is 41
```
Это читаемый способ пройти по объекту: ни индекса, ни обращения по ключу — только те два имени, которые вам важны. `Object.keys` и `Object.values` дают только одну из сторон, `Object.entries` даёт обе.

---

Всё, что мы видели до сих пор, принадлежит одному синтаксису, поэтому части свободно сочетаются: шаблон объекта может вкладывать в себя другой шаблон объекта, который может содержать переименованный ключ со значением по умолчанию, рядом с шаблоном массива, заканчивающимся rest-элементом. Одна строка тогда описывает всю форму, которую ожидает функция:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// prints Post [js] +2
```
Сохраняйте читаемость: шаблон, который больше не помещается в пару строк, — обычно признак того, что функция запрашивает слишком много.
