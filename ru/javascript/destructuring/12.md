# --description--

У шаблонов объектов тоже есть rest, и там он собирает каждый ключ, который шаблон не упомянул, в новый объект:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// prints { name: 'Ada', city: 'London' }
```
Это кратчайший способ создать копию объекта без одного из его ключей: исходный объект никогда не затрагивается, а rest-объект — новый, хранящий оставшиеся значения.

# --asserts--

Ключа `password` быть не должно.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

Остальные ключи должны сохраниться.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

Каждый из остальных ключей должен сохраниться.

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

Исходный объект не должен быть изменён.

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

Объект, содержащий только пароль, должен дать пустой объект.

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
