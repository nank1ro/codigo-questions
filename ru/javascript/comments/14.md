# --description--

Хороший комментарий объясняет, **почему** код что-то делает, а не **что** он делает. Код и так показывает, что происходит; повторение этого словами добавляет шум и устаревает, как только код меняется:
```javascript
// установить timeout равным 30
const timeout = 30;
```
Причина, стоящая за этим числом, — как раз то, о чём читатель не догадается:
```javascript
// сервер закрывает простаивающие соединения через 35 секунд, так что остановись раньше
const timeout = 30;
```
Если комментарий лишь пересказывает строку под ним, удалите его или замените причиной.
