# --description--

Каким бы ни был комментарий, правило одно: текст внутри него — **не код**. `console.log` внутри комментария никогда ничего не выводит, а код, написанный после `//` в той же строке, никогда не выполняется, даже если строка начинается с настоящего кода:
```javascript
console.log("a"); // console.log("b");
/* console.log("c"); */
// prints only a
```
Если вы не уверены, что выведет программа, мысленно удалите все комментарии и прочитайте то, что осталось.

# --instructions--

Что выведет этот код?
```javascript
// console.log("one");
console.log("two"); // console.log("three");
/* console.log("four"); */
console.log("five");
```

# --answers--

- `two` и `five`
- `one`, `two`, `three`, `four` и `five`
- `two`, `three` и `five`
- `two`, `four` и `five`
