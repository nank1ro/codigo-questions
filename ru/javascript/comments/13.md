# --description--

Файл JavaScript может начинаться со специальной строки, которая называется **шебанг** (или хешбанг): `#!` и затем путь к программе, которая должна запускать этот файл. В Unix-подобных системах это позволяет запускать скрипт прямо из терминала, например `./hello.js`, не набирая сначала `node`:
```javascript
#!/usr/bin/env node
console.log("Hello from Node");
```
JavaScript игнорирует эту строку точно так же, как комментарий, но только когда она — **самая первая строка** файла: в любом другом месте `#!` вызовет синтаксическую ошибку. `/usr/bin/env node` означает "найди `node` в этой системе и используй его".
