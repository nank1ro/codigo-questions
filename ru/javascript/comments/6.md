# --description--

В отличие от `//`, который заканчивается в конце строки, комментарий `/*` заканчивается только на `*/`. Если забыть его закрыть, JavaScript посчитает весь последующий код частью комментария и сообщит о синтаксической ошибке:
```javascript
const width = 10; /* in centimetres
console.log(width); // still inside the comment: SyntaxError, the comment is never closed
```
И `//`, и `/* */` работают как строчные комментарии, но с `/*` всегда убеждайтесь, что `*/` на месте.

# --instructions--

Блочный комментарий после `const result = n * 2;` так и не закрыт, поэтому он поглощает остаток файла, и программа падает с синтаксической ошибкой. Закройте комментарий в конце той же строки
