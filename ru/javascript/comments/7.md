# --description--

Блочные комментарии в JavaScript **не могут быть вложенными**: комментарий заканчивается на **первом** встреченном `*/`, сколько бы `/*` ни было до него.
```javascript
/* outer /* inner */ still a comment */
console.log("done");
```
Здесь комментарий заканчивается сразу после `inner`, поэтому `still a comment */` читается как код и вызывает синтаксическую ошибку. Помните об этом, когда закомментируете блок, в котором уже есть комментарий `/* */`: используйте `//` в каждой строке или сначала уберите внутренний комментарий.

# --instructions--

Что произойдёт при запуске этого кода?
```javascript
/* start /* nested */ console.log("hidden"); */
console.log("done");
```

# --answers--

- Синтаксическая ошибка: комментарий заканчивается на первом `*/`, поэтому второй `*/` — некорректный код
- Он выведет `done`
- Он выведет `hidden`, а затем `done`
- Ничего не выводится и никакой ошибки не возникает
