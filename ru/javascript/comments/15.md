# --description--

Некоторые комментарии следуют соглашению, которое понимают редакторы. Самые распространённые **маркеры**:
- `// TODO: ...` отмечает то, что ещё предстоит написать
- `// FIXME: ...` отмечает код, о котором известно, что он неверен и должен быть исправлен

```javascript
const limit = 10;
// TODO: read the limit from the settings
// FIXME: crashes when the list is empty
```
Для JavaScript это обычные комментарии; редакторы собирают их в список, чтобы незавершённую работу было легко найти. `TODO` обычно стоит рядом с заглушкой, которая поддерживает работоспособность кода, пока не написана настоящая реализация. Когда вы завершите работу, замените заглушку и уберите маркер тем же изменением: устаревший `TODO` вводит в заблуждение.
