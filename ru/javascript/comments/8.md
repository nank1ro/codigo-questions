# --description--

Чтобы закомментировать сразу несколько строк, оберните их в один блочный комментарий вместо того, чтобы добавлять `//` к каждой строке:
```javascript
let total = 100;
/*
total = total - 30;
total = total - 20;
*/
console.log(total); // prints 100
```
Так как строки внутри блока игнорируются, `total` никогда не меняется. Помните, что это работает только тогда, когда ни в одной из этих строк нет `*/`.

# --instructions--
