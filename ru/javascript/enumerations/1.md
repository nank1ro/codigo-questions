# --description--

**Перечисление** (или *enum*) — это общий тип для небольшой группы связанных фиксированных значений: дни недели, масти колоды карт, возможные состояния заказа.
В отличие от многих языков, в JavaScript **нет** ключевого слова `enum`. Идиоматической заменой служит обычный объект, свойствами которого являются члены перечисления, переданный в `Object.freeze()`, чтобы никто не мог изменить его позже:
```javascript
const Color = Object.freeze({
  RED: "red",
  GREEN: "green",
  BLUE: "blue",
});
console.log(Color.RED);
// prints red
```
По соглашению объект объявляется с помощью `const`, его имя начинается с заглавной буквы, а имена членов записываются в формате `UPPER_CASE`, точно так же, как и другие константы.
