# --description--

Значение, хранящееся в каждом члене, выбираете вы сами. **Строки** — самый распространённый выбор, потому что они читаемы при выводе, логировании или сохранении в файл:
```javascript
const Status = Object.freeze({
  ACTIVE: "active",
  DONE: "done",
});
console.log(Status.DONE);
// prints done
```
После заморозки объект также не может получить новые свойства, а `Object.isFrozen(obj)` сообщает, был ли объект заморожен:
```javascript
console.log(Object.isFrozen(Status));
// prints true
```
