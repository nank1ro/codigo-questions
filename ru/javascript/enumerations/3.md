# --description--

Зачем вообще замораживать объект? Замороженный объект отклоняет любое изменение: присвоение значения существующему члену, добавление нового или удаление какого-либо не имеет никакого эффекта.
То, как проявляется это отклонение, зависит от режима, в котором выполняется ваш код:
- в **нестрогом режиме** (sloppy mode, режим по умолчанию для обычных скриптов) присвоение **молча игнорируется**
- в **строгом режиме** (strict mode, файлы, начинающиеся с `"use strict"`, модули ES и тела классов) оно **выбрасывает** `TypeError`

```javascript
const Size = Object.freeze({ SMALL: "s", LARGE: "l" });
Size.SMALL = "xs";
Size.MEDIUM = "m";
console.log(Size.SMALL);
// prints s
console.log(Size.MEDIUM);
// prints undefined
```
В любом случае перечисление сохраняет заданные вами значения, а это именно то, что нужно от набора констант.

# --instructions--

Что выведет этот код при выполнении в нестрогом режиме (sloppy mode)?
```javascript
const Level = Object.freeze({ LOW: 1, HIGH: 3 });
Level.LOW = 0;
console.log(Level.LOW);
```

- 1
- 0
- undefined
- TypeError, потому что Level заморожен
