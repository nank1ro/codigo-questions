# --description--

Члены также могут хранить **числа**. Числовые значения удобны, когда члены имеют естественный порядок, поскольку их можно сравнивать обычными операторами:
```javascript
const Priority = Object.freeze({
  LOW: 1,
  MEDIUM: 2,
  HIGH: 3,
});
console.log(Priority.HIGH > Priority.LOW);
// prints true
```
Компромисс — читаемость: вывод `Priority.HIGH` показывает `3`, что говорит гораздо меньше, чем сказала бы строка `"high"`.
