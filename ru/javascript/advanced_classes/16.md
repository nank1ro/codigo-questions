# --description--

`for...of` и оператор расширения `...` работают не с любым объектом: они работают с **итерируемыми** объектами, которые предоставляют метод, хранящийся под особым ключом `Symbol.iterator`. Дайте своему классу этот метод, и он вступит в клуб:
```javascript
class Playlist {
    constructor(songs) {
        this.songs = songs;
    }
    *[Symbol.iterator]() {
        for (const song of this.songs) {
            yield song;
        }
    }
}
const list = new Playlist(["a", "b"]);
console.log([...list]);
// выводит [ 'a', 'b' ]
```
Звёздочка `*` перед именем делает его **генератором**: функцией, которая выдаёт значения по одному через `yield` и приостанавливается между ними. Это самый короткий способ выполнить протокол итерации, и он работает для значений, которые вычисляются, а не хранятся.

# --asserts--

Расширение `new Range(1, 4)` должно давать `[1, 2, 3, 4]`.

```javascript
tryCatch(JSON.stringify([...new Range(1, 4)]) === "[1,2,3,4]");
```

`for...of` должен посетить каждое число из `new Range(3, 5)`.

```javascript
let _sum = 0;
for (const n of new Range(3, 5)) {
  _sum += n;
}
tryCatch(_sum === 12);
```

Диапазон из одного числа должен выдать только это число.

```javascript
tryCatch(JSON.stringify([...new Range(7, 7)]) === "[7]");
```

Пустой диапазон не должен выдавать ничего.

```javascript
tryCatch(JSON.stringify([...new Range(5, 2)]) === "[]");
```

# --solutions--

```javascript
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}
```
