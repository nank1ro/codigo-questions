# --description--

Когда дочерний класс объявляет метод, который уже есть у родителя, побеждает версия дочернего класса. Это называется **переопределением**:
```javascript
class Animal {
    speak() {
        return "some sound";
    }
}
class Dog extends Animal {
    speak() {
        return "Woof";
    }
}
console.log(new Dog().speak());
// prints Woof
```
Переопределение не удаляет родительскую версию, а лишь скрывает её. Внутри дочернего метода до неё по-прежнему можно добраться через `super.methodName(...)`, что позволяет расширить поведение родителя, а не заменить его:
```javascript
class Puppy extends Dog {
    speak() {
        return super.speak() + "!";
    }
}
console.log(new Puppy().speak());
// prints Woof!
```
Обратите внимание на разницу: `super(...)` вызывает **конструктор** родителя, а `super.name(...)` — родительский **метод**.
