# --description--

Когда классы наследуют друг от друга, порядок имеет значение. Объявление `class` **не** поднимается вверх так, как это происходит с `function`: имя существует только начиная со строки, где класс написан. Поэтому дочерний класс должен идти *после* родителя, который он расширяет, иначе выражение `extends` завершится ошибкой `ReferenceError`.

# --instructions--

Расположите элементы так, чтобы получилась работающая программа. Помните, что родительский класс должен быть определён раньше дочернего

# --answers--

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
```

```javascript
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
```

```javascript
console.log(new Car().describe());
```
