# --description--

Некоторое поведение принадлежит самому классу, а не отдельному экземпляру. Например, перевод из одних единиц в другие не нуждается в объекте. Пометка метода словом **`static`** помещает его на класс:
```javascript
class MathUtils {
    static double(n) {
        return n * 2;
    }
}
console.log(MathUtils.double(4));
// выводит 8
```
Статический метод вызывается по имени класса, но никогда на экземпляре: `new MathUtils().double(4)` выбрасывает `TypeError`, потому что экземпляры не получают статические члены. Внутри статического метода `this` указывает на класс, поэтому один статический метод может вызвать другой через `this.otherStatic(...)`.



```javascript
class Temperature {
  static toFahrenheit(celsius) {
    return celsius * 9 / 5 + 32;
  }
  static toCelsius(fahrenheit) {
    return (fahrenheit - 32) * 5 / 9;
  }
}
```
