# --description--

Методы тоже могут быть приватными. Поставьте перед именем `#`, и метод исчезнет с публичной поверхности класса, оставаясь вызываемым из любого другого метода через `this.#name(...)`:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// prints $7
```
Именно так вспомогательные шаги держат вне API: вызывающий код видит `print`, а не деталь форматирования за ним. Приватные поля и приватные методы вместе дают классу чёткое разделение на внутреннее и внешнее.

# --asserts--

Новый счёт должен начинаться с `0`.

```javascript
tryCatch(new Score().total === 0);
```

Положительные значения должны прибавляться.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

Отрицательные значения должны игнорироваться.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

Ноль должен игнорироваться.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

Очки должны быть приватными, поэтому у экземпляра не должно быть публичных свойств.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

Вспомогательный метод должен быть приватным.

```json
{
  "regex": "this\\.#add\\s*\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
