# --description--

Правило насчёт `super()` строже, чем «вызови его где-нибудь». В конструкторе дочернего класса слово `this` не существует, пока не выполнится `super()`, потому что именно родительский конструктор создаёт объект. Обращение к `this` до этой строки приводит к ошибке:
```javascript
class Child extends Base {
    constructor() {
        this.x = 1; // ReferenceError
        super();
    }
}
```
Значит, `super(...)` должен быть **первой инструкцией** любого конструктора дочернего класса, который использует `this`.

# --instructions--

Что произойдёт при запуске этой программы?
```javascript
class Base {
  constructor() {
    this.a = 1;
  }
}
class Child extends Base {
  constructor() {
    this.b = 2;
    super();
  }
}
console.log(new Child().a);
```

# --answers--

- Выбрасывается `ReferenceError`, потому что `this` используется до `super()`
- Выводится `1`
- Выводится `2`
- Выводится `undefined`
