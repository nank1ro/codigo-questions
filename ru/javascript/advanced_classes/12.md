# --description--

Ведущее подчёркивание в `_temperature` — всего лишь соглашение: ничто не мешает внешнему коду написать `v._level = 999` и пройти мимо вашего сеттера. **Приватное поле** обеспечивается самим языком. Его имя начинается с `#`, оно должно быть объявлено в теле класса, и читать или записывать его можно только изнутри этого класса:
```javascript
class Secret {
    #code = 1234;
    reveal() {
        return this.#code;
    }
}
const s = new Secret();
console.log(s.reveal());
// выводит 1234
console.log(s.#code);
// SyntaxError: the field is not accessible here
```
На двух деталях легко споткнуться. Символ `#` является частью имени, поэтому всегда пишут `this.#code`, но никогда `this.code`. И приватное поле не появляется ни в `Object.keys`, ни в выводе `console.log` для экземпляра.
