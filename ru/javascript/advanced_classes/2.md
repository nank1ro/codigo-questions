# --description--

Дочернему классу не нужно заново определять то, что родитель уже предоставляет. Методы тоже наследуются, поэтому экземпляр дочернего класса может вызывать их, как будто это его собственные:
```javascript
class Animal {
    constructor(name) {
        this.name = name;
    }
    speak() {
        return `${this.name} makes a sound`;
    }
}
class Dog extends Animal {}
console.log(new Dog("Max").speak());
// prints Max makes a sound
```
Когда дочерний класс объявляет собственный конструктор, вызвать в нём `super(...)` — **обязательно**: без этого объект никогда не будет инициализирован, и JavaScript выбросит `ReferenceError`. Дочерний класс вовсе без конструктора — это нормально, потому что JavaScript сам создаёт конструктор, который пересылает каждый аргумент родителю.
