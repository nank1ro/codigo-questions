# --description--

Ещё два метода массивов принимают колбэк.
`forEach(callback)` вызывает колбэк один раз для каждого элемента и ничего не возвращает; используйте её ради побочных эффектов, таких как вывод.
`reduce(callback, initialValue)` сворачивает массив в одно значение: колбэк получает накопленное к этому моменту значение и текущий элемент, а возвращает новое накопленное значение:
```javascript
const numbers = [1, 2, 3];
numbers.forEach((n) => console.log(n));
// prints 1, 2 and 3 on three lines
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(total);
// prints 6
```
