# --description--

Стрелочную функцию не обязательно сохранять, чтобы вызвать её. Оберните её в круглые скобки и сразу добавьте список аргументов: это **немедленно вызываемая** стрелочная функция:
```javascript
const doubled = ((n) => n * 2)(5);
console.log(doubled);
// prints 10
```
Круглые скобки вокруг стрелки обязательны: без них `(n) => n * 2(5)` попытается вызвать число `2`. Немедленно вызываемые функции удобны, чтобы вычислить значение с несколькими временными переменными, которые не должны утечь в остальную часть программы.
