# --description--

`sort(compare)` сортирует массив на месте с помощью колбэка, который получает два элемента и возвращает отрицательное число, если первый должен идти раньше, положительное число, если второй должен идти раньше, или `0`, если они равны. Для чисел `(a, b) => a - b` сортирует по возрастанию, а `(a, b) => b - a` — по убыванию.
`find(callback)` возвращает первый элемент, для которого колбэк возвращает `true`, или `undefined`, если такого нет:
```javascript
const scores = [50, 90, 70];
scores.sort((a, b) => a - b);
console.log(scores);
// prints [ 50, 70, 90 ]
console.log(scores.find((s) => s > 60));
// prints 70
```
