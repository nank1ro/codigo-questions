# --description--

Функция помнит переменные области видимости, в которой она была **создана**, даже после того, как эта область закончила выполняться. Это называется **замыканием**.
Классический пример — фабрика счётчиков: каждый вызов `makeCounter` создаёт новый `count` и возвращает стрелочную функцию, которая продолжает использовать тот же самый `count`:
```javascript
const makeCounter = () => {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
};
const next = makeCounter();
console.log(next());
// prints 1
console.log(next());
// prints 2
```
Никто другой не может прочитать или сбросить `count`: он живёт только внутри возвращённой функции. Повторный вызов `makeCounter()` создаёт независимый счётчик со своим собственным `count`.

# --instructions--

Что выведет этот код? (`makeCounter` — функция из описания)
```javascript
const a = makeCounter();
const b = makeCounter();
a();
a();
console.log(a() + b());
```
