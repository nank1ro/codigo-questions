# --description--

Поскольку функция — это значение, стрелочная функция может **возвращать другую стрелочную функцию**. Цепочка из двух стрелок — компактный способ написать функцию, создающую функции:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
Читайте слева направо: `makeAdder` принимает `amount` и возвращает `(n) => n + amount`, стрелочную функцию, которая захватывает `amount` через замыкание. `makeAdder(1)(5)` сразу вызывает возвращённую функцию.

```javascript

```

Функция, возвращённая `makeMultiplier(2)`, должна вернуть `20` при вызове с `10`.

