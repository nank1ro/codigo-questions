Функции не обязательно иметь имя. **Функциональное выражение** создаёт функцию как значение, которое можно сохранить в переменную и вызывать через неё:
```javascript
const add = function (a, b) {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
**Стрелочная функция** — более короткий способ записать то же самое: уберите ключевое слово `function` и поставьте «жирную стрелку» `=>` между списком параметров и телом:
```javascript
const add = (a, b) => {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
Стрелочные функции обычно сохраняют в `const`, чтобы имя нельзя было случайно переназначить, и вызывают их точно так же, как любую другую функцию.

---

В двух распространённых случаях стрелочные функции становятся ещё короче.
Когда тело — это **одно выражение**, можно опустить фигурные скобки и ключевое слово `return`: значение выражения возвращается автоматически (**неявный возврат**):
```javascript
const add = (a, b) => a + b;
console.log(add(2, 3));
// prints 5
```
Когда параметр **ровно один**, можно также опустить круглые скобки вокруг него:
```javascript
const double = n => n * 2;
console.log(double(4));
// prints 8
```
С нулём параметров или с двумя и более скобки обязательны: `() => 42` и `(a, b) => a + b`.

---

У неявного возврата есть одна ловушка. Тело стрелочной функции, начинающееся с `{`, читается как **блок**, но никогда как литерал объекта:
```javascript
const make = (name) => { name: name };
console.log(make("Ana"));
// prints undefined
```
Здесь `{ name: name }` — это блок, содержащий метку `name:`, за которой следует выражение `name`. Ничего не возвращается, поэтому вызов даёт `undefined`.
Чтобы вернуть литерал объекта одной строкой, оберните его в **круглые скобки**, чтобы JavaScript считал его выражением:
```javascript
const make = (name) => ({ name: name });
console.log(make("Ana"));
// prints { name: 'Ana' }
```

---

Оборачивание литерала объекта в круглые скобки — стандартный способ создавать объекты однострочной стрелочной функцией, например когда вы превращаете пару значений в запись:
```javascript
const user = (name, age) => ({ name: name, age: age });
console.log(user("Ana", 30).age);
// prints 30
```
Стрелочная функция без параметров начинается с пустой пары круглых скобок `()`:
```javascript
const empty = () => ({});
console.log(empty());
// prints {}
```

---

Стрелочные функции по-настоящему раскрываются как **колбэки**: функции, передаваемые в качестве аргументов другим функциям. Методы массивов — самый распространённый пример.
`map(callback)` возвращает новый массив с результатом колбэка для каждого элемента, а `filter(callback)` возвращает новый массив только с теми элементами, для которых колбэк возвращает `true`:
```javascript
const numbers = [1, 2, 3, 4];
console.log(numbers.map((n) => n * 10));
// prints [ 10, 20, 30, 40 ]
console.log(numbers.filter((n) => n > 2));
// prints [ 3, 4 ]
```
Оба возвращают новый массив и оставляют исходный нетронутым, поэтому их можно объединять в цепочки: `numbers.filter(...).map(...)`.

---

Ещё два метода массивов принимают колбэк.
`forEach(callback)` вызывает колбэк один раз для каждого элемента и ничего не возвращает; используйте её ради побочных эффектов, таких как вывод.
`reduce(callback, initialValue)` сворачивает массив в одно значение: колбэк получает накопленное к этому моменту значение и текущий элемент, а возвращает новое накопленное значение:
```javascript
const numbers = [1, 2, 3];
numbers.forEach((n) => console.log(n));
// prints 1, 2 and 3 on three lines
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(total);
// prints 6
```

---

`sort(compare)` сортирует массив на месте с помощью колбэка, который получает два элемента и возвращает отрицательное число, если первый должен идти раньше, положительное число, если второй должен идти раньше, или `0`, если они равны. Для чисел `(a, b) => a - b` сортирует по возрастанию, а `(a, b) => b - a` — по убыванию.
`find(callback)` возвращает первый элемент, для которого колбэк возвращает `true`, или `undefined`, если такого нет:
```javascript
const scores = [50, 90, 70];
scores.sort((a, b) => a - b);
console.log(scores);
// prints [ 50, 70, 90 ]
console.log(scores.find((s) => s > 60));
// prints 70
```

---

Параметры стрелочных функций поддерживают те же возможности, что и параметры обычных функций.
**Значение по умолчанию** используется, когда аргумент опущен или равен `undefined`:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
Обратите внимание, что параметр со значением по умолчанию всегда требует круглых скобок, даже когда он единственный: `name = "World" => ...` — синтаксическая ошибка.

---

**Rest-параметр** `...name` собирает любое количество аргументов в массив, и работает он и в стрелочных функциях:
```javascript
const count = (...items) => items.length;
console.log(count("a", "b", "c"));
// prints 3
```
У обычных функций также есть скрытый подобный массиву объект `arguments`, в котором хранится каждый полученный аргумент. У стрелочных функций его **нет**: внутри стрелки `arguments` ссылается на `arguments` окружающей функции или вовсе не существует. Когда в стрелочной функции нужны «все аргументы», используйте rest-параметр.

---

Функция помнит переменные области видимости, в которой она была **создана**, даже после того, как эта область закончила выполняться. Это называется **замыканием**.
Классический пример — фабрика счётчиков: каждый вызов `makeCounter` создаёт новый `count` и возвращает стрелочную функцию, которая продолжает использовать тот же самый `count`:
```javascript
const makeCounter = () => {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
};
const next = makeCounter();
console.log(next());
// prints 1
console.log(next());
// prints 2
```
Никто другой не может прочитать или сбросить `count`: он живёт только внутри возвращённой функции. Повторный вызов `makeCounter()` создаёт независимый счётчик со своим собственным `count`.

---

Поскольку функция — это значение, стрелочная функция может **возвращать другую стрелочную функцию**. Цепочка из двух стрелок — компактный способ написать функцию, создающую функции:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
Читайте слева направо: `makeAdder` принимает `amount` и возвращает `(n) => n + amount`, стрелочную функцию, которая захватывает `amount` через замыкание. `makeAdder(1)(5)` сразу вызывает возвращённую функцию.
