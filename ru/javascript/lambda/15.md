# --description--

Самое большое различие между обычной функцией и стрелочной функцией — ключевое слово `this`.
Обычная `function` получает **собственный** `this`, определяемый тем, *как её вызывают*: в `team.intro()` это `team`, но в колбэке, переданном в `map`, никто его не задаёт, поэтому `this.name` — это `undefined` (или даже ошибка в строгом режиме).
У стрелочной функции **нет** собственного `this`: она просто использует `this` окружающего кода (**лексический** `this`). Именно поэтому стрелочные колбэки внутри метода могут продолжать использовать объект:
```javascript
const team = {
  name: "Tigers",
  players: ["Ana", "Bo"],
  intro() {
    return this.players.map((p) => `${p} plays for ${this.name}`);
  },
};
console.log(team.intro());
// prints [ 'Ana plays for Tigers', 'Bo plays for Tigers' ]
```
С `function (p) { return ... this.name ... }` в качестве колбэка тот же код вывел бы `undefined` вместо `Tigers`.
Обратная сторона: не используйте стрелочную функцию в качестве **метода** объекта, которому нужен `this`, потому что она не будет ссылаться на объект.
