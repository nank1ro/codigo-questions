# --description--

Параметры стрелочных функций поддерживают те же возможности, что и параметры обычных функций.
**Значение по умолчанию** используется, когда аргумент опущен или равен `undefined`:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
Обратите внимание, что параметр со значением по умолчанию всегда требует круглых скобок, даже когда он единственный: `name = "World" => ...` — синтаксическая ошибка.

# --asserts--

`greet()` должна вернуть `"Hello, World!"`.

```javascript
tryCatch(greet() === "Hello, World!");
```

`greet("Ana")` должна вернуть `"Hello, Ana!"`.

```javascript
tryCatch(greet("Ana") === "Hello, Ana!");
```

`greet(undefined)` должна также использовать значение по умолчанию.

```javascript
tryCatch(greet(undefined) === "Hello, World!");
```

`greet` должна быть стрелочной функцией.

