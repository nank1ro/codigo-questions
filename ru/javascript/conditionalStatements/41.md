# --description--

Условие оператора `if` всегда помещается внутрь круглых скобок `()`, сразу после ключевого слова `if` и перед открывающей фигурной скобкой.

# --instructions--

Где мы записываем условие оператора if?

# --answers--

- Между круглыми скобками ()
- Между квадратными скобками []
- Между ключевым словом if и открывающей фигурной скобкой {
- Перед ключевым словом if
