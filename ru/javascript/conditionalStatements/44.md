# --description--

Блок кода оператора `if` — это набор инструкций внутри фигурных скобок `{ }`, та часть, которая действительно выполняется, когда условие равно `true`.

# --instructions--

Что такое блок кода оператора if?

# --answers--

- Код, который выполняется, если условие ложно
- Код, который определяет, должен ли фрагмент кода выполняться
- Ключевое слово сравнения
