Принятие решений необходимо, когда мы хотим выполнить код только при выполнении определённого условия.
Допустим, мы хотим играть на улице, только если погода хорошая.
В программировании мы можем сохранить логическую переменную `niceWeather` и выполнить действие — играть на улице — `if` (если) эта переменная равна `true`, например:
```javascript
var niceWeather = true;
if (niceWeather) {
    // играть на улице
}
```

---

Продолжим с предыдущим примером.
```javascript
var niceWeather = true;
if (niceWeather) {
    // играть на улице
}
```
Мы видели, что оператор `if` выполняет блок кода только если условие равно `true`.
Ещё один важный момент — это **фигурные скобки** `{}`, которые обозначают блок кода.

---

Мы только что увидели, как выполнить блок кода при наступлении условия. Теперь давайте посмотрим, как выполнить другой блок кода, если первое условие не выполняется.
Мы идём играть на улицу, если погода хорошая; в противном случае остаёмся дома.
В JavaScript мы можем использовать оператор `else`, например:
```javascript
var niceWeather = true;
if (niceWeather) {
    // играть на улице
} else {
    // остаться дома
}
```

---

Допустим, у нас есть ещё одно условие для проверки, как в этом примере:
```javascript
var num = 3;
if (num == 2) {
    console.log("the number is 2");
} else if (num == 3) {
    console.log("the number is 3");
} else {
    console.log("do something else");
}
```
и результат выполнения этого кода — `the number is 3`.
Сначала проверяем, равно ли число 2 — это ложь.
Поэтому переходим ко второму оператору и проверяем, равно ли `num` числу 3. Так как это истина, выполняем следующий блок кода и выводим `the number is 3`

---

Мы можем добавить сколько угодно операторов `else if`, ограничений нет
```javascript
var num = 4;
if (num == 2) {
    console.log("the number is 2");
} else if (num == 3) {
    console.log("the number is 3");
} else if (num == 4) {
    console.log("the number is 4");
} else if (num == 5) {
    console.log("the number is 5");
} else if (num == 6) {
    console.log("the number is 6");
}
```
и результат выполнения этого кода — `the number is 4`.

---

Мы также можем вложить условный оператор (`if`, `else if` или `else`) внутрь другого условного оператора, чтобы создать более сложную структуру.
```javascript
var num = 4;
if (num < 3) {
    console.log("the number is lower than 3");
} else {
    if (num == 3) {
        console.log("the number is 3");
    } else if (num == 4) {
        console.log("the number is 4");
    } else {
        console.log("the number is greather than 4");
    }
}
```
и результат выполнения этого кода — `the number is 4`.

---

Тернарный условный оператор — это специальный оператор с тремя частями, который имеет вид `question ? answer1 : answer2`.
Это сокращённый способ вычисления одного из двух выражений в зависимости от того, истинен `question` или ложен.
Если `question` истинен, вычисляется `answer1` и возвращается его значение; в противном случае вычисляется `answer2` и возвращается его значение.
```javascript
let a = 10, b = 20, c = 0;
if (a < b) {
    c = a;
} else {
    c = b;
}
console.log(c);
// выводит 10
```
Сокращённый код для приведённого выше:
```javascript
let a = 10, b = 20, c = 0;
c = a < b ? a : b;
console.log(c);
// выводит 10
```
`c` присваивается значение `a`, потому что условие `a < b` было истинным

---

Оператор _объединения с null_ `a ?? b` извлекает значение из необязательного `a`, если оно содержит значение, или возвращает значение по умолчанию `b`, если `a` равно `nil`.
Выражение `a` всегда имеет необязательный тип.
Выражение `b` должно соответствовать типу, хранящемуся внутри a.
Оператор объединения с null является сокращением для следующего кода:
```javascript
a != nil ? a! : b;
```

---

`if` — это ключевое слово, с которого начинается условный оператор в JavaScript. Здесь нет ключевого слова `elif` — второе условие вводится с помощью `else if`, записанного как два отдельных слова.

---

Булевы литералы в JavaScript пишутся в нижнем регистре: `true` и `false`, а не `True`/`False`, и не строки `"true"`/`"false"`.

---

Чтобы блок кода не выполнялся, условие внутри скобок должно принимать значение `false`.

---

Пробел между `if` и его скобками — чисто косметический: `if(true)` и `if (true)` для JavaScript — одно и то же выражение.

---

Именно фигурные скобки объединяют несколько выражений в один блок. Без них `if` управляет только одним выражением, следующим сразу за ним, поэтому `if (true) console.log("Hello!");` — валидный JavaScript.

---

Условие вычисляется один раз, перед началом блока. JavaScript больше не проверяет его, пока выполняются выражения между скобками.

---

Условие `false` полностью пропускает блок, и программа продолжается с первого выражения после закрывающей скобки.

---

Условие не обязано быть булевым значением: JavaScript приводит к нему всё, что найдёт, поэтому `if (1)` выполняет свой блок, а `if (0)` — нет. Литерал `true` вообще не нуждается в приведении.

---

Блок кода не ограничен одной строкой — каждое выражение внутри фигурных скобок выполняется по порядку, когда условие равно `true`.
```javascript
if (true) {
    console.log("First line");
    console.log("Second line");
}
```
а результат — `First line`, за которым следует `Second line`.

---

Выражения внутри блока выполняются одно за другим, сверху вниз, поэтому два вызова `console.log` в одном блоке выводят текст на двух разных строках.

---

Отступы у выражений внутри блока — это лишь соглашение для удобства чтения. JavaScript использует для определения принадлежности к блоку фигурные скобки, а не отступы.

---

Операторы вроде `if`, `else if` и `else`, которые выполняют или пропускают код в зависимости от того, равно ли условие `true` или `false`, называются **условными операторами**.

---

Булеву переменную, даже построенную с помощью отрицания `!`, как `isAfternoon`, можно использовать напрямую в качестве условия `if`, без сравнения.

---

Условие оператора `if` всегда помещается внутрь круглых скобок `()`, сразу после ключевого слова `if` и перед открывающей фигурной скобкой.

---

Блок может содержать любое количество выражений, а может не содержать ни одного: `if (true) {}` — это валидный JavaScript, который просто ничего не делает.

---

Блок кода оператора `if` — это набор инструкций внутри фигурных скобок `{ }`, та часть, которая действительно выполняется, когда условие равно `true`.
