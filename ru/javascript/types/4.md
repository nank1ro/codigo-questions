# --description--

Значение можно преобразовать в другой тип **явно**, вызвав тип как функцию:
- `Number(value)` преобразует в число: `Number("42")` — это `42`
- `String(value)` преобразует в строку: `String(42)` — это `"42"`
- `Boolean(value)` преобразует в булево значение: `Boolean("")` — это `false`

Результат — совершенно новое значение; исходное не меняется:
```javascript
const input = "7";
const count = Number(input) + 1;
console.log(count, typeof count);
// prints 8 number
console.log(String(count) + "!");
// prints 8!
```
Явное преобразование делает ваш замысел очевидным: тот, кто читает `Number(input)`, знает, что `input` был текстом.
