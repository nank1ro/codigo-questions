# --description--

Текст, приходящий из форм, файлов или URL, — всегда строка, даже когда он представляет число или булево значение. Обратное преобразование в правильный тип объединяет то, что вы уже видели: для булевых значений сравнивайте с `"true"` и `"false"`, а для чисел пробуйте `Number()`, помня, что `Number("")` — это `0` и что `Number.isNaN` сообщает, когда преобразование не удалось:
```javascript
console.log(Number("3.5"), Number(""), Number("12px"));
// prints 3.5 0 NaN
```
Когда ничего не подходит, оставьте строку как есть.

# --asserts--

`parseValue("42")` должна возвращать число `42`.

```javascript
tryCatch(parseValue("42") === 42);
```

`parseValue("3.5")` должна возвращать `3.5`.

```javascript
tryCatch(parseValue("3.5") === 3.5);
```

`parseValue("true")` и `parseValue("false")` должны возвращать булевы значения `true` и `false`.

```javascript
tryCatch(parseValue("true") === true && parseValue("false") === false);
```

`parseValue("Ana")` должна возвращать `"Ana"`.

```javascript
tryCatch(parseValue("Ana") === "Ana");
```

`parseValue("12px")` должна возвращать `"12px"`, потому что весь текст — не число.

```javascript
tryCatch(parseValue("12px") === "12px");
```

`parseValue("")` должна возвращать `""`, а не `0`.

```javascript
tryCatch(parseValue("") === "");
```

```javascript
function parseValue(text) {
  if (text === "true") {
    return true;
  }
  if (text === "false") {
    return false;
  }
  if (text !== "" && !Number.isNaN(Number(text))) {
    return Number(text);
  }
  return text;
}
```
