# --description--

Каждое значение в JavaScript имеет **тип**. Есть семь **примитивных** типов:
- `number` для любого числа, например `42` или `3.14`
- `string` для текста, например `"Ana"`
- `boolean` для `true` и `false`
- `undefined` для значения, которое не было задано
- `null` для намеренно пустого значения
- `bigint` для целых чисел любого размера, например `9007199254740993n`
- `symbol` для уникальных идентификаторов, создаваемых с помощью `Symbol()`

Всё остальное (массивы, функции, объекты, созданные с помощью `{}`, даты...) — это `object`.
Оператор `typeof` сообщает тип значения в виде строки:
```javascript
console.log(typeof 42, typeof "Ana", typeof true);
// prints number string boolean
let city;
console.log(typeof city);
// prints undefined
```
