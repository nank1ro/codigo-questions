# --description--

Поскольку `typeof` отвечает `"object"` для массивов, объектов и `null`, чтобы их различить, нужны две дополнительные проверки.
`Array.isArray(value)` равна `true` только для массивов:
```javascript
console.log(Array.isArray([1, 2]), Array.isArray({}));
// prints true false
```
Для `null` сравнивайте напрямую: `value === null`. Их сочетание даёт полную картину о любом значении:
```javascript
function kind(value) {
  if (value === null) return "null";
  if (Array.isArray(value)) return "array";
  return typeof value;
}
```
Проверяйте `null` и массивы первыми, потому что обычный `typeof` не может их различить.

# --asserts--

`typeName(null)` должна возвращать `"null"`.

```javascript
tryCatch(typeName(null) === "null");
```

`typeName([1, 2])` и `typeName([])` должны возвращать `"array"`.

```javascript
tryCatch(typeName([1, 2]) === "array" && typeName([]) === "array");
```

`typeName({})` должна возвращать `"object"`.

```javascript
tryCatch(typeName({}) === "object");
```

`typeName(42)`, `typeName("a")` и `typeName(true)` должны возвращать `"number"`, `"string"` и `"boolean"`.

```javascript
tryCatch(typeName(42) === "number" && typeName("a") === "string" && typeName(true) === "boolean");
```

`typeName(undefined)`, `typeName(10n)` и `typeName(Symbol())` должны возвращать `"undefined"`, `"bigint"` и `"symbol"`.

```javascript
tryCatch(typeName(undefined) === "undefined" && typeName(10n) === "bigint" && typeName(Symbol()) === "symbol");
```

`typeName(function () {})` должна возвращать `"function"`.

```javascript
tryCatch(typeName(function () {}) === "function");
```
