# --description--

Когда JavaScript требуется булево значение, например в условии `if` или в `Boolean(value)`, он преобразует значение. Только восемь значений становятся `false`; они называются **falsy**:
`false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` и `NaN`.
**Всё остальное — truthy**, включая некоторые значения, которые выглядят пустыми:
```javascript
console.log(Boolean(0), Boolean(""), Boolean(NaN));
// prints false false false
console.log(Boolean("0"), Boolean("false"), Boolean([]), Boolean({}));
// prints true true true true
```
`"0"` — непустая строка, поэтому она truthy; пустой массив — это объект, поэтому он тоже truthy.

# --asserts--

`countTruthy([1, "a", true])` должна возвращать `3`.

```javascript
tryCatch(countTruthy([1, "a", true]) === 3);
```

`countTruthy([0, "", null, undefined, NaN, false])` должна возвращать `0`.

```javascript
tryCatch(countTruthy([0, "", null, undefined, NaN, false]) === 0);
```

`countTruthy(["0", "false", [], {}])` должна возвращать `4`.

```javascript
tryCatch(countTruthy(["0", "false", [], {}]) === 4);
```

`countTruthy([0n, -0, " "])` должна возвращать `1`, потому что truthy является только строка с пробелом.

```javascript
tryCatch(countTruthy([0n, -0, " "]) === 1);
```

`countTruthy([])` должна возвращать `0`.

```javascript
tryCatch(countTruthy([]) === 0);
```

# --solutions--

```javascript
function countTruthy(values) {
  let count = 0;
  for (const value of values) {
    if (value) {
      count++;
    }
  }
  return count;
}
```
