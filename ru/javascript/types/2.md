# --description--

JavaScript — язык с **динамической типизацией**: у переменной нет собственного типа, тип есть только у значения, которое она хранит в данный момент. Одна и та же переменная может хранить число сейчас и строку позже, а `typeof` следует за значением:
```javascript
let data = 10;
console.log(typeof data);
// prints number
data = "ten";
console.log(typeof data);
// prints string
```
Это удобно, но означает и то, что функция может получить значение неожиданного типа, поэтому проверка с помощью `typeof` — обычный первый шаг. Поскольку `typeof` возвращает строку, его результат сравнивают со строкой:
```javascript
if (typeof data === "string") {
  console.log("text");
}
```

```javascript

```

`sameType(1, "1")` должна возвращать `false`.

```javascript
tryCatch(sameType(1, "1") === false);
```

`sameType("", "a")` должна возвращать `true`.

```javascript
tryCatch(sameType("", "a") === true);
```

`sameType(true, 1)` должна возвращать `false`.

```javascript

```

`sameType(null, {})` должна возвращать `true`, потому что `typeof null` — это `"object"`.

```javascript

```

`sameType(undefined, null)` должна возвращать `false`.

```javascript
tryCatch(sameType(undefined, null) === false);
```
