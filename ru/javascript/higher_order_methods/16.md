# --description--

Всё соединяется в `groupBy(items, keyFn)`: функции высшего порядка, которая получает колбэк, определяющий **ключ группы** каждого элемента, и возвращает объект, сопоставляющий каждому ключу массив элементов с этим ключом. `reduce` с объектом-аккумулятором делает всю работу:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Для каждого элемента вычисли ключ, создай массив для этого ключа, если его ещё нет (`acc[key] ?? []`), добавь элемент и верни аккумулятор. Так как `keyFn` выбирает вызывающий код, одна и та же функция группирует слова по первой букве, людей по городу или числа по чётности.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` должна вернуть `{ h: ["hi", "hey"], y: ["yo"] }`.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

Группировка `[1, 2, 3, 4]` по чётности должна вернуть `{ odd: [1, 3], even: [2, 4] }`.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Группировка людей по `city` должна сохранять объекты целиком, в исходном порядке.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` должна вернуть пустой объект.

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

Исходный массив не должен изменяться.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

Функция должна использовать `reduce`.

```javascript
tryCatch(/\.reduce\(/.test(groupBy.toString()));
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
