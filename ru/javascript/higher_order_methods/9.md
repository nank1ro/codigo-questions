# --description--

Замыкание хранит **живую** связь с переменной, а не копию её значения. Когда в одном вызове создаётся несколько функций, они делят одну и ту же переменную, и любое изменение через одну видно остальным:
```javascript
function makeCounter() {
  let count = 0;
  return {
    increment: () => { count += 1; },
    value: () => count,
  };
}
const counter = makeCounter();
counter.increment();
counter.increment();
console.log(counter.value());
// prints 2
```
Никто не может прочитать или сбросить `count` снаружи иначе как через эти две функции: переменная **приватная**. Второй вызов `makeCounter()` создаёт совершенно отдельный `count`.

Что выведет этот код?
```javascript
function makeAccount(balance) {
  return {
    deposit: (amount) => { balance += amount; },
    total: () => balance,
  };
}
const a = makeAccount(10);
const b = makeAccount(10);
a.deposit(5);
a.deposit(5);
b.deposit(1);
console.log(a.total(), b.total());
```
