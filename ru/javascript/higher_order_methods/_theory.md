В JavaScript функция — это **значение**: её можно сохранить в переменной, положить в массив и передать другой функции как аргумент. Функция, которая принимает функцию как аргумент или возвращает функцию, называется **функцией высшего порядка**. Переданную функцию называют **колбэком**, потому что получатель *вызывает её обратно*, когда она нужна:
```javascript
function shout(text) {
  return text.toUpperCase() + "!";
}
function twice(fn, value) {
  return fn(fn(value));
}
console.log(twice(shout, "hi"));
// prints HI!!
```
Обрати внимание, что `shout` передаётся **без скобок**: `twice(shout, "hi")` передаёт саму функцию, тогда как `twice(shout("hi"), "hi")` сначала вызвал бы `shout` и передал его результат, строку `"HI!"`, которую вызвать нельзя.

---

Функции высшего порядка позволяют отделить *что делать с каждым элементом* от *того, как обходить элементы*. Обход пишется один раз, а колбэк решает всё остальное:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
Колбэк получает по одному элементу за раз. Это может быть стрелочная функция, написанная на месте, как выше, или любая функция, сохранённая в переменной. Именно так внутри работают встроенные методы массивов, с которыми ты познакомишься дальше.

---

Встроенный `map` делает то же, что и `transform`: вызывает колбэк для каждого элемента и собирает результаты в **новый массив**. `forEach` тоже вызывает колбэк для каждого элемента, но ничего не собирает и всегда возвращает `undefined`; используй его только ради побочных эффектов, например для вывода:
```javascript
const prices = [5, 10];
const doubled = prices.map((p) => p * 2);
prices.forEach((p) => console.log(p));
// prints 5 and 10 on two lines
console.log(doubled);
// prints [ 10, 20 ]
```
Частая ошибка — сохранить результат `forEach` или прицепить к нему ещё один метод: цеплять нечего, ведь он возвращает `undefined`. Правило: бери `map`, когда нужны новые значения, и `forEach`, когда нужно только что-то *сделать*.

---

Ещё два метода высшего порядка покрывают большинство повседневных задач.
`filter(callback)` возвращает новый массив только с теми элементами, для которых колбэк вернул `true`; колбэк, который так отвечает «да» или «нет», называется **предикатом**.
`reduce(callback, initialValue)` сводит все элементы к одному значению: колбэк получает **аккумулятор** (результат на текущий момент) и текущий элемент и возвращает новый аккумулятор. Второй аргумент `reduce` — начальный аккумулятор:
```javascript
const numbers = [3, 8, 5];
console.log(numbers.filter((n) => n > 4));
// prints [ 8, 5 ]
console.log(numbers.reduce((sum, n) => sum + n, 0));
// prints 16
```
Так как `filter` и `map` возвращают массивы, их можно объединять в цепочку и завершать её `reduce`: `numbers.filter(...).map(...).reduce(...)`.

---

Три метода отвечают на вопросы о массиве с помощью предиката:
- `find(predicate)` возвращает **первый** элемент, для которого предикат равен `true`, или `undefined`, если такого нет
- `some(predicate)` возвращает `true`, если предикату удовлетворяет **хотя бы один** элемент
- `every(predicate)` возвращает `true`, если ему удовлетворяют **все** элементы (и `true` для пустого массива)
```javascript
const scores = [72, 45, 90];
console.log(scores.find((s) => s < 60));
// prints 45
console.log(scores.some((s) => s === 90), scores.every((s) => s >= 60));
// prints true false
```
Все три останавливаются, как только ответ известен, поэтому они никогда не просматривают больше элементов, чем нужно.

---

`sort(compare)` сортирует массив **на месте** с помощью колбэка, который получает два элемента и возвращает отрицательное число, когда первый должен идти раньше, положительное — когда раньше должен идти второй, и `0`, когда они равны. Для чисел `(a, b) => a - b` сортирует по возрастанию, а `(a, b) => b - a` — по убыванию.
Без компаратора `sort()` превращает каждый элемент в **строку** и сравнивает их посимвольно, поэтому `10` идёт раньше `9`: ведь `"1"` меньше `"9"`:
```javascript
console.log([10, 9, 1].sort());
// prints [ 1, 10, 9 ]
console.log([10, 9, 1].sort((a, b) => a - b));
// prints [ 1, 9, 10 ]
```
Так как `sort` изменяет массив, сортируй копию, когда нужен и исходный порядок: `[...numbers].sort(...)`. Для строк используй компаратор `(a, b) => a.localeCompare(b)`, который упорядочивает текст по алфавиту.

---

Компаратор может смотреть на любую часть элементов, поэтому массив объектов сортируется по одному из их свойств простым сравнением этого свойства:
```javascript
const items = [{ name: "b", size: 3 }, { name: "a", size: 1 }];
const bySize = [...items].sort((x, y) => x.size - y.size);
console.log(bySize.map((item) => item.name));
// prints [ 'a', 'b' ]
```
Сортировка копии оставляет `items` в исходном порядке.

---

Функция высшего порядка может и **возвращать** функцию. Возвращённая функция помнит переменные того места, где она была создана, даже после завершения внешней функции: это называется **замыканием**.
```javascript
function makeMultiplier(factor) {
  return function (n) {
    return n * factor;
  };
}
const triple = makeMultiplier(3);
console.log(triple(5));
// prints 15
console.log(makeMultiplier(10)(5));
// prints 50
```
Каждый вызов `makeMultiplier` создаёт новую функцию со своим `factor`. Так из одного шаблона строится семейство похожих функций. То же самое можно записать стрелочными функциями: `const makeMultiplier = (factor) => (n) => n * factor;`.

---

Замыкание хранит **живую** связь с переменной, а не копию её значения. Когда в одном вызове создаётся несколько функций, они делят одну и ту же переменную, и любое изменение через одну видно остальным:
```javascript
function makeCounter() {
  let count = 0;
  return {
    increment: () => { count += 1; },
    value: () => count,
  };
}
const counter = makeCounter();
counter.increment();
counter.increment();
console.log(counter.value());
// prints 2
```
Никто не может прочитать или сбросить `count` снаружи иначе как через эти две функции: переменная **приватная**. Второй вызов `makeCounter()` создаёт совершенно отдельный `count`.

---

Так как функции — это значения, можно написать функцию высшего порядка, которая **объединяет** две функции в новую. `compose(f, g)` возвращает функцию, применяющую сначала `g`, а затем `f` к результату, как в математической записи *f(g(x))*:
```javascript
const compose = (f, g) => (x) => f(g(x));
const trim = (s) => s.trim();
const shout = (s) => s.toUpperCase();
const clean = compose(shout, trim);
console.log(clean("  hi  "));
// prints HI
```
Порядок важен: `compose(f, g)` сначала выполняет `g`, потом `f`. Построение программ из склеенных таким образом маленьких функций называется **композицией функций**.

---

Функция, возвращающая функцию, — это ещё и естественный способ **приспособить** колбэк. Допустим, у тебя есть предикат, а для `filter` нужен противоположный: вместо того чтобы переписывать его, оберни его:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
Общая функция `not(predicate)` сделала бы это для любого предиката: она возвращает новую функцию, которая вызывает `predicate` с тем же аргументом и переворачивает результат с помощью `!`. Предикаты для `filter`, `find`, `some` и `every` получают элемент первым аргументом, поэтому обёртке нужно передать дальше только это значение.

---

Аккумулятор `reduce` не обязан быть числом: это может быть строка, массив или объект. Начав с пустого объекта `{}`, можно за один проход что-то посчитать или сгруппировать. Не забудь **вернуть аккумулятор** из колбэка, иначе следующий шаг получит `undefined`:
```javascript
const votes = ["yes", "no", "yes"];
const tally = votes.reduce((acc, vote) => {
  acc[vote] = (acc[vote] ?? 0) + 1;
  return acc;
}, {});
console.log(tally);
// prints { yes: 2, no: 1 }
```
`acc[vote] ?? 0` читает текущий счётчик или `0`, когда такого ключа ещё нет.

---

У каждой функции есть метод `bind`, который возвращает **новую** функцию с заранее зафиксированными значениями. Его первый аргумент становится `this` новой функции; остальные аргументы ставятся перед теми, с которыми новую функцию вызовут (**частичное применение**):
```javascript
function multiply(a, b) {
  return a * b;
}
const double = multiply.bind(null, 2);
console.log(double(21));
// prints 42
```
Фиксация `this` важна для методов. Когда метод скопирован из своего объекта и вызывается сам по себе, `this` больше не ссылается на объект, поэтому `this.name` становится `undefined`. `bind` привязывает его к объекту:
```javascript
const user = {
  name: "Ana",
  hello() { return `Hi ${this.name}`; },
};
const loose = user.hello;
console.log(loose());
// prints Hi undefined
const bound = user.hello.bind(user);
console.log(bound());
// prints Hi Ana
```
Исходная функция никогда не меняется: `bind` всегда создаёт новую, чьё `name` — это исходное имя с приставкой `bound `.

---

Настоящие программы объединяют эти методы в **конвейер**: отфильтруй нужные элементы, преобразуй их в нужные значения и сверни их в результат. Хранение промежуточных массивов в константах делает каждый шаг читаемым и позволяет использовать их повторно:
```javascript
const adults = people.filter((p) => p.age >= 18);
const names = adults.map((p) => p.name);
const totalAge = adults.reduce((sum, p) => sum + p.age, 0);
```
`names.join(", ")` превращает массив строк в одну строку, элементы которой разделены запятой и пробелом.

---

Замыкания позволяют возвращённой функции хранить **приватное состояние** между вызовами. Классический помощник, построенный так, — `once(fn)`: он возвращает функцию, которая выполняет `fn` только при первом вызове, запоминает результат и при каждом следующем вызове возвращает тот же результат, не запуская `fn` снова:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
Обёртке нужны две приватные переменные: запускалась ли уже `fn` и сохранённый результат. Обе живут в замыкании и невидимы снаружи. Чтобы передать в `fn` все аргументы обёртки, объяви обёртку с остаточным параметром `(...args)` и вызови `fn(...args)`.

---

Всё соединяется в `groupBy(items, keyFn)`: функции высшего порядка, которая получает колбэк, определяющий **ключ группы** каждого элемента, и возвращает объект, сопоставляющий каждому ключу массив элементов с этим ключом. `reduce` с объектом-аккумулятором делает всю работу:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Для каждого элемента вычисли ключ, создай массив для этого ключа, если его ещё нет (`acc[key] ?? []`), добавь элемент и верни аккумулятор. Так как `keyFn` выбирает вызывающий код, одна и та же функция группирует слова по первой букве, людей по городу или числа по чётности.
