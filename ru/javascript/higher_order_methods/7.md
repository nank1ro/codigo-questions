# --description--

Компаратор может смотреть на любую часть элементов, поэтому массив объектов сортируется по одному из их свойств простым сравнением этого свойства:
```javascript
const items = [{ name: "b", size: 3 }, { name: "a", size: 1 }];
const bySize = [...items].sort((x, y) => x.size - y.size);
console.log(bySize.map((item) => item.name));
// prints [ 'a', 'b' ]
```
Сортировка копии оставляет `items` в исходном порядке.
