# --description--

Функция высшего порядка может и **возвращать** функцию. Возвращённая функция помнит переменные того места, где она была создана, даже после завершения внешней функции: это называется **замыканием**.
```javascript
function makeMultiplier(factor) {
  return function (n) {
    return n * factor;
  };
}
const triple = makeMultiplier(3);
console.log(triple(5));
// prints 15
console.log(makeMultiplier(10)(5));
// prints 50
```
Каждый вызов `makeMultiplier` создаёт новую функцию со своим `factor`. Так из одного шаблона строится семейство похожих функций. То же самое можно записать стрелочными функциями: `const makeMultiplier = (factor) => (n) => n * factor;`.

# --asserts--

`makeGreeter("Hello")("Ana")` должна вернуть `"Hello, Ana!"`.

```javascript
tryCatch(makeGreeter("Hello")("Ana") === "Hello, Ana!");
```

`makeGreeter` должна возвращать функцию.

```javascript
tryCatch(typeof makeGreeter("Yo") === "function");
```

Возвращённую функцию можно использовать повторно с разными именами.

```javascript
tryCatch((() => { const hi = makeGreeter("Hi"); return hi("Bo") === "Hi, Bo!" && hi("Cy") === "Hi, Cy!"; })());
```

Каждый greeter должен хранить своё собственное приветствие.

```javascript
tryCatch((() => { const hello = makeGreeter("Hello"); const bye = makeGreeter("Bye"); return hello("Ana") === "Hello, Ana!" && bye("Ana") === "Bye, Ana!"; })());
```
