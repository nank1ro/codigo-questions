# --description--

Замыкания позволяют возвращённой функции хранить **приватное состояние** между вызовами. Классический помощник, построенный так, — `once(fn)`: он возвращает функцию, которая выполняет `fn` только при первом вызове, запоминает результат и при каждом следующем вызове возвращает тот же результат, не запуская `fn` снова:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
Обёртке нужны две приватные переменные: запускалась ли уже `fn` и сохранённый результат. Обе живут в замыкании и невидимы снаружи. Чтобы передать в `fn` все аргументы обёртки, объяви обёртку с остаточным параметром `(...args)` и вызови `fn(...args)`.

# --asserts--

Обёрнутая функция должна выполнить `fn` только один раз и дальше возвращать её результат.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

Аргументы первого вызова должны передаваться в `fn`: `once((a, b) => a + b)(2, 3)` должна вернуть `5`.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

Последующие вызовы должны возвращать сохранённый результат даже с другими аргументами.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` не должна запускаться снова, даже когда её результат — `undefined`.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

Две обёртки одной и той же функции должны быть независимы.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` должна возвращать функцию.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
