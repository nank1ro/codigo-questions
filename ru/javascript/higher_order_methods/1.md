# --description--

В JavaScript функция — это **значение**: её можно сохранить в переменной, положить в массив и передать другой функции как аргумент. Функция, которая принимает функцию как аргумент или возвращает функцию, называется **функцией высшего порядка**. Переданную функцию называют **колбэком**, потому что получатель *вызывает её обратно*, когда она нужна:
```javascript
function shout(text) {
  return text.toUpperCase() + "!";
}
function twice(fn, value) {
  return fn(fn(value));
}
console.log(twice(shout, "hi"));
// prints HI!!
```
Обрати внимание, что `shout` передаётся **без скобок**: `twice(shout, "hi")` передаёт саму функцию, тогда как `twice(shout("hi"), "hi")` сначала вызвал бы `shout` и передал его результат, строку `"HI!"`, которую вызвать нельзя.
