# --description--

Функция, возвращающая функцию, — это ещё и естественный способ **приспособить** колбэк. Допустим, у тебя есть предикат, а для `filter` нужен противоположный: вместо того чтобы переписывать его, оберни его:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
Общая функция `not(predicate)` сделала бы это для любого предиката: она возвращает новую функцию, которая вызывает `predicate` с тем же аргументом и переворачивает результат с помощью `!`. Предикаты для `filter`, `find`, `some` и `every` получают элемент первым аргументом, поэтому обёртке нужно передать дальше только это значение.

# --asserts--

`not((n) => n % 2 === 0)(3)` должна вернуть `true`.

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)` должна вернуть `false`.

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))` должно вернуть `[1, 3]`.

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))` должно вернуть `["a", "b"]`.

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

Двойное отрицание должно вернуть исходный ответ: `not(not(isEven))(4)` должна вернуть `true`.

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not` должна возвращать функцию.

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
