# --description--

Функции высшего порядка позволяют отделить *что делать с каждым элементом* от *того, как обходить элементы*. Обход пишется один раз, а колбэк решает всё остальное:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
Колбэк получает по одному элементу за раз. Это может быть стрелочная функция, написанная на месте, как выше, или любая функция, сохранённая в переменной. Именно так внутри работают встроенные методы массивов, с которыми ты познакомишься дальше.

# --asserts--

`transform([1, 2, 3], (n) => n * 2)` должна вернуть `[2, 4, 6]`.

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())` должна вернуть `["A", "B"]`.

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)` должна вернуть пустой массив.

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

Результат должен быть новым массивом, а исходный массив не должен изменяться.

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

Функция не должна использовать `map`.

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

# --solutions--

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
