# --description--

Три метода отвечают на вопросы о массиве с помощью предиката:
- `find(predicate)` возвращает **первый** элемент, для которого предикат равен `true`, или `undefined`, если такого нет
- `some(predicate)` возвращает `true`, если предикату удовлетворяет **хотя бы один** элемент
- `every(predicate)` возвращает `true`, если ему удовлетворяют **все** элементы (и `true` для пустого массива)
```javascript
const scores = [72, 45, 90];
console.log(scores.find((s) => s < 60));
// prints 45
console.log(scores.some((s) => s === 90), scores.every((s) => s >= 60));
// prints true false
```
Все три останавливаются, как только ответ известен, поэтому они никогда не просматривают больше элементов, чем нужно.

```javascript
function report(scores) {
  if (scores.every((s) => s >= 60)) {
    return "all passed";
  }
  return `first failing: ${scores.find((s) => s < 60)}`;
}
```
