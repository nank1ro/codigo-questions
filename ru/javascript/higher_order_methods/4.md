# --description--

Ещё два метода высшего порядка покрывают большинство повседневных задач.
`filter(callback)` возвращает новый массив только с теми элементами, для которых колбэк вернул `true`; колбэк, который так отвечает «да» или «нет», называется **предикатом**.
`reduce(callback, initialValue)` сводит все элементы к одному значению: колбэк получает **аккумулятор** (результат на текущий момент) и текущий элемент и возвращает новый аккумулятор. Второй аргумент `reduce` — начальный аккумулятор:
```javascript
const numbers = [3, 8, 5];
console.log(numbers.filter((n) => n > 4));
// prints [ 8, 5 ]
console.log(numbers.reduce((sum, n) => sum + n, 0));
// prints 16
```
Так как `filter` и `map` возвращают массивы, их можно объединять в цепочку и завершать её `reduce`: `numbers.filter(...).map(...).reduce(...)`.
