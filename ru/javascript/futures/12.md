# --description--

`Promise.all` работает с массивом любой длины, включая пустой: ожидание `Promise.all([])` сразу возвращает пустой массив. Это позволяет безопасно передавать список, построенный во время выполнения, без особого случая для «нечего ждать».
```javascript
const values = await Promise.all(items);
console.log(values.length === items.length);
// prints true
```
Возвращаемый массив всегда содержит ровно столько же элементов, сколько было в полученном массиве, на тех же позициях, поэтому его можно перебирать, как любой другой массив.

# --asserts--

`await sumAll([])` должно быть `0`.

```javascript
(async () => {
  tryCatch((await sumAll([])) === 0);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)])` должно быть `6`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)];
  tryCatch((await sumAll(promises)) === 6);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(-4), Promise.resolve(4)])` должно быть `0`.

```javascript
(async () => {
  const promises = [Promise.resolve(-4), Promise.resolve(4)];
  tryCatch((await sumAll(promises)) === 0);
})().catch(() => tryCatch(false));
```

`sumAll` должна также работать с промисами, которые выполняются разное время.

```javascript
(async () => {
  const later = (n, ms) => new Promise((resolve) => setTimeout(() => resolve(n), ms));
  tryCatch((await sumAll([later(10, 30), later(5, 5)])) === 15);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function sumAll(promises) {
  const values = await Promise.all(promises);
  let total = 0;
  for (const value of values) {
    total += value;
  }
  return total;
}
```
