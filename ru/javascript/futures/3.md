# --description--

Когда значение действительно приходит позже, вы создаёте промис сами с помощью **`new Promise`**. Он принимает одну функцию, которая получает колбэк **`resolve`**: вызовите `resolve(value)`, когда значение готово, и промис будет выполнен с ним.
```javascript
const soon = new Promise((resolve) => {
  setTimeout(() => resolve("done"), 1000);
});
```
`setTimeout(callback, ms)` планирует запуск `callback` через `ms` миллисекунд и возвращается сразу, так что в это время ничего не блокируется.

Функция, переданная в `new Promise`, выполняется сразу, но промис остаётся **в ожидании** (pending), пока не вызван `resolve`. Ожидание через `await` даёт значение:
```javascript
async function main() {
  console.log(await soon);
  // prints done, about one second later
}

main();
```

# --asserts--

`delay(10, "ok")` должна возвращать промис.

```javascript
(async () => {
  tryCatch(delay(10, "ok") instanceof Promise);
})().catch(() => tryCatch(false));
```

`await delay(0, 7)` должно быть `7`.

```javascript
(async () => {
  tryCatch((await delay(0, 7)) === 7);
})().catch(() => tryCatch(false));
```

`await delay(10, "ok")` должно быть `"ok"`.

```javascript
(async () => {
  tryCatch((await delay(10, "ok")) === "ok");
})().catch(() => tryCatch(false));
```

`await delay(60, "x")` должен занять не меньше `50` миллисекунд.

```javascript
(async () => {
  const start = Date.now();
  await delay(60, "x");
  tryCatch(Date.now() - start >= 50);
})().catch(() => tryCatch(false));
```
