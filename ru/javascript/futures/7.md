# --description--

Асинхронная работа тоже может завершиться неудачей. Функция, переданная в `new Promise`, получает второй колбэк, **`reject`**: вызовите `reject(error)`, и промис станет отклонённым вместо выполненного.
```javascript
function readAge(age) {
  return new Promise((resolve, reject) => {
    if (age >= 0) {
      resolve(age);
    } else {
      reject(new Error("negative age"));
    }
  });
}
```
Всегда отклоняйте промис объектом `Error`: он несёт `message` и стек вызовов, чего нет у простой строки.

Отклонение читается с помощью **`.catch(callback)`**, зеркального отражения `.then`. **`Promise.reject(error)`** создаёт уже отклонённый промис, так же как `Promise.resolve` создаёт выполненный:
```javascript
readAge(-1).catch((error) => {
  console.log(error.message);
  // prints negative age
});
```
Вызов и `resolve`, и `reject`, или вызов одного из них дважды, ничего не меняет: учитывается только первый вызов.

# --asserts--

`await checkAge(20)` должно быть `20`.

```javascript
(async () => {
  tryCatch((await checkAge(20)) === 20);
})().catch(() => tryCatch(false));
```

`await checkAge(18)` должно быть `18`, потому что `18` — уже достаточный возраст.

```javascript
(async () => {
  tryCatch((await checkAge(18)) === 18);
})().catch(() => tryCatch(false));
```

Промис `checkAge(10)` должен быть отклонён с сообщением `"too young"`.

```javascript
(async () => {
  let message = "";
  await checkAge(10).catch((error) => { message = error.message; });
  tryCatch(message === "too young");
})().catch(() => tryCatch(false));
```

Промис `checkAge(0)` должен быть отклонён объектом `Error`, а не строкой.

```javascript
(async () => {
  let reason = null;
  await checkAge(0).catch((error) => { reason = error; });
  tryCatch(reason instanceof Error);
})().catch(() => tryCatch(false));
```
