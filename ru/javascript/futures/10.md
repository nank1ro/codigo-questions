# --description--

Частое применение `try` / `catch` вокруг `await` — заменить сбой разумным значением по умолчанию, чтобы вызывающему коду никогда не пришлось иметь дело с ошибкой:
```javascript
async function sizeOf(path) {
  try {
    return await measure(path);
  } catch (error) {
    return 0;
  }
}
```
Сохраняйте `await` перед `measure(path)`, даже если значение возвращается сразу. Без него промис покинет функцию, так и не пройдя через блок `try`, и отклонение минует `catch`.

# --instructions--

Функция `parseLater` возвращает промис, выполненный с числом, записанным в `text`, или отклонённый, когда `text` — не число. Напишите `async` функцию `safeParse`, которая возвращает это число или `-1`, когда `parseLater` завершается неудачей. Используйте `try` и `catch`

```javascript

```

`await safeParse("-7.5")` должно быть `-7.5`.

```javascript
(async () => {
  tryCatch((await safeParse("-7.5")) === -7.5);
})().catch(() => tryCatch(false));
```

`await safeParse("abc")` должно быть `-1`.

```javascript
(async () => {
  tryCatch((await safeParse("abc")) === -1);
})().catch(() => tryCatch(false));
```

Промис `safeParse("oops")` должен быть выполнен, но никогда не отклонён.

```javascript
(async () => {
  let ok = false;
  await safeParse("oops").then(() => { ok = true; }, () => { ok = false; });
  tryCatch(ok);
})().catch(() => tryCatch(false));
```

```javascript
function parseLater(text) {
  return new Promise((resolve, reject) => {
    const value = Number(text);
    if (Number.isNaN(value)) {
      reject(new Error(`not a number: ${text}`));
    } else {
      resolve(value);
    }
  });
}

async function safeParse(text) {
  try {
    return await parseLater(text);
  } catch (error) {
    return -1;
  }
}
```
