# --description--

**`Promise.race(promises)`** завершается, как только завершится **первый** из промисов, и копирует его исход: выполнен с первым значением или отклонён с первой ошибкой. Остальные не отменяются, они продолжают работать, но всё, что они произведут, игнорируется.
```javascript
const winner = await Promise.race([slowServer(), fastServer()]);
```
Типичное применение — дедлайн: соревнуйте реальную работу с промисом, который падает через некоторое время, и вы получите либо результат, либо ошибку таймаута.

Будьте осторожны с пустым массивом: `Promise.race([])` навсегда остаётся в ожидании, потому что нечему его завершить.

# --instructions--

Что выведет этот код?
```javascript
function later(value, ms) {
  return new Promise((resolve) => setTimeout(() => resolve(value), ms));
}

async function main() {
  const winner = await Promise.race([later("slow", 50), later("fast", 10)]);
  console.log(winner);
}

main();
```

- `fast`
- `slow`
- `fast`, а затем `slow`
- `[ 'slow', 'fast' ]`
