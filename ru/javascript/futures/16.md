# --description--

Соединив последние кусочки вместе, получаем небольшой инструмент, который используется почти в каждом реальном приложении: дедлайн. Создайте промис, который отклоняется через `ms` миллисекунд, соревнуйте его с реальной работой, и тот, кто завершится первым, решает исход:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
Возвращать промис из `async` функции можно: промис, который отдаёт функция, следует за ним, поэтому вызывающий код ожидает итоговое значение, а не промис промиса.

# --instructions--

Напишите `async` функцию `withTimeout`, которая принимает промис и количество миллисекунд `ms`, и возвращает исход промиса, если он завершится в пределах `ms`, или отклоняется с `new Error("timeout")` в противном случае. Используйте `Promise.race`

# --asserts--

Промис, который уже выполнен, должен отдать своё значение.

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

Промис, который отклонён до истечения срока, должен сохранить свою собственную ошибку.

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

Промис, который достаточно быстрый, должен отдать своё значение, а не промис.

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

Промис, который слишком медленный, должен быть отклонён с сообщением `"timeout"`.

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```

```javascript
async function withTimeout(promise, ms) {
  const timer = new Promise((resolve, reject) => {
    setTimeout(() => reject(new Error("timeout")), ms);
  });
  return Promise.race([promise, timer]);
}
```
