# --description--

`.then`, `.catch` и `.finally` — звенья одной цепочки. Отклонение перескакивает каждый `.then`, пока не встретит `.catch`; как только колбэк `.catch` возвращает значение, цепочка снова становится выполненной и продолжает работать как обычно.

**`.finally(callback)`** выполняется, когда цепочка завершается, независимо от того, была ли она выполнена или отклонена. Его колбэк не принимает аргументов, и его возвращаемое значение игнорируется, поэтому значение продолжает течь к следующему `.then`. Это место для очистки, например для скрытия спиннера:
```javascript
Promise.reject(new Error("no network"))
  .then((value) => `ok: ${value}`)
  .catch((error) => `error: ${error.message}`)
  .finally(() => console.log("cleanup"))
  .then((message) => console.log(message));
// prints cleanup, then error: no network
```
