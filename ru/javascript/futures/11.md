# --description--

Когда нужны несколько результатов, ожидание их одного за другим тратит время впустую: каждый начинается только тогда, когда закончился предыдущий. **`Promise.all(promises)`** принимает массив уже запущенных промисов и возвращает один промис, выполненный с массивом всех их значений:
```javascript
const results = await Promise.all([fetchUser(), fetchOrders()]);
```
Два правила стоит запомнить:

- значения приходят **в порядке массива**, а не в порядке их завершения;
- если любой промис отклонён, промис, возвращённый `Promise.all`, немедленно отклоняется с этой первой ошибкой, а остальные значения теряются.
