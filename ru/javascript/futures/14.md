# --description--

`Promise.all` сдаётся, как только один из промисов отклонён. Когда вам всё равно нужны все результаты, используйте **`Promise.allSettled(promises)`**: он никогда не отклоняется, а выполняется с одним небольшим объектом на каждый промис, в том же порядке:

- `{ status: "fulfilled", value: ... }` для тех, что завершились успешно;
- `{ status: "rejected", reason: ... }` для тех, что завершились ошибкой.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
Читайте `value`, только когда `status` равен `"fulfilled"`, и `reason`, только когда он равен `"rejected"`: другое свойство просто отсутствует.

# --asserts--

`await countFulfilled([])` должно быть `0`.

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` должно быть `2`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Если из трёх промисов один отклонён, ответ должен быть `2`.

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Когда все промисы отклонены, ответ должен быть `0`, а `countFulfilled` не должна быть отклонена.

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
