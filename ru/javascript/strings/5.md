# --description--

Метод `indexOf()` возвращает индекс, по которому фрагмент текста **впервые** встречается в строке.
Если текст не найден, он возвращает `-1`:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
