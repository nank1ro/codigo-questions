# --description--

Строки **неизменяемы**: после создания строку никогда нельзя изменить.
Присваивание по индексу ничего не делает, и каждый строковый метод возвращает **новую** строку вместо изменения исходной:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
Чтобы сохранить результат, присвойте его обратно переменной:
```javascript
word = word.toUpperCase();
```

# --instructions--

Первый `console.log` выводит `hello`, потому что `toUpperCase()` не изменил `word`. Дополните код так, чтобы второй `console.log` выводил `HELLO`
