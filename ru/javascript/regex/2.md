# --description--

Шаблоны становятся полезными, когда описывают *тип* символа, а не один конкретный символ. Несколько **escape-последовательностей** покрывают большинство потребностей:
- `\d` любая цифра, от `0` до `9`
- `\w` любой словесный символ: буква, цифра или `_`
- `\s` любой пробельный символ: пробел, табуляция, перевод строки

```javascript
console.log(/\d/.test("room 12"));
// prints true
console.log(/\d/.test("lobby"));
// prints false
```
**Квантификатор** говорит, сколько раз может повториться предыдущая часть. Самый распространённый — `+`, означающий «один или больше»:
```javascript
console.log(/\d+/.test("42"));
// prints true
```
Поэтому `/\d/` соответствует одной цифре, а `/\d+/` — последовательности цифр. Для обычного `test` оба ведут себя одинаково, потому что обоим достаточно наличия одной цифры.
