# --description--

Чтобы переписать **каждое** совпадение вместо первого, у вас есть два варианта:
```javascript
console.log("a1 b2".replace(/\d/g, "#"));
// prints a# b#
console.log("a1 b2".replaceAll(/\d/g, "#"));
// prints a# b#
```
**`replaceAll`** — понятнее из двух, и он также принимает обычную строку в качестве шаблона. Когда вы даёте ему regex, этот regex **обязан** нести флаг `g`, иначе он выбрасывает `TypeError`; именно это останавливает тихую ошибку — написать `replace` и починить только первое совпадение.
