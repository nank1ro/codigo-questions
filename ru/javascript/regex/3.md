# --description--

Литерал вроде `/\d+/` зафиксирован в момент написания. Когда шаблон должен быть **построен во время выполнения**, используйте **конструктор `RegExp`**, который принимает шаблон в виде строки:
```javascript
const word = "cat";
const pattern = new RegExp(word);
console.log(pattern.test("the cat sleeps"));
// prints true
```
Есть одна ловушка. Внутри строки обратная косая черта начинает escape-последовательность для *строки*, поэтому она исчезает до того, как regex её увидит. Чтобы поместить настоящую обратную косую черту в шаблон, её нужно удвоить:
```javascript
const digits = new RegExp("\\d+");
// the same pattern as /\d+/
```
Запись `new RegExp("\d+")` вместо этого даёт шаблон `/d+/`, который соответствует букве `d`, а не цифре.

Предпочитайте литерал, когда шаблон известен уже при написании кода; он короче и не требует удвоенных обратных косых черт.
