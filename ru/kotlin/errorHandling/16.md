# --description--

То, где находится `try`, определяет, сколько работы уничтожает одно плохое значение. Оберните **весь цикл** — и первый сбой отбрасывает остаток партии; оберните **тело** — и теряется только этот один элемент:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // пропускаем это значение
    }
}
println(total) // 8
```
Это естественно сочетается с проверяющей функцией, которая выбрасывает исключение: функция формулирует одно правило и отказывает всему, что его нарушает, а цикл решает, что отказ стоит только одного элемента.

# --instructions--

Напишите две функции.

`validate(text: String): Int` должна вернуть число, содержащееся в `text`, или выбросить `IllegalArgumentException` с сообщением `not a number: `, за которым следует текст.

`sumValid(values: List<String>): Int` должна суммировать значения, которые `validate` принимает, пропуская те, что заставляют её выбросить исключение.

Пример вызова функции:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// выводит 4
```

`validate("7")` должен вернуть `7`

```kotlin

```

`validate("x")` должен выбросить `IllegalArgumentException` с сообщением `not a number: x`

```kotlin
    var message = ""
    try { validate("x") } catch (e: IllegalArgumentException) { message = e.message ?: "" }
    tryCatch(message == "not a number: x")
```

`sumValid(listOf("1", "2", "3"))` должен вернуть `6`

```kotlin
    tryCatch(sumValid(listOf("1", "2", "3")) == 6)
```

Одно плохое значение не должно останавливать остальные

```kotlin
    tryCatch(sumValid(listOf("1", "x", "3")) == 4)
```

`sumValid(listOf("a", "b"))` должен вернуть `0`

```kotlin
    tryCatch(sumValid(listOf("a", "b")) == 0)
```

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // пропускаем это значение
        }
    }
    return total
}
```
