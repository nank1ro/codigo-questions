# --description--

`uppercase()` возвращает копию строки, в которой все буквы записаны заглавными, `lowercase()` делает обратное.
Исходная строка не изменяется:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
