# --description--

`split` разбивает строку на `List` частей вокруг разделителя, а `joinToString`, наоборот, склеивает элементы коллекции в одну строку с выбранным вами разделителем:
```kotlin
val csv = "a,b,c"
val parts = csv.split(",")
println(parts)                  // [a, b, c]
println(parts.joinToString("/")) // a/b/c
```
