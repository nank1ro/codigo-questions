# --description--

`String` — это последовательность символов, записанная между двойными кавычками.
Свойство `length` показывает, сколько символов содержит строка, включая пробелы:
```kotlin
val greeting = "Hello world"
println(greeting.length) // 11
println("".length)       // 0
```
