# --description--

`forEach` выполняет лямбду по одному разу для каждого элемента и ничего не возвращает. Это альтернатива циклу `for` в стиле высшего порядка, и она используется для побочных эффектов, например для вывода:
```kotlin
listOf("a", "b").forEach { println(it) }
```
`forEachIndexed` даёт также позицию каждого элемента. У его лямбды **два** параметра, поэтому их нужно именовать: `it` существует только для лямбд ровно с одним параметром.
```kotlin
listOf("a", "b").forEachIndexed { index, letter ->
    println("$index: $letter") // 0: a, затем 1: b
}
```
