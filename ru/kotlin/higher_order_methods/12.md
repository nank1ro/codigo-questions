# --description--

Форма лямбды должна соответствовать тому, что ожидает метод:
- методы, работающие с одним элементом за раз (`map`, `filter`, `sortedBy`, `groupBy`...), принимают лямбду с **одним параметром**, где доступен `it`
- `reduce`, `fold`, `forEachIndexed` и `zip` с лямбдой передают **два** значения, поэтому параметры нужно явно именовать через `a, b ->`
```kotlin
val numbers = listOf(1, 2, 3)
numbers.map { it * 2 }                  // ок: один параметр, it доступен
numbers.reduce { acc, n -> acc + n }    // ок: два параметра, именованные
numbers.reduce { it + 1 }               // ошибка: it не существует при двух параметрах
```
Именовать параметры разрешено всегда, даже когда он один: `numbers.map { n -> n * 2 }`.

# --instructions--

Какую лямбду можно передать в `reduce` для `List<Int>`, чтобы сложить все элементы?

# --answers--

- `{ acc, n -> acc + n }`
- `{ it + it }`
- `{ acc -> acc + it }`
- `{ acc, n => acc + n }`
