# --description--

`Map` можно обрабатывать как список записей: `filter` и `map` работают прямо с map и получают каждую запись с `.key` и `.value`. `filter` на map возвращает map, а `map` возвращает список. Методы сортировки, такие как `sortedBy`, для map не определены: сначала перейдите к `scores.entries`, коллекции записей:
```kotlin
val scores = mapOf("Ann" to 90, "Bob" to 72)
println(scores.filter { it.value > 80 })              // {Ann=90}
println(scores.entries.sortedBy { it.value }.map { it.key }) // [Bob, Ann]
```
`scores.entries` — это множество всех записей; `scores.keys` и `scores.values` дают только одну из сторон.

# --instructions--

Напишите функцию `topScorers(scores: Map<String, Int>, n: Int): List<String>`, которая, соединяя в цепочку `sortedByDescending`, `take` и `map`, возвращает имена `n` человек с наибольшим результатом, от большего к меньшему. Если `n` больше размера map, верните все имена.

Пример: `topScorers(mapOf("Ann" to 90, "Bob" to 72, "Cy" to 85), 2)` возвращает `[Ann, Cy]`.

```kotlin
fun topScorers(scores: Map<String, Int>, n: Int): List<String> {
    return scores.entries.sortedByDescending { it.value }.take(n).map { it.key }
}
```
