# --description--

В цепочке тип `it` меняется на каждом шаге: после `filter` на `List<String>` у вас по-прежнему строки, но после `map { it.length }` у вас `List<Int>`, поэтому следующая лямбда видит числа.
```kotlin
val words = listOf("kiwi", "fig")
println(words.map { it.length }.filter { it > 3 }) // [4]
```
Каждый шаг возвращает **новый** список и никогда не трогает предыдущий, поэтому цепочку можно разбить на именованные промежуточные значения, не меняя результат.
