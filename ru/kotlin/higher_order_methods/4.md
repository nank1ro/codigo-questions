# --description--

`reduce` объединяет все элементы в одно значение. Его лямбда принимает два параметра: **аккумулятор** (результат на текущий момент) и следующий элемент. Он начинает с первого элемента в качестве аккумулятора и выполняет лямбду для каждого оставшегося элемента:
```kotlin
val numbers = listOf(1, 2, 3, 4)
println(numbers.reduce { acc, n -> acc + n }) // 10
```
`reduce` бросает исключение на пустом списке, потому что нет первого элемента, с которого можно начать. `fold` решает эту проблему: вы передаёте **начальное значение** аккумулятора аргументом, и лямбда выполняется для каждого элемента, включая первый:
```kotlin
println(numbers.fold(0) { acc, n -> acc + n })   // 10
println(listOf<Int>().fold(0) { acc, n -> acc + n }) // 0
```
С `fold` аккумулятор может даже иметь тип, отличный от типа элементов, например при построении `String` из списка чисел.
