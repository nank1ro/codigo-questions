# --description--

Методы агрегации превращают всю коллекцию в одно значение:
- `sum()` складывает список чисел, а `sumOf` складывает значение, которое лямбда вычисляет для каждого элемента
- `maxByOrNull` и `minByOrNull` возвращают **элемент**, для которого лямбда даёт наибольшее или наименьшее значение, или `null` на пустом списке
```kotlin
val words = listOf("fig", "banana", "kiwi")
println(words.sumOf { it.length })      // 13
println(words.minByOrNull { it.length }) // fig
println(listOf(1, 2, 3).sum())           // 6
```
Обратите внимание на отличие от `maxOf { it.length }`, который возвращает наибольшее **значение** (`6`), а не элемент, который его дал.
