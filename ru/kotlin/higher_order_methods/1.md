# --description--

**Метод высшего порядка** — это метод, который принимает функцию в качестве аргумента. Коллекции Kotlin предлагают их множество, и передаваемая функция обычно является **лямбдой**: маленькой анонимной функцией, записанной в фигурных скобках.
`map` — самый распространённый из них: он вызывает лямбду для каждого элемента и возвращает **новый список** с результатами, оставляя исходный нетронутым:
```kotlin
val numbers = listOf(1, 2, 3)
val doubled = numbers.map { it * 2 }
println(doubled) // [2, 4, 6]
println(numbers) // [1, 2, 3]
```
Когда у лямбды один параметр, объявлять его не нужно: Kotlin называет его `it`. Лямбда записывается после имени метода, за круглыми скобками, которые можно опустить, если лямбда — единственный аргумент. Это синтаксис **trailing lambda**, и он используется в каждом упражнении этой темы.
