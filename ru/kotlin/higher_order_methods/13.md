# --description--

Методы высшего порядка можно **соединять в цепочку**: каждый возвращает новую коллекцию, с которой работает следующий, поэтому целое вычисление читается как конвейер слева направо:
```kotlin
val words = listOf("kiwi", "fig", "banana", "date")
println(words.filter { it.length == 4 }.map { it.uppercase() }.sorted()) // [DATE, KIWI]
```
У map тоже есть методы высшего порядка. `mapValues` сохраняет ключи и заменяет каждое значение результатом лямбды, которая получает **запись** с `.key` и `.value`:
```kotlin
val byLength = words.groupBy { it.length }      // {4=[kiwi, date], 3=[fig], 6=[banana]}
println(byLength.mapValues { it.value.size })   // {4=2, 3=1, 6=1}
```

# --instructions--

Напишите функцию `wordCounts(words: List<String>): Map<String, Int>`, которая, соединяя в цепочку `groupBy` и `mapValues`, возвращает, сколько раз каждое слово встречается в `words`.

Пример: `wordCounts(listOf("a", "b", "a"))` возвращает `{a=2, b=1}`.

fun wordCounts(words: List<String>): Map<String, Int> {

}
