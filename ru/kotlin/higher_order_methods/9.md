# --description--

`groupBy` разбивает коллекцию в `Map`: лямбда вычисляет **ключ** каждого элемента, и каждому ключу сопоставляется список элементов, которые его дали, в их исходном порядке:
```kotlin
val words = listOf("fig", "kiwi", "pear")
val byLength = words.groupBy { it.length }
println(byLength)    // {3=[fig], 4=[kiwi, pear]}
println(byLength[4]) // [kiwi, pear]
```
Результат имеет тип `Map<K, List<T>>`, где `K` — тип, возвращаемый лямбдой, а `T` — тип элементов. Ключи идут в том порядке, в котором встретились впервые.
