# --description--

Некоторые методы высшего порядка отвечают на вопрос о коллекции, вместо того чтобы строить новую. Все они принимают предикат:
- `any` возвращает `true`, если ему удовлетворяет **хотя бы один** элемент
- `all` возвращает `true`, если ему удовлетворяет **каждый** элемент
- `none` возвращает `true`, если ему не удовлетворяет **ни один** элемент
- `count` возвращает, **сколько** элементов ему удовлетворяют
```kotlin
val numbers = listOf(1, 2, 3)
println(numbers.any { it > 2 })   // true
println(numbers.all { it > 2 })   // false
println(numbers.none { it > 2 })  // false
println(numbers.count { it > 1 }) // 2
```
На пустом списке `any` возвращает `false`, а `all` и `none` возвращают `true`: нет ни одного элемента, который нарушал бы правило.
