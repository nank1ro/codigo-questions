# --description--

`filter` принимает лямбду, возвращающую `Boolean`, которую называют **предикатом**, и возвращает новый список только с теми элементами, для которых предикат равен `true`:
```kotlin
val numbers = listOf(4, -2, 7, 0)
println(numbers.filter { it > 0 }) // [4, 7]
```
Вместо `it` вы можете дать параметру имя, за которым следует стрелка `->`. Именованный параметр делает длинные лямбды понятнее, и он обязателен, когда одна лямбда вложена в другую, потому что внутренний `it` скрывает внешний элемент:
```kotlin
val minLength = 4
val words = listOf("fig", "banana", "kiwi")
println(words.filter { word -> word.length >= minLength }) // [banana, kiwi]
```
