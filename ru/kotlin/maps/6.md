# --description--

Чтобы проверить, существует ли ключ, используйте `containsKey` или оператор `in`; чтобы проверить, существует ли значение, используйте `containsValue`:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
println(ages.containsKey("Alice")) // true
println("Zoe" in ages)             // false
println(ages.containsValue(25))    // true
```

# --asserts--

`isRegistered` должен вернуть `true` для существующего имени пользователя

```kotlin
    val users = mapOf("ann" to "ann@mail.com", "ben" to "ben@mail.com")
    tryCatch(isRegistered(users, "ann") == true)
```

`isRegistered` должен вернуть `false` для отсутствующего имени пользователя

```kotlin
    tryCatch(isRegistered(users, "zoe") == false)
```

`isEmailTaken` должен вернуть `true` для email, уже присутствующего в map

```kotlin
    tryCatch(isEmailTaken(users, "ben@mail.com") == true)
```

`isEmailTaken` должен вернуть `false` для неиспользуемого email

```kotlin
    tryCatch(isEmailTaken(users, "zoe@mail.com") == false)
```

```kotlin
fun isRegistered(users: Map<String, String>, username: String): Boolean {
    return users.containsKey(username)
}

fun isEmailTaken(users: Map<String, String>, email: String): Boolean {
    return users.containsValue(email)
}
```
