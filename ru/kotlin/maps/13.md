# --instructions--

В чём разница между `mapOf` и `mutableMapOf`?

# --answers--

- `mutableMapOf` создаёт map, записи которого можно добавлять, обновлять или удалять после создания, `mapOf` создаёт map только для чтения
- `mapOf` может хранить только ключи типа `String`, `mutableMapOf` принимает любой тип ключа
- `mutableMapOf` допускает дублирующиеся ключи, `mapOf` — нет
- Разницы нет, это два названия одной и той же функции
