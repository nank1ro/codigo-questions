# --description--

Вы можете перебирать map с помощью `for`, деструктурируя каждую запись на ключ и значение:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Скобки `(name, age)` разбивают каждую запись на две переменные. Записи посещаются в порядке вставки.

# --instructions--

Напишите функцию `report(stock: Map<String, Int>): List<String>`, которая возвращает список с одной строкой на каждую запись, отформатированной как `"item: count"`, в том порядке, в котором записи появляются в map.

Пример вызова функции:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
