# --description--

Чтобы функцию можно было пометить как `infix`, она должна быть членом или расширением, принимать ровно один параметр, и у этого параметра не должно быть значения по умолчанию. Всё остальное — ошибка компиляции:
```kotlin
infix fun Int.add(other: Int): Int = this + other          // ok
infix fun add(a: Int, b: Int): Int = a + b                 // error: not a member or extension
infix fun Int.add(a: Int, b: Int): Int = this + a + b      // error: two parameters
```
По приоритету инфиксные вызовы находятся между арифметикой и сравнением: `1 add 2 * 3` — это `1 add 6`, а `1 add 2 == 3` сравнивает результат с `3`.

# --instructions--

Какое объявление позволяет написать `3 add 4`?

# --answers--

- `infix fun Int.add(other: Int): Int = this + other`
- `fun Int.add(other: Int): Int = this + other`
- `infix fun add(a: Int, b: Int): Int = a + b`
- `infix fun Int.add(a: Int, b: Int): Int = this + a + b`
