# --description--

Параметр типа можно использовать в любом месте сигнатуры: как тип возвращаемого значения, как nullable `T?` или внутри другого типа. Обобщённое расширение, которое может ничего не найти, возвращает `T?`, как встроенная `firstOrNull()`:
```kotlin
fun <T> List<T>.lastOrDefault(default: T): T {
    return if (isEmpty()) default else this[size - 1]
}
println(listOf(1, 2).lastOrDefault(0))          // 2
println(emptyList<String>().lastOrDefault("-")) // -
```
Внутри функции можно использовать `size`, `isEmpty()` и индексацию точно так же, как у любого списка, потому что получатель — это `List<T>`.
