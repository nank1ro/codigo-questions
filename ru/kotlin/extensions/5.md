# --description--

Кроме функций можно добавить **свойство-расширение**. Оно объявляется через `val`, тип получателя, точку и имя, после которых идёт `get()`, вычисляющий значение при каждом чтении свойства:
```kotlin
val String.wordCount: Int
    get() = split(" ").size

println("Kotlin is fun".wordCount) // 3
```
Свойство-расширение ничего не может хранить: у него нет поля хранения, поэтому инициализатор вроде `val String.label = "text"` — ошибка компиляции. Оно может только вычислять значение из получателя.
Свойства-расширения нельзя объявлять внутри функции (локальные свойства-расширения запрещены), в отличие от функций-расширений.
