# --description--

Тип получателя может быть **nullable**. Расширение для `String?` можно вызвать на переменной, которая может содержать `null`, и внутри функции `this` имеет тип `String?`, поэтому случай `null` вы обрабатываете сами, обычно с помощью оператора Элвис `?:`, знакомого по урокам о nullability:
```kotlin
fun String?.orDash(): String {
    return this ?: "-"
}
val name: String? = null
println(name.orDash())  // -
println("Ada".orDash()) // Ada
```
Вызов `name.orDash()` на значении `null` безопасен: `?.` не нужен, потому что сама функция принимает получателя `null`.
