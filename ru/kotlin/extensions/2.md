# --description--

Расширения работают с любым типом, даже с теми, к которым у вас нет исходного кода. `String` приходит из стандартной библиотеки, но вы всё равно можете добавить ему новые функции:
```kotlin
fun String.whisper(): String {
    return this.lowercase() + "..."
}
println("HELLO".whisper()) // hello...
```
Внутри расширения можно опускать `this.` при обращении к другим членам получателя: `lowercase()` сам по себе означает `this.lowercase()`, а `length` — `this.length`.

# --instructions--

Напишите функцию-расширение `shout()` для `String`, которая возвращает текст в верхнем регистре с восклицательным знаком в конце.

Пример: `"hi".shout()` возвращает `"HI!"`.
