# --description--

Можно расширить и **companion object** класса, если класс его объявляет, пусть даже пустым. Тип получателя записывается как `ClassName.Companion`, и расширение затем вызывается на имени класса, как фабричная функция:
```kotlin
class Temperature(val degrees: Int) {
    companion object
}
fun Temperature.Companion.freezing(): Temperature = Temperature(0)

println(Temperature.freezing().degrees) // 0
```
Класс и расширение — оба объявления верхнего уровня, поэтому их нужно писать вне `main`.
