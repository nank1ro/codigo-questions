# --description--

Внутри расширения с nullable-получателем можно также использовать безопасный вызов `this?.`, чтобы обратиться к членам значения только тогда, когда оно не `null`. Стандартная библиотека использует ту же идею в функциях вроде `isNullOrEmpty()`:
```kotlin
fun String?.firstOrQuestion(): Char {
    return this?.firstOrNull() ?: '?'
}
val text: String? = null
println(text.firstOrQuestion())    // ?
println("Kotlin".firstOrQuestion()) // K
```
