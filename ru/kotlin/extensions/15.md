# --description--

Функцию-расширение ровно с **одним** параметром можно пометить как `infix`. Инфиксную функцию можно вызывать без точки и скобок, с получателем слева и аргументом справа, что читается почти как предложение:
```kotlin
infix fun Int.percentOf(total: Int): Int = total * this / 100

println(20 percentOf 50)   // 10
println(20.percentOf(50))  // 10, the normal call still works
```
Kotlin использует это и для некоторых встроенных функций: `1 to "one"` создаёт `Pair`, а `1 until 5` создаёт диапазон.

# --solutions--

```kotlin
infix fun Int.toThe(exponent: Int): Int {
    var result = 1
    repeat(exponent) { result *= this }
    return result
}
```
