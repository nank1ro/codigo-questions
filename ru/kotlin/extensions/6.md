# --description--

Свойства-расширения читаются без скобок, точно так же, как встроенное `length` у `String`. Это естественный выбор, когда значение описывает получателя, а не делает что-то с ним:
```kotlin
val Int.isNegative: Boolean
    get() = this < 0

println((-3).isNegative) // true
println(7.isNegative)    // false
```
Обратите внимание на скобки вокруг `-3`: без них `-3.isNegative` сначала прочитало бы свойство у `3`, а затем попыталось бы поставить минус перед `Boolean`, что не компилируется.
