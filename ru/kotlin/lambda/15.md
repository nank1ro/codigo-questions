# --description--

Функции высшего порядка могут как принимать, так и возвращать функции. Классический пример — **композиция**: создание новой функции, которая запускает одну функцию и передаёт её результат в другую.
```kotlin
fun andThen(first: (Int) -> Int, second: (Int) -> Int): (Int) -> Int {
    return { n -> second(first(n)) }
}
val addOneThenDouble = andThen({ it + 1 }, { it * 2 })
println(addOneThenDouble(3)) // 8
```
Возвращённая лямбда захватывает и `first`, и `second`, поэтому она продолжает работать долго после того, как `andThen` вернулась.

# --instructions--

Напишите функцию `compose(f: (Int) -> Int, g: (Int) -> Int): (Int) -> Int`, которая возвращает лямбду, применяющую `f` к своему аргументу, а затем `g` к результату.

Пример: `compose({ it + 1 }, { it * 2 })(3)` возвращает `8`.
