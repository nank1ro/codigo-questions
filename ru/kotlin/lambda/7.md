# --description--

Лямбды также управляют сортировкой и агрегацией:
- `sortedBy` возвращает новый список, упорядоченный по значению, которое лямбда вычисляет для каждого элемента; `sortedByDescending` делает противоположное
- `reduce` объединяет все элементы в одно значение: лямбда получает накопленный результат на данный момент и следующий элемент
```kotlin
val words = listOf("kiwi", "fig", "banana")
println(words.sortedBy { it.length })          // [fig, kiwi, banana]
println(words.sortedByDescending { it.length }) // [banana, kiwi, fig]

val numbers = listOf(1, 2, 3, 4)
println(numbers.reduce { acc, n -> acc + n })   // 10
```
`reduce` начинает с первого элемента в качестве `acc`, затем запускает лямбду для каждого оставшегося элемента.
