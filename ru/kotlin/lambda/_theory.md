**Лямбда** — это небольшая функция без имени, записанная прямо как выражение в фигурных скобках.
Сначала идут параметры, затем стрелка `->`, затем тело:
```kotlin
val add = { a: Int, b: Int -> a + b }
```
Лямбда — это значение, как любое другое: её можно сохранить в переменной и вызвать позже с круглыми скобками, точно как функцию:
```kotlin
println(add(2, 3)) // 5
```
У лямбды без параметров вообще нет стрелки: `val hello = { println("Hello!") }`.

---

У каждой лямбды есть **функциональный тип**, записываемый как типы параметров в круглых скобках, стрелка и тип возвращаемого значения.
Лямбда `{ a: Int, b: Int -> a + b }` имеет тип `(Int, Int) -> Int`: она принимает два значения `Int` и возвращает `Int`.
Когда вы объявляете функциональный тип у переменной, типы параметров внутри лямбды можно опустить, потому что компилятор уже знает их:
```kotlin
val add: (Int, Int) -> Int = { a, b -> a + b }
val greet: (String) -> Unit = { name -> println("Hi, $name") }
```
Лямбда, которая ничего не возвращает, имеет тип возвращаемого значения `Unit`.

---

Тело лямбды может занимать несколько строк. Ключевого слова `return` нет: значение **последнего выражения** — это то, что возвращает лямбда.
```kotlin
val describe: (Int) -> String = { n ->
    val half = n / 2
    "half of $n is $half" // returned
}
println(describe(10)) // half of 10 is 5
```
Поскольку `if` в Kotlin является выражением, он может быть последней строкой и определять результат:
```kotlin
val parity: (Int) -> String = { n -> if (n % 2 == 0) "even" else "odd" }
```

---

Когда у лямбды ровно **один** параметр, можно не объявлять его: Kotlin сам называет его `it`.
```kotlin
// val double: (Int) -> Int = { n -> n * 2 }
val double: (Int) -> Int = { it * 2 } // same thing
```
`it` существует только тогда, когда параметр не объявлен явно, и только для лямбд с одним параметром.
Он сохраняет компактность коротких лямбд, но для более длинных тел настоящее имя понятнее.

---

Лямбды в основном используются как аргументы других функций. Коллекции предлагают много функций, принимающих лямбду:
- `forEach` запускает лямбду один раз для каждого элемента
- `map` строит новый список из результата лямбды для каждого элемента
```kotlin
val numbers = listOf(1, 2, 3)
val doubled = numbers.map({ it * 2 }) // [2, 4, 6]
```
Когда лямбда является **последним** аргументом, её можно вынести за круглые скобки; когда она — единственный аргумент, круглые скобки можно опустить совсем. Это называется синтаксисом **trailing lambda**, и это обычный способ записи:
```kotlin
val doubled = numbers.map { it * 2 }
doubled.forEach { println(it) }
```

---

Лямбда, возвращающая `Boolean`, называется **предикатом**. Несколько функций коллекций принимают его:
- `filter` оставляет только элементы, для которых предикат равен `true`
- `count` возвращает, сколько элементов ему удовлетворяет
- `any` и `all` сообщают, удовлетворяет ли ему хотя бы один или каждый элемент
```kotlin
val numbers = listOf(1, 2, 3, 4, 5, 6)
println(numbers.filter { it % 2 == 0 }) // [2, 4, 6]
println(numbers.count { it > 4 })        // 2
println(numbers.any { it > 5 })          // true
```
Вызовы можно **объединять в цепочки**: каждая функция возвращает новый список, с которым работает следующая.
```kotlin
println(numbers.filter { it % 2 == 0 }.map { it * 10 }) // [20, 40, 60]
```

---

Лямбды также управляют сортировкой и агрегацией:
- `sortedBy` возвращает новый список, упорядоченный по значению, которое лямбда вычисляет для каждого элемента; `sortedByDescending` делает противоположное
- `reduce` объединяет все элементы в одно значение: лямбда получает накопленный результат на данный момент и следующий элемент
```kotlin
val words = listOf("kiwi", "fig", "banana")
println(words.sortedBy { it.length })          // [fig, kiwi, banana]
println(words.sortedByDescending { it.length }) // [banana, kiwi, fig]

val numbers = listOf(1, 2, 3, 4)
println(numbers.reduce { acc, n -> acc + n })   // 10
```
`reduce` начинает с первого элемента в качестве `acc`, затем запускает лямбду для каждого оставшегося элемента.

---

С `reduce` форма результата зависит от лямбды. Подходит любая операция, объединяющая два значения: сумма, произведение, сохранение большего из двух.
```kotlin
val numbers = listOf(3, 9, 4)
println(numbers.reduce { acc, n -> if (n > acc) n else acc }) // 9
```
Обратите внимание, что `reduce` выбрасывает исключение на пустом списке, потому что нет первого элемента, с которого можно начать.

---

Лямбда может использовать переменные, объявленные вокруг неё, даже после того, как окружающий код завершился. Это называется **замыканием**: лямбда *захватывает* нужные ей переменные.
В отличие от многих других языков, Kotlin позволяет лямбде **изменять** захваченную `var`:
```kotlin
var clicks = 0
val onClick = { clicks++ }
onClick()
onClick()
println(clicks) // 2
```
Каждый вызов `onClick` обновляет ту же переменную `clicks`, которую видит внешний код.

---

Поскольку лямбда — это значение, функция может его **возвращать**. Тип возвращаемого значения — функциональный тип:
```kotlin
fun multiplier(factor: Int): (Int) -> Int {
    return { it * factor }
}
val triple = multiplier(3)
println(triple(5)) // 15
```
Возвращённая лямбда захватывает `factor`, поэтому каждый вызов `multiplier` создаёт другую функцию.
Функции, которые принимают или возвращают другие функции, называются **функциями высшего порядка**.

---

Возвращённая лямбда может захватить `var`, объявленную внутри функции. Эта переменная живёт и после того, как функция вернулась, и только лямбда может до неё добраться: это закрытое состояние.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Каждый вызов `makeGreeter()` объявляет новую `calls`, поэтому два таких приветствия считают независимо.

---

Вы можете писать собственные функции высшего порядка: параметр с функциональным типом принимает любую лямбду такой формы, а внутри функции вы вызываете её как обычную функцию.
```kotlin
fun repeatTwice(text: String, transform: (String) -> String): String {
    return transform(transform(text))
}
println(repeatTwice("a", { it + "!" })) // a!!
println(repeatTwice("a") { it + "!" })  // same, with a trailing lambda
```
Размещение функционального параметра **последним** — именно это делает синтаксис trailing lambda доступным для вызывающих.

---

Когда нужная функция уже существует, нет необходимости оборачивать её в лямбду: **ссылка на функцию** `::имя` превращает именованную функцию в значение с соответствующим функциональным типом.
```kotlin
fun isEven(n: Int) = n % 2 == 0
val numbers = listOf(1, 2, 3, 4)
println(numbers.filter { isEven(it) }) // [2, 4]
println(numbers.filter(::isEven))      // [2, 4], same thing
```
Функции-члены ссылаются через их тип, например `String::uppercase`:
```kotlin
println(listOf("a", "b").map(String::uppercase)) // [A, B]
```

---

**Анонимная функция** — это функция, объявленная с `fun`, но без имени. Это ещё один способ создать функциональное значение:
```kotlin
val square = fun(x: Int): Int {
    return x * x
}
println(square(4)) // 16
```
В отличие от лямбды, она может явно объявить свой тип возвращаемого значения и использует `return`, чтобы получить значение.
Анонимные функции и лямбды взаимозаменяемы: обе можно передать в `map`, `filter` или любую функцию, принимающую функциональный тип.

---

Функции высшего порядка могут как принимать, так и возвращать функции. Классический пример — **композиция**: создание новой функции, которая запускает одну функцию и передаёт её результат в другую.
```kotlin
fun andThen(first: (Int) -> Int, second: (Int) -> Int): (Int) -> Int {
    return { n -> second(first(n)) }
}
val addOneThenDouble = andThen({ it + 1 }, { it * 2 })
println(addOneThenDouble(3)) // 8
```
Возвращённая лямбда захватывает и `first`, и `second`, поэтому она продолжает работать долго после того, как `andThen` вернулась.

---

Некоторые функции принимают **лямбду с приёмником**: внутри лямбды `this` — это конкретный объект, поэтому вы можете вызывать его члены напрямую, не называя его.
`buildString` — распространённый пример: внутри её лямбды `this` — это `StringBuilder`, поэтому `append` можно вызвать, как если бы это была локальная функция:
```kotlin
val text = buildString {
    append("Hello")
    append(", ")
    append("world")
}
println(text) // Hello, world
```
`buildString` возвращает итоговую строку. Это удобная альтернатива конкатенации с `+` в цикле.
