# --description--

С `reduce` форма результата зависит от лямбды. Подходит любая операция, объединяющая два значения: сумма, произведение, сохранение большего из двух.
```kotlin
val numbers = listOf(3, 9, 4)
println(numbers.reduce { acc, n -> if (n > acc) n else acc }) // 9
```
Обратите внимание, что `reduce` выбрасывает исключение на пустом списке, потому что нет первого элемента, с которого можно начать.
