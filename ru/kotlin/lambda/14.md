# --description--

**Анонимная функция** — это функция, объявленная с `fun`, но без имени. Это ещё один способ создать функциональное значение:
```kotlin
val square = fun(x: Int): Int {
    return x * x
}
println(square(4)) // 16
```
В отличие от лямбды, она может явно объявить свой тип возвращаемого значения и использует `return`, чтобы получить значение.
Анонимные функции и лямбды взаимозаменяемы: обе можно передать в `map`, `filter` или любую функцию, принимающую функциональный тип.
