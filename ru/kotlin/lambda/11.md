# --description--

Возвращённая лямбда может захватить `var`, объявленную внутри функции. Эта переменная живёт и после того, как функция вернулась, и только лямбда может до неё добраться: это закрытое состояние.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Каждый вызов `makeGreeter()` объявляет новую `calls`, поэтому два таких приветствия считают независимо.

# --instructions--

Напишите функцию `makeCounter(): () -> Int`, которая возвращает лямбду без параметров. Каждый вызов лямбды увеличивает счётчик, который начинается с `0`, и возвращает новое значение. Счётчики, возвращённые разными вызовами `makeCounter`, должны быть независимыми.

Пример: `val next = makeCounter()`, затем `next()` возвращает `1`, `next()` возвращает `2`.

Первый вызов счётчика должен вернуть `1`

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

Второй вызов того же счётчика должен вернуть `2`

```kotlin
    tryCatch(first() == 2)
```

После трёх вызовов счётчик должен вернуть `3`

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

Два счётчика должны быть независимыми

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
