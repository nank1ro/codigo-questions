# --description--

У каждой лямбды есть **функциональный тип**, записываемый как типы параметров в круглых скобках, стрелка и тип возвращаемого значения.
Лямбда `{ a: Int, b: Int -> a + b }` имеет тип `(Int, Int) -> Int`: она принимает два значения `Int` и возвращает `Int`.
Когда вы объявляете функциональный тип у переменной, типы параметров внутри лямбды можно опустить, потому что компилятор уже знает их:
```kotlin
val add: (Int, Int) -> Int = { a, b -> a + b }
val greet: (String) -> Unit = { name -> println("Hi, $name") }
```
Лямбда, которая ничего не возвращает, имеет тип возвращаемого значения `Unit`.

# --instructions--

Каков функциональный тип лямбды `{ text: String -> text.length }`?
