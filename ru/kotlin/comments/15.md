# --description--

`FIXME` отличается от `TODO`: код уже существует, но известно, что он неверен. Хороший `FIXME` говорит, в чём заключается ошибка, и, когда это возможно, приводит пример, который её демонстрирует, чтобы следующий человек мог быстро её исправить. Как и в случае с `TODO`, удалите маркер, как только ошибка исправлена, но сохраните документирующий комментарий — он по-прежнему верен.

# --instructions--

Исправьте ошибку, описанную комментарием `FIXME` в `average` (добавьте скобки, чтобы сумма вычислялась до деления), а затем удалите комментарий `FIXME`. Документирующий комментарий сохраните


Документирующий комментарий должен быть сохранён

```json
{
  "regex": "Returns the average of",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

```kotlin

```

