# --description--

Чтобы закомментировать несколько строк сразу, оберните их одним блочным комментарием вместо того, чтобы добавлять `//` в каждую строку:
```kotlin
var total = 100
/*
total = total - 30
total = total - 20
*/
println(total) // prints 100
```
Благодаря вложенности это работает даже тогда, когда одна из этих строк уже содержит комментарий `/* */`.
