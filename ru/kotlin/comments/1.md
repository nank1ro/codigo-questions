# --description--

**Комментарий** — это заметка внутри исходного кода, предназначенная для тех, кто его читает. Компилятор полностью игнорирует комментарии, поэтому они никогда не меняют то, что делает программа.

Самый простой комментарий — это **однострочный комментарий**: он начинается с `//` и продолжается до конца строки.
```kotlin
// Greets the user
println("Hello")
```
Используйте комментарии, чтобы объяснить, для чего нужен фрагмент кода или почему он написан именно так.
