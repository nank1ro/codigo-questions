# --description--

Поскольку компилятор полностью удаляет комментарии, добавление или удаление комментария никогда не меняет поведение программы. Выполняется только тот код, который **не** закомментирован.

Поэтому `//` — это быстрый способ выключить строку кода, не удаляя её. Это называется **закомментированием**:
```kotlin
var total = 10
// total = total + 5
println(total) // выводит 10
```
Вторая строка теперь является комментарием, поэтому `total` остаётся равным `10`. Удаление `//` возвращает строку к жизни.

Закомментирование удобно во время экспериментов, но не забывайте убирать за собой: код, который долго остаётся закомментированным, только сбивает с толку того, кто будет читать его после вас.
