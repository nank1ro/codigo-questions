# --description--

После краткого описания документирующий комментарий может описывать параметры и возвращаемое значение с помощью **тегов KDoc**, которые всегда начинаются с `@`:
```kotlin
/**
 * Returns the number of seconds in the given minutes.
 * @param minutes a whole number of minutes, never negative
 * @return [minutes] multiplied by sixty
 */
fun toSeconds(minutes: Int): Int {
    return minutes * 60
}
```
За `@param` следует имя параметра, а затем его описание; для каждого параметра — свой `@param`. `@return` описывает значение, которое возвращает функция. Порядок всегда одинаковый: сначала краткое описание, затем теги `@param`, затем `@return`.
