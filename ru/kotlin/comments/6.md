# --description--

В Java блочный комментарий не может содержать другой блочный комментарий, но в Kotlin они **могут быть вложенными**: каждая `/*` должна быть закрыта своей `*/`, и комментарий заканчивается только тогда, когда закрыт самый внешний.
```kotlin
/* outer /* inner */ still a comment */
println("done")
```
Здесь `still a comment */` является частью внешнего комментария, поэтому выводится только `done`. Именно это позволяет закомментировать целый блок кода, даже если этот блок уже содержит комментарий `/* */`.

/* start

   println("hidden")
