# --description--

Некоторые комментарии следуют соглашениям, которые понимают редакторы. Самые распространённые **маркеры**:
- `// TODO: ...` помечает то, что ещё нужно написать
- `// FIXME: ...` помечает код, который заведомо неверен и должен быть исправлен

```kotlin
val limit = 10
// TODO: read the limit from the settings
```
Для компилятора это обычные комментарии; IntelliJ IDEA собирает их в отдельном окне инструментов, чтобы незавершённую работу было легко найти. `TODO` обычно стоит рядом с заглушкой, которая позволяет коду компилироваться, пока не будет написана настоящая реализация. Завершив работу, замените заглушку и удалите маркер одним изменением, чтобы комментарий никогда не лгал о состоянии кода.

# --asserts--

Комментарий `TODO` должен быть удалён

```json
{
  "regex": "TODO",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

`isEven(4)` должно возвращать `true`

```kotlin
    tryCatch(isEven(4) == true)
```

`isEven(7)` должно возвращать `false`

```kotlin
    tryCatch(isEven(7) == false)
```

`isEven(0)` должно возвращать `true`

```kotlin
    tryCatch(isEven(0) == true)
```
