# --instructions--

Что выведет эта программа?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, потому что `apply` возвращает список, а `run` возвращает результат блока
- `true 2`, потому что `apply` возвращает результат `add`
- `[a, b] [a, b]`, потому что оба возвращают список
- `2 [a, b]`, потому что `apply` возвращает размер, а `run` возвращает список
