# --description--

Внутри блока `let` вы не обязаны называть объект `it`: вы можете дать параметру лямбды имя, что сохраняет код читаемым, когда блоки вложены друг в друга или когда `it` не говорит ничего полезного.
```kotlin
val price: Int? = 12
println(price?.let { amount -> "$amount EUR" }) // 12 EUR
```
То же именование работает для каждой функции области видимости, использующей `it`, то есть для `let` и `also`.

# --instructions--

Напишите функцию `shout(word: String?): String`, которая возвращает `word` в верхнем регистре с `!` на конце, когда он не `null`, и `silence`, когда он равен `null`. Используйте `?.let` и `?:`.

Пример: `shout("hi")` возвращает `HI!`, `shout(null)` возвращает `silence`.

# --asserts--

`shout("hi")` должен вернуть `HI!`

```kotlin
    tryCatch(shout("hi") == "HI!")
```

`shout("Bye")` должен вернуть `BYE!`

```kotlin
    tryCatch(shout("Bye") == "BYE!")
```

`shout(null)` должен вернуть `silence`

```kotlin
    tryCatch(shout(null) == "silence")
```

Пустая строка не является `null`, поэтому `shout("")` должен вернуть `!`

```kotlin
    tryCatch(shout("") == "!")
```

fun shout(word: String?): String {
    return word?.let { it.uppercase() + "!" } ?: "silence"
}
