# --instructions--

Учитывая `enum class Color { RED, GREEN, BLUE }`, что делает `Color.valueOf("PURPLE")`?

# --answers--

- Выбрасывает `IllegalArgumentException`, так как ни одна запись не называется `PURPLE`
- Возвращает `null`
- Возвращает `Color.RED`, первую запись
- Добавляет в enum новую запись `PURPLE`
