# --instructions--

Учитывая `enum class Size { SMALL, MEDIUM, LARGE }`, что произойдёт со следующим кодом?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Код не скомпилируется: выражение `when` по enum должно охватывать все записи или иметь ветку `else`
- Код скомпилируется и вернёт `null` для `LARGE`
- Код скомпилируется и выбросит исключение во время выполнения для `LARGE`
- Код скомпилируется и автоматически вернёт `"L"` для `LARGE`
