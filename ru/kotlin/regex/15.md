# --description--

Поскольку `findAll` даёт последовательность, известные вам агрегирующие методы работают и с совпадениями: `sumOf`, `maxOfOrNull`, `filter`, `sortedBy`. Извлечь числа из произвольного текста — работа в два шага: сначала найти их, а затем преобразовать текст в число.
```kotlin
val total = Regex("""\d+""").findAll("2 apples, 3 pears").sumOf { it.value.toInt() }
println(total) // 5
```
