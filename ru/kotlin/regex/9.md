# --description--

`split` разрезает строку везде, где шаблон совпадает, и возвращает куски в виде `List<String>`. В отличие от разбиения по фиксированной строке-разделителю, разделитель-регулярное выражение может описывать целое семейство разделителей:
```kotlin
val separators = Regex("""[,;]\s*""")
println(separators.split("a, b;c")) // [a, b, c]
```
Совпавшие разделители не входят в результат. Если текст начинается или заканчивается разделителем, соседний с ним кусок пуст:
```kotlin
println(Regex("""\s+""").split(" a b")) // [, a, b]
```
`split` принимает `limit` вторым аргументом, чтобы остановиться после заданного числа кусков, оставив остаток нетронутым в последнем из них.
