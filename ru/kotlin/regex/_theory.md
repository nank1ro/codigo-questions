**Регулярное выражение** (или **регулярка**) — это небольшой шаблон, описывающий форму текста: «четыре цифры», «слово, за которым следует `@`», «всё, что между кавычками». В Kotlin шаблон — это объект `Regex`, который можно создать двумя эквивалентными способами:
```kotlin
val a = Regex("cat")
val b = "cat".toRegex()
```
Большинство символов в шаблоне означают сами себя, но некоторые являются **сокращениями**:
- `\d` — любая цифра, в строке Kotlin она записывается как `"\\d"`, потому что `\` нужно экранировать
- `[a-z]` — любая строчная буква, а `[abc]` — любой из символов `a`, `b` или `c`
- `+` после элемента означает «один или несколько таких элементов», поэтому `\d+` — это последовательность цифр

Самый простой вопрос, который можно задать, — `matches`, который возвращает `true`, только когда шаблон описывает **всю** строку целиком:
```kotlin
val digits = Regex("\\d+")
println(digits.matches("2026")) // true
println(digits.matches("20a6")) // false, the letter is not a digit
```

---

`matches` часто слишком строг: обычно нужно лишь узнать, встречается ли шаблон **где-либо** в тексте. Для этого есть `containsMatchIn`:
```kotlin
val digits = Regex("\\d+")
println(digits.matches("order 42"))          // false, the whole string is not digits
println(digits.containsMatchIn("order 42"))  // true, "42" is in there
```
Помимо `\d`, есть ещё два сокращения, которые вы будете использовать постоянно: `\w` — это символ слова (буква, цифра или `_`), а `\s` — пробельный символ. Каждый из них можно повторить с помощью **квантификатора**:
- `+` — один или несколько
- `*` — ноль или несколько
- `?` — ноль или один
- `{3}` — ровно три, `{2,4}` — от двух до четырёх

Удваивать каждый обратный слеш утомительно, поэтому шаблоны обычно записывают как **сырые строки** в тройных кавычках, где `\` — просто символ:
```kotlin
val digits = Regex("""\d+""") // same as Regex("\\d+")
```

---

`containsMatchIn` говорит лишь о том, *есть ли* шаблон в тексте. `find` также говорит, **что** именно и **где**: он возвращает первое совпадение в виде `MatchResult` или `null`, когда находить нечего.
```kotlin
val match = Regex("""\d+""").find("order 42 shipped")
println(match?.value) // 42
println(match?.range) // 6..7
```
`value` — это совпавший текст, а `range` — индексы, которые он занимает в исходной строке. Поскольку результат допускает `null`, обращайтесь к нему через безопасный вызов `?.`, который вернёт `null` вместо падения, если совпадения не нашлось:
```kotlin
val none = Regex("""\d+""").find("no numbers")
println(none?.value) // null
```

---

Круглые скобки в шаблоне создают **группу захвата**: часть совпадения, которую вы хотите прочитать отдельно. `MatchResult.groupValues` хранит их: индекс `0` — всё совпадение целиком, а `1`, `2`, ... — группы слева направо:
```kotlin
val date = Regex("""(\d{4})-(\d{2})-(\d{2})""")
val match = date.find("released 2026-09-12 in Rome")
println(match?.groupValues?.get(0)) // 2026-09-12
println(match?.groupValues?.get(1)) // 2026
println(match?.groupValues?.get(2)) // 09
```
Когда совпадения нет вовсе, `find` возвращает `null` и читать нечего, поэтому функция, извлекающая группу, обычно сама решает, что вернуть в таком случае:
```kotlin
val match = date.find("no date here")
println(match?.groupValues?.get(1) ?: "unknown") // unknown
```

---

Подсчёт скобок, чтобы выяснить, что хост — это группа `2`, становится хрупким, как только шаблон разрастается. Группе можно дать **имя** с помощью `(?<name>...)` и читать её из `groups` по этому имени:
```kotlin
val email = Regex("""(?<user>\w+)@(?<host>\w+)""")
val match = email.find("write to ann@mail today")
println(match?.groups?.get("user")?.value) // ann
println(match?.groups?.get("host")?.value) // mail
```
`groups` возвращает группу как `MatchGroup?`, поэтому всё ещё нужно запросить её `.value`. Именованная группа при этом нумеруется как обычно, поэтому `groupValues[1]` продолжает работать рядом с ней.

---

`find` останавливается на первом совпадении. `findAll` возвращает **все** совпадения в виде `Sequence<MatchResult>`: ленивую цепочку, с которой можно работать как со списком с помощью `map`, `filter`, `count` и `toList`.
```kotlin
val words = Regex("""\w+""").findAll("one two three")
println(words.count())                    // 3
println(words.map { it.value }.toList())  // [one, two, three]
```
Если совпадений нет, `findAll` возвращает пустую последовательность вместо `null`, поэтому безопасный вызов писать не нужно. Печатать саму последовательность бесполезно: вы увидите объект, а не совпадения — сначала превратите её в список.

---

`replace` переписывает текст: он возвращает **новую** строку, где каждое совпадение заменено подстановкой, а исходная строка остаётся нетронутой.
```kotlin
println(Regex("""\d+""").replace("a1 b22", "#")) // a# b#
```
В строке замены `$1`, `$2`, ... обозначают захваченные группы этого совпадения, поэтому совпавшие куски можно переставлять или использовать повторно:
```kotlin
val name = Regex("""(\w+) (\w+)""")
println(name.replace("Ann Lee", "$2 $1")) // Lee Ann
```
`$0` — это всё совпадение целиком. Если в замене нужен литеральный `$`, экранируйте его как `\$`.
`replace` переписывает **каждое** совпадение, поэтому если переписать нужно только полную строку, закрепите шаблон **якорями** `^` (начало текста) и `$` (конец текста):
```kotlin
println(Regex("""^\w+$""").replace("one two", "x")) // one two, nothing is replaced
```

---

Строка замены может лишь переставлять полученные ей куски. Когда новый текст нужно **вычислить**, передайте в `replace` вместо неё лямбду: она получает `MatchResult` и возвращает строку, которая займёт его место.
```kotlin
val digits = Regex("""\d+""")
println(digits.replace("a1 b22") { m -> (m.value.toInt() * 2).toString() }) // a2 b44
```
Внутри лямбды доступен весь `MatchResult`, поэтому `m.value`, `m.range` и `m.groupValues` — всё к вашим услугам. Обратите внимание: `$1` здесь не имеет особого смысла — это обычные символы в той строке, которую вы вернёте.

---

`split` разрезает строку везде, где шаблон совпадает, и возвращает куски в виде `List<String>`. В отличие от разбиения по фиксированной строке-разделителю, разделитель-регулярное выражение может описывать целое семейство разделителей:
```kotlin
val separators = Regex("""[,;]\s*""")
println(separators.split("a, b;c")) // [a, b, c]
```
Совпавшие разделители не входят в результат. Если текст начинается или заканчивается разделителем, соседний с ним кусок пуст:
```kotlin
println(Regex("""\s+""").split(" a b")) // [, a, b]
```
`split` принимает `limit` вторым аргументом, чтобы остановиться после заданного числа кусков, оставив остаток нетронутым в последнем из них.

---

Шаблоны чувствительны к регистру: `Regex("kotlin")` не совпадает с `"Kotlin"`. Вместо того чтобы писать `[kK][oO]...`, передайте опцию вторым аргументом:
```kotlin
val pattern = Regex("kotlin", RegexOption.IGNORE_CASE)
println(pattern.containsMatchIn("I love Kotlin")) // true
```
Опция принадлежит объекту `Regex`, поэтому каждый метод этого объекта подчиняется ей: и `matches`, и `find`, и `findAll`, и `replace`, и `split`. Другие полезные опции — `RegexOption.MULTILINE`, которая заставляет `^` и `$` совпадать на каждой строке, и `RegexOption.DOT_MATCHES_ALL`. Чтобы объединить их, передайте множество: `Regex("a.b", setOf(RegexOption.IGNORE_CASE, RegexOption.DOT_MATCHES_ALL))`.

---

`Regex("cat")` совпадает и с `cat` внутри `catalog`. Чтобы требовать целое слово, используйте **границу слова** `\b`: она совпадает с пустой позицией между символом слова и чем угодно другим, включая начало и конец текста.
```kotlin
println(Regex("""cat""").findAll("cat catalog").count())     // 2
println(Regex("""\bcat\b""").findAll("cat catalog").count()) // 1
```
Шаблон — это обычная строка, поэтому его можно собрать из частей во время выполнения:
```kotlin
val word = "cat"
val pattern = Regex("""\b""" + word + """\b""")
```

---

Символы `. * + ? ( ) [ ] { } | ^ $ \` имеют особое значение внутри шаблона. Самый коварный из них — `.`, который совпадает с **любым** символом, а не с точкой. Чтобы обозначить сам символ, экранируйте его обратным слешем:
```kotlin
println(Regex("""3.14""").matches("3x14"))  // true, the dot matches the x
println(Regex("""3\.14""").matches("3x14")) // false
```
Когда искомый текст приходит из переменной и должен пониматься буквально, доверьте экранирование библиотеке с помощью `Regex.escape`:
```kotlin
val typed = "1+1"
println(Regex(Regex.escape(typed)).containsMatchIn("1+1=2")) // true
```

---

`findAll` вместе с группами превращает строку текста в структурированные данные. Каждый `MatchResult` последовательности несёт свои `groupValues`, поэтому одна цепочка может построить список, отображение или сумму:
```kotlin
val pair = Regex("""(\w+)=(\w+)""")
val config = pair.findAll("host=local;port=80").associate { it.groupValues[1] to it.groupValues[2] }
println(config) // {host=local, port=80}
```
`associate` строит отображение из пар `key to value`, возвращённых лямбдой. Когда у шаблона фиксированное число групп, `destructured` позволяет распаковать их в именованные переменные вместо чтения по индексу:
```kotlin
val (key, value) = pair.find("host=local")!!.destructured
println(key)   // host
println(value) // local
```

---

Квадратные скобки задают **класс символов**: один символ из перечисленного набора. Внутри них можно использовать диапазоны, а ведущий `^` отрицает весь класс:
```kotlin
println(Regex("""gr[ae]y""").matches("grey"))  // true
println(Regex("""[a-f0-9]+""").matches("1b3")) // true
println(Regex("""[^0-9]+""").matches("abc"))   // true, no digit allowed
```
Класс выбирает только между отдельными символами. Чтобы выбирать между целыми альтернативами, используйте `|`, обычно завёрнутый в группу, чтобы он не поглотил остальную часть шаблона:
```kotlin
println(Regex("""(cat|dog)s?""").matches("dogs")) // true
```

---

Поскольку `findAll` даёт последовательность, известные вам агрегирующие методы работают и с совпадениями: `sumOf`, `maxOfOrNull`, `filter`, `sortedBy`. Извлечь числа из произвольного текста — работа в два шага: сначала найти их, а затем преобразовать текст в число.
```kotlin
val total = Regex("""\d+""").findAll("2 apples, 3 pears").sumOf { it.value.toInt() }
println(total) // 5
```

---

Реалистичный шаблон обычно смешивает всё сразу: группы, чтобы сохранить нужные части, экранированный `\.` для буквальных точек и замену лямбдой, чтобы пересобрать текст вокруг них.
```kotlin
val email = Regex("""(\w+)@(\w+\.\w+)""")
println(email.replace("ping ann@mail.com now") { m -> "<" + m.groupValues[2] + ">" })
// ping <mail.com> now
```
Держите шаблоны настолько простыми, насколько позволяет задача: шаблон, который пытается описать каждый допустимый адрес электронной почты, нечитаем, а `\w+@\w+\.\w+` достаточно, чтобы найти адреса в предложении.
