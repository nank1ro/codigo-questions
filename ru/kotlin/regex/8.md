# --description--

Строка замены может лишь переставлять полученные ей куски. Когда новый текст нужно **вычислить**, передайте в `replace` вместо неё лямбду: она получает `MatchResult` и возвращает строку, которая займёт его место.
```kotlin
val digits = Regex("""\d+""")
println(digits.replace("a1 b22") { m -> (m.value.toInt() * 2).toString() }) // a2 b44
```
Внутри лямбды доступен весь `MatchResult`, поэтому `m.value`, `m.range` и `m.groupValues` — всё к вашим услугам. Обратите внимание: `$1` здесь не имеет особого смысла — это обычные символы в той строке, которую вы вернёте.
