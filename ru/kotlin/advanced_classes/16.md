# --description--

Части этой темы обычно комбинируются: `enum class`, константы которого несут собственные свойства, моделирует фиксированный набор меток, а `data class` переносит сопутствующие данные.

```kotlin
enum class Speed(val surcharge: Int) {
    STANDARD(0),
    EXPRESS(15)
}

data class Order(val total: Int, val speed: Speed)

val order = Order(100, Speed.EXPRESS)
println(order.total + order.speed.surcharge) // 115
```
