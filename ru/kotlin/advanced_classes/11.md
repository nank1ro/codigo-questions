# --description--

`interface` перечисляет, что умеет тип. Его члены по умолчанию абстрактны, но интерфейс может также предоставить **реализацию по умолчанию** — тело, которое каждый реализующий класс наследует бесплатно и может переопределить:

```kotlin
interface Greeter {
    val name: String              // abstract, the class must provide it
    fun greet(): String = "Hi, $name"  // default implementation
}

class Person(override val name: String) : Greeter

class Robot(override val name: String) : Greeter {
    override fun greet(): String = "BEEP $name"
}

println(Person("Ann").greet()) // Hi, Ann
println(Robot("R2").greet())   // BEEP R2
```

Интерфейс не может хранить состояние (у него нет backing field), поэтому абстрактное свойство должно быть реализовано классом, обычно через `override val` в конструкторе. В отличие от класса, тип может реализовывать сколько угодно интерфейсов.
