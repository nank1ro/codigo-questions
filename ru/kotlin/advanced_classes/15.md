# --instructions--

Что происходит с этим кодом?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Код не компилируется: вложенный класс не видит члены внешнего класса, `Nested` должен быть `inner`
- Код компилируется, и `show()` возвращает `name` внешнего экземпляра
- Код компилируется, и `show()` всегда возвращает пустую строку
- Код не компилируется: Kotlin не допускает класс внутри другого класса
