# --description--

Класс, объявленный внутри другого класса, по умолчанию является **вложенным** (nested). Он ничего не знает о внешнем экземпляре, и вы создаёте его от имени внешнего класса:

```kotlin
class Outer {
    class Nested {
        fun hello() = "hi"
    }
}

println(Outer.Nested().hello()) // hi
```

Добавьте ключевое слово `inner`, и ситуация изменится: класс `inner` несёт ссылку на внешний экземпляр, поэтому может читать его свойства, и вы создаёте его **от экземпляра**:

```kotlin
class Counter(val step: Int) {
    inner class Doubler {
        fun value() = step * 2
    }
}

println(Counter(5).Doubler().value()) // 10
```

Внутри класса `inner` `this` — это внутренний объект; используйте `this@Counter`, когда вам явно нужен внешний.
