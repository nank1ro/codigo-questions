# --description--

Для каждого свойства первичного конструктора data class также генерирует функцию `componentN()`: `component1()` для первого свойства, `component2()` для второго и так далее.

Эти функции лежат в основе **деструктурирующих объявлений**, где вы распаковываете объект в несколько переменных одной строкой:

```kotlin
data class Point(val x: Int, val y: Int)

val point = Point(3, 7)
val (x, y) = point
println(x)               // 3
println(point.component2()) // 7
```

Порядок переменных следует порядку свойств, а не их именам. Используйте `_`, чтобы пропустить ненужное:

```kotlin
val (_, onlyY) = point
```
