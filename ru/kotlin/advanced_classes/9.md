# --description--

`companion object` — это синглтон, принадлежащий классу. Помимо констант его естественная задача — хранить **фабричные функции**: функции, которые проверяют или преобразуют входные данные перед созданием экземпляра и могут вернуть `null`, когда входные данные бессмысленны.

Пометка конструктора как `private` заставляет каждого вызывающего идти через фабрику:

```kotlin
class Age private constructor(val years: Int) {
    companion object {
        fun of(years: Int): Age? = if (years >= 0) Age(years) else null
    }
}

println(Age.of(30)?.years) // 30
println(Age.of(-1))        // null
```

Companion вызывается по имени класса, `Age.of(...)`, и может обратиться к приватному конструктору, потому что находится внутри класса.
