# --description--

Иногда нужен ровно **один** экземпляр чего-либо: логгер, реестр, конфигурация приложения. Замена `class` на `object` объявляет этот синглтон за вас:

```kotlin
object Registry {
    var size = 0
    fun add() {
        size++
    }
}

Registry.add()
println(Registry.size) // 1
```

Экземпляр создаётся при первом обращении, и вы используете само имя: нет ни вызова `Registry()`, ни конструктора. `object` может содержать свойства, методы, блоки `init`, а также реализовывать интерфейсы или наследовать класс.
