У каждого значения в Kotlin есть **тип**, который сообщает компилятору, что это за данные и что с ними можно делать.
Основные типы:
- `Int`: целое число, например `42` или `-7`
- `Long`: целое число, которое может быть намного больше `Int`
- `Double`: число с дробной частью, например `3.14`
- `Float`: число с дробной частью, которое использует вдвое меньше памяти, чем `Double`, но менее точно
- `Char`: одиночный символ в одинарных кавычках, например `'a'`
- `Boolean`: `true` или `false`
- `String`: текст в двойных кавычках, например `"Hello"`

Как вы видели в уроках о переменных, тип можно указать явно через двоеточие после имени:
```kotlin
val age: Int = 36
val name: String = "Ada"
```
Значение одного типа нельзя сохранить в переменной другого типа: `val age: Int = "36"` — это ошибка компиляции.

---

Чаще всего вы не пишете тип: Kotlin **выводит** его из присваиваемого значения по нескольким правилам для литералов:
- целое число, например `42`, — это `Int`
- число с десятичной точкой, например `3.14`, — это `Double`
- текст в двойных кавычках — это `String`
- символ в одинарных кавычках — это `Char`
- `true` и `false` — это `Boolean`
```kotlin
val count = 42     // Int
val price = 9.99   // Double
val name = "Ada"   // String
val grade = 'A'    // Char
val isOpen = true  // Boolean
```
Чтобы проверить, что вывел Kotlin, можно вывести имя типа любого значения с помощью `::class.simpleName`:
```kotlin
println(count::class.simpleName) // Int
println(price::class.simpleName) // Double
```
Десятичный литерал никогда не выводится как `Float`: `val ratio = 0.5` — это `Double`.

---

`Int` может хранить целые числа примерно до двух миллиардов, а точнее до `Int.MAX_VALUE`, то есть `2147483647`.
Целочисленный литерал, слишком большой для `Int`, автоматически выводится как `Long`, а для любого литерала можно принудительно задать `Long` суффиксом `L`:
```kotlin
val big = 3000000000  // Long, too big for an Int
val small = 3L        // Long, thanks to the suffix
```
Точно так же суффикс `f` превращает десятичный литерал в `Float`: `val ratio = 0.5f`.
Длинные числа трудно читать, поэтому Kotlin позволяет ставить знак подчёркивания `_` в любом месте между цифрами; компилятор их игнорирует:
```kotlin
val population = 8_000_000_000L
val million = 1_000_000
println(million) // 1000000
```

---

Kotlin никогда не преобразует числовые типы сам при присваивании значения, даже из меньшего типа в больший: сохранить `Int` в переменной `Long` или `Double` — это ошибка компиляции.
```kotlin
val count = 3
val total: Long = count      // error: Int is not a Long
val price: Double = count    // error: Int is not a Double
```
У каждого числового типа есть **функции преобразования**, которые создают новое значение нужного вам типа: `toInt()`, `toLong()`, `toDouble()`, `toFloat()` и, чтобы получить текст, `toString()`.
```kotlin
val total: Long = count.toLong()
val price: Double = count.toDouble() // 3.0
println(count.toString() + "!")      // 3!
```
При преобразовании из дробного числа в целое происходит **усечение**: `toInt()` просто отбрасывает дробную часть, поэтому `3.99.toInt()` — это `3`, а `(-3.99).toInt()` — это `-3`.

---

Типы операндов определяют, как работает деление. Когда оба они `Int`, оператор `/` выполняет **целочисленное деление**: результат — `Int`, а остаток отбрасывается.
Когда хотя бы один операнд — `Double`, `/` выполняет деление с плавающей точкой и сохраняет дробную часть:
```kotlin
println(7 / 2)              // 3
println(7.0 / 2)            // 3.5
val slices = 7
println(slices.toDouble() / 2) // 3.5
```
Поэтому чтобы получить дробный результат из двух переменных `Int`, нужно преобразовать хотя бы одну из них **до** деления: `(7 / 2).toDouble()` — это `3.0`, потому что целочисленное деление уже произошло.

---

Когда функция должна вернуть дробный результат, вычисленный из целых чисел, преобразуйте операнды в `Double` перед делением и объявите тип возвращаемого значения как `Double`:
```kotlin
fun ratio(part: Int, total: Int): Double {
    return part.toDouble() / total
}
println(ratio(1, 4)) // 0.25
```
Помните, что `sum()` и `size` у `List<Int>` тоже являются значениями `Int`, поэтому им нужно такое же преобразование.

---

Каждый `Char` хранится как число — его **код**. Свойство `code` даёт `Int`, стоящий за символом, а `toChar()` делает обратное, превращая `Int` в `Char` с этим кодом:
```kotlin
println('A'.code)        // 65
println(66.toChar())     // B
println(('A'.code + 2).toChar()) // C
```
У букв коды идут подряд, поэтому прибавление к коду сдвигает по алфавиту.
Обратите внимание, что код `'7'` — это `55`, а не `7`: чтобы прочитать цифру, которую представляет `Char`, используйте `digitToInt()`, она вернёт `7`.

---

Поскольку код `Char` — это `Int`, можно выполнять над ним арифметические операции и преобразовать результат обратно в `Char`. Так вы перемещаетесь по алфавиту:
```kotlin
val next = ('a'.code + 1).toChar() // 'b'
```
Kotlin также позволяет прибавлять `Int` напрямую к `Char`: `'a' + 1` — это `'b'`, а разность двух символов `'d' - 'a'` — это `Int` `3`.

---

Текст, введённый пользователем, всегда приходит как `String`, даже когда выглядит как число. Чтобы делать с ним вычисления, его нужно **разобрать**: `toInt()` превращает `"42"` в `Int` `42`, а `toDouble()` превращает `"3.5"` в `Double` `3.5`.
```kotlin
val typed = "42"
println(typed.toInt() + 1) // 43
```
Не каждый текст является числом: `"4x2".toInt()` выбрасывает `NumberFormatException` и останавливает программу.
Безопасные альтернативы `toIntOrNull()` и `toDoubleOrNull()` вместо исключения возвращают `null`, поэтому, как вы узнали в уроках о работе с null, можно задать значение по умолчанию с помощью `?:`:
```kotlin
println("4x2".toIntOrNull())      // null
println("4x2".toIntOrNull() ?: 0) // 0
```

---

`toIntOrNull()` выполняется успешно, только когда весь текст является корректным целым числом, возможно со знаком:
```kotlin
println("42".toIntOrNull())   // 42
println("-7".toIntOrNull())   // -7
println("3.5".toIntOrNull())  // null, not a whole number
println(" 42".toIntOrNull())  // null, spaces are not allowed
println("abc".toIntOrNull())  // null
```
Для десятичного текста используйте `toDoubleOrNull()`, которая принимает `"3.5"` и аналогично возвращает `Double?`.

---

У `Int` фиксированный размер, поэтому у него есть наименьшее и наибольшее значение: `Int.MIN_VALUE` — это `-2147483648`, а `Int.MAX_VALUE` — это `2147483647`.
Выход за границу **не** вызывает ошибку: значение молча **перескакивает** на другой конец диапазона, такое поведение называется переполнением.
```kotlin
println(Int.MAX_VALUE)     // 2147483647
println(Int.MAX_VALUE + 1) // -2147483648
```
Когда результат может превысить два миллиарда, используйте `Long`, чей предел `Long.MAX_VALUE` составляет около девяти квинтиллионов. Не забудьте преобразовать значение перед операцией: `Int.MAX_VALUE.toLong() + 1` — это `2147483648`.

---

`Double` хранит дробные числа в двоичном виде, поэтому некоторые значения нельзя представить точно, и в последних цифрах появляются небольшие погрешности:
```kotlin
println(0.1 + 0.2) // 0.30000000000000004
```
Чтобы показать фиксированное количество знаков после запятой, используйте `String.format` со строкой формата: `"%.2f"` означает «дробное число с 2 цифрами после точки». Результат — `String`, округлённый до этого количества цифр:
```kotlin
println(String.format("%.2f", 0.1 + 0.2)) // 0.30
println(String.format("%.1f", 3.14159))   // 3.1
println(String.format("%.2f", 2.0))       // 2.00
```

---

`Any` — это тип на вершине иерархии: каждое значение в Kotlin является `Any`, поэтому переменная типа `Any` может хранить `Int`, `String`, `Boolean` или что угодно ещё.
Чтобы узнать, что она на самом деле хранит, используйте оператор `is`, который возвращает `true`, когда значение имеет этот тип:
```kotlin
val value: Any = 42
println(value is Int)    // true
println(value is String) // false
```
Когда проверка пройдена, компилятор выполняет **умное приведение** типа: внутри `if` (или ветки `when`) можно использовать значение как этот тип, без всякого преобразования:
```kotlin
if (value is Int) println(value + 1) // 43, value is an Int here
when (value) {
    is String -> println(value.length)
    is Boolean -> println(!value)
}
```
