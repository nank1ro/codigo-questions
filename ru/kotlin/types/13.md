# --description--

`Any` — это тип на вершине иерархии: каждое значение в Kotlin является `Any`, поэтому переменная типа `Any` может хранить `Int`, `String`, `Boolean` или что угодно ещё.
Чтобы узнать, что она на самом деле хранит, используйте оператор `is`, который возвращает `true`, когда значение имеет этот тип:
```kotlin
val value: Any = 42
println(value is Int)    // true
println(value is String) // false
```
Когда проверка пройдена, компилятор выполняет **умное приведение** типа: внутри `if` (или ветки `when`) можно использовать значение как этот тип, без всякого преобразования:
```kotlin
if (value is Int) println(value + 1) // 43, value is an Int here
when (value) {
    is String -> println(value.length)
    is Boolean -> println(!value)
}
```
