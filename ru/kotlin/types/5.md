# --description--

Типы операндов определяют, как работает деление. Когда оба они `Int`, оператор `/` выполняет **целочисленное деление**: результат — `Int`, а остаток отбрасывается.
Когда хотя бы один операнд — `Double`, `/` выполняет деление с плавающей точкой и сохраняет дробную часть:
```kotlin
println(7 / 2)              // 3
println(7.0 / 2)            // 3.5
val slices = 7
println(slices.toDouble() / 2) // 3.5
```
Поэтому чтобы получить дробный результат из двух переменных `Int`, нужно преобразовать хотя бы одну из них **до** деления: `(7 / 2).toDouble()` — это `3.0`, потому что целочисленное деление уже произошло.
