# --description--

Когда функция должна вернуть дробный результат, вычисленный из целых чисел, преобразуйте операнды в `Double` перед делением и объявите тип возвращаемого значения как `Double`:
```kotlin
fun ratio(part: Int, total: Int): Double {
    return part.toDouble() / total
}
println(ratio(1, 4)) // 0.25
```
Помните, что `sum()` и `size` у `List<Int>` тоже являются значениями `Int`, поэтому им нужно такое же преобразование.
