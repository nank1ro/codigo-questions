# --description--

Каждый `Char` хранится как число — его **код**. Свойство `code` даёт `Int`, стоящий за символом, а `toChar()` делает обратное, превращая `Int` в `Char` с этим кодом:
```kotlin
println('A'.code)        // 65
println(66.toChar())     // B
println(('A'.code + 2).toChar()) // C
```
У букв коды идут подряд, поэтому прибавление к коду сдвигает по алфавиту.
Обратите внимание, что код `'7'` — это `55`, а не `7`: чтобы прочитать цифру, которую представляет `Char`, используйте `digitToInt()`, она вернёт `7`.
