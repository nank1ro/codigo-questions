# --description--

Поскольку код `Char` — это `Int`, можно выполнять над ним арифметические операции и преобразовать результат обратно в `Char`. Так вы перемещаетесь по алфавиту:
```kotlin
val next = ('a'.code + 1).toChar() // 'b'
```
Kotlin также позволяет прибавлять `Int` напрямую к `Char`: `'a' + 1` — это `'b'`, а разность двух символов `'d' - 'a'` — это `Int` `3`.
