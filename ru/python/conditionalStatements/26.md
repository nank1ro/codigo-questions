# --description--

Когда `online` равно `False`, условие никогда не выполняется, поэтому блок пропускается и ничего не выводится.

# --instructions--

Что выведет этот код?
```python
online = False
if (online):
    print("Hello user!")
```

- Hello user!
- "Hello user!"
- Ничего, код будет пропущен
