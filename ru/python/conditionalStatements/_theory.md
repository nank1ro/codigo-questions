Принятие решений необходимо, когда мы хотим выполнить код только при выполнении определённого условия.
Допустим, мы хотим играть на улице только если погода хорошая.
В программировании мы можем сохранить булеву переменную `nice_weather` и выполнить действие — играть на улице — `if` (если) эта переменная равна `True`, например:
```python
nice_weather = True
if (nice_weather):
    # играть на улице
```

---

Продолжим предыдущий пример.
```python
nice_weather = True
if (nice_weather):
    # играть на улице
```
Мы видели, что оператор `if` выполняет блок кода только если условие равно `True`.
Ещё один важный момент — это **двоеточие** `:` и **отступы**, которые обозначают начало блока кода.
Отступы — это пробелы в начале строки кода.
В отличие от других языков программирования, где отступы нужны только для удобства чтения, в Python отступы обязательны.
Вы можете использовать любое количество пробелов (2, 4, 6, 8), но рекомендуется 4.
В приложении мы советуем использовать клавишу **TAB** для отступа строк кода

---

Мы только что узнали, как выполнить блок кода при выполнении условия, а теперь давайте посмотрим, как выполнить другой блок кода, если первое условие не выполняется.
Мы идём играть на улицу, если погода хорошая; в противном случае остаёмся дома.
В Python мы можем использовать оператор `else`, например:
```python
nice_weather = True
if (nice_weather):
    # играть на улице
else:
    # остаться дома
```

---

Допустим, у нас есть ещё одно условие для проверки, как в этом примере:
```python
num = 3
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
else:
    print("do something else")
```
и вывод этого кода — `the number is 3`.
Сначала проверяем, равно ли число 2 — это ложь.
Затем переходим ко второму оператору и проверяем, равно ли `num` числу 3 — это истина, поэтому выполняем следующий блок кода и выводим `the number is 3`

---

Мы можем добавлять сколько угодно операторов `elif`, ограничений нет
```python
num = 4
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
elif (num == 4):
    print("the number is 4")
elif (num == 5):
    print("the number is 5")
elif (num == 6):
    print("the number is 6")
```
и вывод этого кода — `the number is 4`.

---

Мы также можем вложить условный оператор (`if`, `elif` или `else`) внутрь другого условного оператора, чтобы создать более сложную структуру.
```python
num = 4
if (num < 3):
    print("the number is lower than 3")
else:
    if (num == 3):
        print("the number is 3")
    elif (num == 4):
        print("the number is 4")
    else:
        print("the number is greather than 4")
```
и вывод этого кода — `the number is 4`.

---

Каждый условный оператор начинается с ключевого слова `if`. Именно оно сообщает Python, что блок ниже выполняется только при выполнении условия.

---

Условием не обязательно должно быть сравнение — булево значение вроде `True` само по себе тоже подходит, и блок выполняется, когда это значение равно `True`.

---

Тот же оператор можно заставить пропустить свой блок, просто изменив условие: как только оно принимает значение `False`, Python сразу переходит к коду после блока с отступом.

---

Строка `if` в Python состоит из трёх частей: ключевого слова `if`, условия и двоеточия, которое закрывает строку. Всё, что идёт с отступом после этого двоеточия, — это блок.

---

Поскольку условие здесь равно `True`, Python выполняет строку с отступом под ним и выводит `Hello!`.

---

Условие `False` означает, что Python никогда не заходит в блок с отступом, поэтому ничего не выводится.

---

Значение, которое решает, выполнится ли блок, называется условием, и оно всегда должно принимать булево значение — `True` или `False`.

---

Блок под `if` никогда не может быть пустым: Python выбрасывает `IndentationError`, если после двоеточия не следует строка с отступом. `pass` — это обычная заглушка, когда пока нечего выполнять.

---

Двоеточие относится к строке `if`, а не к блоку: оно отмечает конец условия и сообщает, что строки с отступом ниже являются частью оператора.

---

Когда условие равно `False`, Python пропускает весь блок с отступом и продолжает выполнение со следующей строки, которая не имеет отступа под `if`.

---

Python не требует скобок вокруг условия — `if True:` уже сам по себе является полным оператором. Скобки здесь — это обычная группировка, такая же, как в арифметике, и они не меняют значение.

---

Блок кода может содержать больше одной строки, и строки выполняются в том порядке, в котором они написаны — оператор, добавленный перед уже существующим, выводится первым.

---

Булеву переменную можно использовать в качестве условия саму по себе — сравнивать её с `True` или `False` не нужно.

---

Когда условием является переменная, `if` считывает то, что она хранит в этот момент. Чтобы отключить блок, достаточно изменить присваивание выше, вообще не трогая строку `if`.

---

Строки с отступом, принадлежащие условному оператору, называются его блоком кода — именно отступ обозначает их принадлежность к нему.

---

Строка, которая находится вне отступа `if`, выполняется независимо от значения условия, поскольку она никогда не была частью этого блока.

---

Блок кода не ограничен одной строкой — он может быть таким коротким или длинным, как того требует логика, пока каждая строка сохраняет одинаковый отступ.

---

Когда `online` равно `False`, условие никогда не выполняется, поэтому блок пропускается и ничего не выводится.

---

Только `print` с отступом сразу после `if` принадлежит его блоку; строка, написанная с тем же отступом, что и сам `if`, — нет.

---

Строка, размещённая после блока `if`, но без дополнительного отступа, больше не является его частью — она выполняется каждый раз, независимо от условия.

---

Блок может содержать любое количество выражений. Они выполняются сверху вниз, и каждое из них должно иметь тот же уровень отступа, что и остальные.

---

Присвоение переменной значения `True` делает условие, в которое она подставляется, истинным, поэтому блок под ним выполняется.

---

Если же присвоить `False`, условие становится ложным, и блок под ним полностью пропускается.

---

Ключевое слово `if` — это то, с чего начинается условный оператор: вместе со своим условием оно решает, выполнится ли блок ниже.

---

`"False"` в кавычках — это строка, а не булево значение, а непустая строка всегда считается истинной. Только `False` без кавычек не даёт блоку выполниться.
```python
print(bool("False"))  # True
```

---

Если выбрать здесь `True`, выполнятся обе строки блока, а не только первая — всё, что имеет отступ под `if`, принадлежит одному и тому же блоку.

---

Двоеточие — единственная часть строки `if`, без которой нельзя обойтись: оно закрывает условие и открывает блок. Скобки вокруг условия в Python необязательны, поэтому `if True:` и `if (True):` ведут себя одинаково.

---

Операторы вроде `if`, `elif` и `else`, которые выполняют или пропускают код в зависимости от булева значения, вместе называются условными операторами.

---

Оператор `not` инвертирует булево значение: `not True` — это `False`, а `not False` — это `True`.
```python
is_online = False
print(not is_online)  # True
```

---

`not` создаёт новое булево значение, а не изменяет то, которое читает, поэтому после `is_afternoon = not is_morning` переменная `is_morning` по-прежнему хранит своё исходное значение.

---

Условие всегда находится между ключевым словом `if` и следующим за ним двоеточием, и больше нигде в строке.

---

Жёсткого ограничения на количество строк в блоке `if` нет — важно лишь то, чтобы каждая строка сохраняла один и тот же уровень отступа.

---

Булев литерал вполне годится в качестве условия: `if True:` выполняет свой блок каждый раз. Запись `if (True):` — это тот же самый оператор, поскольку скобки вокруг условия в Python необязательны.

---

Блок кода оператора `if` — это группа строк с отступом под ним, выделенная из остальной программы именно этим отступом.

---

Условие всегда сводится к одному из двух значений — `True` или `False`, — именно это делает его булевым.
