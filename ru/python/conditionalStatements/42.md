# --description--

Блок кода оператора `if` — это группа строк с отступом под ним, выделенная из остальной программы именно этим отступом.

# --instructions--

Что такое оператор if?

# --answers--

- Код, который выполняется, если условие равно False
- Код, который определяет, должен ли фрагмент кода выполняться
- Ключевое слово сравнения
