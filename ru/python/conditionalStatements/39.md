Условие всегда находится между ключевым словом `if` и следующим за ним двоеточием, и больше нигде в строке.

# --instructions--

Где записывается условие оператора if?

# --answers--

- Между квадратными скобками []
- Между ключевым словом if и двоеточием :
- Перед ключевым словом if
