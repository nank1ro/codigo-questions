# --description--

Только `print` с отступом сразу после `if` принадлежит его блоку; строка, написанная с тем же отступом, что и сам `if`, — нет.

# --instructions--

Какой оператор print является частью блока кода оператора?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)

# --solutions--

- print("Hello User!")
