# --description--

Строку, которая занимает **несколько строк**, можно записать с помощью **тройных кавычек** `"""..."""` (или `'''...'''`).
Каждый перенос строки внутри кавычек становится частью строки, поэтому `\n` не нужен:
```python
poem = """Roses are red,
Violets are blue"""
print(poem)
```
выводит:
```
Roses are red,
Violets are blue
```
Строки в тройных кавычках также могут свободно содержать одинарные и двойные кавычки.
