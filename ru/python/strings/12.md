# --description--

`replace(old, new)` возвращает копию строки, в которой **каждое** вхождение `old` заменено на `new`:
```python
text = "a-b-c"
print(text.replace("-", "+"))  # a+b+c
```
Поскольку строки неизменяемы, не забудьте сохранить результат, если хотите его оставить.
