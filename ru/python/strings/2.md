# --description--

Встроенная функция `len()` возвращает **длину** строки, то есть количество символов, которые она содержит.
Пробелы и знаки препинания тоже считаются символами:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
