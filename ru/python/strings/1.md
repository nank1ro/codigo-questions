# --description--

**Строка** — это фрагмент текста: последовательность символов, заключённых в кавычки.
Python принимает как одинарные `'...'`, так и двойные `"..."` кавычки, и они работают совершенно одинаково:
```python
name = 'Ada'
language = "Python"
```
Выбор имеет значение, когда сам текст содержит кавычку.
Апостроф внутри одинарных кавычек закончил бы строку слишком рано, поэтому в этом случае используйте двойные кавычки:
```python
print("It's sunny")  # It's sunny
```
