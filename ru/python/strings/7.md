# --description--

Оператор `in` проверяет, **содержит** ли одна строка другую.
Он возвращает `True` или `False`, поэтому естественно вписывается в `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` выполняет противоположную проверку.
