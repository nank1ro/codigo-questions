# --description--

**Слаг** (slug) — это удобная для URL версия заголовка: строчные буквы, без пробелов по краям, а слова разделены дефисами, например `hello-world`.
Построить его — это просто цепочка методов, которые вы уже изучили: `strip()`, `lower()` и `replace()`.

# --instructions--

Напишите функцию `slugify(title)`, которая возвращает `title` без пробелов по краям, в нижнем регистре и с каждым пробелом, заменённым на `-`

```python
def slugify(title):
    return title.strip().lower().replace(" ", "-")
```
