# --description--

**Срез** (slice) извлекает часть строки.
Напишите `[начало:конец]` в квадратных скобках: символ на позиции `начало` включается, а символ на позиции `конец` **исключается**:
```python
word = "python"
print(word[0:3])  # pyt
print(word[2:4])  # th
```
Можно опустить `начало`, чтобы делать срез с начала строки, или `конец`, чтобы делать срез до конца:
```python
print(word[:2])  # py
print(word[2:])  # thon
```
Срез никогда не вызывает ошибку: `конец`, превышающий длину строки, просто останавливается на последнем символе.
