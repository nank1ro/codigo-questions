# --description--

`find(sub)` возвращает **индекс** первого вхождения `sub`, или `-1`, если он не найден:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` возвращает, **сколько раз** встречается `sub`:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

Сохраните в `position` индекс первого `o` в `text`, в `missing` — результат поиска `z`, а в `total` — сколько раз встречается `o`
