**Строка** — это фрагмент текста: последовательность символов, заключённых в кавычки.
Python принимает как одинарные `'...'`, так и двойные `"..."` кавычки, и они работают совершенно одинаково:
```python
name = 'Ada'
language = "Python"
```
Выбор имеет значение, когда сам текст содержит кавычку.
Апостроф внутри одинарных кавычек закончил бы строку слишком рано, поэтому в этом случае используйте двойные кавычки:
```python
print("It's sunny")  # It's sunny
```

---

Встроенная функция `len()` возвращает **длину** строки, то есть количество символов, которые она содержит.
Пробелы и знаки препинания тоже считаются символами:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```

---

У каждого символа строки есть позиция, называемая **индексом**.
Индексы начинаются с `0`, а не с `1`: первый символ находится по индексу `0`, второй — по индексу `1`, и так далее.
Напишите индекс в квадратных скобках после строки, чтобы прочитать один символ:
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
Обращение к несуществующему индексу, например `word[6]`, вызывает ошибку `IndexError`.

---

Индексы также могут быть **отрицательными**: они отсчитываются с конца строки.
`-1` — последний символ, `-2` — предпоследний, и так далее:
```python
word = "python"
print(word[-1])  # n
print(word[-2])  # o
```
Это удобно, потому что не нужно знать длину строки, чтобы добраться до её конца.

---

**Срез** (slice) извлекает часть строки.
Напишите `[начало:конец]` в квадратных скобках: символ на позиции `начало` включается, а символ на позиции `конец` **исключается**:
```python
word = "python"
print(word[0:3])  # pyt
print(word[2:4])  # th
```
Можно опустить `начало`, чтобы делать срез с начала строки, или `конец`, чтобы делать срез до конца:
```python
print(word[:2])  # py
print(word[2:])  # thon
```
Срез никогда не вызывает ошибку: `конец`, превышающий длину строки, просто останавливается на последнем символе.

---

Вы уже знаете, что `+` соединяет две строки (**конкатенация**).
Оператор `*` **повторяет** строку заданное количество раз:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
Повторение — быстрый способ рисовать разделители и простые узоры.

---

Оператор `in` проверяет, **содержит** ли одна строка другую.
Он возвращает `True` или `False`, поэтому естественно вписывается в `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` выполняет противоположную проверку.

---

У строк есть много встроенных **методов**: функций, вызываемых через точку после строки.
`upper()` возвращает текст заглавными буквами, `lower()` — строчными:
```python
word = "Python"
print(word.upper())  # PYTHON
print(word.lower())  # python
print(word)          # Python
```
Обратите внимание, что методы **возвращают новую строку**: исходная `word` не изменяется.
`lower()` часто используют для сравнения текста без учёта регистра: `"Yes".lower() == "yes"`.

---

Строки **неизменяемы**: после создания их символы нельзя изменить.
Присваивание по индексу вызывает ошибку `TypeError`:
```python
word = "dog"
word[1] = "i"  # TypeError: 'str' object does not support item assignment
```
Чтобы "изменить" строку, вы создаёте новую, например с помощью срезов и конкатенации, и сохраняете её в переменной:
```python
word = word[0] + "i" + word[2:]
print(word)  # dig
```

---

Текст, вводимый пользователями, часто содержит лишние пробелы вокруг него.
Метод `strip()` возвращает копию строки **без начальных и конечных пробельных символов** (пробелов, табуляций и переводов строк):
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
Пробелы в середине текста сохраняются.
`lstrip()` удаляет только левую сторону, а `rstrip()` — только правую.

---

`split()` разбивает строку на **список** частей.
Без аргументов она разбивает по пробельным символам; с аргументом — по указанному разделителю:
```python
print("a b  c".split())      # ['a', 'b', 'c']
print("2024-01-31".split("-"))  # ['2024', '01', '31']
```
`join()` делает противоположное: склеивает элементы списка в одну строку.
Он вызывается на **разделителе**, а список передаётся как аргумент:
```python
words = ["one", "two", "three"]
print(", ".join(words))  # one, two, three
print("".join(words))    # onetwothree
```

---

`replace(old, new)` возвращает копию строки, в которой **каждое** вхождение `old` заменено на `new`:
```python
text = "a-b-c"
print(text.replace("-", "+"))  # a+b+c
```
Поскольку строки неизменяемы, не забудьте сохранить результат, если хотите его оставить.

---

`find(sub)` возвращает **индекс** первого вхождения `sub`, или `-1`, если он не найден:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` возвращает, **сколько раз** встречается `sub`:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

---

`startswith(prefix)` и `endswith(suffix)` возвращают `True` или `False` в зависимости от того, как начинается или заканчивается строка:
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
Это обычный способ проверки расширений файлов, протоколов или префиксов.

---

Некоторые символы нельзя ввести напрямую внутри строки.
**Экранирующая последовательность** — это обратный слэш `\`, за которым следует буква или символ, обозначающие специальный символ:

- `\n` новая строка
- `\t` табуляция
- `\"` двойная кавычка внутри строки в двойных кавычках
- `\'` одинарная кавычка внутри строки в одинарных кавычках
- `\\` буквальный обратный слэш

```python
print("Line 1\nLine 2")
print("She said \"hi\"")
```
выводит:
```
Line 1
Line 2
She said "hi"
```
Каждая экранирующая последовательность считается **одним** символом, даже если вы вводите два.

---

Строку, которая занимает **несколько строк**, можно записать с помощью **тройных кавычек** `"""..."""` (или `'''...'''`).
Каждый перенос строки внутри кавычек становится частью строки, поэтому `\n` не нужен:
```python
poem = """Roses are red,
Violets are blue"""
print(poem)
```
выводит:
```
Roses are red,
Violets are blue
```
Строки в тройных кавычках также могут свободно содержать одинарные и двойные кавычки.

---

Поскольку каждый строковый метод возвращает новую строку, вы можете **соединять** методы один за другим.
Каждый вызов работает с результатом предыдущего:
```python
text = "  Hello World  "
print(text.strip().lower())  # hello world
```
Срез также принимает третье значение — **шаг**.
Шаг `-1` проходит по строке в обратном направлении, что является классическим приёмом для её разворота:
```python
print("abc"[::-1])  # cba
```

---

**Слаг** (slug) — это удобная для URL версия заголовка: строчные буквы, без пробелов по краям, а слова разделены дефисами, например `hello-world`.
Построить его — это просто цепочка методов, которые вы уже изучили: `strip()`, `lower()` и `replace()`.
