# --description--

Текст, вводимый пользователями, часто содержит лишние пробелы вокруг него.
Метод `strip()` возвращает копию строки **без начальных и конечных пробельных символов** (пробелов, табуляций и переводов строк):
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
Пробелы в середине текста сохраняются.
`lstrip()` удаляет только левую сторону, а `rstrip()` — только правую.
