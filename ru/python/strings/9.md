# --description--

Строки **неизменяемы**: после создания их символы нельзя изменить.
Присваивание по индексу вызывает ошибку `TypeError`:
```python
word = "dog"
word[1] = "i"  # TypeError: 'str' object does not support item assignment
```
Чтобы "изменить" строку, вы создаёте новую, например с помощью срезов и конкатенации, и сохраняете её в переменной:
```python
word = word[0] + "i" + word[2:]
print(word)  # dig
```

# --instructions--

Что происходит, когда выполняется этот код?
```python
word = "cat"
word[0] = "b"
print(word)
```

# --answers--

- Ошибку `TypeError`: строки неизменяемы, символ нельзя заменить на месте
- Выводит `bat`
- Выводит `b`
- Выводит `cat`, присваивание молча игнорируется
