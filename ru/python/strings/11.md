# --description--

`split()` разбивает строку на **список** частей.
Без аргументов она разбивает по пробельным символам; с аргументом — по указанному разделителю:
```python
print("a b  c".split())      # ['a', 'b', 'c']
print("2024-01-31".split("-"))  # ['2024', '01', '31']
```
`join()` делает противоположное: склеивает элементы списка в одну строку.
Он вызывается на **разделителе**, а список передаётся как аргумент:
```python
words = ["one", "two", "three"]
print(", ".join(words))  # one, two, three
print("".join(words))    # onetwothree
```
