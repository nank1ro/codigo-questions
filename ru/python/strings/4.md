# --description--

Индексы также могут быть **отрицательными**: они отсчитываются с конца строки.
`-1` — последний символ, `-2` — предпоследний, и так далее:
```python
word = "python"
print(word[-1])  # n
print(word[-2])  # o
```
Это удобно, потому что не нужно знать длину строки, чтобы добраться до её конца.

# --instructions--

Что выведет этот код?
```python
word = "python"
print(word[-3])
```
