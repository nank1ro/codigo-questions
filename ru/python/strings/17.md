# --description--

Поскольку каждый строковый метод возвращает новую строку, вы можете **соединять** методы один за другим.
Каждый вызов работает с результатом предыдущего:
```python
text = "  Hello World  "
print(text.strip().lower())  # hello world
```
Срез также принимает третье значение — **шаг**.
Шаг `-1` проходит по строке в обратном направлении, что является классическим приёмом для её разворота:
```python
print("abc"[::-1])  # cba
```
