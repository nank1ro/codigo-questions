# --description--

У каждого символа строки есть позиция, называемая **индексом**.
Индексы начинаются с `0`, а не с `1`: первый символ находится по индексу `0`, второй — по индексу `1`, и так далее.
Напишите индекс в квадратных скобках после строки, чтобы прочитать один символ:
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
Обращение к несуществующему индексу, например `word[6]`, вызывает ошибку `IndexError`.
