# --description--

У строк есть много встроенных **методов**: функций, вызываемых через точку после строки.
`upper()` возвращает текст заглавными буквами, `lower()` — строчными:
```python
word = "Python"
print(word.upper())  # PYTHON
print(word.lower())  # python
print(word)          # Python
```
Обратите внимание, что методы **возвращают новую строку**: исходная `word` не изменяется.
`lower()` часто используют для сравнения текста без учёта регистра: `"Yes".lower() == "yes"`.
