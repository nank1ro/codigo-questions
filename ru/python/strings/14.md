# --description--

`startswith(prefix)` и `endswith(suffix)` возвращают `True` или `False` в зависимости от того, как начинается или заканчивается строка:
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
Это обычный способ проверки расширений файлов, протоколов или префиксов.

# --solutions--

```python
def is_python_file(name):
    return name.endswith(".py")

def is_comment(line):
    return line.startswith("#")
```
