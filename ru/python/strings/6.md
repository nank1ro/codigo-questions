# --description--

Вы уже знаете, что `+` соединяет две строки (**конкатенация**).
Оператор `*` **повторяет** строку заданное количество раз:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
Повторение — быстрый способ рисовать разделители и простые узоры.
