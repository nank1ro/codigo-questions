# --description--

Конкурентность окупается, когда количество операций не фиксировано. Создайте объекты-сопрограммы в списковом включении, распакуйте их в `gather` и ожидайте всю партию сразу:
```python
import asyncio

async def fetch(url):
    await asyncio.sleep(0.02)
    return len(url)

async def fetch_all(urls):
    return await asyncio.gather(*[fetch(u) for u in urls])

print(asyncio.run(fetch_all(["a.com", "bb.com"])))  # [5, 6]
```
Десять url-адресов по-прежнему занимают суммарно около 20 миллисекунд вместо 200, а результаты остаются в порядке url-адресов.

```python
    def test_2(self):
        self.assertEqual(asyncio.run(fetch_all([1, 2, 3])), [10, 20, 30], "--err-t2--")
        self.assertEqual(asyncio.run(fetch_all([])), [], "--err-t2--")
```

`fetch_all` с пятью id должна выполнять их конкурентно, затрачивая заметно меньше `0.1` секунды

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(fetch_all([1, 2, 3, 4, 5]))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [10, 20, 30, 40, 50], "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```
