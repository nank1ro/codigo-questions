# --description--

`asyncio.create_task(coro)` оборачивает сопрограмму в **задачу** (Task) и планирует её выполнение в фоне. В отличие от `await`, он возвращается немедленно, поэтому текущая сопрограмма может продолжать работать, пока задача выполняется. На самом деле задача стартует в следующий раз, когда текущая сопрограмма приостановится на `await`. Последующее ожидание задачи с `await` даёт её результат:
```python
import asyncio

async def background():
    print("task started")
    await asyncio.sleep(0.01)
    return "task done"

async def main():
    task = asyncio.create_task(background())
    print("main continues")
    print(await task)

asyncio.run(main())
```
Это сначала выводит `main continues`, потому что `background` стартует только тогда, когда `main` ожидает с `await`, а затем `task started` и `task done`.

# --solutions--

```python
import asyncio

async def background(log):
    log.append("start")
    await asyncio.sleep(0.01)
    log.append("done")

async def main(log):
    task = asyncio.create_task(background(log))
    log.append("main")
    await task
    return log
```
