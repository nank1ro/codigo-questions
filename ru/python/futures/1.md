# --description--

Некоторые операции занимают время: чтение файла, обращение к серверу, ожидание таймера. Python может выполнять такой код **асинхронно** с помощью модуля `asyncio`, так что одна задача может ждать, не блокируя остальные.

Функция, определённая с `async def`, — это **функция-сопрограмма**. Её вызов не выполняет тело: она возвращает **объект-сопрограмму**, описывающий работу, которую нужно сделать. `asyncio.run(coro)` запускает цикл событий, выполняет сопрограмму до завершения и останавливает цикл:
```python
import asyncio

async def greet():
    print("hello")

asyncio.run(greet())  # hello
```
`asyncio.run` — это точка входа асинхронной программы; её вызывают один раз из обычного синхронного кода.
