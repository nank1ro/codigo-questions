# --description--

С `gather` сопрограммы сменяют друг друга на каждом `await`. Сопрограмма выполняется, пока не ожидает что-то, что ещё не готово, — тогда цикл переключается на другую. Поэтому побочные эффекты вроде `print` происходят в том порядке, в котором сопрограммы **возобновляются**, а не в том, в каком они были переданы:
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    print(await asyncio.gather(step("a", 0.03), step("b", 0.01)))

asyncio.run(main())
```
Это выводит `b`, затем `a`, затем `['a', 'b']`: `b` просыпается первой, но список результатов сохраняет порядок аргументов.

Что выведет этот код?
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    names = await asyncio.gather(step("x", 0.03), step("y", 0.01), step("z", 0.02))
    print(names)

asyncio.run(main())
```

# --answers--

- `y`, `z`, `x`, затем `['x', 'y', 'z']`, потому что каждая сопрограмма выводит значение, когда заканчивается её ожидание, но `gather` сохраняет порядок аргументов
- `x`, `y`, `z`, затем `['x', 'y', 'z']`, потому что `gather` выполняет сопрограммы одна за другой
- `y`, `z`, `x`, затем `['y', 'z', 'x']`, потому что `gather` возвращает результаты в порядке завершения
- `x`, `y`, `z`, затем `['y', 'z', 'x']`, потому что вывод происходит до того, как начнётся хоть одно ожидание
