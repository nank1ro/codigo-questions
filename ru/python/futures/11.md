# --description--

Задача продолжает выполняться независимо от того, ждёт ли её кто-нибудь. Создайте её заранее, выполняйте другую работу и ожидайте её с `await` только там, где нужен её результат: ожидание короче, потому что часть задачи уже выполнена в фоне. Задачу также можно проверить с помощью `task.done()`, которая возвращает `True`, как только задача завершилась.

# --instructions--

Дополните код так, чтобы `compute()` была запланирована как задача, `"waiting"` выводился, пока она выполняется, и чтобы затем задача ожидалась с `await` для получения её значения, давая вывод `waiting`, `42`

```python
import asyncio

async def compute():
    await asyncio.sleep(0.01)
    return 42

async def main():
    task = asyncio.create_task(compute())
    print("waiting")
    value = await task
    print(value)

asyncio.run(main())
```
