# --description--

Небольшая асинхронная программа следует фиксированной форме: импортируйте `asyncio`, определите функции-сопрограммы, определите сопрограмму `main`, которая ожидает их с `await`, и в конце один раз вызовите `asyncio.run(main())`.

# --instructions--

Расположите элементы по порядку, чтобы получить программу, которая начинается с импорта, определяет `download` до `main`, выполняет две загрузки конкурентно с помощью `asyncio.gather` и выводит результаты, давая вывод `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

# --output--

['report.pdf', 'data.csv']
