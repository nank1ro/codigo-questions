# --description--

Эти элементы естественно сочетаются. Чтобы выполнить много операций конкурентно, каждая со своим лимитом времени, оберните каждую в небольшую сопрограмму, которая применяет `wait_for` и перехватывает `TimeoutError`, а затем соберите обёртки с помощью `gather`:
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])` затем возвращает значение для каждой задачи, завершившейся вовремя, и `None` для каждой, которая не успела, — в исходном порядке, а вся партия занимает не более примерно `limit` секунд.

# --instructions--

Напишите функцию-сопрограмму `job(delay)`, которая ждёт `delay` секунд и возвращает `delay`, и функцию-сопрограмму `run_jobs(delays, limit)`, которая выполняет `job` для каждой задержки **конкурентно**, ограничивая каждую `limit` секундами с помощью `asyncio.wait_for`, и возвращает список с задержкой каждой задачи, завершившейся вовремя, и `None` для каждой задачи, не уложившейся в таймаут, в исходном порядке

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
