# --description--

Вызова функции-сопрограммы недостаточно, чтобы её выполнить. Вызов лишь создаёт объект-сопрограмму; тело выполняется, когда этот объект ожидают с `await` или передают в `asyncio.run`:
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python даже предупреждает об этом: `RuntimeWarning: coroutine 'hello' was never awaited`. Забытый `await` — самая распространённая асинхронная ошибка: код выглядит вызванным, но никогда не выполняется, а переменная, которая должна была хранить его результат, вместо этого хранит объект-сопрограмму.

# --instructions--

Что выведет этот код?
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- Только `main`, потому что `hello()` создаёт объект-сопрограмму, который никогда не ожидается с `await`, поэтому его тело не выполняется
- `hi`, затем `main`, потому что вызов функции-сопрограммы выполняет её немедленно
- `main`, затем `hi`, потому что сопрограмма выполняется, когда `main` завершается
- `TypeError`, потому что сопрограмму нельзя присвоить переменной
