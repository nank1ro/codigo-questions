# --description--

Встроенная функция `map(func, iterable)` вызывает `func` для каждого элемента и выдаёт результаты, по одному на элемент. Она возвращает ленивый *map object*, поэтому оберните её в `list()`, чтобы увидеть значения:
```python
numbers = [1, 2, 3]
print(list(map(lambda n: n * 10, numbers)))  # [10, 20, 30]
```
Передать можно любой вызываемый объект, не только лямбду: встроенную функцию вроде `len` или метод, взятый из класса, например `str.upper`, который принимает строку первым аргументом:
```python
names = ["ada", "linus"]
print(list(map(str.upper, names)))  # ['ADA', 'LINUS']
print(list(map(len, names)))        # [3, 5]
```
