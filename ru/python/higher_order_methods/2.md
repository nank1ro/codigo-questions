# --description--

Передача функции в аргументе позволяет вызывающему решать, **что** делать, а функция высшего порядка решает, **сколько раз** или **над чем**. Параметр-функцию можно вызывать сколько угодно раз, а её результат подавать ей же на вход:
```python
def repeat(func, value, times):
    for _ in range(times):
        value = func(value)
    return value

def add_one(n):
    return n + 1

print(repeat(add_one, 0, 3))  # 3
```
Подойдёт любой вызываемый объект: функция `def`, встроенная функция вроде `len` или `lambda`.
