# --description--

**Декоратор** — это функция высшего порядка, которая принимает функцию и возвращает новую, оборачивающую её, обычно чтобы добавить поведение до или после исходного вызова:
```python
def announce(func):
    def wrapper(name):
        print("calling " + func.__name__)
        return func(name)
    return wrapper
```
`func.__name__` — это имя, с которым функция была определена. Применение декоратора — это просто вызов: `greet = announce(greet)`. Синтаксис `@`, помещённый на строке **над** `def`, делает ровно это:
```python
@announce
def greet(name):
    return "Hello, " + name
```
Декоратор должен быть определён до того, как он используется с `@`, потому что замена происходит сразу при выполнении `def`.
