В Python функция — это **значение**, такое же как число или строка. Её можно сохранить в переменную, положить в список или передать в другую функцию. Вызывают её только скобки: `shout` — это сама функция, а `shout("hi")` — её результат:
```python
def shout(text):
    return text.upper() + "!"

say = shout
print(say("hi"))  # HI!
```
Функция, которая принимает другую функцию как параметр или возвращает её, называется **функцией высшего порядка**. Внутри неё параметр вызывается со скобками, как любая другая функция:
```python
def apply(func, value):
    return func(value)

print(apply(shout, "bye"))  # BYE!
print(apply(len, "bye"))    # 3
```

---

Передача функции в аргументе позволяет вызывающему решать, **что** делать, а функция высшего порядка решает, **сколько раз** или **над чем**. Параметр-функцию можно вызывать сколько угодно раз, а её результат подавать ей же на вход:
```python
def repeat(func, value, times):
    for _ in range(times):
        value = func(value)
    return value

def add_one(n):
    return n + 1

print(repeat(add_one, 0, 3))  # 3
```
Подойдёт любой вызываемый объект: функция `def`, встроенная функция вроде `len` или `lambda`.

---

Встроенная функция `map(func, iterable)` вызывает `func` для каждого элемента и выдаёт результаты, по одному на элемент. Она возвращает ленивый *map object*, поэтому оберните её в `list()`, чтобы увидеть значения:
```python
numbers = [1, 2, 3]
print(list(map(lambda n: n * 10, numbers)))  # [10, 20, 30]
```
Передать можно любой вызываемый объект, не только лямбду: встроенную функцию вроде `len` или метод, взятый из класса, например `str.upper`, который принимает строку первым аргументом:
```python
names = ["ada", "linus"]
print(list(map(str.upper, names)))  # ['ADA', 'LINUS']
print(list(map(len, names)))        # [3, 5]
```

---

Встроенная функция `filter(func, iterable)` оставляет только те элементы, для которых `func` возвращает истинное значение. Как и `map`, она возвращает ленивый объект, который нужно превратить в список:
```python
numbers = [4, -2, 7, 0]
print(list(filter(lambda n: n > 0, numbers)))  # [4, 7]
```
Функция, переданная в `filter`, называется **предикатом**: она принимает один элемент и отвечает на вопрос о нём «да» или «нет». Если вместо функции передать `None`, останутся элементы, истинные сами по себе, а `0`, `""` и `None` будут отброшены.

---

`sorted(iterable, key=func)` упорядочивает элементы по значению, которое `func` возвращает для каждого из них, не изменяя сами элементы. Добавьте `reverse=True`, чтобы получить сначала наибольшие:
```python
words = ["kiwi", "fig", "banana"]
print(sorted(words, key=len))                # ['fig', 'kiwi', 'banana']
print(sorted(words, key=len, reverse=True))  # ['banana', 'kiwi', 'fig']
```
Сортировка **устойчива**: элементы с равными ключами сохраняют исходный порядок. Функция `key` вызывается один раз для каждого элемента, а её результаты используются только для сравнения, поэтому в выводе остаются исходные слова, а не их длины.

---

Функция `key` может выбирать **любую часть** элемента. Для списка кортежей `lambda s: s[1]` сортирует по второму элементу каждого кортежа; для списка словарей `lambda d: d["age"]` сортирует по значению:
```python
pairs = [("b", 2), ("a", 3), ("c", 1)]
print(sorted(pairs, key=lambda p: p[1]))  # [('c', 1), ('b', 2), ('a', 3)]
```
`min` и `max` принимают тот же параметр `key`, поэтому `max(pairs, key=lambda p: p[1])` возвращает `('a', 3)`: весь кортеж, а не только число.

---

Функция также может **возвращать** функцию. Определите внутреннюю функцию с помощью `def` и верните её, не вызывая:
```python
def make_greeter(greeting):
    def greet(name):
        return greeting + ", " + name
    return greet

hello = make_greeter("Hello")
print(hello("Ada"))  # Hello, Ada
```
Внутренняя функция продолжает использовать `greeting` даже после того, как `make_greeter` завершилась: она **помнит** переменные области видимости, в которой была создана. Такая функция называется **замыканием**. Каждый вызов `make_greeter` создаёт новое независимое замыкание со своим собственным `greeting`.

---

Замыкание может читать переменные объемлющей функции, но присваивание одной из них создаёт вместо этого **новую локальную** переменную. Чтобы обновить внешнюю переменную, объявите её с помощью `nonlocal` внутри внутренней функции:
```python
def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment
```
`global` искал бы `count` на уровне модуля, где его нет. С `nonlocal` каждый вызов возвращённой функции обновляет один и тот же `count`, поэтому замыкание хранит состояние между вызовами, как маленький объект.

---

`reduce(func, iterable, initial)` из модуля `functools` сворачивает последовательность в **одно значение**. Она вызывает `func` с результатом, накопленным на данный момент, и следующим элементом, начиная с `initial`:
```python
from functools import reduce

total = reduce(lambda acc, n: acc + n, [1, 2, 3], 0)
print(total)  # 6
```
Шаги такие: `0 + 1`, затем `1 + 2`, затем `3 + 3`. Если `initial` опущен, начальным значением становится первый элемент, но тогда пустая последовательность вызывает `TypeError`, поэтому задавайте начальное значение всякий раз, когда последовательность может быть пустой.

---

`partial(func, *fixed)` из `functools` создаёт новую функцию, у которой часть аргументов **уже подставлена**. Вызов результата передаёт остальные:
```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(5))  # 25
```
Позиционные аргументы, переданные в `partial`, заполняют первые параметры; именованные аргументы фиксируют параметр по имени и всё ещё могут быть переопределены при вызове. Partial — это обычный вызываемый объект, поэтому его можно передать в `map`, `sorted` или любую другую функцию высшего порядка.

---

`partial` удобен со встроенными функциями, принимающими параметры. `int(text, base=16)` разбирает шестнадцатеричную строку; фиксация основания даёт преобразователь с одним аргументом, который подходит для `map`:
```python
from functools import partial

hex_to_int = partial(int, base=16)
print(hex_to_int("ff"))                      # 255
print(list(map(hex_to_int, ["a", "10"])))    # [10, 16]
```
Объект partial помнит, что он оборачивает: `hex_to_int.func` — это `int`, а `hex_to_int.keywords` — это `{'base': 16}`.

---

**Декоратор** — это функция высшего порядка, которая принимает функцию и возвращает новую, оборачивающую её, обычно чтобы добавить поведение до или после исходного вызова:
```python
def announce(func):
    def wrapper(name):
        print("calling " + func.__name__)
        return func(name)
    return wrapper
```
`func.__name__` — это имя, с которым функция была определена. Применение декоратора — это просто вызов: `greet = announce(greet)`. Синтаксис `@`, помещённый на строке **над** `def`, делает ровно это:
```python
@announce
def greet(name):
    return "Hello, " + name
```
Декоратор должен быть определён до того, как он используется с `@`, потому что замена происходит сразу при выполнении `def`.

---

Декоратор, принимающий только один аргумент, малополезен. Чтобы обернуть **любую** функцию, обёртка собирает все позиционные аргументы в `*args` и все именованные в `**kwargs` и передаёт их без изменений:
```python
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@uppercase
def greet(name, punctuation="!"):
    return "hello " + name + punctuation

print(greet("ada"))                    # HELLO ADA!
print(greet("ada", punctuation="?"))   # HELLO ADA?
```
Внутри обёртки `args` — это кортеж, а `kwargs` — словарь; `*` и `**` в вызове снова распаковывают их в отдельные аргументы.

---

`any(iterable)` возвращает `True`, если истинен **хотя бы один** элемент, а `all(iterable)` — если истинны **все**. Они естественно сочетаются с **генераторным выражением**: это списковое включение, записанное без квадратных скобок, которое выдаёт значения по одному, вместо того чтобы строить список:
```python
ages = [21, 34, 17]
print(any(age >= 18 for age in ages))  # True
print(all(age >= 18 for age in ages))  # False
```
Поскольку значения выдаются лениво, `any` останавливается на первом `True`, а `all` — на первом `False`, не вычисляя остальные. `sum` тоже принимает генераторное выражение: `sum(1 for age in ages if age >= 18)` считает совершеннолетних.
