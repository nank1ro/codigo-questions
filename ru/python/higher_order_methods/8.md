# --description--

Замыкание может читать переменные объемлющей функции, но присваивание одной из них создаёт вместо этого **новую локальную** переменную. Чтобы обновить внешнюю переменную, объявите её с помощью `nonlocal` внутри внутренней функции:
```python
def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment
```
`global` искал бы `count` на уровне модуля, где его нет. С `nonlocal` каждый вызов возвращённой функции обновляет один и тот же `count`, поэтому замыкание хранит состояние между вызовами, как маленький объект.
