# --description--

Декоратор, принимающий только один аргумент, малополезен. Чтобы обернуть **любую** функцию, обёртка собирает все позиционные аргументы в `*args` и все именованные в `**kwargs` и передаёт их без изменений:
```python
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@uppercase
def greet(name, punctuation="!"):
    return "hello " + name + punctuation

print(greet("ada"))                    # HELLO ADA!
print(greet("ada", punctuation="?"))   # HELLO ADA?
```
Внутри обёртки `args` — это кортеж, а `kwargs` — словарь; `*` и `**` в вызове снова распаковывают их в отдельные аргументы.

# --instructions--

Напишите декоратор `exclaim`, который возвращает обёртку, принимающую любые аргументы, вызывающую обёрнутую функцию с ними и возвращающую её результат с добавленным `"!"`; затем используйте его, чтобы декорировать функцию `greet`, которая принимает `name` и возвращает `"hello <name>"`
