# --description--

`sorted(iterable, key=func)` упорядочивает элементы по значению, которое `func` возвращает для каждого из них, не изменяя сами элементы. Добавьте `reverse=True`, чтобы получить сначала наибольшие:
```python
words = ["kiwi", "fig", "banana"]
print(sorted(words, key=len))                # ['fig', 'kiwi', 'banana']
print(sorted(words, key=len, reverse=True))  # ['banana', 'kiwi', 'fig']
```
Сортировка **устойчива**: элементы с равными ключами сохраняют исходный порядок. Функция `key` вызывается один раз для каждого элемента, а её результаты используются только для сравнения, поэтому в выводе остаются исходные слова, а не их длины.

Что выведет этот код?

```python
words = ["kiwi", "fig", "banana", "apple"]
print(sorted(words, key=len))
```

- `[3, 4, 5, 6]`, потому что `sorted` возвращает значения, вычисленные `key`
- `['banana', 'apple', 'kiwi', 'fig']`, потому что `key=len` сортирует от самого длинного к самому короткому
