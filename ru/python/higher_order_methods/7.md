# --description--

Функция также может **возвращать** функцию. Определите внутреннюю функцию с помощью `def` и верните её, не вызывая:
```python
def make_greeter(greeting):
    def greet(name):
        return greeting + ", " + name
    return greet

hello = make_greeter("Hello")
print(hello("Ada"))  # Hello, Ada
```
Внутренняя функция продолжает использовать `greeting` даже после того, как `make_greeter` завершилась: она **помнит** переменные области видимости, в которой была создана. Такая функция называется **замыканием**. Каждый вызов `make_greeter` создаёт новое независимое замыкание со своим собственным `greeting`.
