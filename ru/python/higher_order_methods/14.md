# --description--

`any(iterable)` возвращает `True`, если истинен **хотя бы один** элемент, а `all(iterable)` — если истинны **все**. Они естественно сочетаются с **генераторным выражением**: это списковое включение, записанное без квадратных скобок, которое выдаёт значения по одному, вместо того чтобы строить список:
```python
ages = [21, 34, 17]
print(any(age >= 18 for age in ages))  # True
print(all(age >= 18 for age in ages))  # False
```
Поскольку значения выдаются лениво, `any` останавливается на первом `True`, а `all` — на первом `False`, не вычисляя остальные. `sum` тоже принимает генераторное выражение: `sum(1 for age in ages if age >= 18)` считает совершеннолетних.
