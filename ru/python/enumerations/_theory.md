**Перечисление** (или *enum*) определяет общий тип для группы связанных, фиксированных значений, например дней недели или цветов светофора.
Вместо того чтобы передавать случайные строки или числа, вы даёте каждому значению **имя**, поэтому код становится более читаемым, а опечатки превращаются в ошибки.
В Python вы создаёте перечисление, импортируя `Enum` из модуля `enum` и объявляя класс, который наследуется от него.
Каждый атрибут класса является **элементом** перечисления, у которого есть имя и значение:
```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3
```
По соглашению имена элементов записываются в верхнем регистре. Вы обращаетесь к элементу через класс, и при печати выводятся имена класса и элемента:
```python
favourite = Color.GREEN
print(favourite)  # Color.GREEN
```

---

У каждого элемента перечисления есть два атрибута: `name` — идентификатор, который вы написали в классе, и `value` — значение, которое вы ему присвоили:
```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2

print(Color.GREEN.name)   # GREEN
print(Color.GREEN.value)  # 2
```
Значение может быть любого типа, не только целого числа: строки, кортежи и числа с плавающей запятой — распространённый выбор.
Элемент — это обычный объект, поэтому вы можете сохранить его в переменную и позже прочитать его атрибуты:
```python
chosen = Color.RED
print(chosen.value)  # 1
```

---

Каждый элемент перечисления существует **только в одном экземпляре**: каждый раз, когда вы пишете `Color.RED`, вы получаете тот же самый объект.
По этой причине вы можете сравнивать элементы с помощью `is` (идентичность), а также с помощью `==`, и оба способа дают одинаковый результат:
```python
print(Color.RED is Color.RED)  # True
print(Color.RED == Color.BLUE) # False
```
Элемент **не** равен своему исходному значению, потому что элемент и обычное число — разные вещи:
```python
print(Color.RED == 1)        # False
print(Color.RED.value == 1)  # True
```
Именно это делает перечисления безопасными: `1` из другого места программы нельзя принять за `Color.RED`.

---

Класс перечисления **итерируем**: цикл `for` по классу проходит по каждому элементу в том порядке, в котором они были объявлены:
```python
for color in Color:
    print(color.name, color.value)
```
`len()` возвращает количество элементов перечисления, а `list(Color)` строит список из них:
```python
print(len(Color))    # 3
print(list(Color))   # [<Color.RED: 1>, <Color.GREEN: 2>, <Color.BLUE: 3>]
```
Внутри списка элементы отображаются с помощью своего `repr()`, который включает значение в угловых скобках.

---

Вы можете получить элемент по его **значению**, вызвав класс как функцию, или по его **имени**, используя квадратные скобки:
```python
print(Color(2))        # Color.GREEN
print(Color["BLUE"])   # Color.BLUE
```
Оба способа удобны, когда значение или имя приходят извне программы, например из файла или пользовательского ввода.
Если ничего не совпадает, `Color(9)` вызывает `ValueError`, а `Color["PINK"]` вызывает `KeyError`.

---

Часто точные значения не важны: нужно лишь, чтобы элементы различались.
В этом случае вы можете позволить Python выбрать значения с помощью `auto()`, который также импортируется из модуля `enum`.
Он присваивает `1` первому элементу, а затем увеличивает счётчик:
```python
from enum import Enum, auto

class Direction(Enum):
    NORTH = auto()
    SOUTH = auto()
    EAST = auto()

print(Direction.EAST.value)  # 3
```

---

Обычный элемент `Enum` нельзя сравнивать с помощью `<` или прибавлять к числу.
Когда элементы представляют **уровни**, которые нужно упорядочивать, вместо этого наследуйтесь от `IntEnum`: его элементы также являются целыми числами, поэтому они поддерживают сравнения, арифметику и сортировку:
```python
from enum import IntEnum

class Priority(IntEnum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3

print(Priority.HIGH > Priority.LOW)  # True
print(Priority.LOW + 1)              # 2
print(int(Priority.MEDIUM))          # 2
```
Элемент `IntEnum` также равен своему целочисленному значению: `Priority.LOW == 1` — это `True`.

---

`StrEnum` (доступен начиная с Python 3.11) — это строковый аналог `IntEnum`: его элементы также являются строками и равны своему значению.
Это делает их удобными везде, где ожидаются обычные строки, например в ключах конфигурации или параметрах API:
```python
from enum import StrEnum

class Mode(StrEnum):
    LIGHT = "light"
    DARK = "dark"

print(Mode.DARK == "dark")  # True
print(Mode.DARK.upper())    # DARK
```
В отличие от обычного `Enum`, преобразование элемента `StrEnum` в текст с помощью `str()` или внутри f-строки даёт его **значение**, а не `Mode.DARK`.

---

Перечисление — это класс, поэтому оно может иметь **методы** и **свойства**, как любой другой класс.
Внутри них `self` — это элемент, для которого был вызван метод, поэтому вы можете обращаться к `self.name`, `self.value` или сравнивать `self` с другими элементами:
```python
from enum import Enum

class Light(Enum):
    RED = 1
    GREEN = 2

    def can_go(self):
        return self is Light.GREEN

    @property
    def label(self):
        return self.name.lower()

print(Light.GREEN.can_go())  # True
print(Light.RED.label)       # red
```
Любое обычное значение, присвоенное в теле класса, становится элементом, а функции и свойства — никогда, где бы они ни появлялись.

---

Если два элемента имеют одно и то же значение, второй не является новым элементом, а представляет собой **псевдоним** первого:
```python
class Status(Enum):
    ACTIVE = 1
    ENABLED = 1  # alias of ACTIVE

print(Status.ENABLED)  # Status.ACTIVE
print(len(Status))     # 1
```
Псевдонимы пропускаются при итерации и не учитываются `len()`.
Обычно дублирующееся значение — это ошибка. Декоратор `unique`, импортируемый из `enum`, заставляет Python вызвать `ValueError` сразу после объявления перечисления с псевдонимами:
```python
from enum import Enum, unique

@unique
class Status(Enum):
    ACTIVE = 1
    ENABLED = 1  # ValueError: duplicate values found
```

---

`Flag` — это перечисление, элементы которого можно **комбинировать**: значение может содержать несколько элементов одновременно, как набор опций.
Объявите его элементы с помощью `auto()`, который для `Flag` присваивает степени двойки (`1`, `2`, `4`, ...), так что каждая комбинация имеет отличающееся значение:
```python
from enum import Flag, auto

class Permission(Flag):
    READ = auto()
    WRITE = auto()
    EXECUTE = auto()
```
Используйте `|`, чтобы комбинировать элементы, `in`, чтобы проверить, входит ли элемент в комбинацию, и `value`, чтобы увидеть итоговое число:
```python
full = Permission.READ | Permission.WRITE | Permission.EXECUTE
print(Permission.WRITE in full)  # True
print(full.value)                # 7
print(full)                      # Permission.READ|WRITE|EXECUTE
```

---

Перечисления естественно сочетаются с инструкцией `match` (доступной начиная с Python 3.10), которая сравнивает значение с серией шаблонов `case` и выполняет первый совпавший:
```python
def action(light):
    match light:
        case Light.RED:
            return "Stop"
        case Light.GREEN:
            return "Go"
        case _:
            return "Slow down"
```
Всегда записывайте элемент с его классом, например `Light.RED`: голое имя, такое как `case RED:`, ничего не сравнит, оно просто захватит значение в новую переменную `RED` и совпадёт со всем.
Подстановочный `case _:` — это вариант по умолчанию, и он должен идти последним, потому что любой шаблон после него никогда не будет достигнут.

---

Элементы перечисления **хешируемы**, поэтому их можно использовать как ключи словаря и как элементы множества.
Словарь с ключами-элементами перечисления — это удобный способ привязать данные к каждому элементу, и поиск по элементу безопаснее, чем по обычной строке, в которой можно опечататься:
```python
class Size(Enum):
    SMALL = 1
    LARGE = 2

prices = {Size.SMALL: 2.5, Size.LARGE: 4.5}
print(prices[Size.LARGE])  # 4.5
```
Поскольку элементы могут находиться в любой коллекции, всё, что вы знаете о списках, множествах и генераторах, работает и с ними:
```python
order = [Size.LARGE, Size.SMALL, Size.LARGE]
print(len(set(order)))  # 2
```

---

Значением элемента может быть **кортеж**, что позволяет привязать к каждому элементу сразу несколько данных.
Если перечисление определяет метод `__init__`, Python вызывает его один раз для каждого элемента, распаковывая кортеж в его параметры, так что вы можете сохранить каждую часть в отдельном атрибуте:
```python
from enum import Enum

class Planet(Enum):
    EARTH = (5.97, 6371)
    MARS = (0.64, 3390)

    def __init__(self, mass, radius):
        self.mass = mass
        self.radius = radius

print(Planet.MARS.radius)  # 3390
print(Planet.MARS.value)   # (0.64, 3390)
```
При этом `value` элемента остаётся целым кортежем.

---

Перебор класса и поиск элементов по имени хорошо работают вместе, когда вы обрабатываете данные, приходящие извне, например строки лога или файл.
Генератор словаря по классу подготавливает по одной записи на каждый элемент, а затем `Level[name]` превращает каждую входящую строку в соответствующий элемент:
```python
counts = {level: 0 for level in Level}
counts[Level["INFO"]] += 1
```
Поскольку перечисление сохраняет порядок объявления, последующий перебор `counts` выдаёт элементы в том же порядке.

---

Кроме обычных методов, перечисление может определять **методы класса** с помощью `@classmethod`. Они получают сам класс перечисления как `cls`, поэтому это подходящее место для альтернативных способов найти элемент:
```python
class Color(Enum):
    RED = auto()
    BLUE = auto()

    @classmethod
    def parse(cls, text):
        return cls[text.strip().upper()]

print(Color.parse(" blue "))  # Color.BLUE
```
Вместе с `auto()`, методами, свойствами и поиском элементов это позволяет создавать перечисления, которые несут собственное поведение.
