# --description--

Именно выбор самого узкого типа, покрывающего ожидаемый сбой, делает обработку ошибок надёжной. Функция, читающая текст, должна восстанавливаться после плохого текста (`ValueError`), но не должна скрывать вызов с аргументом неверного вида (`TypeError`) — эта ошибка принадлежит вызывающему, так что пусть она проходит дальше.

# --instructions--

Напишите функцию `parse_age(text)`, которая возвращает `int(text)` и возвращает `-1`, когда `text` — не корректное целое число. Перехватывайте только `ValueError`, чтобы `parse_age(None)` по-прежнему вызывала `TypeError`

# --before-asserts--

import unittest

class CodigoTests(unittest.TestCase):

# --asserts--

`parse_age("30")` должна возвращать `30`

```python
    def test_1(self):
        self.assertEqual(parse_age("30"), 30, "--err-t1--")
```

`parse_age("old")` должна возвращать `-1`

```python
    def test_2(self):
        self.assertEqual(parse_age("old"), -1, "--err-t2--")
```

`parse_age(None)` по-прежнему должна вызывать `TypeError`

```python
    def test_3(self):
        with self.assertRaises(TypeError, msg="--err-t3--"):
            parse_age(None)
```

# --solutions--

```python
def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
```
