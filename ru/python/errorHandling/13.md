# --description--

Горстка встроенных исключений покрывает большинство повседневных сбоев:

| Exception | Raised when | Example |
|---|---|---|
| `ValueError` | тип правильный, но значение невозможно | `int("abc")` |
| `TypeError` | неверен сам тип | `"x" + 1` |
| `ZeroDivisionError` | у деления или остатка нулевой делитель | `1 / 0` |
| `KeyError` | в словаре нет такого ключа | `{"a": 1}["b"]` |
| `IndexError` | индекс последовательности вне диапазона | `[1, 2][5]` |

Обращение к одному из них вместо изобретения нового типа сохраняет ваши ошибки понятными любому, кто знает Python.

# --instructions--

Напишите функцию `get_item(values, index)`, которая возвращает `values[index]`, вызывает `ValueError` с сообщением `"index must be positive"`, когда `index` отрицательный, и возвращает `None`, когда индекс вне диапазона

# --asserts--

`get_item([1, 2, 3], 1)` должна возвращать `2`

```python
    def test_1(self):
        self.assertEqual(get_item([1, 2, 3], 1), 2, "--err-t1--")
```

`get_item([1, 2, 3], 9)` должна возвращать `None`

```python
    def test_2(self):
        self.assertIsNone(get_item([1, 2, 3], 9), "--err-t2--")
```

`get_item([1, 2, 3], -1)` должна вызывать `ValueError`, несущий это сообщение

```python
    def test_3(self):
        with self.assertRaises(ValueError, msg="--err-t3--") as ctx:
            get_item([1, 2, 3], -1)
        self.assertEqual(str(ctx.exception), "index must be positive", "--err-t3--")
```

# --solutions--

```python
def get_item(values, index):
    if index < 0:
        raise ValueError("index must be positive")
    try:
        return values[index]
    except IndexError:
        return None
```
