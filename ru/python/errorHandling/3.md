# --description--

Исключение, которому не соответствует ни один блок `except`, продолжает распространяться наружу: из строки, из функции, которая его вызвала, из её вызывающей функции и так далее. Если ничего не перехватит его до вершины программы, Python печатает трассировку, и процесс завершается с ненулевым кодом выхода. Строки после неудавшейся инструкции никогда не выполняются.

# --instructions--

Что произойдёт при выполнении этого кода?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- Он выводит `start`, затем трассировку, заканчивающуюся `TypeError`, и ни `end`, ни `after` не выводятся, потому что необработанное исключение останавливает программу
- Он выводит `start`, `end` и `after`, потому что Python пропускает только неудавшуюся строку
- Он выводит `start` и `after`, потому что исключение останавливает `sizes`, но программа продолжается
- Он выводит `start` и `0`, потому что `len(None)` равен `0`
