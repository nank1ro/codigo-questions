# --description--

`except:` без типа после себя — это **голый except**. Он соответствует всему, включая исключения, не имеющие никакого отношения к операции, которую вы защищали, поэтому правило простое: всегда называйте типы, от которых вы действительно можете восстановиться.

# --instructions--

Почему этому коду следует назвать конкретный тип исключения вместо голого `except:`?
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- Потому что голый `except:` перехватывает и посторонние сбои, такие как `NameError` из-за опечатки в `amout`, и настоящая ошибка молча превращается в `total = 0`
- Потому что голый `except:` медленнее, так как Python должен сравнивать исключение с каждым встроенным классом
- Потому что голый `except:` работает только на уровне модуля и вызывает `SyntaxError` внутри функции
- Потому что голый `except:` ничего не перехватывает, и исключение вызывается снова, как только блок заканчивается
