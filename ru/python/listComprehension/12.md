# --description--

Внутренний `for` может использовать переменную внешнего.
Это классический способ **сделать плоским** список списков, превратив его в один список:
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
Функция `sum()` затем складывает все числа списка.
