# --description--

Comprehension может содержать **больше одного `for`**.
Они работают как вложенные циклы: первый `for` — это внешний цикл, второй — внутренний.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
