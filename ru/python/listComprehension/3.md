# --description--

Comprehension также может **фильтровать** элементы.
Добавьте условие `if` после части `for`: только элементы, для которых условие равно `True`, попадают в новый список:
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
Это то же самое, что цикл с `if` внутри, и заменяет `filter()` с lambda более читаемым способом.
