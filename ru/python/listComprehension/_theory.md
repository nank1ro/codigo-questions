Очень частая задача — построить новый список на основе существующего.
С циклом `for` и `append()` это занимает несколько строк:
```python
nums = [1, 2, 3]
doubled = []
for n in nums:
    doubled.append(n * 2)
print(doubled)  # [2, 4, 6]
```
Python предлагает более короткую форму именно для этой задачи: **list comprehension**, которая строит весь список в одном выражении:
```python
doubled = [n * 2 for n in nums]
```
Синтаксис такой: `[выражение for элемент in итерируемый объект]`: часть `for` проходит по элементам, а выражение слева вычисляется для каждого из них.
Результат — совершенно новый список, точно такой же, как построенный с помощью цикла.

---

Выражение слева может быть чем угодно, что даёт значение: вычислением, вызовом функции, вызовом метода.
Переменная цикла может иметь любое имя и существует только внутри квадратных скобок:
```python
prices = [10, 20]
with_tax = [price * 1.2 for price in prices]
print(with_tax)  # [12.0, 24.0]
```

---

Comprehension также может **фильтровать** элементы.
Добавьте условие `if` после части `for`: только элементы, для которых условие равно `True`, попадают в новый список:
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
Это то же самое, что цикл с `if` внутри, и заменяет `filter()` с lambda более читаемым способом.

---

Условие фильтра может быть любым выражением, дающим логическое значение, включая вызовы функций вроде `len()`:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```

---

Итерируемый объект не обязательно должен быть списком: подходит всё, по чему можно пройтись циклом, а `range()` — один из любимых.
Это самый быстрый способ построить список чисел:
```python
squares = [n * n for n in range(4)]
print(squares)  # [0, 1, 4, 9]
```
Помните, что `range(start, stop)` не включает `stop`.

---

Comprehension отлично подходят для **преобразования строк**.
Вызовите строковый метод для каждого элемента или постройте новую строку с помощью f-строки:
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```

---

Внутри comprehension можно использовать любую переменную, определённую до неё, например, как предел для `range()`.

---

Иногда вы не хотите отбрасывать элементы, а хотите выбрать **другое значение** для некоторых из них.
Используйте условное выражение `a if условие else b` в качестве выражения, слева от `for`:
```python
nums = [3, -1, 4]
signs = ["+" if n > 0 else "-" for n in nums]
print(signs)  # ['+', '-', '+']
```
Обратите внимание на позицию: `if-else` стоит **перед** `for` и всегда даёт значение, тогда как фильтр `if` стоит **после** `for` и не имеет `else`.

---

Оба условия можно объединить в одной comprehension: `if-else` для выбора значения и фильтр `if` в конце, чтобы пропустить некоторые элементы.
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```

---

Две позиции `if` легко перепутать, поэтому различайте их:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else перед for: выбирает значение, else обязателен
positives = [n for n in nums if n > 0]      # if после for: фильтрует, else недопустим
```
`else` после фильтрующего `if` — это синтаксическая ошибка.

---

Comprehension может содержать **больше одного `for`**.
Они работают как вложенные циклы: первый `for` — это внешний цикл, второй — внутренний.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```

---

Внутренний `for` может использовать переменную внешнего.
Это классический способ **сделать плоским** список списков, превратив его в один список:
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
Функция `sum()` затем складывает все числа списка.

---

По **словарю** тоже можно проходить циклом.
С `.items()` часть `for` распаковывает каждую пару в две переменные — ключ и значение:
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```

---

Та же идея работает и для словарей: **dict comprehension** использует фигурные скобки и выражение `key: value`:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```

---

Фигурные скобки **без** части `key: value` дают **set comprehension**.
Set — это неупорядоченная коллекция, которая хранит только уникальные значения, поэтому дубликаты исчезают автоматически:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```

---

**Когда стоит использовать comprehension?**
Она идеальна, когда результатом является список (или dict, или set), а логика помещается в одну читаемую строку: простое преобразование, необязательный фильтр.
Если вам нужно несколько инструкций, больше двух вложенных `for`, или строка становится трудной для чтения, напишите вместо этого обычный цикл `for`: код будет длиннее, но понятнее.
Comprehension также заменяет большинство случаев использования `map()` и `filter()` с lambda:
```python
doubled = list(map(lambda n: n * 2, nums))
doubled = [n * 2 for n in nums]  # same result, easier to read
```
