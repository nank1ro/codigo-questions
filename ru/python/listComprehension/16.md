# --description--

**Когда стоит использовать comprehension?**
Она идеальна, когда результатом является список (или dict, или set), а логика помещается в одну читаемую строку: простое преобразование, необязательный фильтр.
Если вам нужно несколько инструкций, больше двух вложенных `for`, или строка становится трудной для чтения, напишите вместо этого обычный цикл `for`: код будет длиннее, но понятнее.
Comprehension также заменяет большинство случаев использования `map()` и `filter()` с lambda:
```python
doubled = list(map(lambda n: n * 2, nums))
doubled = [n * 2 for n in nums]  # same result, easier to read
```

def initials(names):
    return [name[0].upper() for name in names if name != ""]
