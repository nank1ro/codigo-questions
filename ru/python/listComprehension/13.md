# --description--

По **словарю** тоже можно проходить циклом.
С `.items()` часть `for` распаковывает каждую пару в две переменные — ключ и значение:
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
