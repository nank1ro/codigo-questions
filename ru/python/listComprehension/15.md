# --description--

Фигурные скобки **без** части `key: value` дают **set comprehension**.
Set — это неупорядоченная коллекция, которая хранит только уникальные значения, поэтому дубликаты исчезают автоматически:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```

# --instructions--

Что выведет этот код?
```python
words = ["hi", "yo", "hey"]
print({len(w) for w in words})
```
