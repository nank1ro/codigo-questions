# --description--

Внутри comprehension можно использовать любую переменную, определённую до неё, например, как предел для `range()`.

# --instructions--

Отсортируйте элементы, чтобы вывести кратные 7 числа ниже `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20

print(multiples)
```
