# --description--

Очень частая задача — построить новый список на основе существующего.
С циклом `for` и `append()` это занимает несколько строк:
```python
nums = [1, 2, 3]
doubled = []
for n in nums:
    doubled.append(n * 2)
print(doubled)  # [2, 4, 6]
```
Python предлагает более короткую форму именно для этой задачи: **list comprehension**, которая строит весь список в одном выражении:
```python
doubled = [n * 2 for n in nums]
```
Синтаксис такой: `[выражение for элемент in итерируемый объект]`: часть `for` проходит по элементам, а выражение слева вычисляется для каждого из них.
Результат — совершенно новый список, точно такой же, как построенный с помощью цикла.
