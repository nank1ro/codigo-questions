# --description--

Оба условия можно объединить в одной comprehension: `if-else` для выбора значения и фильтр `if` в конце, чтобы пропустить некоторые элементы.
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```
