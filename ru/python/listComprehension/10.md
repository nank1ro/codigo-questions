# --description--

Две позиции `if` легко перепутать, поэтому различайте их:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else перед for: выбирает значение, else обязателен
positives = [n for n in nums if n > 0]      # if после for: фильтрует, else недопустим
```
`else` после фильтрующего `if` — это синтаксическая ошибка.

# --instructions--

В чём __проблема__ с этим фрагментом кода?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- Фильтр `if` после `for` не может иметь `else`: `if-else` должен стоять перед `for`
- List comprehension не может содержать условие
- `nums` содержит отрицательное число, что недопустимо
- `else` нужно заменить на `elif`
