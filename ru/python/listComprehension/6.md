# --description--

Comprehension отлично подходят для **преобразования строк**.
Вызовите строковый метод для каждого элемента или постройте новую строку с помощью f-строки:
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
