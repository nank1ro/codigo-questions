# --instructions--

Что выводит этот код?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, потому что `c` — это другое имя для того же списка, что и `a`, поэтому добавление через `c` меняет `a` и делает его отличным от `b`
- `True True [1, 2]`, потому что `c = a` копирует список, поэтому `a` не меняется
- `True False [1, 2, 3]`, потому что `is` сравнивает значения, а `==` сравнивает идентичность
- `False False [1, 2, 3]`, потому что `append` создаёт новый список, поэтому `c` больше не ссылается на `a`
