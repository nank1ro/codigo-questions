# --description--

Поскольку `if value:` уже применяет истинностное значение, сравнение с `== True` или `== False` излишне и может быть даже неверным: `2 == True` — это `False`, хотя `2` истинно. Проверяйте само значение:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Напишите функцию `count_truthy(values)`, которая возвращает, сколько элементов списка `values` истинны

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
