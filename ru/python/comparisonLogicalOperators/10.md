# --description--

`==` сравнивает **значения**; `is` сравнивает **идентичность**, то есть указывают ли оба имени на один и тот же объект. Два одинаковых списка, созданных по отдельности, равны через `==`, но не через `is`:
```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)  # True False True
```
`is` предназначен для одиночных объектов вроде `None`, `True` и `False`: пишите `value is None` или `value is not None`, но никогда `value == None`, потому что класс может определить `==` так, чтобы он возвращал что угодно. Использовать `is` с числами или строками ненадёжно, и Python об этом предупреждает.

# --asserts--

`is_missing(None)` должна вернуть `True`

```python
    def test_1(self):
        self.assertIs(is_missing(None), True, "--err-t1--")
```

Ложные значения — это не `None`

```python
    def test_2(self):
        self.assertIs(is_missing(0), False, "--err-t2--")
        self.assertIs(is_missing(""), False, "--err-t2--")
        self.assertIs(is_missing([]), False, "--err-t2--")
        self.assertIs(is_missing(False), False, "--err-t2--")
```

Объект, чей `==` утверждает, что равен всему, всё равно не является `None`, поэтому проверка должна использовать идентичность

```python
    def test_3(self):
        class Anything:
            def __eq__(self, other):
                return True
        self.assertIs(is_missing(Anything()), False, "--err-t3--")
```
