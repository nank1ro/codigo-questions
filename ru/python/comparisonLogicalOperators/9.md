# --description--

Логические операторы вычисляются **с коротким замыканием**: `and` останавливается, как только операнд оказывается ложным, а `or` — как только истинным, потому что результат уже известен. Оставшиеся операнды никогда не вычисляются, поэтому если это вызовы функций, они не выполняются:
```python
def check(n):
    print("checking", n)
    return n > 0

check(-1) and check(5)  # prints only "checking -1"
check(2) or check(-3)   # prints only "checking 2"
```
