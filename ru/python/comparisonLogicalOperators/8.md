# --description--

`and` и `or` не всегда возвращают `True` или `False`: они возвращают один из своих **операндов**. `a and b` возвращает `a`, если он ложен, иначе `b`; `a or b` возвращает `a`, если он истинен, иначе `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
Результат истинен или ложен ровно тогда, когда таково всё выражение, поэтому `if a and b:` всё равно работает. Частое применение — значение по умолчанию: `name = user_input or "guest"`.

# --instructions--

Что выводит этот код?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, потому что `or` возвращает первый истинный операнд, а `and` — первый ложный, либо последний операнд, если такого нет
- `True False True`, потому что логические операторы всегда дают логическое значение
- `0 3 x`, потому что `and` и `or` всегда возвращают свой первый операнд
- `5 3 y`, потому что оба оператора возвращают истинный операнд
