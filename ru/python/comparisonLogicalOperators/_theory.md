Операторы сравнения сравнивают два значения и возвращают **логическое** значение, `True` или `False`: `==` равно, `!=` не равно, `<` меньше, `>` больше, `<=` меньше или равно, `>=` больше или равно:
```python
age = 18
print(age == 18)  # True
print(age != 18)  # False
print(age < 18)   # False
print(age >= 18)  # True
```
Результат можно сохранить в переменной или вывести напрямую. Одиночный `=` — это присваивание, а не сравнение.

---

Операторы сравнения не ограничиваются числами. Строки сравниваются посимвольно по их кодовым точкам, поэтому `"apple" < "banana"` — это `True`, и, поскольку каждая заглавная буква идёт перед строчными, `"Zoo" < "apple"` тоже `True`. Списки и кортежи сравниваются поэлементно тем же способом:
```python
print("cat" < "dog")       # True
print([1, 2, 3] < [1, 3])  # True
print((1, 2) == (1, 2))    # True
```
Сравнение — это выражение, поэтому функция может сразу написать `return a < b` вместо того, чтобы оборачивать его в `if`.

---

Сравнения можно **объединять в цепочку**: `1 < x < 10` проверяет, что `x` больше `1` **и** меньше `10`, ровно как `1 < x and x < 10`, но `x` вычисляется только один раз:
```python
x = 5
print(1 < x < 10)   # True
print(1 < x <= 5)   # True
print(10 < x < 20)  # False
```
В цепочку можно объединять любые операторы сравнения, и каждый применяется к своим двум соседям: `a < b == c` означает `a < b and b == c`. Чтение цепочки как диапазона, `low < x < high`, — самое частое применение.

---

Логические операторы объединяют логические значения. `and` даёт `True` только когда обе стороны `True`, `or` — когда хотя бы одна, а `not` переворачивает одно значение:
```python
age = 20
member = False
print(age >= 18 and member)  # False
print(age >= 18 or member)   # True
print(not member)            # True
```
Сравнения имеют более высокий приоритет, чем логические операторы, поэтому `age >= 18 and member` не требует скобок. Скобки нужны, чтобы сгруппировать `or` внутри `and`: `a and (b or c)`.

---

Когда `not`, `and` и `or` встречаются в одном выражении, Python применяет сначала `not`, затем `and`, затем `or`. Поэтому `a or b and c` означает `a or (b and c)`, а `not a == b` означает `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Когда нужна другая группировка, добавьте скобки; они также делают выражение легче для чтения.

---

У каждого значения есть **истинностное значение**. `bool(value)` возвращает `False` для `0`, `0.0`, `None`, пустой строки `""` и пустых контейнеров вроде `[]`, `{}` и `set()`; любое другое значение истинно, включая `"0"` и `[0]`:
```python
print(bool(0), bool(""), bool(None))   # False False False
print(bool(42), bool("0"), bool([0]))  # True True True
```
`if`, `while`, `and`, `or` и `not` используют это правило, поэтому `if items:` проверяет, что список не пуст, а `not name` проверяет, что строка пуста; писать `len(items) > 0` или `name == ""` не нужно.

---

Поскольку `if value:` уже применяет истинностное значение, сравнение с `== True` или `== False` излишне и может быть даже неверным: `2 == True` — это `False`, хотя `2` истинно. Проверяйте само значение:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

---

`and` и `or` не всегда возвращают `True` или `False`: они возвращают один из своих **операндов**. `a and b` возвращает `a`, если он ложен, иначе `b`; `a or b` возвращает `a`, если он истинен, иначе `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
Результат истинен или ложен ровно тогда, когда таково всё выражение, поэтому `if a and b:` всё равно работает. Частое применение — значение по умолчанию: `name = user_input or "guest"`.

---

Логические операторы вычисляются **с коротким замыканием**: `and` останавливается, как только операнд оказывается ложным, а `or` — как только истинным, потому что результат уже известен. Оставшиеся операнды никогда не вычисляются, поэтому если это вызовы функций, они не выполняются:
```python
def check(n):
    print("checking", n)
    return n > 0

check(-1) and check(5)  # prints only "checking -1"
check(2) or check(-3)   # prints only "checking 2"
```

---

`==` сравнивает **значения**; `is` сравнивает **идентичность**, то есть указывают ли оба имени на один и тот же объект. Два одинаковых списка, созданных по отдельности, равны через `==`, но не через `is`:
```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)  # True False True
```
`is` предназначен для одиночных объектов вроде `None`, `True` и `False`: пишите `value is None` или `value is not None`, но никогда `value == None`, потому что класс может определить `==` так, чтобы он возвращал что угодно. Использовать `is` с числами или строками ненадёжно, и Python об этом предупреждает.

---

Вычисление с коротким замыканием — безопасный способ **защитить** операцию, которая на некоторых значениях завершилась бы ошибкой. В `word is not None and len(word) < 4` `len(word)` выполняется только когда `word` не `None`, поэтому вызов никогда не вызывает ошибку. Защита должна идти первой:
```python
def is_short(word):
    return word is not None and len(word) < 4

print(is_short(None))   # False
print(is_short("cat"))  # True
```
Помните, что `and` возвращает операнд: `word and len(word) < 4` даёт `None` для `None` и `""` для пустой строки, а не `False`. Защищайте настоящим сравнением, когда требуется логическое значение.

---

Оператор `in` проверяет **вхождение**: находится ли элемент в списке, кортеже или множестве, содержится ли подстрока в строке, есть ли ключ в словаре. `not in` — его отрицание:
```python
fruits = ["apple", "pear"]
print("pear" in fruits)          # True
print("kiwi" not in fruits)      # True
print("ex" in "text")            # True
print("age" in {"name": "Ada"})  # False, only keys are checked
```
Оба возвращают логическое значение и читаются как английский текст, что делает их предпочтительным способом проверки вхождения вместо написания цикла.
