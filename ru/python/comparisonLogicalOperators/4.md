# --description--

Логические операторы объединяют логические значения. `and` даёт `True` только когда обе стороны `True`, `or` — когда хотя бы одна, а `not` переворачивает одно значение:
```python
age = 20
member = False
print(age >= 18 and member)  # False
print(age >= 18 or member)   # True
print(not member)            # True
```
Сравнения имеют более высокий приоритет, чем логические операторы, поэтому `age >= 18 and member` не требует скобок. Скобки нужны, чтобы сгруппировать `or` внутри `and`: `a and (b or c)`.

def is_leap(year):
    return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)
