# --description--

Вычисление с коротким замыканием — безопасный способ **защитить** операцию, которая на некоторых значениях завершилась бы ошибкой. В `word is not None and len(word) < 4` `len(word)` выполняется только когда `word` не `None`, поэтому вызов никогда не вызывает ошибку. Защита должна идти первой:
```python
def is_short(word):
    return word is not None and len(word) < 4

print(is_short(None))   # False
print(is_short("cat"))  # True
```
Помните, что `and` возвращает операнд: `word and len(word) < 4` даёт `None` для `None` и `""` для пустой строки, а не `False`. Защищайте настоящим сравнением, когда требуется логическое значение.
