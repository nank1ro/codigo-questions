# --instructions--

Расположите элементы так, чтобы определить словарь `users` и функцию `can_login`, которая использует `name in users` для защиты обращения, затем выведите результат для Ады с правильным паролем и для Грейс, которая не зарегистрирована, давая вывод `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
