# --description--

Операторы сравнения сравнивают два значения и возвращают **логическое** значение, `True` или `False`: `==` равно, `!=` не равно, `<` меньше, `>` больше, `<=` меньше или равно, `>=` больше или равно:
```python
age = 18
print(age == 18)  # True
print(age != 18)  # False
print(age < 18)   # False
print(age >= 18)  # True
```
Результат можно сохранить в переменной или вывести напрямую. Одиночный `=` — это присваивание, а не сравнение.
