# --description--

Когда `not`, `and` и `or` встречаются в одном выражении, Python применяет сначала `not`, затем `and`, затем `or`. Поэтому `a or b and c` означает `a or (b and c)`, а `not a == b` означает `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Когда нужна другая группировка, добавьте скобки; они также делают выражение легче для чтения.

# --instructions--

Что выводит этот код?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, потому что `and` применяется раньше `or`, поэтому выражение читается как `x == 3 or (x > 10 and x < 0)`
- `False`, потому что операторы применяются слева направо: `(x == 3 or x > 10) and x < 0`
- `False`, потому что `x < 0` ложно, а каждое условие в выражении должно выполняться
- `SyntaxError`, потому что `and` и `or` нельзя смешивать без скобок
