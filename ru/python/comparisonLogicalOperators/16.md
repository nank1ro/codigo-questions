# --description--

`any(iterable)` возвращает `True`, если хотя бы один элемент истинен, а `all(iterable)` — если истинны все (`all([])` даёт `True`). В сочетании с генераторным выражением они выражают условие для целой коллекции и работают с коротким замыканием, как `or` и `and`:
```python
print(any(ch.isdigit() for ch in "abc1"))  # True
print(all(ch.isalpha() for ch in "ab1"))   # False
```

```python
def is_valid_password(password):
    return (
        8 <= len(password) <= 20
        and any(ch.isdigit() for ch in password)
        and " " not in password
    )
```
