# --instructions--

Напишите функцию `is_vowel(ch)`, которая возвращает `True`, когда `ch` — ровно один символ и этот символ является гласной (`a`, `e`, `i`, `o`, `u`) в нижнем или верхнем регистре, и `False` для любой другой строки, включая пустую

# --asserts--

`is_vowel("a")` и `is_vowel("E")` должны вернуть `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` и `is_vowel("y")` должны вернуть `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Строки, которые не являются одним символом, должны вернуть `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```
