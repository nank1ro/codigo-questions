# --description--

Операторы сравнения не ограничиваются числами. Строки сравниваются посимвольно по их кодовым точкам, поэтому `"apple" < "banana"` — это `True`, и, поскольку каждая заглавная буква идёт перед строчными, `"Zoo" < "apple"` тоже `True`. Списки и кортежи сравниваются поэлементно тем же способом:
```python
print("cat" < "dog")       # True
print([1, 2, 3] < [1, 3])  # True
print((1, 2) == (1, 2))    # True
```
Сравнение — это выражение, поэтому функция может сразу написать `return a < b` вместо того, чтобы оборачивать его в `if`.


Заглавные буквы идут перед строчными, поэтому `comes_first("Zoo", "apple")` должна вернуть `True`

```python

        self.assertIs(comes_first("Zoo", "apple"), True, "--err-t3--")
```
