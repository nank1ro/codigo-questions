# --description--

Поскольку тело должно быть единственным выражением, lambda **не может содержать инструкции**.
Никакого `return`, блоков `if`, циклов или присваиваний:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Если вам нужно что-то из этого, напишите обычную функцию `def`.

# --instructions--

В чём __проблема__ этого фрагмента кода?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- Тело lambda — это выражение, оно не может содержать return
- Lambda нельзя сохранить в переменной
- Lambda нельзя вызвать с помощью скобок
- Lambda требует как минимум два параметра
