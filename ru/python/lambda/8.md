# --description--

Lambda, используемая в `key`, может выбрать любую часть элемента.
Для списка списков `lambda p: p[1]` сортирует по второму элементу каждого вложенного списка.

# --instructions--

Отсортируйте элементы, чтобы вывести людей от самого молодого к самому старшему

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
