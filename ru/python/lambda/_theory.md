Иногда нужна крошечная функция всего один раз, например чтобы удвоить число.
Писать для этого полноценный блок `def` кажется слишком громоздким.
Python предлагает более короткую форму: выражение **lambda**, _анонимную_ функцию, записанную в одну строку:
```python
lambda x: x * 2
```
Синтаксис такой: `lambda параметры: выражение`.
У lambda нет имени, но её можно сохранить в переменной и вызывать как обычную функцию:
```python
double = lambda x: x * 2
print(double(4))  # 8
```

---

Обратите внимание, что тело lambda не содержит ключевого слова `return`.
Тело — это **единственное выражение**, значение которого возвращается автоматически:
```python
square = lambda n: n * n
print(square(3))  # 9
```

---

Lambda может принимать **больше одного параметра**.
Разделяйте их запятыми, точно так же, как в функции `def`:
```python
power = lambda base, exp: base ** exp
print(power(2, 3))  # 8
```

---

Поскольку тело должно быть единственным выражением, lambda **не может содержать инструкции**.
Никакого `return`, блоков `if`, циклов или присваиваний:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Если вам нужно что-то из этого, напишите обычную функцию `def`.

---

Параметры lambda тоже поддерживают **значения по умолчанию**:
```python
greet = lambda name="World": f"Hello, {name}!"
print(greet())       # Hello, World!
print(greet("Ana"))  # Hello, Ana!
```

---

Lambda даже не обязательно сохранять: её можно **вызвать сразу же**.
Оберните lambda в скобки, а затем добавьте аргументы:
```python
print((lambda x: x + 1)(4))  # 5
```

---

По-настоящему lambda раскрывается как **аргумент, передаваемый другим функциям**.
`sorted()` принимает параметр `key`: функцию, вызываемую для каждого элемента, результат которой определяет порядок.
Lambda подходит для этого идеально:
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```

---

Lambda, используемая в `key`, может выбрать любую часть элемента.
Для списка списков `lambda p: p[1]` сортирует по второму элементу каждого вложенного списка.

---

`map()` применяет функцию к **каждому элементу** списка.
Она возвращает специальный _объект map_, поэтому оберните его в `list()`, чтобы увидеть значения:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```

---

`filter()` оставляет только те элементы, для которых функция возвращает `True`:
```python
nums = [5, 12, 8, 20]
big = list(filter(lambda n: n > 10, nums))
print(big)  # [12, 20]
```

---

Если вывести объект `map` напрямую, значений вы не увидите: получится что-то вроде `<map object at 0x7f2b1c>`.
Только `list()` (или цикл) превращает его в ожидаемые значения.

---

Lambda не ограничивается встроенными функциями: **ваши собственные функции** тоже могут принимать функцию в качестве параметра и вызывать её.
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

---

`max()` и `min()` тоже принимают функцию `key`, точно так же, как `sorted()`:
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

---

**Когда лучше предпочесть `def`?**
Lambda отлично подходит для короткой одноразовой функции, передаваемой в качестве аргумента.
Если логике нужно имя, несколько строк, docstring или она используется во многих местах, функция `def` понятнее.
Последняя хитрость: `sorted()` также принимает `reverse=True`, чтобы сначала получить наибольшие значения:
```python
print(sorted([3, 1, 2], reverse=True))  # [3, 2, 1]
```
