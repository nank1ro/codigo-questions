# --description--

Обратите внимание, что тело lambda не содержит ключевого слова `return`.
Тело — это **единственное выражение**, значение которого возвращается автоматически:
```python
square = lambda n: n * n
print(square(3))  # 9
```

Сохраните в переменной `square` lambda, которая принимает один параметр `n` и возвращает `n`, умноженное само на себя
