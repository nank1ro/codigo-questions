# --description--

Если вывести объект `map` напрямую, значений вы не увидите: получится что-то вроде `<map object at 0x7f2b1c>`.
Только `list()` (или цикл) превращает его в ожидаемые значения.

# --instructions--

Что выведет этот код?
```python
nums = [1, 2, 3]
print(list(map(lambda x: x + 1, nums)))
```

# --answers--

- [2, 3, 4]
- [1, 2, 3]
- 2 3 4
- <map object>
