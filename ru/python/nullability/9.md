# --description--

Оператор `or` не возвращает `True` или `False`: он возвращает свой **левый** операнд, если тот истинен, и **правый** операнд в противном случае. Это даёт способ предоставить запасное значение в одну строку:
```python
name = None
print(name or "anonymous")  # anonymous
name = "Ada"
print(name or "anonymous")  # Ada
```
Хитрость в том, что `or` смотрит на истинность, а не на `None`: `0`, `""` и `[]` тоже заменяются запасным значением. Используйте `x or fallback`, только когда каждое пустое значение тоже должно становиться запасным.

# --instructions--

Что выведет этот код?
```python
def label(count):
    return count or "unknown"

print(label(0), label(None), label(5))
```

# --answers--

- `unknown unknown 5`, потому что `0` ложен, поэтому он тоже заменяется запасным значением
- `0 unknown 5`, потому что только `None` заменяется запасным значением
- `False unknown 5`, потому что `or` преобразует `0` в логическое значение
- `True True True`, потому что `or` всегда возвращает логическое значение
