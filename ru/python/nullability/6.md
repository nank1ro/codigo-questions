# --description--

Чтение отсутствующего ключа из словаря с помощью `[]` вызывает `KeyError`. Метод `get` — безопасная альтернатива: он возвращает значение, когда ключ существует, и `None`, когда его нет:
```python
ages = {"Ada": 36}
print(ages.get("Ada"))    # 36
print(ages.get("Grace"))  # None
```
`get` принимает второй аргумент — значение, которое нужно вернуть **вместо** `None`, когда ключ отсутствует:
```python
print(ages.get("Grace", 0))  # 0
```
Это самый распространённый способ появления `None` в повседневном коде: поиск, который ничего не нашёл.
