# --description--

`None` считается **ложным** в условии, поэтому `if not value:` даёт `True`, когда `value` — это `None`. Соблазнительно использовать это как проверку на `None`, но тот же тест будет `True` и для `0`, `""`, `[]` и любого другого пустого значения:
```python
count = 0
if not count:
    print("missing?")   # printed, but 0 is a real value!
```
Когда "нет значения" и "пустое значение" должны обрабатываться по-разному, сначала проверьте `is None`, а затем истинность:
```python
if count is None:
    print("no count yet")
elif not count:
    print("count is zero")
```
Используйте `if not value:` только тогда, когда вы действительно хотите обрабатывать `None` и пустые значения одинаково.
