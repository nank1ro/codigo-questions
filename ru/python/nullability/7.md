# --description--

Функция, которая возвращает число **или** `None`, должна сообщать об этом в своей сигнатуре. **Аннотация типа** — это аннотация, которая документирует ожидаемый тип: `name: str` для параметра и `-> int` для возвращаемого значения. Python не требует соблюдать аннотации, но редакторы и читатели полагаются на них:
```python
def parse_age(text: str) -> int | None:
    if text.isdigit():
        return int(text)
    return None
```
`int | None` читается как "`int` или `None`". Более старая запись `Optional[int]` из модуля `typing` означает ровно то же самое, и вы всё ещё встретите её в существующем коде.
Каждый раз, видя `| None` в сигнатуре, не забывайте проверять результат перед использованием.

Возвращаемый тип должен быть аннотирован как `int | None`

```json
{
  "regex": "->\\s*(int\\s*\\|\\s*None|None\\s*\\|\\s*int|Optional\\[int\\])",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`parse_age("42")` должна возвращать `42`

```python
    def test_1(self):
        self.assertEqual(parse_age("42"), 42, "--err-t1--")
        self.assertIsInstance(parse_age("42"), int, "--err-t1--")
```

`parse_age("abc")` должна возвращать `None`

```python
    def test_2(self):
        self.assertIsNone(parse_age("abc"), "--err-t2--")
        self.assertIsNone(parse_age("4a"), "--err-t2--")
```

`parse_age("")` должна возвращать `None`

```python
    def test_3(self):
        self.assertIsNone(parse_age(""), "--err-t3--")
```
