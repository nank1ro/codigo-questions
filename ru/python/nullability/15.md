Результат должен быть `None`, когда ни у кого нет возраста, а возраст `0` должен учитываться

```python

        self.assertIsNone(oldest([]), "--err-t3--")
```

```python
def oldest(people):
    best_name = None
    best_age = None
    for person in people:
        age = person.get("age")
        if age is None:
            continue
        if best_age is None or age > best_age:
            best_age = age
            best_name = person["name"]
    return best_name
```
