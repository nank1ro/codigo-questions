# --description--

Список может содержать `None` рядом с настоящими значениями, например показания, которые не удалось снять, или ответы, которые были пропущены. Большинство операций не принимают его: `sum([8, None])` вызывает `TypeError`.
Отфильтруйте значения `None` с помощью генератора списка, условие которого — `is not None`:
```python
readings = [3, None, 5]
valid = [r for r in readings if r is not None]
print(valid)  # [3, 5]
```
Использование `if r` вместо этого отбросило бы и каждый `0`, поэтому будьте явны, когда ноль — допустимое показание.
