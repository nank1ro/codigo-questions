# --description--

Когда `0` или `""` нужно сохранить, а заменить только `None`, для запасного значения требуется явная проверка `is None`. Компактная форма — **условное выражение** `a if condition else b`, которое вычисляется в `a`, когда условие истинно, и в `b` в противном случае:
```python
timeout = 0
seconds = timeout if timeout is not None else 30
print(seconds)  # 0, not 30
```
