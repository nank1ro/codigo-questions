# --description--

Поиск с последующей проверкой на `None` обычно требует двух строк: одна для сохранения результата, другая для его проверки. Оператор **выражения присваивания** `:=`, по прозвищу *walrus*, присваивает значение **внутри** выражения, поэтому оба шага помещаются в `if`:
```python
ages = {"Ada": 36}
if (age := ages.get("Ada")) is not None:
    print(age + 1)  # 37
```
Скобки обязательны: без них `:=` попытается присвоить всё сравнение целиком. После `if` переменная `age` остаётся доступной, как и любая другая переменная.
