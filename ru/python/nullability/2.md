# --description--

Каждый вызов функции даёт значение, даже если функция, кажется, ничего не возвращает. Функция **без** инструкции `return` или с пустым `return` возвращает `None`:
```python
def say_hello():
    print("hello")

result = say_hello()
print(result)  # None
```
Именно поэтому вызов `print(my_list.append(3))` показывает `None`: `append` изменяет список на месте и не возвращает ничего.
Функция, которая только выполняет действие (печать, сохранение, изменение списка), обычно возвращает `None`, а функция, которая что-то вычисляет, должна явно вернуть результат с помощью `return`.
