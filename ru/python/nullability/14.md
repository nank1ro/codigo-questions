# --description--

`None` нельзя упорядочивать: `None < 1` вызывает `TypeError`, потому что Python понятия не имеет, будет ли "ничто" меньше или больше числа.
Это важно, когда `None` используется в качестве начального значения поиска, например "лучшее значение из увиденных, если оно есть". Каждое сравнение должно быть защищено проверкой `is None`, размещённой **первой**, чтобы `or` сокращал вычисление и сравнение пропускалось, когда пока не с чем сравнивать:
```python
if best is None or value > best:
    best = value
```
Написанное наоборот, `value > best or best is None` сравнивало бы с `None` на первой итерации и аварийно завершалось.

```python
def largest(values):
    best = None
    for value in values:
        if best is None or value > best:
            best = value
    return best
print(largest([3, 9, 4]))
print(largest([]))
```

None
