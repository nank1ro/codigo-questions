# --description--

Не всякое "не найдено" сообщается с помощью `None`. Некоторые старые функции возвращают вместо него **сторожевое** значение — обычное значение, которому придан особый смысл. Строковый метод `find` возвращает индекс подстроки или `-1`, когда её нет:
```python
print("banana".find("n"))  # 2
print("banana".find("x"))  # -1
```
Функция `re.match(pattern, text)` из модуля `re` проверяет, начинается ли `text` с `pattern`, и возвращает объект совпадения или `None`, когда совпадения нет.
`None` — более безопасное соглашение: `-1` является допустимым индексом, поэтому `text[text.find("x")]` молча возвращает последний символ вместо того, чтобы завершиться ошибкой, в то время как использование `None` в качестве индекса вызывает ошибку сразу.

# --instructions--

Что выведет этот код?
```python
import re

text = "banana"
print(text.find("x"), re.match("x", text))
```

- `None None`, потому что обе функции сообщают "не найдено" с помощью `None`
- `-1 -1`, потому что обе функции сообщают "не найдено" с помощью `-1`
- Ошибку `ValueError`, потому что `"x"` нет в тексте
