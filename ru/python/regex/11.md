# --description--

`re.sub(pattern, replacement, text)` возвращает новую строку, в которой заменено каждое совпадение. Строки неизменяемы, поэтому исходный текст остаётся нетронутым:
```python
import re

print(re.sub(r"\d", "#", "call 555 now"))     # call ### now
print(re.sub(r"\s+", " ", "too    many gaps"))  # too many gaps
```

В замене можно ссылаться на группы захвата через `\1`, `\2`, ... (или `\g<name>` для именованной группы), что превращает перестановку текста в однострочник. Замена — тоже сырая строка, по той же причине с обратным слэшем:
```python
import re

print(re.sub(r"(\w+), (\w+)", r"\2 \1", "Lovelace, Ada"))  # Ada Lovelace
```
Аргумент `count` ограничивает, сколько совпадений будет заменено: `re.sub(r"\d", "#", "1 2 3", count=1)` даёт `# 2 3`.

# --solutions--

```python
import re

def mask_digits(text):
    return re.sub(r"\d", "#", text)

def swap_names(text):
    return re.sub(r"(\w+), (\w+)", r"\2 \1", text)
```
