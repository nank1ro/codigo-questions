**Регулярное выражение** (regex) — это небольшой язык шаблонов, описывающий текст. В Python он предоставляется стандартным модулем `re`:
```python
import re
```

`re.search(pattern, text)` ищет шаблон в любом месте текста. Когда что-то найдено, она возвращает **объект match**, а когда нет — `None`. `match.group()` возвращает фрагмент текста, который совпал:
```python
import re

match = re.search(r"\d+", "order 42 shipped")
print(match.group())  # 42
```

Здесь работу выполняют два элемента шаблона. `\d` означает *любую цифру*, а `+` — *один или несколько предыдущих элементов*, поэтому `\d+` читается как «одна или несколько цифр». Другие полезные сокращения — `\w` (буква, цифра или подчёркивание) и `\s` (пробел, табуляция или перевод строки).

Шаблоны записываются как **сырые строки** — с буквой `r` перед кавычками. В обычной строке Python обратный слэш начинает экранирующую последовательность, поэтому `"\d"` — предупреждение, которое только ждёт своего часа, а `"\n"` превратился бы в настоящий перевод строки вместо двух символов, которые ожидает движок регулярных выражений. Префикс `r` снова делает обратный слэш обычным символом, так что `r"\d"` — это ровно то, что получает движок. Всегда используйте `r"..."` для шаблонов.

---

`re.search` просматривает весь текст, а `re.match` пробует шаблон только в **самом начале**:
```python
import re

print(re.search(r"\d+", "order 42"))  # <re.Match object; span=(6, 8), match='42'>
print(re.match(r"\d+", "order 42"))   # None
print(re.match(r"\d+", "42 orders"))  # <re.Match object; span=(0, 2), match='42'>
```

Обе функции возвращают `None`, когда совпадения нет, а объект match всегда истинен, поэтому обычный способ спросить «есть ли совпадение?» — простой `if`:
```python
if re.search(r"\d", text):
    print("there is a digit")
```
Когда требуется настоящее `True` или `False`, сравнивайте с `is not None` или оборачивайте вызов в `bool(...)`.

---

Есть и третий вход в библиотеку — `re.fullmatch`, который завершается успехом, только когда шаблон покрывает **весь** текст от первого символа до последнего. Это правильный инструмент для валидации:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

Таким образом, три функции различаются лишь тем, где шаблону позволено находиться: `re.match` — в начале текста, `re.search` — в любом месте текста, а `re.fullmatch` — по всему тексту целиком.

---

Объект match несёт больше информации, чем совпавший текст. Помимо `.group()` он предоставляет позицию совпадения внутри исходной строки:
```python
import re

match = re.search(r"\d+", "order 42 shipped")
print(match.group())  # 42
print(match.start())  # 6
print(match.end())    # 8
print(match.span())   # (6, 8)
```
`.start()` — это индекс первого совпавшего символа, `.end()` — индекс сразу после последнего, а `.span()` возвращает оба числа в виде кортежа. Это значит, что `text[match.start():match.end()]` всегда равен `match.group()`.

Поскольку `re.search` может вернуть `None`, чтение `.group()` сразу же вызовет `AttributeError`, когда совпадения не было; сначала проверьте результат.

---

Круглые скобки внутри шаблона создают **группу захвата**: часть совпадения, которую можно прочитать отдельно. Группы нумеруются слева направо, начиная с `1`:
```python
import re

match = re.search(r"(\w+)@(\w+)", "write to ada@example today")
print(match.group())   # ada@example
print(match.group(1))  # ada
print(match.group(2))  # example
print(match.groups())  # ('ada', 'example')
```
`match.group(0)` — это всё совпадение, точно так же, как `match.group()`, а `match.groups()` возвращает все группы в виде кортежа. Запрос номера группы, которой не существует, вызывает `IndexError`.

---

Считать скобки, чтобы найти группу `3`, быстро надоедает. Группе можно дать имя с помощью `(?P<name>...)`, а затем прочитать её через `match.group("name")`:
```python
import re

match = re.search(r"(?P<hour>\d\d):(?P<minute>\d\d)", "starts at 09:30")
print(match.group("hour"))    # 09
print(match.group("minute"))  # 30
print(match.groupdict())      # {'hour': '09', 'minute': '30'}
```
`match.groupdict()` возвращает все именованные группы в виде словаря. Именованные группы сохраняют и свой номер, поэтому `match.group(1)` по-прежнему работает.

В примере также используется **квантификатор** с фигурными скобками: `\d{2}` означает ровно две цифры, `\d{2,4}` — от двух до четырёх, а `\d{2,}` — две и более. Это точная версия `+` (один или более), `*` (ноль или более) и `?` (ноль или один).

---

Квадратные скобки задают **класс символов**: набор символов, любой из которых принимается в этой позиции. `[aeiou]` совпадает с одной гласной, `[0-9]` — с одной цифрой, `[a-z]` — с одной строчной буквой. `^` сразу после открывающей скобки меняет смысл на противоположный, поэтому `[^0-9]` совпадает со всем, что *не* цифра.

Вне класса `^` и `$` — это **якоря**: `^` привязывает шаблон к началу текста, а `$` — к концу. У `re.fullmatch` якоря подразумеваются неявно, поэтому валидация с ним читается лучше:
```python
import re

print(bool(re.fullmatch(r"[a-z]{3,8}", "ada")))  # True
print(bool(re.fullmatch(r"[a-z]{3,8}", "Ada")))  # False
```

---

`re.search` останавливается на первом совпадении. `re.findall(pattern, text)` вместо этого собирает **все** совпадения и возвращает их списком строк:
```python
import re

print(re.findall(r"\d+", "a1 bb22 ccc333"))  # ['1', '22', '333']
print(re.findall(r"\d+", "no digits"))       # []
```
Когда совпадений нет, список пуст, поэтому никакого `None` проверять не нужно: его сразу можно обойти в цикле или измерить через `len(...)`. Обратите внимание: `findall` возвращает обычные строки, а не объекты match, поэтому позиции недоступны.

---

Когда нужны позиция или группы каждого совпадения, правильный выбор — `re.finditer(pattern, text)`: он проходит по тексту и выдаёт **объект match** для каждого совпадения, по одному за раз:
```python
import re

for match in re.finditer(r"\d+", "a1 bb22"):
    print(match.group(), match.start())
# 1 1
# 22 5
```
`finditer` создаёт итератор, а не список, поэтому его можно использовать в цикле `for` или в генераторе. Там, где `findall` даёт только текст, `finditer` даёт всё, что знает объект match.

---

`findall` меняет поведение, когда шаблон содержит группы захвата. Ровно с одной группой он возвращает содержимое этой группы вместо всего совпадения, а с двумя и более — кортеж групп для каждого совпадения:
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
Это стоит запомнить: добавление скобок в шаблон только ради группировки молча меняет то, что возвращает `findall`. `re.finditer` так никогда не делает, потому что объект match всегда хранит и всё совпадение, и группы.

---

`re.sub(pattern, replacement, text)` возвращает новую строку, в которой заменено каждое совпадение. Строки неизменяемы, поэтому исходный текст остаётся нетронутым:
```python
import re

print(re.sub(r"\d", "#", "call 555 now"))     # call ### now
print(re.sub(r"\s+", " ", "too    many gaps"))  # too many gaps
```

В замене можно ссылаться на группы захвата через `\1`, `\2`, ... (или `\g<name>` для именованной группы), что превращает перестановку текста в однострочник. Замена — тоже сырая строка, по той же причине с обратным слэшем:
```python
import re

print(re.sub(r"(\w+), (\w+)", r"\2 \1", "Lovelace, Ada"))  # Ada Lovelace
```
Аргумент `count` ограничивает, сколько совпадений будет заменено: `re.sub(r"\d", "#", "1 2 3", count=1)` даёт `# 2 3`.

---

Заменой в `re.sub` может быть и **функция**. Она вызывается один раз для каждого совпадения, получает объект match и должна вернуть строку, которую нужно поставить на его место. Так замена может зависеть от того, что именно совпало:
```python
import re

def shout(match):
    return match.group().upper()

print(re.sub(r"[a-z]+", shout, "one two"))  # ONE TWO
```
Функция передаётся по имени, без скобок: запись `shout(match)` вызвала бы её немедленно вместо передачи в `re.sub`.

---

`str.split` может разрезать строку только по фиксированному разделителю. `re.split(pattern, text)` режет по всему, что описывает шаблон, — именно это обычно нужно для неаккуратного ввода:
```python
import re

print("a, b;c".split(","))            # ['a', ' b;c']
print(re.split(r"[,;]", "a, b;c"))    # ['a', ' b', 'c']
print(re.split(r"[,;\s]+", "a, b;c")) # ['a', 'b', 'c']
```
Запись разделителя как `[,;\s]+` заставляет целую последовательность запятых, точек с запятой и пробелов считаться одним разрезом, а не оставлять пустые строки между ними.

Аргумент `maxsplit` останавливается после заданного числа разрезов, оставляя остаток текста в последнем элементе: `re.split(r"\s+", "a b c", maxsplit=1)` даёт `['a', 'b c']`.

---

Каждый вызов `re.search` или `re.findall` сначала должен искать строку шаблона во внутреннем кэше. `re.compile(pattern)` пропускает этот поиск и возвращает **объект pattern**, несущий те же методы:
```python
import re

word_re = re.compile(r"[a-z]+")
print(word_re.search("ab 12").group())  # ab
print(word_re.findall("cd ef"))         # ['cd', 'ef']
print(word_re.sub("*", "ab cd"))        # * *
```
Текст остаётся единственным аргументом, потому что шаблон уже встроен в объект. Компиляция окупается, когда один и тот же шаблон используется много раз, например внутри цикла, а ещё она даёт шаблону имя, объясняющее, с чем он совпадает.

---

**Флаги** меняют то, как применяется шаблон. Каждая функция в `re` принимает их как аргумент `flags`, а `re.compile` сохраняет их в объекте pattern:
```python
import re

print(re.search(r"cat", "A Cat", flags=re.IGNORECASE).group())  # Cat
title_re = re.compile(r"^#.*", re.MULTILINE)
```
Два самых употребительных — `re.IGNORECASE`, который позволяет буквам совпадать в любом регистре, и `re.MULTILINE`, из-за которого `^` и `$` совпадают в начале и в конце каждой строки, а не всего текста. Несколько флагов объединяются через `|`, как в `re.IGNORECASE | re.MULTILINE`.

Флаг меняет только правила сопоставления: возвращаемый текст — это всегда текст, который действительно был в строке, в своём исходном регистре.
