# --instructions--

Определите скомпилированный шаблон `PAIR_RE`, который совпадает с настройкой в виде одной или нескольких букв, знака `=` и одной или нескольких цифр, где обе части находятся в именованных группах `key` и `value`; затем напишите функцию `parse_settings(text)`, которая возвращает словарь, сопоставляющий каждый найденный в тексте ключ его значению в виде `int`

    def test_1(self):

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
