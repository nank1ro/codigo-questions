# --description--

`re.search` просматривает весь текст, а `re.match` пробует шаблон только в **самом начале**:
```python
import re

print(re.search(r"\d+", "order 42"))  # <re.Match object; span=(6, 8), match='42'>
print(re.match(r"\d+", "order 42"))   # None
print(re.match(r"\d+", "42 orders"))  # <re.Match object; span=(0, 2), match='42'>
```

Обе функции возвращают `None`, когда совпадения нет, а объект match всегда истинен, поэтому обычный способ спросить «есть ли совпадение?» — простой `if`:
```python
if re.search(r"\d", text):
    print("there is a digit")
```
Когда требуется настоящее `True` или `False`, сравнивайте с `is not None` или оборачивайте вызов в `bool(...)`.

# --solutions--

```python
import re

def has_digit(text):
    return re.search(r"\d", text) is not None

def starts_with_digit(text):
    return re.match(r"\d", text) is not None
```
