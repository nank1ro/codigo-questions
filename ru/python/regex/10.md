# --description--

`findall` меняет поведение, когда шаблон содержит группы захвата. Ровно с одной группой он возвращает содержимое этой группы вместо всего совпадения, а с двумя и более — кортеж групп для каждого совпадения:
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
Это стоит запомнить: добавление скобок в шаблон только ради группировки молча меняет то, что возвращает `findall`. `re.finditer` так никогда не делает, потому что объект match всегда хранит и всё совпадение, и группы.

# --instructions--

Что выведет этот код?
```python
import re

print(re.findall(r"(\w+)@(\w+)", "ada@example bob@test"))
```

# --answers--

- `[('ada', 'example'), ('bob', 'test')]`, потому что при более чем одной группе `findall` возвращает кортеж групп для каждого совпадения
- `['ada@example', 'bob@test']`, потому что `findall` всегда возвращает текст всего совпадения
- `['ada', 'example', 'bob', 'test']`, потому что `findall` кладёт каждую группу каждого совпадения в один плоский список
- `[]`, потому что шаблон с группами захвата можно использовать только с `re.finditer`
