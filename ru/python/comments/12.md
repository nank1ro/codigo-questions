# --description--

Docstring должен быть **первой строкой тела**, выше всех остальных инструкций. Строка, записанная после `return` или где угодно ещё в теле, — просто строка: `__doc__` остаётся `None`, и никакой инструмент её никогда не покажет.

# --instructions--

Расположите элементы по порядку, чтобы получить программу, которая определяет `to_seconds` с docstring в качестве первой строки тела, а затем выводит `to_seconds(2)`
