# --description--

Docstring и комментарии `#` выглядят похоже, но отвечают на разные вопросы.

**Docstring** — для тех, кто **использует** код: что делает функция, что она ожидает и что возвращает. Она сохраняется в `__doc__`, её читает `help()`, показывают редакторы и собирают инструменты документации.

**Комментарий** — для тех, кто **читает** код: почему эта строка написана именно так, что означает странное число, какую ошибку он обходит. Он существует только в файле с исходным кодом и исчезает, как только программа запускается.

```python
def timeout():
    """Returns the number of seconds to wait for the server."""
    # сервер разрывает неактивные соединения через 35 секунд
    return 30
```
Итог: документация функции идёт в docstring, а заметки о реализации — в комментарии.

В чём разница между docstring и комментарием `#`?

# --answers--

- Docstring — это строка, которая хранится в `__doc__` и показывается инструментами, а комментарий `#` существует только в файле с исходным кодом
- Разницы нет: оба отбрасываются до запуска программы
- Docstring можно использовать только внутри функции, а комментарий `#` — где угодно
- Комментарий `#` хранится в `__doc__`, а docstring отбрасывается до запуска программы
