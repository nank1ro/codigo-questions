# --description--

Python ищет `#` только в коде и никогда — внутри **строки**. Между кавычками `#` — обычный символ:
```python
print("black is #000000")  # a hex colour
```
Первый `#` — часть текста, а второй начинает настоящий комментарий. То же верно для `"""` внутри комментария `#`: там это просто три символа кавычек, которые ничего не начинают.
