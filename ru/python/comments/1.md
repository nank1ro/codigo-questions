# --description--

**Комментарий** — это заметка внутри исходного кода, написанная для тех, кто его читает. Python полностью игнорирует комментарии, поэтому они никогда не меняют то, что делает программа.

Единственный вид комментариев, который есть в Python, — **однострочный комментарий**: он начинается с `#` и продолжается до конца строки.
```python
# Приветствует пользователя
print("Hello")
```
Используйте комментарии, чтобы объяснить, для чего нужен фрагмент кода или почему он написан именно так.
