# --description--

Во многих языках есть второй вид комментариев — **блочный комментарий**, который занимает несколько строк, например `/* ... */`. В Python такого синтаксиса нет: есть только `#`.

Когда объяснению нужно больше одной строки, поставьте `#` в начале каждой строки:
```python
# Выводит приветственный баннер.
# Вызывается один раз при запуске приложения.
print("Welcome!")
```
Тот же приём закомментирует сразу несколько строк кода: один `#` на строку. Любой редактор умеет добавлять и убирать такие `#` у целого выделения одним сочетанием клавиш, так что на деле это дешевле, чем кажется.
