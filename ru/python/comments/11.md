# --description--

Когда одной строки мало, docstring разрастается в фиксированную структуру, описанную в **PEP 257**: краткое описание в одну строку, пустая строка, затем подробности, а закрывающая `"""` — на отдельной строке.
```python
def to_seconds(minutes):
    """Returns the number of seconds in the given minutes.

    minutes is a whole number and is never negative.
    """
    return minutes * 60
```
Пустая строка важна: инструменты показывают первую строку отдельно, как краткое описание, и оставляют остальное тем, кто захочет читать дальше.

```python
    def test_1(self):

```

Docstring должен начинаться со строки описания, за которой идут пустая строка и ещё текст

```python
    def test_2(self):
        lines = area.__doc__.split("\n")
        self.assertTrue(len(lines) >= 3, "--err-t2--")
        self.assertNotEqual(lines[0].strip(), "", "--err-t2--")
        self.assertEqual(lines[1].strip(), "", "--err-t2--")
        self.assertNotEqual(lines[2].strip(), "", "--err-t2--")
        self.assertEqual(lines[-1].strip(), "", "--err-t2--")
```

`area(3, 4)` должна возвращать `12`, а `area(0, 5)` — `0`

```python
    def test_3(self):
        self.assertEqual(area(3, 4), 12, "--err-t3--")
        self.assertEqual(area(0, 5), 0, "--err-t3--")
```
