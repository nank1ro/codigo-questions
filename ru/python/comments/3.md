# --description--

Поскольку Python полностью отбрасывает комментарии, добавление или удаление комментария никогда не меняет то, что делает программа. Выполняется только код, который **не** закомментирован.

Поэтому `#` — быстрый способ выключить строку кода, не удаляя её. Это называется **закомментированием**:
```python
total = 10
# total = total + 5
print(total)  # prints 10
```
Вторая строка теперь комментарий, поэтому `total` остаётся `10`. Удалите `#` — и строка снова оживёт.

Закомментирование удобно во время экспериментов, но не забывайте прибираться: код, который долго остаётся закомментированным, только путает того, кто будет читать его следующим.
