# --description--

Часто можно встретить **строку в тройных кавычках**, используемую так, будто это блочный комментарий:
```python
"""
This looks like a comment,
but it is a string.
"""
print("done")
```
Строка между `"""` и `"""` может занимать несколько строк, а строка, записанная сама по себе, — это корректная инструкция: Python создаёт её, ничего с ней не делает и выбрасывает. Ничего не выводится, поэтому результат выглядит как комментарий.

Но комментарием она не является. Это строковый литерал, поэтому правила кавычек остаются в силе: непарная кавычка или лишняя `"""` внутри сломают программу, тогда как внутри комментария `#` допустимо всё. Такая строка может и случайно стать docstring, если окажется первой инструкцией файла, класса или функции. Во всех остальных местах она просто никуда не попадает: CPython выбрасывает всю инструкцию ещё при компиляции.

Так что чтобы выключить код, используйте `#`. У строки в тройных кавычках своя собственная роль — она начинается в следующем упражнении.
