# --description--

**Множество** — это коллекция **уникальных** элементов: одно и то же значение может встречаться только один раз, сколько бы раз вы его ни написали.
Множество также **неупорядочено**: у него нет первого или последнего элемента, поэтому вы не можете прочитать элемент по индексу.
Множества идеальны, когда важно только то, *какие* значения присутствуют, а не сколько раз или в какой позиции.
Вы создаёте множество, записывая его элементы в фигурных скобках `{...}`:
```python
colors = {"red", "blue", "red"}
print(len(colors))  # 2
```
Дубликат `"red"` отбрасывается, поэтому `len()` считает только различающиеся элементы.
