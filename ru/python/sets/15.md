# --description--

Операции с множествами также могут изменять множество **на месте** вместо возврата нового.
`update(iterable)` добавляет каждый элемент любой коллекции, как `add()`, но сразу для многих значений:
```python
inventory = {"sword"}
inventory.update(["potion", "map"])
print(len(inventory))  # 3
```
Составные операторы тоже работают на месте: `|=` добавляет элементы другого множества, `&=` оставляет только общие, `-=` удаляет элементы другого множества:
```python
inventory -= {"map"}
print(sorted(inventory))  # ['potion', 'sword']
```
