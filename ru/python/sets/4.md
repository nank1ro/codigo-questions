# --description--

Множества **изменяемы**: вы можете добавлять и удалять элементы после их создания.
`add(value)` вставляет значение; добавление уже присутствующего значения ничего не меняет:
```python
letters = {"a", "b"}
letters.add("c")
letters.add("a")
print(len(letters))  # 3
```
Есть два способа удалить элемент:
- `remove(value)` удаляет его, но вызывает `KeyError`, если значения нет в множестве
- `discard(value)` удаляет его, если он присутствует, и **ничего не делает** в противном случае, без ошибки
```python
letters.remove("a")
letters.discard("z")  # "z" is not there, but no error
letters.remove("z")   # KeyError: 'z'
```
