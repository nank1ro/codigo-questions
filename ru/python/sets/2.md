# --description--

Встроенная функция `set()` строит множество из любой коллекции, например списка или строки.
Поскольку множество хранит каждое значение только один раз, это классический способ **удалить дубликаты**:
```python
nums = [1, 2, 2, 3]
unique = set(nums)
print(len(unique))  # 3
```
Чтобы проверить, присутствует ли значение, используйте оператор `in`, который возвращает `True` или `False`:
```python
print(2 in unique)  # True
print(9 in unique)  # False
```
Проверка принадлежности элемента множеству выполняется очень быстро, даже при тысячах элементов.
