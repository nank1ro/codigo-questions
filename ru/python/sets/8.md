# --description--

**Пересечение** двух множеств содержит только элементы, присутствующие в **обоих**.
Используйте оператор `&` или метод `intersection()`:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
Если у множеств нет ничего общего, результатом будет пустое множество.
