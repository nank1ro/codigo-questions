# --description--

Есть ловушка при создании **пустого множества**.
Фигурные скобки — это также синтаксис словарей, поэтому `{}` создаёт пустой **словарь**, а не множество:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Чтобы получить пустое множество, нужно вызвать `set()` без аргументов:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

Что выведет этот код?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, потому что `{}` создаёт пустой словарь
- `<class 'set'>`, потому что фигурные скобки создают множество
- `<class 'NoneType'>`, потому что у множества нет элементов
- Ошибку `SyntaxError`, потому что скобки должны содержать хотя бы один элемент
