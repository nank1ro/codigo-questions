# --description--

`pop()` удаляет **произвольный элемент** из множества и возвращает его.
Поскольку у множества нет порядка, вы не можете выбрать, какой элемент будет удалён; вызов `pop()` на пустом множестве вызывает `KeyError`:
```python
tickets = {101, 102, 103}
picked = tickets.pop()
print(len(tickets))  # 2
```
`clear()` удаляет **все** элементы, оставляя пустое множество:
```python
tickets.clear()
print(len(tickets))  # 0
```
