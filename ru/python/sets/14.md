# --description--

**Генератор множеств** (set comprehension) строит множество в одном выражении, с тем же синтаксисом, что и list comprehension, но с фигурными скобками:
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
Необязательное `if` фильтрует элементы, а дубликаты, порождённые выражением, отбрасываются автоматически:
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```
