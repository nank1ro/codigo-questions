# --description--

**frozenset** — это **неизменяемое** множество: после создания вы не можете добавлять или удалять элементы.
Создайте его с помощью `frozenset()` из любой коллекции:
```python
days = frozenset(["sat", "sun"])
print("sat" in days)  # True
days.add("mon")       # AttributeError: 'frozenset' object has no attribute 'add'
```
При выводе frozenset его тип отображается вокруг элементов, например `frozenset({'sat', 'sun'})`.
Поскольку он не может изменяться, frozenset хешируем: в отличие от обычного множества, он может быть элементом другого множества или ключом словаря.
Все операции только для чтения (`in`, `len()`, `|`, `&`, `-`, `^`, сравнения) работают как обычно.
