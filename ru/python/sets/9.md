# --description--

**Разность** `a - b` содержит элементы `a`, которых **нет** в `b`.
Порядок имеет значение: `a - b` и `b - a` обычно отличаются:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**Симметрическая разность** `a ^ b` содержит элементы, которые есть **ровно в одном** из двух множеств:
```python
print(a ^ b)  # {1, 4}
```
Методы для этого — `difference()` и `symmetric_difference()`.
