# --description--

Два множества **равны**, когда содержат одинаковые элементы, независимо от порядка, в котором они были записаны:
```python
print({1, 2, 3} == {3, 1, 2})  # True
```
Сравнение длины коллекции с длиной её множества — быстрый способ обнаружить дубликаты: если множество **меньше**, какое-то значение встретилось более одного раза:
```python
emails = ["a@x.com", "b@x.com", "a@x.com"]
print(len(set(emails)) < len(emails))  # True
```
Метод списка `count(value)` показывает, сколько раз встречается значение, что помогает найти, *какие* значения дублируются.
