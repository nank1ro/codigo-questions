# --description--

Вы можете перебирать множество с помощью `for`, точно так же, как список:
```python
for color in {"red", "blue"}:
    print(color)
```
Поскольку множество неупорядочено, элементы могут появляться в **любом порядке**, и этот порядок может даже меняться между запусками.
Когда вам нужен предсказуемый порядок, передайте множество в `sorted()`, которая возвращает отсортированный **список** его элементов:
```python
for color in sorted({"red", "blue"}):
    print(color)  # blue, then red
```
