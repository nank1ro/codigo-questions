**Множество** — это коллекция **уникальных** элементов: одно и то же значение может встречаться только один раз, сколько бы раз вы его ни написали.
Множество также **неупорядочено**: у него нет первого или последнего элемента, поэтому вы не можете прочитать элемент по индексу.
Множества идеальны, когда важно только то, *какие* значения присутствуют, а не сколько раз или в какой позиции.
Вы создаёте множество, записывая его элементы в фигурных скобках `{...}`:
```python
colors = {"red", "blue", "red"}
print(len(colors))  # 2
```
Дубликат `"red"` отбрасывается, поэтому `len()` считает только различающиеся элементы.

---

Встроенная функция `set()` строит множество из любой коллекции, например списка или строки.
Поскольку множество хранит каждое значение только один раз, это классический способ **удалить дубликаты**:
```python
nums = [1, 2, 2, 3]
unique = set(nums)
print(len(unique))  # 3
```
Чтобы проверить, присутствует ли значение, используйте оператор `in`, который возвращает `True` или `False`:
```python
print(2 in unique)  # True
print(9 in unique)  # False
```
Проверка принадлежности элемента множеству выполняется очень быстро, даже при тысячах элементов.

---

Есть ловушка при создании **пустого множества**.
Фигурные скобки — это также синтаксис словарей, поэтому `{}` создаёт пустой **словарь**, а не множество:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Чтобы получить пустое множество, нужно вызвать `set()` без аргументов:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

---

Множества **изменяемы**: вы можете добавлять и удалять элементы после их создания.
`add(value)` вставляет значение; добавление уже присутствующего значения ничего не меняет:
```python
letters = {"a", "b"}
letters.add("c")
letters.add("a")
print(len(letters))  # 3
```
Есть два способа удалить элемент:
- `remove(value)` удаляет его, но вызывает `KeyError`, если значения нет в множестве
- `discard(value)` удаляет его, если он присутствует, и **ничего не делает** в противном случае, без ошибки
```python
letters.remove("a")
letters.discard("z")  # "z" is not there, but no error
letters.remove("z")   # KeyError: 'z'
```

---

`pop()` удаляет **произвольный элемент** из множества и возвращает его.
Поскольку у множества нет порядка, вы не можете выбрать, какой элемент будет удалён; вызов `pop()` на пустом множестве вызывает `KeyError`:
```python
tickets = {101, 102, 103}
picked = tickets.pop()
print(len(tickets))  # 2
```
`clear()` удаляет **все** элементы, оставляя пустое множество:
```python
tickets.clear()
print(len(tickets))  # 0
```

---

Вы можете перебирать множество с помощью `for`, точно так же, как список:
```python
for color in {"red", "blue"}:
    print(color)
```
Поскольку множество неупорядочено, элементы могут появляться в **любом порядке**, и этот порядок может даже меняться между запусками.
Когда вам нужен предсказуемый порядок, передайте множество в `sorted()`, которая возвращает отсортированный **список** его элементов:
```python
for color in sorted({"red", "blue"}):
    print(color)  # blue, then red
```

---

**Объединение** двух множеств — это новое множество с элементами **обоих**, без дубликатов.
Используйте оператор `|` или метод `union()`:
```python
a = {1, 2}
b = {2, 3}
print(a | b)        # {1, 2, 3}
print(a.union(b))   # {1, 2, 3}
```
Ни `a`, ни `b` не изменяются: операции с множествами всегда возвращают новое множество.

---

**Пересечение** двух множеств содержит только элементы, присутствующие в **обоих**.
Используйте оператор `&` или метод `intersection()`:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
Если у множеств нет ничего общего, результатом будет пустое множество.

---

**Разность** `a - b` содержит элементы `a`, которых **нет** в `b`.
Порядок имеет значение: `a - b` и `b - a` обычно отличаются:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**Симметрическая разность** `a ^ b` содержит элементы, которые есть **ровно в одном** из двух множеств:
```python
print(a ^ b)  # {1, 4}
```
Методы для этого — `difference()` и `symmetric_difference()`.

---

Операторы и методы не полностью эквивалентны.
Операторы `|`, `&`, `-` и `^` работают только тогда, когда **оба** операнда — множества.
Методы `union()`, `intersection()`, `difference()` и `symmetric_difference()` принимают **любой итерируемый объект**, например список или строку:
```python
a = {1, 2}
print(a.union([2, 3]))  # {1, 2, 3}
print(a | [2, 3])       # TypeError: unsupported operand type(s) for |: 'set' and 'list'
```

---

Множества также можно **сравнивать** друг с другом.
`a.issubset(b)`, или `a <= b`, равно `True`, когда каждый элемент `a` также есть в `b`.
`a.issuperset(b)`, или `a >= b`, равно `True`, когда `a` содержит каждый элемент `b`.
`a.isdisjoint(b)` равно `True`, когда у двух множеств **нет** общих элементов:
```python
small = {1, 2}
big = {1, 2, 3}
print(small <= big)              # True
print(big.issuperset(small))     # True
print(small.isdisjoint({8, 9}))  # True
```

---

Множество может содержать только **хешируемые** элементы, то есть значения, которые не могут изменяться: числа, строки, `True`/`False` и **кортежи**.
Попытка добавить список, словарь или другое множество вызывает `TypeError`:
```python
points = set()
points.add((1, 2))  # ok, a tuple
points.add([1, 2])  # TypeError: unhashable type: 'list'
```
Множества кортежей удобны для отслеживания уникальных пар, таких как координаты или записи (name, age):
```python
visits = [(1, 2), (1, 2), (3, 4)]
print(len(set(visits)))  # 2
```

---

**frozenset** — это **неизменяемое** множество: после создания вы не можете добавлять или удалять элементы.
Создайте его с помощью `frozenset()` из любой коллекции:
```python
days = frozenset(["sat", "sun"])
print("sat" in days)  # True
days.add("mon")       # AttributeError: 'frozenset' object has no attribute 'add'
```
При выводе frozenset его тип отображается вокруг элементов, например `frozenset({'sat', 'sun'})`.
Поскольку он не может изменяться, frozenset хешируем: в отличие от обычного множества, он может быть элементом другого множества или ключом словаря.
Все операции только для чтения (`in`, `len()`, `|`, `&`, `-`, `^`, сравнения) работают как обычно.

---

**Генератор множеств** (set comprehension) строит множество в одном выражении, с тем же синтаксисом, что и list comprehension, но с фигурными скобками:
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
Необязательное `if` фильтрует элементы, а дубликаты, порождённые выражением, отбрасываются автоматически:
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```

---

Операции с множествами также могут изменять множество **на месте** вместо возврата нового.
`update(iterable)` добавляет каждый элемент любой коллекции, как `add()`, но сразу для многих значений:
```python
inventory = {"sword"}
inventory.update(["potion", "map"])
print(len(inventory))  # 3
```
Составные операторы тоже работают на месте: `|=` добавляет элементы другого множества, `&=` оставляет только общие, `-=` удаляет элементы другого множества:
```python
inventory -= {"map"}
print(sorted(inventory))  # ['potion', 'sword']
```

---

Два множества **равны**, когда содержат одинаковые элементы, независимо от порядка, в котором они были записаны:
```python
print({1, 2, 3} == {3, 1, 2})  # True
```
Сравнение длины коллекции с длиной её множества — быстрый способ обнаружить дубликаты: если множество **меньше**, какое-то значение встретилось более одного раза:
```python
emails = ["a@x.com", "b@x.com", "a@x.com"]
print(len(set(emails)) < len(emails))  # True
```
Метод списка `count(value)` показывает, сколько раз встречается значение, что помогает найти, *какие* значения дублируются.
