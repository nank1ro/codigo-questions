# --description--

Операторы и методы не полностью эквивалентны.
Операторы `|`, `&`, `-` и `^` работают только тогда, когда **оба** операнда — множества.
Методы `union()`, `intersection()`, `difference()` и `symmetric_difference()` принимают **любой итерируемый объект**, например список или строку:
```python
a = {1, 2}
print(a.union([2, 3]))  # {1, 2, 3}
print(a | [2, 3])       # TypeError: unsupported operand type(s) for |: 'set' and 'list'
```

# --instructions--

Что произойдёт при выполнении этого кода?
```python
a = {1, 2}
print(a | [2, 3])
```

# --answers--

- Ошибку `TypeError`, потому что `|` работает только между множествами: используйте `union()`, чтобы объединить множество со списком
- Выведет `{1, 2, 3}`
- Выведет `{1, 2, [2, 3]}`
- Выведет `[1, 2, 2, 3]`
