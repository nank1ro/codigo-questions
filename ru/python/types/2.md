# --description--

`type()` возвращает класс значения, поэтому вы можете сравнить его с именем класса с помощью `is`:
```python
age = 30
print(type(age) is int)  # True
```
Однако чаще всего вам нужно лишь узнать, **имеет ли** значение определённый тип. Именно для этого служит `isinstance(value, cls)`, которая возвращает `True` или `False`:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
Вторым аргументом может быть также **кортеж** классов: результат равен `True`, если значение принадлежит хотя бы одному из них:
```python
print(isinstance(2.5, (int, float)))  # True
```
