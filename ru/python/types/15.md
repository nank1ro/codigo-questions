# --description--

Преобразования можно комбинировать. `int("3.7")` завершается неудачей, но `float("3.7")` работает, а `int()` от `float` отбрасывает дробную часть:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` следует правилам истинности: `bool("")` равно `False`, и обратите внимание, что `bool("False")` равно `True`, потому что это непустая строка.
