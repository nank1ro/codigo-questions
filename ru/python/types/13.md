# --description--

В отличие от многих языков, целые числа в Python не имеют **максимального размера**: `int` растёт, чтобы вместить столько цифр, сколько нужно, поэтому большие вычисления остаются точными:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
Значение `float`, с другой стороны, хранит лишь около 15 значащих цифр, поэтому та же степень в виде `float` теряет точность:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
Поскольку `str()` работает с любым `int`, быстрый способ посчитать количество цифр числа — измерить длину его текста.
