# --description--

При печати `float` выводится столько цифр, сколько нужно для его точного представления, и их часто оказывается слишком много:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
Внутри f-строки вы можете добавить **спецификацию формата** после двоеточия. `.2f` означает "число с фиксированной точкой и 2 десятичными знаками":
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
Значение округляется до запрошенного количества десятичных знаков, и при необходимости добавляются нули: `f"{2.5:.2f}"` даёт `2.50`.
