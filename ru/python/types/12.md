# --description--

Значение `float` хранится в двоичном виде с фиксированным количеством битов, поэтому большинство десятичных чисел можно представить только **приближённо**. Ошибка крошечная, но она проявляется в арифметике:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
По этой причине не следует сравнивать числа `float` на точное равенство. Округлите обе стороны или используйте `math.isclose()`, которая проверяет, что два числа равны в пределах крошечного допуска:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
У целых чисел такой проблемы нет: `1 + 2 == 3` всегда равно `True`.

# --instructions--

Что выведет этот код?
```python
print(0.1 + 0.2 == 0.3)
```

# --answers--

- `False`, потому что `0.1 + 0.2` немного больше, чем `0.3`
- `True`, потому что `0.1 + 0.2` равно `0.3`
- `0.3`, потому что `print` показывает результат сложения
- Ошибку `TypeError`, потому что числа `float` нельзя сравнивать с помощью `==`
