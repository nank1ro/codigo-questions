# --description--

Вы можете указать ожидаемый тип переменной, параметра или возвращаемого значения в виде **подсказки типа**: двоеточие после имени для переменных и параметров, стрелка `->` перед двоеточием для возвращаемого значения:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
Подсказки — это **документация** для людей и для таких инструментов, как редакторы: Python **не** проверяет их. Этот код выполняется без жалоб и выводит `hello`:
```python
count: int = "hello"
print(count)
```
Подсказки делают предполагаемые типы понятными, но реальный тип всё равно определяет само значение.
