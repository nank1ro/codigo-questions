# --description--

Преобразование может завершиться неудачей. `int("abc")` не может получить число, поэтому он вызывает `ValueError`, и программа останавливается:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
Чтобы программа продолжала работать, вы можете перехватить ошибку с помощью `try` / `except`: код в блоке `try` выполняется, и если он вызывает указанную ошибку, вместо него выполняется блок `except`:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
Когда преобразование проходит успешно, блок `except` пропускается.

    except ValueError:
