# --description--

Форматирование меняет лишь то, как число отображается. Чтобы получить округлённое **значение**, используйте встроенную функцию `round()`:
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
С одним аргументом `round()` округляет до ближайшего целого числа и возвращает `int`; с количеством десятичных знаков она возвращает `float`:
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
Обратите внимание, что значения, находящиеся ровно посередине между двумя числами, округляются до **чётного**: `round(2.5)` равно `2`, а `round(3.5)` равно `4`.
