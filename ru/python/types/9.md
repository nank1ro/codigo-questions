# --description--

`None` — это особое значение, которое означает "здесь ничего нет". Его возвращает функция, в которой нет инструкции `return`, и оно часто служит заполнителем для значения, которое ещё неизвестно.
Поскольку `None` существует только в одном экземпляре, проверяйте его с помощью `is`, а не `==`:
```python
result = None
if result is None:
    print("no result yet")
```
У каждого типа есть атрибут `__name__` с его именем в виде строки, что удобно для сообщений:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```
