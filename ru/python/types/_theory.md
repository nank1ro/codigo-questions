Каждое значение в Python имеет **тип**, который говорит, что это за данные и что с ними можно делать.
Основные встроенные типы:
- `int` — целое число, например `42` или `-3`
- `float` — число с дробной частью, например `3.5`
- `str` — фрагмент текста, например `"hello"`
- `bool` — одно из двух значений: `True` и `False`
- `NoneType` — тип специального значения `None`, которое означает "нет значения"

Встроенная функция `type()` возвращает тип значения. При печати выводится имя класса:
```python
print(type(42))     # <class 'int'>
print(type("hi"))   # <class 'str'>
```
Вы никогда не будете писать `NoneType` сами: `type(None)` возвращает его, но это имя не является встроенным, как остальные четыре.

---

`type()` возвращает класс значения, поэтому вы можете сравнить его с именем класса с помощью `is`:
```python
age = 30
print(type(age) is int)  # True
```
Однако чаще всего вам нужно лишь узнать, **имеет ли** значение определённый тип. Именно для этого служит `isinstance(value, cls)`, которая возвращает `True` или `False`:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
Вторым аргументом может быть также **кортеж** классов: результат равен `True`, если значение принадлежит хотя бы одному из них:
```python
print(isinstance(2.5, (int, float)))  # True
```

---

В Python **динамическая типизация**: тип принадлежит **значению**, а не переменной.
Переменная — это просто имя, прикреплённое к значению, и вы можете в любой момент прикрепить его к значению другого типа:
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
Не нужно ни объявления, ни преобразования: старое значение просто забывается.
Это удобно, но означает и то, что тип переменной становится известен только во время выполнения программы, поэтому случайное смешение типов проявляется как ошибка во время выполнения, а не раньше.

---

Вы уже знакомы с арифметическими операторами. Здесь важно то, какой **тип имеет результат**.
Комбинация `int` с `float` даёт `float`, даже когда дробная часть равна нулю:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**Истинное деление** `/` всегда возвращает `float`, даже когда числа делятся нацело:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**Целочисленное деление** `//` округляет результат вниз до ближайшего целого числа (поэтому `-7 // 2` равно `-4`) и возвращает `int`, когда оба операнда — целые числа. Вместе с остатком `%` оно разбивает величину на целые части:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```

---

Значения не меняют тип сами по себе: чтобы превратить значение в другой тип, вы вызываете имя типа как функцию. Это называется **преобразованием** типа (или *приведением* типа):
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` и `float()` читают числа, записанные как текст, — именно такие вы получаете из пользовательского ввода или из файлов. `str()` превращает что угодно в текст, поэтому результат можно присоединить с помощью `+` к другой строке.
Обратите внимание, что `int(3.9)` не округляет: он отбрасывает дробную часть.

---

Преобразование может завершиться неудачей. `int("abc")` не может получить число, поэтому он вызывает `ValueError`, и программа останавливается:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
Чтобы программа продолжала работать, вы можете перехватить ошибку с помощью `try` / `except`: код в блоке `try` выполняется, и если он вызывает указанную ошибку, вместо него выполняется блок `except`:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
Когда преобразование проходит успешно, блок `except` пропускается.

---

Каждое значение можно интерпретировать как логическое значение. `bool()` преобразует значение в `True` или `False`, и то же правило применяется, когда значение используется напрямую в `if`.
Значениями, которые считаются **ложными**, являются "пустые" значения:
- число `0` (и `0.0`)
- пустая строка `""`
- пустые коллекции, такие как `[]`, `{}`, `()` и `set()`
- `None`

Любое непустое значение является **истинным**, включая отрицательные числа и строки, которые лишь выглядят пустыми, например `"0"` или `" "`:
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
Именно поэтому `if name:` — распространённый способ проверить, что строка не пуста.

---

`bool` является **подклассом** `int`: `True` ведёт себя как `1`, а `False` — как `0` везде, где ожидается число:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` складывает элементы списка, поэтому суммирование списка логических значений **подсчитывает**, сколько из них равны `True`:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
Из-за отношения подкласса `isinstance(True, int)` возвращает `True`, при этом `type(True)` остаётся `bool`.

---

`None` — это особое значение, которое означает "здесь ничего нет". Его возвращает функция, в которой нет инструкции `return`, и оно часто служит заполнителем для значения, которое ещё неизвестно.
Поскольку `None` существует только в одном экземпляре, проверяйте его с помощью `is`, а не `==`:
```python
result = None
if result is None:
    print("no result yet")
```
У каждого типа есть атрибут `__name__` с его именем в виде строки, что удобно для сообщений:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

---

При печати `float` выводится столько цифр, сколько нужно для его точного представления, и их часто оказывается слишком много:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
Внутри f-строки вы можете добавить **спецификацию формата** после двоеточия. `.2f` означает "число с фиксированной точкой и 2 десятичными знаками":
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
Значение округляется до запрошенного количества десятичных знаков, и при необходимости добавляются нули: `f"{2.5:.2f}"` даёт `2.50`.

---

Форматирование меняет лишь то, как число отображается. Чтобы получить округлённое **значение**, используйте встроенную функцию `round()`:
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
С одним аргументом `round()` округляет до ближайшего целого числа и возвращает `int`; с количеством десятичных знаков она возвращает `float`:
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
Обратите внимание, что значения, находящиеся ровно посередине между двумя числами, округляются до **чётного**: `round(2.5)` равно `2`, а `round(3.5)` равно `4`.

---

Значение `float` хранится в двоичном виде с фиксированным количеством битов, поэтому большинство десятичных чисел можно представить только **приближённо**. Ошибка крошечная, но она проявляется в арифметике:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
По этой причине не следует сравнивать числа `float` на точное равенство. Округлите обе стороны или используйте `math.isclose()`, которая проверяет, что два числа равны в пределах крошечного допуска:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
У целых чисел такой проблемы нет: `1 + 2 == 3` всегда равно `True`.

---

В отличие от многих языков, целые числа в Python не имеют **максимального размера**: `int` растёт, чтобы вместить столько цифр, сколько нужно, поэтому большие вычисления остаются точными:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
Значение `float`, с другой стороны, хранит лишь около 15 значащих цифр, поэтому та же степень в виде `float` теряет точность:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
Поскольку `str()` работает с любым `int`, быстрый способ посчитать количество цифр числа — измерить длину его текста.

---

Вы можете указать ожидаемый тип переменной, параметра или возвращаемого значения в виде **подсказки типа**: двоеточие после имени для переменных и параметров, стрелка `->` перед двоеточием для возвращаемого значения:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
Подсказки — это **документация** для людей и для таких инструментов, как редакторы: Python **не** проверяет их. Этот код выполняется без жалоб и выводит `hello`:
```python
count: int = "hello"
print(count)
```
Подсказки делают предполагаемые типы понятными, но реальный тип всё равно определяет само значение.

---

Преобразования можно комбинировать. `int("3.7")` завершается неудачей, но `float("3.7")` работает, а `int()` от `float` отбрасывает дробную часть:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` следует правилам истинности: `bool("")` равно `False`, и обратите внимание, что `bool("False")` равно `True`, потому что это непустая строка.

---

Текст, приходящий извне, всегда является `str`, и ваша программа должна сама выяснить, какой тип он на самом деле содержит.
Распространённый подход — сначала попробовать **самое строгое** преобразование, а при возникновении `ValueError` перейти к следующему:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
Вложив второй `try` внутрь блока `except`, вы можете сделать ещё один такой шаг, например оставить текст как есть.
