# --description--

Вы уже знакомы с арифметическими операторами. Здесь важно то, какой **тип имеет результат**.
Комбинация `int` с `float` даёт `float`, даже когда дробная часть равна нулю:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**Истинное деление** `/` всегда возвращает `float`, даже когда числа делятся нацело:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**Целочисленное деление** `//` округляет результат вниз до ближайшего целого числа (поэтому `-7 // 2` равно `-4`) и возвращает `int`, когда оба операнда — целые числа. Вместе с остатком `%` оно разбивает величину на целые части:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```
