# --description--

`bool` является **подклассом** `int`: `True` ведёт себя как `1`, а `False` — как `0` везде, где ожидается число:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` складывает элементы списка, поэтому суммирование списка логических значений **подсчитывает**, сколько из них равны `True`:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
Из-за отношения подкласса `isinstance(True, int)` возвращает `True`, при этом `type(True)` остаётся `bool`.
