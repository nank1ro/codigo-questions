# --description--

Значения не меняют тип сами по себе: чтобы превратить значение в другой тип, вы вызываете имя типа как функцию. Это называется **преобразованием** типа (или *приведением* типа):
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` и `float()` читают числа, записанные как текст, — именно такие вы получаете из пользовательского ввода или из файлов. `str()` превращает что угодно в текст, поэтому результат можно присоединить с помощью `+` к другой строке.
Обратите внимание, что `int(3.9)` не округляет: он отбрасывает дробную часть.
