# --description--

Текст, приходящий извне, всегда является `str`, и ваша программа должна сама выяснить, какой тип он на самом деле содержит.
Распространённый подход — сначала попробовать **самое строгое** преобразование, а при возникновении `ValueError` перейти к следующему:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
Вложив второй `try` внутрь блока `except`, вы можете сделать ещё один такой шаг, например оставить текст как есть.
