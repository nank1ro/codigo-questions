# --description--

`sprintf` не знает, насколько велик буфер. `snprintf` принимает размер буфера вторым аргументом и никогда не записывает больше `size - 1` символов плюс `'\0'`, при необходимости обрезая текст. Он возвращает длину, которую имел бы **полный** текст, поэтому результат больше или равный `size` означает, что вывод был усечён:
```c
char buffer[8];
int n = snprintf(buffer, sizeof buffer, "%s", "formatting");
printf("%s %d\n", buffer, n); // prints "formatt 10"
```
`sizeof buffer` даёт размер массива в байтах, что для массива `char` равно количеству его элементов.
