# --description--

`sprintf` работает точно так же, как `printf`, но вместо вывода на экран записывает отформатированный текст в массив `char`, называемый **буфером**, вместе с завершающим `'\0'`:
```c
char buffer[32];
sprintf(buffer, "%d-%d", 3, 7);
printf("%s\n", buffer); // prints "3-7"
```
Буфер должен быть объявлен до вызова и должен быть достаточно большим для всего текста плюс завершающий символ, иначе `sprintf` запишет за его конец.
