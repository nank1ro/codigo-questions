# --description--

В C нет интерполяции строк: текст и значения объединяет `printf` с помощью **строки формата**, в которой каждый спецификатор `%` заменяется соответствующим аргументом. Самые распространённые спецификаторы:
```c
printf("%d\n", 42);      // prints "42" (int, %i is the same)
printf("%f\n", 2.5);     // prints "2.500000" (double, 6 decimals by default)
printf("%s\n", "hi");    // prints "hi" (string)
printf("%c\n", 'A');     // prints "A" (single character)
printf("%x\n", 255);     // prints "ff" (int as lowercase hexadecimal)
printf("100%%\n");       // prints "100%" (a literal percent sign)
```
Спецификатор должен соответствовать типу аргумента: вывод `double` через `%d` или `int` через `%s` не преобразует значение, а печатает мусор или приводит к аварийному завершению.
