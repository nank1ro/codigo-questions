В C нет интерполяции строк: текст и значения объединяет `printf` с помощью **строки формата**, в которой каждый спецификатор `%` заменяется соответствующим аргументом. Самые распространённые спецификаторы:
```c
printf("%d\n", 42);      // prints "42" (int, %i is the same)
printf("%f\n", 2.5);     // prints "2.500000" (double, 6 decimals by default)
printf("%s\n", "hi");    // prints "hi" (string)
printf("%c\n", 'A');     // prints "A" (single character)
printf("%x\n", 255);     // prints "ff" (int as lowercase hexadecimal)
printf("100%%\n");       // prints "100%" (a literal percent sign)
```
Спецификатор должен соответствовать типу аргумента: вывод `double` через `%d` или `int` через `%s` не преобразует значение, а печатает мусор или приводит к аварийному завершению.

---

`sprintf` работает точно так же, как `printf`, но вместо вывода на экран записывает отформатированный текст в массив `char`, называемый **буфером**, вместе с завершающим `'\0'`:
```c
char buffer[32];
sprintf(buffer, "%d-%d", 3, 7);
printf("%s\n", buffer); // prints "3-7"
```
Буфер должен быть объявлен до вызова и должен быть достаточно большим для всего текста плюс завершающий символ, иначе `sprintf` запишет за его конец.

---

Функция, которая строит строку, обычно получает буфер как параметр и заполняет его с помощью `sprintf`. Массив принадлежит вызывающей стороне, и после вызова она может прочитать результат:
```c
void greet(char *out, char *name) {
    sprintf(out, "Hello, %s!", name);
}

char message[32];
greet(message, "Ada");
printf("%s\n", message); // prints "Hello, Ada!"
```
В этих упражнениях `string.h` уже подключён над вашим кодом, поэтому для сравнения результата можно использовать `strcmp`.

---

`%x` выводит целое число в шестнадцатеричном виде строчными буквами, а `%X` делает то же самое прописными. `%c` принимает целочисленный код символа и выводит символ, который он обозначает, поэтому `%c` с `65` выводит `A`:
```c
printf("%x %X %c\n", 31, 31, 66); // prints "1f 1F B"
```

---

Число между `%` и буквой задаёт минимальную **ширину** поля. Значение дополняется пробелами слева, а **флаги**, поставленные сразу после `%`, меняют это дополнение:
```c
printf("[%5d]\n", 42);  // prints "[   42]" right-aligned in 5 columns
printf("[%-5d]\n", 42); // prints "[42   ]" the - flag aligns to the left
printf("[%05d]\n", 42); // prints "[00042]" the 0 flag pads with zeros
printf("[%+d]\n", 42);  // prints "[+42]" the + flag always shows the sign
```
Значение длиннее ширины никогда не обрезается, поле просто расширяется.

---

Ширина и флаги работают с любым спецификатором, поэтому `%02x` выводит целое число в шестнадцатеричном виде, дополненное нулями до двух цифр. Именно так цвета записываются в виде `#rrggbb`:
```c
printf("%02x\n", 5);   // prints "05"
printf("%02x\n", 255); // prints "ff"
```

---

Точка, за которой следует число, задаёт **точность**. Для `%f` это количество знаков после запятой с округлением; для `%s` это максимальное количество выводимых символов:
```c
printf("%.2f\n", 3.14159);    // prints "3.14"
printf("%.3s\n", "formatting"); // prints "for"
```
Ширину и точность можно сочетать: `%8.2f` выводит два знака после запятой с выравниванием по правому краю в 8 колонках.

---

Точность — обычный способ управлять тем, как `double` выглядит в строке. Отношение вроде `0.425` превращается в проценты умножением на `100` и выводом одного знака после запятой с последующим `%%`:
```c
sprintf(out, "%.1f%%", 0.425 * 100); // out is "42.5%"
```

---

`sprintf` и `printf` **возвращают** количество записанных символов, не считая завершающего `'\0'`. Это длина только что построенной строки, без отдельного вызова `strlen`:
```c
char buffer[32];
int length = sprintf(buffer, "%d-%d", 3, 7);
printf("%d\n", length); // prints "3"
```

---

`sprintf` не знает, насколько велик буфер. `snprintf` принимает размер буфера вторым аргументом и никогда не записывает больше `size - 1` символов плюс `'\0'`, при необходимости обрезая текст. Он возвращает длину, которую имел бы **полный** текст, поэтому результат больше или равный `size` означает, что вывод был усечён:
```c
char buffer[8];
int n = snprintf(buffer, sizeof buffer, "%s", "formatting");
printf("%s %d\n", buffer, n); // prints "formatt 10"
```
`sizeof buffer` даёт размер массива в байтах, что для массива `char` равно количеству его элементов.

---

Сравнение возвращаемого значения `snprintf` с размером буфера показывает, всё ли поместилось. Это безопасный приём построения строк неизвестной длины:
```c
int n = snprintf(out, size, "%s", text);
if (n >= size) {
    // out holds only the first size - 1 characters of text
}
```

---

Строку можно строить в несколько шагов, записывая каждую часть сразу после предыдущей. Возвращаемое значение показывает, где заканчивается текст, поэтому `buffer + n` — это адрес завершающего символа, и следующий `sprintf` может продолжить с этого места:
```c
char buffer[32];
int n = sprintf(buffer, "%s", "Hello");
n += sprintf(buffer + n, ", %s", "world"); // buffer is "Hello, world", n is 12
```
Прибавление каждого возвращённого значения к `n` держит его равным общей длине построенного к этому моменту текста.

---

Строки можно объединять и без строки формата. `strcat` из `string.h` дописывает копию своего второго аргумента в конец первого, у которого должно быть достаточно свободного места, а `strncat` дописывает не более заданного количества символов:
```c
char text[32] = "Hi";
strcat(text, "!!!");        // text is "Hi!!!"
strncat(text, "abcdef", 2); // text is "Hi!!!ab"
```
Обе всегда добавляют завершающий `'\0'` после дописанных символов.

---

Когда форматировать нечего, `puts` выводит строку с переводом строки в конце. В отличие от `printf` он не интерпретирует `%`, поэтому текст выводится ровно так, как записан:
```c
puts("Done");      // prints "Done" and a newline
puts("50% off");   // prints "50% off" and a newline
printf("50% off"); // undefined: % off is not a valid specifier
```
`puts` — правильный выбор для фиксированного текста, а `printf` — когда нужно вставить значения.

---

`strncat` полезен, когда нужно дописать только часть строки или когда дописываемый фрагмент должен быть ограничен максимальной длиной:
```c
char name[16] = "file";
strncat(name, ".backup", 3); // name is "file.ba"
```
Когда предел больше строки, дописывается вся строка.

---

Всё вместе: строка отчёта объединяет текстовое поле с выравниванием по левому краю, разделитель и число с выравниванием по правому краю и фиксированным количеством знаков после запятой, записанная через `snprintf`, чтобы никогда не переполнить буфер:
```c
snprintf(out, size, "%-6s|%5.1f", "Ada", 9.5); // out is "Ada   |  9.5"
```
Пока каждое значение помещается в свою ширину, все строки имеют одинаковую длину, поэтому колонки выстраиваются в ряд, когда строки выводятся одна под другой.
