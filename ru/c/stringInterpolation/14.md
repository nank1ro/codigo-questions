# --description--

Когда форматировать нечего, `puts` выводит строку с переводом строки в конце. В отличие от `printf` он не интерпретирует `%`, поэтому текст выводится ровно так, как записан:
```c
puts("Done");      // выводит "Done" и перевод строки
puts("50% off");   // выводит "50% off" и перевод строки
printf("50% off"); // неопределено: % off — недопустимый спецификатор
```
`puts` — правильный выбор для фиксированного текста, а `printf` — когда нужно вставить значения.

# --instructions--

Какая из следующих строк выводит `100%` с переводом строки в конце?

# --answers--

- puts("100%");
- printf("100%");
- puts("100%%");
- printf("100%%");
