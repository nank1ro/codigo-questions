# --description--

Число между `%` и буквой задаёт минимальную **ширину** поля. Значение дополняется пробелами слева, а **флаги**, поставленные сразу после `%`, меняют это дополнение:
```c
printf("[%5d]\n", 42);  // выводит "[   42]" с выравниванием по правому краю в 5 колонках
printf("[%-5d]\n", 42); // выводит "[42   ]", флаг - выравнивает по левому краю
printf("[%05d]\n", 42); // выводит "[00042]", флаг 0 дополняет нулями
printf("[%+d]\n", 42);  // выводит "[+42]", флаг + всегда показывает знак
```
Значение длиннее ширины никогда не обрезается, поле просто расширяется.

# --instructions--

Выведите `42` в квадратных скобках три раза: с выравниванием по правому краю в ширине 5, с выравниванием по левому краю в ширине 5, затем дополненным нулями до 5 цифр
