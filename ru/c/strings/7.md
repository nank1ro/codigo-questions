# --description--

`strcat(destination, source)` добавляет `source` в конец `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
Как и в случае с `strcpy`, массив назначения должен иметь достаточно места для результата.
