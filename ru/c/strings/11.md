# --description--

Заголовок `ctype.h` предоставляет функции для работы с одним символом.
`toupper(c)` возвращает заглавную версию буквы, а `tolower(c)` — строчную; любой другой символ возвращается без изменений:
```c
char letter = toupper('a'); // 'A'
```
