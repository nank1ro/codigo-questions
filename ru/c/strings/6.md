# --description--

Массиву нельзя присвоить значение оператором `=` после его объявления:
```c
char copy[20];
copy = "Codigo"; // error
```
Чтобы скопировать строку, используйте `strcpy(destination, source)` из `string.h`.
Место назначения должно быть достаточно большим, чтобы вместить все символы плюс `'\0'`.

# --instructions--

Расположите строки кода так, чтобы скопировать `source` в `copy` и вывести её. Объявите `source` перед `copy`

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
