# --description--

Нуль-терминатор занимает место в памяти: литерал `"hi"` занимает 3 байта — `'h'`, `'i'` и `'\0'`.
Когда вы сами указываете размер, всегда оставляйте место для него:
```c
char word[6] = "hello"; // 5 letters + '\0'
```
Без терминатора C не сможет узнать, где заканчивается строка.

# --instructions--
