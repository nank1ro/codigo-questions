В C нет отдельного типа для строк: **строка** — это массив `char`, который заканчивается специальным символом, **нуль-терминатором** `'\0'`.
Самый простой способ создать её — строковый литерал в двойных кавычках:
```c
char name[] = "Codigo";
```
Компилятор сам считает символы и добавляет в конце `'\0'`.
Чтобы вывести строку, используйте спецификатор `%s`:
```c
printf("%s\n", name);
// prints "Codigo"
```

---

Нуль-терминатор занимает место в памяти: литерал `"hi"` занимает 3 байта — `'h'`, `'i'` и `'\0'`.
Когда вы сами указываете размер, всегда оставляйте место для него:
```c
char word[6] = "hello"; // 5 letters + '\0'
```
Без терминатора C не сможет узнать, где заканчивается строка.

---

Заголовок `string.h` предоставляет функции для работы со строками.
`strlen` возвращает количество символов до нуль-терминатора (сам терминатор не учитывается):
```c
strlen("hello"); // 5
```
Функция, принимающая строку, объявляет параметр как `char *text` — указатель на первый символ.
В этих упражнениях `string.h` и `ctype.h` уже подключены над вашим кодом.

---

Поскольку строка — это массив, у каждого символа есть индекс, начинающийся с `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Один символ выводится с помощью `%c`. Символы также можно заменять:
```c
word[0] = 'K'; // word is now "Koding"
```

---

Так как каждая строка заканчивается `'\0'`, вы можете пройти по ней, не зная заранее её длину: продолжайте, пока текущий символ не является терминатором.
```c
for (int i = 0; text[i] != '\0'; i++) {
    printf("%c\n", text[i]);
}
```

---

Массиву нельзя присвоить значение оператором `=` после его объявления:
```c
char copy[20];
copy = "Codigo"; // error
```
Чтобы скопировать строку, используйте `strcpy(destination, source)` из `string.h`.
Место назначения должно быть достаточно большим, чтобы вместить все символы плюс `'\0'`.

---

`strcat(destination, source)` добавляет `source` в конец `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
Как и в случае с `strcpy`, массив назначения должен иметь достаточно места для результата.

---

Две строки нельзя сравнивать оператором `==`: это сравнило бы их адреса в памяти, а не символы.
Вместо этого используйте `strcmp(first, second)`, которая возвращает `0`, когда обе строки содержат абсолютно одинаковые символы:
```c
strcmp("cat", "cat"); // 0
strcmp("cat", "dog"); // not 0
```

---

`strcmp` сравнивает строки символ за символом, используя их коды символов.
Результат отрицательный, если первая строка идёт раньше второй, положительный, если позже, и `0`, если они равны:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

---

`strncpy(destination, source, n)` копирует не более `n` символов.
Если `source` длиннее `n`, `'\0'` не записывается: вам нужно завершить результат самостоятельно.
```c
char prefix[10];
strncpy(prefix, "Codigo", 3);
prefix[3] = '\0'; // prefix is "Cod"
```

---

Заголовок `ctype.h` предоставляет функции для работы с одним символом.
`toupper(c)` возвращает заглавную версию буквы, а `tolower(c)` — строчную; любой другой символ возвращается без изменений:
```c
char letter = toupper('a'); // 'A'
```

---

Строка передаётся в функцию как указатель, поэтому функция, принимающая `char *text`, может изменять символы вызывающего кода напрямую.
Сочетание цикла до `'\0'` с `toupper` преобразует всю строку:
```c
text[i] = toupper(text[i]);
```

---

`sprintf` работает как `printf`, но записывает отформатированный текст в массив символов, а не на экран:
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer is "3 items"
```
Буфер должен быть достаточно большим для всего текста и его `'\0'`.

---

`sprintf` — удобный способ превратить число в текст: как только оно оказывается в буфере, с ним может работать любая строковая функция.
