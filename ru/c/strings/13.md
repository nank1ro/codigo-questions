# --description--

`sprintf` работает как `printf`, но записывает отформатированный текст в массив символов, а не на экран:
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer is "3 items"
```
Буфер должен быть достаточно большим для всего текста и его `'\0'`.

# --instructions--

Расположите строки кода так, чтобы собрать текст `Age: 25` внутри `buffer` и вывести его. Объявите `buffer` перед `age`

# --answers--

```c
char buffer[30];
```

```c
int age = 25;
```

```c

```

```c
printf("%s\n", buffer);
```
