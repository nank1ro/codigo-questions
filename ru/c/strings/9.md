# --description--

`strcmp` сравнивает строки символ за символом, используя их коды символов.
Результат отрицательный, если первая строка идёт раньше второй, положительный, если позже, и `0`, если они равны:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

# --instructions--

Что возвращает `strcmp("apple", "banana")`?

# --answers--

- Отрицательное число
- 0
- Положительное число
- Строку "apple"
