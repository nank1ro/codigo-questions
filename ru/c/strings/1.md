# --description--

В C нет отдельного типа для строк: **строка** — это массив `char`, который заканчивается специальным символом, **нуль-терминатором** `'\0'`.
Самый простой способ создать её — строковый литерал в двойных кавычках:
```c
char name[] = "Codigo";
```
Компилятор сам считает символы и добавляет в конце `'\0'`.
Чтобы вывести строку, используйте спецификатор `%s`:
```c
printf("%s\n", name);
// prints "Codigo"
```
