**Операторы сравнения** сравнивают два значения и дают результат: `1`, если сравнение верно, и `0`, если нет.
Оператор **равенства** `==` проверяет, совпадают ли два значения, оператор **неравенства** `!=` проверяет, отличаются ли они:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// выводит "0"
printf("%d\n", a != b);
// выводит "1"
```
Будьте внимательны: `==` (два знака) сравнивает, а одиночный `=` присваивает значение.

---

Остальные операторы сравнения проверяют порядок двух значений:
- `<` меньше, `>` больше
- `<=` меньше или равно, `>=` больше или равно
```c
printf("%d\n", 3 < 5);  // выводит "1"
printf("%d\n", 5 >= 6); // выводит "0"
```
Функция может возвращать результат сравнения напрямую, поскольку это обычный `int`:
```c
int is_big(int n) {
    return n > 100;
}
```

---

В C результат сравнения не является особым типом: это `int`, значение которого равно ровно `1` (истина) или `0` (ложь).
Это значит, что его можно сохранить в переменной типа `int`, как любое другое число:
```c
int n = 42;
int big = n > 100; // big равно 0
```
В выводе нет слова `true`/`false`: `printf("%d", 2 == 2)` выводит `1`.

---

**Логические операторы** объединяют сравнения. Оператор **и** `&&` даёт `1`, только если истинны обе стороны:
```c
int age = 25;
printf("%d\n", age >= 18 && age < 65); // выводит "1"
```
Не соединяйте сравнения в цепочку, как в математике: `1 <= x <= 10` вычисляется как `(1 <= x) <= 10`, что сравнивает `0` или `1` с `10` и всегда истинно.
Всегда записывайте оба сравнения явно и соединяйте их с помощью `&&`.

---

Оператор **или** `||` даёт `1`, если хотя бы одна сторона истинна, и `0`, только если обе стороны ложны:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // выводит "1"
```
Каждая сторона должна быть полным сравнением: `day == 6 || 7` не означает "6 или 7" (вы поймёте почему позже).

---

Оператор **отрицания** `!` инвертирует результат: `!1` равно `0`, а `!0` равно `1`.
Он ставится перед выражением, поэтому используйте скобки, чтобы отрицать сравнение целиком:
```c
int n = 5;
printf("%d\n", !(n > 3)); // выводит "0"
```
Без скобок `!n > 3` сначала вычислило бы `!n`, а затем сравнило бы результат с `3`.

---

Логические операторы работают не только с `0` и `1`: в C **любое ненулевое значение считается истиной**, и только `0` считается ложью.
Поэтому `5 && 1` равно `1`, `0 || -3` равно `1`, а `!` превращает любое ненулевое значение в `0`:
```c
printf("%d\n", !7); // выводит "0"
printf("%d\n", !0); // выводит "1"
```
Именно поэтому `day == 6 || 7` всегда истинно: само по себе `7` — истинное значение.

---

`&&` и `||` используют **вычисление по короткой схеме**: они останавливаются, как только результат уже известен.
- с `&&`, если левая часть равна `0`, правая часть никогда не вычисляется
- с `||`, если левая часть истинна, правая часть никогда не вычисляется

Это позволяет защитить опасную операцию проверкой, размещённой слева от неё:
```c
int safe = divisor != 0 && value / divisor > 2;
```
Когда `divisor` равен `0`, деление никогда не выполняется.

---

Вычисление по короткой схеме также пропускает вызовы функций: в `0 && check()` функция `check` никогда не вызывается, поэтому любой её побочный эффект (например, обновление счётчика) не происходит.

---

У операторов есть **приоритет**, определяющий, что вычисляется первым:
1. сначала применяется `!`
2. затем реляционные сравнения `<`, `>`, `<=`, `>=`
3. затем сравнения на равенство `==`, `!=`
4. затем `&&`
5. затем `||`

Поэтому `a > 0 && a < 10` не нуждается в скобках: оба сравнения вычисляются до `&&`.
А `x == 1 || y == 2 && z == 3` означает `x == 1 || (y == 2 && z == 3)`, потому что `&&` имеет более высокий приоритет, чем `||`.

---

`char` — это небольшое целое число, поэтому символы можно сравнивать теми же операторами.
Сравнивайте с символьным литералом в одинарных кавычках:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // выводит "1"
```
Двойные кавычки создали бы строку, которую нельзя сравнивать таким образом.

---

Поскольку символы являются числами, `<` и `>` сравнивают их коды, а у последовательных символов, таких как `'a'`, `'b'`, `'c'` или `'0'`, `'1'`, `'2'`, коды идут подряд.
Поэтому проверка диапазона для символов работает точно так же, как и для чисел:
```c
int is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

Классическая ошибка в C — написать `=` там, где имелось в виду `==`. Код всё равно компилируется, потому что присваивание — это выражение, значением которого является присвоенное значение:
```c
int x = 5;
if (x = 0) { ... } // присваивает x значение 0, условие равно 0 (ложь)
if (x = 3) { ... } // присваивает x значение 3, условие равно 3 (истина)
```
Большинство компиляторов предупреждают об этом, так что читайте предупреждения, если условие ведёт себя странно.

---

Условие `if` — это просто выражение, которое считается истинным, если оно не равно нулю, поэтому сравнения и логические операторы вписываются сюда естественно:
```c
if (n < 0) {
    printf("negative\n");
} else if (n == 0) {
    printf("zero\n");
}
```
Можно также сначала сохранить результат и проверить переменную: `int ok = n > 0; if (ok) { ... }`.

---

Цикл `while` продолжает выполняться, пока его условие не равно нулю, поэтому именно сравнение решает, когда он остановится:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// выводит 0, 1, 2
```
Выбор между `<` и `<=` определяет, будет ли включено последнее значение.

---

Начиная с C99, заголовок `stdbool.h` предоставляет тип `bool` и константы `true` (`1`) и `false` (`0`):
```c
#include <stdbool.h>

bool ready = true;
bool done = count == 10;
```
`bool` под капотом всё ещё остаётся целым числом: при выводе через `%d` он показывает `1` или `0`, и работает с `&&`, `||` и `!` как любой результат сравнения.
Использование `bool` делает намерение функции понятнее, чем возврат обычного `int`.

---

Параметр типа `bool` можно использовать напрямую как операнд `&&` или `||`, не сравнивая его с `true`: пишите `age >= 18 && citizen`, а не `citizen == true`.

---

Когда условие сочетает `&&` и `||`, добавляйте скобки вокруг каждой группы, даже если приоритет операторов и так дал бы верный результат: это делает правило понятным с первого взгляда.
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
