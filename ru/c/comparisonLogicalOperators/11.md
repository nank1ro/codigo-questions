# --description--

`char` — это небольшое целое число, поэтому символы можно сравнивать теми же операторами.
Сравнивайте с символьным литералом в одинарных кавычках:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // выводит "1"
```
Двойные кавычки создали бы строку, которую нельзя сравнивать таким образом.
