Принятие решений необходимо, когда мы хотим выполнить код только при выполнении определённого условия.
Предположим, мы хотим играть на улице только если погода хорошая.
В программировании мы можем сохранить булеву переменную `nice_weather` и выполнить действие "играть на улице" `if` (если) эта переменная равна `true`, например:
```c
bool nice_weather = true;
if (nice_weather) {
    // играть на улице
}
```

---

Продолжим с предыдущим примером.
```c
bool nice_weather = true;
if (nice_weather) {
    // играть на улице
}
```
Мы увидели, что оператор `if` выполняет блок кода только если условие равно `true`.
Ещё один важный момент — это **фигурные скобки** `{}`, которые обозначают блок кода.

---

Мы только что увидели, как выполнить блок кода при наступлении определённого условия, теперь давайте посмотрим, как выполнить другой блок кода, если первое условие не выполняется.
Мы идём играть на улицу, если погода хорошая; в противном случае мы остаёмся дома.
В C мы можем использовать оператор `else`, например:
```c
bool nice_weather = false;
if (nice_weather) {
    // играть на улице
} else {
    // остаться дома
}
```

---

Предположим, у нас есть ещё одно условие для проверки, как в этом примере:
```c
int num = 3;
if (num == 2) {
    printf("the number is 2\n");
} else if (num == 3) {
    printf("the number is 3\n");
} else {
    printf("do something else\n");
}
```
и вывод этого кода — `the number is 3`.
Сначала проверяем, равно ли число 2 — это ложь.
Поэтому переходим ко второму оператору и проверяем, равно ли `num` 3; так как это истина, мы выполняем следующий блок кода, выводя `the number is 3`

---

Мы можем добавить сколько угодно операторов `else if`, ограничений нет
```c
int num = 4;
if (num == 2) {
    printf("the number is 2");
} else if (num == 3) {
    printf("the number is 3");
} else if (num == 4) {
    printf("the number is 4");
} else if (num == 5) {
    printf("the number is 5");
} else if (num == 6) {
    printf("the number is 6");
}
```
и вывод этого кода — `the number is 4`.

---

Мы также можем вложить условный оператор (`if`, `else if` или `else`) внутрь другого условного оператора, чтобы создать более сложную структуру.
```c
int num = 4;
if (num < 3) {
    printf("the number is lower than 3\n");
} else {
    if (num == 3) {
        printf("the number is 3\n");
  } else if (num == 4) {
        printf("the number is 4\n");
  } else {
        printf("the number is greather than 4\n");
  }
}
```
и вывод этого кода — `the number is 4`.

Пришло время применить синтаксис оператора `if` на практике: ключевое слово, условие в круглых скобках и блок кода, заключённый в фигурные скобки.
```c
if (condition) {
    // выполняется, когда условие истинно
}
```

---

Булевы литералы в C — `true` и `false`: в нижнем регистре, без кавычек, и определены в `<stdbool.h>`, а не встроены в язык. `True` не скомпилируется как условие — работает только вариант в нижнем регистре, и блок выполняется, когда он равен `true`.

---

В C нет отдельной проверки на булев тип: условие истинно всегда, когда его значение отлично от нуля. `false` из `<stdbool.h>` — это просто `0`, поэтому блок, защищённый им, никогда не выполняется.

---

Оператор `if` в C состоит из трёх частей: ключевого слова `if`, условия в круглых скобках и блока в фигурных скобках. Скобки обязательны — именно по ним компилятор понимает, где заканчивается условие.

---

Каждый условный оператор начинается с ключевого слова, которое сообщает компилятору, что перед тем, как решить, что выполнять дальше, нужно проверить условие.

---

Условие в виде литерала `true` всегда истинно, поэтому блок выполняется, и его `printf` срабатывает именно так, как написано.

---

Условие в виде литерала `false` никогда не бывает истинным, поэтому блок полностью пропускается и ничего внутри него не выполняется.

---

Условия — это значения, которые проверяет оператор `if`: когда условие равно `true`, блок выполняется, когда `false` — пропускается.

---

Открывающая фигурная скобка может стоять на той же строке, что и условие, или на следующей. C игнорирует перенос строки, поэтому оба варианта компилируются в абсолютно одинаковую программу.

---

Скобки вокруг условия — часть синтаксиса `if` в C, а не необязательная группировка: `if true { ... }` не скомпилируется.

---

Значение `"false"` в кавычках — это строка, а не булево значение, а строка в условии — это ненулевой адрес, который считается истинным. Только `false` без кавычек не даёт блоку выполниться.

---

Пробелы между частями строки `if` в C не имеют значения: `if(true){` и `if (true) {` — для компилятора одно и то же выражение, важен только порядок частей.

---

Блок кода не ограничен одним выражением. Каждое выражение между фигурными скобками выполняется одно за другим, в том порядке, в котором оно написано.

---

Булеву переменную можно использовать в качестве условия напрямую, без сравнения. Поскольку `online` уже хранит `true`, достаточно написать `if (online)`, чтобы блок выполнился.

---

Переменная типа `bool` работает как условие, потому что `if` смотрит только на значение, хранящееся в ней в этот момент. Когда в `online` лежит `false`, `if (online)` ведёт себя точно так же, как `if (false)`.

---

Условным является только код между фигурными скобками оператора `if`. Всё, что написано после закрывающей скобки, выполняется безусловно, независимо от значения условия.

---

Нет фиксированного предела на количество выражений в блоке кода — одна строка или сотня, все они выполняются вместе, когда условие равно `true`.

---

Чтение булевой переменной в качестве условия работает так же, как и с литералом: поскольку `online` хранит `true`, блок выполняется, и его `printf` срабатывает.

---

Когда же `online` хранит `false`, условие ложно, поэтому блок полностью пропускается, и ничего внутри этих скобок не выводится.
