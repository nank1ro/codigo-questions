# --description--

Когда же `online` хранит `false`, условие ложно, поэтому блок полностью пропускается, и ничего внутри этих скобок не выводится.

# --instructions--

Что выводит этот код?
```c
bool online = false;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- Ничего, код пропускается
