C — это язык со **статической типизацией**: каждая переменная объявляется с типом, который определяет, что она может хранить и сколько памяти занимает.
Три типа, которые вы будете использовать чаще всего:
- `int` для целых чисел, например `30` или `-4`
- `double` для чисел с дробной частью, например `1.75`
- `char` для одного символа, записываемого в одинарных кавычках, например `'A'`

У каждого типа есть свой **спецификатор формата** для `printf`: `%d` выводит `int`, `%f` выводит `double` (по умолчанию с шестью знаками после запятой), а `%c` выводит `char`:
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// prints "30 1.750000 A"
```
Использование неверного спецификатора для типа выводит мусор, поэтому всегда подбирайте их правильно.

---

В C есть два типа с плавающей точкой: `float` (одинарная точность, около 7 значащих цифр) и `double` (двойная точность, около 15 значащих цифр).
Десятичный литерал вроде `1.75` имеет тип `double`; чтобы записать литерал `float`, добавьте суффикс `f`, как в `1.75f`.
Предпочитайте `double`, если только память не ограничена: это тип по умолчанию, и он точнее.
```c
double pi = 3.14159;
float ratio = 0.5f;
```
Функция, возвращающая дробный результат, должна объявлять `double` в качестве типа возврата, а параметры типа `double` принимают как целые, так и дробные аргументы:
```c
double half(double x) {
    return x / 2;
}
```

---

`%f` выводит шесть знаков после запятой, что редко бывает нужно. Поставьте точность между `%` и `f`, чтобы выбрать, сколько знаков показывать: `%.2f` выводит два знака, `%.1f` — один, при этом значение **округляется**, а не обрезается:
```c
double price = 9.987;
printf("%.2f\n", price); // prints "9.99"
printf("%.1f\n", price); // prints "10.0"
```
`float` выводится с теми же спецификаторами, что и `double`: при передаче в `printf` он автоматически преобразуется в `double`.

---

Результат `/` зависит от типов его операндов.
Когда **оба** операнда — целые числа, результат тоже целое число, а дробная часть отбрасывается: `7 / 2` равно `3`, а не `3.5`.
Когда **хотя бы один** операнд — значение с плавающей точкой, деление сохраняет дробную часть: `7 / 2.0` равно `3.5`.
```c
printf("%d\n", 7 / 2);     // prints "3"
printf("%f\n", 7 / 2.0);   // prints "3.500000"
```
Запись литерала как `2.0` вместо `2` — самый простой способ заставить деление быть с плавающей точкой.

---

C **неявно** преобразует числовые типы, когда значение присваивается переменной другого типа.
- `int`, сохранённый в `double`, расширяется без потерь: `double d = 3;` делает `d` равным `3.0`
- `double`, сохранённый в `int`, **усекается**: `int n = 3.99;` делает `n` равным `3` (компиляторы обычно предупреждают об этом)

Преобразование происходит только в момент присваивания. Выражение справа вычисляется первым, со своими собственными типами:
```c
double d = 7 / 2;
```
Здесь `7 / 2` — это целочисленное деление, дающее `3`, и только потом `3` преобразуется в `3.0`.

---

Когда неявное преобразование делает не то, что нужно, или вы хотите сделать его явным, используйте **явное приведение типа**: укажите целевой тип в скобках перед значением.
```c
double x = 3.99;
int n = (int) x;   // n is 3
```
Приведение значения с плавающей точкой к `int` **усекает в сторону нуля**: `(int) 3.99` равно `3`, а `(int) -2.5` равно `-2`, округление не происходит.
Приведение применяется только к значению сразу после него, поэтому `(int) x * 2` сначала приводит `x`, а затем умножает.

---

Приведение типа — стандартный способ получить деление с плавающей точкой из двух переменных `int`: приведите **один операнд** к `double` перед делением.
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
Приведение всего результата целиком, как в `(double) (total / count)`, — распространённая ошибка: целочисленное деление уже произошло, и дробная часть потеряна.

---

`char` на самом деле — это маленькое целое число: оно хранит **код ASCII** символа.
`'A'` — это `65`, `'a'` — это `97`, а `'0'` — это `48`, и последовательные символы имеют последовательные коды.
Именно поэтому с символами можно выполнять арифметику:
- `'a' + 1` — это `98`, код символа `'b'`
- `'7' - '0'` — это `55 - 48`, то есть число `7`

То же самое значение можно вывести как символ с помощью `%c` или как число с помощью `%d`:
```c
char c = 'A';
printf("%c %d\n", c, c); // prints "A 65"
```

---

Прописные и строчные буквы в таблице ASCII отстоят друг от друга на `32` позиции: `'A'` — это `65`, а `'a'` — это `97`.
Поэтому вычитание `32` из строчной буквы даёт её прописную версию, и результат можно снова сохранить в `char`:
```c
char upper = 'g' - 32; // 'G'
```

---

`int` — не единственный целочисленный тип. Модификаторы меняют его размер и диапазон:
- `short` занимает меньше памяти и имеет меньший диапазон (обычно от -32768 до 32767)
- `long` имеет больший диапазон (на 64-битных системах около ±9 квинтиллионов)
- `unsigned` убирает знак: `unsigned int` принимает значения от `0` до примерно 4 миллиардов, но никогда не может быть отрицательным

Литерал, который должен быть `long`, получает суффикс `L`, `unsigned` — суффикс `U`, и у каждого типа свой спецификатор:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // prints "8000000000 40"
```
`%ld` выводит `long`, `%u` — `unsigned int`, а `%lu` — `unsigned long`. Обычный `int` на большинстве систем хранит значения примерно до 2 миллиардов, поэтому `5000000000` в него не помещается.

---

Оператор `sizeof` показывает, сколько **байт** занимает тип или переменная. Его результат имеет тип `size_t`, который выводится с помощью `%zu`:
```c
printf("%zu\n", sizeof(int));  // prints "4" on most systems
```
Стандарт гарантирует только то, что `sizeof(char)` равен `1` и что `short <= int <= long`, но на типичной 64-битной системе размеры такие: `char` 1, `short` 2, `int` 4, `long` 8, `float` 4, `double` 8.
`sizeof` часто используется, чтобы узнать, сколько памяти занимает переменная, не прописывая число в коде вручную.

---

У каждого целочисленного типа есть ограниченный диапазон, и заголовок `limits.h` даёт этим границам имена: `INT_MAX` и `INT_MIN` для `int`, `LONG_MAX` для `long`, `UINT_MAX` для `unsigned int` и так далее.
```c
#include <limits.h>

printf("%d\n", INT_MAX); // prints "2147483647" on most systems
```
Превышение `INT_MAX` для знакового типа — это **неопределённое поведение**: программа может переполниться по кругу, аварийно завершиться или сделать что угодно ещё. Проверяйте перед вычислением:
```c
if (a <= INT_MAX - b) { /* a + b is safe */ }
```
Обратите внимание, что проверка использует вычитание, а не сложение, потому что само `a + b` уже могло бы переполниться.

---

В отличие от знаковых типов, арифметика **unsigned** хорошо определена при выходе за границы диапазона: значение **переполняется по кругу**, как одометр.
Прибавление `1` к `UINT_MAX` даёт `0`, а вычитание `1` из `0` даёт `UINT_MAX` (`4294967295`, когда `unsigned int` имеет 32 бита):
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // prints "0"
```
Именно поэтому цикл, уменьшающий переменную `unsigned` "пока она не станет отрицательной", никогда не останавливается: значение unsigned никогда не бывает меньше `0`.

---

Начиная с C99, заголовок `stdbool.h` предоставляет тип `bool` с константами `true` (`1`) и `false` (`0`).
`bool` — это целочисленный тип всего с двумя значениями, поэтому преобразование любого числа в `bool` даёт `true` для любого ненулевого значения и `false` для `0`. Это отличается от преобразования в `int`:
```c
#include <stdbool.h>

bool b = 0.5;  // true, because 0.5 is not zero
int n = 0.5;   // 0, because the decimals are truncated
```
Сравнения вроде `x != 0` уже дают результат, совместимый с `bool`, а функция, возвращающая `bool`, документирует, что она отвечает на вопрос да/нет.

---

Арифметическая операция выполняется в типе своих операндов, а **не** в типе переменной, которая получает результат.
Поэтому `long big = n * n;` с `n` типа `int` перемножает два значения `int`, переполняется, если произведение слишком велико, и только потом сохраняет (уже неверный) результат в `long`.
Приведите один операнд **перед** операцией, чтобы вычисление выполнялось в более широком типе:
```c
int n = 100000;
long big = (long) n * n; // 10000000000, computed as long
```
То же правило объясняет, почему работает `(double) total / count`: приведение меняет тип операнда, и деление следует за ним.
