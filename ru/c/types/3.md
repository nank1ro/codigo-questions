# --description--

`%f` выводит шесть знаков после запятой, что редко бывает нужно. Поставьте точность между `%` и `f`, чтобы выбрать, сколько знаков показывать: `%.2f` выводит два знака, `%.1f` — один, при этом значение **округляется**, а не обрезается:
```c
double price = 9.987;
printf("%.2f\n", price); // prints "9.99"
printf("%.1f\n", price); // prints "10.0"
```
`float` выводится с теми же спецификаторами, что и `double`: при передаче в `printf` он автоматически преобразуется в `double`.

# --instructions--

Объявите `price` как `float` и дополните строку формата так, чтобы она выводила цену ровно с двумя знаками после запятой
