# --description--

Проход по списку, называемый **обходом**, — это цикл, который начинается с головы и идёт по `next`, пока не достигнет `NULL`. Цикл `for` выражает его одной строкой, где переменной цикла служит указатель:
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
Индекса здесь нет: единственный способ добраться до узла — через указатель, хранящийся в предыдущем.
