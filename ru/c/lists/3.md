# --description--

Список хранится одним-единственным указателем на его первый узел — **голову**. Любой другой узел достигается от головы переходами по `next`, и стрелку можно продолжать: `head->next` — это второй узел, а `head->next->next` — третий. Пустой список — это голова, равная `NULL`, и `next` последнего узла тоже `NULL`, поэтому один лишний переход по стрелке разыменует `NULL` и уронит программу.

# --instructions--

Что выведет следующий код, учитывая функцию `make_node` из предыдущего упражнения?
```c
Node *head = make_node(1);
head->next = make_node(2);
head->next->next = make_node(3);
printf("%d\n", head->next->next->value);
```
