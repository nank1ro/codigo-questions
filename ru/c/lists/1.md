# --description--

**Связный список** хранит значения в отдельных **узлах**, разбросанных по памяти: каждый узел содержит значение и указатель на следующий узел, а последний указывает на `NULL`. Указатель внутри ссылается на объявляемый тип, поэтому структуре нужен **тег**, чтобы назвать саму себя; имени из `typedef` внутри фигурных скобок ещё не существует:
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
Узлы связываются тем, что адрес одного сохраняется в `next` другого, а члены узла, на который указывает указатель, доступны через стрелку:
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```
