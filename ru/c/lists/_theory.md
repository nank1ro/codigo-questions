**Связный список** хранит значения в отдельных **узлах**, разбросанных по памяти: каждый узел содержит значение и указатель на следующий узел, а последний указывает на `NULL`. Указатель внутри ссылается на объявляемый тип, поэтому структуре нужен **тег**, чтобы назвать саму себя; имени из `typedef` внутри фигурных скобок ещё не существует:
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
Узлы связываются тем, что адрес одного сохраняется в `next` другого, а члены узла, на который указывает указатель, доступны через стрелку:
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```

---

Узлы, объявленные как локальные переменные, исчезают, когда их функция завершается, поэтому списки строятся в **куче** с помощью `malloc` из `stdlib.h`. Он резервирует запрошенное число байтов и возвращает их адрес, а если память исчерпана — `NULL`; `sizeof(Node)` — правильный объём для одного узла:
```c
Node *node = malloc(sizeof(Node));
node->value = 5;
node->next = NULL;
```
Память в куче никогда не освобождается сама: каждый узел, полученный из `malloc`, должен быть возвращён с помощью `free(node)`, как только он перестаёт быть нужным. В этих упражнениях `stdlib.h` уже подключён, а `Node` объявлен выше вашего кода.

---

Список хранится одним-единственным указателем на его первый узел — **голову**. Любой другой узел достигается от головы переходами по `next`, и стрелку можно продолжать: `head->next` — это второй узел, а `head->next->next` — третий. Пустой список — это голова, равная `NULL`, и `next` последнего узла тоже `NULL`, поэтому один лишний переход по стрелке разыменует `NULL` и уронит программу.

---

Проход по списку, называемый **обходом**, — это цикл, который начинается с головы и идёт по `next`, пока не достигнет `NULL`. Цикл `for` выражает его одной строкой, где переменной цикла служит указатель:
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
Индекса здесь нет: единственный способ добраться до узла — через указатель, хранящийся в предыдущем.

---

Добавление узла в **начало** создаёт его, заставляет указывать на текущую голову и возвращает его как новую голову. Вызывающий код сохраняет результат обратно в свою переменную головы:
```c
Node *head = NULL;
head = push_front(head, 7);
head = push_front(head, 8); // the list is now 8, 7
```
Вставка в пустой список работает так же: новый узел указывает на `NULL` и становится всем списком.

---

Освобождение списка означает освобождение каждого узла, по одному шагу обхода за раз. Указатель `next` нужно сохранить **до** освобождения узла, потому что освобождённый узел больше нельзя читать, даже его `next`:
```c
while (head != NULL) {
    Node *next = head->next;
    free(head);
    head = next;
}
```
Запись `free(head)` и затем `head = head->next` читает память, только что освобождённую, а это неопределённое поведение. `free(NULL)` разрешён и ничего не делает, поэтому пустой список не требует особого случая.

---

Список не хранит свою длину: её приходится считать обходом. Вариант цикла с `while` держит указатель снаружи, что удобно, когда тело цикла обновляет другие переменные:
```c
int count = 0;
Node *n = head;
while (n != NULL) {
    count++;
    n = n->next;
}
```
Для пустого списка тело цикла не выполняется ни разу, и счётчик остаётся `0`.

---

Добавление узла в **конец** требует последний узел — тот, чей `next` равен `NULL`. Функция идёт по списку, пока не найдёт его, затем подключает новый узел там и возвращает неизменённую голову:
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
Когда список пуст, идти до последнего узла не нужно: новый узел просто возвращается как голова.

---

Поиск в списке — это обход, который сравнивает каждое значение и останавливается на первом совпадении. Функция возвращает указатель на найденный узел или `NULL`, если достигла конца списка без совпадения:
```c
Node *found = find(head, 5);
if (found != NULL) {
    printf("%d\n", found->value);
}
```
Возврат узла, а не значения, позволяет вызывающему коду изменить его или использовать как отправную точку для другой операции.

---

После `free(p)` переменная `p` всё ещё хранит старый адрес, но память, на которую он указывает, вам больше не принадлежит: `p` теперь **висячий указатель**. Чтение или запись через него, как и повторное освобождение, — неопределённое поведение: программа может напечатать старое значение, напечатать мусор или упасть, и компилятор не станет возражать. Если указатель должен пережить `free`, сразу после него присвойте ему `NULL`, чтобы любое последующее использование перехватывалось проверкой на `NULL`.

---

Вставка **после** заданного узла не требует обхода: новый узел перенимает преемника `node`, затем `node` указывает на новый:
```c
new_node->next = node->next;
node->next = new_node;
```
Порядок двух присваиваний важен: если сначала установить `node->next`, единственный указатель на остаток списка будет перезаписан, и эти узлы будут потеряны. Вставка после последнего узла тоже работает, поскольку его `next` равен `NULL`.

---

Удаление первого узла зеркально `push_front`: сохраните адрес второго узла, освободите первый и верните сохранённый адрес как новую голову. Вызывающий код сохраняет результат обратно в свою переменную головы:
```c
Node *next = head->next;
free(head);
return next;
```
Извлечение, повторяемое пока голова не станет `NULL`, освобождает весь список, по одному узлу за вызов.

---

Удаление узла из середины требует узел, стоящий **перед** ним, поэтому обход хранит два указателя: `prev` — уже посещённый узел и `cur` — рассматриваемый. Когда `cur` совпадает, `prev->next` заставляют пропустить его, а `cur` освобождается. Если совпала сама голова, `prev` всё ещё `NULL`, и новой головой становится `cur->next`:
```c
if (prev == NULL) {
    head = cur->next;
} else {
    prev->next = cur->next;
}
free(cur);
```
Если не совпал ни один узел, список возвращается без изменений.

---

Разворот списка поворачивает каждый указатель `next` в обратную сторону на месте с помощью трёх указателей: `prev` — уже развёрнутая часть, `head` — обрабатываемый узел, а `next` — копия остатка списка, сохранённая до изменения связи. На каждом шаге текущий узел направляется обратно на `prev`, затем и `prev`, и `head` продвигаются вперёд:
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
Когда `head` достигает `NULL`, все связи перевёрнуты, и `prev` — новая голова.

---

Связный список дёшев там, где массив дорог, и наоборот. Добавление или удаление в **начале** — это пара присваиваний указателей при любой длине, тогда как массиву пришлось бы сдвигать каждый элемент. С другой стороны, узлы не расположены в памяти подряд, поэтому нет `list[i]`: добраться до n-го узла, до последнего или узнать общую длину — значит пройти от головы через каждый промежуточный узел. Программы, которые часто дописывают в конец, держат второй указатель на последний узел — **хвост**, чтобы избежать этого прохода.

---

Соберём всё вместе: список часто строится из массива. Вставка в начало меняет порядок на обратный, поэтому массив проходится **с конца**, от последнего элемента к первому, и первый элемент оказывается в голове. Затем программа выводит список с помощью обхода и освобождает его узел за узлом, чтобы каждому `malloc` соответствовал свой `free`.
