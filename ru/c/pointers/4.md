# --description--

Указатель, который пока ни на что не указывает, должен содержать `NULL` — специальную константу, определённую в `stdio.h` и `stddef.h` и означающую «нет адреса»:
```c
int *p = NULL;
```
Разыменование указателя `NULL` — это ошибка времени выполнения, которая аварийно завершает программу, поэтому указатель, который может быть `NULL`, проверяют перед использованием:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
Поскольку `NULL` равен нулю, `if (p)` — распространённое сокращение для `if (p != NULL)`. Указатель, объявленный без инициализатора, содержит мусор, а не `NULL`, поэтому всегда инициализируйте указатели.
