Каждая переменная где-то хранится в памяти, и у этого места есть номер, который называется её **адресом**. Оператор `&`, читаемый как «адрес», даёт адрес переменной:
```c
int x = 42;
printf("%p\n", &x); // prints something like 0x7ffd5c3e9a4c
```
Спецификатор `%p` выводит адрес; точное число меняется от запуска к запуску, поэтому программы никогда на него не полагаются.
Адрес хранится в переменной-**указателе**. Указатель объявляется с типом, на который он указывает, за которым следует `*`:
```c
int *p = &x; // p is a pointer to int, and it holds the address of x
```
Теперь говорят, что `p` **указывает на** `x`. Два указателя равны, когда содержат один и тот же адрес, поэтому `p == &x` истинно.

---

Сам по себе указатель — это просто адрес. Чтобы прочитать значение, хранящееся по этому адресу, указатель **разыменовывают** оператором `*`:
```c
int x = 42;
int *p = &x;
printf("%d\n", *p); // prints "42"
```
`*p` означает «значение, на которое указывает `p`», и это `int`, как и сама `x`. Один и тот же символ `*` играет две роли: в объявлении `int *p` он говорит «это указатель», а в выражении `*p` он проходит по указателю к значению.

---

Разыменованному указателю можно также **присваивать**. Запись в `*p` сохраняет новое значение по адресу, который содержит `p`, поэтому переменная, на которую он указывает, изменяется:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x` и `*p` — два имени для одной и той же памяти. Присваивание `p` без `*` вместо этого изменило бы то, **какой адрес** содержит указатель, а не значение, хранящееся по нему.

---

Указатель, который пока ни на что не указывает, должен содержать `NULL` — специальную константу, определённую в `stdio.h` и `stddef.h` и означающую «нет адреса»:
```c
int *p = NULL;
```
Разыменование указателя `NULL` — это ошибка времени выполнения, которая аварийно завершает программу, поэтому указатель, который может быть `NULL`, проверяют перед использованием:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
Поскольку `NULL` равен нулю, `if (p)` — распространённое сокращение для `if (p != NULL)`. Указатель, объявленный без инициализатора, содержит мусор, а не `NULL`, поэтому всегда инициализируйте указатели.

---

Указатель может указывать на любой тип: `double *`, `char *`, `bool *` и так далее. Тип в объявлении сообщает компилятору, сколько байт читать при разыменовании указателя и что они означают:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
Указатель должен соответствовать типу переменной, на которую он указывает; `int *p = &price;` компилятор отвергнет. `NULL` — единственное значение, которое подходит указателю любого типа.

---

Указатель на `char` работает как любой другой указатель: он содержит адрес одного символа, а `*p` читает или записывает этот символ:
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
Чтение через указатель и запись через него можно свободно смешивать: `*p = *p + 1` превращает `'A'` в `'B'`.

---

Указатель хранит адрес, а все адреса на конкретной машине имеют одинаковый размер, независимо от того, какой тип там хранится. Поэтому `sizeof` указателя одинаков для `char *`, `int *` и `double *`: `8` байт в 64-битной системе и `4` в 32-битной:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
Не путайте размер указателя с размером того, на что он указывает: `sizeof(p)` — это размер адреса, а `sizeof(*p)` — размер значения.

---

Имя массива, использованное в выражении, даёт адрес его **первого элемента**, поэтому его можно напрямую присвоить указателю:
```c
int numbers[3] = {10, 20, 30};
int *p = numbers; // same as &numbers[0]
```
Прибавление целого числа к указателю сдвигает его вперёд на столько **элементов**, а не байт: `p + 1` — это адрес `numbers[1]`, а `*(p + 1)` — это `20`. Компилятор масштабирует шаг по размеру типа.
Индексирование работает и с указателями: `p[i]` определяется как `*(p + i)`, поэтому `p[2]` — это `30`. Это называется **адресной арифметикой**.

---

Поскольку `p + 1` — это следующий элемент, `p++` перемещает сам указатель на следующий элемент. Цикл может обходить массив, продвигая указатель вместо индекса:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
На каждом шаге выводится элемент, на который указывает `p`, а затем `p` сдвигается на один элемент вперёд.

---

Когда массив передаётся в функцию, он **приводится** к указателю на свой первый элемент. Именно поэтому параметры `int values[]` и `int *values` означают в точности одно и то же и поэтому функция не может сама узнать длину: она получает только адрес.
Указатели внутри одного массива можно сравнивать и вычитать. `end - start` — это количество элементов между ними, а цикл может провести указатель от одного адреса к другому:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
Передача `numbers` и `numbers + 3` описывает первые три элемента без отдельного параметра размера.

---

Аргументы функции передаются **по значению**: функция получает копию, и присваивание параметру никогда не изменяет переменную вызывающего кода. Чтобы функция могла изменить переменную, передайте адрес переменной и разыменуйте указатель внутри:
```c
void reset(int *p) {
    *p = 0;
}

int counter = 7;
reset(&counter); // counter is now 0
```
Классический пример — обмен значениями двух переменных, для которого нужна временная копия одного значения, пока другое перезаписывается.

---

Функция может вернуть через `return` только одно значение. Чтобы вернуть больше, она принимает указатели на переменные вызывающего кода и записывает результаты через них. Такие параметры называются **выходными параметрами**:
```c
void min_max(int a, int b, int *min, int *max) {
    *min = a;
    *max = b;
    if (a > b) {
        *min = b;
        *max = a;
    }
}

int lo, hi;
min_max(4, 9, &lo, &hi); // lo is 4, hi is 9
```
Вызывающий код объявляет переменные, передаёт их адреса и после вызова находит их заполненными. Многие стандартные функции используют этот приём, поэтому `scanf("%d", &n)` и требует `&`.

---

Указатель на структуру добирается до её членов через стрелку `->`, а адрес структуры, хранящейся в массиве, берётся как `&items[i]`. Функция также может **возвращать** указатель, например на найденный элемент:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
Затем вызывающий код читает члены через возвращённый указатель с помощью `->`, предварительно убедившись, что он не `NULL`. Возврат указателя избавляет от копирования структуры и позволяет вызывающему коду изменять исходный элемент.

---

`const` может защищать либо значение, либо указатель — в зависимости от того, где он написан:
```c
const int *p = &a; // pointer to const: *p cannot be changed, p can point elsewhere
int *const q = &a; // const pointer: q always points to a, but *q can be changed
```
Читайте объявление справа налево: `p` — это указатель на константный `int`; `q` — это константный указатель на `int`. Указатель на const — обычный способ пообещать, что функция только **читает** то, что получает, как в `int sum(const int *values, int size)`. Ей можно передать и обычную переменную; обещание ограничивает лишь то, что может делать функция.

---

Указатель — это переменная, поэтому у него есть собственный адрес, и этот адрес можно сохранить в **указателе на указатель**, который объявляется двумя звёздочками:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp` — это `p`, адрес `x`, а `**pp` проходит оба шага и добирается до `7`. Указатели на указатели позволяют функции изменить, какой адрес содержит указатель: она получает `&p` и присваивает `*pp`.

---

Соберём всё вместе: функция обходит массив с помощью указателя, хранит указатель на лучший найденный элемент и возвращает его или `NULL`, когда возвращать нечего:
```c
int *first_negative(int *values, int size) {
    for (int *p = values; p < values + size; p++) {
        if (*p < 0) {
            return p;
        }
    }
    return NULL;
}
```
Вызывающий код сравнивает результат с `NULL`, прежде чем разыменовать его, и может использовать `result - values`, чтобы получить индекс элемента.
