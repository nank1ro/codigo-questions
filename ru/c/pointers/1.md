# --description--

Каждая переменная где-то хранится в памяти, и у этого места есть номер, который называется её **адресом**. Оператор `&`, читаемый как «адрес», даёт адрес переменной:
```c
int x = 42;
printf("%p\n", &x); // prints something like 0x7ffd5c3e9a4c
```
Спецификатор `%p` выводит адрес; точное число меняется от запуска к запуску, поэтому программы никогда на него не полагаются.
Адрес хранится в переменной-**указателе**. Указатель объявляется с типом, на который он указывает, за которым следует `*`:
```c
int *p = &x; // p is a pointer to int, and it holds the address of x
```
Теперь говорят, что `p` **указывает на** `x`. Два указателя равны, когда содержат один и тот же адрес, поэтому `p == &x` истинно.
