# --description--

Указатель — это переменная, поэтому у него есть собственный адрес, и этот адрес можно сохранить в **указателе на указатель**, который объявляется двумя звёздочками:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp` — это `p`, адрес `x`, а `**pp` проходит оба шага и добирается до `7`. Указатели на указатели позволяют функции изменить, какой адрес содержит указатель: она получает `&p` и присваивает `*pp`.
