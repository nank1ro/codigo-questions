# --description--

Поскольку `p + 1` — это следующий элемент, `p++` перемещает сам указатель на следующий элемент. Цикл может обходить массив, продвигая указатель вместо индекса:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
На каждом шаге выводится элемент, на который указывает `p`, а затем `p` сдвигается на один элемент вперёд.
