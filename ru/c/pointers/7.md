# --description--

Указатель хранит адрес, а все адреса на конкретной машине имеют одинаковый размер, независимо от того, какой тип там хранится. Поэтому `sizeof` указателя одинаков для `char *`, `int *` и `double *`: `8` байт в 64-битной системе и `4` в 32-битной:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
Не путайте размер указателя с размером того, на что он указывает: `sizeof(p)` — это размер адреса, а `sizeof(*p)` — размер значения.

# --instructions--

Что выведет следующий код в типичной 64-битной системе?
```c
char c = 'x';
char *p = &c;
printf("%zu %zu\n", sizeof(p), sizeof(*p));
```
