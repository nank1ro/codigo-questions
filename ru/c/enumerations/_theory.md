**Перечисление** (`enum`) даёт имена набору связанных целочисленных констант, поэтому вы можете написать `RED` вместо голого числа.
Вы объявляете его с помощью ключевого слова `enum`, имени и списка констант в фигурных скобках:
```c
enum Color { RED, GREEN, BLUE };
```
Каждая константа — целое число: если не указано иное, первая равна `0`, а каждая следующая — предыдущая плюс один, так что `RED` равен `0`, `GREEN` равен `1`, а `BLUE` равен `2`.
Поскольку это целые числа, вы выводите их с помощью `%d`:
```c
printf("%d\n", GREEN);
// prints "1"
```

---

Нумерация продолжается автоматически для стольких констант, сколько вы перечислите: четвёртая константа равна `3`, пятая — `4` и так далее.
Имена обычно пишутся заглавными буквами, как и другие константы, и должны быть уникальными во всей программе: два перечисления не могут использовать одно и то же имя константы.

---

Вы также можете задать константе явное значение с помощью `=`; следующие за ней константы продолжают отсчёт от этого значения:
```c
enum Month { JAN = 1, FEB, MAR }; // FEB is 2, MAR is 3
```
Явные значения не обязаны идти подряд или по возрастанию: `enum Status { OK = 200, NOT_FOUND = 404 };` совершенно допустимо.

---

Перечисление — это ещё и тип: вы можете объявить переменную этого типа, написав `enum`, а затем имя перечисления, и присвоить ей одну из его констант:
```c
enum Color favorite = GREEN;
```
Поскольку константы — целые числа, переменные enum сравниваются обычными операторами:
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```

---

Перечисление может быть типом параметра функции, точно так же как `int`:
```c
int is_weekend(enum Day day) {
    return day == SAT || day == SUN;
}
```
Внутри функции естественный способ обработать каждую константу — оператор `switch`, потому что константы enum можно использовать прямо как метки `case`:
```c
switch (day) {
    case SAT: return 1;
    case SUN: return 1;
    default: return 0;
}
```

---

Когда каждый case в `switch` обрабатывает одну константу, не забывайте про `break` после каждого из них, иначе выполнение провалится к следующему case.
Case `default` не обязателен, если вы охватили все константы перечисления.

---

Функция тоже может возвращать перечисление; достаточно указать тип enum как тип возвращаемого значения и вернуть одну из его констант:
```c
enum Grade grade_for(int score) {
    if (score >= 60) {
        return PASS;
    }
    return FAIL;
}
```
Возврат именованной константы гораздо понятнее для вызывающего кода, чем возврат голого `0` или `1`.

---

Писать `enum Color` каждый раз многословно. С помощью `typedef` вы даёте перечислению короткое имя типа, а само перечисление может остаться анонимным:
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
Новое имя `Color` используется само по себе, без ключевого слова `enum` перед ним.

---

Константа enum автоматически преобразуется в `int`, поэтому `int n = BLUE;` допустимо и сохраняет `2`.
Обратное преобразование делается с помощью **приведения типа**: тип enum записывается в скобках перед целым числом:
```c
enum Color c = (enum Color)1; // c is GREEN
```
C не проверяет, что число соответствует константе: `(enum Color)7` компилируется, даже если ни одна константа не равна `7`, поэтому проверяйте целые числа перед преобразованием.

---

Арифметика над значением enum даёт обычный `int`: `GREEN + 1` равно `2`, а не `BLUE`.
Чтобы сохранить результат обратно в переменную enum или вернуть его из функции, приведите его к типу enum:
```c
enum Color after_green = (enum Color)(GREEN + 1); // BLUE
```
В сочетании с оператором остатка `%` это позволяет циклически проходить по константам и возвращаться к первой.

---

Распространённый приём — добавить в конец перечисления ещё одну константу, обычно называемую `COUNT`: поскольку нумерация начинается с `0`, её значение в точности равно числу настоящих констант перед ней.
```c
enum Day { MON, TUE, WED, DAY_COUNT }; // DAY_COUNT is 3
```
Такой страж позволяет пройти циклом по всем константам, не зашивая число в код, и остаётся верным, если вы добавите константы перед ним:
```c
for (int d = MON; d < DAY_COUNT; d++) {
    printf("%d\n", d);
}
```

---

Страж `COUNT` также идеально подходит по размеру для массива с одним слотом на константу, и константы становятся понятными индексами в нём:
```c
enum Fruit { APPLE, BANANA, CHERRY, FRUIT_COUNT };

int stock[FRUIT_COUNT] = {10, 4, 7};
printf("%d\n", stock[BANANA]); // prints "4"
```
Цикл от `0` до `FRUIT_COUNT` посещает каждый слот, а индекс цикла можно привести обратно к `enum Fruit`, когда нужно его вернуть.

---

В C нет встроенного способа получить имя константы перечисления: `printf("%d\n", SUMMER)` выводит `2`, а не `Summer`. Обычное решение — небольшая функция со `switch`, которая возвращает соответствующую строку для каждой константы.

---

Значения enum можно хранить в массивах, как и любые другие целые числа: `enum Fruit basket[] = {APPLE, APPLE, CHERRY};` содержит три фрукта, и каждый элемент можно сравнить с константой.
