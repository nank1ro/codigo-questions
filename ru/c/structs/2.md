# --description--

Инициализация членов по порядку ненадёжна: если у структуры появится новый член, сдвинется каждый инициализатор. Начиная с C99 **именованный инициализатор** задаёт каждый член через точку, в любом порядке:
```c
struct Point p = {.y = 4, .x = 3};
```
Члены, которые не перечислены, получают значение `0`, поэтому `{.y = 5}` даёт `x`, равный `0`. Это отличается от переменной, объявленной без какого-либо инициализатора, `struct Point q;`, члены которой хранят **мусор**, пока вы не присвоите им значения:
```c
struct Point q;
q.x = 1;
q.y = 2;
```

# --instructions--

Что выведет следующий код?
```c
struct Point { int x; int y; };
struct Point p = {.y = 5};
printf("%d %d\n", p.x, p.y);
```

- 5 0
- 5 5
