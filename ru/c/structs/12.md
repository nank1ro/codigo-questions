# --description--

`sizeof` работает и со структурами, и это правильный способ узнать, сколько памяти она занимает:
```c
printf("%zu\n", sizeof(Point));
```
Размер равен **как минимум** сумме размеров членов. Он может быть больше, потому что компилятор может вставить неиспользуемые байты **заполнения** (padding), чтобы каждый член оказался по адресу, подходящему его типу: `struct { char c; int n; }` обычно занимает `8` байт, а не `5`. Никогда не вписывайте размер структуры в код вручную; спрашивайте у `sizeof`.
