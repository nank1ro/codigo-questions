**Структура** (`struct`) объединяет связанные значения разных типов в один новый тип. Каждое значение внутри неё называется **членом**.
В объявлении перечисляются члены между фигурными скобками, и оно заканчивается точкой с запятой; оно создаёт тип `struct Point`, но пока не переменную:
```c
struct Point {
    int x;
    int y;
};
```
Переменная такого типа объявляется с помощью `struct Point`, а её члены можно инициализировать **по порядку** в фигурных скобках, как массив:
```c
struct Point p = {3, 4}; // x is 3, y is 4
```
Члены читаются и записываются с помощью оператора **точка** `.`:
```c
printf("%d\n", p.x); // prints "3"
p.y = 10;
```

---

Инициализация членов по порядку ненадёжна: если у структуры появится новый член, сдвинется каждый инициализатор. Начиная с C99 **именованный инициализатор** задаёт каждый член через точку, в любом порядке:
```c
struct Point p = {.y = 4, .x = 3};
```
Члены, которые не перечислены, получают значение `0`, поэтому `{.y = 5}` даёт `x`, равный `0`. Это отличается от переменной, объявленной без какого-либо инициализатора, `struct Point q;`, члены которой хранят **мусор**, пока вы не присвоите им значения:
```c
struct Point q;
q.x = 1;
q.y = 2;
```

---

Структура передаётся в функцию, как любое другое значение. Параметр объявляется с полным именем типа, а функция читает члены с помощью `.`:
```c
struct Point { int x; int y; };

int sum(struct Point p) {
    return p.x + p.y;
}
```
Структура должна быть объявлена **до** функции, которая её использует, чтобы компилятор уже знал её члены.

---

Писать `struct Point` каждый раз громоздко. С помощью `typedef` вы даёте структуре короткое имя типа, а сама структура может оставаться анонимной:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
Новое имя `Temperature` используется само по себе, без ключевого слова `struct` перед ним. Это самый распространённый способ объявлять структуры в реальных программах.

---

Член сам может быть структурой. Отрезок, например, состоит из двух точек:
```c
typedef struct { int x; int y; } Point;

typedef struct {
    Point start;
    Point end;
} Segment;
```
Вложенная структура инициализируется своей парой фигурных скобок, а её члены доступны через цепочку операторов точка:
```c
Segment s = {{1, 2}, {5, 2}};
printf("%d\n", s.end.x); // prints "5"
```

---

Структуры можно хранить в массиве, как и любой другой тип. Каждый элемент инициализируется своими фигурными скобками, а цикл обходит их по одному: сначала обращение по индексу, затем оператор точка:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

---

Массив структур передаётся в функцию в точности как массив чисел: параметр записывается как `Item items[]`, а поскольку массив не хранит свою длину, размер передаётся отдельно:
```c
int count_free(Item items[], int size) {
    int count = 0;
    for (int i = 0; i < size; i++) {
        if (items[i].price == 0) {
            count++;
        }
    }
    return count;
}
```

---

Когда структура передаётся в функцию **по значению**, функция получает её **копию**. Изменение члена параметра меняет только копию, а переменная вызывающего кода остаётся прежней:
```c
void reset(Point p) {
    p.x = 0; // changes the copy
}
```
Чтобы функция могла изменить структуру вызывающего кода, передайте её **адрес** с помощью `&` и объявите параметр как **указатель**, `Point *p`. Указатель ссылается на исходную переменную, а не на копию:
```c
void reset(Point *p) { ... }

reset(&origin);
```
Копирование также занимает время для больших структур, поэтому указатели — обычный выбор, даже когда ничего не изменяется.

---

Через указатель члены доступны с помощью оператора **стрелка** `->` вместо точки:
```c
void grow(Box *b) {
    b->size = b->size * 2;
}
```
`b->size` — это сокращение для `(*b).size`: сначала перейти по указателю, затем взять член. Точка работает только со структурой, стрелка — только с указателем на структуру.
Вызывающий код передаёт адрес своей переменной с помощью `&`, и изменение, сделанное через указатель, видно после вызова.

---

Функция, принимающая указатель на структуру, может обновить исходное значение на месте. Это стандартный способ писать функции-«модификаторы» в C: первый параметр — структура, которую нужно изменить, а остальные — данные, которые нужно применить:
```c
void set_number(Player *p, int new_number) {
    p->number = new_number;
}
```
Чтение и запись идут через ту же стрелку: `p->score += 10` прибавляет к члену структуры, на которую ссылается указатель.

---

Функция может также **возвращать** структуру. Соберите её в локальной переменной и верните её; вызывающий код получает копию всего значения:
```c
Point make_point(int x, int y) {
    Point p = {x, y};
    return p;
}

Point origin = make_point(0, 0);
```
Так C возвращает из функции более одного значения: упакуйте их в структуру.

---

`sizeof` работает и со структурами, и это правильный способ узнать, сколько памяти она занимает:
```c
printf("%zu\n", sizeof(Point));
```
Размер равен **как минимум** сумме размеров членов. Он может быть больше, потому что компилятор может вставить неиспользуемые байты **заполнения** (padding), чтобы каждый член оказался по адресу, подходящему его типу: `struct { char c; int n; }` обычно занимает `8` байт, а не `5`. Никогда не вписывайте размер структуры в код вручную; спрашивайте у `sizeof`.

---

Структуры нельзя сравнивать с помощью `==`: запись `a == b` для двух структур — это **ошибка компиляции**. Вместо этого сравнивайте их **по членам**, объединяя результаты с помощью `&&`:
```c
bool same_size(Rectangle a, Rectangle b) {
    return a.width == b.width && a.height == b.height;
}
```
То же относится к `<` и `>`: вы решаете, какой член определяет порядок.

---

Структура часто хранит текст, который содержится в члене — массиве `char` фиксированного размера:
```c
typedef struct {
    char name[20];
    int age;
} Person;
```
Члену-массиву нельзя присвоить значение с помощью `=` после объявления: `p.name = "Ann"` не компилируется. Скопируйте текст в него с помощью `strcpy` из `string.h`, передав член как приёмник:
```c
Person p;
strcpy(p.name, "Ann");
p.age = 30;
```
Только инициализатор в фигурных скобках при объявлении принимает строку напрямую: `Person p = {"Ann", 30};`.

---

У `printf` нет спецификатора для целой структуры. Обычное решение — небольшая функция, которая выводит члены в фиксированном формате, чтобы каждая часть программы показывала значение одинаково:
```c
void print_person(Person p) {
    printf("%s (%d)\n", p.name, p.age);
}
```

---

Соберём всё вместе: функция, принимающая указатель на структуру, может обновить текстовый член с помощью `strcpy` через стрелку, поскольку `item->name` — это массив `char` внутри исходной структуры:
```c
void set_title(Book *book, char *title) {
    strcpy(book->title, title);
}
```
Не забудьте добавить `#include <string.h>` в начало своего кода, чтобы использовать `strcpy`.
