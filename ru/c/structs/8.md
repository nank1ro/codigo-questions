# --description--

Когда структура передаётся в функцию **по значению**, функция получает её **копию**. Изменение члена параметра меняет только копию, а переменная вызывающего кода остаётся прежней:
```c
void reset(Point p) {
    p.x = 0; // changes the copy
}
```
Чтобы функция могла изменить структуру вызывающего кода, передайте её **адрес** с помощью `&` и объявите параметр как **указатель**, `Point *p`. Указатель ссылается на исходную переменную, а не на копию:
```c
void reset(Point *p) { ... }

reset(&origin);
```
Копирование также занимает время для больших структур, поэтому указатели — обычный выбор, даже когда ничего не изменяется.

    printf("%d\n", box.size);
    return 0;
}
