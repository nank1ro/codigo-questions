# --description--

Оператор **сдвига вправо** `>>` перемещает каждый бит вправо; биты, выпавшие за правый край, отбрасываются. У беззнакового значения освободившиеся разряды слева заполняются нулями:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// prints "3"
```
Сдвиг вправо на `n` делит беззнаковое значение на 2 в степени `n`, отбрасывая остаток.
Сдвиг вправо *отрицательного* значения непереносим, и это ещё одна причина выполнять битовые операции с типами `unsigned`.
