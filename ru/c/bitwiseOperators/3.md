# --description--

Оператор **XOR** `^` (исключающее ИЛИ) оставляет `1` только там, где два бита *различаются*:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
Из этого следует полезное свойство: дважды применённый один и тот же XOR возвращает исходное значение.
