Каждое целое число хранится в памяти в виде строки **битов**, каждый из которых равен `0` или `1`. Число `12` хранится как `00001100`, а число `10` — как `00001010`.
**Побитовые операторы** работают с отдельными битами, а не с числом целиком. Оператор **И** `&` сравнивает два значения побитово и оставляет `1` только там, где *оба* бита равны `1`:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// выводит "8"
```
Битовые шаблоны обычно записывают в виде шестнадцатеричных литералов, таких как `0x0C`, потому что каждая шестнадцатеричная цифра соответствует ровно четырём битам. Для битовых операций всегда используйте типы `unsigned` и выводите их с помощью `%u`.

---

Оператор **ИЛИ** `|` сравнивает два значения побитово и оставляет `1` там, где равен `1` *хотя бы один* из битов:
```c
//  00001100   (12)
// |00001010   (10)
//  --------
//  00001110   (14)
printf("%u\n", 12u | 10u);
// выводит "14"
```
`|` — обычный способ объединить два битовых шаблона в один.

---

Оператор **XOR** `^` (исключающее ИЛИ) оставляет `1` только там, где два бита *различаются*:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// выводит "6"
```
Из этого следует полезное свойство: дважды применённый один и тот же XOR возвращает исходное значение.

---

Оператор **НЕ** `~` принимает один операнд и инвертирует каждый его бит: каждый `0` становится `1`, а каждая `1` становится `0`.
В `unsigned int` 32 бита, поэтому `~0x0Fu` инвертирует все 32 и даёт очень большое число. Чтобы оставить только нужный байт, объедините `~` с `& 0xFF`:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// выводит "240"
```
`~` связывает сильнее, чем `&`, поэтому применяется первым.
Не путайте `~` с логическим `!`: `!` смотрит на значение целиком и отвечает `0` или `1`, тогда как `~` переписывает каждый бит.

---

Оператор **сдвига влево** `<<` перемещает каждый бит на несколько разрядов влево и заполняет освободившиеся разряды справа нулями:
```c
//  00000011   (3)
//  << 2
//  00001100   (12)
printf("%u\n", 3u << 2);
// выводит "12"
```
Сдвиг влево на `n` умножает значение на 2 в степени `n`.
Две ошибки делают программу на C неопределённой: сдвиг влево отрицательного значения и сдвиг на величину, равную ширине типа или превышающую её (32 для `unsigned int`). Работа с **беззнаковыми** значениями избавляет от первой из них.

---

Оператор **сдвига вправо** `>>` перемещает каждый бит вправо; биты, выпавшие за правый край, отбрасываются. У беззнакового значения освободившиеся разряды слева заполняются нулями:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// выводит "3"
```
Сдвиг вправо на `n` делит беззнаковое значение на 2 в степени `n`, отбрасывая остаток.
Сдвиг вправо *отрицательного* значения непереносим, и это ещё одна причина выполнять битовые операции с типами `unsigned`.

---

У каждого бинарного побитового оператора есть форма **составного присваивания**, которая обновляет переменную на месте: `&=`, `|=`, `^=`, `<<=` и `>>=`.
```c
unsigned int x = 12;
x &= 10;  // то же самое, что x = x & 10;
x |= 1;   // то же самое, что x = x | 1;
x ^= 3;   // то же самое, что x = x ^ 3;
x <<= 1;  // то же самое, что x = x << 1;
x >>= 2;  // то же самое, что x = x >> 2;
```
Они читаются лучше, чем повторение имени переменной, и являются обычным способом изменить биты переменной-флага.

---

**Маска** — это значение, биты которого выделяют ту часть другого значения, которая вам нужна. В сочетании с `&` маска сохраняет биты, равные `1` в маске, и обнуляет все остальные:
```c
//  10101011   (0xAB)
// &00001111   (0x0F)
//  --------
//  00001011   (0x0B)
printf("%u\n", 0xABu & 0x0Fu);
// выводит "11"
```
`0x0F` сохраняет младшие четыре бита, называемые младшим **ниблом**, а `0xFF` сохраняет младшие восемь бит — целый байт.

---

Биты нумеруются с `0`, начиная с самого правого, поэтому `1u << n` — это маска, в которой включён только бит `n`.
Чтобы **установить** отдельный бит, то есть включить его, не трогая остальные, выполните операцию ИЛИ между значением и этой маской:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// выводит "6"
```
Если бит уже был включён, значение не меняется, что делает установку бита безопасной для повторения.

---

Чтобы **сбросить** отдельный бит, то есть выключить его, выполните операцию И между значением и *инверсией* маски:
```c
unsigned int value = 7;       // 00000111
value = value & ~(1u << 1);   // 00000101
printf("%u\n", value);
// выводит "5"
```
`~(1u << 1)` — это значение, в котором включены все биты, кроме бита `1`, поэтому операция И не трогает всё остальное.

---

Чтобы **переключить** отдельный бит, то есть инвертировать его независимо от текущего состояния, выполните операцию XOR между значением и маской:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// выводит "7"
```
Поскольку XOR отменяет сам себя, повторное переключение того же бита возвращает исходное значение.

---

Чтобы **проверить** отдельный бит, выполните операцию И между значением и маской и посмотрите, отличается ли результат от `0`:
```c
unsigned int value = 10;                  // 00001010
printf("%d\n", (value & (1u << 3)) != 0); // выводит "1"
printf("%d\n", (value & (1u << 2)) != 0); // выводит "0"
```
Операция И не даёт `1`: она даёт либо `0`, либо саму маску, которая для бита `3` равна `8`. Именно поэтому результат сравнивается с помощью `!= 0`, а не используется как готовый ответ.

---

**Флаги** — это именованные маски, каждая из которых использует свой бит; все они могут храниться в одной переменной. Они объединяются с помощью `|` и проверяются с помощью `&`:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// выводит "1"
```
Таким образом, один `unsigned int` может нести 32 независимых ответа «да/нет».

---

До C23 не существовало спецификатора формата, выводящего число в двоичном виде, и литералы вроде `0b1010` тоже не были стандартным C. Чтобы показать биты, напишите цикл сами: пройдите от старшего бита до бита `0` и каждый раз выводите `(value >> i) & 1u`.
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// выводит "0101"
```
Сдвиг значения вправо на `i` помещает бит `i` в самую правую позицию, где `& 1u` изолирует его.

---

Подсчёт того, сколько бит значения равны `1`, — это классический битовый цикл: проверьте младший бит с помощью `& 1u`, прибавьте его к счётчику, затем сдвиньте значение на один разряд вправо с помощью `>>=` и повторяйте, пока ничего не останется.
```c
unsigned int value = 6, count = 0;
while (value != 0) {
    count += value & 1u;
    value >>= 1;
}
// count равно 2
```
Цикл всегда заканчивается, потому что беззнаковое значение после достаточного числа сдвигов вправо становится `0`.

---

Несколько маленьких чисел часто упакованы внутри одного большего значения. Чтобы прочитать одно из них, сначала сдвиньте его вниз так, чтобы оно начиналось с бита `0`, а затем замаскируйте всё, что выше него:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// выводит "18", байт 0x12
```
Сначала сдвиг, потом маскирование — вот порядок, который нужно запомнить: маска всегда описывает поле, когда оно уже опустилось вниз.
