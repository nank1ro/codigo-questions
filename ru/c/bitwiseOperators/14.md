# --description--

До C23 не существовало спецификатора формата, выводящего число в двоичном виде, и литералы вроде `0b1010` тоже не были стандартным C. Чтобы показать биты, напишите цикл сами: пройдите от старшего бита до бита `0` и каждый раз выводите `(value >> i) & 1u`.
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
Сдвиг значения вправо на `i` помещает бит `i` в самую правую позицию, где `& 1u` изолирует его.
