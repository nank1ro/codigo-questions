# --description--

Биты нумеруются с `0`, начиная с самого правого, поэтому `1u << n` — это маска, в которой включён только бит `n`.
Чтобы **установить** отдельный бит, то есть включить его, не трогая остальные, выполните операцию ИЛИ между значением и этой маской:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// prints "6"
```
Если бит уже был включён, значение не меняется, что делает установку бита безопасной для повторения.
