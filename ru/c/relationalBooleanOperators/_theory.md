**Операторы сравнения** сравнивают два значения. Результат не является особым типом: это `int`, который равен `1`, когда сравнение верно, и `0`, когда нет. В C их шесть:
```c
printf("%d\n", 5 == 5); // равно: выводит "1"
printf("%d\n", 5 != 5); // не равно: выводит "0"
printf("%d\n", 3 < 5);  // меньше: выводит "1"
printf("%d\n", 3 > 5);  // больше: выводит "0"
printf("%d\n", 5 <= 5); // меньше или равно: выводит "1"
printf("%d\n", 4 >= 5); // больше или равно: выводит "0"
```
Поскольку результат имеет тип `int`, он выводится с помощью `%d` и может храниться в переменной типа `int`, как любое другое число.

---

Функция может возвращать результат сравнения напрямую: вызывающий код получает `1` или `0`.
```c
int is_big(int n) {
    return n > 100;
}

printf("%d\n", is_big(250)); // выводит "1"
```
Выбор между `>` и `>=` (или `<` и `<=`) определяет, учитывается ли граничное значение: `n >= 100` равно `1` для `100`, `n > 100` равно `0`.

---

Самая распространённая ошибка в C — написать `=` там, где имелся в виду `==`. Одиночный `=` — это **присваивание**, а в C присваивание является выражением, значение которого равно присвоенному значению:
```c
int x = 3;
printf("%d\n", x == 7); // сравнивает: выводит "0", x по-прежнему 3
printf("%d\n", x = 7);  // присваивает: выводит "7", x теперь 7
```
Код с `=` всё равно компилируется, поэтому условие, записанное как `if (x = 0)`, молча присваивает `x` значение `0` вместо проверки. Большинство компиляторов выводят об этом предупреждение: читайте его.

---

**Логические операторы** объединяют условия. Оператор **И** `&&` даёт `1`, только когда истинны обе части, а оператор **ИЛИ** `||` даёт `1`, когда истинна хотя бы одна часть:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // выводит "1"
printf("%d\n", t < 20 || t > 30); // выводит "0"
```
В C **любое ненулевое значение считается истиной**, и только `0` считается ложью, поэтому `5 && 1` равно `1`, а `0 || -3` равно `1`. Результат `&&` и `||` — всегда ровно `1` или `0`.

---

Переменная, хранящая `0` или ненулевое значение, может использоваться как условие сама по себе: одно `holiday` означает «holiday не равно нулю», и писать `holiday != 0` не нужно.
```c
int is_open(int weekday, int holiday) {
    return weekday && !holiday;
}
```
Оператор **НЕ** `!` меняет условие на противоположное: `!0` равно `1`, а `!` от любого ненулевого значения равно `0`.

---

Поскольку `!` превращает любое ненулевое значение в `0`, а `0` — в `1`, двойное применение нормализует значение ровно к `0` или `1`: `!!42` равно `1`, `!!0` равно `0`.
```c
int count = 3;
printf("%d %d\n", !count, !!count); // выводит "0 1"
```
Это удобно, когда функция возвращает произвольное ненулевое число, а вам нужно аккуратное `1`.

---

Начиная с C99 заголовок `stdbool.h` предоставляет тип `bool` и константы `true` (которая равна `1`) и `false` (которая равна `0`):
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // выводит "1 0"
```
По своей сути `bool` остаётся целым числом: он выводится с помощью `%d` и работает с `&&`, `||` и `!` точно так же, как результат сравнения. Он просто делает намерение более ясным, чем обычный `int`.

---

Функция, отвечающая на вопрос «да/нет», должна возвращать `bool`. Параметр типа `bool` уже является условием, поэтому используйте его напрямую как операнд `&&` или `||`: пишите `age >= 18 && citizen`, а не `citizen == true`.
```c
bool can_enter(int age, bool member) {
    return age >= 16 && member;
}
```
`stdbool.h` уже подключён выше вашего кода в этих упражнениях.

---

`&&` и `||` используют **вычисление по короткой схеме**: они прекращают работу, как только результат становится известен.
- при `&&`, если левая часть равна `0`, правая часть никогда не вычисляется
- при `||`, если левая часть не равна нулю, правая часть никогда не вычисляется

Это позволяет проверке слева защитить опасную операцию справа:
```c
int ok = count != 0 && total / count > 2;
```
Когда `count` равен `0`, деление никогда не выполняется, поэтому программа не падает.

---

Вычисление по короткой схеме также пропускает вызовы функций. В `1 || check()` функция `check` никогда не вызывается, поэтому любой её побочный эффект, например обновление счётчика, не происходит.
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
Помните об этом, когда функция в правой части `&&` или `||` делает что-то важное для вас.

---

У операторов есть **приоритет**, определяющий, что вычисляется первым:
1. сначала применяется `!`
2. затем реляционные сравнения `<`, `>`, `<=`, `>=`
3. затем сравнения на равенство `==`, `!=`
4. затем `&&`
5. затем `||`

Поэтому `a > 0 && a < 10` не нуждается в скобках, а `a && b || c` означает `(a && b) || c`, потому что `&&` связывает сильнее, чем `||`. Используйте скобки, чтобы задать другую группировку или просто сделать намерение читаемым.

---

`char` — это небольшое целое число, поэтому символы сравниваются теми же операторами. Сравнивайте с символьным литералом в одинарных кавычках: `"a"` в двойных кавычках — это строка, которую так сравнивать нельзя.
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // выводит "1"
```
Соседние символы, такие как `'0'`, `'1'`, ... `'9'` или `'a'`, `'b'`, ... `'z'`, имеют соседние коды, поэтому проверка диапазона для символов работает точно так же, как для чисел:
```c
bool is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

Не объединяйте сравнения в цепочки, как в математике. `1 <= x <= 10` компилируется, но вычисляется как `(1 <= x) <= 10`: первое сравнение даёт `0` или `1`, и это значение затем сравнивается с `10`, поэтому всё выражение всегда равно `1`.
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // выводит "1" (неверно!)
printf("%d\n", 1 <= x && x <= 10);  // выводит "0"
```
Всегда записывайте оба сравнения явно и объединяйте их с помощью `&&`.

---

Когда условие смешивает `&&` и `||`, заключайте каждую часть в скобки, даже если приоритет уже даёт правильный результат: правило становится читаемым с первого взгляда.
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
Оператор остатка `%` естественно сочетается с `==`: `n % 4 == 0` равно `1`, когда `n` делится на `4`.
