# --description--

Не объединяйте сравнения в цепочки, как в математике. `1 <= x <= 10` компилируется, но вычисляется как `(1 <= x) <= 10`: первое сравнение даёт `0` или `1`, и это значение затем сравнивается с `10`, поэтому всё выражение всегда равно `1`.
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // выводит "1" (неверно!)
printf("%d\n", 1 <= x && x <= 10);  // выводит "0"
```
Всегда записывайте оба сравнения явно и объединяйте их с помощью `&&`.
