# --description--

**Операторы сравнения** сравнивают два значения. Результат не является особым типом: это `int`, который равен `1`, когда сравнение верно, и `0`, когда нет. В C их шесть:
```c
printf("%d\n", 5 == 5); // равно: выводит "1"
printf("%d\n", 5 != 5); // не равно: выводит "0"
printf("%d\n", 3 < 5);  // меньше: выводит "1"
printf("%d\n", 3 > 5);  // больше: выводит "0"
printf("%d\n", 5 <= 5); // меньше или равно: выводит "1"
printf("%d\n", 4 >= 5); // больше или равно: выводит "0"
```
Поскольку результат имеет тип `int`, он выводится с помощью `%d` и может храниться в переменной типа `int`, как любое другое число.
