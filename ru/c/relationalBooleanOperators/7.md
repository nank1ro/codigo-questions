# --description--

Начиная с C99 заголовок `stdbool.h` предоставляет тип `bool` и константы `true` (которая равна `1`) и `false` (которая равна `0`):
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // выводит "1 0"
```
По своей сути `bool` остаётся целым числом: он выводится с помощью `%d` и работает с `&&`, `||` и `!` точно так же, как результат сравнения. Он просто делает намерение более ясным, чем обычный `int`.
