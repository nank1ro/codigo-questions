# --description--

**Логические операторы** объединяют условия. Оператор **И** `&&` даёт `1`, только когда истинны обе части, а оператор **ИЛИ** `||` даёт `1`, когда истинна хотя бы одна часть:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // выводит "1"
printf("%d\n", t < 20 || t > 30); // выводит "0"
```
В C **любое ненулевое значение считается истиной**, и только `0` считается ложью, поэтому `5 && 1` равно `1`, а `0 || -3` равно `1`. Результат `&&` и `||` — всегда ровно `1` или `0`.
