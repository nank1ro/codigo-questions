# --description--

Вычисление по короткой схеме также пропускает вызовы функций. В `1 || check()` функция `check` никогда не вызывается, поэтому любой её побочный эффект, например обновление счётчика, не происходит.
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
Помните об этом, когда функция в правой части `&&` или `||` делает что-то важное для вас.

# --instructions--

Каков результат выполнения следующего кода?
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}

int main() {
    int result = 1 || check();
    printf("%d %d\n", result, calls);
    return 0;
}
```
