# --description--

`&&` и `||` используют **вычисление по короткой схеме**: они прекращают работу, как только результат становится известен.
- при `&&`, если левая часть равна `0`, правая часть никогда не вычисляется
- при `||`, если левая часть не равна нулю, правая часть никогда не вычисляется

Это позволяет проверке слева защитить опасную операцию справа:
```c
int ok = count != 0 && total / count > 2;
```
Когда `count` равен `0`, деление никогда не выполняется, поэтому программа не падает.
