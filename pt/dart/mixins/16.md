# --description--

Mixins empilhados são a forma de combinar regras pequenas e independentes em uma única classe. Cada mixin sobrescreve o mesmo membro, faz a sua parte e chama `super` para passar o trabalho adiante. Como a chamada entra primeiro no **último** mixin, a ordem da lista `with` decide qual regra roda antes de qual:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` dobra cada depósito. Adicione um segundo mixin depois de `Doubled` e ele recebe o depósito primeiro, antes de `Doubled` sequer o ver.

# --instructions--

A classe `Account` já está escrita: ela tem um campo `balance` do tipo `int` começando em `0` e um método `deposit` que soma seu argumento `int` a `balance`.

Declare um mixin `Audited` em `Account` com um campo `log` do tipo `List<String>` começando vazio, sobrescrevendo `deposit` de modo que ele primeiro adicione a string `'deposit '` seguida do valor a `log`, e depois chame `super.deposit`.

Declare um mixin `Limited` em `Account` sobrescrevendo `deposit` de modo que um valor maior que `100` seja ignorado, e qualquer outro valor seja passado adiante para `super.deposit`.

Declare uma classe `SafeAccount` que estende `Account` e usa os dois mixins, de modo que um depósito rejeitado nunca chegue ao log.

Exemplo:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
