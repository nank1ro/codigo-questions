# --description--

Coletar uma série inteira de mensagens segue uma receita: uma lista vazia antes do laço, um `add` por mensagem real, e `close()` no sinal que encerra a stream. Uma vez fechada a porta, o `await for` termina e a função pode retornar:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

As mensagens mantêm a ordem em que foram enviadas, então a lista que você constrói espelha o trabalho do outro isolate passo a passo.

# --instructions--

Escreva uma função de nível superior `sendWords` que recebe uma `List<Object>` `message` em que o elemento `0` é um `SendPort` e o elemento `1` é uma `List<String>`: envie cada palavra à porta e depois envie `null` para sinalizar o fim.

Depois escreva uma função `collectWords` que recebe uma `List<String>` `words` e retorna um `Future<List<String>>` que conclui com todas as palavras recebidas de um isolate `sendWords` iniciado.

Exemplo:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

# --solutions--

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
