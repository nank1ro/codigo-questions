# --instructions--

Escreva uma função `sumUntilError` que recebe uma `Stream<int>` `source` e retorna um `Future<int>` que se completa com a soma de seus valores. Se a stream emitir um erro, pare e complete com a soma dos valores recebidos **antes** do erro, em vez de lançar a exceção.

Exemplo:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
