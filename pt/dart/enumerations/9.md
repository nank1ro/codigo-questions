# --instructions--

Dado `enum Size { small, medium, large }`, o que acontece com o código a seguir?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Não compila: uma expressão `switch` sobre um enum deve cobrir todos os valores
- Compila e retorna `null` para `Size.large`
- Compila e lança uma exceção em tempo de execução para `Size.large`
- Compila e retorna `'L'` para `Size.large` automaticamente
