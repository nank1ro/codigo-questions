# --description--

Como `await` transforma erros de future em exceções comuns, todos os padrões usuais de `try`/`catch` valem para código assíncrono, inclusive laços que tentam de novo. Dentro de um bloco `catch`, **`rethrow`** lança o mesmo erro outra vez, e é assim que você desiste depois da última tentativa:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Um parâmetro do tipo função como `Future<String> Function() task` recebe a **função** em si, não um future: cada chamada de `task()` inicia uma nova tentativa.

# --instructions--

Escreva uma função `async` `retry` que recebe um `Future<int> Function()` `task` e um `int` `attempts`, e retorna um `Future<int>`. Chame `task()` e conclua com o valor dele; se lançar, tente de novo, chamando `task` no máximo `attempts` vezes no total. Se a última tentativa também falhar, relance o erro dela com `rethrow`.

Exemplo:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` de uma tarefa que sempre dá certo deveria concluir com o valor dela depois de uma única chamada

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` de uma tarefa que falha duas vezes e então retorna `7` deveria concluir com `7` depois de `3` chamadas

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` de uma tarefa que sempre falha deveria chamá-la exatamente `attempts` vezes e então falhar com o mesmo erro

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
