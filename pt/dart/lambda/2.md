# --description--

Uma função anônima pode receber parâmetros e `return` um valor, exatamente como uma função nomeada. O tipo de retorno não é escrito: o Dart o **infere** a partir das instruções `return` no corpo.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
