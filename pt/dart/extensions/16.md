# --instructions--

Escreva uma extension chamada `Words` em `String` com:
- um getter `wordCount` do tipo `int`, o número de palavras na string, onde as palavras são separadas por um único espaço
- um getter `initials` do tipo `String`, formado pelo primeiro caractere de cada palavra em maiúsculas, unido sem separadores

A string sempre contém pelo menos uma palavra e nunca tem espaços no início, no fim ou duplos.

Exemplo:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
