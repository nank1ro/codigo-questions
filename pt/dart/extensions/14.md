# --instructions--

A classe `Temperature` é dada. Escreva uma extension chamada `Conversions` em `Temperature` com:
- um getter `fahrenheit` do tipo `double`, igual a `celsius * 9 / 5 + 32`
- um método `isAbove` que recebe um parâmetro `double` `limit` e retorna `true` quando `celsius` é maior que `limit`

Exemplo:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

```dart
extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
```
