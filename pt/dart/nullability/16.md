# --description--

Dados reais são cheios de lacunas: um campo de formulário deixado vazio, uma coluna ausente em um arquivo, uma string que não é bem um número. As ferramentas deste capítulo se combinam naturalmente para lidar com isso: `nonNulls` para descartar elementos ausentes, `int.tryParse` para converter com segurança, `??` ou uma verificação com `if` para tratar o que não pôde ser convertido.

# --instructions--

Escreva uma função `total` que recebe um parâmetro `List<String?>` chamado `prices` e retorna a soma dos valores que podem ser convertidos em `int`, ignorando tanto as entradas `null` quanto as strings que não são inteiros válidos.

Exemplo:
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
