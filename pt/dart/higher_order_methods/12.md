# --description--

`fold` e `reduce` se parecem, e escolher entre os dois se resume a duas perguntas: a coleção pode estar vazia, e o resultado tem o mesmo tipo dos elementos?

```dart
final words = ['fig', 'kiwi'];
final joined = words.reduce((a, b) => '$a, $b'); // String a partir de Strings
final letters = words.fold(0, (acc, w) => acc + w.length); // int a partir de Strings
print(joined);  // fig, kiwi
print(letters); // 7
```

`reduce` só consegue devolver o tipo dos elementos, porque começa a partir de um elemento. `fold` começa a partir de um valor que você escolhe, então o acumulador pode ser um `int` contando, uma `String` crescendo, ou até uma `List` sendo construída. E como esse valor inicial já existe, para uma coleção vazia ele é simplesmente a resposta que `fold` devolve sem mudanças, enquanto `reduce` não tem nada para retornar e lança um erro.

# --instructions--

Qual é a diferença entre `fold` e `reduce`?

# --answers--

- `fold` recebe um valor inicial, então funciona em uma coleção vazia e seu resultado pode ter um tipo diferente do dos elementos; `reduce` começa a partir do primeiro elemento e lança um erro em uma coleção vazia
- São dois nomes para o mesmo método
- `reduce` recebe um valor inicial, enquanto `fold` começa a partir do primeiro elemento
- `fold` retorna uma nova lista, enquanto `reduce` retorna um único valor
