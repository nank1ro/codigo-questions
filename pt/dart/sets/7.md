# --description--

Um conjunto é um `Iterable`, então você pode percorrer seus elementos diretamente com `for-in`, assim como uma lista. Não há índices: os elementos são visitados na ordem de inserção:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
