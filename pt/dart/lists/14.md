# --description--

A propriedade `.isEmpty` é `true` quando uma lista não tem elementos, e `.isNotEmpty` é `true` quando ela tem pelo menos um.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
