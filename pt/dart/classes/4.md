# --description--

O parâmetro `this.x` que você viu no exercício anterior é uma abreviação. A forma longa atribui cada parâmetro ao seu campo dentro do corpo do construtor (`this.x` é o campo, `x` é o parâmetro):

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

A mesma classe pode ser escrita como:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

Essa forma mais curta é chamada de **parâmetros de inicialização** (initializing formals).

# --instructions--

Qual das opções a seguir usa corretamente a abreviação de parâmetros de inicialização?

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`

# --solutions--
