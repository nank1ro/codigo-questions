# --description--

Um **construtor factory** usa a palavra-chave `factory` e permite controlar a criação de objetos — por exemplo, retornando uma instância em cache ou um subtipo:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

Cada chamada a `Logger()` retorna a mesma instância (padrão singleton).

# --instructions--

Crie uma classe `Counter` com um campo privado `_count` inicializado como `0`. Adicione um método de instância `increment()` que aumenta `_count` em `1`, e um getter `count` que retorna `_count`. Use um construtor `factory` `Counter.start()` que sempre retorna um novo `Counter` inicializado com `_count = 0` (usando um construtor nomeado privado `Counter._internal()`).

class Counter {
  int _count = 0;

  Counter._internal();

  factory Counter.start() => Counter._internal();

  void increment() {
    _count++;
  }

  int get count => _count;
}
