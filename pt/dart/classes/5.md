# --description--

Um **método** é uma função definida dentro de uma classe. Métodos descrevem o comportamento de um objeto:

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() {
    print('$name makes a sound.');
  }
}
```

Você chama um método em um objeto usando a notação de ponto: `dog.speak()`.
