# --description--

Você não está limitado às classes genéricas que o Dart traz: você pode declarar as suas. Um **parâmetro de tipo** vai entre colchetes angulares depois do nome da classe, e a partir daí é um tipo normal dentro do corpo:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` é apenas um marcador de posição. Ele é preenchido quando uma `Box` é criada, explicitamente ou por inferência:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, inferido a partir do argumento
print(a.value + 1);      // 8, o compilador sabe que value é um int
```

A letra não importa: `T` é uma convenção para "tipo", nada mais.

# --instructions--

Declare uma classe genérica `Box` com um parâmetro de tipo `T`, um campo `final` `value` do tipo `T` definido pelo construtor, e um getter `label` que retorna o texto `Box of ` seguido do valor.

Exemplo:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)` deve ter `value` `7` e `label` `'Box of 7'`

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` deve funcionar com qualquer tipo, então `Box<String>('fig')` também deve ser uma `Box<String>`

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

O argumento de tipo deve ser inferido a partir do argumento do construtor

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
