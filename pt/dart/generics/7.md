# --description--

Uma classe pode declarar mais de um parâmetro de tipo, separados por vírgulas. `Map<K, V>` é o exemplo embutido: um tipo para as chaves, um para os valores.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

A **ordem** faz parte do tipo: `Entry<String, int>` e `Entry<int, String>` são tipos não relacionados, e um valor de um não pode ser atribuído ao outro. Parâmetros de tipo também podem ser reordenados em um tipo de retorno, que é como um método pode devolver uma versão invertida do objeto:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

Declare uma classe genérica `Pair` com dois parâmetros de tipo `A` e `B`, um campo `final` `first` do tipo `A` e um campo `final` `second` do tipo `B`, ambos definidos pelo construtor, e um getter `swapped` que retorna um `Pair<B, A>` contendo os mesmos dois valores na ordem oposta.

Exemplo:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

# --asserts--

`Pair<String, int>('age', 30)` deve ter `first` `'age'` e `second` `30`

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` deve retornar um `Pair<int, String>` com os valores trocados

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` deve funcionar com quaisquer dois tipos, e trocar duas vezes deve devolver os valores originais

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
```

```dart
class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
