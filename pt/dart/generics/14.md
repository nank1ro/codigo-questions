# --description--

Uma classe genérica pode ter construtores nomeados e **factory** como qualquer outra classe, e o parâmetro de tipo está disponível dentro deles. Um construtor factory não cria o objeto em si: ele executa um corpo e retorna um, o que lhe permite escolher, reutilizar ou construir a instância da maneira que quiser.

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

O argumento de tipo vai na classe, não no nome do construtor: `Box<int>.first(...)`. Dentro da factory, `<T>[]` é uma `List<T>` vazia de verdade, então uma factory é o lugar natural para construir um valor padrão para um tipo que você ainda não conhece.

# --instructions--

Declare uma classe genérica `Stack` com um parâmetro de tipo `T`, um campo `final` `items` do tipo `List<T>` definido pelo construtor normal, um construtor **factory** `Stack.empty()` que constrói uma `Stack` com uma lista vazia, e um getter `top` do tipo `T?` que retorna o último elemento, ou `null` quando a pilha está vazia.

Exemplo:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

`Stack<int>([1, 2, 3]).top` deve ser `3`

```dart
  test('test1', () {
    final stack = Stack<int>([1, 2, 3]);
    expect(stack.top, 3, reason: '--err-t1--');
    expect(stack.items, [1, 2, 3], reason: '--err-t1--');
  });
```

`Stack.empty()` deve construir uma pilha vazia do tipo certo, cujo `top` é `null`

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
    expect(stack, isA<Stack<String>>(), reason: '--err-t2--');
    expect(stack.items, <String>[], reason: '--err-t2--');
    expect(stack.top, null, reason: '--err-t2--');
  });
```

A lista construída por `Stack.empty()` ainda deve ser utilizável

```dart
  test('test3', () {
    final stack = Stack<int>.empty();
    stack.items.add(4);
    stack.items.add(9);
    expect(stack.top, 9, reason: '--err-t3--');
    expect(Stack<bool>([true]).top, true, reason: '--err-t3--');
  });
```

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
