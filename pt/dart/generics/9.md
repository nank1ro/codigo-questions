# --description--

A diferença importa assim que você usa o valor. Em uma `Box<int?>` você acessa o campo normalmente e depois lida com o `null` dentro dele, enquanto em uma `Box<int>?` você precisa primeiro passar pela caixa ausente:

```dart
Box<int?> a = Box(null);
print(a.value ?? 0); // 0, a caixa existe, seu conteúdo é null

Box<int>? b = null;
print(b?.value ?? 0); // 0, a própria caixa está ausente
```

Escrever `b.value` em uma `Box<int>?` não compila de forma alguma: o Dart se recusa a ler um campo de algo que pode não existir.

# --instructions--

Dado `Box<int?> a = Box(null);` e `Box<int>? b = null;`, qual afirmação é verdadeira?

# --answers--

- `a` é uma caixa real cujo `value` é `null`, enquanto `b` não é uma caixa de forma alguma
- Ambas as declarações significam a mesma coisa, o `?` pode ser escrito de qualquer lado
- `a` não compila, porque um argumento de tipo nunca pode ser nullable
- `b` é uma caixa contendo `null`, enquanto `a` não é uma caixa de forma alguma
