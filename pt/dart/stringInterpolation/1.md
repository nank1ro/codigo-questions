# --description--

Uma _interpolação_ de String é uma forma programática de gerar uma String.
Em Dart, podemos usar o sinal `+` (concatenação) para exibir duas ou mais strings juntas, como:
```dart
print("Hello " + "Dart!");
// imprime "Hello Dart!"
```
