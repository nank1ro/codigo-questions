# --description--

Um padrão pode conter vários grupos. Eles são numerados da esquerda para a direita pelo parêntese de abertura, então o segundo é `m.2`, o terceiro `m.3`, e assim por diante:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` continua sendo sempre a correspondência inteira, não importa o número de grupos.

# --instructions--

Escreva uma função `setting` que recebe um texto (`String`) sem rótulo de argumento, encontra uma configuração escrita como letras minúsculas, um sinal de `=` e dígitos, e retorna o nome e o valor unidos por dois-pontos, ou `"none"` quando o texto não contém tal configuração

Exemplo de chamada da função:
```swift
print(setting("size=10"))
// imprime size:10
```

# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
