# --instructions--

O que há de errado com este código?
```swift
print("\(10} friends")
```

# --answers--

- A interpolação de string deveria estar dentro de \()
- O valor dentro de \() não é um número
- A string está sem as aspas " "
- O valor dentro de \() deve ser um nome de variável
