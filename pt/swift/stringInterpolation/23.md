# --instructions--

O que há de errado com este código?
```swift
let pieces = 5
let label = "we have \(pieces) pieces"
```

# --answers--

- Não podemos salvar interpolações de string em variáveis
- Os caracteres \() estão faltando
- Não podemos usar variáveis dentro de \()
- Nada está errado com o código
