# --description--

Como `%` inicia um especificador, um sinal de porcentagem literal deve ser escrito como `%%`. É assim que você formata uma porcentagem:
```swift
let ratio = 0.4567
print(String(format: "%.1f%%", ratio * 100)) // 45.7%
```
Multiplique a razão por `100` primeiro, depois escolha a precisão: `%.0f%%` para `46%`, `%.1f%%` para `45.7%`.

# --instructions--

Escreva uma função `percent` que recebe uma parte e um total (ambos `Double`, sem rótulos de argumento) e retorna a parte como uma porcentagem do total com uma casa decimal, seguida de `%`

Exemplo de chamada da função:
```swift
print(percent(9, 20))
// prints 45.0%
```
