# --description--

As flags de largura funcionam apenas dentro de `String(format:)`. Para preencher você mesmo uma string comum, construa os espaços com `String(repeating:count:)` e junte-os ao texto:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
Se o texto já for mais longo que a largura, `4 - text.count` fica negativo e `String(repeating:count:)` trava. Proteja com `max(0, ...)`, para que a contagem nunca fique abaixo de zero e o texto longo permaneça como está.

# --instructions--

Escreva uma função `leftPad` que recebe um texto (`String`) e uma largura (`Int`), ambos sem rótulos de argumento, e retorna o texto alinhado à direita nessa largura adicionando espaços à esquerda. Texto mais longo que a largura deve ser retornado sem alterações

Exemplo de chamada da função:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
