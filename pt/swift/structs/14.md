# --instructions--

Por que este código falha ao compilar?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` é uma constante `let`, então um método mutating não pode ser chamado nela
- `increase` deve estar marcado como `static` para alterar `value`
- `value` deve ser declarado com `let`
- Uma struct não pode conter métodos
