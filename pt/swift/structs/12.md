# --instructions--

Ordene os itens para imprimir `EUR 12`, declarando a struct primeiro e a instância antes do `print`

# --answers--

```swift
struct Money {
    static let currency = "EUR"
    var amount: Int
}
```

```swift
let price = Money(amount: 12)
```

```swift
print("\(Money.currency) \(price.amount)")
```

struct Money {
