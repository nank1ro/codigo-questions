# --description--

Como uma struct é um valor, um método não tem permissão para alterar suas propriedades, a menos que você indique isso com a palavra-chave `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Um método `mutating` só pode ser chamado em uma instância armazenada em um `var`. Em uma instância `let` o valor está congelado, então `c.increase(by: 5)` não compilaria.

# --instructions--

Adicione a `Counter` um método `mutating` `increase` que recebe um `Int` com o rótulo de argumento `by` e o soma a `value`

Exemplo de uso:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

O método deve estar marcado como `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Aumentar `0` em `5` deve dar `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Aumentar `10` duas vezes deve somar os aumentos

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Aumentar em `0` não deve mudar nada

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Alterar uma cópia não deve mudar o original

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
