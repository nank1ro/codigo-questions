# --description--

Como uma string é uma coleção de caracteres, você pode iterar sobre ela com um laço `for`-`in`. Cada iteração fornece um `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
Um `Character` pode ser comparado com `==` a um literal de caractere, então contar quantas vezes um caractere aparece é apenas um laço e um contador.

# --instructions--

Escreva uma função `occurrences` que recebe um `Character` com o rótulo do argumento `of` e uma `String` com o rótulo do argumento `in`, e retorna quantas vezes o caractere aparece na string.

Example of function call:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
