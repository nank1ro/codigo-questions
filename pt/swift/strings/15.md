# --description--

Dividir por um espaço é a maneira mais simples de quebrar uma frase em palavras, e unir é como você reconstrói o texto a partir de um array.

# --instructions--

Escreva uma função `wordCount` que recebe uma `String` (omita o rótulo do argumento) e retorna quantas palavras separadas por espaço ela contém, e uma função `slug` que recebe um array de `String` (omita o rótulo do argumento) e retorna as palavras unidas por `-`

Exemplo de chamada da função:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
