# --description--

Ao encadear `??`, o Swift avalia da esquerda para a direita e para no primeiro valor que não é `nil`; o último padrão só é usado quando todos os opcionais anteriores são `nil`.

# --instructions--

O que este código imprime?
```swift
let a: Int? = nil
let b: Int? = 7
print(a ?? b ?? 0)
```

# --answers--

- 7
- 0
- nil
- Optional(7)
