# --description--

Conversões que podem falhar combinam naturalmente com `guard let`: converta, saia se o resultado for `nil`, e depois trabalhe com o valor comum.

# --instructions--

Complete a função para que ela converta o texto em `Int` e retorne o seu dobro, ou `nil` quando a conversão falhar.
Depois imprima os resultados, usando `0` como valor padrão

# --seed--

```swift
func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
```

```swift
func doubled(_ text: String) -> Int? {
    guard let number = Int(text) else { return nil }
    return number * 2
}
print(doubled("21") ?? 0)
print(doubled("x") ?? 0)
```
