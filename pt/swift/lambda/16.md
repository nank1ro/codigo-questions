# --description--

Closures podem ser armazenadas em arrays como qualquer outro valor. O tipo do elemento é o tipo de função:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
Percorrer um array assim e chamar cada closure em sequência constrói um pequeno **pipeline** de transformações.

# --instructions--

Escreva uma função `pipeline` que recebe um `Int` e um array de closures do tipo `(Int) -> Int` (omita os dois rótulos de argumento) e retorna o resultado de aplicar cada closure em ordem, cada uma ao resultado da anterior

Exemplo de chamada da função:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
