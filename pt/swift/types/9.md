# --description--

`Int(text)` tem sucesso apenas quando o texto inteiro é um número inteiro válido, com um sinal opcional:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Para texto decimal use `Double(text)`, que retorna um `Double?` da mesma forma: `Double("3.5")` é `Optional(3.5)`.

# --instructions--

Escreva uma função `sumOfNumbers` que recebe um array de `String` (omita o rótulo do argumento) e retorna a soma daquelas que são números inteiros válidos, ignorando as outras

Exemplo de chamada da função:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
