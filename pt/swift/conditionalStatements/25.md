# --instructions--

Como sabemos que `Hello World` sempre sera impresso?
```swift
var online = False;
if online {
    print("User is online")
}
print("Hello World")
```

# --answers--

- Porque não está dentro de um bloco de código
- Porque a instrução if não pode ter mais de uma linha
- Porque não há uma instrução else
- Porque não há uma instrução else if
