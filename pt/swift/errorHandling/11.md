# --description--

Quando uma função lança um erro, tudo depois do `throw` é pulado — incluindo a linha que deveria fechar o arquivo ou liberar o lock. O `defer` resolve isso: ele registra um bloco agora e o executa quando o escopo atual termina, de qualquer maneira que termine.
```swift
func load() throws {
    print("open")
    defer { print("close") }
    throw FileError.missing
}
```
A chamada imprime `open`, depois `close`, e só então o erro segue para quem chamou. Se a função tivesse retornado normalmente, `close` ainda seria impresso — esse é o ponto. Coloque a limpeza bem ao lado da configuração e pare de se preocupar com qual saída o código toma.

# --seed--

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```

# --asserts--

no caminho de sucesso o log deve ser `start`, `done`, `cleanup`

```swift
let _ok: [String] = steps(false)
tryCatch(_ok == ["start", "done", "cleanup"])
```

no caminho que lança erro o log deve ser `start`, `cleanup`, `caught`

```swift
let _bad: [String] = steps(true)
tryCatch(_bad == ["start", "cleanup", "caught"])
```

a limpeza deve executar nos dois caminhos

```swift
tryCatch(steps(false).contains("cleanup") && steps(true).contains("cleanup"))
```

a limpeza deve executar exatamente uma vez no caminho que lança erro

```swift
let _once: [String] = steps(true)
tryCatch(_once.filter { $0 == "cleanup" }.count == 1)
```

enum TaskError: Error {

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        defer { log.append("cleanup") }
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
