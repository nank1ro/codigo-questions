# --description--

Você já sabe que `+` junta duas strings (**concatenação**).
O operador `*` **repete** uma string um determinado número de vezes:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
A repetição é uma forma rápida de desenhar separadores e padrões simples.
