# --description--

A função embutida `len()` retorna o **comprimento** de uma string, ou seja, quantos caracteres ela contém.
Espaços e pontuação também contam como caracteres:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
