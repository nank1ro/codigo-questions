# --description--

O operador `in` verifica se uma string **contém** outra.
Ele retorna `True` ou `False`, então se encaixa naturalmente dentro de um `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` faz a verificação oposta.
