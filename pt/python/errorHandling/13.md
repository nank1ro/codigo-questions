# --description--

Um punhado de exceções embutidas cobre a maioria das falhas do dia a dia:

| Exceção | Levantada quando | Exemplo |
|---|---|---|
| `ValueError` | o tipo está certo, mas o valor é impossível | `int("abc")` |
| `TypeError` | o tipo em si está errado | `"x" + 1` |
| `ZeroDivisionError` | uma divisão ou módulo tem divisor zero | `1 / 0` |
| `KeyError` | um dicionário não tem tal chave | `{"a": 1}["b"]` |
| `IndexError` | o índice de uma sequência está fora do intervalo | `[1, 2][5]` |

Usar uma destas em vez de inventar um novo tipo mantém seus erros legíveis para qualquer pessoa que conheça Python.

# --instructions--

Escreva uma função `get_item(values, index)` que retorna `values[index]`, levanta um `ValueError` com a mensagem `"index must be positive"` quando `index` é negativo, e retorna `None` quando o índice está fora do intervalo

    def test_1(self):

`get_item([1, 2, 3], 9)` deve retornar `None`

```python
    def test_2(self):
        self.assertIsNone(get_item([1, 2, 3], 9), "--err-t2--")
```

`get_item([1, 2, 3], -1)` deve levantar um `ValueError` carregando a mensagem

```python
    def test_3(self):
        with self.assertRaises(ValueError, msg="--err-t3--") as ctx:
            get_item([1, 2, 3], -1)
        self.assertEqual(str(ctx.exception), "index must be positive", "--err-t3--")
```

# --solutions--

```python
def get_item(values, index):
    if index < 0:
        raise ValueError("index must be positive")
    try:
        return values[index]
    except IndexError:
        return None
```
