# --description--

Escolher o tipo mais estreito que cobre a falha que você espera é o que torna o tratamento de erros confiável. Uma função que lê texto deve se recuperar de texto inválido (`ValueError`), mas não deve esconder o fato de ter sido chamada com o tipo errado de argumento (`TypeError`) — esse erro pertence ao chamador, então deixe-o passar.

# --instructions--

Escreva uma função `parse_age(text)` que retorna `int(text)`, e retorna `-1` quando `text` não é um número inteiro válido. Capture apenas `ValueError`, para que `parse_age(None)` ainda levante `TypeError`

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`parse_age("30")` deve retornar `30`

```python
    def test_1(self):
        self.assertEqual(parse_age("30"), 30, "--err-t1--")
```

`parse_age("old")` deve retornar `-1`

```python
    def test_2(self):
        self.assertEqual(parse_age("old"), -1, "--err-t2--")
```

`parse_age(None)` ainda deve levantar `TypeError`

```python
    def test_3(self):
        with self.assertRaises(TypeError, msg="--err-t3--"):
            parse_age(None)
```

# --after-asserts--

```python
if __name__ == "__main__":
    unittest.main()
```

# --solutions--

```python
def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
```
