# --description--

Uma exceção que nenhum bloco `except` corresponde continua se propagando: para fora da linha, para fora da função que a executou, para fora do chamador dela, e assim por diante. Se nada a capturar antes do topo do programa, o Python imprime o traceback e o processo termina com um status de saída diferente de zero. As linhas após a instrução que falhou nunca rodam.

# --instructions--

O que acontece quando este código roda?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- Imprime `start`, depois um traceback que termina com `TypeError`, e nem `end` nem `after` são impressos, porque a exceção não capturada para o programa
- Imprime `start`, `end` e `after`, porque o Python pula apenas a linha que falha
- Imprime `start` e `after`, porque a exceção para `sizes` mas o programa continua
- Imprime `start` e `0`, porque `len(None)` é `0`
