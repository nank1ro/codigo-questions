# --description--

Às vezes um manipulador deve reagir a uma falha sem assumir a responsabilidade por ela: registrá-la, contá-la, fechar algo — e então deixar o chamador lidar com ela. Um `raise` sozinho dentro de um bloco `except` **relança** a exceção sendo tratada, com seu tipo, mensagem e traceback originais intactos:
```python
try:
    value = int(text)
except ValueError:
    print("could not read the value")
    raise
```
Escrever `raise ValueError(...)` em vez disso construiria uma nova exceção e descartaria o traceback original, que é exatamente a informação de que você precisa ao depurar.

```python
def load(text):
    try:
        return int(text)
    except ValueError:
        print(f"could not read {text}")
        raise
print(load("5"))
try:
    load("abc")
except ValueError:
    print("handled by the caller")
```
