# --description--

`except:` sem nenhum tipo depois dele é um **bare except**. Ele corresponde a tudo, incluindo exceções que não têm nada a ver com a operação que você estava protegendo, então a regra é simples: sempre nomeie os tipos dos quais você realmente pode se recuperar.

# --instructions--

Por que este código deve nomear um tipo de exceção específico em vez de usar um bare `except:`?
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- Porque o bare `except:` também captura falhas não relacionadas, como o `NameError` causado pelo `amout` escrito errado, então um bug real silenciosamente se torna `total = 0`
- Porque um bare `except:` é mais lento, pois o Python precisa comparar a exceção com toda classe embutida
- Porque um bare `except:` só funciona no nível do módulo e levanta um `SyntaxError` dentro de uma função
- Porque um bare `except:` não captura nada, então a exceção é levantada novamente assim que o bloco termina
