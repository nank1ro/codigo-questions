# --instructions--

Ordene os itens para definir o dicionário `users` e a função `can_login`, que usa `name in users` para proteger a busca, e depois exiba o resultado para Ada com a senha correta e para Grace, que não está registrada, produzindo a saída `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
