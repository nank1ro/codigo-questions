# --description--

Como `if value:` já aplica o valor de verdade, comparar com `== True` ou `== False` é desnecessário e pode até estar errado: `2 == True` é `False`, e ainda assim `2` é verdadeiro. Teste o próprio valor:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Escreva uma função `count_truthy(values)` que retorne quantos elementos da lista `values` são verdadeiros

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
