# --instructions--

O que este código exibe?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, porque `c` é outro nome para a mesma lista que `a`, então adicionar através de `c` muda `a` e a torna diferente de `b`
- `True True [1, 2]`, porque `c = a` copia a lista, então `a` fica inalterada
- `True False [1, 2, 3]`, porque `is` compara valores e `==` compara identidade
- `False False [1, 2, 3]`, porque `append` cria uma nova lista, então `c` não se refere mais a `a`
