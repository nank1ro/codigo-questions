# --instructions--

Escreva uma função `is_vowel(ch)` que retorne `True` quando `ch` for exatamente um caractere e esse caractere for uma vogal (`a`, `e`, `i`, `o`, `u`) em minúscula ou maiúscula, e `False` para qualquer outra string, incluindo a string vazia

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` e `is_vowel("E")` devem retornar `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` e `is_vowel("y")` devem retornar `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Strings que não são um único caractere devem retornar `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

# --solutions--

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
