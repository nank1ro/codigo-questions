# --description--

Uma linha que fica fora da indentação do `if` é executada não importa qual era a condição, já que ela nunca fez parte daquele bloco.

# --instructions--

Como sabemos que `Hello World` sempre sera impresso?
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- Por causa da sua indentação
- Porque a instrução if não pode ter mais de uma linha
- Porque não há uma instrução else
- Porque não há uma instrução elif
