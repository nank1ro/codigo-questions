# --description--

Apenas o `print` indentado logo depois do `if` pertence ao seu bloco; uma linha escrita com a mesma indentação do próprio `if` não pertence.

# --instructions--

Qual instrução print faz parte do bloco de código da instrução?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)
