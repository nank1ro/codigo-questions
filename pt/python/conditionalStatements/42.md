# --description--

O bloco de código de uma instrução `if` é o conjunto de linhas indentadas abaixo dela, separado do resto do programa por essa indentação.

# --instructions--

O que é o bloco de código de uma instrução if?

# --answers--

- Código que é executado se a condição for False
- Código que determina se um trecho de código deve ser executado
- Uma palavra-chave de comparação
