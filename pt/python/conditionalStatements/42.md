# --description--

O bloco de código de uma instrução `if` é o conjunto de linhas indentadas abaixo dela, separado do resto do programa por essa indentação.

# --instructions--

O que e o bloco de codigo de uma instrucao if?

# --answers--

- Codigo que e executado se a condicao for False
- Codigo que determina se um trecho de codigo deve ser executado
- Uma palavra-chave de comparacao
