# --description--

Uma função que retorna um número **ou** `None` deve dizer isso em sua assinatura. Uma **type hint** é uma anotação que documenta o tipo esperado: `name: str` para um parâmetro e `-> int` para o valor de retorno. O Python não impõe as type hints, mas editores e leitores dependem delas:
```python
def parse_age(text: str) -> int | None:
    if text.isdigit():
        return int(text)
    return None
```
`int | None` se lê "um `int` ou `None`". A grafia mais antiga `Optional[int]` do módulo `typing` significa exatamente a mesma coisa, e você ainda a encontrará em código existente.
Sempre que ver `| None` em uma assinatura, lembre-se de verificar o resultado antes de usá-lo.

O tipo de retorno deve ser anotado como `int | None`

```json
{
  "regex": "->\\s*(int\\s*\\|\\s*None|None\\s*\\|\\s*int|Optional\\[int\\])",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`parse_age("42")` deve retornar `42`

```python
    def test_1(self):
        self.assertEqual(parse_age("42"), 42, "--err-t1--")
        self.assertIsInstance(parse_age("42"), int, "--err-t1--")
```

`parse_age("abc")` deve retornar `None`

```python
    def test_2(self):
        self.assertIsNone(parse_age("abc"), "--err-t2--")
        self.assertIsNone(parse_age("4a"), "--err-t2--")
```

`parse_age("")` deve retornar `None`

```python
    def test_3(self):
        self.assertIsNone(parse_age(""), "--err-t3--")
```
