# --instructions--

Escreva uma função `get_path` que recebe um dicionário `data`, uma lista de `keys` e um `default` opcional (`None` se não fornecido); ela deve seguir as chaves um nível por vez e retornar o valor encontrado, ou `default` quando alguma chave está ausente, contém `None` ou quando um passo não é um dicionário; valores como `0` e `""` devem ser retornados como estão

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` deve retornar `"Rome"`

```python
    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")
        self.assertEqual(get_path(data, ["address"]), {"city": "Rome"}, "--err-t1--")
```

```python
    def test_2(self):
```

```python
    def test_3(self):

        self.assertEqual(get_path(data, ["stats", "note"], "none"), "", "--err-t3--")
```

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
