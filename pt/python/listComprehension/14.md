# --description--

A mesma ideia funciona para dicionários: uma **dict comprehension** usa chaves e uma expressão `key: value`:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
