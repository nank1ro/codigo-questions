# --description--

Dentro de uma comprehension você pode usar qualquer variável definida antes dela, por exemplo como o limite de um `range()`.

# --instructions--

Ordene os itens para imprimir os múltiplos de 7 abaixo de `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--

```python
limit = 20
multiples = [n for n in range(1, limit) if n % 7 == 0]
print(multiples)
```

# --output--

[7, 14]
