# --description--

As duas posições do `if` são fáceis de confundir, então mantenha-as separadas:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else antes do for: escolhe um valor, else obrigatório
positives = [n for n in nums if n > 0]      # if depois do for: filtra, else não permitido
```
Colocar um `else` depois do filtro `if` é um erro de sintaxe.

# --instructions--

Qual é o __problema__ com este trecho de código?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- O filtro `if` depois do `for` não pode ter um `else`: um `if-else` deve vir antes do `for`
- Uma list comprehension não pode conter uma condição
- `nums` contém um número negativo, o que não é permitido
- `else` deve ser substituído por `elif`
