# --description--

A condição de filtro pode ser qualquer expressão que resulte em um booleano, incluindo chamadas de função como `len()`:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
