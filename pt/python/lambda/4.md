# --description--

Como o corpo deve ser uma única expressão, uma lambda **não pode conter instruções**.
Nada de `return`, blocos `if`, loops ou atribuições:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Se você precisar de algo assim, escreva uma função `def` normal.

# --instructions--

Qual é o __problema__ com este trecho de código?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- O corpo de uma lambda é uma expressão, não pode conter return
- Uma lambda não pode ser armazenada em uma variável
- Uma lambda não pode ser chamada com parênteses
- Uma lambda precisa de pelo menos dois parâmetros
