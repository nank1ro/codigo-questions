# --description--

`map()` aplica uma função a **todos os itens** de uma lista.
Ela retorna um _objeto map_ especial, então envolva-o em `list()` para ver os valores:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
