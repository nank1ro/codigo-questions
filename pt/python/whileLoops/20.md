# --instructions--

Como sabemos que o laço `while` pula seu bloco de código?
```python
is_loading = False

while is_loading:
    print("Loading...")
```

# --answers--

- A variável na condição é comparada com True
- A variável na condição é comparada com False

# --solutions--

- A variável na condição é comparada com True
