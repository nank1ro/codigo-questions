# --instructions--

O que acontece quando a condição do laço `while` permanece `True`?

# --answers--

- O laço se repete para sempre
- O laço executa seu bloco de código uma vez
- O laço executa seu bloco de código duas vezes
- O laço executa seu bloco de código três vezes
