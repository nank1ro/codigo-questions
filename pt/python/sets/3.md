# --description--

Existe uma armadilha ao criar um **conjunto vazio**.
Chaves também são a sintaxe de dicionários, então `{}` cria um **dicionário** vazio, não um conjunto:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Para obter um conjunto vazio, você deve chamar `set()` sem argumentos:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

O que este código imprime?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, porque `{}` cria um dicionário vazio
- `<class 'set'>`, porque chaves criam um conjunto
- `<class 'NoneType'>`, porque o conjunto não tem elementos
- Um `SyntaxError`, porque as chaves devem conter pelo menos um elemento
