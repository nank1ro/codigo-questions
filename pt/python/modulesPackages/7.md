# --instructions--

Pacotes são nada mais do que pastas que contêm um arquivo `__init__.py`.
O que pode acontecer se esquecermos de adicionar esse arquivo?

# --answers--

- O Python não reconhecerá a pasta como um pacote
- Ainda podemos importar pacotes, mas não subpacotes
- Ainda podemos importar funções
