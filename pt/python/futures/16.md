# --description--

As peças se combinam naturalmente. Para rodar muitas operações concorrentemente, cada uma com o seu próprio limite de tempo, envolva cada uma numa pequena corrotina que aplica `wait_for` e captura o `TimeoutError`, e então faça `gather` dos invólucros:
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])` então retorna um valor para cada job que terminou a tempo e `None` para cada um que não terminou, na ordem original, e o lote inteiro leva cerca de `limit` segundos no máximo.

Escreva uma função corrotina `job(delay)` que espere `delay` segundos e retorne `delay`, e uma função corrotina `run_jobs(delays, limit)` que rode um `job` para cada delay **concorrentemente**, cada um limitado a `limit` segundos com `asyncio.wait_for`, e retorne uma lista com o delay de cada job que terminou a tempo e `None` para cada job que estourou o timeout, na ordem original

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
