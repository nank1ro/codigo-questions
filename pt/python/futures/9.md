# --description--

Um pequeno programa assíncrono segue uma forma fixa: importe `asyncio`, defina as funções corrotinas, defina uma corrotina `main` que as aguarde e, por fim, chame `asyncio.run(main())` uma vez no final.

# --instructions--

Ordene os itens para construir um programa que comece com o import, defina `download` antes de `main`, rode dois downloads concorrentemente com `asyncio.gather` e exiba os resultados, produzindo a saída `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```
