# --description--

Quando cada caso de um `switch` trata uma constante, lembre-se do `break` depois de cada um, caso contrário a execução cai para o próximo caso.
Um caso `default` não é necessário se você cobrir todas as constantes da enumeração.

# --instructions--

Ordene as linhas para declarar `enum Size`, armazenar `MEDIUM` em `size` e imprimir `Medium` com um `switch`. Mantenha os casos na mesma ordem das constantes na declaração

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```

```c
switch (size) {
```

```c
    case SMALL: printf("Small\n"); break;
```

```c
    case MEDIUM: printf("Medium\n"); break;
```

```c
    case LARGE: printf("Large\n"); break;
```

```c
}
```

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
