# --description--

Um array não pode receber uma atribuição com `=` após sua declaração:
```c
char copy[20];
copy = "Codigo"; // error
```
Para copiar uma string, use `strcpy(destination, source)` de `string.h`.
O destino deve ser grande o suficiente para conter todos os caracteres mais o `'\0'`.

# --instructions--

Ordene as linhas para copiar `source` em `copy` e exibi-lo. Declare `source` antes de `copy`

# --answers--

```c
char source[] = "Codigo";
```

```c
char copy[20];
```

```c
strcpy(copy, source);
```

```c
printf("%s\n", copy);
```
