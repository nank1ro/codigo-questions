# --description--

Como uma string é um array, cada caractere tem um índice começando em `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Um único caractere é exibido com `%c`. Os caracteres também podem ser substituídos:
```c
word[0] = 'K'; // word is now "Koding"
```
