# --description--

`strcat(destination, source)` anexa `source` ao final de `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
Assim como em `strcpy`, o array de destino deve ter espaço suficiente para o resultado.
