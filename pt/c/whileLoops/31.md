# --instructions--

O que `counter += 1` faz?
```c
int counter = 1;

while (counter < 5) {
    printf("%d\n", counter);
    counter += 1;
}
```

# --answers--

- Aumenta counter em um cada vez que o laço executa seu bloco de código
- Cria a variável counter
- Aumenta counter em dois a cada vez
- Aumenta counter em três a cada vez
