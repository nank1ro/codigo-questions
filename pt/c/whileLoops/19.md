# --instructions--

Como sabemos que este e um laco infinito?
```c
bool is_logged = false;

while (true) {
    printf("Please login\n");
}
```

# --answers--

- Este laço não será executado pois a condição é false
- Não há variável na condição
- Este laço será executado uma vez
- Este laço será executado duas vezes
