# --instructions--

O que há de errado com este código?
```c
while (is_loading) {
    printf("Loading...\n");
    is_loading = false;
}
```

# --answers--

- is_loading não é um nome de variável válido
- O laço while tem uma instrução print dentro do bloco de código
- O bloco de código não tem a indentação correta
