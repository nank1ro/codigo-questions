# --description--

O operador **XOR** `^` (ou exclusivo) mantém um `1` apenas onde os dois bits são *diferentes*:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
Uma propriedade útil decorre disso: aplicar o mesmo XOR duas vezes devolve o valor original.
