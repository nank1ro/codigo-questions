# --description--

Letras maiúsculas e minúsculas estão `32` posições distantes na tabela ASCII: `'A'` é `65` e `'a'` é `97`.
Subtrair `32` de uma letra minúscula, portanto, dá sua versão maiúscula, e o resultado pode ser armazenado de volta em um `char`:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Ordene as linhas para armazenar a letra `'a'` em `letter`, calcular sua versão maiúscula em `upper`, e imprimir cada uma delas como um caractere seguido de seu código (`letter` primeiro)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
