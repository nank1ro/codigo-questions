# --description--

Quando `online` guarda `false`, a condição é falsa, então o bloco é completamente ignorado e nada dentro daquelas chaves é impresso.

# --instructions--

O que este código exibe na saída?
```c
bool online = false;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- Nada, o código é ignorado

# --solutions--
