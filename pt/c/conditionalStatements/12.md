# --description--

Uma condição literal `true` é sempre verdadeira, então o bloco é executado e o `printf` dentro dele roda exatamente como está escrito.

# --instructions--

O que este código exibe na saída?
```c
if (true) {
    printf("Hello!\n");
}
```

# --answers--

- Hello!
- Nada porque o bloco de código é ignorado
