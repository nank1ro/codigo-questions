# --description--

Ler uma variável booleana como condição funciona exatamente como um literal: como `online` guarda `true`, o bloco é executado e o `printf` dentro dele roda.

# --instructions--

O que este código exibe na saída?
```c
bool online = true;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- Nada, o código é ignorado
