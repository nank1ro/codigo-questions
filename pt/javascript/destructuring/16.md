# --description--

Tudo o que foi visto até agora pertence a uma única sintaxe, então as peças se combinam livremente: um padrão de objeto pode aninhar outro padrão de objeto, que pode conter uma chave renomeada com um valor padrão, ao lado de um padrão de array terminando em um elemento rest. Uma linha então descreve toda a forma que uma função espera:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// prints Post [js] +2
```
Mantenha legível: um padrão que não cabe mais em um par de linhas é geralmente um sinal de que a função está pedindo demais.

# --asserts--

Três itens devem deixar dois para trás.

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

Um único item deve deixar nenhum para trás.

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

Um cliente sem nome deve se tornar `guest`.

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

Um nome explicitamente `undefined` também deve se tornar `guest`.

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

Quatro itens devem deixar três para trás.

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

```javascript
function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
```
