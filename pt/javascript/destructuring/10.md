# --description--

Quando uma chave contém outro objeto ou um array, o padrão pode simplesmente continuar e descrever essa forma também:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// imprime London
```
Cuidado com o que essa linha cria: `address: { city }` significa "entre em `address`", não "me dê `address`", então apenas `city` se torna uma variável. Para obter ambos, mencione a chave duas vezes: `const { address, address: { city } } = user;`. Padrões de array e de objeto se aninham livremente entre si, como em `{ tags: [first] }`.

# --asserts--

Uma cidade aninhada deve ser retornada.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Uma cidade aninhada diferente deve ser retornada.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Um endereço vazio deve dar `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

As outras chaves do endereço devem ser ignoradas.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Uma cidade explicitamente `undefined` deve dar `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
