# --description--

Padrões de objeto e valores padrão se combinam exatamente como os de array, o que os torna uma forma organizada de ler um objeto de configuração cujas chaves podem ou não estar lá:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// prints dark en
```
Como o padrão inteiro é uma única instrução, uma função pode desempacotar tudo o que precisa do seu argumento já na sua primeira linha.

# --asserts--

Ambas as chaves presentes devem ser usadas.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Um usuário diferente deve dar uma string diferente.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

Uma `city` ausente deve recorrer a `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Chaves extras devem ser ignoradas.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

A ordem das chaves não deve importar.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
