# --description--

Os métodos também podem ser privados. Coloque `#` na frente do nome e o método desaparece da superfície pública da classe, continuando chamável a partir de qualquer outro método com `this.#name(...)`:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// prints $7
```
É assim que você mantém os passos auxiliares fora da API: quem chama vê `print`, não o detalhe de formatação por trás dele. Campos privados e métodos privados, juntos, dão a uma classe um dentro e um fora bem definidos.

# --asserts--

Uma nova pontuação deve começar em `0`.

```javascript
tryCatch(new Score().total === 0);
```

Valores positivos devem ser somados.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

Valores negativos devem ser ignorados.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

Zero deve ser ignorado.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

Os pontos devem ser privados, então a instância não deve ter propriedade pública alguma.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
