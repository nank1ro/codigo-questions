# --description--

O verdadeiro valor de um setter é que ele pode recusar. Entre a atribuição e o valor armazenado, você tem a chance de verificar, limitar ou rejeitar o que chega:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// imprime 3, o setter rejeitou 50
```
Um getter e um setter com o mesmo nome formam uma única propriedade, então eles não podem também ser um campo normal: o valor armazenado vive sob um nome diferente, por convenção o mesmo nome com um sublinhado na frente.

# --asserts--

O getter deve retornar o valor dado ao construtor.

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

O setter deve aceitar um valor válido.

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

O setter deve ignorar um valor negativo.

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

O setter deve aceitar `0`.

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

O valor deve ser armazenado em `_temperature`.

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```

class Thermostat {
  constructor(temperature) {
    this._temperature = temperature;
  }
  get temperature() {
    return this._temperature;
  }
  set temperature(value) {
    if (value >= 0) {
      this._temperature = value;
    }
  }
}
