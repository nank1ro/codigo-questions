# --description--

Tudo se junta em `groupBy(items, keyFn)`: uma função de ordem superior que recebe um callback que decide a **chave de grupo** de cada elemento e devolve um objeto que associa cada chave ao array dos elementos com essa chave. `reduce` com um acumulador objeto faz todo o trabalho:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Para cada elemento, calcula a chave, cria o array dessa chave se ainda não existir (`acc[key] ?? []`), adiciona o elemento e devolve o acumulador. Como é quem chama que escolhe `keyFn`, a mesma função agrupa palavras por inicial, pessoas por cidade ou números por paridade.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` deve devolver `{ h: ["hi", "hey"], y: ["yo"] }`.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

Agrupar `[1, 2, 3, 4]` por paridade deve devolver `{ odd: [1, 3], even: [2, 4] }`.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Agrupar pessoas por `city` deve manter os objetos inteiros, pela ordem original.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` deve devolver um objeto vazio.

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

O array original não deve ser modificado.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

A função deve usar `reduce`.


# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
