# --description--

Uma função que devolve uma função é também a forma natural de **adaptar** um callback. Supõe que tens um predicado e precisas do seu oposto para `filter`: em vez de o reescrever, envolve-o:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
Um `not(predicate)` genérico faria isto para qualquer predicado: devolve uma nova função que chama `predicate` com o mesmo argumento e inverte o resultado com `!`. Os predicados de `filter`, `find`, `some` e `every` recebem o elemento como primeiro argumento, por isso o wrapper só precisa de reencaminhar esse valor.

# --asserts--

`not((n) => n % 2 === 0)(3)` deve devolver `true`.

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)` deve devolver `false`.

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))` deve devolver `[1, 3]`.

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))` deve devolver `["a", "b"]`.

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

Negar duas vezes deve devolver a resposta original: `not(not(isEven))(4)` deve devolver `true`.

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not` deve devolver uma função.

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
