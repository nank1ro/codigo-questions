# --description--

As funções de ordem superior permitem separar *o que fazer com cada elemento* de *como percorrer os elementos*. A parte que percorre é escrita uma só vez, e o callback decide o resto:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
O callback recebe um elemento de cada vez. Pode ser uma arrow function escrita em linha, como acima, ou qualquer função guardada numa variável. É exatamente assim que funcionam por dentro os métodos de array que vais conhecer a seguir.

# --asserts--

`transform([1, 2, 3], (n) => n * 2)` deve devolver `[2, 4, 6]`.

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())` deve devolver `["A", "B"]`.

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)` deve devolver um array vazio.

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

O resultado deve ser um novo array e o original não deve ser modificado.

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

A função não deve usar `map`.

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

# --solutions--

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
