# --description--

As closures permitem que uma função devolvida mantenha **estado privado** entre chamadas. Um utilitário clássico construído assim é `once(fn)`: devolve uma função que executa `fn` apenas na primeira vez que é chamada, guarda o resultado e devolve esse mesmo resultado em todas as chamadas seguintes sem executar `fn` de novo:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
O wrapper precisa de duas variáveis privadas: se `fn` já foi executada, e o resultado guardado. Ambas vivem na closure, invisíveis para o exterior. Para reencaminhar para `fn` todos os argumentos do wrapper, declara o wrapper com um parâmetro rest `(...args)` e chama `fn(...args)`.

# --asserts--

A função envolvida deve executar `fn` uma só vez e continuar a devolver o seu resultado.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

Os argumentos da primeira chamada devem ser reencaminhados para `fn`: `once((a, b) => a + b)(2, 3)` deve devolver `5`.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

As chamadas seguintes devem devolver o resultado guardado mesmo com argumentos diferentes.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` não deve ser executada de novo mesmo quando o seu resultado é `undefined`.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

Dois wrappers da mesma função devem ser independentes.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` deve devolver uma função.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
