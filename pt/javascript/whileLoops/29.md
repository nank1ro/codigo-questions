# --instructions--

O que há de errado com este código?
```javascript
while (isLoading) {
    console.log("Loading...");
    isLoading = false;
}
```

# --answers--

- isLoading não é um nome de variável válido
- O laço while tem uma instrução de impressão dentro do bloco de código
- O bloco de código não tem a indentação correta
