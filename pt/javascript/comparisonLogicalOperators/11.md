# --description--

O `!=` converte antes de comparar, assim como o `==`, então `"5" != 5` é `false`. Seu equivalente estrito `!==` trata uma string e um número como diferentes, não importa o que contenham.
```javascript
console.log("5" !== 5); // true
```
