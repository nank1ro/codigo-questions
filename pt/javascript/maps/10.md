# --description--

Maps não têm métodos de array como `sort()` ou `filter()`. Para usá-los, converta o map (ou suas chaves ou valores) em um array com `Array.from()` ou o operador spread `...`:
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
A conversão inversa, `Object.fromEntries(ages)`, transforma um map de volta em um objeto comum.

# --asserts--

`sortedKeys` de um map com as chaves `"pear"`, `"apple"` e `"kiwi"` deve retornar `["apple", "kiwi", "pear"]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

`sortedKeys` de um map vazio deve retornar `[]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
