# --description--

Strings são **imutáveis**: uma vez criada, uma string nunca pode ser alterada.
Atribuir a um índice não faz nada, e todo método de string retorna uma **nova** string em vez de modificar a original:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
Para manter um resultado, atribua-o de volta à variável:
```javascript
word = word.toUpperCase();
```

# --instructions--

O primeiro `console.log` imprime `hello` porque `toUpperCase()` não alterou `word`. Complete o código para que o segundo `console.log` imprima `HELLO`
