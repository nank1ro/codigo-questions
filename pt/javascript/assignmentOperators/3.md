# --description--

Assim como na atribuição com adição, temos a **atribuição com subtração** `-=`.
O funcionamento é o mesmo, a única diferença é que ela realiza a subtração.
Portanto, as expressões a seguir são exatamente iguais
```javascript
var num = num - 5;
// é igual a
num -= 5;
```
