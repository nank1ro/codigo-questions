# --instructions--

Ordene as linhas para imprimir um array com os nomes em `all` que não estão em `done`.
Declare `all` antes de `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
