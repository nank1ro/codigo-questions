# --description--

A condição de uma instrução `if` sempre vai dentro de parênteses `()`, colocados logo depois da palavra-chave `if` e antes da chave de abertura.

# --instructions--

Onde escrevemos a condicao da instrucao if?

# --answers--

- Entre parenteses ()
- Entre colchetes []
- Entre a palavra-chave if e a chave de abertura {
- Antes da palavra-chave if
