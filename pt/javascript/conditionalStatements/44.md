# --description--

O bloco de código de uma instrução `if` é o conjunto de instruções dentro das chaves `{ }`, a parte que realmente é executada quando a condição é `true`.

# --instructions--

O que e o bloco de codigo de uma instrucao if?

# --answers--

- Codigo que executa se a condicao for false
- Codigo que determina se um trecho de codigo deve ser executado
- Uma palavra-chave de comparacao
