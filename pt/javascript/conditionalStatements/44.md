# --description--

O bloco de código de uma instrução `if` é o conjunto de instruções dentro das chaves `{ }`, a parte que realmente é executada quando a condição é `true`.

# --instructions--

O que é o bloco de código de uma instrução if?

# --answers--

- Código que executa se a condição for false
- Código que determina se um trecho de código deve ser executado
- Uma palavra-chave de comparação
