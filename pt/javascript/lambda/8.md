# --description--

Os parâmetros de arrow functions suportam os mesmos recursos que os parâmetros de funções regulares.
Um **valor padrão** é usado quando o argumento é omitido ou é `undefined`:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
Note que um parâmetro com um valor padrão sempre precisa dos parênteses, mesmo quando é o único: `name = "World" => ...` é um erro de sintaxe.

```javascript

```

`greet("Ana")` deve retornar `"Hello, Ana!"`.

```javascript

```

`greet(undefined)` também deve usar o valor padrão.

```javascript
tryCatch(greet(undefined) === "Hello, World!");
```

`greet` deve ser uma arrow function.

```javascript
tryCatch(typeof greet === "function" && !/function/.test(greet.toString()));
```
