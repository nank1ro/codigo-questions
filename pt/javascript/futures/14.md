# --description--

`Promise.all` desiste assim que uma promise é rejeitada. Quando você quer todos os resultados de qualquer forma, use **`Promise.allSettled(promises)`**: ela nunca é rejeitada e é cumprida com um pequeno objeto por promise, na mesma ordem:

- `{ status: "fulfilled", value: ... }` para as que tiveram sucesso;
- `{ status: "rejected", reason: ... }` para as que falharam.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
Leia `value` apenas quando `status` for `"fulfilled"`, e `reason` apenas quando for `"rejected"`: a outra propriedade simplesmente não existe.

```javascript

  tryCatch((await countFulfilled([])) === 0);

```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` deve ser `2`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Com uma promise rejeitada em três, a resposta deve ser `2`.

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Quando toda promise é rejeitada, a resposta deve ser `0`, e `countFulfilled` não deve ser rejeitada.

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
