"__Hello, World!__" é o tradicional primeiro programa para iniciar a programação em uma nova linguagem.
Usamos a função `println()` para exibir dados no dispositivo de saída padrão (tela).
Para imprimir `Hello, World!` na tela com Kotlin, podemos escrever
```kotlin
println("Hello, World!")
```

---

`println()` move o cursor para uma nova linha após exibir seu parâmetro, de modo que a saída subsequente apareça na próxima linha.
Você pode usar `print()` em vez disso, que deixa o cursor na mesma linha.
