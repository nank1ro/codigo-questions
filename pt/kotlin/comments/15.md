# --description--

Um `FIXME` é diferente de um `TODO`: o código já existe, mas se sabe que está errado. Um bom `FIXME` diz qual é o bug e, quando possível, dá um exemplo que o demonstra, para que a próxima pessoa possa corrigi-lo rapidamente. Assim como no `TODO`, apague o marcador assim que o bug for corrigido, mas mantenha o comentário de documentação, que continua verdadeiro.

# --asserts--

O comentário `FIXME` deve ser removido

```json
{
  "regex": "FIXME",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

O comentário de documentação deve ser mantido

```json
{
  "regex": "Returns the average of",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`average(4, 6)` deve retornar `5`

```kotlin
    tryCatch(average(4, 6) == 5)
```

`average(10, 20)` deve retornar `15`

```kotlin
    tryCatch(average(10, 20) == 15)
```

`average(3, 4)` deve retornar `3`

```kotlin
    tryCatch(average(3, 4) == 3)
```
