# --description--

`replace(old, new)` retorna uma cópia da string em que **toda** ocorrência de `old` é substituída por `new`:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
