# --description--

`uppercase()` retorna uma cópia da string com todas as letras em maiúsculas, `lowercase()` faz o oposto.
A string original não é modificada:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
