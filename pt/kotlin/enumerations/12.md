# --instructions--

Dado `enum class Size { SMALL, MEDIUM, LARGE }`, o que acontece com o código a seguir?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Não compila: uma expressão `when` sobre um enum deve cobrir todas as entradas ou adicionar um ramo `else`
- Compila e retorna `null` para `LARGE`
- Compila e lança uma exceção em tempo de execução para `LARGE`
- Compila e retorna `"L"` para `LARGE` automaticamente
