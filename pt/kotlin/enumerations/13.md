# --instructions--

Dado `enum class Color { RED, GREEN, BLUE }`, o que faz `Color.valueOf("PURPLE")`?

# --answers--

- Lança uma `IllegalArgumentException`, porque nenhuma entrada se chama `PURPLE`
- Retorna `null`
- Retorna `Color.RED`, a primeira entrada
- Adiciona uma nova entrada `PURPLE` ao enum
