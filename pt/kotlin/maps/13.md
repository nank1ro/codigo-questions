# --instructions--

Qual é a diferença entre `mapOf` e `mutableMapOf`?

# --answers--

- `mutableMapOf` cria um map cujas entradas podem ser adicionadas, atualizadas ou removidas após a criação, `mapOf` cria um map somente leitura
- `mapOf` só pode armazenar chaves do tipo `String`, `mutableMapOf` aceita qualquer tipo de chave
- `mutableMapOf` permite chaves duplicadas, `mapOf` não
- Não há diferença, são dois nomes para a mesma função
