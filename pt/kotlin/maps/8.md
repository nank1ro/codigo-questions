# --description--

Você pode percorrer um map com `for`, desestruturando cada entrada em sua chave e valor:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Os parênteses `(name, age)` dividem cada entrada em duas variáveis. As entradas são percorridas na ordem de inserção.

# --instructions--

Escreva uma função `report(stock: Map<String, Int>): List<String>` que retorna uma lista com uma string por entrada, formatada como `"item: count"`, na ordem em que as entradas aparecem no map.

Exemplo de chamada da função:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
