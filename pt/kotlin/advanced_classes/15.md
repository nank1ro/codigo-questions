# --instructions--

O que acontece com este código?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Não compila: uma classe aninhada não pode ver os membros externos, `Nested` deve ser `inner`
- Compila, e `show()` retorna o `name` da instância externa
- Compila, e `show()` sempre retorna uma string vazia
- Não compila: o Kotlin não permite uma classe dentro de outra classe
