# --description--

Os membros gerados olham apenas para as propriedades declaradas no **construtor primário**. Uma propriedade declarada no **corpo** da classe é uma propriedade normal: ela não faz parte de `toString()`, `equals()`, `hashCode()` ou `copy()`.

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

val a = Item("nail")
a.quantity = 5
println(a) // Item(name=nail)
```

Isso é fácil de esquecer, então coloque no construtor primário tudo o que identifica o objeto, e mantenha no corpo o estado derivado ou temporário.

# --instructions--

O que este programa imprime?

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

fun main() {
    val a = Item("nail")
    a.quantity = 5
    val b = Item("nail")
    b.quantity = 9
    println(a == b)
}
```

# --answers--

- `true`, porque o `equals()` gerado compara apenas `name`
- `false`, porque `quantity` é diferente
- `Item(name=nail, quantity=5)`
- Não compila: uma data class não pode declarar propriedades no seu corpo
