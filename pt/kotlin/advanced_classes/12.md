O que acontece com este programa?

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- Imprime `moving`, porque `Robot` herda a implementação padrão
- Não compila: `Robot` deve sobrescrever `move()`
- Não compila: uma interface não pode conter um corpo de função
- Imprime `null`
