# --description--

Uma lambda retornada pode capturar um `var` declarado dentro da função. Essa variável continua viva depois que a função retornou, e apenas a lambda pode alcançá-la: é um estado privado.
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
Cada chamada de `makeGreeter()` declara um novo `calls`, então dois greeters contam de forma independente.

# --instructions--

Escreva uma função `makeCounter(): () -> Int` que retorne uma lambda sem parâmetros. Cada chamada da lambda aumenta um contador que começa em `0` e retorna o novo valor. Contadores retornados por chamadas diferentes de `makeCounter` devem ser independentes.

Exemplo: `val next = makeCounter()`, depois `next()` retorna `1`, `next()` retorna `2`.

# --asserts--

A primeira chamada de um contador deve retornar `1`

```kotlin
    val first = makeCounter()
    tryCatch(first() == 1)
```

A segunda chamada do mesmo contador deve retornar `2`

```kotlin
    tryCatch(first() == 2)
```

Depois de três chamadas um contador deve retornar `3`

```kotlin
    val second = makeCounter()
    second()
    second()
    tryCatch(second() == 3)
```

Dois contadores devem ser independentes

```kotlin
    val a = makeCounter()
    val b = makeCounter()
    a()
    a()
    tryCatch(b() == 1)
```
