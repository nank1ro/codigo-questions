# --description--

Onde o `try` está posicionado decide quanto trabalho um único valor inválido destrói. Envolva o **loop inteiro** e a primeira falha abandona o restante do lote; envolva o **corpo** e apenas aquele elemento é perdido:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // pula este
    }
}
println(total) // 8
```
Isso combina naturalmente com uma função de validação que lança: a função declara uma regra e recusa qualquer coisa que a viole, e o loop decide que uma recusa custa apenas um elemento.

# --instructions--

Escreva duas funções.

`validate(text: String): Int` deve retornar o número contido em `text`, ou lançar uma `IllegalArgumentException` com a mensagem `not a number: ` seguida do texto.

`sumValid(values: List<String>): Int` deve somar os valores que `validate` aceita, pulando os que a fazem lançar.

Exemplo de chamada da função:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// imprime 4
```

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // pula este
        }
    }
    return total
}
```
