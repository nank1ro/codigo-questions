# --description--

세 번째 진입점인 `re.fullmatch`는 패턴이 첫 문자부터 마지막 문자까지 텍스트 **전체**를 덮을 때만 성공합니다. 검증에 알맞은 도구입니다:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

즉, 세 함수는 패턴이 위치할 수 있는 곳만 다릅니다: `re.match`는 텍스트의 시작, `re.search`는 텍스트 어디든, `re.fullmatch`는 텍스트 전체입니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```python
import re

print(bool(re.match(r"\d+", "12abc")), bool(re.search(r"\d+", "12abc")), bool(re.fullmatch(r"\d+", "12abc")))
```

- `True True False`, 숫자가 텍스트의 시작 부분과 안쪽에는 있지만 텍스트 전체를 덮지는 않기 때문입니다
- `True True True`, 패턴이 어딘가에서 발견되는 즉시 세 함수 모두 성공하기 때문입니다
- `False True False`, `re.match`는 패턴이 텍스트 전체를 덮어야 하기 때문입니다
- `True False False`, `re.search`는 첫 문자 뒤만 살피기 때문입니다
