# --instructions--

인수 하나짜리 함수를 위한 데코레이터 `memoize`를 작성하세요: 클로저 안의 딕셔너리에 각 결과를 저장해야 하며, 그래서 같은 인수로 데코레이트된 함수를 다시 호출하면 원래 함수를 호출하지 않고 저장된 결과를 반환합니다

# --asserts--

데코레이트된 함수는 원래 함수와 같은 결과를 반환해야 합니다

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

호출을 반복하면 원래 함수를 다시 실행해서는 안 됩니다

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

데코레이트된 각 함수는 자신만의 캐시를 가져야 합니다

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
