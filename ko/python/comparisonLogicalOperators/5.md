# --description--

`not`, `and`, `or`가 한 표현식에 함께 나오면 Python은 `not`을 먼저, 그다음 `and`, 마지막으로 `or`를 적용합니다. 그래서 `a or b and c`는 `a or (b and c)`를 뜻하고, `not a == b`는 `not (a == b)`를 뜻합니다:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
다른 묶음을 의도한다면 괄호를 추가하세요. 괄호는 표현식을 더 읽기 쉽게도 만들어 줍니다.

# --instructions--

이 코드는 무엇을 출력하나요?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, `and`가 `or`보다 먼저 적용되어 표현식이 `x == 3 or (x > 10 and x < 0)`로 읽히기 때문입니다
- `False`, 연산자가 왼쪽에서 오른쪽으로 적용되기 때문입니다: `(x == 3 or x > 10) and x < 0`
- `False`, `x < 0`이 거짓이고 표현식의 모든 조건이 성립해야 하기 때문입니다
- `SyntaxError`, `and`와 `or`는 괄호 없이 섞어 쓸 수 없기 때문입니다
