# --description--

`==`는 **값**을 비교하고 `is`는 **정체성**, 즉 두 이름이 완전히 같은 객체를 가리키는지를 비교합니다. 따로 만든 두 개의 같은 리스트는 `==`이지만 `is`는 아닙니다:
```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)  # True False True
```
`is`는 `None`, `True`, `False` 같은 싱글턴을 위한 것입니다. `value is None`이나 `value is not None`이라고 쓰고 `value == None`이라고는 절대 쓰지 마세요. 클래스가 `==`를 무엇이든 반환하도록 정의할 수 있기 때문입니다. 숫자나 문자열에 `is`를 쓰는 것은 신뢰할 수 없으며 Python이 경고합니다.

# --instructions--

`value`가 `None`일 때만 `True`를 반환하고 `0`, `""`, `[]` 같은 거짓 값을 포함한 다른 모든 값에 대해서는 `False`를 반환하는 함수 `is_missing(value)`를 작성하세요

# --asserts--

`is_missing(None)`은 `True`를 반환해야 합니다

```python
    def test_1(self):
        self.assertIs(is_missing(None), True, "--err-t1--")
```

거짓 값은 `None`이 아닙니다

```python
    def test_2(self):
        self.assertIs(is_missing(0), False, "--err-t2--")
        self.assertIs(is_missing(""), False, "--err-t2--")
        self.assertIs(is_missing([]), False, "--err-t2--")
        self.assertIs(is_missing(False), False, "--err-t2--")
```

`==`가 모든 것과 같다고 주장하는 객체라도 `None`은 아니므로 검사는 정체성을 사용해야 합니다

```python
    def test_3(self):
        class Anything:
            def __eq__(self, other):
                return True
        self.assertIs(is_missing(Anything()), False, "--err-t3--")
```
