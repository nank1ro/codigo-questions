# --description--

`if value:`가 이미 진리값을 적용하므로 `== True`나 `== False`와 비교하는 것은 불필요하며 틀릴 수도 있습니다. `2 == True`는 `False`이지만 `2`는 참입니다. 값 자체를 검사하세요:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
