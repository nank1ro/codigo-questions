# --instructions--

`ch`가 정확히 한 글자이고 그 글자가 소문자 또는 대문자 모음 (`a`, `e`, `i`, `o`, `u`) 일 때 `True`를 반환하고, 빈 문자열을 포함한 다른 모든 문자열에 대해 `False`를 반환하는 함수 `is_vowel(ch)`를 작성하세요

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")`와 `is_vowel("E")`는 `True`를 반환해야 합니다

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")`와 `is_vowel("y")`는 `False`를 반환해야 합니다

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

한 글자가 아닌 문자열은 `False`를 반환해야 합니다

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
