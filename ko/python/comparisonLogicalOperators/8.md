# --description--

`and`와 `or`가 항상 `True`나 `False`를 반환하는 것은 아닙니다. 이들은 **피연산자** 중 하나를 반환합니다. `a and b`는 `a`가 거짓이면 `a`를, 아니면 `b`를 반환합니다. `a or b`는 `a`가 참이면 `a`를, 아니면 `b`를 반환합니다:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
결과가 참인지 거짓인지는 표현식 전체와 정확히 일치하므로 `if a and b:`는 그대로 동작합니다. 흔한 사용법은 기본값입니다: `name = user_input or "guest"`.

# --instructions--

이 코드는 무엇을 출력하나요?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, `or`는 첫 번째 참인 피연산자를 `and`는 첫 번째 거짓인 피연산자를 반환하고, 그런 값이 없으면 마지막 피연산자를 반환하기 때문입니다
- `True False True`, 논리 연산자는 항상 불리언을 만들어 내기 때문입니다
- `0 3 x`, `and`와 `or`는 항상 첫 번째 피연산자를 반환하기 때문입니다
- `5 3 y`, 두 연산자 모두 참인 피연산자를 반환하기 때문입니다
