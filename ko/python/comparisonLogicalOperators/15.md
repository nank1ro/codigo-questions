# --instructions--

항목을 정렬해 `users` 딕셔너리와, 조회를 보호하기 위해 `name in users`를 사용하는 `can_login` 함수를 정의한 뒤, 올바른 비밀번호를 가진 Ada와 등록되지 않은 Grace에 대한 결과를 출력해 출력 `True`, `False`가 나오도록 하세요

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
