# --description--

`None`은 "여기에 아무것도 없음"을 뜻하는 그 자체로 하나의 값입니다. `return` 문이 없는 함수가 반환하는 값이며, 아직 알 수 없는 값을 위한 흔한 자리표시자이기도 합니다.
`None`은 하나뿐이므로 `==`가 아니라 `is`로 확인하세요:
```python
result = None
if result is None:
    print("no result yet")
```
모든 타입에는 이름을 문자열로 담은 `__name__` 속성이 있어 메시지를 만들 때 유용합니다:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```


`describe(None)`은 `"nothing"`을 반환해야 합니다

```python
    def test_1(self):
        self.assertEqual(describe(None), "nothing", "--err-t1--")
```

`describe(5)`는 `"int"`를, `describe(2.0)`은 `"float"`를 반환해야 합니다

```python
    def test_2(self):
        self.assertEqual(describe(5), "int", "--err-t2--")
        self.assertEqual(describe(2.0), "float", "--err-t2--")
```

`describe("a")`는 `"str"`을, `describe(True)`는 `"bool"`을 반환해야 합니다

```python
    def test_3(self):
        self.assertEqual(describe("a"), "str", "--err-t3--")
        self.assertEqual(describe(True), "bool", "--err-t3--")
```
