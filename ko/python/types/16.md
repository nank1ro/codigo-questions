# --description--

외부에서 들어오는 텍스트는 항상 `str`이며, 그것이 실제로 어떤 타입을 담고 있는지 알아내는 것은 프로그램의 몫입니다.
흔한 접근법은 **가장 엄격한** 변환을 먼저 시도하고, `ValueError`가 발생하면 그다음 변환으로 넘어가는 것입니다:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` 블록 안에 두 번째 `try`를 중첩하면 한 번 더 대안을 둘 수 있습니다. 예를 들어 텍스트를 그대로 유지할 수 있습니다.

def parse_value(text):
    try:
        return int(text)
    except ValueError:
        try:
            return float(text)
        except ValueError:
            return text
