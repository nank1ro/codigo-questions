# --description--

`float`를 출력하면 그 값을 정확히 나타내는 데 필요한 만큼의 자릿수가 표시되는데, 이는 종종 너무 많습니다:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
f-string 안에서는 콜론 뒤에 **포맷 지정**을 추가할 수 있습니다. `.2f`는 "소수점 이하 2자리의 고정소수점 수"를 뜻합니다:
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
값은 요청한 자릿수로 반올림되고, 필요하면 0이 채워집니다: `f"{2.5:.2f}"`는 `2.50`을 줍니다.
