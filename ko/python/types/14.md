# --description--

변수, 매개변수 또는 반환값의 예상 타입을 **타입 힌트**로 쓸 수 있습니다: 변수와 매개변수는 이름 뒤에 콜론을, 반환값은 콜론 앞에 화살표 `->`를 씁니다:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
힌트는 사람과 편집기 같은 도구를 위한 **문서**입니다: Python은 이를 검사하지 **않습니다**. 다음 코드는 아무 불평 없이 실행되어 `hello`를 출력합니다:
```python
count: int = "hello"
print(count)
```
힌트는 의도한 타입을 분명히 해주지만, 실제 타입은 여전히 값이 결정합니다.
