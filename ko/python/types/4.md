# --description--

산술 연산자는 이미 알고 있습니다. 여기서 중요한 것은 **결과의 타입**입니다.
`int`와 `float`를 조합하면, 소수 부분이 0이더라도 `float`가 됩니다:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**참 나눗셈** `/`는 나누어떨어질 때에도 항상 `float`를 반환합니다:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**몫 나눗셈** `//`는 결과를 가장 가까운 정수로 내림하며(그래서 `-7 // 2`는 `-4`입니다), 두 피연산자가 모두 정수이면 `int`를 반환합니다. 나머지 `%`와 함께 사용하면 어떤 양을 정수 단위로 나눌 수 있습니다:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```
