# --description--

`bool`은 `int`의 **하위 클래스**입니다: 숫자가 필요한 곳에서 `True`는 `1`처럼, `False`는 `0`처럼 동작합니다:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()`은 리스트의 항목을 더하므로, 불리언 리스트를 더하면 `True`가 몇 개인지 **셀** 수 있습니다:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
이 상속 관계 때문에 `isinstance(True, int)`는 `True`를 반환하지만, `type(True)`는 여전히 `bool`입니다.
