Python의 모든 값에는 그것이 어떤 종류의 데이터이고 무엇을 할 수 있는지 알려주는 **타입**이 있습니다.
기본 내장 타입은 다음과 같습니다:
- `int`, `42`나 `-3` 같은 정수
- `float`, `3.5` 같은 소수 부분이 있는 수
- `str`, `"hello"` 같은 텍스트
- `bool`, `True`와 `False` 두 값 중 하나
- `NoneType`, "값 없음"을 뜻하는 특별한 값 `None`의 타입

내장 함수 `type()`은 값의 타입을 반환합니다. 이를 출력하면 클래스 이름이 표시됩니다:
```python
print(type(42))     # <class 'int'>
print(type("hi"))   # <class 'str'>
```
`NoneType`을 직접 쓸 일은 없습니다: `type(None)`이 그것을 반환하지만, 그 이름은 다른 네 가지와 달리 내장 이름이 아닙니다.

---

`type()`은 값의 클래스를 반환하므로, `is`를 사용해 클래스 이름과 비교할 수 있습니다:
```python
age = 30
print(type(age) is int)  # True
```
하지만 대부분의 경우에는 값이 특정 타입**인지 아닌지**만 알면 됩니다. 그것이 `isinstance(value, cls)`의 역할이며, `True` 또는 `False`를 반환합니다:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
두 번째 인자는 클래스들의 **튜플**일 수도 있습니다: 값이 그중 하나에 속하면 결과는 `True`입니다:
```python
print(isinstance(2.5, (int, float)))  # True
```

---

Python은 **동적 타입** 언어입니다: 타입은 변수가 아니라 **값**에 속합니다.
변수는 값에 붙은 이름일 뿐이며, 언제든지 다른 타입의 값에 다시 붙일 수 있습니다:
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
선언도 변환도 필요 없습니다: 이전 값은 그냥 잊힙니다.
이는 편리하지만, 변수의 타입이 프로그램이 실행될 때에야 알려진다는 뜻이기도 합니다. 그래서 실수로 타입을 섞으면 실행 전이 아니라 실행 시점에 오류로 나타납니다.

---

산술 연산자는 이미 알고 있습니다. 여기서 중요한 것은 **결과의 타입**입니다.
`int`와 `float`를 조합하면, 소수 부분이 0이더라도 `float`가 됩니다:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**참 나눗셈** `/`는 나누어떨어질 때에도 항상 `float`를 반환합니다:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**몫 나눗셈** `//`는 결과를 가장 가까운 정수로 내림하며(그래서 `-7 // 2`는 `-4`입니다), 두 피연산자가 모두 정수이면 `int`를 반환합니다. 나머지 `%`와 함께 사용하면 어떤 양을 정수 단위로 나눌 수 있습니다:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```

---

값은 스스로 타입을 바꾸지 않습니다: 값을 다른 타입으로 바꾸려면 타입 이름을 함수처럼 호출합니다. 이를 **변환**(또는 *캐스팅*)이라고 합니다:
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()`와 `float()`는 텍스트로 쓰인 숫자를 읽습니다. 사용자 입력이나 파일에서 얻는 것이 바로 그런 형태입니다. `str()`은 무엇이든 텍스트로 바꾸므로, `+`로 다른 문자열과 이어붙일 수 있습니다.
`int(3.9)`는 반올림하지 않고 소수 부분을 버린다는 점에 유의하세요.

---

변환은 실패할 수 있습니다. `int("abc")`는 숫자를 만들 수 없으므로 `ValueError`를 발생시키고 프로그램이 멈춥니다:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
프로그램을 계속 실행하려면 `try` / `except`로 오류를 잡을 수 있습니다: `try` 블록의 코드가 실행되고, 지정한 오류가 발생하면 대신 `except` 블록이 실행됩니다:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
변환이 성공하면 `except` 블록은 건너뜁니다.

---

모든 값은 불리언으로 해석될 수 있습니다. `bool()`은 값을 `True` 또는 `False`로 변환하며, 값이 `if`에서 직접 사용될 때도 같은 규칙이 적용됩니다.
**거짓**으로 취급되는 값은 "비어 있는" 값들입니다:
- 숫자 `0` (그리고 `0.0`)
- 빈 문자열 `""`
- `[]`, `{}`, `()`, `set()` 같은 빈 컬렉션
- `None`

비어 있지 않은 값은 모두 **참**이며, 음수나 `"0"`, `" "`처럼 비어 보이기만 하는 문자열도 포함됩니다:
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
그래서 `if name:`은 문자열이 비어 있지 않은지 확인하는 흔한 방법입니다.

---

`bool`은 `int`의 **하위 클래스**입니다: 숫자가 필요한 곳에서 `True`는 `1`처럼, `False`는 `0`처럼 동작합니다:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()`은 리스트의 항목을 더하므로, 불리언 리스트를 더하면 `True`가 몇 개인지 **셀** 수 있습니다:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
이 상속 관계 때문에 `isinstance(True, int)`는 `True`를 반환하지만, `type(True)`는 여전히 `bool`입니다.

---

`None`은 "여기에 아무것도 없음"을 뜻하는 그 자체로 하나의 값입니다. `return` 문이 없는 함수가 반환하는 값이며, 아직 알 수 없는 값을 위한 흔한 자리표시자이기도 합니다.
`None`은 하나뿐이므로 `==`가 아니라 `is`로 확인하세요:
```python
result = None
if result is None:
    print("no result yet")
```
모든 타입에는 이름을 문자열로 담은 `__name__` 속성이 있어 메시지를 만들 때 유용합니다:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

---

`float`를 출력하면 그 값을 정확히 나타내는 데 필요한 만큼의 자릿수가 표시되는데, 이는 종종 너무 많습니다:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
f-string 안에서는 콜론 뒤에 **포맷 지정**을 추가할 수 있습니다. `.2f`는 "소수점 이하 2자리의 고정소수점 수"를 뜻합니다:
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
값은 요청한 자릿수로 반올림되고, 필요하면 0이 채워집니다: `f"{2.5:.2f}"`는 `2.50`을 줍니다.

---

포맷팅은 숫자가 표시되는 방식만 바꿉니다. 반올림된 **값**을 얻으려면 내장 함수 `round()`를 사용하세요:
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
인자가 하나면 `round()`는 가장 가까운 정수로 반올림하고 `int`를 반환합니다. 소수 자릿수를 함께 주면 `float`를 반환합니다:
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
두 수의 정확히 중간인 값은 **짝수** 쪽으로 반올림된다는 점에 유의하세요: `round(2.5)`는 `2`이고 `round(3.5)`는 `4`입니다.

---

`float`는 고정된 비트 수로 이진수로 저장되므로, 대부분의 십진수는 **근사값**으로만 표현될 수 있습니다. 오차는 아주 작지만 산술 연산에서 드러납니다:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
이 때문에 float를 정확한 동등성으로 비교해서는 안 됩니다. 양쪽을 반올림하거나, 두 수가 아주 작은 허용 오차 안에서 같은지 확인하는 `math.isclose()`를 사용하세요:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
정수에는 이런 문제가 없습니다: `1 + 2 == 3`은 항상 `True`입니다.

---

많은 언어와 달리 Python의 정수에는 **최대 크기가 없습니다**: `int`는 필요한 만큼 자릿수를 늘리므로 큰 계산도 정확하게 유지됩니다:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
반면 `float`는 유효 숫자를 약 15자리만 유지하므로, 같은 거듭제곱을 float로 하면 정밀도를 잃습니다:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
`str()`은 어떤 `int`에도 동작하므로, 숫자의 자릿수를 세는 빠른 방법은 그 텍스트의 길이를 재는 것입니다.

---

변수, 매개변수 또는 반환값의 예상 타입을 **타입 힌트**로 쓸 수 있습니다: 변수와 매개변수는 이름 뒤에 콜론을, 반환값은 콜론 앞에 화살표 `->`를 씁니다:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
힌트는 사람과 편집기 같은 도구를 위한 **문서**입니다: Python은 이를 검사하지 **않습니다**. 다음 코드는 아무 불평 없이 실행되어 `hello`를 출력합니다:
```python
count: int = "hello"
print(count)
```
힌트는 의도한 타입을 분명히 해주지만, 실제 타입은 여전히 값이 결정합니다.

---

변환은 조합할 수 있습니다. `int("3.7")`은 실패하지만 `float("3.7")`은 동작하며, `float`에 `int()`를 적용하면 소수 부분이 버려집니다:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()`은 참/거짓 규칙을 따릅니다: `bool("")`은 `False`이고, `bool("False")`는 비어 있지 않은 문자열이므로 `True`라는 점에 유의하세요.

---

외부에서 들어오는 텍스트는 항상 `str`이며, 그것이 실제로 어떤 타입을 담고 있는지 알아내는 것은 프로그램의 몫입니다.
흔한 접근법은 **가장 엄격한** 변환을 먼저 시도하고, `ValueError`가 발생하면 그다음 변환으로 넘어가는 것입니다:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` 블록 안에 두 번째 `try`를 중첩하면 한 번 더 대안을 둘 수 있습니다. 예를 들어 텍스트를 그대로 유지할 수 있습니다.
