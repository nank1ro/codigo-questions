# --description--

변환은 실패할 수 있습니다. `int("abc")`는 숫자를 만들 수 없으므로 `ValueError`를 발생시키고 프로그램이 멈춥니다:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
프로그램을 계속 실행하려면 `try` / `except`로 오류를 잡을 수 있습니다: `try` 블록의 코드가 실행되고, 지정한 오류가 발생하면 대신 `except` 블록이 실행됩니다:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
변환이 성공하면 `except` 블록은 건너뜁니다.

    except ValueError:
