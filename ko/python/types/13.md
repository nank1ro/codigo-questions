# --description--

많은 언어와 달리 Python의 정수에는 **최대 크기가 없습니다**: `int`는 필요한 만큼 자릿수를 늘리므로 큰 계산도 정확하게 유지됩니다:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
반면 `float`는 유효 숫자를 약 15자리만 유지하므로, 같은 거듭제곱을 float로 하면 정밀도를 잃습니다:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
`str()`은 어떤 `int`에도 동작하므로, 숫자의 자릿수를 세는 빠른 방법은 그 텍스트의 길이를 재는 것입니다.

# --instructions--

`2`의 `200`제곱 값을 `big`에 저장하고, 양의 `int`를 받아 자릿수가 몇 개인지 반환하는 함수 `digits`를 작성하세요
