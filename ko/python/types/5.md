# --description--

값은 스스로 타입을 바꾸지 않습니다: 값을 다른 타입으로 바꾸려면 타입 이름을 함수처럼 호출합니다. 이를 **변환**(또는 *캐스팅*)이라고 합니다:
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()`와 `float()`는 텍스트로 쓰인 숫자를 읽습니다. 사용자 입력이나 파일에서 얻는 것이 바로 그런 형태입니다. `str()`은 무엇이든 텍스트로 바꾸므로, `+`로 다른 문자열과 이어붙일 수 있습니다.
`int(3.9)`는 반올림하지 않고 소수 부분을 버린다는 점에 유의하세요.
