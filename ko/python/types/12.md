# --description--

`float`는 고정된 비트 수로 이진수로 저장되므로, 대부분의 십진수는 **근사값**으로만 표현될 수 있습니다. 오차는 아주 작지만 산술 연산에서 드러납니다:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
이 때문에 float를 정확한 동등성으로 비교해서는 안 됩니다. 양쪽을 반올림하거나, 두 수가 아주 작은 허용 오차 안에서 같은지 확인하는 `math.isclose()`를 사용하세요:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
정수에는 이런 문제가 없습니다: `1 + 2 == 3`은 항상 `True`입니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```python
print(0.1 + 0.2 == 0.3)
```

# --answers--

- `False`, `0.1 + 0.2`가 `0.3`보다 아주 조금 크기 때문입니다
- `True`, `0.1 + 0.2`가 `0.3`이기 때문입니다
- `0.3`, `print`가 덧셈의 결과를 보여주기 때문입니다
- `TypeError`, float는 `==`로 비교할 수 없기 때문입니다
