# --description--

포맷팅은 숫자가 표시되는 방식만 바꿉니다. 반올림된 **값**을 얻으려면 내장 함수 `round()`를 사용하세요:
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
인자가 하나면 `round()`는 가장 가까운 정수로 반올림하고 `int`를 반환합니다. 소수 자릿수를 함께 주면 `float`를 반환합니다:
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
두 수의 정확히 중간인 값은 **짝수** 쪽으로 반올림된다는 점에 유의하세요: `round(2.5)`는 `2`이고 `round(3.5)`는 `4`입니다.
