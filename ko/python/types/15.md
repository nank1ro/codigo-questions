# --description--

변환은 조합할 수 있습니다. `int("3.7")`은 실패하지만 `float("3.7")`은 동작하며, `float`에 `int()`를 적용하면 소수 부분이 버려집니다:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()`은 참/거짓 규칙을 따릅니다: `bool("")`은 `False`이고, `bool("False")`는 비어 있지 않은 문자열이므로 `True`라는 점에 유의하세요.
