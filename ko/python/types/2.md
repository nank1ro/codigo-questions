# --description--

`type()`은 값의 클래스를 반환하므로, `is`를 사용해 클래스 이름과 비교할 수 있습니다:
```python
age = 30
print(type(age) is int)  # True
```
하지만 대부분의 경우에는 값이 특정 타입**인지 아닌지**만 알면 됩니다. 그것이 `isinstance(value, cls)`의 역할이며, `True` 또는 `False`를 반환합니다:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
두 번째 인자는 클래스들의 **튜플**일 수도 있습니다: 값이 그중 하나에 속하면 결과는 `True`입니다:
```python
print(isinstance(2.5, (int, float)))  # True
```
