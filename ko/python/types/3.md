# --description--

Python은 **동적 타입** 언어입니다: 타입은 변수가 아니라 **값**에 속합니다.
변수는 값에 붙은 이름일 뿐이며, 언제든지 다른 타입의 값에 다시 붙일 수 있습니다:
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
선언도 변환도 필요 없습니다: 이전 값은 그냥 잊힙니다.
이는 편리하지만, 변수의 타입이 프로그램이 실행될 때에야 알려진다는 뜻이기도 합니다. 그래서 실수로 타입을 섞으면 실행 전이 아니라 실행 시점에 오류로 나타납니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```python
x = 10
x = "ten"
print(type(x))
```

# --answers--

- `<class 'str'>`, `x`가 이제 문자열을 참조하기 때문입니다
- `<class 'int'>`, `x`의 타입이 첫 번째 대입으로 고정되었기 때문입니다
- `TypeError`, 문자열을 정수 변수에 대입할 수 없기 때문입니다
- `<class 'int'> <class 'str'>`, `x`가 두 값을 모두 유지하기 때문입니다
