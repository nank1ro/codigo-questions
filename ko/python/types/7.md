# --description--

모든 값은 불리언으로 해석될 수 있습니다. `bool()`은 값을 `True` 또는 `False`로 변환하며, 값이 `if`에서 직접 사용될 때도 같은 규칙이 적용됩니다.
**거짓**으로 취급되는 값은 "비어 있는" 값들입니다:
- 숫자 `0` (그리고 `0.0`)
- 빈 문자열 `""`
- `[]`, `{}`, `()`, `set()` 같은 빈 컬렉션
- `None`

비어 있지 않은 값은 모두 **참**이며, 음수나 `"0"`, `" "`처럼 비어 보이기만 하는 문자열도 포함됩니다:
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
그래서 `if name:`은 문자열이 비어 있지 않은지 확인하는 흔한 방법입니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```python
print(bool(0), bool("0"), bool([]), bool(None))
```

# --answers--

- `False True False False`, `"0"`은 비어 있지 않은 문자열이기 때문입니다
- `False False False False`, 모두 0이나 아무것도 없음을 나타내기 때문입니다
- `True True False False`, 숫자는 항상 참이기 때문입니다
- `TypeError`, `None`은 불리언으로 변환할 수 없기 때문입니다
