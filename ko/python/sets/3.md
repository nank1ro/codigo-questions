# --description--

**빈 집합**을 만들 때는 함정이 있습니다.
중괄호는 딕셔너리의 문법이기도 해서, `{}`는 집합이 아니라 빈 **딕셔너리**를 만듭니다:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
빈 집합을 얻으려면 인자 없이 `set()`을 호출해야 합니다:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

이 코드는 무엇을 출력합니까?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`: `{}`는 빈 딕셔너리를 만들기 때문
- `<class 'set'>`: 중괄호는 집합을 만들기 때문
- `<class 'NoneType'>`: 집합에 요소가 없기 때문
- `SyntaxError`: 중괄호는 최소 하나의 요소를 포함해야 하기 때문
