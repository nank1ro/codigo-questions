# --description--

두 집합의 **교집합(intersection)**은 **둘 다**에 존재하는 요소만을 담습니다.
`&` 연산자나 `intersection()` 메서드를 사용하세요:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
두 집합에 공통 요소가 없으면 결과는 빈 집합입니다.
