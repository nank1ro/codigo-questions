# --description--

두 집합의 **합집합(union)**은 **둘 다**의 요소를 중복 없이 담은 새 집합입니다.
`|` 연산자나 `union()` 메서드를 사용하세요:
```python
a = {1, 2}
b = {2, 3}
print(a | b)        # {1, 2, 3}
print(a.union(b))   # {1, 2, 3}
```
`a`도 `b`도 수정되지 않습니다: 집합 연산은 항상 새 집합을 반환합니다.
