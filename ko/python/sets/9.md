# --description--

**차집합(difference)** `a - b`는 `a`의 요소 중 `b`에 **없는** 것들을 담습니다.
순서가 중요합니다: `a - b`와 `b - a`는 보통 다릅니다:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**대칭차집합(symmetric difference)** `a ^ b`는 두 집합 중 **정확히 하나에만** 있는 요소들을 담습니다:
```python
print(a ^ b)  # {1, 4}
```
메서드 형태는 `difference()`와 `symmetric_difference()`입니다.
