# --description--

문자열의 각 문자는 **인덱스(index)**라는 위치를 가집니다.
인덱스는 `1`이 아니라 `0`부터 시작합니다: 첫 번째 문자는 인덱스 `0`, 두 번째는 인덱스 `1`, 이런 식으로 이어집니다.
문자열 뒤에 대괄호로 인덱스를 적으면 문자 하나를 읽을 수 있습니다:
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
`word[6]`처럼 존재하지 않는 인덱스를 요청하면 `IndexError`가 발생합니다.
