# --description--

내장 함수 `len()`은 문자열의 **길이**, 즉 문자열이 포함하는 문자의 개수를 반환합니다.
공백과 문장부호도 문자로 취급됩니다:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
