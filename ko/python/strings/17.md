# --description--

모든 문자열 메서드는 새 문자열을 반환하므로, 메서드를 차례로 **연결(chain)**할 수 있습니다.
각 호출은 이전 결과에 대해 동작합니다:
```python
text = "  Hello World  "
print(text.strip().lower())  # hello world
```
슬라이스는 세 번째 값인 **스텝(step)**도 받을 수 있습니다.
스텝 `-1`은 문자열을 거꾸로 훑는 것으로, 문자열을 뒤집는 대표적인 방법입니다:
```python
print("abc"[::-1])  # cba
```
