# --description--

`in` 연산자는 어떤 문자열이 다른 문자열을 **포함**하는지 확인합니다.
`True` 또는 `False`를 반환하므로 `if` 안에서 자연스럽게 사용할 수 있습니다:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in`은 반대의 검사를 수행합니다.
