# --description--

`startswith(prefix)`와 `endswith(suffix)`는 문자열이 어떻게 시작하고 끝나는지에 따라 `True` 또는 `False`를 반환합니다:
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
이들은 파일 확장자, 프로토콜, 접두사를 확인하는 일반적인 방법입니다.

# --instructions--

`name`이 `.py`로 끝나면 `True`를 반환하는 함수 `is_python_file(name)`과, `line`이 `#`로 시작하면 `True`를 반환하는 함수 `is_comment(line)`을 작성하세요

# --solutions--

```python
def is_python_file(name):
    return name.endswith(".py")

def is_comment(line):
    return line.startswith("#")
```
