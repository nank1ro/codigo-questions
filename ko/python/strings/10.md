# --description--

사용자가 입력한 텍스트에는 앞뒤에 불필요한 공백이 붙어 있는 경우가 많습니다.
`strip()` 메서드는 **앞뒤 공백**(스페이스, 탭, 줄바꿈)이 제거된 문자열의 복사본을 반환합니다:
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
텍스트 중간의 공백은 그대로 유지됩니다.
`lstrip()`은 왼쪽만, `rstrip()`은 오른쪽만 제거합니다.
