# --description--

`find(sub)`는 `sub`가 처음 나타나는 위치의 **인덱스**를 반환하며, 찾지 못하면 `-1`을 반환합니다:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)`는 `sub`가 **몇 번** 나타나는지를 반환합니다:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

`text`에서 처음 나오는 `o`의 인덱스를 `position`에, `z`를 검색한 결과를 `missing`에, `text`에 포함된 `o`의 개수를 `total`에 저장하세요
