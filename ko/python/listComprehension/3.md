# --description--

컴프리헨션은 항목을 **필터링**할 수도 있습니다.
`for` 부분 뒤에 `if` 조건을 추가하면, 조건이 `True`인 항목만 새 리스트에 들어갑니다.
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
이는 안에 `if`가 있는 반복문과 같으며, lambda를 사용한 `filter()`를 더 읽기 쉬운 방식으로 대체합니다.
