# --description--

**딕셔너리**도 반복할 수 있습니다.
`.items()`를 사용하면 `for` 부분이 각 쌍을 키와 값 두 변수로 풀어냅니다.
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
