# --description--

두 조건을 같은 컴프리헨션 안에서 결합할 수 있습니다: 값을 선택하는 `if-else`와, 일부 항목을 걸러내는 마지막의 필터 `if`입니다.
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```

# --instructions--
