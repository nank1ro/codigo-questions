# --description--

`key: value` 부분이 **없는** 중괄호는 **집합 컴프리헨션**이 됩니다.
집합(set)은 순서가 없고 고유한 값만 유지하는 컬렉션이므로, 중복은 자동으로 사라집니다.
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```
