# --description--

컴프리헨션은 **둘 이상의 `for`**를 가질 수 있습니다.
이는 중첩된 반복문처럼 동작하며, 첫 번째 `for`가 바깥쪽 반복문, 두 번째가 안쪽 반복문입니다.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
