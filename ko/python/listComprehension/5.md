# --description--

이터러블이 꼭 리스트일 필요는 없습니다: 반복할 수 있는 것이라면 무엇이든 사용할 수 있고, `range()`가 대표적입니다.
숫자 리스트를 만드는 가장 빠른 방법입니다.
```python
squares = [n * n for n in range(4)]
print(squares)  # [0, 1, 4, 9]
```
`range(start, stop)`은 `stop`을 포함하지 않는다는 점을 기억하세요.
