# --description--

컴프리헨션은 **문자열 변환**에도 매우 유용합니다.
각 항목에 문자열 메서드를 호출하거나, f-문자열로 새 문자열을 만들 수 있습니다.
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
