# --description--

필터 조건은 `len()`과 같은 함수 호출을 포함하여, 불리언 값을 반환하는 모든 표현식이 될 수 있습니다.
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
