# --description--

일부 주석은 에디터가 이해하는 관례를 따릅니다. 가장 흔한 **마커**는 다음과 같습니다:
- `# TODO: ...`는 아직 작성해야 하는 것을 표시합니다
- `# FIXME: ...`는 잘못되었음이 알려져 수정이 필요한 코드를 표시합니다

```python
limit = 10
# TODO: read the limit from the settings
```
Python에게 이것들은 평범한 주석이지만, 에디터는 전용 패널에 모아 주므로 남은 작업을 쉽게 찾을 수 있습니다. `TODO`는 보통 실제 코드가 작성될 때까지 프로그램이 돌아가게 유지하는 자리 표시자 옆에 놓입니다.

작업을 끝내면 같은 변경에서 자리 표시자를 교체하고 마커를 삭제하세요. 그러면 주석이 코드의 상태에 대해 거짓말하는 일이 없습니다.
