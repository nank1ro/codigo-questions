# --description--

한 줄로는 부족할 때, docstring은 **PEP 257**에 기술된 고정된 레이아웃으로 발전합니다: 한 줄 요약, 빈 줄, 그다음 세부 내용, 그리고 마지막 `"""`은 자기 줄에 따로 둡니다.
```python
def to_seconds(minutes):
    """Returns the number of seconds in the given minutes.

    minutes is a whole number and is never negative.
    """
    return minutes * 60
```
빈 줄이 중요합니다: 도구는 첫 줄을 짧은 설명으로 따로 보여 주고, 나머지는 더 읽고 싶은 사람을 위해 남겨 둡니다.

# --asserts--

`area`는 docstring을 가져야 합니다

```python
    def test_1(self):
        self.assertIsNotNone(area.__doc__, "--err-t1--")
```

docstring은 요약 줄로 시작하고, 그 뒤에 빈 줄과 추가 텍스트가 이어져야 합니다

```python
    def test_2(self):
        lines = area.__doc__.split("\n")
        self.assertTrue(len(lines) >= 3, "--err-t2--")
        self.assertNotEqual(lines[0].strip(), "", "--err-t2--")
        self.assertEqual(lines[1].strip(), "", "--err-t2--")
        self.assertNotEqual(lines[2].strip(), "", "--err-t2--")
        self.assertEqual(lines[-1].strip(), "", "--err-t2--")
```

`area(3, 4)`는 `12`를 반환하고 `area(0, 5)`는 `0`을 반환해야 합니다

```python
    def test_3(self):
        self.assertEqual(area(3, 4), 12, "--err-t3--")
        self.assertEqual(area(0, 5), 0, "--err-t3--")
```
