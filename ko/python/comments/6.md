# --description--

문자열이 함수 안의 **첫 번째 문**이면, Python은 그것을 그 함수의 문서로 취급합니다. 이것을 **docstring**이라고 부릅니다:
```python
def greet(name):
    """Returns the greeting for name."""
    return "Hi, " + name + "!"
```
관례상 docstring은 한 줄에 들어가더라도 삼중 큰따옴표, `"""` 사이에 작성합니다. 나중에 따옴표를 바꾸지 않고도 길게 늘릴 수 있도록 하기 위해서입니다.

요약은 함수를 설명하듯 3인칭으로 작성하세요: "Returns...", "Adds...", "Checks...". docstring은 본문의 다른 어떤 문보다 앞에 와야 하며, 그렇지 않으면 그저 평범한 문자열에 불과합니다.

```python

        self.assertEqual(double(21), 42, "--err-t2--")
```

`double(-3)`은 `-6`을 반환하고 `double(0)`은 `0`을 반환해야 합니다

```python

```
