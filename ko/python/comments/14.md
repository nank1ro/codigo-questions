# --description--

함수가 무엇을 하는지 설명하려고 함수 위에 놓인 주석은 잘못된 자리에 있는 것입니다. 그 역할은 docstring의 몫입니다: docstring은 함수에 붙어 있고 `help()`가 찾아 주며 에디터가 보여 주지만, `def` 위의 `#` 주석은 이들 모두에게 보이지 않습니다.

```python
# adds a and b
def add(a, b):
    return a + b
```
같은 문장을 한 줄 아래, 삼중 따옴표 사이로 옮기면 진짜 문서가 됩니다:
```python
def add(a, b):
    """Returns the sum of a and b."""
    return a + b
```

```json

  "modifiers": ["m"],
  "shouldMatch": false
}
```

`# subtract` 주석도 제거되어야 합니다

```json
{
  "regex": "#\\s*subtract",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

`subtract`는 docstring을 가져야 합니다

```python
    def test_1(self):
        self.assertIsNotNone(subtract.__doc__, "--err-t1--")
```

`subtract(5, 3)`은 `2`를 반환해야 합니다

```python
    def test_2(self):
        self.assertEqual(subtract(5, 3), 2, "--err-t2--")
```

`subtract(0, 4)`는 `-4`를 반환해야 합니다

```python
    def test_3(self):
        self.assertEqual(subtract(0, 4), -4, "--err-t3--")
```
