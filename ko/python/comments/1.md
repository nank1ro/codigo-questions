# --description--

**주석(comment)**은 코드를 읽는 사람을 위해 소스 코드 안에 적어 두는 메모입니다. Python은 주석을 완전히 무시하므로, 주석은 프로그램의 동작을 절대 바꾸지 않습니다.

Python에 있는 유일한 주석은 **한 줄 주석**입니다: `#`으로 시작해서 줄의 끝까지 이어집니다.
```python
# 사용자에게 인사함
print("Hello")
```
주석을 사용해 어떤 코드가 무슨 일을 하는지, 또는 왜 그렇게 작성했는지 설명하세요.
