# --description--

docstring과 `#` 주석은 비슷해 보이지만 서로 다른 질문에 답합니다.

**docstring**은 코드를 **사용하는** 사람을 위한 것입니다: 함수가 무엇을 하는지, 무엇을 기대하는지, 무엇을 돌려주는지요. docstring은 `__doc__`에 남아 있고, `help()`가 읽고, 에디터가 보여 주며, 문서화 도구가 수집합니다.

**주석**은 코드를 **읽는** 사람을 위한 것입니다: 이 줄이 왜 이렇게 작성되었는지, 이상한 숫자가 무슨 뜻인지, 어떤 버그를 우회하는 것인지요. 주석은 소스 파일에만 존재하며 프로그램이 실행되는 순간 사라집니다.

```python
def timeout():
    """Returns the number of seconds to wait for the server."""
    # 서버는 35초 후 유휴 연결을 끊음
    return 30
```
정리하면: 함수의 문서는 docstring에 들어가고, 구현에 대한 메모는 주석에 들어갑니다.

# --answers--

- docstring은 `__doc__`에 저장되고 도구가 보여 주는 문자열인 반면, `#` 주석은 소스 파일에만 존재합니다
- 차이가 없습니다: 둘 다 프로그램이 실행되기 전에 버려집니다
- docstring은 함수 안에서만 사용할 수 있는 반면, `#` 주석은 어디에서든 사용할 수 있습니다
- `#` 주석은 `__doc__`에 저장되는 반면, docstring은 프로그램이 실행되기 전에 버려집니다
