# --description--

Python은 주석을 완전히 버리기 때문에, 주석을 추가하거나 삭제해도 프로그램의 동작은 절대 바뀌지 않습니다. 주석 처리되지 **않은** 코드만 실행됩니다.

덕분에 `#`은 코드 줄을 삭제하지 않고 끌 수 있는 빠른 방법이 됩니다. 이것을 **주석 처리(commenting out)**라고 합니다:
```python
total = 10
# total = total + 5
print(total)  # prints 10
```
두 번째 줄은 이제 주석이므로 `total`은 `10`으로 유지됩니다. `#`을 제거하면 그 줄이 다시 살아납니다.

주석 처리는 실험할 때 유용하지만, 나중에 정리하는 것을 잊지 마세요: 오랫동안 주석 처리된 채로 남아 있는 코드는 다음에 읽는 사람을 혼란스럽게 할 뿐입니다.
