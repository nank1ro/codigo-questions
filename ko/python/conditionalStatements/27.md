# --description--

`if` 바로 뒤에 들여쓰기된 `print`만 그 블록에 속합니다. `if`와 같은 들여쓰기 수준으로 작성된 줄은 블록에 속하지 않습니다.

# --instructions--

어떤 print 문이 조건문의 코드 블록에 속합니까?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
- print(Hello World)
