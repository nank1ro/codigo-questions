특정 조건이 충족될 때만 코드를 실행하려면 의사 결정이 필요합니다.
날씨가 좋을 때만 밖에서 놀고 싶다고 가정해 봅시다.
프로그래밍에서는 불리언 변수 `nice_weather`를 저장하고, 이 변수가 `True`일 때 밖에서 노는 행동을 `if`로 수행할 수 있습니다:
```python
nice_weather = True
if (nice_weather):
    # 밖에서 놀기
```

---

이전 예제를 계속 살펴봅시다.
```python
nice_weather = True
if (nice_weather):
    # 밖에서 놀기
```
`if` 문은 조건이 `True`일 때만 코드 블록을 실행한다는 것을 배웠습니다.
또 하나 중요하게 고려해야 할 것은 **콜론** `:`과 **들여쓰기**인데, 이는 코드 블록의 시작을 나타냅니다.
들여쓰기란 코드 줄의 시작 부분에 있는 공백을 말합니다.
다른 프로그래밍 언어에서는 코드의 들여쓰기가 가독성만을 위한 것이지만, Python에서는 들여쓰기가 필수적입니다.
원하는 공백 수(2, 4, 6, 8)를 사용할 수 있으며, 권장되는 것은 4칸입니다.
이 앱에서는 코드 줄을 들여쓸 때 **TAB** 키를 사용하는 것을 권장합니다

---

조건이 발생할 때 코드 블록을 실행하는 방법을 배웠습니다. 이제 첫 번째 조건이 실패할 때 다른 코드 블록을 실행하는 방법을 알아봅시다.
날씨가 좋으면 밖에서 놀고, 그렇지 않으면 집에 있습니다.
Python에서는 `else` 문을 사용할 수 있습니다:
```python
nice_weather = True
if (nice_weather):
    # 밖에서 놀기
else:
    # 집에 있기
```

---

확인해야 할 조건이 하나 더 있다고 가정해 봅시다. 다음 예제를 살펴보겠습니다:
```python
num = 3
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
else:
    print("do something else")
```
이 코드의 출력은 `the number is 3`입니다.
먼저 숫자가 2와 같은지 확인합니다. 이것은 거짓입니다.
그래서 두 번째 문으로 넘어가서 `num`이 3과 같은지 확인하고, 참이므로 `the number is 3`을 출력하는 다음 코드 블록을 실행합니다

---

`elif` 문은 원하는 만큼 추가할 수 있으며, 제한이 없습니다
```python
num = 4
if (num == 2):
    print("the number is 2")
elif (num == 3):
    print("the number is 3")
elif (num == 4):
    print("the number is 4")
elif (num == 5):
    print("the number is 5")
elif (num == 6):
    print("the number is 6")
```
이 코드의 출력은 `the number is 4`입니다.

---

조건문(`if`, `elif` 또는 `else`)을 다른 조건문 안에 중첩하여 더 복잡한 구조를 만들 수도 있습니다.
```python
num = 4
if (num < 3):
    print("the number is lower than 3")
else:
    if (num == 3):
        print("the number is 3")
    elif (num == 4):
        print("the number is 4")
    else:
        print("the number is greather than 4")
```
이 코드의 출력은 `the number is 4`입니다.

---

모든 조건문은 이를 시작하는 `if` 키워드가 필요합니다. 이 키워드가 바로 아래 블록이 조건이 성립할 때만 실행된다는 것을 Python에 알려줍니다.

---

조건이 반드시 비교식일 필요는 없습니다 — `True`와 같은 불리언 값 하나만으로도 충분하며, 그 값이 `True`일 때마다 블록이 실행됩니다.

---

조건만 바꾸면 같은 문장이 블록을 건너뛰게 만들 수 있습니다: 조건이 `False`로 평가될 때마다 Python은 들여쓰기된 코드를 그대로 건너뜁니다.

---

Python의 `if` 줄은 세 부분으로 이루어집니다: `if` 키워드, 조건, 그리고 줄을 마무리하는 콜론입니다. 그 콜론 뒤에 들여쓰기된 모든 것이 블록입니다.

---

여기서는 조건이 `True`이므로, Python은 그 아래 들여쓰기된 줄을 실행하여 `Hello!`를 출력합니다.

---

조건이 `False`이면 Python은 들여쓰기된 블록에 절대 들어가지 않으므로, 아무것도 출력되지 않습니다.

---

블록의 실행 여부를 결정하는 값을 조건이라고 하며, 이 값은 항상 불리언, 즉 `True` 또는 `False`로 평가되어야 합니다.

---

`if` 아래의 블록은 절대 비어 있을 수 없습니다: 콜론 뒤에 들여쓰기된 줄이 없으면 Python은 `IndentationError`를 발생시킵니다. 아직 실행할 내용이 없을 때는 보통 `pass`를 자리표시자로 사용합니다.

---

콜론은 블록이 아니라 `if` 줄에 속합니다: 조건의 끝을 표시하고, 아래의 들여쓰기된 줄들이 그 문장의 일부임을 알립니다.

---

조건이 `False`이면 Python은 들여쓰기된 블록 전체를 건너뛰고, `if` 아래에 들여쓰기되지 않은 다음 줄부터 계속 진행합니다.

---

Python은 조건을 괄호로 감쌀 것을 요구하지 않습니다 — `if True:` 자체만으로 완전한 문장입니다. 여기서 괄호는 산술식에서 쓰이는 것과 같은 평범한 그룹화일 뿐이며, 값을 바꾸지 않습니다.

---

코드 블록은 두 줄 이상을 담을 수 있으며, 각 줄은 작성된 순서대로 실행됩니다 — 기존 문장 위에 새 문장을 추가하면 그 문장이 먼저 출력됩니다.

---

불리언 변수는 그 자체로 조건으로 사용할 수 있습니다 — `True`나 `False`와 먼저 비교할 필요가 없습니다.

---

조건이 변수일 때, `if`는 그 순간 변수에 들어 있는 값을 읽습니다. `if` 줄을 전혀 건드리지 않고도 위쪽의 대입문만 바꾸면 블록을 끌 수 있습니다.

---

조건문에 속하는 들여쓰기된 줄들을 코드 블록이라고 합니다 — 들여쓰기가 바로 그 줄들이 블록의 일부임을 표시합니다.

---

`if`의 들여쓰기 밖에 있는 줄은 그 블록에 속한 적이 없으므로, 조건이 무엇이었든 상관없이 실행됩니다.

---

코드 블록은 한 줄로 제한되지 않습니다 — 모든 줄이 일관되게 들여쓰기되어 있는 한, 로직에 필요한 만큼 짧거나 길어질 수 있습니다.

---

`online`이 `False`로 설정되어 있으면 조건이 결코 성립하지 않으므로, 블록은 건너뛰어지고 아무것도 출력되지 않습니다.

---

`if` 바로 뒤에 들여쓰기된 `print`만 그 블록에 속합니다. `if`와 같은 들여쓰기 수준으로 작성된 줄은 블록에 속하지 않습니다.

---

`if` 블록 뒤에 위치하지만 추가 들여쓰기가 없는 줄은 더 이상 그 블록의 일부가 아닙니다 — 조건이 무엇이었든 항상 실행됩니다.

---

블록은 얼마든지 많은 문장을 담을 수 있습니다. 문장들은 위에서 아래로 실행되며, 각 문장은 다른 문장들과 같은 수준으로 들여쓰기되어야 합니다.

---

변수에 `True`를 대입하면 그 변수를 사용하는 조건이 성립하므로, 아래의 블록이 실행됩니다.

---

대신 `False`를 대입하면 조건이 성립하지 않으므로, 아래의 블록은 완전히 건너뛰어집니다.

---

`if` 키워드는 조건문을 시작하는 키워드입니다 — 조건과 함께 아래 블록의 실행 여부를 결정합니다.

---

따옴표로 감싼 `"False"`는 불리언이 아니라 문자열이며, 비어 있지 않은 문자열은 항상 참으로 취급됩니다. 블록이 실행되지 않게 하려면 따옴표 없는 `False`만 있어야 합니다.
```python
print(bool("False"))  # True
```

---

여기서 `True`를 선택하면 첫 번째 줄만이 아니라 블록의 두 줄이 모두 실행됩니다 — `if` 아래에 들여쓰기된 모든 것이 같은 블록에 속하기 때문입니다.

---

콜론은 `if` 줄에서 없어서는 안 될 유일한 요소입니다: 조건을 마무리하고 블록을 엽니다. Python에서 조건을 감싸는 괄호는 선택 사항이므로, `if True:`와 `if (True):`는 동일하게 동작합니다.

---

불리언 값에 따라 코드를 실행하거나 건너뛰는 `if`, `elif`, `else`와 같은 문장들을 통틀어 조건문이라고 합니다.

---

`not` 연산자는 불리언 값을 뒤집습니다: `not True`는 `False`이고, `not False`는 `True`입니다.
```python
is_online = False
print(not is_online)  # True
```

---

`not`은 읽어온 불리언 값을 수정하는 대신 새로운 불리언 값을 만들어냅니다. 따라서 `is_afternoon = not is_morning`을 실행한 뒤에도 변수 `is_morning`은 원래 값을 그대로 유지합니다.

---

조건은 항상 `if` 키워드와 그 뒤에 오는 콜론 사이에 위치하며, 줄의 다른 어디에도 올 수 없습니다.

---

`if` 블록이 담을 수 있는 줄 수에는 엄격한 제한이 없습니다 — 중요한 것은 모든 줄이 같은 수준으로 들여쓰기되어 있어야 한다는 것입니다.

---

불리언 리터럴은 그 자체로 완벽한 조건이 됩니다: `if True:`는 매번 블록을 실행합니다. Python에서는 조건을 감싸는 괄호가 선택 사항이므로, `if (True):`로 써도 완전히 같은 문장입니다.

---

`if` 문의 코드 블록은 그 아래에 들여쓰기된 줄들의 모음이며, 그 들여쓰기에 의해 프로그램의 나머지 부분과 구분됩니다.

---

조건은 항상 `True` 또는 `False` 둘 중 하나의 값으로 귀결됩니다 — 그것이 바로 조건을 불리언으로 만드는 이유입니다.
