# --description--

`if`의 들여쓰기 밖에 있는 줄은 그 블록에 속한 적이 없으므로, 조건이 무엇이었든 상관없이 실행됩니다.

# --instructions--

`Hello World`가 항상 출력된다는 것을 어떻게 알 수 있습니까?
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- 들여쓰기 때문입니다
- if 문은 한 줄 이상을 가질 수 없기 때문입니다
- else 문이 없기 때문입니다
- elif 문이 없기 때문입니다

# --solutions--

- 들여쓰기 때문입니다
