# --description--

예상하는 실패를 다루는 가장 좁은 타입을 고르는 것이 오류 처리를 신뢰할 수 있게 만듭니다. 텍스트를 읽는 함수는 잘못된 텍스트(`ValueError`)에서는 복구해야 하지만, 잘못된 종류의 인자로 호출되는 것(`TypeError`)은 숨겨서는 안 됩니다 — 그 오류는 호출자의 몫이므로 그대로 통과시키세요.

# --instructions--

`int(text)`를 반환하고, `text`가 유효한 정수가 아니면 `-1`을 반환하는 함수 `parse_age(text)`를 작성하세요. `ValueError`만 잡아서 `parse_age(None)`은 여전히 `TypeError`를 발생시키도록 하세요

```python
    def test_1(self):
```

```python
    def test_2(self):

```

`parse_age(None)`은 여전히 `TypeError`를 발생시켜야 합니다

```python
    def test_3(self):
        with self.assertRaises(TypeError, msg="--err-t3--"):
```

# --solutions--

```python
def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
```
