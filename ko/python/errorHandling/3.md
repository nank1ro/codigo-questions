# --description--

어떤 `except` 블록과도 일치하지 않는 예외는 계속 바깥쪽으로 전파됩니다: 해당 줄을 벗어나, 그 줄을 실행한 함수를 벗어나고, 다시 그 호출자를 벗어나는 식입니다. 프로그램의 최상위에 이를 때까지 아무것도 잡지 못하면 Python은 트레이스백을 출력하고 프로세스는 0이 아닌 종료 상태로 끝납니다. 실패한 문장 뒤의 줄들은 절대 실행되지 않습니다.

# --instructions--

이 코드를 실행하면 어떻게 됩니까?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- `start`를 출력한 뒤 `TypeError`로 끝나는 트레이스백을 출력하고, `end`와 `after`는 출력되지 않습니다. 잡히지 않은 예외가 프로그램을 멈추기 때문입니다
- `start`, `end`, `after`를 모두 출력합니다. Python은 실패한 줄만 건너뛰기 때문입니다
- `start`와 `after`를 출력합니다. 예외가 `sizes`는 멈추지만 프로그램은 계속되기 때문입니다
- `start`와 `0`을 출력합니다. `len(None)`은 `0`이기 때문입니다
