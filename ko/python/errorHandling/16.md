# --description--

내장 타입이 맞지 않을 때는 `Exception`을 상속하여 직접 정의하세요. 빈 몸통으로도 보통 충분합니다 — 이름 자체가 읽는 이에게 하는 메시지입니다:
```python
class ConfigError(Exception):
    pass
```
다른 예외와 똑같이 동작합니다: `raise ConfigError("bad port")`로 발생시키고, `except ConfigError:`로 잡습니다.

저수준 실패를 여러분의 타입으로 바꿔 번역하는 일은 흔하며, 그 과정에서 원래 오류가 사라져서는 안 됩니다. `raise NewError(...) from original`은 둘을 **연결**합니다: `original`을 새 예외의 `__cause__` 속성에 저장하고, 트레이스백은 *The above exception was the direct cause of the following exception* 아래에 둘 다 보여줍니다:
```python
try:
    port = int(text)
except ValueError as e:
    raise ConfigError("bad port") from e
```
`from e`가 없어도 둘은 암묵적으로 연결되지만, `from`은 첫 번째 오류가 두 번째를 일으켰다는 사실을 말로 밝혀줍니다.

`read_port("8080")`은 `8080`을 반환해야 하고, `ConfigError`는 `Exception`을 상속해야 합니다

```python
    def test_1(self):
        self.assertEqual(read_port("8080"), 8080, "--err-t1--")
        self.assertTrue(issubclass(ConfigError, Exception), "--err-t1--")
```

`read_port("abc")`는 메시지 `"bad port"`를 담은 `ConfigError`를 발생시켜야 합니다

```python
    def test_2(self):
        with self.assertRaises(ConfigError, msg="--err-t2--") as ctx:
            read_port("abc")
        self.assertEqual(str(ctx.exception), "bad port", "--err-t2--")
```

발생한 `ConfigError`는 원래의 `ValueError`로부터 연결되어 있어야 합니다

```python
    def test_3(self):
        with self.assertRaises(ConfigError, msg="--err-t3--") as ctx:
            read_port("abc")
        self.assertIsInstance(ctx.exception.__cause__, ValueError, "--err-t3--")
```
