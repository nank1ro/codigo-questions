# --description--

뒤에 타입 없이 `except:`만 쓰면 이를 **베어 except(bare except)**라 합니다. 이것은 모든 것과 일치하며, 여러분이 보호하던 연산과 아무 상관 없는 예외까지도 포함합니다. 따라서 규칙은 간단합니다: 실제로 복구할 수 있는 타입은 항상 명시하세요.

# --instructions--

이 코드는 베어 `except:` 대신 구체적인 예외 타입을 명시해야 하는 이유는 무엇입니까?
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- 베어 `except:`는 관련 없는 실패도 잡습니다. 오타가 있는 `amout` 때문에 생긴 `NameError` 같은 것도요. 그래서 진짜 버그가 조용히 `total = 0`이 되어버립니다
- 베어 `except:`는 더 느립니다. Python이 예외를 모든 내장 클래스와 비교해야 하기 때문입니다
- 베어 `except:`는 모듈 수준에서만 동작하고 함수 안에서는 `SyntaxError`를 발생시킵니다
- 베어 `except:`는 아무것도 잡지 못합니다. 그래서 블록이 끝나자마자 예외가 다시 발생합니다
