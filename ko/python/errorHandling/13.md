# --description--

소수의 내장 예외만으로 일상적인 대부분의 실패를 다룰 수 있습니다:

| 예외 | 발생 조건 | 예시 |
|---|---|---|
| `ValueError` | 타입은 맞지만 값이 불가능한 경우 | `int("abc")` |
| `TypeError` | 타입 자체가 틀린 경우 | `"x" + 1` |
| `ZeroDivisionError` | 나눗셈이나 모듈로의 나눗수가 0인 경우 | `1 / 0` |
| `KeyError` | 딕셔너리에 그런 키가 없는 경우 | `{"a": 1}["b"]` |
| `IndexError` | 시퀀스 인덱스가 범위를 벗어난 경우 | `[1, 2][5]` |

새 타입을 만드는 대신 이 중 하나를 사용하면, Python을 아는 누구에게나 여러분의 오류가 읽기 쉽게 유지됩니다.

# --instructions--

`values[index]`를 반환하고, `index`가 음수면 메시지 `"index must be positive"`를 담은 `ValueError`를 발생시키며, 인덱스가 범위를 벗어나면 `None`을 반환하는 함수 `get_item(values, index)`를 작성하세요

# --solutions--

```python
def get_item(values, index):
    if index < 0:
        raise ValueError("index must be positive")
    try:
        return values[index]
    except IndexError:
        return None
```
