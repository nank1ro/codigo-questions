# --description--

클래스를 함수처럼 호출하여 **값**에서 멤버를 얻거나, 대괄호를 사용하여 **이름**에서 멤버를 얻을 수 있습니다:
```python
print(Color(2))        # Color.GREEN
print(Color["BLUE"])   # Color.BLUE
```
값이나 이름이 파일이나 사용자 입력처럼 프로그램 외부에서 올 때 두 방법 모두 유용합니다.
일치하는 것이 없으면 `Color(9)`는 `ValueError`를 발생시키고, `Color["PINK"]`는 `KeyError`를 발생시킵니다.

# --instructions--

`Status(...)`를 호출하여 값이 `code`인 `Status`의 멤버를 `by_value`에 저장하고, `Status[...]`를 사용하여 이름이 `label`인 멤버를 `by_name`에 저장하세요

from enum import Enum

class Status(Enum):
    PENDING = 0
    DONE = 1
    FAILED = 2

code = 1
label = "FAILED"

# --asserts--

`code`로 `Status(...)`를 호출해야 합니다

```json
{
  "regex": "Status\\(\\s*code\\s*\\)",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`label`로 `Status[...]`를 사용해야 합니다

```json
{
  "regex": "Status\\[\\s*label\\s*\\]",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`by_value`는 `Status.DONE`이어야 합니다

```python
    def test_1(self):
        self.assertIs(by_value, Status.DONE, "--err-t1--")
```

`by_name`은 `Status.FAILED`이어야 합니다

```python
    def test_2(self):
        self.assertIs(by_name, Status.FAILED, "--err-t2--")
```
