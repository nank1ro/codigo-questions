# --description--

`StrEnum`(Python 3.11부터 사용 가능)은 `IntEnum`의 문자열 버전입니다: 멤버들이 문자열이기도 하며 자신의 값과 같습니다.
덕분에 설정 키나 API 매개변수처럼 일반 문자열이 기대되는 곳 어디서든 편리하게 사용할 수 있습니다:
```python
from enum import StrEnum

class Mode(StrEnum):
    LIGHT = "light"
    DARK = "dark"

print(Mode.DARK == "dark")  # True
print(Mode.DARK.upper())    # DARK
```
일반 `Enum`과 달리, `StrEnum` 멤버를 `str()`이나 f-string 안에서 텍스트로 변환하면 `Mode.DARK`가 아니라 그 **값**이 됩니다.

# --instructions--

다음 코드의 출력 결과는 무엇입니까?
```python
from enum import StrEnum

class Mode(StrEnum):
    LIGHT = "light"
    DARK = "dark"

print(f"theme: {Mode.DARK}")
```

# --answers--

- `theme: dark`, `StrEnum` 멤버는 자신의 값으로 포맷되기 때문입니다
- `theme: Mode.DARK`, f-string은 항상 클래스 이름과 멤버 이름을 보여주기 때문입니다
- `theme: DARK`, f-string은 멤버 이름을 보여주기 때문입니다
- `theme: <Mode.DARK: 'dark'>`, f-string은 멤버의 `repr()`을 사용하기 때문입니다
