# --description--

`map` 객체를 그대로 출력하면 값이 보이지 않고 `<map object at 0x7f2b1c>` 같은 결과가 나옵니다.
`list()`(또는 반복문)를 사용해야 기대한 값을 얻을 수 있습니다.

# --instructions--

이 코드는 무엇을 출력합니까?
```python
nums = [1, 2, 3]
print(list(map(lambda x: x + 1, nums)))
```

- [2, 3, 4]
- [1, 2, 3]
- 2 3 4
