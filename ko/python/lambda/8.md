# --description--

`key`에 전달하는 lambda는 항목의 어떤 부분이든 선택할 수 있습니다.
리스트의 리스트의 경우, `lambda p: p[1]`은 각 내부 리스트의 두 번째 요소를 기준으로 정렬합니다.

# --instructions--

항목을 정렬하여 사람들을 가장 어린 순서부터 가장 나이 많은 순서로 출력하세요

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
