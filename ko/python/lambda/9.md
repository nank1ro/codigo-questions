# --description--

`map()`은 리스트의 **모든 항목**에 함수를 적용합니다.
특별한 _map 객체_를 반환하므로, 값을 확인하려면 `list()`로 감싸야 합니다.
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
