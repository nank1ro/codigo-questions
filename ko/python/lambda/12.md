# --description--

lambda는 내장 함수에만 국한되지 않습니다. **여러분이 직접 만든 함수**도 함수를 매개변수로 받아 호출할 수 있습니다.
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

# --instructions--

`func`를 `value`에 두 번 적용하여 그 결과를 반환하는 함수 `apply_twice(func, value)`를 정의하세요.
그런 다음, `3`을 더하는 lambda와 값 `10`으로 호출한 `apply_twice`의 값을 `result`에 저장하세요
