# --description--

lambda가 진가를 발휘하는 곳은 바로 **다른 함수의 인자**로 사용될 때입니다.
`sorted()`는 `key` 매개변수를 받습니다. 이는 각 항목에 대해 호출되는 함수이며, 그 결과가 순서를 결정합니다.
lambda가 여기에 완벽하게 어울립니다.
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```
