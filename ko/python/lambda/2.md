# --description--

lambda의 본문에는 `return` 키워드가 없다는 점에 주목하세요.
본문은 **단일 표현식**이며, 그 값은 자동으로 반환됩니다.
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

변수 `square`에 매개변수 `n` 하나를 받아 `n`을 자기 자신과 곱한 값을 반환하는 lambda를 저장하세요
