# --description--

lambda는 **둘 이상의 매개변수**를 받을 수 있습니다.
`def` 함수에서와 정확히 같은 방식으로 쉼표로 구분합니다.
```python
power = lambda base, exp: base ** exp
print(power(2, 3))  # 8
```
