# --description--

`gather`에서 코루틴들은 `await`마다 순서를 번갈아 가며 실행됩니다. 코루틴은 준비되지 않은 것을 await할 때까지 실행되다가, 루프가 다른 코루틴으로 전환합니다. 따라서 `print` 같은 부수 효과는 코루틴에 전달된 순서가 아니라 코루틴이 **재개되는** 순서로 일어납니다:
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    print(await asyncio.gather(step("a", 0.03), step("b", 0.01)))

asyncio.run(main())
```
이 코드는 `b`, 그다음 `a`, 그다음 `['a', 'b']`를 출력합니다: `b`가 먼저 깨어나지만 결과 리스트는 인수 순서를 유지합니다.

```python
import asyncio

    return name

async def main():
    names = await asyncio.gather(step("x", 0.03), step("y", 0.01), step("z", 0.02))

asyncio.run(main())
```

- `x`, `y`, `z`, 그다음 `['x', 'y', 'z']`가 출력됩니다. `gather`는 코루틴을 하나씩 차례로 실행하기 때문입니다
- `y`, `z`, `x`, 그다음 `['y', 'z', 'x']`가 출력됩니다. `gather`는 결과를 완료된 순서로 반환하기 때문입니다
- `x`, `y`, `z`, 그다음 `['y', 'z', 'x']`가 출력됩니다. 출력이 어떤 sleep도 시작하기 전에 일어나기 때문입니다
