# --description--

이 조각들은 자연스럽게 결합됩니다. 많은 작업을 각자의 시간 제한과 함께 동시에 실행하려면, 각 작업을 `wait_for`를 적용하고 `TimeoutError`를 잡는 작은 코루틴으로 감싼 뒤 그 wrapper들을 `gather`하세요:
```python
async def guarded(coro, limit):
    try:
        return await asyncio.wait_for(coro, timeout=limit)
    except TimeoutError:
        return None
```
`gather(*[guarded(job(x), limit) for x in items])`는 제시간에 끝난 각 작업의 값과 그렇지 못한 각 작업의 `None`을 원래 순서대로 반환하며, 전체 배치는 최대 `limit`초 정도가 걸립니다.

# --instructions--

`delay`초를 기다린 뒤 `delay`를 반환하는 코루틴 함수 `job(delay)`와, 모든 delay에 대해 `job`을 **동시에** 실행하되 각각 `asyncio.wait_for`로 `limit`초로 제한하고, 제시간에 끝난 작업의 delay와 타임아웃된 작업의 `None`을 원래 순서대로 담은 리스트를 반환하는 코루틴 함수 `run_jobs(delays, limit)`를 작성하세요

# --solutions--

```python
import asyncio

async def job(delay):
    await asyncio.sleep(delay)
    return delay

async def guarded(delay, limit):
    try:
        return await asyncio.wait_for(job(delay), timeout=limit)
    except TimeoutError:
        return None

async def run_jobs(delays, limit):
    return await asyncio.gather(*[guarded(d, limit) for d in delays])
```
