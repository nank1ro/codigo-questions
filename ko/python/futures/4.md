# --description--

코루틴 함수를 호출하는 것만으로는 실행되지 않습니다. 호출은 코루틴 객체를 만들 뿐이며, 본문은 그 객체가 await되거나 `asyncio.run`에 전달될 때 실행됩니다:
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python은 이에 대해 `RuntimeWarning: coroutine 'hello' was never awaited` 경고까지 내줍니다. 잊어버린 `await`는 가장 흔한 비동기 버그입니다: 코드는 호출된 것처럼 보이지만 실행되지 않고, 결과를 담아야 할 변수에는 대신 코루틴 객체가 들어갑니다.

# --instructions--

이 코드는 출력에 무엇을 표시합니까?
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- `main`만 출력됩니다. `hello()`는 await되지 않는 코루틴 객체를 만들므로 본문이 실행되지 않기 때문입니다
- `hi` 그다음 `main`이 출력됩니다. 코루틴 함수를 호출하면 즉시 실행되기 때문입니다
- `main` 그다음 `hi`가 출력됩니다. 코루틴은 `main`이 반환될 때 실행되기 때문입니다
- `TypeError`가 발생합니다. 코루틴은 변수에 할당될 수 없기 때문입니다
