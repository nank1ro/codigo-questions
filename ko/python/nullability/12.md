# --description--

조회 후 `None` 검사는 보통 두 줄이 필요합니다: 결과를 저장하는 줄과 검사하는 줄입니다. **대입 표현식** 연산자 `:=`는 별명이 *walrus*이며, 표현식 **안에서** 값을 대입하므로 두 단계 모두 `if` 안에 들어갈 수 있습니다:
```python
ages = {"Ada": 36}
if (age := ages.get("Ada")) is not None:
    print(age + 1)  # 37
```
괄호가 필요합니다: 괄호가 없으면 `:=`가 비교 전체를 대입하려 합니다. `if` 이후에는 `age`가 다른 변수처럼 계속 사용할 수 있습니다.

# --instructions--

이름을 나이에 매핑하는 딕셔너리 `users`와 `name`을 받는 함수 `describe_user`를 작성하세요; 이름이 있으면 `"<name> is <age>"`를, 그렇지 않으면 `"unknown user"`를 반환해야 하며, walrus 연산자를 사용해 `get`의 결과를 저장해야 합니다

`describe_user({"Ada": 36}, "Ada")`는 `"Ada is 36"`을 반환해야 합니다

```python
    def test_1(self):
        self.assertEqual(describe_user({"Ada": 36}, "Ada"), "Ada is 36", "--err-t1--")
```

`describe_user({"Ada": 36}, "Grace")`는 `"unknown user"`를 반환해야 합니다

```python
    def test_2(self):
        self.assertEqual(describe_user({"Ada": 36}, "Grace"), "unknown user", "--err-t2--")
```

`0`인 나이도 여전히 존재하는 것으로 간주되어야 합니다

```python
    def test_3(self):
        self.assertEqual(describe_user({"Tim": 0}, "Tim"), "Tim is 0", "--err-t3--")
```

```python
def describe_user(users, name):
    if (age := users.get(name)) is not None:
        return f"{name} is {age}"
    return "unknown user"
```
