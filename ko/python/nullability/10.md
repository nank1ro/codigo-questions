# --description--

`0`이나 `""`를 유지하고 `None`만 대체해야 할 때는, 폴백에 명시적인 `is None` 검사가 필요합니다. 간결한 형태는 **조건부 표현식** `a if condition else b`로, 조건이 참이면 `a`로 평가되고 그렇지 않으면 `b`로 평가됩니다:
```python
timeout = 0
seconds = timeout if timeout is not None else 30
print(seconds)  # 0, not 30
```

`port_or_default(3000)`은 `3000`을 반환해야 합니다

```python
    def test_1(self):
        self.assertEqual(port_or_default(3000), 3000, "--err-t1--")
```

`port_or_default(None)`은 `8080`을 반환해야 합니다

```python
    def test_2(self):
        self.assertEqual(port_or_default(None), 8080, "--err-t2--")
```

`port_or_default(0)`은 `0`을 반환해야 합니다

