# --description--

`None`을 받을 수 있는 함수는 종종 **가드**로 시작합니다: 다룰 것이 없을 때 일찍 반환하는 `if`입니다. 그러면 함수의 나머지 부분은 모든 것을 `else` 안에 중첩하지 않고도 값이 존재한다고 가정할 수 있습니다:
```python
def shout(text):
    if text is None:
        return None
    return text.upper() + "!"
```
가드는 검사가 일어나야 하는 순서대로 맨 앞에 옵니다: `text`가 `None`이 아님을 알기 전에는 `text.split()`을 호출할 수 없습니다.

# --solutions--

```python
def first_word(text):
    if text is None:
        return None
    words = text.split()
    if len(words) == 0:
        return None
    return words[0]
print(first_word("hello world"))
print(first_word(None))
print(first_word("   "))
```
