# --description--

두 문자열은 `+` 연산자로 결합할 수 있으며, 새로운 문자열이 만들어집니다:
```swift
let full = "Hello" + " " + "world" // Hello world
```
기존 문자열 변수의 끝에 텍스트를 추가하려면 `+=`를 사용하세요. 값이 변경되므로 해당 변수는 `var`로 선언되어야 합니다:
```swift
var log = "Start"
log += "..."
print(log) // Start...
```
