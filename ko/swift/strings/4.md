# --description--

`count` 프로퍼티는 문자열에 포함된 문자 수를 반환하고, `isEmpty`는 문자열에 문자가 전혀 없을 때 `true`가 됩니다:
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
공백과 문장 부호를 포함해 모든 문자가 세어집니다.

# --instructions--

이 코드는 무엇을 출력합니까?
```swift
let text = "Hi there!"
print(text.count)
```
