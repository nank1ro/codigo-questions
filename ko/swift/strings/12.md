# --description--

`uppercased()`와 `lowercased()`는 모든 글자를 대문자 또는 소문자로 바꾼 **새로운** 문자열을 반환합니다. 원본 문자열은 수정되지 않습니다:
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
둘 다 메서드이므로 괄호를 잊지 마세요.
