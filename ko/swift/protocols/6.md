# --description--

프로토콜은 보통 하나 이상의 요구사항을 모아 두며, 준수하는 타입은 그 모두를 만족해야 합니다:
```swift
protocol Vehicle {
    var wheels: Int { get }
    func move() -> String
}

struct Bike: Vehicle {
    var wheels = 2

    func move() -> String {
        return "pedalling"
    }
}
```
중괄호 안에서 요구사항이 어떤 순서로 적혀 있는지는 중요하지 않고, 준수하는 타입이 그것들을 제공하는 순서도 중요하지 않습니다: 컴파일러는 빠진 것이 없는지만 확인합니다.
