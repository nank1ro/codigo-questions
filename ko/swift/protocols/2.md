# --description--

프로토콜은 **메서드**도 요구할 수 있습니다. 시그니처(이름, 매개변수, 반환 타입)만 쓰고, 본문 없이 거기서 멈춥니다:
```swift
protocol Greeter {
    func greet() -> String
}
```
준수하는 타입은 정확히 그 시그니처를 가진 메서드를 선언해야 하며, 본문은 그 타입이 제공합니다:
```swift
struct Robot: Greeter {
    func greet() -> String {
        return "BEEP"
    }
}

print(Robot().greet()) // BEEP
```
이름, 매개변수 타입, 반환 타입 중 무엇이라도 다르면 그 타입은 준수하지 않으며, 컴파일러가 어떤 요구사항이 빠졌는지 알려줍니다.

# --instructions--

필요한 `greet()` 메서드를 추가하여 `Friendly`가 `Greeter`를 준수하도록 만드세요. 이름을 `Hello, `와 `!` 사이에 넣어 반환해야 합니다

사용 예시:
```swift
print(Friendly(name: "Ada").greet())
// Hello, Ada!를 출력
```

```swift
func _asGreeter(_ g: Greeter) -> String {
    return g.greet()
}
```

# --asserts--

`Friendly(name: "Ada")`는 `Hello, Ada!`로 인사해야 합니다

```swift
tryCatch(_asGreeter(Friendly(name: "Ada")) == "Hello, Ada!")
```

`Friendly(name: "Bo")`는 `Hello, Bo!`로 인사해야 합니다

```swift
tryCatch(_asGreeter(Friendly(name: "Bo")) == "Hello, Bo!")
```

빈 이름은 `Hello, !`로 인사해야 합니다

```swift
tryCatch(_asGreeter(Friendly(name: "")) == "Hello, !")
```
