# --description--

준수 선언을 반드시 타입 옆에 둘 필요는 없습니다. **익스텐션(extension)**으로 나중에 추가할 수 있으며, 그러면 타입 자체의 선언은 데이터에만 집중할 수 있습니다:
```swift
protocol Resettable {
    mutating func reset()
}

struct Timer {
    var seconds = 0
}

extension Timer: Resettable {
    mutating func reset() {
        seconds = 0
    }
}
```
이 방법은 직접 작성하지 않은 타입에도 통합니다: 표준 라이브러리 타입의 소스를 건드리지 않고도 자신의 프로토콜을 준수하게 만들 수 있습니다.
