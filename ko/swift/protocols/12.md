# --description--

기본 구현은 규칙이 아니라 대비책입니다. 준수하는 타입이 요구사항의 자체 버전을 제공하면, 실행되는 것은 그 타입의 버전입니다:
```swift
protocol Priced {
    var price: Int { get }
}

extension Priced {
    var price: Int { return 0 }
}

struct Ticket: Priced {
    var price = 12
}

print(Ticket().price) // 12, not 0
```
기본 구현은 타입이 비워 둔 빈자리만 채웁니다.

```swift
    }
}

print(Pirate().greet())
```
