# --description--

**프로토콜**의 익스텐션은 다른 도구입니다: 현재와 미래를 통틀어 그것을 준수하는 모든 타입에 멤버를 추가합니다. 요구사항에 **기본 구현(default implementation)**을 주는 방법이 바로 이것입니다:
```swift
protocol Greeter {
    var name: String { get }
    func greet() -> String
}

extension Greeter {
    func greet() -> String {
        return "Hi, \(name)"
    }
}

struct Person: Greeter {
    var name: String
}

print(Person(name: "Ada").greet()) // Hi, Ada
```
`Person`은 `greet()`를 전혀 작성하지 않고도 준수합니다. 프로토콜 익스텐션 안에서는 프로토콜의 모든 요구사항(여기서는 `name`)을 사용할 수 있습니다. 준수하는 타입이라면 반드시 그것을 가지고 있음이 보장되기 때문입니다.

# --instructions--

항목의 개수 뒤에 ` items`를 붙여 반환하는 `summary()`의 기본 구현을 담은 `Basket`의 익스텐션을 추가하여, `Fruits`가 그 메서드를 작성하지 않고도 준수하게 만드세요

사용 예시:
```swift
print(Fruits(items: ["fig", "plum"]).summary())
// 2 items를 출력
```

# --asserts--

`fig`와 `plum`이 든 바구니는 `2 items`로 요약되어야 합니다

```swift
tryCatch(Fruits(items: ["fig", "plum"]).summary() == "2 items")
```

빈 바구니는 `0 items`로 요약되어야 합니다

```swift
tryCatch(Fruits(items: []).summary() == "0 items")
```

과일이 세 개 든 바구니는 `3 items`로 요약되어야 합니다

```swift
tryCatch(Fruits(items: ["fig", "plum", "pear"]).summary() == "3 items")
```

메서드를 전혀 작성하지 않은 다른 `Basket` 타입도 `1 items`로 요약되어야 합니다

```swift
tryCatch(_Veg(items: ["pea"]).summary() == "1 items")
```

protocol Basket {

    func summary() -> String
}

extension Basket {
    func summary() -> String {
        return "\(items.count) items"
    }
