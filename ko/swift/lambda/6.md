# --description--

클로저는 이를 인수로 받는 배열 메서드에서 진가를 발휘합니다. `map`은 모든 요소에 대해 클로저를 호출하고 그 결과로 이루어진 새 배열을 반환합니다:
```swift
let nums = [1, 2, 3]
let doubled = nums.map { $0 * 2 }
print(doubled) // [2, 4, 6]
```
원래 배열은 변경되지 않습니다. `map`은 클로저 인수를 하나만 받으므로, 후행 클로저 문법이 이를 호출하는 일반적인 방식입니다.
