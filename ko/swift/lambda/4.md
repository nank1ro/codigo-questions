# --description--

클로저는 값이므로 함수가 이를 매개변수로 받을 수 있습니다. 매개변수의 타입은 그냥 함수 타입입니다:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
함수 `apply`는 `operation`이 무엇을 하는지 모릅니다. `Int`를 받아 `Int`를 반환한다는 것만 알고, 다른 함수와 마찬가지로 그것을 호출합니다.

# --instructions--
