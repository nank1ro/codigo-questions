# --description--

`nil`인지 확인한 다음 강제 언래핑하는 것은 장황합니다. Swift는 `if let`을 사용한 **옵셔널 바인딩**을 제공하며, 이는 옵셔널을 언래핑하고 값을 새로운 상수에 한 번에 저장합니다:
```swift
let score: Int? = 10
if let value = score {
    print("Score: \(value)") // value는 Int?가 아니라 Int
} else {
    print("No score")
}
```
`if`의 본문은 옵셔널이 값을 담고 있을 때만 실행되며, 그 안에서 `value`는 `Int?`가 아닌 일반 `Int`이므로 `!`가 필요 없습니다.

# --instructions--

`Int?`(인자 레이블은 생략)를 받아, 옵셔널이 값을 담고 있으면 `"Value: "` 뒤에 숫자를 붙여 반환하고(예: `5`에 대해 `"Value: 5"`), `nil`이면 `"No value"`를 반환하는 함수 `describe`를 작성하세요

# --asserts--

`describe(5)`는 `"Value: 5"`를 반환해야 합니다

```swift
tryCatch(describe(5) == "Value: 5")
```

`describe(42)`는 `"Value: 42"`를 반환해야 합니다

```swift
tryCatch(describe(42) == "Value: 42")
```

`describe(nil)`은 `"No value"`를 반환해야 합니다

```swift
tryCatch(describe(nil) == "No value")
```

func describe(_ number: Int?) -> String {
    if let value = number {
        return "Value: \(value)"
    } else {
        return "No value"
    }
}
