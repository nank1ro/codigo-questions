# --description--

클로저를 받는 함수에는 문제가 하나 있습니다. 건네받은 클로저가 오류를 던질지 알 수 없다는 점입니다. 함수에 `throws`를 붙이면 해를 끼치지 않는 클로저를 넘기는 호출자까지 전부 `try`를 써야 합니다. `rethrows`는 *당신이 준 클로저가 던질 때만 나도 던진다*고 말합니다:
```swift
func applyTwice(_ value: Int, _ transform: (Int) throws -> Int) rethrows -> Int {
    return try transform(transform(value))
}
```
본문 안에서는 여전히 `try`를 씁니다. 그 호출은 정말로 실패할 수 있기 때문입니다. 호출하는 쪽에서는 컴파일러가 넘긴 클로저를 살펴봅니다:
```swift
let doubled = applyTwice(3, { (n: Int) -> Int in n * 2 }) // try가 필요 없습니다
```
표준 라이브러리는 이것을 곳곳에서 씁니다. `map`, `filter`, `sorted(by:)`가 모두 `rethrows`이고, 그래서 평범한 `map` 앞에는 `try`를 쓸 일이 없는 것입니다.

# --instructions--

`applyAll`이 스로우하는 클로저를 받고, 그 클로저가 던질 때만 오류를 던지며, 변환된 값들의 배열을 반환하도록 완성하세요

함수 호출 예시:
```swift
print(applyAll([1, 2], { (n: Int) -> Int in n + 1 }))
// [2, 3] 을 출력합니다
```

# --asserts--

`1, 2, 3`을 두 배로 만들면 `try` 없이 `2, 4, 6`이 되어야 합니다

```swift
let _doubled: [Int] = applyAll([1, 2, 3], { (n: Int) -> Int in n * 2 })
tryCatch(_doubled == [2, 4, 6])
```

빈 배열은 빈 배열이 되어야 합니다

```swift
let _empty: [Int] = applyAll([], { (n: Int) -> Int in n * 2 })
tryCatch(_empty.isEmpty)
```

`5`에 1을 더하면 `6`이 되어야 합니다

```swift
let _plus: [Int] = applyAll([5], { (n: Int) -> Int in n + 1 })
tryCatch(_plus == [6])
```

오류를 던지는 클로저는 `applyAll`도 오류를 던지게 해야 합니다

```swift
tryCatch(_propagates())
```

# --solutions--

```swift
func applyAll(_ numbers: [Int], _ transform: (Int) throws -> Int) rethrows -> [Int] {
    var result: [Int] = []
    for number in numbers {
        result.append(try transform(number))
    }
    return result
}
```
