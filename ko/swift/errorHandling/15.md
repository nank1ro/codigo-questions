# --description--

`do` 블록이 어디에 있느냐가 실패 하나에 드는 비용을 결정합니다. 루프 **안**에 두면 각 항목이 자기만의 시도를 가지므로, 잘못된 값 하나는 건너뛰고 나머지는 그대로 실행됩니다:
```swift
for age in [4, -1, 7] {
    do {
        print(try label(age))
    } catch {
        print("skipped")
    }
}
```
대신 루프 전체를 하나의 `do`로 감싸면 첫 오류에서 멈춰서 `7`에는 결코 도달하지 못합니다. 둘 다 틀린 것은 아닙니다 — *잘못된 항목 하나*와 *포기하는 것*의 차이일 뿐입니다.
