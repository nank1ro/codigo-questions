# --description--

**여러 기준**으로 정렬하려면 첫 번째 프로퍼티를 비교하고, 첫 번째 값들이 같을 때만 두 번째 프로퍼티로 넘어갑니다:
```swift
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age < $1.age
    }
    return $0.name < $1.name
}
```
여기서 사람들은 나이순으로 정렬되고, 나이가 같은 사람들은 이름순으로 정렬됩니다. 클로저는 첫 번째 요소가 두 번째 요소보다 앞에 와야 할 때만 `true`를 반환해야 하므로, 같은 경우에는 다음 비교로 넘어갑니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```swift
struct Person {
    var name: String
    var age: Int
}
let people = [Person(name: "Zed", age: 30), Person(name: "Amy", age: 25), Person(name: "Bea", age: 30)]
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age > $1.age
    }
    return $0.name < $1.name
}
print(sorted.map(\.name))
```
