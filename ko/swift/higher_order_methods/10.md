# --description--

`enumerated()`는 배열을 `(offset, element)` 쌍의 시퀀스로 바꾸므로, 클로저는 각 요소의 값과 함께 그 위치를 사용할 수 있습니다:
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
각 쌍은 튜플이므로, 클로저는 이를 분해할 수도 있습니다: `.map { (i, step) in "\(i + 1). \(step)" }`.

# --instructions--

`enumerated()`, `filter`와 `map`을 사용하여 `String` 배열을 받아(인자 레이블 생략) 짝수 인덱스(0, 2, 4, ...)에 있는 요소들을 반환하는 함수 `evenPositions`를 작성하세요

함수 호출 예시:
```swift
print(evenPositions(["a", "b", "c", "d", "e"]))
// prints ["a", "c", "e"]
```

```json
  "shouldMatch": false
}
```

`evenPositions(["a", "b", "c", "d", "e"])`는 `["a", "c", "e"]`를 반환해야 합니다

```swift
tryCatch(evenPositions(["a", "b", "c", "d", "e"]) == ["a", "c", "e"])
```

`evenPositions(["x", "y"])`는 `["x"]`를 반환해야 합니다

```swift
tryCatch(evenPositions(["x", "y"]) == ["x"])
```

`evenPositions([])`은 `[]`을 반환해야 합니다

```swift
tryCatch(evenPositions([]) == [])
```

```swift
func evenPositions(_ items: [String]) -> [String] {
    return items.enumerated().filter { $0.offset % 2 == 0 }.map { $0.element }
}
```
