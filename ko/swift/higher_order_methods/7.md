# --description--

고차 함수는 직접 만든 구조체의 배열을 포함하여 어떤 배열에도 사용할 수 있습니다. `filter`를 적용한 뒤 `map`을 이어서 사용하는 것은 일부 요소를 선택하고 각 요소에서 값을 추출하는 일반적인 방법입니다:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
반대 순서로, 즉 `map`을 먼저 하고 `filter`를 나중에 하면 검사가 사용하기 전에 `pages` 프로퍼티가 사라져 버립니다.

# --instructions--

구조체 `Product`가 주어져 있습니다. `filter`와 `map`을 이어서 사용하여 `Product` 배열을 받아(인자 레이블 생략) `price`가 `10` 미만인 상품들의 이름을 원래 순서대로 반환하는 함수 `cheapNames`를 작성하세요

함수 호출 예시:
```swift
print(cheapNames([Product(name: "Pen", price: 2.5), Product(name: "Bag", price: 30)]))
// prints ["Pen"]
```

```swift
struct Product {
    var name: String
    var price: Double
}
func cheapNames(_ products: [Product]) -> [String] {
    return products.filter { $0.price < 10 }.map { $0.name }
}
```
