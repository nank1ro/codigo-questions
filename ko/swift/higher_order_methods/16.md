# --description--

배열에 대한 `map`과 `filter`는 **즉시 평가**됩니다: 각각은 다음 단계가 실행되기 전에 배열 전체를 처리하고 새 배열을 만듭니다. 큰 컬렉션을 다루거나 첫 번째 결과만 필요할 때는 이것이 낭비입니다.
`lazy` 프로퍼티는 요소가 실제로 요청될 때만 연산이 실행되는 뷰를 반환하며, 전체 체인을 통해 한 번에 한 요소씩 처리합니다:
```swift
let firstBig = (1...1000).lazy.map { $0 * $0 }.first { $0 > 50 }
print(firstBig!) // 64
```
여기서는 `1, 2, ..., 8`만 제곱됩니다: `first(where:)`는 조건을 만족하는 요소를 찾을 때까지 요소를 요구하고, 체인은 거기서 멈춥니다. `lazy`가 없다면 `map`이 먼저 1000개의 숫자를 모두 제곱할 것입니다.

# --instructions--

`limit`라는 `Int`를 받아(인자 레이블 생략) `limit`보다 큰 가장 작은 세제곱수(`n`이 `1`부터 시작할 때 `n * n * n`)를 반환하는 함수 `firstCubeAbove`를 작성하세요. 범위 `1...limit + 1`에 `lazy`와 `map`을, 그리고 `first(where:)`를 사용하세요

함수 호출 예시:
```swift
print(firstCubeAbove(10))
// prints 27
```

# --solutions--

```swift
func firstCubeAbove(_ limit: Int) -> Int {
    return (1...limit + 1).lazy.map { $0 * $0 * $0 }.first(where: { $0 > limit })!
}
```
