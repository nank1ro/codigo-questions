# --instructions--

이 코드가 컴파일에 실패하는 이유는 무엇일까요?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c`는 `let` 상수이므로 mutating 메서드를 호출할 수 없습니다
- `value`를 변경하려면 `increase`가 `static`으로 표시되어야 합니다
- `value`는 `let`으로 선언되어야 합니다
- 구조체는 메서드를 가질 수 없습니다
