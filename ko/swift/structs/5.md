# --description--

**계산 프로퍼티**는 프로퍼티처럼 보이지만 메서드처럼 동작합니다: 아무것도 저장하지 않고, 읽을 때마다 값을 계산합니다. 타입을 쓰고 그다음 값을 반환하는 코드 블록을 작성합니다:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, no parentheses
```
계산 프로퍼티는 저장할 것이 없기 때문에 멤버별 이니셜라이저에 포함되지 않습니다. 값이 다른 값들에서 파생될 때는 계산 프로퍼티를, 작업에 매개변수가 필요할 때는 메서드를 사용하세요.

# --instructions--

`Temperature`에 세씨우스 값에 `9`를 곱하고 `5`로 나눈 뒤 `32`를 더한 값을 반환하는 `Double` 타입의 계산 프로퍼티 `fahrenheit`를 추가하세요

사용 예시:
```swift
print(Temperature(celsius: 100).fahrenheit)
// prints 212.0
```

struct Temperature {
    var celsius: Double

    var fahrenheit: Double {
        return celsius * 9 / 5 + 32
    }
}
