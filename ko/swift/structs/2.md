```swift
struct Point {
    var x: Int
    var y: Int
}

let p = Point(x: 3, y: 4)
print(p.x) // 3
```
클래스는 이를 무료로 얻지 못하며, 그래서 구조체가 값을 모델링하는 가장 빠른 방법 중 하나입니다.
