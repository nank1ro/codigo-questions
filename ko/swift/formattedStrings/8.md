# --description--

정수는 다른 진수로도 적을 수 있습니다. `%x`는 소문자로 **16진수**를, `%X`는 대문자로 16진수를, `%o`는 8진수를 출력합니다:
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
너비와 `0` 플래그도 여기서 동작합니다: `%02x`는 `#ff8000`처럼 색상의 한 바이트를 적는 고전적인 방법입니다.
