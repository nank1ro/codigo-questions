# --description--

포맷 문자열에는 지정자를 원하는 만큼 넣을 수 있습니다. 값은 같은 순서로 쉼표로 구분되어 뒤따르며, 각 값은 자신의 지정자 타입과 일치해야 합니다: `Int`에는 `%d`, `Double`에는 `%f`입니다:
```swift
let count = 3
let weight = 4.5
print(String(format: "%d items, %.1f kg", count, weight)) // 3 items, 4.5 kg
```
`%d`에 `Double`을(또는 `%f`에 `Int`를) 전달하면 컴파일은 되지만 의미 없는 숫자가 출력되므로, 항상 지정자와 값이 맞아떨어지는지 확인하세요.

# --instructions--

`import Foundation`으로 시작하고 `count`로부터 `weight`를 계산하여 `3 boxes, 7.5 kg`를 출력하도록 항목을 정렬하세요
