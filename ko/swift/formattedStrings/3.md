# --description--

소수(`Double`)의 지정자는 `%f`입니다. 그 자체로는 항상 소수점 뒤에 여섯 자리를 출력합니다:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
원하는 소수 자릿수를 고르려면 `%`와 `f` 사이에 점과 숫자를 적습니다. 이것이 **정밀도**이며, 값은 그에 맞게 반올림됩니다:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
`%.2f`는 항상 정확히 소수 둘째 자리까지 보여주기 때문에 가격에 흔히 사용됩니다.
