# --description--

기본적으로 패딩은 왼쪽에 붙습니다. `%` 바로 뒤에 마이너스 기호를 넣으면 패딩이 대신 오른쪽에 붙으므로 값이 **왼쪽 정렬**됩니다:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
마이너스 기호는 **플래그**입니다: 너비를 바꾸지 않으면서 필드가 채워지는 방식을 바꿉니다.

# --instructions--

다음 코드의 출력 결과는 무엇입니까?
```swift
import Foundation

print(String(format: "[%-5d]", 42))
```
