# --description--

`%`와 문자 사이에 숫자를 넣으면 필드의 **최소 너비**가 정해집니다. 값이 더 짧으면 왼쪽에 공백이 추가되어 **오른쪽 정렬**이 되고, 더 길면 아무것도 잘리지 않습니다:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
너비와 정밀도는 함께 쓸 수 있습니다: `%8.2f`는 "최소 8자 너비, 소수점 둘째 자리까지"를 의미합니다:
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
테이블의 열이 맞춰지는 것은 바로 이 고정된 너비 덕분입니다.

함수 호출 예시:
```swift
print(rightAligned(42) + "|")
```
