**포맷 문자열**은 실행 시점에 일부가 값으로 채워지는 텍스트입니다: 가격, 이름, 점수 같은 것들이죠. Swift는 이를 위한 두 가지 도구를 제공합니다.

첫 번째는 이미 알고 계신 **문자열 보간**입니다: `\( )` 안에 적힌 것은 무엇이든 평가되어 텍스트에 삽입됩니다. 변수일 필요는 없으며 어떤 표현식이든 가능합니다:
```swift
let price = 4
print("Total: \(price * 3)") // Total: 12
print("Name: \("ada".uppercased())") // Name: ADA
```
보간은 문자열을 만드는 가장 빠른 방법이지만, 숫자를 Swift가 저장한 그대로 출력합니다: `3.5`는 `3.5` 그대로이며 절대 `3.50`이 되지 않습니다. 자릿수, 너비, 패딩을 완전히 제어하려면 다음 exercise에서 소개할 `String(format:)`을 사용합니다.

---

두 번째 도구는 **Foundation** 프레임워크에 속한 `String(format:)`이므로, 파일은 `import Foundation`으로 시작해야 합니다.

이 메서드는 삽입할 값들 앞에 **포맷 문자열**을 받습니다. 포맷 문자열 안에서 `%`로 시작하는 **지정자**는 각 값이 어디에 들어가고 어떻게 표현되는지를 나타냅니다. 정수의 지정자는 `%d`입니다:
```swift
import Foundation

let count = 7
let text = String(format: "Item %d", count)
print(text) // Item 7
```
`String(format:)`은 일반 `String`을 반환하므로, 출력하거나 저장하거나 함수에서 반환할 수 있습니다.

---

소수(`Double`)의 지정자는 `%f`입니다. 그 자체로는 항상 소수점 뒤에 여섯 자리를 출력합니다:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
원하는 소수 자릿수를 고르려면 `%`와 `f` 사이에 점과 숫자를 적습니다. 이것이 **정밀도**이며, 값은 그에 맞게 반올림됩니다:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
`%.2f`는 항상 정확히 소수 둘째 자리까지 보여주기 때문에 가격에 흔히 사용됩니다.

---

`%`와 문자 사이에 숫자를 넣으면 필드의 **최소 너비**가 정해집니다. 값이 더 짧으면 왼쪽에 공백이 추가되어 **오른쪽 정렬**이 되고, 더 길면 아무것도 잘리지 않습니다:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
너비와 정밀도는 함께 쓸 수 있습니다: `%8.2f`는 "최소 8자 너비, 소수점 둘째 자리까지"를 의미합니다:
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
테이블의 열이 맞춰지는 것은 바로 이 고정된 너비 덕분입니다.

---

기본적으로 패딩은 왼쪽에 붙습니다. `%` 바로 뒤에 마이너스 기호를 넣으면 패딩이 대신 오른쪽에 붙으므로 값이 **왼쪽 정렬**됩니다:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
마이너스 기호는 **플래그**입니다: 너비를 바꾸지 않으면서 필드가 채워지는 방식을 바꿉니다.

---

또 다른 플래그는 `0`입니다: 공백 대신 필드가 왼쪽에 0으로 채워집니다. `007`이나 `00042` 같은 숫자를 만드는 방법이 바로 이것입니다:
```swift
print(String(format: "%05d", 42))  // 00042
print(String(format: "%03d", 7))   // 007
print(String(format: "%03d", 1234)) // 1234
```
공백과 마찬가지로 너비보다 긴 값은 절대 잘리지 않습니다.

---

포맷 문자열에는 지정자를 원하는 만큼 넣을 수 있습니다. 값은 같은 순서로 쉼표로 구분되어 뒤따르며, 각 값은 자신의 지정자 타입과 일치해야 합니다: `Int`에는 `%d`, `Double`에는 `%f`입니다:
```swift
let count = 3
let weight = 4.5
print(String(format: "%d items, %.1f kg", count, weight)) // 3 items, 4.5 kg
```
`%d`에 `Double`을(또는 `%f`에 `Int`를) 전달하면 컴파일은 되지만 의미 없는 숫자가 출력되므로, 항상 지정자와 값이 맞아떨어지는지 확인하세요.

---

정수는 다른 진수로도 적을 수 있습니다. `%x`는 소문자로 **16진수**를, `%X`는 대문자로 16진수를, `%o`는 8진수를 출력합니다:
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
너비와 `0` 플래그도 여기서 동작합니다: `%02x`는 `#ff8000`처럼 색상의 한 바이트를 적는 고전적인 방법입니다.

---

포맷 문자열에 `String`을 삽입하려면 지정자 `%@`를 사용합니다:
```swift
let name = "Ada"
let age = 36
print(String(format: "%@ is %d years old", name, age)) // Ada is 36 years old
```
`%@`는 Swift `String`을 바로 받습니다. Swift 문자열에 `%s`를 사용하지 마세요: 이 지정자는 C 문자열을 기대하므로 쓰레기 값을 출력하거나 크래시가 납니다.
