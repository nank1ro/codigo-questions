# --description--

포맷 문자열에 `String`을 삽입하려면 지정자 `%@`를 사용합니다:
```swift
let name = "Ada"
let age = 36
print(String(format: "%@ is %d years old", name, age)) // Ada is 36 years old
```
`%@`는 Swift `String`을 바로 받습니다. Swift 문자열에 `%s`를 사용하지 마세요: 이 지정자는 C 문자열을 기대하므로 쓰레기 값을 출력하거나 크래시가 납니다.

# --instructions--

이름(`String`)과 나이(`Int`)를 받아(둘 다 인자 레이블 생략) `%@`와 `%d`로 `String(format:)`을 사용해 `<name> is <age> years old`를 반환하는 함수 `greeting`을 작성하세요

함수 호출 예시:
```swift
print(greeting("Ada", 36))
// prints Ada is 36 years old
```
