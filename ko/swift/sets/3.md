# --description--

set은 같은 값을 절대 두 번 저장하지 않으므로, `count`는 리터럴에 각 값이 몇 번 적혀 있든 상관없이 *고유한* 값의 개수입니다.

# --instructions--

이 코드는 무엇을 출력할까요?
```swift
let guesses: Set<Int> = [7, 3, 7, 7, 3, 9]
print(guesses.count)
```

# --answers--

- 3
- 6
- 2
- 9
