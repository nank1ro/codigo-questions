# --description--

`#/ ... /#` 리터럴은 컴파일 시점에 고정됩니다. 사용자가 입력한 경우처럼 패턴을 실행 중에야 알 수 있다면 `Regex(_:)`로 만드세요:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
이 이니셜라이저는 **throw**합니다. `"["` 같은 잘못된 패턴은 프로그램이 실행될 때에야 발견되므로 호출에 `try`가 필요하고, 에러는 `do`/`catch`(또는 `try?`)로 처리하거나 이 연습처럼 감싸는 함수에 `throws`를 붙여 전파해야 합니다. 이렇게 만든 정규 표현식에는 컴파일 시점에 알려진 번호 프로퍼티가 없지만, `contains`, `matches(of:)`, `replacing`은 이전과 똑같이 동작합니다.

# --instructions--

텍스트(`String`)와 패턴(`String`)을 인수 레이블 없이 받고 `throws`로 표시되며, 텍스트에서 패턴이 몇 번 발견되는지 반환하는 함수 `countMatches`를 작성하세요. 잘못된 패턴은 에러가 밖으로 나가도록 두어야 합니다

함수 호출 예시:
```swift
print(try countMatches("a1 b22", "[0-9]+"))
// prints 2
```

함수는 `try Regex(`로 정규 표현식을 만들어야 합니다

```json
{
  "regex": "try\\s+Regex\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`countMatches("a1 b22", "[0-9]+")`는 `2`를 반환해야 합니다

```swift
tryCatch((try? countMatches("a1 b22", "[0-9]+")) == 2)
```

`countMatches("abc", "[0-9]+")`는 `0`을 반환해야 합니다

```swift
tryCatch((try? countMatches("abc", "[0-9]+")) == 0)
```

`countMatches("hello world", "o")`는 `2`를 반환해야 합니다

```swift
tryCatch((try? countMatches("hello world", "o")) == 2)
```

`countMatches("abc", "[")`는 throw해야 합니다

```swift
tryCatch((try? countMatches("abc", "[")) == nil)
```

# --solutions--

```swift
func countMatches(_ text: String, _ pattern: String) throws -> Int {
    let regex = try Regex(pattern)
    return text.matches(of: regex).count
}
```
