# --description--

`Int(text)`는 전체 텍스트가 선택적 부호를 가진 유효한 정수일 때만 성공합니다:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
소수 텍스트에는 `Double(text)`을 사용하세요. 같은 방식으로 `Double?`을 반환합니다: `Double("3.5")`는 `Optional(3.5)`입니다.

# --instructions--

`String` 배열을 받아(인자 레이블 생략) 유효한 정수인 것들의 합을 나머지는 무시하고 반환하는 함수 `sumOfNumbers`를 작성하세요

함수 호출 예시:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
