# --description--

**타입 별칭**은 `typealias` 키워드로 기존 타입에 새 이름을 부여합니다:
```swift
typealias Score = Int
let best: Score = 100
print(best + 1) // 101
```
`Score`와 `Int`는 같은 타입이므로 자유롭게 섞어 쓸 수 있습니다. 별칭은 안전성을 더하지 않습니다: 일반 타입이 프로그램에서 특별한 의미를 가질 때 코드를 더 잘 읽히게 할 뿐입니다.
