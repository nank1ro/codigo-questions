# --description--

`Int(text)`와 `Double(text)`은 실패하면 `nil`을 반환하므로, 결과를 `nil`과 비교하면 그 텍스트가 해당 종류의 수인지 알 수 있습니다:
```swift
print(Int("42") != nil)     // true
print(Double("4.2") != nil) // true
print(Double("42") != nil)  // true, a whole number is also a valid Double
```
마지막 줄에 주목하세요: `Int`가 받아들이는 텍스트는 `Double`도 모두 받아들이므로, 둘을 구별하려면 먼저 `Int`로 확인해야 합니다.

# --instructions--

`String`을 하나 받아(인자 레이블 생략) 텍스트가 유효한 정수이면 `"Int"`, 유효한 소수이면 `"Double"`, 그 외에는 `"String"`을 반환하는 함수 `classify`를 작성하세요

함수 호출 예시:
```swift
print(classify("3.5"))
// prints Double
```

# --solutions--

```swift
func classify(_ text: String) -> String {
    if Int(text) != nil {
        return "Int"
    }
    if Double(text) != nil {
        return "Double"
    }
    return "String"
}
```
