# --description--

시간이 걸리는 작업은 실패하기 쉽습니다: 서버가 죽었거나, 파일이 없거나, 입력이 잘못되었을 수 있습니다. 그런 함수는 **`async throws`**로 표시되며 **`try await`**로 호출합니다:
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
오류를 처리하려면 호출을 `do` 블록으로 감싸고 catch하세요:
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// could not load를 출력
```
키워드의 순서는 정해져 있습니다: `try`가 먼저 오고, 그다음 `await`가 옵니다.

# --instructions--

문자열을 받아(인자 레이블 생략) 그 문자열을 `Int`로 변환해 반환하는, 오류를 던질 수 있는 비동기 함수 `parse`를 작성하세요. 문자열이 숫자가 아니면 `InputError.notANumber`를 던지세요

함수 호출 예시:
```swift
print(try await parse("7"))
// 7을 출력
```

# --asserts--

함수는 `async throws`로 표시되어야 합니다

```json
{
  "regex": "func\\s+parse\\s*\\([^)]*\\)\\s*async\\s+throws",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`parse("7")`은 `7`을 반환해야 합니다

```swift
do {
    let value = try await parse("7")
    tryCatch(value == 7)
} catch {
    tryCatch(false)
}
```

`parse("-3")`은 `-3`을 반환해야 합니다

```swift
do {
    let value = try await parse("-3")
    tryCatch(value == -3)
} catch {
    tryCatch(false)
}
```

`parse("abc")`는 오류를 던져야 합니다

```swift
do {
    _ = try await parse("abc")
    tryCatch(false)
} catch {
    tryCatch(true)
}
```

# --solutions--

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
