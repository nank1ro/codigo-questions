# --description--
확장은 멤버를 **추가**만 할 수 있고, 기존 멤버를 대체하거나 재정의할 수는 없습니다. `override`는 부모와 다른 타입인 서브클래스에 속합니다. 확장은 같은 타입이므로, 이미 존재하는 메서드를 선언하면 재선언 오류가 납니다:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
다른 동작이 필요하면 새로운 이름의 메서드를 추가하거나, 타입이 클래스일 때는 서브클래스를 작성하세요.

# --instructions--
이 프로그램을 컴파일하고 실행하면 어떻게 되나요?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--
- 같은 타입에 `speak()`가 두 번 선언되어 컴파일되지 않습니다
- 확장이 원래 메서드를 재정의하므로 `Bark`를 출력합니다
- 원래 메서드가 확장보다 우선하므로 `Woof`를 출력합니다
- `Woof`를 출력한 다음 `Bark`를 출력합니다
