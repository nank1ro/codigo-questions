# --description--
확장은 다른 사람의 타입만을 위한 것이 아닙니다. 자신의 코드를 정리하는 흔한 방법은 저장 프로퍼티를 구조체나 클래스 본문에 두고, 동작은 관련된 멤버끼리 묶은 하나 이상의 확장에 추가하는 것입니다:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
확장에 추가된 멤버는 마치 타입 안에 작성된 것처럼 저장 프로퍼티를 직접 사용할 수 있습니다.

# --instructions--
구조체 `Rectangle`이 주어져 있습니다. 다음을 가진 `Rectangle`의 확장을 작성하세요:
- `width`와 `height`의 곱인 `Double` 타입의 계산 프로퍼티 `area`
- 두 변을 모두 `factor`만큼 곱한 새로운 `Rectangle`을 반환하는 메서드 `scaled(by factor: Double)`

# --asserts--
`Rectangle`의 확장을 사용해야 합니다

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`2` × `3` 사각형의 넓이는 `6.0`이어야 합니다

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

`1.5` × `4` 사각형의 넓이는 `6.0`이어야 합니다

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

`2` × `3` 사각형을 `2`배로 확대하면 `4` × `6`이 되어야 합니다

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

확대는 원래 사각형을 바꾸지 않아야 합니다

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
