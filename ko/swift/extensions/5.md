# --description--

확장의 연산 프로퍼티는 `String`에도 자연스럽게 어울립니다. `reversed()` 메서드는 문자들을 반대 순서로 반환하고, `String(...)`은 그것들을 다시 문자열로 만듭니다:
```swift
extension String {
    var backwards: String {
        return String(reversed())
    }
}
print("swift".backwards) // tfiws
```
메서드와 마찬가지로, 확장 안에서 `reversed()`는 `self.reversed()`를 의미합니다.

# --instructions--

`Bool` 타입의 연산 프로퍼티 `isPalindrome`을 가진 `String`의 확장을 작성하세요. 이 프로퍼티는 문자열을 앞으로 읽었을 때와 뒤로 읽었을 때 같을 때 `true`입니다. 비교는 대소문자를 구분합니다

사용 예시:
```swift
print("level".isPalindrome)
// prints true
```

```json

  "regex": "extension\\s+String",

  "shouldMatch": true
```

```swift
tryCatch("level".isPalindrome == true)
```

`"swift".isPalindrome`은 `false`여야 합니다

```swift
tryCatch("swift".isPalindrome == false)
```

`"Anna".isPalindrome`은 `false`여야 합니다 (비교는 대소문자를 구분합니다)

```swift
tryCatch("Anna".isPalindrome == false)
```

`"".isPalindrome`은 `true`여야 합니다

```swift
tryCatch("".isPalindrome == true)
```
