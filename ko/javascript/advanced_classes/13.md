# --description--

메서드도 비공개일 수 있습니다. 이름 앞에 `#`을 붙이면 그 메서드는 클래스의 공개 표면에서 사라지지만, 다른 어떤 메서드에서든 `this.#name(...)`으로 호출할 수 있습니다:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// $7 출력
```
이렇게 하면 도우미 단계를 API 밖에 둘 수 있습니다. 호출자는 그 뒤의 포매팅 세부 사항이 아니라 `print`를 봅니다. 비공개 필드와 비공개 메서드가 함께 클래스에 명확한 안과 밖을 만들어 줍니다.

# --asserts--

새 점수는 `0`으로 시작해야 합니다

```javascript
tryCatch(new Score().total === 0);
```

양수 값은 더해져야 합니다

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

음수 값은 무시되어야 합니다

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

0은 무시되어야 합니다

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

점수는 비공개여야 하므로, 인스턴스는 공개 프로퍼티를 가지면 안 됩니다

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

도우미는 비공개 메서드여야 합니다

```json
{
  "regex": "this\\.#add\\s*\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
