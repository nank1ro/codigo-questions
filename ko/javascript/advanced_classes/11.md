# --description--

세터의 진짜 가치는 값을 거절할 수 있다는 점입니다. 대입과 저장된 값 사이에서 도착한 값을 검사하거나, 제한하거나, 거절할 기회를 얻습니다:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// prints 3, the setter rejected 50
```
같은 이름의 게터와 세터는 하나의 프로퍼티를 이루므로, 동시에 일반 필드일 수는 없습니다. 저장된 값은 다른 이름 아래 있으며, 관례상 앞에 밑줄을 붙인 같은 이름을 사용합니다.

# --asserts--

게터는 생성자에 주어진 값을 반환해야 합니다

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

세터는 유효한 값을 받아들여야 합니다

```javascript

t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

세터는 음수 값을 무시해야 합니다

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

세터는 `0`을 받아들여야 합니다

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

값은 `_temperature`에 저장되어야 합니다

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```

class Thermostat {
  constructor(temperature) {
    this._temperature = temperature;
  }
  get temperature() {
    return this._temperature;
  }
  set temperature(value) {
    if (value >= 0) {
      this._temperature = value;
    }
  }
}
