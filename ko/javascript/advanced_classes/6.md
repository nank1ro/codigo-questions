# --description--

클래스가 서로 상속할 때는 순서가 중요합니다. `class` 선언은 `function`처럼 호이스팅되지 **않습니다**. 그 이름은 클래스가 작성된 줄부터 존재합니다. 따라서 자식 클래스는 자신이 상속하는 부모보다 *나중에* 나타나야 하며, 그렇지 않으면 `extends` 절이 `ReferenceError`로 실패합니다.

# --instructions--

항목을 정렬하여 동작하는 프로그램을 만드세요. 부모 클래스가 자식보다 먼저 정의되어야 한다는 점에 유의하세요

# --answers--

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
```

```javascript
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
```

```javascript
console.log(new Car().describe());
```

```javascript
class Vehicle {
  describe() {
    return "a vehicle";
  }
}
class Car extends Vehicle {
  describe() {
    return super.describe() + " with four wheels";
  }
}
console.log(new Car().describe());
```

# --output--

a vehicle with four wheels
