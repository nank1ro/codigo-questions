# --description--

`super()`에 대한 규칙은 "어딘가에서 호출하라"는 것보다 더 엄격합니다. 자식 생성자 안에서 `this`는 `super()`가 실행되기 전까지 존재하지 않습니다. 객체를 만드는 것은 부모 생성자이기 때문입니다. 그 줄 전에 `this`를 사용하면 오류가 발생합니다:
```javascript
class Child extends Base {
    constructor() {
        this.x = 1; // ReferenceError
        super();
    }
}
```
따라서 `super(...)`는 `this`를 사용하는 자식 생성자의 **첫 번째 문장**이어야 합니다.

# --instructions--

이 프로그램을 실행하면 어떻게 됩니까?
```javascript
class Base {
  constructor() {
    this.a = 1;
  }
}
class Child extends Base {
  constructor() {
    this.b = 2;
    super();
  }
}
console.log(new Child().a);
```

# --answers--

- `super()` 전에 `this`를 사용했기 때문에 `ReferenceError`가 발생합니다
- `1`을 출력합니다
- `2`를 출력합니다
- `undefined`를 출력합니다
