# --description--

`add()`는 세트 자신을 반환하므로 여러 호출을 체이닝할 수 있습니다:
```javascript
let letters = new Set();
letters.add("a").add("b");
```
체이닝을 하든 안 하든, 이미 존재하는 값은 두 번째로 추가되지 않으므로 `size`는 각 고유한 값을 한 번만 셉니다.

let letters = new Set();

console.log(letters.size);
