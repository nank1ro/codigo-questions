# --description--

스프레드와 `filter()`를 결합하면 집합론의 고전적인 연산을 할 수 있습니다. 각각은 **새로운** 컬렉션을 만들고 원본은 그대로 둡니다:
- **합집합**, `a`, `b` 또는 둘 다에 있는 모든 값: `new Set([...a, ...b])`
- **교집합**, **둘 다**에 있는 값만: `[...a].filter((x) => b.has(x))`
- **차집합**, `a`의 값 중 `b`에 **없는** 값: `[...a].filter((x) => !b.has(x))`

```javascript
let a = new Set([1, 2, 3]);
let b = new Set([3, 4]);
console.log([...new Set([...a, ...b])]);
// prints [ 1, 2, 3, 4 ]
console.log([...a].filter((x) => b.has(x)));
// prints [ 3 ]
console.log([...a].filter((x) => !b.has(x)));
// prints [ 1, 2 ]
```
최신 JavaScript 엔진은 세트에 직접 `a.union(b)`, `a.intersection(b)`, `a.difference(b)`도 제공하지만, 스프레드와 filter 버전은 어디서나 동작합니다.

# --asserts--

`union(new Set([1, 2]), new Set([2, 3]))`은 정확히 `1`, `2`, `3`을 포함해야 합니다.

```javascript
tryCatch(JSON.stringify([...union(new Set([1, 2]), new Set([2, 3]))]) === '[1,2,3]');
```

결과는 `Set`이어야 합니다.

```javascript
tryCatch(union(new Set([1]), new Set([2])) instanceof Set);
```

두 개의 빈 세트를 `union`한 결과의 크기는 `0`이어야 합니다.

```javascript
tryCatch(union(new Set(), new Set()).size === 0);
```

첫 번째 세트는 수정되면 안 됩니다.

```javascript
let _a = new Set([1]);
union(_a, new Set([2]));
tryCatch(_a.size === 1);
```
