# --description--

**맵**은 **키-값 쌍**을 저장합니다: 각 값은 키 아래에 저장되고, 그 키를 사용해 값을 다시 찾을 수 있습니다.
`new Map()`으로 빈 맵을 만들고, `set(key, value)`로 쌍을 추가하고, `get(key)`로 값을 읽습니다:
```javascript
let ages = new Map();
ages.set("Ann", 30);
ages.set("Bob", 25);
console.log(ages.get("Ann"));
// prints 30
```
이미 존재하는 키로 `set()`을 호출하면 그 값을 대체합니다.
