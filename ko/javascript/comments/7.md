# --description--

JavaScript의 블록 주석은 **중첩할 수 없습니다**. 앞에 `/*`가 몇 개 있었든, 주석은 만나는 **첫 번째** `*/`에서 끝납니다.
```javascript
/* outer /* inner */ still a comment */
console.log("done");
```
여기서 주석은 `inner` 바로 뒤에서 끝나므로 `still a comment */`는 코드로 읽혀 문법 오류를 일으킵니다. 이미 `/* */` 주석이 들어 있는 블록을 주석 처리할 때 이 점을 기억하세요. 각 줄에 `//`를 쓰거나, 안쪽 주석을 먼저 지우세요.

# --instructions--

이 코드를 실행하면 어떻게 될까요?
```javascript
/* start /* nested */ console.log("hidden"); */
console.log("done");
```

# --answers--

- 문법 오류: 주석이 첫 번째 `*/`에서 끝나므로 두 번째 `*/`는 잘못된 코드입니다
- `done`을 출력합니다
- `hidden`을 출력한 다음 `done`을 출력합니다
- 아무것도 출력되지 않고 오류도 보고되지 않습니다
