# --description--

어떤 종류의 주석을 쓰든 규칙은 같습니다. 그 안의 글자는 **코드가 아닙니다**. 주석 안의 `console.log`는 아무것도 출력하지 않고, 같은 줄에서 `//` 뒤에 쓴 코드는 그 줄이 진짜 코드로 시작하더라도 절대 실행되지 않습니다:
```javascript
console.log("a"); // console.log("b");
/* console.log("c"); */
// prints only a
```
프로그램이 무엇을 출력할지 확신이 서지 않을 때는, 먼저 머릿속에서 모든 주석을 지우고 남은 것을 읽어 보세요.

# --instructions--

이 코드는 무엇을 출력할까요?
```javascript
// console.log("one");
console.log("two"); // console.log("three");
/* console.log("four"); */
console.log("five");
```

# --answers--

- `two`와 `five`
- `one`, `two`, `three`, `four`, `five`
- `two`, `three`, `five`
- `two`, `four`, `five`
