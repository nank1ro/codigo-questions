# --description--

`indexOf()` 메서드는 지정한 텍스트가 문자열에서 **처음** 나타나는 인덱스를 반환합니다.
텍스트를 찾을 수 없으면 `-1`을 반환합니다:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
