# --description--

**문자열**은 `"hello"`나 `'hello'`처럼 따옴표로 감싼 문자의 나열입니다.
모든 문자열에는 포함된 문자 수를 알려주는 `length` 속성이 있습니다:
```javascript
let greeting = "hello";
console.log(greeting.length);
// prints 5
```
공백과 문장 부호도 문자로 계산됩니다.
