# --description--

두 문자열은 정확히 같은 문자가 같은 대소문자로 이루어져 있을 때만 `===`로 같습니다:
```javascript
console.log("hello" === "hello");
// prints true
console.log("hello" === "Hello");
// prints false
```
`<`와 `>` 연산자는 문자열을 한 글자씩 알파벳 순서로 비교합니다.
대문자가 소문자보다 앞에 오므로 `"Zoo" < "apple"`은 `true`입니다.
