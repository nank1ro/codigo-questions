# --description--

문자열은 **불변**입니다: 한 번 만들어진 문자열은 절대 변경할 수 없습니다.
인덱스에 값을 대입해도 아무 일도 일어나지 않으며, 모든 문자열 메서드는 원본을 수정하는 대신 **새로운** 문자열을 반환합니다:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
결과를 유지하려면 변수에 다시 대입하세요:
```javascript
word = word.toUpperCase();
```

# --instructions--

첫 번째 `console.log`가 `hello`를 출력하는 이유는 `toUpperCase()`가 `word`를 바꾸지 않았기 때문입니다. 두 번째 `console.log`가 `HELLO`를 출력하도록 코드를 완성하세요
