# --description--

키가 다른 객체나 배열을 담고 있다면, 패턴은 그대로 이어져 그 모양까지 기술할 수 있습니다:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// London 출력
```
그 줄이 무엇을 만드는지 주의하세요: `address: { city }`는 "`address` 안으로 들어가라"는 뜻이지 "`address`를 주라"는 뜻이 아니므로, `city`만 변수가 됩니다. 둘 다 얻으려면 키를 두 번 언급하세요: `const { address, address: { city } } = user;`. 배열 패턴과 객체 패턴은 `{ tags: [first] }`처럼 서로 자유롭게 중첩됩니다.

# --asserts--

중첩된 도시가 반환되어야 합니다.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

다른 중첩된 도시가 반환되어야 합니다.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

빈 `address`는 `"unknown"`이 되어야 합니다.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

`address`의 다른 키들은 무시되어야 합니다.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

명시적인 `undefined` 도시는 `"unknown"`이 되어야 합니다.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
