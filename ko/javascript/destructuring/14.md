# --description--

기본값이 있는 구조 분해 매개변수는 깔끔한 옵션 객체를 만들지만, 호출자가 아무것도 전달하지 않으면 여전히 깨집니다: `undefined`에서 키를 읽으면 `TypeError`가 발생합니다. 패턴 전체에 `{}` 기본값을 주면 해결됩니다:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// guest/false 출력
```
그 줄은 바깥부터 안으로 읽으세요: 인수가 없을 때 `= {}`가 빈 객체를 공급하고, 그다음 각 안쪽 기본값이 자기 키를 채웁니다.

# --instructions--

# --asserts--

인수 없이 `button()`을 호출하면 두 기본값이 모두 사용되어야 합니다.

```javascript
tryCatch(button() === "OK/medium");
```

빈 객체도 두 기본값을 모두 사용해야 합니다.

```javascript
tryCatch(button({}) === "OK/medium");
```

`label`만 주어지면 기본 size가 유지되어야 합니다.

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

`size`만 주어지면 기본 label이 유지되어야 합니다.

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

두 옵션이 모두 주어지면 모두 사용되어야 합니다.

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
