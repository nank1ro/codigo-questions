# --description--

`!=`는 `==`와 마찬가지로 비교하기 전에 변환을 수행하므로, `"5" != 5`는 `false`입니다. 이에 대응하는 엄격 연산자 `!==`는 문자열과 숫자를 내용과 상관없이 서로 다른 것으로 취급합니다.
```javascript
console.log("5" !== 5); // true
```
