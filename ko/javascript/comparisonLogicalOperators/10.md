# --description--

`==`는 양쪽 값을 공통 타입으로 변환한 뒤 비교하므로, `"5" == 5`는 `true`입니다. 엄격 연산자 `===`는 이 변환을 건너뛰고 타입까지 일치할 것을 요구합니다.
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```
