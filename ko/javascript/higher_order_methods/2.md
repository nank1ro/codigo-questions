# --description--

고차 함수는 *각 요소로 무엇을 할지*와 *요소를 어떻게 순회할지*를 분리해 줍니다. 순회하는 부분은 한 번만 작성하고, 나머지는 콜백이 결정합니다:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
콜백은 한 번에 요소 하나를 받습니다. 위처럼 인라인으로 쓴 화살표 함수일 수도 있고, 변수에 저장된 어떤 함수든 될 수 있습니다. 다음에 배울 내장 배열 메서드도 내부적으로는 정확히 이렇게 동작합니다.

# --asserts--

`transform([1, 2, 3], (n) => n * 2)`는 `[2, 4, 6]`을 반환해야 합니다.

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())`는 `["A", "B"]`를 반환해야 합니다.

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)`은 빈 배열을 반환해야 합니다.

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

결과는 새 배열이어야 하며 원본은 변경되면 안 됩니다.

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

함수는 `map`을 사용하면 안 됩니다.

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

# --solutions--

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
