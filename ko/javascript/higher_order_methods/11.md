# --description--

함수를 반환하는 함수는 콜백을 **맞춰 쓰는** 자연스러운 방법이기도 합니다. 술어가 하나 있는데 `filter`에는 그 반대가 필요하다고 해 봅시다. 다시 작성하는 대신 감싸면 됩니다:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
일반적인 `not(predicate)`는 어떤 술어에 대해서도 이 일을 합니다. 같은 인자로 `predicate`를 호출하고 결과를 `!`로 뒤집는 새 함수를 반환합니다. `filter`, `find`, `some`, `every`의 술어는 요소를 첫 번째 인자로 받으므로, 래퍼는 그 값 하나만 전달하면 됩니다.

# --asserts--

`not((n) => n % 2 === 0)(3)`은 `true`를 반환해야 합니다.

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)`는 `false`를 반환해야 합니다.

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))`은 `[1, 3]`을 반환해야 합니다.

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))`는 `["a", "b"]`를 반환해야 합니다.

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

두 번 부정하면 원래 답이 나와야 합니다: `not(not(isEven))(4)`는 `true`를 반환해야 합니다.

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not`은 함수를 반환해야 합니다.

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
