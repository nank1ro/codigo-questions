# --description--

클로저는 반환된 함수가 호출 사이에 **비공개 상태**를 유지하게 해 줍니다. 이렇게 만든 대표적인 도구가 `once(fn)`입니다. 반환된 함수는 처음 호출될 때만 `fn`을 실행하고 결과를 기억한 뒤, 이후 호출에서는 `fn`을 다시 실행하지 않고 같은 결과를 반환합니다:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
래퍼에는 비공개 변수 두 개가 필요합니다. `fn`이 이미 실행됐는지 여부와 저장된 결과입니다. 둘 다 클로저 안에 있어 바깥에서는 보이지 않습니다. 래퍼의 모든 인자를 `fn`에 넘기려면 나머지 매개변수 `(...args)`로 래퍼를 선언하고 `fn(...args)`를 호출하세요.

# --instructions--

첫 호출에서만 같은 인자로 `fn`을 호출해 그 결과를 반환하고, 이후 호출에서는 `fn`을 다시 호출하지 않고 저장된 결과를 반환하는 함수를 반환하는 함수 `once(fn)`을 작성하세요

# --asserts--

감싼 함수는 `fn`을 한 번만 실행하고 그 결과를 계속 반환해야 합니다.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

첫 호출의 인자는 `fn`에 전달되어야 합니다: `once((a, b) => a + b)(2, 3)`은 `5`를 반환해야 합니다.

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

이후 호출은 인자가 달라도 저장된 결과를 반환해야 합니다.

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn`의 결과가 `undefined`일 때에도 `fn`이 다시 실행되면 안 됩니다.

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

같은 함수의 래퍼 두 개는 서로 독립적이어야 합니다.

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once`는 함수를 반환해야 합니다.

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
