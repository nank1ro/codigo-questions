# --description--

마지막 조각들을 합치면 거의 모든 실제 애플리케이션에서 쓰이는 작은 도구가 됩니다: 마감 시간입니다. `ms`밀리초 후에 거부되는 프로미스를 만들어 실제 작업과 경주시키면, 먼저 처리되는 쪽이 결과를 결정합니다:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
`async` 함수에서 프로미스를 반환해도 괜찮습니다: 함수가 돌려주는 프로미스가 그 프로미스를 따라가므로, 호출자는 프로미스의 프로미스가 아니라 최종 값을 await하게 됩니다.

# --instructions--

프로미스와 밀리초 수 `ms`를 받아, 프로미스가 `ms` 안에 처리되면 그 결과를 반환하고, 그렇지 않으면 `new Error("timeout")`으로 거부되는 `async` 함수 `withTimeout`을 작성하세요. `Promise.race`를 사용하세요

# --asserts--

이미 이행된 프로미스는 그 값을 돌려주어야 합니다

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

마감 전에 거부된 프로미스는 자신의 에러를 그대로 유지해야 합니다

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

충분히 빠른 프로미스는 프로미스가 아니라 그 값을 돌려주어야 합니다

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

너무 느린 프로미스는 `"timeout"`이라는 메시지로 거부되어야 합니다

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function withTimeout(promise, ms) {
  const timer = new Promise((resolve, reject) => {
    setTimeout(() => reject(new Error("timeout")), ms);
  });
  return Promise.race([promise, timer]);
}
```
