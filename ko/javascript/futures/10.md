# --description--

`await`를 둘러싼 `try` / `catch`의 흔한 용도는 실패를 무난한 기본값으로 바꾸는 것입니다. 그러면 호출자는 에러를 전혀 다룰 필요가 없습니다:
```javascript
async function sizeOf(path) {
  try {
    return await measure(path);
  } catch (error) {
    return 0;
  }
}
```
값이 곧바로 반환되더라도 `measure(path)` 앞의 `await`는 그대로 두세요. `await`가 없으면 프로미스가 `try` 블록을 거치지 않고 함수를 빠져나가므로, 거부가 `catch`를 피해 빠져나가 버립니다.

# --instructions--

`parseLater` 함수는 `text`에 적힌 숫자로 이행되는 프로미스를 반환하고, `text`가 숫자가 아니면 거부됩니다. 그 숫자를 반환하고, `parseLater`가 실패하면 `-1`을 반환하는 `async` 함수 `safeParse`를 작성하세요. `try`와 `catch`를 사용하세요

# --asserts--

`await safeParse("12")`는 `12`이어야 합니다

```javascript
(async () => {
  tryCatch((await safeParse("12")) === 12);
})().catch(() => tryCatch(false));
```

`await safeParse("-7.5")`는 `-7.5`이어야 합니다

```javascript
(async () => {
  tryCatch((await safeParse("-7.5")) === -7.5);
})().catch(() => tryCatch(false));
```

`await safeParse("abc")`는 `-1`이어야 합니다

```javascript
(async () => {
  tryCatch((await safeParse("abc")) === -1);
})().catch(() => tryCatch(false));
```

`safeParse("oops")`는 거부되지 않고 이행되어야 합니다

```javascript
(async () => {
  let ok = false;
  await safeParse("oops").then(() => { ok = true; }, () => { ok = false; });

})().catch(() => tryCatch(false));
```

```javascript
function parseLater(text) {
  return new Promise((resolve, reject) => {
    const value = Number(text);
    if (Number.isNaN(value)) {
      reject(new Error(`not a number: ${text}`));
    } else {
      resolve(value);
    }
  });
}

async function safeParse(text) {
  try {
    return await parseLater(text);
  } catch (error) {
    return -1;
  }
}
```
