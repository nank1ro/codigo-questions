# --description--

`Promise.all`은 프로미스 하나가 거부되는 순간 포기합니다. 그래도 모든 결과가 필요하다면 **`Promise.allSettled(promises)`**를 사용하세요: 절대 거부되지 않으며, 같은 순서대로 프로미스마다 작은 객체 하나씩으로 이행됩니다:

- 성공한 것들은 `{ status: "fulfilled", value: ... }`입니다;
- 실패한 것들은 `{ status: "rejected", reason: ... }`입니다.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
`status`가 `"fulfilled"`일 때만 `value`를, `"rejected"`일 때만 `reason`을 읽으세요: 다른 쪽 프로퍼티는 그냥 없습니다.

# --asserts--

`await countFulfilled([])`은 `0`이어야 합니다

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])`은 `2`이어야 합니다

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

셋 중 하나가 거부된 프로미스일 때 답은 `2`이어야 합니다

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

모든 프로미스가 거부될 때 답은 `0`이어야 하고, `countFulfilled`는 거부되지 않아야 합니다

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
