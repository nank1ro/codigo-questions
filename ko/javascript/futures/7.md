# --description--

비동기 작업은 실패할 수도 있습니다. `new Promise`에 주어진 함수는 두 번째 콜백 **`reject`**를 전달받습니다: `reject(error)`를 호출하면 프로미스가 이행 대신 거부(rejected) 상태가 됩니다.
```javascript
function readAge(age) {
  return new Promise((resolve, reject) => {
    if (age >= 0) {
      resolve(age);
    } else {
      reject(new Error("negative age"));
    }
  });
}
```
항상 `Error` 객체로 거부하세요: `Error`는 `message`와 스택 트레이스를 담고 있지만, 문자열만으로는 그렇지 않습니다.

거부는 **`.catch(callback)`**으로 읽습니다. `.then`의 거울상입니다. **`Promise.reject(error)`**는 이미 거부된 프로미스를 만드는데, `Promise.resolve`가 이행된 프로미스를 만드는 것과 같습니다:
```javascript
readAge(-1).catch((error) => {
  console.log(error.message);
  // prints negative age
});
```
`resolve`와 `reject`를 둘 다 호출하거나 두 번 호출해도 아무 일도 일어나지 않습니다: 첫 번째 호출만 효과가 있습니다.

# --asserts--

`await checkAge(20)`은 `20`이어야 합니다

```javascript
(async () => {
  tryCatch((await checkAge(20)) === 20);
})().catch(() => tryCatch(false));
```

`await checkAge(18)`은 `18`이어야 합니다. `18`은 충분히 나이가 많기 때문입니다

```javascript
(async () => {
  tryCatch((await checkAge(18)) === 18);
})().catch(() => tryCatch(false));
```

`checkAge(10)`은 `"too young"`이라는 메시지로 거부되어야 합니다

```javascript
(async () => {
  let message = "";
  await checkAge(10).catch((error) => { message = error.message; });
  tryCatch(message === "too young");
})().catch(() => tryCatch(false));
```

`checkAge(0)`은 문자열이 아니라 `Error` 객체로 거부되어야 합니다

```javascript
(async () => {
  let reason = null;
  await checkAge(0).catch((error) => { reason = error; });
  tryCatch(reason instanceof Error);
})().catch(() => tryCatch(false));
```
