# --description--

객체 리터럴을 괄호로 감싸는 것은 한 줄짜리 화살표 함수로 객체를 만드는 표준적인 방법입니다. 예를 들어 몇 개의 값을 레코드로 바꿀 때 그렇습니다:
```javascript
const user = (name, age) => ({ name: name, age: age });
console.log(user("Ana", 30).age);
// prints 30
```
매개변수가 없는 화살표 함수는 빈 괄호 쌍 `()`으로 시작합니다:
```javascript
const empty = () => ({});
console.log(empty());
// prints {}
```
