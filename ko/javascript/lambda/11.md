# --description--

함수는 값이므로, 화살표 함수는 **다른 화살표 함수를 반환**할 수 있습니다. 두 화살표를 체이닝하는 것은 함수를 만들어 내는 함수를 간결하게 쓰는 방법입니다:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
왼쪽에서 오른쪽으로 읽어 보세요: `makeAdder`는 `amount`를 받아 `(n) => n + amount`, 즉 클로저를 통해 `amount`를 붙잡아 두는 화살표 함수를 반환합니다. `makeAdder(1)(5)`는 반환된 함수를 즉시 호출합니다.

# --asserts--

`makeMultiplier(3)`은 함수를 반환해야 합니다

```javascript
tryCatch(typeof makeMultiplier(3) === "function");
```

`makeMultiplier(3)(4)`는 `12`를 반환해야 합니다

```javascript
tryCatch(makeMultiplier(3)(4) === 12);
```

`makeMultiplier(2)`가 반환한 함수는 `10`으로 호출되었을 때 `20`을 반환해야 합니다

```javascript
tryCatch((() => { const twice = makeMultiplier(2); return twice(10) === 20; })());
```

두 곱셈 함수는 독립적이어야 합니다: `makeMultiplier(5)(2)`는 `10`이어야 하고 `makeMultiplier(0)(2)`는 `0`이어야 합니다

```javascript
tryCatch(makeMultiplier(5)(2) === 10 && makeMultiplier(0)(2) === 0);
```

`makeMultiplier`와 그것이 반환하는 함수는 둘 다 화살표 함수여야 합니다

```javascript
tryCatch(!/function/.test(makeMultiplier.toString()) && /=>/.test(makeMultiplier(3).toString()));
```
