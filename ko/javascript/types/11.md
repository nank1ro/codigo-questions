# --description--

모든 값을 불리언으로 변환하는 흔한 방법은 **이중 부정** `!!`입니다: 첫 번째 `!`는 불리언으로 변환한 뒤 뒤집고, 두 번째는 다시 뒤집습니다:
```javascript
console.log(!!"text", !!0);
// prints true false
```
`!!value`와 `Boolean(value)`는 정확히 같은 결과를 냅니다. 명시적인 형태가 읽기 더 쉽습니다.

# --instructions--

다음 코드의 출력 결과는 무엇입니까?
```javascript
console.log(!!"0", !!"", !![], Boolean(NaN));
```
