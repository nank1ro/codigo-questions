# --description--

`typeof`는 배열, 객체, `null`에 대해 `"object"`라고 답하므로, 이들을 구별하려면 두 가지 추가 검사가 필요합니다.
`Array.isArray(value)`는 배열에 대해서만 `true`입니다:
```javascript
console.log(Array.isArray([1, 2]), Array.isArray({}));
// prints true false
```
`null`에 대해서는 `value === null`처럼 직접 비교합니다. 이들을 결합하면 모든 값에 대한 완전한 그림이 됩니다:
```javascript
function kind(value) {
  if (value === null) return "null";
  if (Array.isArray(value)) return "array";
  return typeof value;
}
```
일반 `typeof`는 이들을 구별할 수 없으므로, `null`과 배열을 먼저 검사하세요.

# --asserts--

`typeName(null)`은 `"null"`을 반환해야 합니다

```javascript
tryCatch(typeName(null) === "null");
```

`typeName([1, 2])`와 `typeName([])`은 `"array"`를 반환해야 합니다

```javascript
tryCatch(typeName([1, 2]) === "array" && typeName([]) === "array");
```

`typeName({})`은 `"object"`를 반환해야 합니다

```javascript
tryCatch(typeName({}) === "object");
```

`typeName(42)`, `typeName("a")`, `typeName(true)`는 `"number"`, `"string"`, `"boolean"`을 반환해야 합니다

```javascript
tryCatch(typeName(42) === "number" && typeName("a") === "string" && typeName(true) === "boolean");
```

`typeName(undefined)`, `typeName(10n)`, `typeName(Symbol())`은 `"undefined"`, `"bigint"`, `"symbol"`을 반환해야 합니다

```javascript
tryCatch(typeName(undefined) === "undefined" && typeName(10n) === "bigint" && typeName(Symbol()) === "symbol");
```

`typeName(function () {})`은 `"function"`을 반환해야 합니다

```javascript
tryCatch(typeName(function () {}) === "function");
```

함수는 `Array.isArray`를 사용해야 합니다
