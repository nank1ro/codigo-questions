# --description--

문자열을 숫자로 변환하는 짧은 방법은 **단항 플러스**입니다: 단일 값 앞에 놓인 `+`는 `Number()`와 정확히 같게 변환합니다:
```javascript
console.log(+"5" + 5);
// prints 10
console.log(typeof +"5");
// prints number
```
간결하지만 덧셈과 혼동하기 쉬우므로, 많은 팀이 명시적인 `Number("5")`를 선호합니다.
