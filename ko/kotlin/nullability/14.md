# --description--

`null`이 호출자의 실수를 의미한다면, `requireNotNull`로 조기에 실패하세요.
값이 있으면 널이 아닌 값으로 반환하고, `null`이면 선택적인 메시지와 함께 `IllegalArgumentException`을 던집니다:
```kotlin
fun greet(name: String?): String {
    val safeName = requireNotNull(name) { "name is required" }
    return "Hello, $safeName"
}
greet(null) // IllegalArgumentException: name is required
```
호출 후에는 컴파일러가 `name` 자체를 `String`으로 스마트 캐스트하므로, 그 줄부터는 `name.length`가 허용됩니다.
`!!`와 달리, 실패는 명확한 메시지를 담고 *인자*가 잘못되었다고 알려 줍니다.

# --asserts--

`safeUpper("abc")`는 `"ABC"`를 반환해야 합니다

```kotlin
    tryCatch(safeUpper("abc") == "ABC")
```

`safeUpper("Kotlin")`은 `"KOTLIN"`을 반환해야 합니다

```kotlin
    tryCatch(safeUpper("Kotlin") == "KOTLIN")
```

`safeUpper(null)`은 `IllegalArgumentException`을 던져야 합니다

```kotlin
    var threw = false
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        threw = true
    }
    tryCatch(threw)
```

예외 메시지는 `text is required`여야 합니다

```kotlin
    var message = ""
    try {
        safeUpper(null)
    } catch (e: IllegalArgumentException) {
        message = e.message ?: ""
    }
    tryCatch(message == "text is required")
```
