# --description--

많은 표준 함수는 실패하는 대신 `null`을 반환합니다. `toIntOrNull()`은 문자열을 `Int`로 변환하고, 텍스트가 정수가 아니면 `null`을 반환합니다:
```kotlin
println("42".toIntOrNull())  // 42
println("4x2".toIntOrNull()) // null
```
`mapNotNull`은 `map`처럼 모든 요소를 변환하지만, `null`인 결과는 버립니다:
```kotlin
val words = listOf("1", "two", "3")
println(words.mapNotNull { it.toIntOrNull() }) // [1, 3]
```

# --instructions--

`tokens`에서 찾은 숫자를 같은 순서로 반환하고, 정수가 아닌 문자열은 무시하는 함수 `parseAll(tokens: List<String>): List<Int>`를 작성하세요.

예: `parseAll(listOf("1", "x", "3"))`은 `[1, 3]`을 반환합니다.

# --asserts--

`parseAll(listOf("1", "x", "3"))`은 `[1, 3]`을 반환해야 합니다

```kotlin
    tryCatch(parseAll(listOf("1", "x", "3")) == listOf(1, 3))
```

`parseAll(listOf("a", "b"))`는 빈 리스트를 반환해야 합니다

```kotlin
    tryCatch(parseAll(listOf("a", "b")) == listOf<Int>())
```

`parseAll(listOf("-4", "2.5", "10"))`은 `[-4, 10]`을 반환해야 합니다

```kotlin
    tryCatch(parseAll(listOf("-4", "2.5", "10")) == listOf(-4, 10))
```

`parseAll(listOf())`는 빈 리스트를 반환해야 합니다

```kotlin
    tryCatch(parseAll(listOf()) == listOf<Int>())
```

fun parseAll(tokens: List<String>): List<Int> {
    return tokens.mapNotNull { it.toIntOrNull() }
}
