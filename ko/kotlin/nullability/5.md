# --description--

안전 호출은 **연쇄**할 수 있습니다: 연쇄의 한 고리가 `null`이 되는 순간 나머지는 건너뛰어지고 전체 표현식은 `null`이 됩니다.
```kotlin
val text: String? = "  hi  "
println(text?.trim()?.uppercase())   // HI
val none: String? = null
println(none?.trim()?.uppercase())   // null, trim() and uppercase() never run
```
`?:`로 끝나는 연쇄는 한 줄에서 널이 아닌 결과를 줍니다:
```kotlin
val cleaned = text?.trim()?.uppercase() ?: ""
```

# --instructions--

양 끝의 공백을 제거한 `text`의 길이를 반환하고, `text`가 `null`이면 `-1`을 반환하는 함수 `trimmedLength(text: String?): Int`를 작성하세요.

예: `trimmedLength("  abc ")`는 `3`을 반환하고, `trimmedLength(null)`은 `-1`을 반환합니다.

# --asserts--

`trimmedLength("  abc ")`는 `3`을 반환해야 합니다

```kotlin

```

`trimmedLength(null)`은 `-1`을 반환해야 합니다

```kotlin
    tryCatch(trimmedLength(null) == -1)
```

`trimmedLength("   ")`는 `0`을 반환해야 합니다

```kotlin
    tryCatch(trimmedLength("   ") == 0)
```

`trimmedLength("kotlin")`은 `6`을 반환해야 합니다

```kotlin
    tryCatch(trimmedLength("kotlin") == 6)
```
