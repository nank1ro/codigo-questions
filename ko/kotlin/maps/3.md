# --description--

키가 없을 수도 있을 때, `getOrDefault`를 사용하면 `null` 대신 사용할 값을 선택할 수 있습니다:
```kotlin
val ages = mapOf("Alice" to 30)
println(ages.getOrDefault("Alice", 0)) // 30
println(ages.getOrDefault("Zoe", 0))   // 0
```
첫 번째 인자는 키이고, 두 번째 인자는 키를 찾지 못했을 때 반환되는 기본값입니다.
