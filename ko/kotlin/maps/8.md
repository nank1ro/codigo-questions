# --description--

`for`로 map을 순회하며 각 항목을 키와 값으로 구조 분해할 수 있습니다:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
괄호 `(name, age)`는 각 항목을 두 개의 변수로 나눕니다. 항목은 삽입된 순서대로 방문됩니다.

# --instructions--

`stock`의 각 항목마다 `"item: count"` 형식의 문자열을 하나씩 담은 리스트를, map에 나타나는 순서대로 반환하는 함수 `report(stock: Map<String, Int>): List<String>`를 작성하세요.

함수 호출 예시:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
