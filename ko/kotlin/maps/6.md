# --description--

키가 존재하는지 확인하려면 `containsKey`나 `in` 연산자를, 값이 존재하는지 확인하려면 `containsValue`를 사용합니다:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
println(ages.containsKey("Alice")) // true
println("Zoe" in ages)             // false
println(ages.containsValue(25))    // true
```

# --instructions--

사용자 이름과 이메일 주소를 매핑한 map이 주어졌을 때, 다음 두 함수를 작성하세요:
- `isRegistered(users: Map<String, String>, username: String): Boolean`은 `username`이 map의 키이면 `true`를 반환합니다
- `isEmailTaken(users: Map<String, String>, email: String): Boolean`은 `email`이 값 중 하나이면 `true`를 반환합니다

# --asserts--

`isRegistered`는 존재하는 사용자 이름에 대해 `true`를 반환해야 합니다

```kotlin
    val users = mapOf("ann" to "ann@mail.com", "ben" to "ben@mail.com")
    tryCatch(isRegistered(users, "ann") == true)
```

`isRegistered`는 존재하지 않는 사용자 이름에 대해 `false`를 반환해야 합니다

```kotlin

```

`isEmailTaken`은 이미 map에 있는 이메일에 대해 `true`를 반환해야 합니다

fun isRegistered(users: Map<String, String>, username: String): Boolean {
    return users.containsKey(username)
}

fun isEmailTaken(users: Map<String, String>, email: String): Boolean {
    return users.containsValue(email)
}
