# --description--

모든 배열에는 인덱스를 다루기 위한 두 가지 유용한 속성이 있습니다:
- `indices`는 `0`부터 마지막 인덱스까지, 유효한 인덱스의 범위입니다
- `lastIndex`는 마지막 요소의 인덱스, 즉 `size - 1`입니다
```kotlin
val letters = arrayOf("x", "y")
println(letters.lastIndex) // 1
for (i in letters.indices) {
    println(letters[i])
}
// prints x, then y
```
