# --description--

배열과 리스트는 서로 쉽게 변환됩니다:
- `toList()`와 `toMutableList()`는 배열을 리스트로 복사합니다
- `toTypedArray()`는 리스트를 `Array<T>`로 복사합니다
- `toIntArray()`는 `Int` 리스트를 `IntArray`로 복사합니다
```kotlin
val arr = arrayOf("a", "b")
val list = arr.toMutableList() // MutableList [a, b]
list.add("c")
val back = list.toTypedArray() // Array [a, b, c]
val nums = listOf(1, 2).toIntArray() // IntArray [1, 2]
```
모든 변환은 **복사본**을 만들기 때문에, 결과를 변경해도 원본에는 영향이 없습니다.

# --instructions--

`items`의 모든 요소 뒤에 `item`을 이어붙인 **새로운** 배열을 반환하는 함수 `appendItem(items: Array<String>, item: String): Array<String>`을 작성하세요. 원본 배열은 변경되지 않아야 합니다.

예: `appendItem(arrayOf("a"), "b")`는 `["a", "b"]`를 반환합니다.

# --solutions--

```kotlin
fun appendItem(items: Array<String>, item: String): Array<String> {
    val list = items.toMutableList()
    list.add(item)
    return list.toTypedArray()
}
```
