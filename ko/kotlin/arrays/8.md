# --description--

숫자 배열에는 집계 함수가 함께 제공됩니다:
```kotlin
val nums = intArrayOf(3, 9, 1)
println(nums.sum())     // 13
println(nums.max())     // 9
println(nums.min())     // 1
println(nums.average()) // 4.333333333333333
println(nums.count())   // 3
```
`max()`와 `min()`은 빈 배열에서 예외를 던지므로, 배열이 비어 있을 수 있다면 `maxOrNull()`과 `minOrNull()`을 사용하세요.

# --instructions--

`numbers`의 가장 큰 요소와 가장 작은 요소의 차이를 반환하는 함수 `range(numbers: IntArray): Int`를 작성하세요. 배열은 절대 비어 있지 않다고 가정해도 됩니다.

예: `range(intArrayOf(3, 9, 1))`은 `8`을 반환합니다.
