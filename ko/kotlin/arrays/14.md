# --description--

배열은 크기가 고정되어 있으므로, 일부를 가져오려면 새로운 배열을 만들어야 합니다:
- `copyOf()`는 배열 전체를 복사하고, `copyOf(n)`은 처음 `n`개의 요소를 복사합니다
- `copyOfRange(from, to)`는 인덱스 `from`부터 `to` **직전까지**의 요소를 복사합니다
- `sliceArray(range)`는 범위의 양 끝을 포함한 인덱스의 요소를 복사합니다
```kotlin
val nums = intArrayOf(10, 20, 30, 40)
println(nums.copyOfRange(1, 3).contentToString()) // [20, 30]
println(nums.sliceArray(0..1).contentToString())  // [10, 20]
```

# --instructions--

`numbers`의 앞쪽 절반을 담은 새로운 배열을 반환하는 함수 `firstHalf(numbers: IntArray): IntArray`를 작성하세요. 크기가 홀수이면 가운데 요소는 제외합니다.

예: `firstHalf(intArrayOf(1, 2, 3, 4, 5))`는 `[1, 2]`를 반환합니다.


`firstHalf(intArrayOf(1, 2, 3, 4, 5))`는 `[1, 2]`를 반환해야 합니다

```kotlin

```

`firstHalf(intArrayOf(7))`은 빈 배열을 반환해야 합니다

```kotlin
    tryCatch(firstHalf(intArrayOf(7)).size == 0)
```

원본 배열은 수정되면 안 됩니다

```kotlin
    val src = intArrayOf(5, 6, 7, 8)
    firstHalf(src)

```
