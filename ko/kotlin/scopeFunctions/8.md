# --description--

블록이 객체를 다른 것의 **인자**로 필요로 할 때는 `apply`보다 `also`가 더 자연스럽게 읽힙니다: `it`은 곧바로 넘겨줄 수 있지만, `this`는 직접 써 주어야 합니다.
```kotlin
val names = mutableListOf<String>()
val user = "ada".also { names.add(it) }
println(user)  // ada
println(names) // [ada]
```
표현식의 값은 여전히 `"ada"`입니다: `also`는 그 값이 지나가는 것을 지켜볼 뿐입니다.

# --instructions--

최상위 레벨에 `val log = mutableListOf<String>()`를 선언하세요.

그다음 `word`를 대문자로 변환해 반환하고, `also`로 반환하기 전에 같은 대문자 값을 `log`에 추가하는 함수 `record(word: String): String`를 작성하세요.

예: `record("hi")` 후에 함수는 `HI`를 반환하고 `log`에는 `HI`가 들어 있습니다.

# --asserts--

`log`는 비어 있는 상태로 시작해야 합니다

```kotlin

```

`record("hi")`는 `HI`를 반환해야 합니다

```kotlin
    tryCatch(record("hi") == "HI")
```

첫 번째 호출 후 `log`에는 `HI`만 들어 있어야 합니다

```kotlin
    tryCatch(log == listOf("HI"))
```

두 번째 호출은 첫 번째 값을 잃지 않고 `log`에 추가해야 합니다

```kotlin
    record("bye")
    tryCatch(log == listOf("HI", "BYE"))
```
