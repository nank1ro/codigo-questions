# --description--

`with`는 `run`과 같은 일을 하지만 **확장 함수가 아닙니다**: 객체가 점 호출의 리시버가 아니라 첫 번째 인자로 전달됩니다.
```kotlin
val text = with(StringBuilder()) {
    append("Hello")
    append(", world")
    toString()
}
println(text) // Hello, world
```
블록 안에서 객체는 `this`이고 호출은 마지막 표현식을 반환하며, 이는 `run`과 정확히 같습니다. 널이 아닌 객체를 이미 가지고 있고 그 객체에 대한 여러 호출을 묶고 싶을 때는 `with`를, 객체가 체인에서 나오거나 안전 호출이 필요할 수 있을 때는 (`obj?.run { ... }`) `run`을 선택하세요.

이 프로그램은 무엇을 출력하나요?

```kotlin
class Point(val x: Int, val y: Int)

fun main() {
    val point = Point(2, 5)
    val result = with(point) {
        x + y
    }
    println(result)
}
```

# --answers--

- `with`가 자신의 블록의 마지막 표현식의 결과를 반환하므로 `7`
- `with`가 객체의 첫 번째 프로퍼티를 반환하므로 `2`
- `with`가 받은 객체를 반환하므로 객체 `point`
- 아무것도 출력하지 않습니다: 컴파일되지 않습니다. `with`는 `point.with { ... }`로 호출해야 합니다
