# --instructions--

이 프로그램은 무엇을 출력하나요?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `apply`는 리스트를 반환하고 `run`은 블록의 결과를 반환하므로 `[a, b] 2`
- `apply`가 `add`의 결과를 반환하므로 `true 2`
- 둘 다 리스트를 반환하므로 `[a, b] [a, b]`
- `apply`는 크기를 반환하고 `run`은 리스트를 반환하므로 `2 [a, b]`
