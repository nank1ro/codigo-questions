# --description--

`uppercase()`는 문자열의 모든 글자를 대문자로 바꾼 사본을 반환하고, `lowercase()`는 그 반대의 일을 합니다.
원본 문자열은 변경되지 않습니다:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
