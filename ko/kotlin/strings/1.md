# --description--

`String`은 큰따옴표로 둘러싸서 작성하는 문자의 나열입니다.
`length` 프로퍼티는 공백을 포함해 문자열에 몇 개의 문자가 들어 있는지 알려줍니다:
```kotlin
val greeting = "Hello world"
println(greeting.length) // 11
println("".length)       // 0
```
