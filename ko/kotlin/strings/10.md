# --description--

`replace(old, new)`는 `old`가 나타나는 **모든** 부분을 `new`로 바꾼 사본을 반환합니다:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
