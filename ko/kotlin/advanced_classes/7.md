# --description--

때로는 로거, 레지스트리, 애플리케이션 설정처럼 어떤 것의 **정확히 하나의** 인스턴스가 필요합니다. `class`를 `object`로 바꾸면 해당 싱글턴을 선언해 줍니다:

```kotlin
object Registry {
    var size = 0
    fun add() {
        size++
    }
}

Registry.add()
println(Registry.size) // 1
```

인스턴스는 처음 접근할 때 생성되며, 이름 자체를 사용합니다. `Registry()` 호출도 없고 생성자도 없습니다. `object`는 프로퍼티, 메서드, `init` 블록을 가질 수 있고, 인터페이스를 구현하거나 클래스를 확장할 수도 있습니다.

# --instructions--

`Int` 타입의 `var` 프로퍼티 `count`가 `0`으로 초기화된 `Logger`라는 이름의 `object`를 선언하고, `count`에 `1`을 더하고 새 count가 접두사로 붙은 메시지를 `"[1] hello"` 형태로 반환하는 메서드 `log(message: String): String`를 작성하세요.

# --asserts--

`Logger.count`는 `0`으로 시작해야 합니다

```kotlin
    tryCatch(Logger.count == 0)
```

첫 번째 호출은 `"[1] hello"`를 반환해야 합니다

```kotlin
    tryCatch(Logger.log("hello") == "[1] hello")
```

상태가 공유되므로 두 번째 호출은 `"[2] bye"`를 반환해야 합니다

```kotlin
    tryCatch(Logger.log("bye") == "[2] bye")
```

두 호출 후 `Logger.count`는 `2`여야 합니다

```kotlin
    tryCatch(Logger.count == 2)
```

object Logger {

    }
