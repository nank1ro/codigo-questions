# --instructions--

이 프로그램에서는 어떤 일이 발생합니까?

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- `moving`을 출력합니다, `Robot`이 기본 구현을 상속하기 때문입니다
- 컴파일되지 않습니다: `Robot`은 `move()`를 재정의해야 합니다
- 컴파일되지 않습니다: 인터페이스는 함수 본문을 포함할 수 없습니다
- `null`을 출력합니다
