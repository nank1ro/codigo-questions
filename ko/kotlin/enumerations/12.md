# --instructions--

`enum class Size { SMALL, MEDIUM, LARGE }`가 주어졌을 때, 다음 코드는 어떻게 될까요?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- 컴파일되지 않습니다: enum에 대한 `when` 표현식은 모든 항목을 다루거나 `else` 분기를 추가해야 합니다
- 컴파일되고 `LARGE`에 대해 `null`을 반환합니다
- 컴파일되고 `LARGE`에 대해 런타임에 예외를 던집니다
- 컴파일되고 `LARGE`에 대해 자동으로 `"L"`을 반환합니다
