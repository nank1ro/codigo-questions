# --description--

`String`에서 다시 항목으로 되돌리려면 `valueOf` 함수를 사용합니다. 이 함수는 `name`이 정확히 일치하는 항목을 찾습니다:
```kotlin
val direction = Direction.valueOf("EAST")
println(direction == Direction.EAST) // true
```
이 비교는 대소문자를 구분합니다. `Direction.valueOf("east")`는 그런 이름을 가진 항목이 없기 때문에 `IllegalArgumentException`을 던집니다.

# --instructions--

`ACTIVE`와 `INACTIVE` 항목을 가진 enum 클래스 `Status`를 선언하세요. 그런 다음, 대소문자와 상관없이 `text`와 일치하는 `Status`를 반환하는 함수 `statusOf(text: String)`을 작성하세요(`"active"`, `"Active"`, `"ACTIVE"` 모두 `Status.ACTIVE`가 되어야 합니다).

enum class Status {
    ACTIVE, INACTIVE
}

fun statusOf(text: String): Status {
    return Status.valueOf(text.uppercase())
}
