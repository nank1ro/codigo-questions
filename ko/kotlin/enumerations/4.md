# --description--

enum 클래스는 일반 클래스와 마찬가지로 **생성자**를 가질 수 있습니다. 각 항목은 자신만의 인자를 전달하고, 그 값들은 프로퍼티에 저장됩니다:
```kotlin
enum class Planet(val moons: Int) {
    MERCURY(0),
    EARTH(1),
    MARS(2)
}
println(Planet.MARS.moons) // 2
```
항목의 데이터는 보통 바뀌지 않기 때문에, 생성자 프로퍼티는 대개 `val`로 선언합니다.
