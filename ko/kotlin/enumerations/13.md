# --instructions--

`enum class Color { RED, GREEN, BLUE }`가 주어졌을 때, `Color.valueOf("PURPLE")`은 어떻게 될까요?

# --answers--

- `PURPLE`이라는 이름의 항목이 없기 때문에 `IllegalArgumentException`을 던집니다
- `null`을 반환합니다
- 첫 번째 항목인 `Color.RED`를 반환합니다
- enum에 새로운 `PURPLE` 항목을 추가합니다
