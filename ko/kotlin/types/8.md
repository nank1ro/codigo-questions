# --description--

`Char`의 코드는 `Int`이므로, 코드에 산술 연산을 하고 그 결과를 다시 `Char`로 변환할 수 있습니다. 알파벳을 따라 이동하는 방법은 다음과 같습니다:
```kotlin
val next = ('a'.code + 1).toChar() // 'b'
```
Kotlin에서는 `Int`를 `Char`에 직접 더할 수도 있습니다: `'a' + 1`은 `'b'`이고, 두 문자의 차이 `'d' - 'a'`는 `Int`인 `3`입니다.
