# --description--

`try`가 어디에 놓이는지에 따라 하나의 나쁜 값이 얼마나 많은 작업을 파괴하는지 결정됩니다. **루프 전체**를 감싸면 첫 번째 실패가 나머지 일괄 작업을 포기하고, **본문**을 감싸면 그 한 요소만 잃습니다:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // 이 값은 건너뜁니다
    }
}
println(total) // 8
```
이것은 던지는 검증 함수와 자연스럽게 짝을 이룹니다: 함수는 하나의 규칙을 명시하고 그 규칙을 깨는 것은 무엇이든 거절하며, 루프는 거절이 한 요소의 비용만 치른다고 결정합니다.

# --instructions--

두 개의 함수를 작성하세요.

`validate(text: String): Int`는 `text`에 담긴 숫자를 반환하거나, `not a number: ` 뒤에 그 텍스트가 붙은 메시지와 함께 `IllegalArgumentException`을 던져야 합니다.

`sumValid(values: List<String>): Int`는 `validate`가 받아들이는 값들을 더하고, 예외를 던지게 만드는 값들은 건너뛰어야 합니다.

함수 호출 예시:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// 4를 출력합니다
```

`validate("7")`는 `7`을 반환해야 합니다

```kotlin

```

`validate("x")`는 `not a number: x`라는 메시지와 함께 `IllegalArgumentException`을 던져야 합니다

```kotlin
    var message = ""
    try { validate("x") } catch (e: IllegalArgumentException) { message = e.message ?: "" }
    tryCatch(message == "not a number: x")
```

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // 이 값은 건너뜁니다
        }
    }
    return total
}
```
