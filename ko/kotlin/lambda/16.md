# --description--

일부 함수는 **수신 객체가 있는 람다**를 받습니다: 람다 안에서 `this`는 특정 객체이므로, 객체 이름을 붙이지 않고 바로 그 멤버를 호출할 수 있습니다.
`buildString`이 대표적인 예입니다: 그 람다 안에서 `this`는 `StringBuilder`이므로, `append`를 로컬 함수처럼 호출할 수 있습니다:
```kotlin
val text = buildString {
    append("Hello")
    append(", ")
    append("world")
}
println(text) // Hello, world
```
`buildString`은 최종 문자열을 반환합니다. 반복문에서 `+`로 이어 붙이는 것을 편리하게 대신하는 방법입니다.

# --instructions--

`buildString`을 사용하여 모든 항목을 대괄호로 감싸 하나씩 이어 붙인 문자열을 반환하는 함수 `bracketed(items: List<String>): String`을 작성하세요.

예: `bracketed(listOf("a", "b"))`는 `"[a][b]"`를 반환합니다.

# --asserts--

`bracketed(listOf("a", "b"))`는 `"[a][b]"`를 반환해야 합니다

```kotlin
    tryCatch(bracketed(listOf("a", "b")) == "[a][b]")
```

`bracketed(listOf("kotlin"))`는 `"[kotlin]"`를 반환해야 합니다

```kotlin
    tryCatch(bracketed(listOf("kotlin")) == "[kotlin]")
```

`bracketed(listOf())`는 빈 문자열을 반환해야 합니다

```kotlin
    tryCatch(bracketed(listOf()) == "")
```

`bracketed(listOf("x", "y", "z"))`는 `"[x][y][z]"`를 반환해야 합니다

```kotlin
    tryCatch(bracketed(listOf("x", "y", "z")) == "[x][y][z]")
```

```kotlin
fun bracketed(items: List<String>): String {
    return buildString {
        items.forEach { append("[").append(it).append("]") }
    }
}
```
