# --description--

`%x`는 정수를 소문자 16진수로 출력하고, `%X`는 같은 일을 대문자로 합니다. `%c`는 정수 문자 코드를 받아 그 코드가 나타내는 문자를 출력하므로, `65`와 함께 쓴 `%c`는 `A`를 출력합니다:
```c
printf("%x %X %c\n", 31, 31, 66); // prints "1f 1F B"
```

# --instructions--

다음 코드의 출력은 무엇인가요?
```c
printf("%x %X %c\n", 255, 255, 65);
```
