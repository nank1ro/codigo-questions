C는 **정적 타입** 언어입니다: 모든 변수는 타입과 함께 선언되며, 이 타입이 저장할 수 있는 값의 종류와 사용하는 메모리 양을 결정합니다.
가장 많이 사용하는 세 가지 타입은 다음과 같습니다:
- `int` : `30`이나 `-4`처럼 정수
- `double` : `1.75`처럼 소수 부분이 있는 수
- `char` : `'A'`처럼 작은따옴표로 감싼 문자 하나

각 타입에는 고유한 `printf` **서식 지정자**가 있습니다: `%d`는 `int`를, `%f`는 `double`을(기본적으로 소수점 이하 6자리), `%c`는 `char`를 출력합니다:
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// "30 1.750000 A" 출력
```
타입에 맞지 않는 지정자를 사용하면 이상한 값이 출력되므로 항상 맞춰서 사용하세요.

---

C에는 두 가지 부동소수점 타입이 있습니다: `float`(단정밀도, 유효 자릿수 약 7자리)와 `double`(배정밀도, 유효 자릿수 약 15자리)입니다.
`1.75`처럼 소수 리터럴은 `double`입니다. `float` 리터럴을 쓰려면 `1.75f`처럼 `f` 접미사를 붙입니다.
메모리가 부족한 경우가 아니라면 `double`을 사용하는 것이 좋습니다: 기본 타입이면서 더 정밀하기 때문입니다.
```c
double pi = 3.14159;
float ratio = 0.5f;
```
소수 결과를 반환하는 함수는 반환 타입으로 `double`을 선언해야 하며, `double` 매개변수는 정수와 소수 인자를 모두 받을 수 있습니다:
```c
double half(double x) {
    return x / 2;
}
```

---

`%f`는 소수점 이하 6자리를 출력하지만, 그것을 원하는 경우는 거의 없습니다. `%`와 `f` 사이에 정밀도를 넣으면 표시할 소수 자릿수를 정할 수 있습니다: `%.2f`는 소수점 이하 2자리, `%.1f`는 1자리를 출력하며, 값은 자르는 것이 아니라 **반올림**됩니다:
```c
double price = 9.987;
printf("%.2f\n", price); // "9.99" 출력
printf("%.1f\n", price); // "10.0" 출력
```
`float`도 `double`과 같은 지정자로 출력됩니다: `printf`에 전달될 때 자동으로 `double`로 변환되기 때문입니다.

---

`/`의 결과는 피연산자의 타입에 따라 달라집니다.
**두** 피연산자가 모두 정수이면 결과는 정수가 되고 소수 부분은 버려집니다: `7 / 2`는 `3.5`가 아니라 `3`입니다.
**적어도 하나**가 부동소수점 값이면 나눗셈은 소수 부분을 유지합니다: `7 / 2.0`은 `3.5`입니다.
```c
printf("%d\n", 7 / 2);     // "3" 출력
printf("%f\n", 7 / 2.0);   // "3.500000" 출력
```
리터럴을 `2` 대신 `2.0`으로 쓰는 것이 부동소수점 나눗셈을 강제하는 가장 간단한 방법입니다.

---

C는 값을 다른 타입의 변수에 대입할 때 숫자 타입을 **암묵적으로** 변환합니다.
- `int`가 `double`에 저장되면 손실 없이 확장됩니다: `double d = 3;`은 `d`를 `3.0`으로 만듭니다
- `double`이 `int`에 저장되면 **잘립니다**: `int n = 3.99;`는 `n`을 `3`으로 만듭니다(컴파일러가 보통 이를 경고합니다)

변환은 대입이 일어나는 순간에만 발생합니다. 오른쪽 표현식은 먼저 자신의 타입으로 계산됩니다:
```c
double d = 7 / 2;
```
여기서 `7 / 2`는 정수 나눗셈으로 `3`이 되고, 그 다음에야 `3`이 `3.0`으로 변환됩니다.

---

암묵적 변환이 원하는 대로 되지 않거나, 변환을 명시적으로 드러내고 싶다면 **명시적 캐스트**를 사용하세요: 값 앞에 괄호로 대상 타입을 적습니다.
```c
double x = 3.99;
int n = (int) x;   // n은 3
```
부동소수점 값을 `int`로 캐스팅하면 **0 방향으로 잘립니다**: `(int) 3.99`는 `3`, `(int) -2.5`는 `-2`가 되며, 반올림은 일어나지 않습니다.
캐스트는 바로 뒤에 오는 값에만 적용되므로, `(int) x * 2`는 먼저 `x`를 캐스팅한 다음 곱셈을 합니다.

---

두 `int` 변수로부터 부동소수점 나눗셈을 얻는 표준적인 방법은 캐스트입니다: 나누기 전에 **한 피연산자**를 `double`로 캐스팅하세요.
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
`(double) (total / count)`처럼 결과 전체를 캐스팅하는 것은 흔한 실수입니다: 그 시점에는 이미 정수 나눗셈이 일어나 소수 부분이 사라진 뒤이기 때문입니다.

---

`char`는 사실 작은 정수입니다: 문자의 **ASCII 코드**를 저장합니다.
`'A'`는 `65`, `'a'`는 `97`, `'0'`은 `48`이며, 연속된 문자는 연속된 코드를 가집니다.
그래서 문자에 대해 산술 연산을 할 수 있습니다:
- `'a' + 1`은 `98`, 즉 `'b'`의 코드입니다
- `'7' - '0'`은 `55 - 48`, 즉 숫자 `7`입니다

같은 값을 `%c`로 문자로, `%d`로 숫자로 출력할 수 있습니다:
```c
char c = 'A';
printf("%c %d\n", c, c); // "A 65" 출력
```

---

대문자와 소문자는 ASCII 표에서 `32`만큼 떨어져 있습니다: `'A'`는 `65`이고 `'a'`는 `97`입니다.
따라서 소문자에서 `32`를 빼면 그 대문자 버전이 되며, 결과는 다시 `char`에 저장할 수 있습니다:
```c
char upper = 'g' - 32; // 'G'
```

---

`int`만이 정수 타입은 아닙니다. 수정자는 크기와 범위를 바꿉니다:
- `short`는 메모리를 덜 사용하고 범위도 더 작습니다(보통 -32768에서 32767까지)
- `long`은 더 큰 범위를 가집니다(64비트 시스템에서 약 ±900경)
- `unsigned`는 부호를 없앱니다: `unsigned int`는 `0`부터 약 40억까지지만, 절대 음수가 될 수 없습니다

`long`이어야 하는 리터럴에는 `L` 접미사를, `unsigned`에는 `U` 접미사를 붙이며, 각 타입에는 고유한 지정자가 있습니다:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" 출력
```
`%ld`는 `long`을, `%u`는 `unsigned int`를, `%lu`는 `unsigned long`을 출력합니다. 대부분의 시스템에서 일반 `int`는 약 20억까지의 값만 담을 수 있으므로, `5000000000`은 그 안에 들어가지 않습니다.

---

`sizeof` 연산자는 타입이나 변수가 몇 **바이트**를 차지하는지 알려줍니다. 그 결과는 `size_t` 타입이며, `%zu`로 출력됩니다:
```c
printf("%zu\n", sizeof(int));  // 대부분의 시스템에서 "4" 출력
```
표준이 보장하는 것은 `sizeof(char)`가 `1`이라는 것과 `short <= int <= long`뿐이지만, 일반적인 64비트 시스템의 크기는 다음과 같습니다: `char`는 1, `short`는 2, `int`는 4, `long`은 8, `float`는 4, `double`은 8입니다.
`sizeof`는 숫자를 하드코딩하지 않고 변수가 차지하는 메모리를 확인하는 데 자주 사용됩니다.

---

모든 정수 타입에는 제한된 범위가 있으며, `limits.h` 헤더는 그 한계에 이름을 붙여줍니다: `int`의 `INT_MAX`와 `INT_MIN`, `long`의 `LONG_MAX`, `unsigned int`의 `UINT_MAX` 등입니다.
```c
#include <limits.h>

printf("%d\n", INT_MAX); // 대부분의 시스템에서 "2147483647" 출력
```
부호 있는 타입에서 `INT_MAX`를 넘어서는 것은 **정의되지 않은 동작**입니다: 프로그램이 값을 감싸거나, 충돌하거나, 그 외 무엇이든 할 수 있습니다. 계산하기 전에 확인하세요:
```c
if (a <= INT_MAX - b) { /* a + b는 안전함 */ }
```
이 검사가 더하기 대신 빼기를 사용한다는 점에 주의하세요. `a + b` 자체가 이미 오버플로될 수 있기 때문입니다.

---

부호 있는 타입과 달리, **부호 없는** 산술은 범위를 벗어났을 때의 동작이 명확히 정의되어 있습니다: 값은 주행 거리계처럼 **랩어라운드(감싸돌기)**됩니다.
`UINT_MAX`에 `1`을 더하면 `0`이 되고, `0`에서 `1`을 빼면 `UINT_MAX`(`unsigned int`가 32비트일 때 `4294967295`)가 됩니다:
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // "0" 출력
```
이것이 `unsigned` 변수를 "음수가 될 때까지" 감소시키는 반복문이 절대 멈추지 않는 이유입니다: 부호 없는 값은 절대 `0`보다 작아지지 않기 때문입니다.

---

C99부터 헤더 `stdbool.h`는 상수 `true`(`1`)와 `false`(`0`)를 가진 `bool` 타입을 제공합니다.
`bool`은 값이 두 개뿐인 정수 타입이므로, 어떤 수를 `bool`로 변환해도 0이 아닌 값은 모두 `true`가 되고 `0`은 `false`가 됩니다. 이는 `int`로 변환하는 것과 다릅니다:
```c
#include <stdbool.h>

bool b = 0.5;  // true, 0.5는 0이 아니므로
int n = 0.5;   // 0, 소수 부분이 잘리므로
```
`x != 0`과 같은 비교는 이미 `bool`과 호환되는 결과를 만들며, `bool`을 반환하는 함수는 그것이 예/아니오 질문에 답한다는 것을 나타냅니다.

---

산술 연산은 결과를 받는 변수의 타입이 아니라, **그 피연산자의 타입**으로 수행됩니다.
그래서 `int`인 `n`에 대해 `long big = n * n;`이라고 쓰면 두 `int` 값을 곱하고, 곱이 너무 크면 오버플로가 발생한 다음, 그제야 (이미 잘못된) 결과를 `long`에 저장합니다.
더 넓은 타입으로 계산하려면 연산 **전에** 한 피연산자를 캐스팅하세요:
```c
int n = 100000;
long big = (long) n * n; // long으로 계산되어 10000000000이 됨
```
같은 규칙이 `(double) total / count`가 동작하는 이유를 설명합니다: 캐스트가 피연산자의 타입을 바꾸고, 그 뒤에 나눗셈이 이어지기 때문입니다.

---

종합하기: 값의 종류에 따라 타입을 선택하고, 모든 `printf` 지정자를 그 인자의 타입에 맞추며, 계산이 피연산자와 다른 타입으로 이루어져야 할 때 캐스팅하세요.
