# --description--

대문자와 소문자는 ASCII 표에서 `32`만큼 떨어져 있습니다: `'A'`는 `65`이고 `'a'`는 `97`입니다.
따라서 소문자에서 `32`를 빼면 그 대문자 버전이 되며, 결과는 다시 `char`에 저장할 수 있습니다:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

문자 `'a'`를 `letter`에 저장하고, 그 대문자 버전을 `upper`에 계산한 다음, 각각을 문자와 그 코드로 출력하도록(`letter`를 먼저) 줄을 정렬하세요

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
