# --description--

`int`만이 정수 타입은 아닙니다. 수정자는 크기와 범위를 바꿉니다:
- `short`는 메모리를 덜 사용하고 범위도 더 작습니다(보통 -32768에서 32767까지)
- `long`은 더 큰 범위를 가집니다(64비트 시스템에서 약 ±900경)
- `unsigned`는 부호를 없앱니다: `unsigned int`는 `0`부터 약 40억까지지만, 절대 음수가 될 수 없습니다

`long`이어야 하는 리터럴에는 `L` 접미사를, `unsigned`에는 `U` 접미사를 붙이며, 각 타입에는 고유한 지정자가 있습니다:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" 출력
```
`%ld`는 `long`을, `%u`는 `unsigned int`를, `%lu`는 `unsigned long`을 출력합니다. 대부분의 시스템에서 일반 `int`는 약 20억까지의 값만 담을 수 있으므로, `5000000000`은 그 안에 들어가지 않습니다.
