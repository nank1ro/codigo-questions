# --description--

지역 변수로 선언된 노드는 함수가 반환되면 사라지므로, 리스트는 `stdlib.h`의 `malloc`으로 **힙** 위에 만듭니다. `malloc`은 요청한 바이트 수를 확보하고 그 주소를 반환하며, 메모리가 부족하면 `NULL`을 반환합니다. `sizeof(Node)`는 노드 하나에 필요한 정확한 크기입니다:
```c
Node *node = malloc(sizeof(Node));
node->value = 5;
node->next = NULL;
```
힙 메모리는 저절로 해제되지 않습니다: `malloc`으로 얻은 모든 노드는 더 이상 필요하지 않게 되면 `free(node)`로 돌려주어야 합니다. 이 연습들에서는 `stdlib.h`가 포함되어 있고 `Node`가 여러분의 코드 위쪽에서 선언되어 있습니다.

# --asserts--

`make_node(5)`는 `value`가 `5`인 노드를 반환해야 한다

```c
    Node *n1 = make_node(5);
    try_catch(n1 != NULL && n1->value == 5);

```

새 노드의 `next`는 `NULL`이어야 한다

```c
    Node *n2 = make_node(0);

```

두 번의 호출은 서로 다른 두 노드를 반환해야 한다

```c
    Node *n3 = make_node(1);
    Node *n4 = make_node(2);
```
