# --description--

**뒤쪽**에 노드를 추가하려면 마지막 노드, 즉 `next`가 `NULL`인 노드가 필요합니다. 함수는 그 노드를 찾을 때까지 걸어간 뒤, 그곳에 새 노드를 붙이고 변경되지 않은 헤드를 반환합니다:
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
리스트가 비어 있으면 걸어갈 마지막 노드가 없습니다: 새 노드가 그저 헤드로 반환됩니다.

# --solutions--

```c
#include <stdio.h>
#include <stdlib.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *push_back(Node *head, int value) {
    Node *node = malloc(sizeof(Node));
    node->value = value;
    node->next = NULL;
    if (head == NULL) {
        return node;
    }
    Node *last = head;
    while (last->next != NULL) {
        last = last->next;
    }
    last->next = node;
    return head;
}
int main() {
    Node *head = NULL;
    head = push_back(head, 1);
    head = push_back(head, 2);
    head = push_back(head, 3);
    for (Node *n = head; n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}
```
