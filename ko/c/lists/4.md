# --description--

리스트를 걸어가는 것, 즉 **순회**는 헤드에서 시작하여 `NULL`에 도달할 때까지 `next`를 따라가는 반복문입니다. `for` 반복문은 반복 변수로 포인터를 사용하여 이것을 한 줄로 표현합니다:
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
인덱스는 없습니다: 노드에 도달하는 유일한 방법은 바로 앞 노드에 저장된 포인터를 통하는 것입니다.
