**연결 리스트**는 메모리 곳곳에 흩어진 개별 **노드**들에 값을 저장합니다: 각 노드는 값과 다음 노드에 대한 포인터를 담고 있으며, 마지막 노드는 `NULL`을 가리킵니다. 그 안의 포인터는 선언 중인 타입 자체를 참조하므로, 구조체는 자기 자신을 이름으로 부르기 위한 **태그**가 필요합니다. 중괄호 안에서는 `typedef` 이름이 아직 존재하지 않습니다:
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
노드는 한 노드의 주소를 다른 노드의 `next`에 저장하여 연결하며, 포인터가 가리키는 노드의 멤버는 화살표로 접근합니다:
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```

---

지역 변수로 선언된 노드는 함수가 반환되면 사라지므로, 리스트는 `stdlib.h`의 `malloc`으로 **힙** 위에 만듭니다. `malloc`은 요청한 바이트 수를 확보하고 그 주소를 반환하며, 메모리가 부족하면 `NULL`을 반환합니다. `sizeof(Node)`는 노드 하나에 필요한 정확한 크기입니다:
```c
Node *node = malloc(sizeof(Node));
node->value = 5;
node->next = NULL;
```
힙 메모리는 저절로 해제되지 않습니다: `malloc`으로 얻은 모든 노드는 더 이상 필요하지 않게 되면 `free(node)`로 돌려주어야 합니다. 이 연습들에서는 `stdlib.h`가 포함되어 있고 `Node`가 여러분의 코드 위쪽에서 선언되어 있습니다.

---

리스트는 첫 번째 노드를 가리키는 하나의 포인터, 즉 **헤드**로 유지됩니다. 나머지 노드들은 헤드에서 `next`를 따라가면 도달할 수 있고, 화살표는 연쇄적으로 쓸 수 있습니다: `head->next`는 두 번째 노드이고 `head->next->next`는 세 번째 노드입니다. 빈 리스트는 `NULL`과 같은 헤드이며, 마지막 노드의 `next`도 `NULL`이므로 화살표를 한 번 더 따라가면 `NULL`을 역참조하여 프로그램이 강제 종료됩니다.

---

리스트를 걸어가는 것, 즉 **순회**는 헤드에서 시작하여 `NULL`에 도달할 때까지 `next`를 따라가는 반복문입니다. `for` 반복문은 반복 변수로 포인터를 사용하여 이것을 한 줄로 표현합니다:
```c
for (Node *n = head; n != NULL; n = n->next) {
    printf("%d\n", n->value);
}
```
인덱스는 없습니다: 노드에 도달하는 유일한 방법은 바로 앞 노드에 저장된 포인터를 통하는 것입니다.

---

**앞쪽**에 노드를 추가하는 것은 노드를 만들고, 현재 헤드를 가리키게 한 뒤, 새 헤드로 반환합니다. 호출자는 그 결과를 자신의 헤드 변수에 다시 저장합니다:
```c
Node *head = NULL;
head = push_front(head, 7);
head = push_front(head, 8); // the list is now 8, 7
```
빈 리스트에 추가하는 것도 같은 방식으로 동작합니다: 새 노드는 `NULL`을 가리키고 리스트 전체가 됩니다.

---

리스트를 해제한다는 것은 모든 노드를 순회하며 한 번에 하나씩 해제하는 것입니다. `next` 포인터는 노드를 해제하기 **전에** 저장해야 합니다. 해제된 노드는 `next`조차 더 이상 읽어서는 안 되기 때문입니다:
```c
while (head != NULL) {
    Node *next = head->next;
    free(head);
    head = next;
}
```
`free(head)`를 쓰고 나서 `head = head->next`를 쓰면 방금 해제된 메모리를 읽는 것이며, 이것은 정의되지 않은 동작입니다. `free(NULL)`은 허용되고 아무것도 하지 않으므로, 빈 리스트는 특별한 경우가 필요 없습니다.

---

리스트는 자신의 길이를 저장하지 않습니다: 순회로 세어야 합니다. 반복문의 `while` 형태는 포인터를 바깥에 두므로, 반복문 본문이 다른 변수를 갱신할 때 유용합니다:
```c
int count = 0;
Node *n = head;
while (n != NULL) {
    count++;
    n = n->next;
}
```
빈 리스트에서는 반복문 본문이 한 번도 실행되지 않고 개수는 `0`으로 유지됩니다.

---

**뒤쪽**에 노드를 추가하려면 마지막 노드, 즉 `next`가 `NULL`인 노드가 필요합니다. 함수는 그 노드를 찾을 때까지 걸어간 뒤, 그곳에 새 노드를 붙이고 변경되지 않은 헤드를 반환합니다:
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
리스트가 비어 있으면 걸어갈 마지막 노드가 없습니다: 새 노드가 그저 헤드로 반환됩니다.

---

리스트를 탐색하는 것은 각 값을 비교하다가 첫 번째 일치에서 멈추는 순회입니다. 함수는 찾은 노드에 대한 포인터를 반환하고, 일치 없이 리스트의 끝에 도달하면 `NULL`을 반환합니다:
```c
Node *found = find(head, 5);
if (found != NULL) {
    printf("%d\n", found->value);
}
```
값 대신 노드를 반환하면 호출자가 그 노드를 수정하거나 다른 연산의 시작점으로 사용할 수 있습니다.

---

`free(p)` 이후에도 변수 `p`는 여전히 예전 주소를 담고 있지만, 그것이 가리키는 메모리는 더 이상 프로그램의 것이 아닙니다: `p`는 이제 **댕글링 포인터**(dangling pointer)입니다. 그것을 통해 읽거나 쓰거나 두 번 해제하는 것은 정의되지 않은 동작입니다: 프로그램은 예전 값을 출력하거나, 쓰레기값을 출력하거나, 강제 종료될 수 있고 컴파일러는 불평하지 않습니다. 포인터가 `free` 이후에도 계속 쓰여야 한다면, 바로 뒤에 `NULL`로 설정하여 이후의 사용이 `NULL` 검사에 걸리도록 하세요.

---

주어진 노드 **뒤에** 삽입하는 것은 순회가 필요 없습니다: 새 노드가 `node`의 다음 노드를 이어받고, 그다음 `node`가 새 노드를 가리킵니다:
```c
new_node->next = node->next;
node->next = new_node;
```
두 대입의 순서가 중요합니다: `node->next`를 먼저 설정하면 리스트의 나머지 부분을 가리키는 유일한 포인터를 덮어써서 그 노드들을 잃게 됩니다. 마지막 노드 뒤에 삽입하는 것도 그 `next`가 `NULL`이므로 잘 동작합니다.

---

첫 번째 노드를 제거하는 것은 `push_front`의 거울상입니다: 두 번째 노드의 주소를 저장하고, 첫 번째 노드를 해제한 뒤, 저장한 주소를 새 헤드로 반환합니다. 호출자는 그 결과를 자신의 헤드 변수에 다시 저장합니다:
```c
Node *next = head->next;
free(head);
return next;
```
헤드가 `NULL`이 될 때까지 pop하면 호출 한 번에 노드 하나씩 리스트 전체를 해제합니다.

---

중간의 노드를 제거하려면 그 **앞의** 노드가 필요하므로, 순회는 두 개의 포인터를 유지합니다: 이미 방문한 노드인 `prev`와 검사 중인 노드인 `cur`입니다. `cur`이 일치하면 `prev->next`가 그 노드를 건너뛰게 하고 `cur`을 해제합니다. 일치하는 것이 헤드 자체라면 `prev`는 여전히 `NULL`이고 새 헤드는 `cur->next`입니다:
```c
if (prev == NULL) {
    head = cur->next;
} else {
    prev->next = cur->next;
}
free(cur);
```
일치하는 노드가 없으면 리스트는 변경되지 않은 채로 반환됩니다.

---

리스트를 뒤집는 것은 세 개의 포인터로 모든 `next` 포인터를 제자리에서 돌려놓습니다: `prev`는 이미 뒤집힌 부분, `head`는 처리 중인 노드, `next`는 링크를 바꾸기 전에 저장해 둔 리스트의 나머지 부분의 복사본입니다. 각 단계에서 현재 노드는 `prev`를 가리키도록 바뀌고, 그다음 `prev`와 `head`가 모두 앞으로 나아갑니다:
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
`head`가 `NULL`에 도달하면 모든 링크가 뒤집힌 것이고 `prev`가 새 헤드입니다.

---

연결 리스트는 배열이 비싼 곳에서 저렴하고, 그 반대도 마찬가지입니다. **앞쪽**에서의 추가와 제거는 길이와 상관없이 포인터 대입 몇 번이면 되지만, 배열이라면 모든 요소를 이동시켜야 합니다. 반면 노드들은 연속적이지 않으므로 `list[i]`가 없습니다: n번째 노드, 마지막 노드 또는 전체 길이에 도달하려면 헤드에서 시작해 그 사이의 모든 노드를 걸어가야 합니다. 자주 추가하는 프로그램은 그 걸음을 피하기 위해 마지막 노드에 대한 두 번째 포인터, 즉 **테일**을 유지합니다.

---

종합해 봅시다: 리스트는 종종 배열로부터 만들어집니다. 앞쪽에 추가하면 순서가 뒤바뀌므로, 배열은 마지막 요소부터 첫 번째 요소까지 **거꾸로** 순회하고, 첫 번째 요소가 헤드에 오게 됩니다. 그다음 프로그램은 순회로 리스트를 출력하고 노드 하나씩 해제하여 모든 `malloc`이 `free`와 짝을 이루도록 합니다.
