# --description--

리스트를 뒤집는 것은 세 개의 포인터로 모든 `next` 포인터를 제자리에서 돌려놓습니다: `prev`는 이미 뒤집힌 부분, `head`는 처리 중인 노드, `next`는 링크를 바꾸기 전에 저장해 둔 리스트의 나머지 부분의 복사본입니다. 각 단계에서 현재 노드는 `prev`를 가리키도록 바뀌고, 그다음 `prev`와 `head`가 모두 앞으로 나아갑니다:
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
`head`가 `NULL`에 도달하면 모든 링크가 뒤집힌 것이고 `prev`가 새 헤드입니다.

# --solutions--

```c
#include <stdio.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head != NULL) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
int main() {
    Node c = {3, NULL};
    Node b = {2, &c};
    Node a = {1, &b};
    for (Node *n = reverse(&a); n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    return 0;
}
```
