# --description--

블록 주석의 흔한 용도는 **헤더 주석**입니다: 함수 바로 위에 놓이는 짧은 블록으로, 그 함수가 무엇을 하는지, 매개변수가 무엇을 뜻하는지, 무엇을 반환하는지 설명합니다.
```c
/*
 * Returns the number of seconds in the given minutes.
 * minutes: a whole number of minutes, never negative
 */
int to_seconds(int minutes) {
    return minutes * 60;
}
```
이제 `to_seconds`를 호출하는 사람은 본문 대신 헤더를 읽을 수 있습니다. 헤더는 함수 바로 옆에 두어 함께 업데이트되도록 하세요.

```c
#include <stdio.h>
/* Returns the larger of a and b */
int max_of(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
int main() {
    printf("%d\n", max_of(9, 4));
    return 0;
}
```
