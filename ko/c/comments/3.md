# --description--

주석이 여러 줄에 걸칠 필요가 있을 때는 C의 **여러 줄 주석**(블록 주석이라고도 함)을 사용합니다: `/*`로 시작해서 `*/`로 끝나며, 줄바꿈을 포함해 그 사이의 모든 내용은 무시됩니다.
```c
/*
  Prints the welcome banner.
  Called once when the program starts.
*/
printf("Welcome!\n");
```
블록 주석은 짧게 한 줄에 머물 수도 있습니다: `/* like this */`.

줄의 끝에서 멈추는 `//`와 달리, `/*` 주석은 `*/`를 만나야만 끝납니다. 닫는 것을 잊으면 컴파일러는 뒤따르는 모든 코드를 주석의 일부로 취급합니다.
