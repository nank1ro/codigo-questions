# --description--

컴파일러는 모든 주석을 공백 하나로 바꿉니다. 즉, `/* */` 주석은 공백이 올 수 있는 어디에든 나타날 수 있으며, 명령문이나 표현식 한가운데에도 가능합니다:
```c
int area = width /* cm */ * height /* cm */;
```
이것은 피연산자나 호출의 인자에 레이블을 붙일 때 가끔 유용합니다. `//` 주석으로는 이렇게 할 수 없는데, 그 줄의 나머지 부분과 뒤따르는 코드까지 주석 처리해 버리기 때문입니다.
