# --description--

비트는 가장 오른쪽 것부터 `0`으로 번호가 매겨지므로, `1u << n`은 비트 `n`만 켜진 마스크입니다.
단일 비트를 **설정**한다는 것은 다른 비트는 건드리지 않고 그 비트만 켜는 것이며, 값과 그 마스크를 OR하면 됩니다:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// "6" 출력
```
비트가 이미 켜져 있었다면 값은 변하지 않으므로, 비트 설정은 반복해도 안전합니다.
