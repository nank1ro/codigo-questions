# --description--

C23 이전에는 숫자를 2진수로 출력하는 서식 지정자가 없었고, `0b1010` 같은 리터럴도 표준 C가 아니었습니다. 비트를 보여주려면 루프를 직접 작성합니다: 최상위 비트부터 비트 `0`까지 내려가며 매번 `(value >> i) & 1u`를 출력합니다.
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
값을 `i`비트 오른쪽으로 시프트하면 비트 `i`가 가장 오른쪽 자리로 오고, 거기서 `& 1u`가 그 비트만 남깁니다.
