# --description--

**XOR** 연산자 `^`(배타적 OR)는 두 비트가 *서로 다른* 자리에만 `1`을 남깁니다:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// "6" 출력
```
여기서 유용한 성질 하나가 나옵니다: 같은 XOR를 두 번 적용하면 원래 값으로 돌아옵니다.
