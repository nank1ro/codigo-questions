# --description--

단일 비트를 **토글**한다는 것은 현재 상태와 관계없이 그 비트를 뒤집는 것이며, 값과 마스크를 XOR하면 됩니다:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// prints "7"
```
XOR는 스스로를 되돌릴 수 있으므로, 같은 비트를 두 번 토글하면 원래 값으로 돌아옵니다.
