# --description--

여러 작은 숫자가 하나의 큰 값 안에 담기는 경우가 많습니다. 그중 하나를 다시 읽으려면, 먼저 비트 `0`에서 시작하도록 아래로 시프트한 다음 그 위의 모든 것을 마스크로 잘라냅니다:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// prints "18", the 0x12 byte
```
먼저 시프트하고 나중에 마스크하는 순서를 기억하세요: 마스크는 필드가 맨 아래로 내려온 뒤에야 그 필드를 온전히 기술합니다.

# --instructions--

`packed`를 16비트 아래로 시프트하고, 시프트된 값의 하위 8비트만 `third_byte`에 담아 출력하도록 줄을 정렬하세요

unsigned int packed = 0xDEADBEEF;
