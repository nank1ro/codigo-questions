# --description--

**오른쪽 시프트** 연산자 `>>`는 모든 비트를 오른쪽으로 옮기며, 오른쪽 끝에서 밀려나간 비트는 버려집니다. unsigned 값에서는 왼쪽에 비워진 자리가 0으로 채워집니다:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// "3" 출력
```
오른쪽으로 `n`비트 시프트하면 unsigned 값은 나머지를 버리고 2의 `n`제곱으로 나뉩니다.
*음수*를 오른쪽 시프트하는 것은 이식성이 없으므로, 비트 작업을 `unsigned` 타입으로 유지해야 할 또 하나의 이유가 됩니다.
