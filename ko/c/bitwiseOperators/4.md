# --description--

**NOT** 연산자 `~`는 하나의 피연산자를 받아 그 모든 비트를 뒤집습니다: 각 `0`은 `1`이 되고 각 `1`은 `0`이 됩니다.
`unsigned int`는 32비트를 담으므로 `~0x0Fu`는 32비트 전부를 뒤집어 아주 큰 수를 만듭니다. 원하는 바이트만 남기려면 `~`를 `& 0xFF`와 함께 사용하세요:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// prints "240"
```
`~`는 `&`보다 먼저 묶이므로(결합 우선순위가 높으므로) 가장 먼저 적용됩니다.
`~`를 논리 연산자 `!`와 혼동하지 마세요: `!`는 값 전체를 보고 `0` 또는 `1`로 답하지만, `~`는 모든 비트를 다시 씁니다.
