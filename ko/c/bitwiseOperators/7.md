# --description--

각 이진 비트 연산자에는 변수를 제자리에서 갱신하는 **복합 대입** 형태가 있습니다: `&=`, `|=`, `^=`, `<<=`, `>>=`입니다.
```c
unsigned int x = 12;
x &= 10;  // x = x & 10;와 같음
x |= 1;   // x = x | 1;와 같음
x ^= 3;   // x = x ^ 3;와 같음
x <<= 1;  // x = x << 1;와 같음
x >>= 2;  // x = x >> 2;와 같음
```
이들은 변수 이름을 반복하는 것보다 읽기 좋으며, 플래그 변수의 비트를 바꾸는 일반적인 방법입니다.

# --instructions--

`flags`가 `0x01`로 시작하고, `|=`로 값 `4`에 해당하는 비트를 켜고, `<<=`로 2비트 왼쪽 시프트한 뒤, 마지막에 출력되도록 줄을 정렬하세요
