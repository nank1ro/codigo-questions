모든 정수는 메모리에 **비트**의 나열로 저장되며, 각 비트는 `0` 또는 `1`입니다. 숫자 `12`는 `00001100`으로, 숫자 `10`은 `00001010`으로 저장됩니다.
**비트 연산자**는 숫자 전체가 아니라 그 개별 비트들에 대해 동작합니다. **AND** 연산자 `&`는 두 값을 비트별로 비교하여 *양쪽* 비트가 모두 `1`인 자리에만 `1`을 남깁니다:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// "8" 출력
```
비트 패턴은 보통 `0x0C` 같은 16진수 리터럴로 쓰는데, 16진수 숫자 하나가 정확히 네 비트를 나타내기 때문입니다. 비트 작업에는 항상 `unsigned` 타입을 사용하고 `%u`로 출력하세요.

---

**OR** 연산자 `|`는 두 값을 비트별로 비교하여 *적어도 하나*의 비트가 `1`인 자리에 `1`을 남깁니다:
```c
//  00001100   (12)
// |00001010   (10)
//  --------
//  00001110   (14)
printf("%u\n", 12u | 10u);
// "14" 출력
```
`|`는 두 비트 패턴을 하나로 합치는 일반적인 방법입니다.

---

**XOR** 연산자 `^`(배타적 OR)는 두 비트가 *서로 다른* 자리에만 `1`을 남깁니다:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// "6" 출력
```
여기서 유용한 성질 하나가 나옵니다: 같은 XOR를 두 번 적용하면 원래 값으로 돌아옵니다.

---

**NOT** 연산자 `~`는 하나의 피연산자를 받아 그 모든 비트를 뒤집습니다: 각 `0`은 `1`이 되고 각 `1`은 `0`이 됩니다.
`unsigned int`는 32비트를 담으므로 `~0x0Fu`는 32비트 전부를 뒤집어 아주 큰 수를 만듭니다. 원하는 바이트만 남기려면 `~`를 `& 0xFF`와 함께 사용하세요:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// "240" 출력
```
`~`는 `&`보다 먼저 묶이므로(결합 우선순위가 높으므로) 가장 먼저 적용됩니다.
`~`를 논리 연산자 `!`와 혼동하지 마세요: `!`는 값 전체를 보고 `0` 또는 `1`로 답하지만, `~`는 모든 비트를 다시 씁니다.

---

**왼쪽 시프트** 연산자 `<<`는 모든 비트를 지정한 칸수만큼 왼쪽으로 옮기고, 오른쪽에 비워진 자리는 0으로 채웁니다:
```c
//  00000011   (3)
//  << 2
//  00001100   (12)
printf("%u\n", 3u << 2);
// "12" 출력
```
왼쪽으로 `n`비트 시프트하면 값은 2의 `n`제곱만큼 곱해집니다.
두 가지 실수는 C 프로그램을 정의되지 않은 동작으로 만듭니다: 음수를 왼쪽 시프트하는 것과, 타입의 비트 폭(`unsigned int`의 경우 32)과 같거나 그보다 큰 칸수만큼 시프트하는 것입니다. **unsigned** 값으로 작업하면 첫 번째 실수는 피할 수 있습니다.

---

**오른쪽 시프트** 연산자 `>>`는 모든 비트를 오른쪽으로 옮기며, 오른쪽 끝에서 밀려나간 비트는 버려집니다. unsigned 값에서는 왼쪽에 비워진 자리가 0으로 채워집니다:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// "3" 출력
```
오른쪽으로 `n`비트 시프트하면 unsigned 값은 나머지를 버리고 2의 `n`제곱으로 나뉩니다.
*음수*를 오른쪽 시프트하는 것은 이식성이 없으므로, 비트 작업을 `unsigned` 타입으로 유지해야 할 또 하나의 이유가 됩니다.

---

각 이진 비트 연산자에는 변수를 제자리에서 갱신하는 **복합 대입** 형태가 있습니다: `&=`, `|=`, `^=`, `<<=`, `>>=`입니다.
```c
unsigned int x = 12;
x &= 10;  // x = x & 10;와 같음
x |= 1;   // x = x | 1;와 같음
x ^= 3;   // x = x ^ 3;와 같음
x <<= 1;  // x = x << 1;와 같음
x >>= 2;  // x = x >> 2;와 같음
```
이들은 변수 이름을 반복하는 것보다 읽기 좋으며, 플래그 변수의 비트를 바꾸는 일반적인 방법입니다.

---

**마스크**는 자신의 비트로 다른 값에서 관심 있는 부분을 고르는 값입니다. `&`와 함께 사용하면 마스크에서 `1`인 비트는 그대로 남고 나머지는 모두 0이 됩니다:
```c
//  10101011   (0xAB)
// &00001111   (0x0F)
//  --------
//  00001011   (0x0B)
printf("%u\n", 0xABu & 0x0Fu);
// "11" 출력
```
`0x0F`는 하위 **니블**이라 부르는 낮은 네 비트를 남기고, `0xFF`는 한 바이트 전체인 낮은 여덟 비트를 남깁니다.

---

비트는 가장 오른쪽 것부터 `0`으로 번호가 매겨지므로, `1u << n`은 비트 `n`만 켜진 마스크입니다.
단일 비트를 **설정**한다는 것은 다른 비트는 건드리지 않고 그 비트만 켜는 것이며, 값과 그 마스크를 OR하면 됩니다:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// "6" 출력
```
비트가 이미 켜져 있었다면 값은 변하지 않으므로, 비트 설정은 반복해도 안전합니다.

---

단일 비트를 **해제**한다는 것은 그 비트를 끄는 것이며, 값과 마스크의 *역*을 AND하면 됩니다:
```c
unsigned int value = 7;       // 00000111
value = value & ~(1u << 1);   // 00000101
printf("%u\n", value);
// "5" 출력
```
`~(1u << 1)`은 비트 `1`만 빼고 모든 비트가 켜진 값이므로, AND는 나머지를 그대로 유지합니다.

---

단일 비트를 **토글**한다는 것은 현재 상태와 관계없이 그 비트를 뒤집는 것이며, 값과 마스크를 XOR하면 됩니다:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// "7" 출력
```
XOR는 스스로를 되돌릴 수 있으므로, 같은 비트를 두 번 토글하면 원래 값으로 돌아옵니다.

---

단일 비트를 **검사**하려면 값과 마스크를 AND하고 그 결과가 `0`과 다른지 확인하면 됩니다:
```c
unsigned int value = 10;                  // 00001010
printf("%d\n", (value & (1u << 3)) != 0); // "1" 출력
printf("%d\n", (value & (1u << 2)) != 0); // "0" 출력
```
AND의 결과는 `1`이 아닙니다: `0` 또는 마스크 자신이며, 비트 `3`의 경우 마스크는 `8`입니다. 그래서 결과를 그대로 답으로 쓰는 대신 `!= 0`과 비교하는 것입니다.

---

**플래그**는 이름이 붙은 마스크로, 각각 서로 다른 비트를 사용하며 하나의 변수 안에 모두 저장될 수 있습니다. 플래그는 `|`로 합쳐지고 `&`로 다시 읽습니다:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// "1" 출력
```
따라서 `unsigned int` 하나가 32개의 독립적인 예/아니오 답을 담을 수 있습니다.

---

C23 이전에는 숫자를 2진수로 출력하는 서식 지정자가 없었고, `0b1010` 같은 리터럴도 표준 C가 아니었습니다. 비트를 보여주려면 루프를 직접 작성합니다: 최상위 비트부터 비트 `0`까지 내려가며 매번 `(value >> i) & 1u`를 출력합니다.
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// "0101" 출력
```
값을 `i`비트 오른쪽으로 시프트하면 비트 `i`가 가장 오른쪽 자리로 오고, 거기서 `& 1u`가 그 비트만 남깁니다.

---

값의 비트 중 몇 개가 `1`인지 세는 것은 고전적인 비트 루프입니다: `& 1u`로 최하위 비트를 검사하고, 그 값을 카운터에 더한 뒤, `>>=`로 값을 한 비트 오른쪽 시프트하고 남은 것이 없을 때까지 반복합니다.
```c
unsigned int value = 6, count = 0;
while (value != 0) {
    count += value & 1u;
    value >>= 1;
}
// count는 2
```
unsigned 값은 충분히 오른쪽 시프트하면 `0`이 되므로, 루프는 언제나 끝납니다.

---

여러 작은 숫자가 하나의 큰 값 안에 담기는 경우가 많습니다. 그중 하나를 다시 읽으려면, 먼저 비트 `0`에서 시작하도록 아래로 시프트한 다음 그 위의 모든 것을 마스크로 잘라냅니다:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// "18" 출력, 0x12 바이트
```
먼저 시프트하고 나중에 마스크하는 순서를 기억하세요: 마스크는 필드가 맨 아래로 내려온 뒤에야 그 필드를 온전히 기술합니다.
