# --description--

모든 정수는 메모리에 **비트**의 나열로 저장되며, 각 비트는 `0` 또는 `1`입니다. 숫자 `12`는 `00001100`으로, 숫자 `10`은 `00001010`으로 저장됩니다.
**비트 연산자**는 숫자 전체가 아니라 그 개별 비트들에 대해 동작합니다. **AND** 연산자 `&`는 두 값을 비트별로 비교하여 *양쪽* 비트가 모두 `1`인 자리에만 `1`을 남깁니다:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// "8" 출력
```
비트 패턴은 보통 `0x0C` 같은 16진수 리터럴로 쓰는데, 16진수 숫자 하나가 정확히 네 비트를 나타내기 때문입니다. 비트 작업에는 항상 `unsigned` 타입을 사용하고 `%u`로 출력하세요.
