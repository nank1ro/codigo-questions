# --description--

**플래그**는 이름이 붙은 마스크로, 각각 서로 다른 비트를 사용하며 하나의 변수 안에 모두 저장될 수 있습니다. 플래그는 `|`로 합쳐지고 `&`로 다시 읽습니다:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// prints "1"
```
따라서 `unsigned int` 하나가 32개의 독립적인 예/아니오 답을 담을 수 있습니다.

# --instructions--

세 플래그를 선언하고, `READ`와 `WRITE`를 `perms`로 합치고, 거기에 `EXEC`를 더한 뒤 결과를 출력하도록 줄을 정렬하세요

```c
perms |= EXEC;
```

```c
printf("%u\n", perms);
```
