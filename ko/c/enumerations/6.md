# --description--

`switch`의 모든 case가 하나의 상수를 처리할 때는 각 case 뒤에 `break`를 잊지 마세요. 그렇지 않으면 실행이 다음 case로 흘러 들어갑니다.
열거형의 모든 상수를 다룬다면 `default` case는 필수가 아닙니다.

# --instructions--

`enum Size`를 선언하고, `size`에 `MEDIUM`을 저장한 뒤, `switch`로 `Medium`을 출력하도록 줄을 정렬하세요. case의 순서는 선언의 상수 순서와 동일하게 유지하세요

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
