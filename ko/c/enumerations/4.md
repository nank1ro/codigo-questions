# --description--

열거형은 타입이기도 합니다: `enum` 뒤에 열거형 이름을 써서 그 타입의 변수를 선언하고, 상수 중 하나를 대입할 수 있습니다.
```c
enum Color favorite = GREEN;
```
상수는 정수이므로, 열거형 변수도 일반적인 연산자로 비교합니다.
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```
