# --description--

매번 `enum Color`라고 쓰는 것은 장황합니다. `typedef`를 사용하면 열거형에 짧은 타입 이름을 붙일 수 있고, 열거형 자체는 이름 없이 둘 수 있습니다.
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
새 이름 `Color`는 앞에 `enum` 키워드 없이 단독으로 사용됩니다.
