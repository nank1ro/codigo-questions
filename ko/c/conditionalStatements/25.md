# --description--

반대로 `online`이 `false`를 담고 있으면 조건이 거짓이 되므로, 블록은 완전히 건너뛰어지고 중괄호 안의 어떤 것도 출력되지 않습니다.

# --instructions--

이 코드는 출력에 무엇을 표시합니까?
```c
bool online = false;
if (online) {
    printf("Hello user!\n");
}
```

# --answers--

- Hello user!
- "Hello user!"
- 아무것도 표시되지 않습니다, 코드가 건너뛰어집니다
