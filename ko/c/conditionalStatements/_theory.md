의사 결정은 특정 조건이 충족될 때만 코드를 실행하고 싶을 때 필요합니다.
날씨가 좋을 때만 밖에서 놀고 싶다고 가정해 봅시다.
프로그래밍에서는 불리언 변수 `nice_weather`를 저장하고, 이 변수가 `true`일 때 `if`를 사용하여 밖에서 노는 동작을 수행할 수 있습니다:
```c
bool nice_weather = true;
if (nice_weather) {
    // 밖에서 놀기
}
```

---

이전 예제를 계속해 봅시다.
```c
bool nice_weather = true;
if (nice_weather) {
    // 밖에서 놀기
}
```
`if` 문은 조건이 `true`일 때만 코드 블록을 실행한다는 것을 확인했습니다.
또 하나 중요한 점은 코드 블록을 나타내는 **중괄호** `{}`입니다.

---

조건이 발생할 때 코드 블록을 실행하는 방법을 방금 살펴보았습니다. 이제 첫 번째 조건이 실패했을 때 다른 코드 블록을 실행하는 방법을 알아봅시다.
날씨가 좋으면 밖에서 놀고, 그렇지 않으면 집에 있습니다.
C에서는 `else` 문을 사용할 수 있습니다:
```c
bool nice_weather = false;
if (nice_weather) {
    // 밖에서 놀기
} else {
    // 집에 있기
}
```

---

다음 예제처럼 확인해야 할 조건이 하나 더 있다고 가정해 봅시다:
```c
int num = 3;
if (num == 2) {
    printf("the number is 2\n");
} else if (num == 3) {
    printf("the number is 3\n");
} else {
    printf("do something else\n");
}
```
이 코드의 출력은 `the number is 3`입니다.
먼저 숫자가 2와 같은지 확인합니다. 이것은 거짓입니다.
그래서 두 번째 문으로 넘어가 `num`이 3과 같은지 확인합니다. 참이므로 다음 코드 블록을 실행하여 `the number is 3`을 출력합니다

---

`else if` 문은 원하는 만큼 추가할 수 있으며, 제한이 없습니다
```c
int num = 4;
if (num == 2) {
    printf("the number is 2");
} else if (num == 3) {
    printf("the number is 3");
} else if (num == 4) {
    printf("the number is 4");
} else if (num == 5) {
    printf("the number is 5");
} else if (num == 6) {
    printf("the number is 6");
}
```
이 코드의 출력은 `the number is 4`입니다.

---

조건문(`if`, `else if` 또는 `else`)을 다른 조건문 안에 중첩하여 더 복잡한 구조를 만들 수도 있습니다.
```c
int num = 4;
if (num < 3) {
    printf("the number is lower than 3\n");
} else {
    if (num == 3) {
        printf("the number is 3\n");
  } else if (num == 4) {
        printf("the number is 4\n");
  } else {
        printf("the number is greather than 4\n");
  }
}
```
이 코드의 출력은 `the number is 4`입니다.

---

이제 `if` 문의 문법을 직접 연습해 볼 차례입니다: 키워드, 괄호로 묶인 조건, 그리고 중괄호로 감싼 코드 블록으로 구성됩니다.
```c
if (condition) {
    // 조건이 true일 때 실행됩니다
}
```

---

C의 불리언 리터럴은 `true`와 `false`입니다: 소문자로 쓰고 따옴표 없이 사용하며, 언어에 내장된 것이 아니라 `<stdbool.h>`에서 정의됩니다. `True`라고 쓰면 조건으로 컴파일되지 않습니다 — 소문자 형태만 동작하며, 값이 `true`일 때 블록이 실행됩니다.

---

C에는 별도의 불리언 검사가 없습니다: 조건은 값이 0이 아니기만 하면 참이 됩니다. `<stdbool.h>`의 `false`는 단순히 `0`이므로, 이 값으로 보호되는 블록은 절대 실행되지 않습니다.

---

C의 `if` 문은 세 부분으로 이루어집니다: `if` 키워드, 괄호로 묶인 조건, 그리고 중괄호로 묶인 블록입니다. 괄호는 필수입니다 — 컴파일러가 조건이 어디서 끝나는지 알 수 있는 방법이기 때문입니다.

---

모든 조건문은 다음에 무엇을 실행할지 결정하기 전에 조건을 확인해야 한다는 것을 컴파일러에 알리는 키워드로 시작합니다.

---

리터럴 `true` 조건은 항상 참이므로, 블록이 실행되고 그 안의 `printf`가 작성된 그대로 실행됩니다.

---

리터럴 `false` 조건은 절대 참이 될 수 없으므로, 블록은 완전히 건너뛰어지고 그 안의 어떤 것도 실행되지 않습니다.

---

조건은 `if` 문이 확인하는 값입니다: 조건이 `true`이면 블록이 실행되고, `false`이면 건너뜁니다.

---

여는 중괄호는 조건과 같은 줄에 있어도 되고, 그다음 줄에 있어도 됩니다. C는 줄바꿈을 무시하므로, 두 스타일 모두 완전히 동일한 프로그램으로 컴파일됩니다.

---

조건을 감싸는 괄호는 선택적인 그룹화가 아니라 C의 `if` 문법의 일부입니다: `if true { ... }`는 컴파일되지 않습니다.

---

따옴표로 감싼 `"false"`는 불리언이 아니라 문자열입니다 — 그리고 조건에 사용된 문자열은 널이 아닌 주소이므로 참으로 취급됩니다. 블록이 실행되지 않게 하려면 따옴표 없는 `false`만 사용해야 합니다.

---

`if` 줄의 각 구성 요소 사이의 공백은 C에서 자유롭습니다: `if(true){`와 `if (true) {`는 컴파일러에게 동일한 문장이므로, 중요한 것은 구성 요소의 순서뿐입니다.

---

코드 블록은 하나의 문장으로 제한되지 않습니다. 중괄호 사이의 모든 문장은 작성된 순서대로 하나씩 실행됩니다.

---

불리언 변수는 비교 없이 그대로 조건으로 사용할 수 있습니다. `online`이 이미 `true`를 담고 있으므로, `if (online)`이라고만 써도 블록을 실행하기에 충분합니다.

---

`bool` 변수는 조건으로 동작합니다. `if`는 그 순간 변수에 저장된 값만 보기 때문입니다. `online`에 `false`가 들어 있으면, `if (online)`은 `if (false)`와 정확히 같게 동작합니다.

---

`if` 문의 중괄호 사이에 있는 코드만 조건부로 실행됩니다. 닫는 중괄호 이후에 작성된 코드는 조건과 상관없이 항상 실행됩니다.

---

코드 블록이 담을 수 있는 문장 수에는 정해진 제한이 없습니다 — 한 줄이든 백 줄이든, 조건이 `true`일 때 모두 함께 실행됩니다.

---

불리언 변수를 조건으로 읽는 것은 리터럴과 똑같이 동작합니다: `online`이 `true`를 담고 있으므로 블록이 실행되고 그 안의 `printf`가 실행됩니다.

---

반대로 `online`이 `false`를 담고 있으면 조건이 거짓이 되므로, 블록은 완전히 건너뛰어지고 중괄호 안의 어떤 것도 출력되지 않습니다.
