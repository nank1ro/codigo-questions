# --description--

포인터를 통해서는 점 대신 **화살표** 연산자 `->`로 멤버에 접근합니다:
```c
void grow(Box *b) {
    b->size = b->size * 2;
}
```
`b->size`는 `(*b).size`의 축약 표현입니다: 먼저 포인터를 따라간 뒤 멤버를 가져옵니다. 점은 구조체에만, 화살표는 구조체를 가리키는 포인터에만 동작합니다.
호출자는 `&`로 자신 변수의 주소를 전달하며, 포인터를 통해 이루어진 변경은 호출 이후에 반영됩니다.

# --instructions--

#include <stdio.h>

typedef struct { int size; } Box;

void grow(Box *b) {
    b[/]size = b->size * 2;
}

int main() {
    Box box = {5};
    grow([/]box);
    printf("%d\n", box.size);
    return 0;
}
