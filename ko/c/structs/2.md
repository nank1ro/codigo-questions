# --description--

멤버를 순서대로 초기화하는 것은 취약합니다: 구조체에 멤버가 추가되면 모든 초기화 값이 밀려납니다. C99부터는 **지정 초기화**가 점으로 각 멤버의 이름을 지정하여 어떤 순서로든 초기화할 수 있습니다:
```c
struct Point p = {.y = 4, .x = 3};
```
나열하지 않은 멤버는 `0`으로 설정되므로 `{.y = 5}`는 `x`를 `0`으로 만듭니다. 이는 초기화 값 없이 선언한 변수 `struct Point q;`와는 다릅니다. 이렇게 선언한 변수의 멤버는 값을 대입하기 전까지 **쓰레기값**을 담고 있습니다:
```c
struct Point q;
q.x = 1;
q.y = 2;
```
