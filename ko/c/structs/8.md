# --description--

구조체가 **값으로** 함수에 전달되면 함수는 그 **복사본**을 받습니다. 매개변수의 멤버를 바꾸면 복사본만 바뀌고, 호출자의 변수는 원래 그대로입니다:
```c
void reset(Point p) {
    p.x = 0; // changes the copy
}
```
함수가 호출자의 구조체를 수정하게 하려면 `&`로 **주소**를 전달하고 매개변수를 **포인터**인 `Point *p`로 선언합니다. 포인터는 복사본이 아닌 원본 변수를 가리킵니다:
```c
void reset(Point *p) { ... }

reset(&origin);
```
복사는 큰 구조체에서 시간도 들기 때문에, 아무것도 수정하지 않을 때조차 포인터가 보통 선택됩니다.
