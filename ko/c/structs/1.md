# --description--

**구조체**는 서로 다른 타입의 관련된 값들을 하나의 새로운 타입으로 묶습니다. 그 안의 각 값은 **멤버**라고 부릅니다.
선언은 중괄호 사이에 멤버들을 나열하고 세미콜론으로 끝납니다. 이 선언은 `struct Point` 타입을 만들 뿐 아직 변수는 만들지 않습니다:
```c
struct Point {
    int x;
    int y;
};
```
그 타입의 변수는 `struct Point`로 선언하며, 멤버들은 배열처럼 중괄호로 **순서대로** 초기화할 수 있습니다:
```c
struct Point p = {3, 4}; // x is 3, y is 4
```
멤버는 **점** 연산자 `.`로 읽고 씁니다:
```c
printf("%d\n", p.x); // prints "3"
p.y = 10;
```
