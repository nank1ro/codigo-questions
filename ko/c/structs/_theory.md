**구조체**는 서로 다른 타입의 관련된 값들을 하나의 새로운 타입으로 묶습니다. 그 안의 각 값은 **멤버**라고 부릅니다.
선언은 중괄호 사이에 멤버들을 나열하고 세미콜론으로 끝납니다. 이 선언은 `struct Point` 타입을 만들 뿐 아직 변수는 만들지 않습니다:
```c
struct Point {
    int x;
    int y;
};
```
그 타입의 변수는 `struct Point`로 선언하며, 멤버들은 배열처럼 중괄호로 **순서대로** 초기화할 수 있습니다:
```c
struct Point p = {3, 4}; // x is 3, y is 4
```
멤버는 **점** 연산자 `.`로 읽고 씁니다:
```c
printf("%d\n", p.x); // prints "3"
p.y = 10;
```

---

멤버를 순서대로 초기화하는 것은 취약합니다: 구조체에 멤버가 추가되면 모든 초기화 값이 밀려납니다. C99부터는 **지정 초기화**가 점으로 각 멤버의 이름을 지정하여 어떤 순서로든 초기화할 수 있습니다:
```c
struct Point p = {.y = 4, .x = 3};
```
나열하지 않은 멤버는 `0`으로 설정되므로 `{.y = 5}`는 `x`를 `0`으로 만듭니다. 이는 초기화 값 없이 선언한 변수 `struct Point q;`와는 다릅니다. 이렇게 선언한 변수의 멤버는 값을 대입하기 전까지 **쓰레기값**을 담고 있습니다:
```c
struct Point q;
q.x = 1;
q.y = 2;
```

---

구조체는 다른 값과 마찬가지로 함수에 전달할 수 있습니다. 매개변수는 전체 타입 이름으로 선언하고, 함수는 `.`로 멤버를 읽습니다:
```c
struct Point { int x; int y; };

int sum(struct Point p) {
    return p.x + p.y;
}
```
구조체는 그것을 사용하는 함수 **앞에서** 선언해야 컴파일러가 이미 그 멤버들을 알 수 있습니다.

---

매번 `struct Point`라고 쓰는 것은 번거롭습니다. `typedef`를 사용하면 구조체에 짧은 타입 이름을 붙일 수 있고, 구조체 자체는 이름 없이 익명으로 둘 수 있습니다:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
새 이름 `Temperature`는 앞에 `struct` 키워드 없이 그 자체로 사용합니다. 이것이 실제 프로그램에서 구조체를 선언하는 가장 일반적인 방법입니다.

---

멤버 자체가 구조체일 수도 있습니다. 예를 들어 선분은 두 점으로 이루어집니다:
```c
typedef struct { int x; int y; } Point;

typedef struct {
    Point start;
    Point end;
} Segment;
```
내부 구조체는 자체적인 중괄호 쌍으로 초기화하며, 점 연산자를 이어 붙여 그 멤버에 접근합니다:
```c
Segment s = {{1, 2}, {5, 2}};
printf("%d\n", s.end.x); // prints "5"
```

---

구조체는 다른 타입과 마찬가지로 배열에 저장할 수 있습니다. 각 요소는 자체적인 중괄호로 초기화하고, 반복문이 인덱싱한 다음 점을 사용하여 하나씩 방문합니다:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

---

구조체 배열은 숫자 배열과 똑같이 함수에 전달됩니다: 매개변수는 `Item items[]`로 쓰며, 배열은 자신의 길이를 갖고 있지 않으므로 크기는 별도로 전달합니다:
```c
int count_free(Item items[], int size) {
    int count = 0;
    for (int i = 0; i < size; i++) {
        if (items[i].price == 0) {
            count++;
        }
    }
    return count;
}
```

---

구조체가 **값으로** 함수에 전달되면 함수는 그 **복사본**을 받습니다. 매개변수의 멤버를 바꾸면 복사본만 바뀌고, 호출자의 변수는 원래 그대로입니다:
```c
void reset(Point p) {
    p.x = 0; // changes the copy
}
```
함수가 호출자의 구조체를 수정하게 하려면 `&`로 **주소**를 전달하고 매개변수를 **포인터**인 `Point *p`로 선언합니다. 포인터는 복사본이 아닌 원본 변수를 가리킵니다:
```c
void reset(Point *p) { ... }

reset(&origin);
```
복사는 큰 구조체에서 시간도 들기 때문에, 아무것도 수정하지 않을 때조차 포인터가 보통 선택됩니다.

---

포인터를 통해서는 점 대신 **화살표** 연산자 `->`로 멤버에 접근합니다:
```c
void grow(Box *b) {
    b->size = b->size * 2;
}
```
`b->size`는 `(*b).size`의 축약 표현입니다: 먼저 포인터를 따라간 뒤 멤버를 가져옵니다. 점은 구조체에만, 화살표는 구조체를 가리키는 포인터에만 동작합니다.
호출자는 `&`로 자신 변수의 주소를 전달하며, 포인터를 통해 이루어진 변경은 호출 이후에 반영됩니다.

---

구조체를 가리키는 포인터를 받는 함수는 원본 값을 그 자리에서 갱신할 수 있습니다. 이것이 C에서 "수정자" 함수를 작성하는 표준 방법으로, 첫 번째 매개변수는 바꿀 구조체이고 나머지는 적용할 데이터입니다:
```c
void set_number(Player *p, int new_number) {
    p->number = new_number;
}
```
읽고 쓰는 것 모두 같은 화살표를 통해 이루어집니다: `p->score += 10`은 포인터가 가리키는 구조체의 멤버에 더합니다.

---

함수는 구조체를 **반환**할 수도 있습니다. 지역 변수에 만든 뒤 반환하면 호출자는 값 전체의 복사본을 받습니다:
```c
Point make_point(int x, int y) {
    Point p = {x, y};
    return p;
}

Point origin = make_point(0, 0);
```
C에서 함수가 여러 값을 반환하는 방법은 바로 구조체에 담는 것입니다.

---

`sizeof`는 구조체에도 동작하며, 구조체가 차지하는 메모리 크기를 알아내는 올바른 방법입니다:
```c
printf("%zu\n", sizeof(Point));
```
크기는 멤버들의 크기의 합 **이상**입니다. 더 커질 수도 있는데, 컴파일러가 각 멤버가 자신의 타입에 맞는 주소에 놓이도록 사용되지 않는 **패딩** 바이트를 삽입할 수 있기 때문입니다: `struct { char c; int n; }`은 보통 `5`가 아니라 `8`바이트입니다. 구조체의 크기를 하드코딩하지 말고 항상 `sizeof`에 물으세요.

---

구조체는 `==`로 비교할 수 없습니다: 두 구조체에 `a == b`라고 쓰면 **컴파일 오류**입니다. 대신 결과를 `&&`로 결합하여 **멤버별로** 비교합니다:
```c
bool same_size(Rectangle a, Rectangle b) {
    return a.width == b.width && a.height == b.height;
}
```
`<`와 `>`에도 마찬가지입니다: 어떤 멤버가 순서를 결정하는지는 여러분이 정합니다.

---

구조체는 텍스트를 담는 경우가 많으며, 텍스트는 고정된 크기의 `char` 배열 멤버로 저장합니다:
```c
typedef struct {
    char name[20];
    int age;
} Person;
```
배열 멤버는 선언 이후 `=`로 대입할 수 없습니다: `p.name = "Ann"`은 컴파일되지 않습니다. `string.h`의 `strcpy`를 사용하여 멤버를 복사 대상으로 전달하고 텍스트를 복사합니다:
```c
Person p;
strcpy(p.name, "Ann");
p.age = 30;
```
선언 시의 중괄호 초기화만이 문자열을 직접 받을 수 있습니다: `Person p = {"Ann", 30};`.

---

`printf`에는 구조체 전체를 위한 서식 지정자가 없습니다. 보통의 해결책은 멤버들을 고정된 형식으로 출력하는 작은 함수를 만드는 것으로, 프로그램의 모든 부분이 같은 방식으로 값을 보여주게 합니다:
```c
void print_person(Person p) {
    printf("%s (%d)\n", p.name, p.age);
}
```

---

지금까지 배운 내용을 종합하면: 구조체를 가리키는 포인터를 받는 함수는 화살표를 통해 `strcpy`로 텍스트 멤버를 갱신할 수 있습니다. `item->name`은 원본 구조체 안의 `char` 배열이기 때문입니다:
```c
void set_title(Book *book, char *title) {
    strcpy(book->title, title);
}
```
`strcpy`를 사용하려면 코드 맨 위에 `#include <string.h>`를 추가해야 한다는 점을 기억하세요.
