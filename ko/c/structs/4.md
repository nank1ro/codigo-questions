# --description--

매번 `struct Point`라고 쓰는 것은 번거롭습니다. `typedef`를 사용하면 구조체에 짧은 타입 이름을 붙일 수 있고, 구조체 자체는 이름 없이 익명으로 둘 수 있습니다:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
새 이름 `Temperature`는 앞에 `struct` 키워드 없이 그 자체로 사용합니다. 이것이 실제 프로그램에서 구조체를 선언하는 가장 일반적인 방법입니다.
