# --description--

`sizeof`는 구조체에도 동작하며, 구조체가 차지하는 메모리 크기를 알아내는 올바른 방법입니다:
```c
printf("%zu\n", sizeof(Point));
```
크기는 멤버들의 크기의 합 **이상**입니다. 더 커질 수도 있는데, 컴파일러가 각 멤버가 자신의 타입에 맞는 주소에 놓이도록 사용되지 않는 **패딩** 바이트를 삽입할 수 있기 때문입니다: `struct { char c; int n; }`은 보통 `5`가 아니라 `8`바이트입니다. 구조체의 크기를 하드코딩하지 말고 항상 `sizeof`에 물으세요.

# --instructions--

`int`가 4바이트인 일반적인 64비트 시스템에서 `printf("%zu\n", sizeof(Point));`는 무엇을 출력합니까?
```c
typedef struct {
    int x;
    int y;
} Point;
```
