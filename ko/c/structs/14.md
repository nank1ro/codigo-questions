# --description--

구조체는 텍스트를 담는 경우가 많으며, 텍스트는 고정된 크기의 `char` 배열 멤버로 저장합니다:
```c
typedef struct {
    char name[20];
    int age;
} Person;
```
배열 멤버는 선언 이후 `=`로 대입할 수 없습니다: `p.name = "Ann"`은 컴파일되지 않습니다. `string.h`의 `strcpy`를 사용하여 멤버를 복사 대상으로 전달하고 텍스트를 복사합니다:
```c
Person p;
strcpy(p.name, "Ann");
p.age = 30;
```
선언 시의 중괄호 초기화만이 문자열을 직접 받을 수 있습니다: `Person p = {"Ann", 30};`.
