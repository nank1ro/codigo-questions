# --description--

포인터도 변수이므로 자체적인 주소를 가지며, 그 주소는 별표 두 개로 선언하는 **포인터에 대한 포인터**에 저장할 수 있습니다:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp`는 `p`, 즉 `x`의 주소이고, `**pp`는 두 단계를 모두 따라가 `7`에 도달합니다. 포인터에 대한 포인터를 사용하면 함수가 포인터가 담고 있는 주소를 바꿀 수 있습니다: 함수는 `&p`를 받아 `*pp`에 대입합니다.
