# --description--

역참조한 포인터에는 **대입**할 수도 있습니다. `*p`에 쓰면 새 값이 `p`가 담고 있는 주소에 저장되므로, 포인터가 가리키는 변수가 바뀝니다:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x`와 `*p`는 같은 메모리를 부르는 두 이름입니다. `*` 없이 `p`에 대입하면 그곳에 저장된 값이 아니라, 포인터가 **어느 주소**를 담고 있는지가 바뀝니다.
