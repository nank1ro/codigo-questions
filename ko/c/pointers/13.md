# --description--

구조체에 대한 포인터는 화살표 `->`로 멤버에 접근하고, 배열에 저장된 구조체의 주소는 `&items[i]`로 구합니다. 함수는 포인터를 **반환**할 수도 있는데, 예를 들어 찾아낸 요소에 대한 포인터를 반환합니다:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
호출자는 반환된 포인터가 `NULL`이 아닌지 검사한 다음 `->`로 멤버를 읽습니다. 포인터를 반환하면 구조체 복사를 피할 수 있고, 호출자가 원본 요소를 수정할 수 있습니다.

# --instructions--

`items`의 `size`개 항목 중 `price`가 가장 낮은 항목에 대한 포인터를 반환하고, `size`가 `0`일 때는 `NULL`을 반환하도록 `cheapest`를 완성하세요

# --solutions--

```c
#include <string.h>

typedef struct {
    char name[20];
    int price;
} Item;

Item *cheapest(Item items[], int size) {
    if (size == 0) {
        return NULL;
    }
    Item *best = &items[0];
    for (int i = 1; i < size; i++) {
        if (items[i].price < best->price) {
            best = &items[i];
        }
    }
    return best;
}
```
