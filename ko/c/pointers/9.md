# --description--

`p + 1`이 다음 요소이므로, `p++`는 포인터를 제자리에서 다음 요소로 옮깁니다. 반복문은 인덱스 대신 포인터를 전진시켜 배열을 순회할 수 있습니다:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
매 차례 `p`가 가리키는 요소를 출력한 다음 `p`를 한 요소 앞으로 움직입니다.

# --instructions--

`values`에 `1`, `2`, `3`을 저장하고, `p`가 첫 번째 요소를 가리키게 한 다음, 포인터를 전진시켜 모든 요소를 출력하도록 줄을 정렬하세요
