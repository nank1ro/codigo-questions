모든 변수는 메모리 어딘가에 자리하며, 그 자리에는 **주소**라고 부르는 번호가 붙어 있습니다. `&` 연산자는 "~의 주소"라고 읽으며, 변수의 주소를 구합니다:
```c
int x = 42;
printf("%p\n", &x); // prints something like 0x7ffd5c3e9a4c
```
`%p` 서식 지정자는 주소를 출력합니다. 정확한 숫자는 실행할 때마다 달라지므로 프로그램은 절대 그 값에 의존하지 않습니다.
주소는 **포인터** 변수에 저장됩니다. 포인터는 가리키는 타입 뒤에 `*`를 붙여 선언합니다:
```c
int *p = &x; // p is a pointer to int, and it holds the address of x
```
이제 `p`는 `x`를 **가리킨다**고 말합니다. 두 포인터는 같은 주소를 담고 있을 때 같으므로 `p == &x`는 참입니다.

---

포인터 자체는 그저 주소일 뿐입니다. 그 주소에 저장된 값을 읽으려면 `*` 연산자로 포인터를 **역참조**합니다:
```c
int x = 42;
int *p = &x;
printf("%d\n", *p); // prints "42"
```
`*p`는 "`p`가 가리키는 값"이라는 뜻이며, `x` 자체와 마찬가지로 `int`입니다. 같은 기호 `*`는 두 가지 역할을 합니다: 선언 `int *p`에서는 "이것은 포인터다"라고 말하고, 표현식 `*p`에서는 포인터를 따라가 값에 도달합니다.

---

역참조한 포인터에는 **대입**할 수도 있습니다. `*p`에 쓰면 새 값이 `p`가 담고 있는 주소에 저장되므로, 포인터가 가리키는 변수가 바뀝니다:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x`와 `*p`는 같은 메모리를 부르는 두 이름입니다. `*` 없이 `p`에 대입하면 그곳에 저장된 값이 아니라, 포인터가 **어느 주소**를 담고 있는지가 바뀝니다.

---

아직 아무것도 가리키지 않는 포인터는 `NULL`을 담고 있어야 합니다. `NULL`은 `stdio.h`와 `stddef.h`에 정의된 특별한 상수로, "주소 없음"을 뜻합니다:
```c
int *p = NULL;
```
`NULL` 포인터를 역참조하는 것은 프로그램을 강제 종료시키는 런타임 오류이므로, `NULL`일 수 있는 포인터는 사용하기 전에 검사합니다:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
`NULL`은 0이므로, `if (p)`는 `if (p != NULL)`의 흔한 축약 표현입니다. 초기값 없이 선언된 포인터는 `NULL`이 아니라 쓰레기값을 담고 있으므로, 항상 포인터를 초기화하세요.

---

포인터는 어떤 타입이든 가리킬 수 있습니다: `double *`, `char *`, `bool *` 등이 그 예입니다. 선언의 타입은 포인터를 역참조할 때 몇 바이트를 읽어야 하는지, 그 바이트가 무엇을 의미하는지 컴파일러에 알려줍니다:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
포인터는 가리키는 변수의 타입과 일치해야 하며, `int *p = &price;`는 컴파일러가 거부합니다. `NULL`은 어떤 타입의 포인터에도 넣을 수 있는 유일한 값입니다.

---

`char`에 대한 포인터도 다른 포인터와 똑같이 동작합니다: 문자 하나의 주소를 담고, `*p`로 그 문자를 읽거나 씁니다:
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
포인터를 통한 읽기와 쓰기는 자유롭게 섞을 수 있습니다: `*p = *p + 1`은 `'A'`를 `'B'`로 바꿉니다.

---

포인터는 주소를 저장하며, 주소의 크기는 무엇이 저장되어 있느냐에 관계없이 주어진 기계에서 모두 같습니다. 따라서 포인터의 `sizeof`는 `char *`, `int *`, `double *`에서 모두 같습니다: 64비트 시스템에서는 `8`바이트이고 32비트 시스템에서는 `4`바이트입니다:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
포인터의 크기와 포인터가 가리키는 대상의 크기를 혼동하지 마세요: `sizeof(p)`는 주소의 크기이고, `sizeof(*p)`는 값의 크기입니다.

---

배열 이름은 표현식에서 사용되면 **첫 번째 요소**의 주소를 나타내므로, 포인터에 바로 대입할 수 있습니다:
```c
int numbers[3] = {10, 20, 30};
int *p = numbers; // same as &numbers[0]
```
포인터에 정수를 더하면 바이트가 아니라 그만큼의 **요소** 수만큼 앞으로 이동합니다: `p + 1`은 `numbers[1]`의 주소이고, `*(p + 1)`은 `20`입니다. 컴파일러가 이동 폭을 타입의 크기에 맞게 조절합니다.
인덱싱은 포인터에도 동작합니다: `p[i]`는 `*(p + i)`로 정의되므로 `p[2]`는 `30`입니다. 이것을 **포인터 산술**이라고 부릅니다.

---

`p + 1`이 다음 요소이므로, `p++`는 포인터를 제자리에서 다음 요소로 옮깁니다. 반복문은 인덱스 대신 포인터를 전진시켜 배열을 순회할 수 있습니다:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
매 차례 `p`가 가리키는 요소를 출력한 다음 `p`를 한 요소 앞으로 움직입니다.

---

배열이 함수에 전달되면 첫 번째 요소를 가리키는 포인터로 **퇴화(decay)**합니다. 그렇기 때문에 매개변수 `int values[]`와 `int *values`는 정확히 같은 의미이며, 함수가 길이를 스스로 알 수 없는 이유이기도 합니다: 함수는 주소만 받기 때문입니다.
같은 배열을 가리키는 포인터끼리는 비교하고 뺄 수 있습니다. `end - start`는 두 포인터 사이의 요소 수이며, 반복문이 포인터를 한 주소에서 다른 주소까지 진행시킬 수 있습니다:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
`numbers`와 `numbers + 3`을 전달하면 별도의 크기 매개변수 없이 처음 세 요소를 지정합니다.

---

함수 인자는 **값으로 전달**됩니다: 함수는 복사본을 받으므로, 매개변수에 대입해도 호출자의 변수는 절대 바뀌지 않습니다. 함수가 변수를 바꾸게 하려면 변수의 주소를 전달하고 함수 안에서 포인터를 역참조합니다:
```c
void reset(int *p) {
    *p = 0;
}

int counter = 7;
reset(&counter); // counter is now 0
```
고전적인 예는 두 변수를 맞바꾸는 것으로, 한 값이 덮어 써지는 동안 다른 한 값의 임시 복사본이 필요합니다.

---

함수는 `return`으로 값을 하나만 돌려줄 수 있습니다. 더 돌려주려면 호출자가 소유한 변수에 대한 포인터를 받아 그 포인터를 통해 결과를 씁니다. 이런 매개변수를 **출력 매개변수**라고 부릅니다:
```c
void min_max(int a, int b, int *min, int *max) {
    *min = a;
    *max = b;
    if (a > b) {
        *min = b;
        *max = a;
    }
}

int lo, hi;
min_max(4, 9, &lo, &hi); // lo is 4, hi is 9
```
호출자는 변수를 선언하고 주소를 전달하면, 호출이 끝난 후 변수가 채워져 있음을 알게 됩니다. 많은 표준 함수가 이 패턴을 사용하는데, `scanf("%d", &n)`에 `&`가 필요한 이유가 바로 이것입니다.

---

구조체에 대한 포인터는 화살표 `->`로 멤버에 접근하고, 배열에 저장된 구조체의 주소는 `&items[i]`로 구합니다. 함수는 포인터를 **반환**할 수도 있는데, 예를 들어 찾아낸 요소에 대한 포인터를 반환합니다:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
호출자는 반환된 포인터가 `NULL`이 아닌지 검사한 다음 `->`로 멤버를 읽습니다. 포인터를 반환하면 구조체 복사를 피할 수 있고, 호출자가 원본 요소를 수정할 수 있습니다.

---

`const`는 어디에 쓰이느냐에 따라 값이나 포인터 중 하나를 보호할 수 있습니다:
```c
const int *p = &a; // pointer to const: *p cannot be changed, p can point elsewhere
int *const q = &a; // const pointer: q always points to a, but *q can be changed
```
선언은 오른쪽에서 왼쪽으로 읽습니다: `p`는 상수 `int`에 대한 포인터이고, `q`는 `int`에 대한 상수 포인터입니다. const에 대한 포인터는 함수가 받은 것을 **읽기만** 한다고 약속하는 일반적인 방법으로, `int sum(const int *values, int size)`가 그 예입니다. 일반 변수도 전달할 수 있으며, 이 약속은 함수가 할 수 있는 일만 제한합니다.

---

포인터도 변수이므로 자체적인 주소를 가지며, 그 주소는 별표 두 개로 선언하는 **포인터에 대한 포인터**에 저장할 수 있습니다:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp`는 `p`, 즉 `x`의 주소이고, `**pp`는 두 단계를 모두 따라가 `7`에 도달합니다. 포인터에 대한 포인터를 사용하면 함수가 포인터가 담고 있는 주소를 바꿀 수 있습니다: 함수는 `&p`를 받아 `*pp`에 대입합니다.

---

종합해 봅시다: 포인터로 배열을 순회하고, 지금까지 본 가장 좋은 요소에 대한 포인터를 유지했다가 그것을 반환하거나, 반환할 것이 없을 때는 `NULL`을 반환하는 함수입니다:
```c
int *first_negative(int *values, int size) {
    for (int *p = values; p < values + size; p++) {
        if (*p < 0) {
            return p;
        }
    }
    return NULL;
}
```
호출자는 결과를 역참조하기 전에 `NULL`과 비교하고, `result - values`로 요소의 인덱스를 알아낼 수 있습니다.
