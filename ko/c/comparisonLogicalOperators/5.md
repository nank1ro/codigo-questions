# --description--

**또는** 연산자 `||`는 한쪽만 참이어도 `1`이 되고, 양쪽이 모두 거짓일 때만 `0`이 됩니다:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // "1" 출력
```
각 쪽은 완전한 비교식이어야 합니다. `day == 6 || 7`은 "6 또는 7"을 의미하지 않습니다(이유는 나중에 알게 됩니다).
