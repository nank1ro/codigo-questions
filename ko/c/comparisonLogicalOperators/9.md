# --description--

단락 평가는 함수 호출도 건너뜁니다. `0 && check()`에서는 함수 `check`가 절대 호출되지 않으므로, (카운터 증가 같은) 부수 효과도 일어나지 않습니다.

# --instructions--

# --solutions--

```c
#include <stdio.h>
int calls = 0;
int check() {
    calls++;
    return 1;
}
int main() {
    int result = 0 && check();
    printf("%d %d\n", result, calls);
    return 0;
}
```
