# --description--

`while` 루프는 조건이 0이 아닌 동안 계속 실행되므로, 비교식이 언제 멈출지를 결정합니다:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 0, 1, 2 출력
```
`<`와 `<=` 중 어느 것을 선택하는지에 따라 마지막 값이 포함되는지가 달라집니다.

# --instructions--

루프가 `1`부터 `3`까지의 숫자를 한 줄에 하나씩 출력하도록 코드를 완성하세요
