# --description--

논리 연산자는 `0`과 `1`에만 작동하는 것이 아닙니다. C에서는 **0이 아닌 값은 모두 참**으로, `0`만 거짓으로 취급됩니다.
따라서 `5 && 1`은 `1`, `0 || -3`은 `1`이며, `!`는 0이 아닌 값을 모두 `0`으로 바꿉니다:
```c
printf("%d\n", !7); // "0" 출력
printf("%d\n", !0); // "1" 출력
```
이것이 `day == 6 || 7`이 항상 참이 되는 이유입니다. `7` 자체가 참인 값이기 때문입니다.
