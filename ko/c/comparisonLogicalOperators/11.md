# --description--

`char`는 작은 정수이므로 같은 연산자로 문자를 비교할 수 있습니다.
작은따옴표로 감싼 문자 리터럴과 비교하세요:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // "1" 출력
```
큰따옴표를 사용하면 문자열이 되어 이 방식으로는 비교할 수 없습니다.
