**비교 연산자**는 두 값을 비교해 비교가 성립하면 `1`, 성립하지 않으면 `0`이라는 결과를 만듭니다.
**동등** 연산자 `==`는 두 값이 같은지 확인하고, **부등** 연산자 `!=`는 두 값이 다른지 확인합니다:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" 출력
printf("%d\n", a != b);
// "1" 출력
```
주의하세요: `==`(기호 2개)는 비교하고, `=`(기호 1개)는 값을 대입합니다.

---

다른 비교 연산자들은 두 값의 순서를 확인합니다:
- `<` 보다 작음, `>` 보다 큼
- `<=` 이하, `>=` 이상
```c
printf("%d\n", 3 < 5);  // "1" 출력
printf("%d\n", 5 >= 6); // "0" 출력
```
결과는 단순한 `int`이므로, 함수는 비교 결과를 그대로 반환할 수 있습니다:
```c
int is_big(int n) {
    return n > 100;
}
```

---

C에서 비교의 결과는 특별한 타입이 아니라, 값이 정확히 `1`(참) 또는 `0`(거짓)인 `int`입니다.
즉, 다른 숫자와 마찬가지로 `int` 변수에 저장할 수 있습니다:
```c
int n = 42;
int big = n > 100; // big은 0
```
출력에는 `true`/`false`라는 단어가 나타나지 않습니다: `printf("%d", 2 == 2)`는 `1`을 출력합니다.

---

**논리 연산자**는 여러 비교를 결합합니다. **그리고** 연산자 `&&`는 양쪽이 모두 참일 때만 `1`이 됩니다:
```c
int age = 25;
printf("%d\n", age >= 18 && age < 65); // "1" 출력
```
수학에서처럼 비교를 연달아 쓰지 마세요. `1 <= x <= 10`은 `(1 <= x) <= 10`으로 평가되며, 이는 `0` 또는 `1`을 `10`과 비교하는 것이 되어 항상 참이 됩니다.
두 비교는 항상 각각 명시적으로 쓰고 `&&`로 연결하세요.

---

**또는** 연산자 `||`는 한쪽만 참이어도 `1`이 되고, 양쪽이 모두 거짓일 때만 `0`이 됩니다:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // "1" 출력
```
각 쪽은 완전한 비교식이어야 합니다. `day == 6 || 7`은 "6 또는 7"을 의미하지 않습니다(이유는 나중에 알게 됩니다).

---

**부정** 연산자 `!`는 결과를 뒤집습니다. `!1`은 `0`이 되고 `!0`은 `1`이 됩니다.
이는 식 앞에 놓이므로, 비교식 전체를 부정하려면 괄호를 사용하세요:
```c
int n = 5;
printf("%d\n", !(n > 3)); // "0" 출력
```
괄호가 없으면 `!n > 3`은 먼저 `!n`을 계산한 뒤 이를 `3`과 비교하게 됩니다.

---

논리 연산자는 `0`과 `1`에만 작동하는 것이 아닙니다. C에서는 **0이 아닌 값은 모두 참**으로, `0`만 거짓으로 취급됩니다.
따라서 `5 && 1`은 `1`, `0 || -3`은 `1`이며, `!`는 0이 아닌 값을 모두 `0`으로 바꿉니다:
```c
printf("%d\n", !7); // "0" 출력
printf("%d\n", !0); // "1" 출력
```
이것이 `day == 6 || 7`이 항상 참이 되는 이유입니다. `7` 자체가 참인 값이기 때문입니다.

---

`&&`와 `||`는 **단락 평가**를 사용합니다. 결과가 정해지는 즉시 평가를 멈춥니다.
- `&&`에서는 왼쪽이 `0`이면 오른쪽은 절대 평가되지 않습니다
- `||`에서는 왼쪽이 참이면 오른쪽은 절대 평가되지 않습니다

이를 이용하면 위험한 연산의 왼쪽에 검사를 두어 보호할 수 있습니다:
```c
int safe = divisor != 0 && value / divisor > 2;
```
`divisor`가 `0`이면 나눗셈은 실행되지 않습니다.

---

단락 평가는 함수 호출도 건너뜁니다. `0 && check()`에서는 함수 `check`가 절대 호출되지 않으므로, (카운터 증가 같은) 부수 효과도 일어나지 않습니다.

---

연산자에는 무엇을 먼저 계산할지 정하는 **우선순위**가 있습니다:
1. `!`가 먼저 적용됩니다
2. 그다음 관계 비교 `<`, `>`, `<=`, `>=`
3. 그다음 동등 비교 `==`, `!=`
4. 그다음 `&&`
5. 마지막으로 `||`

따라서 `a > 0 && a < 10`에는 괄호가 필요 없습니다. 두 비교 모두 `&&`보다 먼저 계산되기 때문입니다.
또한 `x == 1 || y == 2 && z == 3`은 `x == 1 || (y == 2 && z == 3)`을 의미합니다. `&&`가 `||`보다 결합력이 강하기 때문입니다.

---

`char`는 작은 정수이므로 같은 연산자로 문자를 비교할 수 있습니다.
작은따옴표로 감싼 문자 리터럴과 비교하세요:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // "1" 출력
```
큰따옴표를 사용하면 문자열이 되어 이 방식으로는 비교할 수 없습니다.

---

문자는 숫자이므로 `<`와 `>`는 문자 코드를 비교하며, `'a'`, `'b'`, `'c'`나 `'0'`, `'1'`, `'2'`처럼 연속된 문자는 연속된 코드를 가집니다.
따라서 문자에 대한 범위 검사는 숫자에 대한 것과 완전히 똑같이 동작합니다:
```c
int is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

C에서 흔한 실수는 `==`를 써야 할 곳에 `=`를 쓰는 것입니다. 대입은 대입된 값을 값으로 갖는 식이므로, 이 코드는 그래도 컴파일됩니다:
```c
int x = 5;
if (x = 0) { ... } // x에 0을 대입하고, 조건은 0(거짓)이 된다
if (x = 3) { ... } // x에 3을 대입하고, 조건은 3(참)이 된다
```
대부분의 컴파일러는 이에 대해 경고를 하므로, 조건이 이상하게 동작할 때는 경고 메시지를 확인하세요.

---

`if`의 조건은 0이 아니면 참으로 취급되는 단순한 식이므로, 비교 연산자와 논리 연산자가 자연스럽게 어울립니다:
```c
if (n < 0) {
    printf("negative\n");
} else if (n == 0) {
    printf("zero\n");
}
```
결과를 먼저 저장해 두고 그 변수를 검사할 수도 있습니다. `int ok = n > 0; if (ok) { ... }`처럼 씁니다.

---

`while` 루프는 조건이 0이 아닌 동안 계속 실행되므로, 비교식이 언제 멈출지를 결정합니다:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 0, 1, 2 출력
```
`<`와 `<=` 중 어느 것을 선택하는지에 따라 마지막 값이 포함되는지가 달라집니다.

---

C99부터는 헤더 `stdbool.h`가 타입 `bool`과 상수 `true`(`1`), `false`(`0`)를 제공합니다:
```c
#include <stdbool.h>

bool ready = true;
bool done = count == 10;
```
`bool`은 내부적으로는 여전히 정수입니다. `%d`로 출력하면 `1` 또는 `0`이 표시되며, 다른 비교 결과와 마찬가지로 `&&`, `||`, `!`와 함께 사용할 수 있습니다.
`bool`을 사용하면 단순한 `int`를 반환하는 것보다 함수의 의도가 더 명확해집니다.

---

`bool` 매개변수는 `true`와 비교하지 않고도 `&&`나 `||`의 피연산자로 바로 사용할 수 있습니다. `citizen == true`가 아니라 `age >= 18 && citizen`처럼 쓰세요.

---

조건식에서 `&&`와 `||`가 섞여 있을 때는, 우선순위만으로 이미 올바르게 동작하더라도 각 그룹을 괄호로 묶으세요. 그러면 규칙을 한눈에 알아볼 수 있습니다.
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
