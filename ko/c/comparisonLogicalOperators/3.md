# --description--

C에서 비교의 결과는 특별한 타입이 아니라, 값이 정확히 `1`(참) 또는 `0`(거짓)인 `int`입니다.
즉, 다른 숫자와 마찬가지로 `int` 변수에 저장할 수 있습니다:
```c
int n = 42;
int big = n > 100; // big은 0
```
출력에는 `true`/`false`라는 단어가 나타나지 않습니다: `printf("%d", 2 == 2)`는 `1`을 출력합니다.

int result = 3 <= 3;
printf("%d\n", result);
