# --description--

**비교 연산자**는 두 값을 비교해 비교가 성립하면 `1`, 성립하지 않으면 `0`이라는 결과를 만듭니다.
**동등** 연산자 `==`는 두 값이 같은지 확인하고, **부등** 연산자 `!=`는 두 값이 다른지 확인합니다:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" 출력
printf("%d\n", a != b);
// "1" 출력
```
주의하세요: `==`(기호 2개)는 비교하고, `=`(기호 1개)는 값을 대입합니다.
