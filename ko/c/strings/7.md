# --description--

`strcat(destination, source)`는 `source`를 `destination`의 끝에 추가합니다:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
`strcpy`와 마찬가지로, 목적지 배열은 결과를 담을 수 있을 만큼 충분히 커야 합니다.
