# --description--

`strcmp`는 문자 코드를 사용하여 문자열을 한 문자씩 비교합니다.
첫 번째 문자열이 두 번째보다 앞서면 음수, 뒤에 오면 양수, 같으면 `0`이 결과가 됩니다:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

# --instructions--

`strcmp("apple", "banana")`는 무엇을 반환합니까?

# --answers--

- 음수
- 0
- 양수
- 문자열 "apple"
