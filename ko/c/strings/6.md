# --description--

배열은 선언 후에 `=`로 대입할 수 없습니다:
```c
char copy[20];
copy = "Codigo"; // error
```
문자열을 복사하려면 `string.h`의 `strcpy(destination, source)`를 사용합니다.
목적지는 모든 문자와 `'\0'`을 담을 수 있을 만큼 충분히 커야 합니다.

# --instructions--

`source`를 `copy`에 복사하고 출력하도록 줄을 정렬하세요. `source`를 `copy`보다 먼저 선언하세요
