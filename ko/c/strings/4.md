# --description--

문자열은 배열이므로, 모든 문자는 `0`부터 시작하는 인덱스를 가집니다:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
문자 하나는 `%c`로 출력합니다. 문자를 교체할 수도 있습니다:
```c
word[0] = 'K'; // word is now "Koding"
```
