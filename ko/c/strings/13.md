# --description--

`sprintf`는 `printf`처럼 동작하지만, 서식이 적용된 텍스트를 화면이 아니라 `char` 배열에 씁니다:
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer is "3 items"
```
버퍼는 전체 텍스트와 그 `'\0'`을 담을 수 있을 만큼 충분히 커야 합니다.

# --instructions--

`buffer` 안에 텍스트 `Age: 25`를 만들어 출력하도록 줄을 정렬하세요. `buffer`를 `age`보다 먼저 선언하세요

# --answers--

```c
char buffer[30];
```

```c
int age = 25;
```

```c
sprintf(buffer, "Age: %d", age);
```

```c
printf("%s\n", buffer);
```
