**관계 연산자**는 두 값을 비교합니다. 그 결과는 특별한 타입이 아닙니다. 비교가 성립하면 `1`, 그렇지 않으면 `0`인 `int`입니다. C에는 여섯 가지가 있습니다:
```c
printf("%d\n", 5 == 5); // equal: prints "1"
printf("%d\n", 5 != 5); // not equal: prints "0"
printf("%d\n", 3 < 5);  // less than: prints "1"
printf("%d\n", 3 > 5);  // greater than: prints "0"
printf("%d\n", 5 <= 5); // less than or equal: prints "1"
printf("%d\n", 4 >= 5); // greater than or equal: prints "0"
```
결과가 `int`이기 때문에 `%d`로 출력하며, 다른 숫자와 마찬가지로 `int` 변수에 저장할 수 있습니다.

---

함수는 비교 결과를 직접 반환할 수 있습니다. 호출자는 `1` 또는 `0`을 받습니다.
```c
int is_big(int n) {
    return n > 100;
}

printf("%d\n", is_big(250)); // prints "1"
```
`>`와 `>=`(또는 `<`와 `<=`) 중 무엇을 고르느냐에 따라 경계 값이 포함되는지가 결정됩니다. `n >= 100`은 `100`에서 `1`이고, `n > 100`은 `0`입니다.

---

C에서 가장 흔한 실수는 `==`를 쓰려던 자리에 `=`를 쓰는 것입니다. 단 하나의 `=`는 **대입**이며, C에서 대입은 대입된 값을 그 값으로 가지는 표현식입니다:
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
`=`를 쓴 코드도 여전히 컴파일되므로, `if (x = 0)`처럼 쓴 조건은 `x`를 검사하는 대신 조용히 `x`를 `0`으로 설정합니다. 대부분의 컴파일러는 이에 대해 경고를 출력하니 꼭 읽어 보세요.

---

**논리 연산자**는 조건을 결합합니다. **and** 연산자 `&&`는 양쪽이 모두 참일 때만 `1`을 주고, **or** 연산자 `||`는 한쪽이라도 참이면 `1`을 줍니다:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
C에서는 **0이 아닌 값은 모두 참으로 취급**되고 `0`만 거짓으로 취급되므로, `5 && 1`은 `1`이고 `0 || -3`도 `1`입니다. `&&`와 `||`의 결과는 항상 정확히 `1` 또는 `0`입니다.

---

`0` 또는 0이 아닌 값을 담고 있는 변수는 그 자체로 조건으로 사용할 수 있습니다. `holiday`만으로 "holiday가 0이 아님"을 의미하므로 `holiday != 0`이라고 쓸 필요가 없습니다.
```c
int is_open(int weekday, int holiday) {
    return weekday && !holiday;
}
```
**not** 연산자 `!`는 조건을 뒤집습니다. `!0`은 `1`이고, 0이 아닌 값에 대한 `!`는 `0`입니다.

---

`!`는 0이 아닌 값을 `0`으로, `0`을 `1`로 바꾸므로 두 번 적용하면 값을 정확히 `0` 또는 `1`로 정규화합니다. `!!42`는 `1`이고 `!!0`은 `0`입니다.
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
함수가 임의의 0이 아닌 수를 반환할 때 깔끔한 `1`을 얻고 싶다면 유용합니다.

---

C99부터 헤더 `stdbool.h`는 `bool` 타입과 상수 `true`(`1`) 및 `false`(`0`)를 제공합니다:
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
`bool`은 그 아래에서는 여전히 정수입니다. `%d`로 출력되며, 비교 결과와 완전히 똑같이 `&&`, `||`, `!`와 함께 동작합니다. 단순한 `int`보다 의도를 더 분명하게 드러낼 뿐입니다.

---

예/아니오 질문에 답하는 함수는 `bool`을 반환해야 합니다. `bool` 매개변수는 이미 조건이므로 `&&` 또는 `||`의 피연산자로 직접 사용하세요. `citizen == true`가 아니라 `age >= 18 && citizen`이라고 쓰세요.
```c
bool can_enter(int age, bool member) {
    return age >= 16 && member;
}
```
이 연습문제들에서는 `stdbool.h`가 이미 코드 위쪽에 포함되어 있습니다.

---

`&&`와 `||`는 **단락 평가**를 사용합니다. 결과가 알려지는 즉시 멈춥니다.
- `&&`의 경우 왼쪽이 `0`이면 오른쪽은 절대 평가되지 않습니다
- `||`의 경우 왼쪽이 0이 아니면 오른쪽은 절대 평가되지 않습니다

이를 통해 왼쪽의 검사가 오른쪽의 위험한 연산을 보호하게 할 수 있습니다:
```c
int ok = count != 0 && total / count > 2;
```
`count`가 `0`이면 나누기는 절대 실행되지 않으므로 프로그램이 충돌하지 않습니다.

---

단락 평가는 함수 호출도 건너뜁니다. `1 || check()`에서는 함수 `check`가 절대 호출되지 않으므로 카운터 증가 같은 부수 효과도 일어나지 않습니다.
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
`&&`나 `||` 오른쪽에 있는 함수가 여러분이 의존하는 무언가를 할 때는 이 점을 기억하세요.

---

연산자에는 무엇을 먼저 계산할지 정하는 **우선순위**가 있습니다:
1. `!`가 먼저 적용됩니다
2. 그다음 관계 비교 `<`, `>`, `<=`, `>=`
3. 그다음 동등 비교 `==`, `!=`
4. 그다음 `&&`
5. 마지막으로 `||`

따라서 `a > 0 && a < 10`에는 괄호가 필요 없고, `&&`가 `||`보다 결합력이 강하기 때문에 `a && b || c`는 `(a && b) || c`를 의미합니다. 다른 그룹으로 묶으려고 하거나 단순히 의도를 읽기 쉽게 하려면 괄호를 사용하세요.

---

`char`는 작은 정수이므로 문자도 같은 연산자로 비교합니다. 작은따옴표로 된 문자 리터럴과 비교하세요. 큰따옴표인 `"a"`는 문자열이며 이 방식으로 비교할 수 없습니다.
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // prints "1"
```
`'0'`, `'1'`, ... `'9'` 또는 `'a'`, `'b'`, ... `'z'`처럼 연이은 문자들은 코드도 연이어 있으므로, 문자에 대한 범위 검사는 숫자에 대한 것과 완전히 똑같이 동작합니다:
```c
bool is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

수학처럼 비교를 연달아 쓰지 마세요. `1 <= x <= 10`은 컴파일되지만 `(1 <= x) <= 10`으로 평가됩니다. 첫 번째 비교는 `0` 또는 `1`을 주고, 그 결과가 다시 `10`과 비교되므로 전체 표현식은 항상 `1`입니다.
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
항상 두 비교를 명시적으로 쓰고 `&&`로 연결하세요.

---

조건이 `&&`와 `||`를 섞어 쓸 때는 우선순위가 이미 올바르게 동작하더라도 각 부분을 괄호로 묶으세요. 규칙을 한눈에 읽을 수 있게 됩니다.
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
나머지 연산자 `%`는 `==`와 자연스럽게 어울립니다. `n`이 `4`로 나누어떨어지면 `n % 4 == 0`은 `1`입니다.
