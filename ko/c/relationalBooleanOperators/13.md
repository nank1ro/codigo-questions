# --description--

수학처럼 비교를 연달아 쓰지 마세요. `1 <= x <= 10`은 컴파일되지만 `(1 <= x) <= 10`으로 평가됩니다. 첫 번째 비교는 `0` 또는 `1`을 주고, 그 결과가 다시 `10`과 비교되므로 전체 표현식은 항상 `1`입니다.
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
항상 두 비교를 명시적으로 쓰고 `&&`로 연결하세요.

# --instructions--

연달아 쓴 비교는 `chained`에, 올바른 범위 검사는 `correct`에 저장하고 둘 다 출력하는 프로그램을 만들도록 줄을 정렬하세요. `chained`를 `correct`보다 먼저 정의하세요
