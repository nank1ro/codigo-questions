# --description--

C에서 가장 흔한 실수는 `==`를 쓰려던 자리에 `=`를 쓰는 것입니다. 단 하나의 `=`는 **대입**이며, C에서 대입은 대입된 값을 그 값으로 가지는 표현식입니다:
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
`=`를 쓴 코드도 여전히 컴파일되므로, `if (x = 0)`처럼 쓴 조건은 `x`를 검사하는 대신 조용히 `x`를 `0`으로 설정합니다. 대부분의 컴파일러는 이에 대해 경고를 출력하니 꼭 읽어 보세요.
