# --description--

`!`는 0이 아닌 값을 `0`으로, `0`을 `1`로 바꾸므로 두 번 적용하면 값을 정확히 `0` 또는 `1`로 정규화합니다. `!!42`는 `1`이고 `!!0`은 `0`입니다.
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
함수가 임의의 0이 아닌 수를 반환할 때 깔끔한 `1`을 얻고 싶다면 유용합니다.
