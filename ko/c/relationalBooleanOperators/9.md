# --description--

`&&`와 `||`는 **단락 평가**를 사용합니다. 결과가 알려지는 즉시 멈춥니다.
- `&&`의 경우 왼쪽이 `0`이면 오른쪽은 절대 평가되지 않습니다
- `||`의 경우 왼쪽이 0이 아니면 오른쪽은 절대 평가되지 않습니다

이를 통해 왼쪽의 검사가 오른쪽의 위험한 연산을 보호하게 할 수 있습니다:
```c
int ok = count != 0 && total / count > 2;
```
`count`가 `0`이면 나누기는 절대 실행되지 않으므로 프로그램이 충돌하지 않습니다.
