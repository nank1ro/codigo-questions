# --description--

**논리 연산자**는 조건을 결합합니다. **and** 연산자 `&&`는 양쪽이 모두 참일 때만 `1`을 주고, **or** 연산자 `||`는 한쪽이라도 참이면 `1`을 줍니다:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
C에서는 **0이 아닌 값은 모두 참으로 취급**되고 `0`만 거짓으로 취급되므로, `5 && 1`은 `1`이고 `0 || -3`도 `1`입니다. `&&`와 `||`의 결과는 항상 정확히 `1` 또는 `0`입니다.
