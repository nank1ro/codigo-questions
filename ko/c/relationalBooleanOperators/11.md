# --description--

연산자에는 무엇을 먼저 계산할지 정하는 **우선순위**가 있습니다:
1. `!`가 먼저 적용됩니다
2. 그다음 관계 비교 `<`, `>`, `<=`, `>=`
3. 그다음 동등 비교 `==`, `!=`
4. 그다음 `&&`
5. 마지막으로 `||`

따라서 `a > 0 && a < 10`에는 괄호가 필요 없고, `&&`가 `||`보다 결합력이 강하기 때문에 `a && b || c`는 `(a && b) || c`를 의미합니다. 다른 그룹으로 묶으려고 하거나 단순히 의도를 읽기 쉽게 하려면 괄호를 사용하세요.

# --instructions--

`without`이 기본 우선순위로 `a && b || c`를 계산하고 `with`가 `b || c`를 먼저 평가하도록 강제하게 만든 뒤 둘 다 출력하도록 코드를 완성하세요
