# --description--

C99부터 헤더 `stdbool.h`는 `bool` 타입과 상수 `true`(`1`) 및 `false`(`0`)를 제공합니다:
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
`bool`은 그 아래에서는 여전히 정수입니다. `%d`로 출력되며, 비교 결과와 완전히 똑같이 `&&`, `||`, `!`와 함께 동작합니다. 단순한 `int`보다 의도를 더 분명하게 드러낼 뿐입니다.

# --instructions--

`open`이 참에 해당하는 불리언 상수가 되고 `closed`가 그 부정이 되도록 코드를 완성한 뒤 둘 다 출력하세요
