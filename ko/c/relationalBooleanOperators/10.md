# --description--

단락 평가는 함수 호출도 건너뜁니다. `1 || check()`에서는 함수 `check`가 절대 호출되지 않으므로 카운터 증가 같은 부수 효과도 일어나지 않습니다.
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
`&&`나 `||` 오른쪽에 있는 함수가 여러분이 의존하는 무언가를 할 때는 이 점을 기억하세요.

    printf("%d %d\n", result, calls);
    return 0;
}
