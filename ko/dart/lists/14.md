# --description--

`.isEmpty` 속성은 리스트에 요소가 없을 때 `true`이고, `.isNotEmpty`는 요소가 하나 이상 있을 때 `true`입니다.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
