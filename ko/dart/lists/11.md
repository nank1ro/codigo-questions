# --description--

`.remove(value)` 메서드는 리스트에서 `value`와 같은 **첫 번째** 요소를 제거합니다. 요소가 제거되었으면 `true`, 값을 찾지 못했으면 `false`를 반환합니다.

```dart
var colors = ['red', 'green', 'blue'];
bool removed = colors.remove('green');
print(removed); // true
print(colors); // [red, blue]
```
