# --description--

`Isolate.spawn`은 진입점에 정확히 **하나의** 메시지를 전달하며, 워커는 보통 답장할 `SendPort`와 작업할 데이터 둘 다 필요로 합니다. 흔한 요령은 모든 것을 하나의 `List`로 묶어 반대쪽에서 풀어내는 것입니다:

```dart
void multiply(List<Object> message) {
  final port = message[0] as SendPort;
  final value = message[1] as int;
  port.send(value * 2);
}

Future<void> main() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(multiply, <Object>[receivePort.sendPort, 21]);
  print(await receivePort.first); // 42
}
```

리스트는 들어가는 길에 복사되므로 워커는 자신만의 값을 읽습니다. `SendPort`는 복사되지 않고 공유되는 몇 안 되는 것 중 하나입니다. 자신을 만든 isolate의 우편함을 계속 가리키며, 바로 그 이유로 반송 주소로 쓸 수 있습니다.

# --instructions--

`List<Object>` `message`를 받아 요소 `0`이 `SendPort`이고 요소 `1`과 `2`가 `int`일 때 그 합을 포트에 보내는 최상위 함수 `sendSum`을 작성하세요.

그다음 두 `int` `a`와 `b`를 받아 생성된 `sendSum` isolate가 계산한 합으로 완료되는 `Future<int>`를 반환하는 함수 `addInIsolate`를 작성하세요.

예시:
```dart
print(await addInIsolate(2, 3)); // 5
```

# --solutions--

```dart
void sendSum(List<Object> message) {
  final port = message[0] as SendPort;
  final a = message[1] as int;
  final b = message[2] as int;
  port.send(a + b);
}

Future<int> addInIsolate(int a, int b) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendSum, <Object>[receivePort.sendPort, a, b]);
  return await receivePort.first as int;
}
```
