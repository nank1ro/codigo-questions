# --description--

조합해 보면 `Isolate.run` 프로그램은 평범한 순차 코드처럼 읽힙니다. 호출 전의 줄은 main isolate에서 실행되고, 계산은 다른 곳에서 실행되며, `await` 뒤의 줄은 결과를 손에 든 채 main isolate로 돌아와 실행됩니다.

```dart
import 'dart:isolate';

int twice(int n) => n * 2;

Future<void> main() async {
  print('start');
  final result = await Isolate.run(() => twice(4));
  print(result);
}
// start
// 8
```

# --instructions--

코드 라인을 정렬하여 `start`를 출력하고, `Isolate.run`으로 다른 isolate에서 `9`를 제곱한 뒤 그 결과를 출력하는 프로그램을 만드세요. import를 가장 먼저 놓고 `main` 전에 `square`를 정의하세요. 프로그램은 다음을 출력해야 합니다:

```
start
81
```
