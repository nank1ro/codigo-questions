# --description--

일련의 메시지 전체를 모으는 것은 하나의 레시피를 따릅니다. 루프 전에 빈 리스트를 만들고, 진짜 메시지마다 한 번 `add`하고, 스트림을 끝내는 신호에서 `close()`를 호출합니다. 포트가 닫히면 `await for`가 끝나고 함수는 반환할 수 있습니다:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

메시지는 보내진 순서를 유지하므로, 여러분이 만든 리스트는 다른 isolate의 작업을 단계별로 반영합니다.

# --instructions--

`List<Object>` `message`를 받아 요소 `0`이 `SendPort`이고 요소 `1`이 `List<String>`일 때 모든 단어를 포트에 보낸 다음, 끝을 알리는 신호로 `null`을 보내는 최상위 함수 `sendWords`를 작성하세요.

그다음 `List<String>` `words`를 받아 생성된 `sendWords` isolate에서 받은 모든 단어로 완료되는 `Future<List<String>>`를 반환하는 함수 `collectWords`를 작성하세요.

예시:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

# --solutions--

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
