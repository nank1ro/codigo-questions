> 시작하기 전에, Dart를 가르칠 수 있게 되어 매우 기쁘다는 말씀을 드리고 싶습니다.
이 메시지를 통해 여러분이 사용하고 있는 이 앱이 바로 Dart로 작성되었으며, Flutter 프레임워크를 사용했다는 것을 알려드립니다. 이 언어에 대한 전문 지식을 공유할 수 있게 되어 영광입니다.

Dart는 다른 많은 프로그래밍 언어와 마찬가지로 코드를 문서화할 수 있습니다.
이를 통해 코드 옆에 원하는 텍스트를 작성할 수 있습니다.
주석은 컴파일러에 의해 무시됩니다.

Dart는 _한 줄_ 주석, _여러 줄_ 주석, 그리고 _문서화_ 주석을 지원합니다.

다음은 _한 줄_ 주석을 작성하는 방법입니다:
```dart
// This is a comment. It is not executed.
```

---

_한 줄_ 주석을 쌓아서 _여러 줄_ 주석을 작성할 수 있습니다.
```dart
// This is a
// multi-line comment
```

---

주석 블록, 즉 _여러 줄_ 주석을 만들 수도 있습니다.
_여러 줄_ 주석은 `/*`로 시작하고 `*/`로 끝납니다.
```dart
/*
This is a multi-line
comment
*/
```

---

이 두 가지 주석 작성 방법 외에도, Dart에는 _문서화 주석_이 있습니다.

_문서화 주석_은 `///` 또는 `/**`로 시작하는 여러 줄 또는 한 줄 주석입니다. 연속된 줄에서 `///`를 사용하면 여러 줄 문서화 주석과 동일한 효과가 있습니다.

_문서화 주석_은 문서를 자동으로 생성할 수 있게 해주므로 매우 유용합니다.
특정 코드 블록이 무엇을 하는지 명확하게 하기 위해 코드에 _문서화 주석_을 추가하는 것이 좋습니다.

_문서화 주석_ 내에서 분석기는 대괄호로 묶인 이름을 다른 API 요소에 대한 참조로 해석합니다.
대괄호를 사용하여 _클래스_, _메서드_, _필드_, _변수_, _함수_ 및 _매개변수_를 참조할 수 있습니다.

다음은 예시입니다:
```dart
/// 길들여진 남아메리카산 낙타과 동물 (Lama glama).
///
/// 다른 동물과 마찬가지로 llama도 먹어야 하니,
/// llama에게 [food]를 먹이는 것을 잊지 말도록.
class Llama {
  String? name;

  /// llama에게 [food]를 먹인다.
  ///
  /// 보통 llama는 일주일에 건초 한 단을 먹는다.
  void feed(Food food) {
    // ...
  }

  /// [activity]로 llama를 운동시키는 시간
  /// [timeLimit]분.
  void exercise(Activity activity, int timeLimit) {
    // ...
  }
}
```

생성된 문서에서 `[feed]`는 `feed` 메서드의 문서에 대한 링크가 되고, `[Food]`는 `Food` 클래스의 문서에 대한 링크가 됩니다.
`[activity]`와 `[timeLimit]`는 각각 `activity`와 `timeLimit`의 문서에 대한 링크가 됩니다.
