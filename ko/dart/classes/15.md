# --description--

**팩토리 생성자**는 `factory` 키워드를 사용하며, 객체 생성을 제어할 수 있게 해줍니다. 예를 들어 캐시된 인스턴스나 서브타입을 반환할 수 있습니다:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

`Logger()`를 호출할 때마다 같은 인스턴스가 반환됩니다(싱글턴 패턴).

# --instructions--

`0`으로 초기화된 비공개 필드 `_count`를 가진 클래스 `Counter`를 만드세요. `_count`를 `1`만큼 증가시키는 인스턴스 메서드 `increment()`와, `_count`를 반환하는 게터 `count`를 추가하세요. 항상 `_count = 0`으로 초기화된 새 `Counter`를 반환하는 `factory` 생성자 `Counter.start()`를 사용하세요(이름 있는 비공개 생성자 `Counter._internal()` 사용).

```dart
class Counter {
  int _count = 0;

  Counter._internal();

  factory Counter.start() => Counter._internal();

  void increment() {
    _count++;
  }

  int get count => _count;
}
```
