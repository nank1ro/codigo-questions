# --description--

클래스는 각 객체의 데이터를 담는 **인스턴스 변수**(필드라고도 함)를 가질 수 있습니다. 클래스 본문 안에서 선언하며, 각각에 초기값을 부여합니다:

```dart
class Animal {
  String name = '';
  int age = 0;
}
```

이 클래스로 만들어진 각 객체는 자신만의 `name`과 `age`를 갖습니다.
