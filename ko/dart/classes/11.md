# --description--

서브클래스의 생성자가 슈퍼클래스의 생성자를 호출해야 할 때는 **초기화 목록**에서 `super` 키워드를 사용합니다:

```dart
class Vehicle {
  String brand;
  Vehicle(this.brand);
}

class Car extends Vehicle {
  int doors;
  Car(String brand, this.doors) : super(brand);
}
```

`super(brand)`는 `brand` 인자를 `Vehicle`의 생성자에 전달합니다.
