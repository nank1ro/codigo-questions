# --description--

**메서드**는 클래스 안에 정의된 함수입니다. 메서드는 객체의 동작을 나타냅니다:

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() {
    print('$name makes a sound.');
  }
}
```

메서드는 점 표기법으로 객체에 대해 호출합니다: `dog.speak()`.
