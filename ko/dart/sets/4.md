# --description--

`.remove(value)` 메서드는 Set에서 값을 삭제합니다. 값이 있었으면 `true`를, 없었으면 `false`를 반환합니다:

```dart
var numbers = {1, 2, 3};
print(numbers.remove(2)); // true
print(numbers.remove(9)); // false
print(numbers); // {1, 3}
```

모든 요소를 한 번에 삭제하려면 `.clear()`를 사용하세요.
