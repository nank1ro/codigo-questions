# --description--

Set은 `Iterable`이므로 리스트와 마찬가지로 `for-in`으로 요소를 직접 반복할 수 있습니다. 인덱스는 없으며 요소는 삽입 순서로 방문됩니다:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
