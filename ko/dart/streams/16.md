# --instructions--

`Stream<int>` `source`를 받아 그 값들의 합으로 완료되는 `Future<int>`를 반환하는 함수 `sumUntilError`를 작성하세요. 스트림이 오류를 내보내면 예외를 던지는 대신 멈추고, 오류 **이전**에 받은 값들의 합으로 완료하세요.

예시:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
