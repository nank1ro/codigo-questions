# --description--

지금까지 본 스트림은 **단일 구독** 스트림입니다. 리스너를 정확히 하나만 허용하죠. `listen`, `await for` 또는 소비 메서드를 두 번째로 호출하면 `StateError`("Stream has already been listened to")가 던져집니다.

스트림을 여러 리스너가 공유하려면 `asBroadcastStream()`으로 **브로드캐스트** 스트림으로 변환하세요:

```dart
final shared = Stream.fromIterable([1, 2, 3]).asBroadcastStream();
final total = shared.reduce((a, b) => a + b);
final count = shared.length;
print(await total); // 6
print(await count); // 3
```

브로드캐스트 스트림은 버퍼링하지 않습니다. 리스너는 구독한 **이후**에 내보내진 이벤트만 받습니다. 예시에서는 두 리스너 모두 첫 `await` 전에 구독하므로, 둘 다 모든 이벤트를 받습니다.

# --instructions--

`Stream<int>` `source`를 받아 값들의 합과 값의 개수라는 두 요소의 리스트로 완료되는 `Future<List<int>>`를 반환하는 함수 `sumAndCount`를 작성하세요. `source`를 브로드캐스트 스트림으로 변환하고, 둘 중 어느 것도 기다리기 **전에** 두 소비 호출을 모두 시작한 다음 기다리세요. 스트림에는 항상 최소 하나의 이벤트가 있습니다.

예시:
```dart
print(await sumAndCount(Stream.fromIterable([1, 2, 3]))); // [6, 3]
```

```dart
Future<List<int>> sumAndCount(Stream<int> source) async {
  final shared = source.asBroadcastStream();
  final sum = shared.reduce((a, b) => a + b);
  final count = shared.length;
  return [await sum, await count];
}
```
