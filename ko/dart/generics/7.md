# --description--

클래스는 쉼표로 구분하여 둘 이상의 타입 매개변수를 선언할 수 있습니다. `Map<K, V>`가 내장 예시입니다: 키용 타입 하나, 값용 타입 하나입니다.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

**순서**는 타입의 일부입니다: `Entry<String, int>`와 `Entry<int, String>`은 관련 없는 타입이며, 한쪽의 값을 다른 쪽에 할당할 수 없습니다. 타입 매개변수는 반환 타입에서 순서를 바꿀 수도 있는데, 이것이 메서드가 뒤집힌 버전의 객체를 돌려주는 방법입니다:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

타입 매개변수 `A`와 `B` 두 개, 생성자로 설정되는 `A` 타입의 `final` 필드 `first`와 `B` 타입의 `final` 필드 `second`, 그리고 같은 두 값을 반대 순서로 담는 `Pair<B, A>`를 반환하는 게터 `swapped`를 가진 제네릭 클래스 `Pair`를 선언하세요.

예:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

# --asserts--

`Pair<String, int>('age', 30)`의 `first`는 `'age'`이고 `second`는 `30`이어야 합니다

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped`는 값이 서로 바뀐 `Pair<int, String>`를 반환해야 합니다

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair`는 어떤 두 타입으로도 동작해야 하고, 두 번 바꾸면 원래 값이 돌아와야 합니다

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
    expect(pair.swapped.second, true, reason: '--err-t3--');
    expect(pair.swapped.swapped, isA<Pair<bool, String>>(), reason: '--err-t3--');
    expect(pair.swapped.swapped.first, true, reason: '--err-t3--');
  });
```

# --solutions--

```dart
class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
