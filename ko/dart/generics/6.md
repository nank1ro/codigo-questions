# --description--

제네릭 클래스 안에서 타입 매개변수는 어디에서나 볼 수 있습니다: 필드, 생성자 매개변수, 메서드 시그니처, 메서드 본문 어디에서나. 클래스 이름 옆에 한 번 선언되면 모든 멤버가 사용할 수 있습니다.

```dart
class Holder<T> {
  final T item;

  Holder(this.item);

  String describe() => 'holding $item';
}
```

객체를 생성하는 것이 타입을 결정합니다: `Holder<String>('fig')`는 `item`을 `String`으로 만들고, `Holder<int>(3)`은 이를 `int`로 만듭니다.

# --instructions--

항목을 정렬하여 필드 `item`(타입 `T`), 생성자, 메서드 `describe`를 가진 제네릭 클래스 `Holder`, 그리고 `'fig'`로 만든 `Holder<String>`의 설명을 출력하는 `main`을 정의하세요. 클래스를 `main`보다 먼저 정의합니다. 프로그램은 다음을 출력해야 합니다:

```
holding fig
```
