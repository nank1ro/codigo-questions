# --description--

Dart가 제공하는 제네릭 클래스에만 국한되지 않습니다: 직접 선언할 수도 있습니다. **타입 매개변수**는 클래스 이름 뒤 꺾쇠 괄호 사이에 오며, 그 이후로는 본문 안에서 일반 타입처럼 사용됩니다:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T`는 단지 자리표시자일 뿐입니다. `Box`가 생성될 때 명시적으로 또는 추론을 통해 채워집니다:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, 인자로부터 추론됨
print(a.value + 1);      // 8, 컴파일러는 value가 int임을 앎
```

문자 자체는 중요하지 않습니다: `T`는 "타입"을 위한 관례일 뿐 그 이상도 이하도 아닙니다.

# --instructions--

타입 매개변수 `T` 하나, 생성자로 설정되는 `T` 타입의 `final` 필드 `value`, 그리고 `Box of ` 뒤에 값을 이어 붙인 텍스트를 반환하는 게터 `label`을 가진 제네릭 클래스 `Box`를 선언하세요.

예:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

# --asserts--

`Box<int>(7)`의 `value`는 `7`이고 `label`은 `'Box of 7'`이어야 합니다

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box`는 어떤 타입으로도 동작해야 하므로, `Box<String>('fig')` 역시 `Box<String>`이어야 합니다

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

타입 인수는 생성자 인수로부터 추론되어야 합니다

```dart
  test('test3', () {
    expect(Box(true), isA<Box<bool>>(), reason: '--err-t3--');
    expect(Box(true).label, 'Box of true', reason: '--err-t3--');
  });
```
