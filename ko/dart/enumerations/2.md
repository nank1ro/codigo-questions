# --description--

모든 enum 값은 두 가지 내장 프로퍼티를 가집니다:

- `name`은 값의 이름을 `String`으로 나타낸 것
- `index`는 선언에서의 위치이며, `0`부터 시작합니다

```dart
enum Direction { north, south, east, west }

print(Direction.east.name);  // east
print(Direction.east.index); // 2
```
