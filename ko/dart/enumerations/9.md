# --instructions--

`enum Size { small, medium, large }`가 주어졌을 때, 다음 코드는 어떻게 됩니까?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- 컴파일되지 않는다: enum에 대한 switch 표현식은 모든 값을 다루어야 한다
- 컴파일되며, `Size.large`에 대해 `null`을 반환한다
- 컴파일되며, `Size.large`에 대해 런타임에 예외를 던진다
- 컴파일되며, `Size.large`에 대해 자동으로 `'L'`을 반환한다
