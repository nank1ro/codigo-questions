# --description--

Dart는 **선택적 위치 매개변수**도 지원합니다 — 대괄호 `[]`로 감싼 매개변수입니다. 위치로 전달되며, 호출자가 생략할 수 있고, 기본값을 가질 수 있습니다：

```dart
String greet([String name = "World"]) {
  return "Hello, $name!";
}

void main() {
  print(greet());         // Hello, World!
  print(greet("Alice"));  // Hello, Alice!
}
```

# --instructions--

**기본값**이 `"World"`인 **선택적 위치** `String` 매개변수 `name`을 받아 문자열 `"Hello, <name>!"`을 반환하는 함수 `greetUser`를 작성하세요.

예시:
```dart
print(greetUser());          // Hello, World!
print(greetUser("Alice"));   // Hello, Alice!
```
