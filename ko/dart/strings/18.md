# --description--

문자열 메서드는 문자열을 반환하므로, 계속해서 **체이닝**할 수 있습니다. `.split('')`, 리스트 프로퍼티인 `.reversed`, `.join()`을 조합하면 하나의 식으로 문자열을 뒤집을 수 있습니다:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

**회문**(palindrome)은 `level`처럼 앞뒤로 읽어도 같은 텍스트입니다.

# --instructions--

`String`형 매개변수 `text`를 받아, 대소문자와 공백을 무시했을 때 회문이면 `true`를, 아니면 `false`를 반환하는 함수 `isPalindrome`을 작성하세요.

예시:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

```dart
bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
```
