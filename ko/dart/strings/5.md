# --description--

Dart의 문자열은 **불변**입니다: 한 번 만들어진 문자열은 절대 변경되지 않습니다. `.toUpperCase()`나 `.toLowerCase()` 같은 메서드는 원본 문자열을 수정하지 않고 **새로운 문자열을 반환**합니다:

```dart
var word = 'Dart';
var loud = word.toUpperCase();
print(loud);  // DART
print(word);  // Dart
```

변수가 새 값을 갖도록 하려면 결과를 다시 대입하세요: `word = word.toUpperCase();`.
