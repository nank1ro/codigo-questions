# --description--

`.replaceAll(from, to)` 메서드는 `from`이 나타나는 **모든** 부분을 `to`로 바꾼 새 문자열을 반환합니다. `.replaceFirst(from, to)`는 첫 번째 것만 바꿉니다:

```dart
var text = 'a-b-c';
print(text.replaceAll('-', '+'));    // a+b+c
print(text.replaceFirst('-', '+'));  // a+b-c
```
