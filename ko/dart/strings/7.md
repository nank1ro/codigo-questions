# --description--

`.substring(start, end)` 메서드는 인덱스 `start`부터 인덱스 `end` 직전까지(`end`는 **포함하지 않음**)의 부분 문자열을 반환합니다. `end`를 생략하면 문자열 끝까지 모두 가져옵니다:

```dart
var text = 'Hello Dart';
print(text.substring(0, 5));  // Hello
print(text.substring(6));     // Dart
```
