# --description--

존재하지 않는 키를 읽어도 절대 에러가 발생하지 않으므로, 조회 결과가 `null`일 수 있다는 점을 항상 고려하세요. 안전한 패턴은 `??` 연산자로 대체 값을 제공하는 것입니다:

```dart
var ages = {'Ann': 30};
int age = ages['Zed'] ?? 0;
print(age); // 0
```

# --instructions--

다음 코드는 무엇을 출력합니까?

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Zed']);
```

- `null`
- `0`
- 에러가 발생한다
- 빈 문자열
