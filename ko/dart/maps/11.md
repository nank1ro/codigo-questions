# --description--

`.forEach()` 메서드는 모든 쌍에 대해 함수를 한 번씩 실행합니다. 이 함수는 키와 값이라는 두 개의 매개변수를 받습니다:

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
