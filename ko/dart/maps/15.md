# --description--

`.putIfAbsent(key, ifAbsent)` 메서드는 키가 아직 맵에 없을 때만 쌍을 추가합니다. 두 번째 인수는 값을 생성하는 함수입니다. 키가 이미 존재하면 맵은 변경되지 않습니다. 두 경우 모두 그 키 아래에 현재 저장된 값이 반환됩니다:

```dart
var ages = {'Ann': 30};
ages.putIfAbsent('Ann', () => 99); // Ann is already there, nothing changes
ages.putIfAbsent('Bob', () => 25); // Bob is added
print(ages); // {Ann: 30, Bob: 25}
```

# --instructions--

맵 `ages`가 주어졌을 때, `.putIfAbsent()`를 두 번 사용하세요: 먼저 키 `'Ann'`에 값 `99`로, 그다음 키 `'Bob'`에 값 `25`로 사용하세요.
