# --description--

값을 읽으려면 리스트의 인덱스와 마찬가지로 대괄호 안에 키를 사용합니다:

```dart
var ages = {'Ann': 30, 'Bob': 25};
print(ages['Ann']); // 30
```

키가 맵에 없으면 조회는 에러를 발생시키지 **않고** `null`을 반환합니다. 이런 이유로 `ages['Ann']`의 타입은 `int`가 아니라 `int?`(널이 될 수 있는 `int`)입니다:

```dart
print(ages['Zed']); // null
```
