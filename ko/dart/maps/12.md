# --description--

맵은 `Iterable`이 아니므로 `for-in`으로 직접 순회할 수 없습니다. 대신 `.entries`를 순회하세요: 각 요소는 `.key`와 `.value`를 가진 `MapEntry`입니다:

```dart
var ages = {'Ann': 30, 'Bob': 25};
for (var entry in ages.entries) {
  print('${entry.key}: ${entry.value}');
}
// Ann: 30
// Bob: 25
```

# --instructions--

맵 `ages`가 주어졌을 때, `for-in`으로 그 `.entries`를 순회하며 각 쌍마다 `'Ann is 30'` 형태의 문자열 하나를 `List<String>` `lines`에 추가하세요.
