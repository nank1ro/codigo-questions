# --description--

`.update(key, update)` 메서드는 기존 키의 값을 교체합니다. 두 번째 인수는 현재 값을 받아 새 값을 반환하는 함수입니다. 키가 없으면 `.update()`는 에러를 발생시키지만, 초기값을 생성하는 `ifAbsent` 함수를 전달하면 예외입니다:

```dart
var stock = {'apple': 3};
stock.update('apple', (n) => n + 1); // apple becomes 4
stock.update('kiwi', (n) => n + 1, ifAbsent: () => 1); // kiwi is added with 1
print(stock); // {apple: 4, kiwi: 1}
```

# --instructions--

맵 `stock`이 주어졌을 때, `.update()`를 사용해 `'apple'`의 값을 두 배로 만들고, 그다음 `ifAbsent`와 함께 `.update()`를 키 `'kiwi'`에 사용해 값 `5`로 추가되도록 하세요.
