# --description--

`.keys` 속성은 맵의 모든 키를, `.values`는 모든 값을 삽입 순서대로 제공합니다. 둘 다 지연 평가되는 `Iterable`이므로, 실제 `List`가 필요하면 `.toList()`를 호출하세요:

```dart
var ages = {'Ann': 30, 'Bob': 25};
List<String> names = ages.keys.toList();
List<int> years = ages.values.toList();
print(names); // [Ann, Bob]
print(years); // [30, 25]
```
