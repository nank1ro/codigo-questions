# --description--

빈 맵 리터럴 `{}`은 타입을 추론할 쌍이 없으므로, `<K, V>{}`나 타입 어노테이션으로 명시적인 타입을 지정하세요:

```dart
var cart = <String, int>{};
Map<String, int> other = {};
```

`.isEmpty` 속성은 맵에 쌍이 하나도 없을 때 `true`이고, `.isNotEmpty`는 하나라도 있을 때 `true`입니다:

```dart
print(cart.isEmpty); // true
cart['pen'] = 2;
print(cart.isNotEmpty); // true
```
