# --description--

`map[key] = value`로 대입하면, 키가 아직 맵에 없을 때는 새 쌍을 **추가**하고, 이미 존재하는 키라면 그 값을 **업데이트**합니다:

```dart
var ages = {'Ann': 30};
ages['Bob'] = 25; // adds Bob
ages['Ann'] = 31; // updates Ann
print(ages); // {Ann: 31, Bob: 25}
```

새 키는 기존 키 뒤에 추가되므로, 맵은 삽입 순서를 기억합니다.
