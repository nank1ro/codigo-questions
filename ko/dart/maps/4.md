# --description--

`.remove(key)` 메서드는 맵에서 키와 그 값을 삭제합니다. 삭제된 값을 반환하며, 키가 없었다면 `null`을 반환합니다:

```dart
var ages = {'Ann': 30, 'Bob': 25};
int? removed = ages.remove('Ann');
print(removed); // 30
print(ages); // {Bob: 25}
```

`.length` 속성은 키-값 쌍의 개수를 반환합니다:

```dart
print(ages.length); // 1
```
