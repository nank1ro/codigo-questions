# --description--

익명 함수는 이름 있는 함수와 완전히 같은 방식으로 매개변수를 받고 값을 `return`할 수 있습니다. 반환 타입은 쓰지 않습니다. Dart가 본문의 `return` 문으로부터 **추론**합니다:

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
