# --description--

클로저는 자신이 캡처한 변수를 읽기만 하는 것이 아니라 그 변수를 **수정**할 수도 있으며, 변경 사항은 호출 사이에 유지됩니다. 이 덕분에 클래스 없이도 비공개 상태를 유지할 수 있습니다:

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

`makeTimer()`를 호출할 때마다 완전히 새로운 `seconds` 변수가 만들어지므로, 두 타이머가 개수를 공유하는 일은 없습니다.

# --instructions--

매개변수 없이 `int Function()` 타입의 함수를 반환하는 함수 `makeCounter`를 작성하세요. 반환된 함수가 호출될 때마다 캡처된 카운터를 증가시키고 반환해야 하며, `1`부터 시작합니다.

예시:
```dart
var counter = makeCounter();
print(counter()); // 1
print(counter()); // 2
```
