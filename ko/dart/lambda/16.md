# --description--

다른 함수를 받고 반환하는 함수들은 자유롭게 조합할 수 있습니다. 고전적인 예가 **합성**입니다. 하나의 함수를 실행한 다음 그 결과를 다른 함수에 넘기는 새로운 함수를 만드는 것입니다:

```dart
int Function(int) then(int Function(int) first, int Function(int) second) {
  return (n) => second(first(n));
}
```

# --instructions--

`int Function(int)` 타입의 두 매개변수 `f`와 `g`를 받아, 인자에 `f`를 적용한 다음 그 결과에 `g`를 적용하는 `int Function(int)` 타입의 함수를 반환하는 함수 `compose`를 작성하세요.

예시:
```dart
var addThenDouble = compose((n) => n + 1, (n) => n * 2);
print(addThenDouble(3)); // 8
```
