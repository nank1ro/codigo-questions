# --description--

조각들을 합치면, 믹스인을 사용하는 프로그램은 세 부분으로 이루어집니다. `mixin` 선언, `with`로 이를 가져오는 하나 이상의 클래스, 그리고 공유 멤버를 호출하는 코드입니다.

```dart
mixin Barker {
  String bark() => 'Woof!';
}

class Dog with Barker {}

void main() {
  print(Dog().bark()); // Woof!
}
```

최상위 선언은 Dart에서 어떤 순서로든 작성할 수 있지만, 믹스인이 이를 사용하는 클래스보다 앞에 오면 파일을 위에서 아래로 읽기가 더 쉽습니다.
