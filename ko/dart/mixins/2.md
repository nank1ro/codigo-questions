# --description--

믹스인의 본문은 클래스의 본문과 똑같이 보입니다. 메서드, 게터, 필드를 완전히 같은 방식으로 작성합니다. 차이는 선언 자체로 할 수 있는 일에 있습니다.

```dart
mixin Timestamped {
  String get stamp => '[log]';

  String format(String text) => '$stamp $text';
}

class Server with Timestamped {}
class Printer with Timestamped {}
```

믹스인의 이름은 **타입**이기도 합니다. 그래서 `Server() is Timestamped`는 `true`이고 변수를 `Timestamped t = Server();`로 선언할 수 있습니다. 이제 관련 없는 두 클래스가 서로를 상속하지 않고도 하나의 구현을 공유합니다.

# --instructions--

`String` 타입의 `text`를 받아 대문자로 바꾸고 뒤에 느낌표를 붙여 반환하는 메서드 `shout`를 가진 믹스인 `Shouter`를 선언하세요.

`Shouter`를 사용하고 자체 멤버는 아무것도 추가하지 않는 클래스 `Speaker`를 선언하세요.

예:
```dart
print(Speaker().shout('hi')); // HI!
```

# --asserts--

`Speaker().shout('hi')`는 `'HI!'`이어야 합니다

```dart
  test('test1', () {
    expect(Speaker().shout('hi'), 'HI!', reason: '--err-t1--');
  });
```

`Speaker().shout('Dart rocks')`는 `'DART ROCKS!'`이어야 하고 `Speaker().shout('')`는 `'!'`이어야 합니다

```dart
  test('test2', () {
    expect(Speaker().shout('Dart rocks'), 'DART ROCKS!', reason: '--err-t2--');
    expect(Speaker().shout(''), '!', reason: '--err-t2--');
  });
```

`Speaker`는 믹스인에서 `shout`를 받아야 하므로 `Speaker`는 `Shouter`이기도 해야 합니다

```dart
  test('test3', () {
    expect(Speaker(), isA<Shouter>(), reason: '--err-t3--');
  });
```
