# --description--

믹스인에 `on` 절이 있으면 그 타입의 멤버를 **재정의**할 수 있고, 체인에서 자기 아래에 있는 버전에 도달하기 위해 **`super`**를 호출할 수 있습니다:

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log`는 믹스인 자신의 `log`가 아니라 그 아래에 있는 것입니다. 따라서 무한 재귀는 일어나지 않습니다. 이런 믹스인들을 `with A, B`로 여러 개 쌓으면 각 믹스인이 이전 믹스인을 감쌉니다. 호출은 **마지막** 믹스인에 먼저 들어와 슈퍼클래스까지 내려갑니다.

# --instructions--

`String` 타입의 `input`을 받아 그대로 반환하는 메서드 `run`을 가진 클래스 `Pipeline`을 선언하세요.

`Pipeline`에 대한 믹스인 `Trimmed`(trim한 입력을 `super.run`에 전달하여 `run`을 재정의)와, `Pipeline`에 대한 믹스인 `Upper`(`super.run`의 결과를 대문자로 반환하여 `run`을 재정의)를 선언하세요.

`Pipeline`을 상속하고 `Trimmed`에 이어 `Upper`를 사용하는 클래스 `TextPipeline`과, `Pipeline`을 상속하고 `Trimmed`만 사용하는 클래스 `TrimOnly`를 선언하세요.

예:
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

# --solutions--

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
