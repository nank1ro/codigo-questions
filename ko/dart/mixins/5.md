# --description--

믹스인은 **본문 없이** 멤버를 선언할 수도 있습니다. 그런 멤버는 추상 멤버입니다. 믹스인이 이를 사용하고, 믹스인을 가져오는 클래스가 이를 제공해야 합니다.

```dart
mixin Greeting {
  String get name;                       // no body: the class provides it

  String greet() => 'Hello, $name!';
}

class Person with Greeting {
  @override
  final String name;

  Person(this.name);
}

void main() {
  print(Person('Ada').greet()); // Hello, Ada!
}
```

동작은 믹스인이 가져오고 데이터는 클래스가 가져옵니다. `final String name;` 같은 클래스의 필드만으로도 같은 이름의 추상 게터를 만족할 수 있습니다.

# --instructions--

본문 없이 선언된 `String` 타입의 추상 게터 `title`과, `title`을 대괄호로 감싸 반환하는 메서드 `label`을 가진 믹스인 `Labelled`를 선언하세요.

`Labelled`를 사용하고, `final String` 필드 `title`과 이를 받는 생성자를 가진 클래스 `Book`을 선언하세요.

예:
```dart
print(Book('Dune').label()); // [Dune]
```
