# --description--

쌓인 믹스인은 작고 독립적인 규칙들을 하나의 클래스로 결합하는 방법입니다. 각 믹스인은 같은 멤버를 재정의하고 자기 몫을 한 뒤, `super`를 호출해 작업을 넘깁니다. 호출이 **마지막** 믹스인에 먼저 들어가므로, `with` 목록의 순서가 어떤 규칙이 어떤 규칙보다 먼저 실행되는지 결정합니다:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}`는 모든 입금을 두 배로 만듭니다. `Doubled` 뒤에 두 번째 믹스인을 추가하면, `Doubled`가 보기 전에 그 믹스인이 입금을 먼저 받습니다.

# --instructions--

클래스 `Account`는 이미 작성되어 있습니다. `0`에서 시작하는 `int` 필드 `balance`와, `int` 인자를 `balance`에 더하는 메서드 `deposit`을 가집니다.

빈 상태로 시작하는 `List<String>` 필드 `log`를 가지고, `deposit`을 재정의하여 먼저 `'deposit '` 뒤에 금액을 붙인 문자열을 `log`에 추가한 다음 `super.deposit`을 호출하는, `Account`에 대한 믹스인 `Audited`를 선언하세요.

`100`보다 큰 금액은 무시하고 다른 금액은 `super.deposit`으로 전달하도록 `deposit`을 재정의하는, `Account`에 대한 믹스인 `Limited`를 선언하세요.

`Account`를 상속하고 두 믹스인을 모두 사용하여 거부된 입금이 로그에 닿지 않게 하는 클래스 `SafeAccount`를 선언하세요.

예:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

# --solutions--

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
