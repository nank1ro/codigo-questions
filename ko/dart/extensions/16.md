# --instructions--

`String`에 대한 `Words`라는 확장을 작성하세요:
- `int` 타입의 게터 `wordCount`: 문자열의 단어 수(단어는 공백 하나로 구분됩니다)
- `String` 타입의 게터 `initials`: 각 단어의 첫 문자를 대문자로 만들어 구분자 없이 이어 붙인 것

문자열에는 항상 단어가 하나 이상 있고, 앞뒤 공백이나 연속된 공백은 없습니다.

예:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
