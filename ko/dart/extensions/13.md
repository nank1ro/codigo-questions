# --description--

제네릭 확장은 `where`와 `map`이 그렇듯 **함수**를 매개변수로 받을 수 있습니다. 함수 타입은 요소 타입 `T`로 작성하므로, 콜백은 올바른 타입의 요소를 받습니다:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

`countWhere`가 주어진 `test` 함수를 만족하는 요소가 몇 개인지 반환하도록 확장을 완성해서, 프로그램이 `2`와 그다음에 `1`을 출력하도록 만드세요.

```dart
extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
```
