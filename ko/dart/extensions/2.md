# --description--

확장은 숫자를 포함한 모든 타입에 동작합니다. 다음 확장은 모든 `int`에 자기 자신을 두 배로 만드는 메서드를 추가합니다:

```dart
extension Doubling on int {
  int doubled() => this * 2;
}
```

확장은 **타입**에 적용되기 때문에, 메서드를 변수뿐 아니라 **리터럴**에 바로 호출할 수도 있습니다. 음수 리터럴에는 괄호가 필요합니다. 그렇지 않으면 점이 마이너스 기호보다 먼저 읽힙니다:

```dart
var n = 21;
print(n.doubled());    // 42
print(4.doubled());    // 8
print((-3).doubled()); // -6
```

# --instructions--

매개변수 없이 그 수를 자기 자신과 곱한 값을 반환하는 메서드 `squared`를 가진, `int`에 대한 `Squaring`이라는 확장을 작성하세요.

예:
```dart
print(5.squared()); // 25
```
