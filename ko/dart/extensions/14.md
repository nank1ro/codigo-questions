# --instructions--

클래스 `Temperature`가 주어져 있습니다. 다음을 가진 `Temperature`에 대한 `Conversions`라는 확장을 작성하세요:
- `celsius * 9 / 5 + 32`와 같은 `double` 타입의 게터 `fahrenheit`
- `double` 매개변수 `limit`를 받아 `celsius`가 `limit`보다 클 때 `true`를 반환하는 메서드 `isAbove`

예:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

```dart
extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
```
