# --description--

एक setter का असली मूल्य यह है कि वह इनकार कर सकता है। असाइनमेंट और संग्रहीत वैल्यू के बीच आपको आने वाली वैल्यू को जाँचने, सीमित करने या अस्वीकार करने का मौका मिलता है:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// 3 प्रिंट करता है, सेटर ने 50 को रिजेक्ट कर दिया
```
एक ही नाम वाला getter और setter मिलकर एक ही प्रॉपर्टी बनाते हैं, इसलिए वे साथ ही एक साधारण फ़ील्ड भी नहीं हो सकते: संग्रहीत वैल्यू किसी दूसरे नाम के अंतर्गत रहती है, परंपरा के अनुसार वही नाम जिसके आगे एक अंडरस्कोर लगा हो।

# --asserts--

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

setter को एक मान्य वैल्यू स्वीकार करनी चाहिए।

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

setter को एक नकारात्मक वैल्यू को अनदेखा करना चाहिए।

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

setter को `0` स्वीकार करना चाहिए।

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

वैल्यू को `_temperature` में संग्रहीत किया जाना चाहिए।

