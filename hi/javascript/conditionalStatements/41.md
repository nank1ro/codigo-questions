# --description--

एक `if` स्टेटमेंट की शर्त हमेशा कोष्ठकों `()` के अंदर जाती है, जो `if` कीवर्ड के ठीक बाद और ओपनिंग कर्ली ब्रैकेट से पहले रखे जाते हैं।

# --instructions--

हम if स्टेटमेंट की कंडीशन कहां लिखते हैं?

# --answers--

- गोल कोष्ठकों के बीच ()
- वर्ग कोष्ठकों के बीच []
- if कीवर्ड और ओपन कर्ली ब्रेस { के बीच
- if कीवर्ड से पहले
