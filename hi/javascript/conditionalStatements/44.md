# --description--

एक `if` स्टेटमेंट का कोड ब्लॉक कर्ली ब्रैकेट्स `{ }` के अंदर के निर्देशों का सेट है, वह हिस्सा जो शर्त `true` होने पर वास्तव में चलता है।

# --instructions--

if स्टेटमेंट का कोड ब्लॉक क्या है?

# --answers--

- वह कोड जो कंडीशन false होने पर चलता है
- वह कोड जो निर्धारित करता है कि कोड का एक टुकड़ा चलना चाहिए या नहीं
- एक तुलना कीवर्ड
