# --description--

पैटर्न के एक भाग के चारों ओर कोष्ठक लगाने से एक **कैप्चर ग्रुप** बनता है: उस भाग से मेल खाने वाला टेक्स्ट अलग रख लिया जाता है ताकि आप उसे वापस पढ़ सकें।

ग्रुप `match[0]` के बाद आते हैं, जिन्हें उनके खोलने वाले कोष्ठक के अनुसार बाएँ से दाएँ क्रमांकित किया जाता है:
```javascript
const match = "2026-09-12".match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(match[0]);
// 2026-09-12 प्रिंट करता है
console.log(match[1]);
// 2026 प्रिंट करता है
console.log(match[3]);
// 12 प्रिंट करता है
```
इसलिए `match[0]` हमेशा पूरा मेल होता है, और `match[1]`, `match[2]`, ... ग्रुप होते हैं। ऐसा ग्रुप जो एक ऐसे पैटर्न का हिस्सा है जो बिल्कुल मेल नहीं खाता, पूरे `match` को `null` लौटाने पर मजबूर कर देता है।
