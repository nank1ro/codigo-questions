# --description--

`/\d+/` जैसा लिटरल लिखते ही स्थिर हो जाता है। जब पैटर्न को **रन टाइम पर बनाना** हो, तो **`RegExp` कंस्ट्रक्टर** का उपयोग करें, जो पैटर्न को एक स्ट्रिंग के रूप में लेता है:
```javascript
const word = "cat";
const pattern = new RegExp(word);
console.log(pattern.test("the cat sleeps"));
// true प्रिंट करता है
```
यहाँ एक जाल है। एक स्ट्रिंग के अंदर बैकस्लैश *स्ट्रिंग* के लिए एक एस्केप सीक्वेंस शुरू करता है, इसलिए वह रेगेक्स तक पहुँचने से पहले ही गायब हो जाता है। पैटर्न में एक वास्तविक बैकस्लैश रखने के लिए आपको उसे दोगुना करना होगा:
```javascript
const digits = new RegExp("\\d+");
// /\d+/ जैसा ही पैटर्न
```
इसके बजाय `new RegExp("\d+")` लिखने पर पैटर्न `/d+/` मिलता है, जो अंक नहीं बल्कि अक्षर `d` से मेल खाता है।

जब कोड लिखते समय पैटर्न ज्ञात हो तो लिटरल को प्राथमिकता दें; वह छोटा होता है और उसमें दोगुने बैकस्लैश की ज़रूरत नहीं होती।
