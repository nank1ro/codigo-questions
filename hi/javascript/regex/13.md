# --description--

**पहले** मेल के बजाय **हर** मेल को फिर से लिखने के लिए आपके पास दो विकल्प हैं:
```javascript
console.log("a1 b2".replace(/\d/g, "#"));
// a# b# प्रिंट करता है
console.log("a1 b2".replaceAll(/\d/g, "#"));
// a# b# प्रिंट करता है
```
**`replaceAll`** दोनों में से अधिक स्पष्ट है, और वह पैटर्न के रूप में एक साधारण स्ट्रिंग भी स्वीकार करता है। जब आप उसे एक रेगेक्स देते हैं, तो उस रेगेक्स में `g` फ्लैग होना **ज़रूरी** है, अन्यथा वह `TypeError` फेंकता है; यही बात `replace` लिखने और केवल पहला मेल ठीक करने वाले चुपचाप रह जाने वाले बग को रोकती है।

# --instructions--

एक फंक्शन `redact` लिखें जो एक स्ट्रिंग `text` लेता है और `replaceAll` का उपयोग करके उसे हर अंक-शृंखला को एक अकेले `#` से बदलकर लौटाता है

# --asserts--

`replaceAll` मेथड का उपयोग किया जाना चाहिए।

```json
{
  "regex": "\\.replaceAll\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`redact("call 123 or 45")` को `call # or #` लौटाना चाहिए।

```javascript
tryCatch(redact("call 123 or 45") === "call # or #");
```

`redact("no digits")` को टेक्स्ट अपरिवर्तित लौटाना चाहिए।

```javascript
tryCatch(redact("no digits") === "no digits");
```

`redact("2026")` को `#` लौटाना चाहिए।

```javascript
tryCatch(redact("2026") === "#");
```

`redact("a1b2c3")` को `a#b#c#` लौटाना चाहिए।

```javascript
tryCatch(redact("a1b2c3") === "a#b#c#");
```
