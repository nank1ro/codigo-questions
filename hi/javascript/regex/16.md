# --description--

एक आख़िरी फ्लैग सेट को पूरा करता है। डिफ़ॉल्ट रूप से `^` और `$` का अर्थ **पूरी स्ट्रिंग** की शुरुआत और अंत होता है, इसलिए `^` से एंकर किया गया पैटर्न केवल बिल्कुल शुरुआत में मेल खा सकता है, तब भी जब टेक्स्ट में कई पंक्तियाँ हों।

**`m`** (मल्टीलाइन) फ्लैग इसे बदल देता है: `^` और `$` तब हर न्यूलाइन के ठीक बाद और ठीक पहले भी मेल खाते हैं, इसलिए हर पंक्ति अपने आप पर एंकर हो जाती है:
```javascript
const text = "note a\nb\nnote c";
console.log(text.match(/^note.*/g));
// prints [ 'note a' ]
console.log(text.match(/^note.*/gm));
// prints [ 'note a', 'note c' ]
```
यहाँ दो बातें मायने रखती हैं। डिफ़ॉल्ट रूप से `.` एक न्यूलाइन से मेल नहीं खाता (केवल `s` फ्लैग इसे बदलता है), इसलिए `.*` स्वयं ही पंक्ति के अंत पर रुक जाता है। और `g` फ्लैग के साथ `match`, कुछ भी मेल न खाने पर एक खाली ऐरे नहीं बल्कि `null` लौटाता है, इसलिए जब आप एक ऐरे लौटाने का वादा करते हैं तो उसे `?? []` के साथ जोड़ें।
