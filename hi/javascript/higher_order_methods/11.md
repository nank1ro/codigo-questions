# --description--

फ़ंक्शन लौटाने वाला फ़ंक्शन किसी callback को **ढालने** का भी स्वाभाविक तरीक़ा है। मान लीजिए आपके पास एक प्रेडिकेट है और `filter` के लिए आपको उसका उल्टा चाहिए: उसे दोबारा लिखने के बजाय उसे लपेट दीजिए:
```javascript
const isLong = (word) => word.length > 4;
const isShort = (word) => !isLong(word);
console.log(["tree", "forest"].filter(isShort));
// prints [ 'tree' ]
```
एक सामान्य `not(predicate)` यह काम किसी भी प्रेडिकेट के लिए कर देगा: यह एक नया फ़ंक्शन लौटाता है जो उसी आर्ग्युमेंट के साथ `predicate` को कॉल करता है और परिणाम को `!` से उलट देता है। `filter`, `find`, `some` और `every` के प्रेडिकेट को एलिमेंट पहले आर्ग्युमेंट के रूप में मिलता है, इसलिए रैपर को सिर्फ़ वही एक मान आगे भेजना होता है।

# --instructions--

एक फ़ंक्शन `not(predicate)` लिखें जो एक नया प्रेडिकेट लौटाए जो ठीक तब `true` लौटाए जब `predicate` उसी आर्ग्युमेंट के लिए `false` लौटाता है

# --asserts--

`not((n) => n % 2 === 0)(3)` को `true` लौटाना चाहिए।

```javascript
tryCatch(not((n) => n % 2 === 0)(3) === true);
```

`not((n) => n % 2 === 0)(4)` को `false` लौटाना चाहिए।

```javascript
tryCatch(not((n) => n % 2 === 0)(4) === false);
```

`[1, 2, 3, 4].filter(not(isEven))` को `[1, 3]` लौटाना चाहिए।

```javascript
tryCatch((() => { const isEven = (n) => n % 2 === 0; return JSON.stringify([1, 2, 3, 4].filter(not(isEven))) === "[1,3]"; })());
```

`["a", "", "b"].filter(not((s) => s === ""))` को `["a", "b"]` लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(["a", "", "b"].filter(not((s) => s === ""))) === '["a","b"]');
```

दो बार नकारने पर मूल उत्तर मिलना चाहिए: `not(not(isEven))(4)` को `true` लौटाना चाहिए।

```javascript
tryCatch(not(not((n) => n % 2 === 0))(4) === true);
```

`not` को एक फ़ंक्शन लौटाना चाहिए।

```javascript
tryCatch(typeof not((n) => n > 0) === "function");
```
