# --description--

क्लोज़र लौटाए गए फ़ंक्शन को कॉल्स के बीच **निजी स्थिति** बनाए रखने देते हैं। इसी तरह बना एक क्लासिक हेल्पर है `once(fn)`: यह एक ऐसा फ़ंक्शन लौटाता है जो `fn` को सिर्फ़ पहली बार कॉल होने पर चलाता है, परिणाम याद रखता है, और हर बाद की कॉल पर `fn` को दोबारा चलाए बिना वही परिणाम लौटाता है:
```javascript
let calls = 0;
const init = once(() => {
  calls += 1;
  return "ready";
});
console.log(init(), init(), calls);
// prints ready ready 1
```
रैपर को दो निजी वेरिएबल चाहिए: क्या `fn` पहले ही चल चुका है, और सहेजा गया परिणाम। दोनों क्लोज़र में रहते हैं, बाहरी दुनिया के लिए अदृश्य। रैपर के सभी आर्ग्युमेंट `fn` तक पहुँचाने के लिए रैपर को rest पैरामीटर `(...args)` के साथ घोषित करें और `fn(...args)` कॉल करें।

# --instructions--

एक फ़ंक्शन `once(fn)` लिखें जो एक ऐसा फ़ंक्शन लौटाए जो सिर्फ़ अपनी पहली कॉल पर `fn` को उन्हीं आर्ग्युमेंट्स के साथ कॉल करे और `fn` का परिणाम लौटाए, और हर बाद की कॉल पर `fn` को दोबारा कॉल किए बिना वही सहेजा गया परिणाम लौटाए

# --asserts--

लपेटे गए फ़ंक्शन को `fn` सिर्फ़ एक बार चलाना चाहिए और उसका परिणाम लौटाते रहना चाहिए।

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; return 42; }); f(); f(); f(); return f() === 42 && calls === 1; })());
```

पहली कॉल के आर्ग्युमेंट `fn` तक पहुँचने चाहिए: `once((a, b) => a + b)(2, 3)` को `5` लौटाना चाहिए।

```javascript
tryCatch(once((a, b) => a + b)(2, 3) === 5);
```

बाद की कॉल्स को अलग आर्ग्युमेंट्स के साथ भी सहेजा गया परिणाम लौटाना चाहिए।

```javascript
tryCatch((() => { const add = once((a, b) => a + b); add(1, 1); return add(5, 5) === 2; })());
```

`fn` को दोबारा नहीं चलना चाहिए, तब भी नहीं जब उसका परिणाम `undefined` हो।

```javascript
tryCatch((() => { let calls = 0; const f = once(() => { calls += 1; }); f(); f(); return calls === 1 && f() === undefined; })());
```

एक ही फ़ंक्शन के दो रैपर एक-दूसरे से स्वतंत्र होने चाहिए।

```javascript
tryCatch((() => { let n = 0; const inc = () => { n += 1; return n; }; const a = once(inc); const b = once(inc); a(); a(); b(); b(); return a() === 1 && b() === 2 && n === 2; })());
```

`once` को एक फ़ंक्शन लौटाना चाहिए।

```javascript
tryCatch(typeof once(() => {}) === "function");
```

# --solutions--

```javascript
function once(fn) {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
}
```
