# --description--

JavaScript में फ़ंक्शन एक **मान** है: आप उसे किसी वेरिएबल में रख सकते हैं, किसी array में डाल सकते हैं और किसी दूसरे फ़ंक्शन को आर्ग्युमेंट के रूप में पास कर सकते हैं। जो फ़ंक्शन किसी फ़ंक्शन को आर्ग्युमेंट के रूप में लेता है, या कोई फ़ंक्शन लौटाता है, उसे **हायर-ऑर्डर फ़ंक्शन** कहते हैं। पास किए गए फ़ंक्शन को **callback** कहते हैं, क्योंकि लेने वाला ज़रूरत पड़ने पर *उसे वापस बुलाता* है:
```javascript
function shout(text) {
  return text.toUpperCase() + "!";
}
function twice(fn, value) {
  return fn(fn(value));
}
console.log(twice(shout, "hi"));
// prints HI!!
```
ध्यान दें कि `shout` को **बिना कोष्ठक के** पास किया गया है: `twice(shout, "hi")` फ़ंक्शन को ही सौंपता है, जबकि `twice(shout("hi"), "hi")` पहले `shout` को कॉल करता और उसका परिणाम, यानी स्ट्रिंग `"HI!"`, पास करता, जिसे कॉल नहीं किया जा सकता।

# --instructions--

`applyTo` को पूरा करें ताकि वह `fn` को `value` के साथ कॉल करने का परिणाम लौटाए, फिर उसे `double` और `negate` के साथ (फ़ंक्शनों को ही पास करते हुए) दोनों बार `21` देकर कॉल करें, जिससे आउटपुट `42 -21` बने
