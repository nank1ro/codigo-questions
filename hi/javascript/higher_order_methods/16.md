# --description--

सब कुछ `groupBy(items, keyFn)` में मिल जाता है: यह एक हायर-ऑर्डर फ़ंक्शन है जिसे एक callback मिलता है जो हर एलिमेंट की **समूह key** तय करता है, और जो एक ऐसा ऑब्जेक्ट लौटाता है जिसमें हर key के साथ उस key वाले एलिमेंट्स का array जुड़ा होता है। ऑब्जेक्ट संचायक वाला `reduce` पूरा काम कर देता है:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
हर एलिमेंट के लिए key निकालें, अगर उस key का array अभी नहीं है तो उसे बनाएँ (`acc[key] ?? []`), एलिमेंट जोड़ें और संचायक लौटाएँ। चूँकि `keyFn` कॉल करने वाला चुनता है, वही फ़ंक्शन शब्दों को पहले अक्षर से, लोगों को शहर से या संख्याओं को सम-विषम से समूहित कर देता है।

# --instructions--

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` को `{ h: ["hi", "hey"], y: ["yo"] }` लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

`[1, 2, 3, 4]` को सम-विषम से समूहित करने पर `{ odd: [1, 3], even: [2, 4] }` लौटना चाहिए।

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

लोगों को `city` से समूहित करने पर पूरे ऑब्जेक्ट मूल क्रम में बने रहने चाहिए।

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` को एक ख़ाली ऑब्जेक्ट लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

मूल array बदलना नहीं चाहिए।

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

# --solutions--

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
