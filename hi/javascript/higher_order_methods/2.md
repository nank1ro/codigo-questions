# --description--

हायर-ऑर्डर फ़ंक्शन आपको *हर एलिमेंट के साथ क्या करना है* को *एलिमेंट्स पर कैसे चलना है* से अलग करने देते हैं। चलने वाला हिस्सा एक ही बार लिखा जाता है, और बाक़ी callback तय करता है:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
Callback को एक बार में एक एलिमेंट मिलता है। यह ऊपर की तरह इनलाइन लिखा arrow फ़ंक्शन हो सकता है, या किसी वेरिएबल में रखा कोई भी फ़ंक्शन। आगे आप जिन बिल्ट-इन array मेथड्स से मिलेंगे, वे भीतर से ठीक इसी तरह काम करते हैं।

# --instructions--

# --asserts--

`transform([1, 2, 3], (n) => n * 2)` को `[2, 4, 6]` लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())` को `["A", "B"]` लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)` को एक ख़ाली array लौटाना चाहिए।

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

परिणाम एक नया array होना चाहिए और मूल array बदलना नहीं चाहिए।

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

फ़ंक्शन को `map` का उपयोग नहीं करना चाहिए।

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

# --solutions--

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
