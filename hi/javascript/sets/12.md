# --instructions--

उन नामों का ऐरे प्रिंट करने के लिए लाइनों को क्रमबद्ध करें जो `all` में हैं लेकिन `done` में नहीं हैं।
`done` से पहले `all` घोषित करें

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
