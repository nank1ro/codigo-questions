# --description--

पहले से सेट में मौजूद वैल्यू को जोड़ने पर **कुछ नहीं** होता: डुप्लिकेट को बस नज़रअंदाज़ कर दिया जाता है।
दो और ज़रूरी बातें:
- `delete(value)` सेट से वैल्यू हटाता है
- `size` संग्रहीत वैल्यू की संख्या है (यह एक प्रॉपर्टी है, इसलिए कोष्ठक नहीं लगते)

```javascript
let tags = new Set();
tags.add("js");
tags.add("css");
tags.add("js");
console.log(tags.size);
// prints 2
tags.delete("css");
console.log(tags.size);
// prints 1
```

# --instructions--

`tags` में `"html"` जोड़ें, `"css"` हटाएं, फिर `hasCss` में स्टोर करें कि क्या `tags` में अभी भी `"css"` है और `count` में स्टोर करें कि उसमें कितनी वैल्यू हैं


```javascript

```

