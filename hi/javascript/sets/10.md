# --description--

स्प्रेड और `filter()` को मिलाकर आप सेट थ्योरी के क्लासिक ऑपरेशन कर सकते हैं। हर एक एक **नया** कलेक्शन बनाता है और मूल को अपरिवर्तित छोड़ देता है:
- **यूनियन**, हर वैल्यू जो `a` में, `b` में, या दोनों में हो: `new Set([...a, ...b])`
- **इंटरसेक्शन**, सिर्फ वे वैल्यू जो **दोनों** में हों: `[...a].filter((x) => b.has(x))`
- **डिफरेंस**, `a` की वे वैल्यू जो `b` में **नहीं** हैं: `[...a].filter((x) => !b.has(x))`

```javascript
let a = new Set([1, 2, 3]);
let b = new Set([3, 4]);
console.log([...new Set([...a, ...b])]);
// prints [ 1, 2, 3, 4 ]
console.log([...a].filter((x) => b.has(x)));
// prints [ 3 ]
console.log([...a].filter((x) => !b.has(x)));
// prints [ 1, 2 ]
```
हाल के JavaScript इंजन सेट पर सीधे `a.union(b)`, `a.intersection(b)` और `a.difference(b)` भी उपलब्ध कराते हैं, लेकिन स्प्रेड और filter वाला तरीका हर जगह काम करता है।

# --asserts--

`union(new Set([1, 2]), new Set([2, 3]))` में ठीक `1`, `2` और `3` होने चाहिए।

```javascript
tryCatch(JSON.stringify([...union(new Set([1, 2]), new Set([2, 3]))]) === '[1,2,3]');
```

परिणाम एक `Set` होना चाहिए।

```javascript
tryCatch(union(new Set([1]), new Set([2])) instanceof Set);
```

दो खाली सेट के `union` का साइज़ `0` होना चाहिए।

```javascript
tryCatch(union(new Set(), new Set()).size === 0);
```

पहला सेट बदला नहीं जाना चाहिए।

```javascript
let _a = new Set([1]);
union(_a, new Set([2]));
tryCatch(_a.size === 1);
```
