# --description--

एक सेट लगभग `===` जैसे ही नियम से तय करता है कि दो वैल्यू "समान" हैं या नहीं (सिवाय इसके कि `NaN` को खुद के बराबर माना जाता है)। स्ट्रिंग और नंबर के लिए यह कंटेंट की तुलना करता है, लेकिन **ऑब्जेक्ट की तुलना रेफ़रेंस से होती है**: समान फ़ील्ड वाले दो ऑब्जेक्ट लिटरल दो अलग-अलग वैल्यू होते हैं।
```javascript
let alice = { name: "Alice" };
let people = new Set();
people.add(alice);
people.add(alice);
console.log(people.size);
// prints 1
people.add({ name: "Alice" });
console.log(people.size);
// prints 2
```
केवल वही ऑब्जेक्ट दोबारा जोड़ने पर ही उसे नज़रअंदाज़ किया जाता है।
