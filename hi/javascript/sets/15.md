# --description--

`new Set()` सिर्फ ऐरे ही नहीं, बल्कि किसी भी **इटरेबल** को स्वीकार करता है। एक स्ट्रिंग कैरेक्टर-दर-कैरेक्टर इटरेबल होती है, इसलिए यह आपको टेक्स्ट के अलग-अलग कैरेक्टर देती है:
```javascript
let letters = new Set("hello");
console.log([...letters]);
// prints [ 'h', 'e', 'l', 'o' ]
```

# --instructions--

एक फ़ंक्शन `commonLetters(a, b)` लिखें जो एक ऐरे रिटर्न करे जिसमें वे कैरेक्टर हों जो दोनों स्ट्रिंग में आते हैं, बिना डुप्लिकेट के और उस क्रम में जिसमें वे `a` में पहली बार आते हैं

# --solutions--

```javascript
function commonLetters(a, b) {
  let lettersB = new Set(b);
  return [...new Set(a)].filter((ch) => lettersB.has(ch));
}
```
