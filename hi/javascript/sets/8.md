# --description--

`delete(value)` तब `true` रिटर्न करता है जब वैल्यू हटाई गई हो और तब `false` जब वह सेट में थी ही नहीं।
**सारी** वैल्यू को एक साथ हटाने के लिए, `clear()` को कॉल करें:
```javascript
let cart = new Set(["pen", "ink"]);
console.log(cart.delete("pen"));
// true प्रिंट करता है
console.log(cart.delete("pen"));
// false प्रिंट करता है
cart.clear();
console.log(cart.size);
// 0 प्रिंट करता है
```

# --instructions--

`cart` से `"pen"` हटाएं और हटाने का परिणाम प्रिंट करें, फिर पूरे सेट को खाली करें और बताएं कि कितनी वैल्यू बची हैं
