एक **सेट** **यूनीक** वैल्यू का एक कलेक्शन है: हर वैल्यू अधिकतम एक बार आ सकती है, और पोज़िशन से वैल्यू तक पहुँचने के लिए कोई इंडेक्स नहीं होता।
सेट तब उपयोगी होते हैं जब आपको सिर्फ इस बात की परवाह हो कि *कौन सी* वैल्यू मौजूद हैं, न कि वे कितनी बार या किस क्रम में हैं।
आप `new Set()` से एक खाली सेट बनाते हैं, `add(value)` से एक वैल्यू जोड़ते हैं और `has(value)` से जांचते हैं कि कोई वैल्यू मौजूद है या नहीं:
```javascript
let colors = new Set();
colors.add("red");
colors.add("blue");
console.log(colors.has("red"));
// true प्रिंट करता है
console.log(colors.has("green"));
// false प्रिंट करता है
```

---

पहले से सेट में मौजूद वैल्यू को जोड़ने पर **कुछ नहीं** होता: डुप्लिकेट को बस नज़रअंदाज़ कर दिया जाता है।
दो और ज़रूरी बातें:
- `delete(value)` सेट से वैल्यू हटाता है
- `size` संग्रहीत वैल्यू की संख्या है (यह एक प्रॉपर्टी है, इसलिए कोष्ठक नहीं लगते)

```javascript
let tags = new Set();
tags.add("js");
tags.add("css");
tags.add("js");
console.log(tags.size);
// 2 प्रिंट करता है
tags.delete("css");
console.log(tags.size);
// 1 प्रिंट करता है
```

---

`add()` सेट को खुद ही रिटर्न करता है, इसलिए कई कॉल को चेन किया जा सकता है:
```javascript
let letters = new Set();
letters.add("a").add("b");
```
चेन करें या न करें, पहले से मौजूद वैल्यू दूसरी बार कभी नहीं जोड़ी जाती, इसलिए `size` हर अलग वैल्यू को केवल एक बार गिनता है।

---

आप एक ऐरे को `new Set()` में पास करके एक ही बार में एक सेट बना सकते हैं। ऐरे में मौजूद डुप्लिकेट हटा दिए जाते हैं, इसलिए यह किसी ऐरे की अलग-अलग वैल्यू पता करने का सबसे तेज़ तरीका है:
```javascript
let nums = [1, 2, 2, 3, 3, 3];
let distinct = new Set(nums);
console.log(distinct.size);
// 3 प्रिंट करता है
```
**स्प्रेड** ऑपरेटर `...` इसके उल्टा काम करता है और सेट को वापस ऐरे में बदल देता है:
```javascript
let unique = [...distinct];
console.log(unique);
// [ 1, 2, 3 ] प्रिंट करता है
```
`Array.from(distinct)` भी वही काम करता है।

---

सेट यह याद रखता है कि वैल्यू किस क्रम में जोड़ी गई थीं, और आप इसे `for...of` से लूप कर सकते हैं:
```javascript
let nums = new Set([3, 1, 2]);
for (const n of nums) {
  console.log(n);
}
// 3 प्रिंट करता है
// 1 प्रिंट करता है
// 2 प्रिंट करता है
```
सेट में हर वैल्यू के लिए एक फ़ंक्शन कॉल करने वाला `forEach()` मेथड भी होता है:
```javascript
nums.forEach((n) => console.log(n * 10));
// 30 प्रिंट करता है
// 10 प्रिंट करता है
// 20 प्रिंट करता है
```

---

`delete(value)` तब `true` रिटर्न करता है जब वैल्यू हटाई गई हो और तब `false` जब वह सेट में थी ही नहीं।
**सारी** वैल्यू को एक साथ हटाने के लिए, `clear()` को कॉल करें:
```javascript
let cart = new Set(["pen", "ink"]);
console.log(cart.delete("pen"));
// true प्रिंट करता है
console.log(cart.delete("pen"));
// false प्रिंट करता है
cart.clear();
console.log(cart.size);
// 0 प्रिंट करता है
```

---

एक सेट लगभग `===` जैसे ही नियम से तय करता है कि दो वैल्यू "समान" हैं या नहीं (सिवाय इसके कि `NaN` को खुद के बराबर माना जाता है)। स्ट्रिंग और नंबर के लिए यह कंटेंट की तुलना करता है, लेकिन **ऑब्जेक्ट की तुलना रेफ़रेंस से होती है**: समान फ़ील्ड वाले दो ऑब्जेक्ट लिटरल दो अलग-अलग वैल्यू होते हैं।
```javascript
let alice = { name: "Alice" };
let people = new Set();
people.add(alice);
people.add(alice);
console.log(people.size);
// 1 प्रिंट करता है
people.add({ name: "Alice" });
console.log(people.size);
// 2 प्रिंट करता है
```
केवल वही ऑब्जेक्ट दोबारा जोड़ने पर ही उसे नज़रअंदाज़ किया जाता है।

---

स्प्रेड और `filter()` को मिलाकर आप सेट थ्योरी के क्लासिक ऑपरेशन कर सकते हैं। हर एक एक **नया** कलेक्शन बनाता है और मूल को अपरिवर्तित छोड़ देता है:
- **यूनियन**, हर वैल्यू जो `a` में, `b` में, या दोनों में हो: `new Set([...a, ...b])`
- **इंटरसेक्शन**, सिर्फ वे वैल्यू जो **दोनों** में हों: `[...a].filter((x) => b.has(x))`
- **डिफरेंस**, `a` की वे वैल्यू जो `b` में **नहीं** हैं: `[...a].filter((x) => !b.has(x))`

```javascript
let a = new Set([1, 2, 3]);
let b = new Set([3, 4]);
console.log([...new Set([...a, ...b])]);
// [ 1, 2, 3, 4 ] प्रिंट करता है
console.log([...a].filter((x) => b.has(x)));
// [ 3 ] प्रिंट करता है
console.log([...a].filter((x) => !b.has(x)));
// [ 1, 2 ] प्रिंट करता है
```
हाल के JavaScript इंजन सेट पर सीधे `a.union(b)`, `a.intersection(b)` और `a.difference(b)` भी उपलब्ध कराते हैं, लेकिन स्प्रेड और filter वाला तरीका हर जगह काम करता है।

---

`Map` जैसा ही इंटरफ़ेस बनाए रखने के लिए, एक सेट भी इटरेटर मेथड `values()`, `keys()` और `entries()` देता है।
चूंकि सेट में कोई की नहीं होती, `keys()` बस `values()` का दूसरा नाम है, और `entries()` हर वैल्यू को `[value, value]` जोड़े के रूप में **दो बार** देता है:
```javascript
let letters = new Set(["a", "b"]);
console.log([...letters.values()]);
// [ 'a', 'b' ] प्रिंट करता है
console.log([...letters.entries()]);
// [ [ 'a', 'a' ], [ 'b', 'b' ] ] प्रिंट करता है
```
व्यवहार में आपको इनकी शायद ही ज़रूरत पड़े: `for...of` और स्प्रेड पहले से ही वैल्यू पर सीधे लूप करते हैं।

---

`new Set()` सिर्फ ऐरे ही नहीं, बल्कि किसी भी **इटरेबल** को स्वीकार करता है। एक स्ट्रिंग कैरेक्टर-दर-कैरेक्टर इटरेबल होती है, इसलिए यह आपको टेक्स्ट के अलग-अलग कैरेक्टर देती है:
```javascript
let letters = new Set("hello");
console.log([...letters]);
// [ 'h', 'e', 'l', 'o' ] प्रिंट करता है
```
