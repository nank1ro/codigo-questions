# --description--

JSDoc टिप्पणी की पहली पंक्ति **सारांश** होती है: एक छोटा वाक्य जो बताता है कि फ़ंक्शन क्या करता है। इसे तीसरे पुरुष में लिखें, मानो फ़ंक्शन का वर्णन कर रहे हों: "Returns...", "Adds...", "Checks..."। इसके बाद टैग सूचीबद्ध करें, हर पंक्ति में एक:
```javascript
/**
 * Returns true when n is divisible by two.
 * @param {number} n the number to check
 * @returns {boolean} true for even numbers, false otherwise
 */
function isEven(n) {
  return n % 2 === 0;
}
```
टिप्पणी घोषणा के ठीक ऊपर होनी चाहिए, बीच में कोई खाली पंक्ति नहीं, अन्यथा संपादक उसे फ़ंक्शन से नहीं जोड़ते।
