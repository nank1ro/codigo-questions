# --description--

JavaScript में टिप्पणी का एक तीसरा प्रकार भी है, **डॉक्युमेंटेशन टिप्पणी**, जो **JSDoc** प्रारूप में लिखी जाती है: यह `/**` (दो तारांकन) से शुरू होने वाली ब्लॉक टिप्पणी है जो सीधे किसी फ़ंक्शन के ऊपर रखी जाती है। इसके अंदर पंक्तियाँ आमतौर पर ` * ` से शुरू होती हैं और `@` से शुरू होने वाले विशेष **टैग** फ़ंक्शन का वर्णन करते हैं:
- हर पैरामीटर के लिए `@param {type} name description`
- लौटाए गए मान के लिए `@returns {type} description`

```javascript
/**
 * Returns the greeting for a person.
 * @param {string} name the name of the person
 * @returns {string} the greeting, ending with an exclamation mark
 */
function greet(name) {
  return `Hi, ${name}!`;
}
```
JavaScript के लिए यह केवल एक टिप्पणी है, पर संपादक इसे पढ़ते हैं और `greet` के सहायता पाठ के रूप में दिखाते हैं, साथ ही घुंघराले कोष्ठकों में लिखा प्रकार भी (`{number}`, `{string}`, `{boolean}`, `{number[]}`...)।
