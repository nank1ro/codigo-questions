# --description--

`//` के विपरीत, जो पंक्ति के अंत पर रुक जाता है, `/*` टिप्पणी केवल `*/` पर रुकती है। यदि आप इसे बंद करना भूल जाएँ, तो JavaScript आगे के सारे कोड को टिप्पणी का हिस्सा मान लेता है और सिंटैक्स त्रुटि बताता है:
```javascript
const width = 10; /* in centimetres
console.log(width); // still inside the comment: SyntaxError, the comment is never closed
```
`//` और `/* */` दोनों इनलाइन टिप्पणी के रूप में काम करते हैं, पर `/*` के साथ हमेशा सुनिश्चित करें कि `*/` मौजूद है।

# --instructions--

`const result = n * 2;` के बाद वाली ब्लॉक टिप्पणी कभी बंद नहीं होती, इसलिए वह बाकी फ़ाइल को निगल जाती है और प्रोग्राम सिंटैक्स त्रुटि के साथ विफल हो जाता है। उसी पंक्ति के अंत में टिप्पणी को बंद करें
