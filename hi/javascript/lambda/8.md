# --description--

एरो फंक्शन पैरामीटर्स सामान्य फंक्शन पैरामीटर्स जैसी ही सुविधाएँ सपोर्ट करते हैं।
एक **डिफ़ॉल्ट मान** का उपयोग किया जाता है जब आर्ग्युमेंट छोड़ दिया जाए या वह `undefined` हो:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
ध्यान दें कि डिफ़ॉल्ट मान वाले पैरामीटर को हमेशा कोष्ठकों की आवश्यकता होती है, यहाँ तक कि जब वह अकेला हो: `name = "World" => ...` एक सिंटैक्स एरर है।

# --asserts--

`greet()` को `"Hello, World!"` लौटाना चाहिए।

```javascript
tryCatch(greet() === "Hello, World!");
```

`greet("Ana")` को `"Hello, Ana!"` लौटाना चाहिए।

```javascript
tryCatch(greet("Ana") === "Hello, Ana!");
```

`greet(undefined)` को भी डिफ़ॉल्ट मान का उपयोग करना चाहिए।

```javascript
tryCatch(greet(undefined) === "Hello, World!");
```

`greet` एक एरो फंक्शन होना चाहिए।

```javascript
tryCatch(typeof greet === "function" && !/function/.test(greet.toString()));
```

