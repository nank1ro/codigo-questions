# --description--

दो और ऐरे मेथड्स एक कॉलबैक लेते हैं।
`forEach(callback)` प्रत्येक एलिमेंट के लिए कॉलबैक को एक बार कॉल करता है और कुछ भी लौटाता नहीं है; इसे प्रिंट करने जैसे साइड इफ़ेक्ट्स के लिए उपयोग करें।
`reduce(callback, initialValue)` ऐरे को एक सिंगल मान में मोड़ता है: कॉलबैक को अब तक का जमा मान और वर्तमान एलिमेंट मिलता है, और वह नया जमा मान लौटाता है:
```javascript
const numbers = [1, 2, 3];
numbers.forEach((n) => console.log(n));
// prints 1, 2 and 3 on three lines
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(total);
// prints 6
```
