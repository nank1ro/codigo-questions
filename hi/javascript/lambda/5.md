# --description--

एरो फंक्शन **कॉलबैक** के रूप में सचमुच चमकते हैं: फंक्शन जो अन्य फंक्शन्स को आर्ग्युमेंट्स के रूप में पास किए जाते हैं। ऐरे मेथड्स सबसे आम उदाहरण हैं।
`map(callback)` हर एलिमेंट के लिए कॉलबैक के परिणाम के साथ एक नया ऐरे लौटाता है, और `filter(callback)` केवल उन एलिमेंट्स के साथ एक नया ऐरे लौटाता है जिनके लिए कॉलबैक `true` लौटाता है:
```javascript
const numbers = [1, 2, 3, 4];
console.log(numbers.map((n) => n * 10));
// prints [ 10, 20, 30, 40 ]
console.log(numbers.filter((n) => n > 2));
// prints [ 3, 4 ]
```
दोनों एक नया ऐरे लौटाते हैं और मूल ऐरे को अछूता छोड़ देते हैं, इसलिए आप उन्हें चेन कर सकते हैं: `numbers.filter(...).map(...)`।

function evenSquares(numbers) {

}
