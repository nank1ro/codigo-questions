# --description--

`sort(compare)` एक कॉलबैक का उपयोग करके एक ऐरे को उसी जगह क्रमबद्ध करता है; कॉलबैक दो एलिमेंट्स प्राप्त करता है और एक ऋणात्मक संख्या लौटाता है जब पहला पहले आना चाहिए, एक धनात्मक संख्या जब दूसरा पहले आना चाहिए, या `0` जब वे बराबर हों। संख्याओं के लिए, `(a, b) => a - b` आरोही क्रम में और `(a, b) => b - a` अवरोही क्रम में क्रमबद्ध करता है।
`find(callback)` पहला एलिमेंट लौटाता है जिसके लिए कॉलबैक `true` लौटाता है, या `undefined` अगर कोई नहीं है:
```javascript
const scores = [50, 90, 70];
scores.sort((a, b) => a - b);
console.log(scores);
// prints [ 50, 70, 90 ]
console.log(scores.find((s) => s > 60));
// prints 70
```
