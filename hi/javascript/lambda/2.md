# --description--

एरो फंक्शन दो आम स्थितियों में और छोटे हो जाते हैं।
जब बॉडी एक **सिंगल एक्सप्रेशन** हो, तो आप कर्ली ब्रेसेस और `return` कीवर्ड हटा सकते हैं: एक्सप्रेशन का मान अपने आप लौटा दिया जाता है (एक **इंप्लीसिट रिटर्न**):
```javascript
const add = (a, b) => a + b;
console.log(add(2, 3));
// prints 5
```
जब **ठीक एक पैरामीटर** हो, तो आप उसके चारों ओर के कोष्ठक भी हटा सकते हैं:
```javascript
const double = n => n * 2;
console.log(double(4));
// prints 8
```
शून्य पैरामीटर्स के साथ या दो या अधिक के साथ, कोष्ठक आवश्यक होते हैं: `() => 42` और `(a, b) => a + b`।
