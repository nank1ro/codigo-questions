# --description--

चूँकि एक फंक्शन एक वैल्यू है, एक एरो फंक्शन **दूसरा एरो फंक्शन लौटा सकता है**। दो एरोज़ को चेन करना ऐसा फंक्शन लिखने का एक संक्षिप्त तरीका है जो फंक्शन्स बनाता है:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
इसे बाएँ से दाएँ पढ़ें: `makeAdder` `amount` लेता है और `(n) => n + amount` लौटाता है, एक एरो फंक्शन जो क्लोजर के ज़रिए `amount` को कैप्चर करता है। `makeAdder(1)(5)` लौटाए गए फंक्शन को तुरंत कॉल करता है।

```javascript

```

`makeMultiplier(3)(4)` को `12` लौटाना चाहिए।

```javascript
tryCatch(makeMultiplier(3)(4) === 12);
```

`makeMultiplier(2)` द्वारा लौटाया गया फंक्शन `10` के साथ कॉल करने पर `20` लौटाना चाहिए।

```javascript
tryCatch((() => { const twice = makeMultiplier(2); return twice(10) === 20; })());
```

दो मल्टीप्लायर्स स्वतंत्र होने चाहिए: `makeMultiplier(5)(2)` को `10` होना चाहिए और `makeMultiplier(0)(2)` को `0`।

```javascript

```
