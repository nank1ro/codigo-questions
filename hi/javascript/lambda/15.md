# --description--

एक सामान्य फंक्शन और एक एरो फंक्शन के बीच सबसे बड़ा अंतर कीवर्ड `this` है।
एक सामान्य `function` को उसका **अपना** `this` मिलता है, जो *उसे कैसे कॉल किया जाता है* से तय होता है: `team.intro()` में वह `team` है, लेकिन `map` को पास किए गए कॉलबैक में कोई उसे सेट नहीं करता, इसलिए `this.name` `undefined` होता है (स्ट्रिक्ट मोड में तो एक एरर भी)।
एक एरो फंक्शन का **कोई** अपना `this` नहीं होता: वह बस अपने चारों ओर के कोड का `this` उपयोग करता है (एक **लेक्सिकल** `this`)। इसीलिए एक मेथड के अंदर एरो कॉलबैक ऑब्जेक्ट का उपयोग करते रह सकते हैं:
```javascript
const team = {
  name: "Tigers",
  players: ["Ana", "Bo"],
  intro() {
    return this.players.map((p) => `${p} plays for ${this.name}`);
  },
};
console.log(team.intro());
// prints [ 'Ana plays for Tigers', 'Bo plays for Tigers' ]
```
`function (p) { return ... this.name ... }` को कॉलबैक के रूप में रखने पर, वही कोड `Tigers` के बजाय `undefined` प्रिंट करता।
इसका उल्टा पक्ष: जिस ऑब्जेक्ट **मेथड** को `this` की आवश्यकता है उसके लिए एरो फंक्शन का उपयोग न करें, क्योंकि वह ऑब्जेक्ट को संदर्भित नहीं करेगा।
