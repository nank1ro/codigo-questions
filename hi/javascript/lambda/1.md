# --description--

एक फंक्शन का नाम होना ज़रूरी नहीं है। एक **फंक्शन एक्सप्रेशन** फंक्शन को एक वैल्यू के रूप में बनाता है, जिसे आप एक वेरिएबल में स्टोर कर सकते हैं और उसी के ज़रिए कॉल कर सकते हैं:
```javascript
const add = function (a, b) {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
एक **एरो फंक्शन** वही बात लिखने का एक छोटा तरीका है: `function` कीवर्ड हटा दें और पैरामीटर लिस्ट और बॉडी के बीच एक "fat arrow" `=>` लगा दें:
```javascript
const add = (a, b) => {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
एरो फंक्शन आमतौर पर एक `const` में स्टोर किए जाते हैं, ताकि नाम को गलती से दोबारा असाइन न किया जा सके, और इन्हें बिल्कुल किसी और फंक्शन की तरह कॉल किया जाता है।
