# --description--

किसी एरो फंक्शन को कॉल करने के लिए उसे स्टोर करना ज़रूरी नहीं है। उसे कोष्ठकों में लपेटें और तुरंत बाद आर्ग्युमेंट लिस्ट जोड़ें: यह एक **तुरंत इनवोक किया गया** एरो फंक्शन है:
```javascript
const doubled = ((n) => n * 2)(5);
console.log(doubled);
// prints 10
```
एरो के चारों ओर के कोष्ठक आवश्यक होते हैं: उनके बिना `(n) => n * 2(5)` संख्या `2` को कॉल करने की कोशिश करेगा। तुरंत इनवोक किए गए फंक्शन्स किसी मान को कुछ अस्थायी वेरिएबल्स के साथ गणना करने में उपयोगी होते हैं जो प्रोग्राम के बाकी हिस्से में लीक नहीं होने चाहिए।

# --instructions--

कोड पूरा करें ताकि `message` को `"ready"` लौटाने वाले एक तुरंत इनवोक किए गए एरो फंक्शन का परिणाम मिले, फिर `message` और `(n) => n * 3` को `4` के साथ तुरंत कॉल करने का परिणाम प्रिंट करें
