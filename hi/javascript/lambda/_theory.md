एक फंक्शन का नाम होना ज़रूरी नहीं है। एक **फंक्शन एक्सप्रेशन** फंक्शन को एक वैल्यू के रूप में बनाता है, जिसे आप एक वेरिएबल में स्टोर कर सकते हैं और उसी के ज़रिए कॉल कर सकते हैं:
```javascript
const add = function (a, b) {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
एक **एरो फंक्शन** वही बात लिखने का एक छोटा तरीका है: `function` कीवर्ड हटा दें और पैरामीटर लिस्ट और बॉडी के बीच एक "fat arrow" `=>` लगा दें:
```javascript
const add = (a, b) => {
  return a + b;
};
console.log(add(2, 3));
// prints 5
```
एरो फंक्शन आमतौर पर एक `const` में स्टोर किए जाते हैं, ताकि नाम को गलती से दोबारा असाइन न किया जा सके, और इन्हें बिल्कुल किसी और फंक्शन की तरह कॉल किया जाता है।

---

एरो फंक्शन दो आम स्थितियों में और छोटे हो जाते हैं।
जब बॉडी एक **सिंगल एक्सप्रेशन** हो, तो आप कर्ली ब्रेसेस और `return` कीवर्ड हटा सकते हैं: एक्सप्रेशन का मान अपने आप लौटा दिया जाता है (एक **इंप्लीसिट रिटर्न**):
```javascript
const add = (a, b) => a + b;
console.log(add(2, 3));
// prints 5
```
जब **ठीक एक पैरामीटर** हो, तो आप उसके चारों ओर के कोष्ठक भी हटा सकते हैं:
```javascript
const double = n => n * 2;
console.log(double(4));
// prints 8
```
शून्य पैरामीटर्स के साथ या दो या अधिक के साथ, कोष्ठक आवश्यक होते हैं: `() => 42` और `(a, b) => a + b`।

---

इंप्लीसिट रिटर्न के साथ एक जाल है। जिस एरो फंक्शन की बॉडी `{` से शुरू होती है उसे एक **ब्लॉक बॉडी** के रूप में पढ़ा जाता है, कभी भी ऑब्जेक्ट लिटरल के रूप में नहीं:
```javascript
const make = (name) => { name: name };
console.log(make("Ana"));
// prints undefined
```
यहाँ `{ name: name }` एक ब्लॉक है जिसमें लेबल `name:` है जिसके बाद एक्सप्रेशन `name` है। कुछ भी लौटाया नहीं जाता, इसलिए कॉल `undefined` देता है।
एक लाइन में ऑब्जेक्ट लिटरल लौटाने के लिए, उसे **कोष्ठकों** में लपेटें ताकि JavaScript उसे एक एक्सप्रेशन माने:
```javascript
const make = (name) => ({ name: name });
console.log(make("Ana"));
// prints { name: 'Ana' }
```

---

ऑब्जेक्ट लिटरल को कोष्ठकों में लपेटना एक वन-लाइन एरो फंक्शन से ऑब्जेक्ट बनाने का मानक तरीका है, उदाहरण के लिए जब आप कुछ मानों को एक रिकॉर्ड में बदलते हैं:
```javascript
const user = (name, age) => ({ name: name, age: age });
console.log(user("Ana", 30).age);
// prints 30
```
बिना पैरामीटर्स वाला एरो फंक्शन खाली कोष्ठकों के जोड़े `()` से शुरू होता है:
```javascript
const empty = () => ({});
console.log(empty());
// prints {}
```

---

एरो फंक्शन **कॉलबैक** के रूप में सचमुच चमकते हैं: फंक्शन जो अन्य फंक्शन्स को आर्ग्युमेंट्स के रूप में पास किए जाते हैं। ऐरे मेथड्स सबसे आम उदाहरण हैं।
`map(callback)` हर एलिमेंट के लिए कॉलबैक के परिणाम के साथ एक नया ऐरे लौटाता है, और `filter(callback)` केवल उन एलिमेंट्स के साथ एक नया ऐरे लौटाता है जिनके लिए कॉलबैक `true` लौटाता है:
```javascript
const numbers = [1, 2, 3, 4];
console.log(numbers.map((n) => n * 10));
// prints [ 10, 20, 30, 40 ]
console.log(numbers.filter((n) => n > 2));
// prints [ 3, 4 ]
```
दोनों एक नया ऐरे लौटाते हैं और मूल ऐरे को अछूता छोड़ देते हैं, इसलिए आप उन्हें चेन कर सकते हैं: `numbers.filter(...).map(...)`।

---

दो और ऐरे मेथड्स एक कॉलबैक लेते हैं।
`forEach(callback)` प्रत्येक एलिमेंट के लिए कॉलबैक को एक बार कॉल करता है और कुछ भी लौटाता नहीं है; इसे प्रिंट करने जैसे साइड इफ़ेक्ट्स के लिए उपयोग करें।
`reduce(callback, initialValue)` ऐरे को एक सिंगल मान में मोड़ता है: कॉलबैक को अब तक का जमा मान और वर्तमान एलिमेंट मिलता है, और वह नया जमा मान लौटाता है:
```javascript
const numbers = [1, 2, 3];
numbers.forEach((n) => console.log(n));
// prints 1, 2 and 3 on three lines
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(total);
// prints 6
```

---

`sort(compare)` एक कॉलबैक का उपयोग करके एक ऐरे को उसी जगह क्रमबद्ध करता है; कॉलबैक दो एलिमेंट्स प्राप्त करता है और एक ऋणात्मक संख्या लौटाता है जब पहला पहले आना चाहिए, एक धनात्मक संख्या जब दूसरा पहले आना चाहिए, या `0` जब वे बराबर हों। संख्याओं के लिए, `(a, b) => a - b` आरोही क्रम में और `(a, b) => b - a` अवरोही क्रम में क्रमबद्ध करता है।
`find(callback)` पहला एलिमेंट लौटाता है जिसके लिए कॉलबैक `true` लौटाता है, या `undefined` अगर कोई नहीं है:
```javascript
const scores = [50, 90, 70];
scores.sort((a, b) => a - b);
console.log(scores);
// prints [ 50, 70, 90 ]
console.log(scores.find((s) => s > 60));
// prints 70
```

---

एरो फंक्शन पैरामीटर्स सामान्य फंक्शन पैरामीटर्स जैसी ही सुविधाएँ सपोर्ट करते हैं।
एक **डिफ़ॉल्ट मान** का उपयोग किया जाता है जब आर्ग्युमेंट छोड़ दिया जाए या वह `undefined` हो:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
ध्यान दें कि डिफ़ॉल्ट मान वाले पैरामीटर को हमेशा कोष्ठकों की आवश्यकता होती है, यहाँ तक कि जब वह अकेला हो: `name = "World" => ...` एक सिंटैक्स एरर है।

---

एक **रेस्ट पैरामीटर** `...name` किसी भी संख्या में आर्ग्युमेंट्स को एक ऐरे में इकट्ठा करता है, और यह एरो फंक्शन्स में भी काम करता है:
```javascript
const count = (...items) => items.length;
console.log(count("a", "b", "c"));
// prints 3
```
सामान्य फंक्शन्स में एक छिपा हुआ ऐरे-जैसा `arguments` ऑब्जेक्ट भी होता है जिसमें उन्हें मिले हर आर्ग्युमेंट होते हैं। एरो फंक्शन्स में **ऐसा कुछ नहीं होता**: एरो के अंदर, `arguments` चारों ओर के फंक्शन के `arguments` को संदर्भित करता है या बिल्कुल मौजूद नहीं होता। जब भी आपको एरो फंक्शन में "सभी आर्ग्युमेंट्स" चाहिए, एक रेस्ट पैरामीटर का उपयोग करें।

---

एक फंक्शन उस स्कोप के वेरिएबल्स को याद रखता है जहाँ वह **बनाया गया** था, उस स्कोप के चलना पूरा होने के बाद भी। इसे **क्लोजर** कहा जाता है।
क्लासिक उदाहरण एक काउंटर बनाने वाला फंक्शन है: `makeCounter` का हर कॉल एक नया `count` बनाता है और एक एरो फंक्शन लौटाता है जो उसी `count` का उपयोग करता रहता है:
```javascript
const makeCounter = () => {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
};
const next = makeCounter();
console.log(next());
// prints 1
console.log(next());
// prints 2
```
कोई और `count` को पढ़ या रीसेट नहीं सकता: वह केवल लौटाए गए फंक्शन के अंदर रहता है। `makeCounter()` का दूसरा कॉल अपने `count` के साथ एक स्वतंत्र काउंटर बनाता है।

---

चूँकि एक फंक्शन एक वैल्यू है, एक एरो फंक्शन **दूसरा एरो फंक्शन लौटा सकता है**। दो एरोज़ को चेन करना ऐसा फंक्शन लिखने का एक संक्षिप्त तरीका है जो फंक्शन्स बनाता है:
```javascript
const makeAdder = (amount) => (n) => n + amount;
const addTen = makeAdder(10);
console.log(addTen(5));
// prints 15
console.log(makeAdder(1)(5));
// prints 6
```
इसे बाएँ से दाएँ पढ़ें: `makeAdder` `amount` लेता है और `(n) => n + amount` लौटाता है, एक एरो फंक्शन जो क्लोजर के ज़रिए `amount` को कैप्चर करता है। `makeAdder(1)(5)` लौटाए गए फंक्शन को तुरंत कॉल करता है।
