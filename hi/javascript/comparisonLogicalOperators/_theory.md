आइए **बराबर** `==` तुलना ऑपरेटर से शुरू करें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि दो अभिव्यक्तियाँ बराबर हैं या नहीं, उदाहरण के लिए:
```javascript
console.log(2 == 2); 
// true प्रिंट करता है
console.log(2 == 3);
// false प्रिंट करता है
```

---

आइए **बराबर नहीं** `!=` तुलना ऑपरेटर के साथ आगे बढ़ें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि दो अभिव्यक्तियाँ **बराबर नहीं** हैं, उदाहरण के लिए:
```javascript
console.log(2 != 2);
// false प्रिंट करता है
console.log(2 != 3); 
// true प्रिंट करता है
```
यह *बराबर* ऑपरेटर का बिल्कुल विपरीत है

---

आइए **से बड़ा** `>` तुलना ऑपरेटर के साथ आगे बढ़ें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि एक अभिव्यक्ति दूसरी से बड़ी है या नहीं, उदाहरण के लिए:
```javascript
console.log(2 > 2);
// false प्रिंट करता है
console.log(3 > 2);
// true प्रिंट करता है
```

---

आइए **से छोटा** `<` तुलना ऑपरेटर के साथ आगे बढ़ें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि एक अभिव्यक्ति दूसरी से छोटी है या नहीं, उदाहरण के लिए:
```javascript
console.log(2 < 2);
// false प्रिंट करता है
console.log(2 < 3);
// true प्रिंट करता है
```

---

आइए **से बड़ा या बराबर** `>=` तुलना ऑपरेटर के साथ आगे बढ़ें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि एक अभिव्यक्ति दूसरी से बड़ी या बराबर है, उदाहरण के लिए:
```javascript
console.log(2 >= 2); 
// true प्रिंट करता है
console.log(3 >= 2);
// true प्रिंट करता है
console.log(3 >= 4);
// false प्रिंट करता है
```

---

आइए **से छोटा या बराबर** `<=` तुलना ऑपरेटर के साथ आगे बढ़ें।
यह एक **boolean** (`true` या `false`) लौटाता है जो बताता है कि एक अभिव्यक्ति दूसरी से छोटी या बराबर है, उदाहरण के लिए:
```javascript
console.log(2 <= 2); 
// true प्रिंट करता है
console.log(3 <= 2);
// false प्रिंट करता है
console.log(3 <= 4);
// true प्रिंट करता है
```

---

अब आइए **लॉजिकल** ऑपरेटर देखें, पहले __AND__ `&&` से शुरू करते हैं।
यह पहला ऑपरेंड लौटाता है जो *false* का मूल्यांकन करता है या अंतिम ऑपरेंड अगर सभी *true* हैं।
```javascript
console.log(2 == 2 && 2 == 3);
// false प्रिंट करता है
console.log(1 == 1 && 1 == 1.0);
// true प्रिंट करता है
```

---

आइए **or** `||` लॉजिकल ऑपरेटर के साथ आगे बढ़ें।
यह पहला ऑपरेंड लौटाता है जो *true* का मूल्यांकन करता है या अंतिम ऑपरेंड अगर सभी *false* हैं।
```javascript
console.log(2 == 2 || 2 == 3);
// true प्रिंट करता है
console.log(1 == 2 || 1 == 3);
// false प्रिंट करता है
```

---

आइए **not** `!` लॉजिकल ऑपरेटर के साथ समाप्त करें।
यह एक boolean लौटाता है जो किसी अभिव्यक्ति की लॉजिकल स्थिति का उल्टा होता है।
```javascript
console.log(!true);
// false प्रिंट करता है
console.log(!false);
// true प्रिंट करता है
console.log(!(2 == 2));
// false प्रिंट करता है
```

---

`==` अपने दोनों पक्षों को एक सामान्य टाइप में बदलने के बाद तुलना करता है, इसलिए `"5" == 5` का मान `true` होता है। सख्त ऑपरेटर `===` उस बदलाव को छोड़ देता है और यह भी जरूरी बनाता है कि टाइप मेल खाएं।
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```

---

`!=` तुलना करने से पहले बदलाव करता है, बिल्कुल `==` की तरह, इसलिए `"5" != 5` का मान `false` होता है। इसका सख्त समकक्ष `!==` एक स्ट्रिंग और एक संख्या को अलग मानता है चाहे उनमें कुछ भी हो।
```javascript
console.log("5" !== 5); // true
```

---

जब दोनों पक्ष स्ट्रिंग्स होते हैं, तो `>` लंबाई के बजाय कैरेक्टर दर कैरेक्टर उनके कोड क्रम में तुलना करता है, इसलिए `"b" > "a"` का मान `true` होता है और `"apple" > "ant"` का मान भी `true` होता है।

---

`>=` अपने नाम के दोनों हिस्सों में से किसी एक से संतुष्ट हो जाता है: `8 >= 8` का मान `true` है क्योंकि दोनों मान बराबर हैं, जबकि सख्त `8 > 8` का मान `false` है।

---

`NaN` से जुड़ी हर तुलना `false` लौटाती है, यहां तक कि विपरीत तुलनाएं भी: `NaN < 3` और `NaN >= 3` दोनों का मान `false` है, इसलिए एक असफल `<` का मतलब हमेशा यह नहीं होता कि बायां पक्ष बड़ा है।

---

जब एक पक्ष स्ट्रिंग हो और दूसरा संख्या, तो `<=` पहले स्ट्रिंग को संख्या में बदल देता है, इसलिए `"7" <= 8` का मान `true` होता है।
