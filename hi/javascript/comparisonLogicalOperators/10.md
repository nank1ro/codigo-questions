# --description--

`==` अपने दोनों पक्षों को एक सामान्य टाइप में बदलने के बाद तुलना करता है, इसलिए `"5" == 5` का मान `true` होता है। सख्त ऑपरेटर `===` उस बदलाव को छोड़ देता है और यह भी जरूरी बनाता है कि टाइप मेल खाएं।
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```
