# --description--

ऐरे हमेशा पैटर्न की अपेक्षा जितना लंबा नहीं होता। किसी नाम के बाद `= value` लिखने से उसे एक **डिफ़ॉल्ट** मिल जाता है, जिसका उपयोग तब होता है जब ऐरे में उस स्थिति पर कुछ भी न हो:
```javascript
const size = [1920];
const [width, height = 1080] = size;
console.log(width, height);
// prints 1920 1080
```
डिफ़ॉल्ट केवल तब मूल्यांकित होता है जब उसकी ज़रूरत हो, इसलिए वह फंक्शन कॉल भी हो सकता है, और डिफ़ॉल्ट किसी भी स्थिति को दिया जा सकता है, सिर्फ़ आख़िरी वाले को नहीं।
