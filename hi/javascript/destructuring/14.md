# --description--

डिफ़ॉल्ट के साथ डिस्ट्रक्चर किया हुआ पैरामीटर एक साफ़ ऑप्शन्स ऑब्जेक्ट बनाता है, लेकिन वह तब भी टूट जाता है जब कॉल करने वाला कुछ भी पास न करे: `undefined` से कुंजी पढ़ना एक `TypeError` फेंकता है। पूरे पैटर्न को `{}` का डिफ़ॉल्ट देने से यह ठीक हो जाता है:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// prints guest/false
```
इस पंक्ति को बाहर से अंदर पढ़ें: `= {}` एक खाली ऑब्जेक्ट दे देता है जब आर्ग्युमेंट मौजूद न हो, और तब हर अंदरूनी डिफ़ॉल्ट अपनी कुंजी भर देता है।

# --instructions--

एक फंक्शन `button` लिखें जो एक ऑप्शन्स ऑब्जेक्ट लेता है जिसमें `label` का डिफ़ॉल्ट `"OK"` है और `size` का डिफ़ॉल्ट `"medium"`, स्ट्रिंग `"label/size"` लौटाता है, और बिना किसी आर्ग्युमेंट के कॉल करने पर भी काम करता है

# --asserts--

बिना आर्ग्युमेंट के `button()` कॉल करने पर दोनों डिफ़ॉल्ट का उपयोग होना चाहिए।

```javascript
tryCatch(button() === "OK/medium");
```

खाली ऑब्जेक्ट को भी दोनों डिफ़ॉल्ट का उपयोग करना चाहिए।

```javascript
tryCatch(button({}) === "OK/medium");
```

केवल `label` देने पर डिफ़ॉल्ट साइज़ रहना चाहिए।

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

केवल `size` देने पर डिफ़ॉल्ट लेबल रहना चाहिए।

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

दोनों ऑप्शन्स देने पर दोनों का उपयोग होना चाहिए।

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
