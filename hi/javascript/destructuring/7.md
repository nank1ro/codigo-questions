# --description--

ऑब्जेक्ट पैटर्न और डिफ़ॉल्ट ठीक वैसे ही आपस में जुड़ते हैं जैसे ऐरे वाले, जिससे वे किसी कॉन्फ़िगरेशन ऑब्जेक्ट को पढ़ने का एक साफ़-सुथरा तरीका बन जाते हैं जिसकी कुंजियाँ हो भी सकती हैं और नहीं भी:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// prints dark en
```
चूँकि पूरा पैटर्न एक ही कथन है, कोई फंक्शन अपनी पहली ही पंक्ति पर आर्ग्युमेंट से ज़रूरत की हर चीज़ खोल सकता है।

# --asserts--

दोनों कुंजियाँ मौजूद हों तो दोनों का उपयोग होना चाहिए।

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

एक अलग यूज़र को एक अलग स्ट्रिंग देनी चाहिए।

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

`city` के न होने पर `"somewhere"` पर लौटना चाहिए।

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

अतिरिक्त कुंजियों को अनदेखा किया जाना चाहिए।

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

कुंजियों का क्रम मायने नहीं रखना चाहिए।

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
