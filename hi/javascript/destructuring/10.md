# --description--

जहाँ कोई कुंजी दूसरा ऑब्जेक्ट या ऐरे रखती है, वहाँ पैटर्न बस आगे बढ़ता जाता है और उस आकृति का भी वर्णन कर देता है:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// prints London
```
इस पंक्ति से क्या बनता है, इससे सावधान रहें: `address: { city }` का मतलब है "`address` के अंदर जाओ", "मुझे `address` दो" नहीं, इसलिए केवल `city` वेरिएबल बनता है। दोनों पाने के लिए कुंजी का दो बार ज़िक्र करें: `const { address, address: { city } } = user;`। ऐरे और ऑब्जेक्ट पैटर्न आपस में आराम से नेस्ट होते हैं, जैसे `{ tags: [first] }`।

# --instructions--

एक फंक्शन `cityOf` लिखें जो एक `address` ऑब्जेक्ट रखने वाला ऑब्जेक्ट लेता है और उसका `city` लौटाता है, या `"unknown"` जब शहर मौजूद न हो

# --asserts--

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

एक अलग नेस्टेड शहर लौटाया जाना चाहिए।

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

खाली ऐड्रेस को `"unknown"` देना चाहिए।

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

ऐड्रेस की बाकी कुंजियों को अनदेखा किया जाना चाहिए।

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

साफ़ तौर पर `undefined` शहर को `"unknown"` देना चाहिए।

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
