# --description--

ऐरे का सिर लेना और पूँछ बचा लेना इतनी आम ज़रूरत है कि पैटर्न के पास इसके लिए अपना सिंटैक्स है। आख़िरी नाम के आगे तीन बिंदु उसे एक **रेस्ट एलिमेंट** बना देते हैं, और वह हर बचा हुआ एलिमेंट एक बिल्कुल नए ऐरे में इकट्ठा कर लेता है:
```javascript
const queue = ["a", "b", "c"];
const [next, ...waiting] = queue;
console.log(next, waiting);
// a [ 'b', 'c' ] प्रिंट करता है
```
रेस्ट एलिमेंट पैटर्न में आख़िर में ही आना चाहिए और उसे डिफ़ॉल्ट नहीं मिल सकता: जब कुछ न बचे तो वह सीधा एक खाली ऐरे होता है।
