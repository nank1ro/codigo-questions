# --description--

एक ऐरे से एक बार में एक इंडेक्स पर मान पढ़ना बोझिल है:
```javascript
const point = [3, 7];
const x = point[0];
const y = point[1];
```
**डिस्ट्रक्चरिंग** वही काम एक ही पंक्ति में कर देता है। `=` के बाईं ओर आप एक ऐसा पैटर्न लिखते हैं जो ऐरे जैसा ही दिखता है, और उसके अंदर का हर नाम उसी स्थिति पर रखे एलिमेंट को प्राप्त कर लेता है:
```javascript
const point = [3, 7];
const [x, y] = point;
console.log(x, y);
// 3 7 प्रिंट करता है
```
पैटर्न को पूरे ऐरे को कवर करने की ज़रूरत नहीं है: अतिरिक्त एलिमेंट सीधे अनदेखे कर दिए जाते हैं, और जिस नाम का कोई मेल खाता एलिमेंट नहीं होता वह `undefined` हो जाता है।
