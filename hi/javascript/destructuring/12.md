# --description--

ऑब्जेक्ट पैटर्न का भी रेस्ट होता है, और वहाँ वह पैटर्न में जिन कुंजियों का ज़िक्र नहीं हुआ उन सबको एक नए ऑब्जेक्ट में इकट्ठा कर लेता है:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// prints { name: 'Ada', city: 'London' }
```
किसी ऑब्जेक्ट की एक कुंजी के बिना कॉपी बनाने का यह सबसे छोटा तरीका है: मूल ऑब्जेक्ट को कभी छुआ नहीं जाता, और रेस्ट ऑब्जेक्ट एक नया होता है जो बाकी मान रखता है।

# --instructions--

एक फंक्शन `withoutPassword` लिखें जो दिए गए ऑब्जेक्ट की उसकी `password` कुंजी के बिना कॉपी लौटाता है, और मूल ऑब्जेक्ट को अपरिवर्तित छोड़ देता है

# --asserts--

`password` कुंजी गायब होनी चाहिए।

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

बाकी कुंजियाँ बची रहनी चाहिए।

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

बाकी हर कुंजी बची रहनी चाहिए।

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

मूल ऑब्जेक्ट को नहीं बदला जाना चाहिए।

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

केवल पासवर्ड वाले ऑब्जेक्ट को एक खाली ऑब्जेक्ट देना चाहिए।

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
