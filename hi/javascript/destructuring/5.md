# --description--

एक पैटर्न किसी साधारण असाइनमेंट के बाईं ओर भी खड़ा हो सकता है, बिना आगे `const` या `let` के, और तब वह उन वेरिएबल में लिखता है जो पहले से मौजूद हैं। इससे दो मानों को आपस में बदलना एक ही पंक्ति का काम बन जाता है, बिना किसी टेम्पररी वेरिएबल के:
```javascript
let a = 1;
let b = 2;
[a, b] = [b, a];
console.log(a, b);
// 2 1 प्रिंट करता है
```
दाईं ओर पहले बनाई जाती है, इसलिए असाइनमेंट होने तक दोनों पुराने मान टेम्पररी ऐरे के अंदर पहले से सुरक्षित होते हैं। पिछली पंक्ति के सेमीकोलन का ध्यान रखें: वरना `[` से शुरू होने वाली पंक्ति को उससे पहले आई चीज़ का इंडेक्स समझ लिया जाता।
