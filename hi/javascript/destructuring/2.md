# --description--

डिस्ट्रक्चरिंग सबसे ज़्यादा काम तब आता है जब ऐरे कहीं से आता है: किसी फंक्शन का आर्ग्युमेंट, या किसी कॉल का परिणाम। ऐरे को पास रखकर हर जगह इंडेक्स से पढ़ने के बजाय, आप उसे एक बार खोल लेते हैं और हर हिस्से को एक असली नाम दे देते हैं:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// prints 5
```
मूल ऐरे में कुछ भी कॉपी नहीं होता या बदला नहीं जाता, पैटर्न केवल उससे पढ़ता है।

# --instructions--

एक फंक्शन `label` लिखें जो एक नाम और एक स्कोर रखने वाला दो-एलिमेंट का ऐरे लेता है और स्ट्रिंग `"name: score"` लौटाता है
