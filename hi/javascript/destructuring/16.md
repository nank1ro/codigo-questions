# --description--

अब तक देखा गया सब कुछ एक ही सिंटैक्स का हिस्सा है, इसलिए टुकड़े आराम से आपस में जुड़ते हैं: एक ऑब्जेक्ट पैटर्न दूसरे ऑब्जेक्ट पैटर्न को नेस्ट कर सकता है, जो डिफ़ॉल्ट के साथ रीनेम की हुई कुंजी रख सकता है, रेस्ट एलिमेंट पर ख़त्म होने वाले ऐरे पैटर्न के बगल में। तब एक ही पंक्ति पूरी आकृति का वर्णन कर देती है जिसकी फंक्शन को अपेक्षा होती है:
```javascript
function head({ title, tags: [main, ...extra] }) {
    return `${title} [${main}] +${extra.length}`;
}
console.log(head({ title: "Post", tags: ["js", "web", "dev"] }));
// prints Post [js] +2
```
इसे पढ़ने-योग्य रखें: जो पैटर्न अब दो-चार पंक्तियों में नहीं समाता, वह आम तौर पर इसका संकेत है कि फंक्शन बहुत ज़्यादा माँग रहा है।

# --instructions--

एक फंक्शन `report` लिखें जो एक ऐसा ऑब्जेक्ट लेता है जिसमें एक `id`, एक `customer` ऑब्जेक्ट जो `name` रखता है (डिफ़ॉल्ट `"guest"`) और एक गैर-खाली `items` ऐरे हो, और स्ट्रिंग `"#id name: firstItem +n"` लौटाता है जहाँ `n` यह है कि पहले के बाद कितने आइटम बचे

# --asserts--

तीन आइटम दो को पीछे छोड़ने चाहिए।

```javascript
tryCatch(report({ id: 7, customer: { name: "Ada" }, items: ["pen", "book", "lamp"] }) === "#7 Ada: pen +2");
```

एक अकेला आइटम कोई नहीं छोड़ना चाहिए।

```javascript
tryCatch(report({ id: 42, customer: { name: "Bob" }, items: ["mug"] }) === "#42 Bob: mug +0");
```

बिना नाम का कस्टमर `guest` बनना चाहिए।

```javascript
tryCatch(report({ id: 1, customer: {}, items: ["hat", "map"] }) === "#1 guest: hat +1");
```

साफ़ तौर पर `undefined` नाम भी `guest` बनना चाहिए।

```javascript
tryCatch(report({ id: 9, customer: { name: undefined }, items: ["x"] }) === "#9 guest: x +0");
```

चार आइटम तीन को पीछे छोड़ने चाहिए।

```javascript
tryCatch(report({ id: 3, customer: { name: "Cy" }, items: ["a", "b", "c", "d"] }) === "#3 Cy: a +3");
```

# --solutions--

```javascript
function report(order) {
  const { id, customer: { name = "guest" }, items: [first, ...rest] } = order;
  return `#${id} ${name}: ${first} +${rest.length}`;
}
```
