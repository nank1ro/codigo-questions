# --description--

डिफ़ॉल्ट का एक नियम है जो सबको चौंकाता है: वे **केवल** `undefined` पर लागू होते हैं। कोई कुंजी जो मौजूद है और `null`, `0`, `""` या `false` रखती है, एक असली मान है, इसलिए पैटर्न उसे ले लेता है और डिफ़ॉल्ट कभी उपयोग नहीं होता:
```javascript
const { count = 10 } = { count: 0 };
console.log(count);
// 0 प्रिंट करता है
```
यहाँ `null` का व्यवहार `0` जैसा ही है, भले ही वह किसी API रिस्पॉन्स में अक्सर "कोई मान नहीं" का मतलब होता है। जब `null` को भी बदलना हो, तो पहले डिस्ट्रक्चर करें और उसके बाद `??` से फ़ॉलबैक लें।
