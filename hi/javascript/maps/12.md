# --description--

ऐरे की तरह, मैप में भी `forEach()` मेथड होती है जो हर जोड़े के लिए एक फ़ंक्शन को कॉल करती है।
पैरामीटर्स के क्रम का ध्यान रखें: कॉलबैक को पहले **वैल्यू** मिलती है, फिर की:
```javascript
let stock = new Map([["apple", 3], ["pear", 5]]);
stock.forEach((qty, name) => {
  console.log(`${name} x${qty}`);
});
// prints apple x3
// prints pear x5
```

# --instructions--

एक फ़ंक्शन `lowStock(stock)` लिखें जो `forEach()` का उपयोग करके उन आइटम्स के नामों का एक ऐरे लौटाए जिनकी मात्रा `5` से कम है

```javascript
function lowStock(stock) {
  let low = [];
  stock.forEach((qty, name) => {
    if (qty < 5) {
      low.push(name);
    }
  });
  return low;
}
```
