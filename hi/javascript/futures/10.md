# --description--

`await` के चारों ओर `try` / `catch` का एक आम उपयोग किसी विफलता को एक उचित डिफ़ॉल्ट मान से बदलना है, ताकि कॉल करने वाले को कभी त्रुटि से निपटना न पड़े:
```javascript
async function sizeOf(path) {
  try {
    return await measure(path);
  } catch (error) {
    return 0;
  }
}
```
`measure(path)` के आगे `await` रखें, भले ही मान तुरंत ही लौटाया जाता है। इसके बिना प्रॉमिस `try` ब्लॉक से कभी गुज़रे बिना ही फ़ंक्शन से बाहर निकल जाता, और एक rejection `catch` से बच निकलती।

# --instructions--

फ़ंक्शन `parseLater` एक प्रॉमिस लौटाता है जो `text` में लिखी संख्या के साथ fulfilled होता है, या तब rejected होता है जब `text` कोई संख्या न हो। एक `async` फ़ंक्शन `safeParse` लिखें जो वह संख्या लौटाए, या `parseLater` के विफल होने पर `-1` लौटाए। `try` और `catch` का उपयोग करें

```javascript
function parseLater(text) {
  return new Promise((resolve, reject) => {
    const value = Number(text);
    if (Number.isNaN(value)) {
      reject(new Error(`not a number: ${text}`));
    } else {
      resolve(value);
    }
  });
}

async function safeParse(text) {
  try {
    return await parseLater(text);
  } catch (error) {
    return -1;
  }
}
```
