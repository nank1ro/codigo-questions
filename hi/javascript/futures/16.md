# --description--

आख़िरी टुकड़ों को जोड़ने पर एक छोटा औज़ार बनता है जो लगभग हर असली एप्लिकेशन में उपयोग होता है: एक समय-सीमा। एक ऐसा प्रॉमिस बनाएँ जो `ms` मिलीसेकंड के बाद rejected हो जाए, उसे असली काम के साथ race करें, और जो पहले settle हो वही परिणाम तय कर देता है:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
किसी `async` फ़ंक्शन से प्रॉमिस लौटाना ठीक है: फ़ंक्शन द्वारा लौटाया गया प्रॉमिस उसका पीछा करता है, इसलिए कॉल करने वाला अंतिम मान await करता है, प्रॉमिस के प्रॉमिस को नहीं।

# --instructions--

एक `async` फ़ंक्शन `withTimeout` लिखें जो एक प्रॉमिस और मिलीसेकंडों की एक संख्या `ms` ले, और लौटाए प्रॉमिस का परिणाम यदि वह `ms` के भीतर settle हो जाए, अन्यथा `new Error("timeout")` के साथ rejected हो। `Promise.race` का उपयोग करें

# --asserts--

एक पहले से fulfilled प्रॉमिस को अपना मान देना चाहिए।

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

समय-सीमा से पहले rejected होने वाला प्रॉमिस अपनी ही त्रुटि रखना चाहिए।

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

पर्याप्त तेज़ प्रॉमिस को अपना मान देना चाहिए, प्रॉमिस नहीं।

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

बहुत धीमा प्रॉमिस `"timeout"` संदेश के साथ rejected होना चाहिए।

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```
