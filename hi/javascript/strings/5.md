# --description--

`indexOf()` मेथड वह इंडेक्स लौटाता है जहाँ कोई टेक्स्ट स्ट्रिंग में **पहली बार** दिखाई देता है।
अगर टेक्स्ट नहीं मिलता, तो यह `-1` लौटाता है:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// 2 प्रिंट करता है
console.log(word.indexOf("z"));
// -1 प्रिंट करता है
```
