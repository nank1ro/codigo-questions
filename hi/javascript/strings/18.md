# --description--

स्ट्रिंग्स **इम्यूटेबल** होती हैं: एक बार बन जाने के बाद, एक स्ट्रिंग को कभी बदला नहीं जा सकता।
किसी इंडेक्स पर वैल्यू असाइन करने से कुछ नहीं होता, और हर स्ट्रिंग मेथड मूल स्ट्रिंग को बदलने के बजाय एक **नई** स्ट्रिंग लौटाता है:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
परिणाम को बनाए रखने के लिए, इसे वापस वेरिएबल में असाइन करें:
```javascript
word = word.toUpperCase();
```

# --instructions--

पहला `console.log` `hello` प्रिंट करता है क्योंकि `toUpperCase()` ने `word` को नहीं बदला। कोड को इस तरह पूरा करें कि दूसरा `console.log` `HELLO` प्रिंट करे
