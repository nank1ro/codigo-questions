# --description--

`&&` और `||` **short-circuit evaluation** का उपयोग करते हैं: जैसे ही परिणाम पता चल जाता है, वे रुक जाते हैं।
- `&&` के साथ, यदि बायाँ पक्ष `0` है तो दायाँ पक्ष कभी मूल्यांकित नहीं होता
- `||` के साथ, यदि बायाँ पक्ष शून्येतर है तो दायाँ पक्ष कभी मूल्यांकित नहीं होता

इससे बाईं ओर की जाँच दाईं ओर की खतरनाक संक्रिया की रक्षा कर सकती है:
```c
int ok = count != 0 && total / count > 2;
```
जब `count` `0` होता है, तो विभाजन कभी निष्पादित नहीं होता, इसलिए प्रोग्राम क्रैश नहीं होता।
