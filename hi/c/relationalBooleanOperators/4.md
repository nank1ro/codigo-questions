# --description--

**तार्किक ऑपरेटर** शर्तों को जोड़ते हैं। **and** ऑपरेटर `&&` केवल तब `1` देता है जब दोनों पक्ष सही हों, **or** ऑपरेटर `||` तब `1` देता है जब कम से कम एक पक्ष सही हो:
```c
int t = 25;
printf("%d\n", t > 20 && t < 30); // prints "1"
printf("%d\n", t < 20 || t > 30); // prints "0"
```
C में **कोई भी शून्येतर मान सही गिना जाता है** और केवल `0` गलत गिना जाता है, इसलिए `5 && 1`, `1` है और `0 || -3`, `1` है। `&&` और `||` का परिणाम सदैव ठीक `1` या `0` होता है।
