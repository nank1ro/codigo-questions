# --description--

चूँकि `!` कोई भी शून्येतर मान `0` में और `0` को `1` में बदल देता है, इसे दो बार लगाने से मान ठीक `0` या `1` में सामान्यीकृत हो जाता है: `!!42`, `1` है, `!!0` `0` है।
```c
int count = 3;
printf("%d %d\n", !count, !!count); // prints "0 1"
```
यह तब काम आता है जब कोई फंक्शन कोई भी शून्येतर संख्या लौटाए और आप एक साफ़ `1` चाहते हों।
