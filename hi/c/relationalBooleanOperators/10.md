# --description--

Short-circuit evaluation फ़ंक्शन कॉल्स को भी छोड़ देता है। `1 || check()` में फंक्शन `check` कभी कॉल नहीं होता, इसलिए उसका कोई भी साइड इफ़ेक्ट, जैसे काउंटर को अपडेट करना, नहीं होता।
```c
int calls = 0;

int check() {
    calls++;
    return 1;
}
```
इस बात को ध्यान में रखें जब `&&` या `||` के दाईं ओर का कोई फंक्शन ऐसा कुछ करता हो जो आप पर निर्भर करता है।
