# --description--

गणित की तरह तुलनाओं को श्रृंखला में न जोड़ें। `1 <= x <= 10` कंपाइल हो जाता है, लेकिन उसका मूल्यांकन `(1 <= x) <= 10` की तरह होता है: पहली तुलना `0` या `1` देती है, और उसकी फिर `10` से तुलना होती है, इसलिए पूरा व्यंजक सदैव `1` होता है।
```c
int x = 20;
printf("%d\n", 1 <= x <= 10);       // prints "1" (wrong!)
printf("%d\n", 1 <= x && x <= 10);  // prints "0"
```
सदैव दोनों तुलनाएँ स्पष्ट रूप से लिखें और उन्हें `&&` से जोड़ें।

# --instructions--

पंक्तियों को इस तरह क्रमबद्ध करें कि एक प्रोग्रम बने जो श्रृंखलित तुलना को `chained` में, सही रेंज जाँच को `correct` में स्टोर करे और दोनों प्रिंट करे। `chained` को `correct` से पहले परिभाषित करें
