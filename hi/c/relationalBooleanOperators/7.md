# --description--

C99 से हेडर `stdbool.h` टाइप `bool` और स्थिरांक `true` (जो `1` है) तथा `false` (जो `0` है) उपलब्ध कराता है:
```c
#include <stdbool.h>

bool open = true;
bool full = 3 > 5;
printf("%d %d\n", open, full); // prints "1 0"
```
एक `bool` अंदरखाने फिर भी एक पूर्णांक ही है: उसे `%d` से प्रिंट किया जाता है, और वह `&&`, `||` तथा `!` के साथ ठीक किसी तुलना के परिणाम की तरह काम करता है। बस यह आशय को सादे `int` की तुलना में ज़्यादा स्पष्ट कर देता है।

# --instructions--
