# --description--

ऑपरेटरों की एक **प्राथमिकता** होती है जो तय करती है कि पहले क्या गणना होगी:
1. `!` सबसे पहले लागू होता है
2. फिर संबंधात्मक तुलनाएँ `<`, `>`, `<=`, `>=`
3. फिर समता तुलनाएँ `==`, `!=`
4. फिर `&&`
5. फिर `||`

इसलिए `a > 0 && a < 10` को कोष्ठकों की ज़रूरत नहीं है, और `a && b || c` का मतलब `(a && b) || c` है क्योंकि `&&`, `||` से ज़्यादा कसकर बंधता है। अलग समूहन बलपूर्वक लागू करने या आशय को पढ़ने योग्य बनाने के लिए कोष्ठकों का उपयोग करें।

# --instructions--

कोड को इस तरह पूरा करें कि `without`, `a && b || c` को डिफ़ॉल्ट प्राथमिकता के साथ गणना करे और `with`, `b || c` को पहले मूल्यांकित करने के लिए बाध्य करे, फिर दोनों प्रिंट करें
