# --description--

C की सबसे आम गलती जहाँ `==` चाहिए हो वहाँ `=` लिखना है। अकेला `=` एक **असाइनमेंट** है, और C में असाइनमेंट एक व्यंजक होता है जिसका मान वही होता है जो असाइन किया गया था:
```c
int x = 3;
printf("%d\n", x == 7); // compares: prints "0", x is still 3
printf("%d\n", x = 7);  // assigns: prints "7", x is now 7
```
`=` वाला कोड फिर भी कंपाइल हो जाता है, इसलिए `if (x = 0)` लिखी शर्त उसे जाँचने की बजाय चुपचाप `x` को `0` सेट कर देती है। ज़्यादातर कंपाइलर इसके लिए एक चेतावनी प्रिंट करते हैं: उसे पढ़ें।
