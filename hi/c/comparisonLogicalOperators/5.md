# --description--

**or** ऑपरेटर `||` तब `1` देता है जब कम से कम एक पक्ष सही हो, और `0` तभी जब दोनों पक्ष गलत हों:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // "1" प्रिंट करता है
```
हर पक्ष एक पूर्ण तुलना होनी चाहिए: `day == 6 || 7` का मतलब "6 या 7" नहीं होता (आप बाद में जानेंगे क्यों)।
