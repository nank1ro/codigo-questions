# --description--

**तुलना ऑपरेटर** दो मानों की तुलना करते हैं और एक परिणाम देते हैं: तुलना सही होने पर `1` और गलत होने पर `0`।
**बराबर** ऑपरेटर `==` जाँचता है कि दो मान समान हैं या नहीं, और **असमान** ऑपरेटर `!=` जाँचता है कि वे भिन्न हैं या नहीं:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" प्रिंट करता है
printf("%d\n", a != b);
// "1" प्रिंट करता है
```
सावधान रहें: `==` (दो चिह्न) तुलना करता है, जबकि एक `=` मान असाइन करता है।
