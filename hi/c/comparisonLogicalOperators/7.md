# --description--

तार्किक ऑपरेटर केवल `0` और `1` पर ही काम नहीं करते: C में **कोई भी गैर-शून्य मान true माना जाता है** और केवल `0` को false माना जाता है।
इसलिए `5 && 1` का मान `1` है, `0 || -3` का मान `1` है, और `!` किसी भी गैर-शून्य मान को `0` में बदल देता है:
```c
printf("%d\n", !7); // "0" प्रिंट करता है
printf("%d\n", !0); // "1" प्रिंट करता है
```
यही कारण है कि `day == 6 || 7` हमेशा सही होता है: `7` अपने आप में एक true मान है।
