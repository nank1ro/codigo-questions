# --description--

`char` एक छोटा इंटीजर होता है, इसलिए characters की तुलना उन्हीं ऑपरेटरों से की जा सकती है।
सिंगल कोट्स में लिखे character literal से तुलना करें:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // "1" प्रिंट करता है
```
डबल कोट्स से एक स्ट्रिंग बनती है, जिसकी तुलना इस तरह नहीं की जा सकती।
