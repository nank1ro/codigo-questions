# --description--

एक क्लासिक C गलती है वहाँ `=` लिखना जहाँ `==` का इरादा था। कोड फिर भी कंपाइल हो जाता है, क्योंकि assignment एक expression है जिसका मान वही होता है जो असाइन किया गया है:
```c
int x = 5;
if (x = 0) { ... } // x को 0 असाइन करता है, शर्त 0 है (गलत)
if (x = 3) { ... } // x को 3 असाइन करता है, शर्त 3 है (सही)
```
ज़्यादातर compilers इसके बारे में चेतावनी देते हैं, इसलिए जब कोई condition अजीब व्यवहार करे तो चेतावनियाँ पढ़ें।
