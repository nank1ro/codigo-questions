# --description--

C में तुलना का परिणाम कोई विशेष प्रकार नहीं होता: यह एक `int` होता है जिसका मान बिल्कुल `1` (true) या `0` (false) होता है।
यानी आप इसे किसी भी अन्य संख्या की तरह `int` वेरिएबल में स्टोर कर सकते हैं:
```c
int n = 42;
int big = n > 100; // big 0 है
```
आउटपुट में `true`/`false` शब्द कभी नहीं दिखता: `printf("%d", 2 == 2)` `1` प्रिंट करता है।
