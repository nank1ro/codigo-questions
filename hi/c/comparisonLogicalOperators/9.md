# --description--

Short-circuit evaluation फ़ंक्शन कॉल्स को भी छोड़ देता है: `0 && check()` में फ़ंक्शन `check` कभी कॉल नहीं होता, इसलिए उसका कोई भी साइड इफ़ेक्ट (जैसे किसी काउंटर को अपडेट करना) नहीं होता।

# --instructions--

पंक्तियों को इस तरह क्रमबद्ध करें कि एक काउंटर `calls`, एक फ़ंक्शन `check` जो उसे बढ़ाकर `1` लौटाता है, और एक `main` जो `0 && check()` की गणना करके परिणाम के बाद `calls` प्रिंट करता है, परिभाषित हों। फ़ंक्शन को `main` से पहले परिभाषित करें

```c
#include <stdio.h>
int calls = 0;
```
```c
int check() {
```
```c
    calls++;
    return 1;
}
```
```c
int main() {
```
```c
    int result = 0 && check();
```
```c
    printf("%d %d\n", result, calls);
```
```c
    return 0;
}
```
