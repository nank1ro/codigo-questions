**तुलना ऑपरेटर** दो मानों की तुलना करते हैं और एक परिणाम देते हैं: तुलना सही होने पर `1` और गलत होने पर `0`।
**बराबर** ऑपरेटर `==` जाँचता है कि दो मान समान हैं या नहीं, और **असमान** ऑपरेटर `!=` जाँचता है कि वे भिन्न हैं या नहीं:
```c
int a = 7, b = 3;
printf("%d\n", a == b);
// "0" प्रिंट करता है
printf("%d\n", a != b);
// "1" प्रिंट करता है
```
सावधान रहें: `==` (दो चिह्न) तुलना करता है, जबकि एक `=` मान असाइन करता है।

---

अन्य तुलना ऑपरेटर दो मानों के क्रम की जाँच करते हैं:
- `<` से छोटा, `>` से बड़ा
- `<=` से छोटा या बराबर, `>=` से बड़ा या बराबर
```c
printf("%d\n", 3 < 5);  // "1" प्रिंट करता है
printf("%d\n", 5 >= 6); // "0" प्रिंट करता है
```
एक फ़ंक्शन तुलना का परिणाम सीधे लौटा सकता है, क्योंकि परिणाम एक साधारण `int` होता है:
```c
int is_big(int n) {
    return n > 100;
}
```

---

C में तुलना का परिणाम कोई विशेष प्रकार नहीं होता: यह एक `int` होता है जिसका मान बिल्कुल `1` (true) या `0` (false) होता है।
यानी आप इसे किसी भी अन्य संख्या की तरह `int` वेरिएबल में स्टोर कर सकते हैं:
```c
int n = 42;
int big = n > 100; // big 0 है
```
आउटपुट में `true`/`false` शब्द कभी नहीं दिखता: `printf("%d", 2 == 2)` `1` प्रिंट करता है।

---

**तार्किक ऑपरेटर** तुलनाओं को जोड़ते हैं। **and** ऑपरेटर `&&` तभी `1` देता है जब दोनों पक्ष सही हों:
```c
int age = 25;
printf("%d\n", age >= 18 && age < 65); // "1" प्रिंट करता है
```
गणित की तरह तुलनाओं को श्रृंखलाबद्ध न करें: `1 <= x <= 10` का मूल्यांकन `(1 <= x) <= 10` के रूप में होता है, जो `0` या `1` की तुलना `10` से करता है और हमेशा सही होता है।
हमेशा दोनों तुलनाओं को अलग-अलग लिखें और उन्हें `&&` से जोड़ें।

---

**or** ऑपरेटर `||` तब `1` देता है जब कम से कम एक पक्ष सही हो, और `0` तभी जब दोनों पक्ष गलत हों:
```c
int day = 1;
printf("%d\n", day == 1 || day == 7); // "1" प्रिंट करता है
```
हर पक्ष एक पूर्ण तुलना होनी चाहिए: `day == 6 || 7` का मतलब "6 या 7" नहीं होता (आप बाद में जानेंगे क्यों)।

---

**not** ऑपरेटर `!` परिणाम को उलट देता है: `!1` `0` होता है और `!0` `1` होता है।
यह अभिव्यक्ति के आगे रखा जाता है, इसलिए पूरी तुलना को नकारने के लिए कोष्ठक का उपयोग करें:
```c
int n = 5;
printf("%d\n", !(n > 3)); // "0" प्रिंट करता है
```
कोष्ठक के बिना, `!n > 3` पहले `!n` की गणना करेगा और फिर उसकी तुलना `3` से करेगा।

---

तार्किक ऑपरेटर केवल `0` और `1` पर ही काम नहीं करते: C में **कोई भी गैर-शून्य मान true माना जाता है** और केवल `0` को false माना जाता है।
इसलिए `5 && 1` का मान `1` है, `0 || -3` का मान `1` है, और `!` किसी भी गैर-शून्य मान को `0` में बदल देता है:
```c
printf("%d\n", !7); // "0" प्रिंट करता है
printf("%d\n", !0); // "1" प्रिंट करता है
```
यही कारण है कि `day == 6 || 7` हमेशा सही होता है: `7` अपने आप में एक true मान है।

---

`&&` और `||` **short-circuit evaluation** का उपयोग करते हैं: जैसे ही परिणाम निश्चित हो जाता है, वे रुक जाते हैं।
- `&&` के साथ, अगर बायाँ पक्ष `0` है तो दायाँ पक्ष कभी मूल्यांकित नहीं होता
- `||` के साथ, अगर बायाँ पक्ष true है तो दायाँ पक्ष कभी मूल्यांकित नहीं होता

इससे आप किसी खतरनाक ऑपरेशन के बाईं ओर एक जाँच रखकर उसकी सुरक्षा कर सकते हैं:
```c
int safe = divisor != 0 && value / divisor > 2;
```
जब `divisor` `0` होता है, तो भाग कभी निष्पादित नहीं होता।

---

Short-circuit evaluation फ़ंक्शन कॉल्स को भी छोड़ देता है: `0 && check()` में फ़ंक्शन `check` कभी कॉल नहीं होता, इसलिए उसका कोई भी साइड इफ़ेक्ट (जैसे किसी काउंटर को अपडेट करना) नहीं होता।

---

ऑपरेटरों की एक **प्राथमिकता** होती है जो तय करती है कि पहले क्या गणना होगी:
1. `!` सबसे पहले लागू होता है
2. फिर रिलेशनल तुलनाएँ `<`, `>`, `<=`, `>=`
3. फिर इक्वैलिटी तुलनाएँ `==`, `!=`
4. फिर `&&`
5. फिर `||`

इसलिए `a > 0 && a < 10` को कोष्ठक की ज़रूरत नहीं है: दोनों तुलनाएँ `&&` से पहले गणना हो जाती हैं।
और `x == 1 || y == 2 && z == 3` का मतलब है `x == 1 || (y == 2 && z == 3)`, क्योंकि `&&`, `||` से अधिक मजबूती से बंधता है।

---

`char` एक छोटा इंटीजर होता है, इसलिए characters की तुलना उन्हीं ऑपरेटरों से की जा सकती है।
सिंगल कोट्स में लिखे character literal से तुलना करें:
```c
char answer = 'y';
printf("%d\n", answer == 'y'); // "1" प्रिंट करता है
```
डबल कोट्स से एक स्ट्रिंग बनती है, जिसकी तुलना इस तरह नहीं की जा सकती।

---

चूँकि characters संख्याएँ होते हैं, `<` और `>` उनके कोड की तुलना करते हैं, और `'a'`, `'b'`, `'c'` या `'0'`, `'1'`, `'2'` जैसे लगातार characters के कोड भी लगातार होते हैं।
इसलिए characters पर रेंज जाँच बिल्कुल संख्याओं जैसी ही काम करती है:
```c
int is_lower(char c) {
    return c >= 'a' && c <= 'z';
}
```

---

एक क्लासिक C गलती है वहाँ `=` लिखना जहाँ `==` का इरादा था। कोड फिर भी कंपाइल हो जाता है, क्योंकि assignment एक expression है जिसका मान वही होता है जो असाइन किया गया है:
```c
int x = 5;
if (x = 0) { ... } // x को 0 असाइन करता है, शर्त 0 है (गलत)
if (x = 3) { ... } // x को 3 असाइन करता है, शर्त 3 है (सही)
```
ज़्यादातर compilers इसके बारे में चेतावनी देते हैं, इसलिए जब कोई condition अजीब व्यवहार करे तो चेतावनियाँ पढ़ें।

---

`if` की condition बस एक expression है जिसे गैर-शून्य होने पर true माना जाता है, इसलिए तुलना और तार्किक ऑपरेटर स्वाभाविक रूप से फिट बैठते हैं:
```c
if (n < 0) {
    printf("negative\n");
} else if (n == 0) {
    printf("zero\n");
}
```
आप पहले परिणाम को स्टोर करके फिर उस वेरिएबल की जाँच भी कर सकते हैं: `int ok = n > 0; if (ok) { ... }`।

---

एक `while` लूप तब तक चलता रहता है जब तक उसकी condition गैर-शून्य है, इसलिए एक तुलना यह तय करती है कि यह कब रुकेगा:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// 0, 1, 2 प्रिंट करता है
```
`<` और `<=` में से चुनना यह बदल देता है कि आखिरी मान शामिल होगा या नहीं।

---

C99 से, हेडर `stdbool.h` टाइप `bool` और कॉन्स्टेंट्स `true` (`1`) और `false` (`0`) प्रदान करता है:
```c
#include <stdbool.h>

bool ready = true;
bool done = count == 10;
```
`bool` अंदर से अभी भी एक इंटीजर होता है: इसे `%d` से प्रिंट करने पर `1` या `0` दिखता है, और यह किसी भी तुलना परिणाम की तरह `&&`, `||` और `!` के साथ काम करता है।
`bool` का उपयोग करने से किसी फ़ंक्शन का इरादा साधारण `int` लौटाने से ज़्यादा स्पष्ट हो जाता है।

---

एक `bool` पैरामीटर को `true` से तुलना किए बिना सीधे `&&` या `||` के operand के रूप में इस्तेमाल किया जा सकता है: `citizen == true` की जगह `age >= 18 && citizen` लिखें।

---

जब किसी condition में `&&` और `||` मिश्रित हों, तो हर समूह के चारों ओर कोष्ठक लगाएँ, भले ही प्राथमिकता से पहले से ही सही व्यवहार हो रहा हो: इससे नियम एक नज़र में समझ में आता है।
```c
bool free_entry = (age < 12 || age >= 65) && !holiday;
```
