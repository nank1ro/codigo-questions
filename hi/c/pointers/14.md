# --description--

`const` मान या पॉइंटर — किसी को भी सुरक्षित रख सकता है, इस पर निर्भर करता है कि वह कहाँ लिखा जाता है:
```c
const int *p = &a; // pointer to const: *p cannot be changed, p can point elsewhere
int *const q = &a; // const pointer: q always points to a, but *q can be changed
```
घोषणा को दाएँ से बाएँ पढ़ें: `p` एक स्थिरांक `int` की ओर इशारा करने वाला पॉइंटर है; `q` एक `int` की ओर इशारा करने वाला स्थिरांक पॉइंटर है। पॉइंटर to const यह वादा करने का सामान्य तरीका है कि फ़ंक्शन केवल **पढ़ेगा** जो उसे मिलता है, जैसे `int sum(const int *values, int size)` में। उसे एक सामान्य वेरिएबल पास किया जा सकता है; वह वादा केवल यह सीमित करता है कि फ़ंक्शन क्या कर सकता है।

# --instructions--

निम्नलिखित कोड की कौन सी लाइन कंपाइल नहीं होती?
```c
int a = 1, b = 2;
const int *p = &a;
p = &b;
*p = 3;
```

# --answers--

- `*p = 3;`
- `p = &b;`
- `p = &b;` और `*p = 3;` दोनों
- कोई नहीं, कोड कंपाइल हो जाता है
