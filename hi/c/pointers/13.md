# --description--

स्ट्रक्चर की ओर इशारा करने वाला पॉइंटर एरो `->` से सदस्यों तक पहुँचता है, और ऐरे में संग्रहीत स्ट्रक्चर का एड्रेस `&items[i]` से लिया जाता है। एक फ़ंक्शन पॉइंटर **लौटा** भी सकता है, उदाहरण के लिए उस एलिमेंट का जिसे उसने खोजा:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
कॉलर फिर लौटाए गए पॉइंटर से `->` के साथ सदस्य पढ़ता है, यह जाँचने के बाद कि वह `NULL` नहीं है। पॉइंटर लौटाने से स्ट्रक्चर की कॉपी होने से बचा जाता है और कॉलर मूल एलिमेंट को बदल सकता है।

# --instructions--

`cheapest` को पूरा करें ताकि वह `items` के `size` आइटम्स में सबसे कम `price` वाले आइटम की ओर इशारा करने वाला पॉइंटर लौटाए, या `size` के `0` होने पर `NULL` लौटाए

# --solutions--

```c
#include <string.h>

typedef struct {
    char name[20];
    int price;
} Item;

Item *cheapest(Item items[], int size) {
    if (size == 0) {
        return NULL;
    }
    Item *best = &items[0];
    for (int i = 1; i < size; i++) {
        if (items[i].price < best->price) {
            best = &items[i];
        }
    }
    return best;
}
```
