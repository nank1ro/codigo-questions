# --description--

एक पॉइंटर एक एड्रेस संग्रहीत करता है, और किसी दी गई मशीन पर हर एड्रेस का आकार एक जैसा होता है, चाहे वहाँ कोई भी टाइप संग्रहीत हो। इसलिए एक पॉइंटर का `sizeof` `char *`, `int *` और `double *` के लिए एक जैसा होता है: 64-बिट सिस्टम पर `8` बाइट, 32-बिट पर `4`:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
पॉइंटर के आकार को उस चीज़ के आकार से न मिलाएँ जिसकी ओर वह इशारा करता है: `sizeof(p)` एड्रेस का आकार है, `sizeof(*p)` मान का आकार है।

# --instructions--

एक सामान्य 64-बिट सिस्टम पर, निम्नलिखित कोड क्या प्रिंट करता है?
```c
char c = 'x';
char *p = &c;
printf("%zu %zu\n", sizeof(p), sizeof(*p));
```
