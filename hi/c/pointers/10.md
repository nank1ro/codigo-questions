# --description--

जब कोई ऐरे किसी फ़ंक्शन को पास किया जाता है तो वह **डिके** (decay) होकर अपने पहले एलिमेंट की ओर इशारा करने वाला पॉइंटर बन जाता है। इसीलिए पैरामीटर `int values[]` और `int *values` का अर्थ बिल्कुल एक जैसा होता है, और इसीलिए फ़ंक्शन लंबाई अपने आप नहीं जान सकता: उसे सिर्फ़ एक एड्रेस मिलता है।
एक ही ऐरे में इशारा करने वाले पॉइंटर्स की तुलना और घटाव किया जा सकता है। `end - start` उनके बीच के एलिमेंट्स की संख्या है, और एक लूप पॉइंटर को एक एड्रेस से दूसरे एड्रेस तक चला सकता है:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
`numbers` और `numbers + 3` पास करने से पहले तीन एलिमेंट्स बता दिए जाते हैं, बिना अलग साइज़ पैरामीटर के।

```c
int sum_between(int *start, int *end) {
    int total = 0;
    for (int *p = start; p < end; p++) {
        total += *p;
    }
    return total;
}
```
