हर वेरिएबल मेमोरी में कहीं न कहीं रहता है, और उस जगह की एक संख्या होती है जिसे उसका **एड्रेस** कहा जाता है। `&` ऑपरेटर, जिसे "address of" पढ़ा जाता है, किसी वेरिएबल का एड्रेस देता है:
```c
int x = 42;
printf("%p\n", &x); // prints something like 0x7ffd5c3e9a4c
```
`%p` स्पेसिफ़ायर एक एड्रेस प्रिंट करता है; सही संख्या हर रन में बदलती रहती है, इसलिए प्रोग्राम कभी उस पर भरोसा नहीं करते।
एक एड्रेस **पॉइंटर** वेरिएबल में संग्रहीत होता है। एक पॉइंटर को उस टाइप के साथ घोषित किया जाता है जिसकी ओर वह इशारा करता है, जिसके बाद `*` लगता है:
```c
int *p = &x; // p is a pointer to int, and it holds the address of x
```
अब कहा जाता है कि `p`, `x` की ओर **इशारा करता है**। दो पॉइंटर बराबर होते हैं जब वे एक ही एड्रेस रखते हैं, इसलिए `p == &x` सही होता है।

---

अपने आप में एक पॉइंटर सिर्फ़ एक एड्रेस है। उस एड्रेस पर संग्रहीत मान पढ़ने के लिए आप `*` ऑपरेटर से पॉइंटर को **डिरेफ़रेंस** (dereference) करते हैं:
```c
int x = 42;
int *p = &x;
printf("%d\n", *p); // prints "42"
```
`*p` का अर्थ है "वह मान जिसकी ओर `p` इशारा करता है", और यह `x` की तरह ही एक `int` है। एक ही चिह्न `*` की दो भूमिकाएँ हैं: घोषणा `int *p` में यह कहता है "यह एक पॉइंटर है", और अभिव्यक्ति `*p` में यह पॉइंटर का अनुसरण करके मान तक पहुँचता है।

---

डिरेफ़रेंस किए गए पॉइंटर को **असाइन** भी किया जा सकता है। `*p` में लिखने पर नया मान `p` द्वारा रखे गए एड्रेस पर संग्रहीत होता है, इसलिए जिस वेरिएबल की ओर यह इशारा करता है वह बदल जाता है:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x` और `*p` एक ही मेमोरी के दो नाम हैं। बिना `*` के `p` को असाइन करने से बदले में यह बदल जाएगा कि पॉइंटर **कौन सा एड्रेस** रखता है, न कि वहाँ संग्रहीत मान।

---

जो पॉइंटर अभी किसी चीज़ की ओर इशारा नहीं करता, उसे `NULL` रखना चाहिए — `stdio.h` और `stddef.h` में परिभाषित एक विशेष स्थिरांक जिसका अर्थ है "कोई एड्रेस नहीं":
```c
int *p = NULL;
```
एक `NULL` पॉइंटर को डिरेफ़रेंस करना एक रनटाइम एरर है जो प्रोग्राम को क्रैश कर देता है, इसलिए जिस पॉइंटर के `NULL` होने की संभावना होती है उसे उपयोग से पहले जाँचा जाता है:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
चूँकि `NULL` शून्य होता है, `if (p)` एक सामान्य शॉर्टहैंड है `if (p != NULL)` के लिए। बिना इनिशियलाइज़र के घोषित पॉइंटर `NULL` नहीं, बल्कि गार्बेज रखता है, इसलिए पॉइंटर को हमेशा इनिशियलाइज़ करें।

---

एक पॉइंटर किसी भी टाइप की ओर इशारा कर सकता है: `double *`, `char *`, `bool *` और इसी तरह। घोषणा में दिया गया टाइप कंपाइलर को बताता है कि पॉइंटर के डिरेफ़रेंस होने पर कितने बाइट पढ़ने हैं और उनका क्या अर्थ है:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
पॉइंटर को उस वेरिएबल के टाइप से मेल खाना चाहिए जिसकी ओर वह इशारा करता है; `int *p = &price;` को कंपाइलर अस्वीकार कर देता है। `NULL` एकमात्र मान है जो किसी भी टाइप के पॉइंटर में फिट होता है।

---

एक `char` की ओर इशारा करने वाला पॉइंटर किसी भी दूसरे पॉइंटर की तरह काम करता है: वह एक कैरेक्टर का एड्रेस रखता है, और `*p` उस कैरेक्टर को पढ़ता या लिखता है:
```c
char grade = 'B';
char *p = &grade;
*p = 'A';
printf("%c\n", grade); // prints "A"
```
पॉइंटर से पढ़ने और उसके ज़रिए लिखने को आज़ादी से मिलाया जा सकता है: `*p = *p + 1` `'A'` को `'B'` में बदल देता है।

---

एक पॉइंटर एक एड्रेस संग्रहीत करता है, और किसी दी गई मशीन पर हर एड्रेस का आकार एक जैसा होता है, चाहे वहाँ कोई भी टाइप संग्रहीत हो। इसलिए एक पॉइंटर का `sizeof` `char *`, `int *` और `double *` के लिए एक जैसा होता है: 64-बिट सिस्टम पर `8` बाइट, 32-बिट पर `4`:
```c
printf("%zu\n", sizeof(int *));  // prints "8" on 64-bit
printf("%zu\n", sizeof(double)); // prints "8"
printf("%zu\n", sizeof(char));   // prints "1"
```
पॉइंटर के आकार को उस चीज़ के आकार से न मिलाएँ जिसकी ओर वह इशारा करता है: `sizeof(p)` एड्रेस का आकार है, `sizeof(*p)` मान का आकार है।

---

किसी अभिव्यक्ति में उपयोग किया गया ऐरे नाम उसके **पहले एलिमेंट** का एड्रेस देता है, इसलिए इसे सीधे एक पॉइंटर को असाइन किया जा सकता है:
```c
int numbers[3] = {10, 20, 30};
int *p = numbers; // same as &numbers[0]
```
किसी पॉइंटर में एक पूर्णांक जोड़ने से वह उतने **एलिमेंट** आगे बढ़ता है, बाइट नहीं: `p + 1`, `numbers[1]` का एड्रेस है, और `*(p + 1)`, `20` है। कंपाइलर स्टेप को टाइप के आकार से स्केल करता है।
इंडेक्सिंग पॉइंटर पर भी काम करती है: `p[i]` को `*(p + i)` परिभाषित किया जाता है, इसलिए `p[2]`, `30` है। इसे **पॉइंटर अरिथमेटिक** कहा जाता है।

---

चूँकि `p + 1` अगला एलिमेंट है, `p++` पॉइंटर को उसी जगह अगले एलिमेंट पर ले जाता है। एक लूप इंडेक्स की जगह पॉइंटर को आगे बढ़ाकर ऐरे में चल सकता है:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
हर चक्कर में `p` जिस एलिमेंट की ओर इशारा करता है वह प्रिंट होता है, फिर `p` एक एलिमेंट आगे बढ़ जाता है।

---

जब कोई ऐरे किसी फ़ंक्शन को पास किया जाता है तो वह **डिके** (decay) होकर अपने पहले एलिमेंट की ओर इशारा करने वाला पॉइंटर बन जाता है। इसीलिए पैरामीटर `int values[]` और `int *values` का अर्थ बिल्कुल एक जैसा होता है, और इसीलिए फ़ंक्शन लंबाई अपने आप नहीं जान सकता: उसे सिर्फ़ एक एड्रेस मिलता है।
एक ही ऐरे में इशारा करने वाले पॉइंटर्स की तुलना और घटाव किया जा सकता है। `end - start` उनके बीच के एलिमेंट्स की संख्या है, और एक लूप पॉइंटर को एक एड्रेस से दूसरे एड्रेस तक चला सकता है:
```c
for (int *p = start; p < end; p++) {
    printf("%d\n", *p);
}
```
`numbers` और `numbers + 3` पास करने से पहले तीन एलिमेंट्स बता दिए जाते हैं, बिना अलग साइज़ पैरामीटर के।

---

फ़ंक्शन आर्ग्युमेंट **by value** पास किए जाते हैं: फ़ंक्शन को एक कॉपी मिलती है, और किसी पैरामीटर को असाइन करने से कॉलर का वेरिएबल कभी नहीं बदलता। किसी फ़ंक्शन को वेरिएबल बदलने देने के लिए, वेरिएबल का एड्रेस पास करें और अंदर पॉइंटर को डिरेफ़रेंस करें:
```c
void reset(int *p) {
    *p = 0;
}

int counter = 7;
reset(&counter); // counter is now 0
```
क्लासिक उदाहरण दो वेरिएबल्स को आपस में बदलना है, जिसमें एक मान की अस्थायी कॉपी चाहिए होती है जबकि दूसरा ओवरराइट होता है।

---

एक फ़ंक्शन सिर्फ़ एक मान `return` कर सकता है। अधिक वापस देने के लिए, वह कॉलर के वेरिएबल्स की ओर इशारा करने वाले पॉइंटर्स लेता है और उनके ज़रिए परिणाम लिखता है। ऐसे पैरामीटर **आउटपुट पैरामीटर** कहलाते हैं:
```c
void min_max(int a, int b, int *min, int *max) {
    *min = a;
    *max = b;
    if (a > b) {
        *min = b;
        *max = a;
    }
}

int lo, hi;
min_max(4, 9, &lo, &hi); // lo is 4, hi is 9
```
कॉलर वेरिएबल्स घोषित करता है, उनके एड्रेस पास करता है, और कॉल के बाद उन्हें भरा हुआ पाता है। कई स्टैंडर्ड फ़ंक्शन यही पैटर्न उपयोग करते हैं, इसीलिए `scanf("%d", &n)` को `&` चाहिए होता है।

---

स्ट्रक्चर की ओर इशारा करने वाला पॉइंटर एरो `->` से सदस्यों तक पहुँचता है, और ऐरे में संग्रहीत स्ट्रक्चर का एड्रेस `&items[i]` से लिया जाता है। एक फ़ंक्शन पॉइंटर **लौटा** भी सकता है, उदाहरण के लिए उस एलिमेंट का जिसे उसने खोजा:
```c
Player *first_active(Player players[], int size) {
    for (int i = 0; i < size; i++) {
        if (players[i].active) {
            return &players[i];
        }
    }
    return NULL;
}
```
कॉलर फिर लौटाए गए पॉइंटर से `->` के साथ सदस्य पढ़ता है, यह जाँचने के बाद कि वह `NULL` नहीं है। पॉइंटर लौटाने से स्ट्रक्चर की कॉपी होने से बचा जाता है और कॉलर मूल एलिमेंट को बदल सकता है।

---

`const` मान या पॉइंटर — किसी को भी सुरक्षित रख सकता है, इस पर निर्भर करता है कि वह कहाँ लिखा जाता है:
```c
const int *p = &a; // pointer to const: *p cannot be changed, p can point elsewhere
int *const q = &a; // const pointer: q always points to a, but *q can be changed
```
घोषणा को दाएँ से बाएँ पढ़ें: `p` एक स्थिरांक `int` की ओर इशारा करने वाला पॉइंटर है; `q` एक `int` की ओर इशारा करने वाला स्थिरांक पॉइंटर है। पॉइंटर to const यह वादा करने का सामान्य तरीका है कि फ़ंक्शन केवल **पढ़ेगा** जो उसे मिलता है, जैसे `int sum(const int *values, int size)` में। उसे एक सामान्य वेरिएबल पास किया जा सकता है; वह वादा केवल यह सीमित करता है कि फ़ंक्शन क्या कर सकता है।

---

एक पॉइंटर एक वेरिएबल है, इसलिए उसका भी अपना एड्रेस होता है, और वह एड्रेस एक **पॉइंटर का पॉइंटर** में संग्रहीत किया जा सकता है, जिसे दो स्टार्स के साथ घोषित किया जाता है:
```c
int x = 7;
int *p = &x;
int **pp = &p;
```
`*pp`, `p` है, यानी `x` का एड्रेस, और `**pp` दोनों स्टेप्स का अनुसरण करके `7` तक पहुँचता है। पॉइंटर का पॉइंटर फ़ंक्शन को यह बदलने देता है कि पॉइंटर कौन सा एड्रेस रखता है: वह `&p` प्राप्त करता है और `*pp` को असाइन करता है।

---

सब कुछ जोड़ते हुए: एक फ़ंक्शन जो पॉइंटर के साथ ऐरे में चलता है, अब तक देखे गए सबसे अच्छे एलिमेंट की ओर इशारा करने वाला पॉइंटर रखता है और उसे लौटाता है, या `NULL` लौटाता है जब लौटाने को कुछ न हो:
```c
int *first_negative(int *values, int size) {
    for (int *p = values; p < values + size; p++) {
        if (*p < 0) {
            return p;
        }
    }
    return NULL;
}
```
कॉलर परिणाम को डिरेफ़रेंस करने से पहले उसकी तुलना `NULL` से करता है, और एलिमेंट का इंडेक्स वापस पाने के लिए `result - values` का उपयोग कर सकता है।
