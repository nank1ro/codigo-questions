# --description--

सब कुछ जोड़ते हुए: एक फ़ंक्शन जो पॉइंटर के साथ ऐरे में चलता है, अब तक देखे गए सबसे अच्छे एलिमेंट की ओर इशारा करने वाला पॉइंटर रखता है और उसे लौटाता है, या `NULL` लौटाता है जब लौटाने को कुछ न हो:
```c
int *first_negative(int *values, int size) {
    for (int *p = values; p < values + size; p++) {
        if (*p < 0) {
            return p;
        }
    }
    return NULL;
}
```
कॉलर परिणाम को डिरेफ़रेंस करने से पहले उसकी तुलना `NULL` से करता है, और एलिमेंट का इंडेक्स वापस पाने के लिए `result - values` का उपयोग कर सकता है।

```c
int *find_max(int *values, int size) {
    if (size == 0) {
        return NULL;
    }
    int *best = values;
    for (int *p = values + 1; p < values + size; p++) {
        if (*p > *best) {
            best = p;
        }
    }
    return best;
}
```
