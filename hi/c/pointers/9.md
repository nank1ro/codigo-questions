# --description--

चूँकि `p + 1` अगला एलिमेंट है, `p++` पॉइंटर को उसी जगह अगले एलिमेंट पर ले जाता है। एक लूप इंडेक्स की जगह पॉइंटर को आगे बढ़ाकर ऐरे में चल सकता है:
```c
int *p = values;
for (int i = 0; i < 3; i++) {
    printf("%d\n", *p);
    p++;
}
```
हर चक्कर में `p` जिस एलिमेंट की ओर इशारा करता है वह प्रिंट होता है, फिर `p` एक एलिमेंट आगे बढ़ जाता है।

# --instructions--

लाइनों को क्रम में लगाएँ ताकि `values` में `1`, `2` और `3` संग्रहीत हों, `p` उसके पहले एलिमेंट की ओर इशारा करे और पॉइंटर को आगे बढ़ाकर हर एलिमेंट प्रिंट हो
