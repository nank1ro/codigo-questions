# --description--

डिरेफ़रेंस किए गए पॉइंटर को **असाइन** भी किया जा सकता है। `*p` में लिखने पर नया मान `p` द्वारा रखे गए एड्रेस पर संग्रहीत होता है, इसलिए जिस वेरिएबल की ओर यह इशारा करता है वह बदल जाता है:
```c
int x = 5;
int *p = &x;
*p = 10;
printf("%d\n", x); // prints "10"
```
`x` और `*p` एक ही मेमोरी के दो नाम हैं। बिना `*` के `p` को असाइन करने से बदले में यह बदल जाएगा कि पॉइंटर **कौन सा एड्रेस** रखता है, न कि वहाँ संग्रहीत मान।
