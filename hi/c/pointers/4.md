# --description--

जो पॉइंटर अभी किसी चीज़ की ओर इशारा नहीं करता, उसे `NULL` रखना चाहिए — `stdio.h` और `stddef.h` में परिभाषित एक विशेष स्थिरांक जिसका अर्थ है "कोई एड्रेस नहीं":
```c
int *p = NULL;
```
एक `NULL` पॉइंटर को डिरेफ़रेंस करना एक रनटाइम एरर है जो प्रोग्राम को क्रैश कर देता है, इसलिए जिस पॉइंटर के `NULL` होने की संभावना होती है उसे उपयोग से पहले जाँचा जाता है:
```c
if (p != NULL) {
    printf("%d\n", *p);
}
```
चूँकि `NULL` शून्य होता है, `if (p)` एक सामान्य शॉर्टहैंड है `if (p != NULL)` के लिए। बिना इनिशियलाइज़र के घोषित पॉइंटर `NULL` नहीं, बल्कि गार्बेज रखता है, इसलिए पॉइंटर को हमेशा इनिशियलाइज़ करें।
