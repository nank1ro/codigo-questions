# --description--

एक पॉइंटर किसी भी टाइप की ओर इशारा कर सकता है: `double *`, `char *`, `bool *` और इसी तरह। घोषणा में दिया गया टाइप कंपाइलर को बताता है कि पॉइंटर के डिरेफ़रेंस होने पर कितने बाइट पढ़ने हैं और उनका क्या अर्थ है:
```c
double price = 9.5;
double *p = &price;
*p = *p * 2; // price is now 19.0
```
पॉइंटर को उस वेरिएबल के टाइप से मेल खाना चाहिए जिसकी ओर वह इशारा करता है; `int *p = &price;` को कंपाइलर अस्वीकार कर देता है। `NULL` एकमात्र मान है जो किसी भी टाइप के पॉइंटर में फिट होता है।

# --instructions--

# --asserts--

`2.5` की ओर इशारा करने पर परिणाम `2.5` होना चाहिए

```c
    double v1 = 2.5;
    try_catch(value_or(&v1, 0.0) == 2.5);
```

`NULL` पॉइंटर के साथ परिणाम फ़ॉलबैक `-1.0` होना चाहिए

```c
    try_catch(value_or(NULL, -1.0) == -1.0);
```

`0.0` की ओर इशारा करने पर परिणाम `0.0` होना चाहिए, फ़ॉलबैक नहीं

```c
    double v3 = 0.0;
    try_catch(value_or(&v3, 7.0) == 0.0);
```

```c
double value_or(double *p, double fallback) {
    if (p == NULL) {
        return fallback;
    }
    return *p;
}
```
