# --description--

केवल एक `if` स्टेटमेंट के कर्ली ब्रैकेट के बीच का कोड ही conditional होता है। क्लोजिंग ब्रैकेट के बाद लिखी गई कोई भी चीज़ बिना शर्त निष्पादित होती है, चाहे शर्त कुछ भी रही हो।

# --instructions--

हमें कैसे पता चलेगा कि `Hello World` हमेशा प्रिंट होगा?
```c
bool online = false;
if (online) {
    printf("User is online\n");
}
printf("Hello World\n");
```

- क्योंकि कोई else statement नहीं है
- क्योंकि कोई else if statement नहीं है
