निर्णय लेना तब आवश्यक होता है जब हम किसी कोड को केवल तभी निष्पादित करना चाहते हैं जब कोई विशेष शर्त पूरी हो।
मान लीजिए कि हम बाहर खेलना चाहते हैं केवल तभी जब मौसम अच्छा हो।
प्रोग्रामिंग में, हम एक boolean वेरिएबल `nice_weather` सेव कर सकते हैं और बाहर खेलने की क्रिया `if` इस वेरिएबल के `true` होने पर कर सकते हैं, जैसे:
```c
bool nice_weather = true;
if (nice_weather) {
    // बाहर खेलें
}
```

---

आइए पिछले उदाहरण को जारी रखें।
```c
bool nice_weather = true;
if (nice_weather) {
    // बाहर खेलें
}
```
हमने देखा कि `if` स्टेटमेंट कोड ब्लॉक को केवल तभी निष्पादित करता है जब शर्त `true` हो।
एक और महत्वपूर्ण बात **कर्ली ब्रैकेट** `{}` हैं जो एक कोड ब्लॉक को दर्शाती हैं।

---

हमने अभी देखा कि किसी शर्त पूरी होने पर कोड ब्लॉक कैसे निष्पादित करें, अब देखते हैं कि पहली शर्त विफल होने पर दूसरा कोड ब्लॉक कैसे निष्पादित करें।
हम बाहर खेलने जाते हैं अगर मौसम अच्छा है; अन्यथा, हम घर पर रहते हैं।
C में हम `else` स्टेटमेंट का उपयोग कर सकते हैं, जैसे:
```c
bool nice_weather = false;
if (nice_weather) {
    // बाहर खेलें
} else {
    // घर पर रहें
}
```

---

मान लीजिए कि हमारे पास जाँचने के लिए एक और शर्त है, जैसे इस उदाहरण में:
```c
int num = 3;
if (num == 2) {
    printf("the number is 2\n");
} else if (num == 3) {
    printf("the number is 3\n");
} else {
    printf("do something else\n");
}
```
और इस कोड का आउटपुट `the number is 3` है।
सबसे पहले, जाँचें कि संख्या 2 के बराबर है या नहीं, यह false है।
तो दूसरे स्टेटमेंट पर चलते हैं और जाँचते हैं कि `num` 3 के बराबर है या नहीं, true होने पर हम `the number is 3` प्रिंट करके निम्नलिखित कोड ब्लॉक निष्पादित करते हैं

---

हम जितने चाहें उतने `else if` स्टेटमेंट जोड़ सकते हैं, कोई सीमा नहीं है
```c
int num = 4;
if (num == 2) {
    printf("the number is 2");
} else if (num == 3) {
    printf("the number is 3");
} else if (num == 4) {
    printf("the number is 4");
} else if (num == 5) {
    printf("the number is 5");
} else if (num == 6) {
    printf("the number is 6");
}
```
और इस कोड का आउटपुट `the number is 4` है।

---

हम एक सशर्त स्टेटमेंट (`if`, `else if` या `else`) को दूसरे सशर्त स्टेटमेंट के अंदर नेस्ट भी कर सकते हैं, ताकि एक अधिक जटिल संरचना बनाई जा सके।
```c
int num = 4;
if (num < 3) {
    printf("the number is lower than 3\n");
} else {
    if (num == 3) {
        printf("the number is 3\n");
  } else if (num == 4) {
        printf("the number is 4\n");
  } else {
        printf("the number is greather than 4\n");
  }
}
```
और इस कोड का आउटपुट `the number is 4` है।

---

अब `if` स्टेटमेंट के सिंटैक्स को अभ्यास में लाने का समय है: कीवर्ड, कोष्ठकों में एक शर्त, और कर्ली ब्रैकेट में लिपटा एक कोड ब्लॉक।
```c
if (condition) {
    // शर्त सही होने पर चलता है
}
```

---

C के boolean लिटरल `true` और `false` हैं: लोअरकेस, बिना कोट्स के, और भाषा में अंतर्निहित होने के बजाय `<stdbool.h>` द्वारा परिभाषित। `True` लिखने पर यह एक शर्त के रूप में कंपाइल नहीं होगा — केवल लोअरकेस रूप ही काम करता है, और जब यह `true` होता है तो ब्लॉक निष्पादित होता है।

---

C में अलग से कोई boolean टेस्ट नहीं होता: कोई शर्त तब true होती है जब उसका मान शून्य के अलावा कुछ भी हो। `<stdbool.h>` से आने वाला `false` वास्तव में `0` ही है, इसलिए उससे सुरक्षित ब्लॉक कभी निष्पादित नहीं होता।

---

C में एक `if` स्टेटमेंट तीन भागों से बनता है: `if` कीवर्ड, कोष्ठकों में एक शर्त, और ब्रैकेट में एक ब्लॉक। कोष्ठक आवश्यक हैं — इन्हीं से कंपाइलर को पता चलता है कि शर्त कहाँ समाप्त होती है।

---

हर सशर्त स्टेटमेंट एक कीवर्ड से शुरू होता है जो कंपाइलर को बताता है कि आगे क्या निष्पादित होगा यह तय करने से पहले एक शर्त की जांच करनी होगी।

---

एक लिटरल `true` शर्त हमेशा true होती है, इसलिए ब्लॉक निष्पादित होता है और इसका `printf` बिल्कुल वैसे ही चलता है जैसे लिखा गया है।

---

एक लिटरल `false` शर्त कभी true नहीं होती, इसलिए ब्लॉक पूरी तरह से छोड़ दिया जाता है और उसके अंदर कुछ भी निष्पादित नहीं होता।

---

शर्तें वे मान हैं जिन्हें एक `if` स्टेटमेंट जांचता है: जब शर्त `true` होती है तो ब्लॉक निष्पादित होता है, जब यह `false` होती है तो इसे छोड़ दिया जाता है।

---

ओपनिंग ब्रैकेट शर्त के साथ उसी लाइन पर या उसके नीचे वाली लाइन पर रखा जा सकता है। C लाइन ब्रेक को नज़रअंदाज़ करता है, इसलिए दोनों स्टाइल बिल्कुल एक ही प्रोग्राम में कंपाइल होते हैं।

---

किसी शर्त के चारों ओर कोष्ठक C के `if` सिंटैक्स का हिस्सा हैं, कोई वैकल्पिक ग्रुपिंग नहीं: `if true { ... }` कंपाइल नहीं होता।

---

कोट में लिखा `"false"` एक स्ट्रिंग है, boolean नहीं — और शर्त में एक स्ट्रिंग एक नॉन-नल एड्रेस होती है, जिसे true माना जाता है। केवल बिना कोट वाला `false` ही ब्लॉक को निष्पादित होने से रोकता है।

---

C में `if` लाइन के हिस्सों के बीच स्पेस स्वतंत्र है: `if(true){` और `if (true) {` कंपाइलर के लिए एक ही स्टेटमेंट हैं, इसलिए केवल हिस्सों का क्रम ही मायने रखता है।

---

एक कोड ब्लॉक एक स्टेटमेंट तक सीमित नहीं है। ब्रैकेट के बीच का हर स्टेटमेंट, एक के बाद एक, उसी क्रम में निष्पादित होता है जिसमें वह लिखा गया है।

---

एक boolean वेरिएबल को सीधे शर्त के रूप में इस्तेमाल किया जा सकता है, किसी तुलना की जरूरत नहीं। चूंकि `online` में पहले से ही `true` है, अकेले `if (online)` लिखना ही ब्लॉक निष्पादित करने के लिए काफी है।

---

एक `bool` वेरिएबल शर्त के रूप में काम करता है क्योंकि `if` केवल उस पल में उसमें संग्रहीत मान को देखता है। `online` में `false` होने पर, `if (online)` बिल्कुल `if (false)` की तरह व्यवहार करता है।

---

केवल एक `if` स्टेटमेंट के कर्ली ब्रैकेट के बीच का कोड ही conditional होता है। क्लोजिंग ब्रैकेट के बाद लिखी गई कोई भी चीज़ बिना शर्त निष्पादित होती है, चाहे शर्त कुछ भी रही हो।

---

एक कोड ब्लॉक में कितने स्टेटमेंट हो सकते हैं इसकी कोई निश्चित सीमा नहीं है — एक लाइन हो या सौ, शर्त `true` होने पर वे सभी एक साथ निष्पादित होते हैं।

---

किसी boolean वेरिएबल को शर्त के रूप में पढ़ना बिल्कुल एक लिटरल की तरह काम करता है: चूंकि `online` में `true` है, ब्लॉक निष्पादित होता है और इसका `printf` चलता है।

---

जब इसके बजाय `online` में `false` हो, तो शर्त false होती है, इसलिए ब्लॉक पूरी तरह से छोड़ दिया जाता है और उन ब्रैकेट के अंदर कुछ भी प्रिंट नहीं होता।
