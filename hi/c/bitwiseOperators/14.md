# --description--

C23 से पहले कोई ऐसा format specifier नहीं था जो किसी संख्या को बाइनरी में प्रिंट करता, और `0b1010` जैसे लिटरल भी मानक C नहीं थे। बिट्स दिखाने के लिए आप लूप स्वयं लिखते हैं: सबसे ऊँचे बिट से बिट `0` तक नीचे चलें और हर बार `(value >> i) & 1u` प्रिंट करें।
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
मान को `i` से नीचे शिफ्ट करने पर बिट `i` सबसे दाहिने स्थान पर आ जाता है, जहाँ `& 1u` उसे अलग कर देता है।
