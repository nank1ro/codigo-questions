# --description--

किसी एक बिट को **toggle** करने के लिए, यानी उसकी वर्तमान स्थिति जो भी हो, उसे पलटने के लिए, मान को mask के साथ XOR करें:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// "7" प्रिंट करता है
```
चूँकि XOR अपने आप को रद्द कर देता है, उसी बिट को दूसरी बार टॉगल करने पर मूल मान वापस मिल जाता है।
