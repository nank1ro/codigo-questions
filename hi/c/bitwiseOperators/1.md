# --description--

हर पूर्णांक मेमोरी में **बिट्स** की एक पंक्ति के रूप में संग्रहीत होता है, जिनमें से प्रत्येक `0` या `1` होता है। संख्या `12` को `00001100` के रूप में और संख्या `10` को `00001010` के रूप में संग्रहीत किया जाता है।
**बिटवाइज़ ऑपरेटर** पूरी संख्या के बजाय उन अलग-अलग बिट्स पर काम करते हैं। **AND** ऑपरेटर `&` दोनों मानों की बिट दर बिट तुलना करता है और केवल वहीं `1` रखता है जहाँ *दोनों* बिट्स `1` हों:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// "8" प्रिंट करता है
```
बिट पैटर्न आमतौर पर `0x0C` जैसे हेक्साडेसिमल लिटरल के रूप में लिखे जाते हैं, क्योंकि प्रत्येक हेक्स अंक ठीक चार बिट्स को दर्शाता है। बिट के काम के लिए हमेशा `unsigned` टाइप का उपयोग करें और उन्हें `%u` के साथ प्रिंट करें।
