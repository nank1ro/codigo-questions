# --description--

**XOR** ऑपरेटर `^` (exclusive or) केवल वहीं `1` रखता है जहाँ दोनों बिट्स *अलग-अलग* हों:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// "6" प्रिंट करता है
```
इससे एक उपयोगी गुण निकलता है: एक ही XOR को दो बार लगाने पर मूल मान वापस मिल जाता है।
