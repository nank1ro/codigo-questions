# --description--

प्रत्येक बाइनरी बिटवाइज़ ऑपरेटर का एक **compound assignment** रूप होता है जो वेरिएबल को उसी जगह अपडेट करता है: `&=`, `|=`, `^=`, `<<=` और `>>=`।
```c
unsigned int x = 12;
x &= 10;  // x = x & 10; के समान
x |= 1;   // x = x | 1; के समान
x ^= 3;   // x = x ^ 3; के समान
x <<= 1;  // x = x << 1; के समान
x >>= 2;  // x = x >> 2; के समान
```
ये वेरिएबल का नाम दोहराने से बेहतर पढ़े जाते हैं और किसी फ्लैग वेरिएबल के बिट्स बदलने का सामान्य तरीका हैं।

# --instructions--

पंक्तियों को क्रमबद्ध करें ताकि `flags` `0x01` से शुरू हो, फिर `|=` से `4` के मूल्य वाला बिट चालू हो, फिर `<<=` से 2 स्थान बाईं ओर शिफ्ट हो, और अंत में प्रिंट हो
