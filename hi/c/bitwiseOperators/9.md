# --description--

बिट्स की गिनती `0` से होती है, सबसे दाहिने बिट से शुरू, इसलिए `1u << n` एक ऐसा mask है जिसमें केवल बिट `n` चालू होता है।
किसी एक बिट को **set** करने के लिए, यानी बाकी को छुए बिना उसे चालू करने के लिए, मान को उस mask के साथ OR करें:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// "6" प्रिंट करता है
```
यदि बिट पहले से चालू था तो मान नहीं बदलता, जिससे बिट सेट करना दोहराने के लिए सुरक्षित बन जाता है।
