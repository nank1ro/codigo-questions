# --description--

कई छोटी संख्याएँ अक्सर एक बड़े मान के भीतर पैक की जाती हैं। उनमें से किसी एक को वापस पढ़ने के लिए, पहले उसे नीचे शिफ्ट करें ताकि वह बिट `0` से शुरू हो, फिर उसके ऊपर की हर चीज़ को mask कर दें:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// "18" प्रिंट करता है, 0x12 बाइट
```
पहले शिफ्ट करना और बाद में mask करना याद रखने वाला क्रम है: mask हमेशा उस फ़ील्ड का वर्णन करता है जब वह नीचे तक पहुँच चुकी होती है।

# --instructions--

पंक्तियों को क्रमबद्ध करें ताकि `packed` को 16 स्थान नीचे शिफ्ट किया जाए, शिफ्ट किए गए मान के केवल निचले 8 बिट्स `third_byte` में रखे जाएँ और उसे प्रिंट किया जाए
