हर पूर्णांक मेमोरी में **बिट्स** की एक पंक्ति के रूप में संग्रहीत होता है, जिनमें से प्रत्येक `0` या `1` होता है। संख्या `12` को `00001100` के रूप में और संख्या `10` को `00001010` के रूप में संग्रहीत किया जाता है।
**बिटवाइज़ ऑपरेटर** पूरी संख्या के बजाय उन अलग-अलग बिट्स पर काम करते हैं। **AND** ऑपरेटर `&` दोनों मानों की बिट दर बिट तुलना करता है और केवल वहीं `1` रखता है जहाँ *दोनों* बिट्स `1` हों:
```c
//  00001100   (12)
// &00001010   (10)
//  --------
//  00001000   (8)
printf("%u\n", 12u & 10u);
// prints "8"
```
बिट पैटर्न आमतौर पर `0x0C` जैसे हेक्साडेसिमल लिटरल के रूप में लिखे जाते हैं, क्योंकि प्रत्येक हेक्स अंक ठीक चार बिट्स को दर्शाता है। बिट के काम के लिए हमेशा `unsigned` टाइप का उपयोग करें और उन्हें `%u` के साथ प्रिंट करें।

---

**OR** ऑपरेटर `|` दोनों मानों की बिट दर बिट तुलना करता है और वहाँ `1` रखता है जहाँ बिट्स में से *कम से कम एक* `1` हो:
```c
//  00001100   (12)
// |00001010   (10)
//  --------
//  00001110   (14)
printf("%u\n", 12u | 10u);
// prints "14"
```
`|` दो बिट पैटर्न को एक में मिलाने का सामान्य तरीका है।

---

**XOR** ऑपरेटर `^` (exclusive or) केवल वहीं `1` रखता है जहाँ दोनों बिट्स *अलग-अलग* हों:
```c
//  00001100   (12)
// ^00001010   (10)
//  --------
//  00000110   (6)
printf("%u\n", 12u ^ 10u);
// prints "6"
```
इससे एक उपयोगी गुण निकलता है: एक ही XOR को दो बार लगाने पर मूल मान वापस मिल जाता है।

---

**NOT** ऑपरेटर `~` एक एकल ऑपरेंड लेता है और उसके हर बिट को पलट देता है: प्रत्येक `0` `1` बन जाता है और प्रत्येक `1` `0` बन जाता है।
एक `unsigned int` में 32 बिट्स होते हैं, इसलिए `~0x0Fu` उन सभी 32 को पलट देता है और एक बहुत बड़ी संख्या बनाता है। केवल वही बाइट रखने के लिए जिसमें आपकी रुचि है, `~` को `& 0xFF` के साथ मिलाएँ:
```c
printf("%u\n", ~0x0Fu & 0xFFu);
// prints "240"
```
`~` की बाइंडिंग `&` से अधिक तगड़ी होती है, इसलिए वह पहले लागू होता है।
`~` को तार्किक `!` के साथ भ्रमित न करें: `!` पूरे मान को देखकर `0` या `1` देता है, जबकि `~` हर बिट को फिर से लिखता है।

---

**left shift** ऑपरेटर `<<` हर बिट को कुछ स्थानों तक बाईं ओर खिसका देता है और दाईं ओर खाली हुए स्थानों को शून्य से भर देता है:
```c
//  00000011   (3)
//  << 2
//  00001100   (12)
printf("%u\n", 3u << 2);
// prints "12"
```
`n` से बाईं ओर शिफ्ट करना मान को 2 की घात `n` से गुणा कर देता है।
दो गलतियाँ C प्रोग्राम को अपरिभाषित बना देती हैं: ऋणात्मक मान को बाईं ओर शिफ्ट करना, और टाइप की चौड़ाई के बराबर या उससे अधिक मात्रा से शिफ्ट करना (`unsigned int` के लिए 32)। **unsigned** मानों के साथ काम करने से आप पहली गलती से बचे रहते हैं।

---

**right shift** ऑपरेटर `>>` हर बिट को दाईं ओर खिसका देता है; दाहिने छोर से बाहर गिरने वाले बिट्स छोड़ दिए जाते हैं। किसी unsigned मान पर बाईं ओर खाली हुए स्थान शून्य से भर दिए जाते हैं:
```c
//  00001100   (12)
//  >> 2
//  00000011   (3)
printf("%u\n", 12u >> 2);
// prints "3"
```
`n` से दाईं ओर शिफ्ट करना किसी unsigned मान को 2 की घात `n` से विभाजित कर देता है, शेषफल छोड़कर।
*ऋणात्मक* मान को दाईं ओर शिफ्ट करना पोर्टेबल नहीं है, जो बिट का काम `unsigned` टाइप पर रखने का एक और कारण है।

---

प्रत्येक बाइनरी बिटवाइज़ ऑपरेटर का एक **compound assignment** रूप होता है जो वेरिएबल को उसी जगह अपडेट करता है: `&=`, `|=`, `^=`, `<<=` और `>>=`।
```c
unsigned int x = 12;
x &= 10;  // same as x = x & 10;
x |= 1;   // same as x = x | 1;
x ^= 3;   // same as x = x ^ 3;
x <<= 1;  // same as x = x << 1;
x >>= 2;  // same as x = x >> 2;
```
ये वेरिएबल का नाम दोहराने से बेहतर पढ़े जाते हैं और किसी फ्लैग वेरिएबल के बिट्स बदलने का सामान्य तरीका हैं।

---

एक **mask** ऐसा मान होता है जिसके बिट्स किसी दूसरे मान के उस हिस्से को चुनते हैं जिसमें आपकी रुचि है। `&` के साथ मिलाकर, एक mask उन बिट्स को रखता है जो mask में `1` होते हैं और बाकी सबको शून्य कर देता है:
```c
//  10101011   (0xAB)
// &00001111   (0x0F)
//  --------
//  00001011   (0x0B)
printf("%u\n", 0xABu & 0x0Fu);
// prints "11"
```
`0x0F` निचले चार बिट्स रखता है, जिन्हें low **nibble** कहा जाता है, और `0xFF` निचले आठ बिट्स, यानी एक पूरा बाइट, रखता है।

---

बिट्स की गिनती `0` से होती है, सबसे दाहिने बिट से शुरू, इसलिए `1u << n` एक ऐसा mask है जिसमें केवल बिट `n` चालू होता है।
किसी एक बिट को **set** करने के लिए, यानी बाकी को छुए बिना उसे चालू करने के लिए, मान को उस mask के साथ OR करें:
```c
unsigned int value = 4;      // 00000100
value = value | (1u << 1);   // 00000110
printf("%u\n", value);
// prints "6"
```
यदि बिट पहले से चालू था तो मान नहीं बदलता, जिससे बिट सेट करना दोहराने के लिए सुरक्षित बन जाता है।

---

किसी एक बिट को **clear** करने के लिए, यानी उसे बंद करने के लिए, मान को mask के *विपरीत* के साथ AND करें:
```c
unsigned int value = 7;       // 00000111
value = value & ~(1u << 1);   // 00000101
printf("%u\n", value);
// prints "5"
```
`~(1u << 1)` एक ऐसा मान है जिसमें बिट `1` को छोड़कर हर बिट चालू है, इसलिए AND बाकी सब कुछ अछूता रखता है।

---

किसी एक बिट को **toggle** करने के लिए, यानी उसकी वर्तमान स्थिति जो भी हो, उसे पलटने के लिए, मान को mask के साथ XOR करें:
```c
unsigned int value = 5;      // 00000101
value = value ^ (1u << 1);   // 00000111
printf("%u\n", value);
// prints "7"
```
चूँकि XOR अपने आप को रद्द कर देता है, उसी बिट को दूसरी बार टॉगल करने पर मूल मान वापस मिल जाता है।

---

किसी एक बिट को **test** करने के लिए, मान को mask के साथ AND करें और देखें कि परिणाम `0` से अलग है या नहीं:
```c
unsigned int value = 10;                  // 00001010
printf("%d\n", (value & (1u << 3)) != 0); // prints "1"
printf("%d\n", (value & (1u << 2)) != 0); // prints "0"
```
AND `1` उत्पन्न नहीं करता: वह या तो `0` या mask स्वयं उत्पन्न करता है, जो बिट `3` के लिए `8` होता है। इसीलिए परिणाम को सीधे उत्तर के रूप में उपयोग करने के बजाय `!= 0` से तुलना की जाती है।

---

**Flags** नामित masks होते हैं, प्रत्येक एक अलग बिट का उपयोग करता है, और ये सभी एक ही वेरिएबल में संग्रहीत किए जा सकते हैं। इन्हें `|` के साथ जोड़ा जाता है और `&` के साथ पढ़ा जाता है:
```c
unsigned int READ = 0x01, WRITE = 0x02;
unsigned int perms = READ | WRITE;
printf("%d\n", (perms & WRITE) != 0);
// prints "1"
```
इसलिए एक `unsigned int` 32 स्वतंत्र हाँ/नहीं उत्तर रख सकता है।

---

C23 से पहले कोई ऐसा format specifier नहीं था जो किसी संख्या को बाइनरी में प्रिंट करता, और `0b1010` जैसे लिटरल भी मानक C नहीं थे। बिट्स दिखाने के लिए आप लूप स्वयं लिखते हैं: सबसे ऊँचे बिट से बिट `0` तक नीचे चलें और हर बार `(value >> i) & 1u` प्रिंट करें।
```c
unsigned int value = 5;
for (int i = 3; i >= 0; i--) {
    printf("%u", (value >> i) & 1u);
}
printf("\n");
// prints "0101"
```
मान को `i` से नीचे शिफ्ट करने पर बिट `i` सबसे दाहिने स्थान पर आ जाता है, जहाँ `& 1u` उसे अलग कर देता है।

---

यह गिनना कि किसी मान के कितने बिट्स `1` हैं, एक क्लासिक बिट लूप है: निचले बिट को `& 1u` से जाँचें, उसे एक काउंटर में जोड़ें, फिर मान को `>>=` से एक स्थान दाईं ओर शिफ्ट करें और कुछ न बचने तक दोहराएँ।
```c
unsigned int value = 6, count = 0;
while (value != 0) {
    count += value & 1u;
    value >>= 1;
}
// count is 2
```
लूप हमेशा समाप्त होता है, क्योंकि किसी unsigned मान को पर्याप्त बार दाईं ओर शिफ्ट करने पर वह `0` हो जाता है।

---

कई छोटी संख्याएँ अक्सर एक बड़े मान के भीतर पैक की जाती हैं। उनमें से किसी एक को वापस पढ़ने के लिए, पहले उसे नीचे शिफ्ट करें ताकि वह बिट `0` से शुरू हो, फिर उसके ऊपर की हर चीज़ को mask कर दें:
```c
unsigned int packed = 0x1234;
printf("%u\n", (packed >> 8) & 0xFF);
// prints "18", the 0x12 byte
```
पहले शिफ्ट करना और बाद में mask करना याद रखने वाला क्रम है: mask हमेशा उस फ़ील्ड का वर्णन करता है जब वह नीचे तक पहुँच चुकी होती है।
