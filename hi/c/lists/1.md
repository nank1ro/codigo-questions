# --description--

एक **लिंक्ड लिस्ट** मानों को मेमोरी में बिखरे हुए अलग-अलग **नोड्स** में संग्रहीत करती है: हर नोड एक मान और अगले नोड की ओर इशारा करने वाले पॉइंटर को रखता है, और आखिरी नोड `NULL` की ओर इशारा करता है। भीतर का पॉइंटर उसी टाइप की ओर इशारा करता है जिसे घोषित किया जा रहा है, इसलिए स्ट्रक्ट को खुद का नाम देने के लिए एक **टैग** की ज़रूरत होती है; `typedef` नाम ब्रेसिज़ के भीतर अभी मौजूद नहीं होता:
```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```
नोड एक-दूसरे से इस तरह जुड़ते हैं कि एक नोड का एड्रेस दूसरे के `next` में संग्रहीत किया जाता है, और इशारा किए गए नोड के मेंबर एरो से एक्सेस किए जाते हैं:
```c
Node second = {2, NULL};
Node first = {1, &second};
printf("%d\n", first.next->value); // prints "2"
```
