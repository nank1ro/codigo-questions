# --description--

**अंत** में नोड जोड़ने के लिए आखिरी नोड, यानी जिसका `next` `NULL` है, चाहिए। फ़ंक्शन उसे खोजने तक चलता है, फिर नया नोड वहाँ जोड़ देता है और अपरिवर्तित हेड लौटाता है:
```c
Node *last = head;
while (last->next != NULL) {
    last = last->next;
}
last->next = node;
```
जब लिस्ट खाली होती है तो चलने के लिए कोई आखिरी नोड नहीं होता: नया नोड सीधे हेड के रूप में लौटा दिया जाता है।

```c
#include <stdio.h>
#include <stdlib.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *push_back(Node *head, int value) {
    Node *node = malloc(sizeof(Node));
    node->value = value;
    node->next = NULL;
    if (head == NULL) {
        return node;
    }
    Node *last = head;
    while (last->next != NULL) {
        last = last->next;
    }
    last->next = node;
    return head;
}
int main() {
    Node *head = NULL;
    head = push_back(head, 1);
    head = push_back(head, 2);
    head = push_back(head, 3);
    for (Node *n = head; n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}
```
