# --description--

लिस्ट को उलटने का मतलब है हर `next` पॉइंटर को जगह पर ही मोड़ देना, तीन पॉइंटर के साथ: `prev` पहले से उलटा हुआ हिस्सा है, `head` वह नोड है जिसे प्रोसेस किया जा रहा है और `next` लिस्ट के बाकी हिस्से की एक कॉपी है, जिसे लिंक बदलने से पहले सेव किया जाता है। हर स्टेप पर वर्तमान नोड वापस `prev` की ओर इशारा करता है, फिर `prev` और `head` दोनों आगे बढ़ जाते हैं:
```c
Node *next = head->next;
head->next = prev;
prev = head;
head = next;
```
जब `head` `NULL` तक पहुँच जाता है, तब तक हर लिंक पलट चुका होता है और `prev` नया हेड होता है।

```c
#include <stdio.h>
typedef struct Node { int value; struct Node *next; } Node;
Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head != NULL) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
int main() {
    Node c = {3, NULL};
    Node b = {2, &c};
    Node a = {1, &b};
    for (Node *n = reverse(&a); n != NULL; n = n->next) {
        printf("%d\n", n->value);
    }
    return 0;
}
```
