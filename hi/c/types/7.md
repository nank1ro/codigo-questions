# --description--

दो `int` वेरिएबल से फ़्लोटिंग-पॉइंट डिवीज़न पाने का मानक तरीका कास्ट है: भाग देने से पहले **एक ऑपरेंड** को `double` में कास्ट करें।
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
पूरे परिणाम को कास्ट करना, जैसे `(double) (total / count)`, एक आम गलती है: उस समय तक पूर्णांक भाग पहले ही हो चुका होता है और दशमलव भाग खो जाता है।

# --instructions--

कोड को पूरा करें ताकि `avg` में `total` को `count` से भाग देने पर मिलने वाला दशमलव भाग सहित परिणाम आए, फिर उसे एक दशमलव अंक के साथ प्रिंट करें
