C एक **स्टेटिकली टाइप्ड** भाषा है: हर वेरिएबल एक टाइप के साथ घोषित किया जाता है, जो तय करता है कि वह क्या स्टोर कर सकता है और कितनी मेमोरी लेता है।
सबसे ज़्यादा उपयोग होने वाले तीन टाइप हैं:
- `int` : पूर्णांकों के लिए, जैसे `30` या `-4`
- `double` : दशमलव भाग वाली संख्याओं के लिए, जैसे `1.75`
- `char` : एकल उद्धरण चिह्नों में लिखे एक अक्षर के लिए, जैसे `'A'`

हर टाइप का अपना `printf` **फॉर्मेट स्पेसिफायर** होता है: `%d` एक `int` प्रिंट करता है, `%f` एक `double` प्रिंट करता है (डिफ़ॉल्ट रूप से छह दशमलव अंकों के साथ), और `%c` एक `char` प्रिंट करता है:
```c
int age = 30;
double height = 1.75;
char initial = 'A';
printf("%d %f %c\n", age, height, initial);
// "30 1.750000 A" प्रिंट करता है
```
टाइप के लिए गलत स्पेसिफायर उपयोग करने पर गलत आउटपुट मिलता है, इसलिए हमेशा उन्हें मिलाकर रखें।

---

C में दो फ़्लोटिंग-पॉइंट टाइप होते हैं: `float` (सिंगल प्रिसिज़न, लगभग 7 सार्थक अंक) और `double` (डबल प्रिसिज़न, लगभग 15 सार्थक अंक)।
`1.75` जैसा दशमलव लिटरल `double` होता है; `float` लिटरल लिखने के लिए `1.75f` की तरह `f` सफ़िक्स जोड़ें।
जब तक मेमोरी की कमी न हो, `double` को प्राथमिकता दें: यह डिफ़ॉल्ट है और अधिक सटीक है।
```c
double pi = 3.14159;
float ratio = 0.5f;
```
जो फ़ंक्शन दशमलव परिणाम लौटाता है उसे रिटर्न टाइप के रूप में `double` घोषित करना चाहिए, और `double` पैरामीटर पूर्णांक और दशमलव दोनों तरह के आर्गुमेंट स्वीकार करते हैं:
```c
double half(double x) {
    return x / 2;
}
```

---

`%f` छह दशमलव अंक प्रिंट करता है, जो शायद ही कभी वांछित होता है। `%` और `f` के बीच एक प्रिसिज़न लगाकर आप तय कर सकते हैं कि कितने दशमलव अंक दिखाने हैं: `%.2f` दो दशमलव अंक प्रिंट करता है, `%.1f` एक, और मान **राउंड** किया जाता है, काटा नहीं जाता:
```c
double price = 9.987;
printf("%.2f\n", price); // "9.99" प्रिंट करता है
printf("%.1f\n", price); // "10.0" प्रिंट करता है
```
`float` को भी `double` जैसे ही स्पेसिफायर से प्रिंट किया जाता है: `printf` को पास करते समय इसे अपने आप `double` में बदल दिया जाता है।

---

`/` का परिणाम इसके ऑपरेंड्स के टाइप पर निर्भर करता है।
जब **दोनों** ऑपरेंड पूर्णांक होते हैं, तो परिणाम पूर्णांक होता है और दशमलव भाग हटा दिया जाता है: `7 / 2` का मान `3.5` नहीं, `3` होता है।
जब **कम से कम एक** ऑपरेंड फ़्लोटिंग-पॉइंट मान हो, तो भाग दशमलव भाग को बनाए रखता है: `7 / 2.0` का मान `3.5` होता है।
```c
printf("%d\n", 7 / 2);     // "3" प्रिंट करता है
printf("%f\n", 7 / 2.0);   // "3.500000" प्रिंट करता है
```
लिटरल को `2` की जगह `2.0` लिखना फ़्लोटिंग-पॉइंट डिवीज़न को बाध्य करने का सबसे सरल तरीका है।

---

जब कोई मान अलग टाइप के वेरिएबल को असाइन किया जाता है, तो C संख्यात्मक टाइप को **अंतर्निहित रूप से** बदल देता है।
- `double` में स्टोर किया गया `int` बिना किसी नुकसान के बड़ा किया जाता है: `double d = 3;` से `d` का मान `3.0` हो जाता है
- `int` में स्टोर किया गया `double` **छोटा** कर दिया जाता है: `int n = 3.99;` से `n` का मान `3` हो जाता है (कंपाइलर आमतौर पर इसके लिए चेतावनी देता है)

यह रूपांतरण केवल असाइनमेंट के समय होता है। दाईं ओर की अभिव्यक्ति पहले अपने ही टाइप में गणना की जाती है:
```c
double d = 7 / 2;
```
यहाँ `7 / 2` एक पूर्णांक भाग है जो `3` देता है, और उसके बाद ही `3` को `3.0` में बदला जाता है।

---

जब अंतर्निहित रूपांतरण वह नहीं होता जो आप चाहते हैं, या आप इसे स्पष्ट दिखाना चाहते हैं, तो **एक्सप्लिसिट कास्ट** का उपयोग करें: मान से पहले कोष्ठक में लक्ष्य टाइप लिखें।
```c
double x = 3.99;
int n = (int) x;   // n का मान 3 है
```
फ़्लोटिंग-पॉइंट मान को `int` में कास्ट करने पर वह **शून्य की ओर छोटा** हो जाता है: `(int) 3.99` का मान `3` है और `(int) -2.5` का मान `-2` है, कोई राउंडिंग नहीं होती।
कास्ट केवल उसके ठीक बाद वाले मान पर लागू होता है, इसलिए `(int) x * 2` पहले `x` को कास्ट करता है और फिर गुणा करता है।

---

दो `int` वेरिएबल से फ़्लोटिंग-पॉइंट डिवीज़न पाने का मानक तरीका कास्ट है: भाग देने से पहले **एक ऑपरेंड** को `double` में कास्ट करें।
```c
int total = 7, count = 2;
double avg = (double) total / count; // 3.5
```
पूरे परिणाम को कास्ट करना, जैसे `(double) (total / count)`, एक आम गलती है: उस समय तक पूर्णांक भाग पहले ही हो चुका होता है और दशमलव भाग खो जाता है।

---

`char` वास्तव में एक छोटा पूर्णांक है: यह अक्षर का **ASCII कोड** स्टोर करता है।
`'A'` का मान `65` है, `'a'` का `97` है और `'0'` का `48` है, और लगातार आने वाले अक्षरों के कोड भी लगातार होते हैं।
यही कारण है कि आप अक्षरों पर अंकगणित कर सकते हैं:
- `'a' + 1` का मान `98` है, जो `'b'` का कोड है
- `'7' - '0'` का मान `55 - 48` है, यानी संख्या `7`

एक ही मान को `%c` से अक्षर के रूप में या `%d` से संख्या के रूप में प्रिंट किया जा सकता है:
```c
char c = 'A';
printf("%c %d\n", c, c); // "A 65" प्रिंट करता है
```

---

बड़े और छोटे अक्षर ASCII तालिका में `32` स्थान अलग होते हैं: `'A'` का मान `65` है और `'a'` का `97`।
इसलिए किसी छोटे अक्षर में से `32` घटाने पर उसका बड़ा रूप मिलता है, और परिणाम को वापस एक `char` में स्टोर किया जा सकता है:
```c
char upper = 'g' - 32; // 'G'
```

---

`int` अकेला पूर्णांक टाइप नहीं है। मॉडिफायर इसका आकार और सीमा बदल देते हैं:
- `short` कम मेमोरी उपयोग करता है और इसकी सीमा छोटी होती है (आमतौर पर -32768 से 32767 तक)
- `long` की सीमा बड़ी होती है (64-बिट सिस्टम पर लगभग ±9 क्विंटिलियन)
- `unsigned` चिह्न हटा देता है: `unsigned int` की सीमा `0` से लगभग 4 अरब तक होती है, लेकिन यह कभी ऋणात्मक नहीं हो सकता

जिस लिटरल को `long` होना ज़रूरी है उसमें `L` सफ़िक्स लगाया जाता है, `unsigned` में `U` सफ़िक्स, और हर टाइप का अपना स्पेसिफायर होता है:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" प्रिंट करता है
```
`%ld` एक `long` प्रिंट करता है, `%u` एक `unsigned int`, और `%lu` एक `unsigned long`। ज़्यादातर सिस्टम पर एक सामान्य `int` लगभग 2 अरब तक के मान रख सकता है, इसलिए `5000000000` उसमें फिट नहीं होता।

---

`sizeof` ऑपरेटर बताता है कि कोई टाइप या वेरिएबल कितने **बाइट्स** लेता है। इसके परिणाम का टाइप `size_t` होता है, जिसे `%zu` से प्रिंट किया जाता है:
```c
printf("%zu\n", sizeof(int));  // ज़्यादातर सिस्टम पर "4" प्रिंट करता है
```
स्टैंडर्ड केवल इतनी गारंटी देता है कि `sizeof(char)` का मान `1` है और `short <= int <= long` होता है, लेकिन एक सामान्य 64-बिट सिस्टम पर आकार इस प्रकार हैं: `char` 1, `short` 2, `int` 4, `long` 8, `float` 4, `double` 8।
`sizeof` का उपयोग अक्सर बिना संख्या को हार्डकोड किए यह जाँचने के लिए किया जाता है कि कोई वेरिएबल कितनी मेमोरी लेता है।

---

हर पूर्णांक टाइप की एक सीमित सीमा होती है, और `limits.h` हेडर उन सीमाओं को नाम देता है: `int` के लिए `INT_MAX` और `INT_MIN`, `long` के लिए `LONG_MAX`, `unsigned int` के लिए `UINT_MAX`, और इसी तरह अन्य।
```c
#include <limits.h>

printf("%d\n", INT_MAX); // ज़्यादातर सिस्टम पर "2147483647" प्रिंट करता है
```
साइन वाले टाइप में `INT_MAX` से आगे जाना **अपरिभाषित व्यवहार** है: प्रोग्राम रैप अराउंड कर सकता है, क्रैश हो सकता है, या कुछ भी और कर सकता है। गणना करने से पहले जाँच लें:
```c
if (a <= INT_MAX - b) { /* a + b सुरक्षित है */ }
```
ध्यान दें कि यह जाँच जोड़ने के बजाय घटाने का उपयोग करती है, क्योंकि `a + b` खुद पहले ही ओवरफ़्लो कर सकता है।

---

साइन वाले टाइप के विपरीत, **बिना चिह्न का** अंकगणित सीमा से बाहर जाने पर भी अच्छी तरह परिभाषित होता है: मान एक ओडोमीटर की तरह **रैप अराउंड** करता है।
`UINT_MAX` में `1` जोड़ने पर `0` मिलता है, और `0` में से `1` घटाने पर `UINT_MAX` (जब `unsigned int` 32-बिट का हो तो `4294967295`) मिलता है:
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // "0" प्रिंट करता है
```
यही कारण है कि किसी `unsigned` वेरिएबल को "जब तक वह ऋणात्मक न हो जाए" गिनने वाला लूप कभी नहीं रुकता: एक बिना चिह्न वाला मान कभी `0` से कम नहीं होता।

---

C99 से हेडर `stdbool.h`, स्थिरांक `true` (`1`) और `false` (`0`) के साथ `bool` टाइप प्रदान करता है।
`bool` एक पूर्णांक टाइप है जिसके केवल दो मान होते हैं, इसलिए किसी भी संख्या को `bool` में बदलने पर हर गैर-शून्य मान के लिए `true` और `0` के लिए `false` मिलता है। यह `int` में बदलने से अलग है:
```c
#include <stdbool.h>

bool b = 0.5;  // true, क्योंकि 0.5 शून्य नहीं है
int n = 0.5;   // 0, क्योंकि दशमलव भाग छोटा कर दिया जाता है
```
`x != 0` जैसी तुलनाएँ पहले से ही `bool`-संगत परिणाम देती हैं, और `bool` लौटाने वाला फ़ंक्शन यह दर्शाता है कि वह हाँ/नहीं वाले सवाल का जवाब देता है।

---

किसी अंकगणितीय संक्रिया को उसके ऑपरेंड्स के टाइप में किया जाता है, **न कि** परिणाम पाने वाले वेरिएबल के टाइप में।
इसलिए `int` वाले `n` के लिए `long big = n * n;` लिखने पर दो `int` मानों को गुणा किया जाता है, यदि गुणनफल बहुत बड़ा हो तो ओवरफ़्लो होता है, और उसके बाद ही (पहले से गलत) परिणाम को `long` में स्टोर किया जाता है।
अधिक व्यापक टाइप में गणना करने के लिए संक्रिया से **पहले** किसी एक ऑपरेंड को कास्ट करें:
```c
int n = 100000;
long big = (long) n * n; // long के रूप में गणना होकर 10000000000 मिलता है
```
यही नियम बताता है कि `(double) total / count` क्यों काम करता है: कास्ट ऑपरेंड का टाइप बदल देता है, और भाग उसी के अनुसार होता है।

---

सब कुछ मिलाकर: मान के प्रकार के अनुसार टाइप चुनें, हर `printf` स्पेसिफायर को उसके आर्गुमेंट के टाइप से मिलाएँ, और जब किसी गणना को उसके ऑपरेंड्स से अलग टाइप में करना हो तो कास्ट करें।
