# --description--

`%f` छह दशमलव अंक प्रिंट करता है, जो शायद ही कभी वांछित होता है। `%` और `f` के बीच एक प्रिसिज़न लगाकर आप तय कर सकते हैं कि कितने दशमलव अंक दिखाने हैं: `%.2f` दो दशमलव अंक प्रिंट करता है, `%.1f` एक, और मान **राउंड** किया जाता है, काटा नहीं जाता:
```c
double price = 9.987;
printf("%.2f\n", price); // "9.99" प्रिंट करता है
printf("%.1f\n", price); // "10.0" प्रिंट करता है
```
`float` को भी `double` जैसे ही स्पेसिफायर से प्रिंट किया जाता है: `printf` को पास करते समय इसे अपने आप `double` में बदल दिया जाता है।
