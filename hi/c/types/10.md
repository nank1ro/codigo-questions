# --description--

`int` अकेला पूर्णांक टाइप नहीं है। मॉडिफायर इसका आकार और सीमा बदल देते हैं:
- `short` कम मेमोरी उपयोग करता है और इसकी सीमा छोटी होती है (आमतौर पर -32768 से 32767 तक)
- `long` की सीमा बड़ी होती है (64-बिट सिस्टम पर लगभग ±9 क्विंटिलियन)
- `unsigned` चिह्न हटा देता है: `unsigned int` की सीमा `0` से लगभग 4 अरब तक होती है, लेकिन यह कभी ऋणात्मक नहीं हो सकता

जिस लिटरल को `long` होना ज़रूरी है उसमें `L` सफ़िक्स लगाया जाता है, `unsigned` में `U` सफ़िक्स, और हर टाइप का अपना स्पेसिफायर होता है:
```c
long population = 8000000000L;
unsigned int count = 40U;
printf("%ld %u\n", population, count); // "8000000000 40" प्रिंट करता है
```
`%ld` एक `long` प्रिंट करता है, `%u` एक `unsigned int`, और `%lu` एक `unsigned long`। ज़्यादातर सिस्टम पर एक सामान्य `int` लगभग 2 अरब तक के मान रख सकता है, इसलिए `5000000000` उसमें फिट नहीं होता।

# --instructions--

# --answers--

- `long n = 5000000000L;`
- `int n = 5000000000;`
- `short n = 5000000000;`
- `unsigned int n = 5000000000U;`
