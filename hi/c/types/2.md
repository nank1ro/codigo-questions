# --description--

C में दो फ़्लोटिंग-पॉइंट टाइप होते हैं: `float` (सिंगल प्रिसिज़न, लगभग 7 सार्थक अंक) और `double` (डबल प्रिसिज़न, लगभग 15 सार्थक अंक)।
`1.75` जैसा दशमलव लिटरल `double` होता है; `float` लिटरल लिखने के लिए `1.75f` की तरह `f` सफ़िक्स जोड़ें।
जब तक मेमोरी की कमी न हो, `double` को प्राथमिकता दें: यह डिफ़ॉल्ट है और अधिक सटीक है।
```c
double pi = 3.14159;
float ratio = 0.5f;
```
जो फ़ंक्शन दशमलव परिणाम लौटाता है उसे रिटर्न टाइप के रूप में `double` घोषित करना चाहिए, और `double` पैरामीटर पूर्णांक और दशमलव दोनों तरह के आर्गुमेंट स्वीकार करते हैं:
```c
double half(double x) {
    return x / 2;
}
```
