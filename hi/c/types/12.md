# --description--

हर पूर्णांक टाइप की एक सीमित सीमा होती है, और `limits.h` हेडर उन सीमाओं को नाम देता है: `int` के लिए `INT_MAX` और `INT_MIN`, `long` के लिए `LONG_MAX`, `unsigned int` के लिए `UINT_MAX`, और इसी तरह अन्य।
```c
#include <limits.h>

printf("%d\n", INT_MAX); // ज़्यादातर सिस्टम पर "2147483647" प्रिंट करता है
```
साइन वाले टाइप में `INT_MAX` से आगे जाना **अपरिभाषित व्यवहार** है: प्रोग्राम रैप अराउंड कर सकता है, क्रैश हो सकता है, या कुछ भी और कर सकता है। गणना करने से पहले जाँच लें:
```c
if (a <= INT_MAX - b) { /* a + b सुरक्षित है */ }
```
ध्यान दें कि यह जाँच जोड़ने के बजाय घटाने का उपयोग करती है, क्योंकि `a + b` खुद पहले ही ओवरफ़्लो कर सकता है।

# --instructions--
