# --description--

साइन वाले टाइप के विपरीत, **बिना चिह्न का** अंकगणित सीमा से बाहर जाने पर भी अच्छी तरह परिभाषित होता है: मान एक ओडोमीटर की तरह **रैप अराउंड** करता है।
`UINT_MAX` में `1` जोड़ने पर `0` मिलता है, और `0` में से `1` घटाने पर `UINT_MAX` (जब `unsigned int` 32-बिट का हो तो `4294967295`) मिलता है:
```c
unsigned int n = UINT_MAX;
n = n + 1;
printf("%u\n", n); // "0" प्रिंट करता है
```
यही कारण है कि किसी `unsigned` वेरिएबल को "जब तक वह ऋणात्मक न हो जाए" गिनने वाला लूप कभी नहीं रुकता: एक बिना चिह्न वाला मान कभी `0` से कम नहीं होता।
