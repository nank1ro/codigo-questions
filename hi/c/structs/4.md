# --description--

`struct Point` हर बार लिखना लंबा काम है। `typedef` के साथ आप स्ट्रक्चर को एक छोटा प्रकार-नाम दे सकते हैं, और स्ट्रक्चर स्वयं बिना नाम का रह सकता है:
```c
typedef struct {
    double celsius;
} Temperature;

Temperature t = {21.5};
```
नया नाम `Temperature` अकेले उपयोग होता है, उसके आगे `struct` कीवर्ड के बिना। असली प्रोग्रामों में स्ट्रक्चर घोषित करने का यही सबसे आम तरीका है।

# --instructions--

कोड को पूरा करें ताकि सदस्य `celsius` वाले बिना नाम के स्ट्रक्चर को प्रकार-नाम `Temperature` के अंतर्गत परिभाषित किया जाए, फिर `t` को उसी प्रकार के साथ घोषित करें
