# --description--

एक **स्ट्रक्चर** (struct) अलग-अलग प्रकारों के संबंधित मानों को एक ही नए प्रकार में समूहित करता है। इसके अंदर के प्रत्येक मान को एक **सदस्य** (member) कहा जाता है।
घोषणा ब्रेसेज़ के बीच सदस्यों की सूची देती है और एक सेमीकोलन पर समाप्त होती है; यह `struct Point` प्रकार बनाती है लेकिन अभी कोई वेरिएबल नहीं:
```c
struct Point {
    int x;
    int y;
};
```
उस प्रकार का एक वेरिएबल `struct Point` के साथ घोषित किया जाता है, और इसके सदस्यों को ऐरे की तरह ब्रेसेज़ से **क्रम में** इनिशियलाइज़ किया जा सकता है:
```c
struct Point p = {3, 4}; // x is 3, y is 4
```
सदस्यों को **डॉट** ऑपरेटर `.` से पढ़ा और लिखा जाता है:
```c
printf("%d\n", p.x); // prints "3"
p.y = 10;
```

# --instructions--

कोड को पूरा करें ताकि `p` को एक `struct Point` के रूप में घोषित किया जाए जिसमें `x` `3` के बराबर और `y` `4` के बराबर हो, फिर दोनों सदस्यों को प्रिंट करें
