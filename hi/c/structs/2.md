# --description--

सदस्यों को क्रम में इनिशियलाइज़ करना नाज़ुक होता है: यदि स्ट्रक्चर में एक नया सदस्य जुड़ जाए, तो हर इनिशियलाइज़र खिसक जाता है। C99 से एक **डिज़िग्नेटेड इनिशियलाइज़र** (designated initialiser) हर सदस्य को डॉट के साथ नाम देता है, किसी भी क्रम में:
```c
struct Point p = {.y = 4, .x = 3};
```
जो सदस्य सूचीबद्ध नहीं होते उन्हें `0` सेट किया जाता है, इसलिए `{.y = 5}` से `x` `0` के बराबर हो जाता है। यह बिना किसी इनिशियलाइज़र के घोषित वेरिएबल, `struct Point q;`, से अलग है, जिसके सदस्य आपके असाइन करने तक **गार्बेज** मान रखते हैं:
```c
struct Point q;
q.x = 1;
q.y = 2;
```
