# --description--

स्ट्रक्चर को भी किसी अन्य प्रकार की तरह ऐरे में संग्रहीत किया जा सकता है। हर एलिमेंट अपने ब्रेसेज़ से इनिशियलाइज़ किया जाता है, और एक लूप उन्हें एक-एक करके देखता है, पहले इंडेक्स करके फिर डॉट का उपयोग करके:
```c
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};

for (int i = 0; i < 3; i++) {
    printf("%d\n", path[i].y);
}
```

# --instructions--

लाइनों को इस क्रम में लगाएँ ताकि `Point` प्रकार परिभाषित हो, तीन पॉइंट्स `path` में संग्रहीत हों, उनके `x` सदस्यों को जोड़कर `sum` में रखा जाए और उसे प्रिंट किया जाए। `path` को `sum` से पहले घोषित करें

```c
typedef struct { int x; int y; } Point;
Point path[3] = {{0, 0}, {2, 1}, {4, 3}};
int sum = 0;
for (int i = 0; i < 3; i++) {
    sum += path[i].x;
}
printf("%d\n", sum);
```
