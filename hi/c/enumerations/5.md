# --description--

एनम को `int` की तरह ही किसी फ़ंक्शन के पैरामीटर का प्रकार बनाया जा सकता है:
```c
int is_weekend(enum Day day) {
    return day == SAT || day == SUN;
}
```
फ़ंक्शन के अंदर, हर स्थिरांक को संभालने का स्वाभाविक तरीका `switch` है, क्योंकि एनम स्थिरांकों को सीधे `case` लेबल के रूप में इस्तेमाल किया जा सकता है:
```c
switch (day) {
    case SAT: return 1;
    case SUN: return 1;
    default: return 0;
}
```
