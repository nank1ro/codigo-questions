एक **एनम** (`enum`) संबंधित पूर्णांक स्थिरांकों के एक समूह को नाम देता है, ताकि आप एक साधारण संख्या के बजाय `RED` लिख सकें।
इसे `enum` कीवर्ड, एक नाम और ब्रेसेज़ के बीच स्थिरांकों की सूची के साथ घोषित किया जाता है:
```c
enum Color { RED, GREEN, BLUE };
```
हर स्थिरांक एक पूर्णांक होता है: जब तक आप अन्यथा न कहें, पहला स्थिरांक `0` होता है और उसके बाद हर अगला स्थिरांक पिछले वाले से एक अधिक होता है, इसलिए `RED` `0` है, `GREEN` `1` है और `BLUE` `2` है।
चूँकि ये पूर्णांक होते हैं, इन्हें `%d` से आउटपुट करते हैं:
```c
printf("%d\n", GREEN);
// prints "1"
```

---

आपके द्वारा सूचीबद्ध किए गए स्थिरांकों की संख्या के अनुसार क्रमांकन अपने आप जारी रहता है: चौथा स्थिरांक `3` है, पाँचवाँ `4` है, और इसी तरह आगे भी।
नाम आमतौर पर अन्य स्थिरांकों की तरह बड़े अक्षरों में लिखे जाते हैं, और पूरे प्रोग्राम में अद्वितीय होने चाहिए: दो एनम एक ही स्थिरांक नाम साझा नहीं कर सकते।

---

आप `=` का उपयोग करके किसी स्थिरांक को स्पष्ट मान भी दे सकते हैं; उसके बाद के स्थिरांक उसी मान से आगे गिनना जारी रखते हैं:
```c
enum Month { JAN = 1, FEB, MAR }; // FEB is 2, MAR is 3
```
स्पष्ट मानों का लगातार या बढ़ता हुआ होना ज़रूरी नहीं है: `enum Status { OK = 200, NOT_FOUND = 404 };` पूरी तरह मान्य है।

---

एनम एक प्रकार (type) भी है: आप `enum` के बाद एनम का नाम लिखकर उस प्रकार का वेरिएबल घोषित कर सकते हैं, और उसे इसके किसी एक स्थिरांक का मान दे सकते हैं:
```c
enum Color favorite = GREEN;
```
चूँकि स्थिरांक पूर्णांक होते हैं, आप एनम वेरिएबल की तुलना सामान्य ऑपरेटरों से करते हैं:
```c
if (favorite == GREEN) {
    printf("Green it is\n");
}
```

---

एनम को `int` की तरह ही किसी फ़ंक्शन के पैरामीटर का प्रकार बनाया जा सकता है:
```c
int is_weekend(enum Day day) {
    return day == SAT || day == SUN;
}
```
फ़ंक्शन के अंदर, हर स्थिरांक को संभालने का स्वाभाविक तरीका `switch` है, क्योंकि एनम स्थिरांकों को सीधे `case` लेबल के रूप में इस्तेमाल किया जा सकता है:
```c
switch (day) {
    case SAT: return 1;
    case SUN: return 1;
    default: return 0;
}
```

---

जब `switch` का हर केस एक स्थिरांक को संभालता है, तो हर केस के बाद `break` लगाना न भूलें, वरना निष्पादन अगले केस में गिर जाता है (fall through)।
यदि आप एनम के सभी स्थिरांकों को कवर करते हैं, तो `default` केस आवश्यक नहीं है।

---

एक फ़ंक्शन एनम भी लौटा सकता है; बस रिटर्न टाइप के रूप में एनम प्रकार का उपयोग करें और उसके किसी एक स्थिरांक को लौटाएँ:
```c
enum Grade grade_for(int score) {
    if (score >= 60) {
        return PASS;
    }
    return FAIL;
}
```
एक नामित स्थिरांक लौटाना, कॉलर के लिए साधारण `0` या `1` लौटाने की तुलना में कहीं अधिक स्पष्ट होता है।

---

हर बार `enum Color` लिखना काफी लंबा है। `typedef` की मदद से आप एनम को एक छोटा टाइप नाम दे सकते हैं, और एनम खुद अनाम (anonymous) रह सकता है:
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
नया नाम `Color` अकेले इस्तेमाल होता है, इसके आगे `enum` कीवर्ड नहीं लगाया जाता।

---

एक एनम स्थिरांक अपने आप `int` में बदल जाता है, इसलिए `int n = BLUE;` मान्य है और इसमें `2` संग्रहीत होगा।
दूसरी दिशा में जाने के लिए **कास्ट** का उपयोग किया जाता है, पूर्णांक से पहले कोष्ठकों में एनम प्रकार लिखकर:
```c
enum Color c = (enum Color)1; // c is GREEN
```
C यह जाँच नहीं करता कि संख्या किसी स्थिरांक से मेल खाती है या नहीं: `(enum Color)7` तब भी कंपाइल हो जाता है जब कोई भी स्थिरांक `7` न हो, इसलिए बदलने से पहले पूर्णांकों को सत्यापित करें।

---

एनम मान पर अंकगणित एक साधारण `int` उत्पन्न करता है: `GREEN + 1` `BLUE` नहीं बल्कि `2` है।
परिणाम को वापस किसी एनम वेरिएबल में संग्रहीत करने या किसी फ़ंक्शन से लौटाने के लिए, उसे एनम प्रकार में कास्ट करें:
```c
enum Color after_green = (enum Color)(GREEN + 1); // BLUE
```
शेषफल ऑपरेटर `%` के साथ मिलाकर, इससे आप स्थिरांकों में चक्रण (cycle) कर सकते हैं और पहले वाले पर वापस लौट सकते हैं।

---

एक आम तरकीब यह है कि एनम के अंत में एक अतिरिक्त स्थिरांक जोड़ दिया जाए, जिसे आमतौर पर `COUNT` नाम दिया जाता है: चूँकि क्रमांकन `0` से शुरू होता है, इसका मान ठीक उतना ही होता है जितने वास्तविक स्थिरांक उससे पहले हैं।
```c
enum Day { MON, TUE, WED, DAY_COUNT }; // DAY_COUNT is 3
```
यह सेंटिनल आपको संख्या को हार्डकोड किए बिना हर स्थिरांक पर लूप चलाने देता है, और जब आप उससे पहले नए स्थिरांक जोड़ते हैं तो भी यह सही बना रहता है:
```c
for (int d = MON; d < DAY_COUNT; d++) {
    printf("%d\n", d);
}
```

---

`COUNT` सेंटिनल हर स्थिरांक के लिए एक स्लॉट वाले ऐरे के आकार के लिए भी एकदम सही है, और स्थिरांक उसमें पढ़ने-योग्य इंडेक्स बन जाते हैं:
```c
enum Fruit { APPLE, BANANA, CHERRY, FRUIT_COUNT };

int stock[FRUIT_COUNT] = {10, 4, 7};
printf("%d\n", stock[BANANA]); // prints "4"
```
`0` से `FRUIT_COUNT` तक का लूप हर स्लॉट पर जाता है, और जब आपको इसे लौटाना हो तो लूप इंडेक्स को वापस `enum Fruit` में कास्ट किया जा सकता है।

---

C में enum स्थिरांक का नाम पाने का कोई अंतर्निहित तरीका नहीं है: `printf("%d\n", SUMMER)` `Summer` नहीं, बल्कि `2` छापता है। सामान्य समाधान एक छोटा फ़ंक्शन है जो `switch` की मदद से हर स्थिरांक के लिए संबंधित स्ट्रिंग लौटाता है।

---

एनम मानों को अन्य पूर्णांकों की तरह ऐरे में संग्रहीत किया जा सकता है: `enum Fruit basket[] = {APPLE, APPLE, CHERRY};` में तीन फल होते हैं, और हर एलिमेंट की तुलना किसी स्थिरांक से की जा सकती है।
