# --description--

C में enum स्थिरांक का नाम पाने का कोई अंतर्निहित तरीका नहीं है: `printf("%d\n", SUMMER)` `Summer` नहीं, बल्कि `2` छापता है। सामान्य समाधान एक छोटा फ़ंक्शन है जो `switch` की मदद से हर स्थिरांक के लिए संबंधित स्ट्रिंग लौटाता है।

# --instructions--

# --solutions--

```c
#include <stdio.h>
typedef enum { WINTER, SPRING, SUMMER, AUTUMN } Season;
char *season_name(Season season) {
    switch (season) {
        case WINTER: return "Winter";
        case SPRING: return "Spring";
        case SUMMER: return "Summer";
        default: return "Autumn";
    }
}
int main() {
    printf("%s\n", season_name(SUMMER));
    return 0;
}
```
