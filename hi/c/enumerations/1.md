# --description--

एक **एनम** (`enum`) संबंधित पूर्णांक स्थिरांकों के एक समूह को नाम देता है, ताकि आप एक साधारण संख्या के बजाय `RED` लिख सकें।
इसे `enum` कीवर्ड, एक नाम और ब्रेसेज़ के बीच स्थिरांकों की सूची के साथ घोषित किया जाता है:
```c
enum Color { RED, GREEN, BLUE };
```
हर स्थिरांक एक पूर्णांक होता है: जब तक आप अन्यथा न कहें, पहला स्थिरांक `0` होता है और उसके बाद हर अगला स्थिरांक पिछले वाले से एक अधिक होता है, इसलिए `RED` `0` है, `GREEN` `1` है और `BLUE` `2` है।
चूँकि ये पूर्णांक होते हैं, इन्हें `%d` से आउटपुट करते हैं:
```c
printf("%d\n", GREEN);
// prints "1"
```

# --instructions--

कोड को पूरा करें ताकि `RED`, `GREEN` और `BLUE` स्थिरांकों के साथ एनम `Color` घोषित हो, फिर `BLUE` का मान आउटपुट करें
