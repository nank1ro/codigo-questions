# --description--

एक आम तरकीब यह है कि एनम के अंत में एक अतिरिक्त स्थिरांक जोड़ दिया जाए, जिसे आमतौर पर `COUNT` नाम दिया जाता है: चूँकि क्रमांकन `0` से शुरू होता है, इसका मान ठीक उतना ही होता है जितने वास्तविक स्थिरांक उससे पहले हैं।
```c
enum Day { MON, TUE, WED, DAY_COUNT }; // DAY_COUNT is 3
```
यह सेंटिनल आपको संख्या को हार्डकोड किए बिना हर स्थिरांक पर लूप चलाने देता है, और जब आप उससे पहले नए स्थिरांक जोड़ते हैं तो भी यह सही बना रहता है:
```c
for (int d = MON; d < DAY_COUNT; d++) {
    printf("%d\n", d);
}
```
