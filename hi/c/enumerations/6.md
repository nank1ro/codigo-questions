# --description--

जब `switch` का हर केस एक स्थिरांक को संभालता है, तो हर केस के बाद `break` लगाना न भूलें, वरना निष्पादन अगले केस में गिर जाता है (fall through)।
यदि आप एनम के सभी स्थिरांकों को कवर करते हैं, तो `default` केस आवश्यक नहीं है।

# --instructions--

पंक्तियों को इस तरह क्रमबद्ध करें कि `enum Size` घोषित हो, `size` में `MEDIUM` संग्रहीत हो और `switch` से `Medium` आउटपुट हो। केस का क्रम घोषणा में स्थिरांकों के क्रम जैसा ही रखें

# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```
