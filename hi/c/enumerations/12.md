# --description--

`COUNT` सेंटिनल हर स्थिरांक के लिए एक स्लॉट वाले ऐरे के आकार के लिए भी एकदम सही है, और स्थिरांक उसमें पढ़ने-योग्य इंडेक्स बन जाते हैं:
```c
enum Fruit { APPLE, BANANA, CHERRY, FRUIT_COUNT };

int stock[FRUIT_COUNT] = {10, 4, 7};
printf("%d\n", stock[BANANA]); // prints "4"
```
`0` से `FRUIT_COUNT` तक का लूप हर स्लॉट पर जाता है, और जब आपको इसे लौटाना हो तो लूप इंडेक्स को वापस `enum Fruit` में कास्ट किया जा सकता है।

# --instructions--

`most_expensive` को पूरा करें ताकि यह `prices` (जिसमें हर फल के लिए एक कीमत है) में सबसे अधिक कीमत वाला फल लौटाए। यदि दो फलों की कीमत सबसे अधिक और बराबर है, तो पहले वाला फल लौटाएँ

# --solutions--

```c
enum Fruit { APPLE, BANANA, CHERRY, FRUIT_COUNT };

enum Fruit most_expensive(int prices[]) {
    int best = 0;
    for (int i = 1; i < FRUIT_COUNT; i++) {
        if (prices[i] > prices[best]) {
            best = i;
        }
    }
    return (enum Fruit)best;
}
```
