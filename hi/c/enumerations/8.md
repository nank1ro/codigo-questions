# --description--

हर बार `enum Color` लिखना काफी लंबा है। `typedef` की मदद से आप एनम को एक छोटा टाइप नाम दे सकते हैं, और एनम खुद अनाम (anonymous) रह सकता है:
```c
typedef enum { RED, GREEN, BLUE } Color;

Color favorite = BLUE;
```
नया नाम `Color` अकेले इस्तेमाल होता है, इसके आगे `enum` कीवर्ड नहीं लगाया जाता।
