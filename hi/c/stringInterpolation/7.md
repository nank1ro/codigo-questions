# --description--

एक बिंदु के बाद लिखी संख्या **परिशुद्धता** तय करती है। `%f` के लिए यह दशमलव स्थानों की संख्या है, जिसे पूर्णांकित किया जाता है; `%s` के लिए यह प्रिंट किए जाने वाले अधिकतम कैरेक्टरों की संख्या है:
```c
printf("%.2f\n", 3.14159);    // prints "3.14"
printf("%.3s\n", "formatting"); // prints "for"
```
चौड़ाई और परिशुद्धता को मिलाया जा सकता है: `%8.2f` दो दशमलव स्थानों को 8 स्तंभों में दाएँ संरेखित करके प्रिंट करता है।
