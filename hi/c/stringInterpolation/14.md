# --description--

जब फ़ॉर्मेट करने को कुछ न हो, तो `puts` एक स्ट्रिंग प्रिंट करके उसके बाद नई पंक्ति डालता है। `printf` के विपरीत यह `%` की व्याख्या नहीं करता, इसलिए टेक्स्ट ठीक वैसा ही प्रिंट होता है जैसा लिखा गया है:
```c
puts("Done");      // prints "Done" and a newline
puts("50% off");   // prints "50% off" and a newline
printf("50% off"); // undefined: % off is not a valid specifier
```
निश्चित टेक्स्ट के लिए `puts` सही विकल्प है, और जब मान डालने हों तब `printf`।
