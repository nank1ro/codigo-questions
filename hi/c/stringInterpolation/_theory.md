C में स्ट्रिंग इंटरपोलेशन नहीं है: टेक्स्ट और मानों को `printf` एक **फ़ॉर्मेट स्ट्रिंग** के ज़रिए जोड़ता है, जिसमें हर `%` स्पेसिफ़ायर की जगह उससे मेल खाता आर्ग्युमेंट रख दिया जाता है। सबसे आम स्पेसिफ़ायर ये हैं:
```c
printf("%d\n", 42);      // prints "42" (int, %i is the same)
printf("%f\n", 2.5);     // prints "2.500000" (double, 6 decimals by default)
printf("%s\n", "hi");    // prints "hi" (string)
printf("%c\n", 'A');     // prints "A" (single character)
printf("%x\n", 255);     // prints "ff" (int as lowercase hexadecimal)
printf("100%%\n");       // prints "100%" (a literal percent sign)
```
स्पेसिफ़ायर को आर्ग्युमेंट के प्रकार से मेल खाना चाहिए: `double` को `%d` से या `int` को `%s` से प्रिंट करने पर मान बदला नहीं जाता, बल्कि कचरा प्रिंट होता है या प्रोग्राम क्रैश हो जाता है।

---

`sprintf` बिल्कुल `printf` की तरह काम करता है, लेकिन स्क्रीन पर लिखने के बजाय यह फ़ॉर्मेट किया गया टेक्स्ट एक `char` ऐरे में लिखता है, जिसे **बफ़र** कहते हैं, और उसके बाद समाप्ति चिह्न `'\0'` जोड़ता है:
```c
char buffer[32];
sprintf(buffer, "%d-%d", 3, 7);
printf("%s\n", buffer); // prints "3-7"
```
बफ़र को कॉल से पहले घोषित करना ज़रूरी है और वह पूरे टेक्स्ट तथा समाप्ति चिह्न के लिए काफ़ी बड़ा होना चाहिए, वरना `sprintf` उसके अंत के आगे लिख देता है।

---

स्ट्रिंग बनाने वाला फ़ंक्शन आमतौर पर बफ़र को पैरामीटर के रूप में लेता है और उसे `sprintf` से भरता है। ऐरे कॉल करने वाले का होता है, और कॉल के बाद वह परिणाम पढ़ सकता है:
```c
void greet(char *out, char *name) {
    sprintf(out, "Hello, %s!", name);
}

char message[32];
greet(message, "Ada");
printf("%s\n", message); // prints "Hello, Ada!"
```
इन अभ्यासों में `string.h` आपके कोड के ऊपर पहले से शामिल है, इसलिए परिणाम की तुलना करने के लिए `strcmp` का उपयोग किया जा सकता है।

---

`%x` एक पूर्णांक को छोटे अक्षरों वाले हेक्साडेसिमल में प्रिंट करता है, और `%X` वही काम बड़े अक्षरों के साथ करता है। `%c` एक पूर्णांक कैरेक्टर कोड लेता है और उससे दर्शाया गया कैरेक्टर प्रिंट करता है, इसलिए `65` के साथ `%c` `A` प्रिंट करता है:
```c
printf("%x %X %c\n", 31, 31, 66); // prints "1f 1F B"
```

---

`%` और अक्षर के बीच की संख्या फ़ील्ड की न्यूनतम **चौड़ाई** तय करती है। मान को बाईं ओर स्पेस से भरा जाता है, और `%` के तुरंत बाद रखे गए **फ़्लैग** इस भराव को बदल देते हैं:
```c
printf("[%5d]\n", 42);  // prints "[   42]" right-aligned in 5 columns
printf("[%-5d]\n", 42); // prints "[42   ]" the - flag aligns to the left
printf("[%05d]\n", 42); // prints "[00042]" the 0 flag pads with zeros
printf("[%+d]\n", 42);  // prints "[+42]" the + flag always shows the sign
```
चौड़ाई से लंबा मान कभी काटा नहीं जाता, फ़ील्ड बस बड़ा हो जाता है।

---

चौड़ाई और फ़्लैग हर स्पेसिफ़ायर के साथ काम करते हैं, इसलिए `%02x` एक पूर्णांक को दो अंकों तक शून्य से भरे हेक्साडेसिमल के रूप में प्रिंट करता है। रंग `#rrggbb` के रूप में इसी तरह लिखे जाते हैं:
```c
printf("%02x\n", 5);   // prints "05"
printf("%02x\n", 255); // prints "ff"
```

---

एक बिंदु के बाद लिखी संख्या **परिशुद्धता** तय करती है। `%f` के लिए यह दशमलव स्थानों की संख्या है, जिसे पूर्णांकित किया जाता है; `%s` के लिए यह प्रिंट किए जाने वाले अधिकतम कैरेक्टरों की संख्या है:
```c
printf("%.2f\n", 3.14159);    // prints "3.14"
printf("%.3s\n", "formatting"); // prints "for"
```
चौड़ाई और परिशुद्धता को मिलाया जा सकता है: `%8.2f` दो दशमलव स्थानों को 8 स्तंभों में दाएँ संरेखित करके प्रिंट करता है।

---

किसी `double` का स्ट्रिंग में रूप नियंत्रित करने का सामान्य तरीका परिशुद्धता है। `0.425` जैसा अनुपात `100` से गुणा करके और एक दशमलव स्थान के बाद `%%` प्रिंट करके प्रतिशत बन जाता है:
```c
sprintf(out, "%.1f%%", 0.425 * 100); // out is "42.5%"
```

---

`sprintf` और `printf` लिखे गए कैरेक्टरों की संख्या **लौटाते** हैं, जिसमें समाप्ति चिह्न `'\0'` नहीं गिना जाता। यह अभी-अभी बनाई गई स्ट्रिंग की लंबाई है, बिना अलग से `strlen` कॉल किए:
```c
char buffer[32];
int length = sprintf(buffer, "%d-%d", 3, 7);
printf("%d\n", length); // prints "3"
```

---

`sprintf` को पता ही नहीं होता कि बफ़र कितना बड़ा है। `snprintf` बफ़र का आकार अपने दूसरे आर्ग्युमेंट के रूप में लेता है और कभी भी `size - 1` कैरेक्टरों तथा `'\0'` से अधिक नहीं लिखता, ज़रूरत पड़ने पर टेक्स्ट काट देता है। इसका लौटाया गया मान वह लंबाई है जो **पूरे** टेक्स्ट की होती, इसलिए `size` से बड़ा या बराबर परिणाम बताता है कि आउटपुट काटा गया था:
```c
char buffer[8];
int n = snprintf(buffer, sizeof buffer, "%s", "formatting");
printf("%s %d\n", buffer, n); // prints "formatt 10"
```
`sizeof buffer` ऐरे का आकार बाइट में देता है, जो `char` ऐरे के लिए उसके तत्वों की संख्या होती है।

---

`snprintf` के लौटाए मान की बफ़र आकार से तुलना करने पर पता चलता है कि सब कुछ समा गया या नहीं। अज्ञात लंबाई की स्ट्रिंग बनाने का यही सुरक्षित तरीका है:
```c
int n = snprintf(out, size, "%s", text);
if (n >= size) {
    // out holds only the first size - 1 characters of text
}
```

---

स्ट्रिंग को कई चरणों में भी बनाया जा सकता है, हर हिस्से को पिछले हिस्से के ठीक बाद लिखकर। लौटाया गया मान बताता है कि टेक्स्ट कहाँ समाप्त होता है, इसलिए `buffer + n` समाप्ति चिह्न का पता है और अगला `sprintf` वहीं से आगे लिख सकता है:
```c
char buffer[32];
int n = sprintf(buffer, "%s", "Hello");
n += sprintf(buffer + n, ", %s", "world"); // buffer is "Hello, world", n is 12
```
हर लौटाए मान को `n` में जोड़ते रहने से `n` अब तक बने टेक्स्ट की कुल लंबाई के बराबर बना रहता है।

---

स्ट्रिंग को फ़ॉर्मेट स्ट्रिंग के बिना भी जोड़ा जा सकता है। `string.h` का `strcat` अपने दूसरे आर्ग्युमेंट की एक प्रति पहले के अंत में जोड़ता है, जिसमें पर्याप्त खाली जगह होनी चाहिए, और `strncat` अधिकतम दी गई संख्या तक कैरेक्टर जोड़ता है:
```c
char text[32] = "Hi";
strcat(text, "!!!");        // text is "Hi!!!"
strncat(text, "abcdef", 2); // text is "Hi!!!ab"
```
दोनों जोड़े गए कैरेक्टरों के बाद हमेशा समाप्ति चिह्न `'\0'` लगाते हैं।

---

जब फ़ॉर्मेट करने को कुछ न हो, तो `puts` एक स्ट्रिंग प्रिंट करके उसके बाद नई पंक्ति डालता है। `printf` के विपरीत यह `%` की व्याख्या नहीं करता, इसलिए टेक्स्ट ठीक वैसा ही प्रिंट होता है जैसा लिखा गया है:
```c
puts("Done");      // prints "Done" and a newline
puts("50% off");   // prints "50% off" and a newline
printf("50% off"); // undefined: % off is not a valid specifier
```
निश्चित टेक्स्ट के लिए `puts` सही विकल्प है, और जब मान डालने हों तब `printf`।

---

`strncat` तब उपयोगी है जब किसी स्ट्रिंग का केवल एक हिस्सा जोड़ना हो, या जब जोड़े जाने वाले हिस्से को अधिकतम लंबाई तक सीमित रखना हो:
```c
char name[16] = "file";
strncat(name, ".backup", 3); // name is "file.ba"
```
जब सीमा स्ट्रिंग से बड़ी हो, तो पूरी स्ट्रिंग जोड़ दी जाती है।

---

सब कुछ मिलाकर: एक रिपोर्ट पंक्ति बाएँ संरेखित टेक्स्ट फ़ील्ड, एक विभाजक और निश्चित दशमलव स्थानों वाली दाएँ संरेखित संख्या को जोड़ती है, जिसे `snprintf` से लिखा जाता है ताकि बफ़र कभी न भरे:
```c
snprintf(out, size, "%-6s|%5.1f", "Ada", 9.5); // out is "Ada   |  9.5"
```
जब तक हर मान अपनी चौड़ाई में समाता है, सभी पंक्तियों की लंबाई एक जैसी रहती है, इसलिए पंक्तियों को एक के नीचे एक प्रिंट करने पर स्तंभ संरेखित रहते हैं।
