# --description--

`%x` एक पूर्णांक को छोटे अक्षरों वाले हेक्साडेसिमल में प्रिंट करता है, और `%X` वही काम बड़े अक्षरों के साथ करता है। `%c` एक पूर्णांक कैरेक्टर कोड लेता है और उससे दर्शाया गया कैरेक्टर प्रिंट करता है, इसलिए `65` के साथ `%c` `A` प्रिंट करता है:
```c
printf("%x %X %c\n", 31, 31, 66); // prints "1f 1F B"
```

# --instructions--

निम्नलिखित कोड का आउटपुट क्या है?
```c
printf("%x %X %c\n", 255, 255, 65);
```
