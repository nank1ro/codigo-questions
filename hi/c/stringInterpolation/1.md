# --description--

C में स्ट्रिंग इंटरपोलेशन नहीं है: टेक्स्ट और मानों को `printf` एक **फ़ॉर्मेट स्ट्रिंग** के ज़रिए जोड़ता है, जिसमें हर `%` स्पेसिफ़ायर की जगह उससे मेल खाता आर्ग्युमेंट रख दिया जाता है। सबसे आम स्पेसिफ़ायर ये हैं:
```c
printf("%d\n", 42);      // "42" प्रिंट करता है (int, %i भी वही है)
printf("%f\n", 2.5);     // "2.500000" प्रिंट करता है (double, डिफ़ॉल्ट रूप से 6 दशमलव स्थान)
printf("%s\n", "hi");    // "hi" प्रिंट करता है (स्ट्रिंग)
printf("%c\n", 'A');     // "A" प्रिंट करता है (एकल कैरेक्टर)
printf("%x\n", 255);     // "ff" प्रिंट करता है (int को छोटे अक्षरों वाले हेक्साडेसिमल के रूप में)
printf("100%%\n");       // "100%" प्रिंट करता है (एक लिटरल पर्सेंट चिह्न)
```
स्पेसिफ़ायर को आर्ग्युमेंट के प्रकार से मेल खाना चाहिए: `double` को `%d` से या `int` को `%s` से प्रिंट करने पर मान बदला नहीं जाता, बल्कि कचरा प्रिंट होता है या प्रोग्राम क्रैश हो जाता है।
