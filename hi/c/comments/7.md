# --description--

कंपाइलर हर टिप्पणी को एक सिंगल स्पेस से बदल देता है। इसका मतलब है कि `/* */` टिप्पणी वहीं कहीं भी आ सकती है जहाँ एक स्पेस आ सकता है, यहाँ तक कि किसी स्टेटमेंट या एक्सप्रेशन के बीच में भी:
```c
int area = width /* cm */ * height /* cm */;
```
यह कभी-कभी ऑपरेंड या कॉल के आर्गुमेंट को लेबल करने के लिए उपयोगी होता है। `//` टिप्पणी यह नहीं कर सकती, क्योंकि वह उसके बाद के कोड सहित पंक्ति के शेष भाग को कमेंट आउट कर देगी।
