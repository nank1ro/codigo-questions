# --description--

टिप्पणी (**comment**) आपके सोर्स कोड के अंदर मौजूद वह टेक्स्ट है जो कंपाइलर के लिए नहीं, बल्कि लोगों के लिए होती है। प्रोग्राम बनाने से पहले कंपाइलर टिप्पणियों को हटा देता है, इसलिए आप उनका उपयोग यह बताने के लिए कर सकते हैं कि कोड किस लिए है, रिमाइंडर छोड़ने के लिए या किसी निर्णय को नोट करने के लिए।

सबसे आम प्रकार **एकल-पंक्ति टिप्पणी** है: `//` से उस पंक्ति के अंत तक की हर चीज़ को नज़रअंदाज़ कर दिया जाता है।
```c
// Greet the user
printf("Hello\n");
```
प्रोग्राम चलने पर पहली पंक्ति कुछ नहीं करती; केवल `printf` ही आउटपुट देता है।
