# --description--

अच्छी टिप्पणी यह बताती है कि कोड कुछ **क्यों** करता है, न कि वह **क्या** करता है। कोड पहले से ही दिखा देता है कि क्या होता है; उसे शब्दों में दोहराना केवल शोर जोड़ता है और जैसे ही कोड बदलता है, वह पुरानी पड़ जाती है:
```c
// price को 90 से गुणा करें और 100 से भाग दें
return price * 90 / 100;
```
संख्याओं के पीछे का कारण ही वह चीज़ है जिसका अंदाज़ा कोई पाठक नहीं लगा सकता:
```c
// लॉन्च छूट: सदस्यों को जून के अंत तक 10% की छूट मिलती है
return price * 90 / 100;
```
यदि कोई टिप्पणी केवल अपने नीचे की पंक्ति को दोहराती है, तो उसे डिलीट कर दें या उसे कारण से बदल दें।
