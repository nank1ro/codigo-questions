# --description--

ब्लॉक टिप्पणियों का एक आम उपयोग **हेडर टिप्पणी** है: फ़ंक्शन के ठीक ऊपर रखा गया एक छोटा ब्लॉक, जो बताता है कि वह क्या करता है, उसके पैरामीटर का क्या अर्थ है और वह क्या लौटाता है।
```c
/*
 * Returns the number of seconds in the given minutes.
 * minutes: a whole number of minutes, never negative
 */
int to_seconds(int minutes) {
    return minutes * 60;
}
```
जो कोई भी `to_seconds` को कॉल करे, वह अब बॉडी की जगह हेडर पढ़ सकता है। हेडर को फ़ंक्शन के पास ही रखें ताकि दोनों को साथ-साथ अपडेट किया जा सके।

```c
#include <stdio.h>
/* Returns the larger of a and b */
int max_of(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
int main() {
    printf("%d\n", max_of(9, 4));
    return 0;
}
```
