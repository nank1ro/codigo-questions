# --description--

जब एक टिप्पणी को एक से अधिक पंक्तियों की आवश्यकता हो, तो C **बहु-पंक्ति टिप्पणी** (जिसे ब्लॉक टिप्पणी भी कहा जाता है) देता है: यह `/*` से शुरू होकर `*/` पर समाप्त होती है, और इनके बीच की हर चीज़, लाइन ब्रेक सहित, नज़रअंदाज़ कर दी जाती है।
```c
/*
  Prints the welcome banner.
  Called once when the program starts.
*/
printf("Welcome!\n");
```
ब्लॉक टिप्पणी छोटी भी हो सकती है और एक ही पंक्ति पर रह भी सकती है: `/* like this */`।

`//` के विपरीत, जो पंक्ति के अंत पर रुक जाता है, `/*` टिप्पणी केवल `*/` पर रुकती है। यदि आप उसे बंद करना भूल जाएँ, तो कंपाइलर उसके बाद के पूरे कोड को टिप्पणी का हिस्सा मान लेगा।
