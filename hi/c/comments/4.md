# --description--

ब्लॉक टिप्पणियाँ **नेस्ट नहीं होतीं**। कंपाइलर `/*` टिप्पणी को जिस पहले `*/` पर पाता है, उसी पर समाप्त कर देता है, चाहे उससे पहले कितने ही `/*` क्यों न आए हों:
```c
/* outer /* inner */ still code */
```
यहाँ टिप्पणी `inner` के ठीक बाद समाप्त हो जाती है, इसलिए `still code */` कोड के रूप में कंपाइल होता है और एक एरर उत्पन्न करता है।

यह तब मायने रखता है जब आप किसी ऐसे ब्लॉक को कमेंट आउट करना चाहते हों जिसके अंदर पहले से `/* */` टिप्पणी मौजूद है: अंदर वाली `*/` आपकी बाहरी टिप्पणी को बहुत जल्दी बंद कर देगी। ऐसे में, हर पंक्ति के आगे `//` लगा दें।

# --instructions--

जब यह कोड कंपाइल किया जाता है तो क्या होता है?
```c
/* start
   /* nested */
   printf("hidden\n");
*/
printf("done\n");
```

# --answers--

- एक कंपाइलेशन एरर: टिप्पणी पहले `*/` पर समाप्त हो जाती है, जिससे `printf` के बाद एक अनाथ `*/` रह जाता है
- यह `done` प्रिंट करता है
- यह `hidden` और `done` प्रिंट करता है
- यह कुछ नहीं प्रिंट करता, क्योंकि सब कुछ बाहरी टिप्पणी के अंदर है
