# --description--

`strcat(destination, source)`, `source` को `destination` के अंत में जोड़ देता है:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
`strcpy` की तरह ही, डेस्टिनेशन ऐरे में परिणाम के लिए पर्याप्त जगह होनी चाहिए।
