C में कोई समर्पित स्ट्रिंग टाइप नहीं है: एक **स्ट्रिंग** `char` की एक ऐरे होती है जो एक विशेष कैरेक्टर, **नल टर्मिनेटर** `'\0'` पर समाप्त होती है।
इसे बनाने का सबसे आसान तरीका डबल कोट्स के बीच एक स्ट्रिंग लिटरल है:
```c
char name[] = "Codigo";
```
कंपाइलर कैरेक्टर्स गिनकर अंत में `'\0'` अपने आप जोड़ देता है।
स्ट्रिंग प्रिंट करने के लिए `%s` प्लेसहोल्डर का उपयोग करें:
```c
printf("%s\n", name);
// prints "Codigo"
```

---

नल टर्मिनेटर मेमोरी में जगह लेता है: लिटरल `"hi"` 3 बाइट घेरता है, `'h'`, `'i'` और `'\0'`।
जब आप खुद साइज़ घोषित करते हैं, तो हमेशा इसके लिए जगह छोड़ें:
```c
char word[6] = "hello"; // 5 letters + '\0'
```
टर्मिनेटर के बिना, C के पास यह जानने का कोई तरीका नहीं है कि स्ट्रिंग कहाँ समाप्त होती है।

---

हेडर `string.h` स्ट्रिंग्स पर काम करने वाले फ़ंक्शन प्रदान करता है।
`strlen` नल टर्मिनेटर से पहले के कैरेक्टर्स की संख्या लौटाता है (टर्मिनेटर को खुद गिना नहीं जाता):
```c
strlen("hello"); // 5
```
जो फ़ंक्शन एक स्ट्रिंग प्राप्त करता है, वह पैरामीटर को `char *text` के रूप में घोषित करता है, यानी पहले कैरेक्टर की ओर इशारा करने वाला एक पॉइंटर।
इन अभ्यासों में `string.h` और `ctype.h` आपके कोड के ऊपर पहले से ही शामिल (include) हैं।

---

चूँकि एक स्ट्रिंग एक ऐरे है, इसलिए हर कैरेक्टर का एक इंडेक्स होता है जो `0` से शुरू होता है:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
एक अकेला कैरेक्टर `%c` से प्रिंट किया जाता है। कैरेक्टर्स को बदला भी जा सकता है:
```c
word[0] = 'K'; // word is now "Koding"
```

---

चूँकि हर स्ट्रिंग `'\0'` पर समाप्त होती है, इसलिए आप इसकी लंबाई पहले से जाने बिना भी इसमें से गुज़र सकते हैं: जब तक वर्तमान कैरेक्टर टर्मिनेटर न हो, तब तक जारी रखें।
```c
for (int i = 0; text[i] != '\0'; i++) {
    printf("%c\n", text[i]);
}
```

---

एक ऐरे को घोषणा के बाद `=` से असाइन नहीं किया जा सकता:
```c
char copy[20];
copy = "Codigo"; // error
```
स्ट्रिंग कॉपी करने के लिए `string.h` के `strcpy(destination, source)` का उपयोग करें।
डेस्टिनेशन इतना बड़ा होना चाहिए कि वह सभी कैरेक्टर्स और `'\0'` को समा सके।

---

`strcat(destination, source)`, `source` को `destination` के अंत में जोड़ देता है:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
`strcpy` की तरह ही, डेस्टिनेशन ऐरे में परिणाम के लिए पर्याप्त जगह होनी चाहिए।

---

दो स्ट्रिंग्स की तुलना `==` से नहीं की जा सकती: इससे उनके कैरेक्टर्स की नहीं, बल्कि मेमोरी में उनके एड्रेस की तुलना होगी।
इसके बजाय `strcmp(first, second)` का उपयोग करें, जो `0` लौटाता है जब दोनों स्ट्रिंग्स में बिल्कुल एक जैसे कैरेक्टर्स हों:
```c
strcmp("cat", "cat"); // 0
strcmp("cat", "dog"); // not 0
```

---

`strcmp` कैरेक्टर कोड्स का उपयोग करके स्ट्रिंग्स की तुलना कैरेक्टर दर कैरेक्टर करता है।
परिणाम निगेटिव होता है जब पहली स्ट्रिंग दूसरी से पहले आती है, पॉज़िटिव जब यह बाद में आती है, और `0` जब वे बराबर होती हैं:
```c
strcmp("a", "b"); // negative
strcmp("b", "a"); // positive
```

---

`strncpy(destination, source, n)` अधिकतम `n` कैरेक्टर्स कॉपी करता है।
अगर `source`, `n` से लंबा है, तो `'\0'` नहीं लिखा जाता: आपको खुद परिणाम को टर्मिनेट करना होगा।
```c
char prefix[10];
strncpy(prefix, "Codigo", 3);
prefix[3] = '\0'; // prefix is "Cod"
```

---

हेडर `ctype.h` एक अकेले कैरेक्टर पर काम करने वाले फ़ंक्शन प्रदान करता है।
`toupper(c)` किसी अक्षर का अपरकेस रूप लौटाता है और `tolower(c)` लोअरकेस रूप; कोई भी अन्य कैरेक्टर बिना बदलाव के लौटाया जाता है:
```c
char letter = toupper('a'); // 'A'
```

---

एक स्ट्रिंग किसी फ़ंक्शन को पॉइंटर के रूप में पास की जाती है, इसलिए `char *text` प्राप्त करने वाला फ़ंक्शन कॉलर के कैरेक्टर्स को उसी जगह बदल सकता है।
`'\0'` तक के लूप को `toupper` के साथ जोड़कर पूरी स्ट्रिंग को बदला जा सकता है:
```c
text[i] = toupper(text[i]);
```

---

`sprintf`, `printf` की तरह काम करता है, लेकिन फ़ॉर्मेटेड टेक्स्ट को स्क्रीन के बजाय एक `char` ऐरे में लिखता है:
```c
char buffer[30];
sprintf(buffer, "%d items", 3); // buffer is "3 items"
```
बफर इतना बड़ा होना चाहिए कि उसमें पूरा टेक्स्ट और उसका `'\0'` समा सके।

---

`sprintf` किसी संख्या को टेक्स्ट में बदलने का एक सुविधाजनक तरीका है: एक बार यह बफर में आ जाए, तो हर स्ट्रिंग फ़ंक्शन इस पर काम कर सकता है।
