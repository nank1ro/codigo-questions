# --description--

**रेगुलर एक्सप्रेशन** (regex) टेक्स्ट की एक आकृति बताने वाला एक छोटा पैटर्न होता है: "अंकों की एक शृंखला", "एक शब्द जिसके बाद एक बराबर चिह्न हो", "तीन बड़े अक्षर"। वर्णों पर लूप लिखने के बजाय, आप आकृति को एक बार बता देते हैं और Swift को उसे ढूँढने देते हैं।

Swift एक regex को `#/` और `/#` के बीच लिखता है:
```swift
let digits = #/\d+/#
```
पैटर्न के अंदर `\d` का अर्थ है "कोई भी अंक" और `+` का अर्थ है "पिछली चीज़ का एक या अधिक बार", इसलिए `\d+` का अर्थ है "एक या अधिक अंकों की शृंखला"।

सबसे सरल सवाल यह है कि क्या टेक्स्ट में कोई मैच मौजूद है। `contains(_:)` एक regex लेता है और एक `Bool` लौटाता है:
```swift
print("order42".contains(#/\d+/#)) // true
print("order".contains(#/\d+/#))   // false
```
हमेशा यहाँ दिखाए गए `#/ ... /#` रूप का ही उपयोग करें: `/ ... /` वाला छोटा रूप कंपाइलर को उलझा देता है जब पैटर्न सीधे किसी मेथड कॉल के अंदर लिखा जाता है।
