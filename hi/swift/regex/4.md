# --description--

जब कोई भी शॉर्टहैंड उपयुक्त न हो, तो अपने स्वीकार किए वर्णों को स्क्वायर ब्रैकेट के बीच सूचीबद्ध करें। `[abc]` एक `a`, एक `b` या एक `c` से मैच करता है, और एक डैश एक रेंज लिखता है:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
कर्ली ब्रैकेट में एक संख्या बताती है कि पिछला पैटर्न ठीक कितनी बार दोहराया जाता है: `{3}` का अर्थ है तीन बार, `{2,4}` का अर्थ है दो और चार के बीच:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
किसी पैटर्न को गिनती के साथ `^` और `$` में लपेटना यह जाँचने का सामान्य तरीका है कि पूरा टेक्स्ट दी गई आकृति का है।

# --instructions--

एक फ़ंक्शन `isCode` लिखें जो बिना आर्ग्युमेंट लेबल के एक टेक्स्ट (`String`) लेता है और एक regex का उपयोग करके केवल तब `true` लौटाता है जब पूरा टेक्स्ट ठीक तीन बड़े अक्षरों का हो

फ़ंक्शन कॉल का उदाहरण:
```swift
print(isCode("ABC"))
// prints true
```
