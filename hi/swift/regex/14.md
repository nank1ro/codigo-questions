# --description--

`^` और `$` से पूरे टेक्स्ट का सत्यापन करना काम करता है, लेकिन `wholeMatch(of:)` इसे सीधे कह देता है: यह केवल तब एक मैच लौटाता है जब पैटर्न टेक्स्ट को पहले वर्ण से आख़िरी वर्ण तक कवर करे, और अन्यथा `nil`:
```swift
print("1a2b".wholeMatch(of: #/[0-9a-f]+/#) != nil) // true
print("1z".wholeMatch(of: #/[0-9a-f]+/#) != nil)   // false
```
टेक्स्ट के अंदर कुछ ढूँढने के लिए `firstMatch(of:)` का उपयोग करें, और यह जाँचने के लिए कि टेक्स्ट की आकृति ठीक एक जैसी है, `wholeMatch(of:)` का।
