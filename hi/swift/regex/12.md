# --description--

`replacing(_:with:)` हर मैच को एक निश्चित टेक्स्ट से बदल देता है और एक नई `String` लौटाता है, मूल को अनछुआ छोड़कर:
```swift
let text = "a1 b22"
print(text.replacing(#/\d+/#, with: "#")) // a# b#
print(text)                               // a1 b22
```
ध्यान दें कि `\d+` अंकों की पूरी शृंखला को एक अकेले `#` से बदलता है, जबकि `\d` एक बार में एक अंक बदलता। यह पैटर्न तय करता है कि कितना हिस्सा गायब होगा।

# --instructions--

एक फ़ंक्शन `mask` लिखें जो बिना आर्ग्युमेंट लेबल के एक टेक्स्ट (`String`) लेता है और उसमें हर एकल अंक को एक `#` से बदलकर लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(mask("a1 b22"))
// prints a# b##
```
