# --description--

चूँकि `Int(_:)` एक `Substring` स्वीकार करता है, मिले हुए टेक्स्ट को संख्याओं में बदलना एक ही कदम का काम है। `compactMap` यहाँ उपयोगी है: यह उन मानों को हटा देता है जो `nil` लौटाते हैं:
```swift
let text = "a1 b22"
let numbers = text.matches(of: #/\d+/#).compactMap { Int($0.0) }
print(numbers) // [1, 22]
```
`map` का उपयोग करें जब हर एलिमेंट बदल जाए, `compactMap` जब कुछ असफल हो सकते हों।

# --instructions--

फ़ंक्शन कॉल का उदाहरण:
```swift

// [1, 22, 333] प्रिंट करता है
```
