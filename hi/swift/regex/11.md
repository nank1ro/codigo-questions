# --description--

पैटर्न के बड़ा होते ही ब्रैकेट गिनना नाज़ुक हो जाता है। इसके बजाय ग्रुप को एक **नाम** दें, उसके ओपनिंग ब्रैकेट के ठीक बाद `?<name>` लिखकर, और उसे मैच की प्रॉपर्टी की तरह पढ़ें:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
नाम वाले ग्रुप अब भी क्रमांकित रहते हैं, इसलिए `m.1` काम करता रहता है, लेकिन `m.key` बताता है कि उसमें क्या है और पैटर्न में बदलाव के बाद भी बना रहता है।
