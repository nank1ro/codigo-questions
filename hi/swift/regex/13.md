# --description--

`split(separator:)` एक regex भी स्वीकार करता है, जिससे एक ही कॉल उन सेपरेटर को संभाल सकता है जो हमेशा एक जैसे लिखे नहीं जाते:
```swift
let line = "a, b;c"
let parts = line.split(separator: #/[,;]\s*/#)
print(parts.joined(separator: "|")) // a|b|c
```
पैटर्न `[,;]\s*` का अर्थ है "एक कॉमा या एक सेमीकोलन, जिसके बाद कितनी भी स्पेसिंग हो", इसलिए हर सेपरेटर पूरी तरह निगल लिया जाता है और कोई खाली फ़ील्ड नहीं बनता। परिणाम `Substring` की एक ऐरे होता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```swift
let line = "one,two;  three"
print(line.split(separator: #/[,;]\s*/#).joined(separator: "|"))
```

# --answers--

- `one|two|three`
- `one|two|  three`
- `one|two;  three`
- `one,two;  three`
