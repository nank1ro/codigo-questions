# --description--

एक पैटर्न में कई ग्रुप हो सकते हैं। उन्हें उनके ओपनिंग ब्रैकेट के आधार पर बाएँ से दाएँ क्रमांकित किया जाता है, इसलिए दूसरा `m.2` है, तीसरा `m.3`, और आगे इसी तरह:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` हमेशा पूरा मैच ही रहता है, चाहे ग्रुप कितने भी हों।

# --instructions--

एक फ़ंक्शन `setting` लिखें जो बिना आर्ग्युमेंट लेबल के एक टेक्स्ट (`String`) लेता है, छोटे अक्षरों, एक `=` चिह्न और अंकों के रूप में लिखी गई सेटिंग ढूँढता है, और नाम तथा मान को कोलन से जोड़कर लौटाता है, या `"none"` जब टेक्स्ट में ऐसी कोई सेटिंग न हो

फ़ंक्शन कॉल का उदाहरण:
```swift
print(setting("size=10"))
// prints size:10
```

```swift

```

```swift

```

`setting("a=1 b=2")` को `"a:1"` लौटाना चाहिए

```swift

```

`setting("nothing here")` को `"none"` लौटाना चाहिए


# --solutions--

```swift
func setting(_ text: String) -> String {
    if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
        return "\(m.1):\(m.2)"
    }
    return "none"
}
```
