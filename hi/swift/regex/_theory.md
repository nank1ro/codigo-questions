**रेगुलर एक्सप्रेशन** (regex) टेक्स्ट की एक आकृति बताने वाला एक छोटा पैटर्न होता है: "अंकों की एक शृंखला", "एक शब्द जिसके बाद एक बराबर चिह्न हो", "तीन बड़े अक्षर"। वर्णों पर लूप लिखने के बजाय, आप आकृति को एक बार बता देते हैं और Swift को उसे ढूँढने देते हैं।

Swift एक regex को `#/` और `/#` के बीच लिखता है:
```swift
let digits = #/\d+/#
```
पैटर्न के अंदर `\d` का अर्थ है "कोई भी अंक" और `+` का अर्थ है "पिछली चीज़ का एक या अधिक बार", इसलिए `\d+` का अर्थ है "एक या अधिक अंकों की शृंखला"।

सबसे सरल सवाल यह है कि क्या टेक्स्ट में कोई मैच मौजूद है। `contains(_:)` एक regex लेता है और एक `Bool` लौटाता है:
```swift
print("order42".contains(#/\d+/#)) // true
print("order".contains(#/\d+/#))   // false
```
हमेशा यहाँ दिखाए गए `#/ ... /#` रूप का ही उपयोग करें: `/ ... /` वाला छोटा रूप कंपाइलर को उलझा देता है जब पैटर्न सीधे किसी मेथड कॉल के अंदर लिखा जाता है।

---

कुछ शॉर्टहैंड ज़्यादातर पैटर्न को कवर कर लेते हैं। हर एक ठीक **एक** वर्ण से मैच करता है:
- `\d` एक अंक है
- `\w` एक अक्षर, अंक या अंडरस्कोर है
- `\s` एक स्पेस, टैब या न्यूलाइन है
- `.` कोई भी एकल वर्ण है

एक से अधिक वर्णों से मैच करने के लिए, पैटर्न के ठीक बाद एक **क्वांटिफ़ायर** जोड़ें:
- `+` का अर्थ है एक या अधिक
- `*` का अर्थ है शून्य या अधिक
- `?` का अर्थ है शून्य या एक

इसलिए `\w+` एक शब्द है, `\s*` वैकल्पिक स्पेसिंग है, और `\d?` एक वैकल्पिक अंक है:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
बिना किसी विशेष अर्थ वाला वर्ण बस अपने आप से मैच करता है, इसलिए `#/cat/#` तीन अक्षरों `cat` से मैच करता है।

---

डिफ़ॉल्ट रूप से एक पैटर्न टेक्स्ट के अंदर कहीं भी मैच कर सकता है। **एंकर** इसके बजाय इसे एक स्थिति से बाँध देते हैं:
- `^` का अर्थ है "टेक्स्ट की शुरुआत"
- `$` का अर्थ है "टेक्स्ट का अंत"

```swift
print("swift".contains(#/^sw/#))  // true, टेक्स्ट sw से शुरू होता है
print("myswift".contains(#/^sw/#)) // false, sw शुरुआत में नहीं है
print("swift".contains(#/ft$/#))  // true, टेक्स्ट ft के साथ समाप्त होता है
```
एंकर किसी वर्ण से नहीं, एक स्थिति से मैच करते हैं, इसलिए वे मैच की सामग्री में कुछ भी जोड़ते नहीं।

---

जब कोई भी शॉर्टहैंड उपयुक्त न हो, तो अपने स्वीकार किए वर्णों को स्क्वायर ब्रैकेट के बीच सूचीबद्ध करें। `[abc]` एक `a`, एक `b` या एक `c` से मैच करता है, और एक डैश एक रेंज लिखता है:
```swift
print("f".contains(#/[a-f]/#))  // true
print("Z".contains(#/[A-Z]/#))  // true
print("5".contains(#/[0-9a-f]/#)) // true
```
कर्ली ब्रैकेट में एक संख्या बताती है कि पिछला पैटर्न ठीक कितनी बार दोहराया जाता है: `{3}` का अर्थ है तीन बार, `{2,4}` का अर्थ है दो और चार के बीच:
```swift
print("aaa".contains(#/^a{3}$/#))  // true
print("aa".contains(#/^a{3}$/#))   // false
```
किसी पैटर्न को गिनती के साथ `^` और `$` में लपेटना यह जाँचने का सामान्य तरीका है कि पूरा टेक्स्ट दी गई आकृति का है।

---

`contains(_:)` केवल हाँ या नहीं बताता है। मैच हुआ टेक्स्ट पाने के लिए `firstMatch(of:)` का उपयोग करें। यह एक **ऑप्शनल मैच** लौटाता है: कुछ मैच न होने पर `nil`, इसलिए यह `if let` के साथ सहज रूप से जुड़ता है।

मैच हुआ टेक्स्ट मैच की प्रॉपर्टी `0` में संग्रहीत होता है, जिसे `m.0` लिखा जाता है:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)` पहले मैच पर रुक जाता है, भले ही टेक्स्ट में और अधिक हों।

---

`m.0` एक `String` नहीं बल्कि एक `Substring` है: मूल टेक्स्ट में एक दृश्य, कोई प्रतिलिपि नहीं। यह बिल्कुल स्ट्रिंग की तरह प्रिंट होता है, लेकिन जहाँ एक `String` आवश्यक हो, वहाँ आपको इसे बदलना पड़ता है:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
संख्या इनिशियलाइज़र सीधे एक `Substring` स्वीकार करते हैं, इसलिए `Int(m.0)` बिना घुमाव के काम करता है।

---

`matches(of:)` पहले एक के बजाय **हर** मैच को एक ऐरे के रूप में लौटाता है। ऐरे कभी `nil` नहीं होता: कुछ मैच न होने पर वह बस खाली होता है, इसलिए उस पर सीधे लूप चलाया जा सकता है या उसे बदला जा सकता है:
```swift
let text = "a1 b22"
print(text.matches(of: #/\d+/#).count) // 2
```
हर एलिमेंट एक मैच है, इसलिए `map` के अंदर `$0.0` मैच हुआ टेक्स्ट है:
```swift
let found = text.matches(of: #/\d+/#).map { String($0.0) }
print(found) // ["1", "22"]
```

---

चूँकि `Int(_:)` एक `Substring` स्वीकार करता है, मिले हुए टेक्स्ट को संख्याओं में बदलना एक ही कदम का काम है। `compactMap` यहाँ उपयोगी है: यह उन मानों को हटा देता है जो `nil` लौटाते हैं:
```swift
let text = "a1 b22"
let numbers = text.matches(of: #/\d+/#).compactMap { Int($0.0) }
print(numbers) // [1, 22]
```
`map` का उपयोग करें जब हर एलिमेंट बदल जाए, `compactMap` जब कुछ असफल हो सकते हों।

---

पैटर्न के एक हिस्से के चारों ओर गोल ब्रैकेट एक **कैप्चर ग्रुप** बनाते हैं: पूरा मैच अब भी `m.0` रहता है, और ब्रैकेट के अंदर का हिस्सा `m.1` बन जाता है:
```swift
let text = "id-42"
if let m = text.firstMatch(of: #/id-(\d+)/#) {
    print(m.0) // id-42
    print(m.1) // 42
}
```
इसी तरह आप दिलचस्प हिस्से को रखते हैं और आस-पास का टेक्स्ट फेंक देते हैं। बिना ब्रैकेट के `m.1` बिल्कुल नहीं होता, और कोड कंपाइल नहीं होता।

---

एक पैटर्न में कई ग्रुप हो सकते हैं। उन्हें उनके ओपनिंग ब्रैकेट के आधार पर बाएँ से दाएँ क्रमांकित किया जाता है, इसलिए दूसरा `m.2` है, तीसरा `m.3`, और आगे इसी तरह:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/([a-z]+)=(\d+)/#) {
    print(m.1, m.2) // size 10
}
```
`m.0` हमेशा पूरा मैच ही रहता है, चाहे ग्रुप कितने भी हों।

---

पैटर्न के बड़ा होते ही ब्रैकेट गिनना नाज़ुक हो जाता है। इसके बजाय ग्रुप को एक **नाम** दें, उसके ओपनिंग ब्रैकेट के ठीक बाद `?<name>` लिखकर, और उसे मैच की प्रॉपर्टी की तरह पढ़ें:
```swift
let text = "size=10"
if let m = text.firstMatch(of: #/(?<key>[a-z]+)=(?<value>\d+)/#) {
    print(m.key)   // size
    print(m.value) // 10
}
```
नाम वाले ग्रुप अब भी क्रमांकित रहते हैं, इसलिए `m.1` काम करता रहता है, लेकिन `m.key` बताता है कि उसमें क्या है और पैटर्न में बदलाव के बाद भी बना रहता है।

---

`replacing(_:with:)` हर मैच को एक निश्चित टेक्स्ट से बदल देता है और एक नई `String` लौटाता है, मूल को अनछुआ छोड़कर:
```swift
let text = "a1 b22"
print(text.replacing(#/\d+/#, with: "#")) // a# b#
print(text)                               // a1 b22
```
ध्यान दें कि `\d+` अंकों की पूरी शृंखला को एक अकेले `#` से बदलता है, जबकि `\d` एक बार में एक अंक बदलता। यह पैटर्न तय करता है कि कितना हिस्सा गायब होगा।

---

`split(separator:)` एक regex भी स्वीकार करता है, जिससे एक ही कॉल उन सेपरेटर को संभाल सकता है जो हमेशा एक जैसे लिखे नहीं जाते:
```swift
let line = "a, b;c"
let parts = line.split(separator: #/[,;]\s*/#)
print(parts.joined(separator: "|")) // a|b|c
```
पैटर्न `[,;]\s*` का अर्थ है "एक कॉमा या एक सेमीकोलन, जिसके बाद कितनी भी स्पेसिंग हो", इसलिए हर सेपरेटर पूरी तरह निगल लिया जाता है और कोई खाली फ़ील्ड नहीं बनता। परिणाम `Substring` की एक ऐरे होता है।

---

`^` और `$` से पूरे टेक्स्ट का सत्यापन करना काम करता है, लेकिन `wholeMatch(of:)` इसे सीधे कह देता है: यह केवल तब एक मैच लौटाता है जब पैटर्न टेक्स्ट को पहले वर्ण से आख़िरी वर्ण तक कवर करे, और अन्यथा `nil`:
```swift
print("1a2b".wholeMatch(of: #/[0-9a-f]+/#) != nil) // true
print("1z".wholeMatch(of: #/[0-9a-f]+/#) != nil)   // false
```
टेक्स्ट के अंदर कुछ ढूँढने के लिए `firstMatch(of:)` का उपयोग करें, और यह जाँचने के लिए कि टेक्स्ट की आकृति ठीक एक जैसी है, `wholeMatch(of:)` का।

---

एक `#/ ... /#` लिटरल कंपाइल करते समय निश्चित होता है। जब पैटर्न केवल रन टाइम पर पता चलता है, उदाहरण के लिए क्योंकि किसी उपयोगकर्ता ने उसे टाइप किया हो, तो उसे `Regex(_:)` से बनाएँ:
```swift
let regex = try Regex("[0-9]+")
print("abc123".contains(regex)) // true
```
यह इनिशियलाइज़र **throws** करता है: `"["` जैसा कोई अमान्य पैटर्न केवल प्रोग्राम चलते समय पकड़ा जाता है, इसलिए कॉल को `try` की ज़रूरत है, और एरर को या तो `do`/`catch` (या `try?`) से संभाला जाना चाहिए या आस-पास के फ़ंक्शन को `throws` चिह्नित करके आगे बढ़ाया जाना चाहिए, जैसा यह अभ्यास करता है। इस तरह बनाए गए regex की कोई क्रमांकित प्रॉपर्टी कंपाइल टाइम पर ज्ञात नहीं होती, लेकिन `contains`, `matches(of:)` और `replacing` बिल्कुल पहले की तरह काम करते हैं।
