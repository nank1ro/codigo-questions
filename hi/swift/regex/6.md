# --description--

`m.0` एक `String` नहीं बल्कि एक `Substring` है: मूल टेक्स्ट में एक दृश्य, कोई प्रतिलिपि नहीं। यह बिल्कुल स्ट्रिंग की तरह प्रिंट होता है, लेकिन जहाँ एक `String` आवश्यक हो, वहाँ आपको इसे बदलना पड़ता है:
```swift
let text = "order 42"
if let m = text.firstMatch(of: #/\d+/#) {
    let found: String = String(m.0)
    print(found) // 42
}
```
संख्या इनिशियलाइज़र सीधे एक `Substring` स्वीकार करते हैं, इसलिए `Int(m.0)` बिना घुमाव के काम करता है।

# --instructions--

एक फ़ंक्शन `firstNumber` लिखें जो बिना आर्ग्युमेंट लेबल के एक टेक्स्ट (`String`) लेता है और पहली अंक-शृंखला को एक `String` के रूप में लौटाता है, या `"none"` जब टेक्स्ट में कोई अंक न हो

फ़ंक्शन कॉल का उदाहरण:
```swift
print(firstNumber("order 42 today 7"))
// prints 42
```

```swift
func firstNumber(_ text: String) -> String {
    if let m = text.firstMatch(of: #/\d+/#) {
        return String(m.0)
    }
    return "none"
}
```
