# --description--

`contains(_:)` केवल हाँ या नहीं बताता है। मैच हुआ टेक्स्ट पाने के लिए `firstMatch(of:)` का उपयोग करें। यह एक **ऑप्शनल मैच** लौटाता है: कुछ मैच न होने पर `nil`, इसलिए यह `if let` के साथ सहज रूप से जुड़ता है।

मैच हुआ टेक्स्ट मैच की प्रॉपर्टी `0` में संग्रहीत होता है, जिसे `m.0` लिखा जाता है:
```swift
let text = "order 42 today"
if let m = text.firstMatch(of: #/\d+/#) {
    print(m.0) // 42
}
```
`firstMatch(of:)` पहले मैच पर रुक जाता है, भले ही टेक्स्ट में और अधिक हों।
