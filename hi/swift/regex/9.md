# --description--

पैटर्न के एक हिस्से के चारों ओर गोल ब्रैकेट एक **कैप्चर ग्रुप** बनाते हैं: पूरा मैच अब भी `m.0` रहता है, और ब्रैकेट के अंदर का हिस्सा `m.1` बन जाता है:
```swift
let text = "id-42"
if let m = text.firstMatch(of: #/id-(\d+)/#) {
    print(m.0) // id-42
    print(m.1) // 42
}
```
इसी तरह आप दिलचस्प हिस्से को रखते हैं और आस-पास का टेक्स्ट फेंक देते हैं। बिना ब्रैकेट के `m.1` बिल्कुल नहीं होता, और कोड कंपाइल नहीं होता।

# --instructions--
