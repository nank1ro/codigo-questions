# --description--

कुछ शॉर्टहैंड ज़्यादातर पैटर्न को कवर कर लेते हैं। हर एक ठीक **एक** वर्ण से मैच करता है:
- `\d` एक अंक है
- `\w` एक अक्षर, अंक या अंडरस्कोर है
- `\s` एक स्पेस, टैब या न्यूलाइन है
- `.` कोई भी एकल वर्ण है

एक से अधिक वर्णों से मैच करने के लिए, पैटर्न के ठीक बाद एक **क्वांटिफ़ायर** जोड़ें:
- `+` का अर्थ है एक या अधिक
- `*` का अर्थ है शून्य या अधिक
- `?` का अर्थ है शून्य या एक

इसलिए `\w+` एक शब्द है, `\s*` वैकल्पिक स्पेसिंग है, और `\d?` एक वैकल्पिक अंक है:
```swift
print("hello world".contains(#/\w+\s\w+/#)) // true
print("hello".contains(#/\w+\s\w+/#))       // false
```
बिना किसी विशेष अर्थ वाला वर्ण बस अपने आप से मैच करता है, इसलिए `#/cat/#` तीन अक्षरों `cat` से मैच करता है।

```json

  "regex": "#/",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

```swift
tryCatch(hasDigit("abc1") == true)
```

`hasDigit("7")` को `true` लौटाना चाहिए

```swift
tryCatch(hasDigit("7") == true)
```

`hasDigit("abc")` को `false` लौटाना चाहिए

```swift
tryCatch(hasDigit("abc") == false)
```

`hasDigit("")` को `false` लौटाना चाहिए

```swift
tryCatch(hasDigit("") == false)
```
