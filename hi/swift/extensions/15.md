# --description--

एक्सटेंशन केवल मेंबर्स **जोड़** सकते हैं, कभी भी मौजूदा मेंबर्स को बदल या ओवरराइड नहीं कर सकते। `override` सबक्लासेस से संबंधित है, जो अपने पैरेंट से एक अलग टाइप होते हैं; एक एक्सटेंशन वही टाइप है, इसलिए कोई मेथड जो पहले से मौजूद है उसे घोषित करना एक रीडिक्लेरेशन एरर है:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
अगर आपको अलग व्यवहार चाहिए, तो एक नए नाम के साथ एक मेथड जोड़ें, या जब टाइप एक क्लास हो तो एक सबक्लास लिखें।

# --instructions--

जब यह प्रोग्राम कंपाइल और रन किया जाता है तो क्या होता है?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- यह कंपाइल नहीं होता, क्योंकि `speak()` एक ही टाइप के लिए दो बार घोषित है
- यह `Bark` प्रिंट करता है, क्योंकि एक्सटेंशन मूल मेथड को ओवरराइड करता है
- यह `Woof` प्रिंट करता है, क्योंकि मूल मेथड एक्सटेंशन पर भारी पड़ती है
- यह पहले `Woof` और फिर `Bark` प्रिंट करता है
