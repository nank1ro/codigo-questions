# --description--

एक म्यूटेटिंग मेथड किसी भी अन्य मेथड की तरह पैरामीटर्स ले सकती है, और उसे जगह पर अपडेट करने के बजाय `self` को पूरी तरह बदल सकती है:
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

# --instructions--

`Int` का एक एक्सटेंशन लिखें जिसमें एक म्यूटेटिंग मेथड `clamp(to max: Int)` हो जो संख्या को `max` से बदल दे जब संख्या `max` से बड़ी हो, और अन्यथा उसे अपरिवर्तित छोड़ दे

मेथड कॉल का उदाहरण:
```swift
var speed = 15
speed.clamp(to: 10)
print(speed)
// prints 10
```
