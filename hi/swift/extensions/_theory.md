एक **एक्सटेंशन** किसी मौजूदा टाइप में नई कार्यक्षमता जोड़ता है: `Int` या `String` जैसा एक स्टैंडर्ड लाइब्रेरी टाइप, या कोई स्ट्रक्ट या क्लास जिसे आपने खुद लिखा हो।
आप `extension` कीवर्ड लिखते हैं, उसके बाद टाइप का नाम, और कर्ली ब्रेसेस के बीच नए मेंबर्स रखते हैं:
```swift
extension Int {
    func squared() -> Int {
        return self * self
    }
}
print(4.squared()) // 16
```
एक्सटेंशन के अंदर, `self` वह मान है जिस पर मेथड कॉल की जाती है: `4.squared()` में वह `4` है। एक बार एक्सटेंशन मौजूद हो जाने पर, प्रोग्राम का हर `Int` नई मेथड रखता है, बिल्कुल ऐसे जैसे वह शुरू से ही `Int` का हिस्सा हो।

---

एक्सटेंशन किसी भी टाइप पर काम करते हैं, यहाँ तक कि उन पर भी जिनका सोर्स कोड आपके पास नहीं है। `String` स्टैंडर्ड लाइब्रेरी से आता है, फिर भी आप उसे नई मेथड्स दे सकते हैं:
```swift
extension String {
    func whisper() -> String {
        return self.lowercased() + "..."
    }
}
print("HELLO".whisper()) // hello...
```
एक्सटेंशन के अंदर टाइप के अन्य मेंबर्स को कॉल करते समय आप `self.` छोड़ सकते हैं: अकेला `lowercased()` का मतलब `self.lowercased()` है।

---

एक्सटेंशन कोई नया टाइप नहीं बनाता और न ही पुराने की कॉपी बनाता है: यह टाइप में ही मेंबर्स जोड़ता है, इसलिए उस टाइप का हर मौजूदा और भविष्य का मान उन्हें प्राप्त करता है।
इसीलिए एक्सटेंशन उन टाइप्स के साथ बहुत उपयोगी हैं जिन्हें आप एडिट नहीं कर सकते, जैसे स्टैंडर्ड लाइब्रेरी या किसी फ्रेमवर्क के टाइप्स: आप उस फ़ाइल को नहीं खोल सकते जहाँ `Int` परिभाषित है, लेकिन आप उसे अपने प्रोग्राम की किसी भी फ़ाइल से एक्सटेंड कर सकते हैं।
```swift
extension Int {
    func isDivisible(by other: Int) -> Bool {
        return self % other == 0
    }
}
let n = 12
print(n.isDivisible(by: 4)) // true
```

---

मेथड्स के अलावा, एक्सटेंशन **कंप्यूटेड प्रॉपर्टीज़** भी जोड़ सकता है: ऐसी प्रॉपर्टीज़ जो मान संग्रहीत नहीं करतीं बल्कि हर बार पढ़े जाने पर उसकी गणना करती हैं।
कंप्यूटेड प्रॉपर्टी को `var`, एक टाइप एनोटेशन और कर्ली ब्रेसेस के बीच एक बॉडी के साथ घोषित किया जाता है जो मान लौटाती है:
```swift
extension Int {
    var isNegative: Bool {
        return self < 0
    }
}
print((-3).isNegative) // true
print(7.isNegative)    // false
```
इसे किसी भी प्रॉपर्टी की तरह, बिना कोष्ठकों के पढ़ा जाता है: `7.isNegative`, न कि `7.isNegative()`।

---

एक्सटेंशन में कंप्यूटेड प्रॉपर्टीज़ `String` के लिए भी एक स्वाभाविक विकल्प हैं। `reversed()` मेथड कैरेक्टर्स को उलटे क्रम में लौटाती है, और `String(...)` उन्हें वापस एक स्ट्रिंग में बदल देता है:
```swift
extension String {
    var backwards: String {
        return String(reversed())
    }
}
print("swift".backwards) // tfiws
```
मेथड्स की तरह, एक्सटेंशन के अंदर `reversed()` का मतलब `self.reversed()` है।

---

एक्सटेंशन कंप्यूटेड प्रॉपर्टीज़ जोड़ सकता है लेकिन **स्टोर्ड प्रॉपर्टीज़** नहीं: यह कंपाइल नहीं होता:
```swift
extension Int {
    var label = "number" // error: extensions must not contain stored properties
}
```
एक स्टोर्ड प्रॉपर्टी को टाइप के हर इंस्टेंस के अंदर जगह की ज़रूरत होती है। `Int` मान पहले से ही आपके प्रोग्राम में हर जगह मौजूद हैं, और यहाँ तक कि उस कोड में भी जो आपके एक्सटेंशन से बहुत पहले कंपाइल हो चुका है, इसलिए उनकी मेमोरी लेआउट नहीं बदल सकती। एक कंप्यूटेड प्रॉपर्टी को कोई जगह नहीं चाहिए, क्योंकि वह केवल कोड है जो प्रॉपर्टी पढ़े जाने पर चलता है।

---

`Int`, `String`, ऐरे और स्ट्रक्ट्स **वैल्यू टाइप्स** हैं: कोई मेथड उस मान को नहीं बदल सकती जिस पर उसे कॉल किया जाता है, जब तक कि वह `mutating` से चिह्नित न हो। एक्सटेंशन म्यूटेटिंग मेथड्स भी जोड़ सकते हैं:
```swift
extension Int {
    mutating func increment() {
        self += 1
    }
}
var count = 1
count.increment()
print(count) // 2
```
एक म्यूटेटिंग मेथड के अंदर आप `self` को असाइन कर सकते हैं। मान को एक `var` में संग्रहीत होना चाहिए: किसी `let` कॉन्स्टेंट पर `increment()` कॉल करना एक कंपाइल एरर है।

---

एक म्यूटेटिंग मेथड किसी भी अन्य मेथड की तरह पैरामीटर्स ले सकती है, और उसे जगह पर अपडेट करने के बजाय `self` को पूरी तरह बदल सकती है:
```swift
extension Int {
    mutating func reset(to value: Int) {
        self = value
    }
}
var score = 42
score.reset(to: 0)
print(score) // 0
```

---

एक एक्सटेंशन किसी टाइप में नए **इनिशियलाइज़र** जोड़ सकता है। एक स्ट्रक्ट के लिए यह उन्हें रखने की सबसे अच्छी जगह है: स्ट्रक्ट बॉडी के अंदर लिखा गया एक `init` ऑटोमैटिक मेंबरवाइज़ इनिशियलाइज़र को बदल देता है, जबकि एक्सटेंशन में जोड़ा गया उसे बनाए रखता है।
नया इनिशियलाइज़र आम तौर पर `self.init(...)` के साथ किसी मौजूदा इनिशियलाइज़र को काम सौंपता है:
```swift
struct Size {
    var width: Double
    var height: Double
}
extension Size {
    init(square side: Double) {
        self.init(width: side, height: side)
    }
}
let a = Size(square: 3)          // from the extension
let b = Size(width: 2, height: 5) // memberwise, still available
```

---

एक्सटेंशन केवल दूसरों के टाइप्स के लिए नहीं हैं। अपना कोड व्यवस्थित करने का एक सामान्य तरीका है स्टोर्ड प्रॉपर्टीज़ को स्ट्रक्ट या क्लास बॉडी में रखना और व्यवहार को एक या अधिक एक्सटेंशन में जोड़ना, जिनमें से प्रत्येक संबंधित मेंबर्स को समूहित करता है:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
एक्सटेंशन में जोड़े गए मेंबर्स स्टोर्ड प्रॉपर्टीज़ का सीधे उपयोग कर सकते हैं, बिल्कुल ऐसे जैसे वे टाइप के अंदर लिखे गए हों।

---

एक एक्सटेंशन किसी टाइप को एक **प्रोटोकॉल** के अनुरूप भी बना सकता है, जो आवश्यकताओं की एक सूची है जिसे टाइप लागू करने का वादा करता है। प्रोटोकॉल का नाम टाइप के नाम के बाद, एक कोलन से अलग करके लिखें, और आवश्यक मेंबर्स को बॉडी में जोड़ें।
`CustomStringConvertible` एक स्टैंडर्ड प्रोटोकॉल है जिसकी एक ही आवश्यकता है, `String` टाइप की एक कंप्यूटेड प्रॉपर्टी `description`, जिसका उपयोग `print` मान दिखाने के लिए करता है:
```swift
struct Dog {
    var name: String
}
extension Dog: CustomStringConvertible {
    var description: String {
        return "Dog named \(name)"
    }
}
print(Dog(name: "Rex")) // Dog named Rex
```
हर प्रोटोकॉल अनुरूपता को अपने अलग एक्सटेंशन में रखना एक Swift टाइप को व्यवस्थित करने का सामान्य तरीका है।

---

`Array` एक जेनेरिक टाइप है: `[Int]` और `[String]` दोनों ऐरे हैं, जिनका **`Element`** टाइप अलग है। `Array` का एक एक्सटेंशन उन सभी पर लागू होता है, जो एक समस्या है जब नया मेंबर केवल कुछ एलिमेंट्स के लिए ही मायने रखता है: आप उन संख्याओं को नहीं जोड़ सकते जो स्ट्रिंग्स हैं।
एक `where` क्लॉज़ एक्सटेंशन को उन ऐरे तक सीमित कर देता है जिनका `Element` दिया गया टाइप है:
```swift
extension Array where Element == Int {
    var largest: Int {
        var result = Int.min
        for number in self {
            if number > result {
                result = number
            }
        }
        return result
    }
}
print([3, 9, 2].largest) // 9
```
`[3, 9, 2].largest` काम करता है, जबकि `["a", "b"].largest` एक कंपाइल एरर है: प्रॉपर्टी `[String]` पर मौजूद नहीं है।

---

एक्सटेंशन **स्टैटिक** मेंबर्स जोड़ सकते हैं: ऐसी प्रॉपर्टीज़ और मेथड्स जो किसी अकेले मान के बजाय टाइप स्वयं से संबंधित होती हैं, `static` कीवर्ड से चिह्नित होती हैं और टाइप के नाम के माध्यम से एक्सेस की जाती हैं।
एक `static let` अनुमत है भले ही वह एक मान संग्रहीत करता है, क्योंकि पूरे टाइप के लिए केवल एक कॉपी होती है, हर इंस्टेंस के लिए नहीं:
```swift
extension Int {
    static let answer = 42
    static func zeroes(_ count: Int) -> [Int] {
        return Array(repeating: 0, count: count)
    }
}
print(Int.answer)     // 42
print(Int.zeroes(3))  // [0, 0, 0]
```
एक स्टैटिक मेंबर के पास काम करने के लिए कोई `self` मान नहीं होता: `Int.answer` टाइप पर पढ़ा जाता है, किसी संख्या पर नहीं।

---

एक्सटेंशन में स्टैटिक मेथड्स छोटे फ़ैक्टरी फंक्शन्स के लिए एक अच्छी जगह हैं जो टाइप का एक मान बनाते हैं। `String(repeating:count:)` वह स्टैंडर्ड इनिशियलाइज़र है जो एक टेक्स्ट को एक संख्या की बार दोहराता है:
```swift
extension String {
    static func dashes(_ count: Int) -> String {
        return String(repeating: "-", count: count)
    }
}
print(String.dashes(4)) // ----
```

---

एक्सटेंशन केवल मेंबर्स **जोड़** सकते हैं, कभी भी मौजूदा मेंबर्स को बदल या ओवरराइड नहीं कर सकते। `override` सबक्लासेस से संबंधित है, जो अपने पैरेंट से एक अलग टाइप होते हैं; एक एक्सटेंशन वही टाइप है, इसलिए कोई मेथड जो पहले से मौजूद है उसे घोषित करना एक रीडिक्लेरेशन एरर है:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
अगर आपको अलग व्यवहार चाहिए, तो एक नए नाम के साथ एक मेथड जोड़ें, या जब टाइप एक क्लास हो तो एक सबक्लास लिखें।
