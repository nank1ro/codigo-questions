# --description--

एक्सटेंशन **स्टैटिक** मेंबर्स जोड़ सकते हैं: ऐसी प्रॉपर्टीज़ और मेथड्स जो किसी अकेले मान के बजाय टाइप स्वयं से संबंधित होती हैं, `static` कीवर्ड से चिह्नित होती हैं और टाइप के नाम के माध्यम से एक्सेस की जाती हैं।
एक `static let` अनुमत है भले ही वह एक मान संग्रहीत करता है, क्योंकि पूरे टाइप के लिए केवल एक कॉपी होती है, हर इंस्टेंस के लिए नहीं:
```swift
extension Int {
    static let answer = 42
    static func zeroes(_ count: Int) -> [Int] {
        return Array(repeating: 0, count: count)
    }
}
print(Int.answer)     // 42
print(Int.zeroes(3))  // [0, 0, 0]
```
एक स्टैटिक मेंबर के पास काम करने के लिए कोई `self` मान नहीं होता: `Int.answer` टाइप पर पढ़ा जाता है, किसी संख्या पर नहीं।
