# --description--

एक्सटेंशन किसी भी टाइप पर काम करते हैं, यहाँ तक कि उन पर भी जिनका सोर्स कोड आपके पास नहीं है। `String` स्टैंडर्ड लाइब्रेरी से आता है, फिर भी आप उसे नई मेथड्स दे सकते हैं:
```swift
extension String {
    func whisper() -> String {
        return self.lowercased() + "..."
    }
}
print("HELLO".whisper()) // hello...
```
एक्सटेंशन के अंदर टाइप के अन्य मेंबर्स को कॉल करते समय आप `self.` छोड़ सकते हैं: अकेला `lowercased()` का मतलब `self.lowercased()` है।

# --instructions--

`String` का एक एक्सटेंशन लिखें जिसमें मेथड `shout()` हो जो स्ट्रिंग को अपरकेस में लौटाती है, उसके बाद एक विस्मयादिबोधक चिह्न `!`

मेथड कॉल का उदाहरण:
```swift
print("hi".shout())
// prints HI!
```

# --asserts--

आपको `String` के एक एक्सटेंशन का उपयोग करना चाहिए

```json
{
  "regex": "extension\\s+String",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`"hi".shout()` को `"HI!"` लौटाना चाहिए

```swift
tryCatch("hi".shout() == "HI!")
```

`"Swift is fun".shout()` को `"SWIFT IS FUN!"` लौटाना चाहिए

```swift
tryCatch("Swift is fun".shout() == "SWIFT IS FUN!")
```

`"".shout()` को `"!"` लौटाना चाहिए

```swift
tryCatch("".shout() == "!")
```
