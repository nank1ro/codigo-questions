# --description--

एक्सटेंशन केवल दूसरों के टाइप्स के लिए नहीं हैं। अपना कोड व्यवस्थित करने का एक सामान्य तरीका है स्टोर्ड प्रॉपर्टीज़ को स्ट्रक्ट या क्लास बॉडी में रखना और व्यवहार को एक या अधिक एक्सटेंशन में जोड़ना, जिनमें से प्रत्येक संबंधित मेंबर्स को समूहित करता है:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
एक्सटेंशन में जोड़े गए मेंबर्स स्टोर्ड प्रॉपर्टीज़ का सीधे उपयोग कर सकते हैं, बिल्कुल ऐसे जैसे वे टाइप के अंदर लिखे गए हों।

# --instructions--

स्ट्रक्ट `Rectangle` दिया गया है। `Rectangle` का एक एक्सटेंशन लिखें जिसमें हों:
- `Double` टाइप की एक कंप्यूटेड प्रॉपर्टी `area`, जो `width` और `height` का गुणनफल है
- एक मेथड `scaled(by factor: Double)` जो एक नया `Rectangle` लौटाती है जिसकी दोनों भुजाएँ `factor` से गुणा होती हैं

एक `2` गुणा `3` आयत का क्षेत्रफल `6.0` होना चाहिए

```swift

```

एक `1.5` गुणा `4` आयत का क्षेत्रफल `6.0` होना चाहिए

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

एक `2` गुणा `3` आयत जो `2` से स्केल होती है, `4` गुणा `6` होनी चाहिए

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

स्केलिंग को मूल आयत को नहीं बदलना चाहिए

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
