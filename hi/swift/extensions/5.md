# --description--

एक्सटेंशन में कंप्यूटेड प्रॉपर्टीज़ `String` के लिए भी एक स्वाभाविक विकल्प हैं। `reversed()` मेथड कैरेक्टर्स को उलटे क्रम में लौटाती है, और `String(...)` उन्हें वापस एक स्ट्रिंग में बदल देता है:
```swift
extension String {
    var backwards: String {
        return String(reversed())
    }
}
print("swift".backwards) // tfiws
```
मेथड्स की तरह, एक्सटेंशन के अंदर `reversed()` का मतलब `self.reversed()` है।

# --instructions--

`String` का एक एक्सटेंशन लिखें जिसमें `Bool` टाइप की एक कंप्यूटेड प्रॉपर्टी `isPalindrome` हो, जो `true` हो जब स्ट्रिंग आगे और पीछे दोनों दिशाओं में एक जैसी पढ़ी जाए। तुलना केस-सेंसिटिव है

उपयोग का उदाहरण:
```swift
print("level".isPalindrome)
// prints true
```
