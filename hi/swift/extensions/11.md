# --description--

एक एक्सटेंशन किसी टाइप को एक **प्रोटोकॉल** के अनुरूप भी बना सकता है, जो आवश्यकताओं की एक सूची है जिसे टाइप लागू करने का वादा करता है। प्रोटोकॉल का नाम टाइप के नाम के बाद, एक कोलन से अलग करके लिखें, और आवश्यक मेंबर्स को बॉडी में जोड़ें।
`CustomStringConvertible` एक स्टैंडर्ड प्रोटोकॉल है जिसकी एक ही आवश्यकता है, `String` टाइप की एक कंप्यूटेड प्रॉपर्टी `description`, जिसका उपयोग `print` मान दिखाने के लिए करता है:
```swift
struct Dog {
    var name: String
}
extension Dog: CustomStringConvertible {
    var description: String {
        return "Dog named \(name)"
    }
}
print(Dog(name: "Rex")) // Dog named Rex
```
हर प्रोटोकॉल अनुरूपता को अपने अलग एक्सटेंशन में रखना एक Swift टाइप को व्यवस्थित करने का सामान्य तरीका है।
