# --description--

एक **एक्सटेंशन** किसी मौजूदा टाइप में नई कार्यक्षमता जोड़ता है: `Int` या `String` जैसा एक स्टैंडर्ड लाइब्रेरी टाइप, या कोई स्ट्रक्ट या क्लास जिसे आपने खुद लिखा हो।
आप `extension` कीवर्ड लिखते हैं, उसके बाद टाइप का नाम, और कर्ली ब्रेसेस के बीच नए मेंबर्स रखते हैं:
```swift
extension Int {
    func squared() -> Int {
        return self * self
    }
}
print(4.squared()) // 16
```
एक्सटेंशन के अंदर, `self` वह मान है जिस पर मेथड कॉल की जाती है: `4.squared()` में वह `4` है। एक बार एक्सटेंशन मौजूद हो जाने पर, प्रोग्राम का हर `Int` नई मेथड रखता है, बिल्कुल ऐसे जैसे वह शुरू से ही `Int` का हिस्सा हो।
