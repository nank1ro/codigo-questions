# --description--

एक्सटेंशन कोई नया टाइप नहीं बनाता और न ही पुराने की कॉपी बनाता है: यह टाइप में ही मेंबर्स जोड़ता है, इसलिए उस टाइप का हर मौजूदा और भविष्य का मान उन्हें प्राप्त करता है।
इसीलिए एक्सटेंशन उन टाइप्स के साथ बहुत उपयोगी हैं जिन्हें आप एडिट नहीं कर सकते, जैसे स्टैंडर्ड लाइब्रेरी या किसी फ्रेमवर्क के टाइप्स: आप उस फ़ाइल को नहीं खोल सकते जहाँ `Int` परिभाषित है, लेकिन आप उसे अपने प्रोग्राम की किसी भी फ़ाइल से एक्सटेंड कर सकते हैं।
```swift
extension Int {
    func isDivisible(by other: Int) -> Bool {
        return self % other == 0
    }
}
let n = 12
print(n.isDivisible(by: 4)) // true
```

# --instructions--

एक्सटेंशन के बारे में इनमें से कौन सा कथन सही है?

# --answers--

- आप `Int` में मेथड जोड़ सकते हैं भले ही आप उसका सोर्स कोड एडिट नहीं कर सकते
- एक्सटेंशन एक नया टाइप बनाता है जो मूल टाइप की कॉपी होता है
- एक्सटेंशन में जोड़ी गई मेथड को केवल उसी एक्सटेंशन के अंदर कॉल किया जा सकता है
- एक्सटेंशन उसी फ़ाइल में लिखा जाना चाहिए जहाँ टाइप परिभाषित है
