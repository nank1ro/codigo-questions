# --description--

डिफ़ॉल्ट इंप्लीमेंटेशन एक फॉलबैक है, कोई नियम नहीं। अगर अनुरूप बनने वाला टाइप किसी आवश्यकता का अपना वर्ज़न देता है, तो वही वर्ज़न चलता है:
```swift
protocol Priced {
    var price: Int { get }
}

extension Priced {
    var price: Int { return 0 }
}

struct Ticket: Priced {
    var price = 12
}

print(Ticket().price) // 12, न कि 0
```
डिफ़ॉल्ट केवल वही गैप भरता है जिन्हें टाइप खुला छोड़ देता है।

यह कोड क्या प्रिंट करता है?
```swift
protocol Greeter {
    func greet() -> String
}

extension Greeter {
    func greet() -> String {
        return "Hello"
    }
}

struct Pirate: Greeter {
    func greet() -> String {
        return "Ahoy"
    }
}

print(Pirate().greet())
```
