# --description--

अनुरूपता को टाइप के बगल में घोषित करना ज़रूरी नहीं है। एक **एक्सटेंशन** इसे बाद में जोड़ सकता है, जिससे टाइप की अपनी डिक्लेरेशन अपने डेटा पर केंद्रित रहती है:
```swift
protocol Resettable {
    mutating func reset()
}

struct Timer {
    var seconds = 0
}

extension Timer: Resettable {
    mutating func reset() {
        seconds = 0
    }
}
```
यह उन टाइप्स के लिए भी काम करता है जिन्हें आपने नहीं लिखा: आप किसी स्टैंडर्ड लाइब्रेरी टाइप को बिना उसके सोर्स को छुए अपने किसी प्रोटोकॉल के अनुरूप बना सकते हैं।
