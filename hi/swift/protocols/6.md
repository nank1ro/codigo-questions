# --description--

एक प्रोटोकॉल आमतौर पर एक से अधिक आवश्यकताएँ रखता है, और अनुरूप बनने वाले टाइप को उनमें से हर एक को पूरा करना होता है:
```swift
protocol Vehicle {
    var wheels: Int { get }
    func move() -> String
}

struct Bike: Vehicle {
    var wheels = 2

    func move() -> String {
        return "pedalling"
    }
}
```
ब्रेसेस के अंदर आवश्यकताओं का क्रम मायने नहीं रखता, और न ही उस क्रम का जिसमें अनुरूप बनने वाला टाइप उन्हें देता है: कंपाइलर केवल यह जाँचता है कि कुछ भी मिसिंग न हो।
