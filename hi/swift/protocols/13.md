# --description--

स्टैंडर्ड लाइब्रेरी प्रोटोकॉल्स से बनी है, और आपके अपने टाइप्स उन्हें अपना सकते हैं।

`Equatable` किसी टाइप को `==` ऑपरेटर देता है। उस स्ट्रक्चर के लिए जिसकी सभी स्टोर्ड प्रॉपर्टीज़ `Equatable` हैं, अनुरूपता घोषित करना ही काफी है — Swift आपके लिए `==` लिख देता है:
```swift
struct Point: Equatable {
    var x: Int
    var y: Int
}

print(Point(x: 1, y: 2) == Point(x: 1, y: 2)) // true
```
`Comparable` `Equatable` से इनहेरिट करता है और ऑर्डरिंग जोड़ता है। आप एक अकेला ऑपरेटर `<` इंप्लीमेंट करते हैं, जो दो मान लेने वाले `static func` के रूप में लिखा जाता है, और आपको `>`, `<=`, `>=`, साथ ही कलेक्शन्स पर `sorted()`, `min()` और `max()` मुफ़्त में मिल जाते हैं:
```swift
struct Version: Comparable {
    var number: Int

    static func < (lhs: Version, rhs: Version) -> Bool {
        return lhs.number < rhs.number
    }
}
```

