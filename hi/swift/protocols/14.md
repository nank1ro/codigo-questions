# --description--

`CustomStringConvertible` तय करता है कि `print` आपके टाइप के लिए क्या दिखाए। उसकी एक अकेली आवश्यकता एक `description` प्रॉपर्टी है:
```swift
struct Coin: CustomStringConvertible {
    var value: Int

    var description: String {
        return "\(value)c"
    }
}

print(Coin(value: 25)) // 25c
```
अनुरूपता के बिना, किसी स्ट्रक्चर को प्रिंट करने पर `Coin(value: 25)` जैसा एक डिफ़ॉल्ट डंप दिखता है, और अकेली `description` प्रॉपर्टी कुछ नहीं बदलती — `print` प्रोटोकॉल की तलाश करता है। स्ट्रिंग इंटरपोलेशन भी `description` का उपयोग करता है।
