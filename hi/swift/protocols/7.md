# --description--

एक स्ट्रक्चर एक वैल्यू टाइप होता है, इसलिए अपनी किसी स्टोर्ड प्रॉपर्टी को बदलने वाली मेथड को `mutating` के रूप में मार्क किया जाना चाहिए। जब वही मेथड किसी प्रोटोकॉल की आवश्यकता हो, तो प्रोटोकॉल को भी यह कहना होता है:
```swift
protocol Togglable {
    mutating func toggle()
}

struct Light: Togglable {
    var isOn = false

    mutating func toggle() {
        isOn = !isOn
    }
}

var lamp = Light()
lamp.toggle()
print(lamp.isOn) // true
```
प्रोटोकॉल में `mutating` के बिना, कोई स्ट्रक्चर कभी भी इस आवश्यकता को पूरा नहीं कर सकता। क्लासेस रेफरेंस टाइप्स होते हैं और उन्हें इस कीवर्ड की ज़रूरत कभी नहीं होती: कोई क्लास `mutating` आवश्यकता को एक साधारण मेथड से पूरा करता है। म्यूटेटिंग मेथड कॉल करने के लिए एक `var` चाहिए — `let` पर यह एक कंपाइल एरर है।

# --instructions--

`Score` को एक मेथड `reset()` के साथ `Resettable` के अनुरूप बनाएं जो `points` को `0` सेट करती है

उपयोग का उदाहरण:
```swift
var score = Score(points: 10)
score.reset()
print(score.points)
// prints 0
```

# --before-asserts--

```swift
func _reset<T: Resettable>(_ v: inout T) {
    v.reset()
}
```
