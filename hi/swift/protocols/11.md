# --description--

एक प्रोटोकॉल दूसरे पर बन सकता है। कोलन के बाद किसी प्रोटोकॉल का नाम लिखने से नया प्रोटोकॉल पुराने की हर आवश्यकता को **इनहेरिट** करता है:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
`Aged` के अनुरूप बनने वाले टाइप को `age` *और* `name` दोनों देने होते हैं, और वह हर जगह एक `Named` टाइप की तरह गिना जाता है। एक प्रोटोकॉल कई प्रोटोकॉल से एक साथ इनहेरिट कर सकता है, कोमा से अलग करके।

# --before-asserts--

```swift
extension Timed {
    func label() -> String {
        return "\(name) \(seconds)"
    }
}

func _name(_ n: Named) -> String {
    return n.name
}
```

# --asserts--

`90` सेकंड का `Intro` नाम का ट्रैक `Intro 90` लेबल होना चाहिए

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

`5` सेकंड का `Outro` नाम का ट्रैक `Outro 5` लेबल होना चाहिए

```swift

```

`0` सेकंड का `Gap` नाम का ट्रैक `Gap 0` लेबल होना चाहिए

```swift

```

एक `Timed` मान `Named` मान की तरह उपयोग करने योग्य होना चाहिए

