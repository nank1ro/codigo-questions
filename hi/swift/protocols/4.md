# --description--

प्रोटोकॉल केवल स्ट्रक्चर्स तक सीमित नहीं हैं। एक **क्लास** बिल्कुल उसी तरह अनुरूप बनता है, कोलन के बाद प्रोटोकॉल को सूचीबद्ध करके:
```swift
protocol Openable {
    func open() -> String
}

class Door: Openable {
    func open() -> String {
        return "creak"
    }
}
```
अगर क्लास किसी दूसरी क्लास से भी इनहेरिट करती है, तो सुपरक्लास सूची में पहले आता है और प्रोटोकॉल उसके बाद। एक टाइप कई प्रोटोकॉल एक साथ अपना सकता है, कोमा से अलग करके।

# --instructions--

क्लास `Box` को `Sized` के अनुरूप बनाएं, जो उसमें मौजूद आइटम्स की संख्या लौटाती है

उपयोग का उदाहरण:
```swift
print(Box(items: ["pen", "key"]).size())
// 2 प्रिंट करता है
```

# --solutions--

```swift
protocol Sized {
    func size() -> Int
}

class Box: Sized {
    var items: [String]

    init(items: [String]) {
        self.items = items
    }

    func size() -> Int {
        return items.count
    }
}
```
