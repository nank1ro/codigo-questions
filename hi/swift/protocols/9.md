# --description--

एक **प्रोटोकॉल** का एक्सटेंशन एक अलग टूल है: यह हर अनुरूप बनने वाले टाइप — मौजूदा और भविष्य के — में मेंबर्स जोड़ता है। किसी आवश्यकता को **डिफ़ॉल्ट इंप्लीमेंटेशन** देने का तरीका यही है:
```swift
protocol Greeter {
    var name: String { get }
    func greet() -> String
}

extension Greeter {
    func greet() -> String {
        return "Hi, \(name)"
    }
}

struct Person: Greeter {
    var name: String
}

print(Person(name: "Ada").greet()) // Hi, Ada
```
`Person` कभी `greet()` नहीं लिखता और फिर भी अनुरूप बना रहता है। प्रोटोकॉल एक्सटेंशन के अंदर आप प्रोटोकॉल की हर आवश्यकता का उपयोग कर सकते हैं — यहाँ `name` — क्योंकि अनुरूप बनने वाले किसी भी टाइप में उसके होने की गारंटी होती है।

# --instructions--

`Basket` का एक एक्सटेंशन जोड़ें जो `summary()` को एक डिफ़ॉल्ट इंप्लीमेंटेशन दे जो आइटम्स की संख्या के बाद ` items` लौटाती है, ताकि `Fruits` मेथड लिखे बिना अनुरूप बन जाए

उपयोग का उदाहरण:
```swift
print(Fruits(items: ["fig", "plum"]).summary())
// prints 2 items
```
