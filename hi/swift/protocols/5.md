# --description--

एक **एनम** भी अनुरूप बन सकता है। उसके पास कोई स्टोर्ड प्रॉपर्टीज़ नहीं होतीं, इसलिए प्रॉपर्टी आवश्यकता आमतौर पर एक कंप्यूटेड प्रॉपर्टी से पूरी की जाती है जो केसेस पर स्विच करती है:
```swift
protocol Priced {
    var price: Int { get }
}

enum Ticket: Priced {
    case child, adult

    var price: Int {
        switch self {
        case .child: return 5
        case .adult: return 12
        }
    }
}

print(Ticket.adult.price) // 12
```
स्ट्रक्चर्स, क्लासेस और एनम: ये तीनों प्रोटोकॉल को एक ही तरह से अपनाते हैं, और प्रोटोकॉल के आधार पर लिखा गया कोड तीनों के साथ काम करता है।
