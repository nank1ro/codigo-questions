# --description--

अकेला प्रोटोकॉल नाम एक टाइप नहीं है, वह एक कॉन्स्ट्रेंट है, इसलिए Swift आपसे कहता है कि आप दो चीज़ों में से किसका मतलब रखते हैं।

`some Shape` का मतलब है *एक विशिष्ट अनुरूप टाइप*, जो कंपाइल टाइम पर तय होता है। कॉलर को कभी पता नहीं चलता कि कौन सा, लेकिन वह हमेशा एक ही होता है:
```swift
func unitSquare() -> some Shape {
    return Square(side: 1)
}
```
`any Shape` का मतलब है *एक बॉक्स जो कोई भी अनुरूप टाइप रख सकता है*, और उस टाइप के दो मान अलग-अलग टाइप्स रख सकते हैं। इसकी ज़रूरत तब होती है जब कंक्रीट टाइप बदल सकता हो, जैसे एक मिक्स्ड ऐरे के अंदर:
```swift
let shapes: [any Shape] = [Square(side: 2), Rect(width: 2, height: 3)]
```
दोनों आपको प्रोटोकॉल की आवश्यकताओं को कॉल करने देते हैं। जब एक अकेला टाइप काफी हो तो `some` को प्राथमिकता दें, क्योंकि उसकी रन टाइम पर कोई लागत नहीं होती; `any` का उपयोग तब करें जब आपको सचमुच टाइप्स मिलाने की ज़रूरत हो।

# --solutions--

```swift
protocol Shape {
    func area() -> Int
}

struct Square: Shape {
    var side: Int

    func area() -> Int {
        return side * side
    }
}

struct Rect: Shape {
    var width: Int
    var height: Int

    func area() -> Int {
        return width * height
    }
}

func unitSquare() -> some Shape {
    return Square(side: 1)
}

func totalArea(_ shapes: [any Shape]) -> Int {
    var total = 0
    for shape in shapes {
        total += shape.area()
    }
    return total
}
```
