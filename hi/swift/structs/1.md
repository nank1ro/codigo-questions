# --description--

एक **स्ट्रक्चर** (*structure* का संक्षिप्त रूप) एक ऐसा टाइप है जिसे आप स्वयं डिज़ाइन करते हैं ताकि संबंधित मानों को एक साथ रखा जा सके। अलग-अलग `title` और अलग `pages` को संभालने के बजाय, आप एक बार `Book` का वर्णन करते हैं और फिर उसे हर जगह उपयोग करते हैं।

आप इसे `struct` कीवर्ड से घोषित करते हैं, और इसके अंदर लिखे गए वेरिएबल इसकी **स्टोर्ड प्रॉपर्टीज़** कहलाते हैं:
```swift
struct Book {
    var title: String
    var pages: Int
}
```
`Book` अब एक टाइप है, बिल्कुल `Int` या `String` की तरह। आप डॉट लगाकर किसी इंस्टेंस की प्रॉपर्टी तक पहुँचते हैं:
```swift
let book = Book(title: "Swift", pages: 120)
print(book.title) // Swift
```
