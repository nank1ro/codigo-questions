# --instructions--

यह कोड कंपाइल क्यों नहीं होता?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` एक `let` कॉन्स्टेंट है, इसलिए उस पर म्यूटेटिंग मेथड कॉल नहीं किया जा सकता
- `value` बदलने के लिए `increase` को `static` चिह्नित होना चाहिए
- `value` को `let` से घोषित होना चाहिए
- एक स्ट्रक्चर में मेथड नहीं हो सकते
