# --description--

दो स्ट्रक्चर की तुलना `==` से तब तक नहीं की जा सकती जब तक टाइप यह न बताए कि वह इसका समर्थन करता है। आप यह `Equatable` **प्रोटोकॉल** के अनुरूप होकर करते हैं, जिसे घोषणा में कोलन के बाद लिखा जाता है:
```swift
struct Point: Equatable {
    var x: Int
    var y: Int
}

let a = Point(x: 1, y: 2)
let b = Point(x: 1, y: 2)
print(a == b) // true
```
आपको `==` खुद लिखने की ज़रूरत नहीं: जब हर स्टोर्ड प्रॉपर्टी पहले से `Equatable` होती है, तो Swift उसे आपके लिए बना देता है, प्रॉपर्टीज़ की तुलना एक-एक करके करता है। दो इंस्टेंस बराबर होते हैं जब उनकी सारी प्रॉपर्टीज़ बराबर हों, और किसी मान से आप बिल्कुल यही अपेक्षा करते हैं।
