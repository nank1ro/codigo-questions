एक **स्ट्रक्चर** (*structure* का संक्षिप्त रूप) एक ऐसा टाइप है जिसे आप स्वयं डिज़ाइन करते हैं ताकि संबंधित मानों को एक साथ रखा जा सके। अलग-अलग `title` और अलग `pages` को संभालने के बजाय, आप एक बार `Book` का वर्णन करते हैं और फिर उसे हर जगह उपयोग करते हैं।

आप इसे `struct` कीवर्ड से घोषित करते हैं, और इसके अंदर लिखे गए वेरिएबल इसकी **स्टोर्ड प्रॉपर्टीज़** कहलाते हैं:
```swift
struct Book {
    var title: String
    var pages: Int
}
```
`Book` अब एक टाइप है, बिल्कुल `Int` या `String` की तरह। आप डॉट लगाकर किसी इंस्टेंस की प्रॉपर्टी तक पहुँचते हैं:
```swift
let book = Book(title: "Swift", pages: 120)
print(book.title) // Swift
```

---

आपने कभी भी `Book` बनाने वाला कोड नहीं लिखा, फिर भी `Book(title: "Swift", pages: 120)` काम कर गया। Swift यह कोड आपके लिए लिख देता है: हर स्ट्रक्चर को एक मुफ्त **मेम्बरवाइज़ इनिशियलाइज़र** मिलता है, यानी एक ऐसा इनिशियलाइज़र जिसके पैरामीटर उसकी स्टोर्ड प्रॉपर्टीज़ होती हैं, घोषित होने के क्रम में, और हर एक प्रॉपर्टी के नाम को अपने आर्ग्युमेंट लेबल के रूप में उपयोग करता है:
```swift
struct Point {
    var x: Int
    var y: Int
}

let p = Point(x: 3, y: 4)
print(p.x) // 3
```
क्लासेस को यह मुफ्त नहीं मिलता, और यही एक कारण है कि किसी मान को मॉडल करने का सबसे तेज़ तरीका स्ट्रक्चर है।

---

एक स्टोर्ड प्रॉपर्टी को उसकी घोषणा के स्थान पर ही एक **डिफ़ॉल्ट मान** दिया जा सकता है। Swift उस मान से उसका टाइप पता लगा लेता है, इसलिए आप टाइप एनोटेशन हटा सकते हैं:
```swift
struct Counter {
    var label: String
    var value = 0
}
```
मेम्बरवाइज़ इनिशियलाइज़र हर डिफ़ॉल्ट मान वाली प्रॉपर्टी को एक वैकल्पिक आर्ग्युमेंट बना देता है: डिफ़ॉल्ट को बदलने के लिए उसे पास करें, वही रखने के लिए छोड़ दें।
```swift
let a = Counter(label: "clicks")
print(a.value) // 0

let b = Counter(label: "clicks", value: 7)
print(b.value) // 7
```

---

एक स्ट्रक्चर **मेथड्स** भी रख सकता है: ब्रेसिज़ के अंदर लिखे गए फ़ंक्शन जो उसी इंस्टेंस पर काम करते हैं जिस पर उन्हें कॉल किया जाता है। किसी मेथड के अंदर आप प्रॉपर्टी के नाम सीधे उपयोग करते हैं, बिना किसी प्रीफ़िक्स के:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    func area() -> Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area()) // 12
```
यदि मेथड का कोई पैरामीटर किसी प्रॉपर्टी के नाम को शैडो कर दे, तो इंस्टेंस की प्रॉपर्टी का बोध कराने के लिए `self.width` लिखें।

---

एक **कंप्यूटेड प्रॉपर्टी** देखने में प्रॉपर्टी जैसी लगती है पर व्यवहार में मेथड जैसी होती है: यह कुछ भी संग्रहीत नहीं करती, बल्कि हर बार पढ़ने पर अपना मान गणना करती है। आप टाइप लिखते हैं, फिर मान लौटाने वाला कोड का एक ब्लॉक:
```swift
struct Rectangle {
    var width: Int
    var height: Int

    var area: Int {
        return width * height
    }
}

let r = Rectangle(width: 3, height: 4)
print(r.area) // 12, बिना कोष्ठक के
```
कंप्यूटेड प्रॉपर्टीज़ मेम्बरवाइज़ इनिशियलाइज़र का हिस्सा नहीं होतीं, क्योंकि संग्रहीत करने को कुछ नहीं होता। जब मान बाकी मानों से प्राप्त होता हो तो कंप्यूटेड प्रॉपर्टी उपयोग करें, और जब काम के लिए पैरामीटर चाहिए हों तो मेथड।

---

एक स्ट्रक्चर एक **वैल्यू टाइप** है: उसे किसी दूसरे वेरिएबल को असाइन करने पर, या किसी फ़ंक्शन को पास करने पर, एक *कॉपी* हाथ में आती है। कॉपी को बदलने पर मूल अछूता रहता है।
```swift
struct Point {
    var x: Int
}

var a = Point(x: 1)
var b = a
b.x = 99
print(a.x) // 1
```
एक क्लास एक **रेफरेंस टाइप** है: `b = a` दोनों नामों को उसी इंस्टेंस की ओर इंगित करा देता, इसलिए `b.x = 99` करने पर `a.x` भी `99` हो जाता।

यही दोनों का असली अंतर है, और यही कारण है कि Swift ज़्यादातर डेटा को स्ट्रक्चर के रूप में मॉडल करता है: आपके पास मौजूद किसी मान को वह कोड पीठ पीछे बदल नहीं सकता जिसे वह दिया गया था।

---

चूँकि स्ट्रक्चर एक मान है, कोई मेथड उसकी प्रॉपर्टीज़ को तब तक नहीं बदल सकता जब तक आप `mutating` कीवर्ड से यह न बताएँ:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
किसी म्यूटेटिंग मेथड को केवल `var` में संग्रहीत इंस्टेंस पर ही कॉल किया जा सकता है। `let` इंस्टेंस पर मान जम जाता है, इसलिए `c.increase(by: 5)` कंपाइल नहीं होता।

---

जब मेम्बरवाइज़ इनिशियलाइज़र आपके टाइप को बनाने का वह तरीका न हो जैसा आप चाहते हैं, तो अपना खुद का **इनिशियलाइज़र** लिखें। इसे `init` से घोषित किया जाता है, यह आपके चुने हुए पैरामीटर लेता है, और खत्म होने से पहले हर स्टोर्ड प्रॉपर्टी को एक मान देना ज़रूरी होता है। इसके अंदर, `self` वह इंस्टेंस है जो बन रहा होता है:
```swift
struct Square {
    var side: Int

    init(_ side: Int) {
        self.side = side
    }
}

let s = Square(5)
print(s.side) // 5
```
स्ट्रक्चर के ब्रेसिज़ के अंदर एक `init` लिखने से वह मेम्बरवाइज़ इनिशियलाइज़र की जगह ले लेता है, इसलिए अब से `Square(side: 5)` मौजूद ही नहीं रहता।

---

कुछ मान किसी एक इंस्टेंस के बजाय टाइप के अपने होते हैं: एक करेंसी कोड, एक साझा डिफ़ॉल्ट, एक फ़ैक्टरी जो एक सामान्य केस बनाती है। उन्हें `static` चिह्नित करें और टाइप के नाम से पढ़ें:
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
यहाँ `currency` को `let` से घोषित किया गया है क्योंकि वह कभी नहीं बदलता, इसलिए वह पूरे प्रोग्राम द्वारा साझा किया गया एक कॉन्स्टेंट है। `Money.currency` एक भी `Money` बनाए बिना काम करता है, जबकि `amount` को इंस्टेंस चाहिए।

---

दो स्ट्रक्चर की तुलना `==` से तब तक नहीं की जा सकती जब तक टाइप यह न बताए कि वह इसका समर्थन करता है। आप यह `Equatable` **प्रोटोकॉल** के अनुरूप होकर करते हैं, जिसे घोषणा में कोलन के बाद लिखा जाता है:
```swift
struct Point: Equatable {
    var x: Int
    var y: Int
}

let a = Point(x: 1, y: 2)
let b = Point(x: 1, y: 2)
print(a == b) // true
```
आपको `==` खुद लिखने की ज़रूरत नहीं: जब हर स्टोर्ड प्रॉपर्टी पहले से `Equatable` होती है, तो Swift उसे आपके लिए बना देता है, प्रॉपर्टीज़ की तुलना एक-एक करके करता है। दो इंस्टेंस बराबर होते हैं जब उनकी सारी प्रॉपर्टीज़ बराबर हों, और किसी मान से आप बिल्कुल यही अपेक्षा करते हैं।

---

एक स्ट्रक्चर किसी भी दूसरे टाइप की तरह एक टाइप है, इसलिए इसे ऐरे, डिक्शनरी या सेट में संग्रहीत किया जा सकता है, और आपके ज्ञात हर टूल उस पर काम करता रहता है:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
याद रखें कि ऐरे *कॉपीज़* रखता है: `items[0]` को किसी वेरिएबल में पढ़कर बदलने से ऐरे पर कोई असर नहीं पड़ता।
