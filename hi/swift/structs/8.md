# --description--

चूँकि स्ट्रक्चर एक मान है, कोई मेथड उसकी प्रॉपर्टीज़ को तब तक नहीं बदल सकता जब तक आप `mutating` कीवर्ड से यह न बताएँ:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
किसी म्यूटेटिंग मेथड को केवल `var` में संग्रहीत इंस्टेंस पर ही कॉल किया जा सकता है। `let` इंस्टेंस पर मान जम जाता है, इसलिए `c.increase(by: 5)` कंपाइल नहीं होता।

# --instructions--

`Counter` में एक म्यूटेटिंग मेथड `increase` जोड़ें जो आर्ग्युमेंट लेबल `by` के साथ एक `Int` लेता है और उसे `value` में जोड़ता है

उपयोग का उदाहरण:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

मेथड को `mutating` चिह्नित होना चाहिए

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`0` को `5` से बढ़ाने पर `5` मिलना चाहिए

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

`10` को दो बार बढ़ाने पर दोनों वृद्धियाँ जुड़ जानी चाहिए

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

`0` से बढ़ाने पर कुछ नहीं बदलना चाहिए

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

कॉपी बदलने पर मूल को नहीं बदलना चाहिए

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
