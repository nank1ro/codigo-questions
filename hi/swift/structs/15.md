# --description--

एक स्ट्रक्चर किसी भी दूसरे टाइप की तरह एक टाइप है, इसलिए इसे ऐरे, डिक्शनरी या सेट में संग्रहीत किया जा सकता है, और आपके ज्ञात हर टूल उस पर काम करता रहता है:
```swift
struct Item {
    var name: String
    var price: Int
}

let items = [Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]

for item in items {
    print(item.name)
}

let names = items.map { $0.name }
let total = items.reduce(0) { $0 + $1.price }
print(total) // 10
```
याद रखें कि ऐरे *कॉपीज़* रखता है: `items[0]` को किसी वेरिएबल में पढ़कर बदलने से ऐरे पर कोई असर नहीं पड़ता।

# --instructions--

एक फ़ंक्शन `totalPrice` लिखें जो बिना आर्ग्युमेंट लेबल के `Item` का एक ऐरे लेता है और हर आइटम के `price` का योग लौटाता है, या ऐरे खाली होने पर `0` लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(totalPrice([Item(name: "Tea", price: 3), Item(name: "Cake", price: 7)]))
// prints 10
```
