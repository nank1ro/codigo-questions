# --description--

जब मेम्बरवाइज़ इनिशियलाइज़र आपके टाइप को बनाने का वह तरीका न हो जैसा आप चाहते हैं, तो अपना खुद का **इनिशियलाइज़र** लिखें। इसे `init` से घोषित किया जाता है, यह आपके चुने हुए पैरामीटर लेता है, और खत्म होने से पहले हर स्टोर्ड प्रॉपर्टी को एक मान देना ज़रूरी होता है। इसके अंदर, `self` वह इंस्टेंस है जो बन रहा होता है:
```swift
struct Square {
    var side: Int

    init(_ side: Int) {
        self.side = side
    }
}

let s = Square(5)
print(s.side) // 5
```
स्ट्रक्चर के ब्रेसिज़ के अंदर एक `init` लिखने से वह मेम्बरवाइज़ इनिशियलाइज़र की जगह ले लेता है, इसलिए अब से `Square(side: 5)` मौजूद ही नहीं रहता।
