# --description--

कुछ मान किसी एक इंस्टेंस के बजाय टाइप के अपने होते हैं: एक करेंसी कोड, एक साझा डिफ़ॉल्ट, एक फ़ैक्टरी जो एक सामान्य केस बनाती है। उन्हें `static` चिह्नित करें और टाइप के नाम से पढ़ें:
```swift
struct Money {
    static let currency = "EUR"
    var amount: Int

    static func zero() -> Money {
        return Money(amount: 0)
    }
}

print(Money.currency)     // EUR
print(Money.zero().amount) // 0
```
यहाँ `currency` को `let` से घोषित किया गया है क्योंकि वह कभी नहीं बदलता, इसलिए वह पूरे प्रोग्राम द्वारा साझा किया गया एक कॉन्स्टेंट है। `Money.currency` एक भी `Money` बनाए बिना काम करता है, जबकि `amount` को इंस्टेंस चाहिए।

# --instructions--

`Money` में एक स्टैटिक कॉन्स्टेंट `currency` जोड़ें जो `"EUR"` के बराबर हो, और एक स्टैटिक मेथड `zero` जोड़ें जो कोई पैरामीटर नहीं लेता और `amount` `0` के बराबर वाला एक `Money` लौटाता है

उपयोग का उदाहरण:
```swift
print(Money.currency)
// prints EUR
```
