# --description--

संख्याएँ और स्ट्रिंग्स उसी initializer सिंटैक्स से कन्वर्ट होते हैं। `String(42)` एक संख्या को टेक्स्ट `"42"` में बदल देता है, बिल्कुल उसी तरह जैसे उसे `"\(42)"` से इंटरपोलेट करना।
उलटी दिशा विफल हो सकती है, क्योंकि हर टेक्स्ट एक संख्या नहीं होता, इसलिए `Int("42")` एक **ऑप्शनल** `Int?` लौटाता है: यह यहाँ `42` रखता है, लेकिन `Int("hello")` की मान `nil` है।
जैसा आपने nullability पाठों में सीखा, आप `??` से एक फ़ॉलबैक दे सकते हैं या `if let` से उसे अनरैप कर सकते हैं:
```swift
let typed = "42"
let number = Int(typed) ?? 0
print(number + 1) // 43
```
