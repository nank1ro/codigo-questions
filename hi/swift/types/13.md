# --description--

जैसा आपने स्ट्रिंग्स पाठों में देखा, एक `String` पर इटरेट करने से आपको एक बार में एक `Character` मिलता है। एक `Character` एक `String` नहीं है, इसलिए उसे टेक्स्ट के रूप में उपयोग करने के लिए आप उसे `String(c)` से कन्वर्ट करते हैं।
जब अक्षर एक अंक होता है, तो `wholeNumberValue` प्रॉपर्टी आपको उसका संख्यात्मक मान एक `Int?` के रूप में देती है: जो अक्षर अंक नहीं हैं, उनके लिए यह `nil` होता है।
```swift
for c in "a1" {
    print(c.wholeNumberValue)
}
// nil
// Optional(1)
```
