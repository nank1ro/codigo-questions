Swift में हर मान का एक **टाइप** होता है, जो कंपाइलर को बताता है कि वह किस तरह का डेटा है और आप उसके साथ क्या कर सकते हैं।
मूल टाइप ये हैं:
- `Int`: एक पूर्ण संख्या, जैसे `42` या `-7`
- `Double`: दशमलव भाग वाली एक संख्या, जैसे `3.14`
- `String`: टेक्स्ट का एक टुकड़ा, जैसे `"Hello"`
- `Character`: एक अक्षर, जैसे `"a"`
- `Bool`: या तो `true` या `false`

आप किसी कॉन्स्टेंट या वेरिएबल का टाइप एक **टाइप एनोटेशन** से बता सकते हैं: नाम के बाद एक कोलन और टाइप का नाम:
```swift
let age: Int = 36
let name: String = "Ada"
```
एक टाइप का मान दूसरे टाइप के कॉन्स्टेंट में संग्रहीत नहीं किया जा सकता: `let age: Int = "36"` एक कंपाइल एरर है।

---

अधिकतर समय आप टाइप एनोटेशन नहीं लिखते: Swift आपके असाइन किए गए मान से टाइप का **अनुमान** लगाता है, कुछ लिटरल नियमों के अनुसार:
- बिना दशमलव बिंदु वाली संख्या, जैसे `42`, एक `Int` होती है
- दशमलव बिंदु वाली संख्या, जैसे `3.14`, एक `Double` होती है
- डबल कोट्स के बीच का टेक्स्ट एक `String` होता है
- `true` और `false` `Bool` होते हैं
```swift
let count = 42     // Int
let price = 9.99   // Double
let name = "Ada"   // String
let isOpen = true  // Bool
```
Swift में `Float` भी है, एक दशमलव संख्या जो `Double` की आधी मेमोरी उपयोग करती है लेकिन कम सटीक होती है, इसलिए दशमलव लिटरल का अनुमान कभी भी `Float` के रूप में नहीं लगाया जाता: आपको इसे एक एनोटेशन से मांगना होता है।
इसी तरह `"a"` का अनुमान एक `String` के रूप में लगाया जाता है, इसलिए `Character` को हमेशा एक एनोटेशन की ज़रूरत होती है।

---

`type(of:)` फ़ंक्शन किसी मान का टाइप लौटाता है, जो यह जांचने में काम आता है कि Swift ने क्या अनुमान लगाया है:
```swift
print(type(of: 42))    // Int
print(type(of: 2.5))   // Double
print(type(of: "hi"))  // String
```
जब आप अनुमानित टाइप से अलग कोई टाइप चाहते हैं, तो एक एनोटेशन जोड़ें। एक पूर्ण संख्या लिटरल को `Double` या `Float` कॉन्स्टेंट में संग्रहीत किया जा सकता है, और एक-अक्षर वाला लिटरल एक `Character` कॉन्स्टेंट में:
```swift
let ratio: Double = 3       // 3.0, not an Int
let half: Float = 0.5
let initial: Character = "S"
print(type(of: ratio))      // Double
```

---

Swift कभी भी अपने आप संख्या टाइप्स के बीच कन्वर्ज़न नहीं करता: एक `Int` को `Double` में जोड़ना एक कंपाइल एरर है, भले ही दोनों संख्याएँ हों।
```swift
let apples = 3
let price = 1.5
let total = apples * price // error: Int and Double can't be mixed
```
उन्हें मिलाने के लिए आप जिस टाइप की ज़रूरत है उसका एक नया मान बनाते हैं, मान को उस टाइप के initializer को पास करके:
```swift
let total = Double(apples) * price // 4.5
```
यही बात उलटी दिशा में भी काम करती है: `Int(4.5)` एक `Int` बनाता है, जिसमें संख्या का केवल पूर्ण भाग रखा जाता है।

---

`Int(x)` राउंड नहीं करता: यह **ट्रंकेट** करता है, बस दशमलव भाग हटा देता है, इसलिए `Int(3.99)` की मान `3` है और `Int(-3.99)` की मान `-3` है।
निकटतम पूर्ण संख्या पर राउंड करने के लिए, पहले `Double` पर `rounded()` कॉल करें और फिर कन्वर्ट करें:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
आधे के मान जैसे `2.5` शून्य से दूर राउंड होते हैं: `2.5` की मान `3.0` हो जाती है और `-2.5` की मान `-3.0`।

---

ऑपरेंड का टाइप तय करता है कि डिवीज़न कैसे काम करता है। जब दोनों `Int` हों, तो `/` ऑपरेटर **इंटीजर डिवीज़न** करता है: परिणाम एक `Int` होता है और शेषफल फेंक दिया जाता है।
जब कम से कम एक ऑपरेंड `Double` हो, तो `/` फ़्लोटिंग-पॉइंट डिवीज़न करता है और दशमलव भाग रखता है:
```swift
print(7 / 2)              // 3
print(7.0 / 2)            // 3.5
let slices = 7
print(Double(slices) / 2) // 3.5
```
इसलिए दो `Int` मानों से दशमलव परिणाम पाने के लिए आपको डिवाइड करने से **पहले** उनमें से कम से कम एक को `Double` में कन्वर्ट करना होगा: `Double(7 / 2)` की मान `3.0` है, क्योंकि इंटीजर डिवीज़न पहले ही हो चुका होता है।

---

जब किसी फ़ंक्शन को पूर्ण संख्याओं से गणना किया गया दशमलव परिणाम लौटाना होता है, तो ऑपरेंड को डिवाइड करने से पहले `Double` में कन्वर्ट करें और रिटर्न टाइप `Double` घोषित करें:
```swift
func ratio(_ part: Int, _ total: Int) -> Double {
    return Double(part) / Double(total)
}
print(ratio(1, 4)) // 0.25
```
याद रखें कि ऐरे का `count` भी एक `Int` होता है, इसलिए उसे भी वही कन्वर्ज़न चाहिए।

---

संख्याएँ और स्ट्रिंग्स उसी initializer सिंटैक्स से कन्वर्ट होते हैं। `String(42)` एक संख्या को टेक्स्ट `"42"` में बदल देता है, बिल्कुल उसी तरह जैसे उसे `"\(42)"` से इंटरपोलेट करना।
उलटी दिशा विफल हो सकती है, क्योंकि हर टेक्स्ट एक संख्या नहीं होता, इसलिए `Int("42")` एक **ऑप्शनल** `Int?` लौटाता है: यह यहाँ `42` रखता है, लेकिन `Int("hello")` की मान `nil` है।
जैसा आपने nullability पाठों में सीखा, आप `??` से एक फ़ॉलबैक दे सकते हैं या `if let` से उसे अनरैप कर सकते हैं:
```swift
let typed = "42"
let number = Int(typed) ?? 0
print(number + 1) // 43
```

---

`Int(text)` तभी सफल होता है जब पूरा टेक्स्ट एक वैध पूर्ण संख्या हो, एक वैकल्पिक चिह्न के साथ:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
दशमलव टेक्स्ट के लिए `Double(text)` का उपयोग करें, जो उसी तरह एक `Double?` लौटाता है: `Double("3.5")` की मान `Optional(3.5)` है।

---

एक **टाइप एलियास** किसी मौजूदा टाइप को `typealias` कीवर्ड से एक नया नाम देता है:
```swift
typealias Score = Int
let best: Score = 100
print(best + 1) // 101
```
`Score` और `Int` एक ही टाइप हैं, इसलिए वे आपस में बेझिझक मिलते हैं। एक एलियास कोई सुरक्षा नहीं जोड़ता: यह केवल कोड को बेहतर तरीके से पढ़ने योग्य बनाता है जब आपके प्रोग्राम में किसी साधारण टाइप का एक विशिष्ट अर्थ हो।

---

एक `Int` 64 बिट्स का उपयोग करता है, इसलिए यह केवल एक निश्चित सीमा की संख्याएँ दर्शा सकता है। सबसे बड़ा और सबसे छोटा मान `Int.max` और `Int.min` के रूप में उपलब्ध हैं:
```swift
print(Int.max) // 9223372036854775807
print(Int.min) // -9223372036854775808
```
इन सीमाओं से आगे जाना **ओवरफ़्लो** कहलाता है। कई अन्य भाषाओं के विपरीत, Swift चुपचाप सीमा के दूसरे सिरे पर नहीं लपेटता: एक ओवरफ़्लो होने वाली संक्रिया एक **रनटाइम एरर** है जो प्रोग्राम को रोक देती है।

---

किसी चरम मान की खोज करते समय `Int.max` और `Int.min` शुरुआती मानों के रूप में उपयोगी हैं: कोई भी वास्तविक संख्या `Int.max` से छोटी होती है, इसलिए यह "अब तक देखा गया सबसे छोटा" के लिए एक सुरक्षित शुरुआती मान है:
```swift
var smallest = Int.max
for number in [8, 3, 5] {
    if number < smallest {
        smallest = number
    }
}
print(smallest) // 3
```

---

जैसा आपने स्ट्रिंग्स पाठों में देखा, एक `String` पर इटरेट करने से आपको एक बार में एक `Character` मिलता है। एक `Character` एक `String` नहीं है, इसलिए उसे टेक्स्ट के रूप में उपयोग करने के लिए आप उसे `String(c)` से कन्वर्ट करते हैं।
जब अक्षर एक अंक होता है, तो `wholeNumberValue` प्रॉपर्टी आपको उसका संख्यात्मक मान एक `Int?` के रूप में देती है: जो अक्षर अंक नहीं हैं, उनके लिए यह `nil` होता है।
```swift
for c in "a1" {
    print(c.wholeNumberValue)
}
// nil
// Optional(1)
```

---

चूंकि `Int(text)` और `Double(text)` विफल होने पर `nil` लौटाते हैं, परिणाम की तुलना `nil` से करने पर आपको पता चल जाता है कि कोई टेक्स्ट उस तरह की संख्या है या नहीं:
```swift
print(Int("42") != nil)     // true
print(Double("4.2") != nil) // true
print(Double("42") != nil)  // true, a whole number is also a valid Double
```
ध्यान दें कि अंतिम लाइन: `Int` द्वारा स्वीकार किया गया हर टेक्स्ट `Double` द्वारा भी स्वीकार किया जाता है, इसलिए जब आप उन्हें अलग करना चाहते हैं तो पहले `Int` की जांच करें।

---

कभी-कभी आपको विभिन्न टाइप्स के मान एक साथ संग्रहीत करने की ज़रूरत होती है। विशेष टाइप `Any` **किसी भी** टाइप का मान रख सकता है, इसलिए `[Any]` के रूप में घोषित एक ऐरे में संख्याएँ, स्ट्रिंग्स और बूलियन मिल सकते हैं:
```swift
let items: [Any] = [1, "two", true]
```
हर एलिमेंट अपना वास्तविक टाइप याद रखता है, जिसे `type(of:)` प्रकट करता है। मान के साथ उसके वास्तविक टाइप के रूप में काम करने के लिए आप `as?` के साथ एक **कंडीशनल कास्ट** का उपयोग करते हैं, जो एक ऑप्शनल लौटाता है: टाइप मेल खाने पर यह मान रखता है और अन्यथा `nil`:
```swift
for item in items {
    if let number = item as? Int {
        print(number + 1) // runs only for 1
    }
}
```
`Any` अंतिम उपाय है: किसी एक ही ठोस टाइप का ऐरे अधिक सुरक्षित और उपयोग में आसान होता है, इसलिए जब भी संभव हो उसे ही प्राथमिकता दें।

---

कंडीशनल कास्ट `else if` के साथ स्वाभाविक रूप से श्रृंखलाबद्ध होते हैं ताकि कई संभावित टाइप्स को संभाला जा सके, हर एक को उस टाइप में कन्वर्ट करते हुए जिसकी आपको परिणाम के लिए ज़रूरत है:
```swift
let item: Any = 2.5
if let number = item as? Int {
    print(Double(number))
} else if let number = item as? Double {
    print(number)
}
```
`Any` में संग्रहीत एक `Int` अब भी एक `Int` है: उस पर `as? Double` की मान `nil` है, क्योंकि `as?` टाइप की जांच करता है, वह संख्याओं को कन्वर्ट नहीं करता।
