# --description--

`Int(text)` तभी सफल होता है जब पूरा टेक्स्ट एक वैध पूर्ण संख्या हो, एक वैकल्पिक चिह्न के साथ:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
दशमलव टेक्स्ट के लिए `Double(text)` का उपयोग करें, जो उसी तरह एक `Double?` लौटाता है: `Double("3.5")` की मान `Optional(3.5)` है।

# --instructions--

एक फ़ंक्शन `sumOfNumbers` लिखें जो `String` का एक ऐरे लेता है (आर्ग्युमेंट लेबल छोड़ दें) और उनमें से वैध पूर्ण संख्याओं का योग लौटाता है, बाकी को नज़रअंदाज़ करते हुए

फ़ंक्शन कॉल का उदाहरण:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
