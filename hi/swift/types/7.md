# --description--

जब किसी फ़ंक्शन को पूर्ण संख्याओं से गणना किया गया दशमलव परिणाम लौटाना होता है, तो ऑपरेंड को डिवाइड करने से पहले `Double` में कन्वर्ट करें और रिटर्न टाइप `Double` घोषित करें:
```swift
func ratio(_ part: Int, _ total: Int) -> Double {
    return Double(part) / Double(total)
}
print(ratio(1, 4)) // 0.25
```
याद रखें कि ऐरे का `count` भी एक `Int` होता है, इसलिए उसे भी वही कन्वर्ज़न चाहिए।

# --instructions--

एक फ़ंक्शन `average` लिखें जो `Int` का एक ऐरे लेता है (आर्ग्युमेंट लेबल छोड़ दें) और उसके एलिमेंट्स का औसत एक `Double` के रूप में लौटाता है। ऐरे कभी खाली नहीं है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(average([1, 2]))
// prints 1.5
```

# --solutions--

```swift
func average(_ numbers: [Int]) -> Double {
    var sum = 0
    for number in numbers {
        sum += number
    }
    return Double(sum) / Double(numbers.count)
}
```
