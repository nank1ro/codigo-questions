# --description--

`Int(x)` राउंड नहीं करता: यह **ट्रंकेट** करता है, बस दशमलव भाग हटा देता है, इसलिए `Int(3.99)` की मान `3` है और `Int(-3.99)` की मान `-3` है।
निकटतम पूर्ण संख्या पर राउंड करने के लिए, पहले `Double` पर `rounded()` कॉल करें और फिर कन्वर्ट करें:
```swift
let x = 3.99
print(Int(x))            // 3
print(Int(x.rounded()))  // 4
```
आधे के मान जैसे `2.5` शून्य से दूर राउंड होते हैं: `2.5` की मान `3.0` हो जाती है और `-2.5` की मान `-3.0`।

# --instructions--

एक फ़ंक्शन `roundedAverage` लिखें जो दो `Int` लेता है (आर्ग्युमेंट लेबल छोड़ दें) और उनका औसत निकटतम पूर्ण संख्या पर राउंड करके एक `Int` के रूप में लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(roundedAverage(3, 4))
// prints 4
```

```swift
func roundedAverage(_ a: Int, _ b: Int) -> Int {
    let average = Double(a + b) / 2
    return Int(average.rounded())
}
```
