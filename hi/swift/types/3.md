# --description--

`type(of:)` फ़ंक्शन किसी मान का टाइप लौटाता है, जो यह जांचने में काम आता है कि Swift ने क्या अनुमान लगाया है:
```swift
print(type(of: 42))    // Int
print(type(of: 2.5))   // Double
print(type(of: "hi"))  // String
```
जब आप अनुमानित टाइप से अलग कोई टाइप चाहते हैं, तो एक एनोटेशन जोड़ें। एक पूर्ण संख्या लिटरल को `Double` या `Float` कॉन्स्टेंट में संग्रहीत किया जा सकता है, और एक-अक्षर वाला लिटरल एक `Character` कॉन्स्टेंट में:
```swift
let ratio: Double = 3       // 3.0, not an Int
let half: Float = 0.5
let initial: Character = "S"
print(type(of: ratio))      // Double
```

# --instructions--

तीन कॉन्स्टेंट घोषित करें:
- `ratio`, एक `Double` जो पूर्ण संख्या लिटरल `3` रखता है
- `half`, एक `Float` जो `0.5` रखता है
- `initial`, एक `Character` जो `"S"` रखता है
