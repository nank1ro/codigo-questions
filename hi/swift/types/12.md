# --description--

किसी चरम मान की खोज करते समय `Int.max` और `Int.min` शुरुआती मानों के रूप में उपयोगी हैं: कोई भी वास्तविक संख्या `Int.max` से छोटी होती है, इसलिए यह "अब तक देखा गया सबसे छोटा" के लिए एक सुरक्षित शुरुआती मान है:
```swift
var smallest = Int.max
for number in [8, 3, 5] {
    if number < smallest {
        smallest = number
    }
}
print(smallest) // 3
```

# --instructions--

एक फ़ंक्शन `smallest` लिखें जो `Int` का एक ऐरे लेता है (आर्ग्युमेंट लेबल छोड़ दें) और उसका सबसे छोटा एलिमेंट लौटाता है, या ऐरे खाली होने पर `Int.max` लौटाता है। `min()` मेथड का उपयोग न करें

`smallest([8, 3, 5])` को `3` लौटाना चाहिए

```swift

```

`smallest([-5, 5])` को `-5` लौटाना चाहिए

```swift

```

`smallest([Int.min, 0])` को `Int.min` लौटाना चाहिए

```swift
tryCatch(smallest([Int.min, 0]) == Int.min)
```

`smallest([])` को `Int.max` लौटाना चाहिए

```swift
tryCatch(smallest([]) == Int.max)
```

```swift
func smallest(_ numbers: [Int]) -> Int {
    var result = Int.max
    for number in numbers {
        if number < result {
            result = number
        }
    }
    return result
}
```
