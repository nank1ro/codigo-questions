# --description--

एक `Int` 64 बिट्स का उपयोग करता है, इसलिए यह केवल एक निश्चित सीमा की संख्याएँ दर्शा सकता है। सबसे बड़ा और सबसे छोटा मान `Int.max` और `Int.min` के रूप में उपलब्ध हैं:
```swift
print(Int.max) // 9223372036854775807
print(Int.min) // -9223372036854775808
```
इन सीमाओं से आगे जाना **ओवरफ़्लो** कहलाता है। कई अन्य भाषाओं के विपरीत, Swift चुपचाप सीमा के दूसरे सिरे पर नहीं लपेटता: एक ओवरफ़्लो होने वाली संक्रिया एक **रनटाइम एरर** है जो प्रोग्राम को रोक देती है।

# --instructions--

इस कोड को चलाने पर क्या होता है?
```swift
func next(_ n: Int) -> Int {
    return n + 1
}
print(next(Int.max))
```

# --answers--

- प्रोग्राम एक ओवरफ़्लो एरर के साथ क्रैश हो जाता है
- यह -9223372036854775808 प्रिंट करता है
- यह 0 प्रिंट करता है
- यह 9223372036854775807 प्रिंट करता है
