# --description--

कभी-कभी आपको विभिन्न टाइप्स के मान एक साथ संग्रहीत करने की ज़रूरत होती है। विशेष टाइप `Any` **किसी भी** टाइप का मान रख सकता है, इसलिए `[Any]` के रूप में घोषित एक ऐरे में संख्याएँ, स्ट्रिंग्स और बूलियन मिल सकते हैं:
```swift
let items: [Any] = [1, "two", true]
```
हर एलिमेंट अपना वास्तविक टाइप याद रखता है, जिसे `type(of:)` प्रकट करता है। मान के साथ उसके वास्तविक टाइप के रूप में काम करने के लिए आप `as?` के साथ एक **कंडीशनल कास्ट** का उपयोग करते हैं, जो एक ऑप्शनल लौटाता है: टाइप मेल खाने पर यह मान रखता है और अन्यथा `nil`:
```swift
for item in items {
    if let number = item as? Int {
        print(number + 1) // runs only for 1
    }
}
```
`Any` अंतिम उपाय है: किसी एक ही ठोस टाइप का ऐरे अधिक सुरक्षित और उपयोग में आसान होता है, इसलिए जब भी संभव हो उसे ही प्राथमिकता दें।
