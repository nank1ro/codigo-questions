# --description--

Swift में कमेंट का तीसरा प्रकार भी है, **डॉक्युमेंटेशन कमेंट**: एक सिंगल-लाइन कमेंट जो `///` (तीन स्लैश) से शुरू होता है और किसी फ़ंक्शन, टाइप या प्रॉपर्टी के ठीक ऊपर रखा जाता है।
```swift
/// `name` के लिए अभिवादन लौटाता है।
func greet(_ name: String) -> String {
    return "Hi, \(name)!"
}
```
कंपाइलर के लिए यह सिर्फ़ एक कमेंट है, लेकिन Xcode जैसे टूल इसे पढ़कर `greet` के हेल्प टेक्स्ट के रूप में दिखाते हैं। डॉक्युमेंटेशन कमेंट्स **मार्कडाउन** का समर्थन करते हैं, इसलिए आप कोड के लिए बैकटिक, `**बोल्ड**` और लिस्ट इस्तेमाल कर सकते हैं।
