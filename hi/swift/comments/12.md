# --description--

सारांश के बाद, डॉक्युमेंटेशन कमेंट विशेष मार्कडाउन लिस्ट आइटम्स से पैरामीटर्स और रिटर्न वैल्यू का वर्णन कर सकता है, जिन्हें Xcode पहचानता है:
```swift
/// दिए गए मिनटों में सेकंड्स की संख्या लौटाता है।
/// - Parameter minutes: मिनटों की एक पूर्ण संख्या, कभी नकारात्मक नहीं
/// - Returns: `minutes` को साठ से गुणा किया हुआ
func toSeconds(_ minutes: Int) -> Int {
    return minutes * 60
}
```
क्रम हमेशा एक ही रहता है: पहले सारांश, फिर हर पैरामीटर के लिए `- Parameter name:`, फिर `- Returns:`।
