# --description--

कुछ कमेंट्स ऐसी परंपरा का पालन करते हैं जिसे एडिटर समझते हैं। Swift में सबसे आम **मार्कर** ये हैं:
- `// MARK: - Title` फ़ाइल के किसी सेक्शन को नाम देता है, ताकि वह Xcode के नेविगेशन मेन्यू में दिखे
- `// TODO: ...` उस चीज़ को चिह्नित करता है जिसे अभी लिखा जाना बाकी है
- `// FIXME: ...` उस कोड को चिह्नित करता है जो ज्ञात रूप से ग़लत है और ठीक किया जाना चाहिए

```swift
// MARK: - Setup
let limit = 10
// TODO: read the limit from the settings
// FIXME: crashes when the list is empty
```
कंपाइलर के लिए ये सामान्य कमेंट हैं; Xcode इन्हें सूचीबद्ध करता है ताकि बचा हुआ काम आसानी से मिल जाए। काम पूरा होने पर मार्कर हटा दें: पुराना पड़ चुका `TODO` भ्रामक होता है।
