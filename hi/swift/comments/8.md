# --description--

ब्लॉक कमेंट्स का एक आम उपयोग **हेडर कमेंट** है: फ़ंक्शन के ठीक ऊपर रखा गया छोटा ब्लॉक जो बताता है कि वह क्या करता है और उसके पैरामीटर्स का क्या अर्थ है।
```swift
/*
Returns the number of seconds in the given minutes.
minutes is a whole number, never negative.
*/
func toSeconds(_ minutes: Int) -> Int {
    return minutes * 60
}
```
जो कोई `toSeconds` को कॉल करता है वह अब बॉडी के बजाय हेडर पढ़ सकता है। हेडर को फ़ंक्शन के पास ही रखें ताकि दोनों साथ अपडेट हों।
