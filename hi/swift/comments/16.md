# --description--

अच्छा कमेंट यह समझाता है कि कोड कुछ **क्यों** करता है, यह नहीं कि वह **क्या** करता है। कोड पहले ही दिखा देता है कि क्या होता है; उसे शब्दों में दोहराना केवल शोर बढ़ाता है और कोड बदलते ही पुराना पड़ जाता है:
```swift
// set timeout to 30
let timeout = 30
```
संख्या के पीछे का कारण वही है जिसे पढ़ने वाला अंदाज़ा नहीं लगा सकता:
```swift
// the server drops idle connections after 35 seconds, so stop earlier
let timeout = 30
```
अगर कोई कमेंट सिर्फ़ नीचे की लाइन को दोहराता है, तो उसे हटा दें या उसकी जगह कारण लिखें।
