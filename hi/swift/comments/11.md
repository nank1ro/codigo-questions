# --description--

डॉक्युमेंटेशन कमेंट ब्लॉक रूप में भी आते हैं: `/**` उसे खोलता है और `*/` उसे बंद करता है, बिल्कुल मल्टी-लाइन कमेंट की तरह लेकिन शुरुआत में एक दूसरा तारांकन (asterisk) के साथ।
```swift
/**
 Returns the greeting for `name`.

 The result always ends with an exclamation mark.
 */
func greet(_ name: String) -> String {
    return "Hi, \(name)!"
}
```
टूल्स के लिए `/// टेक्स्ट` और `/** टेक्स्ट */` का एक ही अर्थ है; Swift कोड में `///` सबसे आम विकल्प है, जबकि `/** */` लंबे विवरणों के लिए सुविधाजनक है। सादा `/* */` या `//` कमेंट डॉक्युमेंटेशन **नहीं** है, भले ही वह फ़ंक्शन के ऊपर रखा हो।
