# --description--

क्लोजर को किसी भी अन्य मान की तरह ऐरे में स्टोर किया जा सकता है। एलिमेंट का टाइप फ़ंक्शन टाइप होता है:
```swift
let steps: [(Int) -> Int] = [{ $0 + 1 }, { $0 * 10 }]
print(steps[1](3)) // 30
```
ऐसे ऐरे पर लूप चलाकर और हर क्लोजर को क्रम से कॉल करके बदलावों की एक छोटी **पाइपलाइन** बनाई जा सकती है।

# --instructions--

एक फ़ंक्शन `pipeline` लिखें जो एक `Int` और `(Int) -> Int` टाइप के क्लोजर्स का एक ऐरे लेता है (दोनों के आर्ग्युमेंट लेबल छोड़ दें) और हर क्लोजर को क्रम से, पिछले परिणाम पर लागू करने का परिणाम लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(pipeline(2, [{ $0 + 1 }, { $0 * 10 }]))
// prints 30
```

# --solutions--

```swift
func pipeline(_ start: Int, _ steps: [(Int) -> Int]) -> Int {
    var value = start
    for step in steps {
        value = step(value)
    }
    return value
}
```
