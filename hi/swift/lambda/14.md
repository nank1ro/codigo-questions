# --description--

क्लोजर लौटाने वाले फ़ंक्शन की हर कॉल एक **नया** कैप्चर किया गया वेरिएबल बनाती है। अलग-अलग कॉल्स से बने दो क्लोजर अपनी स्टेट साझा नहीं करते:
```swift
let first = makeCounter()
let second = makeCounter()
print(first())  // 1
print(first())  // 2
print(second()) // 1
```
स्टेट केवल तभी साझा होती है जब एक ही क्लोजर को कई बार कॉल किया जाता है।

# --instructions--

यह कोड क्या प्रिंट करता है? (`makeCounter` पिछले अभ्यासों वाला फ़ंक्शन है)
```swift
let a = makeCounter()
let b = makeCounter()
_ = a()
_ = a()
_ = b()
print(a() + b())
```
