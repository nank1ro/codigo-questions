# --description--

एक **क्लोजर** कोड का एक ब्लॉक होता है जिसे आप इधर-उधर पास करके बाद में कॉल कर सकते हैं, बिना नाम वाले फ़ंक्शन की तरह।
पूरे क्लोजर एक्सप्रेशन के सिंटैक्स में पैरामीटर और रिटर्न टाइप को कर्ली ब्रैकेट्स के अंदर रखा जाता है, उसके बाद `in` कीवर्ड और बॉडी आती है:
```swift
{ (parameters) -> ReturnType in
    body
}
```
किसी भी अन्य मान की तरह, क्लोजर को एक कॉन्स्टेंट में स्टोर किया जा सकता है और फिर उस कॉन्स्टेंट के नाम से कॉल किया जा सकता है:
```swift
let greet = { (name: String) -> String in
    return "Hello, \(name)!"
}
print(greet("Ada")) // Hello, Ada!
```
