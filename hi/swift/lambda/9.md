# --description--

`sorted(by:)` एक नया क्रमबद्ध ऐरे लौटाता है। क्लोजर दो एलिमेंट्स लेता है और `true` लौटाता है जब पहले वाले को दूसरे से **पहले** आना चाहिए:
```swift
let nums = [3, 1, 2]
print(nums.sorted { $0 < $1 }) // [1, 2, 3]
print(nums.sorted { $0 > $1 }) // [3, 2, 1]
```
क्लोजर किसी भी चीज़ की तुलना कर सकता है, उदाहरण के लिए `words.sorted { $0.count < $1.count }` स्ट्रिंग्स को सबसे छोटी से सबसे लंबी तक क्रम में लगाता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```swift
let words = ["kiwi", "fig", "banana"]
print(words.sorted { $0.count > $1.count })
```
