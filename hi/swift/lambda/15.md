# --description--

डिफ़ॉल्ट रूप से, किसी फ़ंक्शन को पास किया गया क्लोजर केवल उस फ़ंक्शन के चलने के दौरान ही इस्तेमाल किया जा सकता है। अगर फ़ंक्शन उस क्लोजर को स्टोर कर लेता है या ऐसा दूसरा क्लोजर लौटाता है जो इसका उपयोग करता है, तो वह क्लोजर उस फ़ंक्शन से **एस्केप** करता है, और इसके पैरामीटर को `@escaping` से चिह्नित करना ज़रूरी है:
```swift
func twice(_ task: @escaping () -> Int) -> () -> Int {
    return { task() * 2 }
}
let answer = twice { 21 }
print(answer()) // 42
```
`@escaping` के बिना कंपाइलर एक एरर देता है, क्योंकि लौटाया गया क्लोजर `twice` के खत्म होने के बाद `task` का उपयोग करेगा।

# --instructions--

एक फ़ंक्शन `compose` लिखें जो `(Int) -> Int` टाइप के दो क्लोजर लेता है (दोनों के आर्ग्युमेंट लेबल छोड़ दें) और एक ऐसा क्लोजर लौटाता है जो पहले वाले को लागू करके फिर उसके परिणाम पर दूसरे वाले को लागू करता है

फ़ंक्शन कॉल का उदाहरण:
```swift
let addThenDouble = compose({ $0 + 1 }, { $0 * 2 })
print(addThenDouble(3))
// prints 8
```
