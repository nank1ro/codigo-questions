एक **क्लोजर** कोड का एक ब्लॉक होता है जिसे आप इधर-उधर पास करके बाद में कॉल कर सकते हैं, बिना नाम वाले फ़ंक्शन की तरह।
पूरे क्लोजर एक्सप्रेशन के सिंटैक्स में पैरामीटर और रिटर्न टाइप को कर्ली ब्रैकेट्स के अंदर रखा जाता है, उसके बाद `in` कीवर्ड और बॉडी आती है:
```swift
{ (parameters) -> ReturnType in
    body
}
```
किसी भी अन्य मान की तरह, क्लोजर को एक कॉन्स्टेंट में स्टोर किया जा सकता है और फिर उस कॉन्स्टेंट के नाम से कॉल किया जा सकता है:
```swift
let greet = { (name: String) -> String in
    return "Hello, \(name)!"
}
print(greet("Ada")) // Hello, Ada!
```

---

क्लोजर के अंदर हर टाइप लिखना अक्सर ज़रूरी नहीं होता। जब कॉन्स्टेंट का एक स्पष्ट **फ़ंक्शन टाइप** होता है, तो Swift पैरामीटर और रिटर्न टाइप का अनुमान लगा लेता है, इसलिए आपको `in` से पहले सिर्फ़ पैरामीटर के नाम लिखने होते हैं:
```swift
let triple: (Int) -> Int = { n in
    return n * 3
}
```
टाइप `(Int) -> Int` को "एक फ़ंक्शन जो `Int` लेता है और `Int` लौटाता है" के रूप में पढ़ा जाता है।
जब बॉडी एक ही एक्सप्रेशन हो, तो `return` कीवर्ड को भी छोड़ा जा सकता है, इसे **इम्प्लिसिट रिटर्न** कहा जाता है:
```swift
let triple: (Int) -> Int = { n in n * 3 }
print(triple(4)) // 12
```

---

Swift एक कदम और आगे जाता है: क्लोजर के अंदर आप **शॉर्टहैंड आर्ग्युमेंट नाम** `$0`, `$1`, `$2` वगैरह का उपयोग करके, बिना कोई पैरामीटर घोषित किए या `in` कीवर्ड लिखे, आर्ग्युमेंट्स को संदर्भित कर सकते हैं।
`$0` पहला आर्ग्युमेंट है, `$1` दूसरा:
```swift
let add: (Int, Int) -> Int = { $0 + $1 }
print(add(2, 3)) // 5
```
टाइप अभी भी `(Int, Int) -> Int` एनोटेशन से आते हैं।

---

चूंकि क्लोजर मान होते हैं, इसलिए कोई फ़ंक्शन इसे पैरामीटर के रूप में स्वीकार कर सकता है। पैरामीटर का टाइप बस फ़ंक्शन टाइप होता है:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
फ़ंक्शन `apply` को नहीं पता कि `operation` क्या करता है, उसे बस इतना पता है कि यह एक `Int` लेता है और एक `Int` लौटाता है, और वह इसे किसी भी अन्य फ़ंक्शन की तरह कॉल करता है।

---

जब कोई क्लोजर किसी फ़ंक्शन का **आखिरी** आर्ग्युमेंट होता है, तो आप इसे कॉल के क्लोजिंग पैरेंथेसिस के बाद लिख सकते हैं। यह **ट्रेलिंग क्लोजर** सिंटैक्स है:
```swift
print(apply(5) { $0 + 1 }) // 6
```
अगर क्लोजर ही एकमात्र आर्ग्युमेंट है, तो पैरेंथेसिस को पूरी तरह हटाया जा सकता है:
```swift
func run(_ task: () -> Int) -> Int {
    return task()
}
print(run { 42 }) // 42
```
दोनों रूप बिल्कुल एक ही फ़ंक्शन को कॉल करते हैं, बस जब क्लोजर लंबा हो तो ट्रेलिंग सिंटैक्स पढ़ने में आसान होता है।

---

क्लोजर उन ऐरे मेथड्स के साथ चमकते हैं जो इसे आर्ग्युमेंट के रूप में लेते हैं। `map` हर एलिमेंट पर क्लोजर को कॉल करता है और परिणामों के साथ एक नया ऐरे लौटाता है:
```swift
let nums = [1, 2, 3]
let doubled = nums.map { $0 * 2 }
print(doubled) // [2, 4, 6]
```
मूल ऐरे में कोई बदलाव नहीं होता। चूंकि `map` एक ही क्लोजर आर्ग्युमेंट लेता है, इसलिए इसे कॉल करने का सामान्य तरीका ट्रेलिंग क्लोजर सिंटैक्स है।

---

`filter` केवल उन एलिमेंट्स को रखता है जिनके लिए क्लोजर `true` लौटाता है। क्लोजर एक एलिमेंट लेता है और उसे एक `Bool` लौटाना चाहिए:
```swift
let nums = [5, 12, 8, 20]
let big = nums.filter { $0 > 10 }
print(big) // [12, 20]
```
एलिमेंट्स अपना मूल क्रम बनाए रखते हैं, और परिणाम उसी एलिमेंट टाइप का एक नया ऐरे होता है।

---

`reduce` सभी एलिमेंट्स को एक ही मान में जोड़ देता है। यह एक शुरुआती मान और दो आर्ग्युमेंट्स लेने वाला एक क्लोजर लेता है: अब तक का जमा हुआ मान और वर्तमान एलिमेंट। क्लोजर नया जमा हुआ मान लौटाता है:
```swift
let nums = [1, 2, 3, 4]
let product = nums.reduce(1) { $0 * $1 }
print(product) // 24
```
यहाँ `$0` `1` से शुरू होता है, फिर `1 * 1`, `1 * 2`, `2 * 3` और आखिर में `6 * 4` बनता है।
चूंकि `map`, `filter` और `reduce` सभी मान लौटाते हैं, इसलिए इन्हें जोड़ा जा सकता है: `nums.filter { $0 > 1 }.map { $0 * 10 }`.

---

`sorted(by:)` एक नया क्रमबद्ध ऐरे लौटाता है। क्लोजर दो एलिमेंट्स लेता है और `true` लौटाता है जब पहले वाले को दूसरे से **पहले** आना चाहिए:
```swift
let nums = [3, 1, 2]
print(nums.sorted { $0 < $1 }) // [1, 2, 3]
print(nums.sorted { $0 > $1 }) // [3, 2, 1]
```
क्लोजर किसी भी चीज़ की तुलना कर सकता है, उदाहरण के लिए `words.sorted { $0.count < $1.count }` स्ट्रिंग्स को सबसे छोटी से सबसे लंबी तक क्रम में लगाता है।
