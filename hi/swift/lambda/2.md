# --description--

क्लोजर के अंदर हर टाइप लिखना अक्सर ज़रूरी नहीं होता। जब कॉन्स्टेंट का एक स्पष्ट **फ़ंक्शन टाइप** होता है, तो Swift पैरामीटर और रिटर्न टाइप का अनुमान लगा लेता है, इसलिए आपको `in` से पहले सिर्फ़ पैरामीटर के नाम लिखने होते हैं:
```swift
let triple: (Int) -> Int = { n in
    return n * 3
}
```
टाइप `(Int) -> Int` को "एक फ़ंक्शन जो `Int` लेता है और `Int` लौटाता है" के रूप में पढ़ा जाता है।
जब बॉडी एक ही एक्सप्रेशन हो, तो `return` कीवर्ड को भी छोड़ा जा सकता है, इसे **इम्प्लिसिट रिटर्न** कहा जाता है:
```swift
let triple: (Int) -> Int = { n in n * 3 }
print(triple(4)) // 12
```
