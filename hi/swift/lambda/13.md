# --description--

किसी कॉन्स्टेंट में स्टोर किया गया क्लोजर, पैरामीटर के आर्ग्युमेंट लेबल का उपयोग करके, जहाँ भी क्लोजर आर्ग्युमेंट अपेक्षित हो वहाँ पास किया जा सकता है:
```swift
let ascending = { (a: Int, b: Int) -> Bool in a < b }
print([3, 1, 2].sorted(by: ascending)) // [1, 2, 3]
```

# --instructions--

आइटम्स को क्रम में लगाएं ताकि `byLength` में एक ऐसा क्लोजर स्टोर हो जो दो स्ट्रिंग्स को सबसे छोटी से सबसे लंबी तक क्रम में लगाए, फिर उसका उपयोग करके क्रमबद्ध किए गए `words` को प्रिंट करें।
`words` को `byLength` से पहले घोषित करें

```swift
let words = ["kiwi", "fig", "banana"]
let byLength = { (a: String, b: String) -> Bool in
    a.count < b.count
}
print(words.sorted(by: byLength))
```

# --output--

["fig", "kiwi", "banana"]
