# --description--

एक क्लोजर अपनी बॉडी के बाहर घोषित वेरिएबल्स का उपयोग कर सकता है। यह उन्हें **कैप्चर** करता है: वह वेरिएबल तब तक जीवित रहता है जब तक क्लोजर मौजूद है, भले ही उसे घोषित करने वाला फ़ंक्शन खत्म हो चुका हो।
इससे एक फ़ंक्शन अपनी खुद की प्राइवेट स्टेट वाला क्लोजर बना सकता है:
```swift
func makeCounter() -> () -> Int {
    var count = 0
    return {
        count += 1
        return count
    }
}
```
`() -> Int` उस क्लोजर का टाइप है जिसमें कोई पैरामीटर नहीं है और जो एक `Int` लौटाता है। लौटाए गए क्लोजर की हर कॉल उसी कैप्चर किए गए `count` को बढ़ाती है:
```swift
let counter = makeCounter()
print(counter()) // 1
print(counter()) // 2
```

# --instructions--
