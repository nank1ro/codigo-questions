# --description--

चूंकि क्लोजर मान होते हैं, इसलिए कोई फ़ंक्शन इसे पैरामीटर के रूप में स्वीकार कर सकता है। पैरामीटर का टाइप बस फ़ंक्शन टाइप होता है:
```swift
func apply(_ n: Int, _ operation: (Int) -> Int) -> Int {
    return operation(n)
}
print(apply(5, { $0 + 1 })) // 6
```
फ़ंक्शन `apply` को नहीं पता कि `operation` क्या करता है, उसे बस इतना पता है कि यह एक `Int` लेता है और एक `Int` लौटाता है, और वह इसे किसी भी अन्य फ़ंक्शन की तरह कॉल करता है।

# --instructions--

फ़ंक्शन `apply` को पूरा करें ताकि इसका दूसरा पैरामीटर एक `Int` लेने और `Int` लौटाने वाला क्लोजर हो, और फ़ंक्शन उस क्लोजर को `n` पर कॉल करने का परिणाम लौटाए, जिससे प्रोग्राम `12` प्रिंट करे
