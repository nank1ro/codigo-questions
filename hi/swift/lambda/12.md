# --description--

क्लोजर लौटाना कस्टमाइज़्ड फ़ंक्शन बनाने का एक सुविधाजनक तरीका है। बाहरी फ़ंक्शन के पैरामीटर उस क्लोजर द्वारा कैप्चर कर लिए जाते हैं जिसे वह लौटाता है:
```swift
func makeAdder(_ amount: Int) -> (Int) -> Int {
    return { $0 + amount }
}
let addFive = makeAdder(5)
print(addFive(10)) // 15
```
रिटर्न टाइप `(Int) -> Int` उस क्लोजर का वर्णन करता है, और शॉर्टहैंड `$0` `makeAdder` के आर्ग्युमेंट को नहीं, बल्कि उस क्लोजर के आर्ग्युमेंट को संदर्भित करता है।

# --instructions--

एक फ़ंक्शन `makeMultiplier` लिखें जो `factor` नाम का एक `Int` लेता है (आर्ग्युमेंट लेबल छोड़ दें) और `(Int) -> Int` टाइप का एक क्लोजर लौटाता है जो अपने आर्ग्युमेंट को `factor` से गुणा करता है

फ़ंक्शन कॉल का उदाहरण:
```swift
let double = makeMultiplier(2)
print(double(10))
// prints 20
```
