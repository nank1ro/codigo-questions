# --description--

एक ही `if let` या `guard let` कई ऑप्शनल्स को एक साथ अनरैप कर सकता है: बाइंडिंग्स को कॉमा से अलग करें।
बॉडी तभी चलती है जब हर ऑप्शनल में कोई मान हो:
```swift
let first: String? = "Ada"
let last: String? = "Lovelace"
if let first = first, let last = last {
    print("\(first) \(last)")
}
```
आप बाइंडिंग्स के बाद एक बूलियन शर्त भी जोड़ सकते हैं, जैसे `if let n = number, n > 0`।
