# --description--

कभी-कभी कोई मान बस मौजूद नहीं होता: बिना मध्य नाम वाला उपयोगकर्ता, ऐसी खोज जिसे कुछ नहीं मिलता, या ऐसा टेक्स्ट जिसे संख्या में नहीं बदला जा सकता।
Swift एक अनुपस्थित मान को `nil` से दर्शाता है, लेकिन एक सामान्य वेरिएबल इसे कभी नहीं रख सकता:
```swift
var age: Int = nil // error: 'nil' cannot initialize type 'Int'
```
किसी अनुपस्थित मान की अनुमति देने के लिए आप टाइप के बाद प्रश्न चिह्न `?` जोड़कर एक **ऑप्शनल** टाइप घोषित करते हैं।
एक `Int?` या तो `Int` या `nil` रखता है:
```swift
var age: Int? = 30
age = nil // अनुमत
```
बिना मान के घोषित किया गया ऑप्शनल वेरिएबल `nil` से शुरू होता है।
