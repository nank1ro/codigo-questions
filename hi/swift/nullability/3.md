# --description--

एक ऑप्शनल एक डिब्बे की तरह है: अंदर के मान का उपयोग करने से पहले आपको उसे खोलना होता है, जिसे Swift **अनरैपिंग** कहता है।
सबसे तेज़ तरीका है विस्मयादिबोधक चिह्न `!` के साथ **फोर्स्ड अनरैपिंग**:
```swift
let score: Int? = 10
print(score! + 5) // 15
```
`!` Swift को बताता है "मुझे यकीन है कि यहाँ एक मान मौजूद है"। यदि आप गलत हैं और ऑप्शनल `nil` है, तो प्रोग्राम तुरंत एक रनटाइम क्रैश के साथ रुक जाता है:
```swift
let missing: Int? = nil
print(missing! + 5) // Fatal error: Unexpectedly found nil
```
इसीलिए फोर्स्ड अनरैपिंग को खतरनाक माना जाता है: इसका उपयोग केवल तभी करें जब आपको यकीन हो कि मान मौजूद है।

# --instructions--

जब आप `nil` रखने वाले किसी ऑप्शनल को फोर्स्ड अनरैप करते हैं तो क्या होता है?

# --answers--

- प्रोग्राम रनटाइम पर क्रैश हो जाता है
- अभिव्यक्ति का मूल्यांकन 0 के रूप में होता है
- कंपाइलर एक त्रुटि रिपोर्ट करता है
- मान चुपचाप एक खाली स्ट्रिंग में बदल जाता है
