# --description--

जब किसी अनुपस्थित मान का अर्थ है "यहीं रुक जाओ", तो `guard let`, `if let` से अधिक स्पष्ट है।
यह ऑप्शनल को अनरैप करता है और, यदि वह विफल होता है, तो `else` ब्लॉक चलाता है, जिसे वर्तमान स्कोप से बाहर निकलना होता है (`return`, `break`, `continue` या `throw` के साथ):
```swift
func greet(_ name: String?) {
    guard let name = name else {
        print("Nobody here")
        return
    }
    print("Hello, \(name)!") // यहाँ से आगे name एक String है
}
```
`if let` के विपरीत, अनरैप किया गया कॉन्स्टेंट फ़ंक्शन के बाकी हिस्से के लिए उपलब्ध रहता है, इसलिए मुख्य पथ को `if` के अंदर नेस्ट नहीं किया जाता।
