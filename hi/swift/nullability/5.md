# --description--

`nil` की जाँच करना और फिर फोर्स्ड अनरैप करना अधिक लंबा है। Swift `if let` के साथ **ऑप्शनल बाइंडिंग** प्रदान करता है, जो एक ही चरण में ऑप्शनल को अनरैप करता है और मान को एक नए कॉन्स्टेंट में संग्रहीत करता है:
```swift
let score: Int? = 10
if let value = score {
    print("Score: \(value)") // value एक Int है, Int? नहीं
} else {
    print("No score")
}
```
`if` का बॉडी केवल तभी चलता है जब ऑप्शनल में कोई मान हो; इसके अंदर `value` एक सामान्य `Int` है, `Int?` नहीं, और इसके लिए `!` की आवश्यकता नहीं है।

# --instructions--

एक फ़ंक्शन `describe` लिखें जो एक `Int?` (आर्ग्युमेंट लेबल छोड़ दें) लेता है और `"Value: "` के बाद संख्या (उदाहरण के लिए `5` के लिए `"Value: 5"`) लौटाता है जब ऑप्शनल में कोई मान हो, या `"No value"` लौटाता है जब यह `nil` हो

func describe(_ number: Int?) -> String {
    if let value = number {
        return "Value: \(value)"
    } else {
        return "No value"
    }
}
