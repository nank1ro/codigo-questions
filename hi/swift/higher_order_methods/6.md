# --description--

`contains(where:)` और `allSatisfy` फ्लैग वेरिएबल वाले लूप के सामान्य पैटर्न की जगह लेते हैं। दोनों जैसे ही जवाब पता चल जाता है रुक जाते हैं: `contains(where:)` पहली मैच पर, `allSatisfy` पहले विफल होने वाले एलिमेंट पर।
```swift
let ages = [15, 22, 40]
let anyMinor = ages.contains { $0 < 18 }  // true
let allAdults = ages.allSatisfy { $0 >= 18 } // false
```
`contains { ... }` `contains(where:)` का ट्रेलिंग क्लोजर रूप है, इसे `contains(_:)` से न मिलाएं, जो एक विशिष्ट मान ढूंढता है।
