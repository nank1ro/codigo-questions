# --description--

हायर-ऑर्डर फ़ंक्शन किसी भी ऐरे पर काम करते हैं, जिनमें आपके अपने स्ट्रक्ट्स के ऐरे भी शामिल हैं। कुछ एलिमेंट्स चुनने और हर एक से एक मान निकालने का सामान्य तरीका है पहले `filter` और फिर `map` को श्रृंखलाबद्ध करना:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
इसे उलटे क्रम में करने पर, पहले `map` फिर `filter`, जाँच का उपयोग करने से पहले ही `pages` प्रॉपर्टी खो जाएगी।

# --instructions--

स्ट्रक्ट `Product` दिया गया है। एक फ़ंक्शन `cheapNames` लिखें जो `Product` का एक ऐरे (आर्ग्युमेंट लेबल छोड़ दें) लेता है और उन प्रोडक्ट्स के नाम लौटाता है जिनकी `price` `10` से कम है, मूल क्रम में, `filter` और `map` को श्रृंखलाबद्ध करके

फ़ंक्शन कॉल का उदाहरण:
```swift
print(cheapNames([Product(name: "Pen", price: 2.5), Product(name: "Bag", price: 30)]))
// prints ["Pen"]
```

struct Product {
    var name: String
    var price: Double
}
func cheapNames(_ products: [Product]) -> [String] {
    return products.filter { $0.price < 10 }.map { $0.name }
}
