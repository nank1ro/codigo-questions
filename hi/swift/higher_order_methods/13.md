# --description--

`Dictionary(grouping:by:)` एक कलेक्शन को ऐरे की एक डिक्शनरी में बाँट देता है। क्लोजर हर एलिमेंट की **कुंजी** गणना करता है, और समान कुंजी वाले सभी एलिमेंट्स उसी ऐरे में आ जाते हैं:
```swift
let words = ["apple", "bee", "avocado"]
let byInitial = Dictionary(grouping: words, by: { $0.first! })
print(byInitial["a"]!) // ["apple", "avocado"]
```
`mapValues` डिक्शनरी के हर मान को कुंजियाँ बनाए रखते हुए बदलता है, इसलिए यह ग्रुपिंग के बाद स्वाभाविक अगला कदम है:
```swift
let sizes = byInitial.mapValues { $0.count }
print(sizes["a"]!) // 2
```

# --instructions--

एक फ़ंक्शन `countByLength` लिखें जो `String` का एक ऐरे (आर्ग्युमेंट लेबल छोड़ दें) लेता है और `[Int: Int]` टाइप की एक डिक्शनरी लौटाता है जो हर शब्द लंबाई को उतनी लंबाई वाले शब्दों की संख्या से मैप करती है, `Dictionary(grouping:by:)` और `mapValues` का उपयोग करके

फ़ंक्शन कॉल का उदाहरण:
```swift
print(countByLength(["hi", "yo", "hey"])[2]!)
// prints 2
```

```swift
func countByLength(_ words: [String]) -> [Int: Int] {
    return Dictionary(grouping: words, by: { $0.count }).mapValues { $0.count }
}
```
