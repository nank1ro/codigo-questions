एक **हायर-ऑर्डर फ़ंक्शन** ऐसा फ़ंक्शन होता है जो दूसरे फ़ंक्शन को आर्ग्युमेंट के रूप में लेता है, एक फ़ंक्शन लौटाता है, या दोनों करता है। आप पहले से `map`, `filter`, `reduce` और `sorted(by:)` से मिल चुके हैं: ये एक क्लोजर लेते हैं और उसे किसी कलेक्शन के एलिमेंट्स पर लागू करते हैं। Swift में इनसे भी बहुत सारे हैं, और इन्हें जानने से आप लंबे लूप्स को एक पढ़ने योग्य लाइन से बदल सकते हैं।
`compactMap` `map` की तरह काम करता है, लेकिन क्लोजर एक ऑप्शनल लौटाता है और `nil` परिणाम हटा दिए जाते हैं:
```swift
let words = ["3", "seven", "12"]
let numbers = words.compactMap { Int($0) }
print(numbers) // [3, 12]
```
`Int("seven")` का मान `nil` है, इसलिए वह एलिमेंट गायब हो जाता है और परिणाम एक `[Int]` होता है, `[Int?]` नहीं।

---

`flatMap` उन क्लोजर्स के लिए है जो एक **ऐरे** लौटाते हैं: ऐरे का ऐरे बनाने की जगह, यह सभी लौटाए गए ऐरे को एक फ्लैट परिणाम में जोड़ देता है:
```swift
let teams = [["Ann", "Bob"], ["Cid"]]
print(teams.map { $0 })     // [["Ann", "Bob"], ["Cid"]]
print(teams.flatMap { $0 }) // ["Ann", "Bob", "Cid"]
```
क्लोजर फ्लैट होने से पहले हर इनर ऐरे को बदल भी सकता है, उदाहरण के लिए `teams.flatMap { $0.reversed() }` का परिणाम `["Bob", "Ann", "Cid"]` होता है।

---

तीनों `map` वेरिएंट्स सिर्फ़ इस बात में अलग हैं कि क्लोजर क्या लौटाता है:
- `map`: कोई भी मान, प्रत्येक एलिमेंट के लिए एक परिणाम
- `compactMap`: एक ऑप्शनल, `nil` परिणाम हटा दिए जाते हैं
- `flatMap`: एक ऐरे, सभी परिणाम एक ऐरे में जुड़ जाते हैं

`flatMap` को दिया गया क्लोजर खुद इनर ऐरे पर `map` को कॉल कर सकता है, एक ट्रांसफॉर्मेशन को दूसरे के अंदर नेस्ट करते हुए:
```swift
let matrix = [[1, 2], [3]]
print(matrix.flatMap { row in row.map { $0 + 1 } }) // [2, 3, 4]
```

---

`reduce` हर स्टेप पर एक नया संचित मान बनाता है, जो तब बर्बादी है जब परिणाम एक ऐरे या डिक्शनरी हो। `reduce(into:)` क्लोजर को एक्यूम्युलेटर एक `inout` पैरामीटर के रूप में देता है, ताकि उसे बिना `return` के अपनी जगह पर संशोधित किया जा सके:
```swift
let words = ["a", "b", "a"]
let counts = words.reduce(into: [String: Int]()) { result, word in
    result[word, default: 0] += 1
}
print(counts["a"]!) // 2
```
`[String: Int]()` एक खाली डिक्शनरी बनाता है, और `result[word, default: 0]` वर्तमान गिनती पढ़ता है या कुंजी न मिलने पर `0`।

---

कुछ हायर-ऑर्डर फ़ंक्शन कलेक्शन को बदलने की जगह उसके बारे में एक सवाल का जवाब देते हैं। ये सभी एक ऐसा क्लोजर लेते हैं जो `Bool` लौटाता है:
- `first(where:)` पहला एलिमेंट लौटाता है जो क्लोजर को संतुष्ट करता है, या कोई न होने पर `nil`
- `contains(where:)` `true` लौटाता है यदि कम से कम एक एलिमेंट इसे संतुष्ट करता है
- `allSatisfy` `true` लौटाता है यदि हर एलिमेंट इसे संतुष्ट करता है

```swift
let nums = [4, 9, 16]
print(nums.first(where: { $0 > 5 }))  // Optional(9)
print(nums.contains(where: { $0 > 5 })) // true
print(nums.allSatisfy { $0 > 5 })       // false
```
`filter` के विपरीत, `first(where:)` पहली मैच पर रुक जाता है और कोई नया ऐरे नहीं बनाता।

---

`contains(where:)` और `allSatisfy` फ्लैग वेरिएबल वाले लूप के सामान्य पैटर्न की जगह लेते हैं। दोनों जैसे ही जवाब पता चल जाता है रुक जाते हैं: `contains(where:)` पहली मैच पर, `allSatisfy` पहले विफल होने वाले एलिमेंट पर।
```swift
let ages = [15, 22, 40]
let anyMinor = ages.contains { $0 < 18 }  // true
let allAdults = ages.allSatisfy { $0 >= 18 } // false
```
`contains { ... }` `contains(where:)` का ट्रेलिंग क्लोजर रूप है, इसे `contains(_:)` से न मिलाएं, जो एक विशिष्ट मान ढूंढता है।

---

हायर-ऑर्डर फ़ंक्शन किसी भी ऐरे पर काम करते हैं, जिनमें आपके अपने स्ट्रक्ट्स के ऐरे भी शामिल हैं। कुछ एलिमेंट्स चुनने और हर एक से एक मान निकालने का सामान्य तरीका है पहले `filter` और फिर `map` को श्रृंखलाबद्ध करना:
```swift
struct Book {
    var title: String
    var pages: Int
}
let books = [Book(title: "Dune", pages: 412), Book(title: "Haiku", pages: 40)]
let long = books.filter { $0.pages > 100 }.map { $0.title }
print(long) // ["Dune"]
```
इसे उलटे क्रम में करने पर, पहले `map` फिर `filter`, जाँच का उपयोग करने से पहले ही `pages` प्रॉपर्टी खो जाएगी।

---

जब कोई क्लोजर केवल एक प्रॉपर्टी पढ़ता है, तो आप इसकी जगह एक **की पाथ** पास कर सकते हैं: `\.name` का अर्थ है "एलिमेंट की `name` प्रॉपर्टी", और `map(\.name)` वही है जो `map { $0.name }` है।
किसी प्रॉपर्टी के आधार पर सॉर्ट करना सामान्य दो-आर्ग्युमेंट क्लोजर का उपयोग करता है, जो दोनों एलिमेंट्स पर उस प्रॉपर्टी की तुलना करता है:
```swift
struct City {
    var name: String
    var population: Int
}
let cities = [City(name: "Oslo", population: 700), City(name: "Rome", population: 2800)]
let byPopulation = cities.sorted { $0.population > $1.population }
print(byPopulation.map(\.name)) // ["Rome", "Oslo"]
```

---

**एक से अधिक मानदंडों** के आधार पर सॉर्ट करने के लिए, पहली प्रॉपर्टी की तुलना करें और केवल तब दूसरी पर लौटें जब पहले मान बराबर हों:
```swift
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age < $1.age
    }
    return $0.name < $1.name
}
```
यहाँ लोग आयु के अनुसार क्रमबद्ध हैं, और समान आयु वाले लोग नाम के अनुसार क्रमबद्ध हैं। क्लोजर को `true` केवल तब लौटाना चाहिए जब पहला एलिमेंट दूसरे से पहले आना चाहिए, ताकि बराबर होने की स्थिति अगली तुलना तक जाती है।

---

`enumerated()` एक ऐरे को `(offset, element)` जोड़े की एक सीक्वेंस में बदल देता है, ताकि कोई क्लोजर हर एलिमेंट की स्थिति का उपयोग उसके मान के साथ कर सके:
```swift
let steps = ["mix", "bake"]
let numbered = steps.enumerated().map { pair in
    "\(pair.offset + 1). \(pair.element)"
}
print(numbered) // ["1. mix", "2. bake"]
```
चूंकि हर जोड़ा एक टपल है, क्लोजर उसे डिस्ट्रक्चर भी कर सकता है: `.map { (i, step) in "\(i + 1). \(step)" }`।

---

`zip` दो सीक्वेंस के एलिमेंट्स को स्थिति दर स्थिति जोड़े में बाँधता है, जिससे टपल की एक सीक्वेंस बनती है। यह छोटे सीक्वेंस के अंत पर रुक जाता है:
```swift
let names = ["Ann", "Bob"]
let ages = [31, 27, 99]
let pairs = zip(names, ages).map { "\($0) is \($1)" }
print(pairs) // ["Ann is 31", "Bob is 27"]
```
क्लोजर के अंदर `$0` पहली सीक्वेंस का एलिमेंट है और `$1` दूसरी सीक्वेंस का। `zip` एक फ्री फ़ंक्शन है, मेथड नहीं: आप `zip(a, b)` लिखते हैं, `a.zip(b)` नहीं।

---

`forEach` `for-in` लूप का हायर-ऑर्डर जुड़वां है: यह क्लोजर को क्रम में, प्रत्येक एलिमेंट के लिए एक बार कॉल करता है। अंतर लूप से बाहर निकलने के तरीके में है। `for-in` में आप `break` करके बाहर निकल सकते हैं या `continue` कर सकते हैं; `forEach` क्लोजर के अंदर `break` और `continue` की अनुमति नहीं है, और `return` केवल क्लोजर का **वर्तमान कॉल** समाप्त करता है, फिर अगला एलिमेंट अपने आम तौर पर प्रोसेस होता है:
```swift
[1, 2, 3].forEach { n in
    if n == 2 { return }
    print(n)
}
// prints 1 and 3
```
हर एलिमेंट पर एक छोटे साइड इफ़ेक्ट के लिए `forEach` का उपयोग करें, और `for-in` का तब जब आपको जल्दी रुकना हो।

---

`Dictionary(grouping:by:)` एक कलेक्शन को ऐरे की एक डिक्शनरी में बाँट देता है। क्लोजर हर एलिमेंट की **कुंजी** गणना करता है, और समान कुंजी वाले सभी एलिमेंट्स उसी ऐरे में आ जाते हैं:
```swift
let words = ["apple", "bee", "avocado"]
let byInitial = Dictionary(grouping: words, by: { $0.first! })
print(byInitial["a"]!) // ["apple", "avocado"]
```
`mapValues` डिक्शनरी के हर मान को कुंजियाँ बनाए रखते हुए बदलता है, इसलिए यह ग्रुपिंग के बाद स्वाभाविक अगला कदम है:
```swift
let sizes = byInitial.mapValues { $0.count }
print(sizes["a"]!) // 2
```

---

`prefix(while:)` शुरुआत से एलिमेंट्स तब तक लेता है **जब तक** क्लोजर `true` लौटाता है, और पहले विफल होने वाले एलिमेंट पर रुक जाता है, भले ही बाद के एलिमेंट दोबारा पास हो सकते हों। `drop(while:)` इसका पूरक है: यह वही शुरुआती रन छोड़ देता है और बाकी सब कुछ लौटाता है:
```swift
let temps = [12, 15, 21, 14]
print(temps.prefix { $0 < 20 }) // [12, 15]
print(temps.drop { $0 < 20 })   // [21, 14]
```
दोनों एक `ArraySlice` लौटाते हैं, जो मूल ऐरे का एक व्यू है जो ऐरे की तरह प्रिंट होता है और जिसे `Array(...)` से ऐरे में बदला जा सकता है।

---

आप अपने हायर-ऑर्डर फ़ंक्शन खुद लिख सकते हैं। एक क्लोजर लेने वाला और उससे बना **एक नया क्लोजर लौटाने** वाला फ़ंक्शन एक सामान्य पैटर्न है: लौटाया गया क्लोजर मूल क्लोजर को कैप्चर करता है, इसलिए पैरामीटर `@escaping` होना चाहिए।
उदाहरण के लिए, `negate` एक प्रेडिकेट को उसके विपरीत में बदल देता है, `filter` को पास करने के लिए तैयार:
```swift
func negate(_ predicate: @escaping (Int) -> Bool) -> (Int) -> Bool {
    return { !predicate($0) }
}
let isEven: (Int) -> Bool = { $0 % 2 == 0 }
print([1, 2, 3, 4].filter(negate(isEven))) // [1, 3]
```
ध्यान दें कि `filter(negate(isEven))` क्लोजर को एक सामान्य आर्ग्युमेंट के रूप में पास करता है, बिना ट्रेलिंग क्लोजर सिंटैक्स के।

---

ऐरे पर `map` और `filter` **ईगर** होते हैं: हर एक पूरा ऐरे प्रोसेस करता है और अगला स्टेप चलने से पहले एक नया बनाता है। एक बड़े कलेक्शन पर, या जब आपको केवल पहला परिणाम चाहिए, यह बर्बाद काम है।
`lazy` प्रॉपर्टी एक ऐसा व्यू लौटाती है जिसके ऑपरेशन्स केवल तब चलते हैं जब किसी एलिमेंट को वास्तव में माँगा जाता है, पूरी श्रृंखला में एक बार में एक एलिमेंट:
```swift
let firstBig = (1...1000).lazy.map { $0 * $0 }.first { $0 > 50 }
print(firstBig!) // 64
```
यहाँ केवल `1, 2, ..., 8` के वर्ग किए जाते हैं: `first(where:)` तब तक एलिमेंट्स माँगता है जब तक कोई एक शर्त को संतुष्ट न कर दे, और श्रृंखला वहीं रुक जाती है। `lazy` के बिना, `map` पहले सभी 1000 संख्याओं के वर्ग करता।
