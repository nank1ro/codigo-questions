# --description--

`prefix(while:)` शुरुआत से एलिमेंट्स तब तक लेता है **जब तक** क्लोजर `true` लौटाता है, और पहले विफल होने वाले एलिमेंट पर रुक जाता है, भले ही बाद के एलिमेंट दोबारा पास हो सकते हों। `drop(while:)` इसका पूरक है: यह वही शुरुआती रन छोड़ देता है और बाकी सब कुछ लौटाता है:
```swift
let temps = [12, 15, 21, 14]
print(temps.prefix { $0 < 20 }) // [12, 15]
print(temps.drop { $0 < 20 })   // [21, 14]
```
दोनों एक `ArraySlice` लौटाते हैं, जो मूल ऐरे का एक व्यू है जो ऐरे की तरह प्रिंट होता है और जिसे `Array(...)` से ऐरे में बदला जा सकता है।
