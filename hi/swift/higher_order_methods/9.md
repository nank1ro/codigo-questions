# --description--

**एक से अधिक मानदंडों** के आधार पर सॉर्ट करने के लिए, पहली प्रॉपर्टी की तुलना करें और केवल तब दूसरी पर लौटें जब पहले मान बराबर हों:
```swift
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age < $1.age
    }
    return $0.name < $1.name
}
```
यहाँ लोग आयु के अनुसार क्रमबद्ध हैं, और समान आयु वाले लोग नाम के अनुसार क्रमबद्ध हैं। क्लोजर को `true` केवल तब लौटाना चाहिए जब पहला एलिमेंट दूसरे से पहले आना चाहिए, ताकि बराबर होने की स्थिति अगली तुलना तक जाती है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```swift
struct Person {
    var name: String
    var age: Int
}
let people = [Person(name: "Zed", age: 30), Person(name: "Amy", age: 25), Person(name: "Bea", age: 30)]
let sorted = people.sorted {
    if $0.age != $1.age {
        return $0.age > $1.age
    }
    return $0.name < $1.name
}
print(sorted.map(\.name))
```
