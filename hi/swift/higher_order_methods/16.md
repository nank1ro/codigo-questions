# --description--

ऐरे पर `map` और `filter` **ईगर** होते हैं: हर एक पूरा ऐरे प्रोसेस करता है और अगला स्टेप चलने से पहले एक नया बनाता है। एक बड़े कलेक्शन पर, या जब आपको केवल पहला परिणाम चाहिए, यह बर्बाद काम है।
`lazy` प्रॉपर्टी एक ऐसा व्यू लौटाती है जिसके ऑपरेशन्स केवल तब चलते हैं जब किसी एलिमेंट को वास्तव में माँगा जाता है, पूरी श्रृंखला में एक बार में एक एलिमेंट:
```swift
let firstBig = (1...1000).lazy.map { $0 * $0 }.first { $0 > 50 }
print(firstBig!) // 64
```
यहाँ केवल `1, 2, ..., 8` के वर्ग किए जाते हैं: `first(where:)` तब तक एलिमेंट्स माँगता है जब तक कोई एक शर्त को संतुष्ट न कर दे, और श्रृंखला वहीं रुक जाती है। `lazy` के बिना, `map` पहले सभी 1000 संख्याओं के वर्ग करता।

# --instructions--

एक फ़ंक्शन `firstCubeAbove` लिखें जो `limit` नाम का एक `Int` (आर्ग्युमेंट लेबल छोड़ दें) लेता है और रेंज `1...limit + 1` पर `lazy` और `map` तथा `first(where:)` का उपयोग करके `limit` से बड़ा सबसे छोटा घन (`n` के `1` से शुरू होने पर `n * n * n`) लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(firstCubeAbove(10))
// prints 27
```

```swift
func firstCubeAbove(_ limit: Int) -> Int {
    return (1...limit + 1).lazy.map { $0 * $0 * $0 }.first(where: { $0 > limit })!
}
```
