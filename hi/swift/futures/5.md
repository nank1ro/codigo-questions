# --description--

जब आपको परवाह न हो कि कॉल *क्यों* विफल हुई, तब `try?` एक `do` ब्लॉक से छोटा होता है। यह एक throwing कॉल को **ऑप्शनल** में बदल देता है: सफलता पर मान, विफलता पर `nil`। `await` के साथ मिलाकर इसे `try? await` लिखा जाता है:
```swift
let value = try? await parse("42")  // Optional(42)
let broken = try? await parse("x")  // nil
```
क्योंकि परिणाम ऑप्शनल है, यह सीधे एक `if let` में फिट हो जाता है:
```swift
if let value = try? await parse("x") {
    print(value)
} else {
    print("not a number")
}
```
किसी तुरंत फ़ॉलबैक के लिए `try? await` का उपयोग करें, और `do` / `catch` का उपयोग तब करें जब एरर खुद मायने रखता है।
