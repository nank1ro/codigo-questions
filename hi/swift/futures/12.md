# --description--

`async let` तब काम करता है जब आपको कोड लिखते समय पता हो कि कितनी कॉल्स हैं। किसी ऐसी लिस्ट के लिए जिसका आकार केवल रन टाइम पर पता चलता है, एक **टास्क ग्रुप** का उपयोग करें।

`withTaskGroup(of:)` एक ग्रुप खोलता है, `addTask` हर आइटम के लिए एक चाइल्ड टास्क शुरू करता है, और फिर ग्रुप को `for await` से पढ़ा जाता है, जो परिणामों को उनके पूरा होते ही देता है:
```swift
let total = await withTaskGroup(of: Int.self) { group in
    for n in numbers {
        group.addTask {
            return await square(n)
        }
    }
    var sum = 0
    for await value in group {
        sum += value
    }
    return sum
}
```
`of: Int.self` घोषित करता है कि हर चाइल्ड टास्क क्या लौटाता है। पूरा `withTaskGroup` कॉल एक एक्सप्रेशन है, इसलिए उसके आगे एक ही `await` चाहिए, और वह तब तक लौटता नहीं जब तक हर चाइल्ड टास्क पूरा न हो जाए।

# --solutions--

```swift
func square(_ n: Int) async -> Int {
    return n * n
}

func sumOfSquares(_ numbers: [Int]) async -> Int {
    return await withTaskGroup(of: Int.self) { group in
        for n in numbers {
            group.addTask {
                return await square(n)
            }
        }
        var total = 0
        for await value in group {
            total += value
        }
        return total
    }
}
```
