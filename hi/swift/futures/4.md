# --description--

समय के साथ होने वाला काम अक्सर विफल होता है: सर्वर डाउन है, कोई फ़ाइल गायब है, इनपुट गलत है। ऐसे फ़ंक्शन को **`async throws`** से चिह्नित किया जाता है, और उसे **`try await`** के साथ कॉल किया जाता है:
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
एरर को संभालने के लिए आप कॉल को एक `do` ब्लॉक में लपेटकर उसे कैच करते हैं:
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// could not load प्रिंट करता है
```
कीवर्ड्स का क्रम तय है: `try` पहले आता है, फिर `await`।

# --instructions--

एक फ़ंक्शन `parse` लिखें जो बिना आर्ग्युमेंट लेबल एक स्ट्रिंग लेता है, एसिंक्रोनस है, throw कर सकता है, और स्ट्रिंग को `Int` में बदलकर लौटाता है। अगर स्ट्रिंग कोई संख्या नहीं है, तो `InputError.notANumber` throw करें

फ़ंक्शन कॉल का उदाहरण:
```swift
print(try await parse("7"))
// 7 प्रिंट करता है
```

# --solutions--

```swift
enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
```
