# --description--

एक एसिंक्रोनस फ़ंक्शन अब भी एक साधारण फ़ंक्शन ही है: यह पैरामीटर ले सकता है और किसी भी टाइप का मान लौटा सकता है। सिर्फ़ दो चीज़ें बदलती हैं, सिग्नेचर में `async` कीवर्ड और हर कॉल साइट पर `await`:
```swift
func price(of quantity: Int) async -> Double {
    return Double(quantity) * 2.5
}

let total = await price(of: 4)
print(total)
// 10.0 प्रिंट करता है
```
लौटाया गया मान एक सामान्य `Double` है, कोई रैपर नहीं: `await` के पूरा होने के बाद आप इसके साथ बिल्कुल पहले की तरह काम करते हैं।

# --instructions--

एक फ़ंक्शन `double` लिखें जो बिना आर्ग्युमेंट लेबल एक पूर्णांक लेता है, एसिंक्रोनस है, और उस संख्या का दोगुना लौटाता है

फ़ंक्शन कॉल का उदाहरण:
```swift
print(await double(4))
// 8 प्रिंट करता है
```
