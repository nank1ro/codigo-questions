# --description--

कुछ काम तुरंत पूरे नहीं होते: कोई फ़ाइल डाउनलोड करना, डेटाबेस से पढ़ना, किसी टाइमर का इंतज़ार करना। अगर प्रोग्राम बस रुककर इंतज़ार करता, तो इस बीच कुछ और नहीं हो सकता था। Swift इसका समाधान **एसिंक्रोनस फ़ंक्शन्स** से करता है।

**`async`** से चिह्नित फ़ंक्शन बीच में रुकने और बाद में फिर से शुरू होने की अनुमति रखता है। यह कीवर्ड पैरामीटर लिस्ट के बाद, एरो से पहले आता है:
```swift
func fetchNumber() async -> Int {
    return 42
}
```
इसे कॉल करना भी अलग है: आपको कॉल के आगे **`await`** लिखना होता है। `await` वह सटीक जगह दर्शाता है जहाँ प्रोग्राम रुक सकता है, और फ़ंक्शन के पूरा होने पर आपको सादा मान दे देता है:
```swift
let n = await fetchNumber()
print(n)
// prints 42
```
Swift स्क्रिप्ट में टॉप लेवल पहले से `await` को सपोर्ट करता है, इसलिए आप बिना किसी अतिरिक्त सेटअप के सीधे एसिंक्रोनस फ़ंक्शन्स को कॉल कर सकते हैं। `async` या `await` भूलना एक कंपाइल एरर है, कोई चुपचाप चलता बग नहीं।
