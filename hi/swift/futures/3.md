# --description--

एसिंक्रोनस फ़ंक्शन्स आम तौर पर एक-दूसरे के ऊपर बने होते हैं। किसी `async` फ़ंक्शन के अंदर आप किसी भी दूसरे `async` फ़ंक्शन को `await` कर सकते हैं, और परिणाम किसी सामान्य मान की तरह ही उपयोग होता है:
```swift
func base() async -> Int {
    return 10
}

func withBonus() async -> Int {
    let value = await base()
    return value + 5
}

print(await withBonus())
// 15 प्रिंट करता है
```
`await` केवल एक एसिंक्रोनस कॉन्टेक्स्ट के अंदर ही अनुमत है: कोई `async` फ़ंक्शन, या स्क्रिप्ट का टॉप लेवल। एक साधारण, गैर-`async` फ़ंक्शन कुछ भी `await` नहीं कर सकता।

# --instructions--

यह कोड क्या प्रिंट करता है?
```swift
func first() async -> Int {
    return 10
}

func second() async -> Int {
    let base = await first()
    return base + 5
}

print(await second())
```
