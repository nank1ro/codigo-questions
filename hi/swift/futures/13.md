# --description--

एक टास्क ग्रुप परिणाम **पूरा होने के क्रम (completion order)** में देता है, न कि उस क्रम में जिसमें टास्क्स जोड़े गए थे। सबसे तेज़ चाइल्ड टास्क पहले आता है, इसलिए मानों को एक ऐरे में इकट्ठा करने पर क्रम अप्रत्याशित मिलता है।

जब क्रम मायने रखता है तो दो उपाय हैं। अगर मानों को बस दोबारा क्रमित किया जा सकता है, तो अंत में उन्हें सॉर्ट करें:
```swift
return values.sorted()
```
अगर हर परिणाम एक स्थान से जुड़ा है, तो हर टास्क को एक जोड़ा `(index, value)` लौटाने दें और उसे एक तैयार ऐरे में लिखें:
```swift
for (index, word) in words.enumerated() {
    group.addTask {
        return (index, await lengthOf(word))
    }
}
var result = Array(repeating: 0, count: words.count)
for await (index, value) in group {
    result[index] = value
}
```
एक योग, अधिकतम मान या गिनती को किसी उपाय की ज़रूरत नहीं, क्योंकि मानों का क्रम उत्तर नहीं बदलता।

func square(_ n: Int) async -> Int {

}

let results = await withTaskGroup(of: Int.self) { group in

        }
