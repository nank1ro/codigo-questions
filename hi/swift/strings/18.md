# --description--

`Character`, `String` नहीं होता, इसलिए इसे सीधे `+` से किसी स्ट्रिंग में नहीं जोड़ा जा सकता। पहले इसे `String(...)` से बदलें:
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
इसे `for`-`in` लूप के साथ मिलाने पर आप एक-एक वर्ण करके स्ट्रिंग को फिर से बना सकते हैं, जैसे हर नए वर्ण को अब तक इकट्ठे किए गए वर्णों के आगे रखकर।
