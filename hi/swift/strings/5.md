# --description--

`String`, `Character` मानों का एक कलेक्शन है। `Character` एक अकेला अक्षर, अंक, प्रतीक या स्पेस होता है, और इसे स्ट्रिंग जैसे ही दोहरे उद्धरण चिह्नों में लिखा जाता है, इसलिए इसे पाने के लिए टाइप एनोटेशन ज़रूरी है:
```swift
let letter: Character = "a"
let text = "abc"
print(text.count) // 3
```
`count` की तुलना `0` से करने के बजाय `isEmpty` जांचना बेहतर माना जाता है: यह पढ़ने में बेहतर है और इसके लिए हर वर्ण गिनने की ज़रूरत नहीं होती।

# --instructions--

एक फंक्शन `length` लिखें जो एक `String` ले (आर्गुमेंट लेबल छोड़ें) और उसके वर्णों की संख्या लौटाए, और एक फंक्शन `hasText` लिखें जो एक `String` ले (आर्गुमेंट लेबल छोड़ें) और `true` तभी लौटाए जब स्ट्रिंग खाली न हो

# --solutions--

```swift
func length(_ text: String) -> Int {
    return text.count
}

func hasText(_ text: String) -> Bool {
    return !text.isEmpty
}
```
