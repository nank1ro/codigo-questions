# --description--

चूँकि स्ट्रिंग वर्णों का एक कलेक्शन है, आप इस पर `for`-`in` लूप से पुनरावृत्ति कर सकते हैं। हर पुनरावृत्ति में आपको एक `Character` मिलता है:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
`Character` की तुलना `==` से किसी कैरेक्टर लिटरल के साथ की जा सकती है, इसलिए यह गिनना कि कोई वर्ण कितनी बार आता है, बस एक लूप और एक काउंटर से हो जाता है।

# --instructions--

एक फंक्शन `occurrences` लिखें जो आर्गुमेंट लेबल `of` के साथ एक `Character` और आर्गुमेंट लेबल `in` के साथ एक `String` ले, और यह लौटाए कि वह वर्ण स्ट्रिंग में कितनी बार आता है।

फ़ंक्शन कॉल का उदाहरण:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
