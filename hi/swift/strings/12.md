# --description--

`uppercased()` और `lowercased()` हर अक्षर को क्रमशः अपरकेस या लोअरकेस में बदलकर एक **नई** स्ट्रिंग लौटाते हैं। मूल स्ट्रिंग में कोई बदलाव नहीं होता:
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
दोनों मेथड हैं, इसलिए कोष्ठक लगाना न भूलें।
