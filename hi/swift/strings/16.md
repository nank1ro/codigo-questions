# --description--

Foundation फ्रेमवर्क कई अतिरिक्त स्ट्रिंग मेथड जोड़ता है। सबसे उपयोगी में से एक है `replacingOccurrences(of:with:)`, जो एक नई स्ट्रिंग लौटाता है जिसमें पहले टेक्स्ट की हर मौजूदगी को दूसरे से बदल दिया जाता है:
```swift
import Foundation

let path = "a/b/c"
print(path.replacingOccurrences(of: "/", with: "-")) // a-b-c
```
फ़ाइल के शुरू में `import Foundation` लिखना न भूलें, वरना यह मेथड उपलब्ध नहीं होगा। मेथड कॉल्स को चेन किया जा सकता है, इसलिए `text.lowercased().replacingOccurrences(of: " ", with: "_")` भी मान्य है।

# --instructions--

एक फंक्शन `snakeCase` लिखें जो एक `String` ले (आर्गुमेंट लेबल छोड़ें) और उसे लोअरकेस में लौटाए, जिसमें हर स्पेस को अंडरस्कोर `_` से बदल दिया गया हो

# --asserts--

`snakeCase("Hello World")` को `"hello_world"` लौटाना चाहिए

```swift
tryCatch(snakeCase("Hello World") == "hello_world")
```

`snakeCase("My First Post")` को `"my_first_post"` लौटाना चाहिए

```swift
tryCatch(snakeCase("My First Post") == "my_first_post")
```

`snakeCase("swift")` को `"swift"` लौटाना चाहिए

```swift
tryCatch(snakeCase("swift") == "swift")
```

`snakeCase("")` को `""` लौटाना चाहिए

```swift
tryCatch(snakeCase("") == "")
```

# --solutions--

```swift
func snakeCase(_ text: String) -> String {
    return text.lowercased().replacingOccurrences(of: " ", with: "_")
}
```
