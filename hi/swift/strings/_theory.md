**स्ट्रिंग** टेक्स्ट का एक टुकड़ा होती है। Swift में आप दोहरे उद्धरण चिह्नों के बीच एक स्ट्रिंग लिटरल लिखते हैं, और इसका टाइप `String` होता है:
```swift
let greeting: String = "Hello"
var city = "Rome"
```
किसी भी अन्य मान की तरह, `let` एक कॉन्स्टेंट बनाता है जिसे बदला नहीं जा सकता, और `var` एक वेरिएबल बनाता है जिसे बदला जा सकता है।
Swift लिटरल से `String` टाइप का अनुमान लगा लेता है, इसलिए टाइप एनोटेशन वैकल्पिक होता है।

---

**स्ट्रिंग इंटरपोलेशन** किसी एक्सप्रेशन के मान को स्ट्रिंग लिटरल के अंदर डालता है। एक्सप्रेशन को `\()` में लपेटें:
```swift
let name = "Ada"
let age = 36
print("\(name) is \(age) years old") // Ada is 36 years old
```
किसी भी टाइप को इंटरपोलेट किया जा सकता है: संख्याएँ, बूलियन और अन्य स्ट्रिंग्स सभी अपने आप टेक्स्ट में बदल जाते हैं।

---

दो स्ट्रिंग्स को `+` ऑपरेटर से जोड़ा जा सकता है, जिससे एक नई स्ट्रिंग बनती है:
```swift
let full = "Hello" + " " + "world" // Hello world
```
किसी मौजूदा स्ट्रिंग वेरिएबल के अंत में टेक्स्ट जोड़ने के लिए `+=` का उपयोग करें। चूँकि इसका मान बदलता है, इसलिए वेरिएबल को `var` से घोषित किया जाना चाहिए:
```swift
var log = "Start"
log += "..."
print(log) // Start...
```

---

`count` प्रॉपर्टी स्ट्रिंग में मौजूद वर्णों की संख्या लौटाती है, और `isEmpty` तब `true` होता है जब स्ट्रिंग में बिल्कुल भी वर्ण न हों:
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
स्पेस और विराम चिह्नों सहित हर वर्ण गिना जाता है।

---

`String`, `Character` मानों का एक कलेक्शन है। `Character` एक अकेला अक्षर, अंक, प्रतीक या स्पेस होता है, और इसे स्ट्रिंग जैसे ही दोहरे उद्धरण चिह्नों में लिखा जाता है, इसलिए इसे पाने के लिए टाइप एनोटेशन ज़रूरी है:
```swift
let letter: Character = "a"
let text = "abc"
print(text.count) // 3
```
`count` की तुलना `0` से करने के बजाय `isEmpty` जांचना बेहतर माना जाता है: यह पढ़ने में बेहतर है और इसके लिए हर वर्ण गिनने की ज़रूरत नहीं होती।

---

**मल्टी-लाइन स्ट्रिंग लिटरल** तीन दोहरे उद्धरण चिह्नों `"""` से शुरू और खत्म होता है, हर एक अपनी अलग लाइन पर। इनके बीच की हर लाइन स्ट्रिंग का हिस्सा बन जाती है, और लाइन ब्रेक बरकरार रहते हैं:
```swift
let poem = """
Roses are red
Violets are blue
"""
print(poem)
```
यह लिखी गई दोनों लाइनों को ठीक वैसे ही प्रिंट करता है। समापन `"""` इंडेंटेशन भी तय करता है: उससे पहले का कोई भी व्हाइटस्पेस हर लाइन की शुरुआत से हटा दिया जाता है।

---

चूँकि स्ट्रिंग वर्णों का एक कलेक्शन है, आप इस पर `for`-`in` लूप से पुनरावृत्ति कर सकते हैं। हर पुनरावृत्ति में आपको एक `Character` मिलता है:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
`Character` की तुलना `==` से किसी कैरेक्टर लिटरल के साथ की जा सकती है, इसलिए यह गिनना कि कोई वर्ण कितनी बार आता है, बस एक लूप और एक काउंटर से हो जाता है।

---

ऐरे के विपरीत, स्ट्रिंग्स को `text[2]` जैसे इंटीजर से सबस्क्रिप्ट नहीं किया जा सकता: कुछ वर्ण दूसरों की तुलना में अधिक मेमोरी लेते हैं, इसलिए Swift किसी स्थिति को इंगित करने के लिए एक समर्पित `String.Index` टाइप का उपयोग करता है।
`startIndex` पहले वर्ण की स्थिति है और `endIndex` आखिरी वर्ण के *बाद* की स्थिति है। किसी इंडेक्स से आगे बढ़ने के लिए `index(_:offsetBy:)` का उपयोग करें, फिर परिणाम से स्ट्रिंग को सबस्क्रिप्ट करें:
```swift
let word = "Swift"
let second = word.index(word.startIndex, offsetBy: 1)
print(word[second]) // w
```
स्ट्रिंग के अंत से आगे बढ़ने पर रनटाइम पर क्रैश हो जाता है, इसलिए ऑफसेट को `count` की सीमा के भीतर रखना चाहिए।

---

इंडेक्स के साथ काम करना लंबा होता है, इसलिए Swift सबसे सामान्य मामलों के लिए शॉर्टकट देता है:
- `first` और `last` पहले और आखिरी वर्ण को एक ऑप्शनल `Character?` के रूप में लौटाते हैं (खाली स्ट्रिंग के लिए `nil`)
- `prefix(n)` पहले `n` वर्ण लौटाता है और `suffix(n)` आखिरी `n` वर्ण
```swift
let word = "Swift"
print(word.first!)     // S
print(word.prefix(2))  // Sw
print(word.suffix(3))  // ift
```
`prefix` और `suffix` एक `Substring` लौटाते हैं, जो मूल टेक्स्ट पर एक व्यू है। इसे असली `String` के रूप में सहेजने के लिए इसे `String(...)` में लपेटें। अगर `n`, `count` से बड़ा है, तो आपको बस पूरी स्ट्रिंग मिल जाती है।

---

तीन मेथड स्ट्रिंग की सामग्री के बारे में सबसे आम सवालों के जवाब देते हैं, और हर एक `Bool` लौटाता है:
- `contains(_:)` तब `true` होता है जब स्ट्रिंग में दिया गया टेक्स्ट (या वर्ण) कहीं भी मौजूद हो
- `hasPrefix(_:)` तब `true` होता है जब स्ट्रिंग दिए गए टेक्स्ट से शुरू होती हो
- `hasSuffix(_:)` तब `true` होता है जब स्ट्रिंग दिए गए टेक्स्ट पर खत्म होती हो
```swift
let email = "ada@example.com"
print(email.contains("@"))          // true
print(email.hasPrefix("ada"))       // true
print(email.hasSuffix(".org"))      // false
```
तीनों केस-सेंसिटिव हैं: `"Swift".hasPrefix("s")` `false` है।

---

चूँकि `contains`, `hasPrefix` और `hasSuffix` बूलियन लौटाते हैं, इन्हें `||` और `&&` के साथ स्वाभाविक रूप से जोड़कर अधिक जटिल जांच बनाई जा सकती है।

---

`uppercased()` और `lowercased()` हर अक्षर को क्रमशः अपरकेस या लोअरकेस में बदलकर एक **नई** स्ट्रिंग लौटाते हैं। मूल स्ट्रिंग में कोई बदलाव नहीं होता:
```swift
let name = "Swift"
print(name.uppercased()) // SWIFT
print(name.lowercased()) // swift
print(name)              // Swift
```
दोनों मेथड हैं, इसलिए कोष्ठक लगाना न भूलें।

---

टेक्स्ट को केस को नज़रअंदाज़ करते हुए तुलना करने का सामान्य तरीका उसे लोअरकेस में बदलना है: दो स्ट्रिंग्स जो केवल केस में अलग हों, दोनों को लोअरकेस में बदलने पर बराबर हो जाती हैं।

---

`split(separator:)` जहाँ भी सेपरेटर वर्ण आता है, वहाँ स्ट्रिंग को टुकड़ों की एक ऐरे में तोड़ देता है। `joined(separator:)` इसका उल्टा करता है: यह ऐरे के तत्वों को एक ही स्ट्रिंग में जोड़ता है, और उनके बीच सेपरेटर डालता है:
```swift
let parts = "a-b-c".split(separator: "-") // ["a", "b", "c"]
print(parts.count)                         // 3
print(parts.joined(separator: ", "))       // a, b, c
```
`prefix` की तरह, `split` भी `Substring` मान लौटाता है; अगर इसे `String` के रूप में सहेजना हो तो इसे `String(...)` में लपेटें।

---

स्पेस पर विभाजित करना किसी वाक्य को शब्दों में तोड़ने का सबसे आसान तरीका है, और जोड़ना (join) यह है कि आप ऐरे से टेक्स्ट को फिर से कैसे बनाते हैं।

---

Foundation फ्रेमवर्क कई अतिरिक्त स्ट्रिंग मेथड जोड़ता है। सबसे उपयोगी में से एक है `replacingOccurrences(of:with:)`, जो एक नई स्ट्रिंग लौटाता है जिसमें पहले टेक्स्ट की हर मौजूदगी को दूसरे से बदल दिया जाता है:
```swift
import Foundation

let path = "a/b/c"
print(path.replacingOccurrences(of: "/", with: "-")) // a-b-c
```
फ़ाइल के शुरू में `import Foundation` लिखना न भूलें, वरना यह मेथड उपलब्ध नहीं होगा। मेथड कॉल्स को चेन किया जा सकता है, इसलिए `text.lowercased().replacingOccurrences(of: " ", with: "_")` भी मान्य है।

---

स्ट्रिंग्स की तुलना संख्याओं जैसे ही ऑपरेटरों से की जा सकती है। `==` जांचता है कि दोनों स्ट्रिंग्स में बिल्कुल एक जैसे वर्ण हैं या नहीं, जबकि `<` और `>` उन्हें वर्ण दर वर्ण डिक्शनरी क्रम में तुलना करते हैं:
```swift
print("apple" == "apple")  // true
print("apple" < "banana")  // true
print("car" < "cat")       // true
```
यह तुलना केस-सेंसिटिव होती है, और हर अपरकेस अक्षर हर लोअरकेस अक्षर से **पहले** आता है, इसलिए `"B" < "a"` `true` है।

---

`Character`, `String` नहीं होता, इसलिए इसे सीधे `+` से किसी स्ट्रिंग में नहीं जोड़ा जा सकता। पहले इसे `String(...)` से बदलें:
```swift
let letter: Character = "a"
let text = String(letter) + "bc" // abc
```
इसे `for`-`in` लूप के साथ मिलाने पर आप एक-एक वर्ण करके स्ट्रिंग को फिर से बना सकते हैं, जैसे हर नए वर्ण को अब तक इकट्ठे किए गए वर्णों के आगे रखकर।
