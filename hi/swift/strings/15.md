# --description--

स्पेस पर विभाजित करना किसी वाक्य को शब्दों में तोड़ने का सबसे आसान तरीका है, और जोड़ना (join) यह है कि आप ऐरे से टेक्स्ट को फिर से कैसे बनाते हैं।

# --instructions--

एक फंक्शन `wordCount` लिखें जो एक `String` ले (आर्गुमेंट लेबल छोड़ें) और लौटाए कि उसमें स्पेस से अलग किए गए कितने शब्द हैं, और एक फंक्शन `slug` लिखें जो `String` की एक ऐरे ले (आर्गुमेंट लेबल छोड़ें) और शब्दों को `-` से जोड़कर लौटाए

फ़ंक्शन कॉल का उदाहरण:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
