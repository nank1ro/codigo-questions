# --description--

तीन मेथड स्ट्रिंग की सामग्री के बारे में सबसे आम सवालों के जवाब देते हैं, और हर एक `Bool` लौटाता है:
- `contains(_:)` तब `true` होता है जब स्ट्रिंग में दिया गया टेक्स्ट (या वर्ण) कहीं भी मौजूद हो
- `hasPrefix(_:)` तब `true` होता है जब स्ट्रिंग दिए गए टेक्स्ट से शुरू होती हो
- `hasSuffix(_:)` तब `true` होता है जब स्ट्रिंग दिए गए टेक्स्ट पर खत्म होती हो
```swift
let email = "ada@example.com"
print(email.contains("@"))          // true
print(email.hasPrefix("ada"))       // true
print(email.hasSuffix(".org"))      // false
```
तीनों केस-सेंसिटिव हैं: `"Swift".hasPrefix("s")` `false` है।
