एक **फ़ॉर्मेटेड स्ट्रिंग** ऐसा टेक्स्ट होता है जिसके कुछ हिस्से रन टाइम पर मानों से भर दिए जाते हैं: एक क़ीमत, एक नाम, एक स्कोर। Swift आपको इसके लिए दो टूल्स देता है।

पहला **स्ट्रिंग इंटरपोलेशन** है, जिसे आप पहले से जानते हैं: `\( )` के अंदर लिखी गई कोई भी चीज़ मूल्यांकित होकर टेक्स्ट में डाल दी जाती है। यह ज़रूरी नहीं कि वह एक वेरिएबल हो, यह कोई भी एक्सप्रेशन हो सकता है:
```swift
let price = 4
print("Total: \(price * 3)") // Total: 12
print("Name: \("ada".uppercased())") // Name: ADA
```
इंटरपोलेशन स्ट्रिंग बनाने का सबसे तेज़ तरीका है, लेकिन यह संख्याओं को ठीक उसी रूप में प्रिंट करता है जिस रूप में Swift उन्हें संग्रहीत करता है: `3.5` `3.5` ही रहता है, कभी भी `3.50` नहीं बनता। अंकों, चौड़ाई और पैडिंग पर पूरा नियंत्रण पाने के लिए हम `String(format:)` का उपयोग करेंगे, जिसे अगले अभ्यास में पेश किया जाएगा।

---

दूसरा टूल `String(format:)` है, जो **Foundation** फ्रेमवर्क से आता है, इसलिए फ़ाइल को `import Foundation` से शुरू होना चाहिए।

यह डाले जाने वाले मानों से पहले एक **फ़ॉर्मेट स्ट्रिंग** लेता है। फ़ॉर्मेट स्ट्रिंग के अंदर, `%` से शुरू होने वाला एक **स्पेसिफ़ायर** बताता है कि हर मान कहाँ जाएगा और कैसे लिखा जाएगा। पूर्णांक के लिए स्पेसिफ़ायर `%d` है:
```swift
import Foundation

let count = 7
let text = String(format: "Item %d", count)
print(text) // Item 7
```
`String(format:)` एक सामान्य `String` लौटाता है, इसलिए आप इसे प्रिंट कर सकते हैं, संग्रहीत कर सकते हैं या किसी फ़ंक्शन से लौटा सकते हैं।

---

दशमलव संख्याओं (`Double`) के लिए स्पेसिफ़ायर `%f` है। अकेले यह हमेशा बिंदु के बाद छह अंक प्रिंट करता है:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
यह चुनने के लिए कि आप कितने दशमलव चाहते हैं, `%` और `f` के बीच एक बिंदु और एक संख्या लिखें। यह **प्रेसिशन** है, और मान को उसके अनुरूप राउंड कर दिया जाता है:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
क़ीमतों के लिए `%.2f` आम तौर पर चुना जाता है, क्योंकि यह हमेशा ठीक दो दशमलव दिखाता है।

---

`%` और अक्षर के बीच की संख्या फ़ील्ड की **न्यूनतम चौड़ाई** तय करती है। यदि मान छोटा है, तो बाईं ओर स्पेस जोड़ दिए जाते हैं ताकि वह **दाईं-संरेखित (right-aligned)** हो; यदि वह लंबा है, तो कुछ भी काटा नहीं जाता:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
चौड़ाई और प्रेसिशन साथ में काम करते हैं: `%8.2f` का मतलब है "कम से कम 8 अक्षर चौड़ा, 2 दशमलव के साथ":
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
ठीक यही नियत चौड़ाइयाँ तालिका के कॉलम को संरेखित करती हैं।

---

डिफ़ॉल्ट रूप से पैडिंग बाईं ओर होती है। `%` के ठीक बाद माइनस चिह्न पैडिंग को दाईं ओर कर देता है, ताकि मान **बाईं-संरेखित (left-aligned)** हो:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
माइनस चिह्न एक **फ़्लैग** है: यह चौड़ाई बदले बिना फ़ील्ड को भरने का तरीका बदल देता है।

---

एक और फ़्लैग `0` है: स्पेस के बजाय फ़ील्ड बाईं ओर शून्यों से भर दिया जाता है। इसी तरह आपको `007` या `00042` जैसी संख्याएँ मिलती हैं:
```swift
print(String(format: "%05d", 42))  // 00042
print(String(format: "%03d", 7))   // 007
print(String(format: "%03d", 1234)) // 1234
```
स्पेस की तरह ही, चौड़ाई से लंबा मान कभी काटा नहीं जाता।

---

एक फ़ॉर्मेट स्ट्रिंग में आप जितने चाहें स्पेसिफ़ायर रख सकते हैं। मान उसी क्रम में आते हैं, कॉमा से अलग किए हुए, और हर एक का टाइप अपने स्पेसिफ़ायर से मेल खाना चाहिए: `Int` के लिए `%d`, `Double` के लिए `%f`:
```swift
let count = 3
let weight = 4.5
print(String(format: "%d items, %.1f kg", count, weight)) // 3 items, 4.5 kg
```
`%d` को एक `Double` पास करना (या `%f` को एक `Int`) कंपाइल हो जाता है, लेकिन एक बेकार संख्या प्रिंट करता है, इसलिए हमेशा जाँचें कि स्पेसिफ़ायर और मान आपस में मेल खाते हैं।

---

पूर्णांकों को दूसरे आधारों में भी लिखा जा सकता है। `%x` मान को छोटे अक्षरों वाले **हेक्साडेसिमल** में प्रिंट करता है, `%X` बड़े अक्षरों के साथ, और `%o` ऑक्टल में:
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
चौड़ाई और `0` फ़्लैग यहाँ भी काम करते हैं: `%02x` किसी रंग का एक बाइट लिखने का क्लासिक तरीका है, जैसे `#ff8000` में।

---

एक `String` को फ़ॉर्मेट स्ट्रिंग में डालने के लिए, स्पेसिफ़ायर `%@` का उपयोग करें:
```swift
let name = "Ada"
let age = 36
print(String(format: "%@ is %d years old", name, age)) // Ada is 36 years old
```
`%@` एक Swift `String` सीधे स्वीकार करता है। Swift स्ट्रिंग के साथ `%s` का उपयोग न करें: वह स्पेसिफ़ायर एक C स्ट्रिंग की अपेक्षा करता है और बेकार आउटपुट प्रिंट करता है या क्रैश हो जाता है।
