# --description--

दशमलव संख्याओं (`Double`) के लिए स्पेसिफ़ायर `%f` है। अकेले यह हमेशा बिंदु के बाद छह अंक प्रिंट करता है:
```swift
print(String(format: "%f", 3.5)) // 3.500000
```
यह चुनने के लिए कि आप कितने दशमलव चाहते हैं, `%` और `f` के बीच एक बिंदु और एक संख्या लिखें। यह **प्रेसिशन** है, और मान को उसके अनुरूप राउंड कर दिया जाता है:
```swift
print(String(format: "%.2f", 3.5))     // 3.50
print(String(format: "%.1f", 3.14159)) // 3.1
print(String(format: "%.0f", 2.71))    // 3
```
क़ीमतों के लिए `%.2f` आम तौर पर चुना जाता है, क्योंकि यह हमेशा ठीक दो दशमलव दिखाता है।
