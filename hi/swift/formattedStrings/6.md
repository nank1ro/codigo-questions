# --description--

एक और फ़्लैग `0` है: स्पेस के बजाय फ़ील्ड बाईं ओर शून्यों से भर दिया जाता है। इसी तरह आपको `007` या `00042` जैसी संख्याएँ मिलती हैं:
```swift
print(String(format: "%05d", 42))  // 00042
print(String(format: "%03d", 7))   // 007
print(String(format: "%03d", 1234)) // 1234
```
स्पेस की तरह ही, चौड़ाई से लंबा मान कभी काटा नहीं जाता।

# --instructions--

एक फ़ंक्शन `ticket` लिखें जो एक पूर्णांक ले (आर्गुमेंट लेबल छोड़ें) और `String(format:)` का उपयोग करके `T-` के बाद शून्यों से पैड करके चौड़ाई `5` वाली संख्या लौटाए

फ़ंक्शन कॉल का उदाहरण:
```swift
print(ticket(42))
// prints T-00042
```
