# --description--

Foundation में दाईं ओर पैडिंग के लिए एक तैयार हेल्पर भी है: `padding(toLength:withPad:startingAt:)`। यह पैड टेक्स्ट को दोहराकर स्ट्रिंग को दी गई लंबाई तक बढ़ा देता है, और यदि वह लंबी है तो उसे काट देता है:
```swift
import Foundation

let name = "Ada"
print(name.padding(toLength: 8, withPad: " ", startingAt: 0) + "|") // Ada     |
print("Tea".padding(toLength: 6, withPad: ".", startingAt: 0))     // Tea...
```
`startingAt` पैड टेक्स्ट के अंदर वह इंडेक्स है जहाँ से दोहराना शुरू होता है; एक-अक्षर वाले पैड के साथ यह हमेशा `0` होता है।

# --instructions--
