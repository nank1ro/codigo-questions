# --description--

चौड़ाई फ़्लैग केवल `String(format:)` के अंदर काम करते हैं। एक साधारण स्ट्रिंग को स्वयं पैड करने के लिए, `String(repeating:count:)` से स्पेस बनाएँ और उन्हें टेक्स्ट से जोड़ें:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
यदि टेक्स्ट पहले से चौड़ाई से लंबा है, तो `4 - text.count` ऋणात्मक हो जाता है और `String(repeating:count:)` क्रैश हो जाता है। इसे `max(0, ...)` से सुरक्षित करें, ताकि काउंट कभी शून्य से नीचे न जाए और लंबा टेक्स्ट जैसा है वैसा ही रहे।

# --instructions--

एक फ़ंक्शन `leftPad` लिखें जो एक टेक्स्ट (`String`) और एक चौड़ाई (`Int`) ले, दोनों आर्गुमेंट लेबल के बिना, और बाईं ओर स्पेस जोड़कर टेक्स्ट को उस चौड़ाई में दाईं-संरेखित करके लौटाए। चौड़ाई से लंबा टेक्स्ट अपरिवर्तित लौटाना चाहिए

फ़ंक्शन कॉल का उदाहरण:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

```swift
func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
```
