# --description--

डिफ़ॉल्ट रूप से पैडिंग बाईं ओर होती है। `%` के ठीक बाद माइनस चिह्न पैडिंग को दाईं ओर कर देता है, ताकि मान **बाईं-संरेखित (left-aligned)** हो:
```swift
print(String(format: "%-5d|", 42)) // 42   |
print(String(format: "%5d|", 42))  //    42|
```
माइनस चिह्न एक **फ़्लैग** है: यह चौड़ाई बदले बिना फ़ील्ड को भरने का तरीका बदल देता है।

# --instructions--

यह कोड आउटपुट में क्या प्रदर्शित करता है?
```swift
import Foundation

print(String(format: "[%-5d]", 42))
```
