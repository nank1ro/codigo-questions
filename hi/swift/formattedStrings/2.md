# --description--

दूसरा टूल `String(format:)` है, जो **Foundation** फ्रेमवर्क से आता है, इसलिए फ़ाइल को `import Foundation` से शुरू होना चाहिए।

यह डाले जाने वाले मानों से पहले एक **फ़ॉर्मेट स्ट्रिंग** लेता है। फ़ॉर्मेट स्ट्रिंग के अंदर, `%` से शुरू होने वाला एक **स्पेसिफ़ायर** बताता है कि हर मान कहाँ जाएगा और कैसे लिखा जाएगा। पूर्णांक के लिए स्पेसिफ़ायर `%d` है:
```swift
import Foundation

let count = 7
let text = String(format: "Item %d", count)
print(text) // Item 7
```
`String(format:)` एक सामान्य `String` लौटाता है, इसलिए आप इसे प्रिंट कर सकते हैं, संग्रहीत कर सकते हैं या किसी फ़ंक्शन से लौटा सकते हैं।

# --instructions--

एक फ़ंक्शन `label` लिखें जो एक पूर्णांक ले (आर्गुमेंट लेबल छोड़ें) और संख्या के आगे `Item ` टेक्स्ट लौटाए, जिसके लिए `%d` के साथ `String(format:)` का उपयोग करें

फ़ंक्शन कॉल का उदाहरण:
```swift
print(label(7))
// prints Item 7
```
