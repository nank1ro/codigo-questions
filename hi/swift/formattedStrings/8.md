# --description--

पूर्णांकों को दूसरे आधारों में भी लिखा जा सकता है। `%x` मान को छोटे अक्षरों वाले **हेक्साडेसिमल** में प्रिंट करता है, `%X` बड़े अक्षरों के साथ, और `%o` ऑक्टल में:
```swift
print(String(format: "%x", 255)) // ff
print(String(format: "%X", 255)) // FF
print(String(format: "%o", 8))   // 10
```
चौड़ाई और `0` फ़्लैग यहाँ भी काम करते हैं: `%02x` किसी रंग का एक बाइट लिखने का क्लासिक तरीका है, जैसे `#ff8000` में।

# --instructions--
