# --description--

`%` और अक्षर के बीच की संख्या फ़ील्ड की **न्यूनतम चौड़ाई** तय करती है। यदि मान छोटा है, तो बाईं ओर स्पेस जोड़ दिए जाते हैं ताकि वह **दाईं-संरेखित (right-aligned)** हो; यदि वह लंबा है, तो कुछ भी काटा नहीं जाता:
```swift
print(String(format: "%5d|", 42))    //    42|
print(String(format: "%5d|", 12345)) // 12345|
```
चौड़ाई और प्रेसिशन साथ में काम करते हैं: `%8.2f` का मतलब है "कम से कम 8 अक्षर चौड़ा, 2 दशमलव के साथ":
```swift
print(String(format: "%8.2f|", 3.14159)) //     3.14|
```
ठीक यही नियत चौड़ाइयाँ तालिका के कॉलम को संरेखित करती हैं।

# --instructions--

एक फ़ंक्शन `rightAligned` लिखें जो एक पूर्णांक ले (आर्गुमेंट लेबल छोड़ें) और उसे `String(format:)` का उपयोग करके चौड़ाई `5` वाले फ़ील्ड में दाईं-संरेखित स्ट्रिंग के रूप में लौटाए

फ़ंक्शन कॉल का उदाहरण:
```swift
print(rightAligned(42) + "|")
// prints    42|
```
