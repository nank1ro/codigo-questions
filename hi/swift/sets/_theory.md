**Set** एक कलेक्शन है जो एक ही टाइप के मानों को बिना किसी निश्चित क्रम के संग्रहीत करता है, और सबसे महत्वपूर्ण बात, इसमें **कोई डुप्लिकेट नहीं** होता: हर मान अधिकतम एक बार दिखाई देता है।
Set तब बेहतरीन होते हैं जब आपको केवल इस बात की परवाह हो कि *कौन-से* मान मौजूद हैं, न कि वे कितनी बार या किस स्थान पर हैं।
आप `Set<Element>` टाइप और ऐरे जैसी लिटरल का उपयोग करके एक set घोषित करते हैं:
```swift
let numbers: Set<Int> = [1, 2, 3]
```
यह टाइप एनोटेशन अनिवार्य है: इसके बिना Swift एक ऐरे बना देगा।
अगर लिटरल में कोई मान एक से अधिक बार है, तो set उसकी केवल एक ही कॉपी रखता है:
```swift
let rolls: Set<Int> = [6, 6, 6]
print(rolls.count) // 1
```
`count` प्रॉपर्टी आपको बताती है कि set में कितने अद्वितीय मान हैं।

---

ऐरे की तरह, set भी constant (`let`) या variable (`var`) हो सकते हैं। बनने के बाद केवल `var` वाला set ही बदला जा सकता है।
खाली set बनाने के लिए आप टाइप का initializer कॉल करते हैं, क्योंकि अकेली खाली लिटरल `[]` से Swift को यह पता नहीं चलेगा कि किस एलिमेंट टाइप का उपयोग करना है:
```swift
var visited = Set<String>()
print(visited.isEmpty) // true
```
`isEmpty` प्रॉपर्टी `true` होती है जब set में कोई एलिमेंट नहीं होता, बिल्कुल ऐरे की तरह।

---

क्योंकि एक set कभी भी same मान को दो बार संग्रहीत नहीं करता, इसका `count` *अद्वितीय* मानों की संख्या होती है, चाहे लिटरल में हर मान कितनी भी बार लिखा गया हो।

---

यह जांचने के लिए कि कोई मान set में है या नहीं, `contains(_:)` मेथड का उपयोग करें, जो एक `Bool` लौटाता है:
```swift
let primes: Set<Int> = [2, 3, 5, 7]
print(primes.contains(5)) // true
print(primes.contains(6)) // false
```
यह जांच set पर बहुत तेज़ होती है, भले ही उसमें हजारों एलिमेंट हों, और membership जांचने के लिए ऐरे की जगह set पसंद करने का यह एक मुख्य कारण है।

---

एक `var` set को `insert(_:)` और `remove(_:)` से बदला जा सकता है:
```swift
var numbers: Set<Int> = [1, 2]
numbers.insert(3) // {1, 2, 3}
numbers.insert(2) // 2 is already there: nothing changes
numbers.remove(1) // {2, 3}
numbers.remove(9) // 9 is not there: nothing changes
```
पहले से मौजूद मान को insert करने का कोई असर नहीं होता, और जो मान मौजूद ही नहीं है उसे remove करने पर कोई error नहीं आता।
`remove(_:)` हटाए गए मान को एक optional के रूप में लौटाता है (`nil` जब कुछ भी नहीं हटाया गया हो), जिससे आप जांच सकते हैं कि हटाना वाकई हुआ या नहीं।
set को पूरी तरह खाली करने के लिए `removeAll()` कॉल करें।

---

आप `for`-`in` के साथ set पर लूप चला सकते हैं, लेकिन याद रखें कि set का **कोई निश्चित क्रम नहीं होता**: एलिमेंट किसी भी क्रम में आ सकते हैं, और वह क्रम हर बार रन करने पर बदल सकता है।
जब क्रम मायने रखता है, तो पहले `sorted()` कॉल करें: यह set को बिना बदले, एलिमेंट्स को आरोही क्रम में रखते हुए एक नया **ऐरे** लौटाता है।
```swift
let numbers: Set<Int> = [3, 1, 2]
for number in numbers.sorted() {
    print(number) // 1, 2, 3 on separate lines
}
```
