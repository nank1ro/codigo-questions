# --description--

आप `for`-`in` के साथ set पर लूप चला सकते हैं, लेकिन याद रखें कि set का **कोई निश्चित क्रम नहीं होता**: एलिमेंट किसी भी क्रम में आ सकते हैं, और वह क्रम हर बार रन करने पर बदल सकता है।
जब क्रम मायने रखता है, तो पहले `sorted()` कॉल करें: यह set को बिना बदले, एलिमेंट्स को आरोही क्रम में रखते हुए एक नया **ऐरे** लौटाता है।
```swift
let numbers: Set<Int> = [3, 1, 2]
for number in numbers.sorted() {
    print(number) // 1, 2, 3 on separate lines
}
```

# --instructions--
