# --description--

Swift में एक एरर एक **मान** होता है, क्रैश नहीं। कोई भी टाइप `Error` प्रोटोकॉल को अपनाकर एरर की भूमिका निभा सकता है, और enum आमतौर पर इसके लिए इस्तेमाल होने वाला विकल्प है क्योंकि इसके cases ठीक-ठीक बताते हैं कि क्या गलत हो सकता है:
```swift
enum LoginError: Error {
    case wrongPassword
}
```
विफल हो सकने वाले फ़ंक्शन को `throws` से चिह्नित किया जाता है, और यह `throw` के साथ विफलता की रिपोर्ट करता है:
```swift
func login(_ password: String) throws {
    if password != "swift" {
        throw LoginError.wrongPassword
    }
    print("welcome")
}
```
ऐसे फ़ंक्शन को कॉल करने के लिए `try` चाहिए, और यह कॉल एक `do` ब्लॉक के अंदर होनी चाहिए जिसके बाद एक `catch` ब्लॉक आता है जो बताता है कि विफल होने पर क्या करना है:
```swift
do {
    try login("hunter2")
} catch {
    print("login failed")
}
// login failed
```
जब `throw` चलता है, तो `do` ब्लॉक का बाकी हिस्सा छोड़ दिया जाता है और `catch` संभाल लेता है। कुछ भी क्रैश नहीं होता: प्रोग्राम `catch` के बाद आगे बढ़ता रहता है।
