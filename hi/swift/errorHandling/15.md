# --description--

`do` ब्लॉक कहाँ है, यह तय करता है कि एक अकेली विफलता की कीमत कितनी होगी। इसे लूप के **अंदर** रखें, तो हर आइटम को अपना अलग प्रयास मिलता है, जिससे एक खराब वैल्यू छोड़ दी जाती है और बाकी फिर भी चलते रहते हैं:
```swift
for age in [4, -1, 7] {
    do {
        print(try label(age))
    } catch {
        print("skipped")
    }
}
```
इसके बजाय पूरे लूप को एक ही `do` में लपेटने से पहली एरर पर ही रुक जाता और `7` तक कभी नहीं पहुँचता। दोनों में से कोई भी गलत नहीं है — यह बस *एक खराब आइटम* और *हार मान लेने* के बीच का फ़र्क़ है।
