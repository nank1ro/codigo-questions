# --description--

एक स्कोप एक से अधिक `defer` रजिस्टर कर सकता है। वे **उल्टे** क्रम में चलते हैं: सबसे बाद में रजिस्टर हुआ सबसे पहले चलता है।

यह कोई मनमाना नियम नहीं है। क्लीनअप आमतौर पर क्रम में हुए सेटअप को वापस करते हैं — फ़ाइल खोलें, फिर उसे लॉक करें — और वापस करना उल्टी दिशा में जाना ही चाहिए: अनलॉक करें, फिर बंद करें। उल्टा क्रम हर `defer` को उसके ऊपर की लाइन का दर्पण प्रतिबिंब बना देता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```swift
func run() {
    defer { print("one") }
    defer { print("two") }
    print("body")
}

run()
```

# --answers--

- `body` फिर `two` फिर `one`
- `body` फिर `one` फिर `two`
- `one` फिर `two` फिर `body`
- `two` फिर `one` फिर `body`
