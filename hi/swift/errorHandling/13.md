# --description--

क्लोजर लेने वाले फ़ंक्शन की एक समस्या होती है: वह नहीं जान सकता कि उसे दिया गया क्लोजर थ्रो करेगा या नहीं। फ़ंक्शन को `throws` चिह्नित करने से हर कॉल करने वाले को `try` लिखना पड़ता, यहाँ तक कि जो बेक़सूर क्लोजर पास कर रहे हों उन्हें भी। `rethrows` कहता है *मैं तभी थ्रो करूँगा जब आपके दिया क्लोजर थ्रो करे*:
```swift
func applyTwice(_ value: Int, _ transform: (Int) throws -> Int) rethrows -> Int {
    return try transform(transform(value))
}
```
बॉडी के अंदर आप फिर भी `try` लिखते हैं, क्योंकि यह कॉल सच में विफल हो सकती है। कॉल साइट पर कंपाइलर आपके पास किए गए क्लोजर को देखता है:
```swift
let doubled = applyTwice(3, { (n: Int) -> Int in n * 2 }) // try की ज़रूरत नहीं है
```
स्टैंडर्ड लाइब्रेरी इसे हर जगह उपयोग करती है — `map`, `filter` और `sorted(by:)` सब `rethrows` हैं — इसीलिए आप कभी किसी साधारण `map` के आगे `try` नहीं लिखते।


# --solutions--

```swift
func applyAll(_ numbers: [Int], _ transform: (Int) throws -> Int) rethrows -> [Int] {
    var result: [Int] = []
    for number in numbers {
        result.append(try transform(number))
    }
    return result
}
```
