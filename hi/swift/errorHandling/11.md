# --description--

जब कोई फ़ंक्शन थ्रो करता है, तो `throw` के बाद की हर चीज़ छोड़ दी जाती है — फ़ाइल बंद करने या लॉक छोड़ने वाली लाइन समेत। `defer` इसका समाधान है: यह एक ब्लॉक अभी रजिस्टर करता है और मौजूदा स्कोप के खत्म होने पर चलाता है, चाहे वह किसी भी तरह खत्म हो।
```swift
func load() throws {
    print("open")
    defer { print("close") }
    throw FileError.missing
}
```
कॉल करने पर `open` प्रिंट होता है, फिर `close`, और उसके बाद ही एरर कॉलर की ओर बढ़ता है। अगर फ़ंक्शन सामान्य तरीके से लौटता, तब भी `close` प्रिंट होता — यही तो बात है। क्लीनअप को सेटअप के ठीक बगल में रखें और इस बात की चिंता छोड़ दें कि कोड किस रास्ते बाहर निकलेगा।

# --instructions--

`run` के अंदर एक `defer` ब्लॉक जोड़ें जो `log` में `"cleanup"` जोड़ता है, ताकि यह तब भी हो जब `run` सामान्य तरीके से लौटे और तब भी जब वह थ्रो करे

# --seed--

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```

# --asserts--

सफल पाथ पर लॉग `start`, `done`, `cleanup` होना चाहिए

```swift
let _ok: [String] = steps(false)
tryCatch(_ok == ["start", "done", "cleanup"])
```

थ्रो करने वाले पाथ पर लॉग `start`, `cleanup`, `caught` होना चाहिए

```swift
let _bad: [String] = steps(true)
tryCatch(_bad == ["start", "cleanup", "caught"])
```

क्लीनअप दोनों पाथ्स पर चलना चाहिए

```swift
tryCatch(steps(false).contains("cleanup") && steps(true).contains("cleanup"))
```

थ्रो करने वाले पाथ पर क्लीनअप ठीक एक बार चलना चाहिए

```swift
let _once: [String] = steps(true)
tryCatch(_once.filter { $0 == "cleanup" }.count == 1)
```

```swift
enum TaskError: Error {
    case failed
}

func steps(_ shouldFail: Bool) -> [String] {
    var log: [String] = []
    func run() throws {
        log.append("start")
        defer { log.append("cleanup") }
        if shouldFail {
            throw TaskError.failed
        }
        log.append("done")
    }
    do {
        try run()
    } catch {
        log.append("caught")
    }
    return log
}
```
