# --description--

एक एरर case डेटा रख सकता है। case को **एसोसिएटेड वैल्यूज़** दें और `throw` उन्हें भर देता है, ताकि हैंडलर को सिर्फ़ यह नहीं पता चले कि *क्या* विफल हुआ, बल्कि *कितना* भी:
```swift
enum ValidationError: Error {
    case tooShort(minimum: Int)
}

throw ValidationError.tooShort(minimum: 8)
```
मैच होने वाला `catch` उन मानों को `let` के साथ बाइंड करता है:
```swift
} catch ValidationError.tooShort(let minimum) {
    print("needs at least \(minimum) characters")
}
```
`let` के बाद दिया गया नाम आपकी पसंद का है; यह एक नया कॉन्स्टेंट है जो केवल उसी `catch` ब्लॉक के अंदर उपलब्ध है। इसी तरह एक एरर एक उपयोगी संदेश रखता है, बिना यह ज़रूरत के कि आप विफलता होने की जगह पर स्ट्रिंग्स में संख्याएँ पेस्ट करें।

# --instructions--

`tooShort` को `Int` टाइप का एक एसोसिएटेड वैल्यू `minimum` दें, और पासवर्ड के 8 से कम अक्षरों वाला होने पर `check` को `PasswordError.tooShort(minimum: 8)` थ्रो करवाएँ

फ़ंक्शन कॉल का उदाहरण:
```swift
do {
    try check("abc")
} catch PasswordError.tooShort(let minimum) {
    print(minimum)
}
// prints 8
```

func _minimum(_ password: String) -> Int {
    do {
        try check(password)
        return 0
    } catch PasswordError.tooShort(let minimum) {
        return minimum
    } catch {
        return -1
    }
}
