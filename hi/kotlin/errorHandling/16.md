# --description--

`try` कहाँ रखा गया है, यह तय करता है कि एक गलत मान कितना काम बर्बाद करता है। अगर आप **पूरे लूप** को रैप करें तो पहली विफलता बाकी पूरे बैच को छोड़ देती है; अगर आप **बॉडी** को रैप करें तो सिर्फ़ वह एक एलिमेंट गँवाया जाता है:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // इसे छोड़ दें
    }
}
println(total) // 8
```
यह किसी ऐसे वैलिडेटिंग फ़ंक्शन के साथ स्वाभाविक रूप से मेल खाता है जो थ्रो करता है: फ़ंक्शन एक नियम बताता है और उसे तोड़ने वाली किसी भी चीज़ को अस्वीकार करता है, और लूप यह तय करता है कि एक अस्वीकृति की कीमत सिर्फ़ एक एलिमेंट है।

# --instructions--

दो फ़ंक्शन लिखें।

`validate(text: String): Int` को `text` में मौजूद संख्या लौटानी चाहिए, या मैसेज `not a number: ` के बाद वह टेक्स्ट जोड़कर एक `IllegalArgumentException` थ्रो करनी चाहिए।

`sumValid(values: List<String>): Int` को उन मानों को जोड़ना चाहिए जिन्हें `validate` स्वीकार करता है, और जिनसे वह थ्रो करता है उन्हें छोड़ देना चाहिए।

फ़ंक्शन कॉल का उदाहरण:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// 4 प्रिंट करता है
```

# --solutions--

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // skip this one
        }
    }
    return total
}
```
