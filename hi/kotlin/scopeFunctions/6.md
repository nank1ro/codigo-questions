# --description--

`apply` केवल उन ऑब्जेक्ट्स तक सीमित नहीं है जिन्हें आपने अभी-अभी बनाया है: यह किसी भी ऑब्जेक्ट पर काम करता है, और चूंकि यह ऑब्जेक्ट वापस देता है, आप पूरी एक्सप्रेशन का उपयोग वहीं कर सकते हैं जहाँ ऑब्जेक्ट अपेक्षित हो।
```kotlin
val box = Box()
box.apply { label = "tools" }        // box को बदलता है और उसे लौटाता है
println(listOf(Box().apply { label = "nails" }).size) // 1
```
ब्लॉक कोड का एक सामान्य ब्लॉक है, इसलिए इसमें आपकी ज़रूरत के जितने स्टेटमेंट हो सकते हैं।

# --instructions--

दो गुणों वाली एक क्लास `Profile` बनाएं, `var name: String` जो `""` से शुरू हो और `var age: Int` जो `0` से शुरू हो।

फिर एक फंक्शन `makeProfile(n: String, a: Int): Profile` लिखें जो एक `Profile()` बनाए और `apply` का उपयोग करके `name` को `n` तथा `age` को `a` सेट करे, और कॉन्फ़िगर किया हुआ ऑब्जेक्ट लौटाए।

```kotlin
class Profile {
    var name: String = ""
    var age: Int = 0
}

fun makeProfile(n: String, a: Int): Profile {
    return Profile().apply {
        name = n
        age = a
    }
}
```
