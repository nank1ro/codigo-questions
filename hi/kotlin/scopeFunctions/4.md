# --description--

`let` ब्लॉक के अंदर ऑब्जेक्ट को `it` कहना ज़रूरी नहीं है: आप लैम्ब्डा पैरामीटर को एक नाम दे सकते हैं, जिससे कोड तब पढ़ने में आसान रहता है जब ब्लॉक नेस्टेड हों या जब `it` कुछ उपयोगी न बताए।
```kotlin
val price: Int? = 12
println(price?.let { amount -> "$amount EUR" }) // 12 EUR
```
यही नामकरण हर उस स्कोप फंक्शन के साथ काम करता है जो `it` का उपयोग करता है, यानी `let` और `also` के लिए।

# --instructions--

एक फंक्शन `shout(word: String?): String` लिखें जो `word` को अपरकेस में, उसके बाद `!` के साथ लौटाए जब वह `null` न हो, और `silence` लौटाए जब वह `null` हो। `?.let` और `?:` का उपयोग करें।

उदाहरण: `shout("hi")` `HI!` लौटाता है, `shout(null)` `silence` लौटाता है।

```kotlin
fun shout(word: String?): String {
    return word?.let { it.uppercase() + "!" } ?: "silence"
}
```
