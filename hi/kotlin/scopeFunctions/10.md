# --description--

`with` वही काम करता है जो `run`, लेकिन यह एक्सटेंशन **नहीं** है: ऑब्जेक्ट डॉट कॉल का रिसीवर होने की बजाय पहले आर्गुमेंट के रूप में पास किया जाता है।
```kotlin
val text = with(StringBuilder()) {
    append("Hello")
    append(", world")
    toString()
}
println(text) // Hello, world
```
ब्लॉक के अंदर ऑब्जेक्ट `this` होता है और कॉल आखिरी एक्सप्रेशन लौटाता है, बिल्कुल `run` की तरह। `with` को तब प्राथमिकता दें जब आपके पास पहले से एक non-null ऑब्जेक्ट हो और आप उस पर कई कॉल को एक साथ समूहित करना चाहते हों; `run` को तब प्राथमिकता दें जब ऑब्जेक्ट किसी चेन से निकले या उसे सेफ कॉल की ज़रूरत हो सकती हो (`obj?.run { ... }`)।

# --instructions--

यह प्रोग्राम क्या प्रिंट करता है?

```kotlin
class Point(val x: Int, val y: Int)

fun main() {
    val point = Point(2, 5)
    val result = with(point) {
        x + y
    }
    println(result)
}
```
