# --description--

`apply` दोनों अक्षों पर एक साथ आगे बढ़ता है: इसके ब्लॉक के अंदर ऑब्जेक्ट रिसीवर `this` होता है (इसलिए इसके सदस्यों का उपयोग **बिना किसी प्रीफिक्स** के किया जा सकता है), और कॉल **ऑब्जेक्ट स्वयं** लौटाता है, ब्लॉक का परिणाम नहीं।

यही संयोजन `apply` को ऑब्जेक्ट को **कॉन्फ़िगर** करने का उपकरण बनाता है, ठीक वहीं जहाँ आप उसे बनाते हैं:
```kotlin
class Server {
    var host = "localhost"
    var port = 80
}

val server = Server().apply {
    host = "example.com"
    port = 8080
}
println("${server.host}:${server.port}") // example.com:8080
```
ब्लॉक के अंदर `host` और `port` वास्तव में `this.host` और `this.port` हैं; चूंकि `apply` कॉन्फ़िगर किया हुआ `Server` वापस देता है, इसे सीधे असाइन किया जा सकता है।
