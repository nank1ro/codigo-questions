# --description--

जब ब्लॉक को ऑब्जेक्ट किसी और चीज़ के **आर्गुमेंट** के रूप में चाहिए होता है, तो `also`, `apply` से बेहतर पढ़ा जाता है: `it` को सीधे सौंपा जा सकता है, जबकि `this` को स्पष्ट रूप से लिखना पड़ता।
```kotlin
val names = mutableListOf<String>()
val user = "ada".also { names.add(it) }
println(user)  // ada
println(names) // [ada]
```
एक्सप्रेशन का मान फिर भी `"ada"` है: `also` केवल उसे निकलते हुए देखता है।

# --instructions--

एक टॉप-लेवल `val log = mutableListOf<String>()` घोषित करें।

फिर एक फंक्शन `record(word: String): String` लिखें जो `word` को अपरकेस में लौटाए और `also` के साथ, लौटाने से पहले उसी अपरकेस मान को `log` में जोड़े।

उदाहरण: `record("hi")` के बाद फंक्शन `HI` लौटाता है और `log` में `HI` होता है।


```kotlin

```

```kotlin

```

```kotlin
val log = mutableListOf<String>()

}
```
