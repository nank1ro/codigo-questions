# --instructions--

यह प्रोग्राम क्या प्रिंट करता है?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, क्योंकि `apply` लिस्ट लौटाता है और `run` ब्लॉक का परिणाम लौटाता है
- `true 2`, क्योंकि `apply` `add` का परिणाम लौटाता है
- `[a, b] [a, b]`, क्योंकि दोनों लिस्ट लौटाते हैं
- `2 [a, b]`, क्योंकि `apply` आकार लौटाता है और `run` लिस्ट लौटाता है
