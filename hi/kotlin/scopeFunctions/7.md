# --description--

`also`, `apply` का दर्पण प्रतिबिंब है: ऑब्जेक्ट को `it` के रूप में संदर्भित किया जाता है, और कॉल **ऑब्जेक्ट स्वयं** लौटाता है। चूंकि ब्लॉक का परिणाम छोड़ दिया जाता है, `also` लॉगिंग या जांच जैसे **साइड इफ़ेक्ट** के लिए होता है, और इसे चेन के बीच में डाला जा सकता है बिना यह बदले कि चेन क्या बनाती है:
```kotlin
val total = listOf(1, 2, 3)
    .also { println("size: ${it.size}") } // size: 3
    .sum()
println(total) // 6
```
इसे *"और इसके साथ यह भी करो"* के रूप में पढ़ें: मान अछूता रहते हुए अगले चरण तक बहता रहता है।
