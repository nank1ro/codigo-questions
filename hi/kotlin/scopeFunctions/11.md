# --description--

अब पाँचों स्कोप फंक्शन सामने हैं, और हर एक दो अक्षों पर बस एक बिंदु है:
- `let` - ऑब्जेक्ट `it` है, ब्लॉक का परिणाम लौटाता है
- `run` - ऑब्जेक्ट `this` है, ब्लॉक का परिणाम लौटाता है
- `with` - ऑब्जेक्ट `this` है (आर्गुमेंट के रूप में पास), ब्लॉक का परिणाम लौटाता है
- `apply` - ऑब्जेक्ट `this` है, ऑब्जेक्ट लौटाता है
- `also` - ऑब्जेक्ट `it` है, ऑब्जेक्ट लौटाता है

जिस पंक्ति की ज़रूरत है उसे चुनें: `it` तब बेहतर पढ़ा जाता है जब आप ऑब्जेक्ट को किसी और चीज़ को सौंपते हैं, `this` तब बेहतर पढ़ा जाता है जब आप उसके कई सदस्यों को छूते हैं; नया मान चाहने पर ब्लॉक का परिणाम लौटाएं, ऑब्जेक्ट के साथ काम करते रहने पर ऑब्जेक्ट लौटाएं।

# --instructions--

दो रीड-ओनली गुणों वाली एक क्लास `Point` बनाएं, `val x: Int` और `val y: Int`, दोनों प्राइमरी कंस्ट्रक्टर से लिए हुए।

फिर एक फंक्शन `label(point: Point): String` लिखें जो `with` का उपयोग करके निर्देशांकों को `(x, y)` के रूप में लौटाए।

उदाहरण: `label(Point(2, 5))` `(2, 5)` लौटाता है।

```kotlin
class Point(val x: Int, val y: Int)

fun label(point: Point): String {
    return with(point) {
        "($x, $y)"
    }
}
```
