# --description--

न्यूमेरिक ऐरे के साथ एग्रीगेट फ़ंक्शंस भी आते हैं:
```kotlin
val nums = intArrayOf(3, 9, 1)
println(nums.sum())     // 13
println(nums.max())     // 9
println(nums.min())     // 1
println(nums.average()) // 4.333333333333333
println(nums.count())   // 3
```
`max()` और `min()` खाली ऐरे पर एक एक्सेप्शन थ्रो करते हैं, इसलिए जब ऐरे खाली हो सकता है तो `maxOrNull()` और `minOrNull()` का उपयोग करें।

# --instructions--

एक फ़ंक्शन `range(numbers: IntArray): Int` लिखें जो `numbers` के सबसे बड़े और सबसे छोटे एलिमेंट के बीच का अंतर लौटाए। आप मान सकते हैं कि ऐरे कभी खाली नहीं होगा।

उदाहरण: `range(intArrayOf(3, 9, 1))` `8` लौटाता है।
