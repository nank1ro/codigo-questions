# --description--

जब लूप के दौरान आपको इंडेक्स और वैल्यू दोनों चाहिए हों, तो `withIndex()` का उपयोग करके हर pair को विभाजित करें, या `forEachIndexed` का उपयोग करें:
```kotlin
val pets = arrayOf("cat", "dog")
for ((i, pet) in pets.withIndex()) {
    println("$i -> $pet")
}
pets.forEachIndexed { i, pet -> println("$i -> $pet") }
// both print 0 -> cat, then 1 -> dog
```

# --instructions--

एक फ़ंक्शन `positionsOf(target: String, words: Array<String>): List<Int>` लिखें जो उन सभी इंडेक्स की लिस्ट आरोही क्रम में लौटाए जहां `words` में `target` मौजूद है।

उदाहरण: `positionsOf("a", arrayOf("a", "b", "a"))` `[0, 2]` लौटाता है।

fun positionsOf(target: String, words: Array<String>): List<Int> {
    val result = mutableListOf<Int>()
    for ((i, word) in words.withIndex()) {
        if (word == target) result.add(i)
    }
    return result
}
