# --description--

**एक्सटेंशन फ़ंक्शन** किसी मौजूदा टाइप के सोर्स कोड को छुए बिना उसमें एक नया फ़ंक्शन जोड़ता है।
आप `fun` लिखते हैं, फिर वह टाइप जिसे आप एक्सटेंड करना चाहते हैं (**रिसीवर टाइप**), एक डॉट, और फ़ंक्शन का नाम:
```kotlin
fun Int.squared(): Int {
    return this * this
}
println(4.squared()) // 16
```
फ़ंक्शन के अंदर `this` वह मान है जिस पर फ़ंक्शन कॉल किया जाता है, इसे **रिसीवर** कहते हैं: `4.squared()` में यह `4` है।
एक बार एक्सटेंशन बन जाने पर, आप उसे डॉट के साथ ठीक वैसे ही कॉल करते हैं जैसे कोई फ़ंक्शन शुरू से ही `Int` का हिस्सा रहा हो।
