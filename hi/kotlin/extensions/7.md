# --description--

रिसीवर टाइप **नलेबल** हो सकता है। `String?` पर बना एक्सटेंशन ऐसे वेरिएबल पर भी कॉल किया जा सकता है जिसमें `null` हो सकता है, और फ़ंक्शन के अंदर `this` एक `String?` होता है, इसलिए `null` वाली स्थिति आप खुद संभालते हैं, आमतौर पर एल्विस ऑपरेटर `?:` से जो आपने नलेबिलिटी वाले पाठों में देखा था:
```kotlin
fun String?.orDash(): String {
    return this ?: "-"
}
val name: String? = null
println(name.orDash())  // -
println("Ada".orDash()) // Ada
```
`null` मान पर `name.orDash()` कॉल करना सुरक्षित है: `?.` की ज़रूरत नहीं, क्योंकि फ़ंक्शन खुद `null` रिसीवर स्वीकार करता है।
