# --description--

एक्सटेंशन प्रॉपर्टी कोष्ठकों के बिना पढ़ी जाती हैं, ठीक वैसे ही जैसे `String` की अंतर्निहित `length`। जब मान रिसीवर के साथ कुछ करने के बजाय उसका वर्णन करता है, तब ये स्वाभाविक विकल्प होती हैं:
```kotlin
val Int.isNegative: Boolean
    get() = this < 0

println((-3).isNegative) // true
println(7.isNegative)    // false
```
`-3` के चारों ओर कोष्ठकों पर ध्यान दें: उनके बिना `-3.isNegative` पहले `3` की प्रॉपर्टी पढ़ेगा और फिर एक `Boolean` को ऋणात्मक बनाने की कोशिश करेगा, जो कंपाइल नहीं होता।
