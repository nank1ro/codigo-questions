# --description--

ठीक **एक** पैरामीटर वाले एक्सटेंशन फ़ंक्शन को `infix` चिह्नित किया जा सकता है। इनफ़िक्स फ़ंक्शन को डॉट और कोष्ठकों के बिना कॉल किया जा सकता है, रिसीवर बाईं ओर और आर्ग्युमेंट दाईं ओर, जो लगभग एक वाक्य जैसा पढ़ा जाता है:
```kotlin
infix fun Int.percentOf(total: Int): Int = total * this / 100

println(20 percentOf 50)   // 10
println(20.percentOf(50))  // 10, the normal call still works
```
Kotlin कुछ अंतर्निहित फ़ंक्शनों के लिए भी इसका उपयोग करता है: `1 to "one"` एक `Pair` बनाता है, और `1 until 5` एक रेंज बनाता है।

# --instructions--

`Int` पर एक इनफ़िक्स एक्सटेंशन फ़ंक्शन `toThe(exponent: Int)` लिखें जो रिसीवर को दी गई घात तक बढ़ाकर लौटाए, ताकि `2 toThe 10` `1024` हो। घातांक कभी ऋणात्मक नहीं होता, और किसी भी संख्या की `0` घात `1` होती है।

# --solutions--

```kotlin
infix fun Int.toThe(exponent: Int): Int {
    var result = 1
    repeat(exponent) { result *= this }
    return result
}
```
