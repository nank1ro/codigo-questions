# --description--

आप किसी क्लास के **कम्पेनियन ऑब्जेक्ट** को भी एक्सटेंड कर सकते हैं, बशर्ते क्लास ने एक घोषित किया हो, चाहे वह खाली ही क्यों न हो। रिसीवर टाइप `ClassName.Companion` लिखा जाता है, और फिर एक्सटेंशन को क्लास के नाम पर कॉल किया जाता है, जैसे कोई फ़ैक्ट्री फ़ंक्शन:
```kotlin
class Temperature(val degrees: Int) {
    companion object
}
fun Temperature.Companion.freezing(): Temperature = Temperature(0)

println(Temperature.freezing().degrees) // 0
```
क्लास और एक्सटेंशन दोनों टॉप-लेवल घोषणाएँ हैं, इसलिए उन्हें `main` के बाहर लिखा जाना चाहिए।
