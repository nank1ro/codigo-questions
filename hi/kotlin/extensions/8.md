# --description--

नलेबल रिसीवर वाले एक्सटेंशन के अंदर आप सेफ़ कॉल `this?.` का भी उपयोग कर सकते हैं ताकि मान के मेंबर तक तभी पहुँचें जब वह `null` न हो। स्टैंडर्ड लाइब्रेरी `isNullOrEmpty()` जैसे फ़ंक्शनों में यही विचार इस्तेमाल करती है:
```kotlin
fun String?.firstOrQuestion(): Char {
    return this?.firstOrNull() ?: '?'
}
val text: String? = null
println(text.firstOrQuestion())    // ?
println("Kotlin".firstOrQuestion()) // K
```

# --instructions--

`String?` पर एक एक्सटेंशन फ़ंक्शन `lengthOrZero()` लिखें जो टेक्स्ट की लंबाई लौटाए, या रिसीवर के `null` होने पर `0` लौटाए।

उदाहरण: `"Kotlin".lengthOrZero()` `6` लौटाता है।

# --asserts--

`"Kotlin".lengthOrZero()` को `6` लौटाना चाहिए

```kotlin
    tryCatch("Kotlin".lengthOrZero() == 6)
```

`"".lengthOrZero()` को `0` लौटाना चाहिए

```kotlin
    tryCatch("".lengthOrZero() == 0)
```

`null` रखने वाले `String?` पर कॉल किए जाने पर इसे `0` लौटाना चाहिए

```kotlin
    val missing: String? = null
    tryCatch(missing.lengthOrZero() == 0)
```

`"hi"` रखने वाले `String?` पर कॉल किए जाने पर इसे `2` लौटाना चाहिए

```kotlin
    val present: String? = "hi"
    tryCatch(present.lengthOrZero() == 2)
```
