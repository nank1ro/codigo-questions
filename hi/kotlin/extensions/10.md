# --description--

**टाइप पैरामीटर** की मदद से एक एक्सटेंशन एक साथ कई टाइप्स के परिवार पर काम कर सकता है: टाइप पैरामीटर एक टाइप के लिए प्लेसहोल्डर है, जिसे `fun` के तुरंत बाद कोण कोष्ठकों में घोषित किया जाता है और Kotlin हर कॉल पर उसे भर देता है। इससे एक्सटेंशन **जेनेरिक** बन जाता है:
```kotlin
fun <T> List<T>.second(): T {
    return this[1]
}
println(listOf(1, 2, 3).second())      // 2
println(listOf("a", "b").second())     // b
```
`listOf(1, 2, 3)` के साथ प्लेसहोल्डर `T` `Int` है, `listOf("a", "b")` के साथ वह `String` है, इसलिए वही फ़ंक्शन हर बार सही टाइप लौटाता है।

# --instructions--

`List<T>` पर एक जेनेरिक एक्सटेंशन फ़ंक्शन `penultimate()` लिखें जो लिस्ट का अंतिम से पहला तत्व लौटाए। लिस्ट में हमेशा कम से कम दो तत्व होते हैं।

उदाहरण: `listOf(1, 2, 3).penultimate()` `2` लौटाता है।
