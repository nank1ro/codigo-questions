# --description--

जब किसी क्लास में पहले से ही एक्सटेंशन जैसे नाम और पैरामीटर वाला मेंबर मौजूद हो, तो **मेंबर हमेशा जीतता है**: एक्सटेंशन कभी कॉल नहीं होता, और कंपाइलर चेतावनी देता है कि वह ढँक गया है।
```kotlin
class Box {
    fun describe(): String = "member"
}
fun Box.describe(): String = "extension"

println(Box().describe()) // member
```
एक्सटेंशन मौजूदा व्यवहार को ओवरराइड या प्रतिस्थापित नहीं कर सकता; वह केवल नए फ़ंक्शन और प्रॉपर्टी जोड़ सकता है। चुने जाने के लिए एक्सटेंशन को ऐसा नाम या पैरामीटर सूची चाहिए जो क्लास के पास पहले से न हो।
