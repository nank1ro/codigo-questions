# --description--

`infix` चिह्नित होने के लिए फ़ंक्शन का मेंबर या एक्सटेंशन होना ज़रूरी है, उसे ठीक एक पैरामीटर लेना चाहिए, और उस पैरामीटर का कोई डिफ़ॉल्ट मान नहीं हो सकता। बाकी सब कंपाइल एरर है:
```kotlin
infix fun Int.add(other: Int): Int = this + other          // ok
infix fun add(a: Int, b: Int): Int = a + b                 // error: not a member or extension
infix fun Int.add(a: Int, b: Int): Int = this + a + b      // error: two parameters
```
इनफ़िक्स कॉल की प्राथमिकता अंकगणित और तुलना के बीच होती है: `1 add 2 * 3` का मतलब `1 add 6` है, जबकि `1 add 2 == 3` परिणाम की तुलना `3` से करता है।
