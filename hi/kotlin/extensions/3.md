# --description--

एक्सटेंशन फ़ंक्शन किसी भी दूसरे फ़ंक्शन की तरह पैरामीटर ले सकता है। रिसीवर डॉट के बाईं ओर रहता है और पैरामीटर कोष्ठकों के बीच आते हैं:
```kotlin
fun Int.isDivisibleBy(other: Int): Boolean {
    return this % other == 0
}
println(12.isDivisibleBy(4)) // true
println(12.isDivisibleBy(5)) // false
```
डॉट से पहले वाला टाइप एक सामान्य टाइप है, इसलिए आप उसी तरह `List<Int>`, `Double` या अपनी लिखी हुई क्लास को भी एक्सटेंड कर सकते हैं।

# --instructions--

`Int` पर एक एक्सटेंशन फ़ंक्शन `isBetween(low: Int, high: Int)` लिखें जो `true` लौटाए जब रिसीवर `low` से बड़ा या बराबर और `high` से छोटा या बराबर हो।

उदाहरण: `5.isBetween(1, 10)` `true` लौटाता है।
