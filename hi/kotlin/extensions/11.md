# --description--

टाइप पैरामीटर सिग्नेचर में कहीं भी इस्तेमाल हो सकता है: रिटर्न टाइप के रूप में, नलेबल `T?` के रूप में, या किसी दूसरे टाइप के अंदर। ऐसा जेनेरिक एक्सटेंशन जिसे शायद कुछ न मिले, `T?` लौटाता है, जैसे अंतर्निहित `firstOrNull()`:
```kotlin
fun <T> List<T>.lastOrDefault(default: T): T {
    return if (isEmpty()) default else this[size - 1]
}
println(listOf(1, 2).lastOrDefault(0))          // 2
println(emptyList<String>().lastOrDefault("-")) // -
```
फ़ंक्शन के अंदर आप `size`, `isEmpty()` और इंडेक्सिंग ठीक वैसे ही इस्तेमाल कर सकते हैं जैसे किसी भी लिस्ट पर, क्योंकि रिसीवर एक `List<T>` है।
