# --description--

एक्सटेंशन किसी भी टाइप पर काम करते हैं, उन पर भी जिनका सोर्स कोड आपके पास नहीं है। `String` स्टैंडर्ड लाइब्रेरी से आता है, फिर भी आप उसे नए फ़ंक्शन दे सकते हैं:
```kotlin
fun String.whisper(): String {
    return this.lowercase() + "..."
}
println("HELLO".whisper()) // hello...
```
एक्सटेंशन के अंदर रिसीवर के दूसरे मेंबर इस्तेमाल करते समय आप `this.` छोड़ सकते हैं: अकेला `lowercase()` का मतलब `this.lowercase()` है, और अकेला `length` का मतलब `this.length` है।

# --instructions--

`String` पर एक एक्सटेंशन फ़ंक्शन `shout()` लिखें जो टेक्स्ट को अपरकेस में और उसके बाद विस्मयादिबोधक चिह्न लगाकर लौटाए।

उदाहरण: `"hi".shout()` `"HI!"` लौटाता है।
