# --description--

आप एक्सटेंशन कहाँ घोषित करते हैं यह तय करता है कि उसे कहाँ इस्तेमाल किया जा सकता है, यानी उसका **स्कोप**:
- फ़ाइल के टॉप लेवल पर, वह पूरी फ़ाइल में और बाकी पैकेज में उपलब्ध होता है
- किसी फ़ंक्शन के अंदर, वह लोकल एक्सटेंशन होता है, केवल उसी फ़ंक्शन में इस्तेमाल योग्य
- किसी क्लास के अंदर, वह **मेंबर एक्सटेंशन** होता है, केवल उसी क्लास के अंदर इस्तेमाल योग्य

मेंबर एक्सटेंशन उस क्लास की प्रॉपर्टी पढ़ सकता है जिसमें वह रहता है, इसलिए वह दो रिसीवर जोड़ता है: क्लास का इंस्टेंस और वह मान जिस पर उसे कॉल किया जाता है:
```kotlin
class Greeter(val greeting: String) {
    fun String.greet(): String = "$greeting, $this!"
    fun welcome(name: String): String = name.greet()
}
println(Greeter("Hello").welcome("Ada")) // Hello, Ada!
```
`greet` के अंदर `greeting` `Greeter` से आता है और `this` वह `String` है जिस पर फ़ंक्शन कॉल होता है। क्लास के बाहर `"Ada".greet()` एक कंपाइल एरर है।

# --instructions--
