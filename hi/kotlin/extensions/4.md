# --description--

एक्सटेंशन उस क्लास को **नहीं** बदलता जिसे वह एक्सटेंड करता है और न ही उसमें कोई नया मेंबर डालता है। कंपाइलर बस कॉल को दोबारा लिख देता है: `"kotlin".first3()` उस फ़ंक्शन का कॉल बन जाता है जिसमें `"kotlin"` को `this` के रूप में भेजा जाता है।
```kotlin
fun String.first3(): String = take(3)
val word = "kotlin"
println(word.first3()) // kot
```
इसीलिए आप `String` और `Int` जैसी फ़ाइनल क्लासों को एक्सटेंड कर सकते हैं: उनके अंदर कुछ नहीं बदलता, एक्सटेंशन सिर्फ़ आपके कोड में रहता है।
