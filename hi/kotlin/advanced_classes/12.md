# --instructions--

इस प्रोग्राम के साथ क्या होता है?

```kotlin
interface Movable {
    fun move(): String = "moving"
}

class Robot : Movable

fun main() {
    println(Robot().move())
}
```

# --answers--

- यह `moving` प्रिंट करता है, क्योंकि `Robot` डिफ़ॉल्ट इम्प्लीमेंटेशन इनहेरिट करता है
- यह कंपाइल नहीं होता: `Robot` को `move()` को ओवरराइड करना चाहिए
- यह कंपाइल नहीं होता: एक इंटरफ़ेस में फ़ंक्शन बॉडी नहीं हो सकती
- यह `null` प्रिंट करता है
