# --description--

कभी-कभी आपको किसी चीज़ का ठीक **एक** इंस्टेंस चाहिए होता है: एक logger, एक registry, एक ऐप्लिकेशन कॉन्फ़िगरेशन। `class` की जगह `object` लिखने से वह सिंगलटन आपके लिए घोषित हो जाता है:

```kotlin
object Registry {
    var size = 0
    fun add() {
        size++
    }
}

Registry.add()
println(Registry.size) // 1
```

इंस्टेंस पहली बार उपयोग करने पर बनता है, और आप नाम को ही सीधे उपयोग करते हैं — न कोई `Registry()` कॉल होती है और न कोई कंस्ट्रक्टर। एक `object` में प्रॉपर्टी, मेथड और `init` ब्लॉक हो सकते हैं, और वह इंटरफ़ेस इम्प्लीमेंट कर सकता है या किसी क्लास का विस्तार कर सकता है।

# --instructions--

`Logger` नाम का एक `object` घोषित करें जिसमें `Int` टाइप की एक `var` प्रॉपर्टी `count`, जिसका प्रारंभिक मान `0` है, और एक मेथड `log(message: String): String` हो जो `count` में `1` जोड़ता है और संदेश को नई गिनती के साथ उपसर्गित करके लौटाता है, `"[1] hello"` के रूप में।
