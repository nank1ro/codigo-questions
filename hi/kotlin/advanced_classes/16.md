# --description--

इस टॉपिक के टुकड़े आमतौर पर आपस में जुड़ते हैं: एक `enum class`, जिसकी entries अपनी प्रॉपर्टी साथ रखती हैं, टैग के एक निश्चित सेट को मॉडल करती है, जबकि एक `data class` वह पेलोड रखता है जो उनके साथ आता है।

```kotlin
enum class Speed(val surcharge: Int) {
    STANDARD(0),
    EXPRESS(15)
}

data class Order(val total: Int, val speed: Speed)

val order = Order(100, Speed.EXPRESS)
println(order.total + order.speed.surcharge) // 115
```
