# --description--

जनरेट किया गया `equals()` `==` को एक **स्ट्रक्चरल** तुलना बनाता है: दो इंस्टेंस तब बराबर होते हैं जब प्राइमरी कंस्ट्रक्टर की हर प्रॉपर्टी बराबर हो। `===` ऑपरेटर अलग है, वह पूछता है कि क्या दोनों नाम मेमोरी में **एक ही ऑब्जेक्ट** की ओर इशारा करते हैं।

```kotlin
data class User(val id: Int, val name: String)

val a = User(1, "Ann")
val b = User(1, "Ann")
println(a == b)  // true, same data
println(a === b) // false, two different objects
println(a === a) // true
```

चूंकि `hashCode()`, `equals()` के साथ जनरेट होता है, data class इंस्टेंस एक `Set` के अंदर या `Map` कीज़ की तरह भी सही व्यवहार करते हैं: डुप्लिकेट एक में मिल जाते हैं।

```kotlin
println(setOf(a, b).size) // 1
```

एक साधारण क्लास इनमें से कुछ भी जनरेट नहीं करती, इसलिए उसके लिए `==` पहचान (identity) पर लौट आता है।

# --instructions--

एक data class `User` घोषित करें जिसमें `Int` टाइप की एक `val` प्रॉपर्टी `id` और `String` टाइप की एक `val` प्रॉपर्टी `name` हो।

फिर दो फ़ंक्शन लिखें: `sameData(a: User, b: User): Boolean`, जो `true` लौटाता है जब दोनों users में वही डेटा हो, और `sameInstance(a: User, b: User): Boolean`, जो `true` तभी लौटाता है जब दोनों नाम एक ही ऑब्जेक्ट की ओर इशारा करें।

# --asserts--

एक ही डेटा से बनाए गए दो users में वही डेटा होना चाहिए

```kotlin
    tryCatch(sameData(User(1, "Ann"), User(1, "Ann")))
```

अलग डेटा से बनाए गए दो users में वही डेटा नहीं होना चाहिए

```kotlin
    tryCatch(!sameData(User(1, "Ann"), User(2, "Ann")))
```

अलग-अलग बनाए गए दो users एक ही इंस्टेंस नहीं होने चाहिए

```kotlin
    tryCatch(!sameInstance(User(1, "Ann"), User(1, "Ann")))
```

खुद से तुलना किया गया वही user एक ही इंस्टेंस होना चाहिए

```kotlin
    val user = User(3, "Bo")
    tryCatch(sameInstance(user, user))
```

`User` को `hashCode()` जनरेट करना चाहिए, ताकि दो बराबर users का सेट एक ही एलिमेंट रखे

```kotlin
    tryCatch(setOf(User(4, "Cy"), User(4, "Cy")).size == 1)
```

```kotlin
data class User(val id: Int, val name: String)

fun sameData(a: User, b: User): Boolean {
    return a == b
}

fun sameInstance(a: User, b: User): Boolean {
    return a === b
}
```
