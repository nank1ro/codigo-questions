# --description--

जनरेट किए गए मेंबर केवल **प्राइमरी कंस्ट्रक्टर** में घोषित प्रॉपर्टी को ही देखते हैं। क्लास **बॉडी** में घोषित कोई प्रॉपर्टी एक साधारण प्रॉपर्टी होती है: वह `toString()`, `equals()`, `hashCode()` या `copy()` का हिस्सा नहीं होती।

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

val a = Item("nail")
a.quantity = 5
println(a) // Item(name=nail)
```

यह भूलना आसान है, इसलिए प्राइमरी कंस्ट्रक्टर में वह सब कुछ रखें जो ऑब्जेक्ट की पहचान करता है, और बॉडी में डिराइव्ड या अस्थायी स्टेट रखें।

# --instructions--

यह प्रोग्राम क्या प्रिंट करता है?

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

fun main() {
    val a = Item("nail")
    a.quantity = 5
    val b = Item("nail")
    b.quantity = 9
    println(a == b)
}
```

# --answers--

- `true`, क्योंकि जनरेट किया गया `equals()` केवल `name` की तुलना करता है
- `false`, क्योंकि `quantity` अलग है
- `Item(name=nail, quantity=5)`
- यह कंपाइल नहीं होता: एक data class अपनी बॉडी में प्रॉपर्टी घोषित नहीं कर सकती
