# --description--

किसी दूसरी क्लास के अंदर घोषित क्लास डिफ़ॉल्ट रूप से **नेस्टेड** होती है। वह बाहरी इंस्टेंस के बारे में कुछ नहीं जानती और आप उसे बाहरी क्लास के नाम से बनाते हैं:

```kotlin
class Outer {
    class Nested {
        fun hello() = "hi"
    }
}

println(Outer.Nested().hello()) // hi
```

`inner` कीवर्ड जोड़ें और स्थिति बदल जाती है: एक `inner` क्लास बाहरी इंस्टेंस का संदर्भ रखती है, इसलिए वह बाहरी प्रॉपर्टी पढ़ सकती है, और आप उसे **एक इंस्टेंस से** बनाते हैं:

```kotlin
class Counter(val step: Int) {
    inner class Doubler {
        fun value() = step * 2
    }
}

println(Counter(5).Doubler().value()) // 10
```

एक `inner` क्लास के अंदर, `this` भीतरी ऑब्जेक्ट होता है; जब आपको बाहरी वाला स्पष्ट रूप से चाहिए हो तो `this@Counter` का उपयोग करें।
