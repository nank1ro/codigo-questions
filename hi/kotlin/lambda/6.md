# --description--

जो लैम्ब्डा एक `Boolean` लौटाता है उसे **प्रेडिकेट** कहते हैं। कई collection फ़ंक्शन एक प्रेडिकेट लेते हैं:
- `filter` केवल वही तत्व रखता है जिनके लिए प्रेडिकेट `true` होता है
- `count` लौटाता है कि कितने तत्व इसे संतुष्ट करते हैं
- `any` और `all` बताते हैं कि कोई या हर तत्व इसे संतुष्ट करता है या नहीं
```kotlin
val numbers = listOf(1, 2, 3, 4, 5, 6)
println(numbers.filter { it % 2 == 0 }) // [2, 4, 6]
println(numbers.count { it > 4 })        // 2
println(numbers.any { it > 5 })          // true
```
कॉल को **चेन** किया जा सकता है: हर फ़ंक्शन एक नई लिस्ट लौटाता है जिस पर अगला काम करता है।
```kotlin
println(numbers.filter { it % 2 == 0 }.map { it * 10 }) // [20, 40, 60]
```
