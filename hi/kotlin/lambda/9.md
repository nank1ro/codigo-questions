# --description--

एक लैम्ब्डा अपने आस-पास घोषित वेरिएबल का उपयोग कर सकता है, तब भी जब उन्हें घोषित करने वाला कोड आगे बढ़ चुका हो। इसे **क्लोज़र** कहते हैं: लैम्ब्डा उन वेरिएबल को *कैप्चर* कर लेता है जिनकी उसे ज़रूरत होती है।
कई अन्य भाषाओं के विपरीत, Kotlin एक लैम्ब्डा को कैप्चर किए गए `var` को **बदलने** की अनुमति देता है:
```kotlin
var clicks = 0
val onClick = { clicks++ }
onClick()
onClick()
println(clicks) // 2
```
`onClick` का हर कॉल उसी `clicks` वेरिएबल को अपडेट करता है जिसे बाहरी कोड देखता है।

# --instructions--

लैम्ब्डा `add` को पूरा करें ताकि हर कॉल कैप्चर किए गए वेरिएबल `total` में `n` जोड़े, जिससे प्रोग्राम `12` प्रिंट करे
