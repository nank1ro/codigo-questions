# --description--

लौटाया गया लैम्ब्डा फ़ंक्शन के अंदर घोषित एक `var` को कैप्चर कर सकता है। वह वेरिएबल फ़ंक्शन के लौटने के बाद भी जीवित रहता है, और केवल वही लैम्ब्डा उस तक पहुँच सकता है: यह निजी स्थिति (private state) है।
```kotlin
fun makeGreeter(): () -> String {
    var calls = 0
    return { calls++; "hello #$calls" }
}
val greeter = makeGreeter()
println(greeter()) // hello #1
println(greeter()) // hello #2
```
`makeGreeter()` का हर कॉल एक नया `calls` घोषित करता है, इसलिए दो ग्रीटर स्वतंत्र रूप से गिनती करते हैं।

# --instructions--

एक फ़ंक्शन `makeCounter(): () -> Int` लिखें जो बिना पैरामीटर वाला एक लैम्ब्डा लौटाए। लैम्ब्डा का हर कॉल एक काउंटर को बढ़ाए जो `0` से शुरू होता है, और नया मान लौटाए। `makeCounter` के अलग-अलग कॉल से मिले काउंटर स्वतंत्र होने चाहिए।

उदाहरण: `val next = makeCounter()`, फिर `next()`, `1` लौटाता है, `next()`, `2` लौटाता है।

}
