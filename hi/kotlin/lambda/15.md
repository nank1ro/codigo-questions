# --description--

हायर-ऑर्डर फ़ंक्शन फ़ंक्शन लेते भी हैं और लौटाते भी हैं। एक क्लासिक उदाहरण है **कंपोज़िशन**: एक नया फ़ंक्शन बनाना जो एक फ़ंक्शन चलाता है और उसके परिणाम को दूसरे फ़ंक्शन में भेजता है।
```kotlin
fun andThen(first: (Int) -> Int, second: (Int) -> Int): (Int) -> Int {
    return { n -> second(first(n)) }
}
val addOneThenDouble = andThen({ it + 1 }, { it * 2 })
println(addOneThenDouble(3)) // 8
```
लौटाया गया लैम्ब्डा `first` और `second` दोनों को कैप्चर करता है, इसलिए यह `andThen` के लौटने के बहुत बाद तक भी काम करता रहता है।

# --instructions--

एक फ़ंक्शन `compose(f: (Int) -> Int, g: (Int) -> Int): (Int) -> Int` लिखें जो एक ऐसा लैम्ब्डा लौटाए जो अपने आर्ग्युमेंट पर `f` लागू करे और फिर परिणाम पर `g` लागू करे।

उदाहरण: `compose({ it + 1 }, { it * 2 })(3)`, `8` लौटाता है।
