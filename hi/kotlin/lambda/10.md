# --description--

चूंकि लैम्ब्डा एक मान है, इसलिए एक फ़ंक्शन उसे **लौटा** सकता है। रिटर्न टाइप एक फ़ंक्शन टाइप होता है:
```kotlin
fun multiplier(factor: Int): (Int) -> Int {
    return { it * factor }
}
val triple = multiplier(3)
println(triple(5)) // 15
```
लौटाया गया लैम्ब्डा `factor` को कैप्चर करता है, इसलिए `multiplier` का हर कॉल एक अलग फ़ंक्शन बनाता है।
जो फ़ंक्शन दूसरे फ़ंक्शन लेते हैं या लौटाते हैं, उन्हें **हायर-ऑर्डर फ़ंक्शन** कहते हैं।
