# --instructions--

`mapOf` और `mutableMapOf` में क्या अंतर है?

# --answers--

- `mutableMapOf` एक ऐसा map बनाता है जिसकी entries बनने के बाद जोड़ी, अपडेट या हटाई जा सकती हैं, `mapOf` एक read-only map बनाता है
- `mapOf` केवल `String` keys ही संग्रहीत कर सकता है, `mutableMapOf` किसी भी key टाइप को स्वीकार करता है
- `mutableMapOf` डुप्लिकेट keys की अनुमति देता है, `mapOf` नहीं देता
- कोई अंतर नहीं है, ये एक ही फ़ंक्शन के दो नाम हैं
