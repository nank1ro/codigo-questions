# --description--

आप `for` से map पर लूप चला सकते हैं, हर entry को उसकी key और मान में विभाजित करते हुए:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
कोष्ठक `(name, age)` हर entry को दो वेरिएबल्स में बाँट देते हैं। entries उसी क्रम में देखी जाती हैं जिसमें उन्हें डाला गया था।

# --instructions--

एक फ़ंक्शन `report(stock: Map<String, Int>): List<String>` लिखें जो हर entry के लिए `"item: count"` फ़ॉर्मेट में एक स्ट्रिंग वाली लिस्ट लौटाए, उसी क्रम में जिसमें entries map में दिखाई देती हैं।

फ़ंक्शन कॉल का उदाहरण:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
