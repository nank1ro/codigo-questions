# --instructions--

`enum class Color { RED, GREEN, BLUE }` दिए जाने पर, `Color.valueOf("PURPLE")` क्या करता है?

# --answers--

- यह एक `IllegalArgumentException` throw करता है, क्योंकि `PURPLE` नाम की कोई entry नहीं है
- यह `null` लौटाता है
- यह पहली entry, `Color.RED`, लौटाता है
- यह enum में एक नई `PURPLE` entry जोड़ देता है
