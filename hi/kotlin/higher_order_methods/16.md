# --description--

एक `Map` को एंट्रीज़ की लिस्ट की तरह संसाधित किया जा सकता है: `filter` और `map` सीधे मैप पर काम करती हैं और हर एंट्री को `.key` तथा `.value` के साथ पाती हैं। मैप पर `filter` एक मैप लौटाती है, जबकि `map` एक लिस्ट लौटाती है। `sortedBy` जैसी क्रमबद्ध करने वाली मेथड मैप पर परिभाषित नहीं हैं: पहले `scores.entries` से होकर जाएँ, जो एंट्रीज़ की कलेक्शन है:
```kotlin
val scores = mapOf("Ann" to 90, "Bob" to 72)
println(scores.filter { it.value > 80 })              // {Ann=90}
println(scores.entries.sortedBy { it.value }.map { it.key }) // [Bob, Ann]
```
`scores.entries` सभी एंट्रीज़ का समुच्चय है; `scores.keys` और `scores.values` केवल एक-एक पक्ष देते हैं।

# --instructions--

एक फ़ंक्शन `topScorers(scores: Map<String, Int>, n: Int): List<String>` लिखें जो `sortedByDescending`, `take` और `map` को श्रृंखला में जोड़कर सबसे अधिक स्कोर वाले `n` लोगों के नाम सबसे ऊँचे से नीचे की ओर लौटाए। यदि `n` मैप से बड़ा है, तो सभी नाम लौटाएँ।

उदाहरण: `topScorers(mapOf("Ann" to 90, "Bob" to 72, "Cy" to 85), 2)` `[Ann, Cy]` लौटाता है।

```kotlin
fun topScorers(scores: Map<String, Int>, n: Int): List<String> {
    return scores.entries.sortedByDescending { it.value }.take(n).map { it.key }
}
```
