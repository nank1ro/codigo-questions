# --description--

कुछ उच्च-क्रम मेथड नई कलेक्शन बनाने के बजाय कलेक्शन के बारे में किसी सवाल का जवाब देती हैं। ये सभी एक प्रेडिकेट लेती हैं:
- `any` `true` लौटाती है यदि **कम से कम एक** एलिमेंट उसे संतुष्ट करे
- `all` `true` लौटाती है यदि **हर** एलिमेंट उसे संतुष्ट करे
- `none` `true` लौटाती है यदि **कोई भी** एलिमेंट उसे संतुष्ट न करे
- `count` लौटाती है कि **कितने** एलिमेंट उसे संतुष्ट करते हैं
```kotlin
val numbers = listOf(1, 2, 3)
println(numbers.any { it > 2 })   // true
println(numbers.all { it > 2 })   // false
println(numbers.none { it > 2 })  // false
println(numbers.count { it > 1 }) // 2
```
खाली लिस्ट पर `any` `false` लौटाती है, जबकि `all` और `none` `true` लौटाती हैं: कोई एलिमेंट नहीं है जो नियम तोड़े।
