# --description--

`reduce` सभी एलिमेंट्स को एक ही मान में जोड़ देती है। इसका लैम्ब्डा दो पैरामीटर लेता है: **संचायक** (अब तक का परिणाम) और अगला एलिमेंट। यह पहले एलिमेंट को संचायक बनाकर शुरू करती है और बाकी हर एलिमेंट के लिए लैम्ब्डा चलाती है:
```kotlin
val numbers = listOf(1, 2, 3, 4)
println(numbers.reduce { acc, n -> acc + n }) // 10
```
खाली लिस्ट पर `reduce` एक एक्सेप्शन फेंकती है, क्योंकि शुरू करने के लिए कोई पहला एलिमेंट नहीं होता। `fold` इसे ठीक करती है: आप संचायक का **आरंभिक मान** आर्ग्युमेंट के रूप में देते हैं, और लैम्ब्डा हर एलिमेंट के लिए चलता है, पहले वाले सहित:
```kotlin
println(numbers.fold(0) { acc, n -> acc + n })   // 10
println(listOf<Int>().fold(0) { acc, n -> acc + n }) // 0
```
`fold` के साथ संचायक का टाइप एलिमेंट्स से अलग भी हो सकता है, जैसे संख्याओं की लिस्ट से एक `String` बनाना।
