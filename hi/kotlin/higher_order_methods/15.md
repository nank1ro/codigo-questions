# --description--

एक लैम्ब्डा के भीतर दूसरा उच्च-क्रम कॉल हो सकता है। भीतरी लैम्ब्डा के अंदर `it` **भीतरी** एलिमेंट को दर्शाता है और बाहरी को छिपा देता है, इसलिए बाहरी पैरामीटर को स्पष्ट नाम दें ताकि दोनों तक पहुँच बनी रहे:
```kotlin
val sales = listOf("north" to 120, "south" to 80, "north" to 30)
val byRegion = sales.groupBy { it.first }
val totals = byRegion.mapValues { entry -> entry.value.sumOf { it.second } }
println(totals) // {north=150, south=80}
```
`"north" to 120` एक `Pair` बनाता है। यहाँ बाहरी लैम्ब्डा मैप की एक एंट्री पर काम करता है, जबकि भीतरी उस एंट्री की लिस्ट के पेयर्स पर।
