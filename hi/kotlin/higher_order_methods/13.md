# --description--

उच्च-क्रम मेथड को **श्रृंखला में जोड़ा** जा सकता है: हर एक नई कलेक्शन लौटाती है जिस पर अगली काम करती है, इसलिए पूरी गणना बाएँ से दाएँ चलने वाली पाइपलाइन की तरह पढ़ी जाती है:
```kotlin
val words = listOf("kiwi", "fig", "banana", "date")
println(words.filter { it.length == 4 }.map { it.uppercase() }.sorted()) // [DATE, KIWI]
```
मैप के पास भी उच्च-क्रम मेथड हैं। `mapValues` कुंजियाँ बनाए रखती है और हर मान को लैम्ब्डा के परिणाम से बदल देती है, जिसे `.key` और `.value` के साथ **एंट्री** मिलती है:
```kotlin
val byLength = words.groupBy { it.length }      // {4=[kiwi, date], 3=[fig], 6=[banana]}
println(byLength.mapValues { it.value.size })   // {4=2, 3=1, 6=1}
```

# --instructions--

एक फ़ंक्शन `wordCounts(words: List<String>): Map<String, Int>` लिखें जो `groupBy` और `mapValues` को श्रृंखला में जोड़कर लौटाए कि `words` में हर शब्द कितनी बार आता है।

उदाहरण: `wordCounts(listOf("a", "b", "a"))` `{a=2, b=1}` लौटाता है।
