# --description--

`groupBy` एक कलेक्शन को `Map` में बाँटती है: लैम्ब्डा हर एलिमेंट की **कुंजी** निकालता है, और हर कुंजी उन एलिमेंट्स की लिस्ट से जुड़ी होती है जिन्होंने उसे उत्पन्न किया, उनके मूल क्रम में:
```kotlin
val words = listOf("fig", "kiwi", "pear")
val byLength = words.groupBy { it.length }
println(byLength)    // {3=[fig], 4=[kiwi, pear]}
println(byLength[4]) // [kiwi, pear]
```
परिणाम का टाइप `Map<K, List<T>>` होता है, जहाँ `K` लैम्ब्डा द्वारा लौटाया गया टाइप है और `T` एलिमेंट्स का टाइप है। कुंजियाँ उसी क्रम में आती हैं जिसमें वे पहली बार मिलती हैं।

# --instructions--

उदाहरण: `groupByLength(listOf("fig", "kiwi", "pear"))` `{3=[fig], 4=[kiwi, pear]}` लौटाता है।
