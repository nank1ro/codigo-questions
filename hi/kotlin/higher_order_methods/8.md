# --description--

`take(n)` पहले `n` एलिमेंट्स के साथ एक नई लिस्ट लौटाती है, और `drop(n)` पहले `n` एलिमेंट्स के **बिना** एक नई लिस्ट लौटाती है। इनमें से कोई भी लैम्ब्डा नहीं लेती, लेकिन इन्हें अक्सर ऐसी मेथड के बाद जोड़ा जाता है जो लैम्ब्डा लेती है:
```kotlin
val numbers = listOf(5, 3, 8, 1)
println(numbers.take(2))                    // [5, 3]
println(numbers.drop(2))                    // [8, 1]
println(numbers.sortedDescending().take(2)) // [8, 5]
```
`takeWhile` और `dropWhile` प्रेडिकेट वाले संस्करण हैं: ये शुरुआत से एलिमेंट्स तब तक लेती या छोड़ती हैं **जब तक** प्रेडिकेट `true` है, और पहले ऐसे एलिमेंट पर रुक जाती हैं जो उसे संतुष्ट नहीं करता:
```kotlin
println(numbers.takeWhile { it > 2 }) // [5, 3, 8]
```
