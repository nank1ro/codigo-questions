# --description--

एक श्रृंखला में `it` का टाइप हर चरण पर बदलता है: `List<String>` पर `filter` के बाद आपके पास अब भी स्ट्रिंग्स हैं, लेकिन `map { it.length }` के बाद आपके पास `List<Int>` है, इसलिए अगला लैम्ब्डा संख्याएँ देखता है।
```kotlin
val words = listOf("kiwi", "fig")
println(words.map { it.length }.filter { it > 3 }) // [4]
```
हर चरण एक **नई** लिस्ट लौटाता है और पिछली को कभी नहीं छूता, इसलिए एक श्रृंखला को नाम वाले मध्यवर्ती मानों में बाँटा जा सकता है और परिणाम नहीं बदलता।
