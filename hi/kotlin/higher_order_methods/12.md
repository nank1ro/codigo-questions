# --description--

लैम्ब्डा का रूप उससे मेल खाना चाहिए जिसकी मेथड अपेक्षा करती है:
- जो मेथड एक बार में एक एलिमेंट पर काम करती हैं (`map`, `filter`, `sortedBy`, `groupBy`...) वे **एक पैरामीटर** वाला लैम्ब्डा लेती हैं, जहाँ `it` उपलब्ध होता है
- `reduce`, `fold`, `forEachIndexed` और लैम्ब्डा वाली `zip` **दो** मान देती हैं, इसलिए पैरामीटरों को `a, b ->` के साथ स्पष्ट रूप से नाम देना ज़रूरी है
```kotlin
val numbers = listOf(1, 2, 3)
numbers.map { it * 2 }                  // ठीक: एक पैरामीटर, it उपलब्ध है
numbers.reduce { acc, n -> acc + n }    // ठीक: दो पैरामीटर, नाम के साथ
numbers.reduce { it + 1 }               // त्रुटि: दो पैरामीटर के साथ it मौजूद नहीं होता
```
पैरामीटरों को नाम देना हमेशा अनुमत है, एक ही होने पर भी: `numbers.map { n -> n * 2 }`।
