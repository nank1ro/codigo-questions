# --description--

`forEach` हर एलिमेंट के लिए लैम्ब्डा को एक बार चलाती है और कुछ नहीं लौटाती। यह `for` लूप का उच्च-क्रम विकल्प है, और इसका उपयोग प्रिंट करने जैसे साइड इफ़ेक्ट्स के लिए होता है:
```kotlin
listOf("a", "b").forEach { println(it) }
```
`forEachIndexed` आपको हर एलिमेंट की स्थिति भी देती है। इसके लैम्ब्डा में **दो** पैरामीटर होते हैं, इसलिए उन्हें नाम देना ज़रूरी है: `it` केवल ठीक एक पैरामीटर वाले लैम्ब्डा के लिए मौजूद होता है।
```kotlin
listOf("a", "b").forEachIndexed { index, letter ->
    println("$index: $letter") // 0: a, फिर 1: b
}
```
