# --description--

एग्रीगेशन मेथड पूरी कलेक्शन को एक मान में बदल देती हैं:
- `sum()` संख्याओं की लिस्ट को जोड़ती है, जबकि `sumOf` उस मान को जोड़ती है जो लैम्ब्डा हर एलिमेंट के लिए निकालता है
- `maxByOrNull` और `minByOrNull` वह **एलिमेंट** लौटाती हैं जिसके लिए लैम्ब्डा सबसे बड़ा या सबसे छोटा मान देता है, या खाली लिस्ट पर `null`
```kotlin
val words = listOf("fig", "banana", "kiwi")
println(words.sumOf { it.length })      // 13
println(words.minByOrNull { it.length }) // fig
println(listOf(1, 2, 3).sum())           // 6
```
`maxOf { it.length }` के साथ अंतर पर ध्यान दें, जो उस एलिमेंट के बजाय सबसे बड़ा **मान** (`6`) लौटाती है जिसने उसे उत्पन्न किया।
