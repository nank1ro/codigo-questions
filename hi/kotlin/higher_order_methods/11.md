# --description--

`zip` दो लिस्टों के एलिमेंट्स को स्थान दर स्थान जोड़ती है। लैम्ब्डा के बिना यह `Pair` मानों की लिस्ट लौटाती है, जिनके दोनों हिस्से `.first` और `.second` से पढ़े जाते हैं; लैम्ब्डा के साथ, हर स्थान के दोनों एलिमेंट उसे दिए जाते हैं और परिणाम एक लिस्ट में इकट्ठे होते हैं:
```kotlin
val names = listOf("Ann", "Bob")
val ages = listOf(31, 25)
println(names.zip(ages))                            // [(Ann, 31), (Bob, 25)]
println(names.zip(ages) { name, age -> "$name:$age" }) // [Ann:31, Bob:25]
```
परिणाम दोनों लिस्टों में से **छोटी** वाली जितना लंबा होता है: लंबी वाली के अतिरिक्त एलिमेंट नज़रअंदाज़ कर दिए जाते हैं।

# --instructions--

एक फ़ंक्शन `dotProduct(a: List<Int>, b: List<Int>): Int` लिखें जो `zip` का उपयोग करके `a` और `b` के एलिमेंट्स को स्थान दर स्थान गुणा करे और गुणनफलों का योग लौटाए। लंबी लिस्ट के अतिरिक्त एलिमेंट नज़रअंदाज़ किए जाते हैं।

उदाहरण: `dotProduct(listOf(1, 2, 3), listOf(4, 5, 6))` `32` लौटाता है, यानी `1*4 + 2*5 + 3*6`।

fun dotProduct(a: List<Int>, b: List<Int>): Int {
    return a.zip(b) { x, y -> x * y }.sum()
}
