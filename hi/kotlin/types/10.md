# --description--

`toIntOrNull()` तभी सफल होता है जब पूरा टेक्स्ट एक वैध पूर्ण संख्या हो, एक वैकल्पिक चिह्न के साथ:
```kotlin
println("42".toIntOrNull())   // 42
println("-7".toIntOrNull())   // -7
println("3.5".toIntOrNull())  // null, not a whole number
println(" 42".toIntOrNull())  // null, spaces are not allowed
println("abc".toIntOrNull())  // null
```
दशमलव टेक्स्ट के लिए `toDoubleOrNull()` का उपयोग करें, जो `"3.5"` स्वीकार करता है और उसी तरह एक `Double?` लौटाता है।

# --instructions--

एक फंक्शन `parseAge(text: String): Int` लिखें जो `text` में लिखी पूर्ण संख्या लौटाए, या `-1` जब टेक्स्ट एक वैध पूर्ण संख्या न हो।

उदाहरण: `parseAge("42")` `42` लौटाता है और `parseAge("abc")` `-1` लौटाता है।

fun parseAge(text: String): Int {

}
