# --description--

उपयोगकर्ता द्वारा टाइप किया गया टेक्स्ट हमेशा एक `String` के रूप में आता है, चाहे वह संख्या जैसा कैसा भी दिखे। उसके साथ गणित करने के लिए आपको उसे **पार्स** करना होगा: `toInt()` `"42"` को `Int` `42` में बदल देता है, और `toDouble()` `"3.5"` को `Double` `3.5` में बदल देता है।
```kotlin
val typed = "42"
println(typed.toInt() + 1) // 43
```
हर टेक्स्ट एक संख्या नहीं होती: `"4x2".toInt()` एक `NumberFormatException` थ्रो करता है और प्रोग्राम को रोक देता है।
सुरक्षित विकल्प `toIntOrNull()` और `toDoubleOrNull()` थ्रो करने की बजाय `null` लौटाते हैं, इसलिए, जैसा कि आपने nullability पाठों में सीखा, आप `?:` के साथ एक डिफ़ॉल्ट मान दे सकते हैं:
```kotlin
println("4x2".toIntOrNull())      // null
println("4x2".toIntOrNull() ?: 0) // 0
```
