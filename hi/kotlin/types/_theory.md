Kotlin में हर मान का एक **टाइप** होता है, जो कंपाइलर को बताता है कि वह किस तरह का डेटा है और आप उसके साथ क्या कर सकते हैं।
बुनियादी टाइप ये हैं:
- `Int`: एक पूर्ण संख्या, जैसे `42` या `-7`
- `Long`: एक पूर्ण संख्या जो एक `Int` से कहीं बड़ी हो सकती है
- `Double`: दशमलव भाग वाली एक संख्या, जैसे `3.14`
- `Float`: एक दशमलव संख्या जो `Double` की आधी मेमोरी उपयोग करती है, लेकिन कम सटीक होती है
- `Char`: सिंगल कोट्स के बीच एक अक्षर, जैसे `'a'`
- `Boolean`: `true` या `false` में से एक
- `String`: डबल कोट्स के बीच टेक्स्ट का एक टुकड़ा, जैसे `"Hello"`

जैसा कि आपने variables पाठों में देखा, आप नाम के बाद कोलन के साथ टाइप स्पष्ट रूप से बता सकते हैं:
```kotlin
val age: Int = 36
val name: String = "Ada"
```
एक टाइप का मान दूसरे टाइप के वेरिएबल में स्टोर नहीं किया जा सकता: `val age: Int = "36"` एक कंपाइल एरर है।

---

ज़्यादातर समय आप टाइप नहीं लिखते: Kotlin आपके द्वारा असाइन किए गए मान से उसे **इन्फर** कर लेता है, कुछ literal नियमों के आधार पर:
- एक पूर्ण संख्या, जैसे `42`, एक `Int` होती है
- दशमलव बिंदु वाली एक संख्या, जैसे `3.14`, एक `Double` होती है
- डबल कोट्स के बीच का टेक्स्ट एक `String` होता है
- सिंगल कोट्स के बीच का अक्षर एक `Char` होता है
- `true` और `false` `Boolean` होते हैं
```kotlin
val count = 42     // Int
val price = 9.99   // Double
val name = "Ada"   // String
val grade = 'A'    // Char
val isOpen = true  // Boolean
```
यह जांचने के लिए कि Kotlin ने क्या इन्फर किया, आप किसी भी मान के टाइप का नाम `::class.simpleName` से प्रिंट कर सकते हैं:
```kotlin
println(count::class.simpleName) // Int
println(price::class.simpleName) // Double
```
एक दशमलव literal कभी भी `Float` के रूप में इन्फर नहीं होता: `val ratio = 0.5` एक `Double` है।

---

एक `Int` लगभग दो अरब तक की पूर्ण संख्याएँ रख सकता है, और अधिक सटीक रूप से `Int.MAX_VALUE` तक, जो `2147483647` है।
एक `Int` के लिए बहुत बड़ा पूर्ण संख्या literal स्वतः ही `Long` के रूप में इन्फर हो जाता है, और आप सफिक्स `L` के साथ किसी भी literal के लिए `Long` फोर्स कर सकते हैं:
```kotlin
val big = 3000000000  // Long, too big for an Int
val small = 3L        // Long, thanks to the suffix
```
इसी तरह सफिक्स `f` एक दशमलव literal को `Float` में बदल देता है: `val ratio = 0.5f`।
लंबी संख्याएँ पढ़ने में कठिन होती हैं, इसलिए Kotlin आपको अंकों के बीच कहीं भी अंडरस्कोर `_` रखने देता है; कंपाइलर उन्हें नजरअंदाज कर देता है:
```kotlin
val population = 8_000_000_000L
val million = 1_000_000
println(million) // 1000000
```

---

जब आप कोई मान असाइन करते हैं तो Kotlin कभी भी अपने आप नंबर टाइप्स के बीच कन्वर्ज़न नहीं करता, छोटे टाइप से बड़े टाइप पर भी नहीं: एक `Int` को एक `Long` या `Double` वेरिएबल में स्टोर करना एक कंपाइल एरर है।
```kotlin
val count = 3
val total: Long = count      // error: Int is not a Long
val price: Double = count    // error: Int is not a Double
```
हर नंबर टाइप के पास **कन्वर्ज़न फंक्शन** होते हैं जो आपके ज़रूरत के टाइप का एक नया मान बनाते हैं: `toInt()`, `toLong()`, `toDouble()`, `toFloat()` और टेक्स्ट पाने के लिए `toString()`।
```kotlin
val total: Long = count.toLong()
val price: Double = count.toDouble() // 3.0
println(count.toString() + "!")      // 3!
```
दशमलव से पूर्ण संख्या में जाना **ट्रंकेट** करता है: `toInt()` बस दशमलव भाग को हटा देता है, इसलिए `3.99.toInt()` का मान `3` होता है और `(-3.99).toInt()` का मान `-3` होता है।

---

ऑपरेंड्स के टाइप तय करते हैं कि डिवीज़न कैसे काम करता है। जब दोनों `Int` हों, तो `/` ऑपरेटर **इंटीजर डिवीज़न** करता है: परिणाम एक `Int` होता है और शेषफल छोड़ दिया जाता है।
जब कम से कम एक ऑपरेंड `Double` हो, तो `/` फ्लोटिंग-पॉइंट डिवीज़न करता है और दशमलव भाग रखता है:
```kotlin
println(7 / 2)              // 3
println(7.0 / 2)            // 3.5
val slices = 7
println(slices.toDouble() / 2) // 3.5
```
इसलिए दो `Int` वेरिएबल्स से दशमलव परिणाम पाने के लिए आपको डिवाइड करने से **पहले** उनमें से कम से कम एक को कन्वर्ट करना होगा: `(7 / 2).toDouble()` का मान `3.0` है, क्योंकि इंटीजर डिवीज़न पहले ही हो चुका होता है।

---

जब एक फंक्शन को पूर्ण संख्याओं से गणना किया गया दशमलव परिणाम लौटाना हो, तो डिवाइड करने से पहले ऑपरेंड्स को `Double` में कन्वर्ट करें और रिटर्न टाइप को `Double` घोषित करें:
```kotlin
fun ratio(part: Int, total: Int): Double {
    return part.toDouble() / total
}
println(ratio(1, 4)) // 0.25
```
याद रखें कि एक `List<Int>` का `sum()` और `size` भी `Int` मान होते हैं, इसलिए उन्हें भी वही कन्वर्ज़न चाहिए।

---

हर `Char` एक संख्या के रूप में स्टोर होता है, उसका **कोड**। `code` प्रॉपर्टी किसी अक्षर के पीछे का `Int` देती है, और `toChar()` इसका उल्टा करती है, एक `Int` को उस कोड वाले `Char` में बदल देती है:
```kotlin
println('A'.code)        // 65
println(66.toChar())     // B
println(('A'.code + 2).toChar()) // C
```
अक्षरों के कोड क्रमिक होते हैं, इसलिए कोड में जोड़ने से आप वर्णमाला में आगे बढ़ते हैं।
ध्यान दें कि `'7'` का कोड `55` है, `7` नहीं: किसी `Char` द्वारा दर्शाए गए अंक को पढ़ने के लिए `digitToInt()` का उपयोग करें, जो `7` लौटाता है।

---

चूंकि एक `Char` का कोड एक `Int` होता है, आप उस पर अंकगणित कर सकते हैं और परिणाम को वापस एक `Char` में कन्वर्ट कर सकते हैं। इसी तरह आप वर्णमाला में आगे बढ़ते हैं:
```kotlin
val next = ('a'.code + 1).toChar() // 'b'
```
Kotlin आपको एक `Int` को सीधे एक `Char` में जोड़ने भी देता है: `'a' + 1` का मान `'b'` है, और दो अक्षरों के बीच का अंतर `'d' - 'a'` एक `Int` `3` है।

---

उपयोगकर्ता द्वारा टाइप किया गया टेक्स्ट हमेशा एक `String` के रूप में आता है, चाहे वह संख्या जैसा कैसा भी दिखे। उसके साथ गणित करने के लिए आपको उसे **पार्स** करना होगा: `toInt()` `"42"` को `Int` `42` में बदल देता है, और `toDouble()` `"3.5"` को `Double` `3.5` में बदल देता है।
```kotlin
val typed = "42"
println(typed.toInt() + 1) // 43
```
हर टेक्स्ट एक संख्या नहीं होती: `"4x2".toInt()` एक `NumberFormatException` थ्रो करता है और प्रोग्राम को रोक देता है।
सुरक्षित विकल्प `toIntOrNull()` और `toDoubleOrNull()` थ्रो करने की बजाय `null` लौटाते हैं, इसलिए, जैसा कि आपने nullability पाठों में सीखा, आप `?:` के साथ एक डिफ़ॉल्ट मान दे सकते हैं:
```kotlin
println("4x2".toIntOrNull())      // null
println("4x2".toIntOrNull() ?: 0) // 0
```

---

`toIntOrNull()` तभी सफल होता है जब पूरा टेक्स्ट एक वैध पूर्ण संख्या हो, एक वैकल्पिक चिह्न के साथ:
```kotlin
println("42".toIntOrNull())   // 42
println("-7".toIntOrNull())   // -7
println("3.5".toIntOrNull())  // null, not a whole number
println(" 42".toIntOrNull())  // null, spaces are not allowed
println("abc".toIntOrNull())  // null
```
दशमलव टेक्स्ट के लिए `toDoubleOrNull()` का उपयोग करें, जो `"3.5"` स्वीकार करता है और उसी तरह एक `Double?` लौटाता है।

---

एक `Int` का साइज़ निश्चित होता है, इसलिए उसकी एक सबसे छोटी और एक सबसे बड़ी मान होती है: `Int.MIN_VALUE` का मान `-2147483648` है और `Int.MAX_VALUE` का मान `2147483647` है।
सीमा से आगे जाना कोई एरर **नहीं** उठाता: मान चुपचाप रेंज के दूसरे छोर पर **वापस घूम जाता है**, इस व्यवहार को ओवरफ्लो कहते हैं।
```kotlin
println(Int.MAX_VALUE)     // 2147483647
println(Int.MAX_VALUE + 1) // -2147483648
```
जब कोई परिणाम दो अरब से अधिक हो सकता हो, तो एक `Long` का उपयोग करें, जिसकी सीमा `Long.MAX_VALUE` लगभग नौ क्विंटिलियन है। ऑपरेशन से पहले कन्वर्ट करना याद रखें: `Int.MAX_VALUE.toLong() + 1` का मान `2147483648` है।

---

एक `Double` दशमलव को बाइनरी में स्टोर करता है, इसलिए कुछ मानों को सटीक रूप से दर्शाया नहीं जा सकता और अंतिम अंकों में छोटी त्रुटियाँ दिखाई देती हैं:
```kotlin
println(0.1 + 0.2) // 0.30000000000000004
```
दशमलव की एक निश्चित संख्या दिखाने के लिए, एक फॉर्मेट स्ट्रिंग के साथ `String.format` का उपयोग करें: `"%.2f"` का मतलब है "बिंदु के बाद 2 अंकों वाली एक दशमलव संख्या"। परिणाम एक `String` होता है, जिसे उतने ही अंकों तक राउंड किया जाता है:
```kotlin
println(String.format("%.2f", 0.1 + 0.2)) // 0.30
println(String.format("%.1f", 3.14159))   // 3.1
println(String.format("%.2f", 2.0))       // 2.00
```

---

`Any` हायरार्की के सबसे ऊपर का टाइप है: हर Kotlin मान एक `Any` होता है, इसलिए टाइप `Any` का एक वेरिएबल एक `Int`, एक `String`, एक `Boolean`, या कुछ भी और रख सकता है।
यह पता लगाने के लिए कि वह वास्तव में क्या रखता है, आप `is` ऑपरेटर का उपयोग करते हैं, जो `true` लौटाता है जब मान का टाइप वही होता है:
```kotlin
val value: Any = 42
println(value is Int)    // true
println(value is String) // false
```
जैसे ही एक चेक पास हो जाता है, कंपाइलर मान को **स्मार्ट कास्ट** कर देता है: `if` के अंदर (या `when` ब्रांच में) आप उसे उस टाइप के रूप में उपयोग कर सकते हैं, बिना किसी कन्वर्ज़न की ज़रूरत के:
```kotlin
if (value is Int) println(value + 1) // 43, value is an Int here
when (value) {
    is String -> println(value.length)
    is Boolean -> println(!value)
}
```
