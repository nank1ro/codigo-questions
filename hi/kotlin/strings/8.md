# --description--

चूँकि `split` एक `List` लौटाता है, आप इसके तत्वों पर किसी भी अन्य लिस्ट की तरह लूप चला सकते हैं:
```kotlin
for (part in "a-b".split("-")) {
    println(part)
}
// prints a, then b
```
