# --description--

`replace(old, new)` एक कॉपी लौटाता है जिसमें `old` की **हर** मौजूदगी को `new` से बदल दिया जाता है:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
