# --description--

`String` दोहरे उद्धरण चिह्नों के बीच लिखा गया वर्णों का एक क्रम है।
`length` प्रॉपर्टी बताती है कि स्ट्रिंग में कितने वर्ण हैं, स्पेस सहित:
```kotlin
val greeting = "Hello world"
println(greeting.length) // 11
println("".length)       // 0
```
