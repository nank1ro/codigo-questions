# --description--

`uppercase()` स्ट्रिंग के हर अक्षर को अपरकेस में बदलकर उसकी एक कॉपी लौटाता है, `lowercase()` इसका उल्टा करता है।
मूल स्ट्रिंग में कोई बदलाव नहीं होता:
```kotlin
val name = "Kotlin"
println(name.uppercase()) // KOTLIN
println(name.lowercase()) // kotlin
println(name)             // Kotlin
```
