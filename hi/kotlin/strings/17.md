# --description--

`+` से लंबी स्ट्रिंग को टुकड़ों में बनाने पर हर बार एक नई स्ट्रिंग बनती है। `StringBuilder` इसी काम के लिए बनाया गया एक म्यूटेबल टेक्स्ट बफर है: `append` अंत में टेक्स्ट जोड़ता है (और बिल्डर को ही लौटाता है, ताकि कॉल्स को चेन किया जा सके) और `toString()` अंतिम `String` देता है:
```kotlin
val sb = StringBuilder()
sb.append("Hello")
sb.append(", ").append("world")
println(sb.toString()) // Hello, world
```
`append` स्ट्रिंग, कैरेक्टर और संख्याएँ स्वीकार करता है।

```kotlin
fun initials(fullName: String): String {
    val sb = StringBuilder()
    for (word in fullName.split(" ")) {
        sb.append(word[0])
    }
    return sb.toString()
}
```
