# --description--

दो स्ट्रिंग तब बराबर होती हैं जब उनमें एक ही क्रम में एक जैसे वर्ण हों। Kotlin में `==` स्ट्रिंग की **सामग्री** की तुलना करता है, इसलिए यह उन्हें तुलना करने का सामान्य तरीका है।
`equals` भी वही काम करता है, लेकिन यह बड़े और छोटे अक्षरों के अंतर को नज़रअंदाज़ करने के लिए `ignoreCase = true` भी स्वीकार करता है:
```kotlin
println("hello" == "hello")                          // true
println("Hello" == "hello")                          // false
println("Hello".equals("hello", ignoreCase = true))  // true
```
`===` जांचता है कि क्या दो वेरिएबल मेमोरी में बिल्कुल एक ही ऑब्जेक्ट की ओर इशारा करते हैं, जो स्ट्रिंग्स के मामले में लगभग कभी वह नहीं होता जो आप चाहते हैं।
