# --description--

स्ट्रिंग्स **इम्यूटेबल** होती हैं: एक बार बनने के बाद वे कभी नहीं बदलतीं। अब तक आपने जो भी फंक्शन देखे हैं, जैसे `uppercase()` या `replace()`, वे सभी एक **नई** स्ट्रिंग लौटाते हैं और मूल स्ट्रिंग को नहीं छेड़ते।
परिणाम को बनाए रखने के लिए आपको उसे सहेजना होगा, उदाहरण के लिए किसी `var` को फिर से असाइन करके:
```kotlin
var name = "kotlin"
name.uppercase()        // result is thrown away
println(name)           // kotlin
name = name.uppercase() // result is stored
println(name)           // KOTLIN
```

# --instructions--

यह कोड क्या प्रिंट करता है?
```kotlin
val word = "hi"
word.uppercase()
println(word)
```
