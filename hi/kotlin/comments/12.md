# --description--

एक से अधिक पैरामीटर वाले फ़ंक्शन को उनमें से हर एक के लिए एक `@param` टैग मिलता है, जो पैरामीटर के उसी क्रम में लिखे जाते हैं:
```kotlin
/**
 * Returns the area of a rectangle.
 * @param width the horizontal side, in centimetres
 * @param height the vertical side, in centimetres
 * @return the product of [width] and [height]
 */
fun area(width: Int, height: Int): Int {
    return width * height
}
```
एक टैग फिर भी केवल एक कमेंट है: यदि आप किसी पैरामीटर का नाम बदल दें और टैग को अपडेट करना भूल जाएँ, तो कुछ नहीं टूटता, लेकिन दस्तावेज़ीकरण झूठ बोलना शुरू कर देता है। KDoc को सिग्नेचर के साथ एक साथ अपडेट करें।
