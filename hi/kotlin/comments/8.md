# --description--

ब्लॉक कमेंट का एक सामान्य उपयोग **हेडर कमेंट** है: फ़ंक्शन के ठीक ऊपर रखा गया एक छोटा ब्लॉक, जो बताता है कि वह क्या करता है और उसके पैरामीटर का क्या अर्थ है।
```kotlin
/*
Returns the number of seconds in the given minutes.
minutes is a whole number, never negative.
*/
fun toSeconds(minutes: Int): Int {
    return minutes * 60
}
```
अब `toSeconds` को कॉल करने वाला कोई भी व्यक्ति बॉडी की जगह हेडर पढ़ सकता है। हेडर को फ़ंक्शन के पास ही रखें ताकि दोनों एक साथ अपडेट हों।
