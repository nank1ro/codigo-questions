# --description--

कंपाइलर कमेंट केवल कोड में ढूंढता है, कभी भी **स्ट्रिंग लिटरल** के अंदर नहीं। दोहरे उद्धरण चिह्नों के बीच `//` और `/* */` साधारण अक्षर होते हैं:
```kotlin
println("50 // 2") // prints 50 // 2
```
पहला `//` टेक्स्ट का हिस्सा है, दूसरा एक असली कमेंट शुरू करता है। यह लोगों को सबसे अधिक वेब पतों के साथ चौंकाता है, जिनमें प्रोटोकॉल के ठीक बाद `//` आता है।
