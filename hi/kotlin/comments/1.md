# --description--

एक **कमेंट** सोर्स कोड के अंदर लिखा गया एक नोट होता है, जो उसे पढ़ने वाले लोगों के लिए होता है। कंपाइलर कमेंट्स को पूरी तरह अनदेखा कर देता है, इसलिए वे कभी भी प्रोग्राम के काम को नहीं बदलते।

सबसे सरल कमेंट **सिंगल-लाइन कमेंट** है: यह `//` से शुरू होकर लाइन के अंत तक चलता है।
```kotlin
// Greets the user
println("Hello")
```
किसी कोड का उद्देश्य क्या है, या वह इस तरह क्यों लिखा गया, यह समझाने के लिए कमेंट्स का उपयोग करें।
