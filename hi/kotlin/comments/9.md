# --description--

Kotlin में कमेंट की तीसरी किस्म है, **डॉक्युमेंटेशन कमेंट**, जो **KDoc** नाम के फ़ॉर्मेट में लिखा जाता है: यह `/**` (एक स्लैश और दो एस्टरिस्क) से शुरू होकर `*/` पर समाप्त होता है, और इसे फ़ंक्शन, क्लास या प्रॉपर्टी के ठीक ऊपर रखा जाता है।
```kotlin
/**
 * Returns the greeting for [name].
 */
fun greet(name: String): String {
    return "Hi, $name!"
}
```
कंपाइलर के लिए तो यह बस एक कमेंट है, लेकिन IntelliJ IDEA जैसे टूल इसे पढ़ते हैं और `greet` की सहायता सामग्री के रूप में दिखाते हैं। अंदरूनी लाइनों की शुरुआत में लगा `*` केवल एक परंपरा है जो ब्लॉक को सीधा रखती है। KDoc के अंदर आप Markdown का उपयोग कर सकते हैं, और `[name]` जैसे वर्गाकार कोष्ठक उस पैरामीटर के लिंक बन जाते हैं।

# --instructions--

कोड को पूरा करें ताकि `greet` के ऊपर वाला कमेंट एक डॉक्युमेंटेशन कमेंट हो, जो सही ढंग से खुला और बंद हो। प्रोग्राम `Hi, Ada!` प्रिंट करता है
