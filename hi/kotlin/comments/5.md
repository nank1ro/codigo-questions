# --description--

`//`, जो लाइन के अंत पर रुक जाता है, के विपरीत एक `/*` कमेंट केवल `*/` पर रुकता है। यदि आप उसे बंद करना भूल जाते हैं, तो कंपाइलर उसके बाद के पूरे कोड को कमेंट का हिस्सा मानता है और त्रुटि देता है:
```kotlin
val width = 10 /* in centimetres
println(width) // still inside the comment: error, the comment is never closed
```
`//` और `/* */` दोनों ट्रेलिंग कमेंट के रूप में काम करते हैं, लेकिन `/*` के साथ हमेशा सुनिश्चित करें कि `*/` वहाँ मौजूद हो।

# --asserts--

कमेंट उसी लाइन पर बंद होना चाहिए

```json
{
  "regex": "/\\* twice the input\\s*\\*/",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`twice(4)` को `8` लौटाना चाहिए

```kotlin
    tryCatch(twice(4) == 8)
```

`twice(-3)` को `-6` लौटाना चाहिए

```kotlin
    tryCatch(twice(-3) == -6)
```

```kotlin
    tryCatch(twice(0) == 0)
```
