# --description--

कोरूटीन फ़ंक्शन को कॉल करना ही उसे चलाने के लिए पर्याप्त नहीं है। कॉल केवल एक कोरूटीन ऑब्जेक्ट बनाता है; उसकी बॉडी तभी चलती है जब उस ऑब्जेक्ट को await किया जाए या उसे `asyncio.run` को पास किया जाए:
```python
async def hello():
    print("hi")

hello()  # nothing is printed
```
Python इस पर चेतावनी भी देता है: `RuntimeWarning: coroutine 'hello' was never awaited`। भूला हुआ `await` सबसे आम एसिंक्रोनस बग है: कोड कॉल किया हुआ दिखता है लेकिन कभी निष्पादित नहीं होता, और जो वेरिएबल उसका परिणाम रखना चाहिए, वह उसकी जगह एक कोरूटीन ऑब्जेक्ट रखता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
import asyncio

async def hello():
    print("hi")
    return 1

async def main():
    result = hello()
    print("main")

asyncio.run(main())
```

# --answers--

- केवल `main`, क्योंकि `hello()` एक ऐसा कोरूटीन ऑब्जेक्ट बनाता है जिसे कभी await नहीं किया जाता, इसलिए उसकी बॉडी नहीं चलती
- पहले `hi` फिर `main`, क्योंकि कोरूटीन फ़ंक्शन को कॉल करने पर वह तुरंत चल जाता है
- पहले `main` फिर `hi`, क्योंकि कोरूटीन तब चलता है जब `main` लौटता है
- एक `TypeError`, क्योंकि कोरूटीन को वेरिएबल में असाइन नहीं किया जा सकता
