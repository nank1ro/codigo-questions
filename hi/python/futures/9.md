# --description--

एक छोटा एसिंक्रोनस प्रोग्राम एक निश्चित आकार का होता है: `asyncio` को इंपोर्ट करें, कोरूटीन फ़ंक्शन परिभाषित करें, एक `main` कोरूटीन परिभाषित करें जो उन्हें await करे, और अंत में `asyncio.run(main())` को केवल एक बार कॉल करें।

# --instructions--

आइटम को सॉर्ट करें ताकि ऐसा प्रोग्राम बने जो इंपोर्ट से शुरू हो, `main` से पहले `download` को परिभाषित करे, दो डाउनलोड को `asyncio.gather` के साथ समानांतर रूप से चलाए और परिणाम प्रिंट करे, जिससे आउटपुट `['report.pdf', 'data.csv']` प्राप्त हो

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```
