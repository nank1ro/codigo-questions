# --description--

`gather` के साथ कोरूटीन हर `await` पर अपनी बारी लेते हैं। एक कोरूटीन तब तक चलता है जब तक वह किसी ऐसी चीज़ को await न करे जो अभी तैयार न हो, फिर लूप दूसरे कोरूटीन पर स्विच कर देता है। इसलिए `print` जैसे साइड इफ़ेक्ट उस क्रम में होते हैं जिस क्रम में कोरूटीन **फिर से चलना शुरू (resume)** होते हैं, न कि उस क्रम में जिसमें वे पास किए गए थे:
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    print(await asyncio.gather(step("a", 0.03), step("b", 0.01)))

asyncio.run(main())
```
यह पहले `b`, फिर `a`, और फिर `['a', 'b']` प्रिंट करता है: `b` पहले जागता है, लेकिन परिणामों की लिस्ट आर्ग्युमेंट क्रम बनाए रखती है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
import asyncio

async def step(name, delay):
    await asyncio.sleep(delay)
    print(name)
    return name

async def main():
    names = await asyncio.gather(step("x", 0.03), step("y", 0.01), step("z", 0.02))
    print(names)

asyncio.run(main())
```

# --answers--

- `y`, `z`, `x`, फिर `['x', 'y', 'z']`, क्योंकि हर कोरूटीन तब प्रिंट करता है जब उसकी नींद पूरी होती है लेकिन `gather` आर्ग्युमेंट क्रम बनाए रखता है
- `x`, `y`, `z`, फिर `['x', 'y', 'z']`, क्योंकि `gather` कोरूटीन को एक के बाद एक चलाता है
- `y`, `z`, `x`, फिर `['y', 'z', 'x']`, क्योंकि `gather` परिणाम पूरा होने के क्रम में लौटाता है
- `x`, `y`, `z`, फिर `['y', 'z', 'x']`, क्योंकि सभी प्रिंट किसी भी नींद के शुरू होने से पहले हो जाते हैं
