# --description--

जब संक्रियाओं की संख्या तय न हो, तब कॉन्करेंसी (समानांतर निष्पादन) फ़ायदेमंद होती है। कोरूटीन ऑब्जेक्ट को एक लिस्ट कॉम्प्रिहेंशन में बनाएँ, उन्हें `gather` में अनपैक करें और पूरे बैच का एक साथ इंतज़ार करें:
```python
import asyncio

async def fetch(url):
    await asyncio.sleep(0.02)
    return len(url)

async def fetch_all(urls):
    return await asyncio.gather(*[fetch(u) for u in urls])

print(asyncio.run(fetch_all(["a.com", "bb.com"])))  # [5, 6]
```
दस urls कुल मिलाकर 200 की जगह अब भी लगभग 20 मिलीसेकंड लेते हैं, और परिणाम urls के क्रम में ही रहते हैं।

# --instructions--

एक कोरूटीन फ़ंक्शन `fetch(item_id)` लिखें जो `0.02` सेकंड इंतज़ार करे और `item_id * 10` लौटाए, और एक कोरूटीन फ़ंक्शन `fetch_all(ids)` लिखें जो हर id के लिए `fetch` को `asyncio.gather` के साथ **समानांतर** रूप से चलाए और परिणामों की लिस्ट लौटाए

`fetch(3)` को `30` लौटाना चाहिए

```python
    def test_1(self):
        self.assertEqual(asyncio.run(fetch(3)), 30, "--err-t1--")
```

`fetch_all([1, 2, 3])` को `[10, 20, 30]` लौटाना चाहिए और `fetch_all([])` को `[]` लौटाना चाहिए

```python
    def test_2(self):
        self.assertEqual(asyncio.run(fetch_all([1, 2, 3])), [10, 20, 30], "--err-t2--")
        self.assertEqual(asyncio.run(fetch_all([])), [], "--err-t2--")
```

पाँच ids के साथ `fetch_all` उन्हें समानांतर रूप से चलाना चाहिए, जिसमें `0.1` सेकंड से बहुत कम समय लगे

```python
    def test_3(self):
        start = time.perf_counter()
        result = asyncio.run(fetch_all([1, 2, 3, 4, 5]))
        elapsed = time.perf_counter() - start
        self.assertEqual(result, [10, 20, 30, 40, 50], "--err-t3--")
        self.assertLess(elapsed, 0.08, "--err-t3--")
```
