# --description--

नियमित मेथड्स के अलावा, एक enum `@classmethod` के साथ **क्लास मेथड्स** भी परिभाषित कर सकता है। उन्हें enum क्लास स्वयं `cls` के रूप में मिलती है, इसलिए वे किसी मेंबर को खोजने के वैकल्पिक तरीकों के लिए सही जगह हैं:
```python
class Color(Enum):
    RED = auto()
    BLUE = auto()

    @classmethod
    def parse(cls, text):
        return cls[text.strip().upper()]

print(Color.parse(" blue "))  # Color.BLUE
```
`auto()`, मेथड्स, प्रॉपर्टीज़ और लुकअप्स के साथ मिलकर, यह आपको ऐसे enums बनाने देता है जो अपना व्यवहार साथ रखते हैं।

# --instructions--

`auto()` का उपयोग करके मेंबर्स `NORTH`, `EAST`, `SOUTH` और `WEST`, इसी क्रम में, एक enum `Direction` घोषित करें।
एक मेथड `opposite()` जोड़ें जो विपरीत दिशा की मेंबर रिटर्न करे (`NORTH` और `SOUTH`, `EAST` और `WEST`), और एक क्लास मेथड `parse(text)` जो उस मेंबर को रिटर्न करे जिसका नाम `text` से मैच करता है, केस और आस-पास की स्पेसेस को नज़रअंदाज़ करते हुए

```python
from enum import Enum, auto

class Direction(Enum):
    NORTH = auto()
    EAST = auto()
    SOUTH = auto()
    WEST = auto()

    def opposite(self):
        opposites = {
            Direction.NORTH: Direction.SOUTH,
            Direction.SOUTH: Direction.NORTH,
            Direction.EAST: Direction.WEST,
            Direction.WEST: Direction.EAST,
        }
        return opposites[self]

    @classmethod
    def parse(cls, text):
        return cls[text.strip().upper()]
```
