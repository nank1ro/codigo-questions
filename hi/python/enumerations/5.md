# --description--

आप किसी मेंबर को उसकी **वैल्यू** से क्लास को फ़ंक्शन की तरह कॉल करके, या उसके **नाम** से स्क्वायर ब्रैकेट्स का उपयोग करके प्राप्त कर सकते हैं:
```python
print(Color(2))        # Color.GREEN
print(Color["BLUE"])   # Color.BLUE
```
दोनों तब काम आते हैं जब वैल्यू या नाम प्रोग्राम के बाहर से आता हो, जैसे किसी फ़ाइल या यूज़र इनपुट से।
अगर कुछ भी मैच नहीं होता, तो `Color(9)` एक `ValueError` उठाता है और `Color["PINK"]` एक `KeyError` उठाता है।

# --instructions--

`by_value` में `Status` की वह मेंबर स्टोर करें जिसकी वैल्यू `code` है, `Status(...)` कॉल करके, और `by_name` में वह मेंबर जिसका नाम `label` है, `Status[...]` का उपयोग करके

आपको `Status(...)` को `code` के साथ कॉल करना चाहिए

```json
{
  "regex": "Status\\(\\s*code\\s*\\)",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

आपको `Status[...]` का `label` के साथ उपयोग करना चाहिए

```json
{
  "regex": "Status\\[\\s*label\\s*\\]",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`by_value`, `Status.DONE` होना चाहिए

```python
    def test_1(self):
        self.assertIs(by_value, Status.DONE, "--err-t1--")
```

`by_name`, `Status.FAILED` होना चाहिए

```python
    def test_2(self):
        self.assertIs(by_name, Status.FAILED, "--err-t2--")
```
