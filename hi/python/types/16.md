# --description--

बाहर से आने वाला टेक्स्ट हमेशा एक `str` होता है, और यह पता लगाना कि वह असल में कौन सा टाइप रखता है, आपके प्रोग्राम का काम है।
एक आम तरीका है पहले **सबसे सख्त** कन्वर्ज़न आज़माना, और उसके `ValueError` उठाने पर अगले पर आ जाना:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` ब्लॉक के अंदर एक दूसरा `try` नेस्ट करने से आप एक बार और पीछे हट सकते हैं, उदाहरण के लिए टेक्स्ट को वैसे ही रखने के लिए।
