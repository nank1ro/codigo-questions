# --description--

आप किसी वेरिएबल, पैरामीटर या रिटर्न वैल्यू की अपेक्षित टाइप को एक **टाइप हिंट** के रूप में लिख सकते हैं: वेरिएबल्स और पैरामीटर्स के लिए नाम के बाद एक कोलन, रिटर्न वैल्यू के लिए कोलन से पहले एक एरो `->`:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
हिंट्स लोगों के लिए और एडिटर जैसे टूल्स के लिए **डॉक्यूमेंटेशन** होते हैं: Python उन्हें **जाँचता नहीं** है। यह कोड बिना किसी शिकायत के चलता है और `hello` प्रिंट करता है:
```python
count: int = "hello"
print(count)
```
हिंट्स इच्छित टाइप्स को स्पष्ट करते हैं, लेकिन असली टाइप फिर भी मान तय करता है।
