# --description--

कई भाषाओं के विपरीत, Python के पूर्णांकों की **कोई अधिकतम सीमा नहीं** है: एक `int` जितने अंक चाहिए हों उतने रखने के लिए बढ़ जाता है, इसलिए बड़ी गणनाएँ सटीक रहती हैं:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
दूसरी ओर एक `float` केवल लगभग 15 सार्थक अंक ही रखता है, इसलिए वही घात एक float के रूप में परिशुद्धता खो देती है:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
चूँकि `str()` किसी भी `int` पर काम करता है, किसी संख्या के अंकों की गिनती करने का एक तेज़ तरीका है उसके टेक्स्ट की लंबाई मापना।

# --asserts--

आपको `str()` का उपयोग करना चाहिए

```json
{
  "regex": "str\\(",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`big` का मान `2 ** 200` होना चाहिए

```python
    def test_1(self):
        self.assertEqual(big, 2 ** 200, "--err-t1--")
        self.assertIsInstance(big, int, "--err-t1--")
```

`digits(big)` को `61` वापस करना चाहिए

```python
    def test_2(self):
        self.assertEqual(digits(big), 61, "--err-t2--")
```

`digits(7)` को `1` वापस करना चाहिए और `digits(10 ** 50)` को `51` वापस करना चाहिए

```python
    def test_3(self):
        self.assertEqual(digits(7), 1, "--err-t3--")
        self.assertEqual(digits(10 ** 50), 51, "--err-t3--")
```
