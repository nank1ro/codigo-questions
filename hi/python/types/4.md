# --description--

आप पहले से अंकगणितीय ऑपरेटर्स को जानते हैं। यहाँ मायने रखता है **परिणाम का टाइप**।
एक `int` को एक `float` के साथ मिलाने पर `float` मिलता है, तब भी जब दशमलव भाग शून्य हो:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**ट्रू डिविज़न** `/` हमेशा एक `float` वापस करता है, तब भी जब संख्याएँ पूरी तरह विभाजित हो जाएँ:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**फ्लोर डिविज़न** `//` परिणाम को निकटतम पूर्ण संख्या तक नीचे की ओर राउंड करता है (इसलिए `-7 // 2` का परिणाम `-4` है) और जब दोनों ऑपरेंड पूर्णांक हों तो एक `int` वापस करता है। शेषफल `%` के साथ मिलकर यह एक मात्रा को पूर्ण भागों में बाँटता है:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```
