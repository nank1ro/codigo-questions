# --description--

कन्वर्ज़न को आपस में मिलाया जा सकता है। `int("3.7")` विफल हो जाता है, लेकिन `float("3.7")` काम करता है, और एक `float` का `int()` दशमलव भाग हटा देता है:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` truthiness नियमों का पालन करता है: `bool("")` का परिणाम `False` होता है, और ध्यान दें कि `bool("False")` का परिणाम `True` होता है, क्योंकि यह एक गैर-खाली स्ट्रिंग है।
