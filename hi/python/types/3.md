# --description--

Python **डायनामिकली टाइप्ड** है: टाइप **मान** से जुड़ा होता है, वेरिएबल से नहीं।
वेरिएबल केवल एक मान से जुड़ा एक नाम है, और आप किसी भी समय इसे अलग टाइप के मान से जोड़ सकते हैं:
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
न कोई डिक्लेरेशन चाहिए और न कोई कन्वर्ज़न: पुराना मान बस भूल जाया जाता है।
यह सुविधाजनक है, लेकिन इसका यह मतलब भी है कि वेरिएबल का टाइप केवल प्रोग्राम चलने पर ही पता चलता है, इसलिए गलती से टाइप्स को मिलाना रन टाइम पर एरर के रूप में सामने आता है, उससे पहले नहीं।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
x = 10
x = "ten"
print(type(x))
```

# --answers--

- `<class 'str'>`, क्योंकि `x` अब एक स्ट्रिंग को रेफर करता है
- `<class 'int'>`, क्योंकि `x` का टाइप पहली असाइनमेंट द्वारा तय हो गया था
- एक `TypeError`, क्योंकि एक स्ट्रिंग को एक इंटीजर वेरिएबल में असाइन नहीं किया जा सकता
- `<class 'int'> <class 'str'>`, क्योंकि `x` दोनों मानों को रखता है
