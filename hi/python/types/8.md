# --description--

`bool`, `int` का एक **सबक्लास** है: जहाँ भी एक संख्या की अपेक्षा हो, `True` का व्यवहार `1` जैसा और `False` का `0` जैसा होता है:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` एक लिस्ट के आइटम्स का योग करता है, इसलिए बूलियन की एक लिस्ट का योग करने पर **गिनती** होती है कि उनमें से कितने `True` हैं:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
इस सबक्लास संबंध के कारण `isinstance(True, int)` का परिणाम `True` होता है, जबकि `type(True)` अभी भी `bool` होता है।
