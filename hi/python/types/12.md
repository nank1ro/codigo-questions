# --description--

एक `float` बाइनरी में बिट्स की एक निश्चित संख्या के साथ संग्रहीत होता है, इसलिए अधिकांश दशमलव संख्याओं का केवल **अनुमान** ही लगाया जा सकता है। एरर बहुत छोटा होता है लेकिन यह अंकगणित में सामने आता है:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
इसीलिए आपको floats की तुलना सटीक बराबरी के लिए नहीं करनी चाहिए। दोनों ओर को राउंड करें, या `math.isclose()` का उपयोग करें, जो जाँचता है कि दो संख्याएँ एक बहुत छोटी सहनसीलता के भीतर बराबर हैं:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
पूर्णांकों में यह समस्या नहीं होती: `1 + 2 == 3` हमेशा `True` होता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
print(0.1 + 0.2 == 0.3)
```

# --answers--

- `False`, क्योंकि `0.1 + 0.2` संख्या `0.3` से थोड़ा अधिक है
- `True`, क्योंकि `0.1 + 0.2` बराबर `0.3` है
- `0.3`, क्योंकि `print` जोड़ का परिणाम दिखाता है
- एक `TypeError`, क्योंकि floats की तुलना `==` से नहीं की जा सकती
