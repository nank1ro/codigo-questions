# --description--

कन्वर्ज़न विफल हो सकता है। `int("abc")` कोई संख्या नहीं बना सकता, इसलिए यह एक `ValueError` उठाता है और प्रोग्राम रुक जाता है:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
प्रोग्राम को चलते रखने के लिए आप एरर को `try` / `except` से पकड़ सकते हैं: `try` ब्लॉक का कोड चलता है, और यदि वह नामित एरर उठाता है तो उसकी जगह `except` ब्लॉक चलता है:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
जब कन्वर्ज़न सफल होता है तो `except` ब्लॉक छोड़ दिया जाता है।

    except ValueError:
