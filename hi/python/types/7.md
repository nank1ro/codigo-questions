# --description--

हर मान को बूलियन के रूप में समझा जा सकता है। `bool()` किसी मान को `True` या `False` में बदलता है, और जब कोई मान सीधे एक `if` में उपयोग होता है तो यही नियम लागू होता है।
**false** गिने जाने वाले मान "खाली" वाले होते हैं:
- संख्या `0` (और `0.0`)
- खाली स्ट्रिंग `""`
- खाली कलेक्शन जैसे `[]`, `{}`, `()` और `set()`
- `None`

कोई भी गैर-खाली मान **true** होता है, जिसमें ऋणात्मक संख्याएँ और वे स्ट्रिंग्स शामिल हैं जो केवल खाली दिखती हैं, जैसे `"0"` या `" "`:
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
इसीलिए `if name:` यह जाँचने का एक आम तरीका है कि कोई स्ट्रिंग खाली नहीं है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
print(bool(0), bool("0"), bool([]), bool(None))
```

# --answers--

- `False True False False`, क्योंकि `"0"` एक गैर-खाली स्ट्रिंग है
- `False False False False`, क्योंकि वे सभी शून्य या कुछ नहीं को दर्शाते हैं
- `True True False False`, क्योंकि संख्याएँ हमेशा true होती हैं
- एक `TypeError`, क्योंकि `None` को बूलियन में नहीं बदला जा सकता
