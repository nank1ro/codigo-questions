# --description--

Python में हर मान का एक **टाइप** होता है जो बताता है कि वह किस तरह का डेटा है और आप उसके साथ क्या कर सकते हैं।
बुनियादी बिल्ट-इन टाइप्स ये हैं:
- `int`, एक पूर्ण संख्या जैसे `42` या `-3`
- `float`, दशमलव भाग वाली एक संख्या जैसे `3.5`
- `str`, टेक्स्ट का एक टुकड़ा जैसे `"hello"`
- `bool`, दो मानों `True` और `False` में से एक
- `NoneType`, विशेष मान `None` का टाइप, जिसका मतलब है "कोई मान नहीं"

बिल्ट-इन फंक्शन `type()` किसी मान का टाइप वापस करता है। इसे प्रिंट करने पर क्लास का नाम दिखता है:
```python
print(type(42))     # <class 'int'>
print(type("hi"))   # <class 'str'>
```
आप खुद कभी `NoneType` नहीं लिखेंगे: `type(None)` इसे वापस करता है, लेकिन यह नाम बाकी चारों की तरह बिल्ट-इन नहीं है।
