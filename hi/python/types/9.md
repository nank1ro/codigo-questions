# --description--

`None` अपने आप में एक ऐसा मान है जिसका मतलब है "यहाँ कुछ नहीं"। यह वह है जो एक फंक्शन वापस करता है जब उसमें कोई `return` स्टेटमेंट नहीं होता, और यह किसी ऐसे मान के लिए एक आम प्लेसहोल्डर है जो अभी ज्ञात नहीं है।
चूँकि केवल एक ही `None` होता है, इसे `==` से नहीं बल्कि `is` से जाँचें:
```python
result = None
if result is None:
    print("no result yet")
```
हर टाइप में एक `__name__` एट्रिब्यूट होता है जिसमें उसका नाम एक स्ट्रिंग के रूप में होता है, जो मैसेज के लिए उपयोगी है:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

```json

```

`describe(None)` को `"nothing"` वापस करना चाहिए

```python
    def test_1(self):
        self.assertEqual(describe(None), "nothing", "--err-t1--")
```

`describe(5)` को `"int"` वापस करना चाहिए और `describe(2.0)` को `"float"` वापस करना चाहिए

```python
    def test_2(self):
        self.assertEqual(describe(5), "int", "--err-t2--")
        self.assertEqual(describe(2.0), "float", "--err-t2--")
```

`describe("a")` को `"str"` वापस करना चाहिए और `describe(True)` को `"bool"` वापस करना चाहिए

```python
    def test_3(self):
        self.assertEqual(describe("a"), "str", "--err-t3--")
        self.assertEqual(describe(True), "bool", "--err-t3--")
```
