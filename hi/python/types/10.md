# --description--

एक `float` को प्रिंट करने पर उसे ठीक-ठीक दर्शाने के लिए जितने अंकों की ज़रूरत हो उतने दिखाए जाते हैं, जो अक्सर बहुत अधिक होते हैं:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
एक f-string के अंदर आप कोलन के बाद एक **फॉर्मेट स्पेसिफिकेशन** जोड़ सकते हैं। `.2f` का मतलब है "2 दशमलवों वाली फिक्स्ड-पॉइंट संख्या":
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
मान को अनुरोधित दशमलवों की संख्या तक राउंड किया जाता है, और ज़रूरत पड़ने पर शून्य जोड़े जाते हैं: `f"{2.5:.2f}"` का परिणाम `2.50` होता है।
