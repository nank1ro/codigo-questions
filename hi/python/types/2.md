# --description--

`type()` किसी मान की क्लास वापस करता है, इसलिए आप `is` का उपयोग करके इसकी तुलना एक क्लास नाम से कर सकते हैं:
```python
age = 30
print(type(age) is int)  # True
```
लेकिन ज़्यादातर समय आप केवल यह जानना चाहते हैं कि कोई मान किसी दिए गए टाइप का **है या नहीं**। यही काम `isinstance(value, cls)` करता है, जो `True` या `False` वापस करता है:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
दूसरा आर्ग्युमेंट क्लासों का एक **tuple** भी हो सकता है: परिणाम `True` होता है यदि मान उनमें से किसी एक से संबंधित है:
```python
print(isinstance(2.5, (int, float)))  # True
```
