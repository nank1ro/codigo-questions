Python में हर मान का एक **टाइप** होता है जो बताता है कि वह किस तरह का डेटा है और आप उसके साथ क्या कर सकते हैं।
बुनियादी बिल्ट-इन टाइप्स ये हैं:
- `int`, एक पूर्ण संख्या जैसे `42` या `-3`
- `float`, दशमलव भाग वाली एक संख्या जैसे `3.5`
- `str`, टेक्स्ट का एक टुकड़ा जैसे `"hello"`
- `bool`, दो मानों `True` और `False` में से एक
- `NoneType`, विशेष मान `None` का टाइप, जिसका मतलब है "कोई मान नहीं"

बिल्ट-इन फंक्शन `type()` किसी मान का टाइप वापस करता है। इसे प्रिंट करने पर क्लास का नाम दिखता है:
```python
print(type(42))     # <class 'int'>
print(type("hi"))   # <class 'str'>
```
आप खुद कभी `NoneType` नहीं लिखेंगे: `type(None)` इसे वापस करता है, लेकिन यह नाम बाकी चारों की तरह बिल्ट-इन नहीं है।

---

`type()` किसी मान की क्लास वापस करता है, इसलिए आप `is` का उपयोग करके इसकी तुलना एक क्लास नाम से कर सकते हैं:
```python
age = 30
print(type(age) is int)  # True
```
लेकिन ज़्यादातर समय आप केवल यह जानना चाहते हैं कि कोई मान किसी दिए गए टाइप का **है या नहीं**। यही काम `isinstance(value, cls)` करता है, जो `True` या `False` वापस करता है:
```python
print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
```
दूसरा आर्ग्युमेंट क्लासों का एक **tuple** भी हो सकता है: परिणाम `True` होता है यदि मान उनमें से किसी एक से संबंधित है:
```python
print(isinstance(2.5, (int, float)))  # True
```

---

Python **डायनामिकली टाइप्ड** है: टाइप **मान** से जुड़ा होता है, वेरिएबल से नहीं।
वेरिएबल केवल एक मान से जुड़ा एक नाम है, और आप किसी भी समय इसे अलग टाइप के मान से जोड़ सकते हैं:
```python
x = 10
print(type(x))  # <class 'int'>
x = "ten"
print(type(x))  # <class 'str'>
```
न कोई डिक्लेरेशन चाहिए और न कोई कन्वर्ज़न: पुराना मान बस भूल जाया जाता है।
यह सुविधाजनक है, लेकिन इसका यह मतलब भी है कि वेरिएबल का टाइप केवल प्रोग्राम चलने पर ही पता चलता है, इसलिए गलती से टाइप्स को मिलाना रन टाइम पर एरर के रूप में सामने आता है, उससे पहले नहीं।

---

आप पहले से अंकगणितीय ऑपरेटर्स को जानते हैं। यहाँ मायने रखता है **परिणाम का टाइप**।
एक `int` को एक `float` के साथ मिलाने पर `float` मिलता है, तब भी जब दशमलव भाग शून्य हो:
```python
print(3 + 0.5)   # 3.5
print(2 * 1.0)   # 2.0
```
**ट्रू डिविज़न** `/` हमेशा एक `float` वापस करता है, तब भी जब संख्याएँ पूरी तरह विभाजित हो जाएँ:
```python
print(10 / 5)    # 2.0
print(7 / 2)     # 3.5
```
**फ्लोर डिविज़न** `//` परिणाम को निकटतम पूर्ण संख्या तक नीचे की ओर राउंड करता है (इसलिए `-7 // 2` का परिणाम `-4` है) और जब दोनों ऑपरेंड पूर्णांक हों तो एक `int` वापस करता है। शेषफल `%` के साथ मिलकर यह एक मात्रा को पूर्ण भागों में बाँटता है:
```python
print(7 // 2)    # 3
print(7 % 2)     # 1
```

---

मान अपने आप टाइप नहीं बदलते: किसी मान को दूसरे टाइप में बदलने के लिए आप टाइप के नाम को एक फंक्शन की तरह कॉल करते हैं। इसे **कन्वर्ज़न** (या *कास्टिंग*) कहते हैं:
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` और `float()` टेक्स्ट के रूप में लिखी संख्याओं को पढ़ते हैं, जो आपको यूज़र इनपुट या फाइलों से मिलती है। `str()` किसी भी चीज़ को टेक्स्ट में बदल देता है, ताकि उसे `+` से अन्य स्ट्रिंग्स के साथ जोड़ा जा सके।
ध्यान दें कि `int(3.9)` राउंड नहीं करता: यह दशमलव भाग हटा देता है।

---

कन्वर्ज़न विफल हो सकता है। `int("abc")` कोई संख्या नहीं बना सकता, इसलिए यह एक `ValueError` उठाता है और प्रोग्राम रुक जाता है:
```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
int("3.5")   # ValueError as well: "3.5" is not a whole number
```
प्रोग्राम को चलते रखने के लिए आप एरर को `try` / `except` से पकड़ सकते हैं: `try` ब्लॉक का कोड चलता है, और यदि वह नामित एरर उठाता है तो उसकी जगह `except` ब्लॉक चलता है:
```python
try:
    number = int(text)
except ValueError:
    number = 0
```
जब कन्वर्ज़न सफल होता है तो `except` ब्लॉक छोड़ दिया जाता है।

---

हर मान को बूलियन के रूप में समझा जा सकता है। `bool()` किसी मान को `True` या `False` में बदलता है, और जब कोई मान सीधे एक `if` में उपयोग होता है तो यही नियम लागू होता है।
**false** गिने जाने वाले मान "खाली" वाले होते हैं:
- संख्या `0` (और `0.0`)
- खाली स्ट्रिंग `""`
- खाली कलेक्शन जैसे `[]`, `{}`, `()` और `set()`
- `None`

कोई भी गैर-खाली मान **true** होता है, जिसमें ऋणात्मक संख्याएँ और वे स्ट्रिंग्स शामिल हैं जो केवल खाली दिखती हैं, जैसे `"0"` या `" "`:
```python
print(bool(0))     # False
print(bool(-1))    # True
print(bool(""))    # False
print(bool("0"))   # True
```
इसीलिए `if name:` यह जाँचने का एक आम तरीका है कि कोई स्ट्रिंग खाली नहीं है।

---

`bool`, `int` का एक **सबक्लास** है: जहाँ भी एक संख्या की अपेक्षा हो, `True` का व्यवहार `1` जैसा और `False` का `0` जैसा होता है:
```python
print(True + 1)     # 2
print(True == 1)    # True
print(False * 10)   # 0
```
`sum()` एक लिस्ट के आइटम्स का योग करता है, इसलिए बूलियन की एक लिस्ट का योग करने पर **गिनती** होती है कि उनमें से कितने `True` हैं:
```python
answers = [True, False, True]
print(sum(answers))  # 2
```
इस सबक्लास संबंध के कारण `isinstance(True, int)` का परिणाम `True` होता है, जबकि `type(True)` अभी भी `bool` होता है।

---

`None` अपने आप में एक ऐसा मान है जिसका मतलब है "यहाँ कुछ नहीं"। यह वह है जो एक फंक्शन वापस करता है जब उसमें कोई `return` स्टेटमेंट नहीं होता, और यह किसी ऐसे मान के लिए एक आम प्लेसहोल्डर है जो अभी ज्ञात नहीं है।
चूँकि केवल एक ही `None` होता है, इसे `==` से नहीं बल्कि `is` से जाँचें:
```python
result = None
if result is None:
    print("no result yet")
```
हर टाइप में एक `__name__` एट्रिब्यूट होता है जिसमें उसका नाम एक स्ट्रिंग के रूप में होता है, जो मैसेज के लिए उपयोगी है:
```python
print(type(3).__name__)     # int
print(type(None).__name__)  # NoneType
```

---

एक `float` को प्रिंट करने पर उसे ठीक-ठीक दर्शाने के लिए जितने अंकों की ज़रूरत हो उतने दिखाए जाते हैं, जो अक्सर बहुत अधिक होते हैं:
```python
print(19.999 * 3)  # 59.997
print(10 / 3)      # 3.3333333333333335
```
एक f-string के अंदर आप कोलन के बाद एक **फॉर्मेट स्पेसिफिकेशन** जोड़ सकते हैं। `.2f` का मतलब है "2 दशमलवों वाली फिक्स्ड-पॉइंट संख्या":
```python
total = 10 / 3
print(f"{total:.2f}")   # 3.33
print(f"{total:.0f}")   # 3
```
मान को अनुरोधित दशमलवों की संख्या तक राउंड किया जाता है, और ज़रूरत पड़ने पर शून्य जोड़े जाते हैं: `f"{2.5:.2f}"` का परिणाम `2.50` होता है।

---

फॉर्मेटिंग केवल यह बदलती है कि एक संख्या कैसे प्रदर्शित होती है। एक राउंड किया हुआ **मान** पाने के लिए बिल्ट-इन `round()` का उपयोग करें:
```python
print(round(3.14159, 2))  # 3.14
print(round(2.71828, 1))  # 2.7
```
एक आर्ग्युमेंट के साथ `round()` निकटतम पूर्ण संख्या तक राउंड करके एक `int` वापस करता है; दशमलवों की संख्या देने पर वह एक `float` वापस करता है:
```python
print(round(3.7))     # 4
print(round(3.7, 0))  # 4.0
```
ध्यान दें कि दो संख्याओं के ठीक बीच में आने वाले मान **सम** संख्या की ओर राउंड होते हैं: `round(2.5)` का परिणाम `2` है और `round(3.5)` का `4`।

---

एक `float` बाइनरी में बिट्स की एक निश्चित संख्या के साथ संग्रहीत होता है, इसलिए अधिकांश दशमलव संख्याओं का केवल **अनुमान** ही लगाया जा सकता है। एरर बहुत छोटा होता है लेकिन यह अंकगणित में सामने आता है:
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
इसीलिए आपको floats की तुलना सटीक बराबरी के लिए नहीं करनी चाहिए। दोनों ओर को राउंड करें, या `math.isclose()` का उपयोग करें, जो जाँचता है कि दो संख्याएँ एक बहुत छोटी सहनसीलता के भीतर बराबर हैं:
```python
import math
print(round(0.1 + 0.2, 2) == 0.3)  # True
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
पूर्णांकों में यह समस्या नहीं होती: `1 + 2 == 3` हमेशा `True` होता है।

---

कई भाषाओं के विपरीत, Python के पूर्णांकों की **कोई अधिकतम सीमा नहीं** है: एक `int` जितने अंक चाहिए हों उतने रखने के लिए बढ़ जाता है, इसलिए बड़ी गणनाएँ सटीक रहती हैं:
```python
print(3 ** 100)  # 515377520732011331036461129765621272702107522001
```
दूसरी ओर एक `float` केवल लगभग 15 सार्थक अंक ही रखता है, इसलिए वही घात एक float के रूप में परिशुद्धता खो देती है:
```python
print(3.0 ** 100)  # 5.153775207320113e+47
```
चूँकि `str()` किसी भी `int` पर काम करता है, किसी संख्या के अंकों की गिनती करने का एक तेज़ तरीका है उसके टेक्स्ट की लंबाई मापना।

---

आप किसी वेरिएबल, पैरामीटर या रिटर्न वैल्यू की अपेक्षित टाइप को एक **टाइप हिंट** के रूप में लिख सकते हैं: वेरिएबल्स और पैरामीटर्स के लिए नाम के बाद एक कोलन, रिटर्न वैल्यू के लिए कोलन से पहले एक एरो `->`:
```python
count: int = 3

def greet(name: str) -> str:
    return "Hi " + name
```
हिंट्स लोगों के लिए और एडिटर जैसे टूल्स के लिए **डॉक्यूमेंटेशन** होते हैं: Python उन्हें **जाँचता नहीं** है। यह कोड बिना किसी शिकायत के चलता है और `hello` प्रिंट करता है:
```python
count: int = "hello"
print(count)
```
हिंट्स इच्छित टाइप्स को स्पष्ट करते हैं, लेकिन असली टाइप फिर भी मान तय करता है।

---

कन्वर्ज़न को आपस में मिलाया जा सकता है। `int("3.7")` विफल हो जाता है, लेकिन `float("3.7")` काम करता है, और एक `float` का `int()` दशमलव भाग हटा देता है:
```python
number = float("3.7")   # 3.7
print(int(number))      # 3
```
`bool()` truthiness नियमों का पालन करता है: `bool("")` का परिणाम `False` होता है, और ध्यान दें कि `bool("False")` का परिणाम `True` होता है, क्योंकि यह एक गैर-खाली स्ट्रिंग है।

---

बाहर से आने वाला टेक्स्ट हमेशा एक `str` होता है, और यह पता लगाना कि वह असल में कौन सा टाइप रखता है, आपके प्रोग्राम का काम है।
एक आम तरीका है पहले **सबसे सख्त** कन्वर्ज़न आज़माना, और उसके `ValueError` उठाने पर अगले पर आ जाना:
```python
try:
    value = int(text)
except ValueError:
    value = float(text)
```
`except` ब्लॉक के अंदर एक दूसरा `try` नेस्ट करने से आप एक बार और पीछे हट सकते हैं, उदाहरण के लिए टेक्स्ट को वैसे ही रखने के लिए।
