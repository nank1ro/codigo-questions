# --description--

मान अपने आप टाइप नहीं बदलते: किसी मान को दूसरे टाइप में बदलने के लिए आप टाइप के नाम को एक फंक्शन की तरह कॉल करते हैं। इसे **कन्वर्ज़न** (या *कास्टिंग*) कहते हैं:
```python
print(int("42"))      # 42
print(float("3.5"))   # 3.5
print(str(7))         # '7'
print(int(3.9))       # 3
```
`int()` और `float()` टेक्स्ट के रूप में लिखी संख्याओं को पढ़ते हैं, जो आपको यूज़र इनपुट या फाइलों से मिलती है। `str()` किसी भी चीज़ को टेक्स्ट में बदल देता है, ताकि उसे `+` से अन्य स्ट्रिंग्स के साथ जोड़ा जा सके।
ध्यान दें कि `int(3.9)` राउंड नहीं करता: यह दशमलव भाग हटा देता है।
