# --description--

**अपवाद (exception)** Python का यह बताने का तरीका है कि कोई स्टेटमेंट पूरा नहीं किया जा सकता। शून्य से भाग देना, `"abc"` को इंटीजर में बदलना या डिक्शनरी की गायब कुंजी पढ़ना — ये सभी एक अपवाद उत्पन्न करते हैं। जब उसे संभालने वाला कोई नहीं होता, तो प्रोग्राम वहीं रुक जाता है और एक **ट्रेसबैक (traceback)** प्रिंट करता है:
```python
print(10 / 0)
```
```
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(10 / 0)
          ~~~^~~
ZeroDivisionError: division by zero
```
ट्रेसबैक चल रही लाइनों की सूची दिखाता है, और आखिरी लाइन **अपवाद का टाइप** (`ZeroDivisionError`) और उसका मैसेज (`division by zero`) बताती है। आखिरी लाइन को सबसे पहले पढ़ना चाहिए।

प्रोग्राम को चालू रखने के लिए, जोखिम भरे स्टेटमेंट को `try` ब्लॉक में रखें और उबरने का तरीका `except` ब्लॉक में लिखें:
```python
try:
    print(10 / 0)
except ZeroDivisionError:
    print("cannot divide by zero")
```
Python `try` ब्लॉक चलाता है; अगर बताया गया अपवाद उत्पन्न होता है तो वह सीधे मैच करने वाले `except` ब्लॉक पर कूद जाता है और प्रोग्राम का बाकी हिस्सा चलाता रहता है।
