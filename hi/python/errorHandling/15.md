# --description--

कभी-कभी हैंडलर को किसी फेल होने पर प्रतिक्रिया देनी चाहिए पर उसकी ज़िम्मेदारी लिए बिना: उसे लॉग करना, गिनना, कुछ बंद करना — और फिर कॉलर पर छोड़ देना। `except` ब्लॉक के अंदर अकेला `raise` संभाले जा रहे अपवाद को **दोबारा उत्पन्न (re-raise)** करता है, उसका असली टाइप, मैसेज और ट्रेसबैक यथावत रखते हुए:
```python
try:
    value = int(text)
except ValueError:
    print("could not read the value")
    raise
```
इसकी जगह `raise ValueError(...)` लिखने से एक नया अपवाद अपने खुद के ट्रेसबैक के साथ बनेगा — यह वही फेल होना नहीं रह जाएगा जिसे आपने पकड़ा था, और यही पहचान एक अकेला `raise` सुरक्षित रखता है।

    except ValueError:
        print(f"could not read {text}")
        raise
