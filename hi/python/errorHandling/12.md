# --description--

आपका अपना कोड भी अपवाद उत्पन्न कर सकता है, `raise` स्टेटमेंट के बाद एक अपवाद ऑब्जेक्ट रखकर:
```python
def set_age(age):
    if age < 0:
        raise ValueError("age cannot be negative")
    return age
```
`raise` फंक्शन को तुरंत रोक देता है, बिल्कुल वैसे ही जैसे कोई बिल्ट-इन फेल होना रोकता है। इसकी जगह कोई एरर मान लौटाना — `-1`, `None`, `False` — कॉलर के लिए भूलना आसान है; अपवाद को गलती से नज़रअंदाज़ नहीं किया जा सकता।

वही टाइप चुनें जो समस्या को बताता है: `ValueError` जब आर्ग्युमेंट का टाइप सही हो पर मान नामुमकिन हो, `TypeError` जब टाइप ही गलत हो। अपवाद को दिया गया टेक्स्ट उसका मैसेज होता है।
