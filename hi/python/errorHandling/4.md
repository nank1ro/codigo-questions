# --description--

एक `except` क्लॉज़ केवल वही टाइप पकड़ता है जिसका नाम उसमें लिखा होता है, और उसकी सबक्लासेस। यही तो मकसद है: बाकी सब कुछ बाहर की ओर चलता रहता है, ताकि कोई अनजान बग निगला न जाए बल्कि ट्रेसबैक की तरह सामने आए।

`int(text)` **`ValueError`** उत्पन्न करता है जब टेक्स्ट कोई पूर्ण संख्या नहीं दर्शाता, इसलिए यूज़र इनपुट पढ़ते समय यही टाइप नाम से बताना चाहिए:
```python
def to_int(text):
    try:
        return int(text)
    except ValueError:
        return 0

print(to_int("12"))    # 12
print(to_int("oops"))  # 0
```
यहाँ `ValueError` का नाम लेना एक फैसला है, कोई औपचारिकता नहीं: `int(None)` `TypeError` उत्पन्न करता है, जिसे यह फंक्शन जान-बूझकर **नहीं** पकड़ता, क्योंकि `None` पास करना एक प्रोग्रामिंग की गलती है और उसे दिखना चाहिए।
