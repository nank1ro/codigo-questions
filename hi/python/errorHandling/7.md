# --description--

जब कई फेल होने **एक जैसी** रिकवरी के हकदार हों, तो उन्हें एक ही क्लॉज़ में टपल की तरह लिखना ब्लॉक दोहराने से छोटा होता है:
```python
try:
    value = int(text) / divisor
except (ValueError, ZeroDivisionError):
    value = 0
```
कोष्ठक ज़रूरी हैं: `except ValueError, ZeroDivisionError:` Python 3 में एक सिंटैक्स एरर है। टपल फिर भी टाइप्स की एक साफ़-साफ़ सूची है।

# --instructions--

एक फंक्शन `safe_ratio(a, b)` लिखें जो `a / b` लौटाता है, और `None` लौटाता है जब भाग देने पर `ZeroDivisionError` या `TypeError` उत्पन्न हो, दोनों टाइप्स के टपल वाले एक ही `except` क्लॉज़ का उपयोग करते हुए

# --solutions--

```python
def safe_ratio(a, b):
    try:
        return a / b
    except (ZeroDivisionError, TypeError):
        return None
```
