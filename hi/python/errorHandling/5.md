# --description--

जिस फेल होने की आपको उम्मीद है उसे कवर करने वाला सबसे सँकरा (narrowest) टाइप चुनना ही एरर हैंडलिंग को भरोसेमंद बनाता है। टेक्स्ट पढ़ने वाले फंक्शन को खराब टेक्स्ट (`ValueError`) से उबरना चाहिए, लेकिन गलत किस्म के आर्ग्युमेंट (`TypeError`) के साथ कॉल होने को छिपाना नहीं चाहिए — वह एरर कॉलर का होता है, इसलिए उसे आगे जाने दें।

# --instructions--

एक फंक्शन `parse_age(text)` लिखें जो `int(text)` लौटाता है, और जब `text` कोई मान्य पूर्ण संख्या नहीं है तो `-1` लौटाता है। केवल `ValueError` पकड़ें, ताकि `parse_age(None)` अब भी `TypeError` उत्पन्न करे

def parse_age(text):
    try:
        return int(text)
    except ValueError:
        return -1
