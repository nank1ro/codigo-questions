# --description--

`finally` ब्लॉक **हर हाल में** चलता है: बिना किसी गड़बड़ के पूरे हुए `try` ब्लॉक के बाद, किसी `except` ब्लॉक के बाद, यहाँ तक कि तब भी जब कोई पकड़ा न गया अपवाद बाहर की ओर जा रहा हो, और तब भी जब `try` या `except` ब्लॉक कोई `return` चला दे:
```python
def read(text):
    try:
        return int(text)
    except ValueError:
        return 0
    finally:
        print("done")
```
दोनों रास्तों पर मान के फंक्शन छोड़ने से पहले `done` प्रिंट होता है। यही गारंटी `finally` का मकसद है: फाइल बंद करना, लॉक छोड़ना, सेटिंग वापस लाना। पूरा ढाँचा `try` / `except` / `else` / `finally` है; `try` को कम से कम एक `except` या एक `finally` चाहिए, और `else` केवल `except` के साथ ही काम करता है।
