# --description--

कुछ बिल्ट-इन अपवाद रोज़मर्रा की ज़्यादातर फेल होने को कवर कर लेते हैं:

| अपवाद | कब उत्पन्न होता है | उदाहरण |
|---|---|---|
| `ValueError` | टाइप सही है पर मान नामुमकिन है | `int("abc")` |
| `TypeError` | टाइप ही गलत है | `"x" + 1` |
| `ZeroDivisionError` | भाग या मॉड्यूलो का भाजक शून्य है | `1 / 0` |
| `KeyError` | डिक्शनरी में ऐसी कुंजी नहीं है | `{"a": 1}["b"]` |
| `IndexError` | सीक्वेंस का इंडेक्स रेंज से बाहर है | `[1, 2][5]` |

नया टाइप गढ़ने के बजाय इनमें से किसी एक का उपयोग करने से आपके एरर Python जानने वाले किसी भी व्यक्ति के लिए पढ़ने योग्य रहते हैं।

# --instructions--

एक फंक्शन `get_item(values, index)` लिखें जो `values[index]` लौटाता है, जब `index` नेगेटिव हो तो `"index must be positive"` मैसेज के साथ `ValueError` उत्पन्न करे, और `None` लौटाए जब इंडेक्स रेंज से बाहर हो

# --asserts--

`get_item([1, 2, 3], 1)` को `2` लौटाना चाहिए

```python
    def test_1(self):
        self.assertEqual(get_item([1, 2, 3], 1), 2, "--err-t1--")
```

`get_item([1, 2, 3], 9)` को `None` लौटाना चाहिए

```python
    def test_2(self):
        self.assertIsNone(get_item([1, 2, 3], 9), "--err-t2--")
```

`get_item([1, 2, 3], -1)` को वह मैसेज ले जाता हुआ `ValueError` उत्पन्न करना चाहिए

```python
    def test_3(self):
        with self.assertRaises(ValueError, msg="--err-t3--") as ctx:
            get_item([1, 2, 3], -1)
        self.assertEqual(str(ctx.exception), "index must be positive", "--err-t3--")
```

# --solutions--

```python
def get_item(values, index):
    if index < 0:
        raise ValueError("index must be positive")
    try:
        return values[index]
    except IndexError:
        return None
```
