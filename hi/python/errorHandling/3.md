# --description--

जिस अपवाद से कोई `except` ब्लॉक मैच नहीं होता, वह बाहर की ओर चलता रहता है: लाइन से बाहर, उसे चलाने वाले फंक्शन से बाहर, उसके कॉलर से बाहर, और इसी तरह आगे। अगर प्रोग्राम के सबसे ऊपर तक पहुँचने से पहले उसे कोई नहीं पकड़ता, तो Python ट्रेसबैक प्रिंट करता है और प्रोसेस नॉन-ज़ीरो एग्ज़िट स्टेटस के साथ खत्म होती है। फेल होने वाले स्टेटमेंट के बाद की लाइनें कभी नहीं चलतीं।

# --instructions--

जब यह कोड चलता है तो क्या होता है?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- यह `start` प्रिंट करता है, फिर `TypeError` पर खत्म होने वाला एक ट्रेसबैक, और न `end` प्रिंट होता है न `after`, क्योंकि पकड़ा न गया अपवाद प्रोग्राम को रोक देता है
- यह `start`, `end` और `after` प्रिंट करता है, क्योंकि Python केवल फेल होने वाली लाइन छोड़ता है
- यह `start` और `after` प्रिंट करता है, क्योंकि अपवाद `sizes` को रोक देता है लेकिन प्रोग्राम चलता रहता है
- यह `start` और `0` प्रिंट करता है, क्योंकि `len(None)` `0` होता है
