# --description--

एक `try` ब्लॉक के बाद **कई** `except` क्लॉज़ हो सकते हैं, हर एक अलग फेल होने को अलग रिकवरी से संभालता है। Python उत्पन्न हुए अपवाद की तुलना ऊपर से नीचे तक इनसे करता है और **पहला** मैच करने वाला चलाता है; बाकी छोड़ दिए जाते हैं:
```python
try:
    value = 100 / int(text)
except ValueError:
    print("not a number")
except ZeroDivisionError:
    print("cannot divide by zero")
```
चूँकि पहला मैच जीतता है, संबंधित टाइप्स के बीच क्रम मायने रखता है: एक सामान्य टाइप वाला क्लॉज़ अगर किसी ज़्यादा विशिष्ट टाइप वाले क्लॉज़ के ऊपर रखा हो तो हमेशा जीत जाएगा, और विशिष्ट क्लॉज़ कभी पहुँच ही नहीं पाएगा।
