# --description--

अपवाद एक ऑब्जेक्ट होता है, और `as` उसे एक नाम से बाँध देता है ताकि हैंडलर उसे देख सके:
```python
try:
    int("abc")
except ValueError as e:
    print(e)                   # invalid literal for int() with base 10: 'abc'
    print(type(e).__name__)    # ValueError
```
`str(e)` — जो `print(e)` और f-slot का उपयोग करता है — वही मैसेज देता है जिसके साथ अपवाद बना था, और `type(e).__name__` क्लास का नाम टेक्स्ट की तरह देता है। `as` से बँधा नाम केवल `except` ब्लॉक के अंदर मौजूद रहता है; ब्लॉक खत्म होने पर Python उसे डिलीट कर देता है।

# --instructions--

एक फंक्शन `error_label(text)` लिखें जो `int(text)` लौटाता है, और जब वह `ValueError` उत्पन्न करे तो अपवाद क्लास के नाम, `": "` और अपवाद के मैसेज से बनी एक स्ट्रिंग लौटाता है, जैसे `"ValueError: ..."`

# --solutions--

```python
def error_label(text):
    try:
        return int(text)
    except ValueError as e:
        return f"{type(e).__name__}: {e}"
```
