# --description--

जब कोई बिल्ट-इन टाइप फिट न हो, तो `Exception` की सबक्लास बनाकर अपना खुद का परिभाषित करें। खाली बॉडी आम तौर पर काफ़ी होती है — नाम ही पाठक को मिलने वाला मैसेज है:
```python
class ConfigError(Exception):
    pass
```
यह किसी और अपवाद की तरह ही व्यवहार करता है: `raise ConfigError("bad port")`, और `except ConfigError:` उसे पकड़ लेता है।

किसी लो-लेवल फेल होने को अपने टाइप में बदलना आम बात है, और इस प्रक्रिया में असली एरर खोना नहीं चाहिए। `raise NewError(...) from original` दोनों को **जोड़ता (chain)** है: यह `original` को नए अपवाद के `__cause__` एट्रिब्यूट में सँजोता है, और ट्रेसबैक दोनों को *The above exception was the direct cause of the following exception* के नीचे दिखाता है:
```python
try:
    port = int(text)
except ValueError as e:
    raise ConfigError("bad port") from e
```
`from e` के बिना भी दोनों अप्रत्यक्ष रूप से जुड़े रहते हैं, पर `from` साफ़ शब्दों में कहता है कि पहले एरर ने दूसरा पैदा किया।

# --instructions--

`Exception` की सबक्लास बनने वाली एक अपवाद क्लास `ConfigError` परिभाषित करें, और एक फंक्शन `read_port(text)` लिखें जो `int(text)` लौटाता है और, जब वह `ValueError` उत्पन्न करे, तो `raise ... from` से उससे जोड़कर `ConfigError("bad port")` उत्पन्न करे

# --asserts--

`read_port("8080")` को `8080` लौटाना चाहिए, और `ConfigError` को `Exception` की सबक्लास होनी चाहिए

```python
    def test_1(self):
        self.assertEqual(read_port("8080"), 8080, "--err-t1--")
        self.assertTrue(issubclass(ConfigError, Exception), "--err-t1--")
```

`read_port("abc")` को `"bad port"` मैसेज वाला `ConfigError` उत्पन्न करना चाहिए

```python
    def test_2(self):
        with self.assertRaises(ConfigError, msg="--err-t2--") as ctx:
            read_port("abc")
        self.assertEqual(str(ctx.exception), "bad port", "--err-t2--")
```

उत्पन्न हुआ `ConfigError` असली `ValueError` से जुड़ा (chained) होना चाहिए

```python
    def test_3(self):
        with self.assertRaises(ConfigError, msg="--err-t3--") as ctx:
            read_port("abc")
        self.assertIsInstance(ctx.exception.__cause__, ValueError, "--err-t3--")
```
