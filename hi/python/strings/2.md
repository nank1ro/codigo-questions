# --description--

बिल्ट-इन फ़ंक्शन `len()` एक स्ट्रिंग की **लंबाई** लौटाता है, यानी इसमें कितने कैरेक्टर्स हैं।
स्पेस और विराम चिह्न (punctuation) भी कैरेक्टर्स के रूप में गिने जाते हैं:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
