# --description--

एक **स्लाइस (slice)** स्ट्रिंग का एक हिस्सा निकालता है।
स्क्वायर ब्रैकेट्स के बीच `[start:end]` लिखें: `start` पर मौजूद कैरेक्टर शामिल होता है, `end` पर मौजूद कैरेक्टर **शामिल नहीं** होता:
```python
word = "python"
print(word[0:3])  # pyt
print(word[2:4])  # th
```
आप शुरुआत से स्लाइस करने के लिए `start` को, या अंत तक स्लाइस करने के लिए `end` को छोड़ सकते हैं:
```python
print(word[:2])  # py
print(word[2:])  # thon
```
स्लाइसिंग कभी एरर नहीं देती: लंबाई से बड़ा `end` बस आखिरी कैरेक्टर पर रुक जाता है।
