# --description--

`in` ऑपरेटर यह जाँचता है कि क्या एक स्ट्रिंग में दूसरी स्ट्रिंग **मौजूद** है।
यह `True` या `False` लौटाता है, इसलिए यह `if` के अंदर स्वाभाविक रूप से फिट बैठता है:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` उल्टी जाँच करता है।
