एक **स्ट्रिंग (string)** टेक्स्ट का एक टुकड़ा है: उद्धरण चिह्नों (quotes) में लिपटे हुए कैरेक्टर्स का एक क्रम।
Python सिंगल `'...'` और डबल `"..."` दोनों तरह के उद्धरण चिह्न स्वीकार करता है, और दोनों बिल्कुल एक जैसे काम करते हैं:
```python
name = 'Ada'
language = "Python"
```
जब टेक्स्ट में खुद एक उद्धरण चिह्न होता है, तो यह चुनाव मायने रखता है।
सिंगल कोट्स के अंदर एक अपॉस्ट्रॉफी स्ट्रिंग को बहुत जल्दी समाप्त कर देगी, इसलिए उस टेक्स्ट को इसके बजाय डबल कोट्स में लपेटें:
```python
print("It's sunny")  # It's sunny
```

---

बिल्ट-इन फ़ंक्शन `len()` एक स्ट्रिंग की **लंबाई** लौटाता है, यानी इसमें कितने कैरेक्टर्स हैं।
स्पेस और विराम चिह्न (punctuation) भी कैरेक्टर्स के रूप में गिने जाते हैं:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```

---

स्ट्रिंग के हर कैरेक्टर की एक पोज़िशन होती है जिसे **इंडेक्स (index)** कहते हैं।
इंडेक्स `1` से नहीं, `0` से शुरू होते हैं: पहला कैरेक्टर इंडेक्स `0` पर है, दूसरा इंडेक्स `1` पर, और इसी तरह आगे।
एक ही कैरेक्टर पढ़ने के लिए स्ट्रिंग के बाद स्क्वायर ब्रैकेट्स में इंडेक्स लिखें:
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
`word[6]` जैसा कोई इंडेक्स माँगना, जो मौजूद ही नहीं है, `IndexError` उत्पन्न करता है।

---

इंडेक्स **नेगेटिव** भी हो सकते हैं: वे स्ट्रिंग के अंत से गिनती करते हैं।
`-1` आखिरी कैरेक्टर है, `-2` उससे पहले वाला, और इसी तरह आगे:
```python
word = "python"
print(word[-1])  # n
print(word[-2])  # o
```
यह सुविधाजनक है क्योंकि आपको स्ट्रिंग के अंत तक पहुँचने के लिए उसकी लंबाई जानने की ज़रूरत नहीं होती।

---

एक **स्लाइस (slice)** स्ट्रिंग का एक हिस्सा निकालता है।
स्क्वायर ब्रैकेट्स के बीच `[start:end]` लिखें: `start` पर मौजूद कैरेक्टर शामिल होता है, `end` पर मौजूद कैरेक्टर **शामिल नहीं** होता:
```python
word = "python"
print(word[0:3])  # pyt
print(word[2:4])  # th
```
आप शुरुआत से स्लाइस करने के लिए `start` को, या अंत तक स्लाइस करने के लिए `end` को छोड़ सकते हैं:
```python
print(word[:2])  # py
print(word[2:])  # thon
```
स्लाइसिंग कभी एरर नहीं देती: लंबाई से बड़ा `end` बस आखिरी कैरेक्टर पर रुक जाता है।

---

आप पहले से जानते हैं कि `+` दो स्ट्रिंग्स को जोड़ता है (**concatenation**)।
`*` ऑपरेटर किसी स्ट्रिंग को दी गई संख्या में **दोहराता** है:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
रिपीटीशन (repetition) सेपरेटर और सिंपल पैटर्न बनाने का एक तेज़ तरीका है।

---

`in` ऑपरेटर यह जाँचता है कि क्या एक स्ट्रिंग में दूसरी स्ट्रिंग **मौजूद** है।
यह `True` या `False` लौटाता है, इसलिए यह `if` के अंदर स्वाभाविक रूप से फिट बैठता है:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` उल्टी जाँच करता है।

---

स्ट्रिंग्स में कई बिल्ट-इन **मेथड्स (methods)** होते हैं: ऐसे फ़ंक्शन जिन्हें स्ट्रिंग के बाद डॉट लगाकर कॉल किया जाता है।
`upper()` टेक्स्ट को कैपिटल लेटर्स में लौटाता है, `lower()` स्मॉल लेटर्स में:
```python
word = "Python"
print(word.upper())  # PYTHON
print(word.lower())  # python
print(word)          # Python
```
ध्यान दें कि ये मेथड्स **एक नई स्ट्रिंग लौटाते** हैं: मूल `word` नहीं बदलता।
`lower()` का उपयोग अक्सर केस को नज़रअंदाज़ करते हुए टेक्स्ट की तुलना करने के लिए किया जाता है: `"Yes".lower() == "yes"`।

---

स्ट्रिंग्स **इम्यूटेबल (immutable)** होती हैं: एक बार बन जाने के बाद, उनके कैरेक्टर्स बदले नहीं जा सकते।
किसी इंडेक्स को वैल्यू असाइन करने पर `TypeError` आता है:
```python
word = "dog"
word[1] = "i"  # TypeError: 'str' object does not support item assignment
```
स्ट्रिंग को "बदलने" के लिए आप एक नई स्ट्रिंग बनाते हैं, उदाहरण के लिए स्लाइस और कॉन्कैटेनेशन के साथ, और उसे वेरिएबल में स्टोर करते हैं:
```python
word = word[0] + "i" + word[2:]
print(word)  # dig
```

---

यूज़र्स द्वारा टाइप किए गए टेक्स्ट के आसपास अक्सर एक्स्ट्रा स्पेस होते हैं।
`strip()` मेथड स्ट्रिंग की एक कॉपी लौटाता है जिसमें **आगे और पीछे के व्हाइटस्पेस** (स्पेस, टैब और न्यूलाइन) नहीं होते:
```python
name = "   Ada  "
print("[" + name.strip() + "]")  # [Ada]
```
टेक्स्ट के बीच में मौजूद स्पेस वैसे ही रहते हैं।
`lstrip()` केवल बाईं ओर से हटाता है और `rstrip()` केवल दाईं ओर से।

---

`split()` एक स्ट्रिंग को टुकड़ों की **लिस्ट** में तोड़ता है।
बिना आर्गुमेंट के यह व्हाइटस्पेस पर स्प्लिट करता है; आर्गुमेंट देने पर उस सेपरेटर पर स्प्लिट करता है:
```python
print("a b  c".split())      # ['a', 'b', 'c']
print("2024-01-31".split("-"))  # ['2024', '01', '31']
```
`join()` इसका उल्टा करता है: यह लिस्ट के आइटम्स को एक स्ट्रिंग में जोड़ता है।
इसे **सेपरेटर** पर कॉल किया जाता है, और लिस्ट आर्गुमेंट होती है:
```python
words = ["one", "two", "three"]
print(", ".join(words))  # one, two, three
print("".join(words))    # onetwothree
```

---

`replace(old, new)` स्ट्रिंग की एक कॉपी लौटाता है जिसमें `old` के **हर** occurrence को `new` से बदल दिया गया है:
```python
text = "a-b-c"
print(text.replace("-", "+"))  # a+b+c
```
चूँकि स्ट्रिंग्स इम्यूटेबल होती हैं, अगर आप रिज़ल्ट रखना चाहते हैं तो उसे स्टोर करना न भूलें।

---

`find(sub)` `sub` के पहले occurrence का **इंडेक्स** लौटाता है, या अगर वह न मिले तो `-1` लौटाता है:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` लौटाता है कि `sub` **कितनी बार** आता है:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

---

`startswith(prefix)` और `endswith(suffix)` इस पर निर्भर करते हुए `True` या `False` लौटाते हैं कि स्ट्रिंग कैसे शुरू या खत्म होती है:
```python
url = "https://codigo.dev"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # False
```
फ़ाइल एक्सटेंशन, प्रोटोकॉल या प्रीफ़िक्स चेक करने का यह सामान्य तरीका है।

---

कुछ कैरेक्टर्स को सीधे किसी स्ट्रिंग के अंदर टाइप नहीं किया जा सकता।
एक **एस्केप सीक्वेंस (escape sequence)** एक बैकस्लैश `\` होता है जिसके बाद एक लेटर या सिंबल आता है, जो किसी स्पेशल कैरेक्टर को दर्शाता है:

- `\n` एक नई लाइन
- `\t` एक टैब
- `\"` एक डबल-कोटेड स्ट्रिंग के अंदर एक डबल कोट
- `\'` एक सिंगल-कोटेड स्ट्रिंग के अंदर एक सिंगल कोट
- `\\` एक लिटरल बैकस्लैश

```python
print("Line 1\nLine 2")
print("She said \"hi\"")
```
यह प्रिंट करता है:
```
Line 1
Line 2
She said "hi"
```
हर एस्केप सीक्वेंस **एक** कैरेक्टर के बराबर गिना जाता है, भले ही आप दो टाइप करें।

---

एक स्ट्रिंग जो **कई लाइनों** में फैली हो, उसे **ट्रिपल कोट्स** `"""..."""` (या `'''...'''`) से लिखा जा सकता है।
कोट्स के अंदर हर लाइन ब्रेक स्ट्रिंग का हिस्सा बन जाता है, इसलिए आपको `\n` की ज़रूरत नहीं होती:
```python
poem = """Roses are red,
Violets are blue"""
print(poem)
```
यह प्रिंट करता है:
```
Roses are red,
Violets are blue
```
ट्रिपल-कोटेड स्ट्रिंग्स में सिंगल और डबल कोट्स भी स्वतंत्र रूप से हो सकते हैं।

---

चूँकि हर स्ट्रिंग मेथड एक नई स्ट्रिंग लौटाता है, आप एक के बाद एक मेथड्स को **चेन** कर सकते हैं।
हर कॉल पिछले वाले के रिज़ल्ट पर काम करती है:
```python
text = "  Hello World  "
print(text.strip().lower())  # hello world
```
एक स्लाइस तीसरी वैल्यू भी स्वीकार करती है, **स्टेप (step)**।
स्टेप `-1` स्ट्रिंग में पीछे की ओर चलता है, जो स्ट्रिंग को उल्टा करने का क्लासिक तरीका है:
```python
print("abc"[::-1])  # cba
```

---

एक **स्लग (slug)** किसी टाइटल का URL-फ्रेंडली वर्शन होता है: लोअरकेस, आसपास बिना स्पेस के, और शब्द डैश से अलग किए गए, जैसे `hello-world`।
इसे बनाना बस उन मेथड्स की एक चेन है जो आपने सीखी हैं: `strip()`, `lower()` और `replace()`।
