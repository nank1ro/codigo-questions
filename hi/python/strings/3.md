# --description--

स्ट्रिंग के हर कैरेक्टर की एक पोज़िशन होती है जिसे **इंडेक्स (index)** कहते हैं।
इंडेक्स `1` से नहीं, `0` से शुरू होते हैं: पहला कैरेक्टर इंडेक्स `0` पर है, दूसरा इंडेक्स `1` पर, और इसी तरह आगे।
एक ही कैरेक्टर पढ़ने के लिए स्ट्रिंग के बाद स्क्वायर ब्रैकेट्स में इंडेक्स लिखें:
```python
word = "python"
print(word[0])  # p
print(word[1])  # y
print(word[5])  # n
```
`word[6]` जैसा कोई इंडेक्स माँगना, जो मौजूद ही नहीं है, `IndexError` उत्पन्न करता है।
