# --description--

`str.split` केवल एक फ़िक्स्ड सेपरेटर पर काट सकता है। `re.split(pattern, text)` पैटर्न जो भी वर्णन करे उस पर काटता है, जो आम तौर पर मैसी इनपुट को चाहिए होता है:
```python
import re

print("a, b;c".split(","))            # ['a', ' b;c']
print(re.split(r"[,;]", "a, b;c"))    # ['a', ' b', 'c']
print(re.split(r"[,;\s]+", "a, b;c")) # ['a', 'b', 'c']
```
सेपरेटर को `[,;\s]+` लिखने से कॉमा, सेमीकोलन और स्पेस का पूरा एक क्रम एक कट के रूप में गिना जाता है, बजाय उनके बीच खाली स्ट्रिंग्स छोड़ने के।

एक `maxsplit` आर्ग्युमेंट दिए गए संख्या के कटों के बाद रुक जाता है, और टेक्स्ट का बाकी हिस्सा आख़िरी एलिमेंट में छोड़ देता है: `re.split(r"\s+", "a b c", maxsplit=1)` देता है `['a', 'b c']`।
