एक **रेगुलर एक्सप्रेशन** (regex) टेक्स्ट का वर्णन करने वाली एक छोटी पैटर्न भाषा है। Python इसे स्टैंडर्ड `re` मॉड्यूल में देता है:
```python
import re
```

`re.search(pattern, text)` टेक्स्ट में कहीं भी पैटर्न को खोजता है। जब उसे कुछ मिल जाता है तो यह एक **match ऑब्जेक्ट** लौटाता है, और न मिलने पर `None`। `match.group()` उस टेक्स्ट का टुकड़ा वापस देता है जो मैच हुआ था:
```python
import re

match = re.search(r"\d+", "order 42 shipped")
print(match.group())  # 42
```

यहाँ पैटर्न के दो हिस्से काम करते हैं। `\d` का मतलब है *कोई भी अंक*, और `+` का मतलब है *पिछली चीज़ का एक या अधिक*, इसलिए `\d+` को "एक या अधिक अंक" पढ़ा जाता है। अन्य उपयोगी शॉर्टकट `\w` (एक अक्षर, अंक या अंडरस्कोर) और `\s` (एक स्पेस, टैब या न्यूलाइन) हैं।

पैटर्न **raw स्ट्रिंग्स** के रूप में लिखे जाते हैं, जिसमें उद्धरण चिह्नों से पहले एक `r` लगाया जाता है। एक सामान्य Python स्ट्रिंग में बैकस्लैश एक एस्केप सीक्वेंस शुरू करता है, इसलिए `"\d"` एक चेतावनी बनने की राह में रहता है और `"\n"` एक असली न्यूलाइन बन जाएगा बजाय उन दो कैरेक्टर्स के जिनकी regex इंजन को अपेक्षा होती है। `r` प्रीफ़िक्स बैकस्लैश को वापस एक सामान्य कैरेक्टर बना देता है, इसलिए `r"\d"` बिल्कुल वही है जो इंजन को मिलता है। पैटर्न के लिए हमेशा `r"..."` उपयोग करें।

---

`re.search` पूरे टेक्स्ट को स्कैन करता है, लेकिन `re.match` पैटर्न को केवल टेक्स्ट की **बिल्कुल शुरुआत** पर आज़माता है:
```python
import re

print(re.search(r"\d+", "order 42"))  # <re.Match object; span=(6, 8), match='42'>
print(re.match(r"\d+", "order 42"))   # None
print(re.match(r"\d+", "42 orders"))  # <re.Match object; span=(0, 2), match='42'>
```

दोनों ही `None` लौटाते हैं जब कुछ मैच नहीं होता, और एक match ऑब्जेक्ट हमेशा truthy होता है, इसलिए "क्या यह मैच हुआ?" पूछने का सामान्य तरीका एक सादा `if` है:
```python
if re.search(r"\d", text):
    print("there is a digit")
```
जब एक असली `True` या `False` चाहिए हो, तो `is not None` से तुलना करें या कॉल को `bool(...)` में लपेटें।

---

एक तीसरा एंट्री पॉइंट भी है, `re.fullmatch`, जो केवल तब सफल होता है जब पैटर्न **पूरे** टेक्स्ट को पहले कैरेक्टर से आख़िरी कैरेक्टर तक कवर करे। यह वैलिडेशन के लिए सही टूल है:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

इस तरह तीनों फ़ंक्शन सिर्फ इस बात में अलग हैं कि पैटर्न कहाँ होने की अनुमति है: `re.match` टेक्स्ट की शुरुआत में, `re.search` टेक्स्ट में कहीं भी, और `re.fullmatch` पूरे टेक्स्ट पर।

---

एक match ऑब्जेक्ट मैच हुए टेक्स्ट से ज़्यादा जानकारी रखता है। `.group()` के अलावा यह मूल स्ट्रिंग के अंदर मैच की स्थिति भी देता है:
```python
import re

match = re.search(r"\d+", "order 42 shipped")
print(match.group())  # 42
print(match.start())  # 6
print(match.end())    # 8
print(match.span())   # (6, 8)
```
`.start()` पहले मैच हुए कैरेक्टर का इंडेक्स है, `.end()` आख़िरी कैरेक्टर के ठीक बाद का इंडेक्स है, और `.span()` दोनों को एक टपल के रूप में लौटाता है। इसका मतलब है कि `text[match.start():match.end()]` हमेशा `match.group()` के बराबर होता है।

चूँकि `re.search` `None` लौटा सकता है, सीधे `.group()` पढ़ने पर `AttributeError` उठता है जब कुछ मैच नहीं हुआ हो; पहले रिज़ल्ट की जाँच करें।

---

पैटर्न के अंदर गोल कोष्ठक एक **कैप्चर ग्रुप** बनाते हैं: मैच का एक हिस्सा जिसे अकेले पढ़ा जा सकता है। ग्रुप को बाएँ से दाएँ नंबर दिए जाते हैं, जो `1` से शुरू होते हैं:
```python
import re

match = re.search(r"(\w+)@(\w+)", "write to ada@example today")
print(match.group())   # ada@example
print(match.group(1))  # ada
print(match.group(2))  # example
print(match.groups())  # ('ada', 'example')
```
`match.group(0)` पूरा मैच होता है, बिल्कुल `match.group()` की तरह, और `match.groups()` हर ग्रुप को एक टपल के रूप में लौटाता है। किसी ऐसे ग्रुप नंबर के लिए पूछना जो मौजूद नहीं है `IndexError` उठाता है।

---

ग्रुप `3` ढूँढने के लिए कोष्ठकों की गिनती करना जल्दी उबाऊ हो जाता है। एक ग्रुप को `(?P<name>...)` से नाम दिया जा सकता है और फिर `match.group("name")` से पढ़ा जा सकता है:
```python
import re

match = re.search(r"(?P<hour>\d\d):(?P<minute>\d\d)", "starts at 09:30")
print(match.group("hour"))    # 09
print(match.group("minute"))  # 30
print(match.groupdict())      # {'hour': '09', 'minute': '30'}
```
`match.groupdict()` हर नाम वाले ग्रुप को एक डिक्शनरी के रूप में लौटाता है। नाम वाले ग्रुप अपना नंबर भी रखते हैं, इसलिए `match.group(1)` अब भी काम करता है।

उदाहरण ब्रेसिज़ के साथ एक **क्वांटिफायर** भी उपयोग करता है: `\d{2}` का मतलब ठीक दो अंक, `\d{2,4}` का मतलब दो से चार के बीच, और `\d{2,}` का मतलब दो या अधिक। ये `+` (एक या अधिक), `*` (शून्य या अधिक) और `?` (शून्य या एक) का सटीक रूप हैं।

---

स्क्वायर ब्रैकिट एक **कैरेक्टर क्लास** परिभाषित करते हैं: कैरेक्टर्स का एक सेट, जिनमें से कोई भी एक उस स्थिति पर स्वीकार किया जाता है। `[aeiou]` एक वोवेल से मैच करता है, `[0-9]` एक अंक से और `[a-z]` एक लोअरकेस अक्षर से। खुलने वाले ब्रैकिट के ठीक बाद एक `^` मतलब उलट देता है, इसलिए `[^0-9]` हर उस चीज़ से मैच करता है जो अंक *नहीं* है।

क्लास के बाहर, `^` और `$` **एंकर** होते हैं: `^` पैटर्न को टेक्स्ट की शुरुआत से और `$` उसके अंत से बाँध देता है। `re.fullmatch` के साथ एंकर अंतर्निहित होते हैं, यही कारण है कि वैलिडेशन इसके साथ बेहतर पढ़ा जाता है:
```python
import re

print(bool(re.fullmatch(r"[a-z]{3,8}", "ada")))  # True
print(bool(re.fullmatch(r"[a-z]{3,8}", "Ada")))  # False
```

---

`re.search` पहले मैच पर रुक जाता है। `re.findall(pattern, text)` इसके बजाय **हर** मैच इकट्ठा करता है, और उन्हें स्ट्रिंग्स की एक लिस्ट के रूप में लौटाता है:
```python
import re

print(re.findall(r"\d+", "a1 bb22 ccc333"))  # ['1', '22', '333']
print(re.findall(r"\d+", "no digits"))       # []
```
कुछ मैच न होने पर लिस्ट खाली होती है, इसलिए जाँचने को कोई `None` नहीं होता: इस पर सीधे लूप चलाया जा सकता है या इसे `len(...)` से मापा जा सकता है। ध्यान दें कि `findall` सादे स्ट्रिंग्स लौटाता है, match ऑब्जेक्ट नहीं, इसलिए स्थितियाँ उपलब्ध नहीं होतीं।

---

जब हर मैच की स्थिति या ग्रुप चाहिए हों, तो `re.finditer(pattern, text)` सही कॉल है: यह टेक्स्ट पर चलता है और हर मैच के लिए एक **match ऑब्जेक्ट** देता है, एक बार में एक:
```python
import re

for match in re.finditer(r"\d+", "a1 bb22"):
    print(match.group(), match.start())
# 1 1
# 22 5
```
`finditer` एक इटरेटर देता है, लिस्ट नहीं, इसलिए इसे एक `for` लूप में या किसी कॉम्प्रिहेंशन में उपयोग किया जा सकता है। जहाँ `findall` केवल टेक्स्ट देता है, वहीं `finditer` वह सब देता है जो एक match ऑब्जेक्ट जानता है।

---

`findall` अपना व्यवहार बदल देता है जब पैटर्न में कैप्चर ग्रुप होते हैं। ठीक एक ग्रुप के साथ यह पूरे मैच के बजाय उस ग्रुप का कंटेंट लौटाता है, और दो या अधिक के साथ यह हर मैच के लिए ग्रुप का एक टपल लौटाता है:
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
यह याद रखने लायक है: किसी पैटर्न में केवल ग्रुपिंग के लिए कोष्ठक जोड़ने चुपचाप बदल देता है कि `findall` क्या लौटाता है। `re.finditer` कभी इस तरह व्यवहार नहीं करता, क्योंकि एक match ऑब्जेक्ट हमेशा पूरे मैच और ग्रुप दोनों को रखता है।

---

`re.sub(pattern, replacement, text)` एक नई स्ट्रिंग लौटाता है जिसमें हर मैच बदल दिया गया है। स्ट्रिंग्स इम्यूटेबल होती हैं, इसलिए मूल टेक्स्ट अछूता रहता है:
```python
import re

print(re.sub(r"\d", "#", "call 555 now"))     # call ### now
print(re.sub(r"\s+", " ", "too    many gaps"))  # too many gaps
```

रिप्लेसमेंट कैप्चर ग्रुप को `\1`, `\2`, ... (या किसी नाम वाले ग्रुप के लिए `\g<name>`) से देख सकता है, जिससे टेक्स्ट को फिर से क्रम में लगाना एक वन-लाइनर बन जाता है। रिप्लेसमेंट भी एक raw स्ट्रिंग होता है, उसी बैकस्लैश वाली वजह से:
```python
import re

print(re.sub(r"(\w+), (\w+)", r"\2 \1", "Lovelace, Ada"))  # Ada Lovelace
```
एक `count` आर्ग्युमेंट बताता है कि कितने मैच बदले जाएँ: `re.sub(r"\d", "#", "1 2 3", count=1)` देता है `# 2 3`।

---

`re.sub` को दिया गया रिप्लेसमेंट एक **फ़ंक्शन** भी हो सकता है। इसे हर मैच पर एक बार कॉल किया जाता है, इसे match ऑब्जेक्ट मिलता है, और इसे उसकी जगह रखी जाने वाली स्ट्रिंग लौटानी होती है। इसी तरह एक रिप्लेसमेंट इस बात पर निर्भर हो सकता है कि क्या मैच हुआ:
```python
import re

def shout(match):
    return match.group().upper()

print(re.sub(r"[a-z]+", shout, "one two"))  # ONE TWO
```
फ़ंक्शन नाम से पास किया जाता है, बिना कोष्ठकों के: `shout(match)` लिखने से उसे `re.sub` को देने के बजाय तुरंत कॉल कर दिया जाएगा।

---

`str.split` केवल एक फ़िक्स्ड सेपरेटर पर काट सकता है। `re.split(pattern, text)` पैटर्न जो भी वर्णन करे उस पर काटता है, जो आम तौर पर मैसी इनपुट को चाहिए होता है:
```python
import re

print("a, b;c".split(","))            # ['a', ' b;c']
print(re.split(r"[,;]", "a, b;c"))    # ['a', ' b', 'c']
print(re.split(r"[,;\s]+", "a, b;c")) # ['a', 'b', 'c']
```
सेपरेटर को `[,;\s]+` लिखने से कॉमा, सेमीकोलन और स्पेस का पूरा एक क्रम एक कट के रूप में गिना जाता है, बजाय उनके बीच खाली स्ट्रिंग्स छोड़ने के।

एक `maxsplit` आर्ग्युमेंट दिए गए संख्या के कटों के बाद रुक जाता है, और टेक्स्ट का बाकी हिस्सा आख़िरी एलिमेंट में छोड़ देता है: `re.split(r"\s+", "a b c", maxsplit=1)` देता है `['a', 'b c']`।

---

`re.search` या `re.findall` की हर कॉल को पहले पैटर्न स्ट्रिंग को एक इंटरनल कैश में देखना पड़ता है। `re.compile(pattern)` वह लुकअप छोड़ देता है और एक **pattern ऑब्जेक्ट** लौटाता है जो वही मेथड्स रखता है:
```python
import re

word_re = re.compile(r"[a-z]+")
print(word_re.search("ab 12").group())  # ab
print(word_re.findall("cd ef"))         # ['cd', 'ef']
print(word_re.sub("*", "ab cd"))        # * *
```
टेक्स्ट ही एकमात्र बचा हुआ आर्ग्युमेंट होता है, क्योंकि पैटर्न पहले से ऑब्जेक्ट में बेक होता है। कंपाइल करना तब फ़ायदेमंद होता है जब वही पैटर्न कई बार उपयोग हो, उदाहरण के लिए किसी लूप के अंदर, और यह पैटर्न को एक नाम भी देता है जो बताता है कि वह किससे मैच करता है।

---

**फ़्लैग्स** बदलते हैं कि एक पैटर्न किस तरह लागू हो। `re` का हर फ़ंक्शन उन्हें एक `flags` आर्ग्युमेंट के रूप में स्वीकार करता है, और `re.compile` उन्हें pattern ऑब्जेक्ट में स्टोर कर लेता है:
```python
import re

print(re.search(r"cat", "A Cat", flags=re.IGNORECASE).group())  # Cat
title_re = re.compile(r"^#.*", re.MULTILINE)
```
सबसे अधिक उपयोग होने वाले दो हैं `re.IGNORECASE`, जो अक्षरों को किसी भी केस में मैच कराता है, और `re.MULTILINE`, जो `^` और `$` को पूरे टेक्स्ट के बजाय हर लाइन की शुरुआत और अंत पर मैच कराता है। कई फ़्लैग्स को `|` से जोड़ा जाता है, जैसे `re.IGNORECASE | re.MULTILINE`।

एक फ़्लैग केवल मैचिंग के नियम बदलता है: लौटाया गया टेक्स्ट हमेशा वही टेक्स्ट होता है जो सचमुच वहाँ था, अपने मूल केस के साथ।
