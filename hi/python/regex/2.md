# --description--

`re.search` पूरे टेक्स्ट को स्कैन करता है, लेकिन `re.match` पैटर्न को केवल टेक्स्ट की **बिल्कुल शुरुआत** पर आज़माता है:
```python
import re

print(re.search(r"\d+", "order 42"))  # <re.Match object; span=(6, 8), match='42'>
print(re.match(r"\d+", "order 42"))   # None
print(re.match(r"\d+", "42 orders"))  # <re.Match object; span=(0, 2), match='42'>
```

दोनों ही `None` लौटाते हैं जब कुछ मैच नहीं होता, और एक match ऑब्जेक्ट हमेशा truthy होता है, इसलिए "क्या यह मैच हुआ?" पूछने का सामान्य तरीका एक सादा `if` है:
```python
if re.search(r"\d", text):
    print("there is a digit")
```
जब एक असली `True` या `False` चाहिए हो, तो `is not None` से तुलना करें या कॉल को `bool(...)` में लपेटें।

# --solutions--

```python
import re

def has_digit(text):
    return re.search(r"\d", text) is not None

def starts_with_digit(text):
    return re.match(r"\d", text) is not None
```
