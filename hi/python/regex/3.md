# --description--

एक तीसरा एंट्री पॉइंट भी है, `re.fullmatch`, जो केवल तब सफल होता है जब पैटर्न **पूरे** टेक्स्ट को पहले कैरेक्टर से आख़िरी कैरेक्टर तक कवर करे। यह वैलिडेशन के लिए सही टूल है:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

इस तरह तीनों फ़ंक्शन सिर्फ इस बात में अलग हैं कि पैटर्न कहाँ होने की अनुमति है: `re.match` टेक्स्ट की शुरुआत में, `re.search` टेक्स्ट में कहीं भी, और `re.fullmatch` पूरे टेक्स्ट पर।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
import re

print(bool(re.match(r"\d+", "12abc")), bool(re.search(r"\d+", "12abc")), bool(re.fullmatch(r"\d+", "12abc")))
```

# --answers--

- `True True False`, क्योंकि अंक शुरुआत में और टेक्स्ट के अंदर हैं, लेकिन वे पूरे टेक्स्ट को कवर नहीं करते
- `True True True`, क्योंकि तीनों फ़ंक्शन सफल हो जाते हैं जैसे ही पैटर्न कहीं भी मिल जाता है
- `False True False`, क्योंकि `re.match` को पैटर्न का पूरे टेक्स्ट को कवर करना ज़रूरी है
- `True False False`, क्योंकि `re.search` केवल पहले कैरेक्टर के बाद देखता है
