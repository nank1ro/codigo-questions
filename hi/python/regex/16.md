# --instructions--

एक कंपाइल किया हुआ पैटर्न `PAIR_RE` परिभाषित करें जो एक सेटिंग से मैच करे जो एक या अधिक अक्षरों, एक `=` चिह्न और एक या अधिक अंकों के रूप में लिखी हो, जिसमें दोनों हिस्से नाम वाले ग्रुप `key` और `value` में हों; फिर एक फ़ंक्शन `parse_settings(text)` लिखें जो टेक्स्ट में मिली हर की को उसकी वैल्यू के साथ एक `int` के रूप में मैप करने वाली डिक्शनरी लौटाए

# --asserts--

`PAIR_RE` नाम वाले ग्रुप `key` और `value` वाला एक कंपाइल किया हुआ पैटर्न होना चाहिए

```python
    def test_1(self):
        self.assertIsInstance(PAIR_RE, re.Pattern, "--err-t1--")
        self.assertEqual(PAIR_RE.search("width=10").groupdict(), {"key": "width", "value": "10"}, "--err-t1--")
```

`parse_settings` को हर सेटिंग एक पूर्णांक वैल्यू के साथ लौटानी चाहिए

```python
    def test_2(self):
        self.assertEqual(parse_settings("width=10 height=20"), {"width": 10, "height": 20}, "--err-t2--")
        self.assertEqual(parse_settings("size=3; depth=7"), {"size": 3, "depth": 7}, "--err-t2--")
```

बिना सेटिंग्स वाले टेक्स्ट को एक खाली डिक्शनरी लौटानी चाहिए

```python
    def test_3(self):
        self.assertEqual(parse_settings("nothing to read"), {}, "--err-t3--")
        self.assertEqual(parse_settings(""), {}, "--err-t3--")
```

# --solutions--

```python
import re

PAIR_RE = re.compile(r"(?P<key>[a-zA-Z]+)=(?P<value>\d+)")

def parse_settings(text):
    settings = {}
    for match in PAIR_RE.finditer(text):
        settings[match.group("key")] = int(match.group("value"))
    return settings
```
