# --description--

पैटर्न के अंदर गोल कोष्ठक एक **कैप्चर ग्रुप** बनाते हैं: मैच का एक हिस्सा जिसे अकेले पढ़ा जा सकता है। ग्रुप को बाएँ से दाएँ नंबर दिए जाते हैं, जो `1` से शुरू होते हैं:
```python
import re

match = re.search(r"(\w+)@(\w+)", "write to ada@example today")
print(match.group())   # ada@example
print(match.group(1))  # ada
print(match.group(2))  # example
print(match.groups())  # ('ada', 'example')
```
`match.group(0)` पूरा मैच होता है, बिल्कुल `match.group()` की तरह, और `match.groups()` हर ग्रुप को एक टपल के रूप में लौटाता है। किसी ऐसे ग्रुप नंबर के लिए पूछना जो मौजूद नहीं है `IndexError` उठाता है।
