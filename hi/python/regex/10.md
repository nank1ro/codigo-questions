# --description--

`findall` अपना व्यवहार बदल देता है जब पैटर्न में कैप्चर ग्रुप होते हैं। ठीक एक ग्रुप के साथ यह पूरे मैच के बजाय उस ग्रुप का कंटेंट लौटाता है, और दो या अधिक के साथ यह हर मैच के लिए ग्रुप का एक टपल लौटाता है:
```python
import re

print(re.findall(r"\d+-\d+", "10-20 30-40"))    # ['10-20', '30-40']
print(re.findall(r"(\d+)-\d+", "10-20 30-40"))  # ['10', '30']
```
यह याद रखने लायक है: किसी पैटर्न में केवल ग्रुपिंग के लिए कोष्ठक जोड़ने चुपचाप बदल देता है कि `findall` क्या लौटाता है। `re.finditer` कभी इस तरह व्यवहार नहीं करता, क्योंकि एक match ऑब्जेक्ट हमेशा पूरे मैच और ग्रुप दोनों को रखता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
import re

print(re.findall(r"(\w+)@(\w+)", "ada@example bob@test"))
```

# --answers--

- `[('ada', 'example'), ('bob', 'test')]`, क्योंकि एक से अधिक ग्रुप होने पर `findall` हर मैच के लिए ग्रुप का एक टपल लौटाता है
- `['ada@example', 'bob@test']`, क्योंकि `findall` हमेशा पूरे मैच का टेक्स्ट लौटाता है
- `['ada', 'example', 'bob', 'test']`, क्योंकि `findall` हर मैच के हर ग्रुप को एक फ्लैट लिस्ट में रखता है
- `[]`, क्योंकि कैप्चर ग्रुप वाले पैटर्न का उपयोग केवल `re.finditer` के साथ किया जा सकता है
