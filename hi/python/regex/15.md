# --description--

**फ़्लैग्स** बदलते हैं कि एक पैटर्न किस तरह लागू हो। `re` का हर फ़ंक्शन उन्हें एक `flags` आर्ग्युमेंट के रूप में स्वीकार करता है, और `re.compile` उन्हें pattern ऑब्जेक्ट में स्टोर कर लेता है:
```python
import re

print(re.search(r"cat", "A Cat", flags=re.IGNORECASE).group())  # Cat
title_re = re.compile(r"^#.*", re.MULTILINE)
```
सबसे अधिक उपयोग होने वाले दो हैं `re.IGNORECASE`, जो अक्षरों को किसी भी केस में मैच कराता है, और `re.MULTILINE`, जो `^` और `$` को पूरे टेक्स्ट के बजाय हर लाइन की शुरुआत और अंत पर मैच कराता है। कई फ़्लैग्स को `|` से जोड़ा जाता है, जैसे `re.IGNORECASE | re.MULTILINE`।

एक फ़्लैग केवल मैचिंग के नियम बदलता है: लौटाया गया टेक्स्ट हमेशा वही टेक्स्ट होता है जो सचमुच वहाँ था, अपने मूल केस के साथ।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
import re

print(re.findall(r"cat", "Cat cat CAT", flags=re.IGNORECASE))
```

# --answers--

- `['Cat', 'cat', 'CAT']`, क्योंकि फ़्लैग पैटर्न को किसी भी केस में मैच कराता है जबकि मैच हुआ टेक्स्ट अपना केस रखता है
- `['cat', 'cat', 'cat']`, क्योंकि `re.IGNORECASE` मैच करने से पहले टेक्स्ट को लोअरकेस कर देता है
- `['cat']`, क्योंकि केवल वही उपस्थिति मैच करती है जो बिल्कुल पैटर्न जैसी लिखी हो
- `['Cat', 'CAT']`, क्योंकि फ़्लैग उन स्पेलिंग्स से मैच कराता है जो पैटर्न से अलग हैं
