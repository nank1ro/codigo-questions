# --description--

एक match ऑब्जेक्ट मैच हुए टेक्स्ट से ज़्यादा जानकारी रखता है। `.group()` के अलावा यह मूल स्ट्रिंग के अंदर मैच की स्थिति भी देता है:
```python
import re

match = re.search(r"\d+", "order 42 shipped")
print(match.group())  # 42
print(match.start())  # 6
print(match.end())    # 8
print(match.span())   # (6, 8)
```
`.start()` पहले मैच हुए कैरेक्टर का इंडेक्स है, `.end()` आख़िरी कैरेक्टर के ठीक बाद का इंडेक्स है, और `.span()` दोनों को एक टपल के रूप में लौटाता है। इसका मतलब है कि `text[match.start():match.end()]` हमेशा `match.group()` के बराबर होता है।

चूँकि `re.search` `None` लौटा सकता है, सीधे `.group()` पढ़ने पर `AttributeError` उठता है जब कुछ मैच नहीं हुआ हो; पहले रिज़ल्ट की जाँच करें।

# --solutions--

```python
import re

def first_number(text):
    match = re.search(r"\d+", text)
    if match is None:
        return None
    return (match.group(), match.start(), match.end())
```
