# --description--

एक `if` स्टेटमेंट का कोड ब्लॉक उसके नीचे की इंडेंट की गई लाइनों का समूह है, जो उस इंडेंटेशन के जरिए प्रोग्राम के बाकी हिस्से से अलग होता है।

# --instructions--

if स्टेटमेंट का कोड ब्लॉक क्या है?

# --answers--

- वह कोड जो कंडीशन False होने पर चलता है
- वह कोड जो निर्धारित करता है कि कोड का एक टुकड़ा चलना चाहिए या नहीं
- एक तुलना कीवर्ड
