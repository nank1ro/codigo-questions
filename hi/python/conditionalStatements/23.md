# --description--

`if` की इंडेंटेशन के बाहर स्थित लाइन शर्त चाहे जो भी रही हो, हर हाल में निष्पादित होती है, क्योंकि वह कभी उस ब्लॉक का हिस्सा नहीं थी।

# --instructions--

हम कैसे जानते हैं कि `Hello World` हमेशा प्रिंट होगा?
```python
online = False;
if (online):
    print("User is online")
print("Hello World")
```

# --answers--

- इसके इंडेंटेशन के कारण
- क्योंकि if स्टेटमेंट में एक से अधिक लाइन नहीं हो सकती
- क्योंकि कोई else स्टेटमेंट नहीं है
- क्योंकि कोई elif स्टेटमेंट नहीं है
