कभी-कभी आपको सिर्फ एक बार के लिए एक छोटे फ़ंक्शन की जरूरत होती है, उदाहरण के लिए किसी संख्या को दोगुना करने के लिए।
इसके लिए एक पूरा `def` ब्लॉक लिखना भारी लगता है।
Python एक छोटा रूप प्रदान करता है: **lambda** एक्सप्रेशन, एक _अनाम_ फ़ंक्शन जो एक ही लाइन में लिखा जाता है।
```python
lambda x: x * 2
```
सिंटैक्स है `lambda parameters: expression`।
एक lambda का कोई नाम नहीं होता, लेकिन आप इसे एक वेरिएबल में स्टोर करके किसी भी अन्य फ़ंक्शन की तरह कॉल कर सकते हैं।
```python
double = lambda x: x * 2
print(double(4))  # 8
```

---

ध्यान दें कि lambda के बॉडी में कोई `return` कीवर्ड नहीं है।
बॉडी एक **सिंगल एक्सप्रेशन** है, और इसका मान अपने आप रिटर्न हो जाता है:
```python
square = lambda n: n * n
print(square(3))  # 9
```

---

एक lambda **एक से अधिक पैरामीटर** ले सकता है।
उन्हें कॉमा से अलग करें, बिल्कुल `def` फ़ंक्शन की तरह:
```python
power = lambda base, exp: base ** exp
print(power(2, 3))  # 8
```

---

क्योंकि बॉडी एक सिंगल एक्सप्रेशन होनी चाहिए, एक lambda में **स्टेटमेंट्स नहीं हो सकते**।
कोई `return` नहीं, कोई `if` ब्लॉक नहीं, कोई लूप नहीं, कोई असाइनमेंट नहीं:
```python
# SyntaxError
increment = lambda x: return x + 1
```
अगर आपको इनमें से किसी की जरूरत है, तो इसके बजाय एक सामान्य `def` फ़ंक्शन लिखें।

---

lambda के पैरामीटर भी **डिफ़ॉल्ट वैल्यू** को सपोर्ट करते हैं:
```python
greet = lambda name="World": f"Hello, {name}!"
print(greet())       # Hello, World!
print(greet("Ana"))  # Hello, Ana!
```

---

आपको एक lambda को स्टोर करने की भी जरूरत नहीं है: आप इसे **तुरंत कॉल** कर सकते हैं।
lambda को कोष्ठकों में लपेटें, फिर आर्गुमेंट जोड़ें:
```python
print((lambda x: x + 1)(4))  # 5
```

---

lambda असल में चमकता है जब इसे **दूसरे फ़ंक्शन के आर्गुमेंट** के रूप में इस्तेमाल किया जाता है।
`sorted()` एक `key` पैरामीटर स्वीकार करता है: एक फ़ंक्शन जिसे हर आइटम पर कॉल किया जाता है, और उसका परिणाम क्रम तय करता है।
इसके लिए lambda बिल्कुल सही है:
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```

---

`key` में दिया गया lambda आइटम के किसी भी हिस्से को चुन सकता है।
लिस्ट की लिस्ट के लिए, `lambda p: p[1]` हर अंदरूनी लिस्ट के दूसरे एलिमेंट के आधार पर क्रमबद्ध करता है।

---

`map()` लिस्ट के **हर आइटम** पर एक फ़ंक्शन लागू करता है।
यह एक खास _map ऑब्जेक्ट_ रिटर्न करता है, इसलिए वैल्यू देखने के लिए इसे `list()` में लपेटें:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```

---

`filter()` केवल उन आइटम्स को रखता है जिनके लिए फ़ंक्शन `True` रिटर्न करता है:
```python
nums = [5, 12, 8, 20]
big = list(filter(lambda n: n > 10, nums))
print(big)  # [12, 20]
```

---

`map` ऑब्जेक्ट को सीधे प्रिंट करने पर उसकी वैल्यू नहीं दिखतीं: आपको `<map object at 0x7f2b1c>` जैसा कुछ मिलता है।
सिर्फ़ `list()` (या एक लूप) उसे अपेक्षित वैल्यू में बदलता है।

---

lambda केवल बिल्ट-इन फ़ंक्शंस तक सीमित नहीं है: **आपके खुद के फ़ंक्शन** भी एक फ़ंक्शन को पैरामीटर के रूप में ले सकते हैं और उसे कॉल कर सकते हैं।
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

---

`max()` और `min()` भी, `sorted()` की तरह ही, `key` फ़ंक्शन स्वीकार करते हैं:
```python
words = ["hi", "hello", "hey"]
print(max(words, key=lambda w: len(w)))  # hello
```

---

**तो `def` को कब प्राथमिकता देनी चाहिए?**
एक lambda आर्गुमेंट के रूप में पास किए जाने वाले छोटे, एक-बार इस्तेमाल होने वाले फ़ंक्शन के लिए बढ़िया है।
अगर लॉजिक को नाम, कई लाइनों, docstring की जरूरत है, या इसे कई जगहों पर दोबारा इस्तेमाल किया जाता है, तो एक `def` फ़ंक्शन ज्यादा स्पष्ट होता है।
आखिरी ट्रिक: `sorted()` `reverse=True` भी स्वीकार करता है ताकि सबसे बड़े मान पहले मिलें:
```python
print(sorted([3, 1, 2], reverse=True))  # [3, 2, 1]
```
