# --description--

lambda केवल बिल्ट-इन फ़ंक्शंस तक सीमित नहीं है: **आपके खुद के फ़ंक्शन** भी एक फ़ंक्शन को पैरामीटर के रूप में ले सकते हैं और उसे कॉल कर सकते हैं।
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

# --instructions--

एक फ़ंक्शन `apply_twice(func, value)` परिभाषित करें जो `func` को `value` पर दो बार लागू करता है और परिणाम रिटर्न करता है।
फिर `result` में `apply_twice` का वह मान स्टोर करें जो `3` जोड़ने वाले lambda और मान `10` के साथ कॉल करने पर मिलता है
