# --description--

lambda असल में चमकता है जब इसे **दूसरे फ़ंक्शन के आर्गुमेंट** के रूप में इस्तेमाल किया जाता है।
`sorted()` एक `key` पैरामीटर स्वीकार करता है: एक फ़ंक्शन जिसे हर आइटम पर कॉल किया जाता है, और उसका परिणाम क्रम तय करता है।
इसके लिए lambda बिल्कुल सही है:
```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))
# ['kiwi', 'apple', 'banana']
```
