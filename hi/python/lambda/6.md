# --description--

आपको एक lambda को स्टोर करने की भी जरूरत नहीं है: आप इसे **तुरंत कॉल** कर सकते हैं।
lambda को कोष्ठकों में लपेटें, फिर आर्गुमेंट जोड़ें:
```python
print((lambda x: x + 1)(4))  # 5
```
