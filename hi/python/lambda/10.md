# --description--

`filter()` केवल उन आइटम्स को रखता है जिनके लिए फ़ंक्शन `True` रिटर्न करता है:
```python
nums = [5, 12, 8, 20]
big = list(filter(lambda n: n > 10, nums))
print(big)  # [12, 20]
```
