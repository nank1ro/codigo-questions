# --description--

ध्यान दें कि lambda के बॉडी में कोई `return` कीवर्ड नहीं है।
बॉडी एक **सिंगल एक्सप्रेशन** है, और इसका मान अपने आप रिटर्न हो जाता है:
```python
square = lambda n: n * n
print(square(3))  # 9
```

# --instructions--

वेरिएबल `square` में एक lambda स्टोर करें जो एक पैरामीटर `n` लेता है और `n` को खुद से गुणा करके रिटर्न करता है
