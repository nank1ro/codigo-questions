# --description--

lambda के पैरामीटर भी **डिफ़ॉल्ट वैल्यू** को सपोर्ट करते हैं:
```python
greet = lambda name="World": f"Hello, {name}!"
print(greet())       # Hello, World!
print(greet("Ana"))  # Hello, Ana!
```

# --instructions--

वेरिएबल `multiply` में एक lambda स्टोर करें जो `n` और डिफ़ॉल्ट वैल्यू `2` वाला दूसरा पैरामीटर `factor` लेता है, और `n` को `factor` से गुणा करके रिटर्न करता है
