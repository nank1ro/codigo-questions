# --description--

क्योंकि बॉडी एक सिंगल एक्सप्रेशन होनी चाहिए, एक lambda में **स्टेटमेंट्स नहीं हो सकते**।
कोई `return` नहीं, कोई `if` ब्लॉक नहीं, कोई लूप नहीं, कोई असाइनमेंट नहीं:
```python
# SyntaxError
increment = lambda x: return x + 1
```
अगर आपको इनमें से किसी की जरूरत है, तो इसके बजाय एक सामान्य `def` फ़ंक्शन लिखें।

# --instructions--

इस कोड स्निपेट में __समस्या__ क्या है?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- lambda की बॉडी एक एक्सप्रेशन है, इसमें return नहीं हो सकता
- lambda को एक वेरिएबल में स्टोर नहीं किया जा सकता
- lambda को कोष्ठकों के साथ कॉल नहीं किया जा सकता
- lambda को कम से कम दो पैरामीटर चाहिए
