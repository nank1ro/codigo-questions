# --description--

ऑपरेटर्स और मेथड्स पूरी तरह एक जैसे नहीं होते।
`|`, `&`, `-` और `^` ऑपरेटर्स तभी काम करते हैं जब **दोनों** ऑपरेंड सेट हों।
`union()`, `intersection()`, `difference()` और `symmetric_difference()` मेथड्स किसी भी **इटरेबल** को स्वीकार करते हैं, जैसे लिस्ट या स्ट्रिंग:
```python
a = {1, 2}
print(a.union([2, 3]))  # {1, 2, 3}
print(a | [2, 3])       # TypeError: unsupported operand type(s) for |: 'set' and 'list'
```

# --instructions--

यह कोड चलने पर क्या होता है?
```python
a = {1, 2}
print(a | [2, 3])
```

# --answers--

- एक `TypeError`, क्योंकि `|` केवल सेट्स के बीच काम करता है: सेट को लिस्ट के साथ जोड़ने के लिए `union()` का उपयोग करें
- यह `{1, 2, 3}` प्रिंट करता है
- यह `{1, 2, [2, 3]}` प्रिंट करता है
- यह `[1, 2, 2, 3]` प्रिंट करता है
