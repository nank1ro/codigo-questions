**सेट (set)** एक ऐसा कलेक्शन है जिसमें **यूनिक** एलिमेंट्स होते हैं: एक ही वैल्यू को आप चाहे जितनी बार लिखें, वह केवल एक बार ही दिखाई देती है।
सेट **ऑर्डर-रहित** भी होता है: इसमें कोई पहला या आखिरी एलिमेंट नहीं होता, इसलिए आप इंडेक्स से कोई एलिमेंट नहीं पढ़ सकते।
सेट तब आदर्श होते हैं जब आपको बस इतना जानना हो कि *कौन-सी* वैल्यूज़ मौजूद हैं, न कि वे कितनी बार या किस पोज़िशन पर हैं।
आप कर्ली ब्रेसेज़ `{...}` के बीच एलिमेंट्स लिखकर एक सेट बनाते हैं:
```python
colors = {"red", "blue", "red"}
print(len(colors))  # 2
```
डुप्लीकेट `"red"` हटा दिया जाता है, इसलिए `len()` केवल अलग-अलग एलिमेंट्स को गिनता है।

---

बिल्ट-इन फ़ंक्शन `set()` किसी भी कलेक्शन से, जैसे किसी लिस्ट या स्ट्रिंग से, एक सेट बनाता है।
चूँकि एक सेट हर वैल्यू को केवल एक बार रखता है, इसलिए यह **डुप्लीकेट हटाने** का पारंपरिक तरीका है:
```python
nums = [1, 2, 2, 3]
unique = set(nums)
print(len(unique))  # 3
```
कोई वैल्यू मौजूद है या नहीं, यह जांचने के लिए `in` ऑपरेटर का उपयोग करें, जो `True` या `False` लौटाता है:
```python
print(2 in unique)  # True
print(9 in unique)  # False
```
सेट पर मेंबरशिप चेक बहुत तेज़ होते हैं, चाहे उसमें हज़ारों एलिमेंट्स ही क्यों न हों।

---

**खाली सेट** बनाते समय एक ट्रैप है।
कर्ली ब्रेसेज़ dictionary का भी सिंटैक्स हैं, इसलिए `{}` एक सेट नहीं बल्कि खाली **dictionary** बनाता है:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
खाली सेट पाने के लिए आपको बिना किसी आर्गुमेंट के `set()` कॉल करना होगा:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

---

सेट **म्यूटेबल** होते हैं: बनाने के बाद भी आप एलिमेंट्स जोड़ और हटा सकते हैं।
`add(value)` एक वैल्यू जोड़ता है; पहले से मौजूद वैल्यू को जोड़ने से कुछ नहीं बदलता:
```python
letters = {"a", "b"}
letters.add("c")
letters.add("a")
print(len(letters))  # 3
```
एलिमेंट हटाने के दो तरीके हैं:
- `remove(value)` उसे हटा देता है, लेकिन अगर वह वैल्यू सेट में नहीं है तो `KeyError` आता है
- `discard(value)` अगर वैल्यू मौजूद है तो उसे हटा देता है, वरना बिना किसी एरर के **कुछ नहीं करता**
```python
letters.remove("a")
letters.discard("z")  # "z" is not there, but no error
letters.remove("z")   # KeyError: 'z'
```

---

`pop()`, सेट से **कोई भी एलिमेंट** हटाता है और उसे रिटर्न करता है।
चूँकि सेट में कोई ऑर्डर नहीं होता, इसलिए आप यह नहीं चुन सकते कि कौन-सा एलिमेंट हटाया जाएगा; खाली सेट पर `pop()` कॉल करने से `KeyError` आता है:
```python
tickets = {101, 102, 103}
picked = tickets.pop()
print(len(tickets))  # 2
```
`clear()`, **सभी** एलिमेंट्स हटाकर एक खाली सेट छोड़ देता है:
```python
tickets.clear()
print(len(tickets))  # 0
```

---

आप एक लिस्ट की तरह ही, `for` के साथ किसी सेट पर लूप चला सकते हैं:
```python
for color in {"red", "blue"}:
    print(color)
```
चूँकि सेट ऑर्डर-रहित होता है, एलिमेंट्स **किसी भी क्रम** में आ सकते हैं, और यह क्रम अलग-अलग रन के बीच बदल भी सकता है।
जब आपको एक निश्चित क्रम चाहिए हो, तो सेट को `sorted()` में पास करें, जो इसके एलिमेंट्स की सॉर्ट की गई एक **लिस्ट** लौटाता है:
```python
for color in sorted({"red", "blue"}):
    print(color)  # blue, then red
```

---

दो सेट्स का **यूनियन (union)** एक नया सेट होता है जिसमें **दोनों** के एलिमेंट्स बिना डुप्लीकेट के होते हैं।
`|` ऑपरेटर या `union()` मेथड का उपयोग करें:
```python
a = {1, 2}
b = {2, 3}
print(a | b)        # {1, 2, 3}
print(a.union(b))   # {1, 2, 3}
```
न तो `a` और न ही `b` बदलता है: सेट ऑपरेशंस हमेशा एक नया सेट लौटाते हैं।

---

दो सेट्स का **इंटरसेक्शन (intersection)** केवल वे एलिमेंट्स रखता है जो **दोनों** में मौजूद हैं।
`&` ऑपरेटर या `intersection()` मेथड का उपयोग करें:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
अगर सेट्स में कुछ भी कॉमन नहीं है, तो नतीजा एक खाली सेट होता है।

---

**डिफरेंस (difference)** `a - b` में `a` के वे एलिमेंट्स होते हैं जो `b` में **नहीं** हैं।
क्रम मायने रखता है: `a - b` और `b - a` आमतौर पर अलग होते हैं:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a - b)  # {1}
print(b - a)  # {4}
```
**सिमेट्रिक डिफरेंस (symmetric difference)** `a ^ b` में वे एलिमेंट्स होते हैं जो दोनों सेट्स में से **किसी एक** में हैं:
```python
print(a ^ b)  # {1, 4}
```
मेथड रूप हैं `difference()` और `symmetric_difference()`।

---

ऑपरेटर्स और मेथड्स पूरी तरह एक जैसे नहीं होते।
`|`, `&`, `-` और `^` ऑपरेटर्स तभी काम करते हैं जब **दोनों** ऑपरेंड सेट हों।
`union()`, `intersection()`, `difference()` और `symmetric_difference()` मेथड्स किसी भी **इटरेबल** को स्वीकार करते हैं, जैसे लिस्ट या स्ट्रिंग:
```python
a = {1, 2}
print(a.union([2, 3]))  # {1, 2, 3}
print(a | [2, 3])       # TypeError: unsupported operand type(s) for |: 'set' and 'list'
```

---

सेट्स को एक-दूसरे से **कंपेयर** भी किया जा सकता है।
`a.issubset(b)`, या `a <= b`, तब `True` होता है जब `a` का हर एलिमेंट `b` में भी हो।
`a.issuperset(b)`, या `a >= b`, तब `True` होता है जब `a` में `b` का हर एलिमेंट हो।
`a.isdisjoint(b)` तब `True` होता है जब दोनों सेट्स में **कोई भी** कॉमन एलिमेंट न हो:
```python
small = {1, 2}
big = {1, 2, 3}
print(small <= big)              # True
print(big.issuperset(small))     # True
print(small.isdisjoint({8, 9}))  # True
```

---

एक सेट में केवल **हैशेबल** एलिमेंट्स हो सकते हैं, यानी ऐसी वैल्यूज़ जो बदल नहीं सकतीं: नंबर्स, स्ट्रिंग्स, `True`/`False` और **tuples**।
लिस्ट, dictionary या किसी अन्य सेट को जोड़ने की कोशिश करने पर `TypeError` आता है:
```python
points = set()
points.add((1, 2))  # ok, a tuple
points.add([1, 2])  # TypeError: unhashable type: 'list'
```
tuples के सेट्स यूनिक जोड़ों, जैसे कोऑर्डिनेट्स या (name, age) रिकॉर्ड्स को ट्रैक करने के लिए काफी उपयोगी होते हैं:
```python
visits = [(1, 2), (1, 2), (3, 4)]
print(len(set(visits)))  # 2
```

---

**frozenset** एक **इम्यूटेबल** सेट है: एक बार बन जाने के बाद, आप इसमें एलिमेंट्स जोड़ या हटा नहीं सकते।
इसे किसी भी कलेक्शन से `frozenset()` के साथ बनाएं:
```python
days = frozenset(["sat", "sun"])
print("sat" in days)  # True
days.add("mon")       # AttributeError: 'frozenset' object has no attribute 'add'
```
frozenset को प्रिंट करने पर एलिमेंट्स के आस-पास इसका टाइप दिखता है, जैसे `frozenset({'sat', 'sun'})`।
चूँकि यह बदल नहीं सकता, इसलिए frozenset हैशेबल होता है: एक सामान्य सेट के विपरीत, यह किसी अन्य सेट का एलिमेंट या dictionary की key बन सकता है।
सभी रीड-ओनली ऑपरेशंस (`in`, `len()`, `|`, `&`, `-`, `^`, तुलनाएं) हमेशा की तरह काम करते हैं।

---

एक **सेट कॉम्प्रिहेंशन (set comprehension)**, लिस्ट कॉम्प्रिहेंशन जैसे ही सिंटैक्स में लेकिन कर्ली ब्रेसेज़ के साथ, एक ही एक्सप्रेशन में सेट बनाता है:
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
एक वैकल्पिक `if` एलिमेंट्स को फ़िल्टर करता है, और एक्सप्रेशन से बनने वाले डुप्लीकेट अपने आप हट जाते हैं:
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```

---

सेट ऑपरेशंस एक नया सेट लौटाने के बजाय किसी सेट को **इन-प्लेस (in place)** भी बदल सकते हैं।
`update(iterable)`, किसी भी कलेक्शन का हर एलिमेंट जोड़ता है, `add()` जैसा ही लेकिन एक साथ कई वैल्यूज़ के लिए:
```python
inventory = {"sword"}
inventory.update(["potion", "map"])
print(len(inventory))  # 3
```
ऑगमेंटेड ऑपरेटर्स भी इन-प्लेस काम करते हैं: `|=` किसी दूसरे सेट के एलिमेंट्स जोड़ता है, `&=` केवल कॉमन एलिमेंट्स रखता है, `-=` किसी दूसरे सेट के एलिमेंट्स हटाता है:
```python
inventory -= {"map"}
print(sorted(inventory))  # ['potion', 'sword']
```

---

दो सेट्स **बराबर** होते हैं जब उनमें एक जैसे एलिमेंट्स हों, चाहे वे किसी भी क्रम में लिखे गए हों:
```python
print({1, 2, 3} == {3, 1, 2})  # True
```
किसी कलेक्शन की लंबाई की उसके सेट की लंबाई से तुलना करना डुप्लीकेट्स पहचानने का एक तेज़ तरीका है: अगर सेट **छोटा** है, तो इसका मतलब है कि कोई वैल्यू एक से ज़्यादा बार आई है:
```python
emails = ["a@x.com", "b@x.com", "a@x.com"]
print(len(set(emails)) < len(emails))  # True
```
लिस्ट मेथड `count(value)` बताता है कि कोई वैल्यू कितनी बार आती है, जिससे यह पता लगाने में मदद मिलती है कि *कौन-सी* वैल्यूज़ डुप्लीकेट हैं।
