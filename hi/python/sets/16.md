# --description--

दो सेट्स **बराबर** होते हैं जब उनमें एक जैसे एलिमेंट्स हों, चाहे वे किसी भी क्रम में लिखे गए हों:
```python
print({1, 2, 3} == {3, 1, 2})  # True
```
किसी कलेक्शन की लंबाई की उसके सेट की लंबाई से तुलना करना डुप्लीकेट्स पहचानने का एक तेज़ तरीका है: अगर सेट **छोटा** है, तो इसका मतलब है कि कोई वैल्यू एक से ज़्यादा बार आई है:
```python
emails = ["a@x.com", "b@x.com", "a@x.com"]
print(len(set(emails)) < len(emails))  # True
```
लिस्ट मेथड `count(value)` बताता है कि कोई वैल्यू कितनी बार आती है, जिससे यह पता लगाने में मदद मिलती है कि *कौन-सी* वैल्यूज़ डुप्लीकेट हैं।
