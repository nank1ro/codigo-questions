# --description--

एक **सेट कॉम्प्रिहेंशन (set comprehension)**, लिस्ट कॉम्प्रिहेंशन जैसे ही सिंटैक्स में लेकिन कर्ली ब्रेसेज़ के साथ, एक ही एक्सप्रेशन में सेट बनाता है:
```python
nums = [1, 2, 2, 3]
squares = {n * n for n in nums}
print(squares)  # {1, 4, 9}
```
एक वैकल्पिक `if` एलिमेंट्स को फ़िल्टर करता है, और एक्सप्रेशन से बनने वाले डुप्लीकेट अपने आप हट जाते हैं:
```python
evens = {n for n in range(10) if n % 2 == 0}
print(evens)  # {0, 2, 4, 6, 8}
```
