# --description--

बिल्ट-इन फ़ंक्शन `set()` किसी भी कलेक्शन से, जैसे किसी लिस्ट या स्ट्रिंग से, एक सेट बनाता है।
चूँकि एक सेट हर वैल्यू को केवल एक बार रखता है, इसलिए यह **डुप्लीकेट हटाने** का पारंपरिक तरीका है:
```python
nums = [1, 2, 2, 3]
unique = set(nums)
print(len(unique))  # 3
```
कोई वैल्यू मौजूद है या नहीं, यह जांचने के लिए `in` ऑपरेटर का उपयोग करें, जो `True` या `False` लौटाता है:
```python
print(2 in unique)  # True
print(9 in unique)  # False
```
सेट पर मेंबरशिप चेक बहुत तेज़ होते हैं, चाहे उसमें हज़ारों एलिमेंट्स ही क्यों न हों।
