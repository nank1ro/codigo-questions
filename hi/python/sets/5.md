# --description--

`pop()`, सेट से **कोई भी एलिमेंट** हटाता है और उसे रिटर्न करता है।
चूँकि सेट में कोई ऑर्डर नहीं होता, इसलिए आप यह नहीं चुन सकते कि कौन-सा एलिमेंट हटाया जाएगा; खाली सेट पर `pop()` कॉल करने से `KeyError` आता है:
```python
tickets = {101, 102, 103}
picked = tickets.pop()
print(len(tickets))  # 2
```
`clear()`, **सभी** एलिमेंट्स हटाकर एक खाली सेट छोड़ देता है:
```python
tickets.clear()
print(len(tickets))  # 0
```
