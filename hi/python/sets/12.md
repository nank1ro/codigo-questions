# --description--

एक सेट में केवल **हैशेबल** एलिमेंट्स हो सकते हैं, यानी ऐसी वैल्यूज़ जो बदल नहीं सकतीं: नंबर्स, स्ट्रिंग्स, `True`/`False` और **tuples**।
लिस्ट, dictionary या किसी अन्य सेट को जोड़ने की कोशिश करने पर `TypeError` आता है:
```python
points = set()
points.add((1, 2))  # ok, a tuple
points.add([1, 2])  # TypeError: unhashable type: 'list'
```
tuples के सेट्स यूनिक जोड़ों, जैसे कोऑर्डिनेट्स या (name, age) रिकॉर्ड्स को ट्रैक करने के लिए काफी उपयोगी होते हैं:
```python
visits = [(1, 2), (1, 2), (3, 4)]
print(len(set(visits)))  # 2
```

# --instructions--

`visits` में मौजूद अलग-अलग कोऑर्डिनेट्स का सेट `points` में स्टोर करें, उसमें पॉइंट `(0, 0)` जोड़ें, फिर उसमें मौजूद अलग-अलग पॉइंट्स की संख्या `count` में स्टोर करें
