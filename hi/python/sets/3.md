# --description--

**खाली सेट** बनाते समय एक ट्रैप है।
कर्ली ब्रेसेज़ dictionary का भी सिंटैक्स हैं, इसलिए `{}` एक सेट नहीं बल्कि खाली **dictionary** बनाता है:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
खाली सेट पाने के लिए आपको बिना किसी आर्गुमेंट के `set()` कॉल करना होगा:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, क्योंकि `{}` एक खाली dictionary बनाता है
- `<class 'set'>`, क्योंकि कर्ली ब्रेसेज़ एक सेट बनाते हैं
- `<class 'NoneType'>`, क्योंकि सेट में कोई एलिमेंट नहीं है
- एक `SyntaxError`, क्योंकि ब्रेसेज़ में कम से कम एक एलिमेंट होना चाहिए
