# --description--

**frozenset** एक **इम्यूटेबल** सेट है: एक बार बन जाने के बाद, आप इसमें एलिमेंट्स जोड़ या हटा नहीं सकते।
इसे किसी भी कलेक्शन से `frozenset()` के साथ बनाएं:
```python
days = frozenset(["sat", "sun"])
print("sat" in days)  # True
days.add("mon")       # AttributeError: 'frozenset' object has no attribute 'add'
```
frozenset को प्रिंट करने पर एलिमेंट्स के आस-पास इसका टाइप दिखता है, जैसे `frozenset({'sat', 'sun'})`।
चूँकि यह बदल नहीं सकता, इसलिए frozenset हैशेबल होता है: एक सामान्य सेट के विपरीत, यह किसी अन्य सेट का एलिमेंट या dictionary की key बन सकता है।
सभी रीड-ओनली ऑपरेशंस (`in`, `len()`, `|`, `&`, `-`, `^`, तुलनाएं) हमेशा की तरह काम करते हैं।
