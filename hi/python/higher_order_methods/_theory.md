Python में एक फ़ंक्शन एक **मान** होता है, बिल्कुल एक संख्या या स्ट्रिंग की तरह। आप इसे एक वेरिएबल में स्टोर कर सकते हैं, एक लिस्ट में रख सकते हैं या किसी दूसरे फ़ंक्शन को पास कर सकते हैं। केवल कोष्ठक ही इसे कॉल करते हैं: `shout` फ़ंक्शन खुद है, `shout("hi")` इसका परिणाम है:
```python
def shout(text):
    return text.upper() + "!"

say = shout
print(say("hi"))  # HI!
```
जो फ़ंक्शन किसी दूसरे फ़ंक्शन को पैरामीटर के रूप में प्राप्त करता है, या एक को रिटर्न करता है, उसे **higher-order फ़ंक्शन** कहा जाता है। इसके अंदर, पैरामीटर को किसी भी दूसरे फ़ंक्शन की तरह कोष्ठकों के साथ कॉल किया जाता है:
```python
def apply(func, value):
    return func(value)

print(apply(shout, "bye"))  # BYE!
print(apply(len, "bye"))    # 3
```

---

फ़ंक्शन को आर्ग्युमेंट के रूप में पास करने से कॉल करने वाला तय करता है **क्या** करना है, जबकि higher-order फ़ंक्शन तय करता है **कितनी बार** या **किस पर**। फ़ंक्शन पैरामीटर को जितनी बार जरूरत हो कॉल किया जा सकता है, और इसका परिणाम दोबारा इसमें फीड किया जा सकता है:
```python
def repeat(func, value, times):
    for _ in range(times):
        value = func(value)
    return value

def add_one(n):
    return n + 1

print(repeat(add_one, 0, 3))  # 3
```
कोई भी callable काम करता है: एक `def` फ़ंक्शन, `len` जैसा कोई बिल्ट-इन या एक `lambda`।

---

बिल्ट-इन `map(func, iterable)` हर एलिमेंट पर `func` को कॉल करता है और परिणाम प्रोड्यूस करता है, हर एलिमेंट के लिए एक। यह एक लेज़ी *map object* रिटर्न करता है, इसलिए वैल्यूज़ देखने के लिए इसे `list()` में रैप करें:
```python
numbers = [1, 2, 3]
print(list(map(lambda n: n * 10, numbers)))  # [10, 20, 30]
```
केवल lambda नहीं, कोई भी callable पास किया जा सकता है: `len` जैसा कोई बिल्ट-इन, या उसकी क्लास से लिया गया कोई मेथड, जैसे `str.upper`, जो स्ट्रिंग को अपने पहले आर्ग्युमेंट के रूप में लेता है:
```python
names = ["ada", "linus"]
print(list(map(str.upper, names)))  # ['ADA', 'LINUS']
print(list(map(len, names)))        # [3, 5]
```

---

बिल्ट-इन `filter(func, iterable)` केवल उन्हीं एलिमेंट्स को रखता है जिनके लिए `func` एक ट्रू वैल्यू रिटर्न करता है। `map` की तरह, यह एक लेज़ी ऑब्जेक्ट रिटर्न करता है जिसे लिस्ट में बदलना जरूरी है:
```python
numbers = [4, -2, 7, 0]
print(list(filter(lambda n: n > 0, numbers)))  # [4, 7]
```
`filter` को पास किए गए फ़ंक्शन को **predicate** कहा जाता है: यह एक एलिमेंट लेता है और उसके बारे में एक हाँ/नहीं सवाल का जवाब देता है। फ़ंक्शन की जगह `None` पास करने पर वे एलिमेंट्स रह जाते हैं जो खुद से ट्रू होते हैं, और `0`, `""` तथा `None` ड्रॉप हो जाते हैं।

---

`sorted(iterable, key=func)` एलिमेंट्स को उस वैल्यू के अनुसार ऑर्डर करता है जो `func` उनमें से हर एक के लिए रिटर्न करता है, बिना एलिमेंट्स को खुद बदले। सबसे बड़ा पहले पाने के लिए `reverse=True` जोड़ें:
```python
words = ["kiwi", "fig", "banana"]
print(sorted(words, key=len))                # ['fig', 'kiwi', 'banana']
print(sorted(words, key=len, reverse=True))  # ['banana', 'kiwi', 'fig']
```
सॉर्ट **स्टेबल** होता है: जिन एलिमेंट्स की कीज़ बराबर होती हैं वे अपना मूल क्रम बनाए रखते हैं। `key` फ़ंक्शन हर एलिमेंट पर एक बार कॉल होता है और इसके परिणामों का उपयोग केवल तुलना के लिए होता है, इसलिए आउटपुट में अब भी मूल शब्द होते हैं, उनकी लंबाई नहीं।

---

`key` फ़ंक्शन एक एलिमेंट का **कोई भी हिस्सा** चुन सकता है। ट्यूपल्स की एक लिस्ट के लिए `lambda s: s[1]` हर ट्यूपल के दूसरे आइटम के अनुसार सॉर्ट करता है; डिक्शनरीज़ की एक लिस्ट के लिए `lambda d: d["age"]` एक वैल्यू के अनुसार सॉर्ट करता है:
```python
pairs = [("b", 2), ("a", 3), ("c", 1)]
print(sorted(pairs, key=lambda p: p[1]))  # [('c', 1), ('b', 2), ('a', 3)]
```
`min` और `max` वही `key` पैरामीटर स्वीकार करते हैं, इसलिए `max(pairs, key=lambda p: p[1])` `('a', 3)` रिटर्न करता है: पूरा ट्यूपल, केवल संख्या नहीं।

---

एक फ़ंक्शन किसी दूसरे फ़ंक्शन को **रिटर्न** भी कर सकता है। `def` के साथ एक इनर फ़ंक्शन परिभाषित करें और उसे बिना कॉल किए रिटर्न करें:
```python
def make_greeter(greeting):
    def greet(name):
        return greeting + ", " + name
    return greet

hello = make_greeter("Hello")
print(hello("Ada"))  # Hello, Ada
```
इनर फ़ंक्शन `make_greeter` के खत्म होने के बाद भी `greeting` का उपयोग करता रहता है: यह उस स्कोप के वेरिएबल्स को **याद** रखता है जहाँ वह बनाया गया था। ऐसे फ़ंक्शन को **closure** कहा जाता है। `make_greeter` की हर कॉल अपने `greeting` वाला एक नया, स्वतंत्र closure बनाती है।

---

एक closure अपने एनक्लोज़िंग फ़ंक्शन के वेरिएबल्स को पढ़ सकता है, लेकिन उनमें से किसी एक को असाइन करने पर इसकी जगह एक **नया लोकल** वेरिएबल बन जाता है। आउटर वेरिएबल को अपडेट करने के लिए, इनर फ़ंक्शन के अंदर उसे `nonlocal` के साथ डिक्लेयर करें:
```python
def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment
```
`global` `count` को मॉड्यूल लेवल पर खोजेगा, जहाँ वह मौजूद नहीं है। `nonlocal` के साथ, रिटर्न किए गए फ़ंक्शन की हर कॉल उसी `count` को अपडेट करती है, इसलिए closure कॉल्स के बीच स्टेट कैरी करता है, बिल्कुल एक छोटी ऑब्जेक्ट की तरह।

---

`functools` मॉड्यूल का `reduce(func, iterable, initial)` एक सीक्वेंस को एक **सिंगल वैल्यू** में फोल्ड करता है। यह `func` को अब तक के परिणाम और अगले एलिमेंट के साथ कॉल करता है, `initial` से शुरू करके:
```python
from functools import reduce

total = reduce(lambda acc, n: acc + n, [1, 2, 3], 0)
print(total)  # 6
```
स्टेप्स हैं `0 + 1`, फिर `1 + 2`, फिर `3 + 3`। जब `initial` छोड़ दिया जाता है, तो पहले एलिमेंट को शुरुआती वैल्यू के रूप में इस्तेमाल किया जाता है, लेकिन तब एक खाली सीक्वेंस `TypeError` रेज़ करता है, इसलिए जब भी सीक्वेंस खाली हो सकता हो एक इनिशियल वैल्यू दें।

---

`functools` का `partial(func, *fixed)` कुछ आर्ग्युमेंट्स **पहले से भरे हुए** रखकर एक नया फ़ंक्शन बनाता है। परिणाम को कॉल करने पर बाकी आर्ग्युमेंट्स दिए जाते हैं:
```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(5))  # 25
```
`partial` को दिए गए पोज़िशनल आर्ग्युमेंट्स पहले पैरामीटर्स को भरते हैं; कीवर्ड आर्ग्युमेंट्स नाम से एक पैरामीटर फिक्स करते हैं और उन्हें कॉल के समय अब भी ओवरराइड किया जा सकता है। एक partial एक साधारण callable होता है, इसलिए इसे `map`, `sorted` या किसी भी दूसरे higher-order फ़ंक्शन को पास किया जा सकता है।

---

जो बिल्ट-इन ऑप्शंस लेते हैं उनके साथ `partial` बहुत काम आता है। `int(text, base=16)` एक हेक्साडेसिमल स्ट्रिंग को पार्स करता है; बेस को फिक्स करने से एक वन-आर्ग्युमेंट कन्वर्टर बनता है जो `map` में फिट हो जाता है:
```python
from functools import partial

hex_to_int = partial(int, base=16)
print(hex_to_int("ff"))                      # 255
print(list(map(hex_to_int, ["a", "10"])))    # [10, 16]
```
partial ऑब्जेक्ट याद रखता है कि वह किसे रैप करता है: `hex_to_int.func` `int` है, और `hex_to_int.keywords` `{'base': 16}` है।

---

एक **डेकोरेटर** एक higher-order फ़ंक्शन होता है जो एक फ़ंक्शन लेता है और एक नया फ़ंक्शन रिटर्न करता है जो उसे रैप करता है, आमतौर पर मूल कॉल से पहले या बाद बिहेवियर जोड़ने के लिए:
```python
def announce(func):
    def wrapper(name):
        print("calling " + func.__name__)
        return func(name)
    return wrapper
```
`func.__name__` वह नाम है जिसके साथ फ़ंक्शन परिभाषित किया गया था। डेकोरेटर लगाना बस एक कॉल है: `greet = announce(greet)`। एक `def` के **ऊपर** वाली लाइन पर रखा `@` सिंटैक्स बिल्कुल यही करता है:
```python
@announce
def greet(name):
    return "Hello, " + name
```
डेकोरेटर को `@` के साथ उपयोग करने से पहले परिभाषित किया जाना चाहिए, क्योंकि रिप्लेसमेंट जैसे ही `def` चलता है हो जाता है।

---

जो डेकोरेटर केवल एक आर्ग्युमेंट स्वीकार करता है वह बहुत काम का नहीं होता। **किसी भी** फ़ंक्शन को रैप करने के लिए, रैपर हर पोज़िशनल आर्ग्युमेंट को `*args` में और हर कीवर्ड आर्ग्युमेंट को `**kwargs` में इकट्ठा करता है, और उन्हें बिना बदले फॉरवर्ड करता है:
```python
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@uppercase
def greet(name, punctuation="!"):
    return "hello " + name + punctuation

print(greet("ada"))                    # HELLO ADA!
print(greet("ada", punctuation="?"))   # HELLO ADA?
```
रैपर के अंदर, `args` एक ट्यूपल है और `kwargs` एक डिक्शनरी; कॉल में `*` और `**` उन्हें वापस अलग-अलग आर्ग्युमेंट्स में अनपैक करते हैं।

---

`any(iterable)` `True` रिटर्न करता है यदि **कम से कम एक** एलिमेंट ट्रू है, और `all(iterable)` तब जब **हर** एलिमेंट ट्रू हो। वे एक **जेनरेटर एक्सप्रेशन** के साथ स्वाभाविक रूप से जुड़ते हैं: एक लिस्ट कॉम्प्रिहेंशन जो स्क्वेयर ब्रैकेट्स के बिना लिखा जाता है, जो एक लिस्ट बनाने की जगह वैल्यूज़ को एक-एक करके प्रोड्यूस करता है:
```python
ages = [21, 34, 17]
print(any(age >= 18 for age in ages))  # True
print(all(age >= 18 for age in ages))  # False
```
क्योंकि वैल्यूज़ लेज़ली प्रोड्यूस होती हैं, `any` पहले `True` पर और `all` पहले `False` पर रुक जाता है, बाकी का एवैल्यूएट किए बिना। `sum` भी एक जेनरेटर एक्सप्रेशन स्वीकार करता है: `sum(1 for age in ages if age >= 18)` वयस्कों की गिनती करता है।
