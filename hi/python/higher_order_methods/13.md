# --description--

जो डेकोरेटर केवल एक आर्ग्युमेंट स्वीकार करता है वह बहुत काम का नहीं होता। **किसी भी** फ़ंक्शन को रैप करने के लिए, रैपर हर पोज़िशनल आर्ग्युमेंट को `*args` में और हर कीवर्ड आर्ग्युमेंट को `**kwargs` में इकट्ठा करता है, और उन्हें बिना बदले फॉरवर्ड करता है:
```python
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

@uppercase
def greet(name, punctuation="!"):
    return "hello " + name + punctuation

print(greet("ada"))                    # HELLO ADA!
print(greet("ada", punctuation="?"))   # HELLO ADA?
```
रैपर के अंदर, `args` एक ट्यूपल है और `kwargs` एक डिक्शनरी; कॉल में `*` और `**` उन्हें वापस अलग-अलग आर्ग्युमेंट्स में अनपैक करते हैं।

# --instructions--

एक डेकोरेटर `exclaim` लिखें जो एक ऐसा रैपर रिटर्न करे जो कोई भी आर्ग्युमेंट स्वीकार करे, रैप किए गए फ़ंक्शन को उन्हीं के साथ कॉल करे और उसका परिणाम `"!"` जोड़कर रिटर्न करे; फिर इसका उपयोग एक फ़ंक्शन `greet` को डेकोरेट करने के लिए करें जो एक `name` लेता है और `"hello <name>"` रिटर्न करता है

```python
    def test_2(self):

        self.assertEqual(joined("good", "day"), "good day!", "--err-t2--")
```

```python
    def test_3(self):
        tag = exclaim(lambda word, times=1: word * times)
        self.assertEqual(tag("hi", times=2), "hihi!", "--err-t3--")
```
