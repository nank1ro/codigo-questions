# --instructions--

एक आर्ग्युमेंट वाले फ़ंक्शन्स के लिए एक डेकोरेटर `memoize` लिखें: इसे हर परिणाम को closure के अंदर एक डिक्शनरी में स्टोर करना चाहिए, ताकि डेकोरेटेड फ़ंक्शन को उसी आर्ग्युमेंट के साथ दोबारा कॉल करने पर मूल फ़ंक्शन को कॉल किए बिना सेव किया गया परिणाम रिटर्न हो

# --asserts--

डेकोरेटेड फ़ंक्शन को मूल फ़ंक्शन जितने ही परिणाम रिटर्न करने चाहिए

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

कॉल दोहराने पर मूल फ़ंक्शन दोबारा नहीं चलना चाहिए

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

हर डेकोरेटेड फ़ंक्शन का अपना खुद का कैश होना चाहिए

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
