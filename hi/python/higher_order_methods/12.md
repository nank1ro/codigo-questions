# --description--

एक **डेकोरेटर** एक higher-order फ़ंक्शन होता है जो एक फ़ंक्शन लेता है और एक नया फ़ंक्शन रिटर्न करता है जो उसे रैप करता है, आमतौर पर मूल कॉल से पहले या बाद बिहेवियर जोड़ने के लिए:
```python
def announce(func):
    def wrapper(name):
        print("calling " + func.__name__)
        return func(name)
    return wrapper
```
`func.__name__` वह नाम है जिसके साथ फ़ंक्शन परिभाषित किया गया था। डेकोरेटर लगाना बस एक कॉल है: `greet = announce(greet)`। एक `def` के **ऊपर** वाली लाइन पर रखा `@` सिंटैक्स बिल्कुल यही करता है:
```python
@announce
def greet(name):
    return "Hello, " + name
```
डेकोरेटर को `@` के साथ उपयोग करने से पहले परिभाषित किया जाना चाहिए, क्योंकि रिप्लेसमेंट जैसे ही `def` चलता है हो जाता है।
