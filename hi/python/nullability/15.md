```python
    def test_1(self):
        people = [{"name": "Ada", "age": 36}, {"name": "Linus", "age": 28}, {"name": "Grace", "age": 45}]
        self.assertEqual(oldest(people), "Grace", "--err-t1--")
```

बिना उम्र वाले या `None` उम्र वाले लोगों को इग्नोर किया जाना चाहिए

```python
    def test_2(self):
        people = [{"name": "Tim"}, {"name": "Ada", "age": 36}, {"name": "Bob", "age": None}]
        self.assertEqual(oldest(people), "Ada", "--err-t2--")
```

रिज़ल्ट `None` होना चाहिए जब किसी की उम्र न हो, और उम्र `0` होने पर उसे गिना जाना चाहिए

```python
    def test_3(self):
        self.assertIsNone(oldest([{"name": "Tim"}, {"name": "Bob", "age": None}]), "--err-t3--")
        self.assertIsNone(oldest([]), "--err-t3--")
        self.assertEqual(oldest([{"name": "Baby", "age": 0}, {"name": "Tim"}]), "Baby", "--err-t3--")
```

```python
def oldest(people):
    best_name = None
    best_age = None
    for person in people:
        age = person.get("age")
        if age is None:
            continue
        if best_age is None or age > best_age:
            best_age = age
            best_name = person["name"]
    return best_name
```
