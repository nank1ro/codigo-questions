# --description--

`or` ऑपरेटर `True` या `False` लौटाता नहीं है: वह अपना **बायाँ** ऑपरेंड लौटाता है जब वह true हो, और अन्यथा अपना **दायाँ** ऑपरेंड। इससे फ़ॉलबैक देने का एक एक-लाइन का तरीका मिलता है:
```python
name = None
print(name or "anonymous")  # anonymous
name = "Ada"
print(name or "anonymous")  # Ada
```
बात यह है कि `or` truthiness देखता है, `None` नहीं: `0`, `""` और `[]` भी फ़ॉलबैक से बदल दिए जाते हैं। `x or fallback` का उपयोग केवल तब करें जब हर खाली मान को भी फ़ॉलबैक बनना चाहिए।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
def label(count):
    return count or "unknown"

print(label(0), label(None), label(5))
```

# --answers--

- `unknown unknown 5`, क्योंकि `0` false है, इसलिए उसे भी फ़ॉलबैक से बदल दिया जाता है
- `0 unknown 5`, क्योंकि केवल `None` फ़ॉलबैक से बदला जाता है
- `False unknown 5`, क्योंकि `or`, `0` को बूलियन में बदल देता है
- `True True True`, क्योंकि `or` हमेशा एक बूलियन लौटाता है
