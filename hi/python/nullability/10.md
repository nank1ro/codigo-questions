# --description--

जब `0` या `""` को रखना हो और केवल `None` को बदलना हो, तो फ़ॉलबैक को साफ़ तौर पर लिखी गई एक `is None` जाँच चाहिए। कॉम्पैक्ट रूप **conditional expression** है, `a if condition else b`, जो कंडीशन true होने पर `a` का मूल्यांकन करता है और अन्यथा `b` का:
```python
timeout = 0
seconds = timeout if timeout is not None else 30
print(seconds)  # 0, not 30
```

