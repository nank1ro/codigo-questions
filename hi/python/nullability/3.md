# --description--

यह जाँचने के लिए कि कोई वेरिएबल `None` रखता है या नहीं, `is` और `is not` का उपयोग करें, कभी भी `==` नहीं:
```python
if user is None:
    print("nobody logged in")
if user is not None:
    print("welcome")
```
`==` पूछता है "क्या ये मान *बराबर* हैं?", और कोई भी क्लास `__eq__` मेथड परिभाषित करके इस सवाल का अपने तरीके से जवाब दे सकती है। `is` पूछता है "क्या ये *एक ही ऑब्जेक्ट* हैं?", और इसका जवाब कुछ भी नहीं बदल सकता।
चूँकि `None` केवल एक ही होता है, `is None` हमेशा सही और थोड़ा तेज़ होता है, जबकि `== None` कस्टम `__eq__` वाले ऑब्जेक्ट्स के लिए चौंकाने वाला जवाब दे सकता है।

# --instructions--

यह कोड क्या प्रिंट करता है?
```python
class Anything:
    def __eq__(self, other):
        return True

a = Anything()
print(a == None, a is None)
```

# --answers--

- `True False`, क्योंकि `==` कस्टम `__eq__` को कॉल करता है जबकि `is` पहचान की जाँच करता है
- `False False`, क्योंकि किसी भी स्थिति में `a`, `None` नहीं है
- `True True`, क्योंकि `__eq__` `is` का रिज़ल्ट भी नियंत्रित करता है
- एक `TypeError`, क्योंकि किसी ऑब्जेक्ट की तुलना `None` से नहीं की जा सकती
