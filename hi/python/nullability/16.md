# --instructions--

एक फंक्शन `get_path` लिखें जो एक डिक्शनरी `data`, `keys` की एक लिस्ट और एक ऑप्शनल `default` (प्रोवाइड न होने पर `None`) लेता है; उसे कुंजियों का एक बार में एक लेवल पीछा करना चाहिए और मिला हुआ मान लौटाना चाहिए, या `default` जब कोई कुंजी मौजूद न हो, `None` रखती हो या कोई कदम डिक्शनरी न हो; `0` और `""` जैसे मान ज्यों के त्यों लौटाए जाने चाहिए

# --asserts--

`default` का डिफ़ॉल्ट मान `None` होना चाहिए

```json
{
  "regex": "default\\s*=\\s*None",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`get_path({"address": {"city": "Rome"}}, ["address", "city"])` को `"Rome"` लौटाना चाहिए

```python
    def test_1(self):
        data = {"address": {"city": "Rome"}}
        self.assertEqual(get_path(data, ["address", "city"]), "Rome", "--err-t1--")
        self.assertEqual(get_path(data, ["address"]), {"city": "Rome"}, "--err-t1--")
```

मौजूद न होने वाली, `None` या गैर-डिक्शनरी स्टेप पर डिफ़ॉल्ट मिलना चाहिए

```python
    def test_2(self):
        data = {"address": None, "name": "Ada"}
        self.assertIsNone(get_path(data, ["address", "city"]), "--err-t2--")
        self.assertEqual(get_path(data, ["phone", "home"], "n/a"), "n/a", "--err-t2--")
        self.assertEqual(get_path(data, ["name", "first"], "n/a"), "n/a", "--err-t2--")
```

`0` और `""` ज्यों के त्यों लौटाए जाने चाहिए

```python
    def test_3(self):
        data = {"stats": {"count": 0, "note": ""}}
        self.assertEqual(get_path(data, ["stats", "count"], -1), 0, "--err-t3--")
        self.assertEqual(get_path(data, ["stats", "note"], "none"), "", "--err-t3--")
```

# --solutions--

```python
def get_path(data, keys, default=None):
    current = data
    for key in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(key)
        if current is None:
            return default
    return current
```
