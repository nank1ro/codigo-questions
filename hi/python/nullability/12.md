# --description--

लुकअप के बाद एक `None` जाँच आम तौर पर दो लाइनें लेती है: एक रिज़ल्ट स्टोर करने के लिए, एक उसे टेस्ट करने के लिए। **assignment expression** ऑपरेटर `:=`, जिसे *walrus* के नाम से जाना जाता है, एक एक्सप्रेशन के **अंदर** मान असाइन करता है, ताकि दोनों कदम `if` में समा जाएँ:
```python
ages = {"Ada": 36}
if (age := ages.get("Ada")) is not None:
    print(age + 1)  # 37
```
कोष्ठक ज़रूरी हैं: उनके बिना `:=` पूरी तुलना को असाइन करने की कोशिश करेगा। `if` के बाद `age` किसी भी दूसरे वेरिएबल की तरह उपलब्ध रहता है।

```python
def describe_user(users, name):
    if (age := users.get(name)) is not None:
        return f"{name} is {age}"
    return "unknown user"
```
