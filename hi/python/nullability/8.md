# --description--

जो फंक्शन `None` प्राप्त कर सकते हैं वे अक्सर एक **guard** के साथ शुरू होते हैं: एक `if` जो जल्दी लौट जाता है जब काम करने को कुछ नहीं होता। फंक्शन का बाकी हिस्सा तब मान सकता है कि मान मौजूद है, सब कुछ एक `else` के अंदर नेस्ट किए बिना:
```python
def shout(text):
    if text is None:
        return None
    return text.upper() + "!"
```
Guard पहले आते हैं, उसी क्रम में जिस क्रम में जाँचें होनी चाहिए: `text.split()` को कॉल करना संभव नहीं है इससे पहले कि आप जान लें कि `text`, `None` नहीं है।

```python
def first_word(text):
    if text is None:
        return None
    words = text.split()
    if len(words) == 0:
        return None
    return words[0]
print(first_word("hello world"))
print(first_word(None))
print(first_word("   "))
```
