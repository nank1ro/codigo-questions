# --description--

जब एक लाइन काफ़ी न हो, तो docstring एक निश्चित लेआउट में बदल जाती है, जिसे **PEP 257** में बताया गया है: एक लाइन की समरी, एक खाली लाइन, फिर विवरण, और बंद करने वाला `"""` अपनी अलग लाइन पर।
```python
def to_seconds(minutes):
    """Returns the number of seconds in the given minutes.

    minutes is a whole number and is never negative.
    """
    return minutes * 60
```
खाली लाइन मायने रखती है: टूल पहली लाइन को अकेले, एक छोटे विवरण की तरह दिखाते हैं, और बाकी को उनके लिए रखते हैं जो और पढ़ना चाहें।

# --asserts--

`area` के पास एक docstring होनी चाहिए

```python
    def test_1(self):
        self.assertIsNotNone(area.__doc__, "--err-t1--")
```

docstring की शुरुआत एक समरी लाइन से होनी चाहिए, जिसके बाद एक खाली लाइन और फिर और टेक्स्ट हो

```python
    def test_2(self):
        lines = area.__doc__.split("\n")
        self.assertTrue(len(lines) >= 3, "--err-t2--")
        self.assertNotEqual(lines[0].strip(), "", "--err-t2--")
        self.assertEqual(lines[1].strip(), "", "--err-t2--")
        self.assertNotEqual(lines[2].strip(), "", "--err-t2--")
        self.assertEqual(lines[-1].strip(), "", "--err-t2--")
```

`area(3, 4)` को `12` लौटाना चाहिए और `area(0, 5)` को `0` लौटाना चाहिए

```python
    def test_3(self):
        self.assertEqual(area(3, 4), 12, "--err-t3--")
        self.assertEqual(area(0, 5), 0, "--err-t3--")
```
