# --description--

फंक्शन के ऊपर यह बताने के लिए रखा कमेंट कि फंक्शन क्या करता है, गलत जगह पर होता है। उसके लिए सही जगह docstring है: वह फंक्शन से जुड़ी होती है, `help()` उसे ढूंढता है और एडिटर उसे दिखाते हैं, जबकि `def` के ऊपर का `#` कमेंट इन सबके लिए अदृश्य होता है।

```python
# a और b जोड़ता है
def add(a, b):
    return a + b
```
उसी वाक्य को एक लाइन नीचे, ट्रिपल कोट्स के बीच रखने से वह असली डॉक्यूमेंटेशन बन जाता है:
```python
def add(a, b):
    """Returns the sum of a and b."""
    return a + b
```
