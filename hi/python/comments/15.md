# --description--

Python `#` को केवल कोड में ढूंढता है, कभी भी **स्ट्रिंग** के अंदर नहीं। कोट्स के बीच `#` एक साधारण अक्षर है:
```python
print("black is #000000")  # a hex colour
```
पहला `#` टेक्स्ट का हिस्सा है, दूसरा एक असली कमेंट शुरू करता है। वही बात `#` कमेंट के अंदर `"""` पर भी लागू होती है: वहाँ वह बस तीन कोट अक्षर हैं, और कुछ शुरू नहीं करती।

# --instructions--

एक फंक्शन `label(name)` लिखें जो `name` के आगे एक `#` जोड़कर लौटाए, ताकि `label("python")` `"#python"` लौटाए

# --asserts--

`label("python")` को `"#python"` लौटाना चाहिए

```python
    def test_1(self):
        self.assertEqual(label("python"), "#python", "--err-t1--")
```

`label("ai")` को `"#ai"` लौटाना चाहिए

```python
    def test_2(self):
        self.assertEqual(label("ai"), "#ai", "--err-t2--")
```

`label("")` को `"#"` लौटाना चाहिए

```python
    def test_3(self):
        self.assertEqual(label(""), "#", "--err-t3--")
```

def label(name):
    """Returns name with a # in front of it."""
