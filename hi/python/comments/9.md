# --description--

क्लासेस भी वैसे ही काम करते हैं: क्लास बॉडी के पहले स्टेटमेंट के रूप में रखी गई स्ट्रिंग उस क्लास की docstring होती है, और वह `__doc__` में संग्रहीत रहती है:
```python
class Point:
    """A point on a grid."""

    def __init__(self, x, y):
        self.x = x
        self.y = y

print(Point.__doc__)  # A point on a grid.
```
क्लास के अंदर हर मेथड की अपनी docstring भी हो सकती है, जिसे `Point.__init__.__doc__` से पढ़ा जाता है। इसलिए docstring स्वीकार करने वाली तीन जगहें हैं: मॉड्यूल का शीर्ष, क्लास का शीर्ष और फंक्शन का शीर्ष।
