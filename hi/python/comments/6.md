# --description--

जब कोई स्ट्रिंग किसी फंक्शन के अंदर **पहला स्टेटमेंट** होती है, तो Python उसे उस फंक्शन का डॉक्यूमेंटेशन मानता है। इसे **docstring** कहते हैं:
```python
def greet(name):
    """Returns the greeting for name."""
    return "Hi, " + name + "!"
```
परंपरा के अनुसार docstring ट्रिपल डबल कोट्स, `"""`, के बीच लिखी जाती है, तब भी जब वह एक लाइन में समा जाए, ताकि बाद में कोट्स बदले बिना वह बढ़ सके।

समरी को तीसरे पुरुष में लिखें, मानो फंक्शन का वर्णन कर रहे हों: "Returns...", "Adds...", "Checks..."। docstring बॉडी के किसी भी दूसरे स्टेटमेंट से पहले आनी चाहिए, अन्यथा वह सिर्फ़ एक साधारण स्ट्रिंग है।

# --instructions--

एक फंक्शन `double(n)` लिखें जो `n` का दोगुना लौटाए, और उसे एक लाइन की docstring दें

# --asserts--

`double` का पहला स्टेटमेंट एक docstring होना चाहिए

```python
    def test_1(self):
        self.assertIsNotNone(double.__doc__, "--err-t1--")
```

`double(21)` को `42` लौटाना चाहिए

```python
    def test_2(self):
        self.assertEqual(double(21), 42, "--err-t2--")
```

`double(-3)` को `-6` लौटाना चाहिए और `double(0)` को `0` लौटाना चाहिए

```python
    def test_3(self):
        self.assertEqual(double(-3), -6, "--err-t3--")
        self.assertEqual(double(0), 0, "--err-t3--")
```
