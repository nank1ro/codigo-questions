# --description--

कई भाषाओं में दूसरे प्रकार का कमेंट होता है, एक **ब्लॉक कमेंट** जो कई लाइनों तक फैला होता है, जैसे `/* ... */`। Python में ऐसा कोई सिंटैक्स नहीं है: `#` ही सब कुछ है।

जब किसी समझाने के लिए एक से अधिक लाइन चाहिए, तो हर लाइन के आगे एक `#` लगाएँ:
```python
# Prints the welcome banner.
# Called once when the app starts.
print("Welcome!")
```
वही तरीका एक साथ कई लाइनों के कोड को कमेंट आउट करता है: हर लाइन पर एक `#`। हर एडिटर एक ही शॉर्टकट से चुने हुए पूरे हिस्से के लिए वे `#` जोड़ या हटा सकता है, इसलिए यह जितना लगता है उससे कम काम है।
