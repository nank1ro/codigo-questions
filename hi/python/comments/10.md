# --description--

Docstrings और `#` कमेंट्स एक जैसे दिखते हैं लेकिन अलग-अलग सवालों के जवाब देते हैं।

**docstring** उनके लिए है जो कोड को **उपयोग** करते हैं: फंक्शन क्या करता है, क्या अपेक्षा रखता है और क्या वापस देता है। वह `__doc__` में बची रहती है, `help()` उसे पढ़ता है, एडिटर उसे दिखाते हैं, और डॉक्यूमेंटेशन टूल उसे इकट्ठा करते हैं।

**कमेंट** उनके लिए है जो कोड को **पढ़ते** हैं: यह लाइन इस तरह क्यों लिखी गई है, वह अजीब संख्या क्या दर्शाती है, वह किस बग के इर्द-गिर्द काम करती है। वह केवल सोर्स फ़ाइल में मौजूद होती है और प्रोग्राम चलते ही गायब हो जाती है।

```python
def timeout():
    """Returns the number of seconds to wait for the server."""
    # सर्वर 35 सेकंड बाद निष्क्रिय कनेक्शन हटा देता है
    return 30
```
यानी: फंक्शन का डॉक्यूमेंटेशन docstring में जाता है, इम्प्लीमेंटेशन के बारे में नोट्स कमेंट्स में जाते हैं।

# --instructions--

docstring और `#` कमेंट में क्या अंतर है?

# --answers--

- docstring एक स्ट्रिंग है जो `__doc__` में रहती है और टूल उसे दिखाते हैं, जबकि `#` कमेंट केवल सोर्स फ़ाइल में मौजूद होता है
- कोई अंतर नहीं है: प्रोग्राम चलने से पहले दोनों हटा दिए जाते हैं
- docstring केवल फंक्शन के अंदर उपयोग की जा सकती है, जबकि `#` कमेंट कहीं भी उपयोग किया जा सकता है
- `#` कमेंट `__doc__` में रखा जाता है, जबकि docstring प्रोग्राम चलने से पहले हटा दी जाती है
