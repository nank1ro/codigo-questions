# --description--

एक अच्छा कमेंट यह बताता है कि कोड कोई काम **क्यों** करता है, **क्या** करता है नहीं। कोड पहले से दिखा देता है कि क्या होता है; उसे शब्दों में दोहराना शोर जोड़ता है और कोड बदलते ही वह पुराना पड़ जाता है:
```python
# set timeout to 30
timeout = 30
```
संख्या के पीछे का कारण ही वह चीज़ है जिसका अंदाज़ा पाठक नहीं लगा सकता:
```python
# the server drops idle connections after 35 seconds, so stop earlier
timeout = 30
```
अगर कोई कमेंट सिर्फ़ अपने नीचे की लाइन को दोहराता है, तो उसे हटा दें या उसे कारण से बदल दें। सबसे अच्छे कमेंट वे हैं जो कुछ ऐसा बताते हैं जो कोड नहीं बता सकता।
