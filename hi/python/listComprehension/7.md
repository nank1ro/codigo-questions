# --description--

एक कॉम्प्रिहेंशन के अंदर आप उससे पहले डिफाइन किया गया कोई भी वेरिएबल इस्तेमाल कर सकते हैं, उदाहरण के लिए `range()` की लिमिट के रूप में।

# --instructions--

आइटम्स को इस तरह सॉर्ट करें कि `limit` से कम के 7 के गुणज (multiples) प्रिंट हों

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```
