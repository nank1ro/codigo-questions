एक बहुत ही सामान्य काम है किसी मौजूदा लिस्ट से एक नई लिस्ट बनाना।
`for` लूप और `append()` के साथ इसमें कुछ लाइनें लगती हैं:
```python
nums = [1, 2, 3]
doubled = []
for n in nums:
    doubled.append(n * 2)
print(doubled)  # [2, 4, 6]
```
Python इसी काम के लिए एक छोटा रूप प्रदान करता है: **लिस्ट कॉम्प्रिहेंशन**, जो पूरी लिस्ट को एक ही एक्सप्रेशन में बनाता है:
```python
doubled = [n * 2 for n in nums]
```
सिंटैक्स है `[expression for item in iterable]`: `for` वाला भाग आइटम्स पर लूप करता है, और बाईं ओर का एक्सप्रेशन हर आइटम के लिए एवैल्यूएट होता है।
परिणाम एक बिल्कुल नई लिस्ट होती है, ठीक वैसी ही जैसी लूप से बनाई गई थी।

---

बाईं ओर का एक्सप्रेशन कुछ भी हो सकता है जो एक मान बनाता है: एक कैलकुलेशन, एक फ़ंक्शन कॉल, एक मेथड कॉल।
लूप वेरिएबल का कोई भी नाम हो सकता है, और यह केवल स्क्वेयर ब्रैकेट्स के अंदर ही मौजूद होता है:
```python
prices = [10, 20]
with_tax = [price * 1.2 for price in prices]
print(with_tax)  # [12.0, 24.0]
```

---

एक कॉम्प्रिहेंशन आइटम्स को **फ़िल्टर** भी कर सकता है।
`for` वाले भाग के बाद एक `if` कंडीशन जोड़ें: केवल वे आइटम्स नई लिस्ट में जाते हैं जिनके लिए कंडीशन `True` होती है:
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
यह अंदर `if` वाले लूप जैसा ही है, और यह lambda के साथ `filter()` को एक ज्यादा पढ़ने में आसान तरीके से बदल देता है।

---

फ़िल्टर कंडीशन कोई भी ऐसा एक्सप्रेशन हो सकता है जो एक बूलियन मान देता है, जिसमें `len()` जैसे फ़ंक्शन कॉल भी शामिल हैं:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```

---

इटरेबल का लिस्ट होना ज़रूरी नहीं है: जिस भी चीज़ पर आप लूप कर सकते हैं वह काम करती है, और `range()` इसके लिए सबसे पसंदीदा है।
यह संख्याओं की लिस्ट बनाने का सबसे तेज़ तरीका है:
```python
squares = [n * n for n in range(4)]
print(squares)  # [0, 1, 4, 9]
```
याद रखें कि `range(start, stop)` में `stop` शामिल नहीं होता।

---

कॉम्प्रिहेंशन **स्ट्रिंग्स को बदलने** के लिए भी शानदार हैं।
हर आइटम पर एक स्ट्रिंग मेथड कॉल करें, या f-स्ट्रिंग से एक नई स्ट्रिंग बनाएं:
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```

---

एक कॉम्प्रिहेंशन के अंदर आप उससे पहले डिफाइन किया गया कोई भी वेरिएबल इस्तेमाल कर सकते हैं, उदाहरण के लिए `range()` की लिमिट के रूप में।

---

कभी-कभी आप आइटम्स को हटाना नहीं चाहते, बल्कि उनमें से कुछ के लिए **अलग मान** चुनना चाहते हैं।
`for` से पहले, एक्सप्रेशन के रूप में एक कंडीशनल एक्सप्रेशन `a if condition else b` इस्तेमाल करें:
```python
nums = [3, -1, 4]
signs = ["+" if n > 0 else "-" for n in nums]
print(signs)  # ['+', '-', '+']
```
इसकी पोजीशन ध्यान दें: `if-else` `for` से **पहले** आता है और हमेशा एक मान देता है, जबकि फ़िल्टर `if` `for` के **बाद** आता है और इसका कोई `else` नहीं होता।

---

दोनों कंडीशंस को एक ही कॉम्प्रिहेंशन में जोड़ा जा सकता है: मान चुनने के लिए एक `if-else`, और कुछ आइटम्स को स्किप करने के लिए आखिर में एक फ़िल्टर `if`।
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```

---

`if` की दो स्थितियाँ आसानी से गड्डमड्ड हो जाती हैं, इसलिए इन्हें अलग-अलग याद रखें:
```python
values = [n if n > 0 else 0 for n in nums]  # for से पहले if-else: मान चुनता है, else ज़रूरी
positives = [n for n in nums if n > 0]      # for के बाद if: छानता है, else की अनुमति नहीं
```
फ़िल्टर `if` के बाद `else` लगाना सिंटैक्स त्रुटि है।

---

एक कॉम्प्रिहेंशन में **एक से ज्यादा `for`** हो सकते हैं।
ये नेस्टेड लूप्स की तरह काम करते हैं: पहला `for` बाहरी लूप होता है, दूसरा अंदरूनी।
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```

---

अंदर वाला `for` बाहर वाले के वेरिएबल का उपयोग कर सकता है।
लिस्ट्स की एक लिस्ट को एक ही लिस्ट में **फ़्लैटन** करने का यह क्लासिक तरीका है:
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
इसके बाद `sum()` फ़ंक्शन लिस्ट की सभी संख्याओं को जोड़ देता है।

---

आप एक **डिक्शनरी** पर भी लूप कर सकते हैं।
`.items()` के साथ `for` वाला हिस्सा हर पेयर को दो वेरिएबल्स में अनपैक करता है, एक कुंजी (key) और एक मान (value):
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```

---

यही आइडिया डिक्शनरी के लिए भी काम करता है: एक **डिक्ट कॉम्प्रिहेंशन** कर्ली ब्रेसेज़ और `key: value` एक्सप्रेशन का उपयोग करता है:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```

---

`key: value` वाले हिस्से **के बिना** कर्ली ब्रेसेज़ एक **सेट कॉम्प्रिहेंशन** बनाते हैं।
एक सेट (set) एक ऑर्डर-रहित कलेक्शन है जो केवल यूनिक वैल्यूज़ रखता है, इसलिए डुप्लीकेट अपने आप गायब हो जाते हैं:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```

---

**कॉम्प्रिहेंशन का उपयोग कब करना चाहिए?**
यह तब परफेक्ट होता है जब रिजल्ट एक लिस्ट (या डिक्शनरी, या सेट) हो और लॉजिक एक पढ़ने में आसान लाइन में समा जाए: एक सिंपल ट्रांसफॉर्मेशन, एक ऑप्शनल फ़िल्टर।
अगर आपको कई स्टेटमेंट्स चाहिए, दो से ज्यादा नेस्टेड `for` चाहिए, या लाइन पढ़ने में मुश्किल हो जाती है, तो इसके बजाय एक सामान्य `for` लूप लिखें: कोड लंबा होगा, लेकिन ज्यादा साफ़ होगा।
एक कॉम्प्रिहेंशन lambda के साथ इस्तेमाल होने वाले `map()` और `filter()` के ज्यादातर उपयोगों की जगह भी लेता है:
```python
doubled = list(map(lambda n: n * 2, nums))
doubled = [n * 2 for n in nums]  # same result, easier to read
```
