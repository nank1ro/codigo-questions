# --description--

कॉम्प्रिहेंशन **स्ट्रिंग्स को बदलने** के लिए भी शानदार हैं।
हर आइटम पर एक स्ट्रिंग मेथड कॉल करें, या f-स्ट्रिंग से एक नई स्ट्रिंग बनाएं:
```python
names = ["ana", "bob"]
greetings = [f"Hi {name.capitalize()}" for name in names]
print(greetings)  # ['Hi Ana', 'Hi Bob']
```
