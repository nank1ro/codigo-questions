# --description--

`key: value` वाले हिस्से **के बिना** कर्ली ब्रेसेज़ एक **सेट कॉम्प्रिहेंशन** बनाते हैं।
एक सेट (set) एक ऑर्डर-रहित कलेक्शन है जो केवल यूनिक वैल्यूज़ रखता है, इसलिए डुप्लीकेट अपने आप गायब हो जाते हैं:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```
