# --description--

एक कॉम्प्रिहेंशन आइटम्स को **फ़िल्टर** भी कर सकता है।
`for` वाले भाग के बाद एक `if` कंडीशन जोड़ें: केवल वे आइटम्स नई लिस्ट में जाते हैं जिनके लिए कंडीशन `True` होती है:
```python
nums = [5, 12, 8, 20]
big = [n for n in nums if n > 10]
print(big)  # [12, 20]
```
यह अंदर `if` वाले लूप जैसा ही है, और यह lambda के साथ `filter()` को एक ज्यादा पढ़ने में आसान तरीके से बदल देता है।
