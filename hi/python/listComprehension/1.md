# --description--

एक बहुत ही सामान्य काम है किसी मौजूदा लिस्ट से एक नई लिस्ट बनाना।
`for` लूप और `append()` के साथ इसमें कुछ लाइनें लगती हैं:
```python
nums = [1, 2, 3]
doubled = []
for n in nums:
    doubled.append(n * 2)
print(doubled)  # [2, 4, 6]
```
Python इसी काम के लिए एक छोटा रूप प्रदान करता है: **लिस्ट कॉम्प्रिहेंशन**, जो पूरी लिस्ट को एक ही एक्सप्रेशन में बनाता है:
```python
doubled = [n * 2 for n in nums]
```
सिंटैक्स है `[expression for item in iterable]`: `for` वाला भाग आइटम्स पर लूप करता है, और बाईं ओर का एक्सप्रेशन हर आइटम के लिए एवैल्यूएट होता है।
परिणाम एक बिल्कुल नई लिस्ट होती है, ठीक वैसी ही जैसी लूप से बनाई गई थी।
