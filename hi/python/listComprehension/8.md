# --description--

कभी-कभी आप आइटम्स को हटाना नहीं चाहते, बल्कि उनमें से कुछ के लिए **अलग मान** चुनना चाहते हैं।
`for` से पहले, एक्सप्रेशन के रूप में एक कंडीशनल एक्सप्रेशन `a if condition else b` इस्तेमाल करें:
```python
nums = [3, -1, 4]
signs = ["+" if n > 0 else "-" for n in nums]
print(signs)  # ['+', '-', '+']
```
इसकी पोजीशन ध्यान दें: `if-else` `for` से **पहले** आता है और हमेशा एक मान देता है, जबकि फ़िल्टर `if` `for` के **बाद** आता है और इसका कोई `else` नहीं होता।
