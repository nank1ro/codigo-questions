# --description--

अंदर वाला `for` बाहर वाले के वेरिएबल का उपयोग कर सकता है।
लिस्ट्स की एक लिस्ट को एक ही लिस्ट में **फ़्लैटन** करने का यह क्लासिक तरीका है:
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
इसके बाद `sum()` फ़ंक्शन लिस्ट की सभी संख्याओं को जोड़ देता है।
