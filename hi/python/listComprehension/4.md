# --description--

फ़िल्टर कंडीशन कोई भी ऐसा एक्सप्रेशन हो सकता है जो एक बूलियन मान देता है, जिसमें `len()` जैसे फ़ंक्शन कॉल भी शामिल हैं:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```

# --instructions--

लिस्ट कॉम्प्रिहेंशन का उपयोग करके, `words` में से 4 से ज्यादा अक्षरों वाले शब्दों की लिस्ट को वेरिएबल `long_words` में स्टोर करें
