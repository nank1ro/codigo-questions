# --description--

दोनों कंडीशंस को एक ही कॉम्प्रिहेंशन में जोड़ा जा सकता है: मान चुनने के लिए एक `if-else`, और कुछ आइटम्स को स्किप करने के लिए आखिर में एक फ़िल्टर `if`।
```python
nums = [1, 2, 3, 4]
result = ["big" if n > 2 else "small" for n in nums if n != 3]
print(result)  # ['small', 'small', 'big']
```

# --instructions--
