यही आइडिया डिक्शनरी के लिए भी काम करता है: एक **डिक्ट कॉम्प्रिहेंशन** कर्ली ब्रेसेज़ और `key: value` एक्सप्रेशन का उपयोग करता है:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
