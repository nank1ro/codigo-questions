# --description--

`if` की दो स्थितियाँ आसानी से गड्डमड्ड हो जाती हैं, इसलिए इन्हें अलग-अलग याद रखें:
```python
values = [n if n > 0 else 0 for n in nums]  # for से पहले if-else: मान चुनता है, else ज़रूरी
positives = [n for n in nums if n > 0]      # for के बाद if: छानता है, else की अनुमति नहीं
```
फ़िल्टर `if` के बाद `else` लगाना सिंटैक्स त्रुटि है।

# --instructions--

इस कोड स्निपेट में __समस्या__ क्या है?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- `for` के बाद वाले फ़िल्टर `if` में `else` नहीं हो सकता: `if-else` को `for` से पहले आना चाहिए
- एक लिस्ट कॉम्प्रिहेंशन में कोई कंडीशन नहीं हो सकती
- `nums` में एक नेगेटिव संख्या है, जिसकी अनुमति नहीं है
- `else` को `elif` से बदलना चाहिए
