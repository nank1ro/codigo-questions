# --description--

शॉर्ट-सर्किट मूल्यांकन उस ऑपरेशन को **सुरक्षित करने** का एक सुरक्षित तरीका है जो कुछ मानों पर विफल हो जाएगा। `word is not None and len(word) < 4` में, `len(word)` केवल तभी चलता है जब `word` `None` नहीं होता, इसलिए कॉल कभी त्रुटि नहीं उठाती। सुरक्षा जाँच पहले आनी चाहिए:
```python
def is_short(word):
    return word is not None and len(word) < 4

print(is_short(None))   # False
print(is_short("cat"))  # True
```
ध्यान रखें कि `and` एक ऑपरेंड लौटाता है: `word and len(word) < 4` `None` के लिए `None` और खाली स्ट्रिंग के लिए `""` देता है, `False` नहीं। जब बूलियन आवश्यक हो तो एक वास्तविक तुलना से सुरक्षित करें।
