# --instructions--

यह कोड क्या प्रदर्शित करता है?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, क्योंकि `c` उसी लिस्ट का दूसरा नाम है जो `a` है, इसलिए `c` के ज़रिए जोड़ने से `a` बदल जाता है और वह `b` से अलग हो जाता है
- `True True [1, 2]`, क्योंकि `c = a` लिस्ट की प्रतिलिपि बनाता है, इसलिए `a` अपरिवर्तित रहता है
- `True False [1, 2, 3]`, क्योंकि `is` मानों की तुलना करता है और `==` पहचान की
- `False False [1, 2, 3]`, क्योंकि `append` एक नई लिस्ट बनाता है, इसलिए `c` अब `a` को संदर्भित नहीं करता
