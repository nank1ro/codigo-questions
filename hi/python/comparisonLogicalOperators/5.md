# --description--

जब `not`, `and` और `or` एक ही एक्सप्रेशन में आते हैं, तो Python पहले `not` लागू करता है, फिर `and`, फिर `or`। इसलिए `a or b and c` का अर्थ है `a or (b and c)`, और `not a == b` का अर्थ है `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
जब कोई अलग समूहन अभीष्ट हो, तो कोष्ठक जोड़ें; वे एक्सप्रेशन को पढ़ने में भी आसान बनाते हैं।

# --instructions--

यह कोड क्या प्रदर्शित करता है?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, क्योंकि `and` `or` से पहले लागू होता है, इसलिए एक्सप्रेशन `x == 3 or (x > 10 and x < 0)` के रूप में पढ़ा जाता है
- `False`, क्योंकि ऑपरेटर बाएँ से दाएँ लागू होते हैं: `(x == 3 or x > 10) and x < 0`
- `False`, क्योंकि `x < 0` असत्य है और एक्सप्रेशन की हर शर्त पूरी होनी चाहिए
- एक `SyntaxError`, क्योंकि `and` और `or` को कोष्ठकों के बिना मिलाया नहीं जा सकता
