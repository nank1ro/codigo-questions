# --description--

तुलना ऑपरेटर दो मानों की तुलना करते हैं और एक **बूलियन** लौटाते हैं, `True` या `False`: `==` बराबर, `!=` बराबर नहीं, `<` से छोटा, `>` से बड़ा, `<=` से छोटा या बराबर, `>=` से बड़ा या बराबर:
```python
age = 18
print(age == 18)  # True
print(age != 18)  # False
print(age < 18)   # False
print(age >= 18)  # True
```
परिणाम को किसी वेरिएबल में संग्रहीत किया जा सकता है या सीधे प्रदर्शित किया जा सकता है। एक अकेला `=` असाइनमेंट है, तुलना नहीं।
