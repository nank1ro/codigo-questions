# --description--

लॉजिकल ऑपरेटर बूलियन को जोड़ते हैं। `and` केवल तभी `True` होता है जब दोनों पक्ष `True` हों, `or` तब जब कम से कम एक पक्ष `True` हो, और `not` एक अकेले मान को उलट देता है:
```python
age = 20
member = False
print(age >= 18 and member)  # False
print(age >= 18 or member)   # True
print(not member)            # True
```
तुलनाओं की प्राथमिकता लॉजिकल ऑपरेटरों से अधिक होती है, इसलिए `age >= 18 and member` को कोष्ठकों की आवश्यकता नहीं है। `and` के अंदर `or` को समूहबद्ध करने के लिए कोष्ठक आवश्यक हैं: `a and (b or c)`।

```python
def is_leap(year):
    return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)
```
