# --description--

`==` **मानों** की तुलना करता है; `is` **पहचान** की तुलना करता है, यानी कि क्या दोनों नाम बिल्कुल एक ही ऑब्जेक्ट को संदर्भित करते हैं। अलग-अलग बनाई गई दो बराबर लिस्ट `==` होती हैं पर `is` नहीं:
```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)  # True False True
```
`is` `None`, `True` और `False` जैसे सिंगलटन के लिए है: `value is None` या `value is not None` लिखें, कभी `value == None` नहीं, क्योंकि कोई क्लास `==` को कुछ भी लौटाने के लिए परिभाषित कर सकती है। संख्याओं या स्ट्रिंग्स के साथ `is` का उपयोग अविश्वसनीय है और Python इसकी चेतावनी देता है।

# --instructions--

एक फ़ंक्शन `is_missing(value)` लिखें जो केवल तभी `True` लौटाए जब `value` `None` हो, और किसी भी अन्य मान के लिए `False`, जिसमें `0`, `""` और `[]` जैसे असत्य मान भी शामिल हैं

# --asserts--

`is_missing(None)` को `True` लौटाना चाहिए

```python
    def test_1(self):
        self.assertIs(is_missing(None), True, "--err-t1--")
```

असत्य मान `None` नहीं हैं

```python
    def test_2(self):
        self.assertIs(is_missing(0), False, "--err-t2--")
        self.assertIs(is_missing(""), False, "--err-t2--")
        self.assertIs(is_missing([]), False, "--err-t2--")
        self.assertIs(is_missing(False), False, "--err-t2--")
```

एक ऑब्जेक्ट जिसका `==` हर चीज़ के बराबर होने का दावा करता है, फिर भी `None` नहीं है, इसलिए जाँच में पहचान का उपयोग होना चाहिए

```python
    def test_3(self):
        class Anything:
            def __eq__(self, other):
                return True
        self.assertIs(is_missing(Anything()), False, "--err-t3--")
```
