# --description--

`and` और `or` हमेशा `True` या `False` नहीं लौटाते: वे अपने **ऑपरेंड** में से एक लौटाते हैं। `a and b` `a` लौटाता है यदि वह असत्य है, अन्यथा `b`; `a or b` `a` लौटाता है यदि वह सत्य है, अन्यथा `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
परिणाम ठीक तभी सत्य या असत्य होता है जब पूरा एक्सप्रेशन होता है, इसीलिए `if a and b:` फिर भी काम करता है। एक आम उपयोग डिफ़ॉल्ट मान है: `name = user_input or "guest"`।

# --instructions--

यह कोड क्या प्रदर्शित करता है?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, क्योंकि `or` पहला सत्य ऑपरेंड लौटाता है और `and` पहला असत्य, या अंतिम ऑपरेंड जब कोई नहीं होता
- `True False True`, क्योंकि लॉजिकल ऑपरेटर हमेशा एक बूलियन उत्पन्न करते हैं
- `0 3 x`, क्योंकि `and` और `or` हमेशा अपना पहला ऑपरेंड लौटाते हैं
- `5 3 y`, क्योंकि दोनों ऑपरेटर सत्य ऑपरेंड लौटाते हैं
