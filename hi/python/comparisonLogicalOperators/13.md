# --instructions--

एक फ़ंक्शन `is_vowel(ch)` लिखें जो `True` लौटाए जब `ch` ठीक एक अक्षर हो और वह अक्षर छोटे या बड़े रूप में एक स्वर (`a`, `e`, `i`, `o`, `u`) हो, और किसी भी अन्य स्ट्रिंग के लिए `False`, जिसमें खाली स्ट्रिंग भी शामिल है

# --before-asserts--

```python
import unittest

class CodigoTests(unittest.TestCase):
```

# --asserts--

`is_vowel("a")` और `is_vowel("E")` को `True` लौटाना चाहिए

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` और `is_vowel("y")` को `False` लौटाना चाहिए

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

जो स्ट्रिंग्स एक अकेला अक्षर नहीं हैं उन्हें `False` लौटाना चाहिए

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```

```python
def is_vowel(ch):
    return len(ch) == 1 and ch.lower() in "aeiou"
```
