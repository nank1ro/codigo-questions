# --description--

तुलना ऑपरेटर केवल संख्याओं तक सीमित नहीं हैं। स्ट्रिंग्स की तुलना उनके कोड पॉइंट्स का उपयोग करके अक्षर दर अक्षर की जाती है, इसलिए `"apple" < "banana"` `True` है और, क्योंकि हर बड़ा अक्षर छोटे अक्षरों से पहले आता है, `"Zoo" < "apple"` भी `True` है। लिस्ट और टपल की तुलना उसी तरह तत्व दर तत्व की जाती है:
```python
print("cat" < "dog")       # True
print([1, 2, 3] < [1, 3])  # True
print((1, 2) == (1, 2))    # True
```
तुलना एक एक्सप्रेशन है, इसलिए कोई फ़ंक्शन उसे `if` में लपेटने के बजाय सीधे `return a < b` कर सकता है।

# --instructions--

एक फ़ंक्शन `comes_first(a, b)` लिखें जो `True` लौटाए जब स्ट्रिंग `a` स्ट्रिंग `b` से पहले आती हो, और `False` जब वे बराबर हों या `a` `b` के बाद आता हो

import unittest

# --asserts--

`comes_first("apple", "banana")` को `True` लौटाना चाहिए

```python
    def test_1(self):
        self.assertIs(comes_first("apple", "banana"), True, "--err-t1--")
```

`comes_first("pear", "apple")` और `comes_first("kiwi", "kiwi")` को `False` लौटाना चाहिए

```python
    def test_2(self):
        self.assertIs(comes_first("pear", "apple"), False, "--err-t2--")
        self.assertIs(comes_first("kiwi", "kiwi"), False, "--err-t2--")
```

बड़े अक्षर छोटे अक्षरों से पहले आते हैं, इसलिए `comes_first("Zoo", "apple")` को `True` लौटाना चाहिए

```python
    def test_3(self):
        self.assertIs(comes_first("Zoo", "apple"), True, "--err-t3--")
```
