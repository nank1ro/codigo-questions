# --description--

तुलनाओं को **श्रृंखलाबद्ध** किया जा सकता है: `1 < x < 10` जाँचता है कि `x` `1` से बड़ा **और** `10` से छोटा है, ठीक `1 < x and x < 10` की तरह, लेकिन `x` का मूल्यांकन केवल एक बार होता है:
```python
x = 5
print(1 < x < 10)   # True
print(1 < x <= 5)   # True
print(10 < x < 20)  # False
```
किसी भी तुलना ऑपरेटर को श्रृंखलाबद्ध किया जा सकता है और हर एक अपने दोनों पड़ोसियों पर लागू होता है: `a < b == c` का अर्थ है `a < b and b == c`। श्रृंखला को एक रेंज `low < x < high` की तरह पढ़ना सबसे आम उपयोग है।
