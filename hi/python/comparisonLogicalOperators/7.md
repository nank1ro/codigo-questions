# --description--

चूँकि `if value:` पहले से ही सत्य मान लागू करता है, `== True` या `== False` से तुलना करना अनावश्यक है और ग़लत भी हो सकता है: `2 == True` `False` है, फिर भी `2` सत्य है। मान की स्वयं जाँच करें:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
