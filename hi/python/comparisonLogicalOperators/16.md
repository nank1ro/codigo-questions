# --description--

`any(iterable)` `True` लौटाता है यदि कम से कम एक तत्व सत्य हो और `all(iterable)` तब जब हर तत्व सत्य हो (`all([])` `True` है)। जनरेटर एक्सप्रेशन के साथ मिलकर वे पूरे संग्रह पर एक शर्त व्यक्त करते हैं, और वे `or` और `and` की तरह शॉर्ट-सर्किट करते हैं:
```python
print(any(ch.isdigit() for ch in "abc1"))  # True
print(all(ch.isalpha() for ch in "ab1"))   # False
```

```python
def is_valid_password(password):
    return (
        8 <= len(password) <= 20
        and any(ch.isdigit() for ch in password)
        and " " not in password
    )
```
