# --instructions--

आइटम्स को क्रमबद्ध करें ताकि `users` डिक्शनरी और `can_login` फ़ंक्शन परिभाषित हो, जो लुकअप को सुरक्षित करने के लिए `name in users` का उपयोग करता है, फिर सही पासवर्ड के साथ Ada के लिए और Grace के लिए, जो पंजीकृत नहीं है, परिणाम प्रदर्शित करें, जिससे आउटपुट `True`, `False` बने

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
