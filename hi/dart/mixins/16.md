# --description--

स्टैक किए गए मिक्सिन ही हैं जिनसे छोटे, स्वतंत्र नियम एक क्लास में जुड़ते हैं। हर मिक्सिन उसी सदस्य को ओवरराइड करता है, अपना हिस्सा करता है, और काम आगे सौंपने के लिए `super` कॉल करता है। चूँकि कॉल पहले **अंतिम** मिक्सिन में आती है, `with` सूची का क्रम तय करता है कि कौन सा नियम किससे पहले चलेगा:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` हर जमा को दोगुना कर देता है। `Doubled` के बाद एक दूसरा मिक्सिन जोड़ें और जमा सबसे पहले उसे मिलेगी, `Doubled` तक पहुँचने से पहले।

# --instructions--

क्लास `Account` पहले से लिखी है: उसमें एक `int` फ़ील्ड `balance` है जो `0` से शुरू होता है, और एक मेथड `deposit` है जो अपना `int` तर्क `balance` में जोड़ती है।

`Account` पर एक मिक्सिन `Audited` घोषित करें, जिसमें एक `List<String>` फ़ील्ड `log` हो जो खाली से शुरू हो, और वह `deposit` को इस तरह ओवरराइड करे कि वह पहले स्ट्रिंग `'deposit '` को राशि के साथ जोड़कर `log` में डाले, फिर `super.deposit` कॉल करे।

`Account` पर एक मिक्सिन `Limited` घोषित करें जो `deposit` को इस तरह ओवरराइड करे कि `100` से बड़ी राशि नज़रअंदाज़ कर दी जाए, और कोई और राशि `super.deposit` को पास कर दी जाए।

एक क्लास `SafeAccount` घोषित करें जो `Account` को एक्सटेंड करती है और दोनों मिक्सिन का उपयोग करती है, ताकि अस्वीकृत जमा कभी लॉग तक न पहुँचे।

उदाहरण:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

# --solutions--

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
