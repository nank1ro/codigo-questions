# --description--

`on` क्लॉज वाला मिक्सिन अपने सुपरक्लास के सदस्यों को अपना हुआ पढ़ता है, और यही उसे किसी मौजूदा टाइप को सजाने वाले व्यवहार के लिए एक अच्छी जगह बनाता है:

```dart
class Shape {
  String get kind => 'shape';
}

mixin Printable on Shape {
  void show() {
    print('a $kind');
  }
}

class Square extends Shape with Printable {
  @override
  String get kind => 'square';
}
```

`Square` `kind` को ओवरराइड करती है, और `show` ओवरराइड को स्वतः उठा लेता है: मिक्सिन हमेशा सदस्य को असली ऑब्जेक्ट पर कॉल करता है।

# --instructions--

एक क्लास `Shape` परिभाषित करने के लिए आइटमों को क्रमबद्ध करें, जिसमें एक गेटर `kind` हो जो `'shape'` लौटाता है, एक मिक्सिन `Printable` जो `Shape` तक सीमित हो और जिसमें एक मेथड `show` हो जो `a ` के बाद `kind` प्रिंट करती है, एक क्लास `Square` जो `Shape` को एक्सटेंड करती है, `Printable` का उपयोग करती है और `kind` को `'square'` से ओवरराइड करती है, और एक `main` जो एक `Square` पर `show` कॉल करता है। पहले `Shape` परिभाषित करें, फिर `Printable`, फिर `Square`, फिर `main`। प्रोग्राम को प्रिंट करना चाहिए:

```
a square
```
