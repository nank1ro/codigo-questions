# --description--

जब मिक्सिन के पास एक `on` क्लॉज होता है, तो वह उस टाइप के किसी सदस्य को **ओवरराइड** कर सकता है और चेन में अपने नीचे वाले वर्शन तक पहुँचने के लिए **`super`** कॉल कर सकता है:

```dart
class Logger {
  String log(String message) => message;
}

mixin Timestamped on Logger {
  @override
  String log(String message) => '[12:00] ${super.log(message)}';
}

class AppLogger extends Logger with Timestamped {}

void main() {
  print(AppLogger().log('started')); // [12:00] started
}
```

`super.log` मिक्सिन का अपना `log` नहीं है, वह उसके नीचे वाला है, इसलिए अनंत पुनरावृत्ति नहीं होती। कई ऐसे मिक्सिन को `with A, B` से स्टैक करें और हर एक पिछले को लपेटता है: कॉल पहले **अंतिम** मिक्सिन में आती है और नीचे सुपरक्लास तक जाती है।

# --instructions--

एक क्लास `Pipeline` घोषित करें, जिसमें एक मेथड `run` हो जो एक `String` `input` लेती है और उसे अपरिवर्तित लौटाती है।

`Pipeline` पर एक मिक्सिन `Trimmed` घोषित करें जो `run` को इस तरह ओवरराइड करे कि ट्रिम किया हुआ इनपुट `super.run` को पास करे, और `Pipeline` पर एक मिक्सिन `Upper` जो `run` को इस तरह ओवरराइड करे कि `super.run` का परिणाम अपरकेस में लौटाए।

एक क्लास `TextPipeline` घोषित करें जो `Pipeline` को एक्सटेंड करती है और `Trimmed` फिर `Upper` का उपयोग करती है, और एक क्लास `TrimOnly` जो `Pipeline` को एक्सटेंड करती है और केवल `Trimmed` का उपयोग करती है।

उदाहरण:
```dart
print(TextPipeline().run('  hi  ')); // HI
print(TrimOnly().run('  hi  '));     // hi
```

# --solutions--

```dart
class Pipeline {
  String run(String input) => input;
}

mixin Trimmed on Pipeline {
  @override
  String run(String input) => super.run(input.trim());
}

mixin Upper on Pipeline {
  @override
  String run(String input) => super.run(input).toUpperCase();
}

class TextPipeline extends Pipeline with Trimmed, Upper {}

class TrimOnly extends Pipeline with Trimmed {}
```
