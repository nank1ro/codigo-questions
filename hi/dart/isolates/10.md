# --description--

संदेशों की पूरी शृंखला इकट्ठा करना एक ही विधि चलाता है: लूप से पहले ख़ाली सूची, हर असली संदेश पर एक `add`, और स्ट्रीम ख़त्म करने वाले संकेत पर `close()`। पोर्ट बंद होते ही `await for` समाप्त हो जाता है और फ़ंक्शन लौट सकता है:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

संदेश उसी क्रम में रहते हैं जिस क्रम में वे भेजे गए थे, इसलिए तुम्हारी बनाई सूची दूसरे isolate के काम को क़दम-दर-क़दम दर्शाती है।

# --instructions--

एक टॉप-लेवल फ़ंक्शन `sendWords` लिखो जो एक `List<Object>` `message` लेता है जिसका एलिमेंट `0` एक `SendPort` है और एलिमेंट `1` एक `List<String>` है: हर शब्द पोर्ट पर भेजो, फिर अंत का संकेत देने के लिए `null` भेजो।

फिर एक फ़ंक्शन `collectWords` लिखो जो एक `List<String>` `words` लेता है और एक `Future<List<String>>` लौटाता है जो स्पॉन किए गए `sendWords` isolate से मिले सभी शब्दों के साथ पूरा होता है।

उदाहरण:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

# --solutions--

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
