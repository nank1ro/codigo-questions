# --description--

सब जोड़ो तो एक `Isolate.run` प्रोग्राम साधारण क्रमिक कोड जैसा पढ़ा जाता है: कॉल से पहले वाली पंक्ति main isolate पर चलती है, गणना कहीं और चलती है, और `await` के बाद वाली पंक्ति नतीजे के साथ वापस main isolate पर चलती है।

```dart
import 'dart:isolate';

int twice(int n) => n * 2;

Future<void> main() async {
  print('start');
  final result = await Isolate.run(() => twice(4));
  print(result);
}
// start
// 8
```

# --instructions--

आइटम क्रम में लगाओ ताकि एक प्रोग्राम बने जो `start` छापे, `9` का वर्ग `Isolate.run` से दूसरे isolate पर निकाले और नतीजा छापे। import को सबसे पहले रखो और `square` को `main` से पहले परिभाषित करो। प्रोग्राम को यह छापना चाहिए:

```

81
```
