# --instructions--

एक फ़ंक्शन `sumUntilError` लिखो जो एक `Stream<int>` `source` लेता है और एक `Future<int>` लौटाता है जो उसके मानों के योग के साथ पूरा होता है। यदि स्ट्रीम कोई त्रुटि भेजे, तो रुक जाओ और अपवाद फेंकने के बजाय त्रुटि से **पहले** मिले मानों के योग के साथ पूरा हो जाओ।

उदाहरण:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
