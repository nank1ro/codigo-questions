# --description--

`toList()` के अलावा, स्ट्रीम के पास और भी मेथड हैं जो उसके सारे इवेंट्स **उपयोग** करके एक ही `Future` लौटाते हैं:

- `first` और `last` पहले या आख़िरी इवेंट के साथ पूरे होते हैं
- `length` इवेंट्स की संख्या के साथ पूरा होता है
- `join(separator)` सारे इवेंट्स को एक `String` में जोड़कर पूरा होता है
- `reduce(combine)` इवेंट्स को दो-दो करके एक मान में मिलाता है

```dart
final numbers = Stream.fromIterable([3, 9, 2]);
print(await numbers.reduce((a, b) => a + b)); // 14
```

`reduce` अब तक के परिणाम और अगले इवेंट के साथ `combine` को बुलाता है। यदि स्ट्रीम खाली हो तो यह अपवाद फेंकता है, इसलिए इसका उपयोग तभी करो जब कम से कम एक इवेंट की गारंटी हो।

# --instructions--

दो फ़ंक्शन लिखो:
- `largest`, जो एक `Stream<int>` `source` लेता है और `reduce` का उपयोग करके सबसे बड़े मान के साथ पूरा होने वाला `Future<int>` लौटाता है। स्ट्रीम में हमेशा कम से कम एक इवेंट होता है।
- `sentence`, जो एक `Stream<String>` `words` लेता है और सारे शब्दों को एक स्पेस से जोड़कर पूरा होने वाला `Future<String>` लौटाता है।

उदाहरण:
```dart
print(await largest(Stream.fromIterable([3, 9, 2])));        // 9
print(await sentence(Stream.fromIterable(['I', 'am', 'Dart']))); // I am Dart
```

# --solutions--

```dart
Future<int> largest(Stream<int> source) {
  return source.reduce((a, b) => a > b ? a : b);
}

Future<String> sentence(Stream<String> words) {
  return words.join(' ');
}
```
