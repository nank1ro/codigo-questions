# --description--

`StreamController` अक्सर एक ही जगह बनाया और उपयोग किया जाता है: `listen` से `controller.stream` की सदस्यता लो, फिर `add` से इवेंट्स जोड़ो और `close` से कंट्रोलर बंद करो। चूँकि `listen` इंतज़ार नहीं करता, इवेंट्स मौजूदा कोड ख़त्म होने के बाद पहुँचाए जाते हैं, लेकिन हमेशा उसी क्रम में जिसमें वे जोड़े गए थे:

```dart
import 'dart:async';

void main() {
  final controller = StreamController<int>();
  controller.stream.listen((n) => print('got $n'));
  controller.add(1);
  controller.add(2);
  controller.close();
}
// got 1
// got 2
```

# --instructions--

आइटम्स को क्रम में लगाओ ताकि `dart:async` इम्पोर्ट हो, एक `StreamController<String>` बने, उसकी स्ट्रीम की सदस्यता लेकर हर मान प्रिंट हो, `hello` और फिर `world` जोड़े जाएँ, और आख़िर में कंट्रोलर बंद हो। कोई भी मान जोड़ने से पहले `listen` से सदस्यता लो। प्रोग्राम को यह प्रिंट करना चाहिए:

```
hello
world
```
