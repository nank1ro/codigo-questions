# --description--

`.update(key, update)` मेथड किसी मौजूदा की की वैल्यू बदल देती है। दूसरा आर्गुमेंट एक फ़ंक्शन है जो वर्तमान वैल्यू प्राप्त करता है और नई वैल्यू लौटाता है। यदि की मौजूद नहीं है, तो `.update()` एक त्रुटि देता है, जब तक कि आप एक `ifAbsent` फ़ंक्शन पास न करें जो प्रारंभिक वैल्यू बनाता है:

```dart
var stock = {'apple': 3};
stock.update('apple', (n) => n + 1); // apple becomes 4
stock.update('kiwi', (n) => n + 1, ifAbsent: () => 1); // kiwi is added with 1
print(stock); // {apple: 4, kiwi: 1}
```

# --instructions--

मैप `stock` दिया गया है, `.update()` का उपयोग करके `'apple'` की वैल्यू को दोगुना करें, फिर की `'kiwi'` पर `ifAbsent` के साथ `.update()` का उपयोग करें ताकि वह वैल्यू `5` के साथ जोड़ी जाए।
