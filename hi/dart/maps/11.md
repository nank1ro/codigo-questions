# --description--

`.forEach()` मेथड हर जोड़े के लिए एक बार फ़ंक्शन चलाती है। फ़ंक्शन दो पैरामीटर प्राप्त करता है: की और वैल्यू:

```dart
var ages = {'Ann': 30, 'Bob': 25};
ages.forEach((name, age) {
  print('$name is $age');
});
// Ann is 30
// Bob is 25
```
