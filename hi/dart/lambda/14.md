# --description--

अनामित फंक्शन नामांकित फंक्शनों जैसे ही पैरामीटर प्रकार सपोर्ट करते हैं: `[]` में **वैकल्पिक पोज़िशनल** पैरामीटर और `{}` में **नामांकित** पैरामीटर, दोनों के डिफ़ॉल्ट मान हो सकते हैं:

```dart
var repeat = (String text, [int times = 2]) => text * times;
print(repeat('ab'));    // abab
print(repeat('ab', 3)); // ababab

var describe = ({required String item, int count = 1}) => '$count x $item';
print(describe(item: 'apple'));           // 1 x apple
print(describe(item: 'pear', count: 4));  // 4 x pear
```

# --instructions--

```
Hello, World!
Hello, Dart!
```
