# --description--

एक फंक्शन **एक फंक्शन भी लौटा सकता है**। तब रिटर्न टाइप एक फंक्शन प्रकार होता है, और बॉडी एक अनामित फंक्शन लौटाती है:

```dart
int Function(int) makeAdder(int amount) {
  return (int n) => n + amount;
}

var addTen = makeAdder(10);
print(addTen(5)); // 15
```

ध्यान दें कि लौटाया गया फंक्शन `makeAdder` के समाप्त होने के बाद भी `amount` का उपयोग करता रहता है, जो `makeAdder` का एक पैरामीटर है। इस तरह अपने आस-पास के वेरिएबल याद रखने वाले फंक्शन को **क्लोज़र** कहते हैं।

# --instructions--
