# --description--

जो फंक्शन दूसरे फंक्शन लेते और लौटाते हैं उन्हें स्वतंत्र रूप से जोड़ा जा सकता है। एक क्लासिक उदाहरण है **संयोजन (composition)**: एक नया फंक्शन बनाना जो एक फंक्शन चलाता है और फिर उसका परिणाम दूसरे में भेजता है:

```dart
int Function(int) then(int Function(int) first, int Function(int) second) {
  return (n) => second(first(n));
}
```

# --instructions--

एक फंक्शन `compose` लिखें जो दो पैरामीटर `f` और `g` लेता है — दोनों `int Function(int)` प्रकार के — और `int Function(int)` प्रकार का एक फंक्शन लौटाता है जो अपने तर्क पर `f` लागू करता है और फिर परिणाम पर `g`।

उदाहरण:
```dart
var addThenDouble = compose((n) => n + 1, (n) => n * 2);
print(addThenDouble(3)); // 8
```
