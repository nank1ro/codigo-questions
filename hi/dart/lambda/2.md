# --description--

एक अनामित फंक्शन पैरामीटर ले सकता है और एक मान `return` कर सकता है, बिल्कुल नामांकित फंक्शन की तरह। रिटर्न टाइप नहीं लिखा जाता: Dart इसे बॉडी के `return` कथनों से **अनुमानित** कर लेता है।

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
