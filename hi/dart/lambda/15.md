# --description--

एक अनामित फंक्शन को कहीं संग्रहीत होना ज़रूरी नहीं है: उसके समापन कोष्ठक के ठीक बाद तर्क लिखकर उसे **तुरंत कॉल** किया जा सकता है। यह ऐसे कुछ अस्थायी वेरिएबल के साथ एक मान की गणना करने के लिए उपयोगी है जो आस-पास के कोड में न रिस जाएँ:

```dart
var area = (double radius) {
  var pi = 3.14;
  return pi * radius * radius;
}(2.0);

print(area); // 12.56
```

यहाँ `pi` केवल अनामित फंक्शन के भीतर मौजूद है, और `area` को लौटाया गया मान प्राप्त होता है।

# --instructions--
