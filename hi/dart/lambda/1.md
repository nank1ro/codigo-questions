# --description--

आप पहले से जानते हैं कि नाम के साथ एक फंक्शन कैसे घोषित किया जाता है, जैसे `void sayHello() { ... }`। Dart आपको **बिना नाम** का फंक्शन भी लिखने देता है: एक **अनामित फंक्शन**। इसके पुर्ज़े नामांकित फंक्शन जैसे ही होते हैं (कोष्ठकों में पैरामीटर और घुंघराले कोष्ठकों में बॉडी), पर इसमें न रिटर्न टाइप होता है और न नाम:

```dart
(String name) {
  print('Hello, $name!');
}
```

चूँकि इसका कोई नाम नहीं होता, इसे उपयोग करने का सामान्य तरीका इसे एक वेरिएबल में संग्रहीत करना और फिर उस वेरिएबल को फंक्शन की तरह कॉल करना है:

```dart
var sayHello = (String name) {
  print('Hello, $name!');
};

sayHello('Dart'); // Hello, Dart!
```

ध्यान दें कि समापन कोष्ठक के बाद `;` लगता है: यह असाइनमेंट एक सामान्य कथन है।

# --instructions--

कोड को इस तरह पूरा करें कि `greet` में एक ऐसा अनामित फंक्शन संग्रहीत हो जिसमें कोई पैरामीटर नहीं है और जो `Hello, anonymous!` प्रिंट करता है, फिर उसे कॉल करें।
