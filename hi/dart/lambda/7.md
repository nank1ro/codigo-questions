# --description--

अनामित फंक्शन लेने वाली दो अन्य बहुत सामान्य मेथड्स `map` और `where` हैं:

- `map` फंक्शन के साथ हर तत्व को रूपांतरित करता है और नए मान लौटाता है
- `where` केवल उन्हीं तत्वों को रखता है जिनके लिए फंक्शन `true` लौटाता है

दोनों एक आलसी (lazy) `Iterable` लौटाते हैं; परिणाम को एक `List` में बदलने के लिए `toList()` कॉल करें:

```dart
var numbers = [1, 2, 3];

var squares = numbers.map((n) => n * n).toList();
print(squares); // [1, 4, 9]

var big = numbers.where((n) => n > 1).toList();
print(big); // [2, 3]
```

# --instructions--
