# --description--

चूँकि फंक्शन प्रकार एक सामान्य प्रकार है, एक फंक्शन **दूसरे फंक्शन को पैरामीटर के रूप में** ले सकता है। बॉडी के भीतर, पैरामीटर को किसी भी फंक्शन की तरह कॉल किया जाता है:

```dart
int apply(int n, int Function(int) operation) {
  return operation(n);
}

print(apply(5, (n) => n * 2)); // 10
print(apply(5, (n) => n - 1)); // 4
```

यहाँ कॉलर दूसरे तर्क के रूप में एक अनामित फंक्शन पास करके तय करता है कि `apply` क्या करे।

# --instructions--

एक फंक्शन `applyTwice` लिखें जो एक `int` पैरामीटर `n` और `int Function(int)` प्रकार का एक फंक्शन पैरामीटर `operation` लेता है, और `operation` को `n` पर दो बार लागू करने का परिणाम लौटाता है।

उदाहरण:
```dart
print(applyTwice(3, (n) => n * 2)); // 12
```
