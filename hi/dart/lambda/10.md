# --description--

`reduce` एक सूची के सभी तत्वों को एक अकेले मान में जोड़ता है। इसका अनामित फंक्शन दो पैरामीटर लेता है: **अब तक संचित** मान और **अगला तत्व**, और नया संचित मान लौटाता है। पहले तत्व को शुरुआती बिंदु के रूप में उपयोग किया जाता है:

```dart
var numbers = [2, 3, 4];

var product = numbers.reduce((total, n) => total * n);
print(product); // 24
```

खाली सूची पर `reduce` एक त्रुटि उत्पन्न करता है, क्योंकि शुरुआत करने के लिए कोई पहला तत्व नहीं होता।

# --instructions--

एक फंक्शन `longest` लिखें जो एक गैर-खाली `List<String>` पैरामीटर `words` लेता है और अनामित फंक्शन के साथ `reduce` का उपयोग करके सबसे लंबा शब्द लौटाता है। यदि दो शब्दों की लंबाई समान है, तो पहले आने वाले शब्द को रखें।

उदाहरण:
```dart
print(longest(['sun', 'planet', 'moon'])); // planet
```

String longest(List<String> words) {
  return words.reduce((best, word) => word.length > best.length ? word : best);
}
