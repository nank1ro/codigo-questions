# --description--

चूँकि `map` और `where` दोनों एक `Iterable` लौटाते हैं, इनके कॉल एक के बाद एक **श्रृंखलाबद्ध** किए जा सकते हैं। हर चरण पिछले चरण का परिणाम प्राप्त करता है, और अंत में एक बार `toList()` कॉल किया जाता है:

```dart
var numbers = [1, 2, 3, 4, 5, 6];

var result = numbers.where((n) => n > 3).map((n) => n * 10).toList();
print(result); // [40, 50, 60]
```

# --instructions--

एक फंक्शन `oddSquares` लिखें जो एक `List<int>` पैरामीटर `numbers` लेता है और मूल क्रम में केवल विषम संख्याओं के वर्गों वाली एक `List<int>` लौटाता है। अनामित फंक्शनों के साथ `where` और `map` का उपयोग करें।

उदाहरण:
```dart
print(oddSquares([1, 2, 3, 4, 5])); // [1, 9, 25]
```

List<int> oddSquares(List<int> numbers) {
  return numbers.where((n) => n % 2 != 0).map((n) => n * n).toList();
}
