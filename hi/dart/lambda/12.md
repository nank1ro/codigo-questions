# --description--

एक क्लोज़र जिन वेरिएबल को पकड़ता है उन्हें केवल पढ़ता ही नहीं: वह उन्हें **बदल** भी सकता है, और बदलाव कॉल के बीच बने रहते हैं। इससे एक क्लास के बिना प्राइवेट स्टेट रखना संभव हो जाता है:

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

`makeTimer()` का हर कॉल एक बिल्कुल नया `seconds` वेरिएबल बनाता है, इसलिए दो टाइमर कभी अपनी गिनती साझा नहीं करते।

# --instructions--

एक फंक्शन `makeCounter` लिखें जिसमें कोई पैरामीटर न हो और जो `int Function()` प्रकार का एक फंक्शन लौटाता है। लौटाया गया फंक्शन हर बार कॉल होने पर पकड़े हुए काउंटर को बढ़ाकर उसे लौटाना चाहिए, `1` से शुरुआत करते हुए।

उदाहरण:
```dart
var counter = makeCounter();
print(counter()); // 1
print(counter()); // 2
```
