# --description--

जब बॉडी एक अकेला व्यंजक हो, तो अनामित फंक्शन **ऐरो सिंटैक्स** `=>` का उपयोग कर सकता है, बिल्कुल नामांकित फंक्शन की तरह। ऐरो घुंघराले कोष्ठकों और `return` कीवर्ड की जगह ले लेता है:

```dart
var add = (int a, int b) => a + b;

print(add(2, 3)); // 5
```

यह छोटा रूप Dart में अनामित फंक्शन लिखने का दूर-दूर तक सबसे सामान्य तरीका है।

# --instructions--

कोड को इस तरह पूरा करें कि `triple` में एक ऐसी ऐरो फंक्शन संग्रहीत हो जो अपने तर्क को `3` से गुणा करके लौटाती है, ताकि प्रोग्राम `12` प्रिंट करे।
