आप पहले से जानते हैं कि नाम के साथ एक फंक्शन कैसे घोषित किया जाता है, जैसे `void sayHello() { ... }`। Dart आपको **बिना नाम** का फंक्शन भी लिखने देता है: एक **अनामित फंक्शन**। इसके पुर्ज़े नामांकित फंक्शन जैसे ही होते हैं (कोष्ठकों में पैरामीटर और घुंघराले कोष्ठकों में बॉडी), पर इसमें न रिटर्न टाइप होता है और न नाम:

```dart
(String name) {
  print('Hello, $name!');
}
```

चूँकि इसका कोई नाम नहीं होता, इसे उपयोग करने का सामान्य तरीका इसे एक वेरिएबल में संग्रहीत करना और फिर उस वेरिएबल को फंक्शन की तरह कॉल करना है:

```dart
var sayHello = (String name) {
  print('Hello, $name!');
};

sayHello('Dart'); // Hello, Dart!
```

ध्यान दें कि समापन कोष्ठक के बाद `;` लगता है: यह असाइनमेंट एक सामान्य कथन है।

---

एक अनामित फंक्शन पैरामीटर ले सकता है और एक मान `return` कर सकता है, बिल्कुल नामांकित फंक्शन की तरह। रिटर्न टाइप नहीं लिखा जाता: Dart इसे बॉडी के `return` कथनों से **अनुमानित** कर लेता है।

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```

---

जब बॉडी एक अकेला व्यंजक हो, तो अनामित फंक्शन **ऐरो सिंटैक्स** `=>` का उपयोग कर सकता है, बिल्कुल नामांकित फंक्शन की तरह। ऐरो घुंघराले कोष्ठकों और `return` कीवर्ड की जगह ले लेता है:

```dart
var add = (int a, int b) => a + b;

print(add(2, 3)); // 5
```

यह छोटा रूप Dart में अनामित फंक्शन लिखने का दूर-दूर तक सबसे सामान्य तरीका है।

---

फंक्शन मान होते हैं, इसलिए उनका एक प्रकार होता है। किसी फंक्शन का प्रकार **रिटर्न टाइप** लिखकर, फिर `Function` कीवर्ड, फिर कोष्ठकों में **पैरामीटर प्रकार** लिखकर दर्शाया जाता है:

```dart
int Function(int, int) add = (int a, int b) => a + b;
bool Function(String) isEmpty = (String s) => s.isEmpty;
void Function() hello = () => print('Hello');
```

जब वेरिएबल को इस तरह टाइप किया जाता है, तो अनामित फंक्शन से पैरामीटर प्रकार छोड़े जा सकते हैं, क्योंकि Dart उन्हें घोषित प्रकार से अनुमानित कर लेता है:

```dart
int Function(int, int) add = (a, b) => a + b;
```

खाली प्रकार `Function` किसी भी फंक्शन को स्वीकार करता है, चाहे उसके पैरामीटर और रिटर्न टाइप कुछ भी हों, लेकिन यह Dart को उसे कॉल करने के बारे में कुछ नहीं बताता।

---

चूँकि फंक्शन प्रकार एक सामान्य प्रकार है, एक फंक्शन **दूसरे फंक्शन को पैरामीटर के रूप में** ले सकता है। बॉडी के भीतर, पैरामीटर को किसी भी फंक्शन की तरह कॉल किया जाता है:

```dart
int apply(int n, int Function(int) operation) {
  return operation(n);
}

print(apply(5, (n) => n * 2)); // 10
print(apply(5, (n) => n - 1)); // 4
```

यहाँ कॉलर दूसरे तर्क के रूप में एक अनामित फंक्शन पास करके तय करता है कि `apply` क्या करे।

---

Dart के कई कलेक्शन मेथड्स तर्क के रूप में एक फंक्शन लेते हैं, और उसे पास करने का सहज तरीका अनामित फंक्शन है। सबसे सरल है `forEach`, जो दिया गया फंक्शन सूची के हर तत्व के लिए एक बार कॉल करता है:

```dart
var fruits = ['apple', 'kiwi'];

fruits.forEach((fruit) {
  print('I like $fruit');
});
// I like apple
// I like kiwi
```

पैरामीटर का प्रकार सूची से अनुमानित हो जाता है, इसलिए `fruit` बिना लिखे भी एक `String` होता है।

---

अनामित फंक्शन लेने वाली दो अन्य बहुत सामान्य मेथड्स `map` और `where` हैं:

- `map` फंक्शन के साथ हर तत्व को रूपांतरित करता है और नए मान लौटाता है
- `where` केवल उन्हीं तत्वों को रखता है जिनके लिए फंक्शन `true` लौटाता है

दोनों एक आलसी (lazy) `Iterable` लौटाते हैं; परिणाम को एक `List` में बदलने के लिए `toList()` कॉल करें:

```dart
var numbers = [1, 2, 3];

var squares = numbers.map((n) => n * n).toList();
print(squares); // [1, 4, 9]

var big = numbers.where((n) => n > 1).toList();
print(big); // [2, 3]
```

---

चूँकि `map` और `where` दोनों एक `Iterable` लौटाते हैं, इनके कॉल एक के बाद एक **श्रृंखलाबद्ध** किए जा सकते हैं। हर चरण पिछले चरण का परिणाम प्राप्त करता है, और अंत में एक बार `toList()` कॉल किया जाता है:

```dart
var numbers = [1, 2, 3, 4, 5, 6];

var result = numbers.where((n) => n > 3).map((n) => n * 10).toList();
print(result); // [40, 50, 60]
```

---

`sort` एक सूची को उसी जगह पुनर्व्यवस्थित करता है। डिफ़ॉल्ट रूप से यह तत्वों का सहज क्रम उपयोग करता है, पर आप एक ऐसा अनामित फंक्शन पास कर सकते हैं जो **दो तत्वों की तुलना** करके एक ऋणात्मक संख्या, शून्य या धनात्मक संख्या लौटाता है। `compareTo` ठीक ऐसी ही संख्या देता है, इसलिए यही सामान्य आधार है:

```dart
var words = ['pear', 'fig', 'banana'];

words.sort((a, b) => a.length.compareTo(b.length));
print(words); // [fig, pear, banana]
```

तुलना में `a` और `b` को आपस में बदलने से क्रम उलट जाता है।

---

`reduce` एक सूची के सभी तत्वों को एक अकेले मान में जोड़ता है। इसका अनामित फंक्शन दो पैरामीटर लेता है: **अब तक संचित** मान और **अगला तत्व**, और नया संचित मान लौटाता है। पहले तत्व को शुरुआती बिंदु के रूप में उपयोग किया जाता है:

```dart
var numbers = [2, 3, 4];

var product = numbers.reduce((total, n) => total * n);
print(product); // 24
```

खाली सूची पर `reduce` एक त्रुटि उत्पन्न करता है, क्योंकि शुरुआत करने के लिए कोई पहला तत्व नहीं होता।

---

एक फंक्शन **एक फंक्शन भी लौटा सकता है**। तब रिटर्न टाइप एक फंक्शन प्रकार होता है, और बॉडी एक अनामित फंक्शन लौटाती है:

```dart
int Function(int) makeAdder(int amount) {
  return (int n) => n + amount;
}

var addTen = makeAdder(10);
print(addTen(5)); // 15
```

ध्यान दें कि लौटाया गया फंक्शन `makeAdder` के समाप्त होने के बाद भी `amount` का उपयोग करता रहता है, जो `makeAdder` का एक पैरामीटर है। इस तरह अपने आस-पास के वेरिएबल याद रखने वाले फंक्शन को **क्लोज़र** कहते हैं।

---

एक क्लोज़र जिन वेरिएबल को पकड़ता है उन्हें केवल पढ़ता ही नहीं: वह उन्हें **बदल** भी सकता है, और बदलाव कॉल के बीच बने रहते हैं। इससे एक क्लास के बिना प्राइवेट स्टेट रखना संभव हो जाता है:

```dart
int Function() makeTimer() {
  var seconds = 0;
  return () {
    seconds += 10;
    return seconds;
  };
}

var timer = makeTimer();
print(timer()); // 10
print(timer()); // 20
```

`makeTimer()` का हर कॉल एक बिल्कुल नया `seconds` वेरिएबल बनाता है, इसलिए दो टाइमर कभी अपनी गिनती साझा नहीं करते।
