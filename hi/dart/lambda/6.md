# --description--

Dart के कई कलेक्शन मेथड्स तर्क के रूप में एक फंक्शन लेते हैं, और उसे पास करने का सहज तरीका अनामित फंक्शन है। सबसे सरल है `forEach`, जो दिया गया फंक्शन सूची के हर तत्व के लिए एक बार कॉल करता है:

```dart
var fruits = ['apple', 'kiwi'];

fruits.forEach((fruit) {
  print('I like $fruit');
});
// I like apple
// I like kiwi
```

पैरामीटर का प्रकार सूची से अनुमानित हो जाता है, इसलिए `fruit` बिना लिखे भी एक `String` होता है।
