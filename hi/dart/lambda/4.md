# --description--

फंक्शन मान होते हैं, इसलिए उनका एक प्रकार होता है। किसी फंक्शन का प्रकार **रिटर्न टाइप** लिखकर, फिर `Function` कीवर्ड, फिर कोष्ठकों में **पैरामीटर प्रकार** लिखकर दर्शाया जाता है:

```dart
int Function(int, int) add = (int a, int b) => a + b;
bool Function(String) isEmpty = (String s) => s.isEmpty;
void Function() hello = () => print('Hello');
```

जब वेरिएबल को इस तरह टाइप किया जाता है, तो अनामित फंक्शन से पैरामीटर प्रकार छोड़े जा सकते हैं, क्योंकि Dart उन्हें घोषित प्रकार से अनुमानित कर लेता है:

```dart
int Function(int, int) add = (a, b) => a + b;
```

खाली प्रकार `Function` किसी भी फंक्शन को स्वीकार करता है, चाहे उसके पैरामीटर और रिटर्न टाइप कुछ भी हों, लेकिन यह Dart को उसे कॉल करने के बारे में कुछ नहीं बताता।
