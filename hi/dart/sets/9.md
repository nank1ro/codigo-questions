# --description--

सेट क्लासिक सेट ऑपरेशनों का समर्थन करते हैं। हर एक एक **नया** सेट लौटाता है और मूल सेट को अपरिवर्तित छोड़ देता है:

- `a.union(b)` में वे तत्व होते हैं जो `a` **या** `b` में हैं
- `a.intersection(b)` में वे तत्व होते हैं जो `a` और `b` **दोनों** में हैं
- `a.difference(b)` में `a` के वे तत्व होते हैं जो `b` में **नहीं** हैं

```dart
var a = {1, 2, 3};
var b = {2, 3, 4};
print(a.union(b));        // {1, 2, 3, 4}
print(a.intersection(b)); // {2, 3}
print(a.difference(b));   // {1}
```

# --instructions--

सेट `a` और `b` दिए गए हैं, उनके संघ (union) के साथ एक सेट `both`, उनके प्रतिच्छेदन (intersection) के साथ एक सेट `common`, और `a` के उन तत्वों के साथ एक सेट `onlyA` बनाएं जो `b` में नहीं हैं।
