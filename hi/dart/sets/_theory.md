एक **सेट** **अद्वितीय** (unique) मानों का संग्रह है: एक ही मान अधिकतम एक बार ही आ सकता है। मैप की तरह, सेट भी `{}` लिटरल सिंटैक्स से बनाया जाता है, लेकिन इसमें `key: value` जोड़ों के बजाय सादे मान होते हैं:

```dart
Set<int> numbers = {1, 2, 3};
print(numbers); // {1, 2, 3}
```

टाइप एनोटेशन `Set<int>` Dart को बताती है कि हर तत्व एक `int` है। सूचियों और मैप की तरह, `var` लिटरल से टाइप का अनुमान लगाता है:

```dart
var colors = {'red', 'green'}; // Set<String>
```

---

एक सेट कभी भी एक ही मान को दो बार संग्रहीत नहीं करता। यदि किसी लिटरल में डुप्लिकेट मान हों, तो केवल पहली बार आया मान रखा जाता है और बाकी बिना किसी त्रुटि के रनटाइम पर हटा दिए जाते हैं (एनालाइज़र आपको ऐसे लिटरल के बारे में चेतावनी देगा जो किसी मान को दोहराता है):

```dart
var letters = {'a', 'b', 'a', 'b', 'c'};
print(letters); // {a, b, c}
```

`.length` प्रॉपर्टी बताती है कि सेट में कितने **अद्वितीय** तत्व हैं:

```dart
print(letters.length); // 3
```

---

`.add(value)` मेथड एक मान जोड़ती है। यदि मान जोड़ा गया तो यह `true` लौटाती है, और यदि वह पहले से सेट में मौजूद था तो `false` लौटाती है, जिस स्थिति में कुछ नहीं बदलता। `.addAll(iterable)` मेथड किसी सूची या दूसरे सेट के हर तत्व को जोड़ती है, और पहले से मौजूद तत्वों को भी छोड़ देती है:

```dart
var tags = {'dart'};
tags.add('web');    // true
tags.add('dart');   // false, already there
tags.addAll(['web', 'mobile']);
print(tags); // {dart, web, mobile}
```

एक खाली `{}` लिटरल सेट नहीं, बल्कि एक **मैप** है। खाली सेट बनाने के लिए उसे एक टाइप दें:

```dart
var empty = <String>{};
Set<int> other = {};
```

---

`.remove(value)` मेथड सेट से एक मान हटाती है। यदि मान मौजूद था तो यह `true` लौटाती है, अन्यथा `false`:

```dart
var numbers = {1, 2, 3};
print(numbers.remove(2)); // true
print(numbers.remove(9)); // false
print(numbers); // {1, 3}
```

सभी तत्वों को एक साथ हटाने के लिए `.clear()` का उपयोग करें।

---

किसी मान के सेट में होने की जांच करने के लिए `.contains(value)` का उपयोग करें, जो एक `bool` लौटाती है। `.isEmpty` प्रॉपर्टी `true` होती है जब सेट में कोई तत्व नहीं होता, और `.isNotEmpty` तब `true` होती है जब उसमें कम से कम एक तत्व हो:

```dart
var seen = {'x', 'y'};
print(seen.contains('x')); // true
print(seen.contains('z')); // false
print(seen.isEmpty);       // false
print(seen.isNotEmpty);    // true
```

---

Dart का डिफ़ॉल्ट सेट **इंसर्शन ऑर्डर** (जिस क्रम में तत्व जोड़े गए) याद रखता है: जब आप इसे प्रिंट करते हैं या इस पर लूप चलाते हैं, तो तत्व उसी क्रम में आते हैं जिसमें उन्हें पहली बार जोड़ा गया था। पहले से मौजूद मान को फिर से जोड़ने से उसकी स्थिति नहीं बदलती:

```dart
var numbers = {3, 1, 3, 2};
print(numbers); // {3, 1, 2}
```

---

एक सेट एक `Iterable` है, इसलिए आप इसके तत्वों पर सीधे `for-in` से लूप चला सकते हैं, बिल्कुल एक सूची की तरह। इसमें कोई इंडेक्स नहीं होते: तत्वों को इंसर्शन ऑर्डर में देखा जाता है:

```dart
var numbers = {3, 1, 4};
for (var n in numbers) {
  print(n);
}
// 3
// 1
// 4
```
