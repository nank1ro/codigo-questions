# --description--

किसी सूची को सेट में बदलना **डुप्लिकेट हटाने** का सबसे आसान तरीका है: हर सूची में एक `.toSet()` मेथड होती है जो पहली बार आने के क्रम में उसके अद्वितीय तत्वों के साथ एक सेट लौटाती है। एक सेट में `.toList()` मेथड होती है जो उल्टी दिशा में काम करती है, इसलिए दोनों को जोड़ने से आपको बिना डुप्लिकेट वाली सूची मिलती है:

```dart
var votes = ['a', 'b', 'a', 'c', 'b'];
Set<String> unique = votes.toSet();
print(unique); // {a, b, c}
List<String> cleaned = votes.toSet().toList();
print(cleaned); // [a, b, c]
```
