# --description--

इन मेथड में कुछ भी विशेष नहीं है: उनके पैरामीटर के रूप में बस एक **फंक्शन** होता है, और आपके अपने फंक्शन भी यही कर सकते हैं। फंक्शन पैरामीटर का टाइप पहले रिटर्न टाइप, फिर `Function`, और फिर कोष्ठकों में पैरामीटर टाइप लिखा जाता है:

```dart
List<int> applyAll(List<int> numbers, int Function(int) operation) {
  return numbers.map(operation).toList();
}
```

कॉल करने वाला तय करता है **क्या** होता है, और फंक्शन तय करता है **किस पर** होता है। ध्यान दें कि `operation` सीधे `map` को कैसे सौंपा जाता है: एक फंक्शन मान किसी अन्य मान की तरह आगे पास किया जा सकता है।

आर्ग्युमेंट एक अनामित फंक्शन हो सकता है, या किसी मौजूदा फंक्शन का **नाम**, बिना कोष्ठक लिखा हुआ। कोष्ठक जोड़ने से उसे पास करने के बजाय कॉल कर दिया जाएगा:

```dart
int square(int n) => n * n;

print(applyAll([1, 2, 3], square));       // [1, 4, 9]
print(applyAll([1, 2, 3], (n) => n + 1)); // [2, 3, 4]
```

# --instructions--

कोड पूरा करें ताकि `applyAll` `int` से `int` तक का एक फंक्शन ले, उसे हर तत्व पर लागू करे, और प्रोग्राम पहले वर्ग (squares) और फिर निषेधित (negated) संख्याएँ प्रिंट करे।
