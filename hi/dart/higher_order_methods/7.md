# --description--

`reduce` `fold` का छोटा संबंधी है। यह कोई प्रारंभिक मान नहीं लेता: **पहला तत्व** ही प्रारंभिक accumulator होता है, और फंक्शन हर शेष तत्व के लिए चलता है:

```dart
final numbers = [1, 2, 3, 4];
print(numbers.reduce((a, b) => a + b)); // 10
```

प्रारंभिक मान न होने के कारण, परिणाम में हमेशा **तत्वों के समान टाइप** होता है, और एक खाली कलेक्शन पर `reduce` कॉल करने से एक `StateError` उत्पन्न होता है: शुरू करने के लिए कोई पहला तत्व नहीं होता। `fold` में ऐसी कोई समस्या नहीं है, इसीलिए वह सुरक्षित डिफ़ॉल्ट है।

`reduce` तब सर्वश्रेष्ठ होता है जब आप कई तत्वों में से एक तत्व खोज रहे हों, जैसे सबसे बड़ा:

```dart
print(numbers.reduce((a, b) => a > b ? a : b)); // 4
```
