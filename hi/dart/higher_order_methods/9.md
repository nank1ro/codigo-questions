# --description--

जब आप `map` को दिया गया फंक्शन प्रत्येक तत्व के लिए एक कलेक्शन लौटाता है, तो आपके पास कलेक्शनों का एक अनुक्रम बन जाता है। **`expand`** वही काम करता है लेकिन फिर उन सबको जोड़कर एक सपाट अनुक्रम बना देता है:

```dart
final numbers = [1, 2];
print(numbers.map((n) => [n, -n]).toList());    // [[1, -1], [2, -2]]
print(numbers.expand((n) => [n, -n]).toList()); // [1, -1, 2, -2]
```

क्रम बना रहता है: पहले तत्व द्वारा उत्पन्न सब कुछ पहले आता है, फिर दूसरे तत्व द्वारा उत्पन्न सब कुछ, और इसी तरह।

क्योंकि लौटाया गया कलेक्शन किसी भी आकार का हो सकता है, `expand` यह भी तरीका है कि शुरुआत से **अधिक या कम** तत्व उत्पन्न किए जाएँ: किसी तत्व के लिए एक खाली सूची लौटाना उसे बस हटा देता है।

```dart
print(['a b', 'c'].expand((s) => s.split(' ')).toList()); // [a, b, c]
```

# --instructions--

एक फंक्शन `doubleUp` लिखें जो एक `List<int>` `numbers` ले और एक नई `List<int>` लौटाए जिसमें हर तत्व लगातार दो बार आता हो, `expand` का उपयोग करते हुए।

Example:
```dart
print(doubleUp([1, 2])); // [1, 1, 2, 2]
```
