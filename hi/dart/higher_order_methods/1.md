# --description--

एक **हायर-ऑर्डर मेथड** वह मेथड है जो एक फंक्शन को आर्ग्युमेंट के रूप में लेता है। Dart के कलेक्शन उनमें से बहुत कुछ प्रदान करते हैं, और आपके द्वारा पास किया गया फंक्शन आमतौर पर एरो सिंटैक्स `(x) => ...` से लिखा गया एक अनामित फंक्शन होता है।

`map` उनमें सबसे सामान्य है: यह हर तत्व पर फंक्शन को कॉल करता है और परिणाम उत्पन्न करता है, प्रत्येक तत्व के लिए एक, जिससे मूल कलेक्शन अपरिवर्तित रहता है:

```dart
final numbers = [1, 2, 3];
print(numbers.map((n) => n * 2)); // (2, 4, 6)
print(numbers);                   // [1, 2, 3]
```

आउटपुट में **गोल कोष्ठकों** पर ध्यान दें। `map` एक `List` नहीं लौटाता: यह एक `Iterable` लौटाता है, एक ऐसा अनुक्रम जिसमें आप चल सकते हैं। वास्तविक सूची वापस पाने के लिए, उस पर **`toList()`** कॉल करें:

```dart
final doubled = numbers.map((n) => n * 2).toList();
print(doubled); // [2, 4, 6]
```

आउटपुट में वर्ग कोष्ठक इस बात का संकेत हैं कि आप एक `List` देख रहे हैं, और गोल कोष्ठक इस बात का कि आप एक साधारण `Iterable` देख रहे हैं।
