# --description--

`firstWhere` उन सभी के बजाय predicate से मेल खाने वाला **पहला** तत्व लौटाता है:

```dart
final words = ['fig', 'kiwi', 'banana'];
print(words.firstWhere((w) => w.length > 3)); // kiwi
```

जब कुछ भी मेल न खाए तो लौटाने के लिए कोई तत्व नहीं होता, इसलिए `firstWhere` एक `StateError` उत्पन्न करता है। त्रुटि के बजाय एक उत्तर देने के लिए, नामित आर्ग्युमेंट **`orElse`** पास करें: एक ऐसा फंक्शन जो कोई पैरामीटर नहीं लेता और fallback मान उत्पन्न करता है।

```dart
print(words.firstWhere((w) => w.length > 10, orElse: () => 'none')); // none
```

`orElse` एक साधारण मान नहीं, बल्कि एक फंक्शन है, इसलिए वह केवल तब कॉल होता है जब खोज असफल हो। `orElse: 'none'` लिखना कंपाइल नहीं होता।

# --instructions--

कोड पूरा करें ताकि `10` से लंबा पहला शब्द प्रिंट हो, या ऐसा कोई शब्द न होने पर `none` प्रिंट हो।
