# --description--

एक फंक्शन एक फंक्शन भी **लौटा** सकता है। रिटर्न टाइप बिल्कुल फंक्शन पैरामीटर टाइप की तरह लिखा जाता है, और लौटाया गया मान आमतौर पर एक अनामित फंक्शन होता है:

```dart
int Function(int) multiplier(int factor) {
  return (n) => n * factor;
}
```

`multiplier(3)` कुछ भी गुणा नहीं करता: वह एक नया फंक्शन बनाकर लौटाता है जो `3` से गुणा करता है। फिर उस फंक्शन को किसी अन्य मान की तरह संग्रहीत, कॉल या `map` को पास किया जाता है:

```dart
final triple = multiplier(3);
print(triple(5));                       // 15
print([1, 2, 3].map(triple).toList());  // [3, 6, 9]
```

लौटाया गया फंक्शन `multiplier` के समाप्त होने के बाद भी `factor` को याद रखता है। एक फंक्शन जो अपने निर्माण के दायरे (scope) के वेरिएबल को बनाए रखता है, उसे **closure** कहा जाता है, और यही इस तरह के फंक्शन फैक्ट्री को संभव बनाता है।
