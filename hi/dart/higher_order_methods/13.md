# --description--

इनमें से हर मेथड एक `Iterable` लौटाता है, और हर `Iterable` में वही मेथड फिर से होते हैं। यही उन्हें **शृंखलाबद्ध (chained)** करने देता है: पूरी गणना बाएँ से दाएँ एक पाइपलाइन जैसी पढ़ी जाती है, जहाँ हर कदम पिछले कदम के उत्पन्न किए पर काम करता है।

```dart
final words = ['kiwi', 'fig', 'banana', 'date'];
print(words.where((w) => w.length == 4).map((w) => w.toUpperCase()).toList());
// [KIWI, DATE]
```

केवल अंतिम कदम को `toList()` की आवश्यकता है: बीच में उसे कॉल करने से एक ऐसी सूची बनती जिसे कोई रखता ही नहीं।

शृंखला के साथ टाइप बदलता रहता है, और इसके साथ यह भी बदलता है कि अगला फंक्शन क्या प्राप्त करता है: एक `List<String>` पर `where` के बाद आपके पास अभी भी स्ट्रिंग्स होती हैं, लेकिन `map((w) => w.length)` के बाद अगला कदम संख्याएँ देखता है।

चूंकि हर कदम आलसी है, क्रम केवल परिणाम के लिए ही नहीं, किए गए कार्य के लिए भी मायने रखता है: पहले `where` से छँटाई करने का मतलब है कि `map` कम तत्वों पर कॉल होता है।

# --instructions--

एक फंक्शन `shortUpper` लिखें जो एक `List<String>` `words` ले और अधिकतम `4` अक्षरों वाले शब्दों की एक नई `List<String>` लौटाए, अपर केस में, उनके मूल क्रम में।

Example:
```dart
print(shortUpper(['kiwi', 'banana', 'fig'])); // [KIWI, FIG]
```

List<String> shortUpper(List<String> words) {

}
