> शुरू करने से पहले, मैं आपको बताना चाहता था कि मुझे आपको Dart सिखाकर बहुत खुशी हो रही है।
इस संदेश के साथ मैं आपको यह बताना चाहता हूँ कि आप जिस ऐप का उपयोग कर रहे हैं, वह Dart में ही लिखा गया था, Flutter फ्रेमवर्क का उपयोग करके। इसलिए मेरे लिए भाषा में अपनी विशेषज्ञता साझा करना सम्मान की बात है।

Dart, कई अन्य प्रोग्रामिंग भाषाओं की तरह, आपको अपने कोड को दस्तावेज़ करने की अनुमति देता है।
यह आपको कोड के बगल में कोई भी टेक्स्ट लिखने की अनुमति देता है।
कंपाइलर द्वारा कमेंट्स को अनदेखा किया जाता है।

Dart _सिंगल-लाइन_ कमेंट्स, _मल्टी-लाइन_ कमेंट्स, और _डॉक्यूमेंटेशन_ कमेंट्स का समर्थन करता है।

यहाँ _सिंगल-लाइन_ कमेंट लिखने का तरीका है:
```dart
// यह एक कमेंट है। यह निष्पादित नहीं होता।
```

---

आप _मल्टी-लाइन_ कमेंट्स लिखने के लिए _सिंगल-लाइन_ कमेंट्स को एक के ऊपर एक रख सकते हैं।
```dart
// यह एक
// मल्टी-लाइन कमेंट
```

---

आप कमेंट ब्लॉक, या _मल्टी-लाइन_ कमेंट्स भी बना सकते हैं।
_मल्टी-लाइन_ कमेंट्स `/*` से शुरू होते हैं और `*/` से समाप्त होते हैं।
```dart
/*
This is a multi-line
comment
*/
```

---

कमेंट्स लिखने के इन दो तरीकों के अलावा, Dart में _डॉक्यूमेंटेशन कमेंट्स_ भी शामिल हैं।

_डॉक्यूमेंटेशन कमेंट्स_ मल्टी-लाइन या सिंगल-लाइन कमेंट्स होते हैं जो `///` या `/**` से शुरू होते हैं। लगातार लाइनों पर `///` का उपयोग मल्टी-लाइन डॉक्यूमेंटेशन कमेंट के समान प्रभाव रखता है।

_डॉक्यूमेंटेशन कमेंट्स_ बहुत उपयोगी हैं क्योंकि वे डॉक्यूमेंटेशन उत्पन्न करने की अनुमति देते हैं।
आप अपने कोड में _डॉक्यूमेंटेशन कमेंट्स_ जोड़ना चाहेंगे ताकि यह स्पष्ट हो सके कि कोड का कोई विशेष ब्लॉक क्या करता है।

_डॉक्यूमेंटेशन कमेंट_ के भीतर, एनालाइज़र वर्ग कोष्ठकों में लिखे नामों को अन्य API एलिमेंट्स के संदर्भ (reference) के रूप में हल करता है।
वर्ग कोष्ठकों का उपयोग करके _classes_, _methods_, _fields_, _variables_, _functions_ और _parameters_ को संदर्भित किया जा सकता है।

यहाँ एक उदाहरण है:
```dart
/// एक पालतू दक्षिण अमेरिकी ऊँट-प्रजाति का जानवर (Lama glama)।
///
/// किसी भी दूसरे जानवर की तरह, llama को भी खाना चाहिए,
/// इसलिए [feed] से उन्हें कुछ [Food] देना मत भूलना।
class Llama {
  String? name;

  /// तुम्हारे llama को [food] खिलाता है।
  ///
  /// एक सामान्य llama हफ़्ते में घास की एक गठरी खाता है।
  void feed(Food food) {
    // ...
  }

  /// [activity] से तुम्हारे llama को व्यायाम कराता है, इतनी देर के लिए
  /// [timeLimit] मिनट।
  void exercise(Activity activity, int timeLimit) {
    // ...
  }
}
```

उत्पन्न डॉक्यूमेंटेशन में, `[feed]` `feed` मेथड के डॉक्यूमेंटेशन का लिंक बन जाता है, और `[Food]` `Food` क्लास के डॉक्यूमेंटेशन का लिंक बन जाता है।
जबकि `[activity]` और `[timeLimit]` क्रमशः `activity` और `timeLimit` के डॉक्यूमेंटेशन का लिंक बन जाते हैं।
