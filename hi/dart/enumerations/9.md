# --instructions--

`enum Size { small, medium, large }` दिए जाने पर, निम्नलिखित कोड के साथ क्या होता है?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- यह कंपाइल नहीं होता: enum पर switch expression को हर value कवर करनी चाहिए
- यह कंपाइल होता है और `Size.large` के लिए `null` लौटाता है
- यह कंपाइल होता है और `Size.large` के लिए रनटाइम पर एक exception फेंकता है
- यह कंपाइल होता है और `Size.large` के लिए अपने आप `'L'` लौटाता है
