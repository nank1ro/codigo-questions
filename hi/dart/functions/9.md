# --description--

Dart **वैकल्पिक स्थितीय पैरामीटर** को भी सपोर्ट करता है — पैरामीटर जो वर्गाकार कोष्ठक `[]` में लिपटे होते हैं। ये स्थिति के अनुसार पास किए जाते हैं, कॉलर द्वारा छोड़े जा सकते हैं, और उनका एक डिफ़ॉल्ट मान हो सकता है:

```dart
String greet([String name = "World"]) {
  return "Hello, $name!";
}

void main() {
  print(greet());         // Hello, World!
  print(greet("Alice"));  // Hello, Alice!
}
```

# --instructions--

एक फंक्शन `greetUser` लिखें जो **वैकल्पिक स्थितीय** `String` पैरामीटर `name` लेता है जिसका **डिफ़ॉल्ट मान** `"World"` है, और स्ट्रिंग `"Hello, <name>!"` लौटाता है।

उदाहरण:
```dart
print(greetUser());          // Hello, World!
print(greetUser("Alice"));   // Hello, Alice!
```
