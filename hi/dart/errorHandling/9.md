# --description--

एक `catch` क्लॉज़ एक **दूसरा** पैरामीटर भी लेता है:

```dart
try {
  return int.parse(text);
} on FormatException catch (e, s) {
  log.add('$e');
  log.add('$s');
  rethrow;
}
```

पहला फेंकी गई वस्तु है, दूसरा एक `StackTrace` है: फेंकने के क्षण चल रही कॉलों की श्रृंखला। वह बताता है कि विफलता *कहाँ से* आई, जो अकेला संदेश शायद ही कभी बताता है।

एक स्टैक ट्रेस फ़ाइल नाम, पंक्ति संख्याएँ और फ़्रेम सूचीबद्ध करता है, और वह बिल्ड और कॉल पथ के साथ बदल जाता है। उसे प्रिंट करें, किसी रिपोर्ट से जोड़ें, आगे भेजें — पर उसकी कभी किसी निश्चित टेक्स्ट से तुलना न करें, और उसकी सामग्री पर कभी प्रोग्राम का व्यवहार न बनाएँ। उसे केवल तब माँगें जब आप उसे लॉग करने वाले हों।

# --instructions--

`on FormatException catch (e, s)` में, `s` क्या है?

# --answers--

- फेंकने का स्टैक ट्रेस: लॉग करने के लिए उपयोगी, पर किसी निश्चित टेक्स्ट से तुलना करने के लिए नहीं
- अपवाद का संदेश, `e.toString()` जैसा ही मान
- एक दूसरा अपवाद जो उसी क्षण फेंका गया
- उस फंक्शन का नाम जिसमें `catch` क्लॉज़ लिखा गया
