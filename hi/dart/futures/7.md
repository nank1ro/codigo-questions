# --description--

जब कोई फ़ंक्शन `await` पर पहुँचता है, तो वह उसी पंक्ति पर **रुक** जाता है और बाकी प्रोग्राम चलता रहता है। `await` के बाद वाली पंक्तियाँ तभी चलती हैं जब future पूरा हो जाए। इसलिए किसी `async` फ़ंक्शन को ऊपर से नीचे पढ़ना तुम्हें उसके प्रभावों का सटीक क्रम बता देता है:

```dart
Future<int> load() async {
  await Future.delayed(const Duration(milliseconds: 5));
  return 7;
}

Future<void> main() async {
  print('loading');
  final n = await load();
  print('value: $n');
  print('done');
}
// loading
// value: 7
// done
```

# --instructions--

आइटम क्रम में लगाओ ताकि एक `async` फ़ंक्शन `fetchName` परिभाषित हो जो `10` मिलीसेकंड प्रतीक्षा करके `'Ada'` लौटाए, और एक `async` `main` जो `fetching` छापे, फिर `fetchName()` का await करके `name` में रखे, फिर `Hello, ` के बाद नाम और `!` छापे, और अंत में `done` छापे। `fetchName` को `main` से पहले परिभाषित करो। प्रोग्राम को यह छापना चाहिए:

```
fetching
Hello, Ada!
done
```
