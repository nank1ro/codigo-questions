# --description--

`.indexOf(value)` मेथड `value` के बराबर पहले तत्व का इंडेक्स लौटाती है। यदि मान सूची में नहीं है, तो यह `-1` लौटाती है।

```dart
var colors = ['red', 'green', 'blue'];
print(colors.indexOf('green')); // 1
print(colors.indexOf('pink')); // -1
```
