# --description--

`.isEmpty` प्रॉपर्टी तब `true` होती है जब सूची में कोई तत्व नहीं होता, और `.isNotEmpty` तब `true` होती है जब उसमें कम से कम एक तत्व होता है।

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```

# --instructions--

एक खाली `List<int>` बनाएं। यह `.isEmpty` है या नहीं, इसे एक बूलियन में संग्रहीत करें, फिर उसमें मान `1` जोड़ें और यह `.isNotEmpty` है या नहीं, इसे दूसरे बूलियन में संग्रहीत करें। दोनों बूलियन को उसी क्रम में `List<bool>` के रूप में लौटाएं।
