# --description--

दो स्ट्रिंग्स `==` से बराबर तब होती हैं जब उनमें बिल्कुल वही वर्ण, उसी क्रम में हों। यह तुलना **केस-सेंसिटिव** होती है और हर स्पेस को भी गिनती है:

```dart
print('dart' == 'dart');    // true
print('Dart' == 'dart');    // false
print('dart ' == 'dart');   // false
```

केस को अनदेखा करते हुए तुलना करने के लिए, पहले दोनों तरफ को बदलें: `a.toLowerCase() == b.toLowerCase()`. क्रम के लिए, `.compareTo(other)` एक ऋणात्मक संख्या, `0`, या एक धनात्मक संख्या लौटाता है, यह इस पर निर्भर करता है कि स्ट्रिंग दूसरी से पहले आती है, बराबर है, या बाद में आती है।
