# --description--

स्ट्रिंग मेथड स्ट्रिंग्स लौटाते हैं, इसलिए इन्हें एक के बाद एक **चेन** किया जा सकता है। `.split('')`, लिस्ट प्रॉपर्टी `.reversed`, और `.join()` को मिलाकर, आप एक ही एक्सप्रेशन में एक स्ट्रिंग को उल्टा कर सकते हैं:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

एक **पैलिंड्रोम** (palindrome) एक ऐसा टेक्स्ट है जो आगे और पीछे से पढ़ने पर एक जैसा होता है, जैसे `level`।

# --instructions--

एक फंक्शन `isPalindrome` लिखें जो `String` पैरामीटर `text` लेता है और अक्षरों के केस और स्पेस को अनदेखा करते हुए, अगर यह एक पैलिंड्रोम है तो `true` लौटाता है, अन्यथा `false` लौटाता है।

उदाहरण:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

```dart
bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
```
