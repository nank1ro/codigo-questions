# --description--

कुछ वर्ण उद्धरण चिह्नों के अंदर सीधे टाइप नहीं किए जा सकते। **एस्केप सीक्वेंस** बैकस्लैश से शुरू होते हैं: `\n` एक न्यूलाइन है, `\t` एक टैब है, `\\` एक बैकस्लैश है, और `\$` एक वास्तविक डॉलर चिह्न है (अन्यथा `$` एक इंटरपोलेशन शुरू कर देता है):

```dart
print('one\ntwo');   // prints one and two on separate lines
print('Cost: \$5');  // Cost: $5
```

एक **रॉ स्ट्रिंग** (raw string) के आगे `r` लगाया जाता है: इसके अंदर, बैकस्लैश और `$` सामान्य वर्ण होते हैं, कुछ भी एस्केप या इंटरपोलेट नहीं होता:

```dart
print(r'C:\new\folder'); // C:\new\folder
print(r'Cost: $5');      // Cost: $5
```

कई पंक्तियों में फैले टेक्स्ट के लिए, ट्रिपल कोट्स `'''` या `"""` से घिरी **मल्टी-लाइन स्ट्रिंग** का उपयोग करें: इसके अंदर के लाइन ब्रेक बरकरार रहते हैं।

```dart
var poem = '''
roses are red
violets are blue''';
```
