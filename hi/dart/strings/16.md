# --description--

क्योंकि स्ट्रिंग्स इम्यूटेबल होती हैं, इसलिए एक लूप में `+=` से लंबा टेक्स्ट बनाने पर हर बार एक नई स्ट्रिंग बनती है। एक **StringBuffer** टेक्स्ट के टुकड़ों को कुशलता से इकट्ठा करता है और मांगे जाने पर ही अंतिम स्ट्रिंग बनाता है:

- `.write(value)` एक वैल्यू जोड़ता है (किसी भी प्रकार को टेक्स्ट में बदल दिया जाता है)
- `.writeln(value)` वैल्यू को जोड़ता है और उसके बाद एक न्यूलाइन लगाता है
- `.toString()` अब तक बनी स्ट्रिंग को लौटाता है

```dart
var buffer = StringBuffer();
buffer.write('Hello');
buffer.write(', ');
buffer.writeln('Dart!');
buffer.write(42);
print(buffer.toString()); // Hello, Dart!\n42
```
