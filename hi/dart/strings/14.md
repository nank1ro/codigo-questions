# --description--

अंदर ही अंदर, स्ट्रिंग का हर वर्ण एक संख्या के रूप में, यानी उसके **कोड यूनिट** (UTF-16 कोड) के रूप में संग्रहीत होता है। `.codeUnitAt(index)` एक वर्ण का कोड देता है और `.codeUnits` पूरी सूची देता है। `String.fromCharCode(code)` इसके विपरीत काम करता है, यह किसी कोड से एक स्ट्रिंग बनाता है:

```dart
var word = 'AB';
print(word.codeUnitAt(0));         // 65
print(word.codeUnits);             // [65, 66]
print(String.fromCharCode(67));    // C
```

लगातार आने वाले अक्षरों के कोड भी लगातार होते हैं: `'A'` 65 है, `'B'` 66 है, और इसी तरह आगे भी।
