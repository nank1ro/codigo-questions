# --description--

`List` ही एकमात्र जेनेरिक कलेक्शन नहीं है। एक `Set` एक टाइप आर्ग्युमेंट लेता है, और एक `Map` **दो** लेता है: एक कीज़ के लिए और एक वैल्यूज़ के लिए, इसी क्रम में।

```dart
Set<String> tags = {'new', 'sale'};
Map<String, int> ages = {'Ada': 36, 'Grace': 45};
```

एक खाली कलेक्शन लिटरल को उसकी सामग्री से नहीं पढ़ा जा सकता, इसलिए आप टाइप आर्ग्युमेंट लिटरल पर ही लिखते हैं:

```dart
final counts = <String, int>{};
final seen = <String>{};
counts['fig'] = 3;
```

जैसे ही टाइप ज्ञात हो जाते हैं, कलेक्शन से निकाली गई हर चीज़ का टाइप पहले से सही होता है: `ages['Ada']` एक `int?` है, कोई रहस्यमय मान नहीं।

# --instructions--

एक फंक्शन `lengths` लिखें जो एक `List<String>` `words` ले और एक `Map<String, int>` लौटाए जिसमें हर शब्द एक की हो और उसकी लंबाई उसकी वैल्यू हो।

उदाहरण:
```dart
print(lengths(['fig', 'kiwi'])); // {fig: 3, kiwi: 4}
```

```dart
Map<String, int> lengths(List<String> words) {
  final result = <String, int>{};
  for (final word in words) {
    result[word] = word.length;
  }
  return result;
}
```
