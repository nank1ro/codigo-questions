# --description--

आप Dart के साथ आने वाली जेनेरिक क्लासों तक सीमित नहीं हैं: आप अपनी खुद की घोषित कर सकते हैं। एक **टाइप पैरामीटर** क्लास के नाम के बाद कोणीय कोष्ठकों के बीच लिखा जाता है, और वहाँ से वह बॉडी के अंदर एक सामान्य टाइप की तरह काम करता है:

```dart
class Box<T> {
  final T value;

  Box(this.value);

  T unwrap() => value;
}
```

`T` केवल एक प्लेसहोल्डर है। यह तब भरा जाता है जब एक `Box` बनाया जाता है, चाहे स्पष्ट रूप से और चाहे इन्फ़रेंस से:

```dart
final a = Box<int>(7);   // Box<int>
final b = Box('fig');    // Box<String>, argument से अनुमानित
print(a.value + 1);      // 8, कंपाइलर जानता है कि value एक int है
```

अक्षर कुछ खास नहीं होता: `T` "टाइप" के लिए एक परंपरा है, बस इतना ही।

# --instructions--

एक जेनेरिक क्लास `Box` घोषित करें जिसमें एक टाइप पैरामीटर `T` हो, कंस्ट्रक्टर से सेट होने वाला टाइप `T` का एक `final` फ़ील्ड `value` हो, और एक गेटर `label` हो जो वैल्यू के आगे लगा टेक्स्ट `Box of ` लौटाए।

उदाहरण:
```dart
final box = Box<int>(7);
print(box.value); // 7
print(box.label); // Box of 7
```

`Box<int>(7)` का `value` `7` और `label` `'Box of 7'` होना चाहिए

```dart
  test('test1', () {
    final box = Box<int>(7);
    expect(box.value, 7, reason: '--err-t1--');
    expect(box.label, 'Box of 7', reason: '--err-t1--');
  });
```

`Box` को किसी भी टाइप के साथ काम करना चाहिए, इसलिए `Box<String>('fig')` भी एक `Box<String>` होना चाहिए

```dart
  test('test2', () {
    final box = Box<String>('fig');
    expect(box.value, 'fig', reason: '--err-t2--');
    expect(box.label, 'Box of fig', reason: '--err-t2--');
    expect(box, isA<Box<String>>(), reason: '--err-t2--');
  });
```

टाइप आर्ग्युमेंट का कंस्ट्रक्टर आर्ग्युमेंट से अनुमान लगाया जाना चाहिए
