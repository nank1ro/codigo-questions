# --description--

एक बिना-बाउंड वाला `T` कुछ भी हो सकता है, इसलिए बॉडी के अंदर आप केवल वही उपयोग कर सकते हैं जो हर ऑब्जेक्ट के पास होता है। यह कोड कंपाइल नहीं होता:

```dart
T twice<T>(T value) => value + value; // error: + is not defined for T
```

एक **बाउंड** इसे ठीक कर देता है। `T extends num` लिखने का अर्थ है "`T` केवल एक संख्या हो सकता है", और बदले में बॉडी `num` जो कुछ भी पेश करता है वह सब उपयोग कर सकती है:

```dart
T twice<T extends num>(T value) => (value + value) as T;

num half<T extends num>(T value) => value / 2;
```

बाउंड कॉल साइट पर जाँचा जाता है: `half(4)` और `half(2.5)` ठीक हैं, `half('fig')` एक कंपाइल-टाइम एरर है। बाउंड दोनों दिशाओं में एक वादा है, अंदर अधिक ताक़त के बदले संकरे आर्ग्युमेंट।

उदाहरण:
```dart

print(total([1.5, 2.5])); // 4.0
```

```dart
num total<T extends num>(List<T> values) {
  num sum = 0;
  for (final value in values) {
    sum += value;
  }
  return sum;
}
```
