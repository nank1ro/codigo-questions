# --description--

एक जेनेरिक क्लास के अंदर टाइप पैरामीटर हर जगह दिखाई देता है: फ़ील्ड्स में, कंस्ट्रक्टर पैरामीटर्स में, मेथड सिग्नेचर में और मेथड बॉडी में। इसे एक बार, क्लास के नाम के पास, घोषित किया जाता है, और हर सदस्य उसका उपयोग कर सकता है।

```dart
class Holder<T> {
  final T item;

  Holder(this.item);

  String describe() => 'holding $item';
}
```

ऑब्जेक्ट बनाना ही टाइप तय करता है: `Holder<String>('fig')` `item` को एक `String` बनाता है, `Holder<int>(3)` उसे एक `int` बनाता है।

# --instructions--

टाइप `T` का फ़ील्ड `item`, एक कंस्ट्रक्टर और एक मेथड `describe` वाली एक जेनेरिक क्लास `Holder` परिभाषित करने के लिए आइटम्स को क्रमबद्ध करें, फिर एक `main` जो `'fig'` से बनी एक `Holder<String>` का विवरण प्रिंट करे। क्लास को `main` से पहले परिभाषित करें। प्रोग्राम को प्रिंट करना चाहिए:

```
holding fig
```
