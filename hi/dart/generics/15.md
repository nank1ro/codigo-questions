# --description--

बिना बाउंड लिखा टाइप पैरामीटर वास्तव में बिना-बाउंड नहीं होता: `class Box<T>`, `class Box<T extends Object?>` का संक्षिप्त रूप है। इसीलिए `Box<int?>` स्वीकार किया जाता है, और इसीलिए क्लास के अंदर आप कभी नहीं मान सकते कि `value` नॉन-नल है।

नलेबल टाइप आर्ग्युमेंट मना करने के लिए, पैरामीटर को `Object` से बाउंड करें:

```dart
class Strict<T extends Object> {
  final T value;
  Strict(this.value);
}

final ok = Strict<int>(7);
final bad = Strict<int?>(null);
// error: Type argument 'int?' doesn't conform to the bound 'Object'
```

`Object` `null` को छोड़कर हर चीज़ का टाइप है, इसलिए `T extends Object` पढ़ा जाता है "कुछ भी, बशर्ते वह सचमुच मौजूद हो"।

# --instructions--

`class Strict<T extends Object> { ... }` दिए गए हैं, तो `Strict<int?>(null)` के साथ क्या होता है?

# --answers--

- यह एक कंपाइल-टाइम एरर है, क्योंकि `int?` बाउंड `Object` के अनुरूप नहीं है
- यह काम करता है, और `value` में `null` रहता है
- यह काम करता है, लेकिन `value` चुपचाप एक डिफ़ॉल्ट मान से बदल दिया जाता है
- यह कंपाइल होता है, और `value` को पहली बार पढ़ने पर एरर फेंकता है
