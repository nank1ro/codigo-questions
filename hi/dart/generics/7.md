# --description--

एक क्लास एक से अधिक टाइप पैरामीटर भी घोषित कर सकती है, कॉमा से अलग करके। `Map<K, V>` इसका बिल्ट-इन उदाहरण है: एक टाइप कीज़ के लिए, एक वैल्यूज़ के लिए।

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

**क्रम** टाइप का हिस्सा है: `Entry<String, int>` और `Entry<int, String>` असंबंधित टाइप हैं, और एक का मान दूसरे को असाइन नहीं किया जा सकता। टाइप पैरामीटर को रिटर्न टाइप में दोबारा क्रम में भी लगाया जा सकता है, जिससे एक मेथड ऑब्जेक्ट का पलटा हुआ संस्करण लौटा सकता है:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

दो टाइप पैरामीटर `A` और `B` वाली एक जेनेरिक क्लास `Pair` घोषित करें, टाइप `A` का एक `final` फ़ील्ड `first` और टाइप `B` का एक `final` फ़ील्ड `second`, दोनों कंस्ट्रक्टर से सेट होने वाले, और एक गेटर `swapped` जो वही दो मान उलटे क्रम में रखने वाला एक `Pair<B, A>` लौटाए।

उदाहरण:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

# --asserts--

`Pair<String, int>('age', 30)` का `first` `'age'` और `second` `30` होना चाहिए

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` को मान आपस में बदलकर एक `Pair<int, String>` लौटाना चाहिए

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` को किन्हीं दो टाइप के साथ काम करना चाहिए, और दो बार स्वैप करने पर मूल मान वापस मिलने चाहिए

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
    expect(pair.swapped.second, true, reason: '--err-t3--');
    expect(pair.swapped.swapped, isA<Pair<bool, String>>(), reason: '--err-t3--');
    expect(pair.swapped.swapped.first, true, reason: '--err-t3--');
  });
```

```dart
class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
