# --description--

यह अंतर तुरंत समझ आ जाता है जैसे ही आप मान का उपयोग करते हैं। एक `Box<int?>` पर आप फ़ील्ड को सामान्य तरीके से पढ़ते हैं और फिर उसके अंदर वाले `null` से निपटते हैं, जबकि एक `Box<int>?` पर आपको पहले गायब बॉक्स को पार करना पड़ता है:

```dart
Box<int?> a = Box(null);
print(a.value ?? 0); // 0, बॉक्स मौजूद है, उसका content null है

Box<int>? b = null;
print(b?.value ?? 0); // 0, बॉक्स खुद ही मौजूद नहीं है
```

एक `Box<int>?` पर `b.value` लिखना तो कंपाइल होता ही नहीं: Dart किसी ऐसी चीज़ का फ़ील्ड पढ़ने से इनकार करता है जो मौजूद न हो सकती।

# --instructions--

`Box<int?> a = Box(null);` और `Box<int>? b = null;` दिए गए हैं, तो कौन-सा कथन सही है?

# --answers--

- `a` एक असली बॉक्स है जिसका `value` `null` है, जबकि `b` बिल्कुल भी बॉक्स नहीं है
- दोनों घोषणाएँ एक ही बात कहती हैं, `?` किसी भी तरफ लिखा जा सकता है
- `a` कंपाइल नहीं होता, क्योंकि टाइप आर्ग्युमेंट कभी नलेबल नहीं हो सकता
- `b` एक ऐसा बॉक्स है जो `null` रखता है, जबकि `a` बिल्कुल भी बॉक्स नहीं है
