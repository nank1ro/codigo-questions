# --description--

एक जेनेरिक क्लास किसी भी दूसरी क्लास की तरह नामित और **फ़ैक्टरी** कंस्ट्रक्टर रख सकती है, और टाइप पैरामीटर उनके अंदर उपलब्ध होता है। एक फ़ैक्टरी कंस्ट्रक्टर ऑब्जेक्ट खुद नहीं बनाता: वह एक बॉडी चलाता है और एक ऑब्जेक्ट लौटाता है, जिससे वह इंस्टेंस को अपनी मर्ज़ी से चुन, दोबारा इस्तेमाल या बना सकता है।

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

टाइप आर्ग्युमेंट क्लास पर लगता है, कंस्ट्रक्टर के नाम पर नहीं: `Box<int>.first(...)`। फ़ैक्टरी के अंदर `<T>[]` एक असली खाली `List<T>` होता है, इसलिए फ़ैक्टरी एक ऐसे टाइप के लिए डिफ़ॉल्ट मान बनाने की स्वाभाविक जगह है जो आपको अभी ज्ञात नहीं है।

# --instructions--

एक टाइप पैरामीटर `T` वाली एक जेनेरिक क्लास `Stack` घोषित करें, टाइप `List<T>` का एक `final` फ़ील्ड `items` जो सामान्य कंस्ट्रक्टर से सेट हो, एक **फ़ैक्टरी** कंस्ट्रक्टर `Stack.empty()` जो खाली सूची के साथ एक `Stack` बनाए, और टाइप `T?` का एक गेटर `top` जो अंतिम एलिमेंट लौटाए, या स्टैक खाली होने पर `null` लौटाए।

उदाहरण:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
