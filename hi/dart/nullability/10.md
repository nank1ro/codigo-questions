# --description--

टाइप प्रमोशन ऐसी क्लास **फ़ील्ड** पर काम **नहीं** करता जिसे बाहर से बदला जा सकता है, क्योंकि जाँच और उपयोग के बीच कोई दूसरा कोड (सबक्लास में ओवरराइड किया गया गेटर, कोई दूसरा मेथड) उसे फिर से `null` कर सकता है:

```dart
class Box {
  int? value;

  int doubled() {
    if (value != null) {
      return value * 2; // error: 'value' can't be unconditionally accessed
    }
    return 0;
  }
}
```

मानक हल यह है कि फ़ील्ड को किसी **लोकल वेरिएबल** में कॉपी कर लें, जिसका प्रमोशन होता है:

```dart
int doubled() {
  final v = value;
  if (v != null) {
    return v * 2;
  }
  return 0;
}
```

# --instructions--

विवरण में दिए `doubled` का पहला संस्करण कंपाइल क्यों नहीं होता?

# --answers--

- `value` एक फ़ील्ड है, इसलिए नल जाँच उसका प्रमोशन नहीं करती: पहले उसे किसी लोकल वेरिएबल में कॉपी करें
- `int?` मानों का गुणा नहीं किया जा सकता, भले ही वे `null` न हों
- `if` स्टेटमेंट में `else` शाखा नहीं है
- क्लास की फ़ील्ड्स का टाइप नलेबल नहीं हो सकता
