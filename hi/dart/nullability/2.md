# --description--

**बिना मान के** घोषित किया गया नलेबल वेरिएबल `null` से शुरू होता है, इसलिए `= null` छोड़ा जा सकता है:

```dart
int? age;
print(age); // null
```

नॉन-नलेबल वेरिएबल के लिए ऐसा कोई डिफ़ॉल्ट नहीं है: Dart ऐसे किसी भी कोड को कंपाइल करने से मना कर देता है जो मान असाइन होने से पहले उसे पढ़ता है।

```dart
int count;
print(count); // error: 'count' must be assigned before it can be used
```
