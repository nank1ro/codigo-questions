# --description--

नॉन-नलेबल फ़ील्ड को सामान्यतः कंस्ट्रक्टर में मान मिलना चाहिए। जब मान केवल **बाद में** पता चलता है (फ़ाइल पढ़ने के बाद, कनेक्शन खोलने के बाद...), तो आप फ़ील्ड को `late` चिह्नित कर सकते हैं: कंपाइलर इनिशियलाइज़र की अनुपस्थिति स्वीकार कर लेता है और भरोसा करता है कि आप पढ़ने से पहले फ़ील्ड को मान दे देंगे।

```dart
class Connection {
  late String host;

  void open() {
    host = 'example.com';
  }
}
```

ऐसी `late` फ़ील्ड पढ़ना जिसे अभी तक मान नहीं मिला है, रन टाइम पर `LateInitializationError` फेंकता है। `!` की तरह `late` भी कंपाइल-समय की गारंटी के बदले रन-टाइम जाँच लेता है, इसलिए यह एक वादा है जिसे आपको निभाना है।

`late` को इनिशियलाइज़र के साथ भी जोड़ा जा सकता है, जो फिर **आलसी रूप से** चलता है, यानी वेरिएबल पहली बार पढ़े जाने पर:

```dart
late String report = buildReport(); // buildReport() runs only when report is used
```
