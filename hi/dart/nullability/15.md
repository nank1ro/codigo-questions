# --description--

दो और ऑपरेटरों का नल-अवेयर रूप होता है।

**नल-अवेयर कैस्केड** `?..` कैस्केड ऑपरेशनों की शृंखला तभी चलाता है जब ऑब्जेक्ट `null` न हो, वरना सभी को छोड़ देता है:

```dart
List<int>? numbers;
numbers?..add(1)..add(2); // nothing happens, numbers is still null
```

**नल-अवेयर स्प्रेड** `...?` किसी नलेबल कलेक्शन के एलिमेंट्स को लिटरल में डालता है, और कलेक्शन के `null` होने पर कुछ नहीं जोड़ता:

```dart
List<int>? extra;
print([0, ...?extra]); // [0]

extra = [1, 2];
print([0, ...?extra]); // [0, 1, 2]
```

`?` के बिना, `List<int>?` पर `...extra` कंपाइल एरर होता।
