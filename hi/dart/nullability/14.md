# --description--

कई लाइब्रेरी फंक्शन यह बताने के लिए `null` का उपयोग करते हैं कि कुछ **नहीं किया जा सका**। स्ट्रिंग को संख्या में बदलना इसका क्लासिक उदाहरण है: टेक्स्ट के संख्या न होने पर `int.parse` `FormatException` फेंकता है, जबकि `int.tryParse` उसके बजाय `null` लौटाता है और तय करना आप पर छोड़ देता है:

```dart
print(int.tryParse('42'));  // 42
print(int.tryParse('4x2')); // null
print(int.tryParse(''));    // null
```

`int.tryParse` का रिटर्न टाइप `int?` है, इसलिए आपने जो सीखा है वह सब लागू होता है: डिफ़ॉल्ट के लिए `??`, चेन करने के लिए `?.`, और प्रमोशन के लिए `if` जाँच। `double.tryParse` भी इसी तरह काम करता है।

# --instructions--

एक फंक्शन `parseOrZero` लिखें जो `String` पैरामीटर `text` लेता है और उसमें मौजूद पूर्णांक लौटाता है, या टेक्स्ट के वैध पूर्णांक न होने पर `0` लौटाता है। `int.tryParse` का उपयोग करें।

उदाहरण:
```dart
print(parseOrZero('42'));  // 42
print(parseOrZero('abc')); // 0
```
