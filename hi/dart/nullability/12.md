# --description--

नलेबिलिटी यह तय करती है कि आप **नेम्ड पैरामीटर** कैसे घोषित करते हैं। नलेबल टाइप वाला नेम्ड पैरामीटर वैकल्पिक होता है: कॉल करने वाला उसे छोड़ दे तो वह बस `null` होता है।

```dart
String label({String? title}) => title ?? 'untitled';

print(label());               // untitled
print(label(title: 'Notes')); // Notes
```

नॉन-नलेबल टाइप और बिना डिफ़ॉल्ट मान वाले नेम्ड पैरामीटर के छोड़े जाने पर उसके पास कोई मान नहीं होता, इसलिए Dart आपसे उसे `required` चिह्नित करने को कहता है; तब कॉल करने वाले को उसे हमेशा देना होगा:

```dart
String label({required String name, String? title}) { ... }

label(name: 'Ada');               // ok
label(name: 'Ada', title: 'Dr.'); // ok
label(title: 'Dr.');              // error: the named parameter 'name' is required
```

# --instructions--

आइटम्स को क्रम में लगाएँ ताकि एक फंक्शन `label` परिभाषित हो जिसमें आवश्यक नेम्ड पैरामीटर `name` और वैकल्पिक नलेबल नेम्ड पैरामीटर `title` हो, जो `title` के `null` होने पर केवल `name` और अन्यथा `'$title $name'` लौटाए। पहले फंक्शन परिभाषित करें, फिर `main`। प्रोग्राम को यह प्रिंट करना चाहिए:

```
Ada
Countess Lovelace
```

String label({required String name, String? title}) {
  if (title == null) return name;
  return '$title $name';
}

void main() {
  print(label(name: 'Ada'));
  print(label(name: 'Lovelace', title: 'Countess'));
}
