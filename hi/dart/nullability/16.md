# --description--

असली डेटा में खाली जगहें भरी होती हैं: खाली छोड़ा गया फ़ॉर्म फ़ील्ड, फ़ाइल में गायब कोई कॉलम, ऐसी स्ट्रिंग जो पूरी तरह संख्या नहीं है। इस अध्याय के औज़ार इन्हें संभालने के लिए स्वाभाविक रूप से मिलकर काम करते हैं: अनुपस्थित एलिमेंट्स हटाने के लिए `nonNulls`, सुरक्षित रूप से बदलने के लिए `int.tryParse`, और जो नहीं बदला जा सका उससे निपटने के लिए `??` या `if` जाँच।

# --instructions--

एक फंक्शन `total` लिखें जो `List<String?>` पैरामीटर `prices` लेता है और उन मानों का योग लौटाता है जिन्हें `int` में बदला जा सकता है, `null` एंट्रियों और अवैध पूर्णांक स्ट्रिंग्स दोनों को अनदेखा करते हुए।

उदाहरण:
```dart
print(total(['3', null, 'abc', '4'])); // 7
```

# --solutions--

```dart
int total(List<String?> prices) {
  var sum = 0;
  for (var price in prices.nonNulls) {
    var value = int.tryParse(price);
    if (value != null) {
      sum += value;
    }
  }
  return sum;
}
```
