# --description--

अक्सर अनुपस्थित मान को किसी **डिफ़ॉल्ट** से बदलना चाहिए। **if-null** ऑपरेटर `??` बाएँ ऑपरेंड को लौटाता है जब वह `null` नहीं है, वरना दाएँ ऑपरेंड को:

```dart
String? nickname;
print(nickname ?? 'anonymous'); // anonymous

nickname = 'Ada';
print(nickname ?? 'anonymous'); // Ada
```

`??` केवल `null` पर प्रतिक्रिया करता है: खाली स्ट्रिंग `''` या संख्या `0` असली मान हैं, इसलिए वे बने रहते हैं।

`??` का `?.` के साथ अच्छा मेल है, क्योंकि `?.` नलेबल परिणाम देता है:

```dart
String? text;
print(text?.length ?? 0); // 0
```

# --instructions--

एक फंक्शन `greet` लिखें जो नलेबल `String` पैरामीटर `name` लेता है और `'Hello, '` के बाद `name` लौटाता है, या `name` के `null` होने पर `'stranger'` लौटाता है। `??` का उपयोग करें।

उदाहरण:
```dart
print(greet('Ada')); // Hello, Ada
print(greet(null));  // Hello, stranger
```
