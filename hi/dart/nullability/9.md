# --description--

नलेबल मान की जाँच `if` से करना `!` से अधिक सुरक्षित है, और Dart इसके लिए आपको पुरस्कृत करता है। `if (x != null)` जैसी जाँच के बाद कंपाइलर जानता है कि ब्लॉक के भीतर `x` `null` नहीं हो सकता, इसलिए वहाँ वह `x` को नॉन-नलेबल मानता है। इसे **टाइप प्रमोशन** कहते हैं:

```dart
int twice(int? n) {
  if (n != null) {
    return n * 2; // here n is an int, no ! needed
  }
  return 0;
}
```

प्रमोशन जल्दी रिटर्न के बाद भी काम करता है:

```dart
int twice(int? n) {
  if (n == null) return 0;
  return n * 2; // n is an int from here on
}
```

प्रमोशन **लोकल वेरिएबल्स और पैरामीटर्स** पर लागू होता है, जिनका मान जाँच और उपयोग के बीच आपकी जानकारी के बिना नहीं बदल सकता।

# --instructions--

एक फंक्शन `half` लिखें जो नलेबल `int` पैरामीटर `n` लेता है और पूर्णांक भाग `~/` से `n` को `2` से भाग देकर लौटाता है, या `n` के `null` होने पर `0` लौटाता है। `!` नहीं, बल्कि `if` से नल जाँच का उपयोग करें।

उदाहरण:
```dart
print(half(10));   // 5
print(half(null)); // 0
```
