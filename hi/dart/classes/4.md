# --description--

पिछले अभ्यास में देखा गया `this.x` पैरामीटर एक संक्षिप्त रूप है। लंबे रूप में, कंस्ट्रक्टर बॉडी के अंदर हर पैरामीटर को उसकी फ़ील्ड में असाइन किया जाता है (`this.x` फ़ील्ड है, `x` पैरामीटर है):

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

वही क्लास इस तरह भी लिखी जा सकती है:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

इस छोटे रूप को **initializing formals** कहा जाता है।

# --instructions--

निम्नलिखित में से कौन सा initializing formals शॉर्टहैंड का सही उपयोग करता है?

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`

# --solutions--

- `Point(this.x, this.y);`
