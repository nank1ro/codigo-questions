# --description--

एक **method** क्लास के अंदर परिभाषित एक फ़ंक्शन है। मेथड किसी ऑब्जेक्ट के व्यवहार का वर्णन करते हैं:

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() {
    print('$name makes a sound.');
  }
}
```

आप डॉट नोटेशन का उपयोग करके किसी ऑब्जेक्ट पर मेथड कॉल करते हैं: `dog.speak()`।
