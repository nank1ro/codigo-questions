# --description--

एक **factory constructor**, `factory` कीवर्ड का उपयोग करता है और आपको ऑब्जेक्ट बनाने पर नियंत्रण देता है — उदाहरण के लिए, एक कैश्ड इंस्टेंस या subtype लौटाना:

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance;

  Logger._internal();
}
```

`Logger()` की हर कॉल एक ही इंस्टेंस लौटाती है (singleton pattern)।

# --instructions--

एक क्लास `Counter` बनाएं जिसमें एक private फ़ील्ड `_count` हो जो `0` से शुरू हो। एक instance मेथड `increment()` जोड़ें जो `_count` को `1` से बढ़ाए, और एक getter `count` जोड़ें जो `_count` लौटाए। एक `factory` constructor `Counter.start()` का उपयोग करें जो हमेशा `_count = 0` के साथ शुरू किया गया एक नया `Counter` लौटाए (एक named private constructor `Counter._internal()` का उपयोग करते हुए)।

      c.increment();

```dart
class Counter {
  int _count = 0;

  Counter._internal();

  factory Counter.start() => Counter._internal();

  void increment() {
    _count++;
  }

  int get count => _count;
}
```
