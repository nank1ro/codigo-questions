# --instructions--

क्लास `Temperature` दिया गया है। `Temperature` पर एक एक्सटेंशन `Conversions` लिखें जिसमें:
- `double` टाइप का एक गेटर `fahrenheit` हो, `celsius * 9 / 5 + 32` के बराबर
- एक मेथड `isAbove` हो जो एक `double` पैरामीटर `limit` लेती है और `true` लौटाती है जब `celsius`, `limit` से बड़ा हो

उदाहरण:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

```dart
extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
```
