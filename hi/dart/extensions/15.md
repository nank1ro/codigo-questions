# --description--

एक्सटेंशन सदस्य **कंपाइल टाइम** पर हल किए जाते हैं, व्यंजक के **स्टैटिक टाइप** के आधार पर, यानी उस टाइप के आधार पर जिसे कंपाइलर जानता है, रन टाइम पर वास्तविक ऑब्जेक्ट के नहीं। टाइप `Object` के एक वेरिएबल में संग्रहीत एक `String` प्रोग्राम के चलने पर अभी भी एक `String` है, लेकिन कंपाइलर केवल `Object` देखता है, इसलिए उसे इसके लिए कोई एक्सटेंशन नहीं मिलता:

```dart
extension Shout on String {
  String shout() => toUpperCase() + '!';
}

void main() {
  Object text = 'hi';
  print(text.shout()); // error: the method 'shout' isn't defined for the type 'Object'
}
```

वही बात `dynamic` पर भी लागू होती है: एक्सटेंशन सदस्य कभी भी एक `dynamic` रिसीवर के माध्यम से नहीं मिलते। पहले मान को कास्ट करें, या उसे सटीक टाइप के साथ घोषित करें।
