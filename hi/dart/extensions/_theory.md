आप जानते हैं कि स्वयं लिखी क्लास में मेथड कैसे जोड़ें। लेकिन `String`, `int` या `List` का क्या, जिनका कोड Dart SDK में रहता है? आप उन्हें एडिट नहीं कर सकते, फिर भी अक्सर आप कामना करते हैं कि उनमें एक और मेथड होती।

एक **एक्सटेंशन** यह हल करता है: यह एक **मौजूदा** टाइप में नए सदस्य जोड़ता है, बिना उसके सोर्स कोड को छुए और बिना सबक्लास बनाए। सिंटैक्स है:

```dart
extension ExtensionName on Type {
  // new methods and getters
}
```

एक्सटेंशन के अंदर, `this` उस मान को संदर्भित करता है जिस पर सदस्य को कॉल किया जाता है। एक बार एक्सटेंशन घोषित हो जाने पर, उसके सदस्यों को बिल्कुल टाइप के अपने सदस्यों की तरह कॉल किया जाता है:

```dart
extension Greeting on String {
  String greet() => 'Hello, $this!';
}

void main() {
  var name = 'Ada';
  print(name.greet()); // Hello, Ada!
}
```

एक्सटेंशन को फ़ाइल के **टॉप लेवल** पर घोषित किया जाता है, क्लास और फंक्शन के बगल में, कभी भी `main` के अंदर नहीं।

---

एक्सटेंशन किसी भी टाइप पर काम करते हैं, संख्याओं सहित। यह एक्सटेंशन हर `int` को एक ऐसी मेथड देता है जो उसे दोगुना कर देती है:

```dart
extension Doubling on int {
  int doubled() => this * 2;
}
```

चूँकि एक्सटेंशन **टाइप** पर लागू होता है, आप मेथड को किसी वेरिएबल पर या सीधे **लिटरल** पर कॉल कर सकते हैं। नकारात्मक लिटरल को कोष्ठकों की आवश्यकता होती है, वरना डॉट को माइनस चिह्न से पहले पढ़ा जाता है:

```dart
var n = 21;
print(n.doubled());    // 42
print(4.doubled());    // 8
print((-3).doubled()); // -6
```

---

एक एक्सटेंशन **गेटर** भी घोषित कर सकता है, जिन्हें प्रॉपर्टी की तरह, बिना कोष्ठकों के पढ़ा जाता है। एक्सटेंशन के अंदर आप टाइप के अपने सदस्यों को सीधे कॉल कर सकते हैं: `this.` वैकल्पिक है, बिल्कुल क्लास के अंदर की तरह।

```dart
extension Sizes on String {
  bool get isLong => length > 10;      // same as this.length
  String get firstChar => this[0];
}

void main() {
  print('Dart'.isLong);           // false
  print('extension'.firstChar);   // e
}
```

गेटर चुनें जब सदस्य केवल एक मान को **पढ़ता** हो और कोई पैरामीटर न लेता हो; मेथड चुनें जब वह काम करती हो या तर्कों की आवश्यकता हो।

---

`on` के बाद का टाइप एक **पैरामीटराइज़्ड** टाइप हो सकता है, जैसे `List<int>`। तब एक्सटेंशन केवल उस एलिमेंट टाइप की लिस्टों पर लागू होता है: `[1, 2].total()` काम करता है, `['a', 'b'].total()` कंपाइल नहीं होता।

```dart
extension Totals on List<int> {
  int total() {
    var sum = 0;
    for (final n in this) {
      sum += n;
    }
    return sum;
  }
}
```

एक्सटेंशन के अंदर, `this` वही लिस्ट है, इसलिए आप उस पर लूप कर सकते हैं, उसे इंडेक्स कर सकते हैं, या हमेशा की तरह `length` कॉल कर सकते हैं।

---

`List<int>` पर एक एक्सटेंशन को `List<String>` पर उपयोग नहीं किया जा सकता। एक ऐसा एक्सटेंशन लिखने के लिए जो **हर** एलिमेंट टाइप के लिए काम करे, एक्सटेंशन को एक **टाइप पैरामीटर** दें, जो उसके नाम के बाद एंगल ब्रैकेटों के बीच लिखा जाता है, और उसे `on` टाइप में उपयोग करें:

```dart
extension Firsts<T> on List<T> {
  T get firstOrLast => length > 1 ? this[0] : this[length - 1];
}
```

`T`, "एलिमेंट टाइप जो भी हो" के लिए एक प्लेसहोल्डर है: `List<int>` पर यह `int` बन जाता है, `List<String>` पर यह `String` बन जाता है, इसलिए ऊपर का गेटर तदनुसार एक `int` या एक `String` लौटाता है। कंपाइलर हर कॉल पर `T` को आपके लिए भर देता है।

```dart
print([7, 8, 9].firstOrLast); // 7
print(['a', 'b'].firstOrLast); // a
```

---

`String` पर एक एक्सटेंशन को `String?` पर कॉल नहीं किया जा सकता: मान `null` हो सकता है, और कंपाइलर कॉल को अस्वीकार कर देता है। यदि आप इसके बजाय एक्सटेंशन को **नलेबल** टाइप पर घोषित करें, तो मेथड को सीधे `String?` पर कॉल किया जा सकता है, और उसके अंदर `this` का टाइप `String?` होता है, इसलिए आपको `null` केस को स्वयं संभालना होगा, उदाहरण के लिए `??` के साथ:

```dart
extension Defaults on int? {
  int orZero() => this ?? 0;
}

void main() {
  int? count = null;
  print(count.orZero()); // 0
  print(5.orZero());     // 5
}
```

एक नॉन-नलेबल `int` को वहाँ पास किया जा सकता है जहाँ एक `int?` अपेक्षित है, इसलिए एक्सटेंशन दोनों पर काम करता है।

---

एक एक्सटेंशन मेथड, गेटर, सेटर और ऑपरेटर जोड़ सकता है, लेकिन वह **इंस्टेंस फ़ील्ड जोड़ नहीं सकता**। एक `int` मान की मेमोरी में एक निश्चित लेआउट होता है, और एक एक्सटेंशन केवल फंक्शनों का एक सेट है जिन्हें कंपाइलर आपको डॉट सिंटैक्स से कॉल करने देता है: प्रति मान अतिरिक्त डेटा संग्रहीत करने के लिए कोई जगह नहीं है।

```dart
extension Counter on int {
  int count = 0; // error: extensions can't declare instance fields
}
```

एक्सटेंशन में गेटर और सेटर केवल `this` से मान गणना कर सकते हैं या मौजूदा सदस्यों को फॉरवर्ड कर सकते हैं: वे कॉलों के बीच कुछ भी याद नहीं रख सकते।

---

एक एक्सटेंशन **स्टैटिक** सदस्य घोषित कर सकता है। क्लास की तरह, वे स्वयं एक्सटेंशन के होते हैं, किसी मान के नहीं, और उन्हें **एक्सटेंशन के नाम** के माध्यम से एक्सेस किया जाता है, उस टाइप के माध्यम से नहीं जिसे वह एक्सटेंड करता है:

```dart
extension Temperatures on double {
  static const double boiling = 100.0;

  static bool isBoiling(double celsius) => celsius >= boiling;
}

void main() {
  print(Temperatures.boiling);         // 100.0
  print(Temperatures.isBoiling(37.5)); // false
  print(double.boiling);               // error: 'boiling' isn't defined for 'double'
}
```

स्टैटिक सदस्य एक्सटेंडेड टाइप से संबंधित कॉन्स्टेंट और हेल्पर फंक्शन के लिए एक उपयोगी जगह हैं।

---

एक्सटेंशन केवल SDK टाइप के लिए नहीं हैं: आप **अपनी खुद की क्लास** को भी एक्सटेंड कर सकते हैं। यह तब उपयोगी है जब क्लास किसी ऐसे पैकेज से आती है जिसे आप नियंत्रित नहीं करते, या जब आप क्लास को छोटा रखना चाहते हैं और वैकल्पिक हेल्पर को उस कोड के बगल में जोड़ना चाहते हैं जिसे उनकी आवश्यकता है।

```dart
class Circle {
  final double radius;
  Circle(this.radius);
}

extension CircleMath on Circle {
  double get diameter => radius * 2;
}

void main() {
  print(Circle(3).diameter); // 6.0
}
```

एक्सटेंशन को क्लास के पब्लिक फ़ील्ड और मेथड दिखाई देते हैं, बिल्कुल क्लास के बाहर लिखे गए कोड की तरह।

---

Dart एक टाइप को यह परिभाषित करने देता है कि `+`, `*` या `==` जैसे ऑपरेटर उसके मानों के लिए क्या अर्थ रखते हैं, एक ऐसी मेथड के माध्यम से जिसका नाम कीवर्ड `operator` है और उसके बाद प्रतीक आता है। ऑपरेटर का दायाँ हिस्सा मेथड का पैरामीटर होता है:

```dart
extension Scaling on List<int> {
  List<int> operator *(int factor) => map((n) => n * factor).toList();
}

void main() {
  print([1, 2, 3] * 10); // [10, 20, 30]
}
```

चूँकि एक्सटेंशन ऑपरेटर घोषित कर सकते हैं, आप एक मौजूदा टाइप को एक नया ऑपरेटर दे सकते हैं जो उसके पास पहले से नहीं है। `String` के पास `+` और `*` हैं, लेकिन `-` नहीं, इसलिए एक एक्सटेंशन परिभाषित कर सकता है कि `'hello world' - 'o'` का क्या अर्थ है।

---

क्या हो अगर एक एक्सटेंशन ऐसा सदस्य घोषित करे जो टाइप के पास **पहले से हो**? टाइप का अपना सदस्य हमेशा जीतता है: एक्सटेंशन सदस्यों पर केवल तब विचार किया जाता है जब टाइप स्वयं में उस नाम का कोई सदस्य नहीं हो। एक्सटेंशन सदस्य चुपचाप अनदेखा कर दिया जाता है, न कोई त्रुटि होती है और न कोई ओवरराइड।

```dart
extension Shorter on String {
  int get length => 0;
}

void main() {
  print('four'.length); // 4, String's own length is used
}
```

इसलिए एक एक्सटेंशन सदस्य जोड़ सकता है और कमियों को भर सकता है, लेकिन वह कभी भी मौजूदा सदस्यों के व्यवहार को **बदल** नहीं सकता।

---

एक एक्सटेंशन का नाम वैकल्पिक है। एक **बिना नाम वाला** एक्सटेंशन उसी तरह काम करता है, लेकिन वह केवल उस फ़ाइल में दिखाई देता है जो उसे घोषित करती है:

```dart
extension on int {
  bool get isTriple => this % 3 == 0;
}
```

एक **नाम** तब मायने रखता है जब दो एक्सटेंशन एक ही टाइप पर वही सदस्य प्रदान करते हैं: कॉल **अस्पष्ट** हो जाती है और कंपाइल नहीं होती। नाम आपको संघर्ष को दो तरीकों से सुलझाने देता है। जब एक्सटेंशन अलग-अलग फ़ाइलों से आते हैं, तो आप इंपोर्ट में उनमें से एक को `show` या `hide` कर सकते हैं:

```dart
import 'package:loud/loud.dart';
import 'package:quiet/quiet.dart' hide Quiet;
```

या, कहीं भी, आप एक्सटेंशन को **स्पष्ट रूप से** लागू कर सकते हैं, मान को एक्सटेंशन के नाम में इस तरह लपेटकर जैसे वह एक कंस्ट्रक्टर हो:

```dart
print(Loud('hi').describe());
```

बिना नाम वाले एक्सटेंशन को छिपाया या स्पष्ट रूप से लागू नहीं किया जा सकता, इसलिए उस कोड में नाम वाले एक्सटेंशन को प्राथमिकता दें जिसे दूसरे इंपोर्ट करेंगे।

---

एक जेनेरिक एक्सटेंशन **फंक्शन** को पैरामीटर के रूप में ले सकता है, बिल्कुल `where` और `map` की तरह। फंक्शन टाइप एलिमेंट टाइप `T` के साथ लिखा जाता है, इसलिए कॉलबैक सही टाइप के एलिमेंट प्राप्त करता है:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```
