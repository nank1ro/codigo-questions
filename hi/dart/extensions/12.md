# --description--

एक एक्सटेंशन का नाम वैकल्पिक है। एक **बिना नाम वाला** एक्सटेंशन उसी तरह काम करता है, लेकिन वह केवल उस फ़ाइल में दिखाई देता है जो उसे घोषित करती है:

```dart
extension on int {
  bool get isTriple => this % 3 == 0;
}
```

एक **नाम** तब मायने रखता है जब दो एक्सटेंशन एक ही टाइप पर वही सदस्य प्रदान करते हैं: कॉल **अस्पष्ट** हो जाती है और कंपाइल नहीं होती। नाम आपको संघर्ष को दो तरीकों से सुलझाने देता है। जब एक्सटेंशन अलग-अलग फ़ाइलों से आते हैं, तो आप इंपोर्ट में उनमें से एक को `show` या `hide` कर सकते हैं:

```dart
import 'package:loud/loud.dart';
import 'package:quiet/quiet.dart' hide Quiet;
```

या, कहीं भी, आप एक्सटेंशन को **स्पष्ट रूप से** लागू कर सकते हैं, मान को एक्सटेंशन के नाम में इस तरह लपेटकर जैसे वह एक कंस्ट्रक्टर हो:

```dart
print(Loud('hi').describe());
```

बिना नाम वाले एक्सटेंशन को छिपाया या स्पष्ट रूप से लागू नहीं किया जा सकता, इसलिए उस कोड में नाम वाले एक्सटेंशन को प्राथमिकता दें जिसे दूसरे इंपोर्ट करेंगे।

# --instructions--

नीचे दोनों एक्सटेंशन `int` पर `describe` घोषित करते हैं, इसलिए `7.describe()` अस्पष्ट है। `main` को इस तरह पूरा करें कि पहली पंक्ति पर `Loud` को स्पष्ट रूप से लागू किया जाए और दूसरी पंक्ति पर `Quiet` को, ताकि प्रोग्राम `LOUD 7` और फिर `quiet 7` प्रिंट करे।
