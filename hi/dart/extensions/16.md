# --instructions--

`String` पर एक एक्सटेंशन `Words` लिखें जिसमें:
- `int` टाइप का एक गेटर `wordCount` हो, स्ट्रिंग में शब्दों की संख्या, जहाँ शब्द एक अकेले स्पेस से अलग किए जाते हैं
- `String` टाइप का एक गेटर `initials` हो, जो हर शब्द के पहले अक्षर से, अपरकेस में, बिना विभाजकों के जोड़कर बना हो

स्ट्रिंग में हमेशा कम से कम एक शब्द होता है और उसमें कभी शुरुआती, अंतिम या दोहरे स्पेस नहीं होते।

उदाहरण:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
