# --description--

क्या हो अगर एक एक्सटेंशन ऐसा सदस्य घोषित करे जो टाइप के पास **पहले से हो**? टाइप का अपना सदस्य हमेशा जीतता है: एक्सटेंशन सदस्यों पर केवल तब विचार किया जाता है जब टाइप स्वयं में उस नाम का कोई सदस्य नहीं हो। एक्सटेंशन सदस्य चुपचाप अनदेखा कर दिया जाता है, न कोई त्रुटि होती है और न कोई ओवरराइड।

```dart
extension Shorter on String {
  int get length => 0;
}

void main() {
  print('four'.length); // 4, String's own length is used
}
```

इसलिए एक एक्सटेंशन सदस्य जोड़ सकता है और कमियों को भर सकता है, लेकिन वह कभी भी मौजूदा सदस्यों के व्यवहार को **बदल** नहीं सकता।

यह प्रोग्राम क्या प्रिंट करता है?

```dart
extension Loud on String {
  String toUpperCase() => 'LOUD';
}

void main() {
  print('hi'.toUpperCase());
}
```

# --answers--

- `HI`
- `LOUD`
- कुछ नहीं, यह कंपाइल नहीं होता क्योंकि `toUpperCase` पहले से परिभाषित है
- कुछ नहीं, यह रन टाइम पर एक त्रुटि उत्पन्न करता है
