# --description--

Dart एक टाइप को यह परिभाषित करने देता है कि `+`, `*` या `==` जैसे ऑपरेटर उसके मानों के लिए क्या अर्थ रखते हैं, एक ऐसी मेथड के माध्यम से जिसका नाम कीवर्ड `operator` है और उसके बाद प्रतीक आता है। ऑपरेटर का दायाँ हिस्सा मेथड का पैरामीटर होता है:

```dart
extension Scaling on List<int> {
  List<int> operator *(int factor) => map((n) => n * factor).toList();
}

void main() {
  print([1, 2, 3] * 10); // [10, 20, 30]
}
```

चूँकि एक्सटेंशन ऑपरेटर घोषित कर सकते हैं, आप एक मौजूदा टाइप को एक नया ऑपरेटर दे सकते हैं जो उसके पास पहले से नहीं है। `String` के पास `+` और `*` हैं, लेकिन `-` नहीं, इसलिए एक एक्सटेंशन परिभाषित कर सकता है कि `'hello world' - 'o'` का क्या अर्थ है।

# --instructions--

`String` पर `Removing` नाम का एक एक्सटेंशन लिखें जिसमें एक ऑपरेटर `-` हो जो एक `String` पैरामीटर `part` लेता है और स्ट्रिंग को `part` की सभी घटनाओं को हटाकर लौटाता है। `replaceAll` का उपयोग करें।

उदाहरण:
```dart
print('hello world' - 'o'); // hell wrld
```
