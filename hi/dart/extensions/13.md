# --description--

एक जेनेरिक एक्सटेंशन **फंक्शन** को पैरामीटर के रूप में ले सकता है, बिल्कुल `where` और `map` की तरह। फंक्शन टाइप एलिमेंट टाइप `T` के साथ लिखा जाता है, इसलिए कॉलबैक सही टाइप के एलिमेंट प्राप्त करता है:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

एक्सटेंशन को इस तरह पूरा करें कि `countWhere` यह लौटाए कि दिए गए `test` फंक्शन को कितने एलिमेंट संतुष्ट करते हैं, ताकि प्रोग्राम `2` और फिर `1` प्रिंट करे।

```dart
extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
  print(['a', 'bb', 'c'].countWhere((s) => s.length > 1));
}
```
