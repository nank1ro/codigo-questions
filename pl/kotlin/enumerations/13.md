# --instructions--

Mając `enum class Color { RED, GREEN, BLUE }`, co robi `Color.valueOf("PURPLE")`?

# --answers--

- Rzuca `IllegalArgumentException`, ponieważ żadna wartość nie nazywa się `PURPLE`
- Zwraca `null`
- Zwraca `Color.RED`, pierwszą wartość
- Dodaje do enuma nową wartość `PURPLE`
