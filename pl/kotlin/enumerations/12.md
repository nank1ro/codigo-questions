# --instructions--

Mając `enum class Size { SMALL, MEDIUM, LARGE }`, co się stanie z poniższym kodem?

```kotlin
fun label(size: Size): String = when (size) {
    Size.SMALL -> "S"
    Size.MEDIUM -> "M"
}
```

# --answers--

- Nie kompiluje się: wyrażenie `when` po enumie musi obejmować wszystkie wartości albo mieć gałąź `else`
- Kompiluje się i zwraca `null` dla `LARGE`
- Kompiluje się i rzuca wyjątek w czasie wykonania dla `LARGE`
- Kompiluje się i automatycznie zwraca `"L"` dla `LARGE`
