# --description--

Where the `try` sits decides how much work a single bad value destroys. Wrap the **whole loop** and the first failure abandons the rest of the batch; wrap the **body** and only that one element is lost:

```kotlin
var total = 0
for (value in listOf("3", "x", "5")) {
    try {
        total += value.toInt()
    } catch (e: NumberFormatException) {
        // skip this one
    }
}
println(total) // 8
```
This pairs naturally with a validating function that throws: the function states one rule and refuses anything breaking it, and the loop decides that a refusal only costs one element.

# --instructions--

Write two functions.

`validate(text: String): Int` must return the number contained in `text`, or throw an `IllegalArgumentException` with the message `not a number: ` followed by the text.

`sumValid(values: List<String>): Int` must add up the values that `validate` accepts, skipping the ones that make it throw.

Example of function call:
```kotlin
println(sumValid(listOf("1", "x", "3")))
// prints 4
```

# --solutions--

```kotlin
fun validate(text: String): Int {
    val n = text.toIntOrNull()
    if (n == null) throw IllegalArgumentException("not a number: $text")
    return n
}

fun sumValid(values: List<String>): Int {
    var total = 0
    for (value in values) {
        try {
            total += validate(value)
        } catch (e: IllegalArgumentException) {
            // skip this one
        }
    }
    return total
}
```
