# --description--

`String` to sekwencja znaków zapisana w cudzysłowach.
Właściwość `length` mówi, ile znaków zawiera ciąg znaków, łącznie ze spacjami:
```kotlin
val greeting = "Hello world"
println(greeting.length) // 11
println("".length)       // 0
```
