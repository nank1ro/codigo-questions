# --description--

`replace(old, new)` zwraca kopię ciągu znaków, w której **każde** wystąpienie `old` jest zastąpione przez `new`:
```kotlin
val text = "a-b-c"
println(text.replace("-", "+")) // a+b+c
println(text)                   // a-b-c
```
