# --instructions--

Co wypisuje ten program?

```kotlin
fun main() {
    val words = mutableListOf("a")
    val first = words.apply { add("b") }
    val second = words.run { size }
    println("$first $second")
}
```

# --answers--

- `[a, b] 2`, ponieważ `apply` zwraca listę, a `run` zwraca wynik bloku
- `true 2`, ponieważ `apply` zwraca wynik `add`
- `[a, b] [a, b]`, ponieważ oba zwracają listę
- `2 [a, b]`, ponieważ `apply` zwraca rozmiar, a `run` zwraca listę
