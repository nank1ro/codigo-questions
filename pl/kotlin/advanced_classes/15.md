# --instructions--

Co dzieje się z tym kodem?

```kotlin
class Outer(val name: String) {
    class Nested {
        fun show(): String = name
    }
}
```

# --answers--

- Nie kompiluje się: klasa zagnieżdżona nie widzi składowych klasy zewnętrznej, `Nested` musi być `inner`
- Kompiluje się, a `show()` zwraca `name` instancji zewnętrznej
- Kompiluje się, a `show()` zawsze zwraca pusty łańcuch znaków
- Nie kompiluje się: Kotlin nie pozwala na klasę wewnątrz innej klasy
