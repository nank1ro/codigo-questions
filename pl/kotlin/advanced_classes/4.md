# --description--

Wygenerowane składowe biorą pod uwagę tylko właściwości zadeklarowane w **konstruktorze głównym**. Właściwość zadeklarowana w **ciele** klasy jest zwykłą właściwością: nie należy do `toString()`, `equals()`, `hashCode()` ani `copy()`.

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

val a = Item("nail")
a.quantity = 5
println(a) // Item(name=nail)
```

Łatwo o tym zapomnieć, więc w konstruktorze głównym umieszczaj wszystko, co identyfikuje obiekt, a stan pochodny lub tymczasowy trzymaj w ciele klasy.

# --instructions--

Co wypisuje ten program?

```kotlin
data class Item(val name: String) {
    var quantity: Int = 0
}

fun main() {
    val a = Item("nail")
    a.quantity = 5
    val b = Item("nail")
    b.quantity = 9
    println(a == b)
}
```

# --answers--

- `true`, ponieważ wygenerowane `equals()` porównuje tylko `name`
- `false`, ponieważ `quantity` się różni
- `Item(name=nail, quantity=5)`
- Nie kompiluje się: data class nie może deklarować właściwości w swoim ciele
