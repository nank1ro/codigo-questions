# --description--

Niektóre funkcje przyjmują **lambdę z odbiornikiem**: wewnątrz lambdy `this` to konkretny obiekt, więc można wywoływać jego składowe bezpośrednio, bez nazywania go.
`buildString` to częsty przykład: wewnątrz jej lambdy `this` to `StringBuilder`, więc `append` można wywołać, jakby była lokalną funkcją:
```kotlin
val text = buildString {
    append("Hello")
    append(", ")
    append("world")
}
println(text) // Hello, world
```
`buildString` zwraca końcowy ciąg znaków. To wygodna alternatywa dla łączenia za pomocą `+` w pętli.

# --instructions--

Napisz funkcję `bracketed(items: List<String>): String`, która zwraca każdy element owinięty w nawiasy kwadratowe, jeden po drugim, używając `buildString`.

Przykład: `bracketed(listOf("a", "b"))` zwraca `"[a][b]"`.

# --asserts--

`bracketed(listOf("a", "b"))` musi zwracać `"[a][b]"`

```kotlin
    tryCatch(bracketed(listOf("a", "b")) == "[a][b]")
```

`bracketed(listOf("kotlin"))` musi zwracać `"[kotlin]"`

```kotlin
    tryCatch(bracketed(listOf("kotlin")) == "[kotlin]")
```

`bracketed(listOf())` musi zwracać pusty ciąg znaków

```kotlin
    tryCatch(bracketed(listOf()) == "")
```

`bracketed(listOf("x", "y", "z"))` musi zwracać `"[x][y][z]"`

```kotlin
    tryCatch(bracketed(listOf("x", "y", "z")) == "[x][y][z]")
```

```kotlin
fun bracketed(items: List<String>): String {
    return buildString {
        items.forEach { append("[").append(it).append("]") }
    }
}
```
