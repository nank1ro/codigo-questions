# --description--

Możesz iterować po mapie za pomocą `for`, rozkładając każdy wpis na klucz i wartość:
```kotlin
val ages = mapOf("Alice" to 30, "Bob" to 25)
for ((name, age) in ages) {
    println("$name is $age")
}
// prints
// Alice is 30
// Bob is 25
```
Nawiasy `(name, age)` dzielą każdy wpis na dwie zmienne. Wpisy są odwiedzane w kolejności wstawiania.

# --instructions--

Napisz funkcję `report(stock: Map<String, Int>): List<String>`, która zwraca listę z jednym ciągiem znaków na wpis, sformatowanym jako `"item: count"`, w kolejności, w jakiej wpisy pojawiają się w mapie.

Przykład wywołania funkcji:
```kotlin
println(report(mapOf("apple" to 3, "pear" to 0)))
// prints [apple: 3, pear: 0]
```

```kotlin
fun report(stock: Map<String, Int>): List<String> {
    val lines = mutableListOf<String>()
    for ((item, count) in stock) {
        lines.add("$item: $count")
    }
    return lines
}
```
