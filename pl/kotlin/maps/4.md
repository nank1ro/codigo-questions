# --description--

Mapa utworzona za pomocą `mapOf` jest tylko do odczytu. Aby dodać lub zmienić wpisy, użyj `mutableMapOf`, która zwraca `MutableMap`:
```kotlin
val ages = mutableMapOf("Alice" to 30)
ages["Bob"] = 25   // adds a new entry
ages["Alice"] = 31 // updates the existing one
println(ages)
// prints {Alice=31, Bob=25}
```
Przypisanie za pomocą `map[key] = value` dodaje parę, gdy klucz jest nowy, i zastępuje wartość, gdy klucz już istnieje. Możesz też wywołać `ages.put("Bob", 25)`, co robi to samo.

# --asserts--

Po `setGrade(grades, "Ben", 90)` mapa musi zawierać `Ben` z oceną `90`

```kotlin
    val grades = mutableMapOf("Ann" to 80)
    setGrade(grades, "Ben", 90)
    tryCatch(grades["Ben"] == 90)
```

Po `setGrade(grades, "Ann", 95)` ocena `Ann` musi zostać zastąpiona przez `95`

```kotlin
    setGrade(grades, "Ann", 95)
    tryCatch(grades["Ann"] == 95)
```

Mapa musi być równa `{Ann=95, Ben=90}`

```kotlin
    tryCatch(grades == mapOf("Ann" to 95, "Ben" to 90))
```
