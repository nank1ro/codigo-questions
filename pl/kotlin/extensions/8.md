# --description--

Wewnątrz rozszerzenia z nullowalnym odbiorcą możesz też użyć bezpiecznego wywołania `this?.`, aby sięgnąć po składowe wartości tylko wtedy, gdy nie jest ona `null`. Biblioteka standardowa korzysta z tego samego pomysłu w funkcjach takich jak `isNullOrEmpty()`:
```kotlin
fun String?.firstOrQuestion(): Char {
    return this?.firstOrNull() ?: '?'
}
val text: String? = null
println(text.firstOrQuestion())    // ?
println("Kotlin".firstOrQuestion()) // K
```

# --asserts--

`"Kotlin".lengthOrZero()` musi zwracać `6`

```kotlin
    tryCatch("Kotlin".lengthOrZero() == 6)
```

`"".lengthOrZero()` musi zwracać `0`

```kotlin
    tryCatch("".lengthOrZero() == 0)
```

Wywołana na `String?` zawierającym `null`, musi zwracać `0`

```kotlin
    val missing: String? = null
    tryCatch(missing.lengthOrZero() == 0)
```

Wywołana na `String?` zawierającym `"hi"`, musi zwracać `2`

```kotlin
    val present: String? = "hi"
    tryCatch(present.lengthOrZero() == 2)
```
