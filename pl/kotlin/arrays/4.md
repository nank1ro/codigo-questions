# --description--

Nawet gdy tablica jest zadeklarowana za pomocą `val`, jej **elementy** można zastąpić, przypisując wartość do indeksu:
```kotlin
val nums = intArrayOf(1, 2, 3)
nums[0] = 10 // nums is now [10, 2, 3]
```
Aby odwiedzić każdy element, możesz użyć pętli `for` lub `forEach`:
```kotlin
for (n in nums) {
    println(n)
}
nums.forEach { println(it) }
```
Zwróć uwagę, że `n` i `it` to kopie wartości tylko do odczytu i nie można im nic ponownie przypisać, więc aby zmodyfikować elementy, potrzebujesz ich indeksu.

# --asserts--

Po `doubleAll` tablica `[1, 2, 3]` musi stać się `[2, 4, 6]`

```kotlin
    val a1 = intArrayOf(1, 2, 3)
    doubleAll(a1)
    tryCatch(a1.contentEquals(intArrayOf(2, 4, 6)))
```

Po `doubleAll` tablica `[0, -5]` musi stać się `[0, -10]`

```kotlin
    val a2 = intArrayOf(0, -5)
    doubleAll(a2)
    tryCatch(a2.contentEquals(intArrayOf(0, -10)))
```

`doubleAll` nie może zawieść na pustej tablicy

```kotlin
    val a3 = intArrayOf()
    doubleAll(a3)
    tryCatch(a3.size == 0)
```

fun doubleAll(numbers: IntArray) {
    for (i in numbers.indices) {
        numbers[i] = numbers[i] * 2
    }
}
