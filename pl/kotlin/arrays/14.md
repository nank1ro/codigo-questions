# --description--

Ponieważ tablice mają stały rozmiar, wzięcie części tablicy oznacza utworzenie nowej tablicy:
- `copyOf()` kopiuje całą tablicę, `copyOf(n)` kopiuje pierwsze `n` elementów
- `copyOfRange(from, to)` kopiuje elementy od indeksu `from` do `to` **wyłącznie**
- `sliceArray(range)` kopiuje elementy pod indeksami zakresu, z obydwoma końcami włącznie
```kotlin
val nums = intArrayOf(10, 20, 30, 40)
println(nums.copyOfRange(1, 3).contentToString()) // [20, 30]
println(nums.sliceArray(0..1).contentToString())  // [10, 20]
```

# --instructions--

Napisz funkcję `firstHalf(numbers: IntArray): IntArray`, która zwraca nową tablicę z pierwszą połową `numbers`. Gdy rozmiar jest nieparzysty, środkowy element zostaje pominięty.

Przykład: `firstHalf(intArrayOf(1, 2, 3, 4, 5))` zwraca `[1, 2]`.

# --asserts--

`firstHalf(intArrayOf(1, 2, 3, 4))` musi zwrócić `[1, 2]`

```kotlin
    tryCatch(firstHalf(intArrayOf(1, 2, 3, 4)).contentEquals(intArrayOf(1, 2)))
```

`firstHalf(intArrayOf(1, 2, 3, 4, 5))` musi zwrócić `[1, 2]`

```kotlin
    tryCatch(firstHalf(intArrayOf(1, 2, 3, 4, 5)).contentEquals(intArrayOf(1, 2)))
```

`firstHalf(intArrayOf(7))` musi zwrócić pustą tablicę

```kotlin
    tryCatch(firstHalf(intArrayOf(7)).size == 0)
```

Oryginalna tablica nie może zostać zmodyfikowana

```kotlin
    val src = intArrayOf(5, 6, 7, 8)
    firstHalf(src)
    tryCatch(src.contentEquals(intArrayOf(5, 6, 7, 8)))
```
