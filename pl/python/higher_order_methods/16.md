# --instructions--

Napisz dekorator `memoize` dla funkcji jednego argumentu: musi zapisywać każdy wynik w słowniku wewnątrz domknięcia, tak aby ponowne wywołanie udekorowanej funkcji z tym samym argumentem zwracało zapamiętany wynik bez wywoływania oryginalnej funkcji

# --asserts--

Udekorowana funkcja musi zwracać te same wyniki co oryginał

```python
    def test_1(self):
        square = memoize(lambda n: n * n)
        self.assertEqual(square(4), 16, "--err-t1--")
        self.assertEqual(square(5), 25, "--err-t1--")
```

Powtórne wywołanie nie może ponownie uruchamiać oryginalnej funkcji

```python
    def test_2(self):
        calls = []
        @memoize
        def double(n):
            calls.append(n)
            return n * 2
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(3), 6, "--err-t2--")
        self.assertEqual(double(7), 14, "--err-t2--")
        self.assertEqual(calls, [3, 7], "--err-t2--")
```

Każda udekorowana funkcja musi mieć własny cache

```python
    def test_3(self):
        plus = memoize(lambda n: n + 1)
        minus = memoize(lambda n: n - 1)
        self.assertEqual(plus(1), 2, "--err-t3--")
        self.assertEqual(minus(1), 0, "--err-t3--")
```

# --solutions--

```python
def memoize(func):
    cache = {}
    def wrapper(arg):
        if arg not in cache:
            cache[arg] = func(arg)
        return cache[arg]
    return wrapper
```
