# --description--

Jest pewna pułapka przy tworzeniu **pustego zbioru**.
Nawiasy klamrowe to również składnia słowników, więc `{}` tworzy pusty **słownik**, a nie zbiór:
```python
empty = {}
print(type(empty))  # <class 'dict'>
```
Aby otrzymać pusty zbiór, musisz wywołać `set()` bez argumentów:
```python
empty = set()
print(type(empty))  # <class 'set'>
print(len(empty))   # 0
```

# --instructions--

Co wypisze ten kod?
```python
empty = {}
print(type(empty))
```

# --answers--

- `<class 'dict'>`, ponieważ `{}` tworzy pusty słownik
- `<class 'set'>`, ponieważ nawiasy klamrowe tworzą zbiór
- `<class 'NoneType'>`, ponieważ zbiór nie ma elementów
- Błąd `SyntaxError`, ponieważ nawiasy klamrowe muszą zawierać przynajmniej jeden element
