# --description--

**Przecięcie** dwóch zbiorów zawiera tylko elementy obecne w **obu**.
Użyj operatora `&` lub metody `intersection()`:
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)               # {2, 3}
print(a.intersection(b))   # {2, 3}
```
Jeśli zbiory nie mają nic wspólnego, wynikiem jest pusty zbiór.
