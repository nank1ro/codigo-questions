# --description--

Do bloku `if` należy tylko `print` z wcięciem znajdujący się bezpośrednio po nim; linia zapisana z takim samym wcięciem jak sam `if` już nie.

# --instructions--

Która instrukcja print jest częścią bloku kodu instrukcji?
```python
online = False
if (online):
    print("Hello User!")
print("Hello World")
```

# --answers--

- print("Hello User!")
- print(Hello User!)
- print("Hello World")
