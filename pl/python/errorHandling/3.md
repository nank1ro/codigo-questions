# --description--

Wyjątek, którego nie dopasuje żaden blok `except`, wędruje dalej na zewnątrz: poza wiersz, poza funkcję, która go wykonała, poza jej wywołującego i tak dalej. Jeśli nic go nie przechwyci przed szczytem programu, Python wypisuje traceback, a proces kończy się niezerowym kodem wyjścia. Wiersze po instrukcji, która zawiodła, nigdy się nie wykonują.

# --instructions--

Co się stanie, gdy ten kod zostanie uruchomiony?
```python
def sizes(values):
    print("start")
    print(len(values))
    print("end")

sizes(None)
print("after")
```

# --answers--

- Wypisze `start`, potem traceback kończący się `TypeError`, a ani `end`, ani `after` nie zostaną wypisane, ponieważ nieprzechwycony wyjątek zatrzymuje program
- Wypisze `start`, `end` i `after`, ponieważ Python pomija tylko wiersz, który zawiódł
- Wypisze `start` i `after`, ponieważ wyjątek zatrzymuje `sizes`, ale program kontynuuje działanie
- Wypisze `start` i `0`, ponieważ `len(None)` wynosi `0`
