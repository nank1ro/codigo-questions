# --description--

`except:` bez żadnego typu po nim to **goły except**. Pasuje do wszystkiego, łącznie z wyjątkami, które nie mają nic wspólnego z chronioną operacją, więc zasada jest prosta: zawsze wymieniaj typy, z których naprawdę potrafisz się podnieść.

# --instructions--

Dlaczego ten kod powinien wymieniać konkretny typ wyjątku zamiast używać gołego `except:`?
```python
try:
    total = int(amout)
except:
    total = 0
```

# --answers--

- Ponieważ goły `except:` przechwytuje także niepowiązane awarie, na przykład `NameError` spowodowany literówką `amout`, więc prawdziwy błąd po cichu zamienia się w `total = 0`
- Ponieważ goły `except:` jest wolniejszy, gdyż Python musi porównać wyjątek z każdą klasą wbudowaną
- Ponieważ goły `except:` działa tylko na poziomie modułu i zgłasza `SyntaxError` wewnątrz funkcji
- Ponieważ goły `except:` nic nie przechwytuje, więc wyjątek jest zgłaszany ponownie zaraz po zakończeniu bloku
