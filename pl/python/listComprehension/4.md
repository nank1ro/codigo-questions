# --description--

Warunek filtrujący może być dowolnym wyrażeniem zwracającym wartość logiczną, w tym wywołaniami funkcji, takimi jak `len()`:
```python
words = ["a", "bee", "cat"]
short = [w for w in words if len(w) < 3]
print(short)  # ['a']
```
