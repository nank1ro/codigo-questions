# --description--

Nawiasy klamrowe **bez** części `key: value` dają **set comprehension**.
Set to nieuporządkowana kolekcja, która przechowuje tylko unikalne wartości, więc duplikaty znikają automatycznie:
```python
nums = [1, 2, 2, 3, 3, 3]
unique = {n for n in nums}
print(unique)  # {1, 2, 3}
```
