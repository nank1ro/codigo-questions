# --description--

Ten sam pomysł działa dla słowników: **dict comprehension** używa nawiasów klamrowych i wyrażenia `key: value`:
```python
names = ["ana", "bob"]
lengths = {name: len(name) for name in names}
print(lengths)  # {'ana': 3, 'bob': 3}
```
