# --description--

Wewnętrzne `for` może użyć zmiennej z zewnętrznego.
To klasyczny sposób na **spłaszczenie** listy list do jednej listy:
```python
matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)  # [1, 2, 3, 4]
```
Funkcja `sum()` sumuje wtedy wszystkie liczby z listy.
