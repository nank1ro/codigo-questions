# --description--

Comprehension może mieć **więcej niż jedno `for`**.
Działają jak zagnieżdżone pętle: pierwsze `for` jest pętlą zewnętrzną, drugie — wewnętrzną.
```python
pairs = [a + b for a in ["x", "y"] for b in ["1", "2"]]
print(pairs)  # ['x1', 'x2', 'y1', 'y2']
```
