# --description--

Wewnątrz comprehension możesz użyć dowolnej zmiennej zdefiniowanej wcześniej, na przykład jako granicy `range()`.

# --instructions--

Posortuj elementy, aby wypisać wielokrotności 7 poniżej `limit`

# --answers--

```python
limit = 20
```

```python
multiples = [n for n in range(1, limit) if n % 7 == 0]
```

```python
print(multiples)
```

# --solutions--
