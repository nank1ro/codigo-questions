# --description--

Dwie pozycje `if` łatwo pomylić, więc je rozróżnij:
```python
values = [n if n > 0 else 0 for n in nums]  # if-else przed for: wybiera wartość, else wymagany
positives = [n for n in nums if n > 0]      # if po for: filtruje, else niedozwolony
```
Umieszczenie `else` po filtrującym `if` to błąd składni.

# --instructions--

Jaki jest __problem__ z tym fragmentem kodu?
```python
nums = [3, -1, 4]
result = [n for n in nums if n > 0 else 0]
```

# --answers--

- Filtr `if` po `for` nie może mieć `else`: `if-else` musi znajdować się przed `for`
- List comprehension nie może zawierać warunku
- `nums` zawiera liczbę ujemną, co jest niedozwolone
- `else` musi zostać zastąpione przez `elif`
