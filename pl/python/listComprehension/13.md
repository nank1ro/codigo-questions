# --description--

Możesz też iterować po **słowniku**.
Dzięki `.items()` część `for` rozpakowuje każdą parę na dwie zmienne, klucz i wartość:
```python
ages = {"ana": 31, "bob": 25}
lines = [f"{name} is {age}" for name, age in ages.items()]
print(lines)  # ['ana is 31', 'bob is 25']
```
