# --description--

`and` i `or` nie zawsze zwracają `True` lub `False`: zwracają jeden ze swoich **argumentów**. `a and b` zwraca `a`, jeśli jest fałszywe, a w przeciwnym razie `b`; `a or b` zwraca `a`, jeśli jest prawdziwe, a w przeciwnym razie `b`:
```python
print(0 and "x")       # 0
print(3 and "x")       # x
print("" or "none")    # none
print("hi" or "none")  # hi
```
Wynik jest prawdziwy lub fałszywy dokładnie wtedy, gdy jest takie całe wyrażenie, dlatego `if a and b:` nadal działa. Częstym zastosowaniem jest wartość domyślna: `name = user_input or "guest"`.

# --instructions--

Co wyświetla ten kod?
```python
print(0 or 5, 3 and 0, "x" and "y")
```

# --answers--

- `5 0 y`, ponieważ `or` zwraca pierwszy prawdziwy argument, a `and` pierwszy fałszywy, albo ostatni argument, gdy takiego nie ma
- `True False True`, ponieważ operatory logiczne zawsze dają wartość logiczną
- `0 3 x`, ponieważ `and` i `or` zawsze zwracają swój pierwszy argument
- `5 3 y`, ponieważ oba operatory zwracają prawdziwy argument
