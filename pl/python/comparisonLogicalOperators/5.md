# --description--

Gdy `not`, `and` i `or` występują w jednym wyrażeniu, Python stosuje najpierw `not`, potem `and`, a na końcu `or`. Zatem `a or b and c` oznacza `a or (b and c)`, a `not a == b` oznacza `not (a == b)`:
```python
x = 6
print(x == 6 or x < 10 and x > 100)  # True: x == 6 or (False)
print(not x == 6)                    # False
```
Gdy zamierzone jest inne grupowanie, dodaj nawiasy; czynią one także wyrażenie łatwiejszym do czytania.

# --instructions--

Co wyświetla ten kod?
```python
x = 3
print(x == 3 or x > 10 and x < 0)
```

# --answers--

- `True`, ponieważ `and` jest stosowane przed `or`, więc wyrażenie czyta się jako `x == 3 or (x > 10 and x < 0)`
- `False`, ponieważ operatory są stosowane od lewej do prawej: `(x == 3 or x > 10) and x < 0`
- `False`, ponieważ `x < 0` jest fałszem, a każdy warunek w wyrażeniu musi być spełniony
- `SyntaxError`, ponieważ `and` i `or` nie mogą być mieszane bez nawiasów
