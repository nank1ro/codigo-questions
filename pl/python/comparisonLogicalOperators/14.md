# --instructions--

Co wyświetla ten kod?
```python
a = [1, 2]
b = [1, 2]
c = a
c.append(3)
print(a == b, a is c, a)
```

# --answers--

- `False True [1, 2, 3]`, ponieważ `c` to inna nazwa tej samej listy co `a`, więc dodanie przez `c` zmienia `a` i sprawia, że różni się od `b`
- `True True [1, 2]`, ponieważ `c = a` kopiuje listę, więc `a` pozostaje niezmienione
- `True False [1, 2, 3]`, ponieważ `is` porównuje wartości, a `==` porównuje tożsamość
- `False False [1, 2, 3]`, ponieważ `append` tworzy nową listę, więc `c` nie odnosi się już do `a`
