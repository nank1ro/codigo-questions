# --instructions--

Uporządkuj elementy, aby zdefiniować słownik `users` i funkcję `can_login`, która używa `name in users` do zabezpieczenia odczytu, a następnie wyświetl wynik dla Ady z poprawnym hasłem i dla Grace, która nie jest zarejestrowana, dając wynik `True`, `False`

# --answers--

```python
users = {"ada": "secret", "linus": "tux"}
```

```python
def can_login(name, password):
    return name in users and users[name] == password
```

```python
print(can_login("ada", "secret"))
```

```python
print(can_login("grace", "secret"))
```
