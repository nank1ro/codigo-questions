# --description--

Ponieważ `if value:` stosuje już wartość logiczną, porównywanie z `== True` lub `== False` jest zbędne, a nawet może być błędne: `2 == True` to `False`, a mimo to `2` jest prawdziwe. Sprawdzaj samą wartość:
```python
values = [0, 1, "", "a", None, [], [0]]
for value in values:
    if value:
        print(value)  # 1, a, [0]
```

# --instructions--

Napisz funkcję `count_truthy(values)`, która zwraca, ile elementów listy `values` jest prawdziwych

    def test_1(self):

`count_truthy([])` musi zwrócić `0`

```python
    def test_2(self):

```

Wartości prawdziwe, które nie są `True`, także muszą być policzone

```python
    def test_3(self):
        self.assertEqual(count_truthy([2, "no", [None], 0.0, True]), 4, "--err-t3--")
```

```python
def count_truthy(values):
    count = 0
    for value in values:
        if value:
            count += 1
    return count
```
