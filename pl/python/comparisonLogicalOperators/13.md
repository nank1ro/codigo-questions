# --instructions--

Napisz funkcję `is_vowel(ch)`, która zwraca `True`, gdy `ch` to dokładnie jeden znak i jest on samogłoską (`a`, `e`, `i`, `o`, `u`) małą lub wielką, a `False` dla każdego innego łańcucha, w tym pustego

# --before-asserts--

import unittest

class CodigoTests(unittest.TestCase):

# --asserts--

`is_vowel("a")` i `is_vowel("E")` muszą zwrócić `True`

```python
    def test_1(self):
        self.assertIs(is_vowel("a"), True, "--err-t1--")
        self.assertIs(is_vowel("E"), True, "--err-t1--")
```

`is_vowel("b")` i `is_vowel("y")` muszą zwrócić `False`

```python
    def test_2(self):
        self.assertIs(is_vowel("b"), False, "--err-t2--")
        self.assertIs(is_vowel("y"), False, "--err-t2--")
```

Łańcuchy, które nie są pojedynczym znakiem, muszą zwrócić `False`

```python
    def test_3(self):
        self.assertIs(is_vowel(""), False, "--err-t3--")
        self.assertIs(is_vowel("ae"), False, "--err-t3--")
```
