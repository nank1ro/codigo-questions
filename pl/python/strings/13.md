# --description--

`find(sub)` zwraca **indeks** pierwszego wystąpienia `sub`, albo `-1`, jeśli nie zostanie znalezione:
```python
text = "hello world"
print(text.find("o"))  # 4
print(text.find("z"))  # -1
```
`count(sub)` zwraca **ile razy** `sub` występuje:
```python
print(text.count("o"))   # 2
print(text.count("ll"))  # 1
```

# --instructions--

Zapisz w `position` indeks pierwszego `o` w `text`, w `missing` wynik wyszukiwania `z`, a w `total` ile razy `text` zawiera `o`
