# --description--

Już wiesz, że `+` łączy dwa ciągi znaków (**konkatenacja**).
Operator `*` **powtarza** ciąg znaków określoną liczbę razy:
```python
print("ab" * 3)        # ababab
print("=" * 10)        # ==========
print("Hi" + "!" * 3)  # Hi!!!
```
Powtarzanie to szybki sposób na rysowanie separatorów i prostych wzorów.
