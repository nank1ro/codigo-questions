# --description--

Operator `in` sprawdza, czy jeden ciąg znaków **zawiera** inny.
Zwraca `True` lub `False`, więc naturalnie pasuje do wnętrza `if`:
```python
email = "ada@mail.com"
print("@" in email)      # True
print("xyz" in email)    # False
if " " in email:
    print("No spaces allowed")
```
`not in` sprawdza sytuację przeciwną.
