# --description--

Wbudowana funkcja `len()` zwraca **długość** ciągu znaków, czyli liczbę zawartych w nim znaków.
Spacje i znaki interpunkcyjne również liczą się jako znaki:
```python
print(len("hello"))     # 5
print(len("hi there"))  # 8
print(len(""))          # 0
```
