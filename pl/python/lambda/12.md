# --description--

Lambdy nie ograniczają się do funkcji wbudowanych: **twoje własne funkcje** też mogą przyjmować funkcję jako parametr i ją wywoływać.
```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x * 10, 3))  # 30
```

# --instructions--

Zdefiniuj funkcję `apply_twice(func, value)`, która stosuje `func` do `value` dwa razy i zwraca wynik.
Następnie zapisz w `result` wartość `apply_twice` wywołanej z lambdą dodającą `3` i wartością `10`
