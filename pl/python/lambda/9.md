# --description--

`map()` stosuje funkcję do **każdego elementu** listy.
Zwraca specjalny _obiekt map_, więc opakuj go w `list()`, aby zobaczyć wartości:
```python
nums = [1, 2, 3]
doubled = list(map(lambda n: n * 2, nums))
print(doubled)  # [2, 4, 6]
```
