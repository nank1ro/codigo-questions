# --description--

Zauważ, że ciało lambdy nie ma słowa kluczowego `return`.
Ciało to **pojedyncze wyrażenie**, którego wartość jest zwracana automatycznie:
```python
square = lambda n: n * n
print(square(3))  # 9
```
