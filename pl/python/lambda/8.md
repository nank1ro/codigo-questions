# --description--

Lambda użyta w `key` może wybrać dowolną część elementu.
Dla listy list, `lambda p: p[1]` sortuje według drugiego elementu każdej wewnętrznej listy.

# --instructions--

Posortuj elementy, aby wypisać osoby od najmłodszej do najstarszej

# --answers--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
```

```python
youngest_first = sorted(people, key=lambda p: p[1])
```

```python
for p in youngest_first:
```

```python
    print(p[0], p[1])
```

# --solutions--

```python
people = [["Ana", 31], ["Bo", 25], ["Cy", 40]]
youngest_first = sorted(people, key=lambda p: p[1])
for p in youngest_first:
    print(p[0], p[1])
```

# --output--

Bo 25
Ana 31
Cy 40
