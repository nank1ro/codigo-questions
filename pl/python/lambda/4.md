# --description--

Ponieważ ciało musi być pojedynczym wyrażeniem, lambda **nie może zawierać instrukcji**.
Żadnego `return`, żadnych bloków `if`, pętli ani przypisań:
```python
# SyntaxError
increment = lambda x: return x + 1
```
Jeśli potrzebujesz czegoś z tego, napisz zwykłą funkcję `def`.

# --instructions--

Jaki jest __problem__ z tym fragmentem kodu?
```python
increment = lambda x: return x + 1
print(increment(5))
```

# --answers--

- Ciało lambdy jest wyrażeniem, nie może zawierać return
- Lambda nie może być zapisana w zmiennej
- Lambda nie może być wywołana z nawiasami
- Lambda potrzebuje co najmniej dwóch parametrów
