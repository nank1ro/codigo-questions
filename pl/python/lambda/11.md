# --description--

Wypisanie obiektu `map` bezpośrednio nie pokazuje jego wartości: otrzymasz coś w rodzaju `<map object at 0x7f2b1c>`.
Dopiero `list()` (albo pętla) zamienia go w oczekiwane wartości.

# --instructions--

Co wypisze ten kod?
```python
nums = [1, 2, 3]
print(list(map(lambda x: x + 1, nums)))
```
