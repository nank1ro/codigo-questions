# --description--

Jest jeszcze trzeci punkt wejścia, `re.fullmatch`, który kończy się sukcesem tylko wtedy, gdy wzorzec pokrywa **cały** tekst od pierwszego do ostatniego znaku. To właściwe narzędzie do walidacji:
```python
import re

print(bool(re.fullmatch(r"\d+", "2026")))    # True
print(bool(re.fullmatch(r"\d+", "2026!")))   # False
```

Te trzy funkcje różnią się więc tylko tym, gdzie wzorzec może się znajdować: `re.match` na początku tekstu, `re.search` gdziekolwiek w tekście, a `re.fullmatch` na całym tekście.

# --instructions--

Co wypisuje ten kod?
```python
import re

print(bool(re.match(r"\d+", "12abc")), bool(re.search(r"\d+", "12abc")), bool(re.fullmatch(r"\d+", "12abc")))
```

# --answers--

- `True True False`, ponieważ cyfry są na początku i wewnątrz tekstu, ale nie pokrywają całego tekstu
- `True True True`, ponieważ wszystkie trzy funkcje kończą się sukcesem, gdy tylko wzorzec zostanie znaleziony gdziekolwiek
- `False True False`, ponieważ `re.match` wymaga, aby wzorzec pokrywał cały tekst
- `True False False`, ponieważ `re.search` patrzy tylko za pierwszy znak
