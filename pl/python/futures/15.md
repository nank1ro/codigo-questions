# --solutions--

```python
import asyncio
async def load(name):
    await asyncio.sleep(0.01)
    if name == "":
        raise ValueError("empty name")
    return f"loaded {name}"
async def main():
    print(await load("config"))
    try:
        await load("")
    except ValueError as e:
        print(e)
asyncio.run(main())
```

# --output--

loaded config
empty name
