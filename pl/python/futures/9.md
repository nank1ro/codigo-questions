# --description--

Mały program asynchroniczny ma ustalony kształt: zaimportuj `asyncio`, zdefiniuj funkcje asynchroniczne, zdefiniuj korutynę `main`, która używa na nich `await`, a na koniec wywołaj raz `asyncio.run(main())`.

# --instructions--

Ułóż elementy, aby zbudować program, który zaczyna się od importu, definiuje `download` przed `main`, wykonuje dwa pobrania równolegle za pomocą `asyncio.gather` i wypisuje wyniki, tworząc wynik `['report.pdf', 'data.csv']`

# --answers--

```python
import asyncio
```

```python
async def download(name):
    await asyncio.sleep(0.01)
    return name
```

```python
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
```

```python
asyncio.run(main())
```

# --solutions--

```python
import asyncio
async def download(name):
    await asyncio.sleep(0.01)
    return name
async def main():
    files = await asyncio.gather(download("report.pdf"), download("data.csv"))
    print(files)
asyncio.run(main())
```

# --output--

['report.pdf', 'data.csv']
