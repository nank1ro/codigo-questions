# --description--

Tekst pochodzący z formularzy, plików czy adresów URL jest zawsze ciągiem znaków, nawet gdy reprezentuje liczbę lub wartość logiczną. Przekształcenie go z powrotem w odpowiedni typ łączy to, co już widziałeś: porównaj z `"true"` i `"false"` dla wartości logicznych, a dla liczb wypróbuj `Number()`, pamiętając, że `Number("")` to `0` i że `Number.isNaN` mówi ci, kiedy konwersja się nie powiodła:
```javascript
console.log(Number("3.5"), Number(""), Number("12px"));
// prints 3.5 0 NaN
```
Gdy nic nie pasuje, zostaw ciąg znaków taki, jaki jest.

# --asserts--

`parseValue("42")` musi zwrócić liczbę `42`.

```javascript

```

`parseValue("3.5")` musi zwrócić `3.5`.

```javascript

```

`parseValue("true")` i `parseValue("false")` muszą zwrócić wartości logiczne `true` i `false`.

```javascript
tryCatch(parseValue("true") === true && parseValue("false") === false);
```

`parseValue("Ana")` musi zwrócić `"Ana"`.

```javascript
tryCatch(parseValue("Ana") === "Ana");
```

`parseValue("12px")` musi zwrócić `"12px"`, ponieważ cały tekst nie jest liczbą.

```javascript
tryCatch(parseValue("12px") === "12px");
```

`parseValue("")` musi zwrócić `""`, a nie `0`.

```javascript
tryCatch(parseValue("") === "");
```

# --solutions--

```javascript
function parseValue(text) {
  if (text === "true") {
    return true;
  }
  if (text === "false") {
    return false;
  }
  if (text !== "" && !Number.isNaN(Number(text))) {
    return Number(text);
  }
  return text;
}
```
