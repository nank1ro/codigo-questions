# --description--

Gdy JavaScript potrzebuje wartości logicznej, na przykład w warunku `if` albo w `Boolean(value)`, konwertuje wartość. Tylko osiem wartości staje się `false`; nazywa się je **falsy**:
`false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` oraz `NaN`.
**Wszystko inne jest truthy**, w tym niektóre wartości, które wyglądają na puste:
```javascript
console.log(Boolean(0), Boolean(""), Boolean(NaN));
// prints false false false
console.log(Boolean("0"), Boolean("false"), Boolean([]), Boolean({}));
// prints true true true true
```
`"0"` to niepusty ciąg znaków, więc jest truthy; pusta tablica jest obiektem, więc też jest truthy.

# --asserts--

`countTruthy([1, "a", true])` musi zwrócić `3`.

```javascript
tryCatch(countTruthy([1, "a", true]) === 3);
```

`countTruthy([0, "", null, undefined, NaN, false])` musi zwrócić `0`.

```javascript
tryCatch(countTruthy([0, "", null, undefined, NaN, false]) === 0);
```

`countTruthy(["0", "false", [], {}])` musi zwrócić `4`.

```javascript
tryCatch(countTruthy(["0", "false", [], {}]) === 4);
```

`countTruthy([0n, -0, " "])` musi zwrócić `1`, ponieważ tylko ciąg znaków ze spacją jest truthy.

```javascript
tryCatch(countTruthy([0n, -0, " "]) === 1);
```

`countTruthy([])` musi zwrócić `0`.

```javascript
tryCatch(countTruthy([]) === 0);
```

# --solutions--

```javascript
function countTruthy(values) {
  let count = 0;
  for (const value of values) {
    if (value) {
      count++;
    }
  }
  return count;
}
```
