# --description--

Metody też mogą być prywatne. Poprzedź nazwę znakiem `#`, a metoda zniknie z publicznej powierzchni klasy, wciąż będąc wywoływalną z dowolnej innej metody za pomocą `this.#nazwa(...)`:
```javascript
class Receipt {
    #format(n) {
        return `$${n}`;
    }
    print(n) {
        return this.#format(n);
    }
}
console.log(new Receipt().print(7));
// wypisuje $7
```
W ten sposób trzymasz kroki pomocnicze z dala od API: wywołujący widzi `print`, a nie szczegół formatowania, który się za nim kryje. Prywatne pola i prywatne metody razem dają klasie wyraźne wnętrze i zewnętrze.

# --asserts--

Nowy wynik musi zaczynać się od `0`.

```javascript
tryCatch(new Score().total === 0);
```

Wartości dodatnie muszą być dodane.

```javascript
const s1 = new Score();
s1.record(5);
s1.record(3);
tryCatch(s1.total === 8);
```

Wartości ujemne muszą być zignorowane.

```javascript
const s2 = new Score();
s2.record(5);
s2.record(-4);
tryCatch(s2.total === 5);
```

Zero musi być zignorowane.

```javascript
const s3 = new Score();
s3.record(0);
tryCatch(s3.total === 0);
```

Punkty muszą być prywatne, więc instancja nie może mieć publicznej właściwości.

```javascript
tryCatch(Object.keys(new Score()).length === 0);
```

# --solutions--

```javascript
class Score {
  #points = 0;
  #add(value) {
    if (value > 0) {
      this.#points += value;
    }
  }
  record(value) {
    this.#add(value);
  }
  get total() {
    return this.#points;
  }
}
```
