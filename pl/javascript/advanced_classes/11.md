# --description--

Prawdziwa wartość settera polega na tym, że może odmówić. Między przypisaniem a zapisaną wartością masz szansę sprawdzić, ograniczyć lub odrzucić to, co nadchodzi:
```javascript
class Volume {
    constructor(level) {
        this._level = level;
    }
    get level() {
        return this._level;
    }
    set level(value) {
        if (value <= 10) {
            this._level = value;
        }
    }
}
const v = new Volume(3);
v.level = 50;
console.log(v.level);
// wypisuje 3, setter odrzucił 50
```
Getter i setter o tej samej nazwie tworzą jedną właściwość, więc nie mogą nią być jednocześnie zwykłe pole: zapisana wartość mieszka pod inną nazwą, z konwencją tej samej nazwy z wiodącym podkreślnikiem.

# --asserts--

Getter musi zwrócić wartość przekazaną do konstruktora.

```javascript
tryCatch(new Thermostat(20).temperature === 20);
```

Setter musi zaakceptować poprawną wartość.

```javascript
const t1 = new Thermostat(20);
t1.temperature = 25;
tryCatch(t1.temperature === 25);
```

Setter musi zignorować wartość ujemną.

```javascript
const t2 = new Thermostat(20);
t2.temperature = -5;
tryCatch(t2.temperature === 20);
```

Setter musi zaakceptować `0`.

```javascript
const t3 = new Thermostat(20);
t3.temperature = 0;
tryCatch(t3.temperature === 0);
```

Wartość musi być przechowywana w `_temperature`.

```javascript
tryCatch(new Thermostat(20)._temperature === 20);
```
