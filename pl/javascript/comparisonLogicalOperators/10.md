# --description--

`==` porównuje obie strony po przekonwertowaniu ich do wspólnego typu, więc `"5" == 5` daje `true`. Ścisły operator `===` pomija tę konwersję i wymaga, aby typy również się zgadzały.
```javascript
console.log("5" == 5);  // true
console.log("5" === 5); // false
```
