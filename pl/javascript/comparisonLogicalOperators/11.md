# --description--

`!=` konwertuje przed porównaniem, tak samo jak `==`, więc `"5" != 5` daje `false`. Jego ścisły odpowiednik `!==` traktuje ciąg znaków i liczbę jako różne, niezależnie od tego, co zawierają.
```javascript
console.log("5" !== 5); // true
```
