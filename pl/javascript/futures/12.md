# --description--

`Promise.all` działa z tablicą dowolnej długości, także pustą: oczekiwanie na `Promise.all([])` za pomocą `await` od razu oddaje pustą tablicę. Dzięki temu można bezpiecznie przekazać listę budowaną w czasie działania, bez specjalnego przypadku dla „nie ma na co czekać”.
```javascript
const values = await Promise.all(items);
console.log(values.length === items.length);
// prints true
```
Zwracana tablica zawsze ma dokładnie tyle elementów, ile tablica otrzymana, na tych samych pozycjach, więc można po niej iterować jak po każdej innej tablicy.

# --asserts--

`await sumAll([])` musi dawać `0`.

```javascript
(async () => {
  tryCatch((await sumAll([])) === 0);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)])` musi dawać `6`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)];
  tryCatch((await sumAll(promises)) === 6);
})().catch(() => tryCatch(false));
```

`await sumAll([Promise.resolve(-4), Promise.resolve(4)])` musi dawać `0`.

```javascript
(async () => {
  const promises = [Promise.resolve(-4), Promise.resolve(4)];
  tryCatch((await sumAll(promises)) === 0);
})().catch(() => tryCatch(false));
```

`sumAll` musi też działać z obietnicami, które zajmują różną ilość czasu.

```javascript
(async () => {
  const later = (n, ms) => new Promise((resolve) => setTimeout(() => resolve(n), ms));
  tryCatch((await sumAll([later(10, 30), later(5, 5)])) === 15);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function sumAll(promises) {
  const values = await Promise.all(promises);
  let total = 0;
  for (const value of values) {
    total += value;
  }
  return total;
}
```
