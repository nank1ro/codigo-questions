# --description--

`Promise.all` poddaje się, gdy tylko jedna obietnica zostanie odrzucona. Gdy mimo wszystko chcesz dostać każdy wynik, użyj **`Promise.allSettled(promises)`**: nigdy nie jest odrzucana i jest spełniana jednym małym obiektem na obietnicę, w tej samej kolejności:

- `{ status: "fulfilled", value: ... }` dla tych, które się powiodły;
- `{ status: "rejected", reason: ... }` dla tych, które zawiodły.

```javascript
const results = await Promise.allSettled([
  Promise.resolve(1),
  Promise.reject(new Error("nope")),
]);
console.log(results[0].status);
// prints fulfilled
console.log(results[1].reason.message);
// prints nope
```
Czytaj `value` tylko wtedy, gdy `status` to `"fulfilled"`, a `reason` tylko wtedy, gdy to `"rejected"`: druga właściwość po prostu nie istnieje.

# --asserts--

`await countFulfilled([])` musi dawać `0`.

```javascript
(async () => {
  tryCatch((await countFulfilled([])) === 0);
})().catch(() => tryCatch(false));
```

`await countFulfilled([Promise.resolve(1), Promise.resolve(2)])` musi dawać `2`.

```javascript
(async () => {
  const promises = [Promise.resolve(1), Promise.resolve(2)];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Przy jednej odrzuconej obietnicy z trzech odpowiedź musi wynosić `2`.

```javascript
(async () => {
  const promises = [
    Promise.resolve(1),
    Promise.reject(new Error("nope")),
    Promise.resolve(3),
  ];
  tryCatch((await countFulfilled(promises)) === 2);
})().catch(() => tryCatch(false));
```

Gdy każda obietnica jest odrzucona, odpowiedź musi wynosić `0`, a `countFulfilled` nie może zostać odrzucona.

```javascript
(async () => {
  const promises = [Promise.reject(new Error("a")), Promise.reject(new Error("b"))];
  tryCatch((await countFulfilled(promises)) === 0);
})().catch(() => tryCatch(false));
```

# --solutions--

```javascript
async function countFulfilled(promises) {
  const results = await Promise.allSettled(promises);
  let count = 0;
  for (const result of results) {
    if (result.status === "fulfilled") {
      count += 1;
    }
  }
  return count;
}
```
