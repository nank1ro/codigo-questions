# --description--

Połączenie ostatnich elementów daje małe narzędzie używane w prawie każdej prawdziwej aplikacji: limit czasu. Zbuduj obietnicę odrzucaną po `ms` milisekundach, uruchom z nią wyścig prawdziwej pracy, a to, co rozstrzygnie się pierwsze, decyduje o wyniku:
```javascript
const timer = new Promise((resolve, reject) => {
  setTimeout(() => reject(new Error("timeout")), ms);
});
return Promise.race([work, timer]);
```
Zwracanie obietnicy z funkcji `async` jest w porządku: obietnica oddawana przez funkcję podąża za nią, więc wywołujący oczekuje finalnej wartości, a nie obietnicy obietnicy.

# --instructions--

Napisz funkcję `async` `withTimeout`, która przyjmuje obietnicę oraz liczbę milisekund `ms` i zwraca wynik obietnicy, jeśli rozstrzygnie się w ciągu `ms`, albo jest odrzucana z `new Error("timeout")` w przeciwnym razie. Użyj `Promise.race`

# --asserts--

Już spełniona obietnica musi dać swoją wartość.

```javascript
(async () => {
  tryCatch((await withTimeout(Promise.resolve("ok"), 50)) === "ok");
})().catch(() => tryCatch(false));
```

Obietnica odrzucona przed limitem czasu musi zachować swój własny błąd.

```javascript
(async () => {
  const failing = Promise.reject(new Error("broken"));
  let message = "";
  await withTimeout(failing, 60).catch((error) => { message = error.message; });
  tryCatch(message === "broken");
})().catch(() => tryCatch(false));
```

Obietnica wystarczająco szybka musi dać swoją wartość, a nie obietnicę.

```javascript
(async () => {
  const quick = new Promise((resolve) => setTimeout(() => resolve(7), 10));
  tryCatch((await withTimeout(quick, 120)) === 7);
})().catch(() => tryCatch(false));
```

Obietnica zbyt wolna musi zostać odrzucona z komunikatem `"timeout"`.

```javascript
(async () => {
  const slow = new Promise((resolve) => setTimeout(() => resolve("late"), 150));
  let message = "";
  await withTimeout(slow, 20).catch((error) => { message = error.message; });
  tryCatch(message === "timeout");
})().catch(() => tryCatch(false));
```
