# --description--

Metoda `indexOf()` zwraca indeks, pod którym fragment tekstu **pierwszy raz** pojawia się w łańcuchu.
Jeśli tekst nie zostanie znaleziony, zwraca `-1`:
```javascript
let word = "hello";
console.log(word.indexOf("l"));
// prints 2
console.log(word.indexOf("z"));
// prints -1
```
