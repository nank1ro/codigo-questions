# --description--

Łańcuchy są **niemutowalne**: po utworzeniu łańcuch nigdy nie może zostać zmieniony.
Przypisanie do indeksu nic nie robi, a każda metoda łańcucha zwraca **nowy** łańcuch zamiast modyfikować oryginał:
```javascript
let word = "hello";
word[0] = "j";
console.log(word);
// prints hello
word.toUpperCase();
console.log(word);
// prints hello
```
Aby zachować wynik, przypisz go z powrotem do zmiennej:
```javascript
word = word.toUpperCase();
```

# --instructions--

Pierwsze `console.log` drukuje `hello`, ponieważ `toUpperCase()` nie zmieniło `word`. Uzupełnij kod tak, aby drugie `console.log` wydrukowało `HELLO`
