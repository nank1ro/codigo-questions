# --instructions--

Uporządkuj linie, aby wydrukować tablicę z imionami z `all`, których nie ma w `done`.
Zadeklaruj `all` przed `done`

# --answers--

```javascript
const all = new Set(["ann", "bob", "cy"]);
```

```javascript
const done = new Set(["bob"]);
```

```javascript
const pending = [...all].filter((name) => !done.has(name));
```

```javascript
console.log(pending);
```
