# --description--

Wszystko spotyka się w `groupBy(items, keyFn)`: funkcji wyższego rzędu, która dostaje callback ustalający **klucz grupy** każdego elementu i zwraca obiekt przypisujący każdemu kluczowi tablicę elementów o tym kluczu. `reduce` z akumulatorem będącym obiektem wykonuje całą pracę:
```javascript
const byInitial = groupBy(["hi", "yo", "hey"], (w) => w[0]);
console.log(byInitial);
// prints { h: [ 'hi', 'hey' ], y: [ 'yo' ] }
```
Dla każdego elementu wylicz klucz, utwórz tablicę dla tego klucza, jeśli jeszcze nie istnieje (`acc[key] ?? []`), dodaj element i zwróć akumulator. Ponieważ to wywołujący wybiera `keyFn`, ta sama funkcja grupuje słowa po pierwszej literze, osoby po mieście albo liczby po parzystości.

# --asserts--

`groupBy(["hi", "yo", "hey"], (w) => w[0])` musi zwrócić `{ h: ["hi", "hey"], y: ["yo"] }`.

```javascript
tryCatch(JSON.stringify(groupBy(["hi", "yo", "hey"], (w) => w[0])) === '{"h":["hi","hey"],"y":["yo"]}');
```

Grupowanie `[1, 2, 3, 4]` po parzystości musi zwrócić `{ odd: [1, 3], even: [2, 4] }`.

```javascript
tryCatch(JSON.stringify(groupBy([1, 2, 3, 4], (n) => (n % 2 === 0 ? "even" : "odd"))) === '{"odd":[1,3],"even":[2,4]}');
```

Grupowanie osób po `city` musi zachować całe obiekty, w pierwotnej kolejności.

```javascript
tryCatch((() => { const people = [{ name: "Ana", city: "Rome" }, { name: "Bo", city: "Oslo" }, { name: "Cy", city: "Rome" }]; const groups = groupBy(people, (p) => p.city); return groups.Rome.map((p) => p.name).join(",") === "Ana,Cy" && groups.Oslo.length === 1 && groups.Oslo[0] === people[1]; })());
```

`groupBy([], (x) => x)` musi zwrócić pusty obiekt.

```javascript
tryCatch(JSON.stringify(groupBy([], (x) => x)) === "{}");
```

Pierwotna tablica nie może zostać zmieniona.

```javascript
tryCatch((() => { const input = ["a", "b"]; groupBy(input, (s) => s); return JSON.stringify(input) === '["a","b"]'; })());
```

Funkcja musi używać `reduce`.

```javascript
tryCatch(/\.reduce\(/.test(groupBy.toString()));
```

```javascript
function groupBy(items, keyFn) {
  return items.reduce((acc, item) => {
    const key = keyFn(item);
    acc[key] = acc[key] ?? [];
    acc[key].push(item);
    return acc;
  }, {});
}
```
