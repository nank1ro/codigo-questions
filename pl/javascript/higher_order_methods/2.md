# --description--

Funkcje wyższego rzędu pozwalają oddzielić *co robić z każdym elementem* od *jak przechodzić po elementach*. Część przechodząca jest napisana raz, a callback decyduje o reszcie:
```javascript
function each(items, action) {
  for (let i = 0; i < items.length; i++) {
    action(items[i]);
  }
}
each(["a", "b"], (letter) => console.log(letter));
// prints a and b on two lines
```
Callback dostaje po jednym elemencie naraz. Może to być funkcja strzałkowa napisana w miejscu, jak wyżej, albo dowolna funkcja zapisana w zmiennej. Dokładnie tak działają wewnątrz wbudowane metody tablic, które poznasz dalej.

# --asserts--

`transform([1, 2, 3], (n) => n * 2)` musi zwrócić `[2, 4, 6]`.

```javascript
tryCatch(JSON.stringify(transform([1, 2, 3], (n) => n * 2)) === "[2,4,6]");
```

`transform(["a", "b"], (s) => s.toUpperCase())` musi zwrócić `["A", "B"]`.

```javascript
tryCatch(JSON.stringify(transform(["a", "b"], (s) => s.toUpperCase())) === '["A","B"]');
```

`transform([], (n) => n)` musi zwrócić pustą tablicę.

```javascript
tryCatch(JSON.stringify(transform([], (n) => n)) === "[]");
```

Wynik musi być nową tablicą, a oryginał nie może zostać zmieniony.

```javascript
tryCatch((() => { const input = [1, 2]; const out = transform(input, (n) => n + 1); return out !== input && JSON.stringify(input) === "[1,2]"; })());
```

Funkcja nie może używać `map`.

```javascript
tryCatch(!/\.map\(/.test(transform.toString()));
```

```javascript
function transform(items, fn) {
  const result = [];
  for (const item of items) {
    result.push(fn(item));
  }
  return result;
}
```
