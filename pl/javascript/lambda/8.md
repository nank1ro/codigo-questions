# --description--

Parametry funkcji strzałkowej obsługują te same możliwości co parametry zwykłej funkcji.
**Wartość domyślna** jest używana, gdy argument zostanie pominięty lub jest równy `undefined`:
```javascript
const greet = (name = "World") => `Hello, ${name}!`;
console.log(greet());
// prints Hello, World!
console.log(greet("Ana"));
// prints Hello, Ana!
```
Zauważ, że parametr z wartością domyślną zawsze wymaga nawiasów, nawet gdy jest jedyny: `name = "World" => ...` to błąd składni.

# --asserts--

`greet()` musi zwracać `"Hello, World!"`.

```javascript
tryCatch(greet() === "Hello, World!");
```

`greet("Ana")` musi zwracać `"Hello, Ana!"`.

```javascript
tryCatch(greet("Ana") === "Hello, Ana!");
```

`greet(undefined)` też musi używać wartości domyślnej.

```javascript
tryCatch(greet(undefined) === "Hello, World!");
```

`greet` musi być funkcją strzałkową.

```javascript
tryCatch(typeof greet === "function" && !/function/.test(greet.toString()));
```

Wartość domyślna musi być zadeklarowana na liście parametrów.

