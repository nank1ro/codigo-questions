# --description--

Warunek instrukcji `if` zawsze umieszcza się wewnątrz nawiasów `()`, znajdujących się bezpośrednio po słowie kluczowym `if` i przed otwierającym nawiasem klamrowym.

# --instructions--

Gdzie zapisujemy warunek instrukcji if?

# --answers--

- Między nawiasami okrągłymi ()
- Między nawiasami kwadratowymi []
- Między słowem kluczowym if a otwartym nawiasem klamrowym {
- Przed słowem kluczowym if
