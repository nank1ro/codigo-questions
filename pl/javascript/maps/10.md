# --description--

Map nie ma metod tablicowych, takich jak `sort()` czy `filter()`. Aby ich użyć, przekonwertuj Map (lub jego klucze albo wartości) na tablicę za pomocą `Array.from()` lub operatora rozproszenia `...`:
```javascript
let ages = new Map([["Bob", 25], ["Ann", 30]]);
let pairs = Array.from(ages);
console.log(pairs);
// prints [ [ 'Bob', 25 ], [ 'Ann', 30 ] ]
let names = [...ages.keys()];
console.log(names);
// prints [ 'Bob', 'Ann' ]
let values = [...ages.values()];
console.log(values);
// prints [ 25, 30 ]
```
Odwrotna konwersja, `Object.fromEntries(ages)`, zamienia Map z powrotem w zwykły obiekt.

`sortedKeys` dla Map z kluczami `"pear"`, `"apple"` i `"kiwi"` musi zwrócić `["apple", "kiwi", "pear"]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map([["pear", 5], ["apple", 3], ["kiwi", 2]]))) === '["apple","kiwi","pear"]');
```

`sortedKeys` dla pustego Map musi zwrócić `[]`.

```javascript
tryCatch(JSON.stringify(sortedKeys(new Map())) === '[]');
```
