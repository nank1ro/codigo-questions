# --description--

Tam, gdzie klucz zawiera inny obiekt lub tablicę, wzorzec może po prostu iść dalej i opisać również ten kształt:
```javascript
const user = { name: "Ada", address: { city: "London" } };
const { address: { city } } = user;
console.log(city);
// wypisuje London
```
Uważaj, co tworzy taka linijka: `address: { city }` znaczy „wejdz do `address`”, a nie „daj mi `address`”, więc tylko `city` staje się zmienną. Aby uzyskać oba, wymień klucz dwa razy: `const { address, address: { city } } = user;`. Wzorce tablic i obiektów swobodnie zagnieżdżają się w sobie, jak w `{ tags: [first] }`.

# --asserts--

Zagnieżdżone miasto musi zostać zwrócone.

```javascript
tryCatch(cityOf({ name: "Ada", address: { city: "London" } }) === "London");
```

Inne zagnieżdżone miasto musi zostać zwrócone.

```javascript
tryCatch(cityOf({ name: "Bob", address: { city: "Rome" } }) === "Rome");
```

Pusty adres musi dać `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Cy", address: {} }) === "unknown");
```

Inne klucze adresu muszą być ignorowane.

```javascript
tryCatch(cityOf({ name: "Dee", address: { city: "Oslo", zip: "0150" } }) === "Oslo");
```

Jawne `undefined` jako miasto musi dać `"unknown"`.

```javascript
tryCatch(cityOf({ name: "Eve", address: { city: undefined } }) === "unknown");
```
