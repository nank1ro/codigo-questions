# --description--

Zdestrukturyzowany parametr z wartościami domyślnymi tworzy zgrabny obiekt opcji, ale wciąż się psuje, gdy wywołujący nie przekazuje niczego: odczytanie klucza z `undefined` rzuca `TypeError`. Nadanie całemu wzorcowi wartości domyślnej `{}` naprawia to:
```javascript
function createUser({ name = "guest", admin = false } = {}) {
    return `${name}/${admin}`;
}
console.log(createUser());
// wypisuje guest/false
```
Czytaj tę linijkę od zewnątrz do środka: `= {}` dostarcza pusty obiekt, gdy brakuje argumentu, a każda wewnętrzna wartość domyślna wypełnia potem swój własny klucz.

# --asserts--

Wywołanie `button()` bez argumentu musi użyć obu wartości domyślnych.

```javascript
tryCatch(button() === "OK/medium");
```

Pusty obiekt też musi użyć obu wartości domyślnych.

```javascript
tryCatch(button({}) === "OK/medium");
```

Podanie tylko `label` musi zachować domyślny rozmiar.

```javascript
tryCatch(button({ label: "Save" }) === "Save/medium");
```

Podanie tylko `size` musi zachować domyślną etykietę.

```javascript
tryCatch(button({ size: "large" }) === "OK/large");
```

Obie podane opcje muszą być użyte.

```javascript
tryCatch(button({ label: "Cancel", size: "small" }) === "Cancel/small");
```
