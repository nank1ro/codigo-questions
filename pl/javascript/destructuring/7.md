# --description--

Wzorce obiektów i wartości domyślne łączą się dokładnie tak jak tablicowe, co czyni je schludnym sposobem na odczytanie obiektu konfiguracji, którego klucze mogą być, ale nie muszą, obecne:
```javascript
const options = { theme: "dark" };
const { theme, lang = "en" } = options;
console.log(theme, lang);
// prints dark en
```
Ponieważ cały wzorzec to jedna instrukcja, funkcja może rozpakować wszystko, czego potrzebuje, ze swojego argumentu już w pierwszej linijce.

# --asserts--

Oba obecne klucze muszą być użyte.

```javascript
tryCatch(greet({ name: "Ada", city: "London" }) === "Hi Ada from London");
```

Inny użytkownik musi dać inny łańcuch.

```javascript
tryCatch(greet({ name: "Bob", city: "Rome" }) === "Hi Bob from Rome");
```

Brakujący `city` musi przyjąć `"somewhere"`.

```javascript
tryCatch(greet({ name: "Cy" }) === "Hi Cy from somewhere");
```

Nadmiarowe klucze muszą być ignorowane.

```javascript
tryCatch(greet({ name: "Dee", city: "Oslo", age: 30 }) === "Hi Dee from Oslo");
```

Kolejność kluczy nie może mieć znaczenia.

```javascript
tryCatch(greet({ city: "Paris", name: "Eve" }) === "Hi Eve from Paris");
```
