# --description--

Destrukturyzacja jest najbardziej przydatna dokładnie tam, gdzie pojawia się tablica: argument funkcji albo wynik wywołania. Zamiast trzymać tablicę przy sobie i indeksować ją wszędzie, rozpakowujesz ją raz i nadajesz częściom prawdziwe nazwy:
```javascript
function middle(range) {
    const [start, end] = range;
    return (start + end) / 2;
}
console.log(middle([0, 10]));
// wypisuje 5
```
Nic nie jest kopiowane ani zmieniane w oryginalnej tablicy, wzorzec jedynie z niej czyta.

# --asserts--

`label(["Ada", 90])` musi zwrócić `"Ada: 90"`.

```javascript
tryCatch(label(["Ada", 90]) === "Ada: 90");
```

`label(["Bob", 0])` musi zwrócić `"Bob: 0"`.

```javascript
tryCatch(label(["Bob", 0]) === "Bob: 0");
```

Ujemny wynik musi pozostać bez zmian.

```javascript
tryCatch(label(["Cy", -3]) === "Cy: -3");
```

`label(["Dee", 100])` musi zwrócić `"Dee: 100"`.

```javascript
tryCatch(label(["Dee", 100]) === "Dee: 100");
```

Nadmiarowe elementy muszą być ignorowane.

```javascript
tryCatch(label(["Eve", 55, "extra"]) === "Eve: 55");
```
