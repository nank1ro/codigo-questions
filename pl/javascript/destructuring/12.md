# --description--

Wzorce obiektów też mają rest i tam zbiera on każdy klucz, którego wzorzec nie wymienił, do nowego obiektu:
```javascript
const user = { id: 1, name: "Ada", city: "London" };
const { id, ...profile } = user;
console.log(profile);
// wypisuje { name: 'Ada', city: 'London' }
```
To najkrótszy sposób na zbudowanie kopii obiektu bez jednego z jego kluczy: oryginał nie jest nigdy dotykany, a obiekt rest jest świeżym obiektem przechowującym pozostałe wartości.

# --asserts--

Klucz `password` musi zniknąć.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).password === undefined);
```

Pozostałe klucze muszą przetrwać.

```javascript
tryCatch(withoutPassword({ name: "Ada", password: "x" }).name === "Ada");
```

Każdy inny klucz musi przetrwać.

```javascript
tryCatch(Object.keys(withoutPassword({ name: "Ada", password: "x", city: "London" })).length === 2);
```

Oryginalny obiekt nie może zostać zmieniony.

```javascript
const original = { name: "Bob", password: "y" };
withoutPassword(original);
tryCatch(original.password === "y");
```

Obiekt zawierający tylko hasło musi dać pusty obiekt.

```javascript
tryCatch(Object.keys(withoutPassword({ password: "z" })).length === 0);
```
