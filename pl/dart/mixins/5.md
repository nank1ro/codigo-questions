# --description--

Mixin może zadeklarować składową **bez ciała**. Taka składowa jest abstrakcyjna: mixin z niej korzysta, a klasa przejmująca mixin musi ją dostarczyć.

```dart
mixin Greeting {
  String get name;                       // no body: the class provides it

  String greet() => 'Hello, $name!';
}

class Person with Greeting {
  @override
  final String name;

  Person(this.name);
}

void main() {
  print(Person('Ada').greet()); // Hello, Ada!
}
```

Mixin przynosi zachowanie, klasa przynosi dane. Pole w klasie, takie jak `final String name;`, wystarcza, aby spełnić abstrakcyjny getter o tej samej nazwie.

# --instructions--

Zadeklaruj mixin `Labelled` z:
- abstrakcyjnym getterem `title` typu `String`, zadeklarowanym bez ciała
- metodą `label`, która zwraca `title` ujęte w nawiasy kwadratowe

Zadeklaruj klasę `Book`, która korzysta z `Labelled`, ma pole `title` typu `final String` i konstruktor je przyjmujący.

Przykład:
```dart
print(Book('Dune').label()); // [Dune]
```

mixin Labelled {

  final String title;
