# --description--

Ułożone mixiny to sposób, w jaki małe, niezależne reguły łączy się w jedną klasę. Każdy mixin nadpisuje tę samą składową, robi swoją część i wywołuje `super`, aby przekazać pracę dalej. Ponieważ wywołanie wchodzi najpierw do **ostatniego** mixinu, kolejność listy `with` decyduje, która reguła działa przed którą:

```dart
class Account {
  int balance = 0;

  void deposit(int amount) {
    balance += amount;
  }
}

mixin Doubled on Account {
  @override
  void deposit(int amount) {
    super.deposit(amount * 2);
  }
}
```

`class A extends Account with Doubled {}` podwaja każdą wpłatę. Dodaj drugi mixin za `Doubled`, a to on dostanie wpłatę pierwszy, zanim `Doubled` w ogóle ją zobaczy.

# --instructions--

Klasa `Account` jest już napisana: ma pole `balance` typu `int` zaczynające się od `0` oraz metodę `deposit`, która dodaje swój argument `int` do `balance`.

Zadeklaruj mixin `Audited` na `Account` z polem `log` typu `List<String>` zaczynającym się pusto, nadpisującym `deposit` tak, aby najpierw dodawał do `log` ciąg `'deposit '` z kwotą, a potem wywoływał `super.deposit`.

Zadeklaruj mixin `Limited` na `Account` nadpisujący `deposit` tak, aby kwota większa niż `100` była ignorowana, a każda inna była przekazywana do `super.deposit`.

Zadeklaruj klasę `SafeAccount`, która dziedziczy po `Account` i używa obu mixinów, tak aby odrzucona wpłata nigdy nie trafiała do logu.

Przykład:
```dart
final account = SafeAccount();
account.deposit(30);
account.deposit(500);
print(account.balance); // 30
print(account.log);     // [deposit 30]
```

```dart
mixin Audited on Account {
  final List<String> log = [];

  @override
  void deposit(int amount) {
    log.add('deposit $amount');
    super.deposit(amount);
  }
}

mixin Limited on Account {
  @override
  void deposit(int amount) {
    if (amount > 100) return;
    super.deposit(amount);
  }
}

class SafeAccount extends Account with Audited, Limited {}
```
