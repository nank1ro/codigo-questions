# --description--

Mixin z klauzulą `on` czyta składowe swojej nadklasy tak, jakby były jego własnymi, co czyni go dobrym miejscem na zachowanie zdobiące istniejący typ:

```dart
class Shape {
  String get kind => 'shape';
}

mixin Printable on Shape {
  void show() {
    print('a $kind');
  }
}

class Square extends Shape with Printable {
  @override
  String get kind => 'square';
}
```

`Square` nadpisuje `kind`, a `show` automatycznie korzysta z nadpisania: mixin zawsze wywołuje składową na prawdziwym obiekcie.

# --instructions--

Ułóż elementy, aby zdefiniować klasę `Shape` z getterem `kind` zwracającym `'shape'`, mixin `Printable` ograniczony do `Shape` z metodą `show`, która wypisuje `a `, a po nim `kind`, klasę `Square`, która dziedziczy po `Shape`, korzysta z `Printable` i nadpisuje `kind` wartością `'square'`, oraz `main`, który wywołuje `show` na `Square`. Zdefiniuj najpierw `Shape`, potem `Printable`, potem `Square`, potem `main`. Program musi wypisać:

```
a square
```
