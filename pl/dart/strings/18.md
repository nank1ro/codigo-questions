# --description--

Metody ciągów znaków zwracają ciągi znaków, więc można je **łączyć w łańcuch**, jedną po drugiej. W połączeniu z `.split('')`, właściwością list `.reversed` i `.join()` pozwala to odwrócić ciąg znaków w jednym wyrażeniu:

```dart
var text = 'Dart';
print(text.split('').reversed.join()); // traD
print(text.toLowerCase().replaceAll('a', '4')); // d4rt
```

**Palindrom** to tekst, który czyta się tak samo od przodu i od tyłu, na przykład `level`.

# --instructions--

Napisz funkcję `isPalindrome`, która przyjmuje parametr `String` o nazwie `text` i zwraca `true`, jeśli jest on palindromem, ignorując wielkość liter i spacje, lub `false` w przeciwnym razie.

Przykład:
```dart
print(isPalindrome('Level'));            // true
print(isPalindrome('never odd or even')); // true
print(isPalindrome('Dart'));             // false
```

bool isPalindrome(String text) {
  var clean = text.toLowerCase().replaceAll(' ', '');
  return clean == clean.split('').reversed.join();
}
