# --instructions--

Napisz funkcję `sumUntilError`, która przyjmuje `Stream<int>` `source` i zwraca `Future<int>` kończący się sumą jego wartości. Jeśli strumień wyemituje błąd, zatrzymaj się i zakończ sumą wartości otrzymanych **przed** błędem, zamiast rzucać wyjątek.

Przykład:
```dart
Stream<int> broken() async* {
  yield 5;
  yield 3;
  throw StateError('lost');
}

print(await sumUntilError(Stream.fromIterable([1, 2, 3]))); // 6
print(await sumUntilError(broken()));                       // 8
```

`sumUntilError` dla strumienia, który emituje `5`, `3`, a potem błąd, powinno zakończyć się wartością `8`

```dart
  test('test2', () async {
    Stream<int> broken() async* {
      yield 5;
      yield 3;
```

`sumUntilError` dla strumienia, który od razu zgłasza błąd, powinno zakończyć się wartością `0`, a dla pustego strumienia powinno zakończyć się wartością `0`

```dart

    Stream<int> failing() async* {
      throw FormatException('nothing');

    expect(await sumUntilError(Stream.fromIterable(<int>[])), 0, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> sumUntilError(Stream<int> source) async {
  var total = 0;
  try {
    await for (final n in source) {
      total += n;
    }
  } catch (e) {
    // stop at the first error and keep the sum so far
  }
  return total;
}
```
