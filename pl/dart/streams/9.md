# --description--

Oprócz `toList()` strumień oferuje inne metody, które **konsumują** wszystkie jego zdarzenia i zwracają pojedynczy `Future`:

- `first` i `last` kończą się pierwszym lub ostatnim zdarzeniem
- `length` kończy się liczbą zdarzeń
- `join(separator)` kończy się wszystkimi zdarzeniami złączonymi w jeden `String`
- `reduce(combine)` łączy zdarzenia po dwa w jedną wartość

```dart
final numbers = Stream.fromIterable([3, 9, 2]);
print(await numbers.reduce((a, b) => a + b)); // 14
```

`reduce` wywołuje `combine` z dotychczasowym wynikiem i kolejnym zdarzeniem. Rzuca wyjątek, gdy strumień jest pusty, więc używaj go tylko wtedy, gdy co najmniej jedno zdarzenie jest gwarantowane.

# --instructions--

Napisz dwie funkcje:
- `largest`, która przyjmuje `Stream<int>` `source` i zwraca `Future<int>` kończący się największą wartością, używając `reduce`. Strumień zawsze ma co najmniej jedno zdarzenie.
- `sentence`, która przyjmuje `Stream<String>` `words` i zwraca `Future<String>` kończący się wszystkimi słowami złączonymi pojedynczą spacją.

Przykład:
```dart
print(await largest(Stream.fromIterable([3, 9, 2])));        // 9
print(await sentence(Stream.fromIterable(['I', 'am', 'Dart']))); // I am Dart
```

# --solutions--

```dart
Future<int> largest(Stream<int> source) {
  return source.reduce((a, b) => a > b ? a : b);
}

Future<String> sentence(Stream<String> words) {
  return words.join(' ');
}
```
