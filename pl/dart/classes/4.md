# --description--

Parametr `this.x`, który widziałeś w poprzednim ćwiczeniu, to skrót. Dłuższa forma przypisuje każdy parametr do jego pola w ciele konstruktora (`this.x` to pole, `x` to parametr):

```dart
class Point {
  int x = 0;
  int y = 0;

  Point(int x, int y) {
    this.x = x;
    this.y = y;
  }
}
```

Tę samą klasę można zapisać jako:

```dart
class Point {
  int x;
  int y;

  Point(this.x, this.y);
}
```

Ta krótsza forma nosi nazwę **inicjalizujących parametrów formalnych**.

# --instructions--

Która z poniższych opcji poprawnie używa skróconej składni inicjalizujących parametrów formalnych?

# --answers--

- `Point(this.x, this.y);`
- `Point(x, y) { self.x = x; self.y = y; }`
- `Point(x, y) => x + y;`
- `Point.init(x, y);`

# --solutions--
