# --description--

Zebranie całej serii wiadomości trzyma się jednego przepisu: pusta lista przed pętlą, jedno `add` na każdą prawdziwą wiadomość i `close()` na sygnał kończący strumień. Gdy port zostanie zamknięty, `await for` się kończy i funkcja może zwrócić wynik:

```dart
Future<List<int>> collect(ReceivePort port) async {
  final values = <int>[];
  await for (final message in port) {
    if (message == null) {
      port.close();
    } else {
      values.add(message as int);
    }
  }
  return values;
}
```

Wiadomości zachowują kolejność, w jakiej zostały wysłane, więc budowana lista odzwierciedla pracę drugiego izolatu krok po kroku.

# --instructions--

Napisz funkcję najwyższego poziomu `sendWords`, która przyjmuje `List<Object>` `message`, gdzie element `0` to `SendPort`, a element `1` to `List<String>`: wyślij każde słowo do portu, a potem wyślij `null` jako sygnał końca.

Potem napisz funkcję `collectWords`, która przyjmuje `List<String>` `words` i zwraca `Future<List<String>>` kończące się wszystkimi słowami odebranymi od uruchomionego izolatu `sendWords`.

Przykład:
```dart
print(await collectWords(['a', 'b'])); // [a, b]
```

```dart
void sendWords(List<Object> message) {
  final port = message[0] as SendPort;
  final words = message[1] as List<String>;
  for (final word in words) {
    port.send(word);
  }
  port.send(null);
}

Future<List<String>> collectWords(List<String> words) async {
  final receivePort = ReceivePort();
  await Isolate.spawn(sendWords, <Object>[receivePort.sendPort, words]);
  final collected = <String>[];
  await for (final message in receivePort) {
    if (message == null) {
      receivePort.close();
    } else {
      collected.add(message as String);
    }
  }
  return collected;
}
```
