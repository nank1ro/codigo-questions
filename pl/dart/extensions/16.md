# --instructions--

Napisz rozszerzenie o nazwie `Words` na `String` z:
- getterem `wordCount` typu `int`, czyli liczbą słów w ciągu znaków, gdzie słowa są rozdzielone pojedynczą spacją
- getterem `initials` typu `String`, złożonym z pierwszego znaku każdego słowa wielką literą, połączonym bez separatorów

Ciąg znaków zawsze zawiera co najmniej jedno słowo i nigdy nie ma spacji na początku, na końcu ani podwójnych spacji.

Przykład:
```dart
print('ada lovelace'.wordCount); // 2
print('ada lovelace'.initials);  // AL
```

# --solutions--

```dart
extension Words on String {
  int get wordCount => split(' ').length;

  String get initials => split(' ').map((w) => w[0].toUpperCase()).join();
}
```
