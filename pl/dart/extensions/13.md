# --description--

Rozszerzenie generyczne może przyjmować **funkcje** jako parametry, dokładnie tak jak robią to `where` i `map`. Typ funkcji zapisuje się z typem elementów `T`, więc callback otrzymuje elementy właściwego typu:

```dart
extension Checks<T> on List<T> {
  bool all(bool Function(T) test) {
    for (final item in this) {
      if (!test(item)) return false;
    }
    return true;
  }
}

void main() {
  print([2, 4, 6].all((n) => n.isEven)); // true
}
```

# --instructions--

Uzupełnij rozszerzenie tak, aby `countWhere` zwracało, ile elementów spełnia podaną funkcję `test`, tak aby program wypisał `2`, a potem `1`.

extension Counting<T> on List<T> {
  int countWhere([/] Function(T) test) {
    var count = 0;
    for (final item in [/]) {
      if (test(item)) count++;
    }
    return count;
  }
}

void main() {
  print([1, 2, 3, 4].countWhere((n) => n.isEven));
