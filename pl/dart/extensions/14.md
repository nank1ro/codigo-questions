# --instructions--

Klasa `Temperature` jest podana. Napisz rozszerzenie o nazwie `Conversions` na `Temperature` z:
- getterem `fahrenheit` typu `double`, równym `celsius * 9 / 5 + 32`
- metodą `isAbove`, która przyjmuje parametr `limit` typu `double` i zwraca `true`, gdy `celsius` jest większe niż `limit`

Przykład:
```dart
print(Temperature(100).fahrenheit);   // 212.0
print(Temperature(20).isAbove(25.0)); // false
```

extension Conversions on Temperature {
  double get fahrenheit => celsius * 9 / 5 + 32;

  bool isAbove(double limit) => celsius > limit;
}
