# --description--

Ponieważ `map` i `where` zwracają `Iterable`, ich wywołania można **łączyć w łańcuch** jedno po drugim. Każdy krok otrzymuje wynik poprzedniego, a `toList()` jest wywoływane raz na końcu:

```dart
var numbers = [1, 2, 3, 4, 5, 6];

var result = numbers.where((n) => n > 3).map((n) => n * 10).toList();
print(result); // [40, 50, 60]
```

# --instructions--

Napisz funkcję `oddSquares`, która przyjmuje parametr `numbers` typu `List<int>` i zwraca `List<int>` z kwadratami tylko nieparzystych liczb, w oryginalnej kolejności. Użyj `where` i `map` z funkcjami anonimowymi.

Przykład:
```dart
print(oddSquares([1, 2, 3, 4, 5])); // [1, 9, 25]
```

List<int> oddSquares(List<int> numbers) {
  return numbers.where((n) => n % 2 != 0).map((n) => n * n).toList();
}
