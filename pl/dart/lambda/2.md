# --description--

Funkcja anonimowa może przyjmować parametry i zwracać wartość za pomocą `return`, dokładnie jak funkcja nazwana. Typu zwracanego się nie pisze: Dart **wnioskuje** go z instrukcji `return` w ciele funkcji.

```dart
var add = (int a, int b) {
  return a + b;
};

print(add(2, 3)); // 5
```
