# --description--

`firstWhere` zwraca pierwszy element spełniający test. Gdy nic nie pasuje, nie ma elementu do zwrócenia, więc rzuca `StateError`:

```dart
final words = ['a', 'fg'];
print(words.firstWhere((w) => w.length > 3)); // Bad state: No element
```

Podobnie jak `int.tryParse`, biblioteka oferuje wyjście z sytuacji. Nazwany parametr `orElse` przyjmuje funkcję, która produkuje wartość do użycia, gdy nic nie pasowało:

```dart
print(words.firstWhere((w) => w.length > 3, orElse: () => 'none')); // none
```

Wybór jest taki sam jak wcześniej: `orElse`, gdy "nic nie pasowało" to zwykły wynik, nagie wywołanie, gdy oznaczałoby to, że dane są zepsute i ktoś musi się o tym dowiedzieć.

# --instructions--

Napisz dwie funkcje, które przyjmują `List<String>` `words`.

`firstLong` zwraca pierwsze słowo dłuższe niż trzy znaki za pomocą `firstWhere`, albo `'none'`, gdy takiego nie ma, z `orElse`.

`firstLongStrict` robi to samo za pomocą `firstWhere`, ale bez `orElse`, więc rzuca `StateError`, gdy takiego nie ma.

Przykład:
```dart
print(firstLong(['a', 'bcde', 'fg'])); // bcde
print(firstLong(['a', 'fg'])); // none
```

# --solutions--

```dart
String firstLong(List<String> words) {
  return words.firstWhere((w) => w.length > 3, orElse: () => 'none');
}

String firstLongStrict(List<String> words) {
  return words.firstWhere((w) => w.length > 3);
}
```
