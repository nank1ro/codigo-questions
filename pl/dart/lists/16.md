# --description--

Metoda `.indexOf(value)` zwraca indeks pierwszego elementu równego `value`. Jeśli wartości nie ma na liście, zwraca `-1`.

```dart
var colors = ['red', 'green', 'blue'];
print(colors.indexOf('green')); // 1
print(colors.indexOf('pink')); // -1
```
