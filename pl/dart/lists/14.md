# --description--

Właściwość `.isEmpty` ma wartość `true`, gdy lista nie ma elementów, a `.isNotEmpty` ma wartość `true`, gdy ma co najmniej jeden.

```dart
var colors = <String>[];
print(colors.isEmpty); // true
colors.add('red');
print(colors.isNotEmpty); // true
```
