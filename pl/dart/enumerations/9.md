# --instructions--

Mając `enum Size { small, medium, large }`, co się stanie z poniższym kodem?

```dart
String label(Size size) => switch (size) {
      Size.small => 'S',
      Size.medium => 'M',
    };
```

# --answers--

- Nie kompiluje się: wyrażenie `switch` nad enumem musi obejmować wszystkie wartości
- Kompiluje się i zwraca `null` dla `Size.large`
- Kompiluje się i rzuca wyjątkiem w czasie działania dla `Size.large`
- Kompiluje się i automatycznie zwraca `'L'` dla `Size.large`
