# --description--

Różnica ma znaczenie, gdy tylko użyjesz wartości. Na `Box<int?>` sięgasz do pola normalnie, a potem radzisz sobie z `null` w środku, natomiast na `Box<int>?` musisz najpierw ominąć brakujące pudełko:

```dart
Box<int?> a = Box(null);
print(a.value ?? 0); // 0, the box is there, its content is null

Box<int>? b = null;
print(b?.value ?? 0); // 0, the box itself is missing
```

Zapisanie `b.value` na `Box<int>?` w ogóle się nie skompiluje: Dart odmawia odczytania pola czegoś, co może nie istnieć.

# --instructions--

Dla `Box<int?> a = Box(null);` i `Box<int>? b = null;`, które stwierdzenie jest prawdziwe?

# --answers--

- `a` to prawdziwe pudełko, którego `value` to `null`, podczas gdy `b` w ogóle nie jest pudełkiem
- Obie deklaracje oznaczają to samo, `?` można zapisać po dowolnej stronie
- `a` się nie kompiluje, ponieważ argument typu nigdy nie może być nullowalny
- `b` to pudełko przechowujące `null`, podczas gdy `a` w ogóle nie jest pudełkiem
