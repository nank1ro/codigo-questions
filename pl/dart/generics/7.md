# --description--

Klasa może deklarować więcej niż jeden parametr typu, oddzielonych przecinkami. `Map<K, V>` to wbudowany przykład: jeden typ dla kluczy, jeden dla wartości.

```dart
class Entry<K, V> {
  final K key;
  final V value;

  Entry(this.key, this.value);
}

final e = Entry<String, int>('age', 30);
```

**Kolejność** jest częścią typu: `Entry<String, int>` i `Entry<int, String>` to niespokrewnione typy i wartości jednego nie można przypisać do drugiego. Parametry typu można też przestawiać w typie zwracanym — dzięki temu metoda może oddać odwróconą wersję obiektu:

```dart
Entry<V, K> get flipped => Entry(value, key);
```

# --instructions--

Zadeklaruj generyczną klasę `Pair` z dwoma parametrami typu `A` i `B`, polem `final` `first` typu `A` i polem `final` `second` typu `B`, oboma ustawianymi przez konstruktor, oraz getterem `swapped`, który zwraca `Pair<B, A>` przechowujący te same dwie wartości w odwrotnej kolejności.

Przykład:
```dart
final p = Pair<String, int>('age', 30);
print(p.first);         // age
print(p.swapped.first); // 30
```

# --asserts--

`Pair<String, int>('age', 30)` powinno mieć `first` równe `'age'` i `second` równe `30`

```dart
  test('test1', () {
    final pair = Pair<String, int>('age', 30);
    expect(pair.first, 'age', reason: '--err-t1--');
    expect(pair.second, 30, reason: '--err-t1--');
  });
```

`swapped` powinno zwracać `Pair<int, String>` z wartościami zamienionymi miejscami

```dart
  test('test2', () {
    final swapped = Pair<String, int>('age', 30).swapped;
    expect(swapped, isA<Pair<int, String>>(), reason: '--err-t2--');
    expect(swapped.first, 30, reason: '--err-t2--');
    expect(swapped.second, 'age', reason: '--err-t2--');
  });
```

`Pair` powinno działać z dowolnymi dwoma typami, a podwójna zamiana powinna dać z powrotem oryginalne wartości

```dart
  test('test3', () {
    final pair = Pair<bool, String>(true, 'yes');
    expect(pair.swapped.first, 'yes', reason: '--err-t3--');
    expect(pair.swapped.second, true, reason: '--err-t3--');
    expect(pair.swapped.swapped, isA<Pair<bool, String>>(), reason: '--err-t3--');
    expect(pair.swapped.swapped.first, true, reason: '--err-t3--');
  });
```

```dart
class Pair<A, B> {
  final A first;
  final B second;

  Pair(this.first, this.second);

  Pair<B, A> get swapped => Pair(second, first);
}
```
