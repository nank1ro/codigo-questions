# --description--

Generyczna klasa może mieć nazwane i **fabryczne** konstruktory jak każda inna klasa, a parametr typu jest dostępny w ich wnętrzu. Konstruktor fabryczny sam nie tworzy obiektu: wykonuje ciało i zwraca jeden, co pozwala mu wybrać, ponownie użyć albo zbudować instancję na dowolny sposób.

```dart
class Box<T> {
  final T value;

  Box(this.value);

  factory Box.first(List<T> items) => Box(items.first);
}

final b = Box<int>.first([5, 6]);
print(b.value); // 5
```

Argument typu zapisuje się przy klasie, a nie przy nazwie konstruktora: `Box<int>.first(...)`. Wewnątrz fabryki `<T>[]` to prawdziwa pusta `List<T>`, więc fabryka to naturalne miejsce do budowania wartości domyślnej dla typu, którego jeszcze nie znasz.

# --instructions--

Zadeklaruj generyczną klasę `Stack` z jednym parametrem typu `T`, polem `final` `items` typu `List<T>` ustawianym przez zwykły konstruktor, **fabrycznym** konstruktorem `Stack.empty()`, który buduje `Stack` z pustą listą, oraz getterem `top` typu `T?` zwracającym ostatni element albo `null`, gdy stos jest pusty.

Przykład:
```dart
print(Stack<int>([1, 2, 3]).top);  // 3
print(Stack<String>.empty().top);  // null
```

# --asserts--

`Stack<int>([1, 2, 3]).top` powinno być `3`

```dart
  test('test1', () {
    final stack = Stack<int>([1, 2, 3]);
    expect(stack.top, 3, reason: '--err-t1--');
    expect(stack.items, [1, 2, 3], reason: '--err-t1--');
  });
```

`Stack.empty()` powinno budować pusty stos właściwego typu, którego `top` to `null`

```dart
  test('test2', () {
    final stack = Stack<String>.empty();
    expect(stack, isA<Stack<String>>(), reason: '--err-t2--');
    expect(stack.items, <String>[], reason: '--err-t2--');
    expect(stack.top, null, reason: '--err-t2--');
  });
```

Lista zbudowana przez `Stack.empty()` powinna nadal nadawać się do użytku

```dart
  test('test3', () {
    final stack = Stack<int>.empty();
    stack.items.add(4);
    stack.items.add(9);
    expect(stack.top, 9, reason: '--err-t3--');
    expect(Stack<bool>([true]).top, true, reason: '--err-t3--');
  });
```

# --solutions--

```dart
class Stack<T> {
  final List<T> items;

  Stack(this.items);

  factory Stack.empty() => Stack(<T>[]);

  T? get top => items.isEmpty ? null : items.last;
}
```
