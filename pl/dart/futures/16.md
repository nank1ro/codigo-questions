# --description--

Ponieważ `await` zamienia błędy future w zwykłe wyjątki, do kodu asynchronicznego stosują się wszystkie typowe wzorce `try`/`catch`, w tym pętle z ponawianiem. Wewnątrz bloku `catch` **`rethrow`** rzuca ten sam błąd ponownie i w ten sposób poddajesz się po ostatniej próbie:

```dart
Future<String> onceThenGiveUp(Future<String> Function() task) async {
  try {
    return await task();
  } catch (e) {
    print('first attempt failed');
    rethrow; // the caller sees the original error
  }
}
```

Parametr o typie funkcyjnym, taki jak `Future<String> Function() task`, otrzymuje samą **funkcję**, a nie future: każde wywołanie `task()` rozpoczyna nową próbę.

# --instructions--

Napisz funkcję `async` `retry`, która przyjmuje `Future<int> Function()` `task` oraz `int` `attempts` i zwraca `Future<int>`. Wywołaj `task()` i zakończ jego wartością; jeśli rzuci wyjątek, spróbuj ponownie, wywołując `task` w sumie najwyżej `attempts` razy. Jeśli ostatnia próba też zawiedzie, rzuć jej błąd ponownie przez `rethrow`.

Przykład:
```dart
var count = 0;
Future<int> flaky() async {
  count++;
  if (count < 3) throw StateError('busy');
  return 7;
}
print(await retry(flaky, 5)); // 7, after 3 calls
```

# --asserts--

`retry` dla zadania, które zawsze się udaje, powinno zakończyć się jego wartością po jednym wywołaniu

```dart
  test('test1', () async {
    var count = 0;
    Future<int> fine() async {
      count++;
      return 42;
    }
    expect(await retry(fine, 3), 42, reason: '--err-t1--');
    expect(count, 1, reason: '--err-t1--');
  });
```

`retry` dla zadania, które zawodzi dwa razy, a potem zwraca `7`, powinno zakończyć się wartością `7` po `3` wywołaniach

```dart
  test('test2', () async {
    var count = 0;
    Future<int> flaky() async {
      count++;
      if (count < 3) throw StateError('busy');
      return 7;
    }
    expect(await retry(flaky, 5), 7, reason: '--err-t2--');
    expect(count, 3, reason: '--err-t2--');
  });
```

`retry` dla zadania, które zawsze zawodzi, powinno wywołać je dokładnie `attempts` razy, a potem zawieść z tym samym błędem

```dart
  test('test3', () async {
    var count = 0;
    Future<int> broken() async {
      count++;
      throw FormatException('bad');
    }
    await expectLater(retry(broken, 2), throwsA(isA<FormatException>()), reason: '--err-t3--');
    expect(count, 2, reason: '--err-t3--');
  });
```

# --solutions--

```dart
Future<int> retry(Future<int> Function() task, int attempts) async {
  var failures = 0;
  while (true) {
    try {
      return await task();
    } catch (e) {
      failures++;
      if (failures == attempts) rethrow;
    }
  }
}
```
