# --description--

Ponieważ struktura jest wartością, metoda nie może zmieniać jej właściwości, chyba że powiesz o tym słowem kluczowym `mutating`:
```swift
struct Counter {
    var value = 0

    mutating func increase(by amount: Int) {
        value += amount
    }
}

var c = Counter()
c.increase(by: 5)
print(c.value) // 5
```
Metodę mutating można wywołać tylko na instancji przechowywanej w `var`. Na instancji `let` wartość jest zamrożona, więc `c.increase(by: 5)` nie skompilowałoby się.

# --instructions--

Dodaj do `Counter` metodę mutating `increase`, która przyjmuje `Int` z etykietą argumentu `by` i dodaje go do `value`

Przykład użycia:
```swift
var c = Counter(value: 0)
c.increase(by: 5)
print(c.value)
// prints 5
```

# --asserts--

Metoda musi być oznaczona jako `mutating`

```json
{
  "regex": "mutating\\s+func\\s+increase",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Zwiększenie `0` o `5` musi dać `5`

```swift
var counterA = Counter(value: 0)
counterA.increase(by: 5)
tryCatch(counterA.value == 5)
```

Dwukrotne zwiększenie `10` musi się zsumować

```swift
var counterB = Counter(value: 10)
counterB.increase(by: 3)
counterB.increase(by: 2)
tryCatch(counterB.value == 15)
```

Zwiększenie o `0` nie może nic zmienić

```swift
var counterC = Counter(value: 4)
counterC.increase(by: 0)
tryCatch(counterC.value == 4)
```

Zmiana kopii nie może zmienić oryginału

```swift
var counterD = Counter(value: 1)
var counterE = counterD
counterE.increase(by: 9)
tryCatch(counterD.value == 1)
```
