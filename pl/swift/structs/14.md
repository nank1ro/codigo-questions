# --instructions--

Dlaczego ten kod się nie kompiluje?
```swift
struct Counter {
    var value = 0

    mutating func increase() {
        value += 1
    }
}

let c = Counter()
c.increase()
```

# --answers--

- `c` to stała `let`, więc nie można na niej wywołać metody mutating
- `increase` musi być oznaczone jako `static`, aby zmienić `value`
- `value` musi być zadeklarowane słowem `let`
- Struktura nie może zawierać metod
