# --description--

Rozszerzenia nie służą tylko do typów innych osób. Częstym sposobem organizowania własnego kodu jest trzymanie właściwości przechowywanych w ciele struktury lub klasy i dodawanie zachowań w jednym lub kilku rozszerzeniach, z których każde grupuje powiązane składowe:
```swift
struct Circle {
    var radius: Double
}
extension Circle {
    var diameter: Double {
        return radius * 2
    }
    func grown(by amount: Double) -> Circle {
        return Circle(radius: radius + amount)
    }
}
```
Składowe dodane w rozszerzeniu mogą korzystać z właściwości przechowywanych bezpośrednio, dokładnie tak, jakby były zapisane wewnątrz typu.

# --asserts--

Musisz użyć rozszerzenia `Rectangle`

```json
{
  "regex": "extension\\s+Rectangle",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

Pole prostokąta `2` na `3` musi być równe `6.0`

```swift
tryCatch(Rectangle(width: 2, height: 3).area == 6.0)
```

Pole prostokąta `1.5` na `4` musi być równe `6.0`

```swift
tryCatch(Rectangle(width: 1.5, height: 4).area == 6.0)
```

Prostokąt `2` na `3` przeskalowany przez `2` musi być `4` na `6`

```swift
let _r = Rectangle(width: 2, height: 3).scaled(by: 2)
tryCatch(_r.width == 4.0 && _r.height == 6.0)
```

Skalowanie nie może zmieniać oryginalnego prostokąta

```swift
let _o = Rectangle(width: 2, height: 3)
let _s = _o.scaled(by: 0.5)
tryCatch(_o.width == 2.0 && _o.height == 3.0 && _s.area == 1.5)
```

# --solutions--

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
extension Rectangle {
    var area: Double {
        return width * height
    }
    func scaled(by factor: Double) -> Rectangle {
        return Rectangle(width: width * factor, height: height * factor)
    }
}
```
