# --description--

Rozszerzenia mogą tylko **dodawać** składowe, nigdy zastępować ani nadpisywać istniejących. `override` należy do podklas, które są innym typem niż ich nadklasa; rozszerzenie to ten sam typ, więc zadeklarowanie metody, która już istnieje, to błąd ponownej deklaracji:
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String { // error: invalid redeclaration of 'speak()'
        return "Bark"
    }
}
```
Jeśli potrzebujesz innego zachowania, dodaj metodę o nowej nazwie albo napisz podklasę, gdy typ jest klasą.

# --instructions--

Co się stanie, gdy ten program zostanie skompilowany i uruchomiony?
```swift
struct Dog {
    func speak() -> String {
        return "Woof"
    }
}
extension Dog {
    func speak() -> String {
        return "Bark"
    }
}
print(Dog().speak())
```

# --answers--

- Nie kompiluje się, ponieważ `speak()` jest zadeklarowane dwa razy dla tego samego typu
- Wyświetla `Bark`, ponieważ rozszerzenie nadpisuje oryginalną metodę
- Wyświetla `Woof`, ponieważ oryginalna metoda wygrywa z rozszerzeniem
- Wyświetla `Woof`, a potem `Bark`
