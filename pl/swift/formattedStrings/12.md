# --description--

Flagi szerokości działają tylko wewnątrz `String(format:)`. Aby samodzielnie dopełnić zwykły ciąg znaków, zbuduj spacje za pomocą `String(repeating:count:)` i dołącz je do tekstu:
```swift
let text = "7"
let spaces = String(repeating: " ", count: 4 - text.count)
print(spaces + text + "|") //    7|
```
Jeśli tekst jest już dłuższy niż szerokość, `4 - text.count` staje się ujemne i `String(repeating:count:)` ulega awarii. Zabezpiecz to przez `max(0, ...)`, dzięki czemu liczba nigdy nie spadnie poniżej zera, a długi tekst pozostanie bez zmian.

# --instructions--

Napisz funkcję `leftPad`, która przyjmuje tekst (`String`) i szerokość (`Int`), oba bez etykiet argumentów, i zwraca tekst wyrównany do prawej w tej szerokości przez dodanie spacji po lewej. Tekst dłuższy niż szerokość musi zostać zwrócony bez zmian

Przykład wywołania funkcji:
```swift
print(leftPad("7", 4) + "|")
// prints    7|
```

func leftPad(_ text: String, _ width: Int) -> String {
    let spaces = String(repeating: " ", count: max(0, width - text.count))
    return spaces + text
}
