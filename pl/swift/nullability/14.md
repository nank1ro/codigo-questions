# --description--

Wiązanie kilku opcjonałów w jednym `if let` sprawia, że kod pozostaje płaski: jeden blok `else` obejmuje wszystkie brakujące wartości.

# --instructions--

Ułóż elementy tak, aby wypisać `Area: 20`, gdy zarówno `width`, jak i `height` mają wartość, oraz `Missing size` w przeciwnym razie.
Zadeklaruj `width` przed `height`

# --answers--


```swift
let height: Int? = 5
```

# --solutions--

```swift
let width: Int? = 4
let height: Int? = 5
if let w = width, let h = height {
    print("Area: \(w * h)")
} else {
    print("Missing size")
}
```
