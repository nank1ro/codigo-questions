Konwersje, które mogą się nie powieść, naturalnie łączą się z `guard let`: przekonwertuj, wyjdź, gdy wynik jest `nil`, a następnie pracuj ze zwykłą wartością.

# --instructions--

Następnie wypisz wyniki, używając `0` jako wartości domyślnej

func doubled(_ text: String) -> Int? {
    guard let number = [/](text) else { return [/] }
    return number * 2
}
print(doubled("21") [/] 0)
print(doubled("x") ?? 0)
