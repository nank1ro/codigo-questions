# --description--

Ponieważ ciąg znaków jest kolekcją znaków, możesz iterować po nim za pomocą pętli `for`-`in`. Każda iteracja daje ci jeden `Character`:
```swift
for letter in "hey" {
    print(letter)
}
// h
// e
// y
```
`Character` można porównać operatorem `==` z literałem znakowym, więc zliczanie, ile razy pojawia się dany znak, to po prostu pętla i licznik.

# --instructions--

Napisz funkcję `occurrences`, która przyjmuje `Character` z etykietą argumentu `of` oraz `String` z etykietą argumentu `in`, i zwraca, ile razy dany znak występuje w ciągu.

Example of function call:
```swift
print(occurrences(of: "l", in: "hello"))
// prints 2
```

# --solutions--

```swift
func occurrences(of target: Character, in text: String) -> Int {
    var total = 0
    for letter in text {
        if letter == target {
            total += 1
        }
    }
    return total
}
```
