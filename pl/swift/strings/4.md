# --description--

Właściwość `count` zwraca liczbę znaków w ciągu, a `isEmpty` ma wartość `true`, gdy ciąg nie zawiera żadnych znaków:
```swift
print("Swift".count) // 5
print("".isEmpty)    // true
```
Liczony jest każdy znak, w tym spacje i znaki interpunkcyjne.
