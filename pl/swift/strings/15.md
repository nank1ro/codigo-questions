# --description--

Dzielenie po spacji to najprostszy sposób na rozbicie zdania na słowa, a łączenie to sposób na odbudowanie tekstu z tablicy.

# --instructions--

Napisz funkcję `wordCount`, która przyjmuje `String` (pomiń etykietę argumentu) i zwraca liczbę słów oddzielonych spacjami, oraz funkcję `slug`, która przyjmuje tablicę `String` (pomiń etykietę argumentu) i zwraca słowa połączone znakiem `-`

Przykład wywołania funkcji:
```swift
print(wordCount("hello big world"))
// prints 3
print(slug(["hello", "world"]))
// prints hello-world
```

# --solutions--

```swift
func wordCount(_ sentence: String) -> Int {
    return sentence.split(separator: " ").count
}

func slug(_ words: [String]) -> String {
    return words.joined(separator: "-")
}
```
