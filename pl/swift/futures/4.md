# --description--

Praca rozłożona w czasie często kończy się niepowodzeniem: serwer nie działa, plik nie istnieje, dane wejściowe są błędne. Taka funkcja jest oznaczona **`async throws`** i jest wywoływana z **`try await`**:
```swift
enum LoadError: Error {
    case missing
}

func load(_ name: String) async throws -> String {
    if name.isEmpty {
        throw LoadError.missing
    }
    return "file: \(name)"
}
```
Aby obsłużyć błąd, owijasz wywołanie w blok `do` i łapiesz go:
```swift
do {
    let text = try await load("")
    print(text)
} catch {
    print("could not load")
}
// wypisuje could not load
```
Kolejność słów kluczowych jest ustalona: najpierw `try`, potem `await`.

# --instructions--

Napisz funkcję `parse`, która przyjmuje ciąg znaków (pomiń etykietę argumentu), jest asynchroniczna, może zgłaszać błąd i zwraca ciąg znaków skonwertowany na `Int`. Jeśli ciąg znaków nie jest liczbą, zgłoś `InputError.notANumber`

Przykład wywołania funkcji:
```swift
print(try await parse("7"))
// wypisuje 7
```

# --asserts--

Funkcja musi być oznaczona jako `async throws`

```json
{
  "regex": "func\\s+parse\\s*\\([^)]*\\)\\s*async\\s+throws",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`parse("7")` musi zwrócić `7`

```swift
do {
    let value = try await parse("7")
    tryCatch(value == 7)
} catch {
    tryCatch(false)
}
```

`parse("-3")` musi zwrócić `-3`

```swift
do {
    let value = try await parse("-3")
    tryCatch(value == -3)
} catch {
    tryCatch(false)
}
```

`parse("abc")` musi zgłosić błąd

```swift
do {
    _ = try await parse("abc")
    tryCatch(false)
} catch {
    tryCatch(true)
}
```

enum InputError: Error {
    case notANumber
}

func parse(_ text: String) async throws -> Int {
    guard let value = Int(text) else {
        throw InputError.notANumber
    }
    return value
}
