# --description--

`FIXME` różni się od `TODO`: kod już istnieje, ale wiadomo, że jest błędny. # --asserts--

Komentarz `FIXME` musi zostać usunięty

```json
{
  "regex": "FIXME",
  "modifiers": ["m"],
  "shouldMatch": false
}
```

Komentarz dokumentacyjny `///` musi zostać zachowany

```json
{
  "regex": "/// Returns the average",
  "modifiers": ["m"],
  "shouldMatch": true
}
```

`average(4, 6)` musi zwrócić `5`

```swift
tryCatch(average(4, 6) == 5)
```

`average(10, 20)` musi zwrócić `15`

```swift
tryCatch(average(10, 20) == 15)
```

`average(3, 4)` musi zwrócić `3`

```swift
tryCatch(average(3, 4) == 3)
```
