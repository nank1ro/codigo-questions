# --description--

`Int(text)` udaje się tylko wtedy, gdy cały tekst jest poprawną liczbą całkowitą, z opcjonalnym znakiem:
```swift
print(Int("42"))   // Optional(42)
print(Int("-7"))   // Optional(-7)
print(Int("3.5"))  // nil, not a whole number
print(Int(" 42"))  // nil, spaces are not allowed
print(Int("abc"))  // nil
```
Dla tekstu dziesiętnego użyj `Double(text)`, który w ten sam sposób zwraca `Double?`: `Double("3.5")` to `Optional(3.5)`.

# --instructions--

Napisz funkcję `sumOfNumbers`, która przyjmuje tablicę `String` (pomiń etykietę argumentu) i zwraca sumę tych, które są poprawnymi liczbami całkowitymi, ignorując pozostałe

Przykład wywołania funkcji:
```swift
print(sumOfNumbers(["1", "2", "x"]))
// prints 3
```

# --solutions--

```swift
func sumOfNumbers(_ texts: [String]) -> Int {
    var sum = 0
    for text in texts {
        if let number = Int(text) {
            sum += number
        }
    }
    return sum
}
```
