# --description--

Protokół może też wymagać **metod**. Piszesz sygnaturę — nazwę, parametry i typ zwracany — i na tym kończysz, bez ciała:
```swift
protocol Greeter {
    func greet() -> String
}
```
Zgodny typ musi zadeklarować metodę o dokładnie tej sygnaturze i to on dostarcza ciało:
```swift
struct Robot: Greeter {
    func greet() -> String {
        return "BEEP"
    }
}

print(Robot().greet()) // BEEP
```
Jeśli cokolwiek się różni — nazwa, typ parametru, typ zwracany — typ nie jest zgodny, a kompilator powie ci, którego wymagania brakuje.

# --instructions--

Spraw, aby `Friendly` był zgodny z `Greeter`, dodając wymaganą metodę `greet()`, zwracającą nazwę między `Hello, ` a `!`

Przykład użycia:
```swift
print(Friendly(name: "Ada").greet())
// prints Hello, Ada!
```

}

# --asserts--

`Friendly(name: "Ada")` musi witać słowami `Hello, Ada!`

```swift
tryCatch(_asGreeter(Friendly(name: "Ada")) == "Hello, Ada!")
```

`Friendly(name: "Bo")` musi witać słowami `Hello, Bo!`

```swift
tryCatch(_asGreeter(Friendly(name: "Bo")) == "Hello, Bo!")
```

Pusta nazwa musi witać słowami `Hello, !`

```swift
tryCatch(_asGreeter(Friendly(name: "")) == "Hello, !")
```
