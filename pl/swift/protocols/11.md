# --description--

Protokół może budować na innym. Zapisanie nazwy protokołu po dwukropku sprawia, że nowy protokół **dziedziczy** każde wymaganie starego:
```swift
protocol Named {
    var name: String { get }
}

protocol Aged: Named {
    var age: Int { get }
}
```
Typ zgodny z `Aged` musi zapewniać `age` *i* `name`, i wszędzie liczy się jako typ `Named`. Protokół może dziedziczyć po kilku protokołach naraz, oddzielonych przecinkami.

}

# --before-asserts--

```swift
extension Timed {
    func label() -> String {
        return "\(name) \(seconds)"
    }
}

func _name(_ n: Named) -> String {
    return n.name
}
```

# --asserts--

Utwór o nazwie `Intro` i długości `90` sekund musi mieć etykietę `Intro 90`

```swift
tryCatch(Track(name: "Intro", seconds: 90).label() == "Intro 90")
```

Utwór o nazwie `Outro` i długości `5` sekund musi mieć etykietę `Outro 5`

```swift
tryCatch(Track(name: "Outro", seconds: 5).label() == "Outro 5")
```

Utwór o nazwie `Gap` i długości `0` sekund musi mieć etykietę `Gap 0`

```swift
tryCatch(Track(name: "Gap", seconds: 0).label() == "Gap 0")
```

Wartość `Timed` musi dać się użyć jako wartość `Named`

```swift
tryCatch(_name(Track(name: "Intro", seconds: 90)) == "Intro")
```
