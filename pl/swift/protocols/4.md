# --description--

Protokoły nie ograniczają się do struktur. **Klasa** jest zgodna dokładnie w ten sam sposób, wymieniając protokół po dwukropku:
```swift
protocol Openable {
    func open() -> String
}

class Door: Openable {
    func open() -> String {
        return "creak"
    }
}
```
Jeśli klasa dziedziczy też po innej klasie, nadklasa stoi pierwsza na liście, a protokoły następują po niej. Typ może przyjąć kilka protokołów naraz, oddzielonych przecinkami.

# --instructions--

Spraw, aby klasa `Box` była zgodna z `Sized`, zwracając liczbę przechowywanych przez nią elementów

Przykład użycia:
```swift
print(Box(items: ["pen", "key"]).size())
// wypisuje 2
```

# --before-asserts--

```swift
func _asSized(_ s: Sized) -> Int {
    return s.size()
}
```

# --asserts--

Pudełko z `pen` i `key` musi mieć rozmiar `2`

```swift
tryCatch(_asSized(Box(items: ["pen", "key"])) == 2)
```

Puste pudełko musi mieć rozmiar `0`

```swift
tryCatch(_asSized(Box(items: [])) == 0)
```

Pudełko z trzema elementami musi mieć rozmiar `3`

```swift
tryCatch(_asSized(Box(items: ["a", "b", "c"])) == 3)
```

# --solutions--

```swift
protocol Sized {
    func size() -> Int
}

class Box: Sized {
    var items: [String]

    init(items: [String]) {
        self.items = items
    }

    func size() -> Int {
        return items.count
    }
}
```
