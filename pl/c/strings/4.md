# --description--

Ponieważ ciąg znaków jest tablicą, każdy znak ma indeks zaczynający się od `0`:
```c
char word[] = "Coding";
word[0]; // 'C'
word[5]; // 'g'
```
Pojedynczy znak wyświetla się za pomocą `%c`. Znaki można też podmieniać:
```c
word[0] = 'K'; // word is now "Koding"
```
