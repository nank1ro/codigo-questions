# --description--

Nagłówek `ctype.h` udostępnia funkcje działające na pojedynczym znaku.
`toupper(c)` zwraca wielką literę, a `tolower(c)` małą; każdy inny znak jest zwracany bez zmian:
```c
char letter = toupper('a'); // 'A'
```

# --instructions--
