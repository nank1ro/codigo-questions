# --description--

`strcat(destination, source)` dołącza `source` na końcu `destination`:
```c
char text[20] = "Hello";
strcat(text, " World");
// text is now "Hello World"
```
Podobnie jak w `strcpy`, tablica docelowa musi mieć wystarczająco dużo miejsca na wynik.
