# --description--

Gdy każdy przypadek `switch` obsługuje jedną stałą, pamiętaj o `break` po każdym z nich, w przeciwnym razie wykonanie przechodzi do kolejnego przypadku.
Przypadek `default` nie jest wymagany, jeśli obsłużysz wszystkie stałe wyliczenia.

# --instructions--

Uporządkuj linie, aby zadeklarować `enum Size`, zapisać `MEDIUM` w `size` i wypisać `Medium` za pomocą `switch`. Zachowaj przypadki w tej samej kolejności co stałe w deklaracji

# --answers--

```c
enum Size { SMALL, MEDIUM, LARGE };
```

```c
enum Size size = MEDIUM;
```


# --solutions--

```c
enum Size { SMALL, MEDIUM, LARGE };
enum Size size = MEDIUM;
switch (size) {
    case SMALL: printf("Small\n"); break;
    case MEDIUM: printf("Medium\n"); break;
    case LARGE: printf("Large\n"); break;
}
```

# --output--

Medium
