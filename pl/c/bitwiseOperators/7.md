# --description--

Każdy binarny operator bitowy ma formę **przypisania złożonego**, która aktualizuje zmienną w miejscu: `&=`, `|=`, `^=`, `<<=` i `>>=`.
```c
unsigned int x = 12;
x &= 10;  // same as x = x & 10;
x |= 1;   // same as x = x | 1;
x ^= 3;   // same as x = x ^ 3;
x <<= 1;  // same as x = x << 1;
x >>= 2;  // same as x = x >> 2;
```
Są czytelniejsze niż powtarzanie nazwy zmiennej i stanowią typowy sposób zmieniania bitów zmiennej flagowej.

# --instructions--

Ułóż linie tak, aby `flags` zaczynało od `0x01`, następnie za pomocą `|=` został włączony bit o wartości `4`, potem za pomocą `<<=` zostało przesunięte o 2 miejsca w lewo, a na końcu zostało wypisane
