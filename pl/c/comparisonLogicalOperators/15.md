# --description--

Pętla `while` działa dopóki jej warunek jest różny od zera, więc to porównanie decyduje, kiedy się zatrzyma:
```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
// wypisuje 0, 1, 2
```
Wybór między `<` a `<=` decyduje o tym, czy ostatnia wartość zostanie uwzględniona.
