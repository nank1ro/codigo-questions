# --description--

Wielkie i małe litery są oddalone o `32` pozycje w tabeli ASCII: `'A'` to `65`, a `'a'` to `97`.
Odjęcie `32` od małej litery daje więc jej wielką wersję, a wynik można zapisać z powrotem w `char`:
```c
char upper = 'g' - 32; // 'G'
```

# --instructions--

Uporządkuj linie tak, aby zapisać literę `'a'` w `letter`, obliczyć jej wielką wersję w `upper` i wypisać każdą z nich jako znak, po którym następuje jej kod (najpierw `letter`)

# --answers--

```c
char letter = 'a';
```

```c
char upper = letter - 32;
```

```c
printf("%c %d\n", letter, letter);
```

```c
printf("%c %d\n", upper, upper);
```
